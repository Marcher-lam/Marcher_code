# 人工智能算法按应用场景分类总表

> 说明：人工智能算法很难做到“世界上所有算法”逐一穷尽，因为算法、模型和任务仍在快速演化。本表按**应用场景**组织，尽量覆盖当前主流 AI 落地方向，并列出每类场景常见的算法、模型、方法与理论框架，方便后续做知识库、课程大纲或项目选型。

1. 明确输入数据类型：文本、图像、音频、视频、表格、图、时间序列、传感器、多模态。
2. 明确输出目标：分类、回归、排序、生成、检索、规划、控制、优化。
3. 明确约束：实时性、成本、隐私、可解释性、准确率、召回率、安全性。
4. 选择算法族：传统 ML、深度学习、强化学习、生成模型、图模型、优化算法。
5. 建立基线模型，再逐步替换为复杂模型。

# 25. 总结

人工智能算法按应用场景可以粗略分为：

1. 感知类：视觉、语音、传感器、多模态。
2. 认知类：文本理解、知识推理、问答、推理规划。
3. 生成类：文本、图像、语音、视频、3D、代码生成。
4. 预测类：分类、回归、时间序列、风险预测、异常检测。
5. 推荐与检索类：搜索、推荐、广告、排序。
6. 决策优化类：调度、路径、库存、定价、资源配置。
7. 控制与机器人类：自动驾驶、机器人、强化学习、控制系统。
8. 科学与工程类：药物、材料、能源、制造、气候、仿真。
9. 安全与治理类：网络安全、模型安全、隐私、公平、可解释。
10. 工程平台类：AutoML、MLOps、部署、监控、评测。

实际项目中，一个完整 AI 系统通常不是单一算法，而是多个算法族的组合，例如：

- 智能客服 = ASR + NLP + RAG + LLM + TTS + 质检模型
- 自动驾驶 = 感知 + 预测 + 规划 + 控制 + 仿真 + 安全监控
- 医疗影像系统 = 图像分割 + 分类 + 检索 + 报告生成 + 可解释 AI
- 推荐系统 = 召回 + 粗排 + 精排 + 重排 + Bandit + 因果评估
- 工业质检 = 视觉检测 + 异常检测 + 追溯分析 + 边缘部署
