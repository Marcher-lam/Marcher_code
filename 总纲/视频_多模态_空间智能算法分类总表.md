# 视频、多模态与空间智能算法分类总表

> 说明：视频、多模态与空间智能是当前 AI 从“看图识别”走向“理解时间、融合多模态、理解三维世界并能行动”的核心方向。  
> 本文按 **视频理解、视频生成、多模态学习、视觉语言模型、音视频多模态、三维视觉、空间智能、世界模型、具身智能、机器人与 Agent** 系统分类。

---

## 0. 总体分类框架

视频、多模态与空间智能可以分为 15 大类：

| 大类 | 代表任务 |
|---|---|
| 视频基础处理 | 抽帧、压缩、去噪、超分、插帧、稳像 |
| 视频理解 | 视频分类、动作识别、事件检测、视频问答 |
| 视频目标检测 | 视频目标检测、时序检测、开放词汇视频检测 |
| 视频分割 | 视频语义分割、视频实例分割、视频目标分割 |
| 视频跟踪 | 单目标跟踪、多目标跟踪、ReID、轨迹预测 |
| 视频生成 | 文生视频、图生视频、视频续写、视频编辑 |
| 多模态表示学习 | 图文、音文、视听、视频语言统一表征 |
| 视觉语言模型 | CLIP、BLIP、LLaVA、Qwen-VL、InternVL 等 |
| 视频语言模型 | Video-LLaVA、VideoChat、Video-ChatGPT、Gemini 视频理解等 |
| 音视频多模态 | 视听语音识别、声源定位、视听分离、音视频生成 |
| 三维视觉 | 深度估计、SLAM、三维重建、点云、NeRF、3DGS |
| 空间智能 | 3D 场景理解、空间关系推理、导航、交互、物理预测 |
| 世界模型 | 环境动力学建模、视频预测、可交互仿真、规划 |
| 具身智能 | 机器人感知、操作、导航、任务规划、VLA/VLAM |
| 多智能体空间系统 | 多机器人协作、交通仿真、群体智能、空间 Agent |

# 7. 视觉语言模型算法

## 7.1 VLM 总体架构

视觉语言模型通常包含视觉编码器、文本处理模块、跨模态对齐或交互模块。近年 VLM 综述通常将架构、对齐方法、基准和评测作为核心分析维度。

典型结构：

```text
Image / Video
  ↓
Vision Encoder
  ↓
Projector / Q-Former / Cross Attention
  ↓
LLM
  ↓
Text Output / Tool Action
```

核心组件：

- Vision Encoder
- Image Tokenizer
- Projector
- Q-Former
- Cross-Attention
- LLM Backbone
- Multimodal Instruction Tuning

# 23. 总结

视频、多模态与空间智能算法可以概括为以下大类：

1. **视频基础处理**：去噪、超分、插帧、稳像、压缩  
2. **视频理解**：分类、动作识别、事件检测、异常检测、视频摘要  
3. **视频检测分割跟踪**：视频目标检测、实例分割、目标分割、多目标跟踪  
4. **视频语言模型**：视频描述、视频问答、长视频理解、视频 RAG  
5. **视频生成**：文生视频、图生视频、视频续写、视频编辑、可控视频生成  
6. **多模态学习**：多模态融合、对齐、预训练、缺失模态鲁棒学习  
7. **视觉语言模型**：CLIP、BLIP、LLaVA、Qwen-VL、InternVL、Florence 等  
8. **音视频多模态**：AVSR、唇读、声源定位、视听分离、Talking Head  
9. **三维视觉**：深度、光流、SLAM、三维重建、点云、NeRF、3DGS  
10. **空间智能**：空间关系、场景图、占据建模、BEV、空间推理  
11. **世界模型**：视频预测、3D 世界模型、物理世界模型、规划 rollout  
12. **具身智能**：机器人导航、操作、VLA、任务规划、Sim-to-Real  
13. **空间 RAG / Embodied RAG**：地图、场景图、轨迹、经验记忆检索  
14. **多智能体空间系统**：多机器人、自动驾驶协同、群体智能、空间 Agent  

一句话总结：

> 视频、多模态与空间智能正在把 AI 从“识别静态图片和文本”，推进到“理解时间、融合感官、建模三维世界、预测未来并在空间中行动”的新阶段。
