# 图像算法分类总表：分类、检测、分割、生成、三维视觉、多模态视觉

> 说明：图像算法属于计算机视觉（Computer Vision）的核心组成部分，覆盖从传统图像处理、特征工程、几何视觉，到深度学习、视觉 Transformer、生成式图像模型、多模态视觉大模型等完整技术栈。  
> 本文按 **任务类型、算法范式、模型架构、应用场景、工程部署** 系统整理。

---

## 0. 图像算法总览

图像算法可以按任务分为以下大类：

| 大类 | 典型任务 |
|---|---|
| 图像基础处理 | 去噪、增强、滤波、边缘检测、直方图均衡 |
| 图像分类 | 单标签分类、多标签分类、细粒度分类、开放集分类 |
| 图像检测 | 目标检测、人脸检测、缺陷检测、小目标检测 |
| 图像分割 | 语义分割、实例分割、全景分割、医学分割 |
| 图像定位 | 关键点检测、姿态估计、目标定位、地标检测 |
| 图像匹配 | 特征匹配、图像配准、图像检索、相似图搜索 |
| 图像跟踪 | 单目标跟踪、多目标跟踪、检测跟踪联合 |
| OCR 与文档视觉 | 文字检测、文字识别、版面分析、表格识别 |
| 三维视觉 | 深度估计、SLAM、三维重建、点云处理、NeRF |
| 图像生成 | GAN、VAE、扩散模型、文生图、图生图 |
| 图像编辑 | 修复、超分、风格迁移、抠图、换脸、局部编辑 |
| 视觉理解 | 场景理解、视觉问答、图像描述、视觉推理 |
| 多模态视觉 | CLIP、VLM、视觉语言模型、图文检索 |
| 视频视觉 | 视频分类、动作识别、视频分割、视频生成 |
| 视觉工程 | 模型压缩、加速部署、边缘视觉、工业检测 |

# 23. 总结

图像算法可以概括为以下大类：

1. **传统图像处理**：滤波、增强、去噪、边缘、形态学、特征点  
2. **图像分类**：传统特征分类、CNN、ViT、自监督、零样本分类  
3. **目标检测**：传统检测、两阶段检测、单阶段检测、DETR、开放词汇检测  
4. **图像分割**：语义分割、实例分割、全景分割、医学分割、SAM 交互分割  
5. **人脸视觉**：检测、关键点、识别、属性、活体、生成编辑  
6. **姿态估计**：人体、手部、脸部、动物、2D/3D 姿态  
7. **OCR 文档视觉**：文字检测、文字识别、表格识别、版面分析  
8. **匹配检索配准**：特征匹配、图像配准、以图搜图、相似图搜索  
9. **目标跟踪**：单目标、多目标、视频目标分割  
10. **图像生成**：GAN、VAE、Flow、Diffusion、自回归图像生成  
11. **图像编辑复原**：修复、超分、去模糊、去雾、风格迁移、抠图  
12. **三维视觉**：深度估计、光流、SLAM、三维重建、点云、NeRF、3DGS  
13. **行业视觉**：遥感、医学、工业、交通、零售、内容创作  
14. **多模态视觉**：CLIP、BLIP、LLaVA、Qwen-VL、视觉问答、视觉推理  
15. **视频视觉**：视频分类、动作识别、视频检测、视频分割、视频生成  

一句话总结：

> 图像算法正在从“传统图像处理 + CNN 识别”，发展到“视觉 Transformer + 通用分割 + 生成式扩散模型 + 多模态视觉大模型”的统一视觉智能体系。
