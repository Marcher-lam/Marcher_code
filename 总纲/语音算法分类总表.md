# 语音算法分类总表：ASR、TTS、端到端语音、声音生成、声音克隆与语音大模型

> 说明：语音算法不是单一技术，而是覆盖 **语音信号处理、语音识别、语音合成、语音生成、语音理解、说话人建模、语音增强、语音转换、语音大模型、实时对话系统** 的完整技术体系。  
> 本文按“任务场景 → 模型架构 → 训练范式 → 工程系统 → 应用方向”详细分类。

---

## 0. 语音算法总览

语音技术可以粗略分为 12 大类：

| 大类 | 代表任务 |
|---|---|
| 语音信号处理 | 分帧、加窗、降噪、特征提取、端点检测 |
| 语音前端 | VAD、降噪、回声消除、声源定位、波束形成 |
| ASR 语音识别 | 语音转文字、实时听写、会议转写 |
| 端到端 ASR | CTC、Attention、RNN-T、Conformer、Whisper 类模型 |
| TTS 语音合成 | 文本转语音、播报、虚拟人配音 |
| 端到端 TTS | Tacotron、FastSpeech、VITS、Diffusion TTS、Audio LLM TTS |
| 声音生成 | 语音、音效、音乐、环境声生成 |
| 声音克隆 | 说话人复刻、零样本克隆、跨语言克隆 |
| 语音转换 | Voice Conversion、音色转换、情感转换 |
| 说话人算法 | 说话人识别、验证、分离、日志分离 |
| 语音理解 | 情感识别、意图识别、关键词检测、语音问答 |
| 语音大模型 | SpeechLM、AudioLM、端到端语音对话、多模态语音 Agent |

# 4. 端到端 ASR 算法

## 4.1 端到端 ASR 总览

端到端 ASR 直接从语音到文字，减少传统 ASR 的中间模块。

主要路线：

| 路线 | 代表算法 |
|---|---|
| CTC | DeepSpeech、wav2letter、Conformer-CTC |
| Attention Encoder-Decoder | Listen Attend and Spell、Transformer ASR |
| RNN-T / Transducer | RNN-T、Transformer Transducer、Conformer Transducer |
| CTC-Attention Hybrid | ESPnet、WeNet U2 |
| AED + LM | Whisper 类模型 |
| Speech Foundation Model | wav2vec 2.0、HuBERT、WavLM、Whisper |
| Large Speech Model | SeamlessM4T、Qwen-Audio、SpeechGPT 类 |

端到端 ASR 综述通常将其按建模、训练、解码和语言模型融合等维度分类，典型模型包括 CTC、Attention Encoder-Decoder 与 Transducer 系列。

---

## 4.2 CTC ASR

CTC = Connectionist Temporal Classification。

代表算法：

- CTC
- DeepSpeech
- Wav2Letter
- Jasper-CTC
- QuartzNet-CTC
- Conformer-CTC
- Transformer-CTC
- Branchformer-CTC
- Zipformer-CTC

特点：

- 不需要帧级对齐
- 训练稳定
- 解码较简单
- 适合流式或准流式系统

缺点：

- 条件独立假设较强
- 语言建模能力弱
- 依赖外部 LM 提升效果

---

## 4.3 Attention Encoder-Decoder ASR

代表算法：

- Listen, Attend and Spell
- LAS
- Transformer ASR
- Conformer AED
- Speech-Transformer
- Speech2Text Transformer
- Whisper-like Seq2Seq ASR

特点：

- 编码器提取声学特征
- 解码器自回归生成文本
- 内建语言建模能力强

缺点：

- 流式识别困难
- 长音频稳定性问题
- 可能漏词、重复或幻觉

# 6. 端到端 TTS 算法

## 6.1 端到端 TTS 定义

路线：

| 类型 | 代表模型 |
|---|---|
| Text-to-Mel + Vocoder | Tacotron 2 + WaveNet / HiFi-GAN |
| Non-autoregressive | FastSpeech 2 + Vocoder |
| Flow-based | Glow-TTS、VITS |
| GAN-based | VITS、GAN-TTS |
| Diffusion-based | Grad-TTS、Diff-TTS、NaturalSpeech |
| Codec-token-based | VALL-E、AudioLM、Bark、CosyVoice |
| Fully end-to-end waveform | VITS、E2E neural vocoder models |

# 24. 总结

语音算法可以从任务上分为：

1. **语音前端**：VAD、降噪、回声消除、波束形成、语音分离  
2. **ASR**：传统 HMM、混合 DNN-HMM、端到端 CTC / Attention / RNN-T / Conformer / Whisper  
3. **TTS**：传统拼接与参数合成、神经 TTS、端到端 TTS、扩散 TTS、Codec TTS  
4. **声音生成**：语音、音乐、音效、环境声生成  
5. **声音克隆**：多样本、少样本、零样本、跨语言、情感克隆  
6. **语音转换**：音色转换、情感转换、口音转换、歌声转换  
7. **说话人算法**：识别、验证、分离、日志分离  
8. **语音增强**：降噪、去混响、超分辨率、修复  
9. **语音理解**：关键词、情感、意图、语音翻译、语音问答  
10. **语音大模型**：SpeechLM、AudioLM、Speech-to-Speech LLM、多模态语音 Agent  

一句话总结：

> 现代语音技术正在从“ASR + TTS 的模块化流水线”，演进到“语音大模型 + 神经音频 Codec + 实时 Agent”的端到端语音智能系统。
