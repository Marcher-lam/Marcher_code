# 9. 混合精度训练

## 9.1 混合精度基本概念

混合精度训练将不同操作分配到不同精度：线性层和卷积等适合低精度，归一化、规约、累加等敏感操作保留高精度。PyTorch AMP 文档强调 autocast 与 GradScaler 是混合精度训练的关键组件。

精度类型：

- FP32
- TF32
- FP16
- BF16
- FP8
- FP4
- INT8
- Mixed Precision

# 10. 显存优化技术

## 10.1 Activation Checkpointing

又称：

- Gradient Checkpointing
- Activation Recomputation
- Recompute

思想：

```text
前向时不保存所有中间激活；
反向时重新计算部分激活。
```

优点：

- 显著降低显存
- 支持更大 batch / 更大模型

代价：

- 额外计算
- 训练时间增加

---

## 10.2 Gradient Accumulation

思想：

```text
多个 micro-batch 累积梯度，再执行一次 optimizer step。
```

适用：

- 显存不足
- 模拟大 batch
- 稳定训练

---

# 11. 分布式训练技术

## 11.1 数据并行

每个 GPU 拥有完整模型副本，处理不同数据 batch，再同步梯度。

算法：

- Data Parallel
- Distributed Data Parallel
- Synchronous SGD
- Asynchronous SGD
- Gradient AllReduce
- Ring AllReduce
- Hierarchical AllReduce

PyTorch DDP 文档将 DDP 定义为可跨多 GPU、多机器并行化模型训练的模块，通常每个进程维护一个模型副本并同步梯度。

---

## 11.2 Fully Sharded Data Parallel

FSDP 将参数、梯度、优化器状态切分到多个 GPU。PyTorch FSDP 文档强调 FSDP 通过 shard 参数并在计算前后 all-gather / reduce-scatter 来降低单卡显存压力。

技术：

- Parameter Sharding
- Gradient Sharding
- Optimizer State Sharding
- AllGather Parameters
- ReduceScatter Gradients
- Mixed Precision FSDP
- CPU Offload
- Auto Wrap Policy

阶段：

| 阶段 | 切分对象 |
|---|---|
| ZeRO-1 | Optimizer States |
| ZeRO-2 | Optimizer States + Gradients |
| ZeRO-3 | Optimizer States + Gradients + Parameters |

扩展：

- ZeRO-Offload
- ZeRO-Infinity
- ZeRO++
- DeepSpeedCPUAdam
- NVMe Offload
- Parameter Partitioning
- Communication Overlap

# 24. 训练故障排查

## 24.1 Loss 不下降

可能原因：

- 学习率不合适
- 数据标签错误
- 模型太小
- 优化器错误
- loss 实现错误
- 输入归一化错误
- 梯度被截断
- 参数未更新
- 分布式同步错误

---

## 24.2 过拟合

表现：

- train loss 下降
- val loss 上升
- 测试集差

处理：

- 增加数据
- 数据增强
- dropout
- weight decay
- early stopping
- 降低模型容量
- label smoothing
- 正则化
- 交叉验证

---

## 24.3 欠拟合

处理：

- 增大模型
- 训练更久
- 提高学习率
- 减少正则
- 改进特征
- 降低数据噪声
- 更换架构

---

## 24.4 分布式训练卡死

可能原因：

- rank 数不一致
- NCCL 通信失败
- 数据 loader 某个 worker 挂掉
- barrier 不匹配
- collective 顺序不一致
- checkpoint 同步阻塞
- 网络故障
- GPU OOM

排查：

- NCCL_DEBUG
- torch.distributed logs
- 检查 world size
- 检查每个 rank batch
- timeout 设置
- 单机复现
- 缩小规模
- 保存 rank 日志

# 28. 总结

人工智能模型训练相关技术可以概括为以下大类：

1. **数据工程**：采集、清洗、标注、去重、增强、采样、数据治理  
2. **训练范式**：监督、无监督、半监督、自监督、弱监督、迁移、元学习、强化学习  
3. **损失函数**：分类、回归、对比、排序、检测、分割、生成、大模型偏好损失  
4. **优化器**：SGD、Adam、AdamW、Adafactor、LAMB、Lion、Sophia、二阶优化  
5. **学习率与正则化**：Warmup、Cosine、Dropout、Weight Decay、Label Smoothing、Mixup  
6. **训练稳定性**：梯度裁剪、loss scaling、归一化、NaN 检测、checkpoint 恢复  
7. **混合精度**：FP16、BF16、FP8、AMP、GradScaler、Transformer Engine  
8. **显存优化**：Activation Checkpointing、Gradient Accumulation、Offload、FlashAttention、Packing  
9. **分布式训练**：DDP、FSDP、ZeRO、TP、PP、SP、CP、EP、3D/4D 并行  
10. **大模型预训练**：CLM、MLM、FIM、数据混合、Tokenizer、长上下文、checkpoint 管理  
11. **大模型微调**：Full FT、SFT、LoRA、QLoRA、Adapter、Prefix、Prompt Tuning  
12. **大模型对齐**：Reward Model、RLHF、RLAIF、DPO、KTO、ORPO、GRPO、RLVR、安全对齐  
13. **多模态训练**：图文对齐、视频语言、语音语言、多模态指令微调  
14. **强化学习训练**：PPO、SAC、Offline RL、MARL、Agentic RL、工具调用训练  
15. **训练框架**：PyTorch、TensorFlow、JAX、DeepSpeed、Megatron、NeMo、Accelerate、PEFT  
16. **MLOps**：实验追踪、数据版本、模型注册、自动评测、训练流水线  
17. **安全治理**：隐私、版权、数据污染、偏见、有害内容、安全对齐、红队测试  

一句话总结：

> AI 模型训练的本质是：用高质量数据、合适的目标函数、稳定高效的优化策略和可扩展训练系统，把模型参数逐步塑造成能够泛化、推理、生成、决策并安全服务真实任务的能力载体。
