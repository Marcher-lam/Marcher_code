# 多智能体、社会模拟与群体智能算法分类总表

> 说明：多智能体（Multi-Agent Systems, MAS）、社会模拟（Social Simulation / Agent-Based Modeling, ABM）与群体智能（Swarm Intelligence, SI）共同研究“多个自主个体如何感知、决策、交互、协作、竞争、涌现出群体行为”。  
> 该领域横跨 **人工智能、强化学习、博弈论、复杂系统、社会科学、经济学、交通、机器人、军事仿真、城市仿真、组织管理、LLM Agent、群体智能优化** 等方向。  
> 本文按 **多智能体系统 → 多智能体强化学习 → 博弈与机制设计 → Agent-Based 社会模拟 → LLM 社会模拟 → 群体智能优化 → 群机器人 → 复杂网络 → 多智能体工程架构** 系统分类。

# 2. 多智能体强化学习 MARL

## 2.1 MARL 基础

MARL 将多个学习型 Agent 放入同一个环境中学习策略。2025 年 MARL 综述通常将 MARL 按合作、竞争、混合博弈、集中训练分散执行、通信学习、可扩展性等维度分类。

基本形式：

```text
N 个 Agent
每个 Agent 获得局部观测 o_i
执行动作 a_i
环境转移到新状态 s'
获得奖励 r_i 或共享奖励 r
```

核心挑战：

- 非平稳性
- 信用分配
- 部分可观测
- 多智能体探索
- 协作涌现
- 通信学习
- 规模扩展
- 对抗鲁棒性
- 奖励稀疏
- 策略共适应

---

# 6. 社会模拟与 Agent-Based Modeling

## 6.1 ABM 基础

Agent-Based Modeling 使用大量个体 Agent 及其交互规则来模拟宏观社会现象。

组成：

- Agent
- 环境
- 规则
- 网络
- 时间步
- 交互机制
- 宏观指标

基本流程：

```text
初始化 Agent 和环境
  ↓
每个 Agent 感知局部状态
  ↓
依据行为规则决策
  ↓
执行动作并与其他 Agent 交互
  ↓
环境更新
  ↓
统计宏观结果
```

# 23. 总结

多智能体、社会模拟与群体智能算法可以概括为以下大类：

1. **多智能体系统基础**：Agent 架构、通信、协调、组织结构、任务分配  
2. **多智能体强化学习**：Independent RL、CTDE、VDN/QMIX、MADDPG、MAPPO、通信 MARL、图 MARL、平均场 MARL  
3. **博弈论与机制设计**：纳什均衡、Stackelberg、演化博弈、拍卖、协商、激励机制  
4. **多智能体规划**：任务分配、分布式约束优化、多智能体路径规划、协同搜索  
5. **社会模拟 ABM**：Schelling、Sugarscape、社会网络、舆论传播、疫情、城市、市场、组织模拟  
6. **LLM Agent 社会模拟**：生成式 Agent、人格建模、记忆、反思、社会互动、群体涌现  
7. **群体智能优化**：PSO、ACO、ABC、GWO、WOA、DE、CMA-ES、MAP-Elites  
8. **群机器人**：编队、覆盖、探索、避障、任务分配、无人机蜂群  
9. **复杂网络**：社群发现、传播、影响力最大化、意见演化、群体极化  
10. **多智能体行业应用**：交通、机器人、供应链、能源、电网、金融、社会科学、军事仿真  
11. **多智能体安全与治理**：鲁棒性、信任、隐私、可解释、AgentOps  
12. **多智能体工程平台**：NetLogo、Mesa、PettingZoo、SMAC、SUMO、AutoGen、LangGraph  

一句话总结：

> 多智能体研究的核心是“个体如何通过局部感知、交互、学习与协调，形成可控、可解释、可优化的群体智能与社会涌现”。
