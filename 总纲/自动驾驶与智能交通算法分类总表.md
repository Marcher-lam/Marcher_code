# 自动驾驶与智能交通算法分类总表

> 说明：自动驾驶与智能交通（ITS）是“车辆智能 + 道路智能 + 云端调度 + 多智能体协同”的综合系统。  
> 自动驾驶侧关注 **感知、定位、预测、决策、规划、控制、端到端驾驶、世界模型、安全验证**；智能交通侧关注 **交通流预测、信号控制、路径诱导、车路协同、公交/物流/停车/交通网络优化、多智能体调度**。  
> 本文按 **车端自动驾驶算法、路端智能交通算法、车路云协同算法、仿真评测与工程架构** 系统分类。

---

## 0. 总体分类框架

自动驾驶与智能交通算法可以分为以下大类：

| 大类 | 子类 |
|---|---|
| 自动驾驶感知 | 车道线、目标检测、语义分割、3D 检测、占据网络、BEV 感知 |
| 定位与建图 | GNSS/IMU、视觉 SLAM、激光 SLAM、高精地图、在线建图 |
| 多传感器融合 | Camera、LiDAR、Radar、IMU、V2X 融合 |
| 目标跟踪 | 单目标、多目标、3D 跟踪、轨迹管理 |
| 行为预测 | 车辆、行人、骑行者、交互式、多模态轨迹预测 |
| 决策规划 | 行为决策、路径规划、轨迹规划、交互式规划、博弈规划 |
| 控制算法 | PID、LQR、MPC、鲁棒控制、学习控制 |
| 端到端自动驾驶 | 直接从传感器到轨迹/控制、VLA、世界模型驾驶 |
| 自动驾驶安全 | 功能安全、SOTIF、冗余、故障诊断、形式化验证 |
| 智能交通感知 | 交通检测、流量估计、事件检测、路侧感知 |
| 交通预测 | 流量、速度、拥堵、OD、需求、事故预测 |
| 信号控制 | 固定配时、自适应控制、RL/MARL 信号控制 |
| 路径诱导 | 动态交通分配、导航、拥堵绕行、出行需求管理 |
| 车路协同 | V2X、协同感知、协同决策、队列行驶 |
| 交通网络优化 | 匝道控制、潮汐车道、可变限速、区域协调 |
| 仿真与数字孪生 | SUMO、CARLA、VISSIM、数字孪生交通、闭环评测 |

# 1. 自动驾驶系统架构

## 1.1 传统模块化自动驾驶架构

经典自动驾驶通常被拆成：

```text
传感器输入
  ↓
感知 Perception
  ↓
定位与建图 Localization & Mapping
  ↓
目标跟踪 Tracking
  ↓
行为预测 Prediction
  ↓
决策 Decision Making
  ↓
路径/轨迹规划 Planning
  ↓
控制 Control
  ↓
车辆执行
```

优点：

- 模块可解释
- 工程可控
- 安全验证相对清晰
- 便于功能分工

缺点：

- 模块误差会累积
- 各模块接口复杂
- 全局最优困难
- 长尾场景处理难

---

## 1.2 端到端自动驾驶架构

端到端自动驾驶直接从传感器数据生成规划轨迹或控制指令。近期综述通常把传统自动驾驶拆为感知、跟踪、预测、规划和控制等子任务，同时指出端到端方法试图减少模块误差累积。

典型结构：

```text
Camera / LiDAR / Radar
  ↓
Neural Encoder
  ↓
Scene Representation / BEV / Occupancy / Latent
  ↓
Planner Decoder
  ↓
Trajectory / Control
```

代表方向：

- Imitation Learning End-to-End Driving
- Reinforcement Learning End-to-End Driving
- Transformer End-to-End Driving
- BEV-based End-to-End Driving
- Occupancy-based End-to-End Driving
- World Model End-to-End Driving
- VLM/VLA-based Driving Agent

---

## 1.3 车路云一体化架构

```text
车端智能
  ↔ V2X 通信
路侧感知与计算
  ↔ 边缘云
交通云控平台
  ↔ 城市交通数字孪生
```

核心能力：

- 单车自动驾驶
- 路侧补盲
- 车路协同感知
- 车车协同决策
- 云端路径诱导
- 交通信号协同
- 区域流量优化
- 应急事件管理

# 29. 总结

自动驾驶与智能交通算法可以概括为以下大类：

1. **车端感知**：2D/3D 检测、语义分割、车道线、交通灯、Occupancy、BEV  
2. **定位建图**：GNSS/IMU、视觉 SLAM、激光 SLAM、高精地图、在线地图  
3. **多传感器融合**：Camera-LiDAR-Radar 融合、BEV 融合、V2X 协同感知  
4. **跟踪预测**：多目标跟踪、轨迹预测、交互预测、多模态预测  
5. **决策规划**：规则、状态机、行为树、POMDP、博弈、搜索、采样、优化规划  
6. **控制算法**：PID、Pure Pursuit、Stanley、LQR、MPC、鲁棒控制、学习控制  
7. **端到端驾驶**：模仿学习、强化学习、Transformer、BEV/Occupancy、VLM/VLA  
8. **世界模型驾驶**：未来视频、BEV、Occupancy、点云世界预测与规划  
9. **安全验证**：RSS、TTC、CBF、仿真测试、长尾场景、功能安全、SOTIF  
10. **智能交通感知**：路侧检测、交通流估计、事件检测、轨迹重建  
11. **交通预测**：ARIMA、LSTM、Transformer、STGCN、DCRNN、Graph WaveNet  
12. **信号控制**：固定配时、感应控制、SCOOT/SCATS、Max Pressure、RL/MARL  
13. **交通网络优化**：匝道控制、可变限速、动态交通分配、路径诱导、拥堵控制  
14. **车路协同**：V2X、协同感知、协同规划、编队控制、云控平台  
15. **交通仿真与数字孪生**：SUMO、CARLA、CityFlow、VISSIM、闭环仿真、场景生成  
16. **多智能体交通**：多路口、多车辆、多机器人、多区域交通协同优化  

一句话总结：

> 自动驾驶解决“单车如何安全智能地开”，智能交通解决“城市路网如何整体高效运行”；未来趋势是车端智能、路侧智能、云控优化、世界模型和多智能体协同的一体化闭环系统。
