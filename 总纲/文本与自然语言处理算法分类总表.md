# 文本与自然语言处理算法分类总表

> 说明：自然语言处理（NLP）算法覆盖文本预处理、语言学分析、文本表示、分类、序列标注、信息抽取、检索、问答、机器翻译、摘要、对话系统、文本生成、大语言模型、RAG、Agent、评测与安全等完整技术栈。  
> 本文按 **传统 NLP → 统计机器学习 NLP → 深度学习 NLP → Transformer / 大模型 NLP → RAG / Agent 工程系统** 的演进路线系统整理。

---

## 0. NLP 算法总览

NLP 可以按任务和技术范式分为以下大类：

| 大类 | 典型任务 |
|---|---|
| 文本预处理 | 分词、规范化、清洗、拼写纠错、停用词、词干化 |
| 文本表示 | One-hot、TF-IDF、Word2Vec、GloVe、BERT Embedding、LLM Embedding |
| 语言模型 | N-gram、RNN-LM、Transformer LM、GPT、BERT、T5 |
| 文本分类 | 情感分析、主题分类、意图识别、垃圾文本检测 |
| 序列标注 | 分词、词性标注、命名实体识别、槽位填充 |
| 句法分析 | 依存句法、成分句法、语义角色标注 |
| 信息抽取 | 实体抽取、关系抽取、事件抽取、属性抽取 |
| 信息检索 | BM25、向量检索、混合检索、重排序 |
| 问答系统 | 抽取式问答、生成式问答、开放域问答、RAG 问答 |
| 机器翻译 | 统计机器翻译、神经机器翻译、多语种翻译 |
| 文本摘要 | 抽取式摘要、生成式摘要、多文档摘要 |
| 文本生成 | 文案生成、改写、续写、代码生成、结构化生成 |
| 对话系统 | 任务型对话、开放域对话、语音对话、Agent 对话 |
| 大语言模型 | 预训练、指令微调、偏好对齐、长上下文、工具调用 |
| RAG | 检索增强生成、GraphRAG、Agentic RAG |
| NLP 评测 | BLEU、ROUGE、F1、BERTScore、LLM-as-Judge |
| NLP 安全 | 有害内容识别、越狱检测、隐私保护、事实性检测 |

# 26. 总结

文本与自然语言处理算法可以概括为以下大类：

1. **文本预处理**：清洗、分词、Tokenization、纠错、去重  
2. **文本表示**：TF-IDF、Word2Vec、BERT Embedding、LLM Embedding  
3. **语言模型**：N-gram、RNN-LM、BERT、GPT、T5、现代 LLM  
4. **文本分类**：情感、主题、意图、审核、多标签、零样本分类  
5. **序列标注**：NER、词性标注、槽位填充、术语抽取  
6. **句法语义分析**：依存句法、成分句法、语义角色、共指消解  
7. **信息抽取**：实体、关系、事件、关键词、知识图谱  
8. **文本匹配与检索**：BM25、Dense Retrieval、ColBERT、Reranker  
9. **问答系统**：抽取式、生成式、开放域、KGQA、RAG QA  
10. **机器翻译**：规则、统计、神经、多语种、LLM 翻译  
11. **文本摘要**：抽取式、生成式、多文档、长文档摘要  
12. **文本生成**：续写、改写、结构化生成、受控生成  
13. **对话系统**：任务型、开放域、LLM Agent 对话  
14. **大语言模型**：预训练、微调、对齐、推理增强、长上下文  
15. **RAG 与 Agent**：检索增强、GraphRAG、Self-RAG、Tool Calling  
16. **代码 NLP**：代码理解、代码生成、Text-to-SQL  
17. **安全可信 NLP**：幻觉检测、越狱检测、隐私保护、有害内容识别  
18. **多语言与领域 NLP**：法律、医疗、金融、科研、低资源语言  

一句话总结：

> NLP 正在从“规则 + 统计机器学习 + 深度学习任务模型”，演进为“预训练大模型 + RAG + 工具调用 + Agent + 安全评测”的统一语言智能系统。
