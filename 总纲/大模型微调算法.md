# 大模型微调算法分类总表

> 目标：系统梳理目前大模型（LLM / VLM / 多模态大模型）常见的微调、后训练、对齐和参数高效适配算法。  
> 范围：包含全量微调、继续预训练、监督微调、PEFT、LoRA 系列、量化微调、偏好对齐、强化学习微调、多模态微调、长上下文微调、持续学习与工程训练策略等。

---

## 1. 按训练阶段划分

| 类别 | 英文 | 代表算法 / 方法 | 主要用途 |
|---|---|---|---|
| 继续预训练 | Continued Pretraining / Domain-Adaptive Pretraining | CPT、DAPT、TAPT | 让模型适应领域语料、行业语言、代码库、企业知识 |
| 指令微调 | Instruction Tuning | SFT、IFT、FLAN-style instruction tuning | 让模型学会遵循指令、问答、对话格式 |
| 监督微调 | Supervised Fine-Tuning | SFT、teacher forcing、chat template SFT | 用高质量输入-输出样本训练模型行为 |
| 偏好对齐 | Preference Alignment | RLHF、DPO、IPO、KTO、ORPO、CPO、SimPO | 让模型输出更符合人类偏好、安全规范、风格要求 |
| 强化学习微调 | RL Fine-tuning / RLVR | PPO、GRPO、RLOO、REINFORCE、DAPO、Dr.GRPO | 强化推理、数学、代码、工具调用、任务成功率 |
| 安全微调 | Safety Fine-tuning | Constitutional AI、RLAIF、Safety SFT、拒答微调 | 提升安全性、降低有害输出 |
| 多模态微调 | Multimodal Fine-tuning | LLaVA-style SFT、Q-Former tuning、Vision projector tuning | 适配图文、视频、语音、文档理解等任务 |
| 长上下文微调 | Long-context Fine-tuning | RoPE scaling、Position Interpolation、YaRN、LongLoRA | 扩展上下文窗口、提升长文档理解 |
| 工具/Agent 微调 | Tool-use / Agent Fine-tuning | ReAct SFT、Toolformer-style tuning、function calling SFT | 学会调用工具、API、浏览器、代码解释器 |
| 蒸馏微调 | Distillation Fine-tuning | KD、Self-distillation、Logit distillation、Reasoning distillation | 从大模型迁移能力到小模型 |

## 2. 全参数微调类

全参数微调会更新模型全部或大部分参数，效果上限高，但显存、算力、数据质量要求高。

### 2.1 Full Fine-tuning / FFT

- **全参数微调（Full Fine-tuning）**
- **全模型监督微调（Full SFT）**
- **全模型继续预训练（Full Continued Pretraining）**
- **全模型偏好微调（Full Preference Fine-tuning）**
- **全模型 RL 微调（Full RL Fine-tuning）**

适用场景：

- 有大量高质量数据；
- 需要深度改变模型能力；
- 行业专用基础模型训练；
- 模型规模较小或算力充足。

风险：

- 容易灾难性遗忘；
- 训练成本高；
- 数据污染或格式错误会明显破坏模型能力；
- 不适合频繁为多个任务保存多个版本。

### 2.2 部分层微调

| 方法 | 说明 |
|---|---|
| 只微调顶层 Transformer block | 冻结底层语义能力，只调整高层任务表示 |
| 只微调底层/中层/高层 | 根据任务需求选择层级 |
| 只微调 Embedding 层 | 适配新词表、新领域术语 |
| 只微调 LM Head | 用于输出分布轻微适配 |
| 只微调 LayerNorm / RMSNorm | 极低参数量，稳定但表达能力有限 |
| BitFit | 只微调 bias 参数，早期 PEFT 方法之一 |
| Last-layer fine-tuning | 类似传统迁移学习中的最后一层微调 |
| Selective fine-tuning | 按梯度、重要性、模块类型选择部分参数 |

## 3. 继续预训练类

继续预训练通常不强调“问答格式”，而是让模型继续学习某类语料分布。

| 方法 | 说明 | 典型数据 |
|---|---|---|
| CPT：Continued Pretraining | 在原模型基础上继续语言建模训练 | 通用新增语料、领域语料 |
| DAPT：Domain-Adaptive Pretraining | 领域自适应预训练 | 医疗、法律、金融、代码、科研论文 |
| TAPT：Task-Adaptive Pretraining | 任务自适应预训练 | 下游任务未标注语料 |
| Corpus-adaptive pretraining | 语料自适应训练 | 企业知识库、客服记录 |
| Vocabulary expansion tuning | 扩词表后继续训练 embedding | 生僻领域术语、多语言术语 |
| Continual pretraining with replay | 加回放数据防止遗忘 | 原通用语料 + 新领域语料 |
| Mixture continued pretraining | 多领域混合继续预训练 | 通用 + 行业 + 指令数据 |

## 5. 参数高效微调 PEFT 总类

PEFT（Parameter-Efficient Fine-Tuning）核心思想是冻结大部分基座模型，只训练少量新增或选择性参数。

### 5.1 PEFT 总分类

| 大类 | 代表方法 | 核心思想 |
|---|---|---|
| 加性方法 | Adapter、LoRA、Prefix Tuning | 给模型增加可训练模块或增量参数 |
| 选择性方法 | BitFit、LayerNorm tuning、Diff Pruning | 只更新原模型中一小部分参数 |
| 重参数化方法 | LoRA、AdaLoRA、LoHa、LoKr | 用低秩或结构化形式表示权重更新 |
| 软提示方法 | Prompt Tuning、P-Tuning、Prefix Tuning | 学习连续提示向量，不改主干参数 |
| 混合方法 | UniPELT、MAM Adapter、S4、Adapter+LoRA | 组合多种 PEFT 机制 |
| 稀疏/门控方法 | SparseAdapter、Compacter、IA³ | 通过稀疏、缩放或门控降低参数量 |

## 6. Prompt / Prefix / P-Tuning 类

这类方法通常冻结模型主体，训练一组连续向量或前缀表示。

| 方法 | 中文名 | 说明 |
|---|---|---|
| Prompt Tuning | 软提示微调 | 只训练输入前的可学习 prompt embeddings |
| Prefix Tuning | 前缀微调 | 在每层 Transformer 的 key/value 前加入可学习前缀 |
| P-Tuning | P-Tuning | 用可学习模板向量替代人工 prompt |
| P-Tuning v2 | 深层提示微调 | 在多层加入连续提示，适合更大模型和更多任务 |
| Deep Prompt Tuning | 深层软提示 | 在多个层级注入 prompt 表示 |
| Prompt Encoder Tuning | 提示编码器微调 | 用 LSTM/MLP 编码可学习 prompt |
| Multitask Prompt Tuning | 多任务提示微调 | 多任务共享/独立软提示 |
| Prompt Pool / Prompt Routing | 提示池/提示路由 | 为不同任务选择不同 prompt |
| Hard Prompt + Soft Prompt Hybrid | 硬提示+软提示混合 | 人工模板与可学习向量结合 |

适合：分类、小数据任务、多任务路由、快速适配。  
不适合：深度改变模型知识、复杂生成风格迁移。

## 8. LoRA 系列

LoRA（Low-Rank Adaptation）是目前最常用的大模型微调方法之一。核心思想是冻结原权重，用低秩矩阵学习权重增量。

### 8.1 基础 LoRA

| 方法 | 说明 |
|---|---|
| LoRA | 低秩适配，训练 A/B 两个低秩矩阵 |
| QLoRA | 量化基座模型 + LoRA，通常使用 4-bit NF4 |
| LoRA+ | 给 LoRA A/B 矩阵设置不同学习率 |
| LoRA-FA | 固定 LoRA A，只训练 B，降低显存 |
| LoRA Dropout | 对 LoRA 路径加 dropout 防过拟合 |
| Merged LoRA | 推理时把 LoRA 合并进原权重 |
| Multi-LoRA | 同一基座加载多个 LoRA 适配器 |
| LoRA Router | 根据输入路由到不同 LoRA |

### 8.2 动态秩 / 自适应 LoRA

| 方法 | 说明 |
|---|---|
| AdaLoRA | 自适应分配不同层/矩阵的 LoRA rank |
| DyLoRA | 训练可动态裁剪不同 rank 的 LoRA |
| AutoLoRA | 自动搜索 LoRA 位置和秩 |
| Rank-adaptive LoRA | 根据层重要性动态调整 rank |
| Layer-wise LoRA | 不同层设置不同 rank/alpha |
| Sparse LoRA | 稀疏化 LoRA 更新 |

### 8.3 LoRA 结构变体

| 方法 | 说明 |
|---|---|
| DoRA | Weight-Decomposed LoRA，把权重方向和幅值分开学习 |
| rsLoRA | Rank-Stabilized LoRA，改善高 rank 训练稳定性 |
| LoHa | Low-rank Hadamard Product，使用 Hadamard 积增强表达 |
| LoKr | Low-rank Kronecker Product，使用 Kronecker 分解 |
| VeRA | 使用共享随机矩阵，只训练缩放向量 |
| Tied-LoRA | 多层共享 LoRA 参数 |
| KronA | Kronecker Adapter 低秩适配 |
| HRA / HiRA | 高秩或结构化残差适配变体 |
| PiSSA | 基于主奇异值和奇异向量初始化的 LoRA 变体 |
| OLoRA | 正交初始化/正交约束 LoRA |
| CorDA | 上下文导向的 LoRA 初始化或适配方法 |
| LoRA-GA | 梯度感知 LoRA 初始化 |

### 8.4 LoRA 组合与融合

| 方法 | 说明 |
|---|---|
| LoRA Fusion | 融合多个 LoRA 适配器 |
| LoRA Merging | 权重级合并 LoRA |
| Weighted LoRA | 多个 LoRA 按权重混合 |
| Task Arithmetic for LoRA | 对 LoRA 权重做任务向量运算 |
| TIES-Merging | 解决多 LoRA 合并冲突 |
| DARE | 随机丢弃/重缩放合并权重增量 |
| Model Soup with LoRA | 多个微调 LoRA 平均或加权平均 |
| MoE-LoRA | LoRA 专家混合 |
| X-LoRA | 动态混合多个 LoRA 专家 |
| LoRAHub | 组合已有 LoRA 解决新任务 |

### 8.5 LoRA 注入位置

| 注入位置 | 说明 |
|---|---|
| q_proj | 查询投影，常见注入位置 |
| k_proj | 键投影 |
| v_proj | 值投影，常见注入位置 |
| o_proj | 注意力输出投影 |
| gate_proj | MLP 门控层 |
| up_proj | MLP 上投影 |
| down_proj | MLP 下投影 |
| embedding | 词嵌入层 |
| lm_head | 输出头 |
| all-linear | 所有线性层，QLoRA 常用 |

## 11. 偏好对齐与后训练算法

偏好对齐用于让模型更符合人类偏好、安全要求、格式规范、推理质量。

### 11.1 RLHF 系列

| 方法 | 说明 |
|---|---|
| RLHF | Reinforcement Learning from Human Feedback，人类反馈强化学习 |
| Reward Modeling / RM | 训练奖励模型，判断哪个回答更好 |
| PPO | Proximal Policy Optimization，经典 RLHF 优化算法 |
| PPO-ptx | PPO 中混合预训练损失，防止遗忘 |
| RLAIF | Reinforcement Learning from AI Feedback，用 AI 反馈替代人类反馈 |
| Constitutional AI | 用宪法原则产生反馈和修正 |
| Rejection Sampling | 生成多个候选，用奖励模型筛选 |
| Best-of-N Sampling + SFT | 多候选筛选后再监督微调 |

### 11.2 Direct Preference Optimization 系列

| 方法 | 说明 |
|---|---|
| DPO | Direct Preference Optimization，直接用偏好对训练，无需显式 RL |
| IPO | Identity Preference Optimization，偏好优化变体 |
| KTO | Kahneman-Tversky Optimization，可用好/坏单边反馈 |
| ORPO | Odds Ratio Preference Optimization，把 SFT 与偏好项结合 |
| CPO | Contrastive Preference Optimization，对比偏好优化 |
| SimPO | Simple Preference Optimization，使用平均 log probability 作为隐式奖励 |
| R-DPO | Robust DPO，增强偏好噪声鲁棒性 |
| cDPO | Conservative DPO，保守偏好优化 |
| f-DPO | 基于 f-divergence 的 DPO 变体 |
| sDPO | Self-DPO 或 stepwise DPO 变体，依论文语境不同 |
| RS-DPO | Rejection Sampling + DPO |
| Online DPO | 在线采样偏好数据并进行 DPO |
| Iterative DPO | 多轮生成-筛选-优化 |
| Distilled DPO | 从强模型偏好蒸馏到弱模型 |

### 11.3 RLVR / 可验证奖励强化学习

| 方法 | 说明 |
|---|---|
| RLVR | Reinforcement Learning with Verifiable Rewards，可验证奖励强化学习 |
| GRPO | Group Relative Policy Optimization，用组内相对优势替代价值模型 |
| RLOO | REINFORCE Leave-One-Out，组内 baseline 的策略梯度方法 |
| REINFORCE++ | 面向 LLM 的 REINFORCE 改进训练 |
| DAPO | Decoupled Clip and Dynamic Sampling Policy Optimization，GRPO 类改进 |
| Dr.GRPO | 去长度偏差/稳定化的 GRPO 变体 |
| GSPO | Group Sequence Policy Optimization，序列级组优化思路 |
| VAPO | Value-based / Variance-aware Policy Optimization 类方法，依论文定义 |
| PPO with verifiable rewards | 用规则奖励、单测、数学答案验证做 PPO |
| Outcome Reward RL | 只对最终答案给奖励 |
| Process Reward RL | 对推理步骤给奖励 |
| PRM-guided RL | 使用过程奖励模型指导训练 |
| ORM-guided RL | 使用结果奖励模型指导训练 |

### 11.4 安全与宪法对齐

| 方法 | 说明 |
|---|---|
| Safety SFT | 用安全样本进行监督微调 |
| Refusal tuning | 训练拒答边界和拒答风格 |

## 27. 一句话总结

大模型微调算法可以概括为九大类：

1. **全参数微调**：直接改整个模型；
2. **继续预训练**：让模型吸收领域语料；
3. **监督微调**：让模型学会指令和任务格式；
4. **参数高效微调**：LoRA、Adapter、Prompt 等低成本适配；
5. **量化微调**：QLoRA 等低显存训练；
6. **偏好对齐**：DPO、RLHF、KTO、ORPO 等；
7. **强化学习微调**：PPO、GRPO、RLVR 等；
8. **多模态/工具/长上下文微调**：面向新输入和新能力；
9. **持续学习与融合**：多任务、多 LoRA、防遗忘、模型合并。
