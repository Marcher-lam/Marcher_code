# 决策优化、运筹学与资源调度算法分类总表

> 说明：决策优化、运筹学（Operations Research, OR）与资源调度算法，核心目标是在有限资源、复杂约束和不确定环境下做出最优或近似最优决策。  
> 它们广泛应用于生产制造、物流运输、供应链、排班、能源、电力、交通、金融、医疗、云计算、广告投放、机器人、多智能体系统等领域。  
> 本文按 **数学规划、约束规划、组合优化、网络优化、排程调度、路径规划、库存供应链、资源分配、随机鲁棒优化、仿真优化、实时在线决策、AI+OR** 系统分类。

---

## 0. 总体分类框架

决策优化、运筹与资源调度算法可以分为以下大类：

| 大类 | 典型问题 |
|---|---|
| 数学规划 | LP、QP、NLP、MILP、MINLP、SOCP、SDP |
| 约束规划 | CP、CP-SAT、CSP、全局约束、排班排程 |
| 组合优化 | TSP、VRP、背包、集合覆盖、匹配、割、图优化 |
| 网络优化 | 最短路、最大流、最小费用流、网络设计、多商品流 |
| 排程调度 | 单机、多机、车间、项目、人员、云资源调度 |
| 路径与车辆调度 | TSP、VRP、VRPTW、PDP、DARP、动态路径 |
| 供应链优化 | 库存、补货、选址、产销协同、网络设计 |
| 资源分配 | 预算、人力、算力、带宽、仓储、产能、频谱 |
| 随机优化 | 两阶段随机规划、多阶段随机规划、情景树、SDDP |
| 鲁棒优化 | 最坏情况、分布鲁棒、可调鲁棒、风险约束 |
| 多目标决策 | Pareto、目标规划、层级优化、权衡优化 |
| 仿真优化 | 排队仿真、离散事件仿真、数字孪生优化 |
| 在线优化 | 在线匹配、在线调度、bandit、MPC、滚动优化 |
| 强化学习调度 | RL 排程、RL 库存、RL 路由、MARL 调度 |
| AI + OR | 学习增强求解器、神经组合优化、大模型建模助手 |

# 1. 决策优化基础概念

## 1.1 决策优化是什么

决策优化是把现实问题抽象为：

```text
决策变量 + 目标函数 + 约束条件 + 数据参数
```

然后求解：

```text
minimize / maximize  objective
subject to           constraints
```

典型目标：

- 成本最小
- 利润最大
- 延迟最小
- 产能最大
- 服务水平最大
- 风险最小
- 资源利用率最大
- 公平性最大
- 碳排放最小
- 多目标综合最优

---

## 1.2 运筹学方法体系

运筹学是对复杂系统进行科学决策和优化的学科。INFORMS 将分析分为描述性、预测性和处方性三类，其中处方性分析用于给出可行动的决策建议。

核心方法：

- 数学规划
- 线性规划
- 整数规划
- 非线性规划
- 动态规划
- 网络优化
- 排队论
- 库存论
- 可靠性理论
- 约束规划
- 博弈论
- 决策分析
- 仿真
- 随机过程
- 马尔可夫决策过程
- 启发式与元启发式
- 强化学习

---

# 2. 数学规划算法

## 2.1 线性规划

形式：

```text
min c^T x
s.t. A x <= b

```

# 23. 总结

决策优化、运筹与资源调度算法可以概括为以下大类：

1. **数学规划**：LP、IP、MILP、QP、NLP、MINLP、SOCP、SDP  
2. **约束规划**：CSP、CP、CP-SAT、SAT、MaxSAT、全局约束  
3. **组合优化**：分支定界、动态规划、局部搜索、元启发式、近似算法  
4. **网络优化**：最短路、最大流、最小费用流、匹配、网络设计  
5. **排程调度**：单机、并行机、流水车间、作业车间、项目、人员排班  
6. **物流路由**：TSP、VRP、VRPTW、取送货、仓储路径、多智能体路径  
7. **库存供应链**：EOQ、Newsvendor、多级库存、选址、生产计划、供应链网络  
8. **资源分配**：预算、人力、算力、带宽、电力、频谱、公平分配  
9. **不确定性优化**：随机规划、鲁棒优化、分布鲁棒、机会约束、风险优化  
10. **仿真优化**：离散事件仿真、排队论、数字孪生、仿真代理模型  
11. **在线优化**：滚动时域、在线匹配、在线调度、Bandit、MPC  
12. **智能调度**：强化学习、多智能体 RL、学习增强求解器、神经组合优化  
13. **行业优化**：制造、物流、供应链、能源、交通、医疗、金融、云计算、广告  

一句话总结：

> 决策优化的本质是：在现实约束下，把有限资源分配给最有价值的任务，并通过数学建模、求解器、启发式、仿真和 AI 学习方法持续逼近最优决策。
