# 优化算法分类总表

> 说明：优化算法是一个横跨数学、运筹学、控制、机器学习、深度学习、强化学习、工程设计、金融、调度和人工智能的庞大体系。  
> 本文按 **问题类型、约束形式、目标函数性质、变量类型、确定性/随机性、搜索机制、应用领域** 对优化算法进行系统分类。

---

## 0. 优化算法总览

优化问题的一般形式：

```text
minimize / maximize     f(x)
subject to              g_i(x) <= 0
                        h_j(x) = 0
                        x ∈ X
```

其中：

- `x`：决策变量
- `f(x)`：目标函数
- `g_i(x)`：不等式约束
- `h_j(x)`：等式约束
- `X`：可行域

优化算法可以从以下维度分类：

| 分类维度 | 主要类别 |
|---|---|
| 变量类型 | 连续优化、离散优化、混合整数优化 |
| 目标函数 | 线性、二次、凸、非凸、非光滑、多目标 |
| 约束形式 | 无约束、有约束、等式约束、不等式约束、锥约束 |
| 信息使用 | 零阶、一阶、二阶、高阶 |
| 随机性 | 确定性优化、随机优化、鲁棒优化、分布鲁棒优化 |
| 搜索范围 | 局部优化、全局优化 |
| 算法思想 | 梯度法、牛顿法、内点法、单纯形法、分支定界、动态规划、进化算法、群智能、贝叶斯优化 |
| 应用场景 | 机器学习、深度学习、控制、调度、路径规划、资源分配、金融、工程设计 |

---

# 30. 总结

优化算法可以概括为以下大类：

1. **数学规划**：线性规划、二次规划、非线性规划、整数规划、锥规划  
2. **凸优化**：梯度法、内点法、近端法、ADMM、Frank-Wolfe  
3. **非凸优化**：多起点、随机扰动、信赖域、MM、DC、Langevin  
4. **组合优化**：分支定界、动态规划、约束规划、局部搜索  
5. **随机优化**：SGD、SAA、随机规划、仿真优化  
6. **鲁棒优化**：最坏情况优化、分布鲁棒优化、风险优化  
7. **全局优化**：确定性全局优化、随机全局优化、代理模型优化  
8. **元启发式**：遗传算法、进化策略、粒子群、蚁群、模拟退火  
9. **贝叶斯优化**：高斯过程、采集函数、多保真 HPO  
10. **机器学习优化**：EM、变分推断、SVM 优化、矩阵分解  
11. **深度学习优化**：SGD、AdamW、Lion、LAMB、Adafactor、SAM  
12. **控制优化**：MPC、iLQR、DDP、轨迹优化  
13. **图与网络优化**：最短路、最大流、匹配、图割  
14. **联邦与分布式优化**：FedAvg、ADMM、分布式 SGD  
15. **量子与物理启发优化**：量子退火、QAOA、Ising 优化  

一句话总结：

> 优化算法的本质是“在约束下寻找最优决策”。  
> 选择算法时，首先判断变量是连续还是离散、目标是否凸、是否可微、是否有约束、是否有噪声、是否能计算梯度、是否要求全局最优。
