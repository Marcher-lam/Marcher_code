# 进化遗传算法分类总表

> 说明：这里的“进化遗传算法”按更广义的**进化计算（Evolutionary Computation, EC）/进化算法（Evolutionary Algorithms, EA）**整理。严格说，遗传算法（GA）只是进化算法的一个分支；现实中常把 GA、遗传编程、进化策略、差分进化、多目标进化、神经进化、质量多样性算法等统称为“进化/遗传类算法”。

---

## 0. 总览：进化遗传算法可以分为哪些大类

| 一级类别 | 代表算法/模型/方法 | 主要用途 |
|---|---|---|
| 遗传算法 GA | SGA、二进制 GA、实数编码 GA、排列编码 GA、CHC、Messy GA | 通用组合优化、参数搜索、特征选择 |
| 遗传编程 GP | 树形 GP、线性 GP、语法引导 GP、笛卡尔 GP、强类型 GP | 自动生成程序、表达式、规则、符号回归 |
| 进化策略 ES | $(1+1)$-ES、$(\mu,\lambda)$-ES、CMA-ES、NES、OpenAI-ES | 连续优化、黑箱优化、神经网络参数搜索 |
| 进化规划 EP | 有限状态机进化、实值 EP、自适应 EP | 早期预测、控制、策略进化 |
| 差分进化 DE | DE/rand/1/bin、DE/best/1、JADE、SHADE、L-SHADE | 连续参数优化、工程优化 |
| 估计分布算法 EDA | PBIL、UMDA、cGA、MIMIC、BOA、hBOA | 用概率模型替代交叉变异的全局搜索 |
| 多目标进化 MOEA | NSGA-II、NSGA-III、SPEA2、MOEA/D、MOPSO、SMS-EMOA | 多目标优化、Pareto 前沿搜索 |
| 约束进化优化 | Deb 规则、ε-constraint、Penalty GA、可行性优先、修复算子 | 有复杂约束的工程/调度/设计优化 |
| 协同进化/共进化 | Cooperative Coevolution、Competitive Coevolution、Host-Parasite GA | 大规模变量分解、多智能体、博弈优化 |
| 质量多样性 QD | Novelty Search、MAP-Elites、NSLC、CMA-ME、Differentiable QD | 寻找多样且高质量的解，不只找单一最优解 |
| 神经进化 | NEAT、HyperNEAT、CoDeepNEAT、CMA-ES-NN、EvoNAS | 神经网络结构搜索、权重搜索、策略搜索 |
| 进化机器学习 | Learning Classifier System、Genetic Fuzzy System、Evolutionary Feature Selection | 规则学习、特征选择、模型集成、自动机器学习 |
| 进化群体智能 | PSO、ACO、ABC、Firefly、Cuckoo Search、BBO | 群体启发式优化、路径规划、调参 |
| 混合/模因算法 | Memetic Algorithm、GA+Local Search、DE+Gradient、Lamarckian EA | 全局搜索 + 局部搜索，加速收敛 |
| 动态/在线进化算法 | Dynamic GA、Immigrants GA、Restart EA、Memory-based EA | 动态环境、非平稳目标、在线优化 |
| 大规模/分布式进化 | Island Model GA、Cellular GA、Parallel ES、Distributed CMA-ES | 大规模搜索、并行计算、云端/集群优化 |
| 多任务/迁移进化 | Multifactorial Evolutionary Algorithm、Transfer EA | 多任务联合优化、跨任务知识迁移 |
| 交互式/人机协同进化 | Interactive GA、Human-in-the-loop EA、Aesthetic Evolution | 设计、艺术、推荐、用户偏好优化 |

# 1. 基础进化算法框架

## 1.1 经典进化算法通用流程

进化算法通常包含以下组件：

1. **编码表示（Representation / Encoding）**
   - 二进制编码
   - 实数编码
   - 整数编码
   - 排列编码
   - 树编码
   - 图编码
   - 程序编码
   - 规则编码
   - 神经网络结构编码

2. **初始化（Initialization）**
   - 随机初始化
   - 启发式初始化
   - 分层初始化
   - 拉丁超立方采样初始化
   - 混沌初始化
   - 先验知识初始化

3. **适应度函数（Fitness Function）**
   - 单目标适应度
   - 多目标适应度
   - 约束惩罚适应度
   - 奖励函数
   - 代理模型预测适应度
   - 人类反馈适应度

4. **选择算子（Selection）**
   - 轮盘赌选择
   - 随机遍历采样
   - 锦标赛选择
   - 排名选择
   - 截断选择
   - 精英选择
   - 环境选择
   - Pareto 选择

5. **变异算子（Mutation）**
   - 位翻转变异
   - 高斯变异
   - 均匀变异
   - 非均匀变异
   - 多项式变异
   - 交换变异
   - 插入变异
   - 反转变异
   - 子树变异
   - 结构变异

6. **交叉算子（Crossover / Recombination）**
   - 单点交叉
   - 两点交叉
   - 多点交叉
   - 均匀交叉
   - 算术交叉
   - 模拟二进制交叉 SBX
   - 顺序交叉 OX
   - 部分匹配交叉 PMX
   - 循环交叉 CX
   - 子树交叉

7. **替换策略（Replacement）**
   - 世代替换
   - 稳态替换
   - 精英保留
   - 父子竞争
   - 年龄淘汰
   - 拥挤替换

8. **终止条件（Stopping Criteria）**
   - 达到最大代数
   - 达到适应度阈值
   - 长期无改进
   - 计算预算耗尽
   - 多样性过低
   - 收敛判据满足

# 33. 一句话总结

进化遗传算法不是单一算法，而是一整套以“种群、选择、变异、重组、适应度、生存竞争”为核心思想的黑箱优化与智能搜索方法体系。它可以粗略分为：

> 遗传算法、遗传编程、进化策略、进化规划、差分进化、估计分布算法、多目标进化、协同进化、质量多样性、神经进化、群体智能、混合模因算法、动态进化、代理模型辅助进化、进化机器学习与进化强化学习。
