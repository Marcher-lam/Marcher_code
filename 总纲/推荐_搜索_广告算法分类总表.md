# 推荐、搜索与广告算法分类总表

> 说明：推荐、搜索与广告算法本质上都是“从海量候选中找到最合适内容并排序展示”的信息分发系统。  
> 工业系统通常不是单一模型，而是由 **召回 / 检索 → 粗排 → 精排 → 重排 → 混排 → 机制 / 出价 / 预算 / 反馈学习** 组成的多阶段系统。  
> 本文按 **推荐系统、搜索引擎、广告系统、排序学习、召回检索、用户建模、广告竞价、实时决策、评测与工程架构** 系统整理。

---

## 0. 推荐、搜索与广告的统一框架

推荐、搜索、广告三类系统有共同结构：

```text
用户 / Query / 广告请求
  ↓
理解与特征构建
  ↓
候选召回 / 检索
  ↓
粗排 / 预排序
  ↓
精排 / 深度排序
  ↓
重排 / 多目标优化
  ↓
混排 / 业务规则 / 机制约束
  ↓
曝光
  ↓
点击 / 转化 / 停留 / 反馈
  ↓
在线学习与系统优化
```

三者区别：

| 系统 | 输入 | 输出 | 核心目标 |
|---|---|---|---|
| 推荐系统 | 用户、上下文、历史行为 | 个性化内容列表 | 用户满意、时长、点击、转化、多样性 |
| 搜索系统 | Query、用户、上下文 | 相关文档或商品 | 相关性、准确性、权威性、时效性 |
| 广告系统 | 用户、上下文、广告库存、预算 | 广告展示 | ROI、CTR、CVR、收入、预算消耗、用户体验 |

工业系统常见漏斗：

```text
全量候选库
  ↓ 召回：百万/千万 → 千级
  ↓ 粗排：千级 → 百级
  ↓ 精排：百级 → 十级
  ↓ 重排：多样性/业务约束/探索
  ↓ 展示
```

## 1.3 协同过滤

协同过滤是推荐系统经典算法家族。

### 1.3.1 User-based Collaborative Filtering

思想：

```text
相似用户喜欢的物品，也推荐给当前用户
```

算法：

- UserCF
- 基于余弦相似度的 UserCF
- 基于 Pearson 相关系数的 UserCF
- 基于 Jaccard 的 UserCF
- KNN UserCF

---

### 1.3.2 Item-based Collaborative Filtering


- Swing
- ItemKNN
- Co-occurrence Recommendation
- Amazon Item-to-Item CF
- 基于共现矩阵的推荐
- 基于条件概率的 ItemCF

优点：

- 稳定
- 可解释
- 工业上常用于召回

# 19. 总结

推荐、搜索与广告算法可以概括为以下大类：

1. **召回 / 检索算法**：关键词、协同过滤、向量召回、图召回、多模态召回  
2. **排序算法**：LR、GBDT、FM、DeepFM、DIN、Transformer Ranker、LambdaMART  
3. **重排算法**：MMR、DPP、列表优化、多目标重排、LLM 重排  
4. **用户建模**：用户画像、行为序列、长期兴趣、实时兴趣、LTV  
5. **物品与内容建模**：文本、图像、视频、多模态、知识图谱  
6. **搜索算法**：倒排索引、BM25、Learning to Rank、Dense Retrieval、Hybrid Search  
7. **广告算法**：CTR/CVR、RTB、拍卖、出价、预算 pacing、频控、创意优化  
8. **探索与在线学习**：Bandit、FTRL、在线学习、强化学习  
9. **因果与归因**：IPS、Doubly Robust、Uplift、增量实验、多触点归因  
10. **图算法**：用户-物品图、知识图谱、GNN 推荐、PageRank、随机游走  
11. **多模态算法**：CLIP/VLM 推荐、多模态搜索、多模态广告创意  
12. **LLM / Agent 算法**：Query 改写、LLM 排序、对话推荐、广告投放 Agent  
13. **工程系统**：特征平台、向量索引、实时流、A/B 实验、监控治理  

一句话总结：

> 推荐、搜索与广告算法的核心是“理解用户与意图，从海量候选中高效召回、精准排序，并在商业目标、用户体验、公平性和长期价值之间做动态优化”。
