# 强化学习算法分类总表

> 说明：强化学习（Reinforcement Learning, RL）算法数量庞大，而且很多算法是多个思想的组合，例如“深度 + 离轨 + Actor-Critic + 最大熵 + 连续动作”。因此更合理的方式不是把算法放进唯一类别，而是按**问题建模、学习方式、策略结构、是否有模型、数据来源、应用场景**进行多维分类。本表尽量覆盖当前主流与常见研究算法。

---

## 0. 总览：强化学习算法的主要分类维度

| 分类维度 | 主要类别 | 代表算法/方法 |
|---|---|---|
| 是否学习环境模型 | 无模型 RL、基于模型 RL | Q-learning、PPO、SAC；Dyna、PILCO、MBPO、MuZero |
| 学习对象 | 价值函数、策略函数、模型、奖励函数 | TD、DQN、REINFORCE、World Model、IRL |
| 策略更新方式 | 同轨、离轨 | SARSA、PPO；Q-learning、DQN、SAC |
| 动作空间 | 离散动作、连续动作、混合动作 | DQN、C51；DDPG、TD3、SAC |
| 数据来源 | 在线 RL、离线 RL、批量 RL | PPO、SAC；CQL、IQL、BCQ |
| 目标形式 | 累积回报、平均回报、风险敏感、多目标 | Q-learning、R-learning、CVaR RL、MORL |
| 智能体数量 | 单智能体、多智能体 | DQN、PPO；MADDPG、QMIX、MAPPO |
| 表示形式 | 表格型、函数逼近、深度 RL | Tabular Q；Linear TD；DQN、PPO |
| 任务结构 | 平坦 RL、层次 RL、选项框架 | Options、MAXQ、FeUdal Networks |
| 安全约束 | 普通 RL、安全 RL、约束 RL | CPO、Lagrangian PPO、Shielded RL |
| 与人类反馈关系 | 标准 RL、模仿学习、逆强化学习、RLHF | BC、GAIL、MaxEnt IRL、PPO-RLHF、DPO |
| 大模型后训练 | 奖励模型 RL、直接偏好优化、可验证奖励 RL | PPO、DPO、GRPO、RLVR |

# 28. 一句话学习路线

1. **入门表格型 RL**：MDP → 动态规划 → 蒙特卡洛 → TD → SARSA → Q-learning。
2. **进入深度 RL**：DQN → Double/Dueling/PER/Rainbow → PPO → SAC → TD3。
3. **掌握进阶方向**：模型 RL、离线 RL、模仿学习、层次 RL、安全 RL、多智能体 RL。
4. **面向大模型**：RLHF/PPO → DPO/ORPO/KTO/SimPO → GRPO/RLVR → Agentic RL。
5. **面向工程应用**：优先掌握 PPO、SAC、DQN、CQL/IQL、MAPPO、MCTS、上下文老虎机和 OPE。
