## 1. 算法基础认知

**一句话定义**：时序差分（Temporal Difference, TD）方法结合了蒙特卡罗的"从经验学习"和动态规划的"自举"思想，每步就可以更新，比只等回合结束快很多。

**直觉类比**：就像你在网上买东西等快递，你不用等快递完全到了才知道，你每隔一段时间就检查一下物流信息更新预期——这就是TD的思想。

**历史背景**：TD方法由Sutton在1988年提出，是强化学习中最重要的方法之一。

**算法定位**：
- 类型：强化学习 → 免模型预测
- 输出：状态价值函数V(s)
- 模型类型：TD学习

---

## 2. 核心原理

### 2.1 核心思想

TD核心是用"估计"代替"完整回报"：
- MC：V(s) ← G_t（需要等回合结束）
- TD：V(s) ← r + γV(s')（每步都可更新）

**TD目标**：$r + \gamma V(s')$

### 2.2 工作流程

1. 观察状态s，执行动作a，得到r和s'
2. 计算TD目标：target = r + γV(s')
3. 更新：V(s) ← V(s) + α(target - V(s))
4. s ← s'，重复

### 2.3 关键概念

- **TD目标**：r + γV(s')
- **TD误差**：target - V(s)
- **自举**：用当前估计更新

---

## 3. 数学公式

### 3.1 TD(0)更新

$$V(s_t) \leftarrow V(s_t) + \alpha [r_t + gamma \cdot V(s_{t+1}) - V(s_t)]$$

**TD误差**：$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$

### 3.2 n步TD

| n | 方法 | 特点 |
|---|------|------|
| n=1 | TD(0) | 单步，高方差，低偏差 |
| n=中间 | n-step TD | 平衡 |
| n=∞ | MC | 低方差，高偏差 |

### 3.3 TD(λ)

$$A_t^{GAE} = (1-\lambda) \sum_{n=1}^{\infty} \lambda^{n-1} \delta_t^{(n)}$$

## 5. 调库实现

```python
import numpy as np
import gymnasium as gym

class TDAgent:
    """TD(0)预测"""
    
    def __init__(self, n_states, alpha=0.1, gamma=0.99):
        self.n_states = n_states
        self.alpha = alpha
        self.gamma = gamma
        self.V = np.zeros(n_states)
    
    def update(self, state, reward, next_state, done):
        """单步更新"""
        if done:
            target = reward
        else:
            target = reward + self.gamma * self.V[next_state]
        
        self.V[state] += self.alpha * (target - self.V[state])

if __name__ == "__main__":
    env = gym.make('CliffWalking-v0')
    
    print("=" * 50)
    print("TD方法测试")
    print("=" * 50)
    
    agent = TDAgent(48, alpha=0.1, gamma=0.99)
    
    for ep in range(500):
        s, _ = env.reset()
        done = False
        
        while not done:
            a = env.action_space.sample()
            s2, r, d, t, _ = env.step(a)
            done = d or t
            
            agent.update(s, r, s2, done)
            s = s2
    
    print("\n状态价值:")
    print(agent.V[:16])
```

## 6. 优缺点

### 6.1 优点

1. **效率高**：每步更新
2. **在线学习**：立即反馈
3. **稳定性**：比MC稳定

### 6.2 缺点

1. **有偏估计**：依赖当前V
2. **需要自举**：V(s')要有意义
