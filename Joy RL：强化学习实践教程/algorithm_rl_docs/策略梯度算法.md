# 策略梯度算法 学习文档

> 直接学习随机策略的强化学习方法，适用于连续动作空间

---

## 1. 算法基础认知

**一句话定义**：策略梯度（Policy Gradient）方法直接学习一个 stochastic policy network，输出在每个状态下执行各个动作的概率，通过最大化期望回报来训练。

**直觉类比**：不像DQN输出每个动作的分数，策略梯度直接"说出"每个动作的好坏概率——就像凭感觉做决定，而不是算分。

**历史背景**：策略梯度由Sutton等人在2000年提出（REINFORCE算法），是完全不同于值函数方法的新范式。

**算法定位**：
- 类型：强化学习 → 策略学习
- 输出：随机策略 π(a|s)
- 模型类型：神经网络直接输出概率

**前置知识**：
- [必备] 神经网络基础
- [必备] 梯度下降

---

## 2. 核心原理

### 2.1 核心思想

直接最大化期望回报：
$$J(\theta) = E_{\tau \sim \pi_\theta}[R(\tau)]$$

用梯度上升更新参数：
$$\theta \leftarrow \theta + \alpha \nabla_\theta J$$

### 2.2 REINFORCE算法

**策略梯度公式**：
$$\nabla_\theta J = E_{\tau \sim \pi}[G_t \cdot \nabla_\theta \ln \pi_\theta(a_t|s_t)]$$

### 2.3 实际实现

## 4. 调库实现

```python
import torch
import torch.nn as nn
import numpy as np
import gymnasium as gym

class PolicyNetwork(nn.Module):
    """策略网络"""
    
    def __init__(self, state_dim, action_dim, hidden_dim=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim),
        )
    
    def forward(self, x):
        return self.net(x)
    
    def get_action(self, state):
        """采样动作"""
        logits = self(torch.FloatTensor(state))
        probs = torch.softmax(logits, dim=-1)
        return torch.multinomial(probs, 1).item()
    
    def get_log_prob(self, state, action):
        """获取log概率"""
        logits = self(torch.FloatTensor(state))
        probs = torch.softmax(logits, dim=-1)
        log_probs = torch.log(probs + 1e-8)
        return log_probs[action]

class REINFORCEAgent:
    """REINFORCE算法"""
    
    def __init__(self, state_dim, action_dim, lr=3e-4, gamma=0.99):
        self.state_dim = state_dim
        self.action_dim = action_dim
        self.gamma = gamma
        self.lr = lr
        
        self.policy = PolicyNetwork(state_dim, action_dim)
        self.optimizer = torch.optim.Adam(self.policy.parameters(), lr=lr)
    
    def collect_trajectory(self, env, max_steps=200):
        """收集一个回合"""
        trajectory = []
        state, _ = env.reset()
        
        for _ in range(max_steps):
            action = self.policy.get_action(state)
            next_state, reward, terminated, truncated, _ = env.step(action)
            done = terminated or truncated
            
            trajectory.append((state, action, reward))
            
            if done:
                break
            
            state = next_state
        
        return trajectory
    
    def update(self, trajectory):
        """策略梯度更新"""
        G = 0
        loss = 0
        
        for state, action, reward in reversed(trajectory):
            G = self.gamma * G + reward
            
            log_prob = self.policy.get_log_prob(state, action)
            loss += -G * log_prob
        
        loss /= len(trajectory)
        
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()

# ===============================
# 测试
# ===============================
if __name__ == "__main__":
    env = gym.make('CartPole-v1')
    agent = REINFORCEAgent(4, 2, lr=3e-4, gamma=0.99)
    
    print("=" * 50)
    print("REINFORCE策略梯度测试")
    print("=" * 50)
    
    for ep in range(300):
        # 收集轨迹
        trajectory = agent.collect_trajectory(env, 200)
        
        # 更新
        agent.update(trajectory)
        
        # 评估
        if ep % 50 == 0:
            s, _ = env.reset()
            total_r = 0
            for _ in range(200):
                a = agent.policy.get_action(s)
                s, r, d, t, _ = env.step(a)
                total_r += r
                if d or t:
                    break
            
            print(f"回合{ep}: 奖励={total_r}")
```

## 练习题

### 练习1：策略梯度 vs 值函数

**问题**：为什么需要策略梯度？DQN不也能学习动作吗？

**答案**：
1. 连续动作：DQN需要枚举所有动作，策略梯度直接输出
2. 随机策略：某些任务需要随机性
3. 不可微分：环境不可微分只能用策略梯度（无模型方法）
