# 强化学习算法 - 快速选择指南

> 根据任务特征快速选择合适的算法

---

## 1. 算法选择决策树

```
您的任务特征是什么？
│
├─ 动作空间是？
│   ├─ 离散 → 状态空间？
│   │          ├─ 小(<10000) → Q学习表格？
│   │          │              ├─ 需要最高性能 → Rainbow DQN
│   │          │              └─ 入门学习 → Q学习 / Sarsa
│   │          │
│   │          └─ 大/图像 → DQN变体？
│   │                        ├─ 需要稳定性 → DoubleDQN + PER
│   │                        ├─ 最简化 → DQN
│   │                        └─ 需要最高性能 → Rainbow DQN
│   │
│   └─ 连续 → 需要最高样本效率？
│              ├─ 是 → SAC（样本效率最高）
│              ├─ 需要最稳定 → PPO（最稳定）
│              └─ 传统选择 → TD3 / DDPG
│
└─ 是否需要在线探索？
    ├─ 是（同策略） → A2C / PPO
    └─ 否（异策略） → DQN / SAC
```

## 5. 问题与解决方案

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 不收敛 | 学习率太高 | 降低α到1e-4 |
| 只用同一个动作 | 探索不够 | ε_decay设小 |
| 训练崩溃 | 梯度爆炸 | 梯度裁剪到1.0 |
| 性能不增加 | 奖励设计差 | 检查奖励函数 |
| 卡在局部 | 策略太确定 | 增加熵奖励 |

## 7. 快���开始代码片段

### 最简单的Q学习
```python
Q = np.zeros((state_n, action_n))
for e in range(1000):
    s = env.reset()
    while True:
        a = np.argmax(Q[s]) if random>eps else random
        s2, r, d, _ = env.step(a)
        Q[s,a] += 0.1*(r + 0.99*max(Q[s2]) - Q[s,a])
        if d: break
```
