# 强化学习 - 核心数学公式推导

> 详细推导RL算法的数学基础

---

## 1. 回报的期望

### 1.1 定义

从状态s开始的期望回报：
$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + ...$$

递归形式：
$$G_t = R_{t+1} + \gamma G_{t+1}$$

### 1.2 期望计算

在策略π下的期望：
$$V_\pi(s) = \mathbb{E}_\pi[G_t | S_t = s]$$

展开：
$$V_\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a) [R(s,a) + \gamma V_\pi(s')]$$

### 1.3 为什么用期望？

- 状态的价值是未来奖励的平均值
- 期望消除了随机性的影响
- 贝尔曼方程的基础

---

## 2. 贝尔曼方程详细推导

### 2.1 从定义出发

$$V_\pi(s) = \mathbb{E}_\pi[G_t | S_t = s]$$

### 2.2 第一步分解

$$= \mathbb{E}_\pi[R_{t+1} + \gamma G_{t+1} | S_t = s]$$

### 2.3 期望展开

使用全期望公式：

$$= \sum_a \pi(a|s) \mathbb{E}[R_{t+1} + \gamma G_{t+1} | S_t = s, A_t = a]$$

### 2.4 状态转移

$$= \sum_a \pi(a|s) \sum_{s'} P(s'|s,a) [R(s,a) + \gamma \mathbb{E}[G_{t+1} | S_{t+1} = s']]$$

### 2.5 最终形式

$$= \sum_a \pi(a|s) \sum_{s'} P(s'|s,a) [R(s,a) + \gamma V_\pi(s')]$$

这就是贝尔曼方程！

---

## 3. Q函数的期望

### 3.1 定义

$$Q_\pi(s,a) = \mathbb{E}_\pi[G_t | S_t=s, A_t=a]$$

### 3.2 贝尔曼方程

$$Q_\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \sum_{a'} \pi(a'|s') Q_\pi(s',a')$$

### 3.3 与V的关系

$$V_\pi(s) = \sum_a \pi(a|s) Q_\pi(s,a)$$
$$Q_\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) V_\pi(s')$$

---

## 4. 最优性方程

### 4.1 最优状态价值

$$V^*(s) = \max_a \sum_{s'} P(s'|s,a)[R(s,a) + \gamma V^*(s')]$$

### 4.2 最优动作价值

$$Q^*(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \max_{a'} Q^*(s',a')$$

### 4.3 最优策略

$$\pi^*(a|s) = \begin{cases} 1 & \text{if } a = \arg\max_a Q^*(s,a) \\ 0 & \text{otherwise} \end{cases}$$

---

## 5. TD学习的期望

### 5.1 TD目标

$$\text{TD Target} = R_{t+1} + \gamma V(s_{t+1})$$

### 5.2 TD误差

$$\delta_t = R_{t+1} + \gamma V(s_{t+1}) - V(s_t)$$

### 5.3 期望的性质

$$\mathbb{E}[\delta_t] = 0 \quad \text{当}V = V_\pi$$

这意味着平均TD误差为0！

---

## 6. 策略梯度推导

### 6.1 目标函数

$$J(\theta) = V_{\pi_\theta}(s_0)$$

### 6.2 梯度上升

$$\nabla_\theta J = \nabla_\theta V_{\pi_\theta}(s_0)$$

### 6.3 展开

使用对数导数技巧：

$$\nabla_\theta V = \nabla_\theta \sum_a \pi_\theta(a|s) Q(s,a)$$

$$= \sum_a [\nabla_\theta \pi_\theta(a|s) Q + \pi_\theta(a|s) \nabla_\theta Q]$$

### 6.4 简化（忽略状态分布变化）

$$\nabla_\theta J \approx \mathbb{E}_s \mathbb{E}_a [\nabla_\theta \ln \pi_\theta(a|s) Q(s,a)]$$

这就是REINFORCE的核心！

### 6.5 引入基线

加入一个不依赖于状态的基线b(s)：

$$\nabla_\theta J \approx \mathbb{E}_s \mathbb{E}_a [\nabla_\theta \ln \pi_\theta(a|s) (Q(s,a) - b(s))]$$

使用V(s)作为基线：

$$\nabla_\theta J \approx \mathbb{E}_s \mathbb{E}_a [\nabla_\theta \ln \pi_\theta(a|s) A(s,a)]$$

其中A是Advantage函数！

---

## 7. 价值迭代的收敛性

### 7.1 压缩映射定理

定义算子T：

$$(TV)(s) = \max_a \sum_{s'} P(s'|s,a)[R(s,a) + \gamma V(s')]$$

### 7.2 证明

对任意V1, V2：

$$\|TV_1 - TV_2\|_\infty \leq \gamma \|V_1 - V_2\|_\infty$$

由于γ<1，这是一个压缩映射！

### 7.3 收敛

根据 Banach 不动点定理，迭代V会收敛到唯一的不动点V*。

这证明了价值迭代一定收敛到最优价值函数！

---

## 8. GAE (Generalized Advantage Estimation)

### 8.1 定义

$$\hat{A}_t^{(k)} = \sum_{l=0}^{k-1} \gamma^l \delta_{t+l}$$

### 8.2 展开

$$\hat{A}_t^{(k)} = \delta_t + \gamma\lambda\delta_{t+1} + ... + \gamma^{k-1}\delta_{t+k-1}$$

### 8.3 极限

- 当k=1：TD(0)
- 当k→∞：MC
- 当λ=0：TD(0)
- 当λ=1：MC

## 9. 重要恒等式

| 名称 | 公式 |
|------|------|
| 回报定义 | $G_t = R_{t+1} + \gamma G_{t+1}$ |
| 状态价值 | $V_\pi(s) = \mathbb{E}[G_t\|s]$ |
| 动作价值 | $Q_\pi(s,a) = \mathbb{E}[G_t\|s,a]$ |
| 贝尔曼 | $V = R + \gamma P V$ |
| 最优贝尔曼 | $V^* = \max_a (R + \gamma P V^*)$ |
| TD误差 | $\delta = R + \gamma V' - V$ |
| 策略梯度 | $\nabla J = \mathbb{E}[\nabla \ln \pi \cdot A]$ |

---

这些公式是所有强化学习算法的基础，建议熟练掌握！
