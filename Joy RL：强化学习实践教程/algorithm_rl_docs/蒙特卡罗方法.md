# 蒙特卡罗方法 学习文档

> 通过完整回合采样估计状态价值函数的免模型预测方法

---

## 1. 算法基础认知

**一句话定义**：蒙特卡罗（Monte Carlo, MC）方法是一种免模型的预测方法，通过采样完整回合的经历来估计每个状态的价值，等经验足够多时自然收敛到真实值。

**直觉类比**：就像你第一次去一个餐厅，你不知道每个菜好不好吃，但多吃几次后，你就能估计出每个菜的平均味道——这就是蒙特卡罗的思想。

**历史背景**：蒙特卡罗方法源于1940年代的曼哈顿计划，用随机采样近似确定性问题。在强化学习中由Sutton等人发展完善。

**算法定位**：
- 类型：强化学习 → 免模型预测
- 输出：状态价值函数V(s)
- 模型类型：无模型、无偏估计

**前置知识**：
- [必备] 概率统计基础
- [必备] MDP基础

---

## 2. 核心原理

### 2.1 核心思想

蒙特卡罗方法的核心是"平均回报"：
- 从状态s出发，采样很多完整回合
- 记录每个回合的回报G
- V(s) = E[G]（经验平均）

### 2.2 工作流程

1. **采样**：从当前策略π生成完整回合
2. **计算回报**：G = r1 + γr2 + ... + γ^T r^T
3. **更新V**：V(s) ← V(s) + α(G - V(s))

### 2.3 关键概念

- **首次访问MC**：只记录第一次访问该状态的回报
- **每次访问MC**：每次访问都记录回报
- **增量更新**：用均值更新公式

---

## 3. 数学公式

### 3.1 回报定义

$$G_t = r_{t+1} + \gamma r_{t+2} + ... + \gamma^{T-t-1} r_T$$

### 3.2 价值更新

$$V(s) \leftarrow V(s) + \alpha [G - V(s)]$$

增量形式：

$$V_n = V_{n-1} + \frac{1}{n}(G - V_{n-1})$$

### 3.3 首次访问vs每次访问

| 方法 | 特点 | 偏差 |
|------|------|------|
| 首次访问 | 只用第一次访问的回报 | 无偏 |
| 每次访问 | 用所有访问的回报 | 有偏但方差小 |

## 4. 训练过程

### 4.1 算法步骤

```python
def monte_carlo_prediction(env, policy, n_episodes=1000, gamma=0.99, alpha=0.1):
    """
    蒙特卡罗预测
    
    Args:
        env: 环境
        policy: 策略
        n_episodes: 回合数
        gamma: 折扣因子
        alpha: 学习率
    
    Returns:
        V: 状态价值函数
    """
    V = np.zeros(env.n_states)
    returns = [[] for _ in range(env.n_states)]
    
    for episode in range(n_episodes):
        # 生成完整回合
        trajectory = []
        state, _ = env.reset()
        
        done = False
        while not done:
            # 根据策略选择动作
            action = np.random.choice(env.n_actions, p=policy[state])
            next_state, reward, terminated, truncated, _ = env.step(action)
            done = terminated or truncated
            
            trajectory.append((state, reward))
            state = next_state
        
        # 计算回报
        G = 0
        for t, (state, reward) in enumerate(reversed(trajectory)):
            G = gamma * G + reward
            
            # 首次访问更新
            first_visit = True
            for s, _ in trajectory[:len(trajectory)-1-t]:
                if s == state:
                    first_visit = False
                    break
            
            if first_visit:
                returns[state].append(G)
                V[state] = np.mean(returns[state])
    
    return V
```

### 4.2 超参数

| 参数 | 作用 | 推荐值 |
|------|------|--------|
| n_episodes | 采样回合数 | 1000-10000 |
| gamma | 折扣因子 | 0.9-0.99 |
| alpha | 学习率 | 0.01-0.1 |

## 6. 优缺点分析

### 6.1 优点

1. **无模型**：不需要环境转移概率
2. **无偏**：对回报的真实期望
3. **简单**：易于实现和理解

### 6.2 缺点

1. **需要完整回合**：效率低
2. **方差大**：回报随机性大
3. **高方差估计**：需要大量样本

### 6.3 与TD对比

| 方法 | 效率 | 方差 | 偏差 |
|------|------|------|------|
| 蒙特卡罗 | 低 | 高 | 无偏 |
| 时序差分 | 高 | 低 | 有偏 |

### 7.2 完整代码

```python
"""
蒙特卡罗方法 - 预测算法实现
"""

import numpy as np
import gymnasium as gym

class MonteCarloPrediction:
    """蒙特卡罗预测"""
    
    def __init__(self, n_states, gamma=0.99, alpha=0.1):
        self.n_states = n_states
        self.gamma = gamma
        self.alpha = alpha
        self.V = np.zeros(n_states)
        self.returns = [[] for _ in range(n_states)]
        self.counts = np.zeros(n_states)
    
    def update(self, trajectory):
        """从轨迹更新价值"""
        G = 0
        
        for t in range(len(trajectory) - 1, -1, -1):
            state, reward = trajectory[t]
            G = self.gamma * G + reward
            
            # 检查首次访问
            if self.counts[state] == 0 or not self._was_visited_before(state, trajectory[:t]):
                self.counts[state] += 1
                
                # 增量更新
                self.V[state] += self.alpha * (G - self.V[state])
    
    def _was_visited_before(self, state, trajectory):
        """检查之前是否访问过"""
        for s, _ in trajectory:
            if s == state:
                return True
        return False
    
    def get_value(self, state):
        """获取状态价值"""
        return self.V[state]

# ===============================
# 主程序
# ===============================
if __name__ == "__main__":
    # 创建简单环境
    env = gym.make('FrozenLake-v1', is_slippery=False)
    
    print("=" * 50)
    print("蒙特卡罗方法 - 预测")
    print("=" * 50)
    
    # 随机策略
    n_states = env.observation_space.n
    n_actions = env.action_space.n
    policy = np.ones((n_states, n_actions)) / n_actions
    
    # 创建MC预测器
    mc = MonteCarloPrediction(n_states, gamma=0.99, alpha=0.1)
    
    # 训练
    n_episodes = 5000
    
    for episode in range(n_episodes):
        # 生成轨迹
        trajectory = []
        state, _ = env.reset()
        done = False
        
        while not done:
            action = np.random.choice(n_actions, p=policy[state])
            next_state, reward, terminated, truncated, _ = env.step(action)
            done = terminated or truncated
            
            trajectory.append((state, reward))
            state = next_state
        
        # 更新
        mc.update(trajectory)
        
        if episode % 1000 == 0:
            print(f"回合{episode}: 平均价值={np.mean(mc.V):.3f}")
    
    # 输出结果
    print("\n状态价值:")
    for s in range(n_states):
        print(f"  V(s{s}) = {mc.V[s]:.3f}")
```

## 8. 手工代码实现

```python
"""
蒙特卡罗方法 - 手工NumPy实现
"""

import numpy as np
import gymnasium as gym

class MCPredictionManual:
    """纯NumPy实现"""
    
    def __init__(self, n_states, gamma=0.99, alpha=0.01):
        self.n_states = n_states
        self.gamma = gamma
        self.alpha = alpha
        self.V = np.zeros(n_states)
        self.returns_sum = np.zeros(n_states)
        self.returns_count = np.zeros(n_states)
    
    def update(self, trajectory):
        """增量更新"""
        G = 0
        visited = set()
        
        for state, reward in reversed(trajectory):
            G = self.gamma * G + reward
            
            if state not in visited:
                self.returns_sum[state] += G
                self.returns_count[state] += 1
                self.V[state] = self.returns_sum[state] / self.returns_count[state]
                visited.add(state)
    
    def get_V(self):
        return self.V

# 测试
if __name__ == "__main__":
    env = gym.make('FrozenLake-v1', is_slippery=True)
    mc = MCPredictionManual(16, gamma=0.99)
    
    print("=" * 50)
    print("蒙特卡罗 - 手工实现")
    print("=" * 50)
    
    for ep in range(5000):
        traj = []
        s, _ = env.reset()
        done = False
        while not done:
            a = env.action_space.sample()
            s2, r, d, t, _ = env.step(a)
            traj.append((s, r))
            if d or t:
                break
            s = s2
        
        if ep % 1000 == 0:
            print(f"回合{ep}: V平均={np.mean(mc.V):.3f}")
        
        if ep >= 100:
            pass  # 继续训练
    
    print("\n最终价值估计:")
    print(mc.get_V())
```

## 11. 常见问题

### 11.1 方差过大

**问题**：回报波动大，收敛慢

**解决**：
1. 增加回合数
2. 使用每次访问MC
3. 结合TD方法

### 11.2 状态访问不均

**问题**：某些状态从未访问

**解决**：
- 改进策略增加探索

## 13. 练习题

### 练习1：MC vs TD

**问题**：为什么MC方法对回报估计是无偏的，而TD是有偏的？

**答案**：
- MC用真实回报G_t，是真实期望
- TD用估计值r + γV(s')，有估计误差
