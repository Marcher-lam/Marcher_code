# 动态规划 学习文档

> 基于模型的最优策略求解算法，通过迭代更新价值函数找到最优决策

---

## 1. 算法基础认知

**一句话定义**：动态规划（Dynamic Programming, DP）是一种将复杂问题分解为子问题并逐个求解的优化方法，在强化学习中用于在已知环境模型的情况下求解最优策略。

**直觉类比**：想象你在走一个迷宫，其他人都直接尝试走通，但你知道用动态规划的人会先记录每个位置到终点的距离，然后从终点反向推算每个位置的价值，最后只要沿着价值最高的方向走就能找到最优路径。

**历史背景**：动态规划由理查德·贝尔曼在1950年代提出，最初用于解决多阶段决策问题。1957年贝尔曼发表《动态规划》一书，将动态规划引入优化领域。后来被广泛应用于强化学习，成为基于模型RL算法的基础。

**算法定位**：
- 类型：有模型强化学习 → 最优控制
- 输出：最优策略和最优价值函数
- 模型类型：基于模型（Model-based）

**前置知识**：
- [必备] 马尔可夫决策过程基础
- [必备] 概率论基础（期望、转移概率）
- [扩展] 线性代数（矩阵运算）

## 2. 核心原理

### 2.1 核心思想

动态规划的核心思想是"分而治之"和"最优子结构"：
1. **分而治之**：将大问题拆成小问题解决
2. **最优子结构**：最优解包含子问题的最优解
3. **重叠子问题**：子问题会被重复使用

在强化学习中，就是利用贝尔曼方程将状态价值递归分解，从终止状态反向推算每个状态的价值。

**核心思想**：利用价值函数的递归结构，从已知价值推算未知价值

### 2.2 工作流程

动态规划主要有两种算法：**策略迭代**和**价值迭代**。

**策略迭代流程**：
1. 初始化价值函数V(s)和策略π(s)
2. **策略估计**：根据当前π估计V(s)
3. **策略改进**：根据V(s)改进π(s)
4. 重复2-3直到策略收敛

**价值迭代流程**：
1. 初始化V(s)=0
2. 对每个状态：V(s) = max_a Σ P(s'|s,a)[R + γV(s')]
3. 重复直到收敛
4. 提取最优策略

### 2.3 关键概念解释

- **策略估计（Policy Evaluation）**：给定策略π，计算状态价值函数V_π
- **策略改进（Policy Improvement）**：根据V改进策略π
- **策略稳定性**：当π不再改进时，找到最优策略
- **价值迭代**：直接迭代更新价值函数

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 | 说明 |
|------|------|------|
| $V(s)$ | 状态价值函数 | 状态s的期望回报 |
| $Q(s,a)$ | 动作价值函数 | 在s执行a的期望回报 |
| $V^*(s)$ | 最优状态价值 | 最佳策略下的价值 |
| $π^*(s)$ | 最优策略 | 最大化价值的策略 |
| $θ$ | 收敛阈值 | 迭代停止条件 |

### 3.2 策略估计公式

给定策略π，状态价值函数满足贝尔曼方程：

$$V_π(s) = \sum_a π(a|s) \sum_{s'} P(s'|s,a)[R(s,a) + γV_π(s')]$$

**迭代求解**：
$$V_{k+1}(s) = \sum_a π(a|s) \sum_{s'} P(s'|s,a)[R(s,a) + γV_k(s')]$$

### 3.3 策略改进公式

根据当前价值函数改进策略：

$$Q(s,a) = \sum_{s'} P(s'|s,a)[R(s,a) + γV(s')]$$

$$π_{new}(s) = \arg\max_a Q(s,a)$$

### 3.4 价值迭代公式

$$V(s) \leftarrow \max_a \sum_{s'} P(s'|s,a)[R(s,a) + γV(s')]$$

### 3.5 贝尔曼最优方程

$$V^*(s) = \max_a \sum_{s'} P(s'|s,a)[R(s,a) + γV^*(s')]$$

$$π^*(s) = \arg\max_a \sum_{s'} P(s'|s,a)[R(s,a) + γV^*(s')]$$

### 3.6 推导证明

**策略迭代收敛证明**：

设原策略π，改���后得到π'。如果存在状态满足：

$$V_{π'}(s) > V_π(s)$$

则价值提升。反之如果：

$$V_{π'}(s) = V_π(s)$$

则π已是最优策略。

## 4. 训练过程讲解

### 4.1 策略估计实现

```python
def policy_evaluation(env, pi, theta=1e-6, gamma=0.9):
    """
    策略估计：迭代计算状态价值函数
    
    Args:
        env: 环境（MDP）
        pi: 策略
        theta: 收敛阈值
        gamma: 折扣因子
        
    Returns:
        V: 状态价值函数
    """
    V = np.zeros(env.n_states)
    
    while True:
        delta = 0
        for s in range(env.n_states):
            v = V[s]
            new_v = 0
            for a, prob_a in enumerate(pi[s]):
                for (s_next, p), r = env.get_transition(s, a):
                    new_v += prob_a * p * (r + gamma * V[s_next])
            V[s] = new_v
            delta = max(delta, abs(v - V[s]))
        
        if delta < theta:
            break
    
    return V
```

### 4.2 策略改进实现

```python
def policy_improvement(env, V, gamma=0.9):
    """
    策略改进：根据价值函数改进策略
    
    Returns:
        pi_new: 改进后的策略
    """
    pi_new = np.zeros((env.n_states, env.n_actions))
    
    for s in range(env.n_states):
        q_values = []
        for a in range(env.n_actions):
            q = 0
            for (s_next, p), r in env.get_transition(s, a):
                q += p * (r + gamma * V[s_next])
            q_values.append(q)
        
        # 贪心选择最大Q值对应的动作
        best_a = np.argmax(q_values)
        pi_new[s, best_a] = 1.0
    
    return pi_new
```

### 4.3 策略迭代主循环

```python
def policy_iteration(env, theta=1e-6, gamma=0.9):
    """
    策略迭代算法
    """
    # 初始化随机策略
    pi = np.ones((env.n_states, env.n_actions)) / env.n_actions
    
    while True:
        # 策略估计
        V = policy_evaluation(env, pi, theta, gamma)
        
        # 策略改进
        pi_new = policy_improvement(env, V, gamma)
        
        # 检查策略是否稳定
        if np.allclose(pi, pi_new):
            break
        
        pi = pi_new
    
    return V, pi
```

- 投资组合优化

### 5.2 适用条件

动态规划要求：
1. ✓ 环境模型已知（P和R已知）
2. ✓ 状态空间可枚举
3. ✓ 动作空间有限

### 5.3 不适用场景

1. ✗ 环境模型未知
2. ✗ 状态空间巨大（维度灾难）
3. ✗ 连续状态/动作空间

---

## 6. 优缺点分析

### 6.1 优点

1. **收敛保证**：理论上一定收敛到最优解
2. **效率高**：利��重叠子问题避免重复计算
3. **理论基础强**：有严格的数学证明

### 6.2 缺点

1. **需要模型**：必须知道环境转移概率
2. **维度灾难**：状态多时计算困难
3. **计算复杂度**：O(|S|²|A|)每轮

### 6.3 与同类对比

| 算法 | 需要模型 | 收敛速度 | 适用场景 |
|------|---------|---------|---------|
| 策略迭代 | 是 | 快 | 小状态空间 |
| 价值迭代 | 是 | 慢但稳定 | 小状态空间 |
| Q-learning | 否 | 慢 | 大状态空间 |

```python
"""
动态规划算法 - 策略迭代与价值迭代实现
使用Gymnasium环境测试
"""

import numpy as np
import gymnasium as gym
from collections import defaultdict

class DPAgent:
    """
    动态规划智能体
    """
    
    def __init__(self, env, gamma=0.9):
        self.env = env
        self.gamma = gamma
        self.n_states = env.observation_space.n
        self.n_actions = env.action_space.n
        
        # 提取MDP参数
        self.P = defaultdict(lambda: defaultdict(list))
        self.R = {}
        
        # 遍历环境获取转移概率
        for s in range(self.n_states):
            for a in range(self.n_actions):
                for prob, s_next, r, done in env.P[s][a]:
                    self.P[s][a].append(((s_next, prob), r))
                    if done:
                        self.R[(s, a)] = r
        
        # 初始化
        self.V = np.zeros(self.n_states)
        self.pi = np.ones((self.n_states, self.n_actions)) / self.n_actions
    
    def PolicyEvaluation(self, theta=1e-6):
        """策略估计"""
        while True:
            delta = 0
            for s in range(self.n_states):
                v = self.V[s]
                new_v = 0
                for a, prob_a in enumerate(self.pi[s]):
                    for (s_next, p), r in self.P[s][a]:
                        new_v += prob_a * p * (r + self.gamma * self.V[s_next])
                
                self.V[s] = new_v
                delta = max(delta, abs(v - self.V[s]))
            
            if delta < theta:
                break
        
        return self.V
    
    def PolicyImprovement(self):
        """策略改进"""
        policy_stable = True
        pi_new = np.zeros((self.n_states, self.n_actions))
        
        for s in range(self.n_states):
            q_values = []
            for a in range(self.n_actions):
                q = 0
                for (s_next, p), r in self.P[s][a]:
                    q += p * (r + self.gamma * self.V[s_next])
                q_values.append(q)
            
            best_a = np.argmax(q_values)
            pi_new[s, best_a] = 1.0
            
            if not np.isclose(self.pi[s, pi_new[s]).all():
                policy_stable = False
        
        self.pi = pi_new
        return policy_stable
    
    def PolicyIteration(self, max_iterations=1000, theta=1e-6):
        """策略迭代"""
        for i in range(max_iterations):
            self.PolicyEvaluation(theta)
            stable = self.PolicyImprovement()
            if stable:
                print(f"策略迭代在第{i+1}轮收敛")
                break
        
        return self.V, self.pi
    
    def ValueIteration(self, theta=1e-6, max_iterations=1000):
        """价值迭代"""
        for i in range(max_iterations):
            delta = 0
            for s in range(self.n_states):
                v = self.V[s]
                max_q = max(
                    sum(p * (r + self.gamma * self.V[s_next]) 
                        for (s_next, p), r in self.P[s][a])
                    for a in range(self.n_actions)
                )
                self.V[s] = max_q
                delta = max(delta, abs(v - self.V[s]))
            
            if delta < theta:
                print(f"价值迭代在第{i+1}轮收敛")
                break
        
        # 提取策略
        pi = np.zeros((self.n_states, self.n_actions))
        for s in range(self.n_states):
            q_values = [
                sum(p * (r + self.gamma * self.V[s_next])
                    for (s_next, p), r in self.P[s][a])
                for a in range(self.n_actions)
            ]
            best_a = np.argmax(q_values)
            pi[s, best_a] = 1.0
        
        return self.V, pi
    
    def get_action(self, state):
        """获取动作"""
        return np.argmax(self.pi[state])
```

## 8. 手工代码实现

### 8.1 完整实现

```python
"""
动态规划算法 - 手工实现
不使用强化学习库，从零实现
"""

import numpy as np
from collections import defaultdict

class FrozenLakeDP:
    """
    动态规划求解FrozenLake
    """
    
    def __init__(self, gamma=0.9, theta=1e-6):
        self.gamma = gamma
        self.theta = theta
        
        # 4x4网格
        self.n_states = 16
        self.n_actions = 4
        
        # 状态转移和奖励（确定性）
        # P[s][a] = [(s', p, r), ...]
        self.P = self._build_P()
        
    def _build_P(self):
        """构建转移概率"""
        P = defaultdict(lambda: defaultdict(list))
        
        # 简化的4x4FrozenLake转移
        for s in range(16):
            row, col = s // 4, s % 4
            
            for a in range(4):
                # 动作：0-上, 1-右, 2-下, 3-左
                if a == 0:  # 上
                    s_next = max(0, row - 1) * 4 + col
                elif a == 1:  # 右
                    s_next = min(3, row + 1) * 4 + col
                elif a == 2:  # 下
                    s_next = min(3, row + 1) * 4 + col if row < 3 else s
                else:  # 左
                    s_next = row * 4 + max(0, col - 1)
                
                # 奖励
                if s_next == 15:  # 目标
                    r = 1
                elif s_next in [5, 7, 11, 12]:  # 洞
                    r = 0
                else:
                    r = 0
                
                P[s][a].append((s_next, 1.0, r))
        
        return P
    
    def policy_evaluation(self, pi):
        """策略估计"""
        V = np.zeros(self.n_states)
        
        for iteration in range(1000):
            delta = 0
            for s in range(self.n_states):
                v = V[s]
                new_v = 0
                
                for a in range(self.n_actions):
                    prob_a = pi[s, a] if len(pi.shape) > 1 else pi[s]
                    
                    for s_next, p, r in self.P[s][a]:
                        new_v += prob_a * p * (r + self.gamma * V[s_next])
                
                V[s] = new_v
                delta = max(delta, abs(v - V[s]))
            
            if delta < self.theta:
                print(f"策略估计在第{iteration+1}轮收敛")
                break
        
        return V
    
    def policy_improvement(self, V):
        """策略改进"""
        pi_new = np.zeros((self.n_states, self.n_actions))
        
        for s in range(self.n_states):
            q_values = []
            for a in range(self.n_actions):
                q = sum(
                    p * (r + self.gamma * V[s_next])
                    for s_next, p, r in self.P[s][a]
                )
                q_values.append(q)
            
            best_a = np.argmax(q_values)
            pi_new[s, best_a] = 1.0
        
        return pi_new
    
    def policy_iteration(self, max_iters=100):
        """策略迭代"""
        pi = np.ones((self.n_states, self.n_actions)) / self.n_actions
        
        for i in range(max_iters):
            V = self.policy_evaluation(pi)
            pi_new = self.policy_improvement(V)
            
            if np.allclose(pi, pi_new):
                print(f"策略迭代在第{i+1}轮收敛")
                break
            
            pi = pi_new
        
        return V, pi
    
    def value_iteration(self, max_iters=1000):
        """价值迭代"""
        V = np.zeros(self.n_states)
        
        for i in range(max_iters):
            delta = 0
            for s in range(self.n_states):
                v = V[s]
                max_q = max(
                    sum(p * (r + self.gamma * V[s_next])
                    for s_next, p, r in self.P[s][a]
                    for a in range(self.n_actions)
                )
                V[s] = max_q
                delta = max(delta, abs(v - V[s]))
            
            if delta < self.theta:
                print(f"价值迭代在第{i+1}轮收敛")
                break
        
        # 提取策略
        pi = self.policy_improvement(V)
        
        return V, pi
```

## 10. 模型评估

### 10.1 评估指标

| 指标 | 含义 | 目标 |
|------|------|------|
| 迭代次数 | 收敛所需轮数 | 越少越好 |
| Δ | 每轮最大价值变化 | 越小越好 |
| V(goal) | 目标状态价值 | 越高越好 |

### 10.2 评估代码

```python
def evaluate_dp(env, pi, V, n_episodes=100):
    """评估动态规划策略"""
    total_rewards = []
    success_count = 0
    
    for _ in range(n_episodes):
        s, _ = env.reset()
        episode_reward = 0
        done = False
        
        while not done and episode_reward < 1000:
            a = np.argmax(pi[s])
            s, r, terminated, truncated, _ = env.step(a)
            episode_reward += r
            done = terminated or truncated
            
            if r > 0:
                success_count += 1
        
        total_rewards.append(episode_reward)
    
    return np.mean(total_rewards), success_count / n_episodes
```

## 11. 常见问题与易错点

### 11.1 价值不收敛

**问题**：迭代不收敛，价值振荡

**原因**：
1. 折扣因子γ设置不当（太大）
2. 价值初始化不为0
3. 存在环（无终止状态）

**解决方法**：
```python
# 确保折扣因子合理
gamma = 0.9  # 不要设置太大

# 初始化为0
V = np.zeros(n_states)

# 检查环境有终止状态
assert has_terminal_state
```

### 11.2 维度灾难

**问题**：状态空间太大无法计算

**原因**：|S|指数爆炸

**解决方法**：
1. 状态离散化
2. 使用函数逼近
3. 降维（PCA）

### 11.3 策略初始化

**问题**：随机策略导致收敛慢

**解决方法**：使用贪心初始化

## 12. 学习总结

### 12.1 核心要点

✓ **策略迭代**：评估→改进→循环，直到稳定

✓ **价值迭代**：直接迭代更新价值，提取策略

✓ **贝尔曼方程**：连接相邻状态的价值

✓ **最优子结构**：最优解包含子问题最优解

### 12.2 关键公式

**策略估计**：
$$V_{π} = \sum_a π(a|s) [R + γP V_{π}]$$

**价值迭代**：
$$V(s) = \max_a [R + γP V(s')]$$

### 12.3 最佳实践

1. ✓ 先验证环境模型已知
2. ✓ 合理设置折扣因子
3. ✓ 使用合适的收敛阈值

## 13. 练习题与思考题

### 13.1 基础练习

**练习1**：一个3状态MDP，γ=0.9，使用价值迭代求V*

| s | a=0 | a=1 | R |
|---|-----|-----|-----|
| s0 | s1(1.0) | s0(1.0) | a0:R=0, a1:R=1 |
| s1 | s2(1.0) | s0(1.0) | R=0 |
| s2 | 终止 | 终止 | R=10 |

**答案**：
- V*(s2) = 10
- V*(s1) = 0.9*10 = 9
- V*(s0) = max(0+0.9*9, 1+0.9*0) = 8.1

### 13.2 进阶思考

**思考**：为什么动态规划需要知道环境模型，而Q-learning不需要？

**答案**：
- 动态规划用贝尔曼方程直接计算，需要P(s'|s,a)
- Q-learning通过试错学习，不需要环境知识
