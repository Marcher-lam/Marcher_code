## 1. 为什么需要近似

---

## 2. 近似方法

### 2.1 线性近似
$$Q(s,a) = \theta^T \cdot f(s,a)$$

### 2.2 神经网络近似
```python
class QNetwork(nn.Module):
    def __init__(self, state_dim, action_dim):
        self.net = nn.Sequential(
            nn.Linear(state_dim, 128),
            nn.ReLU(),
            nn.Linear(128, action_dim)
        )
    
    def forward(self, s):
        return self.net(s)
```
