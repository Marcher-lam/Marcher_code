# C51（Categorical 51）学习文档

> 学习Q值分布的原始算法

---

## 1. 算法基础认知

**一句话定义**：C51是Distributional DQN的原始实现，将Q值建模为51个离散atoms的分布。

---

## 2. 核心原理

### 2.1 支持集

- 51个离散点 V_min 到 V_max
- 均匀分布

### 2.2 网络结构

```python
class C51Network(nn.Module):
    def __init__(self, n_atoms=51):
        self.output_dim = n_atums * action_dim
        self.n_atoms = n_atoms
    
    def forward(self, x):
        # 每个动作输出51个概率
        probs = F.softmax(self.net(x).view(-1, self.n_atoms)
        return probs
```
