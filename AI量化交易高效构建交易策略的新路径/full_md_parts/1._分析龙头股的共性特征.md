步骤3：构建模仿因子公式。

- 小市值（低于中位数）。  
- 新题材（topic_new为True）。  
- 换手率低于龙头股区间上限。

Python

```python
def mimic_factor(row):
    score = 0
    if row['total_mv'] < median_mv:
        score += 1
    if row['topic_new':
        score += 1
    if row['turnover_rate'] < turnover_range[1]:
        score += 1
    return score
first Boards['mimic_score'] = first Boards.apply(mimic_factor, axis=1) 
```
