# 加载预训练模型

## 本章目标

在前面章节中，我们学习了如何使用分词器准备输入数据。现在，我们将加载LLM本身。

**我们将使用的模型：Qwen3 0.6B**

"0.6B"表示模型包含大约0.6亿个权重参数。

## 为什么选择Qwen3？

在仔细评估了几个开源权重基础模型后，我选择了Qwen3 0.6B，原因如下：

1. **小而强大**：一个小但有能力、可在消费级硬件上运行的开源权重模型
2. **性能领先**：Qwen3模型家族的较大版本在建模性能方面是领先的开源权重模型
3. **内存高效**：Qwen3 0.6B比Llama 3 1B和OLMo 2 1B更节省内存
4. **双重支持**：Qwen3提供基础模型（我们的推理模型开发重点）和官方推理变体，可用于评估参考

**注意：** "Qwen3"的标准拼写不包含空格，而"Llama 3"包含空格。

## Qwen3模型架构

Qwen3 0.6B基础模型架构包括：

- **嵌入层（Embedding）**：将token ID转换为向量表示
- **28个Transformer块（Transformer Blocks）**：模型的核心处理单元
  - 每个块包含：
    - 分组查询注意力（Grouped-Query Attention，GQA）
    - 前馈网络（Feed-Forward Network）
    - RMS归一化（RMS Normalization）
- **最终归一化层**
- **输出头（Output Head）**：将输出投影回词汇表大小

```
输入文本
    ↓
分词器 → Token ID
    ↓
嵌入层
    ↓
[Transformer块1] → [Transformer块2] → ... → [Transformer块28]
    ↓
最终归一化
    ↓
输出头 → 词汇表分数
    ↓
预测的下一个Token
```

**注意：**
- 详细的架构理解不是本书必需的
- 因为我们不修改基础模型本身，而是在其之上构建推理方法
- 你现在可以将架构视为一个黑盒
- 感兴趣的读者可以在附录C中找到更多关于这些组件的信息

## 模型配置参数

Qwen3 0.6B的主要配置：

```python
QWEN_CONFIG_06_B = {
    "vocab_size": 151_936,       # 词汇表大小
    "context_length": 40_960,     # 训练时使用的原始长度
    "emb_dim": 1024,               # 嵌入维度
    "n_heads": 16,                 # 注意力头数
    "n_layers": 28,                # 层数
    "hidden_dim": 3072,            # FeedForward中的中间维度大小
    "head_dim": 128,               # GQA中的头大小
    "qk_norm": True,               # 是否在GQA中归一化查询和键
    "n_kv_groups": 8,              # GQA的键值组
    "rope_base": 1_000_000.0,     # RoPE中的"theta"基数
    "dtype": torch.bfloat16,       # 降低精度的数据类型以减少内存
}
```

def get_device():

## 下载模型权重

在加载模型并将其放到选定设备之前，我们需要先下载Qwen3 0.6B的权重文件。这些文件是正确初始化预训练模型所必需的：

```python
download_qwen3_small(kind="base", tokenizer_only=False, out_dir="qwen3")
```

输出：
```
qwen3-0.6B-base.pth: 100% (1433 MiB / 1433 MiB)
✓ qwen3-tokenizer-base.json already up-to-date
```

**说明：**
分词器前面的对勾标记，是因为我们在前一节已经下载过了。

## 加载模型

下载模型权重后，我们现在可以实例化一个`Qwen3Model`类，并通过PyTorch的`load_state_dict`方法将预训练权重加载到其中：

```python
from reasoning_from_scratch.qwen3 import Qwen3Model, QWEN_CONFIG_06_B

model_file = Path("qwen3") / "qwen3-0.6B-base.pth"

# 实例化一个带有随机权重占位符的Qwen3模型
model = Qwen3Model(QWEN_CONFIG_06_B)

# 将预训练权重加载到模型中
model.load_state_dict(torch.load(model_file))

# 将模型转移到指定设备（例如"cuda"）
model.to(device)
```

**说明：**
- 如果设备设置为"cpu"，`model.to(device)`操作会被跳过，因为模型默认已经在CPU内存中
