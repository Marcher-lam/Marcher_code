# 常用术语对照表

## A

**Activation Function（激活函数）**
神经网络中的非线性函数，使模型能够学习复杂的模式。常见的激活函数包括ReLU、GELU、SiLU等。

**Autoregressive Text Generation（自回归文本生成）**
LLM一次生成一个token，每个token基于之前生成的所有token。这是LLM生成文本的标准方式。

**Apple Silicon GPU (MPS)**
苹果芯片（M1/M2/M3/M4等）上的GPU加速，通过Metal Performance Shaders (MPS) 实现。

## B

**Batch Size（批大小）**
一次输入模型的样本数量。批大小为1表示一次处理一个样本。

**Bias（偏差）**
神经网络层中的可学习偏移项，用于平移输出。RMSNorm默认不使用偏差。

**Byte Pair Encoding (BPE)（字节对编码）**
一种子词分词算法，通过迭代合并最常见的字符对来构建词汇表。大多数现代LLM（包括Qwen3）使用BPE或其变体。

## C

**Cache（缓存）**
存储中间计算结果以避免重复计算的技术。KV缓存存储注意力机制中的键和值。

**Chain-of-Thought (CoT) Reasoning（思维链推理）**
LLM在给出最终答案之前明确生成中间推理步骤的技术。这是推理模型的核心特征。

**Context Length（上下文长度）**
模型可以处理的最大输入序列长度。Qwen3 0.6B的训练长度为40,960个token。

**CUDA**
NVIDIA的并行计算平台和API，用于在NVIDIA GPU上加速深度学习计算。

**Compilation（编译）**
使用torch.compile优化模型以提高推理性能的技术，包括操作融合、死代码消除等。

## D

**Decoder-only（仅解码器）**
Transformer架构的一种变体，仅包含解码器部分。大多数现代LLM（如GPT、Qwen）都是解码器模型。

**Distillation（蒸馏）**
将大型、强大模型的知识转移到小型、高效模型的技术。在LLM语境中，通常使用SFT从大模型生成的数据训练小模型。

**Device（设备）**
模型运行的计算设备，可以是CPU、NVIDIA GPU (CUDA)或Apple Silicon GPU (MPS)。

**dtype（数据类型）**
张量中元素的数据类型，如float32、float16、bfloat16等。较低精度类型（如bfloat16）可以减少内存使用。

## E

**Embedding（嵌入）**
将离散元素（如token ID）映射到连续向量表示的层。Token嵌入是LLM的第一层。

**Embedding Dimension（嵌入维度）**
嵌入向量的维度大小，也是模型的隐藏维度。Qwen3 0.6B为1024。

**End-of-Sequence (EOS) Token（结束序列token）**
标记文本或序列结束的特殊token。Qwen3使用`<|endoftext|>`或`<|im_end|>`作为EOS token。

**Epoch（轮次）**
训练期间完整遍历整个训练数据集一次。

**Evaluation（评估）**
衡量模型在特定任务或数据集上性能的过程。评估指标包括准确率、F1分数等。

## F

**Feed-Forward Network（前馈网络）**
Transformer块中由全连接层组成的子模块。Qwen3使用GLU变体（SwiGLU）。

**Fine-tuning（微调）**
在预训练模型上进一步训练以适应特定任务或领域的较小数据集。

**Forward Pass（前向传播）**
数据从输入层流向输出层的计算过程。推理期间只进行前向传播。

## G

**GPU (Graphics Processing Unit)（图形处理单元）**
专门为并行计算设计的硬件，深度学习中用于加速模型训练和推理。

**GELU (Gaussian Error Linear Unit)（高斯误差线性单元）**
一种平滑的激活函数，使用高斯累积分布函数。比ReLU计算更昂贵但性能更好。

**GLU (Gated Linear Unit)（门控线性单元）**
一种前馈网络变体，使用额外的线性层和门控机制来提高表达能力。SwiGLU是GLU和SiLU的结合。

**Grouped Query Attention (GQA)（分组查询注意力）**
多头注意力（MHA）的高效变体，多个查询头共享键和值投影。减少参数和内存使用。

**Gradient（梯度）**
损失函数相对于模型参数的偏导数，用于通过反向传播更新参数。

## H

**Head Dimension（头维度）**
注意力机制中每个头的维度大小。Qwen3 0.6B为128。

**Hidden Dimension（隐藏维度）**
前馈网络中间层的维度大小。Qwen3 0.6B为3072。

**Hidden State（隐藏状态）**
模型在处理过程中的内部表示。在RNN中是隐藏向量，在Transformer中通常是token嵌入。

## I

**Inference（推理）**
使用训练好的模型进行预测，如从提示生成文本。不同于统计学中的推理（从数据得出结论）。

**Inference Mode（推理模式）**
使用`@torch.inference_mode()`装饰器禁用梯度跟踪，以提高推理速度和减少内存使用。

**Inference-time Compute Scaling（推理时计算扩展）**
在推理时通过增加计算资源来提升模型性能的技术，如思维链推理，无需修改模型权重。

**Input Tensor（输入张量）**
传递给模型的输入数据，形状为[batch_size, sequence_length]。

**Intermediate Steps（中间步骤）**
推理过程中生成的中间推理步骤或思维过程。CoT推理的关键特征。

## K

**Key (K)（键）**
注意力机制中的向量之一，用于与查询计算注意力分数。

**KV Cache（键值缓存）**
存储注意力机制中键和值向量的缓存技术，避免在自回归生成中重复计算。显著加速推理。

## L

**Layer（层）**
神经网络的基本构建块，包含可学习参数（权重和偏差）。

**Layer Normalization (LayerNorm)（层归一化）**
对层输出进行归一化的技术，减去均值并除以标准差。使均值为0，标准差为1。

**Linear Layer（线性层/全连接层）**
应用线性变换（y = Wx + b）的神经网络层。

**LLM (Large Language Model)（大语言模型）**
在大规模文本数据上训练的大型神经网络，能够理解和生成人类语言。

**Logits（对数几率）**
模型输出的原始分数，在最终分类前应用softmax等函数。

**Loss Function（损失函数）**
衡量模型预测与真实标签之间差异的函数。训练目标是最小化损失。

## M

**Mask（掩码）**
用于在注意力机制中屏蔽某些位置的张量。下三角掩码用于自回归模型，防止看到未来token。

**Memory Allocated（分配的内存）**
模型在GPU上使用的内存量。KV缓存会减少内存带宽使用。

**Multi-Head Attention (MHA)（多头注意力）**
注意力机制的一种，将查询、键和值投影到多个头，每个头学习不同的表示。

**Model Compilation（模型编译）**
使用torch.compile优化模型以提高性能，包括操作融合、内存优化等。

## N

**Next-token Prediction（下一个token预测）**
训练LLM的核心目标，预测文本序列中的下一个token。

**Normalization（归一化）**
对数据或层输出进行缩放以使其分布稳定的技术。常见方法有LayerNorm、RMSNorm。

**Number of Heads（头数）**
注意力机制中的头数量。Qwen3 0.6B有16个注意力头。

**Number of Key-Value Groups（键值组数）**
GQA中的键值组数。Qwen3 0.6B有8个组（因此每个组对应2个查询头）。

## O

**Output Token（输出token）**
LLM生成的下一个token ID，通过分词器解码为文本。

**Output Head（输出头）**
模型最后一层，将隐藏状态投影到词汇表大小的分数。

**Overfitting（过拟合）**
模型在训练数据上表现很好但在新数据上表现差的现象。

## P

**Parameter（参数）**
神经网络中的可学习权重。参数数量是模型大小的主要度量。Qwen3 0.6B有约0.6亿参数。

**Position Encoding（位置编码）**
将位置信息注入模型的技术。RoPE通过旋转查询和键向量实现。

**Post-training（后训练）**
预训练后对模型进行的训练，包括指令微调（SFT）和偏好微调。

**Pre-training（预训练）**
在大规模文本数据上训练LLM的基础阶段，学习预测下一个token。

**Prompt（提示）**
输入给LLM的文本，用于引导模型生成特定的输出。

## Q

**Query (Q)（查询）**
注意力机制中的向量之一，用于与键计算注意力分数。

**QKNorm（查询键归一化）**
对查询和键向量应用额外的RMSNorm的技术，Qwen3中使用以提高训练稳定性。

## R

**ReLU (Rectified Linear Unit)（整流线性单元）**
简单且流行的激活函数，max(0, x)。在零处有折点但计算便宜。

**Reinforcement Learning (RL)（强化学习）**
通过与环境交互并接收奖励来学习策略的方法。在推理模型中用于训练推理能力。

**Reinforcement Learning from Human Feedback (RLHF)（带人类反馈的强化学习）**
使用人类反馈作为奖励信号的强化学习，用于对齐LLM与人类偏好。

**RMS Normalization (RMSNorm)（均方根归一化）**
比LayerNorm计算更高效的归一化方法，除以均方根而非均值和标准差。

**RoPE (Rotary Position Embeddings)（旋转位置嵌入）**
通过旋转查询和键向量编码位置信息的位置编码方法，现代LLM中广泛使用。

## S

**Sequence Length（序列长度）**
输入或输出文本的token数量。

**Shape（形状）**
张量的维度，如[batch_size, sequence_length]或[batch_size, num_tokens, vocab_size]。

**SiLU (Sigmoid Linear Unit)（sigmoid线性单元）**
也称为Swish，是平滑的激活函数。比GELU计算更便宜，性能相当。

**Supervised Fine-tuning (SFT)（监督微调）**
使用标记数据集对预训练模型进行微调，也称为指令微调。

**SwiGLU**
Swish激活和GLU前馈网络的结合，是Qwen3中前馈模块的实现。

## T

**Tensor（张量）**
PyTorch中的基本数据结构，类似于NumPy数组但可以在GPU上运行。

**Text Generation（文本生成）**
LLM根据输入提示生成连贯文本的过程，也称为推理。

**Token（令牌）**
分词器处理的文本最小单元，可以是完整单词、子词或标点。

**Tokenizer（分词器）**
将文本转换为token ID并解码回来的模型或工具，是LLM文本处理管道的关键组件。

**Training（训练）**
通过反向传播和梯度下降更新模型参数以最小化损失函数的过程。

**Transformer Block（Transformer块）**
LLM的核心构建块，包含注意力机制和前馈网络，重复多次（如28次）。

## U

**Unsqueeze（解压）**
添加大小为1的维度的PyTorch操作，如将[1, 2, 3]变为[[1, 2, 3]]。

## V

**Value (V)（值）**
注意力机制中的向量之一，根据注意力分数加权求和得到上下文。

**Vocabulary Size（词汇表大小）**
分词器可以处理的唯一token数量。Qwen3的词汇表大小为151,936。

**Variance（方差）**
数据点与均值之差的平方的平均值，衡量数据的离散程度。

## W

**Weight（权重）**
神经网络层中的可学习参数。权重数量是模型大小的主要度量。

**Word（词）**
文本的基本单位，但分词器可能将词拆分为更小的子词token。

## X

**XOR (Exclusive OR)（异或）**
逻辑运算符，输入不同时为真，相同时为假。常用于测试逻辑推理能力。

## 其他重要概念

**Inference vs Training（推理 vs 训练）**
- 推理：使用训练好的模型进行预测（如生成文本），只进行前向传播
- 训练：更新模型参数以最小化损失，包括前向和反向传播

**Reasoning vs Pattern Matching（推理 vs 模式匹配）**
- 推理：通过中间步骤系统地推导结论
- 模式匹配：基于学习的统计关联生成文本

**Compute vs Memory Tradeoff（计算 vs 内存权衡）**
- KV缓存：减少计算但增加内存使用
- 模型编译：提高速度但首次运行有编译开销

**Precision vs Performance（精度 vs 性能）**
- 低精度类型（bfloat16）：减少内存使用但可能影响数值稳定性
- 标准精度（float32）：稳定但占用更多内存

**学习建议：**
1. 在遇到术语时，先在本表中查找基本定义
2. 结合具体代码示例理解术语的实际应用
3. 注意术语在不同上下文中的细微差别（如"inference"在神经网络和统计学中的不同含义）
4. 优先掌握核心术语（LLM、Token、Embedding、Attention等），再学习更具体的技术细节
