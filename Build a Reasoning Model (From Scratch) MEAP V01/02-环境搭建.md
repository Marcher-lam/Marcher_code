# 环境搭建

## 前置要求

在开始之前，你需要：
- 已安装Python 3.10或更新版本
- 基本的Python编程经验

## 安装依赖

### 方法一：使用pip安装

如果你已经有Python环境，最简单的方法是使用Python的包安装器pip。

从requirements.txt安装所有依赖：

```bash
pip install -r requirements.txt
```

或者直接安装所有必要的包：

```bash
pip install torch>=2.7.1 tokenizers>=0.21.2 reasoning-from-scratch
```

**说明：**
- **torch**：PyTorch，广泛使用的深度学习库，提供构建和训练神经网络的工具
- **tokenizers**：提供高效分词算法的库，用于准备LLM的输入数据
- **reasoning-from-scratch**：本书作者开发的自定义库，包含书中的所有代码示例和实用工具

### 方法二：使用uv包管理器（推荐）

uv是一个Python包和项目管理器，它自带Python可执行文件，即使你的系统上没有安装Python也能使用。

#### 安装步骤

1. **安装uv**

从官网下载适用于你操作系统的安装包：
https://docs.astral.sh/uv/getting-started/installation/

2. **克隆GitHub仓库**

```bash
git clone --depth 1 https://github.com/rasbt/reasoning-from-scratch.git
```

说明：`--depth 1`选项告诉git执行浅克隆，只下载最新版本的代码，不包含完整版本历史。这样下载更快，占用空间更少。

**如果没有安装git：**
也可以手动下载源代码仓库：
https://github.com/rasbt/reasoning-from-scratch/archive/refs/heads/main.zip

3. **导航到文件夹**

```bash
cd reasoning-from-scratch
```

4. **启动JupyterLab**

```bash
uv run jupyter lab
```

这将启动JupyterLab，你可以：
- 打开一个空白的Jupyter notebook输入和执行代码
- 或打开包含本章所有代码的第2章notebook

**重要说明：**
- `uv run jupyter lab`命令会自动设置本地虚拟环境（通常在`.venv/`文件夹内）
- 自动从`reasoning-from-scratch`文件夹内的`pyproject.toml`文件安装所有依赖
- 不需要通过requirements文件手动安装代码依赖

#### 安装额外包

如果你想安装额外的包：

```bash
uv add package_name
```

## 硬件需求

### 关于GPU

训练LLM非常昂贵。对于领先的LLM公司，训练一个新的基础模型LLM（在添加任何推理技术之前）的计算成本可能在100万到5000万美元之间。

但在本书中，我们将使用一个相对较小但有能力的预训练LLM，在其上实现推理技术。

这个较小的LLM是当代最先进模型的缩小版本，遵循相同的架构。我们应用的推理方法与更大LLM使用的方法相同。区别在于，较小的LLM允许我们以预算友好的方式探索这些方法。

### 检查GPU可用性

使用以下Python代码检查你的计算机是否有PyTorch支持的GPU：

```python
import torch
print(f"PyTorch版本: {torch.__version__}")

if torch.cuda.is_available():
    print("CUDA GPU")
elif torch.mps.is_available():
    print("Apple Silicon GPU")
else:
    print("仅CPU")
```

可能的输出：
```
PyTorch版本: 2.7.1
仅CPU
```

**不用担心：**
- 如果你的机器没有GPU，第2-4章的代码可以在CPU上合理的时间内执行
- 代码会自动使用NVIDIA GPU（如果可用），否则运行在CPU（或Apple Silicon GPU，如果适用于特定章节）
- 我会在相应章节和部分提供更多信息

## PyTorch基础

### 什么是PyTorch？

PyTorch是当前最广泛使用的通用库。我们将用它来运行和训练LLM，包括我们将开发的推理方法。

### 学习PyTorch

如果你是PyTorch新手，为了充分利用本书，推荐阅读我的一小时PyTorch教程：

**《PyTorch in One Hour: From Tensors to Training Neural Networks on Multiple GPUs》**

免费获取：https://sebastianraschka.com/teaching/pytorch-1h

这个教程涵盖了：
- 张量（Tensors）基础知识
- 神经网络构建
- 多GPU训练

掌握这些基础知识会让你在使用LLM代码时更加得心应手。
