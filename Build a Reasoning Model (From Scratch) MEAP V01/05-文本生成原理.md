# 文本生成原理

## LLM文本生成概述

在加载了预训练LLM后，我们的目标是编写一个利用LLM生成文本的函数。

**文本生成过程：**
LLM的文本生成是一个顺序过程，LLM一次生成一个词。这也常被称为**自回归（autoregressive）文本生成**。

## 自回归文本生成

### 基本概念

LLM在每个步骤基于输入和之前生成的token生成下一个token。新token累积地反馈给模型以生成连贯的输出。

```
迭代1: 输入 "Hello" → 生成 "world"
迭代2: 输入 "Hello world" → 生成 "!"
迭代3: 输入 "Hello world!" → 生成 "<|endoftext|>"
```

### 单次迭代详解

如果我们仔细观察其中一次迭代，LLM为每个输入token生成一个输出token。这意味着如果我们有6个输入token，LLM返回6个输出token。

**重要：**
我们只关心每次迭代中最后生成的token。

### 为什么只关心最后一个token？

因为LLM被训练为预测下一个词（next-token prediction）：
- 给定输入tokens [t1, t2, t3, ..., tn]
- 模型输出 [pred(t2), pred(t3), ..., pred(tn+1)]
- 只有`pred(tn+1)`是我们需要的新token

## 实战示例

让我们用一个具体例子说明：提示词 "Explain large language models."

### 步骤1：分词

```python
prompt = "Explain large language models."
input_token_ids_list = tokenizer.encode(prompt)
print(f"输入token数量: {len(input_token_ids_list)}")
```

输出：
```
输入token数量: 6
```

### 步骤2：转换为张量

```python
# 将Python列表转换为PyTorch张量
input_tensor = torch.tensor(input_token_ids_list)

# 添加一个额外维度
input_tensor_fmt = input_tensor.unsqueeze(0)

# 生成输出
output_tensor = model(input_tensor_fmt)

# 移除额外维度
output_tensor_fmt = output_tensor.squeeze(0)

print(f"格式化输出张量形状: {output_tensor_fmt.shape}")
```

输出：
```
格式化输出张量形状: torch.Size([6, 151936])
```

## 理解输出张量

我们将6个输入token输入模型，模型返回一个6×151,936维的矩阵。

- **6**：对应于6个输入token
- **151,936**：对应于模型支持的词汇表大小

每个token由一个包含151,936个值的向量表示。我们可以将这些向量中的值视为词汇表中每个可能单词的分数，最高分数对应于最可能被选为生成token的单词或子词。

### 张量形状解释

```
input_tensor_fmt.shape = [1, 6]  # [batch_size, sequence_length]
output_tensor_fmt.shape = [6, 151936]  # [sequence_length, vocab_size]
```

## 提取下一个token

要获得下一个生成的词，我们需要：
1. 提取6×151,936维矩阵的最后一行
2. 找到该行中分数值最大的token ID
3. 通过分词器将该token ID转换回文本

### 提取最后一个token

```python
# 只关心最后一个token（LLM被训练为预测下一个词）
last_token = output_tensor_fmt[-1].detach()
print(last_token)
```

**说明：**
- `[-1]`：获取最后一个token（下一个词的预测）
- `.detach()`：从跟踪模型如何学习的部分分离张量
  - 简单来说，让我们从模型输出中获取最后一个token，用于下一步而不保留不需要的额外信息
  - 节省内存并可能加速运行

输出：
```
tensor([7.3750, 2.0312, 8.0000, ..., -2.5469, -2.5469, -2.5469], dtype=torch.bfloat16)
```

这是对应于最后一个token的151,936个值。

### 找到最大值的索引

使用`argmax`函数找到该张量中最大分数值（值）的位置：

```python
print(last_token.argmax(dim=-1, keepdim=True))
```

输出：
```
tensor([20286])
```

**解释：**
- 这个返回的整数值是此向量中最大值的位置
- 它也对应于生成token（last_token）的token ID

### 将token ID转换回文本

```python
print(tokenizer.decode([20286]))
```

输出：
```
Large
```

## 重要的PyTorch操作

### Squeeze（压缩）和Unsqueeze（解压）

这些操作用于通过移除或添加大小为1的维度来改变张量的形状。这对于将张量重塑为模型期望的形状很有用。

#### Unsqueeze示例

```python
example = torch.tensor([1, 2, 3])
print(example)
print(example.unsqueeze(0))
```

输出：
```
tensor([1, 2, 3])
tensor([[1, 2, 3]])
```

`unsqueeze(0)`在位置0添加一个新维度，将1D张量变为形状为(1, 3)的2D张量。

#### Squeeze示例

```python
example = torch.tensor([[1, 2, 3]])
print(example)
print(example.squeeze(0))
```

输出：
```
tensor([[1, 2, 3]])
tensor([1, 2, 3])
```

`squeeze(0)`从位置0移除大小为1的维度。

### Max vs Argmax

**torch.max()**：找到张量中的最大值
**torch.argmax()**：找到该值的索引

```python
example = torch.tensor([-2, 1, 3, 1])
print(torch.max(example))
print(torch.argmax(example))
```

输出：
```
tensor(3)     # 最大值是3
tensor(2)     # 它首先出现在索引2
```

#### 使用keepdim保持维度

```python
print(torch.argmax(example, keepdim=True))
```

输出：
```
tensor([2])
```

`keepdim=True`保持结果为与输入相同维数的1D张量，这对于保持分词器所需的形状以及稍后在文本生成函数中连接很有帮助。

## 从单次迭代到完整生成

我们现在已经看到了如何使用LLM生成单个token。下一节，我们将把这些概念付诸实践，实现一个函数，顺序应用这个概念来生成连贯的输出文本。

这个函数会：
1. 将输入提示转换为token ID
2. 模型预测下一个最可能的token
3. 将其追加到序列中
4. 重新处理扩展的序列以生成下一个token
5. 重复直到满足停止条件
6. 将生成的token ID解码回文本

这个过程会产生连贯的文本，就像我们习惯从ChatGPT等LLM看到的那样。
