# 面试题：广告冷启动与物品冷启动的区别

广告系统的广告冷启动与推荐系统的物品冷启动虽然同属冷启动范畴，但由于业务场景、目标导向和实现逻辑的差异，存在以下核心区别：

# 一、核心目标对比

# 1. 广告冷启动

- 目标：快速提升广告转化效率（如点击率 CTR、转化率 CVR）和广告主的 ROI，同时平衡平台流量分配效率。
- 优先级：商业化收益 $>$ 用户兴趣匹配，需在数小时至几天内完成模型验证，否则可能因超成本或消耗停滞被强制下架。
- 示例：新广告投放初期需通过高曝光快速积累转化数据，若 72 小时内转化数不足 10 个，可能被判定为冷启动失败。

# 2. 物品冷启动

- 目标：提升新物品的曝光率和用户兴趣匹配度，避免"马太效应"（头部物品垄断流量）。
- 优先级：用户体验 > 短期转化，允许更长的探索周期（如抖音短视频需通过多轮流量池验证）。
- 示例：电商新品需通过知识图谱关联相似商品用户，短视频需通过内容标签匹配兴趣人群。

# 二、关键维度对比

<table><tr><td>维度</td><td>广告冷启动</td><td>物品冷启动</td></tr><tr><td>数据缺失</td><td>新广告无历史点击/转化数据，广告主 信息有限</td><td>新物品无用户交互数据，内容特征提取难度高</td></tr><tr><td>关键限制</td><td>预算约束、超成本风险、投放时效性</td><td>流量分配固化、同类物品竞争、新颖性需求</td></tr><tr><td>核心特征</td><td>广告属性（如行业、关键词）、出价策 略</td><td>物品内容（文本/图像特征）、标签/分类体系</td></tr><tr><td>核心指标</td><td>转化数、eCPM、ROI</td><td>曝光量、点击率、完播率（视频）、互动率</td></tr><tr><td>反馈时效性</td><td>实时调整（小时级出价/定向优化）</td><td>阶段性评估（如流量池分层验证）</td></tr><tr><td>冷启失败后果</td><td>广告下架、预算浪费</td><td>物品流量受限、生产者积极性下降</td></tr></table>

# 三、解决策略的差异

# 1. 广告冷启动的典型方法

- 流量扶持：初期提高出价（如成本上浮 $20\%-50\%$）、放宽定向范围（如使用"智能放量"）。
- 模型优化：迁移学习（跨行业广告数据复用）、Bias 特征增强（如广告主行业权重提升）。
- 失败处理：超成本阈值强制下架，或复用老广告模型数据（如"一键继承"）。

# 2. 物品冷启动的典型方法

- 内容匹配：基于文本/图像特征提取（如 MetaEmbedding）、知识图谱关联（如关联品牌/类目用户）。
- 流量池机制：分阶段曝光（如抖音"倒三角流量池"），观察互动数据决定是否进入下一阶段。
- 多样性探索：随机曝光、跨领域推荐（如 EMCDR 算法迁移用户兴趣）。

# 四、多臂老虎机（Multi-Armed Bandit）冷启动方案

多臂老虎机是冷启动探索的经典方法，通过在探索（Exploration）与利用（Exploitation）之间取得平衡来优化冷启动策略。

## 4.1 UCB（Upper Confidence Bound）方法

UCB 的核心思想是：对每个广告/物品维护一个置信上界，优先选择上界最高的。

$$\text{UCB}_i = \hat{\mu}_i + \sqrt{\frac{2 \ln t}{n_i}}$$

其中 $\hat{\mu}_i$ 是第 $i$ 个臂的均值奖励，$n_i$ 是被选择的次数，$t$ 是总轮次。

```python
import numpy as np

class UCBBandit:
    def __init__(self, n_arms):
        self.n_arms = n_arms
        self.counts = np.zeros(n_arms)
        self.rewards = np.zeros(n_arms)
        self.total_count = 0

    def select(self):
        if self.total_count < self.n_arms:
            return self.total_count
        ucb_values = self.rewards / (self.counts + 1e-10) + np.sqrt(
            2 * np.log(self.total_count) / (self.counts + 1e-10)
        )
        return np.argmax(ucb_values)

    def update(self, arm, reward):
        self.counts[arm] += 1
        self.rewards[arm] += reward
        self.total_count += 1

np.random.seed(42)
true_ctrs = [0.05, 0.08, 0.12, 0.03, 0.10]
bandit = UCBBandit(len(true_ctrs))
n_rounds = 10000
total_reward = 0
for t in range(n_rounds):
    arm = bandit.select()
    reward = 1.0 if np.random.random() < true_ctrs[arm] else 0.0
    bandit.update(arm, reward)
    total_reward += reward
print(f"UCB 总奖励: {total_reward}")
print(f"各臂选择次数: {bandit.counts}")
print(f"各臂估计CTR: {bandit.rewards / (bandit.counts + 1e-10)}")
```

## 4.2 Thompson Sampling

基于贝叶斯思想，用 Beta 分布建模每个臂的 CTR 后验：

$$\theta_i \sim \text{Beta}(\alpha_i, \beta_i)$$

```python
class ThompsonSamplingBandit:
    def __init__(self, n_arms):
        self.n_arms = n_arms
        self.alpha = np.ones(n_arms)
        self.beta = np.ones(n_arms)

    def select(self):
        samples = [np.random.beta(self.alpha[i], self.beta[i]) for i in range(self.n_arms)]
        return np.argmax(samples)

    def update(self, arm, reward):
        if reward > 0:
            self.alpha[arm] += 1
        else:
            self.beta[arm] += 1

ts_bandit = ThompsonSamplingBandit(len(true_ctrs))
ts_total_reward = 0
for t in range(n_rounds):
    arm = ts_bandit.select()
    reward = 1.0 if np.random.random() < true_ctrs[arm] else 0.0
    ts_bandit.update(arm, reward)
    ts_total_reward += reward
print(f"Thompson Sampling 总奖励: {ts_total_reward}")
print(f"各臂后验均值: {ts_bandit.alpha / (ts_bandit.alpha + ts_bandit.beta)}")
```

## 4.3 LinUCB（带特征的上下文 Bandit）

在冷启动场景中，我们可以利用广告/物品的特征信息来加速学习：

$$\text{LinUCB}_i = x_i^T \hat{\theta}_i + \alpha \sqrt{x_i^T A_i^{-1} x_i}$$

```python
class LinUCBBandit:
    def __init__(self, n_arms, feature_dim, alpha=1.0):
        self.n_arms = n_arms
        self.feature_dim = feature_dim
        self.alpha = alpha
        self.A = [np.eye(feature_dim) for _ in range(n_arms)]
        self.b = [np.zeros(feature_dim) for _ in range(n_arms)]

    def select(self, context_features):
        ucb_values = np.zeros(self.n_arms)
        for arm in range(self.n_arms):
            theta = np.linalg.solve(self.A[arm], self.b[arm])
            x = context_features[arm]
            p = x.dot(theta) + self.alpha * np.sqrt(x.dot(np.linalg.solve(self.A[arm], x)))
            ucb_values[arm] = p
        return np.argmax(ucb_values)

    def update(self, arm, reward, context_features):
        x = context_features[arm]
        self.A[arm] += np.outer(x, x)
        self.b[arm] += reward * x
```

# 五、元学习（Meta-Learning）冷启动方法

元学习通过"学会学习"的方式，让模型在新广告/物品只有少量样本时也能快速适应。

## 5.1 MAML（Model-Agnostic Meta-Learning）思路

MAML 的目标：找到一组好的初始化参数 $\theta$，使得对于新任务只需少量梯度步即可适应。

$$\theta^* = \arg\min_{\theta} \sum_{T_i \sim p(T)} \mathcal{L}_{T_i}(f_{\theta_i'})$$

其中 $\theta_i' = \theta - \alpha \nabla_\theta \mathcal{L}_{T_i}(f_\theta)$

```python
import torch
import torch.nn as nn

class MAMLModel(nn.Module):
    def __init__(self, input_dim, hidden_dim=64, output_dim=1):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, output_dim),
        )

    def forward(self, x):
        return self.net(x)

def maml_train(model, task_loader, n_inner_steps=5, inner_lr=0.01, outer_lr=0.001, n_epochs=100):
    outer_optimizer = torch.optim.Adam(model.parameters(), lr=outer_lr)
    criterion = nn.BCEWithLogitsLoss()
    for epoch in range(n_epochs):
        meta_loss = 0.0
        for task_data, task_labels in task_loader:
            fast_weights = {n: p.clone() for n, p in model.named_parameters()}
            support_data, support_labels = task_data[:len(task_data)//2], task_labels[:len(task_labels)//2]
            query_data, query_labels = task_data[len(task_data)//2:], task_labels[len(task_labels)//2:]
            for step in range(n_inner_steps):
                pred = model(support_data)
                loss = criterion(pred.squeeze(), support_labels.float())
                grads = torch.autograd.grad(loss, model.parameters(), create_graph=True)
                fast_weights = {n: w - inner_lr * g for (n, w), g in zip(fast_weights.items(), grads)}
            temp_model = MAMLModel(model.net[0].in_features)
            temp_model.load_state_dict(fast_weights)
            query_pred = temp_model(query_data)
            query_loss = criterion(query_pred.squeeze(), query_labels.float())
            meta_loss += query_loss
        meta_loss = meta_loss / len(task_loader)
        outer_optimizer.zero_grad()
        meta_loss.backward()
        outer_optimizer.step()
    return model
```

## 5.2 冷启动中的元学习应用

- **广告冷启动**：每个广告主作为一个任务，用 MAML 学习通用初始化，新广告主只需少量数据微调。
- **物品冷启动**：每个物品类别作为一个任务，快速学习新物品的 CTR 预估模型。

## 6.1 评估指标体系

```python
from collections import defaultdict

class ColdStartEvaluator:
    def __init__(self):
        self.new_item_exposures = defaultdict(int)
        self.new_item_clicks = defaultdict(int)
        self.new_item_conversions = defaultdict(int)
        self.total_exposures = 0
        self.total_clicks = 0

    def log_impression(self, item_id, is_new, clicked=False, converted=False):
        self.total_exposures += 1
        if clicked:
            self.total_clicks += 1
        if is_new:
            self.new_item_exposures[item_id] += 1
            if clicked:
                self.new_item_clicks[item_id] += 1
            if converted:
                self.new_item_conversions[item_id] += 1

    def report(self):
        new_items = list(self.new_item_exposures.keys())
        if not new_items:
            print("无新物品数据")
            return
        total_new_exposures = sum(self.new_item_exposures.values())
        total_new_clicks = sum(self.new_item_clicks.values())
        avg_new_ctr = total_new_clicks / max(total_new_exposures, 1)
        overall_ctr = self.total_clicks / max(self.total_exposures, 1)
        ctr_ratio = avg_new_ctr / max(overall_ctr, 1e-10)
        coverage = len([i for i, e in self.new_item_exposures.items() if e >= 10]) / len(new_items)
        print(f"新物品数量: {len(new_items)}")
        print(f"新物品平均CTR: {avg_new_ctr:.4f}")
        print(f"整体CTR: {overall_ctr:.4f}")
        print(f"新/旧 CTR比值: {ctr_ratio:.4f}")
        print(f"新物品曝光覆盖率(>=10次): {coverage:.4f}")
        print(f"新物品转化数: {sum(self.new_item_conversions.values())}")
        return {"new_item_count": len(new_items), "new_ctr": avg_new_ctr,
                "overall_ctr": overall_ctr, "ctr_ratio": ctr_ratio, "coverage": coverage}

evaluator = ColdStartEvaluator()
np.random.seed(42)
for _ in range(10000):
    is_new = np.random.random() < 0.1
    item_id = f"new_{np.random.randint(100)}" if is_new else f"old_{np.random.randint(1000)}"
    clicked = np.random.random() < (0.05 if is_new else 0.10)
    converted = clicked and np.random.random() < 0.3
    evaluator.log_impression(item_id, is_new, clicked, converted)
evaluator.report()
```

## 6.2 A/B 测试框架

```python
import numpy as np
from scipy import stats

def ab_test_cold_start(control_ctrs, treatment_ctrs, alpha=0.05):
    control_mean = np.mean(control_ctrs)
    treatment_mean = np.mean(treatment_ctrs)
    t_stat, p_value = stats.ttest_ind(treatment_ctrs, control_ctrs)
    lift = (treatment_mean - control_mean) / control_mean * 100
    result = {
        "control_ctr": control_mean,
        "treatment_ctr": treatment_mean,
        "lift_pct": lift,
        "p_value": p_value,
        "significant": p_value < alpha,
    }
    print(f"对照组CTR: {control_mean:.4f}")
    print(f"实验组CTR: {treatment_mean:.4f}")
    print(f"提升: {lift:.2f}%")
    print(f"P值: {p_value:.4f}")
    print(f"是否显著: {'是' if result['significant'] else '否'}")
    return result

np.random.seed(42)
control = np.random.binomial(1, 0.05, size=10000)
treatment = np.random.binomial(1, 0.058, size=10000)
ab_test_cold_start(control, treatment)
```

# 七、广告冷启动与物品冷启动的方案选型

| 场景 | 推荐方法 | 适用条件 |
|------|---------|---------|
| 新广告（有广告主历史） | 迁移学习 + 出价上浮 | 广告主有历史广告数据 |
| 新广告（全新广告主） | Bandit + 元学习 | 无任何历史数据 |
| 新物品（有内容特征） | 内容匹配 + 流量池 | 视频有文本/图像信息 |
| 新物品（无内容特征） | 随机探索 + 协同过滤迁移 | 缺乏内容信息 |
| 新用户冷启动 | 跨域推荐 + 热门兜底 | 用户无行为历史 |

# 八、常见问题与易错点

1. **冷启动探索不足**：太早收敛到次优策略，导致新广告/物品得不到充分曝光。建议至少保证每个新物品 50-100 次曝光。
2. **探索成本失控**：广告冷启动中过度探索导致 ROI 不达标。建议设置预算上限和成本控制机制。
3. **特征提取质量差**：物品冷启动严重依赖内容特征质量，低质量特征导致匹配效果差。
4. **忽略冷启动的时间衰减**：冷启动策略应随数据积累逐渐从探索转向利用。

# 第五章：损失函数&评估指标

# 5.1 损失函数
