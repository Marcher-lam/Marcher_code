# 面试题：神经网络有哪些常见的参数初始化方式？

面试题：神经网络有哪些常见的参数初始化方式？

# 1. 神经网络初始化的重要性

参数初始化是神经网络训练的起点，对模型能否有效收敛至关重要。

不当的初始化会导致两大核心问题：对称性破坏和梯度不稳定。

# 打破对称性

如果所有权重初始化为相同的值（如全零初始化），那么同一层内的所有神经元在前向传播过程中会计算出相同的输出，在反向传播时也会获得相同的梯度更新。这将导致所有神经元始终学习相同的特征，使得网络的表现力退化为仅相当于一个神经元，严重制约其学习能力。

# 控制梯度方差

在深层网络中，信号在前向传播和梯度在反向传播过程中会逐层传递。如果权重初始化不当，会导致激活值和梯度的方差在传播过程中指数级地缩小或放大。

- 初始化过小：激活值方差逐层递减，导致梯度消失，参数更新缓慢甚至停滞
- 初始化过大：激活值方差逐层递增，导致梯度爆炸，训练不稳定

优秀的初始化方法旨在确保每一层的输入和输出的方差在传播过程中保持稳定，从而为训练提供一个良好的起点。

**方差稳定的数学条件：** 设第 $l$ 层的权重为 $W^{(l)}$，输入为 $x^{(l)}$，输出为 $y^{(l)} = W^{(l)} x^{(l)}$。为了保持前向传播中方差稳定，需要：

$$
\text{Var}(y^{(l)}) = \text{Var}(x^{(l)})
$$

假设 $W^{(l)}$ 和 $x^{(l)}$ 独立，且 $W^{(l)}$ 的元素均值为 0，方差为 $\text{Var}(W)$，则：

$$
\text{Var}(y^{(l)}) = n_{in} \cdot \text{Var}(W) \cdot \text{Var}(x^{(l)})
$$

要使 $\text{Var}(y^{(l)}) = \text{Var}(x^{(l)})$，需要 $\text{Var}(W) = \frac{1}{n_{in}}$。类似地，反向传播中需要 $\text{Var}(W) = \frac{1}{n_{out}}$。两者取折中得到 $\text{Var}(W) = \frac{2}{n_{in} + n_{out}}$。

# 2. 主要初始化方法

# 2.1 Xavier/Glorot 初始化

Xavier 初始化由 Glorot 和 Bengio 提出，旨在保持 Sigmoid 和 Tanh 这类饱和型激活函数网络中各层激活值的方差一致。

- 核心思想：使权重矩阵在前向传播中维持输入信号的方差，在反向传播中维持梯度的方差。

# 数学推导：

假设权重 W 来自均值为 0 的分布，且与输入 $x$ 独立。前向传播中，我们希望输出 $z = Wx$ 的方差与输入 $x$ 的方差相等: $\text{Var}(z) = \text{Var}(x)$。由于 $z$ 是多个随机变量的和，推导得出 $\text{Var}(z) = n_{in} \cdot \text{Var}(W) \cdot \text{Var}(x)$，其中 $n_{in}$ 是输入神经元数量。

因此，要满足 $\text{Var}(z) = \text{Var}(x)$，就需要 $\text{Var}(W) = \frac{1}{n_{in}}$。同时考虑反向传播，最终取权衡值：

$$
\text{Var}(W) = \frac{2}{n_{in} + n_{out}}
$$

# 具体公式：

- 均匀分布：

$$
W \sim U\left(-\sqrt{\frac{6}{n_{in} + n_{out}}}, \sqrt{\frac{6}{n_{in} + n_{out}}}\right)
$$

- 正态分布：

$$
W \sim \mathcal{N}\left(0, \frac{2}{n_{in} + n_{out}}\right)
$$

**为什么均匀分布的上下界是 $\sqrt{\frac{6}{n_{in} + n_{out}}}$？** 对于均匀分布 $U(-a, a)$，其方差为 $\frac{a^2}{3}$。令 $\frac{a^2}{3} = \frac{2}{n_{in} + n_{out}}$，解得 $a = \sqrt{\frac{6}{n_{in} + n_{out}}}$。

# 2.2 He/Kaiming 初始化

He 初始化（也称 Kaiming 初始化）由何凯明提出，专门为 ReLU 及其变体这类非对称、非线性的激活函数设计。

- 核心思想：ReLU 激活函数会将一半的神经元输出置零，这会使前向传播中信号的方差减半。He 初始化通过调整权重的方差来补偿这一变化。

- 数学推导：考虑到 ReLU 的作用，期望 $E[x^2] = \frac{1}{2}\text{Var}(x)$。代入前向传播方差公式 $\text{Var}(z) = n_{in} \cdot \text{Var}(W) \cdot E[x^2]$，为保持方差稳定 $\text{Var}(z) = \text{Var}(x)$，可推导出 $\text{Var}(W) = \frac{2}{n_{in}}$。

具体公式：

- 正态分布：$W \sim \mathcal{N}\left(0, \sqrt{\frac{2}{n_{in}}}\right)$
- 均匀分布：$W \sim U\left(-\sqrt{\frac{6}{n_{in}}}, \sqrt{\frac{6}{n_{in}}}\right)$

**He 初始化与 Xavier 初始化的区别：** He 初始化的方差是 $\frac{2}{n_{in}}$，而 Xavier 的方差是 $\frac{2}{n_{in} + n_{out}}$。差异来源于 ReLU 会将约一半的神经元置零，因此需要额外乘以 2 来补偿信号衰减。对于 LeakyReLU，补偿因子为 $\frac{2}{1 + \alpha^2}$，其中 $\alpha$ 为负区间的斜率。

# 2.3 LeCun 初始化

LeCun 初始化是 Xavier 初始化的前身，适用于如 SELU 之类的自归一化激活函数。

- 核心思想：主要考虑前向传播中的方差稳定。

$$
W \sim \mathcal{N}\left(0, \frac{1}{n_{in}}\right) \text{或} W \sim U\left(-\sqrt{\frac{3}{n_{in}}}, \sqrt{\frac{3}{n_{in}}}\right)
$$

**SELU 激活函数的特点：** SELU（Scaled Exponential Linear Unit）具有自归一化性质，即通过适当的初始化，网络各层的输出会自动收敛到零均值、单位方差的分布。LeCun 初始化与 SELU 配合可以实现这一特性，无需额外的 Batch Normalization。

# 2.4 其他初始化方法

- 随机初始化：从一个均值为 0、标准差为一个小值（如 0.01）的正态分布或均匀分布中采样。这是早期网络的简单方法，但在深层网络中容易引发梯度问题。
- 全零初始化：强烈不推荐用于权重。它会导致严重的对称性问题，使得网络无法学习。但偏置项通常可以初始化为 0。
- 预训练初始化：在迁移学习场景中，使用在大数据集（如 ImageNet）上预训练好的模型参数作为初始值，通常能加速收敛并提升性能。
- 正交初始化：将权重矩阵初始化为正交矩阵 $W^TW = I$，可以确保前向传播和反向传播中信号的范数保持不变，适合 RNN 等深层网络。

# 3. 初始化方法对比

| 初始化方法 | 核心公式（正态分布） | 设计目标 | 适用激活函数 | 优点与缺点 |
|-----------|-------------------|---------|------------|----------|
| Xavier/Glorot | W ~ N(0, 2/(nin + nout)) | 保持输入/输出方差一致 | Sigmoid, Tanh | 对饱和激活函数有效；不适用于ReLU |
| He/Kaiming | W ~ N(0, 2/nin) | 补偿ReLU的神经元"死亡" | ReLU, LeakyReLU, PReLU | 解决ReLU网络的梯度消失；是当前最常用的方法之一 |
| LeCun | W ~ N(0, 1/nin) | 保持前向传播方差稳定 | SELU, 自归一化网络 | Tanh 的早期方案；在特定架构中表现良好 |
| 正交初始化 | W 为正交矩阵 | 保持信号范数不变 | 任意 | 适合RNN；计算成本较高 |
| 随机初始化 | W ~ N(0, 0.01²) | 简单打破对称性 | 任意（需谨慎调整） | 实现简单；规模敏感，易导致梯度不稳定 |

# 4. Python 代码验证初始化效果

```python
import torch
import torch.nn as nn
import numpy as np

def init_xavier(m):
    if isinstance(m, nn.Linear):
        nn.init.xavier_uniform_(m.weight)
        if m.bias is not None:
            nn.init.zeros_(m.bias)

def init_kaiming(m):
    if isinstance(m, nn.Linear):
        nn.init.kaiming_normal_(m.weight, mode='fan_in', nonlinearity='relu')
        if m.bias is not None:
            nn.init.zeros_(m.bias)

def init_lecun(m):
    if isinstance(m, nn.Linear):
        nn.init.normal_(m.weight, std=1.0 / np.sqrt(m.in_features))
        if m.bias is not None:
            nn.init.zeros_(m.bias)

def check_variance(model, init_fn, name, input_dim=512, num_layers=20):
    model.apply(init_fn)
    model.eval()
    x = torch.randn(1000, input_dim)
    variances = [x.var().item()]
    with torch.no_grad():
        for i, layer in enumerate(model.layers):
            x = layer(x)
            if i % 2 == 0:
                x = torch.relu(x)
            variances.append(x.var().item())
    print(f"\n{name}:")
    for i, v in enumerate(variances):
        print(f"  Layer {i}: variance = {v:.6f}")

def build_deep_network(input_dim=512, hidden_dim=512, num_layers=20):
    layers = []
    for _ in range(num_layers):
        layers.append(nn.Linear(input_dim, hidden_dim))
    model = nn.Module()
    model.layers = nn.ModuleList(layers)
    return model

deep_net = build_deep_network()
check_variance(deep_net, init_xavier, "Xavier Init (with ReLU - may degrade)")
deep_net = build_deep_network()
check_variance(deep_net, init_kaiming, "Kaiming Init (with ReLU - should be stable)")
deep_net = build_deep_network()
check_variance(deep_net, lambda m: None, "Default Init (with ReLU - baseline)")
```

# 5. 常见问题与面试追问

1. **偏置项如何初始化？** 偏置通常初始化为 0。某些特殊情况下，如 LSTM 的遗忘门偏置可以初始化为 1（鼓励初期更多记忆保留）。

2. **Batch Normalization 对初始化的影响？** BN 可以在一定程度缓解不良初始化的影响，因为它会对每一层的激活值进行归一化。但好的初始化仍然重要，因为 BN 在推理时使用训练时的统计量，初始化不当会影响训练早期的统计量质量。

3. **Transformer 中的初始化策略？** Transformer 通常使用 Xavier 或 He 初始化，但 Embedding 层需要特殊处理（通常从 $\mathcal{N}(0, 1/\sqrt{d_{model}})$ 初始化）。某些实现会对残差连接的最后一个线性层进行缩放初始化（如 GPT-2 中将残差投影层的权重除以 $\sqrt{2N}$，$N$ 为残差层数）。
