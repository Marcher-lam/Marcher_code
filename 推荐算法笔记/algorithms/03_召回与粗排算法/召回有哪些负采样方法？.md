# 面试题：召回有哪些负采样方法？

在互联网大厂推荐召回算法中，负样本采样是提升模型区分能力的关键技术。以下结合工业界实践详细介绍负采样的主要方法：

# 一、基础采样方法

# 1. 随机负采样（RNS）

原理：从全体候选池中随机抽取未交互样本作为负例。  
 特点：简单高效，符合线上候选池分布，但对热门物料敏感，可能无法区分细粒度差异。  
改进：热门打压（如Youtube策略）调整采样概率：

$P _ { n e g } ( i ) \propto$ 流行度 $( i ) ^ { 0 . 7 5 }$ ，通过降低热门物品的负采样概率，缓解头部效应。

# 2. 基于流行度的负采样

原理：根据物品曝光/点击频率调整采样权重，热门物品更易被选为负例。  
特点：抑制头部物料过曝，但可能过度打压长尾。

$$
P _ {n e g} (i) = \frac {\text {流 行 度} (i) ^ {\alpha}}{\sum_ {i} \text {流 行 度} (i) ^ {\alpha}}
$$

 数学公式： $\scriptstyle { \sum _ { j } }$ ，其中 $\alpha \in ( 0 , 1 )$ 用于平滑分布（常用 $\mathtt { 0 = 0 . 7 5 }$

# 二、进阶采样方法

# 3. 硬负采样（Hard Negative Sampling）

原理：选择与用户兴趣相近但未交互的样本，提升模型细粒度区分能力。  
典型方法：

 业务规则：如 Airbnb 选取同城未点击房源作为硬负样本。

 模型筛选：Facebook EBR 使用上一版模型召回结果中排名 101-500 的样本。

 选择相似度接近正样本但低于点击阈值的样本作为负例。

# 4. 混合采样策略

 原理：结合随机负样本（Easy Negative）与硬负样本（Hard Negative），平衡分布与难度。  
公式示例 （混合损失函数）：

$$
\mathcal {L} = \lambda \mathcal {L} _ {\mathrm {e a s y}} + (1 - \lambda) \mathcal {L} _ {\mathrm {h a r d}}, \text {其 中} \lambda \text {控 制 权 重 。}
$$

# 5. 动态自适应采样

原理：根据模型反馈动态调整采样分布。  
典型方法：

 DNS（动态负采样）：选择当前模型预测分数高的未交互样本作为负例。

 ESANS（阿里）：基于多模态嵌入和 RQ 分层聚类，通过线性插值生成困难样本。

插值公式： ${ \bf e } _ { \mathrm { i n t e r p } } = \beta { \bf e } _ { \mathrm { p o s } } + ( 1 - \beta ) { \bf e } _ { \mathrm { h a r d } }$ ，其中 β⋅[0,1] 控制插值强度。

# 三、采样相关优化

# 1. 采样偏差修正

问题：训练数据与线上分布不一致（SSB 问题）。  
解法：阿里 ESAM 通过迁移学习正则化损失函数：

$\mathcal { L } _ { \mathrm { E S A M } } = \mathcal { L } _ { \mathrm { b a s e } } + \gamma \Vert \theta _ { \mathrm { s o u r c e } } - \theta _ { \mathrm { t a r g e t } } \Vert ^ { 2 }$ ，其中 θ 为模型参数，γ 为权重。

# 2. 对比学习损失

应用场景：双塔模型中的 In-batch 采样。

$$
\mathcal {L} = - \log \frac {e ^ {\mathbf {q} ^ {T} \mathbf {k} ^ {+}}}{e ^ {\mathbf {q} ^ {T} \mathbf {k} ^ {+}} + \sum_ {i = 1} ^ {N} e ^ {\mathbf {q} ^ {T} \mathbf {k} _ {i} ^ {-}}}
$$

 公式：

其中 q 为用户向量， $\mathbf { k } +$ 为正样本， $\mathbf { k } _ { i } ^ { - }$ 为 Batch 内其他样本作为负例。

# 五、In-batch 负采样详解

## 1. 核心思想

In-batch 负采样是工业界最广泛使用的负采样策略。在一个 batch 中，每个样本的正样本对为 $(q_i, k_i^+)$，而 batch 内其他样本的 item $k_j$（$j \neq i$）自动作为 $q_i$ 的负样本。

对于一个 batch 大小为 $B$ 的训练，每个样本有 $B-1$ 个负样本，计算效率极高（无需额外采样）。

## 2. In-batch 负采样的数学表达

$$
\mathcal{L}_i = -\log \frac{\exp(\text{sim}(q_i, k_i^+) / \tau)}{\exp(\text{sim}(q_i, k_i^+) / \tau) + \sum_{j \neq i} \exp(\text{sim}(q_i, k_j) / \tau)}
$$

其中 $\tau$ 为温度系数，$\text{sim}$ 为相似度函数（通常为余弦相似度）。

## 3. 与传统负采样的效率对比

| 维度 | 传统负采样 | In-batch 负采样 |
|------|-----------|----------------|
| 负样本数量 | 固定（如 100-1000） | 等于 batch size - 1 |
| 额外计算开销 | 需要额外前向传播 | 无（复用 batch 内计算） |
| GPU 利用率 | 低 | 高 |
| 负样本多样性 | 取决于采样策略 | 取决于 batch 组成 |
| 代表实践 | Word2Vec、Airbnb | Google YouTube、Facebook EBR |

## 4. In-batch 的交叉熵计算优化

利用矩阵乘法可以高效计算 batch 内所有配对的相似度：

```python
sim_matrix = user_emb @ item_emb.T / temperature
labels = torch.arange(B).to(device)
loss = F.cross_entropy(sim_matrix, labels)
```

这种实现将 $O(B^2)$ 的配对计算转化为一次矩阵乘法，GPU 友好。

# 六、采样偏差与修正方法

## 1. 选择偏差（Selection Bias）

用户只能与曝光的物品交互，未曝光的物品既不是正样本也不是可靠的负样本。如果将未曝光物品简单作为负样本，会引入偏差。

**修正方法**：
- 逆倾向得分加权（IPW）：为每个样本赋予权重 $w_i = 1 / P(\text{exposure} | x_i)$
- 仅使用曝光未点击的样本作为负样本（但可能遗漏真正的负样本）

## 2. 样本选择偏差（SSB，Sample Selection Bias）

训练时使用的负样本分布与线上实际候选分布不一致。例如，训练时用随机负样本，线上需要从全量候选中召回。

**修正方法**：
- ESAM（阿里）：通过迁移学习将 source domain（有标签数据）的知识迁移到 target domain（全量候选）
- 混合采样：同时使用随机负样本和曝光未点击样本

## 3. 位置偏差（Position Bias）

用户更倾向于点击排名靠前的物品，即使后面的物品更相关。这会导致高排名物品被误判为正样本。

**修正方法**：
- 逆倾向得分：$w_i = 1 / P(\text{click} | \text{position}, x_i)$
- 位置作为特征：将位置信息作为输入特征，推理时设为固定值

# 七、Python 代码实现

```python
import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F

class RandomNegSampler:
    def __init__(self, item_count, alpha=0.75):
        prob = np.power(item_count, alpha)
        self.prob = prob / prob.sum()

    def sample(self, n_neg):
        return np.random.choice(len(self.prob), size=n_neg, p=self.prob, replace=False)

class HardNegSampler:
    def __init__(self, item_embeddings, top_k=50, exclude_pos=True):
        self.embeddings = item_embeddings
        self.top_k = top_k
        self.exclude_pos = exclude_pos

    def sample(self, query_emb, pos_item_id, n_neg):
        sim = torch.matmul(
            torch.tensor(query_emb).float(),
            self.embeddings.T
        )
        sim[pos_item_id] = -float('inf')
        top_k_idx = torch.topk(sim, self.top_k).indices
        selected = top_k_idx[torch.randperm(min(self.top_k, n_neg))[:n_neg]]
        return selected.numpy()

class MixedNegSampler:
    def __init__(self, random_sampler, hard_sampler, easy_ratio=0.7):
        self.random_sampler = random_sampler
        self.hard_sampler = hard_sampler
        self.easy_ratio = easy_ratio

    def sample(self, query_emb, pos_item_id, n_neg):
        n_easy = int(n_neg * self.easy_ratio)
        n_hard = n_neg - n_easy
        easy_neg = self.random_sampler.sample(n_easy)
        hard_neg = self.hard_sampler.sample(query_emb, pos_item_id, n_hard)
        return np.concatenate([easy_neg, hard_neg])

class InBatchNegLoss(nn.Module):
    def __init__(self, temperature=0.07):
        super().__init__()
        self.temperature = temperature

    def forward(self, user_emb, item_emb):
        user_emb = F.normalize(user_emb, p=2, dim=-1)
        item_emb = F.normalize(item_emb, p=2, dim=-1)
        sim = torch.matmul(user_emb, item_emb.T) / self.temperature
        labels = torch.arange(sim.size(0), device=sim.device)
        loss = F.cross_entropy(sim, labels)
        return loss

class HardNegLoss(nn.Module):
    def __init__(self, temperature=0.07):
        super().__init__()
        self.temperature = temperature

    def forward(self, user_emb, pos_item_emb, hard_neg_item_emb):
        user_emb = F.normalize(user_emb, p=2, dim=-1)
        pos_emb = F.normalize(pos_item_emb, p=2, dim=-1)
        neg_emb = F.normalize(hard_neg_item_emb, p=2, dim=-1)

        pos_sim = torch.sum(user_emb * pos_emb, dim=-1, keepdim=True) / self.temperature
        neg_sim = torch.matmul(user_emb, neg_emb.T) / self.temperature
        logits = torch.cat([pos_sim, neg_sim], dim=-1)
        labels = torch.zeros(logits.size(0), dtype=torch.long, device=logits.device)
        return F.cross_entropy(logits, labels)

item_count = np.random.poisson(100, size=1000).astype(float) + 1
random_sampler = RandomNegSampler(item_count, alpha=0.75)
neg_samples = random_sampler.sample(10)
print(f"随机负采样结果: {neg_samples}")

item_emb = torch.randn(1000, 64)
hard_sampler = HardNegSampler(item_emb, top_k=50)
query = np.random.randn(64)
hard_neg = hard_sampler.sample(query, 0, 5)
print(f"硬负采样结果: {hard_neg}")

inbatch_loss = InBatchNegLoss(temperature=0.07)
user_emb = torch.randn(32, 64)
item_emb_batch = torch.randn(32, 64)
loss = inbatch_loss(user_emb, item_emb_batch)
print(f"In-batch 负采样损失: {loss.item():.4f}")

hard_loss_fn = HardNegLoss(temperature=0.07)
pos_items = torch.randn(32, 64)
hard_neg_items = torch.randn(32 * 10, 64)
hard_loss = hard_loss_fn(user_emb, pos_items, hard_neg_items)
print(f"硬负采样损失: {hard_loss.item():.4f}")
```

# 八、工业实践中的负采样策略演进

## 1. 典型演进路线

| 阶段 | 策略 | 适用条件 |
|------|------|---------|
| 冷启动 | 随机负采样 + 流行度打压 | 数据量小，快速上线 |
| 增长期 | In-batch 负采样 + 温度系数 | GPU 资源充足，需要高效训练 |
| 成熟期 | 混合采样（随机 + 硬负 + In-batch） | 有历史模型可用于筛选硬负样本 |
| 精细化 | 动态自适应采样 + 偏差修正 | 数据量大，需要消除各种偏差 |

## 2. 各大厂策略对比

| 公司 | 召回模型 | 负采样策略 | 关键创新 |
|------|---------|-----------|---------|
| YouTube | 双塔 | 随机负采样 + 流行度打压 | batch softmax + 温度系数 |
| Facebook | EBR 双塔 | 模型筛选硬负样本 | ANN 检索排名 101-500 |
| Airbnb | 短期+长期双塔 | 业务规则硬负样本 | 同城未预订房源 |
| 阿里 | MIND/DSSM | 动态自适应采样 | ESANS 多模态插值 |
| 字节 | 多路召回 | 混合采样 | In-batch + 硬负 + 随机 |

# 九、常见问题与注意事项

1. **负样本比例**：每个正样本搭配多少负样本是关键超参数。召回阶段通常 1:100 ~ 1:1000，精排阶段通常 1:10 ~ 1:50。比例过小模型区分力不够，比例过大会导致训练不稳定

2. **硬负样本的"硬度"控制**：硬负样本太"硬"（与正样本非常接近）会导致模型过拟合到这些困难样本，泛化性差。建议使用排名 101-500 的"中等硬度"负样本，而非排名 1-100 的极硬负样本

3. **温度系数与负样本数量的关系**：负样本越多，温度系数通常需要调小。经验公式：$\tau \approx 1 / \log(N_{neg})$

4. **曝光未点击 vs 随机负样本**：曝光未点击样本偏向于热门物品，且可能包含"用户不感兴趣但确实看到了"的真正负样本。随机负样本分布更广，但"太简单"。两者通常混合使用

5. **负采样与损失函数的配合**：不同的负采样策略需要配合不同的损失函数。In-batch 负采样通常配合 InfoNCE/Softmax 损失；硬负采样通常配合 Pairwise/Hinge 损失或 BCE 损失
