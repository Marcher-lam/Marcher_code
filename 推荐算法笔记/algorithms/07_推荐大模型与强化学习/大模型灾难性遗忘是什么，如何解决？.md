# 面试题：大模型灾难性遗忘是什么，如何解决？

面试题：大模型灾难性遗忘是什么，如何解决？

# 一、大模型灾难性遗忘的定义

灾难性遗忘（Catastrophic Forgetting）：是指大语言模型（LLM）在学习新任务或适应新数据分布时，因参数更新导致对旧任务的知识快速丢失的现象。

例如，模型在微调医疗问答任务后，可能无法再正确生成代码或回答常识问题。这一问题的核心在于模型的全局参数共享机制：新任务的梯度更新会覆盖旧任务的关键权重，破坏原有知识结构。

## 1.1 直观理解

可以把大模型想象成一个学生：
- 他先学会了数学（预训练阶段）
- 然后集中学了一个月的医学（微调阶段）
- 结果医学学好了，但数学知识大幅退化

这就是灾难性遗忘的本质——新知识的学习挤占了旧知识的存储空间。

## 1.2 形式化定义

假设模型参数为 $\theta$，在任务 A 上训练后得到参数 $\theta_A$。随后在任务 B 上继续训练得到 $\theta_{A+B}$。灾难性遗忘表现为：

$$\text{Forgetting} = \mathcal{L}_A(\theta_{A+B}) - \mathcal{L}_A(\theta_A) \gg 0$$

即模型在任务 A 上的损失显著增大。

# 二、主要成因

- 参数更新机制：梯度下降会因新任务的优化需求而大幅调整参数，导致旧任务依赖的权重被覆盖。
- 数据分布差异：持续学习场景中，新旧任务的数据分布差异显著，模型难以维持对旧任务的适应性。
- 模型容量限制：固定架构的模型在学习新任务时可能因容量不足而牺牲旧知识的存储空间。
- 任务相似性与顺序：任务间相似性低或训练顺序不合理会加剧遗忘程度。

## 2.1 梯度冲突视角

当两个任务的梯度方向存在冲突时（夹角大于 90°），优化一个任务必然会损害另一个任务。衡量梯度冲突的指标为：

$$\cos(\theta) = \frac{g_A \cdot g_B}{\|g_A\| \cdot \|g_B\|}$$

当 $\cos(\theta) < 0$ 时，说明两个任务的梯度方向相反，遗忘风险高。

# 三、解决灾难性遗忘的主要方法

## 3.1 正则化技术

### 3.1.1 弹性权重巩固（Elastic Weight Consolidation, EWC）

EWC 通过计算旧任务参数的重要性（费舍尔信息矩阵），对关键参数施加正则化约束，限制其大幅调整。

**数学推导：**

贝叶斯视角下，持续学习的目标是最大化后验概率：

$$\log p(\theta | \mathcal{D}_A, \mathcal{D}_B) = \log p(\mathcal{D}_B | \theta) + \log p(\theta | \mathcal{D}_A) + \text{const}$$

其中 $p(\theta | \mathcal{D}_A)$ 可用高斯分布近似：

$$\log p(\theta | \mathcal{D}_A) \approx -\frac{1}{2} \sum_i F_i (\theta_i - \theta_{A,i}^*)^2 + \text{const}$$

其中 $F_i$ 是费舍尔信息矩阵的对角元素，衡量参数 $\theta_i$ 对任务 A 的重要性。

最终 EWC 的损失函数为：

$$\mathcal{L}_{EWC}(\theta) = \mathcal{L}_B(\theta) + \frac{\lambda}{2} \sum_i F_i (\theta_i - \theta_{A,i}^*)^2$$

**费舍尔信息矩阵的计算：**

$$F_i = \mathbb{E}_{x \sim \mathcal{D}_A} \left[ \left( \frac{\partial \log p(y|x,\theta)}{\partial \theta_i} \right)^2 \right]_{\theta = \theta_A^*}$$

```python
import torch
import torch.nn as nn
import copy

class EWC:
    def __init__(self, model, dataloader, criterion):
        self.model = model
        self.criterion = criterion
        self.params = {n: p.clone().detach() for n, p in model.named_parameters() if p.requires_grad}
        self.fisher_matrix = self._compute_fisher(dataloader)

    def _compute_fisher(self, dataloader):
        fisher = {n: torch.zeros_like(p) for n, p in self.model.named_parameters() if p.requires_grad}
        self.model.eval()
        for data, target in dataloader:
            self.model.zero_grad()
            output = self.model(data)
            loss = self.criterion(output, target)
            loss.backward()
            for n, p in self.model.named_parameters():
                if p.requires_grad:
                    fisher[n] += p.grad.data.pow(2) / len(dataloader)
        return fisher

    def penalty(self, model):
        loss = 0
        for n, p in model.named_parameters():
            if p.requires_grad:
                loss += (self.fisher_matrix[n] * (p - self.params[n]).pow(2)).sum()
        return loss

def train_with_ewc(model, dataloader_B, ewc, lambda_ewc=1000, epochs=5, lr=1e-3):
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    criterion = nn.CrossEntropyLoss()
    for epoch in range(epochs):
        for data, target in dataloader_B:
            optimizer.zero_grad()
            output = model(data)
            loss = criterion(output, target) + lambda_ewc * ewc.penalty(model)
            loss.backward()
            optimizer.step()
    return model
```

### 3.1.2 学习不遗忘（Learning without Forgetting, LwF）

在新任务训练时，用旧任务输出作为伪标签，通过知识蒸馏保留原有知识。

$$\mathcal{L}_{LwF} = \mathcal{L}_{new}(y_{new}, \hat{y}_{new}) + \lambda \cdot \mathcal{L}_{KD}(\hat{y}_{old}^{(t)}, \hat{y}_{old})$$

其中 $\hat{y}_{old}^{(t)}$ 是当前模型对旧任务的输出，$\hat{y}_{old}$ 是旧模型的输出（伪标签）。

## 3.2 记忆回放

### 3.2.1 经验回放（Rehearsal）

保存部分旧任务数据，与新任务数据混合训练，强制模型复习旧知识。例如，增量预训练时加入通用领域数据以防止泛化能力下降。

```python
import random

class ReplayBuffer:
    def __init__(self, max_size=1000):
        self.buffer = []
        self.max_size = max_size

    def add(self, data):
        if len(self.buffer) >= self.max_size:
            self.buffer.pop(0)
        self.buffer.append(data)

    def sample(self, batch_size):
        return random.sample(self.buffer, min(batch_size, len(self.buffer)))

def train_with_replay(model, new_dataloader, replay_buffer, alpha=0.5, epochs=5, lr=1e-3):
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    criterion = nn.CrossEntropyLoss()
    for epoch in range(epochs):
        for new_data, new_target in new_dataloader:
            optimizer.zero_grad()
            new_loss = criterion(model(new_data), new_target)
            if len(replay_buffer.buffer) > 0:
                replay_batch = replay_buffer.sample(32)
                old_data = torch.stack([d[0] for d in replay_batch])
                old_target = torch.tensor([d[1] for d in replay_batch])
                old_loss = criterion(model(old_data), old_target)
                loss = alpha * new_loss + (1 - alpha) * old_loss
            else:
                loss = new_loss
            loss.backward()
            optimizer.step()
            for d, t in zip(new_data, new_target):
                replay_buffer.add((d.detach(), t.item()))
    return model
```

### 3.2.2 生成式回放（Generative Replay）

使用生成模型（如 VAE 或 GAN）生成旧任务数据，无需存储真实数据：

$$\mathcal{L} = \mathcal{L}_{new}(x_{new}) + \lambda \cdot \mathcal{L}_{old}(G(z))$$

## 3.3 参数隔离

### 3.3.1 低秩适配（LoRA）

仅微调模型新增的低秩矩阵，冻结主干参数，最大限度保留预训练知识。

$$W' = W + \Delta W = W + BA$$

其中 $B \in \mathbb{R}^{d \times r}$，$A \in \mathbb{R}^{r \times k}$，$r \ll \min(d, k)$。

```python
import torch
import torch.nn as nn
import math

class LoRALayer(nn.Module):
    def __init__(self, original_layer, rank=8, alpha=16):
        super().__init__()
        self.original_layer = original_layer
        self.rank = rank
        self.alpha = alpha
        d_in = original_layer.in_features
        d_out = original_layer.out_features
        self.lora_A = nn.Parameter(torch.zeros(d_in, rank))
        self.lora_B = nn.Parameter(torch.zeros(rank, d_out))
        nn.init.kaiming_uniform_(self.lora_A, a=math.sqrt(5))
        nn.init.zeros_(self.lora_B)
        self.scaling = alpha / rank
        for p in self.original_layer.parameters():
            p.requires_grad = False

    def forward(self, x):
        base_out = self.original_layer(x)
        lora_out = (x @ self.lora_A @ self.lora_B) * self.scaling
        return base_out + lora_out

def apply_lora_to_model(model, rank=8, alpha=16, target_modules=None):
    if target_modules is None:
        target_modules = ["q_proj", "v_proj"]
    for name, module in model.named_modules():
        if any(t in name for t in target_modules):
            if isinstance(module, nn.Linear):
                parent_name = ".".join(name.split(".")[:-1])
                child_name = name.split(".")[-1]
                parent = dict(model.named_modules())[parent_name] if parent_name else model
                setattr(parent, child_name, LoRALayer(module, rank=rank, alpha=alpha))
    return model
```

### 3.3.2 适配层（Adapter Layers）

在 Transformer 模块中插入小型可训练网络，限制参数更新范围。

```python
class AdapterLayer(nn.Module):
    def __init__(self, hidden_size, bottleneck_size=64):
        super().__init__()
        self.down_proj = nn.Linear(hidden_size, bottleneck_size)
        self.up_proj = nn.Linear(bottleneck_size, hidden_size)
        self.activation = nn.GELU()
        nn.init.zeros_(self.up_proj.weight)
        nn.init.zeros_(self.up_proj.bias)

    def forward(self, x):
        residual = x
        x = self.activation(self.down_proj(x))
        x = self.up_proj(x)
        return residual + x
```

### 3.3.3 LoRAMoE

通过混合专家（MoE）机制隔离新旧任务参数。每个专家负责一组特定任务，门控网络决定路由：

$$\text{output} = \sum_{i=1}^{N} g_i(x) \cdot E_i(x)$$

## 3.4 多任务训练

- 多任务联合优化：同时训练新旧任务，平衡参数更新方向，但需权衡计算效率和任务数量。
- 专家门模块（Expert Gating）：为不同任务分配独立子网络，通过路由机制动态选择激活路径。

# 四、评估指标

## 4.1 遗忘度衡量

$$\text{Average Forgetting} = \frac{1}{T-1} \sum_{t=1}^{T-1} [a_{t,t} - a_{T,t}]$$

其中 $a_{i,j}$ 表示在学完任务 $i$ 后在任务 $j$ 上的准确率。

## 4.2 前向迁移与后向迁移

- 前向迁移（FWT）：学习旧任务对新任务的帮助
- 后向迁移（BWT）：学习新任务后旧任务性能变化

$$\text{BWT} = \frac{1}{T-1} \sum_{t=1}^{T-1} [a_{T,t} - a_{t,t}]$$

## 4.3 综合评估代码

```python
def evaluate_continual_learning(accuracy_matrix):
    T = accuracy_matrix.shape[0]
    forgetting = 0
    for t in range(T - 1):
        best_past = accuracy_matrix[t, t]
        current = accuracy_matrix[T - 1, t]
        forgetting += best_past - current
    avg_forgetting = forgetting / (T - 1) if T > 1 else 0
    bwt = sum(accuracy_matrix[T-1, t] - accuracy_matrix[t, t] for t in range(T-1)) / (T - 1) if T > 1 else 0
    fwt = sum(accuracy_matrix[t+1, t] - accuracy_matrix[t, t] for t in range(T-1)) / (T - 1) if T > 1 else 0
    avg_accuracy = accuracy_matrix[-1, :T].mean()
    return {"avg_accuracy": avg_accuracy, "avg_forgetting": avg_forgetting, "BWT": bwt, "FWT": fwt}
```

# 五、方法对比与选型建议

| 方法 | 原理 | 优点 | 缺点 | 适用场景 |
|------|------|------|------|----------|
| EWC | 正则化约束重要参数 | 无需存储旧数据 | 费舍尔矩阵计算开销大 | 任务数较少 |
| LwF | 知识蒸馏保留旧知识 | 无需旧数据 | 旧任务输出可能不准确 | 任务相似度高 |
| Rehearsal | 混合旧数据训练 | 简单有效 | 需要存储旧数据 | 存储资源充足 |
| LoRA | 冻结主干+低秩适配 | 参数高效 | 复杂交互受限 | 大模型微调 |
| Adapter | 插入小网络 | 模块化 | 增加推理延迟 | 多任务场景 |

# 六、实践中的完整缓解方案

```python
import torch
import torch.nn as nn
from copy import deepcopy

class ContinualLearningTrainer:
    def __init__(self, model, method="ewc", lambda_reg=1000, replay_size=500):
        self.model = model
        self.method = method
        self.lambda_reg = lambda_reg
        self.replay_buffer = []
        self.replay_size = replay_size
        self.ewc_params = None
        self.fisher_matrix = None
        self.old_model = None

    def after_task(self, dataloader, task_id):
        if self.method == "ewc":
            self._compute_fisher(dataloader)
            self.ewc_params = {n: p.clone().detach() for n, p in self.model.named_parameters() if p.requires_grad}
        elif self.method == "replay":
            for data, target in dataloader:
                for d, t in zip(data, target):
                    if len(self.replay_buffer) < self.replay_size:
                        self.replay_buffer.append((d, t))
        elif self.method == "lwf":
            self.old_model = deepcopy(self.model)
            self.old_model.eval()

    def _compute_fisher(self, dataloader):
        self.fisher_matrix = {n: torch.zeros_like(p) for n, p in self.model.named_parameters() if p.requires_grad}
        self.model.eval()
        for data, target in dataloader:
            self.model.zero_grad()
            output = self.model(data)
            loss = nn.functional.cross_entropy(output, target)
            loss.backward()
            for n, p in self.model.named_parameters():
                if p.requires_grad and p.grad is not None:
                    self.fisher_matrix[n] += p.grad.data.pow(2) / len(dataloader)

    def compute_loss(self, output, target, data=None):
        loss = nn.functional.cross_entropy(output, target)
        if self.method == "ewc" and self.ewc_params is not None:
            reg = sum((self.fisher_matrix[n] * (p - self.ewc_params[n]).pow(2)).sum()
                      for n, p in self.model.named_parameters() if p.requires_grad)
            loss = loss + (self.lambda_reg / 2) * reg
        elif self.method == "lwf" and self.old_model is not None:
            with torch.no_grad():
                old_output = self.old_model(data)
            kd_loss = nn.functional.kl_div(
                nn.functional.log_softmax(output, dim=-1),
                nn.functional.softmax(old_output / 2.0, dim=-1),
                reduction='batchmean'
            )
            loss = loss + self.lambda_reg * kd_loss
        return loss
```

# 七、常见问题与易错点

1. **EWC 中 $\lambda$ 设置过大**：导致模型无法学习新任务，欠拟合新数据。建议从 1000 开始网格搜索。
2. **Rehearsal 比例不当**：旧数据比例过高会抑制新任务学习，建议新旧比 1:4 到 1:1。
3. **LoRA rank 选择**：rank 过低无法表达新知识，过高接近全量微调。推荐 8-64。
4. **忽略任务顺序**：先学简单任务再学复杂任务通常效果更好。
