# 互联网大厂推荐算法知识库

## 项目介绍

本知识库系统化整理了推荐算法领域的核心知识点，覆盖推荐系统全链路：从特征工程、召回排序到深度模型、大模型与强化学习。内容源自一线大厂面试真题，融合算法原理、数学推导、业务场景与创新点，形成 **算法 + 业务 + 创新** 一体化的知识体系。

## 目录结构

```
algorithms/
├── 01_推荐系统概述/          # 推荐系统链路、与广告系统区别、生成式推荐
├── 02_特征与Embedding/       # 语义ID编码、特征融合、重要度评估、分桶策略
├── 03_召回与粗排算法/        # 负采样方法、ESANS、CROLoss、双塔LayerNorm
├── 04_精排模型算法/          # 特征交叉、注意力、序列建模、多任务、因果推断、CVR/LTV、冷启动
├── 05_损失函数与评估指标/    # KL散度、交叉熵、对比学习Loss、AUC、NDCG
├── 06_推荐基础八股算法/      # XGBoost/LightGBM、Transformer、优化器、正则化
└── 07_推荐大模型与强化学习/  # 生成式推荐、大模型架构、RLHF/PPO/DQN
```

## 使用方式

1. **按章节学习**：从 01 开始依次阅读，建立系统知识框架
2. **按主题查阅**：根据面试/工作需要，直接定位相关文件
3. **查漏补缺**：结合 roadmap.md 评估学习进度，针对性补强

## 统计

- 总计 **102** 个独立知识点文档

- 数学公式推导

- 创新点与优势分析
