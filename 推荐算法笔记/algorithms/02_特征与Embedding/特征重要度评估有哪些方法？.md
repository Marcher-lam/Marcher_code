# 面试题：特征重要度评估有哪些方法？

在机器学习和深度学习中，特征重要度评估是特征工程、模型优化的核心环节。以下详细介绍几类主流的特征重要度计算方法：

# 一、基于统计的方法（较为传统，现在用的很少）

# 1. 相关系数法

 原理：通过计算特征与目标变量之间的线性相关性（如皮尔逊相关系数），衡量特征重要性。皮尔逊系数的计算公式为：

$$
r = \frac {\sum \left(x _ {i} - \bar {x}\right) \left(y _ {i} - \bar {y}\right)}{\sqrt {\sum \left(x _ {i} - \bar {x}\right) ^ {2} \cdot \sum \left(y _ {i} - \bar {y}\right) ^ {2}}} \text {, 取 值 范 围 为} [ - 1, 1 ], \text {绝 对 值 越 大 表 示 相 关 性 越 强 。}
$$

 适用场景：连续型特征与目标变量的线性关系分析，例如金融风控中的收入与违约率关联。  
 优缺点：计算高效，但仅能捕捉线性关系，无法处理非线性或高阶交互效应。

**斯皮尔曼秩相关系数**：当数据不满足正态分布假设时，可采用斯皮尔曼秩相关系数，基于变量的秩次计算相关性，公式为：

$$
\rho_s = 1 - \frac{6 \sum d_i^2}{n(n^2 - 1)}
$$

其中 $d_i$ 为两个变量的秩次差。斯皮尔曼相关系数可以捕捉单调非线性关系，适用范围更广。

**互相关分析扩展**：在时间序列场景中，可采用互相关函数（Cross-Correlation）分析特征与目标的滞后相关性，识别具有预测能力的先行指标。

# 2. 卡方检验与互信息

 原理：

卡方检验：评估特征与目标变量的独立性，卡方值越大，独立性越低，特征越重要。

互信息：基于信息论，衡量特征与目标变量的信息共享程度，适用于非线性关系。

$$
I (X; Y) = \sum_ {x \in X} \sum_ {y \in Y} p (x, y) \log \frac {p (x , y)}{p (x) p (y)}
$$

 适用场景：分类任务中离散特征的重要性评估，如文本分类的词频筛选。  
 优缺点：无需依赖模型，但对高维数据敏感，互信息计算复杂度较高。

**卡方检验的数学推导**：卡方统计量衡量观察频数与期望频数的偏差程度：

$$
\chi^2 = \sum_{i=1}^{r} \sum_{j=1}^{c} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}
$$

其中 $O_{ij}$ 为观察频数，$E_{ij} = \frac{n_i \cdot n_j}{N}$ 为期望频数。卡方值越大，说明特征与目标变量的关联越强。

**互信息的直觉理解**：互信息度量的是"知道X的值后，对Y的不确定性减少了多少"。当X和Y完全独立时，$I(X;Y) = 0$；当X完全确定Y时，$I(X;Y) = H(Y)$。

**条件互信息**：在多特征场景中，可用条件互信息评估在给定其他特征后，某特征的增量重要性：

$$
I(X_i; Y | X_j) = \sum p(x_i, x_j, y) \log \frac{p(x_i | x_j, y)}{p(x_i | x_j)}
$$

# 二、基于树模型的方法（树模型自带）

# 1. 随机森林

 原理：通过多棵决策树的平均特征重要性（如基尼指数减少量或平均精度下降）评估特征贡献。

$$
\text {I m p o r t a n c e} _ {i} = \frac {1}{N _ {\text {t r e e s}}} \sum_ {T} \sum_ {t \in T} \left(\Delta \operatorname {G i n i} _ {t} \cdot I (\text {s p l i t n o d e} = i)\right)
$$

 适用场景：复杂非线性关系下的特征选择，如医疗诊断中的多指标联合分析。  
 优缺点：抗过拟合能力强，但计算成本高，特征交互解释性弱。

**基尼不纯度的计算**：

$$
\text{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^2
$$

特征 $i$ 在节点 $t$ 分裂后的基尼减少量为：

$$
\Delta \text{Gini}_t = \text{Gini}(t) - \frac{N_L}{N_t} \text{Gini}(t_L) - \frac{N_R}{N_t} \text{Gini}(t_R)
$$

**排列重要性的详细流程**：
1. 用训练好的模型在验证集上计算基准指标（如AUC）
2. 对第 $i$ 个特征的值进行随机打乱
3. 重新计算指标，记录下降量
4. 多次重复取平均，得到该特征的排列重要性

排列重要性相比基尼重要性更可靠，因为它直接衡量特征对模型预测性能的贡献，且不受特征基数的影响。

**高基数特征的偏差问题**：当特征取值种类很多（如用户ID）时，基尼重要性会偏高，这是因为高基数特征更容易产生"完美"的分裂点。排列重要性可以缓解这一问题。

# 2. 梯度提升树（GBDT）

 原理：通过特征在所有树中的分裂次数或信息增益总和计算重要性，常用于 XGBoost、LightGBM 等框架。

下面公式是基于损失函数梯度和二阶导数计算特征分裂的增益总和，来计算特征特重要度：

$$
\text {I m p o r t a n c e} _ {i} = \sum_ {\text {s p l i t s}} \left(\frac {\partial L}{\partial f}\right) ^ {2} \cdot \text {H e s s i a n}
$$

 适用场景：大规模数据下的特征优化，如广告点击率预测中的用户行为特征排序。  
 优缺点：精度高，支持缺失值处理，但训练时间长。

**XGBoost 的增益计算**：XGBoost 在每次分裂时计算增益：

$$
\text{Gain} = \frac{1}{2} \left[ \frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda} \right] - \gamma
$$

其中 $G$ 为一阶梯度之和，$H$ 为二阶梯度之和，$\lambda$ 为L2正则化系数，$\gamma$ 为分裂惩罚项。特征的重要性即为其在所有分裂中增益的总和。

**SHAP 值（SHapley Additive exPlanations）**：这是目前最权威的特征重要度评估方法之一，基于博弈论中的Shapley值：

$$
\phi_i = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|! \cdot (|F| - |S| - 1)!}{|F|!} [v(S \cup \{i\}) - v(S)]
$$

SHAP 值满足一致性、局部准确性等理想性质，能够同时提供全局和局部的特征重要性解释。TreeSHAP 算法针对树模型实现了多项式时间复杂度的精确计算。

# 三、基于深度学习的方法

# 1. 基于扰动的方法

这种方法符合人类直觉：如果去掉某个特征后模型表现大幅下滑，就说明这个特征很重要。具体操作方法包括：

 特征置零/掩码（Mask）：在模型推理时，将待评估特征的全部值置为 0 或一个特殊值，然后观察模型评估集上 AUC 等指标的下降幅度（AUC Diff）。  
 排列重要性（Permutation Importance）：对验证集中某个特征的值进行随机打乱，破坏其与标签的关系，然后观察模型性能的下降程度。下降越多，特征越重要。

**特征扰动法的注意事项**：
- 特征间存在强相关性时，扰动某个特征可能同时破坏了相关特征的信息，导致重要性估计偏高
- 应多次随机打乱取平均，减少随机性的影响
- 扰动方法计算成本较高，需要对每个特征单独评估

**LIME（Local Interpretable Model-agnostic Explanations）**：通过在局部邻域内拟合一个可解释模型（如线性模型）来解释模型的预测：

$$
\xi(x) = \arg\min_{g \in G} \sum_{i=1}^{n} \pi_x(z_i) \left| f(z_i) - g(z_i) \right|^2 + \Omega(g)
$$

其中 $\pi_x$ 是基于与目标样本 $x$ 的距离定义的权重，$\Omega(g)$ 是模型复杂度正则项。

# 2. 基于模型内置权重的方法

 梯度与显著图（Saliency Maps）：对于深度学习模型，可以通过计算模型输出相对于输入特征的梯度。梯度绝对值越大，表明特征微小的变化对输出影响越大，其重要性可能越高。  
 注意力权重（Attention Weights）：如果模型结构中含有注意力机制（Attention Mechanism），那么注意力权重本身就可以直接解释为不同特征或特征交互的重要性。例如，在Transformer或FiBiNet 等模型中，注意力权重的高低直观反映了模型对不同特征的"关注"程度。  
 SENet（Squeeze-and-Excitation Network）：最初用于计算机视觉，后被引入推荐模型如 FiBinet。SENet 通过"压缩"和"激励"两个步骤，自动学习每个特征域（Field）的重要性权重，然后对原始特征 Embedding 进行加权，从而放大重要特征的作用，抑制不重要或噪声特征。

PS：这类方法效率很高，但需要谨慎选择。例如，梯度的绝对值可能受特征数值尺度影响；自动学习的注意力权重有时可能并不完全可靠。

**Integrated Gradients（积分梯度）**：解决了普通梯度方法在饱和区域梯度为零的问题：

$$
IG_i(x) = (x_i - x_i') \times \int_{\alpha=0}^{1} \frac{\partial F(x' + \alpha(x - x'))}{\partial x_i} d\alpha
$$

其中 $x'$ 是基线输入（如全零向量），通过在基线到实际输入的路径上积分梯度，得到更稳定的特征重要性归因。

# 四、Python 代码实现

```python
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.inspection import permutation_importance
from sklearn.metrics import accuracy_score
from scipy.stats import pearsonr, spearmanr, chi2_contingency
from sklearn.feature_selection import mutual_info_classif

X, y = make_classification(
    n_samples=2000, n_features=20, n_informative=8,
    n_redundant=4, random_state=42
)
feature_names = [f"feature_{i}" for i in range(X.shape[1])]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

print("=== 皮尔逊相关系数 ===")
correlations = []
for i in range(X.shape[1]):
    corr, _ = pearsonr(X_train[:, i], y_train)
    correlations.append(abs(corr))
corr_df = pd.DataFrame({
    'feature': feature_names,
    'pearson_corr': correlations
}).sort_values('pearson_corr', ascending=False)
print(corr_df.head(10))

print("\n=== 互信息 ===")
mi_scores = mutual_info_classif(X_train, y_train, random_state=42)
mi_df = pd.DataFrame({
    'feature': feature_names,
    'mutual_info': mi_scores
}).sort_values('mutual_info', ascending=False)
print(mi_df.head(10))

print("\n=== 随机森林特征重要性 (基尼) ===")
rf = RandomForestClassifier(n_estimators=200, random_state=42, n_jobs=-1)
rf.fit(X_train, y_train)
rf_imp_df = pd.DataFrame({
    'feature': feature_names,
    'rf_importance': rf.feature_importances_
}).sort_values('rf_importance', ascending=False)
print(rf_imp_df.head(10))

print("\n=== 排列重要性 ===")
perm_result = permutation_importance(
    rf, X_test, y_test, n_repeats=10, random_state=42, n_jobs=-1
)
perm_imp_df = pd.DataFrame({
    'feature': feature_names,
    'perm_importance_mean': perm_result.importances_mean,
    'perm_importance_std': perm_result.importances_std
}).sort_values('perm_importance_mean', ascending=False)
print(perm_imp_df.head(10))

print("\n=== GBDT 特征重要性 ===")
gbdt = GradientBoostingClassifier(
    n_estimators=200, max_depth=5, random_state=42
)
gbdt.fit(X_train, y_train)
gbdt_imp_df = pd.DataFrame({
    'feature': feature_names,
    'gbdt_importance': gbdt.feature_importances_
}).sort_values('gbdt_importance', ascending=False)
print(gbdt_imp_df.head(10))

print("\n=== 方法对比 ===")
comparison = pd.DataFrame({'feature': feature_names})
comparison = comparison.merge(corr_df, on='feature')
comparison = comparison.merge(mi_df, on='feature')
comparison = comparison.merge(rf_imp_df, on='feature')
comparison = comparison.merge(perm_imp_df[['feature', 'perm_importance_mean']], on='feature')
comparison = comparison.merge(gbdt_imp_df, on='feature')
for col in ['pearson_corr', 'mutual_info', 'rf_importance', 'perm_importance_mean', 'gbdt_importance']:
    comparison[f'{col}_rank'] = comparison[col].rank(ascending=False)
print(comparison.sort_values('rf_importance_rank')[['feature'] + [c for c in comparison.columns if 'rank' in c]])
```

# 五、方法对比与选择建议

| 方法类别 | 代表方法 | 计算成本 | 可靠性 | 适用模型 | 是否考虑交互 |
|---------|---------|---------|--------|---------|------------|
| 统计方法 | 皮尔逊/互信息 | 低 | 中 | 模型无关 | 否 |
| 树模型内置 | 基尼/增益重要性 | 中 | 中高 | 树模型 | 是 |
| 扰动方法 | 排列重要性 | 高 | 高 | 模型无关 | 间接 |
| 梯度方法 | Integrated Gradients | 中 | 高 | 可导模型 | 是 |
| 博弈论 | SHAP | 高 | 极高 | 模型无关 | 是 |

# 六、常见问题与易错点

1. **特征相关性干扰**：高度相关的特征会"分摊"重要性，导致单个特征的重要性被低估。建议先进行特征去相关处理。
2. **高基数偏差**：取值种类多的特征在树模型中容易获得偏高的基尼重要性，应结合排列重要性或SHAP值交叉验证。
3. **训练集 vs 验证集**：排列重要性应在验证集上计算，在训练集上计算可能过拟合。
4. **方向性缺失**：大部分特征重要度方法只能告诉"多重要"，不能告诉"正向还是负向"，需要结合SHAP值或偏依赖图分析。
5. **稳定性问题**：随机性较大的方法（如随机森林的重要性）应多次计算取平均，确保结果稳定。

# 七、工业实践建议

- **快速筛选阶段**：先用统计方法（相关系数、互信息）过滤明显无关特征，降低维度
- **精细评估阶段**：用树模型的排列重要性和SHAP值做深入分析
- **深度学习模型**：优先使用Integrated Gradients或SHAP DeepExplainer
- **推荐系统场景**：推荐模型中特征数量庞大（数百到数千），建议先用SENet做自动特征选择，再用排列重要性做精排特征筛选
