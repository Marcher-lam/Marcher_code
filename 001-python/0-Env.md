# Anaconda 安装指南

Anaconda 是一个用于 Python 科学计算、数据分析、AI 开发的发行版，内置 Conda 包管理器和大量常用库。

---

## 1. 下载 Anaconda

前往官方下载页面：

https://www.anaconda.com/download

选择对应系统版本：

- Windows（.exe）
- macOS（Intel / Apple Silicon）
- Linux（.sh）

---

## 2. Windows 安装步骤

### 2.1 运行安装程序
双击下载的 `Anaconda3-xxxx-Windows-x86_64.exe`

### 2.2 安装选项建议
-（可选）不勾选：**Add Anaconda to my PATH**
- 勾选：**Register Anaconda as my default Python 3.x**

### 2.3 验证安装

打开 *Anaconda Prompt*：

```bash
conda --version
