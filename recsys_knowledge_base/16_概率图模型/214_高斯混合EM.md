## 1. 算法基础认知

**高斯混合模型（Gaussian Mixture Model, GMM）** 假设数据由多个高斯分布混合生成，每个数据点属于某个高斯成分（但不知道是哪个）。用EM算法学习参数。

---

## 3. 数学公式

### 3.1 模型定义

$$P(x) = \sum_{k=1}^{K} \pi_k \mathcal{N}(x|\mu_k, \Sigma_k)$$

- $\pi_k$: 混合权重，$\sum \pi_k = 1$
- $\mu_k$: 第k个高斯的均值
- $\Sigma_k$: 第k个高斯的协方差

### 3.2 EM步骤

**E步**：计算后验概率

$$\gamma_{nk} = \frac{\pi_k \mathcal{N}(x_n|\mu_k, \Sigma_k)}{\sum_{j}\pi_j \mathcal{N}(x_n|\mu_j, \Sigma_j)}$$

**M步**：更新参数

$$\mu_k = \frac{\sum_n \gamma_{nk} x_n}{\sum_n \gamma_{nk}}, \quad \pi_k = \frac{\sum_n \gamma_{nk}}{N}$$

## 7. 调库实现

```python
from sklearn.mixture import GaussianMixture
import numpy as np

# 生成数据
np.random.seed(42)
X = np.vstack([
    np.random.randn(200, 2) * 0.5 + [2, 2],
    np.random.randn(300, 2) * 0.8 + [-2, -1],
    np.random.randn(100, 2) * 0.3 + [0, 4]
])

# GMM聚类
gmm = GaussianMixture(n_components=3, random_state=42)
labels = gmm.fit_predict(X)

print(f"聚类中心:\n{gmm.means_}")
print(f"样本数分配: {np.bincount(labels)}")
```
