# 马尔可夫链蒙特卡洛 学习文档

> 从概率分布中采样的通用方法

---

## 1. 算法基础认知

**MCMC（Markov Chain Monte Carlo）** 是一类从复杂概率分布中采样的算法，通过构造马尔可夫链使其平稳分布等于目标分布。

### 核心思想

```
目标: 从复杂分布 P(x) 中采样
方法: 构造一个马尔可夫链，其平稳分布 = P(x)
     运行足够长时间后，链的状态 ≈ P(x)的样本
```

---

## 3. 数学公式

### Metropolis-Hastings

1. 从当前状态 $x_t$，提议新状态 $x' \sim q(x'|x_t)$
2. 计算接受率：$\alpha = \min\left(1, \frac{P(x')q(x_t|x')}{P(x_t)q(x'|x_t)}\right)$
3. 以概率 $\alpha$ 接受（$x_{t+1} = x'$），否则拒绝（$x_{t+1} = x_t$）

---

## 8. 手工实现

```python
import numpy as np

def metropolis_hastings(target_pdf, n_samples, proposal_std=1.0):
    """Metropolis-Hastings采样"""
    samples = []
    x = 0.0  # 初始状态
    
    for _ in range(n_samples):
        # 提议新状态
        x_new = x + np.random.randn() * proposal_std
        
        # 计算接受率
        alpha = min(1, target_pdf(x_new) / (target_pdf(x) + 1e-10))
        
        # 接受或拒绝
        if np.random.rand() < alpha:
            x = x_new
        
        samples.append(x)
    
    return np.array(samples)

# 采样目标: 混合高斯
def target(x):
    return 0.3 * np.exp(-0.5*(x+2)**2) + 0.7 * np.exp(-0.5*(x-3)**2)

samples = metropolis_hastings(target, 10000)
print(f"采样均值: {samples.mean():.2f}")
print(f"采样标准差: {samples.std():.2f}")
```
