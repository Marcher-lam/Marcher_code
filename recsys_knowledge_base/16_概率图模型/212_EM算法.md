# EM算法 学习文档

> 含隐变量的极大似然估计——迭代求解的艺术

## 1. 算法基础认知

### 1.1 什么是EM算法

**EM（Expectation-Maximization）** 算法用于含有隐变量的概率模型的参数估计，通过交替执行E步（期望）和M步（最大化）迭代求解。

```
问题: 有些变量观测不到（隐变量）
  例: 用户聚类中，用户属于哪个群体是未知的

EM思想:
  E步: 根据当前参数，估计隐变量的分布
  M步: 根据隐变量的估计，更新参数
  交替执行直到收敛
```

---

## 3. 数学公式

### 3.1 问题定义

观测数据 $X$，隐变量 $Z$，参数 $\theta$，目标是最大化：

$$\log P(X|\theta) = \log \sum_{Z} P(X, Z|\theta)$$

由于对数内有求和，难以直接优化。

### 3.2 EM算法

**E步**：计算隐变量的后验分布

$$Q(\theta|\theta^{(t)}) = \mathbb{E}_{Z|X,\theta^{(t)}}[\log P(X, Z|\theta)]$$

**M步**：最大化期望

$$\theta^{(t+1)} = \arg\max_{\theta} Q(\theta|\theta^{(t)})$$

### 3.3 收敛性

EM保证每次迭代后似然不减：

$$\log P(X|\theta^{(t+1)}) \geq \log P(X|\theta^{(t)})$$

## 7. 调库实现（GMM-EM）

```python
"""
EM算法应用: 高斯混合模型(GMM)
"""
import numpy as np
from sklearn.mixture import GaussianMixture

# 生成混合高斯数据
np.random.seed(42)
data1 = np.random.randn(200, 2) + np.array([3, 3])
data2 = np.random.randn(300, 2) + np.array([-3, -1])
data = np.vstack([data1, data2])

# 用EM算法拟合GMM
gmm = GaussianMixture(n_components=2, random_state=42)
gmm.fit(data)

print(f"均值:\n{gmm.means_}")
print(f"协方差:\n{gmm.covariances_}")
print(f"混合权重: {gmm.weights_}")

# 聚类预测
labels = gmm.predict(data)
print(f"聚类标签分布: {np.bincount(labels)}")
```

## 8. 手工代码实现

```python
"""
EM算法求解GMM —— 纯 NumPy
"""
import numpy as np

def gaussian_pdf(x, mean, cov):
    """多元高斯概率密度"""
    d = len(mean)
    diff = x - mean
    cov_inv = np.linalg.inv(cov)
    norm = 1.0 / np.sqrt((2*np.pi)**d * np.linalg.det(cov))
    return norm * np.exp(-0.5 * diff @ cov_inv @ diff)

def em_gmm(X, K, max_iter=100):
    """
    EM算法求解高斯混合模型
    
    X: (N, D) 数据
    K: 高斯成分数
    """
    N, D = X.shape
    
    # 初始化
    means = X[np.random.choice(N, K, replace=False)]
    covs = [np.eye(D) for _ in range(K)]
    weights = np.ones(K) / K
    
    for iteration in range(max_iter):
        # E步: 计算每个样本属于每个成分的后验概率
        responsibilities = np.zeros((N, K))
        for k in range(K):
            for n in range(N):
                responsibilities[n, k] = weights[k] * gaussian_pdf(X[n], means[k], covs[k])
        
        responsibilities /= responsibilities.sum(axis=1, keepdims=True)
        
        # M步: 更新参数
        Nk = responsibilities.sum(axis=0)
        for k in range(K):
            # 更新均值
            means[k] = (responsibilities[:, k:k+1].T @ X / Nk[k]).flatten()
            # 更新协方差
            diff = X - means[k]
            covs[k] = (diff * responsibilities[:, k:k+1]).T @ diff / Nk[k]
            # 更新权重
            weights[k] = Nk[k] / N
    
    return means, covs, weights

if __name__ == "__main__":
    np.random.seed(42)
    data = np.vstack([
        np.random.randn(100, 2) + [3, 3],
        np.random.randn(150, 2) + [-2, -1]
    ])
    means, covs, weights = em_gmm(data, K=2, max_iter=50)
    print(f"学到的均值: {means}")
    print(f"学到的权重: {weights}")
```

## 12. 学习总结

1. **EM = E步(估计隐变量) + M步(更新参数)**
2. **保证收敛**：每次迭代似然不减
3. **GMM是EM的经典应用**：用EM学习高斯混合的参数
4. **在推荐中**：用户分群、主题模型、协同过滤中的隐因子
