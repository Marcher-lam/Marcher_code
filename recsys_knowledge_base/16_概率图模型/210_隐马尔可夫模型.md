## 1. 算法基础认知

### 1.1 什么是HMM

**隐马尔可夫模型（Hidden Markov Model, HMM）** 是一种统计模型，用于描述含有隐含状态的序列过程。我们能观测到的是状态产生的"输出"，真正的"状态"是隐藏的。

```
天气(隐藏) → 穿衣(观测)
[晴天] → [T恤]
[雨天] → [雨衣]
[晴天] → [T恤]

我们只能看到穿衣，需要推断天气
```

### 1.2 核心假设

1. **马尔可夫假设**：当前状态只依赖前一个状态
2. **观测独立假设**：当前观测只依赖当前状态

## 3. 数学公式

### 3.1 五元组

HMM由 $\lambda = (S, O, \pi, A, B)$ 定义：

- $S$: 状态集合（隐藏状态）
- $O$: 观测集合
- $\pi$: 初始状态概率
- $A$: 状态转移概率矩阵, $a_{ij} = P(s_{t+1}=j|s_t=i)$
- $B$: 观测概率矩阵, $b_j(o_t) = P(o_t|s_t=j)$

### 3.2 三个基本问题

| 问题 | 算法 | 说明 |
|------|------|------|
| **评估** | 前向算法 | 给定模型λ，计算观测序列概率P(O\|λ) |
| **解码** | Viterbi算法 | 给定模型λ和观测O，找最可能的状态序列 |
| **学习** | Baum-Welch | 给定观测O，学习模型参数λ |

### 3.3 前向算法

$$\alpha_t(i) = P(o_1,o_2,...,o_t, s_t=i|\lambda)$$

初始化：$\alpha_1(i) = \pi_i b_i(o_1)$

递推：$\alpha_t(j) = \left[\sum_{i=1}^{N}\alpha_{t-1}(i)a_{ij}\right] b_j(o_t)$

### 3.4 Viterbi算法

$$\delta_t(j) = \max_{s_1,...,s_{t-1}} P(s_1,...,s_t=j, o_1,...,o_t|\lambda)$$

递推：$\delta_t(j) = \max_{i}[\delta_{t-1}(i) \cdot a_{ij}] \cdot b_j(o_t)$

## 7. 调库实现

```python
"""
HMM 实现与应用
"""
import numpy as np
from hmmlearn import hmm


# ============================================================
# 1. 手写HMM前向算法
# ============================================================
def forward_algorithm(obs, pi, A, B):
    """
    前向算法计算P(O|λ)
    
    obs: 观测序列 [o1, o2, ..., oT]
    pi:  初始概率 (N,)
    A:   转移矩阵 (N, N)
    B:   观测矩阵 (N, M)
    """
    T = len(obs)
    N = len(pi)
    
    # 初始化
    alpha = np.zeros((T, N))
    alpha[0] = pi * B[:, obs[0]]
    
    # 递推
    for t in range(1, T):
        for j in range(N):
            alpha[t, j] = np.sum(alpha[t-1] * A[:, j]) * B[j, obs[t]]
    
    return np.sum(alpha[-1])


# ============================================================
# 2. Viterbi解码
# ============================================================
def viterbi(obs, pi, A, B):
    """Viterbi算法找最可能的状态序列"""
    T = len(obs)
    N = len(pi)
    
    delta = np.zeros((T, N))
    psi = np.zeros((T, N), dtype=int)
    
    # 初始化
    delta[0] = pi * B[:, obs[0]]
    
    # 递推
    for t in range(1, T):
        for j in range(N):
            probs = delta[t-1] * A[:, j]
            psi[t, j] = np.argmax(probs)
            delta[t, j] = np.max(probs) * B[j, obs[t]]
    
    # 回溯
    path = np.zeros(T, dtype=int)
    path[-1] = np.argmax(delta[-1])
    for t in range(T-2, -1, -1):
        path[t] = psi[t+1, path[t+1]]
    
    return path


if __name__ == "__main__":
    # 定义HMM模型
    # 状态: 0=晴天, 1=雨天
    # 观测: 0=散步, 1=购物, 2=宅家
    
    pi = np.array([0.6, 0.4])         # 初始概率
    A = np.array([[0.7, 0.3],          # 转移矩阵
                  [0.4, 0.6]])
    B = np.array([[0.6, 0.3, 0.1],     # 观测概率（晴天）
                  [0.1, 0.3, 0.6]])    # 观测概率（雨天）
    
    # 观测序列: 散步 → 购物 → 宅家
    obs = [0, 1, 2]
    
    # 1. 计算概率
    prob = forward_algorithm(obs, pi, A, B)
    print(f"P(散步,购物,宅家) = {prob:.6f}")
    
    # 2. 解码
    path = viterbi(obs, pi, A, B)
    state_names = ["晴天", "雨天"]
    print(f"最可能的状态序列: {[state_names[s] for s in path]}")
```

## 12. 学习总结

1. **HMM = 隐状态 + 观测 + 转移 + 发射**
2. **三个问题**：评估（前向）、解码（Viterbi）、学习（Baum-Welch）
3. **在推荐中**：用户兴趣建模、行为序列分析
4. **局限性**：马尔可夫假设太强，被RNN/Transformer取代
