## 1. 算法基础认知

### 1.1 什么是GPT

**GPT（Generative Pre-trained Transformer）** 是OpenAI提出的大规模语言模型，采用Transformer Decoder架构，通过自回归方式生成文本。

### 1.2 核心思想

```
预训练: 在海量文本上做"下一个词预测"（自回归语言模型）
微调:   在下游任务上用少量标注数据微调

GPT系列:
- GPT-1 (2018): 1.17亿参数
- GPT-2 (2019): 15亿参数
- GPT-3 (2020): 1750亿参数
- GPT-4 (2023): 多模态大模型
```

### 1.3 在推荐系统中的应用

| 应用 | 说明 |
|------|------|
| **大模型推荐** | 用GPT理解用户意图、生成推荐理由 |
| **特征提取** | 用GPT编码文本特征 |
| **生成式推荐** | 直接生成推荐列表 |
| **冷启动** | 利用GPT的通用知识处理新物品 |

## 3. 数学公式

### 3.1 自回归语言模型

$$P(x) = \prod_{t=1}^{T} P(x_t | x_1, x_2, ..., x_{t-1})$$

### 3.2 训练目标

$$\mathcal{L} = -\sum_{t=1}^{T}\log P(x_t | x_{<t}; \theta)$$

> 本质就是"给定前面的词，预测下一个词"。

## 7. 调库实现

```python
"""
GPT 模型结构演示 (简化版)
"""
import torch
import torch.nn as nn
import math


class GPTBlock(nn.Module):
    """GPT Block = Masked Self-Attention + FFN"""
    
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        self.attention = nn.MultiheadAttention(d_model, n_heads, dropout=dropout, batch_first=True)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Linear(d_ff, d_model),
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        # Masked Self-Attention (防止看到未来)
        attn_out, _ = self.attention(x, x, x, attn_mask=mask)
        x = self.norm1(x + self.dropout(attn_out))
        ffn_out = self.ffn(x)
        x = self.norm2(x + self.dropout(ffn_out))
        return x


class SimpleGPT(nn.Module):
    """简化版GPT"""
    
    def __init__(self, vocab_size, d_model=128, n_heads=4, n_layers=4, max_len=256):
        super().__init__()
        self.token_embedding = nn.Embedding(vocab_size, d_model)
        self.pos_embedding = nn.Embedding(max_len, d_model)
        
        self.blocks = nn.ModuleList([
            GPTBlock(d_model, n_heads, d_model * 4)
            for _ in range(n_layers)
        ])
        
        self.output_head = nn.Linear(d_model, vocab_size)
    
    def forward(self, input_ids):
        B, T = input_ids.shape
        pos = torch.arange(T, device=input_ids.device).unsqueeze(0)
        
        x = self.token_embedding(input_ids) + self.pos_embedding(pos)
        
        # 因果mask
        mask = torch.triu(torch.ones(T, T), diagonal=1).bool()
        
        for block in self.blocks:
            x = block(x, mask)
        
        logits = self.output_head(x)
        return logits


if __name__ == "__main__":
    torch.manual_seed(42)
    
    model = SimpleGPT(vocab_size=1000, d_model=128, n_heads=4, n_layers=4)
    input_ids = torch.randint(0, 1000, (2, 32))  # 2个样本，长度32
    
    logits = model(input_ids)
    print(f"输入: {input_ids.shape}")
    print(f"输出: {logits.shape}")  # (2, 32, 1000) - 每个位置预测下一个词
    
    total_params = sum(p.numel() for p in model.parameters())
    print(f"参数量: {total_params:,}")
```

## 12. 学习总结

1. **GPT = Transformer Decoder + 自回归训练**
2. **Masked Self-Attention**：只能看到当前位置之前的词
3. **预训练-微调范式**：先在大规模数据上预训练，再在下游任务微调
4. **在推荐中**：大模型推荐、生成式推荐、冷启动解决方案
