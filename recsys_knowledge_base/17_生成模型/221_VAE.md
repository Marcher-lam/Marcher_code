# VAE变分自编码器 学习文档

> 概率化的自编码器——学会生成而非仅仅重建

---

## 1. 算法基础认知

**VAE（Variational Autoencoder）** 是一种生成模型，在AE基础上引入概率建模，编码器输出的是分布参数（均值和方差）而非确定值，从分布中采样后解码。

### 核心创新

```
AE:  x → 编码器 → z (确定值) → 解码器 → x̂
VAE: x → 编码器 → (μ, σ²) → 采样 z~N(μ,σ²) → 解码器 → x̂
```

---

## 3. 数学公式

### 3.1 损失函数

$$\mathcal{L} = \underbrace{\mathbb{E}_{q(z|x)}[\log p(x|z)]}_{\text{重建损失}} + \underbrace{KL(q(z|x) \| p(z))}_{\text{正则化}}$$

### 3.2 重参数化技巧

$$z = \mu + \sigma \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

> 使采样操作可微，允许梯度回传。

### 3.3 KL散度

$$KL = -\frac{1}{2}\sum(1 + \log\sigma^2 - \mu^2 - \sigma^2)$$

## 7. 调库实现

```python
import torch
import torch.nn as nn

class VAE(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=400, latent_dim=20):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim), nn.ReLU()
        )
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, input_dim), nn.Sigmoid()
        )
    
    def encode(self, x):
        h = self.encoder(x)
        return self.fc_mu(h), self.fc_logvar(h)
    
    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std
    
    def decode(self, z):
        return self.decoder(z)
    
    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar

def vae_loss(x_recon, x, mu, logvar):
    recon_loss = nn.functional.binary_cross_entropy(x_recon, x, reduction='sum')
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return recon_loss + kl_loss

if __name__ == "__main__":
    model = VAE()
    x = torch.rand(16, 784)
    x_recon, mu, logvar = model(x)
    loss = vae_loss(x_recon, x, mu, logvar)
    print(f"输入: {x.shape} → 潜在: {mu.shape} → 重建: {x_recon.shape}")
    print(f"损失: {loss.item():.2f}")
```

## 12. 学习总结

1. VAE = 概率化的AE，编码器输出分布参数
2. 损失 = 重建损失 + KL散度正则化
3. 重参数化技巧使采样可微
4. 在推荐中：生成式推荐、多样性增强
