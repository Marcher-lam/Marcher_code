# AE自编码器 学习文档

> 无监督学习表征——压缩与重建的艺术

---

## 1. 算法基础认知

**自编码器（Autoencoder, AE）** 是一种无监督学习模型，通过将输入压缩为低维编码再重建输入来学习数据表征。

```
输入 x → 编码器 → 编码 z (低维) → 解码器 → 重建 x̂
目标: 让 x̂ 尽可能接近 x
```

### 在推荐系统中的应用

- **协同过滤**：AutoRec用自编码器预测评分
- **特征降维**：学习用户/物品的低维表征
- **异常检测**：重建误差大的样本可能是异常

## 3. 数学公式

## 7. 调库实现

```python
import torch
import torch.nn as nn

class Autoencoder(nn.Module):
    def __init__(self, input_dim, encoding_dim=32):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 128),
            nn.ReLU(),
            nn.Linear(128, encoding_dim),
        )
        self.decoder = nn.Sequential(
            nn.Linear(encoding_dim, 128),
            nn.ReLU(),
            nn.Linear(128, input_dim),
        )
    
    def forward(self, x):
        z = self.encoder(x)
        x_hat = self.decoder(z)
        return x_hat, z

if __name__ == "__main__":
    model = Autoencoder(input_dim=100, encoding_dim=32)
    x = torch.randn(16, 100)
    x_hat, z = model(x)
    print(f"输入: {x.shape} → 编码: {z.shape} → 重建: {x_hat.shape}")
```

## 12. 学习总结

1. AE = 编码器 + 解码器，学习数据的低维压缩表示
2. 重建损失训练，无需标签
3. 在推荐中用于协同过滤（AutoRec）和特征学习
