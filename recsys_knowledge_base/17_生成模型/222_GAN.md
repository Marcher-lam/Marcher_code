# GAN生成对抗网络 学习文档

> 生成器的对抗训练——让两个网络互相博弈

---

## 1. 算法基础认知

**GAN（Generative Adversarial Network）** 由Goodfellow在2014年提出，包含两个网络：
- **生成器G**：从噪声生成假数据
- **判别器D**：区分真假数据

```
训练过程:
  真实数据 ─→ D(判别器) → "真"     D努力区分真假
  噪声 → G(生成器) → 假数据 → D → "假"  G努力骗过D

  两者博弈，最终G能生成逼真的数据
```

---

## 3. 数学公式

$$\min_G \max_D V(D,G) = \mathbb{E}_{x\sim p_{data}}[\log D(x)] + \mathbb{E}_{z\sim p_z}[\log(1-D(G(z)))]$$

## 7. 调库实现

```python
import torch
import torch.nn as nn

class Generator(nn.Module):
    def __init__(self, latent_dim=100, output_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(latent_dim, 256), nn.LeakyReLU(0.2),
            nn.Linear(256, 512), nn.LeakyReLU(0.2),
            nn.Linear(512, output_dim), nn.Tanh()
        )
    def forward(self, z): return self.net(z)

class Discriminator(nn.Module):
    def __init__(self, input_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, 512), nn.LeakyReLU(0.2),
            nn.Linear(512, 256), nn.LeakyReLU(0.2),
            nn.Linear(256, 1), nn.Sigmoid()
        )
    def forward(self, x): return self.net(x)

# 训练循环
if __name__ == "__main__":
    G = Generator()
    D = Discriminator()
    
    opt_G = torch.optim.Adam(G.parameters(), lr=0.0002)
    opt_D = torch.optim.Adam(D.parameters(), lr=0.0002)
    criterion = nn.BCELoss()
    
    for epoch in range(100):
        # 训练判别器
        real_data = torch.rand(32, 784)
        fake_data = G(torch.randn(32, 100))
        
        d_loss = (criterion(D(real_data), torch.ones(32, 1)) +
                  criterion(D(fake_data.detach()), torch.zeros(32, 1))) / 2
        opt_D.zero_grad(); d_loss.backward(); opt_D.step()
        
        # 训练生成器
        fake_data = G(torch.randn(32, 100))
        g_loss = criterion(D(fake_data), torch.ones(32, 1))
        opt_G.zero_grad(); g_loss.backward(); opt_G.step()
        
        if (epoch+1) % 20 == 0:
            print(f"Epoch {epoch+1}: D_loss={d_loss.item():.4f}, G_loss={g_loss.item():.4f}")
```

## 12. 学习总结

1. GAN = 生成器 vs 判别器的对抗训练
2. 训练不稳定是GAN的主要挑战
3. DCGAN用卷积结构改善训练稳定性
4. 在推荐中：数据增强、多样性提升
