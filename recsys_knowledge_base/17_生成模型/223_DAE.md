# DAE去噪自编码器 学习文档

> 通过加噪声学习更鲁棒的表征

**DAE（Denoising Autoencoder）** 在输入上加噪声，训练模型从损坏的输入中恢复原始数据。

## 核心原理

```
原始输入 x → 加噪声 → x̃ (损坏) → 编码器 → z → 解码器 → x̂
目标: x̂ ≈ x (从损坏数据恢复原始数据)
```

## 数学公式

$$L = \|x - D(E(\tilde{x}))\|^2$$

其中 $\tilde{x} = x + \epsilon$，$\epsilon$ 是随机噪声。

## 调库实现

```python
import torch
import torch.nn as nn

class DenoisingAutoencoder(nn.Module):
    def __init__(self, input_dim, hidden_dim=64):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim), nn.ReLU()
        )
        self.decoder = nn.Sequential(
            nn.Linear(hidden_dim, input_dim), nn.Sigmoid()
        )
        self.noise_level = 0.3
    
    def add_noise(self, x):
        noise = torch.randn_like(x) * self.noise_level
        return torch.clamp(x + noise, 0, 1)
    
    def forward(self, x):
        x_noisy = self.add_noise(x)
        z = self.encoder(x_noisy)
        return self.decoder(z), x_noisy

if __name__ == "__main__":
    model = DenoisingAutoencoder(100, 32)
    x = torch.rand(16, 100)
    x_hat, x_noisy = model(x)
    loss = nn.MSELoss()(x_hat, x)
    print(f"输入→加噪→编码→重建, 损失: {loss.item():.4f}")
```

## 学习总结

1. DAE通过加噪声训练，学习更鲁棒的特征
2. 是对比学习（如掩码语言模型BERT的MLM）的思想先驱
3. 在推荐中可用于数据增强和抗噪推荐
