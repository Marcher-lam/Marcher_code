# 感知机 学习文档

> 最简单的神经网络——深度学习的起点

---

## 1. 算法基础认知

**感知机（Perceptron）** 是1957年Rosenblatt提出的最简单的线性二分类模型，是神经网络和深度学习的起点。

---

## 3. 数学公式

$$f(x) = \text{sign}(w \cdot x + b)$$

学习规则：对误分类样本 $(x_i, y_i)$：

$$w \leftarrow w + \eta y_i x_i$$
$$b \leftarrow b + \eta y_i$$

---

## 7. 调库实现

```python
from sklearn.linear_model import Perceptron
import numpy as np

X = np.array([[1,1],[2,2],[3,3],[-1,-1],[-2,-2]])
y = np.array([1, 1, 1, -1, -1])

clf = Perceptron(eta0=0.1, max_iter=100)
clf.fit(X, y)
print(f"权重: {clf.coef_}, 偏置: {clf.intercept_}")
print(f"预测 [0.5,0.5]: {clf.predict([[0.5, 0.5]])}")
```

## 8. 手工实现

```python
import numpy as np

class Perceptron:
    def __init__(self, lr=0.1, max_iter=100):
        self.lr = lr
        self.max_iter = max_iter
    
    def fit(self, X, y):
        self.w = np.zeros(X.shape[1])
        self.b = 0
        
        for _ in range(self.max_iter):
            for xi, yi in zip(X, y):
                if yi * (np.dot(self.w, xi) + self.b) <= 0:
                    self.w += self.lr * yi * xi
                    self.b += self.lr * yi
    
    def predict(self, X):
        return np.sign(X @ self.w + self.b)

# 测试: XOR问题（感知机无法解决！）
X = np.array([[0,0],[0,1],[1,0],[1,1]])
y = np.array([-1, 1, 1, -1])  # XOR
p = Perceptron()
p.fit(X, y)
print(f"XOR预测: {p.predict(X)}")  # 无法正确分类
print("感知机无法解决非线性问题（如XOR），需要多层网络(MLP)")
```

---

## 12. 学习总结

1. 感知机 = 最简单的线性分类器
2. 只能解决线性可分问题（不能解决XOR）
3. 是理解多层感知机(MLP)和深度学习的基础
4. 学习规则：误分类时更新权重
