## 简介

本知识库是一套面向**零基础初学者**的推荐系统算法工程师培养体系，覆盖从数学基础到工业落地的完整链路，力争打造**最全最大的推荐系统知识库**。

### 你将学到什么

- 推荐系统的业务目标与系统架构
- 召回、粗排、精排、重排、多目标优化的原理与实践
- 机器学习、深度学习、图算法、序列建模在推荐中的应用
- 特征工程、样本构造、离线评估、在线实验
- 工业界主流推荐模型的原理与实现（FM系列、DeepFM、DIN/DIEN、ESMM、PLE等）
- 大模型与推荐系统、因果推断、对比学习等前沿主题
- 从数据到上线落地的完整工程能力

## 学习路径

### 第一阶段：基础准备（2-4周）
1. **基础认知** - 理解推荐系统解决什么问题
2. **数学基础** - 线性代数、概率统计、微积分、优化
3. **编程基础** - Python、NumPy、Pandas、SQL
4. **机器学习入门** - 监督学习、无监督学习基础
5. **深度学习基础** - PyTorch、神经网络

### 第二阶段：推荐入门（3-4周）
1. **热门/规则推荐** - 最简单的推荐方式
2. **协同过滤** - UserCF、ItemCF
3. **矩阵分解** - SVD、FunkSVD、BiasSVD
4. **基于内容推荐** - 标签、关键词、文本向量

### 第三阶段：排序与CTR（4-6周）
1. **逻辑回归排序** - CTR预估基础
2. **树模型排序** - GBDT、XGBoost、LightGBM
3. **因子分解机** - FM、FFM、AFM
4. **深度排序模型** - DeepFM、Wide&Deep、DCN、xDeepFM
5. **用户兴趣建模** - DIN、DIEN、BST
6. **多任务学习** - MMOE、PLE、ESMM

### 第四阶段：召回与向量化（3-4周）
1. **Embedding基础** - 向量表示学习
2. **双塔模型** - DSSM、Two-Tower
3. **向量检索** - Faiss、HNSW、IVF
4. **图推荐** - DeepWalk、Node2Vec、LightGCN

### 第五阶段：序列与进阶（3-4周）
1. **序列推荐** - GRU4Rec、SASRec、BERT4Rec
2. **排序学习** - BPR、LambdaMART
3. **去偏学习** - Position Bias、Selection Bias

### 第六阶段：工程化落地（2-3周）
1. **特征工程** - 特征设计、样本构造
2. **离线评估** - AUC、NDCG、MAP
3. **A/B测试** - 实验设计、显著性检验
4. **在线部署** - 模型服务、监控

### 第七阶段：高级主题（4-6周）
1. **冷启动** - 新用户/新物品策略
2. **因果推断** - IPS、无偏学习
3. **对比学习** - 自监督推荐
4. **知识蒸馏** - 模型压缩
5. **大模型+推荐** - LLM增强、生成式推荐

## 如何使用本知识库

### 对于零基础学习者
1. 从 `00_基础认知` 开始，建立整体概念
2. 按顺序学习各阶段内容
3. 每学完一个模块，完成对应的练习题
4. 在 `13_项目实战` 中动手实践

### 对于有经验的学习者
1. 根据需要跳转到对应模块
2. 重点阅读原理推导和工程实践部分
3. 关注高级专题中的前沿方向

### 文档阅读建议
- **算法文档**：包含原理、公式、代码实现、练习题
- **专题文档**：聚焦特定问题的解决方案
- **项目文档**：完整的端到端实践案例
