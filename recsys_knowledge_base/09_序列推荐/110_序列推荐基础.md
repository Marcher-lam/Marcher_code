# 序列推荐基础 学习文档

## 1. 算法基础认知

### 1.1 什么是序列推荐？

序列推荐（Sequential Recommendation）是一种考虑用户行为**时间顺序**的推荐方法。它假设用户的偏好会随时间变化，且当前行为受之前行为影响。

### 1.2 与传统推荐的区别

| 维度 | 传统推荐 | 序列推荐 |
|------|----------|----------|
| 用户表示 | 静态向量 | 动态序列 |
| 时间信息 | 忽略 | 显式建模 |
| 行为顺序 | 不考虑 | 核心输入 |
| 预测目标 | 总体偏好 | 下一个行为 |

### 1.3 应用场景

- **电商**：预测用户下一个购买商品
- **视频**：预测下一个观看视频
- **音乐**：推荐下一首歌曲
- **新闻**：推荐下一条新闻
- **搜索**：预测下一个查询

## 2. 核心原理

### 2.1 问题定义

给定用户行为序列 $S_u = \{i_1, i_2, ..., i_n\}$，预测用户下一个可能交互的物品 $i_{n+1}$。

**数学表示：**
$$P(i_{n+1} | i_1, i_2, ..., i_n)$$

### 2.2 序列推荐的核心假设

1. **马尔可夫假设**：当前行为只与前 k 个行为相关
2. **长短期兴趣**：用户同时有长期稳定偏好和短期兴趣
3. **序列模式**：物品之间存在顺序转移模式

### 2.3 发展脉络

```
传统方法
├── 马尔可夫链
├── FPMC（因子分解个性化马尔可夫链）
└── 基于规则的方法

深度学习方法
├── RNN 系列
│   ├── GRU4Rec (2015)
│   └── GRU4Rec+ (2016)
├── CNN 系列
│   ├── Caser (2018)
│   └── NextItNet (2019)
└── Transformer 系列
    ├── SASRec (2018)
    └── BERT4Rec (2019)
```

## 3. 序列数据处理

### 3.1 序列构造

```python
import numpy as np
from collections import defaultdict

class SequenceProcessor:
    """
    序列数据处理器
    """

    def __init__(self, max_seq_len=50, min_seq_len=3):
        """
        参数:
            max_seq_len: 最大序列长度
            min_seq_len: 最小序列长度
        """
        self.max_seq_len = max_seq_len
        self.min_seq_len = min_seq_len

    def construct_sequences(self, interactions):
        """
        构造用户行为序列

        参数:
            interactions: [(user_id, item_id, timestamp), ...]

        返回:
            user_sequences: {user_id: [item_id1, item_id2, ...]}
        """
        # 按用户分组
        user_interactions = defaultdict(list)
        for user_id, item_id, timestamp in interactions:
            user_interactions[user_id].append((item_id, timestamp))

        # 按时间排序
        user_sequences = {}
        for user_id, items in user_interactions.items():
            # 按时间戳排序
            sorted_items = sorted(items, key=lambda x: x[1])
            # 提取物品序列
            seq = [item_id for item_id, _ in sorted_items]
            # 过滤短序列
            if len(seq) >= self.min_seq_len:
                user_sequences[user_id] = seq

        return user_sequences

    def truncate_sequence(self, sequence):
        """
        截断序列到最大长度（保留最近的）

        参数:
            sequence: 物品序列

        返回:
            截断后的序列
        """
        if len(sequence) > self.max_seq_len:
            return sequence[-self.max_seq_len:]
        return sequence

    def split_train_test(self, user_sequences, test_ratio=0.2):
        """
        划分训练集和测试集

        参数:
            user_sequences: 用户序列字典
            test_ratio: 测试集比例

        返回:
            train_data, test_data
        """
        train_data = []
        test_data = []

        for user_id, seq in user_sequences.items():
            # 最后一个物品作为测试目标
            split_point = int(len(seq) * (1 - test_ratio))

            if split_point >= self.min_seq_len:
                # 训练序列
                train_seq = seq[:split_point]
                for i in range(self.min_seq_len, len(train_seq)):
                    # 使用前 i 个预测第 i+1 个
                    train_data.append({
                        'user_id': user_id,
                        'sequence': train_seq[:i],
                        'target': train_seq[i]
                    })

                # 测试数据
                test_data.append({
                    'user_id': user_id,
                    'sequence': seq[:split_point],
                    'target': seq[split_point]
                })

        return train_data, test_data


class SequenceDataset:
    """
    序列数据集（PyTorch）
    """

    def __init__(self, data, item_num, max_seq_len=50):
        """
        参数:
            data: 训练数据列表
            item_num: 物品数量
            max_seq_len: 最大序列长度
        """
        self.data = data
        self.item_num = item_num
        self.max_seq_len = max_seq_len

    def __len__(self):
        return len(self.data)

    def __getitem__(self, idx):
        item = self.data[idx]

        # 序列处理
        seq = item['sequence'][-self.max_seq_len:]  # 截断
        seq_len = len(seq)

        # 填充
        padded_seq = [0] * (self.max_seq_len - seq_len) + seq

        # 构建注意力掩码
        attention_mask = [0] * (self.max_seq_len - seq_len) + [1] * seq_len

        return {
            'user_id': item['user_id'],
            'sequence': np.array(padded_seq, dtype=np.int64),
            'seq_len': seq_len,
            'attention_mask': np.array(attention_mask, dtype=np.float32),
            'target': item['target']
        }
```

## 4. 基础序列模型

### 4.1 马尔可夫链模型

```python
import numpy as np
from collections import defaultdict

class MarkovChainRecommender:
    """
    基于一阶马尔可夫链的序列推荐
    """

    def __init__(self, order=1):
        """
        参数:
            order: 马尔可夫链阶数
        """
        self.order = order
        self.transition_matrix = None
        self.item_to_idx = {}
        self.idx_to_item = {}

    def fit(self, sequences):
        """
        训练模型

        参数:
            sequences: {user_id: [item1, item2, ...]}
        """
        # 构建物品索引
        all_items = set()
        for seq in sequences.values():
            all_items.update(seq)

        self.item_to_idx = {item: idx for idx, item in enumerate(all_items)}
        self.idx_to_item = {idx: item for item, idx in self.item_to_idx.items()}
        n_items = len(all_items)

        # 统计转移次数
        transition_counts = defaultdict(lambda: defaultdict(int))

        for seq in sequences.values():
            for i in range(len(seq) - 1):
                current_item = self.item_to_idx[seq[i]]
                next_item = self.item_to_idx[seq[i + 1]]
                transition_counts[current_item][next_item] += 1

        # 计算转移概率
        self.transition_matrix = np.zeros((n_items, n_items))

        for current_item in range(n_items):
            total = sum(transition_counts[current_item].values())
            if total > 0:
                for next_item, count in transition_counts[current_item].items():
                    self.transition_matrix[current_item, next_item] = count / total

    def predict(self, sequence, top_k=10):
        """
        预测下一个物品

        参数:
            sequence: 用户行为序列
            top_k: 返回 top-k 推荐

        返回:
            推荐物品列表
        """
        if not sequence:
            # 冷启动：返回热门物品
            item_scores = self.transition_matrix.sum(axis=0)
        else:
            # 使用最后一个物品
            last_item = self.item_to_idx.get(sequence[-1])
            if last_item is None:
                item_scores = self.transition_matrix.sum(axis=0)
            else:
                item_scores = self.transition_matrix[last_item]

        # 获取 top-k
        top_indices = np.argsort(item_scores)[::-1][:top_k]

        return [self.idx_to_item[idx] for idx in top_indices if item_scores[idx] > 0]

    def get_transition_probability(self, item_from, item_to):
        """获取转移概率"""
        if item_from not in self.item_to_idx or item_to not in self.item_to_idx:
            return 0.0
        return self.transition_matrix[
            self.item_to_idx[item_from],
            self.item_to_idx[item_to]
        ]


# 高阶马尔可夫链
class HighOrderMarkovChain:
    """
    高阶马尔可夫链
    考虑前 k 个物品的影响
    """

    def __init__(self, order=3):
        """
        参数:
            order: 马尔可夫链阶数（考虑前 order 个物品）
        """
        self.order = order
        self.transition_matrix = None
        self.item_to_idx = {}
        self.idx_to_item = {}

    def fit(self, sequences):
        """训练"""
        # 构建物品索引
        all_items = set()
        for seq in sequences.values():
            all_items.update(seq)

        self.item_to_idx = {item: idx for idx, item in enumerate(all_items)}
        self.idx_to_item = {idx: item for item, idx in self.item_to_idx.items()}
        n_items = len(all_items)

        # 统计转移次数
        # key: (item_{t-order}, ..., item_{t-1})
        # value: {next_item: count}
        transition_counts = defaultdict(lambda: defaultdict(int))

        for seq in sequences.values():
            for i in range(self.order, len(seq)):
                # 前 order 个物品作为状态
                state = tuple(
                    self.item_to_idx[seq[j]]
                    for j in range(i - self.order, i)
                )
                next_item = self.item_to_idx[seq[i]]
                transition_counts[state][next_item] += 1

        self.transition_counts = transition_counts
        self.n_items = n_items

    def predict(self, sequence, top_k=10):
        """预测"""
        if len(sequence) < self.order:
            # 序列太短，使用一阶
            state = tuple(self.item_to_idx.get(seq[-1], 0)
                         for seq in [sequence[-1:]] * self.order)
        else:
            state = tuple(
                self.item_to_idx.get(item, 0)
                for item in sequence[-self.order:]
            )

        if state in self.transition_counts:
            # 有转移记录
            item_counts = self.transition_counts[state]
            total = sum(item_counts.values())
            scores = {item: count / total for item, count in item_counts.items()}
        else:
            # 没有记录，返回均匀分布
            scores = {i: 1.0 / self.n_items for i in range(self.n_items)}

        # 排序返回
        sorted_items = sorted(scores.items(), key=lambda x: x[1], reverse=True)[:top_k]
        return [self.idx_to_item[idx] for idx, _ in sorted_items]
```

### 4.2 FPMC（因子分解个性化马尔可夫链）

```python
import numpy as np

class FPMC:
    """
    Factorizing Personalized Markov Chains (FPMC)

    结合矩阵分解和马尔可夫链的序列推荐方法
    """

    def __init__(self, n_factors=64, learning_rate=0.01, regularization=0.01, n_epochs=50):
        """
        参数:
            n_factors: 隐向量维度
            learning_rate: 学习率
            regularization: 正则化系数
            n_epochs: 训练轮数
        """
        self.n_factors = n_factors
        self.learning_rate = learning_rate
        self.regularization = regularization
        self.n_epochs = n_epochs

        # 隐向量
        self.user_factors = None   # 用户隐向量
        self.item_factors = None   # 物品隐向量
        self.prev_item_factors = None  # 前一个物品隐向量

    def fit(self, user_sequences):
        """
        训练

        参数:
            user_sequences: {user_id: [item1, item2, ...]}
        """
        # 构建索引
        users = list(user_sequences.keys())
        items = set()
        for seq in user_sequences.values():
            items.update(seq)
        items = list(items)

        self.user_to_idx = {u: i for i, u in enumerate(users)}
        self.item_to_idx = {i: j for j, i in enumerate(items)}
        self.idx_to_item = {j: i for i, j in self.item_to_idx.items()}

        n_users = len(users)
        n_items = len(items)

        # 初始化隐向量
        self.user_factors = np.random.normal(0, 0.1, (n_users, self.n_factors))
        self.item_factors = np.random.normal(0, 0.1, (n_items, self.n_factors))
        self.prev_item_factors = np.random.normal(0, 0.1, (n_items, self.n_factors))

        # 构建训练数据
        train_data = []
        for user_id, seq in user_sequences.items():
            user_idx = self.user_to_idx[user_id]
            for i in range(1, len(seq)):
                prev_item = self.item_to_idx[seq[i - 1]]
                curr_item = self.item_to_idx[seq[i]]
                train_data.append((user_idx, prev_item, curr_item))

        # 训练
        for epoch in range(self.n_epochs):
            np.random.shuffle(train_data)
            total_loss = 0

            for user_idx, prev_item, curr_item in train_data:
                # 计算分数
                user_vec = self.user_factors[user_idx]
                prev_vec = self.prev_item_factors[prev_item]
                curr_vec = self.item_factors[curr_item]

                # MF 部分: <u, i>
                mf_score = np.dot(user_vec, curr_vec)

                # FMC 部分: <i_{t-1}, i_t>
                fmc_score = np.dot(prev_vec, curr_vec)

                # 总分
                score = mf_score + fmc_score

                # Sigmoid 损失
                prob = 1 / (1 + np.exp(-score))
                loss = -np.log(prob + 1e-10)
                total_loss += loss

                # 梯度
                grad = (prob - 1)

                # 更新参数
                self.user_factors[user_idx] -= self.learning_rate * (
                    grad * curr_vec + self.regularization * user_vec
                )
                self.item_factors[curr_item] -= self.learning_rate * (
                    grad * (user_vec + prev_vec) + self.regularization * curr_vec
                )
                self.prev_item_factors[prev_item] -= self.learning_rate * (
                    grad * curr_vec + self.regularization * prev_vec
                )

            if (epoch + 1) % 10 == 0:
                print(f"Epoch {epoch + 1}/{self.n_epochs}, Loss: {total_loss:.4f}")

    def predict(self, user_id, sequence, top_k=10):
        """
        预测

        参数:
            user_id: 用户ID
            sequence: 当前序列
            top_k: 返回数量

        返回:
            推荐物品列表
        """
        if user_id not in self.user_to_idx:
            # 冷启动用户
            return list(self.idx_to_item.values())[:top_k]

        user_idx = self.user_to_idx[user_id]
        user_vec = self.user_factors[user_idx]

        # 计算所有物品分数
        scores = np.zeros(self.item_factors.shape[0])

        for item_idx in range(self.item_factors.shape[0]):
            # MF 部分
            mf_score = np.dot(user_vec, self.item_factors[item_idx])

            # FMC 部分（使用最后一个物品）
            if sequence:
                prev_item = self.item_to_idx.get(sequence[-1])
                if prev_item is not None:
                    fmc_score = np.dot(
                        self.prev_item_factors[prev_item],
                        self.item_factors[item_idx]
                    )
                else:
                    fmc_score = 0
            else:
                fmc_score = 0

            scores[item_idx] = mf_score + fmc_score

        # 排序
        top_indices = np.argsort(scores)[::-1][:top_k]

        # 过滤已交互物品
        interacted = set(self.item_to_idx.get(i) for i in sequence)
        results = []
        for idx in top_indices:
            if idx not in interacted:
                results.append(self.idx_to_item[idx])
            if len(results) >= top_k:
                break

        return results
```

## 5. 评估方法

### 5.1 序列推荐评估指标

```python
import numpy as np
from typing import List, Dict

class SequenceEvaluator:
    """
    序列推荐评估器
    """

    def __init__(self, k_list=[1, 5, 10, 20]):
        """
        参数:
            k_list: 评估的 K 值列表
        """
        self.k_list = k_list

    def evaluate(self, predictions: List[Dict], ground_truth: List[str]):
        """
        评估

        参数:
            predictions: [{'user_id': x, 'sequence': [...], 'recs': [...]}, ...]
            ground_truth: 真实的下一个物品列表

        返回:
            指标字典
        """
        results = {
            'hit': {k: [] for k in self.k_list},
            'ndcg': {k: [] for k in self.k_list},
            'mrr': []
        }

        for pred, true_item in zip(predictions, ground_truth):
            recs = pred['recs']

            # MRR
            if true_item in recs:
                rank = recs.index(true_item) + 1
                results['mrr'].append(1.0 / rank)
            else:
                results['mrr'].append(0.0)

            # Hit@K 和 NDCG@K
            for k in self.k_list:
                top_k = recs[:k]
                if true_item in top_k:
                    results['hit'][k].append(1.0)
                    # NDCG
                    rank = top_k.index(true_item) + 1
                    dcg = 1.0 / np.log2(rank + 1)
                    idcg = 1.0  # 理想情况下排在第一位
                    results['ndcg'][k].append(dcg / idcg)
                else:
                    results['hit'][k].append(0.0)
                    results['ndcg'][k].append(0.0)

        # 计算平均值
        metrics = {
            'MRR': np.mean(results['mrr'])
        }
        for k in self.k_list:
            metrics[f'Hit@{k}'] = np.mean(results['hit'][k])
            metrics[f'NDCG@{k}'] = np.mean(results['ndcg'][k])

        return metrics

    def evaluate_sequence(self, model, test_sequences, top_k=10):
        """
        评估序列模型

        参数:
            model: 序列推荐模型
            test_sequences: {user_id: [item1, item2, ...]}
            top_k: 推荐 K 个物品

        返回:
            指标字典
        """
        predictions = []
        ground_truth = []

        for user_id, seq in test_sequences.items():
            # 使用前 n-1 个预测第 n 个
            input_seq = seq[:-1]
            target = seq[-1]

            # 获取推荐
            recs = model.predict(user_id, input_seq, top_k=top_k)

            predictions.append({
                'user_id': user_id,
                'sequence': input_seq,
                'recs': recs
            })
            ground_truth.append(target)

        return self.evaluate(predictions, ground_truth)


def leave_one_out_split(sequences, test_size=1):
    """
    Leave-one-out 划分

    参数:
        sequences: {user_id: [item1, item2, ...]}
        test_size: 测试集大小（从末尾取几个）

    返回:
        train_sequences, test_sequences
    """
    train_sequences = {}
    test_sequences = {}

    for user_id, seq in sequences.items():
        if len(seq) > test_size:
            train_sequences[user_id] = seq[:-test_size]
            test_sequences[user_id] = seq

    return train_sequences, test_sequences
```

```python
import numpy as np
from datetime import datetime

class TemporalFeatureExtractor:
    """
    时间特征提取器
    """

    def extract_features(self, timestamp):
        """
        提取时间特征

        参数:
            timestamp: Unix 时间戳

        返回:
            时间特征字典
        """
        dt = datetime.fromtimestamp(timestamp)

        return {
            'hour': dt.hour,
            'day_of_week': dt.weekday(),
            'is_weekend': dt.weekday() >= 5,
            'month': dt.month,
            'is_morning': 6 <= dt.hour < 12,
            'is_afternoon': 12 <= dt.hour < 18,
            'is_evening': 18 <= dt.hour < 24,
            'is_night': 0 <= dt.hour < 6
        }

    def extract_interval_features(self, timestamps):
        """
        提取时间间隔特征

        参数:
            timestamps: 时间戳列表

        返回:
            间隔特征列表
        """
        intervals = []
        for i in range(1, len(timestamps)):
            interval = timestamps[i] - timestamps[i - 1]
            intervals.append({
                'interval_seconds': interval,
                'interval_minutes': interval / 60,
                'interval_hours': interval / 3600,
                'interval_days': interval / 86400
            })
        return intervals
```

### 6.2 位置特征

```python
class PositionalEncoding:
    """
    位置编码
    """

    def __init__(self, d_model, max_len=5000):
        """
        参数:
            d_model: 嵌入维度
            max_len: 最大序列长度
        """
        self.d_model = d_model
        self.max_len = max_len

        # 预计算位置编码
        pe = np.zeros((max_len, d_model))
        position = np.arange(0, max_len)[:, np.newaxis]
        div_term = np.exp(np.arange(0, d_model, 2) * (-np.log(10000.0) / d_model))

        pe[:, 0::2] = np.sin(position * div_term)
        pe[:, 1::2] = np.cos(position * div_term)

        self.pe = pe

    def encode(self, x):
        """
        添加位置编码

        参数:
            x: (seq_len, d_model)

        返回:
            带位置编码的输入
        """
        seq_len = x.shape[0]
        return x + self.pe[:seq_len]
```

## 7. 学习总结

### 7.1 核心要点

1. **序列推荐考虑时间顺序**：传统推荐忽略时序，序列推荐显式建模
2. **马尔可夫假设是基础**：当前行为受之前行为影响
3. **深度学习大幅提升效果**：RNN、CNN、Transformer 都有应用

### 7.2 方法对比

| 方法 | 优点 | 缺点 |
|------|------|------|
| 马尔可夫链 | 简单、可解释 | 只考虑短程依赖 |
| FPMC | 结合个性化 | 仍是线性模型 |
| RNN | 处理变长序列 | 并行化困难 |
| Transformer | 并行计算、长依赖 | 计算量大 |

### 7.3 后续学习路径

```
序列推荐基础 → GRU4Rec → SASRec → BERT4Rec
```
