# 残差神经网络 学习文档

> 更深的网络 ≠ 更好的结果？残差连接打破深度瓶颈

---

## 1. 算法基础认知

### 1.1 什么是残差神经网络

**ResNet（Residual Network）** 由何恺明等人在2015年提出，核心创新是**跳跃连接（Skip Connection）**，让梯度可以直接在网络中"跳跃"传播，解决了深度网络的退化问题。

### 1.2 网络退化问题

```
实验发现（反直觉）:
- 56层网络比20层网络效果差
- 不是过拟合（训练集误差也高）
- 而是优化困难——更深的网络更难训练！

原因：梯度消失导致深层参数几乎不更新
```

### 1.3 残差学习的直觉

```
普通网络: 学习 H(x) = 目标映射
残差网络: 学习 F(x) = H(x) - x，即残差

如果恒等映射是最优的：
  普通网络需要学习 H(x) = x（很难）
  残差网络只需学习 F(x) = 0（把权重推向0即可，很容易！）
```

### 1.4 在推荐系统中的影响

ResNet 的跳跃连接思想深刻影响了推荐模型设计：
- **DIN/DIEN** 中的残差连接
- **Deep Crossing** 微软提出的残差推荐模型
- **特征交叉网络** 中的跨层连接

## 2. 核心原理

### 2.1 残差块

```
普通块:                残差块:
  x → [Conv] →          x ──────────────────┐
      [BN] →                 ↓              │
      [ReLU] →            [Conv]            │
      [Conv] →            [BN]              │
      [BN] →              [ReLU]            │
      [ReLU] → y          [Conv]            │
                          [BN] → (+) ←──────┘
                               [ReLU] → y
                               
输出: y = F(x) + x
```

### 2.2 数学表达

$$y = \mathcal{F}(x, \{W_i\}) + x$$

其中 $\mathcal{F}(x, \{W_i\})$ 是需要学习的残差映射。

**两层的残差块**：

$$\mathcal{F}(x) = W_2 \cdot \text{ReLU}(W_1 x + b_1) + b_2$$

**最终输出**：

$$y = \text{ReLU}(W_2 \cdot \text{ReLU}(W_1 x + b_1) + b_2 + x)$$

### 2.3 为什么残差连接有效

**梯度流分析**：

在反向传播中，残差连接提供了一个"梯度高速公路"：

$$\frac{\partial \mathcal{L}}{\partial x} = \frac{\partial \mathcal{L}}{\partial y} \cdot \frac{\partial y}{\partial x} = \frac{\partial \mathcal{L}}{\partial y} \cdot \left(\frac{\partial \mathcal{F}}{\partial x} + 1\right)$$

> 关键在于 **"+1"**：即使 $\frac{\partial \mathcal{F}}{\partial x}$ 很小（梯度消失），梯度仍然可以通过 "$+1$" 直接传回去。

### 2.4 瓶颈结构（Bottleneck）

```
Basic Block (18/34层):     Bottleneck (50/101/152层):
x → [3×3 Conv, 64]          x → [1×1 Conv, 64]    降维
    [3×3 Conv, 64]              [3×3 Conv, 64]    提取特征
    (+) ← x                     [1×1 Conv, 256]   升维
    (+) ← x                     (+) ← x

参数量更少，适合更深的网络
```

## 3. 数学公式与推导

### 3.1 前向传播

对于第 $l$ 个残差块：

$$y_l = \mathcal{F}(x_l, W_l) + x_l$$

$$x_{l+1} = \sigma(y_l)$$

### 3.2 梯度传播

$$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_{l+1}} \cdot \frac{\partial x_{l+1}}{\partial x_l}$$

$$= \frac{\partial \mathcal{L}}{\partial x_{l+1}} \cdot \left(\frac{\partial \mathcal{F}}{\partial x_l} + \mathbf{I}\right)$$

> $\mathbf{I}$ 是单位矩阵。即使 $\frac{\partial \mathcal{F}}{\partial x_l}$ 很小，$\frac{\partial \mathcal{L}}{\partial x_l}$ 仍然接近 $\frac{\partial \mathcal{L}}{\partial x_{l+1}}$。

### 3.3 多层梯度

堆叠 $L$ 个残差块：

$$\frac{\partial \mathcal{L}}{\partial x_0} = \frac{\partial \mathcal{L}}{\partial x_L} \cdot \prod_{l=0}^{L-1}\left(\frac{\partial \mathcal{F}_l}{\partial x_l} + \mathbf{I}\right)$$

> 每个因子中都有 $\mathbf{I}$，保证梯度不会消失到0。

## 6. 优缺点分析

### 6.1 优点

- **突破深度限制**：可以训练上百层的网络
- **梯度流通畅**：残差连接保证梯度传播
- **性能优异**：ImageNet冠军级表现
- **通用性强**：可嵌入任何网络结构

### 6.2 缺点

- **计算成本**：深层网络训练慢
- **内存占用**：需要保存中间激活值
- **不一定越深越好**：超过一定深度收益递减

## 7. 调库实现（PyTorch）

```python
"""
ResNet 实现
"""

import torch
import torch.nn as nn


class BasicBlock(nn.Module):
    """基本残差块（用于ResNet-18/34）"""
    expansion = 1
    
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        
        # 如果输入输出维度不匹配，用1×1卷积调整
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride, bias=False),
                nn.BatchNorm2d(out_channels)
            )
    
    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += self.shortcut(x)  # 残差连接
        out = torch.relu(out)
        return out


class ResNet(nn.Module):
    """ResNet 模型"""
    
    def __init__(self, block, num_blocks, num_classes=10):
        super().__init__()
        self.in_channels = 64
        
        self.conv1 = nn.Conv2d(1, 64, 3, 1, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(64)
        
        self.layer1 = self._make_layer(block, 64, num_blocks[0], 1)
        self.layer2 = self._make_layer(block, 128, num_blocks[1], 2)
        self.layer3 = self._make_layer(block, 256, num_blocks[2], 2)
        
        self.fc = nn.Linear(256 * 7 * 7, num_classes)
    
    def _make_layer(self, block, out_channels, num_blocks, stride):
        strides = [stride] + [1] * (num_blocks - 1)
        layers = []
        for s in strides:
            layers.append(block(self.in_channels, out_channels, s))
            self.in_channels = out_channels
        return nn.Sequential(*layers)
    
    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.layer1(out)
        out = self.layer2(out)
        out = self.layer3(out)
        out = out.view(out.size(0), -1)
        out = self.fc(out)
        return out


# 创建 ResNet-18
def ResNet18(num_classes=10):
    return ResNet(BasicBlock, [2, 2, 2, 2], num_classes)


if __name__ == "__main__":
    model = ResNet18(num_classes=10)
    x = torch.randn(2, 1, 28, 28)
    y = model(x)
    print(f"输入: {x.shape}")
    print(f"输出: {y.shape}")
    
    total_params = sum(p.numel() for p in model.parameters())
    print(f"参数量: {total_params:,}")
```

## 8. 手工代码实现

```python
"""
残差连接 —— 纯 NumPy 演示
对比有/无残差连接的梯度差异
"""

import numpy as np


def relu(x):
    return np.maximum(0, x)

def relu_derivative(x):
    return (x > 0).astype(float)


# 模拟5层网络，观察梯度
np.random.seed(42)
n_layers = 5
dim = 10

# 普通网络 vs 残差网络的梯度对比
x = np.random.randn(dim)
grad_output = np.random.randn(dim)  # 假设的输出梯度

print("=== 梯度传播对比（5层网络）===\n")

# 1. 普通网络
grad = grad_output.copy()
print("普通网络:")
for i in range(n_layers):
    W = np.random.randn(dim, dim) * 0.5  # 权重较小
    grad = grad @ W * relu_derivative(np.random.randn(dim))
    print(f"  第{i+1}层后梯度范数: {np.linalg.norm(grad):.6f}")

# 2. 残差网络
grad = grad_output.copy()
print("\n残差网络:")
for i in range(n_layers):
    W = np.random.randn(dim, dim) * 0.5
    z = np.random.randn(dim)
    # 残差: y = F(x) + x, ∂L/∂x = ∂L/∂y * (∂F/∂x + I)
    grad = grad @ W * relu_derivative(z) + grad  # +grad 就是跳跃连接的贡献
    print(f"  第{i+1}层后梯度范数: {np.linalg.norm(grad):.6f}")

print("\n结论: 残差连接让梯度保持较大，避免梯度消失！")
```

## 11. 常见问题与易错点

1. **维度不匹配**：残差连接要求 F(x) 和 x 维度相同，不同时需要用1×1卷积调整
2. **放置位置**：BatchNorm 应该在卷积之后、ReLU之前
3. **学习率设置**：ResNet通常用较大的初始学习率(0.1)，配合warmup

## 12. 学习总结

1. **残差连接 = F(x) + x**：让网络学习残差而非直接映射
2. **梯度高速公路**："+1"保证梯度不消失
3. **突破深度限制**：从几十层到上百层
4. **推荐系统应用**：Deep Crossing、特征交叉网络中的残差思想

## 13. 练习题与思考题

**Q1**：为什么残差网络中学习 F(x)=0 比普通网络学习 H(x)=x 更容易？

<details>
<summary>答案</summary>

在普通网络中，要实现恒等映射 H(x)=x，网络需要精确调整权重使 W₂σ(W₁x)=x，这是很困难的优化问题。

在残差网络中，要实现恒等映射只需 F(x)=0，即将权重初始化为接近0即可。推动权重趋向0（L2正则化的方向）本身就趋向恒等映射，这与正则化的目标一致，所以更容易优化。

</details>
