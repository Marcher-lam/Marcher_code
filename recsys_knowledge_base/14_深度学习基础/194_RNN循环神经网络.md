# RNN循环神经网络 学习文档

> 处理序列数据的基石——理解时间步展开与梯度消失

---

## 1. 算法基础认知

### 1.1 什么是RNN

**循环神经网络（Recurrent Neural Network, RNN）** 是处理序列数据的神经网络，通过隐藏状态在时间步之间传递信息，具有"记忆"能力。

```
FNN: x₁,x₂,...,xₙ → 网络 → y  (把序列展平，丢失顺序信息)
RNN: x₁ → h₁ → x₂ → h₂ → ... → hₙ → y  (逐步处理，保留顺序信息)
```

### 1.2 为什么需要RNN

| 数据类型 | FNN的问题 | RNN的解决方案 |
|---------|----------|-------------|
| 用户行为序列 | 无法建模顺序 | 按时间步处理 |
| 文本 | 无法理解上下文 | 隐藏状态保留上下文 |
| 时间序列 | 忽略时间依赖 | 循环连接建模时序 |

### 1.3 在推荐系统中的应用

RNN是**序列推荐**的基础：
- **GRU4Rec**：用RNN建模用户浏览序列
- **DIEN**：用GRU建模兴趣演化
- **Session推荐**：用RNN建模会话内行为

## 2. 核心原理

### 2.1 RNN结构

```
展开视图:
         h₀    h₁    h₂    h₃
          ↑     ↑     ↑     ↑
     ┌───┐ ┌───┐ ┌───┐ ┌───┐
     │RNN│ │RNN│ │RNN│ │RNN│  ← 同一组参数，不同时间步
     │Cell│ │Cell│ │Cell│ │Cell│
     └─┬─┘ └─┬─┘ └─┬─┘ └─┬─┘
       ↑     ↑     ↑     ↑
      x₁    x₂    x₃    x₄   ← 输入序列

hₜ = f(hₜ₋₁, xₜ)  ← 核心递推公式
```

### 2.2 核心公式

$$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)$$

$$y_t = W_{hy} h_t + b_y$$

- $W_{hh}$：隐藏状态到隐藏状态的权重
- $W_{xh}$：输入到隐藏状态的权重
- $W_{hy}$：隐藏状态到输出的权重
- $h_t$：时刻 $t$ 的隐藏状态（"记忆"）

### 2.3 多种输入输出模式

```
一对多: 图片描述生成     多对一: 情感分析        多对多: 序列标注
x → h₁→h₂→...→hₙ    x₁,x₂,...,xₙ→hₙ→y   x₁→h₁→y₁, x₂→h₂→y₂,...
       ↓↓...↓               ↑                    ↑↓  ↑↓
      y₁y₂...yₙ            y                   (NER,分词)
```

## 3. 数学公式与推导

### 3.1 前向传播

对于序列 $[x_1, x_2, ..., x_T]$：

$$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h) \quad t = 1, 2, ..., T$$

初始状态 $h_0$ 通常设为零向量。

### 3.2 BPTT（随时间反向传播）

将RNN按时间展开后，使用反向传播计算梯度。

损失函数：

$$L = \sum_{t=1}^{T} L_t(y_t, \hat{y}_t)$$

梯度计算：

$$\frac{\partial L}{\partial W_{hh}} = \sum_{t=1}^{T} \frac{\partial L_t}{\partial h_t} \cdot \frac{\partial h_t}{\partial W_{hh}}$$

其中 $\frac{\partial h_t}{\partial W_{hh}}$ 涉及递归展开：

$$\frac{\partial h_t}{\partial W_{hh}} = \frac{\partial h_t}{\partial h_{t-1}} \cdot \frac{\partial h_{t-1}}{\partial W_{hh}} + \frac{\partial h_t}{\partial W_{hh}}\bigg|_{\text{direct}}$$

展开后：

$$\frac{\partial L}{\partial h_k} = \frac{\partial L}{\partial h_T} \prod_{t=k+1}^{T} \frac{\partial h_t}{\partial h_{t-1}}$$

$$= \frac{\partial L}{\partial h_T} \prod_{t=k+1}^{T} \left( W_{hh}^T \cdot \text{diag}(\tanh'(z_t)) \right)$$

### 3.3 梯度消失/爆炸分析

$$\left\| \prod_{t=k+1}^{T} \frac{\partial h_t}{\partial h_{t-1}} \right\| \leq \prod_{t=k+1}^{T} \left\| W_{hh} \right\| \cdot \|\tanh'\|$$

- 如果 $\|W_{hh}\| < 1$：梯度指数衰减 → **梯度消失**
- 如果 $\|W_{hh}\| > 1$：梯度指数增长 → **梯度爆炸**

> $\tanh'$ 的最大值为1，所以关键在于 $\|W_{hh}\|$ 的大小。

## 4. 训练过程讲解

### 4.1 训练步骤

```
1. 输入序列 [x₁, x₂, ..., xₜ]
2. 逐步前向传播: h₁ → h₂ → ... → hₜ
3. 计算损失: L = Σ Lₜ
4. BPTT反向传播（可能截断到固定长度）
5. 梯度裁剪（防止梯度爆炸）
6. 参数更新
```

### 4.2 截断BPTT

```python
# 不是展开所有时间步，而是固定长度
truncation_length = 50  # 只回看50步

# 超过长度就截断，避免长距离梯度问题
```

## 6. 优缺点分析

| 优点 | 缺点 |
|------|------|
| 处理变长序列 | 梯度消失/爆炸 |
| 参数共享 | 长距离依赖困难 |
| 可以建模时序关系 | 无法并行计算 |
| 适合在线学习 | 训练较慢 |

## 7. 调库实现

```python
"""
RNN 完整实现 - PyTorch
"""

import torch
import torch.nn as nn
import numpy as np


class SimpleRNN(nn.Module):
    """简单RNN模型"""
    
    def __init__(self, input_size, hidden_size, output_size, num_layers=1):
        super().__init__()
        self.rnn = nn.RNN(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,
            dropout=0.1 if num_layers > 1 else 0
        )
        self.fc = nn.Linear(hidden_size, output_size)
    
    def forward(self, x):
        # x: (batch, seq_len, input_size)
        out, hidden = self.rnn(x)
        # 取最后一个时间步的输出
        out = self.fc(out[:, -1, :])
        return out


if __name__ == "__main__":
    np.random.seed(42)
    torch.manual_seed(42)
    
    # 模拟序列数据
    batch_size = 32
    seq_len = 10
    input_size = 8
    num_classes = 5
    
    X = torch.randn(batch_size, seq_len, input_size)
    y = torch.randint(0, num_classes, (batch_size,))
    
    model = SimpleRNN(input_size, hidden_size=64, output_size=num_classes)
    
    # 前向传播
    output = model(X)
    print(f"输入: {X.shape}")
    print(f"输出: {output.shape}")
    
    # 训练
    criterion = nn.CrossEntropyLoss()
    optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
    
    for epoch in range(50):
        output = model(X)
        loss = criterion(output, y)
        
        optimizer.zero_grad()
        loss.backward()
        
        # 梯度裁剪（防止梯度爆炸）
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=5.0)
        
        optimizer.step()
        
        if (epoch + 1) % 10 == 0:
            acc = (output.argmax(1) == y).float().mean()
            print(f"Epoch {epoch+1}: Loss={loss.item():.4f}, Acc={acc:.4f}")
```

## 8. 手工代码实现

```python
"""
RNN 纯 NumPy 手写实现
"""

import numpy as np


class RNNCell:
    """手写RNN单元"""
    
    def __init__(self, input_size, hidden_size):
        """初始化参数"""
        self.input_size = input_size
        self.hidden_size = hidden_size
        
        # Xavier初始化
        scale = np.sqrt(2.0 / (input_size + hidden_size))
        self.W_xh = np.random.randn(input_size, hidden_size) * scale
        self.W_hh = np.random.randn(hidden_size, hidden_size) * scale
        self.b_h = np.zeros((1, hidden_size))
    
    def forward(self, x, h_prev):
        """
        单步前向传播
        
        h_t = tanh(x_t @ W_xh + h_{t-1} @ W_hh + b_h)
        """
        h_t = np.tanh(x @ self.W_xh + h_prev @ self.W_hh + self.b_h)
        return h_t
    
    def forward_sequence(self, X):
        """
        处理整个序列
        
        X: (seq_len, input_size) 或 (batch, seq_len, input_size)
        返回: 所有隐藏状态
        """
        if X.ndim == 2:
            X = X[np.newaxis, :]  # 添加batch维度
        
        batch_size, seq_len, _ = X.shape
        h = np.zeros((batch_size, self.hidden_size))
        hidden_states = [h.copy()]
        
        for t in range(seq_len):
            h = self.forward(X[:, t, :], h)
            hidden_states.append(h.copy())
        
        return np.array(hidden_states[1:])  # (seq_len, batch, hidden)


if __name__ == "__main__":
    np.random.seed(42)
    
    rnn = RNNCell(input_size=4, hidden_size=8)
    
    # 模拟用户行为序列 (5个行为, 每个行为4维特征)
    sequence = np.random.randn(5, 4)
    
    hidden_states = rnn.forward_sequence(sequence)
    print(f"输入序列: {sequence.shape}")
    print(f"隐藏状态: {hidden_states.shape}")
    print(f"\n最终隐藏状态: {hidden_states[-1, 0]}")
    print("(这个向量编码了整个序列的信息)")
```

## 9-14. 总结与扩展

### 学习总结

1. **RNN核心**：$h_t = f(h_{t-1}, x_t)$，隐藏状态传递信息
2. **BPTT**：随时间反向传播计算梯度
3. **致命弱点**：梯度消失，难以学习长距离依赖
4. **解决方案**：LSTM、GRU、梯度裁剪

### 学习路径

```
RNN → LSTM/GRU（解决梯度消失）→ Attention（解决长距离依赖）→ Transformer
```
