# 反向传播算法 学习文档

> 理解神经网络如何学习——从链式法则到梯度计算

---

## 1. 算法基础认知

### 1.1 什么是反向传播

**反向传播（Backpropagation, BP）** 是训练神经网络的核心算法。它通过链式法则高效地计算损失函数对每个参数的梯度，从而实现参数优化。

```
前向传播: 输入 → 隐藏层 → 输出 → 损失    (计算预测值)
反向传播: 损失 → 输出层 → 隐藏层 → 输入    (计算梯度)
参数更新: 参数 = 参数 - 学习率 × 梯度       (优化参数)
```

### 1.2 为什么需要反向传播

| 问题 | 说明 |
|------|------|
| **参数量大** | 深度网络可能有数百万参数，逐个计算梯度不现实 |
| **参数共享** | 不同层参数的计算相互关联 |
| **计算效率** | 反向传播利用链式法则，避免重复计算 |

> **核心洞察**：反向传播的本质就是在计算图上利用链式法则高效计算梯度。

### 1.3 历史背景

- **1974年**：Werbos 提出反向传播算法
- **1986年**：Rumelhart, Hinton, Williams 重新推广，使神经网络训练变得可行
- **如今**：所有深度学习框架（PyTorch, TensorFlow）的核心自动微分机制

## 2. 核心原理

### 2.1 计算图视角

将神经网络看作一个有向无环图（DAG），每个节点是一个运算：

```
前向传播（自底向上）:
x → [×W₁] → [+b₁] → [σ] → [×W₂] → [+b₂] → [σ] → L

反向传播（自顶向下）:
∂L/∂x ← [∂W₁·] ← [1] ← [σ'] ← [∂W₂·] ← [1] ← [σ'] ← 1
```

### 2.2 链式法则

链式法则是反向传播的数学基础：

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial x}$$

对于复合函数 $y = f(g(x))$：

$$\frac{\partial y}{\partial x} = \frac{\partial y}{\partial g} \cdot \frac{\partial g}{\partial x}$$

### 2.3 两层网络的反向传播

考虑一个两层网络：

```
z₁ = W₁x + b₁       # 第一层线性变换
a₁ = σ(z₁)           # 第一层激活
z₂ = W₂a₁ + b₂       # 第二层线性变换
a₂ = σ(z₂)           # 输出（或softmax）
L = Loss(a₂, y)      # 损失函数
```

**反向传播的目标**：计算 $\frac{\partial L}{\partial W_1}$, $\frac{\partial L}{\partial b_1}$, $\frac{\partial L}{\partial W_2}$, $\frac{\partial L}{\partial b_2}$

**步骤**：

1. **输出层梯度**：
$$\delta_2 = \frac{\partial L}{\partial z_2} = \frac{\partial L}{\partial a_2} \odot \sigma'(z_2)$$

2. **第二层参数梯度**：
$$\frac{\partial L}{\partial W_2} = \delta_2 \cdot a_1^T$$
$$\frac{\partial L}{\partial b_2} = \delta_2$$

3. **传播到第一层**：
$$\delta_1 = (W_2^T \delta_2) \odot \sigma'(z_1)$$

4. **第一层参数梯度**：
$$\frac{\partial L}{\partial W_1} = \delta_1 \cdot x^T$$
$$\frac{\partial L}{\partial b_1} = \delta_1$$

## 3. 数学公式与推导

### 3.1 一般形式推导

对于 L 层网络，第 $l$ 层：

$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$$
$$a^{(l)} = \sigma(z^{(l)})$$

**定义误差项**：

$$\delta^{(l)} = \frac{\partial L}{\partial z^{(l)}}$$

**输出层（第 L 层）**：

对于交叉熵损失 + Softmax 输出：

$$\delta^{(L)} = a^{(L)} - y$$

> 这是一个优美的结果！Softmax + 交叉熵的组合使得输出层梯度极其简洁。

**隐藏层（第 l 层，l < L）**：

$$\delta^{(l)} = (W^{(l+1)})^T \delta^{(l+1)} \odot \sigma'(z^{(l)})$$

> $\odot$ 是 Hadamard 乘积（逐元素相乘）。

**参数梯度**：

$$\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^T$$

$$\frac{\partial L}{\partial b^{(l)}} = \delta^{(l)}$$

### 3.2 常用激活函数的导数

| 激活函数 | σ(z) | σ'(z) |
|---------|------|-------|
| Sigmoid | $\frac{1}{1+e^{-z}}$ | $\sigma(z)(1-\sigma(z))$ |
| Tanh | $\frac{e^z-e^{-z}}{e^z+e^{-z}}$ | $1-\tanh^2(z)$ |
| ReLU | $\max(0,z)$ | $\begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}$ |
| LeakyReLU | $\max(\alpha z, z)$ | $\begin{cases} 1 & z > 0 \\ \alpha & z \leq 0 \end{cases}$ |

### 3.3 完整数值示例

2层网络，2个输入，2个隐藏神经元，1个输出：

```
输入: x = [0.5, 0.3]
目标: y = 1

W₁ = [[0.1, 0.2],    b₁ = [0.0, 0.0]
      [0.3, 0.4]]

W₂ = [[0.5],         b₂ = [0.0]
      [0.6]]

激活: Sigmoid
损失: MSE
```

**Step 1: 前向传播**

$$z_1 = W_1 x + b_1 = \begin{pmatrix} 0.1 & 0.2 \\ 0.3 & 0.4 \end{pmatrix} \begin{pmatrix} 0.5 \\ 0.3 \end{pmatrix} = \begin{pmatrix} 0.11 \\ 0.27 \end{pmatrix}$$

$$a_1 = \sigma(z_1) = \begin{pmatrix} 0.5275 \\ 0.5671 \end{pmatrix}$$

$$z_2 = W_2 a_1 + b_2 = \begin{pmatrix} 0.5 \\ 0.6 \end{pmatrix}^T \begin{pmatrix} 0.5275 \\ 0.5671 \end{pmatrix} = 0.5950$$

$$a_2 = \sigma(0.5950) = 0.6443$$

$$L = \frac{1}{2}(1 - 0.6443)^2 = 0.0633$$

**Step 2: 反向传播**

输出层误差：
$$\delta_2 = (a_2 - y) \cdot \sigma'(z_2) = (0.6443 - 1) \times 0.6443 \times (1-0.6443) = -0.0816$$

隐藏层误差：
$$\delta_1 = (W_2^T \delta_2) \odot \sigma'(z_1)$$

$$= \begin{pmatrix} 0.5 \\ 0.6 \end{pmatrix} \times (-0.0816) \odot \begin{pmatrix} 0.5275 \times 0.4725 \\ 0.5671 \times 0.4329 \end{pmatrix}$$

$$= \begin{pmatrix} -0.0408 \\ -0.0490 \end{pmatrix} \odot \begin{pmatrix} 0.2492 \\ 0.2455 \end{pmatrix} = \begin{pmatrix} -0.0102 \\ -0.0120 \end{pmatrix}$$

**Step 3: 计算梯度**

$$\frac{\partial L}{\partial W_2} = \delta_2 \cdot a_1^T = -0.0816 \times \begin{pmatrix} 0.5275 \\ 0.5671 \end{pmatrix}^T = \begin{pmatrix} -0.0430 \\ -0.0463 \end{pmatrix}^T$$

$$\frac{\partial L}{\partial W_1} = \delta_1 \cdot x^T = \begin{pmatrix} -0.0102 \\ -0.0120 \end{pmatrix} \begin{pmatrix} 0.5 \\ 0.3 \end{pmatrix}^T = \begin{pmatrix} -0.0051 & -0.0031 \\ -0.0060 & -0.0036 \end{pmatrix}$$

**Step 4: 参数更新（lr=0.5）**

$$W_1 \leftarrow W_1 - 0.5 \times \frac{\partial L}{\partial W_1} = \begin{pmatrix} 0.1026 & 0.2016 \\ 0.3030 & 0.4018 \end{pmatrix}$$

## 4. 训练过程讲解

### 4.1 完整训练流水线

```python
# 伪代码：完整的训练循环
for epoch in range(num_epochs):
    for batch in dataloader:
        # 1. 前向传播
        output = model(batch.x)
        
        # 2. 计算损失
        loss = criterion(output, batch.y)
        
        # 3. 反向传播（计算梯度）
        optimizer.zero_grad()  # 清零旧梯度
        loss.backward()        # 反向传播计算新梯度
        
        # 4. 参数更新
        optimizer.step()       # 用梯度更新参数
```

### 4.2 BPTT（随时间反向传播）

对于RNN等序列模型，需要将网络按时间步展开：

```
h₀ → h₁ → h₂ → h₃ → ... → hₜ
↑     ↑     ↑     ↑           ↑
x₁    x₂    x₃    x₄         xₜ
```

梯度需要沿时间维度反向传播，这可能导致**梯度消失**或**梯度爆炸**。

### 4.3 梯度累积

```python
# 小批量无法放入内存时的技巧
optimizer.zero_grad()
for i, (x, y) in enumerate(dataloader):
    loss = criterion(model(x), y) / accumulation_steps
    loss.backward()  # 梯度累积
    if (i + 1) % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
```

## 6. 优缺点分析

### 6.1 优点

- **高效**：利用链式法则避免重复计算，复杂度 O(V+E)（V=节点数，E=边数）
- **通用**：适用于任意可微的计算图
- **自动**：现代框架自动实现，无需手写梯度

### 6.2 缺点

- **梯度消失**：深层网络中梯度可能逐层衰减至0
- **梯度爆炸**：梯度可能逐层放大至无穷
- **局部最优**：梯度下降可能陷入局部最小值或鞍点
- **内存开销**：需要存储前向传播的中间值用于反向计算

## 7. 调库实现（PyTorch Autograd）

```python
"""
反向传播演示：PyTorch Autograd
对比自动微分与手动梯度计算
"""

import torch
import torch.nn as nn
import torch.optim as optim


def demonstrate_autograd():
    """演示 PyTorch 自动微分"""
    print("=== PyTorch Autograd 演示 ===\n")
    
    # 创建计算图
    x = torch.tensor(2.0, requires_grad=True)
    
    # 前向计算
    y = x ** 2        # y = x²
    z = 3 * y + x     # z = 3x² + x
    loss = z.sum()     # 标量损失
    
    print(f"x = {x.item()}")
    print(f"y = x² = {y.item()}")
    print(f"z = 3y + x = {z.item()}")
    print(f"loss = {loss.item()}")
    
    # 反向传播
    loss.backward()
    
    # dz/dx = 6x + 1, 当 x=2 时, dz/dx = 13
    print(f"\n自动计算的梯度 dz/dx = {x.grad.item()}")
    print(f"手动计算的梯度 dz/dx = {6 * 2 + 1} (6x+1, x=2)")


def demonstrate_training():
    """演示完整训练过程中的反向传播"""
    print("\n\n=== 完整训练过程演示 ===\n")
    
    # 简单的2层网络
    model = nn.Sequential(
        nn.Linear(2, 4),
        nn.ReLU(),
        nn.Linear(4, 1),
        nn.Sigmoid()
    )
    
    # 数据
    X = torch.randn(100, 2)
    y = (X[:, 0] + X[:, 1] > 0).float().unsqueeze(1)
    
    criterion = nn.BCELoss()
    optimizer = optim.SGD(model.parameters(), lr=0.1)
    
    # 训练
    for epoch in range(100):
        # 前向传播
        output = model(X)
        loss = criterion(output, y)
        
        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        
        # 查看梯度（每20轮）
        if epoch % 20 == 0:
            for name, param in model.named_parameters():
                if param.grad is not None:
                    print(f"Epoch {epoch:3d} | {name:20s} | "
                          f"grad_norm: {param.grad.norm().item():.6f}")
        
        # 参数更新
        optimizer.step()
    
    print(f"\n最终损失: {loss.item():.4f}")


def gradient_checking():
    """数值梯度检查：验证反向传播的正确性"""
    print("\n\n=== 梯度检查 ===\n")
    
    model = nn.Sequential(
        nn.Linear(3, 4),
        nn.Tanh(),
        nn.Linear(4, 2)
    )
    
    x = torch.randn(1, 3)
    y = torch.tensor([1])
    
    criterion = nn.CrossEntropyLoss()
    
    # 计算解析梯度（反向传播）
    output = model(x)
    loss = criterion(output, y)
    
    model.zero_grad()
    loss.backward()
    
    # 数值梯度检查
    eps = 1e-4
    print(f"损失值: {loss.item():.6f}\n")
    
    for name, param in model.named_parameters():
        analytical_grad = param.grad.clone()
        numerical_grad = torch.zeros_like(param)
        
        for i in range(param.numel()):
            # +ε
            param_flat = param.view(-1)
            original = param_flat[i].item()
            param_flat[i] = original + eps
            
            output_plus = model(x)
            loss_plus = criterion(output_plus, y)
            
            # -ε
            param_flat[i] = original - eps
            output_minus = model(x)
            loss_minus = criterion(output_minus, y)
            
            # 恢复
            param_flat[i] = original
            
            # 数值梯度
            numerical_grad.view(-1)[i] = (loss_plus.item() - loss_minus.item()) / (2 * eps)
        
        # 比较解析梯度和数值梯度
        diff = (analytical_grad - numerical_grad).norm() / (analytical_grad.norm() + numerical_grad.norm() + 1e-8)
        status = "✅ 通过" if diff < 1e-5 else "❌ 不匹配"
        print(f"{name:20s}: 相对误差 = {diff:.2e} {status}")


if __name__ == "__main__":
    demonstrate_autograd()
    demonstrate_training()
    gradient_checking()
```

## 8. 手工代码实现

```python
"""
反向传播算法 —— 纯 NumPy 手写实现
2层网络的完整反向传播过程
"""

import numpy as np


class TwoLayerNet:
    """手写两层神经网络，完整实现反向传播"""
    
    def __init__(self, input_size, hidden_size, output_size):
        """
        初始化权重（He初始化）
        """
        self.W1 = np.random.randn(input_size, hidden_size) * np.sqrt(2.0 / input_size)
        self.b1 = np.zeros((1, hidden_size))
        self.W2 = np.random.randn(hidden_size, output_size) * np.sqrt(2.0 / hidden_size)
        self.b2 = np.zeros((1, output_size))
    
    def relu(self, z):
        """ReLU激活函数"""
        return np.maximum(0, z)
    
    def relu_derivative(self, z):
        """ReLU导数"""
        return (z > 0).astype(float)
    
    def softmax(self, z):
        """数值稳定的Softmax"""
        exp_z = np.exp(z - np.max(z, axis=1, keepdims=True))
        return exp_z / np.sum(exp_z, axis=1, keepdims=True)
    
    def forward(self, X):
        """
        前向传播，保存中间值用于反向传播
        
        返回: (输出概率, 缓存字典)
        """
        # 第一层
        z1 = X @ self.W1 + self.b1           # 线性变换
        a1 = self.relu(z1)                    # ReLU激活
        
        # 第二层
        z2 = a1 @ self.W2 + self.b2           # 线性变换
        a2 = self.softmax(z2)                 # Softmax输出
        
        cache = {'X': X, 'z1': z1, 'a1': a1, 'z2': z2, 'a2': a2}
        return a2, cache
    
    def backward(self, cache, y):
        """
        反向传播算法
        
        参数:
            cache: 前向传播的缓存
            y: 真实标签 (batch_size,)
        
        返回: 各参数的梯度
        """
        batch_size = y.shape[0]
        
        # One-hot编码
        y_onehot = np.zeros_like(cache['a2'])
        y_onehot[np.arange(batch_size), y] = 1
        
        # ============ 输出层梯度 ============
        # Softmax + 交叉熵 的简化梯度
        # ∂L/∂z₂ = a₂ - y
        dz2 = cache['a2'] - y_onehot                          # (batch, output)
        
        # ∂L/∂W₂ = a₁ᵀ · δ₂ / batch
        dW2 = cache['a1'].T @ dz2 / batch_size                # (hidden, output)
        
        # ∂L/∂b₂ = Σ δ₂ / batch
        db2 = np.sum(dz2, axis=0, keepdims=True) / batch_size  # (1, output)
        
        # ============ 隐藏层梯度 ============
        # ∂L/∂a₁ = δ₂ · W₂ᵀ
        da1 = dz2 @ self.W2.T                                  # (batch, hidden)
        
        # ∂L/∂z₁ = ∂L/∂a₁ ⊙ σ'(z₁)
        dz1 = da1 * self.relu_derivative(cache['z1'])          # (batch, hidden)
        
        # ∂L/∂W₁ = Xᵀ · δ₁ / batch
        dW1 = cache['X'].T @ dz1 / batch_size                  # (input, hidden)
        
        # ∂L/∂b₁ = Σ δ₁ / batch
        db1 = np.sum(dz1, axis=0, keepdims=True) / batch_size  # (1, hidden)
        
        return {'W1': dW1, 'b1': db1, 'W2': dW2, 'b2': db2}
    
    def compute_loss(self, y_pred, y_true):
        """交叉熵损失"""
        batch_size = y_true.shape[0]
        y_onehot = np.zeros_like(y_pred)
        y_onehot[np.arange(batch_size), y_true] = 1
        return -np.sum(y_onehot * np.log(y_pred + 1e-8)) / batch_size
    
    def train(self, X, y, epochs=100, lr=0.01, batch_size=32):
        """训练"""
        n = X.shape[0]
        
        for epoch in range(epochs):
            indices = np.random.permutation(n)
            epoch_loss = 0
            
            for start in range(0, n, batch_size):
                idx = indices[start:start+batch_size]
                X_batch, y_batch = X[idx], y[idx]
                
                # 前向传播
                output, cache = self.forward(X_batch)
                loss = self.compute_loss(output, y_batch)
                epoch_loss += loss * len(idx)
                
                # 反向传播
                grads = self.backward(cache, y_batch)
                
                # 参数更新
                self.W1 -= lr * grads['W1']
                self.b1 -= lr * grads['b1']
                self.W2 -= lr * grads['W2']
                self.b2 -= lr * grads['b2']
            
            if (epoch + 1) % 20 == 0:
                avg_loss = epoch_loss / n
                acc = self.score(X, y)
                print(f"Epoch {epoch+1:4d}: Loss={avg_loss:.4f}, Acc={acc:.4f}")
    
    def predict(self, X):
        output, _ = self.forward(X)
        return np.argmax(output, axis=1)
    
    def score(self, X, y):
        return np.mean(self.predict(X) == y)


# 运行
if __name__ == "__main__":
    from sklearn.datasets import make_classification
    from sklearn.model_selection import train_test_split
    
    X, y = make_classification(n_samples=2000, n_features=10, n_classes=3,
                               n_informative=6, random_state=42)
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
    
    net = TwoLayerNet(10, 32, 3)
    net.train(X_train, y_train, epochs=100, lr=0.05)
    
    print(f"\n训练准确率: {net.score(X_train, y_train):.4f}")
    print(f"测试准确率: {net.score(X_test, y_test):.4f}")
```

## 9. 可视化与结果理解

### 9.1 梯度流动示意

```
正常梯度流动:
∂L/∂W₃ ← ∂L/∂W₂ ← ∂L/∂W₁    梯度逐层传递，幅度稳定

梯度消失:
∂L/∂W₃ ← (∂L/∂W₂ × 0.1) ← (∂L/∂W₁ × 0.01) ← 接近0
      ↑ 正常              ↑ 很小           ↑ 几乎为0

梯度爆炸:
∂L/∂W₃ ← (∂L/∂W₂ × 10) ← (∂L/∂W₁ × 100) ← ∞
      ↑ 正常             ↑ 很大           ↑ 爆炸
```

### 9.2 学习率对训练的影响

```
学习率太小:              学习率合适:            学习率太大:
Loss ↑                   Loss ↑                Loss ↑
      │\                       │\                    │/\/\/\/\ 
      │ \                      │ \                   │  振荡！
```

## 11. 常见问题与易错点

### 11.1 忘记 zero_grad

```python
# ❌ 错误：梯度会累积
for x, y in dataloader:
    loss = criterion(model(x), y)
    loss.backward()  # 梯度累积！
    optimizer.step()

# ✅ 正确：每次迭代前清零
for x, y in dataloader:
    optimizer.zero_grad()  # 清零旧梯度
    loss = criterion(model(x), y)
    loss.backward()
    optimizer.step()
```

### 11.2 梯度裁剪

```python
# 防止梯度爆炸的常用方法
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

## 13. 练习题与思考题

**Q1**：为什么 Softmax + 交叉熵的组合能简化梯度计算？

<details>
<summary>答案</summary>

交叉熵损失：$L = -\sum_i y_i \log(\hat{y}_i)$

Softmax：$\hat{y}_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$

对 $z_k$ 求导：

$$\frac{\partial L}{\partial z_k} = \hat{y}_k - y_k$$

推导过程中，分母的求和项在分子分母中抵消，最终结果非常简洁。这个性质使得深度学习框架几乎总是使用这个组合。

</details>

**Q2**：如果一个3层网络的激活函数全部是线性的（σ(x)=x），反向传播的结果是什么？

<details>
<summary>答案</summary>

如果所有激活函数都是线性的，整个网络等价于一个单层线性变换。因为：

$$a^{(1)} = W_1 x, \quad a^{(2)} = W_2 W_1 x, \quad a^{(3)} = W_3 W_2 W_1 x = \tilde{W} x$$

所有参数的梯度会被"压缩"成等价于单层网络的梯度，多层结构失去意义。这就是为什么**非线性激活函数是必不可少的**。

</details>
