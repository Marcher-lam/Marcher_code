# GRU 学习文档

> LSTM的简化版——更少的参数，相当的效果

---

## 1. 算法基础认知

### 1.1 什么是GRU

**GRU（Gated Recurrent Unit）** 是2014年提出的RNN变体，将LSTM的三个门简化为两个门（重置门和更新门），参数更少，训练更快。

### 1.2 LSTM vs GRU

```
LSTM: 3个门（遗忘门、输入门、输出门）+ 细胞状态
GRU:  2个门（重置门、更新门）        + 无独立细胞状态

GRU更简单，但在多数任务上效果与LSTM相当
```

### 1.3 在推荐系统中的应用

- **GRU4Rec**：最早将GRU用于序列推荐
- **DIEN**：阿里深度兴趣演化网络，用GRU建模兴趣变化
- **会话推荐**：基于GRU的会话行为预测

---

## 2. 核心原理

### 2.1 GRU结构

```
hₜ₋₁ ──→ [更新门zₜ] ──→ (1-zₜ)·hₜ₋₁ + zₜ·h̃ₜ ──→ hₜ
          [重置门rₜ] ──→ 控制候选状态计算
                ↑
               xₜ
```

### 2.2 两个门

| 门 | 公式 | 作用 |
|----|------|------|
| **重置门** rₜ | σ(Wᵣ·[hₜ₋₁, xₜ]) | 控制候选状态中保留多少旧信息 |
| **更新门** zₜ | σ(W_z·[hₜ₋₁, xₜ]) | 控制新旧信息的混合比例 |

---

## 3. 数学公式与推导

### 3.1 完整公式

**更新门**：

$$z_t = \sigma(W_z \cdot [h_{t-1}, x_t] + b_z)$$

**重置门**：

$$r_t = \sigma(W_r \cdot [h_{t-1}, x_t] + b_r)$$

**候选隐藏状态**：

$$\tilde{h}_t = \tanh(W \cdot [r_t \odot h_{t-1}, x_t] + b)$$

**最终隐藏状态**：

$$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$

### 3.2 与LSTM的关系

| | LSTM | GRU |
|--|------|-----|
| 门数量 | 3（遗忘+输入+输出） | 2（重置+更新） |
| 状态 | h + C | 只有h |
| 遗忘/记忆 | fₜ和iₜ分开控制 | zₜ统一控制 |
| 参数量 | 4h(h+d+1) | 3h(h+d+1) |

> GRU的更新门 $z_t$ 同时承担了LSTM中遗忘门和输入门的功能。

### 3.3 梯度传播

$$\frac{\partial h_t}{\partial h_{t-1}} = (1-z_t) + z_t \cdot \frac{\partial \tilde{h}_t}{\partial h_{t-1}}$$

当 $z_t ≈ 0$ 时，$h_t ≈ h_{t-1}$，梯度直接传递（类似LSTM的细胞状态）。

## 7. 调库实现

```python
import torch
import torch.nn as nn


class GRUModel(nn.Module):
    """GRU序列模型"""
    
    def __init__(self, input_size, hidden_size, num_classes, num_layers=2):
        super().__init__()
        self.gru = nn.GRU(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,
            dropout=0.2
        )
        self.fc = nn.Linear(hidden_size, num_classes)
    
    def forward(self, x):
        gru_out, h_n = self.gru(x)
        out = self.fc(gru_out[:, -1, :])
        return out


# GRU4Rec 简化版
class GRU4Rec(nn.Module):
    """
    GRU4Rec: 基于GRU的序列推荐模型
    
    输入: 用户历史点击序列 [item₁, item₂, ..., itemₜ]
    输出: 每个位置对候选集的概率分布
    """
    
    def __init__(self, num_items, embed_dim, hidden_size):
        super().__init__()
        self.item_embedding = nn.Embedding(num_items, embed_dim)
        self.gru = nn.GRU(embed_dim, hidden_size, batch_first=True)
        self.output_layer = nn.Linear(hidden_size, num_items)
    
    def forward(self, item_seq):
        # item_seq: (batch, seq_len) 物品ID序列
        embeds = self.item_embedding(item_seq)  # (batch, seq_len, embed_dim)
        gru_out, _ = self.gru(embeds)            # (batch, seq_len, hidden)
        logits = self.output_layer(gru_out)       # (batch, seq_len, num_items)
        return logits


if __name__ == "__main__":
    torch.manual_seed(42)
    
    # 基本GRU
    model = GRUModel(input_size=32, hidden_size=64, num_classes=5)
    x = torch.randn(16, 10, 32)
    print(f"基本GRU: {x.shape} → {model(x).shape}")
    
    # GRU4Rec
    rec_model = GRU4Rec(num_items=1000, embed_dim=32, hidden_size=64)
    item_seq = torch.randint(0, 1000, (16, 10))
    logits = rec_model(item_seq)
    print(f"GRU4Rec: 序列{item_seq.shape} → logits{logits.shape}")
```

## 8. 手工代码实现

```python
"""GRU Cell 纯 NumPy 实现"""
import numpy as np

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-np.clip(x, -500, 500)))

class GRUCell:
    def __init__(self, input_size, hidden_size):
        self.input_size = input_size
        self.hidden_size = hidden_size
        concat_size = hidden_size + input_size
        
        # 更新门
        self.W_z = np.random.randn(concat_size, hidden_size) * 0.1
        self.b_z = np.zeros((1, hidden_size))
        # 重置门
        self.W_r = np.random.randn(concat_size, hidden_size) * 0.1
        self.b_r = np.zeros((1, hidden_size))
        # 候选状态
        self.W_h = np.random.randn(concat_size, hidden_size) * 0.1
        self.b_h = np.zeros((1, hidden_size))
    
    def forward(self, x_t, h_prev):
        concat = np.concatenate([h_prev, x_t], axis=1)
        
        # 更新门
        z_t = sigmoid(concat @ self.W_z + self.b_z)
        # 重置门
        r_t = sigmoid(concat @ self.W_r + self.b_r)
        # 候选隐藏状态
        concat_r = np.concatenate([r_t * h_prev, x_t], axis=1)
        h_hat_t = np.tanh(concat_r @ self.W_h + self.b_h)
        # 最终隐藏状态
        h_t = (1 - z_t) * h_prev + z_t * h_hat_t
        
        return h_t

if __name__ == "__main__":
    gru = GRUCell(8, 16)
    h = np.zeros((1, 16))
    for t in range(5):
        x_t = np.random.randn(1, 8)
        h = gru.forward(x_t, h)
        print(f"Step {t+1}: h_norm = {np.linalg.norm(h):.4f}")
```

## 12. 学习总结

1. **GRU = LSTM简化版**：2个门替代3个门，无独立细胞状态
2. **更新门zₜ**：统一控制遗忘和记忆，$h_t = (1-z_t)h_{t-1} + z_t\tilde{h}_t$
3. **参数更少**：比LSTM少约25%参数，训练更快
4. **效果相当**：大多数任务上与LSTM性能接近
5. **推荐首选**：序列推荐常用GRU（GRU4Rec, DIEN）
