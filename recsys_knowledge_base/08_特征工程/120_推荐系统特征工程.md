# 推荐系统特征工程 学习文档

## 1. 基础认知

### 1.1 什么是特征工程？

特征工程是将原始数据转换为机器学习模型可以理解和利用的特征的过程。在推荐系统中，特征工程直接影响模型效果。

**名言：**
> "特征工程决定了模型的上限，算法只是逼近这个上限。"

### 1.2 推荐系统中的特征类型

```
特征类型
├── 用户特征 (User Features)
│   ├── ID 特征
│   ├── 统计特征
│   ├── 行为特征
│   └── 画像特征
├── 物品特征 (Item Features)
│   ├── ID 特征
│   ├── 内容特征
│   ├── 统计特征
│   └── Embedding 特征
├── 上下文特征 (Context Features)
│   ├── 时间特征
│   ├── 位置特征
│   └── 设备特征
└── 交叉特征 (Cross Features)
    ├── 用户-物品交叉
    ├── 用户-上下文交叉
    └── 物品-上下文交叉
```

### 1.3 特征工程的重要性

| 方面 | 影响 |
|------|------|
| 模型效果 | 好的特征可以显著提升 AUC |
| 模型效率 | 好的特征可以减少模型复杂度 |
| 可解释性 | 好的特征更容易解释模型决策 |
| 泛化能力 | 好的特征可以提高模型泛化 |

```python
def create_sequence_features(user_history, max_len=50):
    """
    创建行为序列特征
    """
    # 最近点击的物品 ID 序列
    item_sequence = user_history['clicked_items'][-max_len:]

    # 序列长度
    seq_length = len(item_sequence)

    # 序列统计
    seq_unique = len(set(item_sequence))
    seq_repeat_ratio = (seq_length - seq_unique) / seq_length if seq_length > 0 else 0

    # 时间特征
    click_timestamps = user_history['click_timestamps'][-max_len:]
    if len(click_timestamps) > 1:
        time_intervals = np.diff(click_timestamps)
        avg_interval = np.mean(time_intervals)
        interval_std = np.std(time_intervals)
    else:
        avg_interval = 0
        interval_std = 0

    return {
        'item_sequence': item_sequence,
        'seq_length': seq_length,
        'seq_unique': seq_unique,
        'seq_repeat_ratio': seq_repeat_ratio,
        'avg_click_interval': avg_interval,
        'click_interval_std': interval_std
    }
```

## 6. 特征处理技术

### 6.1 类别特征处理

```python
from sklearn.preprocessing import LabelEncoder, OneHotEncoder
import numpy as np

class CategoryFeatureProcessor:
    """类别特征处理器"""

    def __init__(self, min_freq=10, embedding_dim=16):
        self.min_freq = min_freq
        self.embedding_dim = embedding_dim
        self.encoders = {}
        self.vocab_sizes = {}

    def fit(self, df, columns):
        """拟合编码器"""
        for col in columns:
            # 统计频率
            value_counts = df[col].value_counts()

            # 低频类别归为 'others'
            rare_values = value_counts[value_counts < self.min_freq].index

            # 创建映射
            unique_values = ['<UNK>'] + sorted(
                set(df[col].unique()) - set(rare_values)
            )
            self.encoders[col] = {v: i for i, v in enumerate(unique_values)}
            self.vocab_sizes[col] = len(unique_values)

        return self

    def transform(self, df, columns):
        """转换特征"""
        result = {}
        for col in columns:
            # 映射到索引
            mapped = df[col].map(self.encoders[col])
            mapped = mapped.fillna(0)  # 未知类别映射到 <UNK>
            result[col] = mapped.astype(int).values

        return result

    def get_embedding_config(self):
        """获取 Embedding 配置"""
        return {
            col: {'vocab_size': size, 'embed_dim': self.embedding_dim}
            for col, size in self.vocab_sizes.items()
        }
```

### 6.2 数值特征处理

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler
import numpy as np

class NumericFeatureProcessor:
    """数值特征处理器"""

    def __init__(self, method='standard'):
        """
        参数:
            method: 'standard' (标准化), 'minmax' (归一化), 'log' (对数)
        """
        self.method = method
        self.scalers = {}

    def fit(self, df, columns):
        """拟合"""
        for col in columns:
            if self.method == 'standard':
                scaler = StandardScaler()
            elif self.method == 'minmax':
                scaler = MinMaxScaler()
            else:
                scaler = None

            if scaler:
                scaler.fit(df[[col]])
                self.scalers[col] = scaler

        return self

    def transform(self, df, columns):
        """转换"""
        result = {}
        for col in columns:
            if col in self.scalers:
                result[col] = self.scalers[col].transform(df[[col]]).flatten()
            elif self.method == 'log':
                result[col] = np.log1p(df[col].values)
            else:
                result[col] = df[col].values

        return result

    def binning(self, values, n_bins=10, method='quantile'):
        """分桶"""
        if method == 'quantile':
            bins = np.quantile(values, np.linspace(0, 1, n_bins + 1))
        else:
            bins = np.linspace(values.min(), values.max(), n_bins + 1)

        return np.digitize(values, bins[1:-1])
```

### 6.3 序列特征处理

```python
class SequenceFeatureProcessor:
    """序列特征处理器"""

    def __init__(self, max_len=50, padding_value=0):
        self.max_len = max_len
        self.padding_value = padding_value

    def pad_sequence(self, sequence):
        """填充/截断序列"""
        if len(sequence) >= self.max_len:
            return sequence[-self.max_len:]
        else:
            return sequence + [self.padding_value] * (self.max_len - len(sequence))

    def create_mask(self, sequence):
        """创建 mask（标记有效位置）"""
        return [1 if x != self.padding_value else 0 for x in sequence]

    def process(self, sequences):
        """批量处理"""
        padded = [self.pad_sequence(seq) for seq in sequences]
        masks = [self.create_mask(seq) for seq in padded]

        return np.array(padded), np.array(masks)
```

## 8. 特征管道

### 8.1 完整的特征管道

```python
import pandas as pd
import numpy as np
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer

class FeaturePipeline:
    """完整的特征处理管道"""

    def __init__(self):
        self.cat_processor = None
        self.num_processor = None
        self.seq_processor = None

        self.cat_columns = []
        self.num_columns = []

    def fit(self, data):
        """
        拟合特征处理器

        参数:
            data: dict, 包含 'user', 'item', 'context' 等
        """
        # 识别特征类型
        self._identify_feature_types(data)

        # 初始化处理器
        if self.cat_columns:
            self.cat_processor = CategoryFeatureProcessor(min_freq=10)
            self.cat_processor.fit(data['df'], self.cat_columns)

        if self.num_columns:
            self.num_processor = NumericFeatureProcessor(method='standard')
            self.num_processor.fit(data['df'], self.num_columns)

        return self

    def transform(self, data):
        """
        转换特征
        """
        features = {}

        # 类别特征
        if self.cat_processor:
            cat_features = self.cat_processor.transform(data['df'], self.cat_columns)
            features.update(cat_features)

        # 数值特征
        if self.num_processor:
            num_features = self.num_processor.transform(data['df'], self.num_columns)
            features.update(num_features)

        return features

    def _identify_feature_types(self, data):
        """识别特征类型"""
        df = data['df']

        for col in df.columns:
            if df[col].dtype == 'object' or df[col].dtype.name == 'category':
                self.cat_columns.append(col)
            elif df[col].dtype in ['int64', 'float64']:
                # 检查是否是类别（唯一值较少）
                if df[col].nunique() < 20:
                    self.cat_columns.append(col)
                else:
                    self.num_columns.append(col)

    def get_feature_spec(self):
        """获取特征规格（用于模型构建）"""
        spec = {}

        if self.cat_processor:
            for col, vocab_size in self.cat_processor.vocab_sizes.items():
                spec[col] = {
                    'type': 'categorical',
                    'vocab_size': vocab_size,
                    'embed_dim': 16
                }

        if self.num_processor:
            for col in self.num_columns:
                spec[col] = {
                    'type': 'numerical'
                }

        return spec
```

## 9. 常见问题与易错点

### 9.1 常见问题

**Q1：如何处理新特征值？**

A：
- 类别特征：映射到 <UNK> 或 'others'
- 数值特征：使用均值或中位数填充

**Q2：如何处理缺失值？**

A：
- 类别特征：使用特殊标记如 'missing'
- 数值特征：使用均值、中位数或模型预测

**Q3：如何防止特征穿越？**

A：
- 严格区分训练时和预测时可用的特征
- 不使用未来信息
- 注意时间窗口的计算

### 9.2 易错点

1. **特征穿越**：使用了预测时不可获得的特征
2. **数据泄露**：训练数据包含测试数据的信息
3. **类别爆炸**：未处理低频类别
4. **未归一化**：数值特征量纲不同
5. **过拟合特征**：特征与标签高度相关但在生产中不可用
