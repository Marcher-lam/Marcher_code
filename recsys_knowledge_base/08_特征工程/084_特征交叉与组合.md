# 特征交叉与组合 学习文档

## 1. 特征交叉概述

### 1.1 什么是特征交叉？

```
特征交叉 (Feature Crossing):
- 组合两个或多个特征生成新特征
- 捕捉特征间的交互作用
- 提升模型非线性表达能力

例子:
- 用户年龄 × 物品类目
- 用户历史点击 × 当前物品
- 时间 × 地域 × 用户类型

推荐系统中的交叉:
- 用户特征 × 物品特征
- 上下文特征 × 物品特征
- 多个用户行为特征组合
```

### 1.2 为什么需要特征交叉？

```python
"""
为什么需要特征交叉?

1. 线性模型的局限
   - LR 只能学习 w1*x1 + w2*x2
   - 无法学习 x1 和 x2 的联合影响

2. 交叉特征的意义
   - 用户A 偏好 类目B ≠ 用户A偏好 + 类目B
   - 是两者的联合效应

3. 例子:
   - 年轻用户 + 数码类目 = 高转化
   - 年轻用户 + 奢侈品类目 = 低转化
   - 老年用户 + 数码类目 = 低转化
   - 老年用户 + 奢侈品类目 = 高转化

   单独的年龄或类目无法表达这种关系
"""
```

## 2. 手工特征交叉

### 2.1 二阶交叉

```python
from typing import List, Dict, Tuple
import numpy as np
import pandas as pd
from itertools import combinations


class ManualFeatureCross:
    """
    手工特征交叉
    """

    @staticmethod
    def cross_two_features(df: pd.DataFrame,
                           col1: str, col2: str,
                           sep: str = '_') -> pd.Series:
        """
        两个特征的交叉

        例如: user_age_category = age_category
        """
        return df[col1].astype(str) + sep + df[col2].astype(str)

    @staticmethod
    def create_cross_features(df: pd.DataFrame,
                               feature_pairs: List[Tuple[str, str]],
                               sep: str = '_') -> pd.DataFrame:
        """
        批量创建交叉特征
        """
        result = df.copy()

        for col1, col2 in feature_pairs:
            cross_name = f'{col1}_x_{col2}'
            result[cross_name] = (
                result[col1].astype(str) + sep + result[col2].astype(str)
            )

        return result

    @staticmethod
    def create_all_pairwise_crosses(df: pd.DataFrame,
                                     columns: List[str],
                                     max_crosses: int = 100) -> pd.DataFrame:
        """
        创建所有两两交叉特征
        """
        result = df.copy()
        cross_count = 0

        for col1, col2 in combinations(columns, 2):
            if cross_count >= max_crosses:
                break

            cross_name = f'{col1}_x_{col2}'
            result[cross_name] = (
                result[col1].astype(str) + '_' + result[col2].astype(str)
            )
            cross_count += 1

        print(f"创建了 {cross_count} 个交叉特征")
        return result
```

### 2.2 数值特征交叉

```python
class NumericalFeatureCross:
    """
    数值特征交叉
    """

    @staticmethod
    def multiply_cross(df: pd.DataFrame,
                       col1: str, col2: str) -> pd.Series:
        """
        乘法交叉

        适用于两个连续特征
        """
        return df[col1] * df[col2]

    @staticmethod
    def ratio_cross(df: pd.DataFrame,
                    numerator: str, denominator: str,
                    min_val: float = 1e-5) -> pd.Series:
        """
        比率交叉

        例如: 点击率 = 点击数 / 曝光数
        """
        return df[numerator] / (df[denominator] + min_val)

    @staticmethod
    def diff_cross(df: pd.DataFrame,
                   col1: str, col2: str) -> pd.Series:
        """
        差值交叉

        例如: 价格差异 = 用户平均消费 - 物品价格
        """
        return df[col1] - df[col2]

    @staticmethod
    def statistical_crosses(df: pd.DataFrame,
                            cols: List[str]) -> pd.DataFrame:
        """
        统计交叉特征

        包括: max, min, mean, std
        """
        result = pd.DataFrame()

        values = df[cols].values

        result['cross_max'] = values.max(axis=1)
        result['cross_min'] = values.min(axis=1)
        result['cross_mean'] = values.mean(axis=1)
        result['cross_std'] = values.std(axis=1)
        result['cross_range'] = result['cross_max'] - result['cross_min']

        return result
```

### 2.3 分组统计交叉

```python
class GroupStatCross:
    """
    分组统计交叉特征

    例如:
    - 用户在当前类目的历史点击率
    - 物品在当前时段的点击率
    """

    @staticmethod
    def create_group_stats(df: pd.DataFrame,
                           group_cols: List[str],
                           stat_col: str,
                           stats: List[str] = ['mean', 'std', 'count']
                           ) -> pd.DataFrame:
        """
        创建分组统计特征
        """
        result = df.copy()

        # 分组计算
        group_key = '_'.join(group_cols)
        grouped = df.groupby(group_cols)[stat_col]

        for stat in stats:
            if stat == 'mean':
                result[f'{group_key}_{stat_col}_mean'] = grouped.transform('mean')
            elif stat == 'std':
                result[f'{group_key}_{stat_col}_std'] = grouped.transform('std').fillna(0)
            elif stat == 'count':
                result[f'{group_key}_{stat_col}_count'] = grouped.transform('count')
            elif stat == 'max':
                result[f'{group_key}_{stat_col}_max'] = grouped.transform('max')
            elif stat == 'min':
                result[f'{group_key}_{stat_col}_min'] = grouped.transform('min')

        return result

    @staticmethod
    def create_target_encoding(df: pd.DataFrame,
                               cat_col: str,
                               target_col: str,
                               alpha: float = 10,
                               global_mean: float = None) -> pd.Series:
        """
        目标编码 (Target Encoding)

        用类别的目标均值替换类别值

        平滑公式:
        (count * category_mean + alpha * global_mean) / (count + alpha)
        """
        if global_mean is None:
            global_mean = df[target_col].mean()

        # 类别统计
        stats = df.groupby(cat_col)[target_col].agg(['mean', 'count'])

        # 平滑
        smoothed = (
            stats['count'] * stats['mean'] + alpha * global_mean
        ) / (stats['count'] + alpha)

        # 映射
        return df[cat_col].map(smoothed)
```

## 3. 自动化特征交叉

### 3.1 多项式特征

```python
from sklearn.preprocessing import PolynomialFeatures


class PolynomialCross:
    """
    多项式特征交叉

    自动生成所有多项式组合
    """

    def __init__(self, degree: int = 2,
                 interaction_only: bool = True,
                 include_bias: bool = False):
        self.degree = degree
        self.interaction_only = interaction_only
        self.include_bias = include_bias
        self.poly = None

    def fit_transform(self, X: np.ndarray,
                      feature_names: List[str] = None) -> Tuple[np.ndarray, List[str]]:
        """
        拟合并转换

        返回: (变换后的特征, 特征名)
        """
        self.poly = PolynomialFeatures(
            degree=self.degree,
            interaction_only=self.interaction_only,
            include_bias=self.include_bias
        )

        X_poly = self.poly.fit_transform(X)

        # 生成特征名
        if feature_names is not None:
            poly_names = self.poly.get_feature_names_out(feature_names)
        else:
            poly_names = self.poly.get_feature_names_out()

        print(f"原始特征: {X.shape[1]}, 多项式特征: {X_poly.shape[1]}")

        return X_poly, poly_names.tolist()
```

### 3.2 特征哈希交叉

```python
class FeatureHashCross:
    """
    特征哈希交叉

    使用哈希函数将交叉特征映射到固定维度
    """

    def __init__(self, n_buckets: int = 10000):
        self.n_buckets = n_buckets

    def hash_cross(self, val1: str, val2: str) -> int:
        """
        哈希交叉特征
        """
        combined = f'{val1}_{val2}'
        return hash(combined) % self.n_buckets

    def transform(self, df: pd.DataFrame,
                  feature_pairs: List[Tuple[str, str]]) -> np.ndarray:
        """
        转换为稀疏矩阵
        """
        n_samples = len(df)
        result = np.zeros((n_samples, self.n_buckets))

        for i, row in df.iterrows():
            for col1, col2 in feature_pairs:
                val1 = str(row[col1])
                val2 = str(row[col2])
                bucket = self.hash_cross(val1, val2)
                result[i, bucket] = 1

        return result
```

## 4. 深度学习特征交叉

### 4.1 FM 风格交叉

```python
import torch
import torch.nn as nn


class FactorizedInteraction(nn.Module):
    """
    因子分解交叉 (FM 风格)

    学习特征间的二阶交叉
    """

    def __init__(self, n_features: int, embed_dim: int = 16):
        super().__init__()

        # 每个特征一个嵌入
        self.embeddings = nn.Embedding(n_features, embed_dim)

        # 线性项
        self.linear = nn.Linear(n_features, 1)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        前向传播

        FM 公式:
        y = w0 + sum(wi*xi) + sum(sum(<vi,vj>*xi*xj))

        简化计算:
        sum(sum(<vi,vj>*xi*xj)) = 0.5 * sum((sum(vi*xi))^2 - sum((vi*xi)^2))
        """
        # 线性项
        linear = self.linear(x)

        # 嵌入
        # x: (batch, n_features)
        # embeddings: (batch, n_features, embed_dim)
        embed = self.embeddings.weight.unsqueeze(0)  # (1, n_features, embed_dim)
        x_expand = x.unsqueeze(-1)  # (batch, n_features, 1)
        embed_x = x_expand * embed  # (batch, n_features, embed_dim)

        # 交叉项
        sum_embed = embed_x.sum(dim=1)  # (batch, embed_dim)
        sum_square = (sum_embed ** 2).sum(dim=1, keepdim=True)  # (batch, 1)

        square_sum = (embed_x ** 2).sum(dim=1).sum(dim=1, keepdim=True)  # (batch, 1)

        cross = 0.5 * (sum_square - square_sum)

        return linear + cross


class CrossNetwork(nn.Module):
    """
    Cross Network (DCN)

    显式学习有界阶特征交叉
    """

    def __init__(self, input_dim: int, n_layers: int = 3):
        super().__init__()

        self.n_layers = n_layers

        # 每层的权重和偏置
        self.w = nn.ParameterList([
            nn.Parameter(torch.randn(input_dim, 1))
            for _ in range(n_layers)
        ])

        self.b = nn.ParameterList([
            nn.Parameter(torch.zeros(input_dim))
            for _ in range(n_layers)
        ])

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        Cross 层公式:
        x_{l+1} = x_0 * (W_l * x_l + b_l) + x_l

        这样可以学习 1 到 l+1 阶的所有交叉
        """
        x0 = x
        xl = x

        for i in range(self.n_layers):
            # W_l * x_l + b_l
            xlw = torch.matmul(xl, self.w[i]).squeeze(-1) + self.b[i]  # (batch, input_dim)

            # x_0 * (...) + x_l
            xl = x0 * xlw.unsqueeze(-1) + xl

        return xl
```

### 4.2 注意力交叉

```python
class AttentionCross(nn.Module):
    """
    注意力特征交叉

    使用注意力机制学习特征交叉权重
    """

    def __init__(self, embed_dim: int, n_heads: int = 4):
        super().__init__()

        self.attention = nn.MultiheadAttention(
            embed_dim=embed_dim,
            num_heads=n_heads,
            batch_first=True
        )

        self.ffn = nn.Sequential(
            nn.Linear(embed_dim, embed_dim * 4),
            nn.ReLU(),
            nn.Linear(embed_dim * 4, embed_dim)
        )

        self.norm1 = nn.LayerNorm(embed_dim)
        self.norm2 = nn.LayerNorm(embed_dim)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: (batch, n_features, embed_dim)

        使用自注意力学习特征交叉
        """
        # 自注意力
        attn_out, _ = self.attention(x, x, x)
        x = self.norm1(x + attn_out)

        # FFN
        ffn_out = self.ffn(x)
        x = self.norm2(x + ffn_out)

        return x


class InteractionBlock(nn.Module):
    """
    交互块

    学习特征对之间的交互强度
    """

    def __init__(self, input_dim: int, hidden_dim: int = 64):
        super().__init__()

        # 交互权重网络
        self.interaction_net = nn.Sequential(
            nn.Linear(input_dim * 2, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1),
            nn.Sigmoid()
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: (batch, n_features, dim)

        计算所有特征对的交互权重
        """
        batch_size, n_features, dim = x.shape

        # 创建所有特征对
        # (batch, n_features, 1, dim) + (batch, 1, n_features, dim)
        x1 = x.unsqueeze(2).expand(-1, -1, n_features, -1)
        x2 = x.unsqueeze(1).expand(-1, n_features, -1, -1)

        # 拼接
        pairs = torch.cat([x1, x2], dim=-1)  # (batch, n_features, n_features, dim*2)

        # 计算交互权重
        weights = self.interaction_net(pairs).squeeze(-1)  # (batch, n_features, n_features)

        # 加权求和
        # (batch, n_features, n_features) @ (batch, n_features, dim)
        output = torch.matmul(weights, x)  # (batch, n_features, dim)

        return output
```

## 5. 推荐系统特征交叉实践

### 5.1 交叉特征生成器

```python
class RecSysCrossFeatureGenerator:
    """
    推荐系统交叉特征生成器
    """

    def __init__(self):
        self.encoders = {}

    def generate_user_item_crosses(self,
                                    user_features: Dict[str, float],
                                    item_features: Dict[str, float]
                                    ) -> Dict[str, float]:
        """
        生成用户-物品交叉特征
        """
        crosses = {}

        # 常用交叉对
        cross_pairs = [
            ('user_age_group', 'item_category'),
            ('user_gender', 'item_category'),
            ('user_city_level', 'item_price_level'),
            ('user_active_level', 'item_popularity'),
        ]

        for u_feat, i_feat in cross_pairs:
            if u_feat in user_features and i_feat in item_features:
                cross_name = f'{u_feat}_x_{i_feat}'
                # 哈希编码
                cross_val = hash(f'{user_features[u_feat]}_{item_features[i_feat]}') % 10000
                crosses[cross_name] = cross_val

        # 数值交叉
        if 'user_avg_price' in user_features and 'item_price' in item_features:
            crosses['price_diff'] = user_features['user_avg_price'] - item_features['item_price']
            crosses['price_ratio'] = item_features['item_price'] / (user_features['user_avg_price'] + 1)

        return crosses

    def generate_context_crosses(self,
                                  user_features: Dict,
                                  item_features: Dict,
                                  context_features: Dict
                                  ) -> Dict[str, float]:
        """
        生成上下文交叉特征
        """
        crosses = {}

        # 时间 × 类目
        if 'hour' in context_features and 'item_category' in item_features:
            crosses['hour_x_category'] = hash(
                f"{context_features['hour']}_{item_features['item_category']}"
            ) % 1000

        # 地域 × 物品
        if 'user_city' in user_features and 'item_ship_from' in item_features:
            crosses['city_x_shipfrom'] = 1 if user_features['user_city'] == item_features['item_ship_from'] else 0

        # 周末 × 类目
        if 'is_weekend' in context_features and 'item_category' in item_features:
            crosses['weekend_x_category'] = hash(
                f"{context_features['is_weekend']}_{item_features['item_category']}"
            ) % 100

        return crosses
```

### 5.2 特征交叉配置

```python
class FeatureCrossConfig:
    """
    特征交叉配置
    """

    # 推荐的交叉特征组合
    RECOMMENDED_CROSSES = {
        # 用户 × 物品
        'user_item': [
            ('user_age_group', 'item_category'),
            ('user_gender', 'item_category'),
            ('user_vip_level', 'item_price_level'),
            ('user_city_tier', 'item_brand_tier'),
        ],

        # 用户 × 上下文
        'user_context': [
            ('user_id', 'hour'),
            ('user_id', 'day_of_week'),
            ('user_city', 'weather'),
        ],

        # 物品 × 上下文
        'item_context': [
            ('item_category', 'hour'),
            ('item_id', 'is_weekend'),
            ('item_brand', 'festival'),
        ],

        # 行为 × 物品
        'behavior_item': [
            ('user_last_click_category', 'item_category'),
            ('user_last_click_brand', 'item_brand'),
        ],
    }

    @staticmethod
    def get_cross_features(df: pd.DataFrame,
                           cross_type: str = 'all') -> pd.DataFrame:
        """
        获取配置的交叉特征
        """
        result = df.copy()

        if cross_type == 'all':
            cross_groups = FeatureCrossConfig.RECOMMENDED_CROSSES.values()
        else:
            cross_groups = [FeatureCrossConfig.RECOMMENDED_CROSSES[cross_type]]

        for cross_pairs in cross_groups:
            for col1, col2 in cross_pairs:
                if col1 in df.columns and col2 in df.columns:
                    cross_name = f'{col1}_x_{col2}'
                    result[cross_name] = (
                        df[col1].astype(str) + '_' + df[col2].astype(str)
                    )

        return result
```

## 6. 学习总结

### 6.1 核心要点

```
1. 特征交叉捕捉特征间交互
2. 手工交叉需要领域知识
3. 自动化交叉适合探索
4. 深度学习自动学习交叉
```

### 6.2 方法选择

```
场景                    推荐方法
───────────────────────────────────────
特征数少、领域知识丰富   手工交叉
特征数多                自动化或深度学习
在线推理                预计算或哈希
需要可解释性            手工交叉
```

### 6.3 最佳实践

```
1. 避免过度交叉（组合爆炸）
2. 使用平滑处理稀疏交叉
3. 交叉特征也需要筛选
4. 考虑计算和存储成本
5. 结合业务理解设计交叉
```
