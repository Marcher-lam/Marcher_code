# A/B 测试基础 学习文档

## 1. 基础认知

### 1.1 什么是 A/B 测试？

A/B 测试（也称为分流测试）是一种随机实验，将用户随机分配到不同的组，比较不同方案的效果，以数据驱动的方式做出决策。

```
           ┌──→ A 组（对照组）──→ 体验 A ──→ 指标 A
用户流量 ──┤
           └──→ B 组（实验组）──→ 体验 B ──→ 指标 B

比较：指标 A vs 指标 B
```

### 1.2 为什么需要 A/B 测试？

**离线评估的局限：**

1. **数据偏差**：历史数据可能不代表未来
2. **特征穿越**：离线特征可能与在线不一致
3. **用户行为差异**：真实用户行为复杂
4. **网络效应**：无法模拟用户间的相互影响

**A/B 测试的价值：**

1. **真实效果验证**：在真实环境中测试
2. **降低风险**：小流量先验证
3. **因果推断**：可以建立因果关系
4. **量化决策**：数据驱动，而非拍脑袋

### 1.3 A/B 测试流程

```
1. 提出假设
    ↓
2. 设计实验
    - 确定指标
    - 确定样本量
    - 确定分流策略
    ↓
3. 实施实验
    - 流量分配
    - 监控实验
    ↓
4. 分析结果
    - 统计检验
    - 效果评估
    ↓
5. 决策
    - 全量发布
    - 继续优化
    - 放弃方案
```

### 2.2 分流策略

**用户级分流：**
```python
def user_level_split(user_id, experiment_name, control_ratio=0.5):
    """
    用户级分流

    优点：用户体验一致
    缺点：样本量可能不足
    """
    import hashlib

    # 使用用户 ID 和实验名生成 hash
    hash_key = f"{user_id}_{experiment_name}"
    hash_value = int(hashlib.md5(hash_key.encode()).hexdigest(), 16)

    # 归一化到 [0, 1)
    normalized = (hash_value % 10000) / 10000

    return 'treatment' if normalized >= control_ratio else 'control'
```

**请求级分流：**
```python
def request_level_split(request_id, control_ratio=0.5):
    """
    请求级分流

    优点：样本量大
    缺点：同一用户体验不一致
    """
    import random
    return 'treatment' if random.random() >= control_ratio else 'control'
```

**分层分流（Layered Sampling）：**
```python
def layered_split(user_id, layer_name, num_buckets=1000):
    """
    分层分流：支持多个并行实验

    不同层使用不同的 hash，允许同一用户参与多个实验
    """
    import hashlib

    hash_key = f"{user_id}_{layer_name}"
    hash_value = int(hashlib.md5(hash_key.encode()).hexdigest(), 16)
```

**零假设（H0）：** 新方案与旧方案无差异
**备择假设（H1）：** 新方案与旧方案有差异

```python
from scipy import stats
import numpy as np

def two_sample_t_test(group_a, group_b, alpha=0.05):
    """
    双样本 t 检验
    """
    t_stat, p_value = stats.ttest_ind(group_a, group_b)

    reject_null = p_value < alpha

    return {
        't_statistic': t_stat,
        'p_value': p_value,
        'significant': reject_null,
        'alpha': alpha
    }

# 示例
```

### 3.2 样本量计算

```python
def calculate_sample_size(baseline_rate, min_detectable_effect, alpha=0.05, power=0.8):
    """
    计算所需样本量

    参数:
        baseline_rate: 基准转化率
        min_detectable_effect: 最小可检测效应（相对提升）
        alpha: 显著性水平
        power: 统计功效

    返回:
        每组所需样本量
    """
    from scipy import stats
    import math

    # 计算期望转化率
    expected_rate = baseline_rate * (1 + min_detectable_effect)

    # Z 分数
    z_alpha = stats.norm.ppf(1 - alpha / 2)
    z_beta = stats.norm.ppf(power)

    # 样本量公式
    p1, p2 = baseline_rate, expected_rate
    p_pooled = (p1 + p2) / 2

    n = (
        (z_alpha * math.sqrt(2 * p_pooled * (1 - p_pooled)) +
         z_beta * math.sqrt(p1 * (1 - p1) + p2 * (1 - p2))) ** 2
    ) / (p1 - p2) ** 2

    return int(math.ceil(n))

# 示例
baseline_ctr = 0.05  # 5% CTR
mde = 0.05  # 希望检测到 5% 的相对提升

sample_size = calculate_sample_size(baseline_ctr, mde)
print(f"每组需要样本量: {sample_size}")
print(f"总样本量: {sample_size * 2}")
```

### 3.3 置信区间

```python
def confidence_interval(data, confidence=0.95):
    """
    计算置信区间
    """
    import scipy.stats as stats
    import numpy as np

    n = len(data)
    mean = np.mean(data)
    se = stats.sem(data)
    h = se * stats.t.ppf((1 + confidence) / 2, n - 1)

    return mean - h, mean + h

# 示例
data = np.random.normal(0.05, 0.02, 1000)
ci_low, ci_high = confidence_interval(data)
print(f"均值: {np.mean(data):.4f}")
print(f"95% 置信区间: [{ci_low:.4f}, {ci_high:.4f}]")
```

### 3.4 效应量

```python
def cohen_d(group_a, group_b):
    """
    计算 Cohen's d 效应量

    d < 0.2: 小效应
    0.2 <= d < 0.8: 中等效应
    d >= 0.8: 大效应
    """
    import numpy as np

    n1, n2 = len(group_a), len(group_b)
    var1, var2 = np.var(group_a, ddof=1), np.var(group_b, ddof=1)

    # 汇合标准差
    pooled_std = np.sqrt(((n1 - 1) * var1 + (n2 - 1) * var2) / (n1 + n2 - 2))

    # Cohen's d
    d = (np.mean(group_b) - np.mean(group_a)) / pooled_std

    return d
```

```python
class RecSysMetrics:
    """推荐系统指标计算"""

    @staticmethod
    def calculate_ctr(clicks, exposures):
        """计算 CTR"""
        return sum(clicks) / sum(exposures) if sum(exposures) > 0 else 0

    @staticmethod
    def calculate_cvr(conversions, clicks):
        """计算 CVR"""
        return sum(conversions) / sum(clicks) if sum(clicks) > 0 else 0

    @staticmethod
    def calculate_gmv(prices, quantities):
        """计算 GMV（商品交易总额）"""
        return sum(p * q for p, q in zip(prices, quantities))

    @staticmethod
    def calculate_per_user_metric(user_data, metric_name):
        """计算用户级指标"""
        from collections import defaultdict

        user_metrics = defaultdict(list)

        for record in user_data:
            user_id = record['user_id']
            metric_value = record.get(metric_name, 0)
            user_metrics[user_id].append(metric_value)

        # 聚合
        user_level = {}
        for user_id, values in user_metrics.items():
            user_level[user_id] = sum(values) / len(values)

        return user_level


def compare_ab_groups(control_data, treatment_data):
    """
    比较 A/B 组的指标
    """
    # 汇总统计
    control_summary = {
        'users': len(control_data),
        'impressions': sum(d['impressions'] for d in control_data),
        'clicks': sum(d['clicks'] for d in control_data),
        'conversions': sum(d['conversions'] for d in control_data)
```

### 4.3 统计显著性检验

```python
from scipy import stats
import numpy as np

def chi_square_test(control_success, control_total,
                    treatment_success, treatment_total):
    """
    卡方检验（适用于比例指标如 CTR）

    返回:
        chi2: 卡方统计量
        p_value: p 值
        significant: 是否显著
    """
    # 构建列联表
    contingency_table = [
        [control_success, control_total - control_success],
        [treatment_success, treatment_total - treatment_success]
    ]

    chi2, p_value, dof, expected = stats.chi2_contingency(contingency_table)

    return {
        'chi2': chi2,
        'p_value': p_value,
        'significant': p_value < 0.05
    }

def z_test_proportions(control_success, control_total,
                       treatment_success, treatment_total):
    """
    双比例 Z 检验
    """
    # 汇合比例
    p_pooled = (control_success + treatment_success) / (control_total + treatment_total)

    # 标准误差
    se = np.sqrt(p_pooled * (1 - p_pooled) * (1/control_total + 1/treatment_total))

    # Z 统计量
    p_control = control_success / control_total
    p_treatment = treatment_success / treatment_total

    z = (p_treatment - p_control) / se

    # p 值（双侧）
    p_value = 2 * (1 - stats.norm.cdf(abs(z)))

    return {
        'z_statistic': z,
        'p_value': p_value,
        'significant': p_value < 0.05
    }

# 示例
control_clicks = 500
control_impressions = 10000
treatment_clicks = 550
treatment_impressions = 10000

result = chi_square_test(control_clicks, control_impressions,
                         treatment_clicks, treatment_impressions)
print(f"卡方检验: chi2={result['chi2']:.4f}, p={result['p_value']:.4f}")
print(f"显著差异: {result['significant']}")
```

## 5. 实验分析

### 5.1 完整分析流程

```python
import pandas as pd
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

class ABTestAnalyzer:
    """A/B 测试分析器"""

    def __init__(self, control_data, treatment_data, alpha=0.05):
        """
        参数:
            control_data: DataFrame, 对照组数据
            treatment_data: DataFrame, 实验组数据
            alpha: 显著性水平
        """
        self.control = control_data
        self.treatment = treatment_data
        self.alpha = alpha
        self.results = {}

    def analyze_metric(self, metric_name, metric_type='ratio'):
        """
        分析单个指标

        参数:
            metric_name: 指标名称
            metric_type: 'ratio' (比例) 或 'continuous' (连续)
        """
        if metric_type == 'ratio':
            # 比例指标（如 CTR）
            control_success = self.control[metric_name].sum()
            control_total = len(self.control)
            treatment_success = self.treatment[metric_name].sum()
            treatment_total = len(self.treatment)

            # 检验
            test_result = chi_square_test(
                control_success, control_total,
                treatment_success, treatment_total
            )

            # 计算比例
            control_rate = control_success / control_total
            treatment_rate = treatment_success / treatment_total

            self.results[metric_name] = {
                'type': 'ratio',
                'control_rate': control_rate,
                'treatment_rate': treatment_rate,
                'lift': (treatment_rate - control_rate) / control_rate * 100,
                **test_result
            }

        elif metric_type == 'continuous':
            # 连续指标（如时长）
            control_values = self.control[metric_name].values
            treatment_values = self.treatment[metric_name].values

            # t 检验
            t_stat, p_value = stats.ttest_ind(control_values, treatment_values)

            self.results[metric_name] = {
                'type': 'continuous',
                'control_mean': control_values.mean(),
                'treatment_mean': treatment_values.mean(),
                'control_std': control_values.std(),
                'treatment_std': treatment_values.std(),
                'lift': (treatment_values.mean() - control_values.mean()) / control_values.mean() * 100,
                't_statistic': t_stat,
                'p_value': p_value,
                'significant': p_value < self.alpha
            }

    def generate_report(self):
        """生成报告"""
        report = []
        for metric, result in self.results.items():
            row = {
                'Metric': metric,
                'Control': f"{result.get('control_rate', result.get('control_mean', 0)):.4f}",
                'Treatment': f"{result.get('treatment_rate', result.get('treatment_mean', 0)):.4f}",
                'Lift (%)': f"{result['lift']:.2f}%",
                'P-value': f"{result['p_value']:.4f}",
                'Significant': 'Yes' if result['significant'] else 'No'
            }
            report.append(row)

        return pd.DataFrame(report)

    def plot_metric_distribution(self, metric_name):
        """绘制指标分布"""
        if metric_name not in self.results:
            print(f"指标 {metric_name} 未分析")
            return

        result = self.results[metric_name]

        if result['type'] == 'continuous':
            plt.figure(figsize=(10, 6))
            plt.hist(self.control[metric_name], bins=50, alpha=0.5, label='Control')
            plt.hist(self.treatment[metric_name], bins=50, alpha=0.5, label='Treatment')
            plt.xlabel(metric_name)
            plt.ylabel('Frequency')
            plt.title(f'{metric_name} Distribution')
            plt.legend()
            plt.show()
```

### 5.2 分层分析

```python
def stratified_analysis(data, strata_column, metric_column):
    """
    分层分析

    参数:
        data: DataFrame
        strata_column: 分层列（如用户群体）
        metric_column: 指标列
    """
    results = []

    for stratum in data[strata_column].unique():
        stratum_data = data[data[strata_column] == stratum]

        control = stratum_data[stratum_data['group'] == 'control'][metric_column]
        treatment = stratum_data[stratum_data['group'] == 'treatment'][metric_column]

        # 检验
        if len(control) > 0 and len(treatment) > 0:
            t_stat, p_value = stats.ttest_ind(control, treatment)

            results.append({
                'stratum': stratum,
                'control_mean': control.mean(),
                'treatment_mean': treatment.mean(),
                'lift': (treatment.mean() - control.mean()) / control.mean() * 100,
                'p_value': p_value,
                'significant': p_value < 0.05
            })

    return pd.DataFrame(results)
```

```python
class ABTestBestPractices:
    """A/B 测试最佳实践"""

    @staticmethod
    def check_randomization(control_data, treatment_data, user_features):
        """
        检查随机化是否成功（SRM 检验）
        """
        # 样本比例检验
        n_control = len(control_data)
        n_treatment = len(treatment_data)
        n_total = n_control + n_treatment

        expected_ratio = 0.5
        observed_ratio = n_treatment / n_total

        # Chi-square test
        chi2, p_value = stats.chisquare(
            [n_control, n_treatment],
            [n_total * expected_ratio, n_total * expected_ratio]
        )

        return {
            'control_size': n_control,
            'treatment_size': n_treatment,
            'expected_ratio': expected_ratio,
            'observed_ratio': observed_ratio,
            'p_value': p_value,
            'randomization_ok': p_value > 0.05  # 不显著表示随机化成功
        }

    @staticmethod
    def check_aa_test(aa_control, aa_treatment, metrics):
        """
        A/A 测试检查
        """
        results = {}
        for metric in metrics:
            control_values = aa_control[metric]
            treatment_values = aa_treatment[metric]

            t_stat, p_value = stats.ttest_ind(control_values, treatment_values)
            results[metric] = {
                'p_value': p_value,
                'pass': p_value > 0.05  # A/A 测试不应该显著
            }

        return results

    @staticmethod
    def calculate_required_duration(daily_users, required_sample_size, traffic_ratio=0.1):
        """
        计算所需实验时长
        """
        daily_experiment_users = daily_users * traffic_ratio
        users_per_group = daily_experiment_users / 2

        days = np.ceil(required_sample_size / users_per_group)

        return int(days)
```

```python
        """
        exp = self.experiments.get(experiment_id)
        if not exp or exp['status'] != 'running':
            return 'control'

        # 一致性 hash
        hash_key = f"{experiment_id}_{user_id}"
        hash_value = int(hashlib.md5(hash_key.encode()).hexdigest(), 16) % 100

        # 根据分配比例确定变体
        cumulative = 0
        for variant, ratio in exp['traffic_allocation'].items():
            cumulative += ratio * 100
            if hash_value < cumulative:
                return variant

        return 'control'

    def log_event(self, experiment_id: str, user_id: str, variant: str,
                  event_name: str, event_value: float = 1):
        """记录事件"""
        if experiment_id not in self.results:
            self.results[experiment_id] = {}

        key = f"{variant}_{event_name}"
        if key not in self.results[experiment_id]:
            self.results[experiment_id][key] = []

        self.results[experiment_id][key].append({
            'user_id': user_id,
            'value': event_value,
            'timestamp': datetime.now().isoformat()
        })

    def get_results(self, experiment_id: str) -> Dict:
        """获取实验结果"""
        return self.results.get(experiment_id, {})

    def stop_experiment(self, experiment_id: str):
        """停止实验"""
        if experiment_id in self.experiments:
            self.experiments[experiment_id]['status'] = 'completed'
            self.experiments[experiment_id]['completed_at'] = datetime.now().isoformat()
```

## 8. 常见问题与易错点

### 8.1 常见问题

**Q1：A/B 测试需要多长时间？**

A：取决于：
- 基准转化率
- 期望检测的最小效应
- 流量大小
- 显著性水平和功效

**Q2：如何确定最小可检测效应（MDE）？**

A：根据业务价值和可行性：
- 太小：需要大量样本
- 太大：可能错过真实效果

**Q3：多个实验同时进行怎么办？**

A：使用分层分流，确保实验正交。

### 8.2 易错点

1. **样本量不足**：过早下结论
2. **过早查看**：多次检验问题
3. **辛普森悖论**：未分层分析
4. **新颖效应**：短期效应不代表长期
5. **相互干扰**：实验组之间相互影响
