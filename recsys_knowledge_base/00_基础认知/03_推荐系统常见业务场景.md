## 2. 电商推荐

### 2.1 代表产品
淘宝、京东、拼多多、亚马逊

### 2.2 推荐场景

| 场景 | 位置 | 目标 |
|-----|------|-----|
| **首页推荐** | App首页信息流 | 发现商品、提升GMV |
| **详情页推荐** | 商品详情页下方 | 关联销售、提升客单价 |
| **购物车推荐** | 购物车页面 | 凑单、提升转化 |
| **搜索结果** | 搜索列表 | 提升点击和转化 |
| **Push推送** | 通知消息 | 召回用户、促成交易 |

### 2.3 推荐目标

```
核心指标：
├── GMV（商品交易总额）
├── 转化率（CVR）
├── 客单价
└── 复购率

过程指标：
├── CTR（点击率）
├── 加购率
├── 收藏率
└── 停留时长
```

### 2.4 特点与挑战

| 特点 | 说明 |
|-----|------|
| **决策周期长** | 用户可能浏览很久才购买 |
| **价格敏感** | 价格对决策影响大 |
| **多目标** | 点击、加购、购买、复购 |
| **季节性** | 不同季节/节日需求变化大 |
| **冷启动频繁** | 新商品不断上架 |

### 2.5 推荐策略

```
用户行为序列：搜索 → 浏览 → 加购 → 购买

推荐策略：
├── 看了又看（相似商品）
├── 买了又买（关联商品）
├── 猜你喜欢（个性化推荐）
├── 热门推荐（销量/热度排序）
└── 凑单推荐（购物车场景）
```

## 3. 短视频推荐

### 3.1 代表产品
抖音、快手、视频号、TikTok

### 3.2 推荐场景

| 场景 | 位置 | 特点 |
|-----|------|-----|
| **沉浸式信息流** | 首页全屏 | 单列下滑，决策时间短 |
| **关注页** | 关注tab | 社交关系驱动 |
| **同城页** | 同城tab | 地理位置相关 |
| **搜索结果** | 搜索页 | 意图明确 |

### 3.3 推荐目标

```
核心指标：
├── 停留时长（Time Spent）
├── 完播率（视频看完比例）
├── 互动率（点赞/评论/分享）
└── DAU/MAU（日活/月活）

过程指标：
├── CTR（点击进主页）
├── 关注转化率
└── 粉丝留存率
```

### 3.4 特点与挑战

| 特点 | 说明 |
|-----|------|
| **决策极快** | 几秒内判断是否喜欢 |
| **实时性强** | 用户兴趣变化快 |
| **内容消费** | 主要是消耗时间 |
| **创作者生态** | 需要激励创作者 |
| **内容理解** | 视频/音频/文本多模态 |

### 3.5 推荐策略

```
用户单次会话：
下滑 → 观看3秒 → 点赞 → 继续下滑 → 完播 → 分享 → ...

推荐策略：
├── 协同过滤（看相似用户看过的）
├── 内容召回（相似视频）
├── 向量召回（Embedding相似）
├── 热门召回（爆款内容）
└── 探索召回（新内容冷启动）

多目标优化：
├── 完播模型
├── 点赞模型
├── 评论模型
├── 分享模型
└── 关注模型
```

### 3.6 核心挑战

```
挑战1：实时性
- 用户行为秒级变化
- 需要实时特征更新
- 在线学习/增量学习

挑战2：探索利用
- 新视频需要曝光机会
- 但不能影响用户体验
- Bandit算法 / 流量分配

挑战3：创作者激励
- 优质创作者需要正向反馈
- 冷启动流量分配
- 流量扶持策略
```

## 4. 音乐推荐

### 4.1 代表产品
网易云音乐、QQ音乐、Spotify、Apple Music

### 4.2 推荐场景

| 场景 | 说明 | 目标 |
|-----|------|-----|
| **每日推荐** | 个性化歌单 | 发现新音乐 |
| **相似歌曲** | 当前播放后 | 延长听歌时长 |
| **歌单推荐** | 推荐歌单 | 发现歌单 |
| **歌手推荐** | 相似歌手 | 拓展兴趣 |
| **电台推荐** | 个性化电台 | 持续播放 |

### 4.3 推荐目标

```
核心指标：
├── 听歌时长
├── 听歌完成率
├── 日活用户数
└── 会员转化率

过程指标：
├── 歌曲点击率
├── 收藏率
├── 分享率
└── 跳过率（负向）
```

### 4.4 特点与挑战

| 特点 | 说明 |
|-----|------|
| **长期偏好** | 音乐口味相对稳定 |
| **场景依赖** | 工作/运动/睡前场景不同 |
| **情感因素** | 音乐与情绪强相关 |
| **歌曲关联** | 专辑、歌手、歌单关联 |
| **冷启动** | 新歌/新歌手需要曝光 |

### 4.5 推荐策略

```
推荐维度：
├── 基于歌曲（Audio特征）
│   ├── 节奏、调性、能量
│   └── MFCC、Chroma等
│
├── 基于歌手
│   └── 相似歌手、同流派歌手
│
├── 基于歌单
│   └── UGC歌单协同过滤
│
├── 基于用户
│   └── 听歌历史、收藏、点赞
│
└── 基于场景
    ├── 早晨/晚上
    ├── 运动/睡眠
    └── 工作/学习
```

### 4.6 每日推荐歌单

```
┌─────────────────────────────────────────────────────────┐
│  每日推荐                                                │
├─────────────────────────────────────────────────────────┤
│  根据你的口味生成，每天6:00更新                          │
│                                                        │
│  1. 歌曲A - 歌手1    [收藏] [不喜欢]                    │
│  2. 歌曲B - 歌手2    [收藏] [不喜欢]                    │
│  3. 歌曲C - 歌手3    [收藏] [不喜欢]                    │
│  ...                                                   │
│                                                        │
│  [换一批]                                               │
└─────────────────────────────────────────────────────────┘

策略：
- 70% 熟悉风格的歌曲
- 20% 稍有变化的歌曲
- 10% 探索性歌曲（惊喜）
```

## 5. 新闻资讯推荐

### 5.1 代表产品
今日头条、腾讯新闻、知乎、微博

### 5.2 推荐场景

| 场景 | 说明 |
|-----|------|
| **信息流** | 首页推荐流 |
| **热点推荐** | 实时热点新闻 |
| **相关推荐** | 文章底部相关内容 |
| **Push推送** | 重大新闻推送 |

### 5.3 推荐目标

```
核心指标：
├── 阅读时长
├── 阅读完成率
├── 日活跃用户
└── 留存率

过程指标：
├── CTR
├── 互动率（评论/转发）
├── 负反馈率（不感兴趣）
└── 深度阅读率
```

### 5.4 特点与挑战

| 特点 | 说明 |
|-----|------|
| **时效性极强** | 新闻很快过时 |
| **兴趣广泛** | 用户可能关注多个领域 |
| **热点驱动** | 突发事件流量激增 |
| **内容理解** | NLP技术重要 |
| **假新闻问题** | 内容质量把控 |

### 5.5 推荐策略

```
内容召回：
├── 关键词匹配
├── 主题模型（LDA）
├── 文本相似度
└── 实体识别（NER）

协同召回：
├── 用户协同过滤
├── 物品协同过滤
└── 图召回

热点召回：
├── 实时热度排序
├── 社交传播速度
└── 搜索热度

时间衰减：
├── 新新闻权重高
├── 旧新闻快速衰减
└── 热点事件特殊处理
```

```
├── 观看时段

推荐策略：
├── 相似影视推荐
├── 同演员/导演推荐
├── 续集/系列推荐
```

## 7. 本地生活推荐

### 7.1 代表产品
美团、大众点评、饿了么

### 7.2 推荐场景

| 场景 | 说明 |
|-----|------|
| **美食推荐** | 餐厅推荐 |
| **外卖推荐** | 外卖商家/菜品 |
| **酒店推荐** | 住宿推荐 |
| **休闲娱乐** | KTV、电影等 |
| **景点门票** | 旅游推荐 |

### 7.3 推荐目标

```
核心指标：
├── GMV
├── 订单转化率
├── 复购率
└── 用户留存

过程指标：
├── 点击率
├── 收藏率
```

### 7.4 特点与挑战

| 特点 | 说明 |

```
场景召回：
├── 早餐/午餐/晚餐
├── 工作日/周末
├── 一人食/聚餐
└── 堂食/外卖

协同召回：
├── 相似用户偏好
├── 同商圈热门
└── 好友推荐

内容召回：
├── 菜系/口味
├── 价格区间
```

## 10. 本章总结

### 10.1 核心要点

1. **不同场景目标不同**：电商重GMV，短视频重时长
2. **技术挑战各异**：实时性、冷启动、多目标各有侧重
3. **推荐策略需适配**：根据场景特点设计策略
4. **业务理解很重要**：技术要服务于业务目标

### 10.2 选择推荐系统的判断

```
是否需要推荐系统？

✅ 内容/商品数量大（>10000）
✅ 用户选择困难
✅ 用户偏好可学习
✅ 有足够的行为数据
✅ 用户有发现需求

❌ 内容很少
❌ 用户需求明确（搜索更好）
❌ 决策非常理性
❌ 没有行为数据
```
