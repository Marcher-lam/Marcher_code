# 推荐系统与搜索广告的区别

> 理解推荐、搜索、广告三者的联系与区别

---

## 1. 概述

推荐、搜索、广告是互联网三大核心变现技术，它们既有联系又有区别。


## 2. 一句话区分

| 系统 | 一句话定义 | 核心特点 |
|-----|-----------|---------|
| **搜索** | 用户主动查询，系统返回匹配结果 | **用户意图明确** |
| **推荐** | 系统根据用户画像，主动推送内容 | **系统主动推送** |
| **广告** | 广告主付费，系统展示广告内容 | **付费推广** |

---

## 3. 搜索系统（Search）

### 3.1 定义

**搜索是用户主动输入查询词（Query），系统返回与查询词最相关的结果。**

### 3.2 工作流程

```
┌─────────────────────────────────────────────────────────────┐
│                      搜索系统流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  用户输入 ──→ 查询理解 ──→ 召回 ──→ 排序 ──→ 展示         │
│   "iPhone"     │           │        │        │              │
│                │           │        │        │              │
│                ▼           ▼        ▼        ▼              │
│             纠错/      倒排索引   相关性   搜索结果         │
│             分词/      布尔检索   打分     页面             │
│             意图理解                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 核心组件

```
搜索系统核心组件：

1. 查询理解（Query Understanding）
   ├── 分词
   ├── 纠错（"iphon" → "iphone"）
   ├── 意图识别（找商品？找新闻？找视频？）
   ├── 实体识别（"苹果手机" → 品牌=Apple）
   └── 查询改写（"便宜手机" → "性价比手机"）

2. 召回（Retrieval）
   ├── 倒排索引
   ├── 布尔检索
   └── 向量检索（语义召回）

3. 排序（Ranking）
   ├── 相关性打分（BM25）
   ├── 精排模型（Learning to Rank）
   └── 业务规则
```

### 3.4 关键指标

| 指标 | 说明 |
|-----|------|
| **CTR** | 点击率 |
| **MRR** | 首条结果排名倒数均值 |
| **NDCG** | 排序质量 |
| **查询无结果率** | 无结果查询占比 |
| **查询延迟** | 响应时间 |

### 3.5 特点

| 特点 | 说明 |
|-----|------|
| **用户主动** | 用户明确表达需求 |
| **意图明确** | 查询词反映用户意图 |
| **实时响应** | 需要快速返回结果 |
| **精准匹配** | 结果要与查询高度相关 |

## 4. 推荐系统（Recommendation）

### 4.1 定义

**推荐系统根据用户的历史行为和偏好，主动推送用户可能感兴趣的内容。**

### 4.2 工作流程

```
┌─────────────────────────────────────────────────────────────┐
│                      推荐系统流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  用户画像 ──→ 多路召回 ──→ 排序 ──→ 重排 ──→ 展示         │
│     │           │           │        │        │            │
│     │           │           │        │        │            │
│     ▼           ▼           ▼        ▼        ▼            │
│  历史/兴趣   协同过滤    CTR预估  多样性   推荐流          │
│  特征计算   向量召回    深度模型  业务规则                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 核心组件

```
推荐系统核心组件：

1. 用户建模
   ├── 历史行为分析
   ├── 兴趣画像构建
   └── 实时兴趣更新

2. 召回（Recall）
   ├── 协同过滤
   ├── 向量召回
   ├── 内容召回
   └── 热门召回

3. 排序（Ranking）
   ├── CTR/CVR预估
   ├── 多目标优化
   └── Learning to Rank

4. 重排（Re-ranking）
   ├── 多样性控制
   ├── 业务规则
   └── 曝光控制
```

### 4.4 关键指标

| 指标 | 说明 |
|-----|------|
| **CTR** | 点击率 |
| **CVR** | 转化率 |
| **时长** | 用户停留时长 |
| **留存率** | 用户回访率 |
| **覆盖率** | 被推荐物品占比 |
| **多样性** | 推荐结果的多样性 |

### 4.5 特点

| 特点 | 说明 |
|-----|------|
| **系统主动** | 系统主动推送内容 |
| **意图模糊** | 用户没有明确表达需求 |
| **个性化** | 不同用户看到不同内容 |
| **发现性** | 帮助用户发现新内容 |

## 5. 广告系统（Advertising）

### 5.1 定义

**广告系统是广告主付费购买展示机会，系统根据用户和上下文匹配广告内容。**

### 5.2 工作流程

```
┌─────────────────────────────────────────────────────────────┐
│                      广告系统流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  广告请求 ──→ 广告召回 ──→ 排序/竞价 ──→ 展示 ──→ 计费    │
│     │           │             │          │         │        │
│     ▼           ▼             ▼          ▼         ▼        │
│  用户/页面   定向匹配      eCPM排序   广告展示  CPM/CPC     │
│  上下文     相关性筛选    出价×pCTR            CPA/CPV     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.3 核心概念

```
广告核心概念：

1. 广告主（Advertiser）
   - 付费投放广告的一方
   - 关注ROI（投资回报率）

2. 媒体（Publisher）
   - 提供广告位的一方（如抖音、淘宝）
   - 关注收益最大化

3. 用户（User）
   - 看到广告的一方
   - 体验与广告价值的平衡

4. 计费模式
   ├── CPM：按千次展示计费
   ├── CPC：按点击计费
   ├── CPA：按转化计费
   └── oCPM/oCPC：优化目标计费
```

### 5.4 核心组件

```
广告系统核心组件：

1. 广告召回
   ├── 定向条件匹配（地域、年龄、兴趣）
   ├── 预算控制
   └── 频次控制

2. 排序/竞价
   ├── pCTR预估（点击率预估）
   ├── pCVR预估（转化率预估）
   ├── eCPM = bid × pCTR × 1000
   └── 竞价排序

3. 计费
   ├── 一价计费
   ├── 二价计费（GSP）
   └── VCG计费
```

### 5.5 关键指标

| 指标 | 说明 |
|-----|------|
| **CPM** | 千次展示成本 |
| **CPC** | 单次点击成本 |
| **CTR** | 点击率 |
| **CVR** | 转化率 |
| **ROI** | 投资回报率 |
| **收入** | 广告收入 |

## 6. 三者对比

### 6.1 核心区别

| 维度 | 搜索 | 推荐 | 广告 |
|-----|------|-----|-----|
| **触发方式** | 用户主动查询 | 系统主动推送 | 广告主付费 |
| **用户意图** | 明确 | 模糊/无 | 可能无 |
| **输入** | 查询词 | 用户画像 | 广告库+用户信息 |
| **输出** | 相关结果 | 可能感兴趣的内容 | 广告 |
| **目标** | 满足查询需求 | 发现兴趣/提升时长 | 收益最大化 |
| **个性化程度** | 低（基于查询） | 高（基于用户） | 高（基于用户） |

### 6.2 技术对比

| 技术 | 搜索 | 推荐 | 广告 |
|-----|------|-----|-----|
| **召回** | 倒排索引 | 协同过滤/向量 | 定向匹配 |
| **排序** | 相关性 | CTR/CVR预估 | eCPM |
| **评估** | NDCG/MRR | AUC/NDCG | CPM/ROI |
| **延迟要求** | <100ms | <100ms | <50ms |

### 6.3 数据对比

| 数据类型 | 搜索 | 推荐 | 广告 |
|---------|------|-----|-----|
| **用户数据** | 当前查询 | 历史行为 | 历史行为+广告互动 |
| **内容数据** | 网页/商品索引 | 物品库 | 广告库 |
| **上下文** | 查询上下文 | 时间/位置/场景 | 广告位/页面 |

## 8. 选择哪种系统

### 8.1 决策树

```
                    用户需求是什么？
                         │
           ┌─────────────┼─────────────┐
           ▼             ▼             ▼
        明确表达       模糊/无        推广付费
           │             │             │
           ▼             ▼             ▼
       ┌───────┐     ┌───────┐     ┌───────┐
       │ 搜索  │     │ 推荐  │     │ 广告  │
       └───────┘     └───────┘     └───────┘
```

### 8.2 场景匹配

| 场景 | 适合的系统 | 原因 |
|-----|-----------|-----|
| 用户想买特定商品 | 搜索 | 意图明确 |
| 用户想看短视频打发时间 | 推荐 | 无明确目标 |
| 商家想推广商品 | 广告 | 付费推广 |
| 用户想看新闻 | 搜索+推荐 | 可搜可推 |
| 电商首页 | 推荐+广告 | 发现+变现 |

### 8.3 组合使用

大多数产品会**组合使用**：

```
典型产品架构：

1. 内容平台（抖音）
   ├── 推荐：首页信息流
   ├── 搜索：搜索功能
   └── 广告：信息流广告

2. 电商平台（淘宝）
   ├── 搜索：商品搜索
   ├── 推荐：首页推荐、详情页推荐
   └── 广告：直通车、钻展

3. 社交平台（微博）
   ├── 推荐：热搜、推荐流
   ├── 搜索：话题搜索
   └── 广告：信息流广告
```

## 11. 本章总结

### 11.1 核心区别

| 维度 | 搜索 | 推荐 | 广告 |
|-----|------|-----|-----|
| **核心** | 匹配用户查询 | 发现用户兴趣 | 变现流量 |
| **触发** | 用户主动 | 系统主动 | 广告主付费 |
| **目标** | 满足需求 | 提升时长/转化 | 收益最大化 |

### 11.2 联系

1. **技术共通**：CTR预估、Embedding、排序学习
2. **数据共用**：用户行为数据
3. **场景融合**：搜索结果含广告、推荐流含广告

### 11.3 记忆口诀

```
搜索推荐和广告，三者技术有交叉
搜索用户主动查，推荐系统主动推
广告付费来展示，流量变现靠大家
CTR预估通用技，Embedding都能用
```

1. 为什么电商平台同时需要搜索和推荐？
