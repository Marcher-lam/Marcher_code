# FM（因子分解机） 学习文档

## 1. 算法基础认知

### 1.1 什么是 FM？

FM（Factorization Machines，因子分解机）是由 Steffen Rendle 在 2010 年提出的一种通用预测模型。它结合了因子分解模型（如矩阵分解）和支持向量机（SVM）的优点，特别适合处理稀疏数据。

### 1.2 为什么需要 FM？

**逻辑回归的问题：**

逻辑回归模型：
$$\hat{y} = w_0 + \sum_{i=1}^{n} w_i x_i$$

- 只能学习一阶特征，无法捕捉特征之间的交互
- 要学习特征交叉，需要手工构造交叉特征

**多项式回归的问题：**

二阶多项式回归：
$$\hat{y} = w_0 + \sum_{i=1}^{n} w_i x_i + \sum_{i=1}^{n} \sum_{j=i+1}^{n} w_{ij} x_i x_j$$

- 参数量 $O(n^2)$，维度灾难
- 很多交叉特征 $x_i x_j$ 在训练数据中从未出现，无法学习 $w_{ij}$

**FM 的解决方案：**

FM 用隐向量内积代替独立参数：
$$\hat{y} = w_0 + \sum_{i=1}^{n} w_i x_i + \sum_{i=1}^{n} \sum_{j=i+1}^{n} \langle v_i, v_j \rangle x_i x_j$$

- 参数量 $O(nk)$，k 是隐向量维度
- 即使 $x_i x_j$ 未在训练数据中出现，只要有 $x_i$ 或 $x_j$ 出现，就能学到 $v_i$ 或 $v_j$

### 1.3 FM 的优势

| 优势 | 说明 |
|------|------|
| 稀疏数据 | 能在高度稀疏数据下学习特征交叉 |
| 参数少 | O(nk) vs O(n²) |
| 泛化强 | 能预测未见过的特征组合 |
| 效率高 | 线性时间复杂度 O(nk) |
| 通用性 | 可用于回归、分类、排序 |

## 2. 核心原理

### 2.1 模型定义

**二阶 FM：**

$$\hat{y}(x) = w_0 + \sum_{i=1}^{n} w_i x_i + \sum_{i=1}^{n} \sum_{j=i+1}^{n} \langle v_i, v_j \rangle x_i x_j$$

其中：
- $w_0$：全局偏置
- $w_i$：第 i 个特征的权重
- $v_i$：第 i 个特征的 k 维隐向量
- $\langle v_i, v_j \rangle$：隐向量内积，表示特征交叉权重

**隐向量内积：**

$$\langle v_i, v_j \rangle = \sum_{f=1}^{k} v_{i,f} \cdot v_{j,f}$$

### 2.2 时间复杂度优化

**直接计算：** $O(kn^2)$（需要计算所有特征对）

**优化后的计算：** $O(kn)$

推导：
$$\sum_{i=1}^{n} \sum_{j=i+1}^{n} \langle v_i, v_j \rangle x_i x_j$$

$$= \frac{1}{2} \sum_{i=1}^{n} \sum_{j=1}^{n} \langle v_i, v_j \rangle x_i x_j - \frac{1}{2} \sum_{i=1}^{n} \langle v_i, v_i \rangle x_i x_i$$

$$= \frac{1}{2} \left( \sum_{i=1}^{n} \sum_{j=1}^{n} \sum_{f=1}^{k} v_{i,f} v_{j,f} x_i x_j - \sum_{i=1}^{n} \sum_{f=1}^{k} v_{i,f}^2 x_i^2 \right)$$

$$= \frac{1}{2} \sum_{f=1}^{k} \left( \left( \sum_{i=1}^{n} v_{i,f} x_i \right)^2 - \sum_{i=1}^{n} v_{i,f}^2 x_i^2 \right)$$

这样只需要计算每个特征的线性组合，然后平方求和。

### 2.3 高阶 FM

**三阶 FM：**

$$\hat{y}(x) = w_0 + \sum_{i} w_i x_i + \sum_{i<j} \langle v_i, v_j \rangle x_i x_j + \sum_{i<j<l} \langle v_i, v_j, v_l \rangle x_i x_j x_l$$

实际上，二阶 FM 已经足够，因为：
- 高阶交叉可以通过多层二阶 FM 近似
- 二阶交叉通常是信息量最大的

## 3. 数学公式与推导

### 3.1 损失函数

**回归任务：**
$$L = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2$$

**二分类任务：**
$$L = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \log(\sigma(\hat{y}_i)) + (1-y_i) \log(1-\sigma(\hat{y}_i)) \right]$$

其中 $\sigma(x) = \frac{1}{1+e^{-x}}$ 是 Sigmoid 函数。

**排序任务：**
$$L = \sum_{(i,j) \in D} \log(1 + e^{-\hat{y}_i + \hat{y}_j})$$

其中 $(i,j)$ 表示样本 i 应该排在样本 j 前面。

### 3.2 梯度计算

FM 的预测公式：
$$\hat{y} = w_0 + \sum_{i=1}^{n} w_i x_i + \frac{1}{2} \sum_{f=1}^{k} \left( \left( \sum_{i=1}^{n} v_{i,f} x_i \right)^2 - \sum_{i=1}^{n} v_{i,f}^2 x_i^2 \right)$$

**对 $w_0$ 的梯度：**
$$\frac{\partial \hat{y}}{\partial w_0} = 1$$

**对 $w_i$ 的梯度：**
$$\frac{\partial \hat{y}}{\partial w_i} = x_i$$

**对 $v_{i,f}$ 的梯度：**
$$\frac{\partial \hat{y}}{\partial v_{i,f}} = x_i \left( \sum_{j=1}^{n} v_{j,f} x_j - v_{i,f} x_i \right)$$

令 $S_f = \sum_{j=1}^{n} v_{j,f} x_j$，则：
$$\frac{\partial \hat{y}}{\partial v_{i,f}} = x_i (S_f - v_{i,f} x_i)$$

### 3.3 稀疏性分析

在 CTR 预估中，特征向量 x 非常稀疏：

```python
# 原始数据

item_category = "electronics"

# One-Hot 编码后（假设有 100 万用户，1000 类别，10 设备类型）

# 但只有 3 个位置是 1，其余都是 0
```

FM 的优势：
- 只需要对非零特征计算
- 时间复杂度从 O(nk) 降到 O(nnz(x) × k)，其中 nnz(x) 是非零元素数

### 4.2 训练流程

```python
import numpy as np

def train_fm(X, y, k=10, learning_rate=0.01, reg_param=0.01, n_epochs=100):
    """
    训练 FM 模型（简化版）

    参数:
        X: 特征矩阵 (n_samples, n_features)，稀疏
        y: 标签 (n_samples,)
        k: 隐向量维度
        learning_rate: 学习率
        reg_param: 正则化参数
        n_epochs: 迭代次数
    """
    n_samples, n_features = X.shape

    # 初始化参数
    w0 = 0
    w = np.zeros(n_features)
    V = np.random.normal(0, 0.1, (n_features, k))

    for epoch in range(n_epochs):
        total_loss = 0

        for i in range(n_samples):
            x = X[i]
            y_true = y[i]

            # 预测
            linear = w0 + np.dot(w, x)

            # 交叉项（优化计算）
            cross = 0
            for f in range(k):
                sum_vx = np.dot(V[:, f], x)
                sum_vx2 = np.dot(V[:, f]**2, x**2)
                cross += 0.5 * (sum_vx**2 - sum_vx2)

            y_pred = linear + cross

            # 计算误差
            error = y_pred - y_true  # 回归
            total_loss += error ** 2

            # 更新参数
            w0 -= learning_rate * error
            w -= learning_rate * (error * x + reg_param * w)

            # 更新 V
            for f in range(k):
                sum_vx = np.dot(V[:, f], x)
                for j in np.where(x != 0)[0]:
                    V[j, f] -= learning_rate * (error * x[j] * (sum_vx - V[j, f] * x[j]) + reg_param * V[j, f])

        rmse = np.sqrt(total_loss / n_samples)
        if (epoch + 1) % 10 == 0:
            print(f"Epoch {epoch+1}, RMSE: {rmse:.4f}")

    return w0, w, V
```

#### AdaGrad 优化器

```python
class FMAdaGrad:
    """使用 AdaGrad 的 FM 训练"""

    def __init__(self, n_features, k=10, learning_rate=0.1, eps=1e-8):
        self.k = k
        self.lr = learning_rate
        self.eps = eps

        # 参数
        self.w0 = 0
        self.w = np.zeros(n_features)
        self.V = np.random.normal(0, 0.1, (n_features, k))

        # 梯度累积平方
        self.w0_grad_sq = 0
        self.w_grad_sq = np.zeros(n_features)
        self.V_grad_sq = np.zeros((n_features, k))

    def predict(self, x):
        """预测"""
        linear = self.w0 + np.dot(self.w, x)

        cross = 0
        for f in range(self.k):
            sum_vx = np.dot(self.V[:, f], x)
            sum_vx2 = np.dot(self.V[:, f]**2, x**2)
            cross += 0.5 * (sum_vx**2 - sum_vx2)

        return linear + cross

    def update(self, x, error, reg_param=0.01):
        """AdaGrad 更新"""
        # 更新 w0
        grad_w0 = error
        self.w0_grad_sq += grad_w0 ** 2
        self.w0 -= self.lr / (np.sqrt(self.w0_grad_sq) + self.eps) * grad_w0

        # 更新 w（只对非零特征）
        nonzero_idx = np.where(x != 0)[0]
        for j in nonzero_idx:
            grad_w = error * x[j] + reg_param * self.w[j]
            self.w_grad_sq[j] += grad_w ** 2
            self.w[j] -= self.lr / (np.sqrt(self.w_grad_sq[j]) + self.eps) * grad_w

        # 更新 V
        for f in range(self.k):
            sum_vx = np.dot(self.V[:, f], x)
            for j in nonzero_idx:
                grad_v = error * x[j] * (sum_vx - self.V[j, f] * x[j]) + reg_param * self.V[j, f]
                self.V_grad_sq[j, f] += grad_v ** 2
                self.V[j, f] -= self.lr / (np.sqrt(self.V_grad_sq[j, f]) + self.eps) * grad_v
```

## 6. 优缺点分析

### 6.1 优点

1. **处理稀疏数据**：在高度稀疏数据下仍能有效学习
2. **参数量小**：O(nk) vs O(n²)
3. **泛化能力强**：能预测未见过的特征组合
4. **线性时间复杂度**：O(k × nnz(x))
5. **通用性**：支持回归、分类、排序

### 6.2 缺点

1. **只有二阶交叉**：需要更高阶交叉时效果有限
2. **隐向量维度选择**：k 的选择需要调参
3. **特征工程仍重要**：好的特征仍能提升效果

### 6.3 与其他模型对比

| 模型 | 特征交叉 | 参数量 | 稀疏数据 | 复杂度 |
|------|----------|--------|----------|--------|
| LR | 无 | O(n) | 好 | 低 |
| Poly2 | 二阶 | O(n²) | 差 | 中 |
| FM | 二阶 | O(nk) | 好 | 低 |
| FFM | 二阶（字段级） | O(nfk) | 好 | 中 |
| DeepFM | 二阶+高阶 | 大 | 好 | 高 |

### 7.3 使用 PyTorch 实现

```python
import torch
import torch.nn as nn

class FactorizationMachine(nn.Module):
    """
    PyTorch 实现的 FM
    """

    def __init__(self, num_features, num_fields, embed_dim):
        super().__init__()

        # 特征嵌入
        self.embedding = nn.Embedding(num_features, embed_dim)

        # 一阶特征
        self.linear = nn.Embedding(num_features, 1)

        # 偏置
        self.bias = nn.Parameter(torch.zeros(1))

    def forward(self, x):
        """
        参数:
            x: (batch_size, num_fields) 每个字段对应的特征索引
        """
        # 一阶特征
        linear = self.linear(x).squeeze(-1)  # (batch, num_fields)
        linear = linear.sum(dim=1)  # (batch,)

        # 二阶交叉
        emb = self.embedding(x)  # (batch, num_fields, embed_dim)

        # 优化计算: sum(embed)^2 - sum(embed^2)
        sum_emb = emb.sum(dim=1)  # (batch, embed_dim)
        sum_emb_sq = sum_emb ** 2

        emb_sq = emb ** 2
        sum_emb_sq_ = emb_sq.sum(dim=1)

        cross = 0.5 * (sum_emb_sq - sum_emb_sq_).sum(dim=1)  # (batch,)

        # 输出
        output = self.bias + linear + cross
        return output.squeeze()


class FMForCTR(nn.Module):
    """
    用于 CTR 预估的 FM
    """

    def __init__(self, field_dims, embed_dim):
        super().__init__()

        self.num_fields = len(field_dims)
        self.embeddings = nn.ModuleList([
            nn.Embedding(dim, embed_dim) for dim in field_dims
        ])
        self.linear = nn.ModuleList([
            nn.Embedding(dim, 1) for dim in field_dims
        ])
        self.bias = nn.Parameter(torch.zeros(1))

    def forward(self, x):
        """
        参数:
            x: (batch, num_fields) 每个字段是特征索引
        """
        batch_size = x.size(0)

        # 一阶特征
        linear = torch.cat([
            self.linear[i](x[:, i]) for i in range(self.num_fields)
        ], dim=1).sum(dim=1)

        # 二阶特征
        embeddings = torch.cat([
            self.embeddings[i](x[:, i]).unsqueeze(1)
            for i in range(self.num_fields)
        ], dim=1)  # (batch, num_fields, embed_dim)

        # 优化计算
        sum_emb = embeddings.sum(dim=1)  # (batch, embed_dim)
        sum_emb_sq = sum_emb ** 2

        emb_sq = embeddings ** 2
        sum_emb_sq_ = emb_sq.sum(dim=1)

        cross = 0.5 * (sum_emb_sq - sum_emb_sq_).sum(dim=1)

        output = self.bias.squeeze() + linear + cross
        return torch.sigmoid(output)


# 使用示例
if __name__ == "__main__":
```

## 8. 手工代码实现

### 8.1 完整的 FM 实现

```python
import numpy as np
from collections import defaultdict

class FactorizationMachine:
    """
    完整的 FM 实现
    """

    def __init__(self, k=10, learning_rate=0.01, reg_w=0.01, reg_v=0.01,
                 n_epochs=100, task='classification', random_state=42):
        """
        参数:
            k: 隐向量维度
            learning_rate: 学习率
            reg_w: 一阶权重正则化
            reg_v: 隐向量正则化
            n_epochs: 迭代次数
            task: 'classification' 或 'regression'
            random_state: 随机种子
        """
        self.k = k
        self.lr = learning_rate
        self.reg_w = reg_w
        self.reg_v = reg_v
        self.n_epochs = n_epochs
        self.task = task
        self.random_state = random_state

        # 模型参数
        self.w0 = 0
        self.w = None
        self.V = None

        # 特征数量
        self.n_features = 0

    def fit(self, X, y):
        """
        训练模型

        参数:
            X: 特征矩阵 (n_samples, n_features)，支持稀疏
            y: 标签
        """
        np.random.seed(self.random_state)

        X = np.asarray(X)
        y = np.asarray(y)

        n_samples, self.n_features = X.shape

        # 初始化参数
        self.w0 = 0
        self.w = np.zeros(self.n_features)
        self.V = np.random.normal(0, 0.1, (self.n_features, self.k))

        # 训练
        for epoch in range(self.n_epochs):
            # 打乱数据
            indices = np.random.permutation(n_samples)
            total_loss = 0

            for idx in indices:
                x = X[idx]
                y_true = y[idx]

                # 预测
                y_pred = self._predict_single(x)

                # 计算误差
                if self.task == 'classification':
                    y_pred_sigmoid = self._sigmoid(y_pred)
                    error = y_pred_sigmoid - y_true
                    loss = -y_true * np.log(y_pred_sigmoid + 1e-10) - \
                           (1 - y_true) * np.log(1 - y_pred_sigmoid + 1e-10)
                else:
                    error = y_pred - y_true
                    loss = error ** 2

                total_loss += loss

                # 更新参数
                self._update(x, error)

            avg_loss = total_loss / n_samples
            if (epoch + 1) % 10 == 0:
                print(f"Epoch {epoch+1}/{self.n_epochs}, Loss: {avg_loss:.4f}")

        return self

    def _predict_single(self, x):
        """单个样本预测"""
        # 一阶项
        linear = self.w0 + np.dot(self.w, x)

        # 二阶交叉项（优化计算）
        cross = 0
        for f in range(self.k):
            # 只对非零特征计算
            nonzero_idx = np.where(x != 0)[0]
            if len(nonzero_idx) == 0:
                continue

            sum_vx = np.sum(self.V[nonzero_idx, f] * x[nonzero_idx])
            sum_vx2 = np.sum(self.V[nonzero_idx, f]**2 * x[nonzero_idx]**2)
            cross += 0.5 * (sum_vx**2 - sum_vx2)

        return linear + cross

    def _update(self, x, error):
        """更新参数"""
        # 更新 w0
        self.w0 -= self.lr * error

        # 更新 w（只对非零特征）
        nonzero_idx = np.where(x != 0)[0]
        for j in nonzero_idx:
            grad = error * x[j] + self.reg_w * self.w[j]
            self.w[j] -= self.lr * grad

        # 更新 V
        for f in range(self.k):
            sum_vx = np.sum(self.V[nonzero_idx, f] * x[nonzero_idx])
            for j in nonzero_idx:
                grad = error * x[j] * (sum_vx - self.V[j, f] * x[j]) + self.reg_v * self.V[j, f]
                self.V[j, f] -= self.lr * grad

    def predict(self, X):
        """
        预测
        """
        X = np.asarray(X)
        predictions = []

        for x in X:
            y_pred = self._predict_single(x)
            if self.task == 'classification':
                y_pred = self._sigmoid(y_pred)
            predictions.append(y_pred)

        return np.array(predictions)

    def predict_proba(self, X):
        """
        预测概率（分类任务）
        """
        if self.task != 'classification':
            raise ValueError("predict_proba only for classification")

        return self.predict(X)

    def _sigmoid(self, x):
        """Sigmoid 函数"""
        return 1 / (1 + np.exp(-np.clip(x, -500, 500)))

    def get_feature_importance(self):
        """获取特征重要性"""
        # 一阶特征重要性
        w_importance = np.abs(self.w)

        # 二阶特征重要性（隐向量范数）
        v_importance = np.linalg.norm(self.V, axis=1)

        # 综合重要性
        total_importance = w_importance + v_importance

        return {
            'linear_importance': w_importance,
            'cross_importance': v_importance,
            'total_importance': total_importance
        }
```

```python
from sklearn.metrics import roc_auc_score, log_loss, accuracy_score

def evaluate_fm(model, X_test, y_test):
    """
    评估 FM 模型
    """
    y_pred = model.predict_proba(X_test)

    metrics = {
        'AUC': roc_auc_score(y_test, y_pred),
        'LogLoss': log_loss(y_test, y_pred),
        'Accuracy': accuracy_score(y_test, (y_pred > 0.5).astype(int))
    }

    # 分位数校准
    percentiles = [10, 25, 50, 75, 90]
    calibration = {}
    for p in percentiles:
        threshold = np.percentile(y_pred, p)
        mask = (y_pred >= threshold) & (y_pred < np.percentile(y_pred, p + 10))
        if mask.sum() > 0:
            predicted = y_pred[mask].mean()
            actual = y_test[mask].mean()
            calibration[p] = actual / predicted if predicted > 0 else 0

    metrics['Calibration'] = calibration

    return metrics
```

## 11. 常见问题与易错点

### 11.1 常见问题

**Q1：FM 的隐向量维度 k 如何选择？**

A：通常在 8-64 之间，可以通过交叉验证选择。k 越大，模型越复杂，但训练时间也越长。

**Q2：FM 和 FFM 有什么区别？**

A：FFM（Field-aware FM）为每个字段对学习不同的隐向量，参数量更大，但在某些场景下效果更好。

**Q3：如何处理新特征？**

A：FM 需要预先知道所有特征，新特征需要重新训练或使用默认嵌入初始化。

### 11.2 易错点

1. **忘记优化计算**：直接计算所有特征对导致 O(n²k) 复杂度
2. **特征未归一化**：数值特征需要归一化
3. **正则化不当**：过强的正则化会导致欠拟合
4. **学习率太大**：训练不稳定

## 12. 学习总结

### 12.1 核心要点

1. **FM = LR + 隐向量交叉**：用隐向量内积学习特征交互
2. **线性时间复杂度**：优化后为 O(k × nnz(x))
3. **泛化能力强**：能预测未见过的特征组合
4. **稀疏数据友好**：只对非零特征计算
