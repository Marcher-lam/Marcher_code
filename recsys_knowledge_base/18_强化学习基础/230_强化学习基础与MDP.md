## 1. 算法基础认知

### 1.1 什么是强化学习

**强化学习（Reinforcement Learning, RL）** 是智能体通过与环境交互，学习最大化累积奖励的策略。

```
推荐系统中的RL视角:
  智能体: 推荐模型
  环境: 用户
  动作: 推荐哪个物品
  状态: 用户历史行为、上下文
  奖励: 用户点击/购买/停留时长

目标: 学习一个策略π，使得长期累积奖励最大
```

### 1.2 核心概念

| 概念 | 说明 | 推荐系统对应 |
|------|------|------------|
| **State (S)** | 环境当前状态 | 用户历史+上下文 |
| **Action (A)** | 智能体的行为 | 推荐的物品 |
| **Reward (R)** | 即时反馈 | CTR/CVR/时长 |
| **Policy (π)** | 决策规则 | 推荐策略 |
| **Value (V)** | 长期价值估计 | 用户长期价值 |

## 2. MDP（马尔可夫决策过程）

### 2.1 定义

MDP由 $(S, A, P, R, \gamma)$ 定义：

- $S$: 状态空间
- $A$: 动作空间
- $P(s'|s,a)$: 转移概率
- $R(s,a)$: 奖励函数
- $\gamma$: 折扣因子 $(0 \leq \gamma \leq 1)$

### 2.2 价值函数

**状态价值函数**：

$$V^\pi(s) = \mathbb{E}_\pi\left[\sum_{t=0}^{\infty}\gamma^t R_{t+1} | S_0 = s\right]$$

**动作价值函数（Q函数）**：

$$Q^\pi(s,a) = \mathbb{E}_\pi\left[\sum_{t=0}^{\infty}\gamma^t R_{t+1} | S_0 = s, A_0 = a\right]$$

### 2.3 Bellman方程

$$V^\pi(s) = \sum_a \pi(a|s)\sum_{s'}P(s'|s,a)[R(s,a) + \gamma V^\pi(s')]$$

$$Q^\pi(s,a) = \sum_{s'}P(s'|s,a)[R(s,a) + \gamma \sum_{a'}\pi(a'|s')Q^\pi(s',a')]$$

## 3. 多臂老虎机（Multi-Armed Bandit）

### 3.1 问题定义

K个臂（物品），每个臂有未知奖励分布。目标：最大化累积奖励。

### 3.2 探索-利用困境

```
利用(Exploit): 选择当前最好的臂
探索(Explore): 尝试不确定的臂，可能发现更好的

推荐系统: 推用户已知喜欢的(利用) vs 推新内容(探索)
```

### 3.3 UCB算法

$$a_t = \arg\max_a \left[\bar{R}_a + \sqrt{\frac{2\ln t}{N_a}}\right]$$

- $\bar{R}_a$: 臂a的平均奖励
- $N_a$: 臂a被选中的次数

### 3.4 Thompson Sampling

对每个臂维护奖励概率的Beta分布后验，从中采样选择：

```python
import numpy as np

def thompson_sampling(bandit_probs, n_rounds):
    K = len(bandit_probs)
    successes = np.zeros(K)
    failures = np.zeros(K)
    
    for t in range(n_rounds):
        # 从Beta后验采样
        samples = [np.random.beta(successes[k]+1, failures[k]+1) for k in range(K)]
        # 选择采样值最大的臂
        arm = np.argmax(samples)
        # 观察奖励
        reward = np.random.rand() < bandit_probs[arm]
        if reward:
            successes[arm] += 1
        else:
            failures[arm] += 1
    
    return successes, failures
```

## 4. 时序差分学习（TD Learning）

### 4.1 TD(0)

$$V(S_t) \leftarrow V(S_t) + \alpha[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)]$$

> 用当前的估计去更新上一时刻的估计（自举/Bootstrap）。

### 4.2 SARSA

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha[R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t)]$$

### 4.3 Q-Learning

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha[R_{t+1} + \gamma \max_{a'}Q(S_{t+1}, a') - Q(S_t, A_t)]$$

> Q-Learning是off-policy的（使用max而非实际策略的Q值）。

## 5. 深度强化学习

### 5.1 DQN

用神经网络近似Q函数：

$$L = \mathbb{E}\left[(r + \gamma \max_{a'}Q_\theta(s', a') - Q_\theta(s, a))^2\right]$$

关键技巧：经验回放 + 目标网络

### 5.2 REINFORCE（策略梯度）

$$\nabla J(\theta) = \mathbb{E}_\pi\left[\nabla\log\pi_\theta(a|s) \cdot G_t\right]$$

$$\theta \leftarrow \theta + \alpha \nabla\log\pi_\theta(a|s) \cdot G_t$$

### 5.3 PPO（Proximal Policy Optimization）

$$L^{CLIP}(\theta) = \mathbb{E}\left[\min(r_t(\theta)\hat{A}_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t)\right]$$

- $r_t(\theta) = \frac{\pi_\theta(a|s)}{\pi_{\theta_{old}}(a|s)}$: 重要性采样比
- $\hat{A}_t$: 优势函数估计

> PPO通过裁剪限制策略更新幅度，保证训练稳定。

### 5.4 Actor-Critic架构

```
Actor(策略网络):  输入状态 → 输出动作概率
Critic(价值网络): 输入状态 → 输出状态价值

优势函数: A(s,a) = Q(s,a) - V(s) = r + γV(s') - V(s)
```

### 5.5 DDPG / SAC / TD3

| 算法 | 特点 |
|------|------|
| **DDPG** | 确定策略梯度，适用于连续动作 |
| **SAC** | 最大熵RL，鼓励探索 |
| **TD3** | DDPG改进，双Q网络+延迟更新 |

## 7. 调库实现

```python
"""
Q-Learning 实现（推荐系统简化场景）
"""
import numpy as np

class QLearningRecommender:
    """用Q-Learning做简单推荐"""
    
    def __init__(self, n_states, n_actions, lr=0.1, gamma=0.9, epsilon=0.1):
        self.Q = np.zeros((n_states, n_actions))
        self.lr = lr
        self.gamma = gamma
        self.epsilon = epsilon
    
    def choose_action(self, state):
        """ε-greedy策略"""
        if np.random.rand() < self.epsilon:
            return np.random.randint(self.Q.shape[1])
        return np.argmax(self.Q[state])
    
    def update(self, state, action, reward, next_state):
        """Q-Learning更新"""
        td_target = reward + self.gamma * np.max(self.Q[next_state])
        td_error = td_target - self.Q[state, action]
        self.Q[state, action] += self.lr * td_error


if __name__ == "__main__":
    # 简化场景: 5个用户状态, 10个可推荐物品
    recommender = QLearningRecommender(n_states=5, n_actions=10)
    
    # 模拟训练
    for episode in range(1000):
        state = np.random.randint(5)
        action = recommender.choose_action(state)
        reward = np.random.rand()  # 模拟用户反馈
        next_state = np.random.randint(5)
        recommender.update(state, action, reward, next_state)
    
    # 查看学到的策略
    print("学到的推荐策略（每个状态最优动作）:")
    for s in range(5):
        print(f"  状态{s}: 推荐物品 {np.argmax(recommender.Q[s])}")
```

## 12. 学习总结

1. **RL核心**：智能体通过交互学习最优策略
2. **MDP**是RL的数学框架
3. **Bandit**是最简单的RL问题（单步决策）
4. **TD学习** = 蒙特卡洛 + 动态规划的折中
5. **DQN/PPO/SAC**是当前主流深度RL算法
6. **在推荐中**：长期奖励优化、探索利用平衡、推荐策略优化

## 13. 练习题

**Q1**：为什么推荐系统需要考虑长期奖励而非只优化即时CTR？

<details>
<summary>答案</summary>

只优化即时CTR会导致推荐标题党、低质量但吸引眼球的内容，用户长期体验下降。RL可以建模：
- 点击后是否真正满意（用户停留时长）
- 是否会回来（用户留存）
- 推荐多样性（避免信息茧房）

这些都是需要考虑长期影响的指标。

</details>
