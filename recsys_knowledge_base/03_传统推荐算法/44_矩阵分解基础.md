# 矩阵分解基础 学习文档

## 1. 算法基础认知

### 1.1 什么是矩阵分解？

矩阵分解（Matrix Factorization, MF）是推荐系统中最重要的技术之一。它的核心思想是将一个大的稀疏矩阵分解为两个或多个小矩阵的乘积。

在推荐系统中，我们通常有一个用户-物品评分矩阵 R（m×n），其中 m 是用户数，n 是物品数。矩阵分解的目标是找到：
- 用户矩阵 P（m×k）
- 物品矩阵 Q（n×k）

使得 P × Q^T ≈ R

### 1.2 为什么需要矩阵分解？

**协同过滤的问题：**
1. **数据稀疏性**：实际场景中，用户只对极少数物品有评分，矩阵非常稀疏
2. **冷启动问题**：新用户或新物品没有足够的历史数据
3. **可扩展性**：UserCF 和 ItemCF 在大规模数据下计算复杂度高
4. **泛化能力**：协同过滤只能推荐用户或物品相似的内容

**矩阵分解的优势：**
1. **隐因子建模**：自动发现用户和物品的隐含特征
2. **降维压缩**：将高维稀疏矩阵压缩为低维稠密矩阵
3. **泛化能力**：可以预测用户对未见物品的偏好
4. **可扩展性**：训练后预测速度快

### 1.3 直观理解

想象一个电影推荐场景：
- 用户矩阵 P 的每一行代表一个用户的偏好向量
- 物品矩阵 Q 的每一行代表一个电影的特征向量
- 隐因子 k 可以理解为：动作、爱情、科幻、喜剧等隐含类型
- 用户对电影的评分 ≈ 用户偏好 × 电影特征的匹配程度

```
用户-物品矩阵 R (稀疏)          用户矩阵 P           物品矩阵 Q
    物品1 物品2 物品3           隐因子1 隐因子2      隐因子1 隐因子2
用户1 [5,  ?,  3]           用户1 [0.8, 0.2]      物品1 [0.9, 0.1]
用户2 [?,  4,  ?]    ≈      用户2 [0.3, 0.7]  ×   物品2 [0.2, 0.8]
用户3 [4,  2,  ?]           用户3 [0.7, 0.3]      物品3 [0.6, 0.4]
```

## 2. 核心原理

### 2.1 数学建模

**目标函数：**

找到 P 和 Q，使得预测评分矩阵 $\hat{R} = PQ^T$ 尽可能接近真实评分矩阵 R。

对于已知的评分 $r_{ui}$（用户 u 对物品 i 的评分）：

$$\hat{r}_{ui} = p_u \cdot q_i^T = \sum_{k=1}^{K} p_{uk} q_{ik}$$

**损失函数（带正则化）：**

$$J = \frac{1}{2} \sum_{(u,i) \in \mathcal{K}} (r_{ui} - p_u \cdot q_i^T)^2 + \frac{\lambda}{2} (||P||^2 + ||Q||^2)$$

其中：
- $\mathcal{K}$ 是已知评分的集合
- $\lambda$ 是正则化系数，防止过拟合
- $||P||^2$ 和 $||Q||^2$ 是 Frobenius 范数

### 2.2 优化方法

#### 方法一：随机梯度下降（SGD）

**梯度计算：**

对于每个已知评分 $(u, i)$：

$$e_{ui} = r_{ui} - p_u \cdot q_i^T$$

$$\frac{\partial J}{\partial p_{uk}} = -e_{ui} \cdot q_{ik} + \lambda p_{uk}$$

$$\frac{\partial J}{\partial q_{ik}} = -e_{ui} \cdot p_{uk} + \lambda q_{ik}$$

**更新规则：**

$$p_{uk} \leftarrow p_{uk} + \alpha (e_{ui} \cdot q_{ik} - \lambda p_{uk})$$

$$q_{ik} \leftarrow q_{ik} + \alpha (e_{ui} \cdot p_{uk} - \lambda q_{ik})$$

其中 $\alpha$ 是学习率。

#### 方法二：交替最小二乘法（ALS）

**原理：**
- 固定 Q，优化 P：问题变成关于 P 的二次优化问题，有闭式解
- 固定 P，优化 Q：问题变成关于 Q 的二次优化问题，有闭式解
- 交替迭代直到收敛

**优点：**
- 每步都能保证损失下降
- 并行化友好
- 适合隐式反馈场景

### 2.3 算法流程

```
输入：评分矩阵 R，隐因子数 K，学习率 α，正则化参数 λ，迭代次数 T
输出：用户矩阵 P，物品矩阵 Q

1. 随机初始化 P 和 Q
2. for t = 1 to T:
3.     for each (u, i) in 已知评分集合:
4.         计算误差: e_{ui} = r_{ui} - p_u · q_i^T
5.         更新 p_u: p_u = p_u + α(e_{ui} · q_i - λ · p_u)
6.         更新 q_i: q_i = q_i + α(e_{ui} · p_u - λ · q_i)
7. 返回 P, Q
```

## 3. 数学公式与推导

### 3.1 损失函数推导

**目标**：最小化预测误差的平方和

$$\min_{P,Q} \sum_{(u,i) \in \mathcal{K}} (r_{ui} - \sum_{k=1}^{K} p_{uk} q_{ik})^2$$

**添加正则化项：**

$$\min_{P,Q} \sum_{(u,i) \in \mathcal{K}} (r_{ui} - \sum_{k=1}^{K} p_{uk} q_{ik})^2 + \lambda \sum_{u,k} p_{uk}^2 + \lambda \sum_{i,k} q_{ik}^2$$

### 3.2 梯度推导详解

令 $\hat{r}_{ui} = \sum_{k=1}^{K} p_{uk} q_{ik}$

损失函数对 $p_{uk}$ 的偏导：

$$\frac{\partial J}{\partial p_{uk}} = \frac{\partial}{\partial p_{uk}} \left[ \frac{1}{2}(r_{ui} - \hat{r}_{ui})^2 + \frac{\lambda}{2} p_{uk}^2 \right]$$

$$= -(r_{ui} - \hat{r}_{ui}) \cdot \frac{\partial \hat{r}_{ui}}{\partial p_{uk}} + \lambda p_{uk}$$

$$= -(r_{ui} - \hat{r}_{ui}) \cdot q_{ik} + \lambda p_{uk}$$

$$= -e_{ui} \cdot q_{ik} + \lambda p_{uk}$$

同理可得 $\frac{\partial J}{\partial q_{ik}} = -e_{ui} \cdot p_{uk} + \lambda q_{ik}$

### 3.3 预测公式

训练完成后，用户 u 对物品 i 的预测评分：

$$\hat{r}_{ui} = \sum_{k=1}^{K} p_{uk} q_{ik} = p_u \cdot q_i^T$$

### 4.2 训练过程详解

```python
def train_mf_sgd(R, K=10, alpha=0.01, lambda_=0.1, epochs=100):
    """
    使用SGD训练矩阵分解

    参数:
        R: 用户-物品评分矩阵 (稀疏)
        K: 隐因子数量
        alpha: 学习率
        lambda_: 正则化系数
        epochs: 迭代次数
    """
    n_users, n_items = R.shape

    # 初始化
    P = np.random.randn(n_users, K) * 0.01
    Q = np.random.randn(n_items, K) * 0.01

    # 获取非零元素的索引
    users, items = R.nonzero()

    for epoch in range(epochs):
        # 打乱训练数据
        indices = np.random.permutation(len(users))

        for idx in indices:
            u, i = users[idx], items[idx]

            # 计算误差
            e_ui = R[u, i] - np.dot(P[u], Q[i])

            # 更新参数
            P[u] += alpha * (e_ui * Q[i] - lambda_ * P[u])
            Q[i] += alpha * (e_ui * P[u] - lambda_ * Q[i])

        # 计算训练误差
        if (epoch + 1) % 10 == 0:
            loss = compute_loss(R, P, Q, lambda_)
            print(f"Epoch {epoch+1}: Loss = {loss:.4f}")

    return P, Q
```

### 4.3 训练技巧

1. **学习率调度**：随着训练进行逐渐减小学习率
2. **早停**：当验证集损失不再下降时停止训练
3. **批量SGD**：每次更新使用一个小批量样本
4. **动量**：加速收敛并避免局部最优

## 5. 应用场景

### 5.1 适用场景

| 场景 | 说明 |
|------|------|
| 电影/音乐推荐 | 预测用户对内容的评分 |

### 5.2 显式反馈 vs 隐式反馈

**显式反馈：**
- 用户直接给出评分（1-5星）
- 用户点赞/收藏
- 用户评价

**隐式反馈：**
- 浏览行为
- 购买记录
- 停留时间

隐式反馈需要特殊处理（如加权、置信度），后续 FunkSVD 会详细讲解。

## 6. 优缺点分析

### 6.1 优点

1. **隐因子建模**：自动学习用户和物品的隐含特征
2. **处理稀疏性**：对稀疏数据有较好的泛化能力
3. **可扩展性**：训练后预测复杂度低 O(K)
4. **灵活性**：容易添加额外特征（如 BiasSVD）
5. **理论基础**：有完整的数学理论支撑

### 6.2 缺点

1. **冷启动**：无法处理新用户或新物品
2. **可解释性差**：隐因子难以解释其含义
3. **参数敏感**：K、α、λ 需要调优
4. **训练时间**：大规模数据训练较慢
5. **单点估计**：不提供预测的不确定性

### 7.3 使用 TensorFlow/PyTorch 实现

```python
import torch
import torch.nn as nn
import torch.optim as optim

class MatrixFactorization(nn.Module):
    def __init__(self, n_users, n_items, n_factors=20):
        super().__init__()
        # 用户嵌入矩阵
        self.user_embedding = nn.Embedding(n_users, n_factors)
        # 物品嵌入矩阵
        self.item_embedding = nn.Embedding(n_items, n_factors)

        # 初始化
        nn.init.normal_(self.user_embedding.weight, std=0.01)
        nn.init.normal_(self.item_embedding.weight, std=0.01)

    def forward(self, user_ids, item_ids):
        user_factors = self.user_embedding(user_ids)  # (batch, n_factors)
        item_factors = self.item_embedding(item_ids)  # (batch, n_factors)

        # 点积预测评分
        prediction = (user_factors * item_factors).sum(dim=1)
        return prediction

# 训练代码
def train_pytorch_mf(train_data, n_users, n_items, n_factors=50, epochs=100):
    """
    使用 PyTorch 训练矩阵分解
    """
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

    model = MatrixFactorization(n_users, n_items, n_factors).to(device)
    optimizer = optim.Adam(model.parameters(), lr=0.01, weight_decay=0.001)  # weight_decay 即 L2 正则
    criterion = nn.MSELoss()

    # 准备数据
    user_ids = torch.LongTensor(train_data[:, 0]).to(device)
    item_ids = torch.LongTensor(train_data[:, 1]).to(device)
    ratings = torch.FloatTensor(train_data[:, 2]).to(device)

    for epoch in range(epochs):
        model.train()
        optimizer.zero_grad()

        predictions = model(user_ids, item_ids)
        loss = criterion(predictions, ratings)

        loss.backward()
        optimizer.step()

        if (epoch + 1) % 10 == 0:
            print(f"Epoch {epoch+1}: Loss = {loss.item():.4f}")

    return model
```

## 8. 手工代码实现

### 8.1 完整的 SGD 实现

```python
import numpy as np
from collections import defaultdict

class MatrixFactorizationSGD:
    """
    基于随机梯度下降的矩阵分解实现
    """

    def __init__(self, n_factors=100, learning_rate=0.005,
                 reg_param=0.02, n_epochs=20, random_state=42):
        """
        参数:
            n_factors: 隐因子数量
            learning_rate: 学习率
            reg_param: 正则化参数
            n_epochs: 迭代次数
            random_state: 随机种子
        """
        self.n_factors = n_factors
        self.learning_rate = learning_rate
        self.reg_param = reg_param
        self.n_epochs = n_epochs
        self.random_state = random_state

        # 用户和物品的 ID 映射
        self.user_id_map = {}
        self.item_id_map = {}
        self.n_users = 0
        self.n_items = 0

        # 模型参数
        self.P = None  # 用户因子矩阵
        self.Q = None  # 物品因子矩阵

    def fit(self, user_ids, item_ids, ratings, verbose=True):
        """
        训练模型

        参数:
            user_ids: 用户 ID 列表
            item_ids: 物品 ID 列表
            ratings: 评分列表
            verbose: 是否打印训练信息
        """
        np.random.seed(self.random_state)

        # 构建 ID 映射
        unique_users = list(set(user_ids))
        unique_items = list(set(item_ids))
        self.user_id_map = {uid: i for i, uid in enumerate(unique_users)}
        self.item_id_map = {iid: i for i, iid in enumerate(unique_items)}
        self.n_users = len(unique_users)
        self.n_items = len(unique_items)

        # 初始化因子矩阵
        self.P = np.random.normal(0, 0.1, (self.n_users, self.n_factors))
        self.Q = np.random.normal(0, 0.1, (self.n_items, self.n_factors))

        # 转换数据格式
        train_data = []
        for u, i, r in zip(user_ids, item_ids, ratings):
            u_idx = self.user_id_map[u]
            i_idx = self.item_id_map[i]
            train_data.append((u_idx, i_idx, r))

        # SGD 训练
        for epoch in range(self.n_epochs):
            np.random.shuffle(train_data)
            total_loss = 0

            for u_idx, i_idx, r in train_data:
                # 预测评分
                pred = np.dot(self.P[u_idx], self.Q[i_idx])

                # 计算误差
                error = r - pred
                total_loss += error ** 2

                # 更新因子
                # 注意：需要保存旧值用于更新
                p_old = self.P[u_idx].copy()

                self.P[u_idx] += self.learning_rate * (
                    error * self.Q[i_idx] - self.reg_param * self.P[u_idx]
                )
                self.Q[i_idx] += self.learning_rate * (
                    error * p_old - self.reg_param * self.Q[i_idx]
                )

            # 计算正则化损失
            reg_loss = self.reg_param * (
                np.sum(self.P ** 2) + np.sum(self.Q ** 2)
            )
            total_loss = total_loss + reg_loss

            if verbose and (epoch + 1) % 5 == 0:
                rmse = np.sqrt(total_loss / len(train_data))
                print(f"Epoch {epoch+1}/{self.n_epochs}, RMSE: {rmse:.4f}")

        return self

    def predict(self, user_id, item_id):
        """
        预测用户对物品的评分
        """
        if user_id not in self.user_id_map or item_id not in self.item_id_map:
            # 未知用户或物品，返回全局平均或默认值
            return 0

        u_idx = self.user_id_map[user_id]
        i_idx = self.item_id_map[item_id]

        return np.dot(self.P[u_idx], self.Q[i_idx])

    def recommend(self, user_id, n_items=10, exclude_items=None):
        """
        为用户推荐物品

        参数:
            user_id: 用户 ID
            n_items: 推荐物品数量
            exclude_items: 要排除的物品列表（如已交互物品）

        返回:
            推荐物品 ID 列表及其预测评分
        """
        if user_id not in self.user_id_map:
            return []

        u_idx = self.user_id_map[user_id]
        user_factors = self.P[u_idx]

        # 计算所有物品的预测评分
        scores = np.dot(self.Q, user_factors)

        # 排除已知物品
        if exclude_items:
            for item_id in exclude_items:
                if item_id in self.item_id_map:
                    scores[self.item_id_map[item_id]] = -np.inf

        # 获取 top-n 推荐物品索引
        top_indices = np.argsort(scores)[::-1][:n_items]

        # 转换回原始物品 ID
        idx_to_item = {v: k for k, v in self.item_id_map.items()}
        recommendations = [
            (idx_to_item[idx], scores[idx]) for idx in top_indices
        ]

        return recommendations

    def get_similar_items(self, item_id, n_items=10):
        """
        获取相似物品

        参数:
            item_id: 物品 ID
            n_items: 返回相似物品数量

        返回:
            相似物品 ID 列表及其相似度
        """
        if item_id not in self.item_id_map:
            return []

        i_idx = self.item_id_map[item_id]
        item_factors = self.Q[i_idx]

        # 计算余弦相似度
        norms = np.linalg.norm(self.Q, axis=1)
        item_norm = norms[i_idx]
        norms[i_idx] = 1  # 避免除零

        similarities = np.dot(self.Q, item_factors) / (norms * item_norm)
        similarities[i_idx] = -np.inf  # 排除自身

        # 获取 top-n 相似物品
        top_indices = np.argsort(similarities)[::-1][:n_items]

        idx_to_item = {v: k for k, v in self.item_id_map.items()}
        similar_items = [
            (idx_to_item[idx], similarities[idx]) for idx in top_indices
        ]

        return similar_items
```

### 8.2 ALS 实现

```python
import numpy as np
from scipy.sparse import csr_matrix

class MatrixFactorizationALS:
    """
    基于交替最小二乘法（ALS）的矩阵分解实现
    适用于隐式反馈场景
    """

    def __init__(self, n_factors=100, reg_param=0.01, n_epochs=15):
        """
        参数:
            n_factors: 隐因子数量
            reg_param: 正则化参数
            n_epochs: 迭代次数
        """
        self.n_factors = n_factors
        self.reg_param = reg_param
        self.n_epochs = n_epochs

        self.P = None
        self.Q = None

    def fit(self, R, verbose=True):
        """
        训练模型

        参数:
            R: 用户-物品交互矩阵（稀疏矩阵或 numpy 数组）
            verbose: 是否打印训练信息
        """
        if isinstance(R, csr_matrix):
            R = R.toarray()

        n_users, n_items = R.shape

        # 初始化因子矩阵
        self.P = np.random.normal(0, 0.1, (n_users, self.n_factors))
        self.Q = np.random.normal(0, 0.1, (n_items, self.n_factors))

        # ALS 迭代
        for epoch in range(self.n_epochs):
            # 固定 Q，更新 P
            self._update_users(R)

            # 固定 P，更新 Q
            self._update_items(R)

            if verbose:
                loss = np.sum((R - np.dot(self.P, self.Q.T)) ** 2)
                print(f"Epoch {epoch+1}/{self.n_epochs}, Loss: {loss:.4f}")

        return self

    def _update_users(self, R):
        """更新用户因子"""
        QtQ = np.dot(self.Q.T, self.Q) + self.reg_param * np.eye(self.n_factors)

        for u in range(R.shape[0]):
            # 该用户的交互向量
            ru = R[u, :]

            if np.sum(ru > 0) == 0:
                continue

            # 只使用有交互的物品
            QtQ_inv = np.linalg.inv(QtQ)
            self.P[u] = np.dot(np.dot(QtQ_inv, self.Q.T), ru)

    def _update_items(self, R):
        """更新物品因子"""
        PtP = np.dot(self.P.T, self.P) + self.reg_param * np.eye(self.n_factors)

        for i in range(R.shape[1]):
            # 该物品的交互向量
            ri = R[:, i]

            if np.sum(ri > 0) == 0:
                continue

            PtP_inv = np.linalg.inv(PtP)
            self.Q[i] = np.dot(np.dot(PtP_inv, self.P.T), ri)

    def predict(self, user_idx, item_idx):
        """预测评分"""
        return np.dot(self.P[user_idx], self.Q[item_idx])

    def recommend(self, user_idx, n_items=10, exclude_indices=None):
        """推荐物品"""
        scores = np.dot(self.Q, self.P[user_idx])

        if exclude_indices:
            scores[exclude_indices] = -np.inf

        top_indices = np.argsort(scores)[::-1][:n_items]
        return list(zip(top_indices, scores[top_indices]))
```

## 10. 模型评估

### 10.1 评估指标

```python
from sklearn.metrics import mean_squared_error, mean_absolute_error
from collections import defaultdict

def evaluate_mf(model, test_data):
    """
    评估矩阵分解模型

    参数:
        model: 训练好的模型
        test_data: 测试数据 [(user_id, item_id, rating), ...]

    返回:
        评估指标字典
    """
    actual = []
    predicted = []

    for user_id, item_id, rating in test_data:
        pred = model.predict(user_id, item_id)
        actual.append(rating)
        predicted.append(pred)

    actual = np.array(actual)
    predicted = np.array(predicted)

    # 回归指标
    rmse = np.sqrt(mean_squared_error(actual, predicted))
    mae = mean_absolute_error(actual, predicted)

    # R² 分数
    ss_res = np.sum((actual - predicted) ** 2)
    ss_tot = np.sum((actual - np.mean(actual)) ** 2)
    r2 = 1 - (ss_res / ss_tot)

    return {
        'RMSE': rmse,
        'MAE': mae,
        'R2': r2
    }


def evaluate_ranking(model, test_data, k=10):
    """
    评估排序质量

    参数:
        model: 训练好的模型
        test_data: 测试数据，格式为 {user_id: [item_id1, item_id2, ...]}
        k: 推荐列表长度

    返回:
        Precision@K, Recall@K, NDCG@K
    """
    precisions = []
    recalls = []
    ndcgs = []

    for user_id, relevant_items in test_data.items():
        # 获取推荐
        recommendations = model.recommend(user_id, n_items=k)
        recommended_items = [item_id for item_id, _ in recommendations]

        if not relevant_items:
            continue

        # Precision@K
        n_relevant = len(set(recommended_items) & set(relevant_items))
        precision = n_relevant / k
        precisions.append(precision)

        # Recall@K
        recall = n_relevant / len(relevant_items)
        recalls.append(recall)

        # NDCG@K
        dcg = 0
        for i, item_id in enumerate(recommended_items):
            if item_id in relevant_items:
                dcg += 1 / np.log2(i + 2)  # i+2 因为 log2(1) = 0

        idcg = sum(1 / np.log2(i + 2) for i in range(min(k, len(relevant_items))))
        ndcg = dcg / idcg if idcg > 0 else 0
        ndcgs.append(ndcg)

    return {
        f'Precision@{k}': np.mean(precisions),
        f'Recall@{k}': np.mean(recalls),
        f'NDCG@{k}': np.mean(ndcgs)
    }
```

## 11. 常见问题与易错点

### 11.1 常见问题

**Q1：隐因子数量 K 如何选择？**

A：一般通过交叉验证选择：
- K 太小：模型欠拟合，无法捕捉足够信息
- K 太大：模型过拟合，计算量增加
- 通常在 20-200 之间

**Q2：学习率如何设置？**

A：
- 初始值通常在 0.001-0.01
- 可以使用学习率衰减策略
- 观察损失曲线调整

**Q3：如何处理新用户/新物品？**

A：
- 新用户：基于人口统计学特征初始化，或使用混合推荐
- 新物品：基于内容特征初始化隐向量
- 可以使用增量更新策略

### 11.2 易错点

1. **忘记正则化**：导致过拟合，在测试集上表现差
2. **初始化不当**：初始化值太大可能导致训练不稳定
3. **更新顺序错误**：SGD 更新 P 和 Q 时，要使用旧的 P 值更新 Q
4. **未处理冷启动**：新用户/物品需要特殊处理
5. **评估方法不当**：不能只在训练集上评估

### 参考答案

1. 用户矩阵 P、物品矩阵 Q

2. C（K-均值聚类不用于矩阵分解优化）

3. 正则化项用于防止过拟合。通过对因子矩阵的范数进行惩罚，避免模型学习到过大的参数值，提高泛化能力。

4. 固定 Q 时，目标函数关于 P 是二次的：
   $$\min_P ||R - PQ^T||^2 + \lambda||P||^2$$
   对每个用户 u：
   $$p_u = (Q^TQ + \lambda I)^{-1}Q^Tr_u$$

5. 提示：在预测公式中加入用户偏置 $b_u$ 和物品偏置 $b_i$：
   $$\hat{r}_{ui} = \mu + b_u + b_i + p_u^T q_i$$

6. SGD：适合显式反馈，实现简单，但串行性强
   ALS：适合隐式反馈，可并行化，但每次迭代需要矩阵求逆
