# 基于内容的推荐 学习文档

## 1. 算法基础认知

### 1.1 什么是基于内容的推荐？

基于内容的推荐（Content-Based Recommendation）通过分析物品的内容特征，推荐与用户历史偏好相似的物品。

### 1.2 核心思想

```
用户喜欢具有某些特征的物品
→ 推荐具有相似特征的物品
```

### 1.3 与协同过滤的区别

| 维度 | 协同过滤 | 基于内容 |
|------|----------|----------|
| 数据依赖 | 用户行为 | 物品内容 |
| 冷启动 | 差 | 好（物品冷启动） |
| 多样性 | 高 | 低（过度相似） |
| 可解释性 | 弱 | 强 |

## 2. 核心原理

### 2.1 物品表示

将物品表示为特征向量：

```
物品特征:
- 类别: [科技, 娱乐, 体育, ...]
- 标签: [手机, 苹果, 新品, ...]
- 文本: 商品描述、标题
- 属性: 价格、品牌、颜色
```

### 2.2 用户画像

基于用户历史行为构建用户画像：

$$\text{Profile}(u) = \frac{1}{|I_u|} \sum_{i \in I_u} \text{Feature}(i)$$

### 2.3 相似度计算

$$\text{Score}(u, i) = \text{sim}(\text{Profile}(u), \text{Feature}(i))$$

## 3. 完整实现

```python
import numpy as np
from typing import List, Dict, Tuple, Optional
from collections import defaultdict
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity


class ContentBasedRecommender:
    """
    基于内容的推荐器
    """

    def __init__(self, item_features: Dict[int, Dict] = None):
        """
        参数:
            item_features: {item_id: {feature_name: value}}
        """
        self.item_features = item_features or {}
        self.user_profiles = {}
        self.item_vectors = {}
        self.feature_names = []

    def build_item_vectors(self, text_features: Dict[int, str] = None,
                          categorical_features: Dict[int, Dict] = None):
        """
        构建物品向量表示

        参数:
            text_features: {item_id: text}
            categorical_features: {item_id: {feature: value}}
        """
        # 文本特征 - TF-IDF
        if text_features:
            item_ids = list(text_features.keys())
            texts = [text_features[i] for i in item_ids]

            self.tfidf = TfidfVectorizer(max_features=1000)
            tfidf_matrix = self.tfidf.fit_transform(texts)

            for i, item_id in enumerate(item_ids):
                self.item_vectors[item_id] = tfidf_matrix[i].toarray().flatten()

            self.feature_names = self.tfidf.get_feature_names_out()

        # 类别特征 - One-Hot
        if categorical_features:
            # 获取所有可能的特征值
            all_features = set()
            for features in categorical_features.values():
                for f, v in features.items():
                    all_features.add(f"{f}_{v}")

            self.feature_names = sorted(all_features)
            feature_to_idx = {f: i for i, f in enumerate(self.feature_names)}

            for item_id, features in categorical_features.items():
                vec = np.zeros(len(self.feature_names))
                for f, v in features.items():
                    key = f"{f}_{v}"
                    if key in feature_to_idx:
                        vec[feature_to_idx[key]] = 1

                if item_id in self.item_vectors:
                    self.item_vectors[item_id] = np.concatenate([
                        self.item_vectors[item_id], vec
                    ])
                else:
                    self.item_vectors[item_id] = vec

    def build_user_profile(self, user_id: int,
                          liked_items: List[int],
                          weights: List[float] = None) -> np.ndarray:
        """
        构建用户画像

        参数:
            user_id: 用户ID
            liked_items: 用户喜欢的物品
            weights: 各物品的权重（如评分）

        返回:
            用户画像向量
        """
        if weights is None:
            weights = [1.0] * len(liked_items)

        profile = np.zeros_like(next(iter(self.item_vectors.values())))

        for item_id, weight in zip(liked_items, weights):
            if item_id in self.item_vectors:
                profile += self.item_vectors[item_id] * weight

        # 归一化
        if len(liked_items) > 0:
            profile = profile / len(liked_items)

        self.user_profiles[user_id] = profile
        return profile

    def recommend(self, user_id: int, candidate_items: List[int] = None,
                 n: int = 10, exclude_items: List[int] = None) -> List[Tuple[int, float]]:
        """
        推荐

        参数:
            user_id: 用户ID
            candidate_items: 候选物品（None表示全部）
            n: 返回数量
            exclude_items: 要排除的物品

        返回:
            [(item_id, score), ...]
        """
        if user_id not in self.user_profiles:
            return []

        user_profile = self.user_profiles[user_id]
        exclude_set = set(exclude_items or [])

        # 候选物品
        if candidate_items is None:
            candidate_items = list(self.item_vectors.keys())

        scores = []
        for item_id in candidate_items:
            if item_id in exclude_set:
                continue
            if item_id not in self.item_vectors:
                continue

            item_vec = self.item_vectors[item_id]
            score = cosine_similarity(
                user_profile.reshape(1, -1),
                item_vec.reshape(1, -1)
            )[0, 0]
            scores.append((item_id, score))

        # 排序
        scores.sort(key=lambda x: x[1], reverse=True)

        return scores[:n]

    def explain_recommendation(self, user_id: int, item_id: int,
                               top_k: int = 5) -> List[Tuple[str, float]]:
        """
        解释推荐理由

        返回:
            [(feature_name, contribution), ...]
        """
        if user_id not in self.user_profiles:
            return []

        user_profile = self.user_profiles[user_id]
        item_vec = self.item_vectors.get(item_id)

        if item_vec is None:
            return []

        # 计算各特征的贡献
        contributions = user_profile * item_vec

        # 排序
        indices = np.argsort(contributions)[::-1][:top_k]

        explanations = []
        for idx in indices:
            if idx < len(self.feature_names):
                explanations.append((
                    self.feature_names[idx],
                    float(contributions[idx])
                ))

        return explanations


class TextBasedRecommender:
    """
    基于文本内容的推荐
    """

    def __init__(self):
        self.vectorizer = TfidfVectorizer(max_features=5000)
        self.item_vectors = None
        self.item_ids = []

    def fit(self, item_texts: Dict[int, str]):
        """
        训练

        参数:
            item_texts: {item_id: text}
        """
        self.item_ids = list(item_texts.keys())
        texts = [item_texts[i] for i in self.item_ids]

        self.item_vectors = self.vectorizer.fit_transform(texts)

    def recommend_similar(self, item_id: int, n: int = 10) -> List[Tuple[int, float]]:
        """
        推荐相似物品
        """
        if item_id not in self.item_ids:
            return []

        idx = self.item_ids.index(item_id)
        item_vec = self.item_vectors[idx]

        # 计算相似度
        similarities = cosine_similarity(item_vec, self.item_vectors)[0]

        # 排序（排除自己）
        ranked_indices = np.argsort(similarities)[::-1]

        results = []
        for i in ranked_indices:
            if self.item_ids[i] != item_id:
                results.append((self.item_ids[i], similarities[i]))
            if len(results) >= n:
                break

        return results

    def recommend_by_query(self, query: str, n: int = 10) -> List[Tuple[int, float]]:
        """
        根据查询文本推荐
        """
        query_vec = self.vectorizer.transform([query])
        similarities = cosine_similarity(query_vec, self.item_vectors)[0]

        ranked_indices = np.argsort(similarities)[::-1][:n]

        return [(self.item_ids[i], similarities[i]) for i in ranked_indices]


class HybridContentCollabRecommender:
    """
    混合内容与协同过滤的推荐器
    """

    def __init__(self, content_weight: float = 0.5):
        self.content_weight = content_weight
        self.content_rec = ContentBasedRecommender()
        self.user_item_matrix = None

    def fit(self, item_features: Dict, user_item_interactions: Dict):
        """
        训练
        """
        # 内容推荐
        self.content_rec.build_item_vectors(
            text_features=item_features.get('text', {}),
            categorical_features=item_features.get('categorical', {})
        )

        # 协同过滤矩阵
        self.user_item_matrix = user_item_interactions

    def recommend(self, user_id: int, n: int = 10) -> List[Tuple[int, float]]:
        """混合推荐"""
        # 内容分数
        content_scores = {}
        if user_id in self.content_rec.user_profiles:
            for item_id, vec in self.content_rec.item_vectors.items():
                score = cosine_similarity(
                    self.content_rec.user_profiles[user_id].reshape(1, -1),
                    vec.reshape(1, -1)
                )[0, 0]
                content_scores[item_id] = score

        # 协同分数（简化版）
        collab_scores = {}
        if user_id in self.user_item_matrix:
            user_items = set(self.user_item_matrix[user_id])
            # 基于物品相似度的推荐
            # ... 实现省略

        # 混合
        all_items = set(content_scores.keys()) | set(collab_scores.keys())
        hybrid_scores = []

        for item_id in all_items:
            c_score = content_scores.get(item_id, 0)
            cf_score = collab_scores.get(item_id, 0)
            hybrid = self.content_weight * c_score + (1 - self.content_weight) * cf_score
            hybrid_scores.append((item_id, hybrid))

        hybrid_scores.sort(key=lambda x: x[1], reverse=True)
        return hybrid_scores[:n]


def demo_content_based():
    """基于内容的推荐示例"""
    # 物品文本特征
    item_texts = {
```

```python
class TextFeatureExtractor:
    """
    文本特征提取器
    """

    def __init__(self, method: str = 'tfidf'):
        self.method = method

    def extract(self, texts: List[str]) -> np.ndarray:
        """提取特征"""
        if self.method == 'tfidf':
            from sklearn.feature_extraction.text import TfidfVectorizer
            vectorizer = TfidfVectorizer(max_features=1000)
            return vectorizer.fit_transform(texts).toarray()

        elif self.method == 'bow':
            from sklearn.feature_extraction.text import CountVectorizer

            return vectorizer.fit_transform(texts).toarray()
```

### 4.2 标签特征处理

```python
class TagFeatureProcessor:
    """
    标签特征处理器
    """

    def __init__(self, min_freq: int = 2):
        self.min_freq = min_freq
        self.tag_to_idx = {}

    def fit(self, item_tags: Dict[int, List[str]]):
        """训练"""
        # 统计标签频率
        tag_freq = defaultdict(int)
        for tags in item_tags.values():
            for tag in tags:
                tag_freq[tag] += 1

        # 过滤低频标签
        valid_tags = [tag for tag, freq in tag_freq.items()
                     if freq >= self.min_freq]
        self.tag_to_idx = {tag: i for i, tag in enumerate(sorted(valid_tags))}

    def transform(self, item_tags: Dict[int, List[str]]) -> np.ndarray:
        """转换"""
        n_items = len(item_tags)
        n_tags = len(self.tag_to_idx)

        matrix = np.zeros((n_items, n_tags))

        for i, (item_id, tags) in enumerate(item_tags.items()):
            for tag in tags:
                if tag in self.tag_to_idx:
                    matrix[i, self.tag_to_idx[tag]] = 1

        return matrix
```

## 5. 优缺点分析

### 5.1 优点

- **冷启动友好**: 新物品只要有内容特征即可推荐
- **可解释性强**: 可以解释为什么推荐这个物品
- **不需要其他用户**: 独立为每个用户推荐
- **适应用户偏好**: 能捕捉用户特定兴趣

### 5.2 缺点

- **过度专门化**: 推荐结果过于相似，缺乏多样性
- **特征依赖**: 效果严重依赖内容特征质量
- **冷启动用户**: 新用户没有历史，无法构建画像
- **信息茧房**: 用户只看到相似内容

## 6. 改进策略

### 6.1 增加多样性

```python
def diversify_recommendations(items: List[Tuple[int, float]],
                              item_features: Dict,
                              lambda_param: float = 0.5,
                              n: int = 10) -> List[int]:
    """
    MMR 多样性重排

    参数:
        items: [(item_id, score), ...]
        item_features: {item_id: feature_vector}
        lambda_param: 相关性 vs 多样性权重

    返回:
        重排后的物品ID列表
    """
    selected = []
    remaining = list(items)

    while len(selected) < n and remaining:
        best_score = -np.inf
        best_item = None
        best_idx = 0

        for idx, (item_id, relevance) in enumerate(remaining):
            # 计算与已选物品的最大相似度
            if selected:
                max_sim = max(
                    cosine_similarity(
                        item_features[item_id].reshape(1, -1),
                        item_features[s].reshape(1, -1)
                    )[0, 0]
                    for s in selected
                )
            else:
                max_sim = 0

            # MMR 分数
            mmr_score = lambda_param * relevance - (1 - lambda_param) * max_sim

            if mmr_score > best_score:
                best_score = mmr_score
                best_item = item_id
                best_idx = idx

        if best_item is not None:
            selected.append(best_item)
            remaining.pop(best_idx)

    return selected
```

## 7. 学习总结

### 7.1 核心要点

1. **物品表示**: 将物品转换为特征向量
2. **用户画像**: 基于历史构建用户偏好
3. **相似度匹配**: 推荐与用户画像相似的物品

### 7.2 适用场景

- 物品冷启动
- 需要可解释推荐
- 用户行为稀疏
- 专业领域推荐
