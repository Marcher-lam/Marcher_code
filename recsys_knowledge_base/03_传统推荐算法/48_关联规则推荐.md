# 关联规则推荐 学习文档

## 1. 关联规则概述

### 1.1 什么是关联规则？

```
关联规则 (Association Rules):

- 发现物品之间的共现关系
- 经典应用: 购物篮分析
- "买了 A 的人也买了 B"

经典案例:
- 啤酒和尿布
- 面包和黄油
- 手机和手机壳

在推荐系统中的应用:
- 捆绑推荐
- 凑单推荐
- 相关商品推荐
- 交叉销售
```

### 1.2 基本概念

```python
"""
关联规则基本概念:

1. 事务 (Transaction): 一次购买行为
   T = {item1, item2, ...}

2. 项集 (Itemset): 物品集合
   {牛奶, 面包}

3. 频繁项集: 出现次数超过阈值的项集

4. 关联规则: X → Y
   如果买了 X，则可能买 Y

5. 支持度 (Support): 项集出现的频率
   Support(X) = count(X) / total_transactions

6. 置信度 (Confidence): 规则的可信度
   Confidence(X → Y) = Support(X ∪ Y) / Support(X)

7. 提升度 (Lift): 规则的有效性
   Lift(X → Y) = Confidence(X → Y) / Support(Y)
   - Lift > 1: 正相关
   - Lift = 1: 无关
   - Lift < 1: 负相关
"""

from typing import List, Dict, Set, Tuple
from collections import defaultdict
from itertools import combinations
import numpy as np


class AssociationRules:
    """
    关联规则基础
    """

    @staticmethod
    def support(itemset: Set, transactions: List[Set]) -> float:
        """计算支持度"""
        count = sum(1 for t in transactions if itemset.issubset(t))
        return count / len(transactions)

    @staticmethod
    def confidence(x: Set, y: Set, transactions: List[Set]) -> float:
        """计算置信度"""
        xy = x | y
        support_xy = AssociationRules.support(xy, transactions)
        support_x = AssociationRules.support(x, transactions)
        return support_xy / support_x if support_x > 0 else 0

    @staticmethod
    def lift(x: Set, y: Set, transactions: List[Set]) -> float:
        """计算提升度"""
        conf = AssociationRules.confidence(x, y, transactions)
        support_y = AssociationRules.support(y, transactions)
        return conf / support_y if support_y > 0 else 0
```

## 2. Apriori 算法

### 2.1 算法原理

```python
"""
Apriori 算法:

核心思想:
- 频繁项集的子集也是频繁的
- 非频繁项集的超集也是非频繁的

流程:
1. 扫描数据，找频繁 1-项集
2. 用频繁 k-项集生成候选 k+1-项集
3. 剪枝：移除包含非频繁子集的候选
4. 扫描数据，验证候选项集
5. 重复直到没有新的频繁项集
"""


class Apriori:
    """
    Apriori 算法实现
    """

    def __init__(self, min_support: float = 0.01,
                 min_confidence: float = 0.5):
        """
        参数:
            min_support: 最小支持度
            min_confidence: 最小置信度
        """
        self.min_support = min_support
        self.min_confidence = min_confidence
        self.frequent_itemsets = {}
        self.rules = []

    def fit(self, transactions: List[List[int]]) -> 'Apriori':
        """
        训练

        transactions: 交易列表，每个交易是物品ID列表
        """
        # 转换为集合
        self.transactions = [set(t) for t in transactions]
        self.n_transactions = len(self.transactions)

        # 1. 找频繁项集
        self._find_frequent_itemsets()

        # 2. 生成关联规则
        self._generate_rules()

        return self

    def _find_frequent_itemsets(self):
        """找频繁项集"""
        # 获取所有物品
        all_items = set()
        for t in self.transactions:
            all_items.update(t)

        # 从 1-项集开始
        k = 1
        current_itemsets = [{item} for item in all_items]

        while current_itemsets:
            # 计算支持度
            frequent = []
            for itemset in current_itemsets:
                support = self.support(itemset)
                if support >= self.min_support:
                    frequent.append(itemset)
                    self.frequent_itemsets[frozenset(itemset)] = support

            # 生成下一层候选项集
            k += 1
            current_itemsets = self._generate_candidates(frequent, k)

        print(f"Found {len(self.frequent_itemsets)} frequent itemsets")

    def _generate_candidates(self, frequent_itemsets: List[Set],
                            k: int) -> List[Set]:
        """
        生成候选项集

        通过合并两个 k-1 项集生成 k 项集
        """
        candidates = []
        n = len(frequent_itemsets)

        for i in range(n):
            for j in range(i + 1, n):
                # 合并
                union = frequent_itemsets[i] | frequent_itemsets[j]
                if len(union) == k:
                    # 剪枝：检查所有 k-1 子集是否频繁
                    if self._check_subsets(union, frequent_itemsets):
                        candidates.append(union)

        return candidates

    def _check_subsets(self, itemset: Set,
                      frequent_itemsets: List[Set]) -> bool:
        """检查所有子集是否频繁"""
        for subset in combinations(itemset, len(itemset) - 1):
            if set(subset) not in frequent_itemsets:
                return False
        return True

    def support(self, itemset: Set) -> float:
        """计算支持度"""
        count = sum(1 for t in self.transactions if itemset.issubset(t))
        return count / self.n_transactions

    def _generate_rules(self):
        """生成关联规则"""
        self.rules = []

        for itemset in self.frequent_itemsets:
            if len(itemset) < 2:
                continue

            # 对每个非空子集生成规则
            for i in range(1, len(itemset)):
                for antecedent in combinations(itemset, i):
                    antecedent = set(antecedent)
                    consequent = itemset - antecedent

                    # 计算置信度
                    support_itemset = self.frequent_itemsets[frozenset(itemset)]
                    support_ante = self.frequent_itemsets.get(frozenset(antecedent), 0)

                    if support_ante > 0:
                        confidence = support_itemset / support_ante

                        if confidence >= self.min_confidence:
                            # 计算提升度
                            support_cons = self.frequent_itemsets.get(
                                frozenset(consequent), 0
                            )
                            lift = confidence / support_cons if support_cons > 0 else 0

                            self.rules.append({
                                'antecedent': antecedent,
                                'consequent': consequent,
                                'support': support_itemset,
                                'confidence': confidence,
                                'lift': lift
                            })

        # 按置信度排序
        self.rules.sort(key=lambda x: x['confidence'], reverse=True)

        print(f"Generated {len(self.rules)} rules")

    def get_recommendations(self, items: List[int], top_k: int = 10
                           ) -> List[Tuple[int, float]]:
        """
        获取推荐

        基于当前购买物品，推荐相关物品
        """
        item_set = set(items)
        recommendations = defaultdict(float)

        for rule in self.rules:
            # 如果购买了前件
            if rule['antecedent'].issubset(item_set):
                for item in rule['consequent']:
                    if item not in item_set:  # 排除已购买
                        recommendations[item] = max(
                            recommendations[item],
                            rule['confidence']
                        )

        # 排序
        sorted_recs = sorted(recommendations.items(),
                            key=lambda x: x[1],
                            reverse=True)

        return sorted_recs[:top_k]
```

## 3. FP-Growth 算法

### 3.1 FP树结构

```python
class FPTreeNode:
    """
    FP树节点
    """

    def __init__(self, item: int = None, parent: 'FPTreeNode' = None):
        self.item = item
        self.count = 1
        self.parent = parent
        self.children: Dict[int, 'FPTreeNode'] = {}
        self.link = None  # 指向相同物品的下一个节点

    def increment(self):
        self.count += 1


class FPGrowth:
    """
    FP-Growth 算法

    只需两次扫描数据库
    1. 统计物品频率
    2. 构建 FP 树
    """

    def __init__(self, min_support: float = 0.01,
                 min_confidence: float = 0.5):
        self.min_support = min_support
        self.min_confidence = min_confidence
        self.frequent_itemsets = {}

    def fit(self, transactions: List[List[int]]) -> 'FPGrowth':
        """训练"""
        self.transactions = transactions
        self.n_transactions = len(transactions)
        min_count = int(self.min_support * self.n_transactions)

        # 1. 统计物品频率
        item_counts = defaultdict(int)
        for t in transactions:
            for item in t:
                item_counts[item] += 1

        # 过滤非频繁物品
        self.frequent_items = {
            item: count for item, count in item_counts.items()
            if count >= min_count
        }

        # 按频率排序
        self.item_order = sorted(
            self.frequent_items.keys(),
            key=lambda x: self.frequent_items[x],
            reverse=True
        )

        # 2. 构建 FP 树
        self.root = FPTreeNode()
        self.header_table = defaultdict(list)  # 物品到节点的映射

        for t in transactions:
            # 过滤并排序
            filtered = [item for item in t if item in self.frequent_items]
            filtered.sort(key=lambda x: self.item_order.index(x))

            # 插入树
            self._insert_tree(filtered, self.root)

        # 3. 挖掘频繁项集
        self._mine_frequent_itemsets()

        return self

    def _insert_tree(self, items: List[int], node: FPTreeNode):
        """插入到 FP 树"""
        if not items:
            return

        first = items[0]
        remaining = items[1:]

        if first in node.children:
            node.children[first].increment()
        else:
            new_node = FPTreeNode(first, node)
            node.children[first] = new_node

            # 更新头表
            self.header_table[first].append(new_node)

        self._insert_tree(remaining, node.children[first])

    def _mine_frequent_itemsets(self):
        """挖掘频繁项集"""
        # 从频率最低的物品开始
        for item in reversed(self.item_order):
            # 构建条件模式基
            conditional_patterns = []

            for node in self.header_table[item]:
                # 找到从根到该节点的路径
                path = []
                current = node.parent
                while current.item is not None:
                    path.append(current.item)
                    current = current.parent

                if path:
                    conditional_patterns.append((path, node.count))

            # 构建条件 FP 树
            # (简化实现)
            self.frequent_itemsets[frozenset([item])] = (
                self.frequent_items[item] / self.n_transactions
            )

    def get_frequent_itemsets(self) -> Dict[frozenset, float]:
        """获取频繁项集"""
        return self.frequent_itemsets
```

## 4. 推荐系统应用

### 4.1 关联规则推荐器

```python
class AssociationRuleRecommender:
    """
    基于关联规则的推荐器
    """

    def __init__(self, min_support: float = 0.01,
                 min_confidence: float = 0.3,
                 min_lift: float = 1.0,
                 algorithm: str = 'apriori'):
        self.min_support = min_support
        self.min_confidence = min_confidence
        self.min_lift = min_lift
        self.algorithm = algorithm
        self.rules = []

    def fit(self, transactions: List[List[int]]):
        """
        训练

        transactions: 用户购买历史列表
        """
        if self.algorithm == 'apriori':
            miner = Apriori(self.min_support, self.min_confidence)
            miner.fit(transactions)
            self.rules = miner.rules
        else:
            raise ValueError(f"Unknown algorithm: {self.algorithm}")

        # 过滤提升度
        self.rules = [r for r in self.rules if r['lift'] >= self.min_lift]

        print(f"Loaded {len(self.rules)} valid rules")
        return self

    def recommend(self, cart: List[int], top_k: int = 10,
                 exclude_in_cart: bool = True) -> List[Tuple[int, Dict]]:
        """
        推荐

        cart: 当前购物车
        返回: [(item_id, rule_info), ...]
        """
        cart_set = set(cart)
        recommendations = defaultdict(lambda: {'confidence': 0, 'support': 0, 'lift': 0})

        for rule in self.rules:
            # 检查购物车是否包含规则前件
            if rule['antecedent'].issubset(cart_set):
                for item in rule['consequent']:
                    if exclude_in_cart and item in cart_set:
                        continue

                    if rule['confidence'] > recommendations[item]['confidence']:
                        recommendations[item] = {
                            'confidence': rule['confidence'],
                            'support': rule['support'],
                            'lift': rule['lift']
                        }

        # 排序
        sorted_recs = sorted(
            recommendations.items(),
            key=lambda x: x[1]['confidence'],
            reverse=True
        )

        return sorted_recs[:top_k]

    def get_bundle_recommendations(self, item: int, top_k: int = 5
                                  ) -> List[Tuple[Set, Dict]]:
        """
        获取捆绑推荐

        给定一个物品，返回经常一起购买的物品组合
        """
        bundles = []

        for rule in self.rules:
            if item in rule['antecedent'] or item in rule['consequent']:
                bundle = rule['antecedent'] | rule['consequent']
                bundles.append((bundle, {
                    'confidence': rule['confidence'],
                    'support': rule['support'],
                    'lift': rule['lift']
                }))

        bundles.sort(key=lambda x: x[1]['lift'], reverse=True)
        return bundles[:top_k]


class CrossSellRecommender:
    """
    交叉销售推荐器

    用于"买了又买"场景
    """

    def __init__(self):
        self.association_recommender = None
        self.item_popularity = {}

    def fit(self, transactions: List[List[int]],
            min_support: float = 0.005,
            min_confidence: float = 0.1):
        """训练"""
        # 训练关联规则
        self.association_recommender = AssociationRuleRecommender(
            min_support=min_support,
            min_confidence=min_confidence
        )
        self.association_recommender.fit(transactions)

        # 计算物品流行度
        item_counts = defaultdict(int)
        for t in transactions:
            for item in t:
                item_counts[item] += 1

        total = len(transactions)
        self.item_popularity = {
            item: count / total for item, count in item_counts.items()
        }

        return self

    def get_cross_sell_items(self, purchased_item: int, top_k: int = 10
                            ) -> List[Tuple[int, float]]:
        """
        获取交叉销售物品

        基于"买了 A 的人也买了 B"
        """
        recommendations = []

        for rule in self.association_recommender.rules:
            if purchased_item in rule['antecedent']:
                for item in rule['consequent']:
                    if item != purchased_item:
                        recommendations.append((item, rule['confidence']))

        # 去重并排序
        unique_recs = {}
        for item, conf in recommendations:
            if item not in unique_recs or conf > unique_recs[item]:
                unique_recs[item] = conf

        sorted_recs = sorted(unique_recs.items(),
                            key=lambda x: x[1],
                            reverse=True)

        return sorted_recs[:top_k]

    def get_upsell_items(self, current_item: int, item_prices: Dict[int, float],
                        price_ratio: float = 1.2, top_k: int = 5
                        ) -> List[Tuple[int, float]]:
        """
        获取向上销售物品

        推荐价格更高但相关的物品
        """
        current_price = item_prices.get(current_item, 0)
        min_price = current_price * price_ratio

        cross_sell = self.get_cross_sell_items(current_item, top_k * 2)

        upsell = [
            (item, conf) for item, conf in cross_sell
            if item_prices.get(item, 0) >= min_price
        ]

        return upsell[:top_k]
```

## 5. 学习总结

### 5.1 算法对比

```
算法          时间复杂度        空间复杂度        适用场景
────────────────────────────────────────────────────
Apriori       O(2^n)           O(k)             小数据集
FP-Growth     O(n)             O(2^n)           大数据集
Eclat         O(2^n)           O(2^n)           稠密数据
```

### 5.2 指标解释

```
指标        公式                        意义
────────────────────────────────────────────────────
支持度      P(X ∪ Y)                   规则出现的频率
置信度      P(Y | X)                   规则的可信程度
提升度      P(Y|X) / P(Y)              规则的有效性
 convictions (1 - P(Y)) / (1 - Conf(X→Y))  规则的意外性
```

### 5.3 最佳实践

```
1. 支持度阈值: 太低会生成过多规则，太高会漏掉有用规则
2. 置信度阈值: 通常 0.3-0.7
3. 提升度过滤: 只保留 lift > 1 的规则
4. 规则数量控制: 限制最大项集大小
5. 业务过滤: 结合业务场景筛选规则
```
