# 多项式逻辑回归 学习文档

## 1. 算法基础认知

多项式逻辑回归（Multinomial Logistic Regression），也称为 Softmax 回归，是二项逻辑回归在多分类问题上的自然推广。它通过 Softmax 函数将线性模型的输出映射为多个类别上的概率分布，是深度学习中多分类任务的最后一步（输出层）的标准做法。

与二项逻辑回归不同，多项式逻辑回归不需要训练多个二分类器，而是直接用一个模型同时估计所有类别的概率。

## 2. 核心原理

给定 $K$ 个类别，多项式逻辑回归为每个类别 $k$ 学习一组参数 $\theta_k$，然后通过 Softmax 函数计算样本属于每个类别的概率：

$$P(y=k|\mathbf{x}) = \frac{e^{\theta_k^T \mathbf{x}}}{\sum_{j=1}^{K} e^{\theta_j^T \mathbf{x}}}$$

**Softmax 函数的性质**：
- 所有输出值在 $(0, 1)$ 之间
- 所有输出值之和为1（满足概率公理）
- 最大值被"放大"，体现了"赢者通吃"

**为什么叫 Softmax？**

相比于取最大值的 hardmax（one-hot），Softmax 是一个"软化"版本——它保留了最大值对应位置的最高概率，同时给其他位置也分配了非零概率。温度参数 $\tau$ 可控制软化程度：

$$\text{Softmax}(z_k) = \frac{e^{z_k/\tau}}{\sum_j e^{z_j/\tau}}$$

$\tau \to 0$ 时趋近 hardmax，$\tau \to \infty$ 时趋近均匀分布。

## 3. 数学公式与推导

**Softmax 函数**：

$$\hat{y}_k = P(y=k|\mathbf{x}) = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}, \quad z_k = \theta_k^T \mathbf{x} + b_k$$

**交叉熵损失函数**：

$$J(\Theta) = -\frac{1}{n} \sum_{i=1}^{n} \sum_{k=1}^{K} \mathbb{1}[y_i = k] \log \hat{y}_k^{(i)}$$

其中 $\Theta = \{\theta_1, \dots, \theta_K\}$ 是所有类别的参数矩阵。

对于单个样本 $(x, y=c)$，损失简化为：

$$J = -\log \hat{y}_c = -\log \frac{e^{\theta_c^T \mathbf{x}}}{\sum_{j=1}^{K} e^{\theta_j^T \mathbf{x}}}$$

**梯度推导**：

$$\frac{\partial J}{\partial \theta_k} = -\frac{1}{n} \sum_{i=1}^{n} \left( \mathbb{1}[y_i = k] - \hat{y}_k^{(i)} \right) \mathbf{x}_i$$

梯度形式简洁：预测概率与真实标签的差值乘以输入特征。当样本属于类别 $k$ 但预测概率 $\hat{y}_k$ 很低时，梯度大，更新幅度大。

**参数冗余性**：

Softmax 参数存在冗余——将所有 $\theta_k$ 减去同一个向量 $\mathbf{v}$，预测结果不变：

$$\frac{e^{(\theta_k - \mathbf{v})^T \mathbf{x}}}{\sum_j e^{(\theta_j - \mathbf{v})^T \mathbf{x}}} = \frac{e^{\theta_k^T \mathbf{x}} / e^{\mathbf{v}^T \mathbf{x}}}{\sum_j e^{\theta_j^T \mathbf{x}} / e^{\mathbf{v}^T \mathbf{x}}} = \frac{e^{\theta_k^T \mathbf{x}}}{\sum_j e^{\theta_j^T \mathbf{x}}}$$

因此通常固定 $\theta_K = \mathbf{0}$ 或加正则化来唯一确定参数。

## 4. 训练过程讲解

1. **初始化**：参数矩阵 $\Theta \in \mathbb{R}^{K \times d}$ 初始化为零或小随机值
2. **前向传播**：计算 $z_k = \theta_k^T \mathbf{x}$，然后 $\hat{y}_k = \text{Softmax}(z_k)$
3. **计算损失**：交叉熵损失 $J = -\frac{1}{n}\sum_i \log \hat{y}_{y_i}^{(i)}$
4. **计算梯度**：$\nabla_{\theta_k} J = -\frac{1}{n} \sum_i (\mathbb{1}[y_i=k] - \hat{y}_k^{(i)}) \mathbf{x}_i$
5. **更新参数**：$\theta_k := \theta_k - \eta \nabla_{\theta_k} J$
6. 重复直到收敛

**数值稳定性技巧**：计算 Softmax 时先减去最大值：

$$\hat{y}_k = \frac{e^{z_k - z_{max}}}{\sum_j e^{z_j - z_{max}}}$$

避免 $e^{z_k}$ 溢出。

## 5. 应用场景

- **图像分类**：MNIST 手写数字（10类）
- **文本分类**：新闻主题分类
- **语言模型**：预测下一个词（词表大小为类别数）
- **广告系统**：多品类广告推荐
- **深度学习输出层**：几乎所有多分类网络的最后一层

## 6. 优缺点分析

**优点**：
- 输出概率分布，包含不确定性信息
- 端到端的多分类，无需训练多个二分类器
- 梯度形式简洁，训练高效
- 是深度学习多分类的标配

**缺点**：
- 线性决策边界，对非线性问题效果差
- 类别数很多时（如词表），计算 Softmax 的分母代价大
- 对特征质量和特征工程依赖强
- 类别不平衡时需要调整权重

## 7. 调库实现（Python + 完整代码 + 注释）

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import classification_report, confusion_matrix

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

model = LogisticRegression(multi_class='multinomial', solver='lbfgs', C=1.0, max_iter=1000, random_state=42)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(f"Accuracy: {model.score(X_test, y_test):.4f}")
print(classification_report(y_test, y_pred, target_names=load_iris().target_names))
print("Confusion Matrix:")
print(confusion_matrix(y_test, y_pred))
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

class SoftmaxRegression:
    def __init__(self, lr=0.1, n_iters=1000, reg_lambda=0.01):
        self.lr = lr
        self.n_iters = n_iters
        self.reg_lambda = reg_lambda

    def _softmax(self, z):
        z_shifted = z - np.max(z, axis=1, keepdims=True)
        exp_z = np.exp(z_shifted)
        return exp_z / np.sum(exp_z, axis=1, keepdims=True)

    def _one_hot(self, y, n_classes):
        one_hot = np.zeros((len(y), n_classes))
        one_hot[np.arange(len(y)), y] = 1
        return one_hot

    def fit(self, X, y):
        n, d = X.shape
        self.n_classes = len(np.unique(y))
        self.W = np.zeros((d, self.n_classes))
        self.b = np.zeros(self.n_classes)
        y_onehot = self._one_hot(y, self.n_classes)

        for _ in range(self.n_iters):
            logits = X @ self.W + self.b
            probs = self._softmax(logits)
            error = probs - y_onehot
            self.W -= self.lr * (X.T @ error / n + self.reg_lambda * self.W)
            self.b -= self.lr * np.mean(error, axis=0)

    def predict_proba(self, X):
        return self._softmax(X @ self.W + self.b)

    def predict(self, X):
        return np.argmax(self.predict_proba(X), axis=1)

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

model = SoftmaxRegression(lr=0.1, n_iters=2000, reg_lambda=0.001)
model.fit(X_train, y_train)
print(f"手工实现准确率: {accuracy_score(y_test, model.predict(X_test)):.4f}")
print("各类别概率示例:")
print(model.predict_proba(X_test[:3]))
```

## 11. 常见问题与易错点

1. **multi_class 参数**：sklearn 中设为 `'multinomial'` 使用 Softmax，设为 `'ovr'` 使用一对多策略。多分类任务优先用 `'multinomial'`。
2. **数值稳定性**：Softmax 计算必须先减最大值，否则大指数值会导致溢出（NaN）。
3. **类别数很多时**：如语言模型中词表大小为几万到几十万，标准 Softmax 计算量极大。可用层次 Softmax（Hierarchical Softmax）或负采样（Negative Sampling）加速。
4. **参数冗余**：$K$ 个类只需 $K-1$ 组参数，但实际中通常保留全部 $K$ 组并加正则化。
5. **与 One-vs-Rest 的区别**：OvR 训练 $K$ 个独立二分类器，概率不归一；Softmax 端到端训练，概率自动归一。

## 12. 学习总结

多项式逻辑回归（Softmax 回归）是二项逻辑回归的多分类推广，也是深度学习中多分类网络的标准输出层。掌握 Softmax 函数和交叉熵损失的推导是理解神经网络反向传播的基础。Softmax + Cross-Entropy 的组合使得梯度形式极其简洁（预测值与真实值之差），这是深度学习训练高效的关键之一。

## 13. 练习题与思考题（含答案）

**题目1**：三个类别的 logits 为 $z = [2, 1, 0]$，求 Softmax 输出。

**解答**：

分母 $= e^2 + e^1 + e^0 = 7.389 + 2.718 + 1.0 = 11.107$

$\hat{y}_1 = 7.389 / 11.107 \approx 0.665$

$\hat{y}_2 = 2.718 / 11.107 \approx 0.245$

$\hat{y}_3 = 1.0 / 11.107 \approx 0.090$

验证：$0.665 + 0.245 + 0.090 = 1.0$ ✓

**题目2**：为什么 Softmax + 交叉熵的梯度是 $\hat{y}_k - \mathbb{1}[y=k]$？

**解答**：设 $J = -\log \hat{y}_c$（$c$ 为真实类别），$\hat{y}_k = e^{z_k}/\sum_j e^{z_j}$。

$\frac{\partial J}{\partial z_k} = \frac{\partial J}{\partial \hat{y}_k} \cdot \frac{\partial \hat{y}_k}{\partial z_k}$

当 $k = c$ 时：$\frac{\partial J}{\partial z_c} = \hat{y}_c - 1$

当 $k \neq c$ 时：$\frac{\partial J}{\partial z_k} = \hat{y}_k$

合并：$\frac{\partial J}{\partial z_k} = \hat{y}_k - \mathbb{1}[y=k]$，恰好是预测概率与真实 one-hot 编码的差值。

**题目3**：多项式逻辑回归与训练多个二分类逻辑回归（One-vs-Rest）有什么区别？

**解答**：Softmax 回归所有类别的参数联合优化，输出的概率自动归一化，适合概率校准的场景。OvR 独立训练每个二分类器，各分类器的概率各自独立，不保证归一。Softmax 通常在类别间有竞争关系时表现更好。
