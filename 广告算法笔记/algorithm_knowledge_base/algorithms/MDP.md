# MDP（马尔可夫决策过程）学习文档

## 1. 算法基础认知

MDP（Markov Decision Process）是强化学习的数学基础。在广告系统中，出价问题通常被建模为 MDP。

## 2. 核心原理

MDP 由四元组 (S, A, P, R) 定义：
- **S**：状态空间
- **A**：动作空间
- **P**：状态转移概率 P(s'|s,a)
- **R**：奖励函数 R(s,a)

### 在广告出价中的建模

| 要素 | 定义 | 具体内容 |
|------|------|---------|
| State | 广告当前状态 | 已积累曝光/点击/转化数、pCTR/pCVR置信度、已消耗预算比例、剩余学习期时间 |
| Action | 系统可执行的动作 | 探索加权系数调整、出价调整幅度、流量分配比例 |
| Reward | 即时回报 | 短期收入 + λ₁×冷启成功信号 + λ₂×广告主留存价值 - λ₃×成本超标惩罚 |
| Transition | 状态转移 | 根据当前动作和用户反馈更新广告状态 |

### 优化目标

$$
\max_\pi \mathbb{E}_\pi \left[ \sum_{t=0}^{T} \gamma^t r_t \right]
$$

## 3. 在广告中的应用

- 强化学习出价（第三代出价算法）
- 冷启动的动态决策优化
- 多目标调控的 MDP 建模

## 4. 学习总结

MDP 是广告系统中强化学习应用的理论基础。理解 MDP 建模是理解 RL 出价、RL 冷启动和 RL 多目标调控的前提。
