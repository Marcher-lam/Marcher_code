# 马尔可夫链蒙特卡洛 学习文档

## 1. 算法基础认知

马尔可夫链蒙特卡洛（Markov Chain Monte Carlo, MCMC）是一类利用马尔可夫链的平稳分布性质，结合蒙特卡洛随机采样来近似复杂概率分布的算法族。它不是单一算法，而是一个框架，最经典的实例包括 Metropolis-Hastings 和 Gibbs 采样。

**为什么需要 MCMC？** 当目标分布 $p(x)$ 的归一化常数无法计算或高维积分难以求解时，直接采样不可行。MCMC 通过构造一条马尔可夫链，使其平稳分布恰好等于 $p(x)$，从而在链收敛后抽取的样本近似服从目标分布。

## 2. 核心原理

MCMC 的核心由两部分组成：

- **蒙特卡洛积分**：用随机样本近似期望 $\mathbb{E}_{p}[f(x)] \approx \frac{1}{N}\sum_{i=1}^{N}f(x^{(i)})$
- **马尔可夫链**：状态转移只依赖当前状态 $P(x_{t+1}|x_t)$，当链满足遍历性时，将收敛到唯一的平稳分布 $\pi$

**关键性质——细致平衡条件（Detailed Balance）**：若转移核 $T$ 满足 $\pi(x)T(x'|x) = \pi(x')T(x|x')$，则 $\pi$ 是该链的平稳分布。Metropolis-Hastings 算法就是通过接受-拒绝机制来保证细致平衡。

## 3. 数学公式与推导

### Metropolis-Hastings 算法

给定提议分布 $q(x'|x)$，接受概率：

$$\alpha(x'|x) = \min\left(1, \frac{p(x')q(x|x')}{p(x)q(x'|x)}\right)$$

转移核为 $T(x'|x) = q(x'|x)\alpha(x'|x)$。验证细致平衡：

$$\pi(x)T(x'|x) = \pi(x)q(x'|x)\min\left(1, \frac{\pi(x')q(x|x')}{\pi(x)q(x'|x)}\right)$$

对称情况下 $q(x'|x)=q(x|x')$，接受概率简化为 $\alpha = \min(1, p(x')/p(x))$。

### Gibbs 采样

当 $x$ 为多维变量时，依次对每个维度从条件分布中采样：

$$x_i^{(t+1)} \sim p(x_i | x_1^{(t+1)}, ..., x_{i-1}^{(t+1)}, x_{i+1}^{(t)}, ..., x_d^{(t)})$$

Gibbs 采样是 MH 的特例，每次提议的接受概率恒为 1。

## 4. 训练过程讲解

1. **初始化**：选择初始状态 $x^{(0)}$
2. **迭代采样**（for $t = 0, 1, ..., N-1$）：
   - 从提议分布 $q(x'|x^{(t)})$ 中生成候选 $x'$
   - 计算接受概率 $\alpha$
   - 以概率 $\alpha$ 接受：$x^{(t+1)} = x'$；否则 $x^{(t+1)} = x^{(t)}$
3. **Burn-in**：丢弃前 $B$ 个样本（链尚未收敛）
4. **Thin**：每隔 $k$ 步取一个样本以降低自相关性

## 5. 应用场景

- 贝叶斯推断中后验分布采样
- 隐变量模型的参数估计
- 物理模拟中的配分函数估计
- 广告 CTR 预估中的贝叶斯分层模型参数采样

## 6. 优缺点分析

| 优点 | 缺点 |
|------|------|
| 能处理任意复杂分布 | 收敛诊断困难 |
| 理论保证（遍历定理） | 采样效率低，高维时尤其明显 |
| Gibbs 采样接受率恒为 1 | 样本间存在自相关性 |
| 仅需未归一化概率比 | burn-in 和 thinning 需经验选择 |

## 7. 调库实现（Python + 完整代码 + 注释）

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

def metropolis_hastings(target_log_pdf, proposal_sampler, proposal_log_pdf,
                        x0, n_samples, burn_in=1000):
    samples = np.zeros(n_samples + burn_in)
    x = x0
    for i in range(n_samples + burn_in):
        x_prop = proposal_sampler(x)
        log_alpha = (target_log_pdf(x_prop) - target_log_pdf(x)
                     - proposal_log_pdf(x_prop, x) + proposal_log_pdf(x, x_prop))
        if np.log(np.random.rand()) < log_alpha:
            x = x_prop
        samples[i] = x
    return samples[burn_in:]

np.random.seed(42)
target = lambda x: -0.5 * x**2
prop_sampler = lambda x: x + np.random.normal(0, 1)
prop_log = lambda x_new, x_old: -0.5 * (x_new - x_old)**2

samples = metropolis_hastings(target, prop_sampler, prop_log, x0=0.0, n_samples=10000)

x_grid = np.linspace(-4, 4, 200)
plt.hist(samples, bins=50, density=True, alpha=0.6, label='MCMC samples')
plt.plot(x_grid, stats.norm.pdf(x_grid), 'r-', lw=2, label='N(0,1)')
plt.legend()
plt.title('Metropolis-Hastings sampling vs true N(0,1)')
plt.savefig('mcmc_demo.png', dpi=150)
plt.close()
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

def gibbs_sampling_bivariate_normal(mu, cov, n_samples, burn_in=500):
    sigma11 = cov[0, 0]
    sigma22 = cov[1, 1]
    rho = cov[0, 1] / np.sqrt(sigma11 * sigma22)
    samples = np.zeros((n_samples + burn_in, 2))
    x = np.array([mu[0], mu[1]])
    for i in range(n_samples + burn_in):
        cond_std1 = np.sqrt(sigma11 * (1 - rho**2))
        cond_mu1 = mu[0] + rho * np.sqrt(sigma11 / sigma22) * (x[1] - mu[1])
        x[0] = np.random.normal(cond_mu1, cond_std1)

        cond_std2 = np.sqrt(sigma22 * (1 - rho**2))
        cond_mu2 = mu[1] + rho * np.sqrt(sigma22 / sigma11) * (x[0] - mu[0])
        x[1] = np.random.normal(cond_mu2, cond_std2)
        samples[i] = x.copy()
    return samples[burn_in:]

mu = np.array([0.0, 0.0])
cov = np.array([[1.0, 0.8], [0.8, 1.0]])
samples = gibbs_sampling_bivariate_normal(mu, cov, n_samples=5000)
print(f"Sample mean: {samples.mean(axis=0)}")
print(f"Sample cov:\n{np.cov(samples.T)}")
```

## 9. 可视化与结果理解

- **轨迹图（Trace Plot）**：绘制参数随迭代步数的变化，收敛后应在均值附近震荡
- **自相关图**：检查样本间相关性，高自相关意味着需要更多 thinning
- **直方图 vs 真实密度**：直观验证采样分布是否匹配目标分布

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

np.random.seed(42)

n_total = 6000
burn_in = 1000
samples = np.zeros(n_total)
x = 5.0
proposal_std = 1.0
target_mu, target_sigma = 0.0, 1.0

for i in range(n_total):
    x_prop = x + np.random.normal(0, proposal_std)
    log_alpha = -0.5 * ((x_prop - target_mu) ** 2 - (x - target_mu) ** 2) / target_sigma ** 2
    if np.log(np.random.rand()) < log_alpha:
        x = x_prop
    samples[i] = x

post_burn = samples[burn_in:]

fig, axes = plt.subplots(2, 2, figsize=(14, 10))

axes[0, 0].plot(range(n_total), samples, 'b-', linewidth=0.3, alpha=0.7)
axes[0, 0].axvline(x=burn_in, color='red', linestyle='--', linewidth=2, label=f'Burn-in = {burn_in}')
axes[0, 0].axhline(y=target_mu, color='green', linestyle=':', linewidth=1.5, label=f'True mean = {target_mu}')
axes[0, 0].set_xlabel('Iteration', fontsize=11)
axes[0, 0].set_ylabel('Sampled Value', fontsize=11)
axes[0, 0].set_title('Trace Plot — MCMC Sampling Trajectory', fontsize=13, fontweight='bold')
axes[0, 0].legend(fontsize=10)
axes[0, 0].grid(True, alpha=0.3)

max_lag = 50
acf = np.zeros(max_lag)
for lag in range(max_lag):
    acf[lag] = np.corrcoef(post_burn[:-lag or len(post_burn)], post_burn[lag:])[0, 1] if lag > 0 else 1.0
axes[0, 1].bar(range(max_lag), acf, color='#42A5F5', edgecolor='black', linewidth=0.3)
axes[0, 1].axhline(y=0.05, color='red', linestyle='--', alpha=0.5, label='Threshold')
axes[0, 1].axhline(y=-0.05, color='red', linestyle='--', alpha=0.5)
axes[0, 1].set_xlabel('Lag', fontsize=11)
axes[0, 1].set_ylabel('Autocorrelation', fontsize=11)
axes[0, 1].set_title('Autocorrelation Plot', fontsize=13, fontweight='bold')
axes[0, 1].legend(fontsize=10)
axes[0, 1].grid(True, alpha=0.3)

x_grid = np.linspace(-4, 4, 200)
axes[1, 0].hist(post_burn, bins=50, density=True, alpha=0.6, color='#42A5F5', edgecolor='black', linewidth=0.3, label='MCMC Samples')
axes[1, 0].plot(x_grid, stats.norm.pdf(x_grid, target_mu, target_sigma), 'r-', linewidth=2.5, label='True N(0,1)')
axes[1, 0].set_xlabel('Value', fontsize=11)
axes[1, 0].set_ylabel('Density', fontsize=11)
axes[1, 0].set_title('Sampled vs True Distribution', fontsize=13, fontweight='bold')
axes[1, 0].legend(fontsize=11)
axes[1, 0].grid(True, alpha=0.3)

running_mean = np.cumsum(post_burn) / np.arange(1, len(post_burn) + 1)
axes[1, 1].plot(range(1, len(post_burn) + 1), running_mean, 'b-', linewidth=1, alpha=0.8, label='Running Mean')
axes[1, 1].axhline(y=target_mu, color='red', linestyle='--', linewidth=2, label=f'True Mean = {target_mu}')
axes[1, 1].set_xlabel('Sample Count', fontsize=11)
axes[1, 1].set_ylabel('Running Mean', fontsize=11)
axes[1, 1].set_title('Convergence — Running Mean', fontsize=13, fontweight='bold')
axes[1, 1].legend(fontsize=11)
axes[1, 1].grid(True, alpha=0.3)

plt.suptitle('MCMC Sampling Diagnostics — Metropolis-Hastings on N(0,1)', fontsize=15, fontweight='bold', y=1.01)
plt.tight_layout()
plt.savefig('mcmc_trace_visualization.png', dpi=150, bbox_inches='tight')
plt.show()
```

## 10. 模型评估

- **有效样本量（ESS）**：$\text{ESS} = N / (1 + 2\sum_{k=1}^{\infty}\rho_k)$，衡量独立样本的等价数量
- **Gelman-Rubin 统计量**：$\hat{R} < 1.1$ 表示多链已收敛
- **KL 散度**：采样分布与目标分布之间的距离

## 11. 常见问题与易错点

- **Burn-in 不够**：初始值远离高概率区域，前期样本不代表目标分布
- **提议分布选择不当**：方差太大会导致大量拒绝，太小则探索缓慢（随机游走行为）
- **忽略样本自相关**：直接使用所有样本会低估方差
- **维度灾难**：高维空间中接受率急剧下降，需考虑自适应 MCMC 或 HMC

## 12. 学习总结

MCMC 是连接贝叶斯统计与计算实践的桥梁。核心思想是构造一条以目标分布为平稳分布的马尔可夫链。Metropolis-Hastings 通过接受-拒绝保证细致平衡，Gibbs 采样则利用条件分布简化采样。掌握 MCMC 需要同时理解马尔可夫链理论和实际采样技巧。

## 13. 练习题与思考题（含答案）

**Q1**：证明当提议分布对称时，MH 接受概率简化为 $\min(1, p(x')/p(x))$。

> A1：对称即 $q(x'|x)=q(x|x')$，代入 $\alpha$ 公式，分子分母中的 $q$ 项约去，得 $\min(1, p(x')/p(x))$。

**Q2**：Gibbs 采样中每一步的接受概率是多少？为什么？

> A2：接受概率恒为 1。因为提议就是从满条件分布中采样，而 $p(x_i|x_{-i})$ 正是目标分布的条件边际，自然满足细致平衡。

**Q3**：如果 MH 算法的接受率接近 0 或接近 1，分别说明了什么问题？

> A3：接近 0 说明提议步长太大，大部分候选被拒绝；接近 1 说明步长太小，链几乎不动，探索效率低。实践中接受率在 0.2~0.5 较理想。
