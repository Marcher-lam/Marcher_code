# 隐马尔可夫 学习文档

## 1. 算法基础认知

隐马尔可夫模型（Hidden Markov Model, HMM）是一种概率图模型，用于描述一个含有**隐藏状态**的马尔可夫过程。系统存在一条不可观测的状态序列，每个隐藏状态按照转移概率转移到下一个状态，同时每个状态按照发射概率生成一个可观测的输出。

HMM 由 Baum 等人在 1960 年代提出，广泛应用于语音识别、自然语言处理、生物信息学等领域。

## 2. 核心原理

HMM 包含五个要素 $(S, O, \pi, A, B)$：

- $S$：隐藏状态集合，$|S| = N$
- $O$：观测符号集合，$|O| = M$
- $\pi$：初始状态概率分布，$\pi_i = P(q_1 = s_i)$
- $A$：状态转移概率矩阵，$a_{ij} = P(q_{t+1}=s_j | q_t=s_i)$
- $B$：发射概率矩阵，$b_j(o_k) = P(o_t=o_k | q_t=s_j)$

HMM 有两个基本假设：
1. **齐次马尔可夫假设**：当前状态只依赖前一个状态
2. **观测独立假设**：当前观测只依赖当前状态

## 3. 数学公式与推导

**HMM 的三个基本问题**：

1. **概率计算问题**（Evaluation）：给定模型 $\lambda$ 和观测序列 $O$，求 $P(O|\lambda)$
2. **解码问题**（Decoding）：给定模型 $\lambda$ 和观测序列 $O$，求最可能的状态序列 $Q^*$
3. **学习问题**（Learning）：给定观测序列 $O$，估计模型参数 $\lambda^* = \arg\max P(O|\lambda)$

**前向算法**（解决问题1）：

$$\alpha_t(i) = P(o_1, o_2, ..., o_t, q_t = s_i | \lambda)$$

递推公式：

$$\alpha_{t+1}(j) = \left[\sum_{i=1}^{N}\alpha_t(i) \cdot a_{ij}\right] \cdot b_j(o_{t+1})$$

最终：$P(O|\lambda) = \sum_{i=1}^{N}\alpha_T(i)$

**后向算法**：

$$\beta_t(i) = P(o_{t+1}, ..., o_T | q_t = s_i, \lambda)$$

递推（从后向前）：

$$\beta_t(i) = \sum_{j=1}^{N} a_{ij} \cdot b_j(o_{t+1}) \cdot \beta_{t+1}(j)$$

**Viterbi 算法**（解决问题2）：

$$\delta_t(j) = \max_{q_1,...,q_{t-1}} P(q_1,...,q_{t-1}, q_t=s_j, o_1,...,o_t|\lambda)$$

递推：

$$\delta_{t+1}(j) = \max_{1 \leq i \leq N}[\delta_t(i) \cdot a_{ij}] \cdot b_j(o_{t+1})$$

## 4. 训练过程讲解

**Baum-Welch 算法**（EM 算法的特例，解决问题3）：

1. **E 步**：用当前参数计算 $\gamma_t(i) = P(q_t=s_i|O,\lambda)$ 和 $\xi_t(i,j) = P(q_t=s_i, q_{t+1}=s_j|O,\lambda)$
   - $\gamma_t(i) = \frac{\alpha_t(i)\beta_t(i)}{\sum_j\alpha_t(j)\beta_t(j)}$
   - $\xi_t(i,j) = \frac{\alpha_t(i)a_{ij}b_j(o_{t+1})\beta_{t+1}(j)}{\sum_{i,j}\alpha_t(i)a_{ij}b_j(o_{t+1})\beta_{t+1}(j)}$

2. **M 步**：更新参数
   - $\pi_i = \gamma_1(i)$
   - $a_{ij} = \frac{\sum_t\xi_t(i,j)}{\sum_t\gamma_t(i)}$
   - $b_j(k) = \frac{\sum_{t:o_t=o_k}\gamma_t(j)}{\sum_t\gamma_t(j)}$

3. 重复 E、M 步直到收敛

## 5. 应用场景

- 语音识别（经典应用）
- 中文分词、词性标注
- 命名实体识别（NER）
- 生物信息学（基因序列分析）
- 金融时序预测（隐含状态推断）
- 手写体识别

## 6. 优缺点分析

**优点**：
- 有严格的概率解释
- 算法成熟，前向-后向、Viterbi、Baum-Welch 均有高效实现
- 适合序列建模

**缺点**：
- 齐次马尔可夫假设过强（状态只依赖前一步）
- 观测独立假设过强（观测只依赖当前状态）
- 无法考虑长距离依赖
- 状态数需要预先设定
- 生成式模型，无法直接引入丰富的特征

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

class HMM:
    def __init__(self, A, B, pi):
        self.A = A
        self.B = B
        self.pi = pi
        self.N = A.shape[0]
        self.M = B.shape[1]

    def forward(self, obs):
        T = len(obs)
        alpha = np.zeros((T, self.N))
        alpha[0] = self.pi * self.B[:, obs[0]]
        for t in range(1, T):
            for j in range(self.N):
                alpha[t, j] = np.sum(alpha[t-1] * self.A[:, j]) * self.B[j, obs[t]]
        return alpha, np.sum(alpha[-1])

    def backward(self, obs):
        T = len(obs)
        beta = np.zeros((T, self.N))
        beta[-1] = 1.0
        for t in range(T-2, -1, -1):
            for i in range(self.N):
                beta[t, i] = np.sum(self.A[i, :] * self.B[:, obs[t+1]] * beta[t+1])
        return beta

    def viterbi(self, obs):
        T = len(obs)
        delta = np.zeros((T, self.N))
        psi = np.zeros((T, self.N), dtype=int)
        delta[0] = self.pi * self.B[:, obs[0]]
        for t in range(1, T):
            for j in range(self.N):
                scores = delta[t-1] * self.A[:, j]
                psi[t, j] = np.argmax(scores)
                delta[t, j] = np.max(scores) * self.B[j, obs[t]]
        path = [np.argmax(delta[-1])]
        for t in range(T-1, 0, -1):
            path.append(psi[t, path[-1]])
        return list(reversed(path)), np.max(delta[-1])

A = np.array([[0.7, 0.3], [0.4, 0.6]])
B = np.array([[0.1, 0.4, 0.5], [0.6, 0.3, 0.1]])
pi = np.array([0.6, 0.4])
hmm = HMM(A, B, pi)

obs = [0, 1, 2, 0, 1]
alpha, prob = hmm.forward(obs)
print("P(O|lambda):", prob)
path, max_prob = hmm.viterbi(obs)
print("Best path:", path, "prob:", max_prob)
```

## 10. 模型评估

- **对数似然**：$\log P(O|\lambda)$，越大越好
- **Perplexity**：$\exp(-\frac{1}{T}\log P(O|\lambda))$，越小越好
- **解码准确率**：如有标注状态，比较 Viterbi 解码与真实状态的匹配率

## 11. 常见问题与易错点

1. **下溢问题**：长序列下前向/后向概率会趋近于零，需使用 log-space 计算或缩放技术
2. **局部最优**：Baum-Welch 是 EM 算法，只能保证收敛到局部最优，多次随机初始化有帮助
3. **状态数选择**：N 的选择需要经验或交叉验证，过大导致过拟合，过小表达力不足
4. **连续观测**：实际应用中观测常为连续值，需使用 GaussianHMM 或 GMMHMM

## 12. 学习总结

HMM 是序列建模的经典方法，其三个问题（评估、解码、学习）分别对应前向算法、Viterbi 算法和 Baum-Welch 算法。理解 HMM 有助于学习 CRF（条件随机场）和深度学习中的 RNN/Attention 序列模型。HMM 的主要局限在于其过强的独立性假设，CRF 正是为了克服这些局限而提出的。

## 13. 练习题与思考题（含答案）

**Q1**：为什么前向算法的复杂度是 $O(N^2T)$ 而不是 $O(N^T)$？

**A1**：直接计算需要枚举所有可能的状态路径（$N^T$ 种）。前向算法利用动态规划，在每步只保留 $\alpha_t(i)$ 共 $N$ 个值，递推时对每个 $j$ 求 $N$ 次求和，共 $T$ 步，因此复杂度为 $O(N^2 T)$。

**Q2**：Viterbi 算法与前向算法的区别是什么？

**A2**：前向算法在递推时对所有前驱状态**求和**（计算概率），Viterbi 算法在递推时**取最大值**（寻找最优路径）。前者是概率计算，后者是最大后验估计。

**Q3**：HMM 是生成模型还是判别模型？CRF 呢？各有什么优劣？

**A3**：HMM 是生成模型（建模 $P(O,Q)$），CRF 是判别模型（建模 $P(Q|O)$）。HMM 可以处理缺失数据、生成新序列，但无法灵活引入特征；CRF 可以引入任意特征函数，不受独立性假设限制，但训练更复杂。
