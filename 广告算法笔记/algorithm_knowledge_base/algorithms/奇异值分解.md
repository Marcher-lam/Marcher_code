# 奇异值分解 学习文档

## 1. 算法基础认知

奇异值分解（Singular Value Decomposition, SVD）是线性代数中最重要的矩阵分解之一。任意实矩阵 $A \in \mathbb{R}^{m \times n}$ 都可以分解为三个矩阵的乘积。SVD 是 PCA、推荐系统、自然语言处理等领域的数学基石，也是广告算法中降维与隐因子模型的核心工具。

## 2. 核心原理

SVD 的核心思想：**将矩阵分解为"旋转-缩放-旋转"三个线性变换的组合**。

$$A = U \Sigma V^T$$

- $U \in \mathbb{R}^{m \times m}$：左奇异向量矩阵（列向量称为左奇异向量）
- $\Sigma \in \mathbb{R}^{m \times n}$：对角矩阵，对角线上的非负元素称为奇异值
- $V \in \mathbb{R}^{n \times n}$：右奇异向量矩阵

奇异值 $\sigma_1 \geq \sigma_2 \geq \cdots \geq 0$ 按降序排列，反映了矩阵各"方向"上信息量的多少。

## 3. 数学公式与推导

**存在性证明要点**：

对 $A^T A$（$n \times n$ 对称半正定矩阵）做特征分解：

$$A^T A = V \Lambda V^T$$

取 $V$ 的列为右奇异向量，奇异值 $\sigma_i = \sqrt{\lambda_i}$，左奇异向量 $u_i = \frac{A v_i}{\sigma_i}$（当 $\sigma_i > 0$）。

**低秩近似（Eckart-Young 定理）**：

取前 $r$ 个最大奇异值构造截断 SVD：

$$A_r = U_r \Sigma_r V_r^T = \sum_{i=1}^{r} \sigma_i u_i v_i^T$$

Eckart-Young 定理保证 $A_r$ 是秩为 $r$ 的矩阵中，在 Frobenius 范数和谱范数下最优的近似：

$$\|A - A_r\|_F = \sqrt{\sum_{i=r+1}^{\min(m,n)} \sigma_i^2}$$

## 4. 训练过程讲解

SVD 的计算过程（非迭代，直接分解）：

1. 计算 $A^T A$，对其进行特征分解得到 $V$ 和 $\Lambda$
2. 奇异值 $\sigma_i = \sqrt{\lambda_i}$
3. 对 $\sigma_i > 0$ 的分量，计算 $u_i = A v_i / \sigma_i$
4. 组装 $U, \Sigma, V$

实际计算中，numpy/scipy 使用更高效的 LAPACK 例程（如分治法），避免显式计算 $A^T A$。

## 5. 应用场景

- **推荐系统**：用户-物品评分矩阵分解，隐语义模型
- **降维**：截断 SVD 等价于 PCA（中心化后）
- **文本处理**：LSA（潜在语义分析）的核心
- **图像压缩**：用低秩近似压缩图像
- **广告系统**：用户-广告交互矩阵分解，用于 CTR 预估的特征提取

## 6. 优缺点分析

**优点**：
- 对任意矩阵都存在（不像特征分解要求方阵）
- 低秩近似有最优性保证
- 数值稳定性好

**缺点**：
- 完整 SVD 计算复杂度 $O(mn \cdot \min(m,n))$，大矩阵计算昂贵
- 对稀疏矩阵需要先填充缺失值
- 结果解释性不如某些专用方法

## 7. 调库实现（Python + 完整代码 + 注释）

```python
import numpy as np
from sklearn.decomposition import TruncatedSVD
from sklearn.datasets import load_digits

digits = load_digits()
X = digits.data

U, sigma, Vt = np.linalg.svd(X, full_matrices=False)
print(f"Original shape: {X.shape}")
print(f"U: {U.shape}, Sigma: {sigma.shape}, Vt: {Vt.shape}")
print(f"Top 10 singular values: {sigma[:10].round(2)}")

svd = TruncatedSVD(n_components=30, random_state=42)
X_reduced = svd.fit_transform(X)
print(f"Explained variance ratio (30 components): {svd.explained_variance_ratio_.sum():.4f}")
print(f"Reduced shape: {X_reduced.shape}")
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

def svd_scratch(A):
    AtA = A.T @ A
    eigenvalues, V = np.linalg.eigh(AtA)
    idx = np.argsort(eigenvalues)[::-1]
    eigenvalues = eigenvalues[idx]
    V = V[:, idx]
    sigma = np.sqrt(np.maximum(eigenvalues, 0))
    r = np.sum(sigma > 1e-10)
    U = np.zeros((A.shape[0], r))
    for i in range(r):
        U[:, i] = A @ V[:, i] / sigma[i]
    Sigma = np.diag(sigma[:r])
    return U, Sigma, V[:, :r].T

A = np.random.randn(5, 4)
U, S, Vt = svd_scratch(A)
print("Reconstruction error:", np.linalg.norm(A - U @ S @ Vt))
```

## 10. 模型评估

- **重构误差**：$\|A - A_r\|_F / \|A\|_F$，衡量低秩近似的精度
- **解释方差比**：前 $r$ 个奇异值平方和占总奇异值平方和的比例
- **下游任务性能**：用降维后的特征在分类/回归任务上评估

## 11. 常见问题与易错点

- **SVD 与 PCA 的关系**：对中心化后的矩阵做 SVD 就是 PCA。PCA 要求先减去均值
- **截断 SVD 与完整 SVD**：截断 SVD 只计算前 $r$ 个奇异值/向量，适合大规模稀疏矩阵
- **full_matrices 参数**：`full_matrices=True` 返回完整 $U$（$m \times m$），`False` 返回精简版（$m \times \min(m,n)$）
- **奇异值为零**：意味着矩阵秩亏损，对应方向无信息

## 12. 学习总结

SVD 是连接线性代数与机器学习的桥梁。它提供了矩阵的最优低秩近似，是降维、推荐系统、信号处理的理论基础。掌握 SVD 后，PCA、LSA、矩阵补全等方法都水到渠成。

## 13. 练习题与思考题（含答案）

**Q1**：一个 $1000 \times 50$ 的矩阵，完整 SVD 后 $U, \Sigma, V$ 的维度分别是多少？

> 答：$U$ 为 $1000 \times 1000$，$\Sigma$ 为 $1000 \times 50$，$V$ 为 $50 \times 50$。若用 `full_matrices=False`，则 $U$ 为 $1000 \times 50$。

**Q2**：为什么说截断 SVD 适合处理稀疏矩阵？

> 答：截断 SVD 不需要中心化（与 PCA 不同），可以直接处理稀疏矩阵，通过随机化算法高效计算前 $r$ 个奇异向量。

**Q3**：SVD 在推荐系统中的基本思路是什么？

> 答：将用户-物品评分矩阵分解为 $U \Sigma V^T$，其中 $U$ 的行是用户的隐因子表示，$V$ 的行是物品的隐因子表示。用低秩近似补全缺失评分。
