# 条件随机场 学习文档

## 1. 算法基础认知

条件随机场（Conditional Random Field, CRF）由 Lafferty 等人于 2001 年提出，是一种**判别式**概率无向图模型。与 HMM 对联合概率 $P(Y,X)$ 建模不同，CRF 直接对条件概率 $P(Y|X)$ 建模，因此在给定观测序列的条件下，可以对标签序列做出更准确的预测。

CRF 最常用的形式是**线性链 CRF**（Linear-Chain CRF），广泛用于序列标注任务（如命名实体识别、词性标注）。

## 2. 核心原理

CRF 的核心思想是：**给定观测序列 $X$，定义标签序列 $Y$ 的条件概率分布，使得该分布在无向图中满足马尔可夫性**。

对于线性链 CRF，每个标签 $y_t$ 只与相邻标签 $y_{t-1}$ 和 $y_{t+1}$ 相关联，同时可以依赖于整个观测序列 $X$（这是 CRF 相对 HMM 的关键优势）。

CRF 通过**特征函数**来定义概率分布：
- **转移特征** $t_k(y_{t-1}, y_t, X, t)$：描述标签之间的转移关系
- **状态特征** $s_l(y_t, X, t)$：描述标签与观测之间的关系

## 3. 数学公式与推导

**线性链 CRF 的条件概率**：

$$P(y|x) = \frac{1}{Z(x)} \exp\left(\sum_{t=1}^{T}\sum_{k=1}^{K}\lambda_k t_k(y_{t-1}, y_t, x, t) + \sum_{t=1}^{T}\sum_{l=1}^{L}\mu_l s_l(y_t, x, t)\right)$$

简化形式（统一为 $f_j$）：

$$P(y|x) = \frac{1}{Z(x)} \exp\left(\sum_{j=1}^{J}w_j \sum_{t=1}^{T}f_j(y_{t-1}, y_t, x, t)\right)$$

其中配分函数：

$$Z(x) = \sum_{y}\exp\left(\sum_{j=1}^{J}w_j \sum_{t=1}^{T}f_j(y_{t-1}, y_t, x, t)\right)$$

**对数似然**：

$$L(w) = \sum_{i=1}^{N}\log P(y^{(i)}|x^{(i)}) = \sum_{i=1}^{N}\left[\sum_{j}w_j F_j(x^{(i)}, y^{(i)}) - \log Z(x^{(i)})\right]$$

**梯度**：

$$\frac{\partial L}{\partial w_j} = \sum_{i=1}^{N}\left[F_j(x^{(i)}, y^{(i)}) - E_{P(Y|x^{(i)})}[F_j(x^{(i)}, Y)]\right]$$

即特征在真实标签下的值与模型期望下的值之差。

## 4. 训练过程讲解

CRF 训练采用**极大似然估计**（可加 L2 正则化）：

1. 初始化权重 $w$
2. 对每个训练样本 $(x^{(i)}, y^{(i)})$：
   - 计算特征的模型期望 $E_P[F_j]$（需要前向-后向算法）
   - 计算特征的经验值 $F_j(x^{(i)}, y^{(i)})$
   - 计算梯度
3. 使用 L-BFGS / SGD 等优化方法更新权重
4. 重复直到收敛

**推断（解码）** 使用改进的 Viterbi 算法：将特征函数的加权和作为得分，在状态空间中寻找最优路径。

## 5. 应用场景

- **命名实体识别（NER）**：BiLSTM-CRF 是经典架构
- **词性标注（POS Tagging）**
- **中文分词**：序列标注方法（B/M/E/S 标签）
- **信息抽取**：从文本中提取结构化信息
- **图像分割**：二维 CRF 用于像素级分类
- **广告系统**：query 意图理解、slot filling

## 6. 优缺点分析

**优点**：
- 判别式模型，直接建模 $P(Y|X)$，不受观测独立性假设限制
- 可以引入全局特征（整个观测序列）
- 可以灵活设计特征函数
- 全局归一化，避免了标签偏置问题
- 在序列标注任务中表现优于 HMM

**缺点**：
- 训练时计算配分函数 $Z(x)$ 复杂度高
- 推断时需要 Viterbi，$O(T \cdot N^2)$
- 特征工程需要领域知识
- 无法像深度学习那样自动学习特征表示

## 7. 调库实现（Python + 完整代码 + 注释）

```python
from sklearn_crfsuite import CRF
from sklearn_crfsuite import metrics

train_sentences = [
    [("The", "DT"), ("cat", "NN"), ("sits", "VBZ")],
    [("A", "DT"), ("dog", "NN"), ("runs", "VBZ")],
]

def extract_features(sentence, i):
    word = sentence[i][0]
    features = {
        'bias': 1.0,
        'word.lower()': word.lower(),
        'word.isupper()': word.isupper(),
        'word.istitle()': word.istitle(),
        'word.isdigit()': word.isdigit(),
        'suffix-3': word[-3:],
        'suffix-2': word[-2:],
        'prefix-3': word[:3],
    }
    if i > 0:
        features.update({
            '-1:word.lower()': sentence[i-1][0].lower(),
            '-1:word.istitle()': sentence[i-1][0].istitle(),
        })
    else:
        features['BOS'] = True
    if i < len(sentence) - 1:
        features.update({
            '+1:word.lower()': sentence[i+1][0].lower(),
        })
    else:
        features['EOS'] = True
    return features

X_train = [[extract_features(s, i) for i in range(len(s))] for s in train_sentences]
y_train = [[tag for _, tag in s] for s in train_sentences]

crf = CRF(algorithm='lbfgs', c1=0.1, c2=0.1, max_iterations=100, all_possible_transitions=True)
crf.fit(X_train, y_train)

y_pred = crf.predict(X_train)
print(metrics.flat_accuracy_score(y_train, y_pred))

print("CRF 训练完成")
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

class LinearChainCRF:
    def __init__(self, n_tags, max_iter=100, lr=0.01, C=0.1):
        self.n_tags = n_tags
        self.max_iter = max_iter
        self.lr = lr
        self.C = C

    def _compute_scores(self, x_features):
        T = len(x_features)
        emission = np.zeros((T, self.n_tags))
        for t in range(T):
            for feat in x_features[t]:
                if feat in self.feat_dict:
                    emission[t] += self.w[self.feat_dict[feat]]

        transition = self.trans_w.copy()
        return emission, transition

    def _forward(self, emission, transition):
        T = emission.shape[0]
        alpha = np.zeros((T, self.n_tags))
        alpha[0] = emission[0]
        for t in range(1, T):
            for j in range(self.n_tags):
                alpha[t, j] = np.logaddexp.reduce(alpha[t-1] + transition[:, j]) + emission[t, j]
        return alpha

    def _backward(self, emission, transition):
        T = emission.shape[0]
        beta = np.zeros((T, self.n_tags))
        beta[-1] = 0.0
        for t in range(T-2, -1, -1):
            for i in range(self.n_tags):
                beta[t, i] = np.logaddexp.reduce(transition[i, :] + emission[t+1, :] + beta[t+1])
        return beta

    def fit(self, X_features, y_seqs):
        all_feats = set()
        for x_feats in X_features:
            for t_feats in x_feats:
                all_feats.update(t_feats.keys())
        self.feat_dict = {f: i for i, f in enumerate(sorted(all_feats))}
        n_feats = len(self.feat_dict) * self.n_tags
        self.w = np.zeros(n_feats)
        self.trans_w = np.zeros((self.n_tags, self.n_tags))

        for epoch in range(self.max_iter):
            for x_feats, y_seq in zip(X_features, y_seqs):
                emission, transition = self._compute_scores(x_feats)
                alpha = self._forward(emission, transition)
                beta = self._backward(emission, transition)
                log_z = np.logaddexp.reduce(alpha[-1])

                T = len(y_seq)
                for t in range(T):
                    for feat in x_feats[t]:
                        if feat in self.feat_dict:
                            idx = self.feat_dict[feat] * self.n_tags + y_seq[t]
                            self.w[idx] += self.lr
                    marginal = np.exp(alpha[t] + beta[t] - log_z)
                    for feat in x_feats[t]:
                        if feat in self.feat_dict:
                            for tag in range(self.n_tags):
                                idx = self.feat_dict[feat] * self.n_tags + tag
                                self.w[idx] -= self.lr * marginal[tag]

                for t in range(T - 1):
                    log_edges = (alpha[t].reshape(-1, 1) + transition
                                 + emission[t + 1].reshape(1, -1)
                                 + beta[t + 1].reshape(1, -1))
                    trans_marginal = np.exp(log_edges - log_z)
                    self.trans_w -= self.lr * trans_marginal
                    self.trans_w[y_seq[t], y_seq[t + 1]] += self.lr

            self.w -= self.lr * self.C * self.w
            self.trans_w -= self.lr * self.C * self.trans_w

    def predict(self, x_features):
        emission, transition = self._compute_scores(x_features)
        T = emission.shape[0]
        delta = np.zeros((T, self.n_tags))
        psi = np.zeros((T, self.n_tags), dtype=int)
        delta[0] = emission[0]
        for t in range(1, T):
            for j in range(self.n_tags):
                scores = delta[t-1] + transition[:, j]
                psi[t, j] = np.argmax(scores)
                delta[t, j] = np.max(scores) + emission[t, j]
        path = [np.argmax(delta[-1])]
        for t in range(T-1, 0, -1):
            path.append(psi[t, path[-1]])
        return list(reversed(path))

np.random.seed(42)
n_tags = 3
crf = LinearChainCRF(n_tags=n_tags, max_iter=10, lr=0.01)
X = [[{'bias': 1.0, 'word': 'hello'}, {'bias': 1.0, 'word': 'world'}]]
y = [[0, 1]]
crf.fit(X, y)
print("Predicted:", crf.predict(X[0]))
```

## 10. 模型评估

- **序列标注**：Token-level Accuracy、Entity-level F1（更严格）
- **常用工具**：`conlleval` 脚本、seqeval 库
- **调参重点**：L1/L2 正则化系数（c1/c2）、特征模板设计

## 11. 常见问题与易错点

1. **标签偏置问题**：MEMM 等局部归一化模型存在此问题，CRF 通过全局归一化解决
2. **特征工程繁琐**：传统 CRF 需要手工设计特征模板，BiLSTM-CRF 用神经网络自动学习特征
3. **计算效率**：CRF 的全局归一化需要计算 $Z(x)$，标签数多时计算量大
4. **BIO/BIOES 标签体系**：序列标注中标签编码方式的选择影响 CRF 效果

## 12. 学习总结

CRF 的核心贡献在于对条件概率 $P(Y|X)$ 做全局归一化而非局部归一化，从根本上解决了 MEMM 等模型中的标签偏置问题（Label Bias Problem）。通过灵活的特征函数设计（转移特征+状态特征），CRF 可以同时建模标签间的转移约束和观测序列的全局依赖，这是它在序列标注任务中长期占据主流的理论根基。

CRF 的关键优势是全局一致性保证——它考虑所有可能的标签路径后选择最优解，而非在每个位置独立决策。这使得 CRF 特别适合 BIO/BIOES 标签体系下的命名实体识别、中文分词等任务，因为"O 标签不能接在 I-PER 后面"这类约束可以被自然编码。但训练时计算配分函数 $Z(x)$ 的复杂度较高，特征工程也依赖领域知识。

在知识体系中，CRF 是本库中 HMM（生成式序列模型）的判别式对应，与最大熵模型共享指数族分布的理论基础。BiLSTM-CRF 架构将 CRF 与深度学习结合，是理解后续 Transformer-CRF 和结构化预测方法的关键节点。

工业实践中，纯 CRF 已逐渐被 BiLSTM-CRF 或 BERT-CRF 替代（用神经网络自动学习特征表示），但 CRF 层本身仍然是序列标注模型中不可或缺的组件。广告系统中 CRF 常用于 query 意图理解的 slot filling 任务。

## 13. 练习题与思考题（含答案）

**Q1**：CRF 与 HMM 的本质区别是什么？

**A1**：三个核心区别：(1) HMM 是生成模型（建模 $P(X,Y)$），CRF 是判别模型（建模 $P(Y|X)$）；(2) HMM 有观测独立假设（当前观测只依赖当前状态），CRF 可以使用整个观测序列的特征；(3) HMM 是有向图模型，CRF 是无向图模型。

**Q2**：什么是标签偏置问题？CRF 如何解决？

**A2**：在 MEMM（最大熵马尔可夫模型）中，由于在每个状态做局部归一化，转移分支少的状态会"偏袒"自己，导致路径选择偏向低熵状态。CRF 对整个序列做全局归一化（计算 $Z(x)$ 时考虑所有路径），从而避免了这个问题。

**Q3**：为什么 BiLSTM-CRF 比单独的 CRF 效果好？

**A3**：因为 BiLSTM 自动学习上下文相关的特征表示（无需手工特征工程），而 CRF 层在此基础上建模标签转移约束。两者互补：BiLSTM 提供强大的特征提取，CRF 提供全局一致性约束。
