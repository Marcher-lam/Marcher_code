# 决策树 学习文档

## 1. 算法基础认知

决策树（Decision Tree）是一种基于树结构进行决策的监督学习算法，既可以用于分类也可以用于回归。它通过递归地将特征空间划分为若干个子区域，在每个子区域上给出一个预测值。决策树的直观性极强——它的决策过程类似于人类做判断时的"如果...那么..."逻辑，是机器学习中最具可解释性的模型之一。

决策树的核心问题有三个：如何选择最优划分特征、何时停止划分、如何防止过拟合。

## 2. 核心原理

决策树的学习过程是一个递归地选择最优特征、按特征值划分数据集的过程：

1. **特征选择**：从当前节点的所有特征中选择一个最优特征，按其取值将数据集分成子集
2. **递归分裂**：对每个子集重复步骤1，直到满足停止条件
3. **停止条件**：子集中所有样本属于同一类、没有特征可供划分、子集为空、达到最大深度等

三种主流的特征选择标准对应三种经典算法：
- **信息增益** → ID3
- **信息增益率** → C4.5
- **基尼指数** → CART

## 3. 数学公式与推导

**信息熵**（度量数据集纯度）：

$$H(D) = -\sum_{k=1}^{K} p_k \log_2 p_k$$

其中 $p_k$ 是第 $k$ 类样本所占比例。熵越大，数据越不纯。

**信息增益**（ID3使用）：

$$g(D, A) = H(D) - H(D|A) = H(D) - \sum_{v=1}^{V} \frac{|D^v|}{|D|} H(D^v)$$

其中 $D^v$ 是特征 $A$ 取值为 $v$ 的子集。

**信息增益率**（C4.5使用）：

$$g_R(D, A) = \frac{g(D, A)}{H_A(D)}, \quad H_A(D) = -\sum_{v=1}^{V} \frac{|D^v|}{|D|} \log_2 \frac{|D^v|}{|D|}$$

**基尼指数**（CART使用）：

$$\text{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^2$$

$$\text{Gini\_index}(D, A) = \sum_{v=1}^{V} \frac{|D^v|}{|D|} \text{Gini}(D^v)$$

基尼指数越小，数据集纯度越高。CART选择使基尼指数最小的特征进行划分。

## 4. 训练过程讲解

**决策树构建（CART分类树为例）**：

1. 对当前节点的数据集，计算每个特征每个可能切分点的基尼指数
2. 选择基尼指数最小的特征及其切分点，将数据集分为两个子集
3. 对子集递归执行步骤1-2
4. 当满足停止条件时，将当前节点标记为叶节点，类别取子集中多数类

**剪枝**：决策树容易过拟合，需要通过剪枝来提高泛化能力：
- **预剪枝**：在构建过程中提前停止（限制深度、最小样本数等）
- **后剪枝**：先构建完整树，再自底向上将子树替换为叶节点

## 5. 应用场景

- **信用评分**：根据收入、负债等特征判断违约风险
- **医疗诊断**：根据症状和检查结果辅助诊断
- **用户画像**：根据行为特征对用户分类
- **广告点击预测**：判断用户是否点击广告（可解释性强）
- **故障诊断**：定位系统故障原因

## 6. 优缺点分析

**优点**：
- 直观易懂，可解释性极强
- 不需要特征标准化
- 能处理数值型和类别型特征
- 训练和预测速度快
- 对缺失值有一定鲁棒性

**缺点**：
- 容易过拟合，需要剪枝
- 对数据微小变化敏感（不稳定）
- 只能进行轴平行划分，对斜决策边界效果差
- 贪心算法，无法保证全局最优

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np
from collections import Counter

class DecisionTree:
    def __init__(self, max_depth=5, min_samples=2):
        self.max_depth = max_depth
        self.min_samples = min_samples

    def _gini(self, y):
        counts = np.bincount(y)
        probs = counts / len(y)
        return 1.0 - np.sum(probs ** 2)

    def _best_split(self, X, y):
        best_gain, best_feat, best_thresh = 0, None, None
        parent_gini = self._gini(y)
        n_features = X.shape[1]
        for feat in range(n_features):
            thresholds = np.unique(X[:, feat])
            for t in thresholds:
                left_mask = X[:, feat] <= t
                right_mask = ~left_mask
                if left_mask.sum() == 0 or right_mask.sum() == 0:
                    continue
                n = len(y)
                weighted = (left_mask.sum() / n) * self._gini(y[left_mask]) + \
                           (right_mask.sum() / n) * self._gini(y[right_mask])
                gain = parent_gini - weighted
                if gain > best_gain:
                    best_gain, best_feat, best_thresh = gain, feat, t
        return best_feat, best_thresh, best_gain

    def _build(self, X, y, depth):
        if depth >= self.max_depth or len(y) < self.min_samples or len(set(y)) == 1:
            return {'leaf': True, 'value': Counter(y).most_common(1)[0][0]}
        feat, thresh, gain = self._best_split(X, y)
        if feat is None:
            return {'leaf': True, 'value': Counter(y).most_common(1)[0][0]}
        left_mask = X[:, feat] <= thresh
        return {
            'leaf': False, 'feature': feat, 'threshold': thresh,
            'left': self._build(X[left_mask], y[left_mask], depth + 1),
            'right': self._build(X[~left_mask], y[~left_mask], depth + 1)
        }

    def fit(self, X, y):
        self.tree = self._build(X, y, 0)

    def _predict_one(self, x, node):
        if node['leaf']:
            return node['value']
        if x[node['feature']] <= node['threshold']:
            return self._predict_one(x, node['left'])
        return self._predict_one(x, node['right'])

    def predict(self, X):
        return np.array([self._predict_one(x, self.tree) for x in X])

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
dt = DecisionTree(max_depth=5)
dt.fit(X_train, y_train)
print(f"手工实现准确率: {accuracy_score(y_test, dt.predict(X_test)):.4f}")
```

## 11. 常见问题与易错点

1. **过拟合**：决策树默认会生长到每个叶节点纯度最高，极易过拟合。务必设置 `max_depth`、`min_samples_split` 等参数。
2. **特征选择偏向**：信息增益偏向取值多的特征，C4.5 通过增益率修正此问题。
3. **连续特征处理**：C4.5 和 CART 支持连续特征，ID3 只支持离散特征。
4. **数据不平衡**：类别不平衡时，决策树偏向多数类，可设置 `class_weight='balanced'`。

## 12. 学习总结

决策树是机器学习中最重要的基础模型之一，理解它是学习随机森林、GBDT、XGBoost 等集成方法的前提。核心是掌握三种划分标准（信息增益、增益率、基尼指数）的原理与区别，以及剪枝策略。

## 13. 练习题与思考题（含答案）

**题目1**：数据集有10个样本，6个正例4个反例，按特征A划分后左子集5个正例0个反例，右子集1个正例4个反例，求特征A的信息增益。

**解答**：

$$H(D) = -\frac{6}{10}\log_2\frac{6}{10} - \frac{4}{10}\log_2\frac{4}{10} \approx 0.971$$

$$H(D|A) = \frac{5}{10} \times 0 + \frac{5}{10} \times \left(-\frac{1}{5}\log_2\frac{1}{5} - \frac{4}{5}\log_2\frac{4}{5}\right) \approx 0.5 \times 0.722 = 0.361$$

$$g(D, A) = 0.971 - 0.361 = 0.610 \text{ bit}$$

**题目2**：为什么 CART 使用基尼指数而不是信息熵？

**解答**：基尼指数计算不需要对数运算，计算效率更高；在数值上基尼指数与信息熵的曲线形状相似，功能等价；CART 的二叉树结构使得基尼指数的计算更自然。
