# 残差神经网络 学习文档

## 1. 算法基础认知

残差神经网络（Residual Neural Network, ResNet）由何恺明等人在 2015 年提出，是深度学习发展史上的里程碑。其核心贡献是提出了**残差连接（Residual Connection / Skip Connection）**，成功训练了 152 层甚至上千层的网络，彻底解决了深层网络训练中的**退化问题**。

在 ResNet 之前，网络加深后训练误差反而上升——这并非过拟合，而是一个优化难题。ResNet 通过让网络学习残差映射而非直接映射，使梯度能够直接回传到浅层，从而解决了这一瓶颈。

## 2. 核心原理

**退化问题**：理论上，更深的网络至少不应比浅层网络差（多余层可以学恒等映射）。但实际上 SGD 难以优化恒等映射，导致深层网络反而性能下降。

**残差连接的核心思想**：不直接学习目标映射 $H(x)$，而是学习残差 $F(x) = H(x) - x$，即：

$$H(x) = F(x) + x$$

如果最优映射接近恒等映射，则 $F(x) \approx 0$ 比直接学习 $H(x) \approx x$ 更容易优化（将权重推向零比维持恒等映射更简单）。

**恒等映射（Identity Mapping）**：当残差块的输入输出维度一致时，shortcut 路径直接传递 $x$；维度不一致时使用 1×1 卷积调整通道数。

## 3. 数学公式与推导

**基本残差块：**

$$\mathbf{y} = \mathcal{F}(\mathbf{x}, \{W_i\}) + \mathbf{x}$$

其中 $\mathcal{F}(\mathbf{x}, \{W_i\})$ 表示需要学习的残差映射，通常包含 2-3 个卷积层：

$$\mathcal{F}(\mathbf{x}) = W_2 \cdot \text{ReLU}(W_1 \cdot \mathbf{x} + b_1) + b_2$$

**梯度反传分析：**

设损失为 $L$，对 $x$ 的梯度为：

$$\frac{\partial L}{\partial \mathbf{x}} = \frac{\partial L}{\partial \mathbf{y}} \cdot \frac{\partial \mathbf{y}}{\partial \mathbf{x}} = \frac{\partial L}{\partial \mathbf{y}} \cdot \left(\frac{\partial \mathcal{F}}{\partial \mathbf{x}} + I\right)$$

其中 $I$ 为单位矩阵。关键点在于：即使 $\frac{\partial \mathcal{F}}{\partial \mathbf{x}}$ 很小，梯度仍可通过 $I$ 这条路径无损传递，避免了梯度消失。

**Bottleneck 结构（ResNet-50/101/152）：**

$$\mathcal{F}(\mathbf{x}) = W_3 \cdot \text{ReLU}(W_2 \cdot \text{ReLU}(W_1 \cdot \mathbf{x}))$$

其中 $W_1$ 为 1×1 卷积降维，$W_2$ 为 3×3 卷积，$W_3$ 为 1×1 卷积升维。

## 4. 训练过程讲解

1. **输入**：图像输入网络，依次通过多个残差阶段（每个阶段包含多个残差块）。
2. **残差计算**：在每个残差块中，输入 $x$ 同时走两条路径：主路径经过卷积变换得到 $F(x)$，shortcut 路径直接传递 $x$，两者相加后经 ReLU 激活。
3. **损失与反传**：交叉熵损失经反向传播到每个残差块时，梯度通过加法节点分流：一路经 $F(x)$ 的卷积层，一路直接传给 $x$。后者保证了浅层始终能收到有效梯度。
4. **训练技巧**：ResNet 原论文使用了 BN + ReLU 的后激活顺序（Pre-activation ResNet 改为前置），权重初始化使用 He 初始化。

## 5. 应用场景

- 通用图像分类（ResNet-50 是最常用的骨干网络之一）
- 目标检测与实例分割的骨干（Faster R-CNN、Mask R-CNN）
- 人脸识别（ResNet + ArcFace）
- 广告系统中的图像特征提取、多模态模型的视觉编码器
- 医学影像、遥感图像分析

## 6. 优缺点分析

**优点：**
- 可训练极深网络（100+ 层）而不退化
- 梯度流通顺畅，训练更稳定
- 结构简单，易于复用和组合

**缺点：**
- 残差连接引入额外的内存开销（需保存 shortcut 的输入）
- 极深网络（1000+ 层）的收益递减，训练时间成本高
- 推理时 shortcut 分支不参与计算但增加了图的复杂度

## 7. 调库实现（Python + 完整代码 + 注释）

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms

class BasicBlock(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride=stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, stride=1, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride=stride, bias=False),
                nn.BatchNorm2d(out_channels),
            )

    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += self.shortcut(x)
        out = torch.relu(out)
        return out

class ResNet18(nn.Module):
    def __init__(self):
        super().__init__()
        self.in_channels = 64
        self.conv1 = nn.Conv2d(3, 64, 3, stride=1, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(64)
        self.layer1 = self._make_layer(64, 2, stride=1)
        self.layer2 = self._make_layer(128, 2, stride=2)
        self.layer3 = self._make_layer(256, 2, stride=2)
        self.layer4 = self._make_layer(512, 2, stride=2)
        self.fc = nn.Linear(512, 10)

    def _make_layer(self, out_channels, num_blocks, stride):
        strides = [stride] + [1] * (num_blocks - 1)
        layers = []
        for s in strides:
            layers.append(BasicBlock(self.in_channels, out_channels, s))
            self.in_channels = out_channels
        return nn.Sequential(*layers)

    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.layer1(out)
        out = self.layer2(out)
        out = self.layer3(out)
        out = self.layer4(out)
        out = out.mean(dim=[2, 3])
        out = self.fc(out)
        return out

transform = transforms.Compose([transforms.ToTensor(), transforms.Normalize((0.5,0.5,0.5),(0.5,0.5,0.5))])
train_loader = torch.utils.data.DataLoader(datasets.CIFAR10('./data', train=True, download=True, transform=transform), batch_size=128, shuffle=True)

model = ResNet18()
optimizer = optim.SGD(model.parameters(), lr=0.1, momentum=0.9, weight_decay=5e-4)
criterion = nn.CrossEntropyLoss()

for epoch in range(3):
    for bx, by in train_loader:
        optimizer.zero_grad()
        loss = criterion(model(bx), by)
        loss.backward()
        optimizer.step()
    print(f"Epoch {epoch+1}, Loss: {loss.item():.4f}")
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

def residual_block_forward(x, W1, b1, W2, b2, W_skip=None, b_skip=None):
    F = np.maximum(0, x @ W1 + b1)
    F = F @ W2 + b2
    identity = x @ W_skip + b_skip if W_skip is not None else x
    return np.maximum(0, F + identity)

def residual_block_backward(dout, cache):
    x, F_relu, F_pre, identity, W1, W2, W_skip = cache
    drelu = dout * (F + identity > 0)
    dF = drelu
    didentity = drelu
    dW2 = F_relu.T @ dF
    db2 = dF.sum(axis=0)
    dF_relu = dF @ W2.T
    dF_pre = dF_relu * (F_pre > 0)
    dW1 = x.T @ dF_pre
    db1 = dF_pre.sum(axis=0)
    dx = dF_pre @ W1.T
    if W_skip is not None:
        dW_skip = x.T @ didentity
        db_skip = didentity.sum(axis=0)
        dx += didentity @ W_skip.T
    else:
        dx += didentity
    return dx, dW1, db1, dW2, db2
```

## 9. 可视化与结果理解

- **残差值分布**：观察 $F(x)$ 的值分布，训练良好的 ResNet 中 $F(x)$ 值普遍较小，说明网络在学习"微调"而非"重建"
- **梯度范数**：对比有无残差连接时各层梯度范数，残差连接使梯度在各层间更均匀
- **学习曲线**：ResNet 的训练损失随深度增加持续下降，而普通网络在加深后出现训练损失上升
- **特征可视化**：深层残差块的特征图对语义信息更敏感

## 10. 模型评估

- **Top-1 / Top-5 准确率**：ImageNet 上的标准指标，ResNet-18 约 69.8%/89.1%
- **参数量与 FLOPs**：ResNet-18 约 11.7M 参数，ResNet-50 约 25.6M 参数
- **特征质量**：提取的中间特征用于下游任务（检测、分割）时的迁移性能
- **推理延迟**：实际部署场景下的单帧推理时间

## 11. 常见问题与易错点

- **维度不匹配**：shortcut 分支输入输出通道数或空间尺寸不同时，必须用 1×1 卷积调整，否则无法相加
- **BN 位置**：原始 ResNet 在卷积后 BN 再 ReLU，Pre-activation ResNet 将 BN+ReLU 放在卷积前，性能更好但需注意实现细节
- **stride 设置**：在残差块的第一个卷积设置 stride=2 进行下采样，shortcut 也需要相应 stride
- **He 初始化**：ReLU 激活函数配合 He 初始化效果最佳，错误使用 Xavier 可能导致训练不稳定
- **忘记 bias=False**：使用 BN 时卷积层通常不使用偏置，因为 BN 本身包含偏移参数

## 12. 学习总结

ResNet 的核心创新极其简洁——一条加法 shortcut，但影响深远。它不仅解决了退化问题，更成为了几乎所有现代深度网络的默认构建单元。残差连接的思想已超越 CNN，被广泛应用于 Transformer（残差连接在每个子层）、GAN 等架构中。掌握 ResNet 是理解现代深度学习架构的必经之路。

## 13. 练习题与思考题（含答案）

**Q1：为什么学习 $F(x) = H(x) - x$ 比直接学习 $H(x)$ 更容易？**

A1：当最优映射接近恒等映射时，$F(x) \approx 0$ 意味着只需将权重推向零，而学习 $H(x) \approx x$ 需要精确维持一组权重使其输出等于输入。前者通过正则化自然趋向，后者是精确的约束优化问题。

**Q2：去掉残差连接，直接堆叠 100 个卷积层，会出现什么问题？**

A2：梯度消失/爆炸导致训练无法收敛；即使使用 BN，也会出现退化问题——训练误差随深度增加而上升，这并非过拟合而是优化困难。

**Q3：Bottleneck 结构中，为什么用 1×1 卷积先降维再升维？**

A3：3×3 卷积的计算量与通道数成正比。先用 1×1 卷积将 256 维降到 64 维再做 3×3 卷积，计算量从 $256^2 \times 3^2$ 降到 $256×64×3^2 + 256×64×1^2 + 64×256×1^2$，大幅减少。
