# 朴素贝叶斯 学习文档

## 1. 算法基础认知

朴素贝叶斯（Naive Bayes）是一类基于贝叶斯定理与条件独立性假设的分类算法。它的核心思想是：通过已知的先验概率和似然函数，利用贝叶斯公式计算后验概率，将样本分到后验概率最大的类别中。

"朴素"二字源于一个强假设——所有特征在给定类别标签的条件下相互独立。虽然该假设在现实中几乎不成立，但朴素贝叶斯在文本分类、垃圾邮件过滤等任务上表现优异，是机器学习入门必学的经典算法。

## 2. 核心原理

朴素贝叶斯的分类逻辑如下：

给定样本 $\mathbf{x} = (x_1, x_2, \dots, x_d)$，我们希望找到使后验概率 $P(y=c|\mathbf{x})$ 最大的类别 $c$。根据贝叶斯定理：

$$P(y=c|\mathbf{x}) = \frac{P(\mathbf{x}|y=c) \cdot P(y=c)}{P(\mathbf{x})}$$

由于 $P(\mathbf{x})$ 对所有类别相同，只需最大化分子。利用条件独立性假设：

$$P(\mathbf{x}|y=c) = \prod_{j=1}^{d} P(x_j|y=c)$$

因此分类规则为：

$$\hat{y} = \arg\max_c P(y=c) \prod_{j=1}^{d} P(x_j|y=c)$$

## 3. 数学公式与推导

**贝叶斯定理**：

$$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$$

**先验概率**：

$$P(y=c) = \frac{N_c}{N}$$

其中 $N_c$ 是类别 $c$ 的样本数，$N$ 是总样本数。

**条件概率（似然）**：取决于特征分布假设，有三种常见变体：

- **高斯朴素贝叶斯**（Gaussian NB）：$P(x_j|y=c) = \frac{1}{\sqrt{2\pi\sigma_{c,j}^2}} \exp\left(-\frac{(x_j-\mu_{c,j})^2}{2\sigma_{c,j}^2}\right)$
- **多项式朴素贝叶斯**（Multinomial NB）：$P(x_j|y=c) = \frac{N_{c,j} + \alpha}{N_c + \alpha \cdot d}$
- **伯努利朴素贝叶斯**（Bernoulli NB）：特征为二值，$P(x_j|y=c)$ 按伯努利分布估计

**拉普拉斯平滑**：为避免某个条件概率为零导致整个乘积为零，引入平滑参数 $\alpha$（通常 $\alpha=1$）：

$$P(x_j = a|y=c) = \frac{N_{c,j,a} + \alpha}{N_c + \alpha \cdot |S_j|}$$

其中 $|S_j|$ 是特征 $j$ 的可能取值数。

## 4. 训练过程讲解

1. 统计每个类别的先验概率 $P(y=c)$
2. 对每个特征，在每个类别下统计条件概率 $P(x_j|y=c)$
3. 连续特征使用高斯分布，需计算每个类别下每个特征的均值 $\mu$ 和方差 $\sigma^2$
4. 预测时，计算所有类别的后验概率（取对数避免下溢），选择最大值对应的类别

**对数概率**：由于多个小概率连乘会导致数值下溢，实际计算时取对数：

$$\log P(y=c|\mathbf{x}) \propto \log P(y=c) + \sum_{j=1}^{d} \log P(x_j|y=c)$$

## 5. 应用场景

- **文本分类**：新闻分类、情感分析
- **垃圾邮件过滤**：经典应用场景
- **广告点击率预估**：作为基线模型
- **情感分析**：正面/负面评论判断
- **医疗诊断辅助**：基于症状判断疾病

## 6. 优缺点分析

**优点**：
- 训练和预测速度极快
- 对小样本数据表现良好
- 对高维数据（如文本特征）效果好
- 天然支持多分类
- 可处理缺失特征

**缺点**：
- 特征条件独立性假设过强，现实中难以满足
- 对特征间的相关性完全忽略
- 输出概率值不够准确（但排序通常正确）
- 对输入数据的表达形式敏感

## 7. 调库实现（Python + 完整代码 + 注释）

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import GaussianNB, MultinomialNB, BernoulliNB
from sklearn.metrics import classification_report, accuracy_score

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

model = GaussianNB()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(f"Accuracy: {accuracy_score(y_test, y_pred):.4f}")
print(classification_report(y_test, y_pred, target_names=load_iris().target_names))
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

class NaiveBayesGaussian:
    def fit(self, X, y):
        self.classes = np.unique(y)
        self.n_classes = len(self.classes)
        self.means = {}
        self.vars = {}
        self.priors = {}
        n = X.shape[0]
        for c in self.classes:
            X_c = X[y == c]
            self.means[c] = X_c.mean(axis=0)
            self.vars[c] = X_c.var(axis=0) + 1e-9
            self.priors[c] = X_c.shape[0] / n

    def _log_likelihood(self, x, c):
        mean = self.means[c]
        var = self.vars[c]
        return -0.5 * np.sum(np.log(2 * np.pi * var)) - 0.5 * np.sum((x - mean) ** 2 / var)

    def predict(self, X):
        preds = []
        for x in X:
            log_probs = []
            for c in self.classes:
                log_prior = np.log(self.priors[c])
                log_likelihood = self._log_likelihood(x, c)
                log_probs.append(log_prior + log_likelihood)
            preds.append(self.classes[np.argmax(log_probs)])
        return np.array(preds)

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

nb = NaiveBayesGaussian()
nb.fit(X_train, y_train)
print(f"手工实现准确率: {accuracy_score(y_test, nb.predict(X_test)):.4f}")
```

## 11. 常见问题与易错点

1. **零概率问题**：某个特征值在训练集中未出现时，条件概率为零，导致整个后验为零。必须使用拉普拉斯平滑。
2. **连续特征处理**：不要直接用频率估计连续特征的条件概率，应使用高斯朴素贝叶斯或先离散化。
3. **特征独立性假设**：高度相关的特征会导致重复计数，可通过特征选择或使用半朴素贝叶斯缓解。
4. **数值下溢**：多个小概率相乘结果趋近于零，必须取对数计算。
5. **不平衡数据**：先验概率会偏向多数类，可能需要调整类权重或重采样。

## 12. 学习总结

朴素贝叶斯虽然假设"朴素"，但在实践中效果出奇地好，尤其是在文本分类等高维稀疏场景。其训练复杂度为 $O(N \cdot d)$，预测复杂度为 $O(C \cdot d)$，是非常高效的算法。理解贝叶斯思想（先验 + 似然 → 后验）是学习概率图模型、贝叶斯深度学习的基础。

## 13. 练习题与思考题（含答案）

**题目1**：给定训练集中 $P(y=1)=0.6$，$P(x_1=\text{晴天}|y=1)=0.7$，$P(x_1=\text{晴天}|y=0)=0.2$，求 $P(y=1|x_1=\text{晴天})$。

**解答**：

$$P(y=1|x_1=\text{晴天}) = \frac{0.7 \times 0.6}{0.7 \times 0.6 + 0.2 \times 0.4} = \frac{0.42}{0.42 + 0.08} = \frac{0.42}{0.50} = 0.84$$

**题目2**：为什么朴素贝叶斯在文本分类中效果好，即使独立性假设不成立？

**解答**：文本特征维度极高，每个特征（词）的信息量有限，朴素贝叶斯不需要精确估计概率值，只需保证各类别概率的相对排序正确即可。高维空间中，即使单个条件概率估计有偏差，大量特征的累积效应仍能给出正确的分类结果。
