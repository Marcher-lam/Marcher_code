# 二项逻辑回归 学习文档

## 1. 算法基础认知

二项逻辑回归（Binomial Logistic Regression）是机器学习中最经典的二分类算法。虽然名字中有"回归"，但它本质上是一个分类模型。其核心思想是：通过 Sigmoid 函数将线性回归的输出映射到 $(0,1)$ 区间，作为样本属于正类的概率估计，然后通过最大似然估计求解最优参数。

逻辑回归是广告点击率（CTR）预估中最经典的模型，也是广义线性模型（GLM）的重要实例。

## 2. 核心原理

逻辑回归的假设函数为：

$$h_\theta(\mathbf{x}) = \sigma(\theta^T \mathbf{x}) = \frac{1}{1 + e^{-\theta^T \mathbf{x}}}$$

其中 $\sigma(\cdot)$ 是 Sigmoid 函数，$\theta^T \mathbf{x}$ 是线性组合（也称为 logit）。

**为什么用 Sigmoid？**

Sigmoid 函数有两个关键性质：
1. 输出范围 $(0, 1)$，可直接解释为概率
2. 形式优美：$\sigma'(z) = \sigma(z)(1 - \sigma(z))$，梯度计算简洁

**对数几率（Log-Odds）**：

$$\log \frac{P(y=1|\mathbf{x})}{P(y=0|\mathbf{x})} = \theta^T \mathbf{x}$$

即对数几率是输入特征的线性函数，这就是"逻辑回归"名称的来源——在对数几率空间中做回归。

## 3. 数学公式与推导

**Sigmoid 函数**：

$$\sigma(z) = \frac{1}{1 + e^{-z}}, \quad \sigma'(z) = \sigma(z)(1 - \sigma(z))$$

**似然函数**：

$$L(\theta) = \prod_{i=1}^{n} h_\theta(\mathbf{x}_i)^{y_i} (1 - h_\theta(\mathbf{x}_i))^{1 - y_i}$$

**对数似然**：

$$\ell(\theta) = \sum_{i=1}^{n} \left[ y_i \log h_\theta(\mathbf{x}_i) + (1 - y_i) \log(1 - h_\theta(\mathbf{x}_i)) \right]$$

等价于最小化交叉熵损失：

$$J(\theta) = -\frac{1}{n} \sum_{i=1}^{n} \left[ y_i \log h_\theta(\mathbf{x}_i) + (1 - y_i) \log(1 - h_\theta(\mathbf{x}_i)) \right]$$

**梯度推导**：

$$\frac{\partial J}{\partial \theta_j} = \frac{1}{n} \sum_{i=1}^{n} (h_\theta(\mathbf{x}_i) - y_i) x_{ij}$$

梯度形式与线性回归的 MSE 梯度相同（都是残差乘以特征），但假设函数不同。

**参数更新（梯度下降）**：

$$\theta_j := \theta_j - \eta \cdot \frac{\partial J}{\partial \theta_j}$$

**带 L2 正则化的损失函数**：

$$J_{reg}(\theta) = J(\theta) + \frac{\lambda}{2n} \|\theta\|_2^2$$

## 4. 训练过程讲解

1. **初始化参数** $\theta = \mathbf{0}$ 或随机小值
2. **前向传播**：计算 $h_\theta(\mathbf{x}_i) = \sigma(\theta^T \mathbf{x}_i)$
3. **计算损失**：代入交叉熵损失公式
4. **计算梯度**：$\nabla J = \frac{1}{n} X^T (\mathbf{h} - \mathbf{y})$
5. **更新参数**：$\theta := \theta - \eta \nabla J$
6. 重复步骤2-5直到收敛（损失变化小于阈值或达到最大迭代次数）

**决策规则**：若 $h_\theta(\mathbf{x}) \geq 0.5$，预测为正类；否则预测为负类。

## 5. 应用场景

- **广告点击率预估（CTR）**：预测用户是否点击广告
- **垃圾邮件分类**：判断邮件是否为垃圾邮件
- **信用评分**：预测用户是否违约
- **疾病诊断**：判断是否患病
- **转化率预估（CVR）**：预测用户是否会购买

## 6. 优缺点分析

**优点**：
- 模型简单，训练速度快
- 输出概率值，可用于排序
- 可解释性强（权重反映特征重要性）
- 适合高维稀疏特征（如 One-Hot 编码后）
- 工业部署方便，在线预测快

**缺点**：
- 只能处理线性可分问题（除非添加特征交叉）
- 对非线性关系建模能力弱
- 对异常值敏感
- 多重共线性会影响权重估计

## 7. 调库实现（Python + 完整代码 + 注释）

```python
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import classification_report, roc_auc_score

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

model = LogisticRegression(C=1.0, penalty='l2', solver='lbfgs', max_iter=1000, random_state=42)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
y_prob = model.predict_proba(X_test)[:, 1]

print(f"AUC: {roc_auc_score(y_test, y_prob):.4f}")
print(classification_report(y_test, y_pred, target_names=['malignant', 'benign']))
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

class LogisticRegressionGD:
    def __init__(self, lr=0.01, n_iters=1000, reg_lambda=0.01):
        self.lr = lr
        self.n_iters = n_iters
        self.reg_lambda = reg_lambda

    def _sigmoid(self, z):
        return 1 / (1 + np.exp(-np.clip(z, -500, 500)))

    def fit(self, X, y):
        n, d = X.shape
        self.w = np.zeros(d)
        self.b = 0
        for _ in range(self.n_iters):
            z = X @ self.w + self.b
            h = self._sigmoid(z)
            error = h - y
            self.w -= self.lr * (X.T @ error / n + self.reg_lambda * self.w)
            self.b -= self.lr * np.mean(error)

    def predict_proba(self, X):
        return self._sigmoid(X @ self.w + self.b)

    def predict(self, X):
        return (self.predict_proba(X) >= 0.5).astype(int)

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

model = LogisticRegressionGD(lr=0.1, n_iters=2000, reg_lambda=0.01)
model.fit(X_train, y_train)
print(f"手工实现准确率: {accuracy_score(y_test, model.predict(X_test)):.4f}")
```

## 11. 常见问题与易错点

1. **特征标准化**：逻辑回归对特征尺度敏感，必须先标准化或归一化。
2. **类别不平衡**：数据不平衡时模型偏向多数类，设置 `class_weight='balanced'` 或调整阈值。
3. **完全分离**：当特征能完美区分两类时，最大似然估计不存在（参数趋向无穷），需加正则化。
4. **多共线性**：高度相关的特征导致权重不稳定，可用 L1 正则化做特征选择。
5. **决策阈值**：默认0.5不一定是最佳阈值，应根据业务需求（Precision/Recall 权衡）调整。

## 12. 学习总结

二项逻辑回归是最重要的分类模型之一，它将线性模型与概率框架完美结合。理解 Sigmoid 函数、最大似然估计和交叉熵损失是掌握逻辑回归的关键。在广告系统中，逻辑回归（及其特征交叉变体如 FM、FFM）至今仍是 CTR 预估的重要基线模型。

## 13. 练习题与思考题（含答案）

**题目1**：给定 $\theta^T \mathbf{x} = 2$，求 $P(y=1|\mathbf{x})$。

**解答**：

$$P(y=1|\mathbf{x}) = \sigma(2) = \frac{1}{1 + e^{-2}} = \frac{1}{1 + 0.1353} \approx \frac{1}{1.1353} \approx 0.8808$$

**题目2**：逻辑回归的决策边界是什么形状？为什么？

**解答**：线性决策边界（超平面）。因为决策边界在 $h_\theta(\mathbf{x}) = 0.5$ 处，即 $\sigma(\theta^T \mathbf{x}) = 0.5$，等价于 $\theta^T \mathbf{x} = 0$，这是一个关于特征的线性方程，在二维空间中为一条直线，高维空间中为超平面。

**题目3**：为什么逻辑回归用交叉熵损失而不是 MSE？

**解答**：若用 MSE，损失函数为 $J = (y - \sigma(z))^2$，此时 $J$ 对 $z$ 的梯度为 $2(y-\sigma(z))\sigma(z)(1-\sigma(z))$。当 $\sigma(z)$ 接近0或1时，梯度趋近于0，即使预测错误也无法有效更新参数（学习速度极慢）。交叉熵损失的梯度为 $h_\theta(x) - y$，不存在此问题。
