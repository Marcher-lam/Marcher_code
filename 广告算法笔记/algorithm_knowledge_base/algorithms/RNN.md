# RNN 学习文档

## 1. 算法基础认知

RNN（循环神经网络）是一类处理序列数据的神经网络，通过隐藏状态在时间步之间传递信息。

## 2. 核心原理

$$
h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)
$$
$$
y_t = W_{hy} h_t + b_y
$$

## 3. 变体

- **LSTM**：引入门控机制，解决长程依赖
- **GRU**：简化版 LSTM，参数更少
- **DRNN**：深度 RNN，多层堆叠

## 4. 在广告中的应用

- 用户行为序列建模（已被 Transformer 替代）
- 文本特征编码

## 5. 学习总结

RNN 是序列建模的基础，但其梯度消失问题导致在长序列上表现不佳。现代广告系统更倾向使用 GRU 或 Transformer。
