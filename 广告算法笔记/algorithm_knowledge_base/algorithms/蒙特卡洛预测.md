# 蒙特卡洛预测 学习文档

## 1. 算法基础认知

蒙特卡洛（Monte Carlo, MC）方法是一类基于**随机采样**来估计数值结果的算法。在强化学习中，MC 预测用于从完整的 episode 经验中学习价值函数 $V^\pi(s)$ 或 $Q^\pi(s,a)$。

核心思想：用**经验回报的均值**来近似期望回报。根据大数定律，当采样数趋于无穷时，均值收敛到期望值。

与动态规划（DP）不同，MC 不需要环境的完整模型（转移概率），只需要实际交互产生的样本。

## 2. 核心原理

### 2.1 First-Visit MC

对每个状态 $s$，只统计每个 episode 中**第一次访问** $s$ 之后的回报 $G_t$，取平均作为 $V(s)$ 的估计。

### 2.2 Every-Visit MC

对每个状态 $s$，统计 episode 中**所有访问** $s$ 时的回报，取平均。

两种方法都是 $V^\pi(s)$ 的一致估计量。First-Visit 在理论上更常用于分析，Every-Visit 在实践中更简单。

### 2.3 增量式更新

不需要存储所有历史回报，用增量均值公式在线更新：

$$V(s) \leftarrow V(s) + \frac{1}{N(s)}[G_t - V(s)]$$

其中 $N(s)$ 是状态 $s$ 被访问的次数。用常数 $\alpha$ 代替 $1/N(s)$ 可实现遗忘旧数据的非平稳估计。

## 3. 数学公式与推导

定义回报（Return）：

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

状态价值函数：

$$V^\pi(s) = \mathbb{E}_\pi[G_t | S_t = s]$$

MC 预测的无偏性证明：设 episode 中首次访问 $s$ 的时刻为 $t_i$，对应的回报为 $G_{t_i}$，则：

$$V(s) = \frac{1}{N(s)} \sum_{i=1}^{N(s)} G_{t_i} \xrightarrow{N(s) \to \infty} \mathbb{E}_\pi[G_t | S_t = s] = V^\pi(s)$$

由大数定律保证收敛。

## 4. 训练过程讲解

1. **初始化**：$V(s) = 0$，$N(s) = 0$，$\forall s$
2. **生成 episode**：按策略 $\pi$ 与环境交互，得到序列 $(S_0, A_0, R_1, S_1, A_1, R_2, \ldots, S_T)$
3. **计算回报**：反向遍历，$G_t = R_{t+1} + \gamma G_{t+1}$
4. **更新价值**：对 First-Visit，找到每个状态首次出现的位置，更新 $V(s)$
5. **重复**：收集更多 episode 直到收敛

## 5. 应用场景

- **棋类游戏评估**：通过模拟对局评估局面价值
- ** blackjack 策略评估**：估计不同手牌下的胜率
- **系统仿真**：排队系统、库存管理的长期收益评估
- **风险分析**：金融衍生品定价（经典 MC 应用）
- **广告投放效果评估**：模拟用户行为序列计算长期价值

## 6. 优缺点分析

**优点**：
- 无需环境模型（model-free）
- 无偏估计
- 可独立估计每个状态的价值（不 bootstrap）
- 适合 episodic 环境

**缺点**：
- 必须等 episode 结束才能更新（高方差、高延迟）
- 不适用于非终止性（continuing）环境
- 方差较大（单次回报波动大）
- 采样效率低于 bootstrapping 方法

## 7. 调库实现（Python）

```python
import numpy as np
from collections import defaultdict

def mc_prediction_first_visit(env, policy, num_episodes=10000, gamma=1.0):
    V = defaultdict(float)
    returns_sum = defaultdict(float)
    returns_count = defaultdict(int)

    for _ in range(num_episodes):
        episode = []
        state = env.reset()
        done = False
        while not done:
            action = policy(state)
            next_state, reward, done, _ = env.step(action)
            episode.append((state, action, reward))
            state = next_state

        G = 0.0
        visited_states = set()
        for t in reversed(range(len(episode))):
            state, action, reward = episode[t]
            G = gamma * G + reward
            if state not in visited_states:
                visited_states.add(state)
                returns_sum[state] += G
                returns_count[state] += 1
                V[state] = returns_sum[state] / returns_count[state]

    return V

def mc_prediction_every_visit(env, policy, num_episodes=10000, gamma=1.0):
    V = defaultdict(float)
    returns_sum = defaultdict(float)
    returns_count = defaultdict(int)

    for _ in range(num_episodes):
        episode = []
        state = env.reset()
        done = False
        while not done:
            action = policy(state)
            next_state, reward, done, _ = env.step(action)
            episode.append((state, action, reward))
            state = next_state

        G = 0.0
        for t in reversed(range(len(episode))):
            state, action, reward = episode[t]
            G = gamma * G + reward
            returns_sum[state] += G
            returns_count[state] += 1
            V[state] = returns_sum[state] / returns_count[state]

    return V
```

## 8. 手工代码实现

```python
import numpy as np
from collections import defaultdict

class MCPrediction:
    def __init__(self, n_states, gamma=1.0, alpha=0.1):
        self.V = np.zeros(n_states)
        self.gamma = gamma
        self.alpha = alpha

    def generate_episode(self, env, policy):
        episode = []
        state = env.reset()
        done = False
        while not done:
            action = policy(state)
            next_state, reward, done, _ = env.step(action)
            episode.append((state, action, reward))
            state = next_state
        return episode

    def update_first_visit(self, episode):
        G = 0.0
        visited = set()
        for t in reversed(range(len(episode))):
            state, _, reward = episode[t]
            G = self.gamma * G + reward
            if state not in visited:
                visited.add(state)
                self.V[state] += self.alpha * (G - self.V[state])

    def update_every_visit(self, episode):
        G = 0.0
        for t in reversed(range(len(episode))):
            state, _, reward = episode[t]
            G = self.gamma * G + reward
            self.V[state] += self.alpha * (G - self.V[state])
```

## 10. 模型评估

- **均方根误差（RMSE）**：$\text{RMSE} = \sqrt{\frac{1}{|S|}\sum_s (V_{\text{est}}(s) - V_{\text{true}}(s))^2}$，与真实价值函数比较
- **收敛速度**：达到指定精度所需的 episode 数
- **方差分析**：多次独立运行的估计标准差
- **探索覆盖度**：被访问过的状态占总状态的比例

## 11. 常见问题与易错点

- **混淆 First-Visit 和 Every-Visit**：在一个 episode 中同一状态被多次访问时，结果不同
- **折扣因子选择**：$\gamma=1$ 只适用于有限 episode，无限 episode 必须用 $\gamma < 1$
- **增量更新的学习率**：固定 $\alpha$ 不收敛（有偏），$1/N(s)$ 保证收敛但遗忘不了旧数据
- **忽略探索**：MC 要求策略覆盖所有状态，纯贪心策略会导致部分状态无法估计
- **off-policy 忘记重要性采样**：用行为策略采样但评估目标策略时，需要重要性权重 $w_t = \prod_{k=0}^{t} \frac{\pi(A_k|S_k)}{b(A_k|S_k)}$

## 12. 学习总结

蒙特卡洛预测是强化学习中最直观的策略评估方法：通过实际经验估计价值函数。它的核心优势是 model-free 和无偏，但需要完整 episode 导致高方差和延迟更新。理解 MC 是学习 TD 学习、Q-learning 等方法的基础。

## 13. 练习题与思考题

**Q1**：为什么 First-Visit MC 估计是 $V^\pi$ 的无偏估计？

> **答案**：每个 episode 中首次访问 $s$ 的回报 $G_{t_i}$ 是从策略 $\pi$ 下以 $s$ 为起点的轨迹的独立同分布采样（因为每个 episode 独立），其均值是 $\mathbb{E}[G|S=s]$ 的无偏估计。

**Q2**：MC 预测能否用于 continuing 任务？

> **答案**：不能直接使用，因为 continuing 任务没有 episode 边界。需要人为分片或改用 TD 方法。

**Q3**：对比 First-Visit 和 Every-Visit MC 的偏差和方差。

> **答案**：两者都是一致的（收敛到真值），First-Visit 是无偏的，Every-Visit 在有限样本下偏差更小但方差也略有不同。
