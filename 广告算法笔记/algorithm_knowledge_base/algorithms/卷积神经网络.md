# 卷积神经网络 学习文档

## 1. 算法基础认知

卷积神经网络（Convolutional Neural Network, CNN）是一种专门处理网格状数据（如图像）的深度学习模型。其核心思想来源于生物视觉皮层中神经元的局部感受野机制——每个神经元只关注输入的一个局部区域，而非全部。

传统全连接网络处理图像时参数量巨大且忽略空间结构，CNN 通过**局部连接**和**权值共享**两大策略大幅减少参数，同时保留了图像的空间拓扑信息。自 1998 年 LeNet-5 诞生以来，CNN 已成为计算机视觉领域的基石模型。

## 2. 核心原理

CNN 由三种核心层堆叠而成：

- **卷积层（Convolutional Layer）**：使用可学习的卷积核在输入特征图上滑动，提取局部特征。卷积核越小感受野越局部，但堆叠多层后可覆盖更大区域。
- **池化层（Pooling Layer）**：对特征图进行下采样（如最大池化、平均池化），降低空间维度，增强平移不变性。
- **全连接层（Fully Connected Layer）**：将提取的特征映射到输出空间，用于分类或回归。

卷积操作的**权值共享**意味着同一个卷积核在整张图上复用同一组参数，这使得模型天然具备平移等变性——无论特征出现在图像哪个位置，都能被同一核检测到。

## 3. 数学公式与推导

**二维卷积运算：**

设输入特征图为 $X \in \mathbb{R}^{H \times W \times C_{in}}$，卷积核为 $W \in \mathbb{R}^{k \times k \times C_{in} \times C_{out}}$，偏置为 $b \in \mathbb{R}^{C_{out}}$，则输出特征图的每个位置 $(i, j)$ 在第 $c$ 个通道上的值为：

$$Y_{i,j,c} = \sum_{m=0}^{k-1} \sum_{n=0}^{k-1} \sum_{c'=0}^{C_{in}-1} W_{m,n,c',c} \cdot X_{i+m, j+n, c'} + b_c$$

**最大池化：**

$$\text{MaxPool}(X)_{i,j} = \max_{m \in [0,p)} \max_{n \in [0,p)} X_{si+m, sj+n}$$

其中 $s$ 为步长，$p$ 为池化窗口大小。

**输出尺寸计算：**

$$H_{out} = \lfloor \frac{H_{in} + 2P - k}{S} \rfloor + 1$$

其中 $P$ 为 padding，$S$ 为 stride。

## 4. 训练过程讲解

1. **前向传播**：输入图像依次经过多个"卷积→激活（ReLU）→池化"块，逐步提取从低级（边缘、纹理）到高级（语义、对象）的特征，最后通过全连接层输出预测。
2. **损失计算**：分类任务常用交叉熵损失 $L = -\sum_i y_i \log \hat{y}_i$。
3. **反向传播**：通过链式法则计算损失对每个卷积核参数的梯度。卷积层的反向传播本质上是"转置卷积"操作。
4. **参数更新**：使用优化器（如 Adam、SGD）根据梯度更新所有卷积核和全连接层权重。

训练时常用技巧包括：Batch Normalization、Dropout、数据增强（随机裁剪、翻转、颜色抖动）。

## 5. 应用场景

- 图像分类（ImageNet、CIFAR）
- 目标检测（YOLO、Faster R-CNN 的骨干网络）
- 语义分割（U-Net、DeepLab）
- 广告系统中的图片素材理解、CTR 预估中的图像特征提取
- 文本分类（TextCNN，将文本视为一维信号）
- 医学影像分析

## 6. 优缺点分析

**优点：**
- 参数量远小于全连接网络，训练效率高
- 自动学习层次化特征，无需手工设计特征
- 平移等变性，对位置变化鲁棒

**缺点：**
- 对旋转、缩放变化不够鲁棒（需数据增强弥补）
- 感受野受限于网络深度，长距离依赖建模能力弱于 Transformer
- 需要大量标注数据

## 7. 调库实现（Python + 完整代码 + 注释）

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.Linear(64 * 7 * 7, 128),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(128, 10),
        )

    def forward(self, x):
        x = self.features(x)
        x = x.view(x.size(0), -1)
        x = self.classifier(x)
        return x

transform = transforms.Compose([transforms.ToTensor(), transforms.Normalize((0.1307,), (0.3081,))])
train_loader = torch.utils.data.DataLoader(datasets.MNIST('./data', train=True, download=True, transform=transform), batch_size=64, shuffle=True)

model = SimpleCNN()
optimizer = optim.Adam(model.parameters(), lr=0.001)
criterion = nn.CrossEntropyLoss()

for epoch in range(5):
    for batch_x, batch_y in train_loader:
        optimizer.zero_grad()
        output = model(batch_x)
        loss = criterion(output, batch_y)
        loss.backward()
        optimizer.step()
    print(f"Epoch {epoch+1}, Loss: {loss.item():.4f}")
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

def conv2d_forward(x, kernel, bias, stride=1, padding=0):
    if padding > 0:
        x = np.pad(x, ((0,0),(0,0),(padding,padding),(padding,padding)))
    N, C_in, H, W = x.shape
    C_out, _, k, _ = kernel.shape
    H_out = (H - k) // stride + 1
    W_out = (W - k) // stride + 1
    output = np.zeros((N, C_out, H_out, W_out))
    for n in range(N):
        for co in range(C_out):
            for i in range(H_out):
                for j in range(W_out):
                    h_start, w_start = i * stride, j * stride
                    patch = x[n, :, h_start:h_start+k, w_start:w_start+k]
                    output[n, co, i, j] = np.sum(patch * kernel[co]) + bias[co]
    return output

def maxpool2d_forward(x, pool_size=2, stride=2):
    N, C, H, W = x.shape
    H_out = (H - pool_size) // stride + 1
    W_out = (W - pool_size) // stride + 1
    output = np.zeros((N, C, H_out, W_out))
    for i in range(H_out):
        for j in range(W_out):
            h_s, w_s = i * stride, j * stride
            output[:, :, i, j] = x[:, :, h_s:h_s+pool_size, w_s:w_s+pool_size].max(axis=(2,3))
    return output
```

## 9. 可视化与结果理解

训练完成后可通过以下方式理解模型：
- **特征图可视化**：提取第一层卷积的输出，观察边缘、纹理检测器
- **卷积核可视化**：第一层卷积核通常呈现 Gabor 滤波器形态（边缘/方向检测）
- **Grad-CAM**：通过梯度加权生成类激活热力图，定位模型决策依据区域
- **t-SNE**：将全连接层前的特征降维，观察同类样本是否聚集

浅层卷积核学习低级特征（边缘、颜色），深层学习高级语义（部件、对象），体现了层次化特征提取的思想。

## 10. 模型评估

- **准确率（Accuracy）**：正确分类样本占总样本比例
- **Top-5 准确率**：预测概率最高的 5 个类别中包含正确标签的比例（ImageNet 常用）
- **混淆矩阵**：分析各类别的分类错误模式
- **FLOPs 与参数量**：衡量模型复杂度，常用 `thop` 库计算
- **推理速度（FPS）**：实际部署时的关键指标

## 11. 常见问题与易错点

- **通道顺序混淆**：PyTorch 使用 NCHW 格式，TensorFlow 默认 NHWC，转换时需注意
- **感受野计算错误**：堆叠 3×3 卷积的感受野需逐层累加，而非直接相乘
- **padding 设置不当**：padding=0 时特征图尺寸会逐层缩小，可能导致信息丢失
- **忘记展平（flatten）**：卷积输出到全连接层前需要 reshape，否则维度不匹配
- **Batch Normalization 的训练/推理模式**：训练时使用 batch 统计量，推理时使用运行均值

## 12. 学习总结

CNN 的核心贡献在于通过局部连接和权值共享两大策略，将全连接网络处理图像时的参数量从天文数字降至可训练范围，同时保留了空间拓扑结构。卷积核的权值共享使模型天然具备平移等变性，堆叠的卷积层则实现了从边缘纹理到语义对象的层次化特征提取——这一"由浅入深"的特征学习范式深刻影响了整个深度学习领域。

CNN 的关键优势是参数效率高、推理速度快、部署生态成熟（TensorRT、CoreML 等均有针对 CNN 的深度优化）。它最适合图像分类、目标检测、图像分割等视觉任务，在广告系统中广泛用于图片素材理解和多模态 CTR 预估的图像特征提取。TextCNN 还将卷积思想成功迁移到文本分类领域。

在知识体系中，CNN 是本库中前馈神经网络在空间数据上的自然扩展，ResNet 引入的残差连接直接启发了后续 Transformer 中的结构设计，而 U-Net 中 CNN 的编码-解码架构也与 AE/VAE 等生成模型的思想相通。

工业实践中，CNN 部署时需注意 Batch Normalization 的训练/推理模式切换，以及 NCHW（PyTorch）和 NHWC（TensorFlow）的格式差异。在资源受限的移动端，常用 MobileNet 的深度可分离卷积替代标准卷积以降低计算量。

## 13. 练习题与思考题（含答案）

**Q1：一个 3×3 卷积核作用于 32×32×3 的输入，输出 64 个特征图（padding=1, stride=1），求输出尺寸和参数量。**

A1：输出尺寸 = $(32 + 2×1 - 3)/1 + 1 = 32$，即 $32×32×64$。参数量 = $3×3×3×64 + 64 = 1792$。

**Q2：为什么堆叠两个 3×3 卷积等价于一个 5×5 卷积的感受野，但参数更少？**

A2：两个 3×3 卷积的感受野 = $1 + (3-1) + (3-1) = 5$。参数量：$2×(C×C×3×3) = 18C^2$ vs $C×C×5×5 = 25C^2$。参数更少且多一次非线性激活。

**Q3：为什么 CNN 具有平移等变性？**

A3：因为卷积核在整张图上共享参数、以相同方式滑动，所以输入平移后输出也相应平移。
