# Algorithm Knowledge Base

这是一个面向广告系统与机器学习工程师的 **算法学习知识库**。

## 项目介绍

本项目从《互联网大厂广告算法笔记》full.md 中提取了所有涉及的算法，并为每个算法创建了独立的学习文档。文档分为两类：

1. **完整提取文档**：从 full.md 中完整提取了相关内容的算法（如 PID、MPC、DeepFM、DIN、DQN 等）
2. **模板文档**：算法列表中的其他算法，提供了标准 14 节模板结构，待后续补充

## 使用方式

- 在 `algorithms/` 目录下找到对应算法的 `.md` 文件
- 每个 文档遵循统一的 14 节结构
- `utils/` 目录包含通用评估指标和优化方法的说明

## 学习路径

请参考 `roadmap.md`，按照"初级 → 中级 → 高级"的层级逐步学习。

## 如何阅读这些文档

1. 先阅读「算法基础认知」，建立直观理解
2. 再看「核心原理」和「数学公式与推导」，掌握理论
3. 结合「代码实现」动手实践
4. 通过「练习题」检验掌握程度
5. 参考「学习路径建议」继续深入
