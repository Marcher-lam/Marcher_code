# 随机森林 学习文档

> 种一堆决策树，让它们投票——少数服从多数的智慧远超单棵树的独断专行。
> 来源线索：本节内容根据原书中关于"机器学习量价特征工程"（第3章3.7节）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：随机森林是通过 Bootstrap 采样训练多棵决策树，用随机特征子集增强多样性，最终投票（分类）或平均（回归）的集成学习算法。

**直觉类比**：专家会诊——与其依赖一位医生（单棵决策树），不如请 100 位不同背景的专家各自诊断，最后投票决定。每位专家只看病历的一部分（Bootstrap 样本）和一部分检查结果（随机特征），避免了群体思维。

**历史背景**：Leo Breiman 于 2001 年正式提出随机森林算法。它整合了 1995 年 Tin Kam Ho 提出的"随机子空间方法"和 Breiman 自己 1996 年提出的 Bagging 方法。Breiman 证明随机森林在大规模数据上不会过拟合，这一特性让它成为机器学习史上最有影响力的算法之一。

**算法定位**：监督学习 / 集成学习（Bagging 族）/ 分类 + 回归。

**前置知识**：决策树原理（CART、信息熵、基尼系数）、Bootstrap 重采样概念、基本概率统计。

## 2. 核心原理

**核心思想**：两重随机性打造多样性。随机森林的威力来自"好而不同"——每棵树都还不错，但它们犯的错误各不相同，投票平均后误差急剧下降。

第一重随机：数据层面。从原始训练集中有放回地采样出 $N$ 个 Bootstrap 样本，每个样本训练一棵树。
第二重随机：特征层面。每棵树分裂时，只随机选择 $\sqrt{n}$（分类）或 $n/3$（回归）个候选特征，从中找最优分裂点。

**工作流程**：

1. 从原始数据中有放回地采样，生成 $T$ 个 Bootstrap 样本
2. 对每个 Bootstrap 样本：
   a. 训练一棵决策树（通常不剪枝，让树充分生长）
   b. 每个节点分裂时，随机选择 $k$ 个特征，只在这 $k$ 个中找最优分裂
3. 预测时：
   a. 分类：$T$ 棵树投票，多数决定
   b. 回归：$T$ 棵树输出取平均值

**关键概念解释**：

- **Bootstrap 采样**：有放回地从 $m$ 个样本中抽 $m$ 个，每个样本被抽中的概率为 $1 - (1-1/m)^m \approx 63.2\%$。未被抽中的 $\approx 36.8\%$ 称为 OOB（Out-Of-Bag）样本，可作为天然验证集。
- **OOB 误差**：用未被某棵树训练的 OOB 样本来评估该树，所有树的 OOB 预测汇总得到无偏的泛化误差估计。
- **特征重要性**：衡量某特征对模型预测能力的贡献。主要方式有：
  - 基于杂质减少（MDI）：计算该特征在所有树中分裂时减少的不纯度之和
  - 基于排列（Permutation）：打乱该特征值后 OOB 误差的增量

```text
原始数据 (m 个样本)
    │
    ├─ Bootstrap 1 ──→ 决策树 1（随机特征子集）──┐
    ├─ Bootstrap 2 ──→ 决策树 2（随机特征子集）──┤
    ├─ Bootstrap 3 ──→ 决策树 3（随机特征子集）──┼─→ 投票/平均 → 最终预测
    ├─ ...             ...                       │
    └─ Bootstrap T ──→ 决策树 T（随机特征子集）──┘
```

## 3. 数学公式与推导

### 3.1 BootStrap 与 OOB

Bootstrap 样本中某样本被抽中的概率：
$$
P(\text{被选中}) = 1 - \left(1 - \frac{1}{m}\right)^m \approx 1 - e^{-1} \approx 0.632
$$

OOB 误差：
$$
\hat{\text{err}}_{\text{OOB}} = \frac{1}{m}\sum_{i=1}^{m} L(y_i, \hat{y}_i^{\text{OOB}})
$$

其中 $\hat{y}_i^{\text{OOB}}$ 是只用未包含样本 $i$ 的树进行预测的结果。

### 3.2 泛化误差界

Breiman 证明了随机森林的泛化误差上界：
$$
PE^* \le \bar{\rho} \cdot \frac{1 - s^2}{s^2}
$$

其中 $\bar{\rho}$ 是树之间相关性的平均值，$s$ 是单棵树的分类强度（strength）。

**解读**：泛化误差由两个因素决定——树的相关性越低越好，单棵树的强度越高越好。随机特征选择降低了相关性，充分生长的树保证了强度。

### 3.3 特征重要性（MDI）

对于特征 $j$，在树 $t$ 中的重要性为：
$$
\text{Imp}_t(j) = \sum_{n \in \text{用特征 j 分裂}} \Delta I(n)
$$

其中 $\Delta I(n)$ 是节点 $n$ 分裂后不纯度的减少量（分类用基尼系数，回归用 MSE）。所有树平均：
$$
\text{Imp}(j) = \frac{1}{T}\sum_{t=1}^{T} \text{Imp}_t(j)
$$

## 4. 训练过程讲解

### 4.1 数据预处理
- 缺失值：可填充（均值/中位数）或用 `-1` 标记为单独值——树模型可直接处理（分裂时将缺失值独立处理）
- 不需要特征标准化：树模型基于阈值分裂，与特征尺度无关
- 不需要独热编码：数值型标签编码即可（某些实现需注意）

### 4.2 关键超参数

| 超参数 | 作用 | 推荐范围 | 默认值 |
|--------|------|----------|--------|
| n_estimators | 树的数量 | 100 - 1000 | 100 |
| max_depth | 最大深度（防过拟合） | 3 - 30, None | None（不限制） |
| max_features | 每次分裂候选特征数 | sqrt/0.3/None | sqrt(n) 或 n/3 |
| min_samples_split | 节点最少样本数才分裂 | 2 - 20 | 2 |
| min_samples_leaf | 叶节点最少样本数 | 1 - 10 | 1 |
| bootstrap | 是否用 Bootstrap | True/False | True |

### 4.3 迭代过程
随机森林的训练天然可并行——每棵树独立训练，互不依赖。在 8 核 CPU 上，设置 `n_jobs=-1` 可使训练速度近乎线性加速。

### 4.4 收敛判断
- 观察 OOB 误差随 n_estimators 变化的曲线——通常 100 棵树后趋于平稳
- 用 OOB 误差调优，不需要额外划分验证集

## 5. 应用场景

### 典型应用

1. **量价因子筛选**（量化投资，原书 3.7 节）：在众多量价指标中，用随机森林的特征重要性排序，找出对收益预测最有价值的因子。OOB 评估天然适合时序数据。

2. **信用评分**：银行根据数百个特征（收入、负债、消费习惯等）预测违约风险。随机森林能自动处理特征交互，且特征重要性便于向监管解释。

3. **金融欺诈检测**：识别异常交易模式。对类别不平衡不敏感（可通过 class_weight 调整），且对异常值鲁棒。

4. **医疗诊断**：根据多项指标预测疾病。高准确率 + 可解释的特征重要性。

### 适用数据特征
- 特征维度高，存在较多冗余或无关特征
- 特征与标签关系非线性，存在复杂交互
- 数据有噪声和缺失值

### 不适用场景
- 需要严格外推的回归（树模型预测值不会超过训练数据范围）
- 超高维稀疏数据（文本、基因，考虑 XGBoost）
- 需要增量学习/在线学习的场景

## 6. 优缺点分析

### 优点

| 优点 | 成立条件 |
|------|----------|
| **不易过拟合**：树足够多时，方差持续降低 | n_estimators >= 100 |
| **自动特征选择**：直接给出特征重要性排名 | 数据有明确预测目标 |
| **对异常值和缺失值鲁棒** | 异常比例不超过 5-10% |
| **可并行训练** | 有足够 CPU 核数 |
| **不需要特征工程**：原生支持非线性关系和特征交互 | 有足够多的树 |

### 缺点

| 缺点 | 发生时条件 | 缓解思路 |
|------|-----------|----------|
| **黑箱性**：难以解释具体某次预测的原因 | 需要逐案例解释 | SHAP 值、LIME 等事后解释工具 |
| **高维稀疏数据效果差** | 特征数 $>$ 10000 | 降维或换 XGBoost/LightGBM |
| **预测速度慢** | 1000 棵树推理 | 剪枝压缩、减少树数量 |
| **内存占用大** | 树多且深 | 限制 max_depth，使用更少但更强的树 |
| **回归时外推能力弱** | 测试集范围超训练集 | 先做差分/detrend，预测变化量 |

### 与同类算法对比

| 维度 | 随机森林 | GBDT | XGBoost | 决策树 |
|------|----------|------|---------|--------|
| 训练方式 | 并行 Bagging | 串行 Boosting | 串行 Boosting | 单棵 |
| 过拟合倾向 | 低 | 中 | 中（正则化） | 高 |
| 训练速度 | 快（并行） | 慢 | 中（优化多） | 快 |
| 预测速度 | 中 | 快 | 快 | 快 |
| 特征重要性 | 有（MDI/排列） | 有 | 有（多指标） | 有 |

"""
随机森林调库实现

from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.metrics import accuracy_score, f1_score, mean_squared_error, r2_score
from sklearn.datasets import make_classification, make_regression

    n_samples=2000, n_features=10, n_informative=6,
    n_redundant=2, random_state=42

## 8. 手工代码实现

```python
"""
随机森林手工实现
使用 NumPy 从零实现核心逻辑：决策树桩 + Bootstrap + 随机特征
"""
import numpy as np
from collections import Counter


class DecisionTreeStump:
    """简单决策树桩（仅一层分裂），用于随机森林的基学习器"""

    def __init__(self, max_depth=3, min_samples_split=5):
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.tree = None

    def _gini(self, y):
        """计算基尼不纯度"""
        unique, counts = np.unique(y, return_counts=True)
        probs = counts / len(y)
        return 1 - np.sum(probs ** 2)

    def _best_split(self, X, y, feature_indices):
        """在指定特征子集中找最优分裂点"""
        best_gain = -1
        best_feat = None
        best_thresh = None

        current_gini = self._gini(y)

        for feat in feature_indices:
            thresholds = np.unique(X[:, feat])
            for thresh in thresholds:
                left_mask = X[:, feat] <= thresh
                right_mask = ~left_mask

                if left_mask.sum() == 0 or right_mask.sum() == 0:
                    continue

                left_gini = self._gini(y[left_mask])
                right_gini = self._gini(y[right_mask])
                weighted_gini = (left_mask.sum() * left_gini + right_mask.sum() * right_gini) / len(y)
                gain = current_gini - weighted_gini

                if gain > best_gain:
                    best_gain = gain
                    best_feat = feat
                    best_thresh = thresh

        return best_feat, best_thresh, best_gain

    def _build_tree(self, X, y, depth):
        """递归构建决策树"""
        n_samples, n_features = X.shape
        unique_classes = len(np.unique(y))

        # 停止条件
        if depth >= self.max_depth or n_samples < self.min_samples_split or unique_classes == 1:
            counts = Counter(y)
            return {'leaf': True, 'class': counts.most_common(1)[0][0]}

        # 随机选择 sqrt(n) 个特征
        k = max(1, int(np.sqrt(n_features)))
        feature_indices = np.random.choice(n_features, k, replace=False)

        best_feat, best_thresh, best_gain = self._best_split(X, y, feature_indices)

        if best_feat is None or best_gain <= 0:
            counts = Counter(y)
            return {'leaf': True, 'class': counts.most_common(1)[0][0]}

        # 递归分裂
        left_mask = X[:, best_feat] <= best_thresh
        right_mask = ~left_mask

        return {
            'leaf': False,
            'feature': best_feat,
            'threshold': best_thresh,
            'left': self._build_tree(X[left_mask], y[left_mask], depth + 1),
            'right': self._build_tree(X[right_mask], y[right_mask], depth + 1)
        }

    def fit(self, X, y):
        self.tree = self._build_tree(X, y, depth=0)
        return self

    def _predict_one(self, x, node):
        if node['leaf']:
            return node['class']
        if x[node['feature']] <= node['threshold']:
            return self._predict_one(x, node['left'])
        else:
            return self._predict_one(x, node['right'])

    def predict(self, X):
        return np.array([self._predict_one(x, self.tree) for x in X])


class RandomForestScratch:
    """从零实现随机森林分类器"""

    def __init__(self, n_estimators=100, max_depth=5, min_samples_split=5,
                 random_state=None):
        self.n_estimators = n_estimators
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.random_state = random_state
        self.trees = []
        self.oob_indices = []  # 每棵树的 OOB 样本索引

    def _bootstrap_sample(self, X, y):
        """生成 Bootstrap 样本和 OOB 索引"""
        n_samples = X.shape[0]
        indices = np.random.choice(n_samples, n_samples, replace=True)
        oob_indices = list(set(range(n_samples)) - set(indices))
        return X[indices], y[indices], oob_indices

    def fit(self, X, y):
        np.random.seed(self.random_state)
        X, y = np.array(X), np.array(y)
        self.trees = []
        self.oob_indices = []

        for i in range(self.n_estimators):
            X_boot, y_boot, oob_idx = self._bootstrap_sample(X, y)
            tree = DecisionTreeStump(
                max_depth=self.max_depth,
                min_samples_split=self.min_samples_split
            )
            tree.fit(X_boot, y_boot)
            self.trees.append(tree)
            self.oob_indices.append(oob_idx)

        return self

    def predict(self, X):
        """多数投票"""
        X = np.array(X)
        predictions = np.array([tree.predict(X) for tree in self.trees])
        # 对每列（每个样本）取众数
        result = []
        for i in range(X.shape[0]):
            counts = Counter(predictions[:, i])
            result.append(counts.most_common(1)[0][0])
        return np.array(result)

    def oob_score(self, X, y):
        """计算 OOB 准确率"""
        X, y = np.array(X), np.array(y)
        oob_preds = [[] for _ in range(X.shape[0])]

        for tree, oob_idx in zip(self.trees, self.oob_indices):
            for idx in oob_idx:
                pred = tree._predict_one(X[idx], tree.tree)
                oob_preds[idx].append(pred)

        correct = 0
        total = 0
        for i, preds in enumerate(oob_preds):
            if len(preds) > 0:
                majority = Counter(predes).most_common(1)[0][0]
                if majority == y[i]:
                    correct += 1
                total += 1
        return correct / total if total > 0 else 0

    def feature_importances_(self, n_features):
        """简化的特征重要性：基于树中特征被选为分裂依据的频次"""
        importances = np.zeros(n_features)
        for tree in self.trees:
            def traverse(node):
                if node['leaf']:
                    return
                importances[node['feature']] += 1
                traverse(node['left'])
                traverse(node['right'])
            traverse(tree.tree)
        return importances / importances.sum()


# ==================== 测试 ====================
if __name__ == '__main__':
    from sklearn.datasets import make_classification
    from sklearn.model_selection import train_test_split
    from sklearn.ensemble import RandomForestClassifier as SklearnRF

    X, y = make_classification(n_samples=500, n_features=8, random_state=42)
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=0.25, random_state=42
    )

    # 手工模型
    rf_scratch = RandomForestScratch(
        n_estimators=50, max_depth=5, random_state=42
    )
    rf_scratch.fit(X_train, y_train)
    scratch_acc = (rf_scratch.predict(X_test) == y_test).mean()
    scratch_oob = rf_scratch.oob_score(X_train, y_train)

    # sklearn 对比
    rf_sk = SklearnRF(n_estimators=50, max_depth=5, random_state=42, oob_score=True)
    rf_sk.fit(X_train, y_train)
    sk_acc = rf_sk.score(X_test, y_test)
    sk_oob = rf_sk.oob_score_

    print(f"手工模型: 测试准确率={scratch_acc:.4f}, OOB={scratch_oob:.4f}")
    print(f"sklearn:  测试准确率={sk_acc:.4f}, OOB={sk_oob:.4f}")
    print(f"特征重要性: {rf_scratch.feature_importances_(8).round(3)}")
```

## 11. 常见问题与易错点

### 数据层面
- **问题 1**：类别标签用数值编码但被当成回归问题（如用 0/1/2 但做了回归而非分类）
- **问题 2**：时序数据直接用随机 K 折交叉验证（应使用时序交叉验证或滚动窗口）

### 模型层面
- **问题 3**：树太少导致高方差，树太多导致预测慢——画 OOB 曲线找准拐点
- **问题 4**：max_depth=None 导致树过于庞大、内存爆炸——限制深度到 10-20
- **问题 5**：回归问题中预测值不会超过训练标签的范围——需要外推时用其他模型

### 调参层面
- **问题 6**：搜参顺序错误——应该先调 n_estimators（影响大但单调），再调 max_depth（防过拟合），最后微调 min_samples 参数
- **问题 7**：max_features='auto' 在回归中默认使用全部特征，失去了随机性优势——回归应设为约 n/3

## 12. 学习总结

**核心思想回顾**：集成多棵"好而不同"的决策树，通过投票消除个体误差。两重随机性（Bootstrap + 随机特征子集）是关键。

**关键公式**：泛化误差 $\le \bar{\rho} \cdot \frac{1-s^2}{s^2}$——相关性越低、单树强度越高，泛化越好。

**后续方向**：理解随机森林后，学习 Boosting 族（AdaBoost → GBDT → XGBoost → LightGBM），理解 Bagging 和 Boosting 的本质区别。

## 13. 练习题与思考题

**题 1**（基础）：为什么随机森林中的树通常不做剪枝？
**参考答案**：每棵树用 Bootstrap 样本训练，OOB 样本天然提供验证。更重要的是，随机森林的泛化误差来自树之间的相关性而非单棵树的过拟合程度。让树充分生长（低偏差），通过增加树数量来降低方差，是更优策略。

**题 2**（基础）：如果一个特征完全随机噪声，它在随机森林中的 MDI 重要性会是多少？
**参考答案**：理论上应接近 0，但实际上会有一个很小的正值（因为 Noise 变量偶尔也能在有限样本中伪装出分裂增益）。当特征数量很多时，随机噪声的重要性绝对值可能显著，应通过排列重要性交叉验证来确认。

**题 3**（进阶）：在量化选股中，用随机森林做未来 5 日涨跌预测，如何设计训练/测试分割避免"未来信息泄露"？
**参考答案**：必须使用时序分割：(1) 用 2018-2020 年数据训练，2021 年测试；(2) 滚动窗口：每新增一个月数据重新训练；(3) 对每个时间截面的股票横截面做预测。绝不能随机打乱样本，因为不同时间的样本不是独立同分布的。

**题 4**（开放）：随机森林和 XGBoost 在特征重要性排名上有何不同？哪种更适合做因子筛选？
**参考答案**：随机森林的 MDI 偏向高基数特征，排列重要性更可靠。XGBoost 的特征重要性基于分裂增益加权，对数值特征更友好。实际因子筛选中建议两者交叉验证——两者都认可的重要特征才保留。

## 14. 学习路径建议

**前置算法**：决策树（特别是 CART 分类回归树原理）

**平行算法**：Extra Trees（极端随机树——进一步增加随机性）、Isolation Forest（用随机森林思想做异常检测）

**进阶算法**：AdaBoost → GBDT → XGBoost → LightGBM → CatBoost（Boosting 族进化链）
