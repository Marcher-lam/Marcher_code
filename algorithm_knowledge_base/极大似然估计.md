# 极大似然估计 (MLE) 学习文档

> 统计推断的基石——用数据反推最可能的模型参数。

> 来源线索：本节内容根据原书中关于"极大似然估计"的相关章节（第13章13.4.1节）整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义：** MLE 选择使观测数据出现概率最大的参数值作为估计，是统计推断中最基本、最常用的参数估计方法。

**直觉类比：** 一个盒子里有黑白球，你摸了 10 次发现 7 次黑球。MLE 的逻辑是：既然你"确实"摸到了这个结果，那最可能的情况就是黑球比例约为 70%——因为如果真实比例是 10%，你几乎不可能摸到 7 次黑球。

**历史背景：** MLE 由 Fisher 于 1922 年正式提出，是频率学派统计推断的核心方法。几乎所有机器学习模型的训练（线性回归、逻辑回归、神经网络）本质上都在做 MLE。

**算法定位：** 参数估计、统计推断、机器学习基础。

**前置知识：** 概率论、条件概率、对数、导数。

---

## 2. 核心原理

### 核心思想

给定观测数据 $D = \{x_1, \ldots, x_n\}$ 和参数化模型 $p(x|\theta)$，MLE 寻找使似然函数最大的参数：

$$\hat{\theta}_{MLE} = \arg\max_\theta p(D|\theta) = \arg\max_\theta \prod_{i=1}^{n} p(x_i|\theta)$$

### 为什么用对数似然？

$$\log p(D|\theta) = \sum_{i=1}^{n} \log p(x_i|\theta)$$

- 乘法变加法，计算更方便
- 避免数值下溢（概率连乘可能接近 0）
- 对数是单调函数，不改变最大值位置

---

## 3. 数学公式与推导

### 正态分布的 MLE

给定 $x_1, \ldots, x_n \sim \mathcal{N}(\mu, \sigma^2)$：

$$\hat{\mu}_{MLE} = \frac{1}{n}\sum_{i=1}^{n} x_i, \quad \hat{\sigma}^2_{MLE} = \frac{1}{n}\sum_{i=1}^{n}(x_i - \hat{\mu})^2$$

### 伯努利分布的 MLE

$$\hat{p}_{MLE} = \frac{\text{成功次数}}{n}$$

### MLE 与机器学习的关系

- **线性回归**：最小化 MSE = 最大化高斯噪声下的似然
- **逻辑回归**：最小化交叉熵 = 最大化伯努利似然
- **神经网络**：训练损失通常是负对数似然的变体

## 4-8. 训练与代码实现

```python
import numpy as np

# MLE 估计正态分布参数
np.random.seed(42)
data = np.random.randn(1000) * 2 + 3  # mu=3, sigma=2

mu_mle = data.mean()
sigma2_mle = data.var()  # 注意：NumPy 默认用 n-1，MLE 用 n
print(f"MLE 估计: mu={mu_mle:.4f} (真实=3), sigma2={sigma2_mle:.4f} (真实=4)")

# MLE 估计伯努利参数
flips = np.random.binomial(1, 0.7, size=100)
p_mle = flips.mean()
print(f"MLE 估计: p={p_mle:.4f} (真实=0.7)")

# MLE 估计线性回归
n = 100
X = np.random.randn(n, 1)
y = 2 * X.flatten() + 1 + np.random.randn(n) * 0.5
# 最小二乘 = 高斯 MLE
X_aug = np.column_stack([np.ones(n), X])
theta_mle = np.linalg.lstsq(X_aug, y, rcond=None)[0]
print(f"线性回归 MLE: w={theta_mle[1]:.4f} (真实=2), b={theta_mle[0]:.4f} (真实=1)")
```

## 9-14. 练习与路径

**题1：** MLE 的三个性质是什么？

**参考答案：** (1) **一致性**：数据量→无穷时估计值→真实值；(2) **渐近正态性**：大样本下估计值服从正态分布；(3) **渐近有效性**：大样本下方差达到 Cramér-Rao 下界。

### 学习路径
- 前置：概率论、微积分
- 平行：MAP（贝叶斯估计）
- 进阶：EM 算法（隐变量模型的 MLE）
- 推荐：Casella & Berger, "Statistical Inference"
