# 动作转换机制 学习文档

> 多智能体强化学习中考虑对手行为的学习机制。

## 1. 算法基础认知

动作转换机制（Action Conversion Mechanism）是Q-ac多智能体学习方法中的核心创新，通过将对手的动作信息加入到自身状态的描述中，将部分可观测马尔可夫决策过程转化为完全可观测。

**直觉类比**：打牌时看到对手出了什么牌，会影响你接下来怎么出。动作转换机制就是让智能体能够"看到"对手的动作。

**前置知识**：多智能体强化学习

## 2. 核心原理

**核心思想**：将对手的动作作为自身状态的一部分。

**状态定义**：
$$s' = (s, a_{opp})$$

其中s是自身状态，a_opp是对手的动作。

## 3. 数学公式

**Q值更新**：
$$Q(s, a) \leftarrow (1-\alpha)Q(s,a) + \alpha[r + \gamma \max_{a'} Q(s', a')]$$

## 4. 应用场景

- 对抗性多智能体环境
- 博弈论场景
- 竞争与合作混合任务
