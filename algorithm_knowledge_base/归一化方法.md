# 归一化方法 学习文档

> 来源线索：本节内容根据原书中关于"归一化方法"的相关章节（第2章2.7节）整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义：** 归一化方法通过对网络层的输入进行标准化处理（零均值、单位方差），并引入可学习的缩放和平移参数，显著提高训练稳定性和收敛速度。

**直觉类比：** 想象一个流水线上有多道工序。如果每道工序的输出波动太大（数值范围不统一），后续工序就难以正常工作。归一化就像在每道工序之间加一个"校准站"——把数值重新调整到标准范围，确保下游工序收到的数据始终稳定可控。不同的归一化方法只是"校准的维度"不同。

**历史背景：** 批量归一化（Batch Normalization）由 Ioffe 和 Szegedy 于 2015 年提出，被认为是深度学习最重要的训练技巧之一。层归一化（Layer Normalization）由 Ba 等人于 2016 年提出，更适合 RNN/Transformer 等序列模型。

**算法定位：** 深度学习训练技巧、正则化方法、优化辅助。

**前置知识：** 神经网络、梯度下降、均值/方差、PyTorch。

---

## 2. 核心原理

### 为什么需要归一化？

深度网络训练时，每层的输入分布会随着底层参数的更新而变化（**内部协变量偏移**，Internal Covariate Shift）。这导致：
1. 上层需要不断适应新的输入分布
2. 学习率需要设得很小，训练缓慢
3. 参数初始化变得极其敏感

归一化通过稳定每层输入的分布来解决这些问题。

### 四种主要归一化方法

对于 4D 张量 $X \in \mathbb{R}^{N \times C \times H \times W}$（Batch × Channel × Height × Width）：

| 方法 | 计算统计量的维度 | 适用场景 |
|------|----------------|---------|
| Batch Norm | 沿 N, H, W | CNN、大批量 |
| Layer Norm | 沿 C, H, W | RNN、Transformer |
| Instance Norm | 沿 H, W | 风格迁移 |
| Group Norm | 沿分组的 C, H, W | 小批量、目标检测 |

### 工作流程

1. 计算指定维度的均值 $\mu$ 和方差 $\sigma^2$
2. 标准化：$\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \varepsilon}}$
3. 缩放和平移：$y = \gamma \hat{x} + \beta$（$\gamma, \beta$ 是可学习参数）

---

## 3. 数学公式与推导

### 批量归一化（Batch Normalization）

对每个通道 $c$，在 $(N, H, W)$ 维度上计算统计量：

$$\mu_c = \frac{1}{N \cdot H \cdot W} \sum_{n,h,w} x_{n,c,h,w}$$

$$\sigma_c^2 = \frac{1}{N \cdot H \cdot W} \sum_{n,h,w} (x_{n,c,h,w} - \mu_c)^2$$

$$\hat{x}_{n,c,h,w} = \frac{x_{n,c,h,w} - \mu_c}{\sqrt{\sigma_c^2 + \varepsilon}}$$

$$y_{n,c,h,w} = \gamma_c \hat{x}_{n,c,h,w} + \beta_c$$

**推理时**：使用训练过程中累积的移动平均 $\mu_{running}$ 和 $\sigma^2_{running}$。

### 层归一化（Layer Normalization）

对每个样本 $n$，在 $(C, H, W)$ 维度上计算：

$$\mu_n = \frac{1}{C \cdot H \cdot W} \sum_{c,h,w} x_{n,c,h,w}$$

$$\sigma_n^2 = \frac{1}{C \cdot H \cdot W} \sum_{c,h,w} (x_{n,c,h,w} - \mu_n)^2$$

$$y_{n,c,h,w} = \gamma \frac{x_{n,c,h,w} - \mu_n}{\sqrt{\sigma_n^2 + \varepsilon}} + \beta$$

**关键区别**：LN 不依赖 batch 维度，对单样本独立计算。

### 实例归一化（Instance Normalization）

对每个样本的每个通道 $(H, W)$ 上计算：

$$\mu_{n,c} = \frac{1}{H \cdot W} \sum_{h,w} x_{n,c,h,w}$$

### 为什么需要 $\gamma$ 和 $\beta$？

标准化将数据映射到 $\mathcal{N}(0, 1)$，可能落入激活函数的线性区。$\gamma$ 和 $\beta$ 通过可学习的缩放和平移恢复非线性表达能力，同时保持数值稳定。

## 4. 训练过程讲解

### 超参数

| 参数 | Batch Norm | Layer Norm |
|------|-----------|-----------|
| eps | 1e-5 | 1e-5 |
| momentum | 0.1 | N/A |
| affine | True | True |
| normalized_shape | C | [C, H, W] 或 hidden_size |

### 使用原则
- **CNN**：用 Batch Norm（卷积后、激活前）
- **Transformer/RNN**：用 Layer Norm（注意力/FFN 后或前）
- **风格迁移**：用 Instance Norm
- **小批量/检测**：用 Group Norm

---

## 5. 应用场景

1. **图像分类**：Batch Norm 是 ResNet 等标准组件
2. **NLP/LLM**：Layer Norm 是 Transformer 的标配（Pre-LN 或 Post-LN）
3. **风格迁移**：Instance Norm 消除内容图像的风格信息
4. **小批量训练**：Group Norm 在 batch_size < 8 时优于 Batch Norm

---

## 6. 优缺点分析

### Batch Norm 优缺点
- **优点**：训练加速、有正则化效果（batch 统计量的噪声）
- **缺点**：依赖 batch 大小、不适合 RNN/序列模型、训练/推理行为不一致

### Layer Norm 优缺点
- **优点**：不依赖 batch、适合变长序列、训练/推理一致
- **缺点**：在 CNN 上不如 BN 有效

### 对比

| 特性 | Batch Norm | Layer Norm | Instance Norm |
|------|-----------|-----------|---------------|
| 依赖 batch | 是 | 否 | 否 |
| 适合 CNN | 极好 | 一般 | 一般 |
| 适合 RNN/Transformer | 差 | 极好 | 一般 |
| 训练/推理一致 | 否 | 是 | 是 |
| 正则化效果 | 强 | 弱 | 无 |

## 7. 调库实现

```python
import torch
import torch.nn as nn

# === 批量归一化 ===
bn = nn.BatchNorm2d(num_features=64)  # 用于 2D 卷积
x_conv = torch.randn(8, 64, 32, 32)   # (B, C, H, W)
out_bn = bn(x_conv)
print(f"BN 输入: {x_conv.shape} → 输出: {out_bn.shape}")

# === 层归一化 ===
ln = nn.LayerNorm(normalized_shape=512)  # 用于 Transformer
x_attn = torch.randn(8, 20, 512)        # (B, seq_len, d_model)
out_ln = ln(x_attn)
print(f"LN 输入: {x_attn.shape} → 输出: {out_ln.shape}")

# === 实例归一化 ===
inn = nn.InstanceNorm2d(num_features=64)
out_in = inn(x_conv)
print(f"IN 输入: {x_conv.shape} → 输出: {out_in.shape}")

# === Group Norm ===
gn = nn.GroupNorm(num_groups=32, num_channels=64)  # 64/32=2 channels/group
out_gn = gn(x_conv)
print(f"GN 输入: {x_conv.shape} → 输出: {out_gn.shape}")

# 验证均值和方差
print(f"BN 输出均值: {out_bn.mean(dim=(0,2,3))[0]:.4f} (应接近0)")
print(f"BN 输出方差: {out_bn.var(dim=(0,2,3))[0]:.4f} (应接近1)")
```

## 8. 手工代码实现

```python
import torch

def manual_batch_norm(X, gamma, beta, eps=1e-5, momentum=0.1, training=True,
                      running_mean=None, running_var=None):
    """手工实现 Batch Normalization（4D 输入）"""
    if training:
        # 训练模式：在 (N, H, W) 维度计算统计量
        mean = X.mean(dim=(0, 2, 3), keepdim=True)  # (1, C, 1, 1)
        var = X.var(dim=(0, 2, 3), unbiased=False, keepdim=True)
        # 更新移动平均
        if running_mean is not None:
            running_mean = momentum * running_mean + (1 - momentum) * mean.squeeze()
            running_var = momentum * running_var + (1 - momentum) * var.squeeze()
    else:
        # 推理模式：使用移动平均
        mean = running_mean.view(1, -1, 1, 1)
        var = running_var.view(1, -1, 1, 1)

    X_hat = (X - mean) / torch.sqrt(var + eps)
    Y = gamma.view(1, -1, 1, 1) * X_hat + beta.view(1, -1, 1, 1)
    return Y

def manual_layer_norm(X, gamma, beta, eps=1e-5):
    """手工实现 Layer Normalization（3D 输入：B, L, D）"""
    # 在最后一个维度 D 上计算统计量
    mean = X.mean(dim=-1, keepdim=True)  # (B, L, 1)
    var = X.var(dim=-1, unbiased=False, keepdim=True)
    X_hat = (X - mean) / torch.sqrt(var + eps)
    return gamma * X_hat + beta

# 测试
X_4d = torch.randn(4, 3, 8, 8)  # (B, C, H, W)
gamma_bn = torch.ones(3)
beta_bn = torch.zeros(3)
out = manual_batch_norm(X_4d, gamma_bn, beta_bn)
print(f"BN 输出均值: {out.mean(dim=(0,2,3))}")  # 应接近 [0, 0, 0]

X_3d = torch.randn(2, 10, 64)  # (B, L, D)
gamma_ln = torch.ones(64)
beta_ln = torch.zeros(64)
out_ln = manual_layer_norm(X_3d, gamma_ln, beta_ln)
print(f"LN 输出均值: {out_ln.mean(dim=-1)[0, 0]:.6f}")  # 应接近 0
print(f"LN 输出方差: {out_ln.var(dim=-1)[0, 0]:.6f}")   # 应接近 1
```

## 9-14. 评估/问题/总结/练习/路径

### 常见问题
1. **Batch Norm 训练/推理不一致**：训练用 batch 统计量，推理用移动平均 → 确保调用 `model.eval()`
2. **Batch Norm 小批量问题**：batch_size=1 时统计量无意义 → 使用 Group Norm
3. **Layer Norm 位置**：Pre-LN（先归一化再计算）比 Post-LN 训练更稳定

### 练习题

**题1：** 为什么 Transformer 用 Layer Norm 而非 Batch Norm？

**参考答案：** 三个原因：(1) NLP 序列长度可变，Batch Norm 在不同位置计算统计量不一致；(2) Batch Norm 依赖 batch 大小，而 NLP 经常用小批量甚至单条推理；(3) Layer Norm 对每个样本独立计算，适合自回归生成（逐 token 生成）。

**题2：** Batch Norm 的 $\gamma$ 和 $\beta$ 为什么是可学习的而非固定的？

**参考答案：** 标准化将数据映射到 $\mathcal{N}(0,1)$，可能落入激活函数的线性区，降低表达能力。$\gamma$ 和 $\beta$ 让网络自行决定最优的分布：可以恢复原始分布（$\gamma=\sigma, \beta=\mu$），也可以学到一个更适合当前任务的新分布。

### 学习路径
- 前置：神经网络基础、梯度下降
- 平行：正则化方法（Dropout、Weight Decay）
- 进阶：RMSNorm（LLM 常用）、DeepNorm（训练超深 Transformer）
- 推荐：Ioffe & Szegedy, "Batch Normalization: Accelerating Deep Network Training" (2015)
