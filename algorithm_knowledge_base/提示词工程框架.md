# 提示词工程框架 学习文档

> 掌握与大模型对话的艺术——CRISPE、BROKE、ICIO三大框架让你的AI输出质量提升十倍。
> 来源线索：本节内容根据原书中关于"提示词工程"(第2章2.2节)及第3章各策略中提示词模板的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：提示词工程是通过设计结构化输入模板来精确引导大模型生成高质量、符合预期的输出的方法论。

**直觉类比**：点菜——对服务员说"来点吃的"(模糊提示词)→得到随机菜品。说"一份微辣水煮鱼、少油、加一份米饭"(结构化提示词)→得到满意的菜。

**背景**：大模型的输出质量极大程度上取决于提示词的质量。同一个模型，好的提示词和差的提示词之间准确率差异可达50%以上。2023年提示词工程从"技巧"上升为"工程学科"，出现了CRISPE、BROKE、ICIO等系统化框架。

**算法定位**：AI应用 / 提示词设计 / LLM交互 / 方法论。

**前置知识**：大模型基本使用经验。

## 2. 核心原理

### CRISPE 框架
| 要素 | 含义 | 示例 |
|------|------|------|
| **C**apability & Role | 能力与角色 | "你是量化交易策略分析师" |
| **R**equest / Insight | 请求/见解 | "分析竞价数据构建预测因子" |
| **I**nstruction | 指令/声明 | "输出过去5日RankIC排名" |
| **S**pecialty | 个性风格 | "专业简洁，表格化输出" |
| **P**ersonality | 输出格式 | - |
| **E**xperiment | 实验尝试 | "给出3种不同参数方案" |

### BROKE 框架
| 要素 | 含义 |
|------|------|
| **B**ackground | 背景：说清楚"为什么要做这个任务" |
| **R**ole | 角色：大模型扮演什么身份 |
| **O**bjective | 目标：任务的具体目标 |
| **K**ey Result | 关键结果：期望的具体输出 |
| **E**volve | 改进：请求优化建议 |

### ICIO 框架
| 要素 | 含义 |
|------|------|
| **I**nstruction | 任务说明 |
| **C**ontext | 上下文/背景信息 |
| **I**nput Data | 输入数据描述 |
| **O**utput Indicator | 输出格式指示 |

### 思维链(Chain-of-Thought)技术
**Zero-Shot CoT**：在提示词末尾加"让我们一步步思考"
**Few-Shot CoT**：提供2-3个"问题→逐步推理→答案"的示例

## 3-4. 应用方法论

**提示词设计黄金法则**：
1. **角色先行**：先明确角色定位，模型才知道以什么视角回答
2. **格式约束**：明确输出格式(JSON/表格/列表)，可大幅减少后续处理
3. **多轮优于单轮**：复杂任务拆分多轮对话，每轮聚焦一个子问题
4. **提供示例**：Few-Shot是性价比最高的质量提升手段
5. **明确约束**：字数/风格/受众/排除项

**常见提示词模板**：

**量化因子提取模板**：
```
角色：量化因子解析专家
背景：以下为券商研报节选
任务：提取所有量化因子的英文名称、计算公式、回测参数
输出：标准JSON格式
约束：若无明确公式，根据描述推断并标注(推断)
```

**策略回测模板**：
```
角色：量化策略回测分析师
背景：基于A股2020-2023年日线数据
任务：回测20日均线突破策略
要求：输出年化收益、最大回撤、夏普比率、月度收益表
代码：Python+pandas实现
```

## 5. 应用场景

1. **策略开发**：自然语言描述策略思路→大模型生成Python代码
2. **因子挖掘**：批量输入研报文本→提取因子→自动生成回测代码
3. **研报分析**：输入100页研报PDF→大模型提取核心观点和投资建议
4. **代码解释**：输入复杂策略代码→大模型逐行解释逻辑
5. **错误诊断**：输入错误日志→大模型分析原因+给出修复建议

## 6. 优缺点分析

**优点**：降低使用门槛、大幅提升输出质量、可复用(优质模板共享)、模型能力放大器
**缺点**：依赖模型能力(小模型做不到的事提示词再好也没用)、模板需要针对场景调整、过长提示词可能被模型截断

## 7-14. 综合章节

**常见问题**：
- 提示词太长被截断→精简到500字以内，或分多轮输入
- 大模型"理解偏差"→在提示词中加入正反示例锚定预期
- 输出格式不一致→先用JSON Schema约束，失败后用正则修正
- 角色设定被模型忽略→在开头和结尾各重复一次角色描述

**关键公式**（原书九大段位演进）：基础提示词→优化提示词→+公共数据→+私有数据→+基础RAG→+高级RAG→+简单工作流→+复杂工作流→微调+定制

**学习路径**：基础提示词→结构化框架→Few-Shot→思维链→多轮交互→Agent工作流
