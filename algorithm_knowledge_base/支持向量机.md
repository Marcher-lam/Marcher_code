# 支持向量机 学习文档

## 1. 算法基础认知
寻找最优超平面最大化间隔的分类器。

## 2. 核心原理
硬间隔：$\min_{oldsymbol{w},b} rac{1}{2}\|oldsymbol{w}\|^2$ s.t. $y_i(oldsymbol{w}^Toldsymbol{x}_i + b) \ge 1$

## 3. 数学推导
拉格朗日对偶转化为二次规划问题。

## 4. 训练过程
求解对偶问题，得到支持向量。

## 5. 应用场景
- 高维特征分类
- 小样本数据

## 6. 优缺点
优点：泛化能力强；缺点：核函数选择敏感

## 8. 手工实现
```python
import numpy as np
from cvxopt import matrix, solvers

class SVMScratch:
    def fit(self, X, y):
        n_samples = X.shape[0]
        K = np.outer(y, y) * (X @ X.T)
        
        P = matrix(K)
        q = matrix(-np.ones(n_samples))
        G = matrix(-np.eye(n_samples))
        h = matrix(np.zeros(n_samples))
        
        A = matrix(y.reshape(1, -1).astype('float'))
        b = matrix(0.0)
        
        sol = solvers.qp(P, q, G, h, A, b)
        alphas = np.ravel(sol['x'])
        
        # 支持向量
        sv = alphas > 1e-5
        self.alphas = alphas[sv]
        self.sv_X = X[sv]
        self.sv_y = y[sv]
        
        # 计算偏置
        self.b = np.mean([y_k - np.sum(self.alphas * self.sv_y * (self.sv_X @ X[sv].T))
                         for y_k, X_sv in zip(self.sv_y, self.sv_X)])
    
    def predict(self, X):
        return np.sign((self.alphas * self.sv_y @ (self.sv_X @ X.T)) + self.b)
```
