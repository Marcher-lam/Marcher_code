# 多头潜在注意力学习文档

> 多头潜在注意力（Multi-Head Latent Attention，MLA）是DeepSeek-V2系列模型中提出的创新注意力机制，通过将Key和Value压缩到低维潜在空间，在保持强建模能力的同时进一步降低推理时的KV Cache占用

---

## 1. 算法基础认知

### 1.1 一句话定义

**多头潜在注意力（MLA）** 是对标准多头注意力和多查询注意力的进一步优化，其核心思想是引入**潜在表示**（Latent Representation）——将所有头的Key和Value先映射到一个压缩的低维潜在空间，在注意力计算时动态恢复，从而将KV Cache从$O(n_h d_k)$降低到$O(d_c)$。

### 1.2 经典类比

| 机制 | 比喻 | KV Cache |
|------|------|----------|
| MHA | 每人有独立字典 | 大 |
| MQA | 全员共用字典 | 中 |
| MLA | 共享压缩版字典 | 小 |

MLA就像把所有字典先压缩成一本小册子——查找快、内容经过提炼。

### 1.3 历史背景

| 年份 | 里程碑 |
|------|--------|
| 2022 | DeepSeek-V2提出MLA |
| 2024 | MLA + MoE 结合 |
| 2024 | DeepSeek-Coder-V2 |
| 2024 | DeepSeek-V3 |

### 1.4 核心定位

| 维度 | 描述 |
|------|------|
| 类型 | 注意力机制优化 |
| 核心 | 潜在空间压缩 |
| 优化 | KV Cache最小化 |
| 应用 | DeepSeek系列模型 |

### 1.5 前置知识

- Transformer基础
- Multi-Head Attention
- Multi-Query Attention (MQA)
- 低秩近似思想

## 2. 核心原理

### 2.1 MLA vs MHA vs MQA

| 机制 | K/V头数 | 存储量 | 建模能力 |
|------|---------|--------|----------|
| MHA | $n_h$ | $n_h d_k$ | 最高 |
| MQA | 1 | $d_k$ | 降低 |
| MLA | $d_c$ (潜在) | $d_c$ | 保持 |

### 2.2 MLA计算流程

**步骤1：潜在压缩**
$$c = h W^C$$

其中$c \in \mathbb{R}^{d_c}$是压缩后的潜在向量。

**步骤2：恢复K/V**
$$k_i = c W_i^{K'} + b_i^K$$
$$v_i = c W_i^{V'} + b_i^V$$

**步骤3：注意力计算**
$$\text{head}_i = \text{Attention}(Q_i, k_i, v_i)$$

### 2.3 关键设计

```python
class MultiHeadLatentAttention(nn.Module):
    """MLA核心实现"""
    
    def __init__(self, d_model, n_heads, d_c):
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_c = d_c  # 潜在维度，通常 < d_model
        self.head_dim = d_model // n_heads
        
        # Query: 标准投影
        self.q_proj = nn.Linear(d_model, d_model)
        
        # 潜在压缩：输入 -> 潜在空间
        self.c_proj = nn.Linear(d_model, d_c)
        
        # 潜在恢复：潜在空间 -> K/V (每个头)
        self.k_proj = nn.Linear(d_c, n_heads * self.head_dim)
        self.v_proj = nn.Linear(d_c, n_heads * self.head_dim)
        
        # 输出投影
        self.o_proj = nn.Linear(d_model, d_model)
    
    def forward(self, x, use_cache=False, past_kv=None):
        batch_size, seq_len, _ = x.shape
        
        # Query (保持多头)
        Q = self.q_proj(x).view(
            batch_size, seq_len, self.n_heads, self.head_dim
        ).transpose(1, 2)
        
        # 潜在表示 (压缩)
        c = self.c_proj(x)  # (batch, seq, d_c)
        
        if use_cache and past_kv is not None:
            past_c = past_kv
            c = torch.cat([past_c, c], dim=1)
        
        # 从潜在恢复K/V
        K = self.k_proj(c).view(
            batch_size, seq_len if past_kv is None else -1,
            self.n_heads, self.head_dim
        ).transpose(1, 2)
        
        V = self.v_proj(c).view(
            batch_size, seq_len if past_kv is None else -1,
            self.n_heads, self.head_dim
        ).transpose(1, 2)
        
        # 注意力计算
        scores = torch.matmul(Q, K.transpose(-2, -1)) / (self.head_dim ** 0.5)
        attn = F.softmax(scores, dim=-1)
        context = torch.matmul(attn, V)
        
        # 输出
        context = context.transpose(1, 2).contiguous().view(
            batch_size, seq_len, self.d_model
        )
        
        output = self.o_proj(context)
        
        return output, c if use_cache else None
```

## 3. 数学公式与推导

### 3.1 形式化定义

设模型参数：
- $d_{model}$：模型隐藏维度
- $n_h$：Query头数
- $d_k$：Key维度
- $d_c$：潜在压缩维度

**输入映射到潜在空间**：
$$c = \text{LN}(x) W^C$$

其中$W^C \in \mathbb{R}^{d_{model} \times d_c}$。

**Query投影**（标准）：
$$Q = \text{LN}(x) W^Q$$

其中$W^Q \in \mathbb{R}^{d_{model} \times d_{model}}$。

**从潜在恢复Key和Value**：
$$K = c W^K + b^K$$
$$V = c W^V + b^V$$

其中$W^K, W^V \in \mathbb{R}^{d_c \times (n_h d_k)}$。

### 3.2 内存分析

| 机制 | KV Cache维度 | 计算公式 |
|------|------------|----------|
| MHA | $n_h \times d_k$ | 标准 |
| MQA | $1 \times d_k$ | 共享 |
| MLA | $d_c$ | 压缩 |

假设：$n_h = 32, d_k = 128, d_c = 512$

- MHA: $32 \times 128$ = 4096
- MQA: $1 \times 128$ = 128
- MLA: $512$

### 3.3 能量化视角

MLA利用了低秩近似的思想：

完整K矩阵秩：$\text{rank}(K) = \min(n_h d_k, d_c)$

由于$d_c \ll n_h d_k$，实际秩被限制为$d_c$，这自然实现了降维。

### 3.4 与Q的交互

MLA的Query处理保持标准：
$$Q_l = h_l W_l^Q$$

这确保了Query的多样性，不会因为KV压缩而降低Query的表达能力。

## 4. Python实现

### 4.1 完整MLA实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class MultiHeadLatentAttention(nn.Module):
    """多头潜在注意力（MLA）完整实现"""
    
    def __init__(self, d_model, n_heads, d_c, dropout=0.0):
        super().__init__()
        
        assert d_model % n_heads == 0
        
        self.d_model = d_model
        self.n_heads = n_heads
        self.head_dim = d_model // n_heads
        self.d_c = d_c  # 潜在维度
        
        # Query: 标准多头
        self.q_proj = nn.Linear(d_model, d_model)
        
        # 潜在压缩: 输入 -> 潜在空间
        self.c_proj = nn.Linear(d_model, d_c)
        
        # 潜在恢复: 潜在空间 -> 每个头的K/V
        self.k_proj = nn.Linear(d_c, n_heads * self.head_dim)
        self.v_proj = nn.Linear(d_c, n_heads * self.head_dim)
        
        self.o_proj = nn.Linear(d_model, d_model)
        self.dropout = nn.Dropout(dropout)
        
        self._init_weights()
    
    def _init_weights(self):
        for proj in [self.q_proj, self.c_proj, self.k_proj, self.v_proj, self.o_proj]:
            nn.init.xavier_uniform_(proj.weight)
            if proj.bias is not None:
                nn.init.zeros_(proj.bias)
    
    def forward(self, x, mask=None, use_cache=False, past_c=None):
        """
        Args:
            x: (batch, seq_len, d_model)
            mask: optional attention mask
            use_cache: 是否缓存潜在向量
            past_c: 过去的潜在向量
        Returns:
            output: (batch, seq_len, d_model)
            cache: 潜在向量
        """
        batch_size, seq_len, _ = x.shape
        
        # Query: 多头
        Q = self.q_proj(x).view(
            batch_size, seq_len, self.n_heads, self.head_dim
        ).transpose(1, 2)
        
        # 潜在表示
        c = self.c_proj(x)  # (batch, seq, d_c)
        
        if use_cache and past_c is not None:
            c = torch.cat([past_c, c], dim=1)
        
        # 从潜在恢复Key和Value
        K = self.k_proj(c).view(
            batch_size, -1, self.n_heads, self.head_dim
        ).transpose(1, 2)
        
        V = self.v_proj(c).view(
            batch_size, -1, self.n_heads, self.head_dim
        ).transpose(1, 2)
        
        # 注意力分数
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.head_dim)
        
        if mask is not None:
            scores = scores.masked_fill(mask, float('-inf'))
        
        # Softmax
        attn_weights = F.softmax(scores, dim=-1)
        attn_weights = self.dropout(attn_weights)
        
        # 上下文向量
        context = torch.matmul(attn_weights, V)
        
        context = context.transpose(1, 2).contiguous().view(
            batch_size, seq_len, self.d_model
        )
        
        output = self.o_proj(context)
        
        # 缓存潜在向量
        cache = c if use_cache else None
        
        return output, cache


class MLALayer(nn.Module):
    """MLA Transformer层"""
    
    def __init__(self, d_model, n_heads, d_ff, d_c, dropout=0.1):
        super().__init__()
        
        self.attention = MultiHeadLatentAttention(d_model, n_heads, d_c, dropout)
        self.norm1 = nn.LayerNorm(d_model)
        
        self.feed_forward = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout)
        )
        self.norm2 = nn.LayerNorm(d_model)
    
    def forward(self, x, mask=None, use_cache=False, past_kv=None):
        attn_output, cache = self.attention(
            self.norm1(x), mask, use_cache, past_kv
        )
        x = x + attn_output
        
        ff_output = self.feed_forward(self.norm2(x))
        x = x + ff_output
        
        return x, cache


class DeepSeekAttention(nn.Module):
    """DeepSeek模型中的MLA实现"""
    
    def __init__(self, d_model=2048, n_heads=8, d_c=1024):
        super().__init__()
        
        self.d_model = d_model
        self.n_heads = n_heads
        self.head_dim = d_model // n_heads
        self.d_c = d_c
        
        # 投影
        self.q_proj = nn.Linear(d_model, d_model)
        self.c_proj = nn.Linear(d_model, d_c)
        self.kv_proj = nn.Linear(d_c, 2 * d_c)
        
        # 输出
        self.o_proj = nn.Linear(d_model, d_model)
        
        # 归一化
        self.q_norm = nn.RMSNorm(d_model)
        self.kv_norm = nn.RMSNorm(d_c)
    
    def forward(self, x, position_ids=None, mask=None):
        batch_size, seq_len, _ = x.shape
        
        # Query
        q = self.q_proj(x)
        q = self.q_norm(q)
        q = q.view(batch_size, seq_len, self.n_heads, self.head_dim).transpose(1, 2)
        
        # 潜在
        c = self.c_proj(x)
        
        # KV恢复
        kv = self.kv_proj(c)
        kv = self.kv_norm(kv)
        
        k, v = kv.chunk(2, dim=-1)
        k = k.view(batch_size, seq_len, self.n_heads, self.head_dim).transpose(1, 2)
        v = v.view(batch_size, seq_len, self.n_heads, self.head_dim).transpose(1, 2)
        
        # 旋转位置编码 (可选)
        if seq_len > 1 and position_ids is not None:
            q = self.apply_rope(q, position_ids)
            k = self.apply_rope(k, position_ids)
        
        # 注意力
        scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(self.head_dim)
        
        if mask is not None:
            scores = scores.masked_fill(mask, float('-inf'))
        
        attn = F.softmax(scores, dim=-1)
        context = torch.matmul(attn, v)
        
        context = context.transpose(1, 2).contiguous().view(
            batch_size, seq_len, -1
        )
        
        return self.o_proj(context)
    
    def apply_rope(self, x, position_ids):
        """旋转位置编码（简化版）"""
        # RoPE实现需要额外的rope模块
        return x  # 简化版本
```

### 4.2 MLA推理优化

```python
class MLAInference:
    """MLA推理优化"""
    
    def __init__(self, model, tokenizer):
        self.model = model
        self.tokenizer = tokenizer
        self.past_c = None
    
    def prefill(self, prompt):
        """预填充阶段"""
        inputs = self.tokenizer(prompt, return_tensors="pt")
        
        with torch.no_grad():
            outputs = self.model(
                inputs['input_ids'],
                use_cache=True
            )
        
        # 缓存潜在向量
        self.past_c = outputs.cache
        
        return outputs
    
    def decode(self, next_token):
        """解码阶段"""
        with torch.no_grad():
            # 使用缓存的潜在向量
            outputs = self.model(
                next_token,
                past_c=self.past_c,
                use_cache=True
            )
        
        # 更新缓存
        self.past_c = outputs.cache
        
        return outputs.logits
    
    def generate(self, prompt, max_new_tokens=50):
        """生成"""
        self.prefill(prompt)
        
        for _ in range(max_new_tokens):
            logits = self.decode()
            next_token = logits.argmax(-1)
            
            if next_token == self.tokenizer.eos_token_id:
                break
        
        return self.tokenizer.decode(generated)
```

```python
def convert_to_mla(model, d_c):
    """将标准注意力转换为MLA"""
    
    for name, module in model.named_modules():
        if 'attention' in name.lower():
            if hasattr(module, 'k_proj'):
                # 添加潜在压缩
                original_k_proj = module.k_proj
                
                module.c_proj = nn.Linear(
                    module.k_proj.in_features,
                    d_c
                )
                
                # 修改K/V投影
                new_k_proj = nn.Linear(
                    d_c,
                    original_k_proj.out_features
                )
                
                module.k_proj = new_k_proj
                module.v_proj = new_k_proj
    
    return model
```

```python
    def forward(self, x):
        # Query
        Q = self.q_proj(x).view(-1, self.n_heads, self.head_dim).transpose(1, 2)
        
        # 潜在
        c = self.c_proj(x)
        
        # K/V
        K = self.k_proj(c).view(-1, self.n_heads, self.head_dim).transpose(1, 2)
        V = self.v_proj(c).view(-1, self.n_heads, self.head_dim).transpose(1, 2)

        attn = F.softmax(scores, dim=-1)

        return self.o_proj(out)


class DeepSeekMLAComplete(nn.Module):
    """完整的DeepSeek MLA模型"""
    
    def __init__(self, vocab_size, d_model, n_layers, n_heads, d_c):
        super().__init__()
        
        self.embedding = nn.Embedding(vocab_size, d_model)
        
        self.layers = nn.ModuleList([
            SimpleMLA(d_model, n_heads, d_c) for _ in range(n_layers)
        ])
        
        self.norm = nn.LayerNorm(d_model)
        self.lm_head = nn.Linear(d_model, vocab_size, bias=False)
    
    def forward(self, input_ids, cache=None):
        h = self.embedding(input_ids)
        
        presents = []
        
        for i, layer in enumerate(self.layers):
            h = layer(h)
            
            if cache is not None:
                presents.append(cache[i] if i < len(cache) else None)
        
        h = self.norm(h)
        
        return self.lm_head(h), presents
```

## 11. 常见问题与易错点

### 11.1 问题：d_c设置

**原因**：d_c影响质量与内存平衡

**解决方案**：
- 小模型：d_c = 512
- 中模型：d_c = 1024
- 大模型：d_c = 2048

### 11.2 问题：训练推理不一致

**原因**：MLA在推理时缓存c

**解决方案**：确保训练时也模拟缓存

### 11.3 问题：RoPE兼容性

**原因**：需要正确处理位置编码

**解决方案**：在Query和恢复的K上应用RoPE

## 12. 学习总结

### 12.1 核心要点

1. **潜在压缩**：输入 -> c (d_c)
2. **动态恢复**：c -> K/V (每头)
3. **KV缓存**：缓存c而非K/V
4. **压缩比**：$(n_h d_k) / d_c$

### 12.2 关键公式

- 压缩：$c = xW^C$
- 恢复：$K = cW^K$
- 存储：只存c

### 12.3 学习路径

```
MHA → MQA → GQA → MLA
  ↓
MoE + MLA (DeepSeek)
```

### 练习2

**问题**：实现MLA的推理缓存

<details>
<summary>答案</summary>

```python
class MLACache:
    def __init__(self, d_c, max_seq):
        self.c_cache = torch.zeros(1, max_seq, d_c)
    
    def update(self, new_c):
        self.c_cache = torch.cat([self.c_cache, new_c], dim=1)
    
    def get_kv(self, c_proj):
        return self.c_proj(self.c_cache)
```
