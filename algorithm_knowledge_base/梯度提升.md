# 梯度提升 学习文档

## 1. 算法基础认知
迭代训练弱学习器，通过梯度下降最小化损失函数。

## 2. 核心原理
使用损失函数的负梯度作为新弱学习器的目标。

## 3. 数学推导
$oldsymbol{	heta}^{(t+1)} = oldsymbol{	heta}^{(t)} - lpha 
abla L(oldsymbol{	heta}^{(t)})$

## 4. 训练过程
逐步添加树来纠正残差。

## 5. 应用场景
- Kaggle竞赛
- 结构化数据预测

## 6. 优缺点
优点：精度高；缺点：训练慢、调参复杂

## 8. 手工实现
```python
import numpy as np
from sklearn.tree import DecisionTreeRegressor

class GradientBoostingScratch:
    def __init__(self, n_trees=100, lr=0.1, max_depth=3):
        self.n_trees = n_trees
        self.lr = lr
        self.max_depth = max_depth
        self.trees = []
    
    def fit(self, X, y):
        # 初始化预测值为均值
        pred = np.mean(y)
        
        for _ in range(self.n_trees):
            # 计算负梯度（残差）
            residuals = y - pred
            
            # 拟合残差
            tree = DecisionTreeRegressor(max_depth=self.max_depth)
            tree.fit(X, residuals)
            
            # 更新预测
            pred += self.lr * tree.predict(X)
            self.trees.append(tree)
    
    def predict(self, X):
        pred = np.mean([tree.predict(X) for tree in self.trees])
        return pred
```
