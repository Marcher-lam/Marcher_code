# 数据预处理核心方法 学习文档

> 数据质量和预处理决定量化策略的成败——垃圾进、垃圾出，好数据是策略的根基。
> 来源线索：本节内容根据原书中关于"量化交易的数据基石"（第3章3.1节）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：数据预处理是对原始金融数据进行清洗、变换、标准化和特征构造的系统化流程，确保后续模型训练的数据质量和一致性。

**直觉类比**：建筑打地基——数据预处理就是打地基。再漂亮的设计(策略逻辑)、再先进的建材(模型算法)，地基不正(数据脏乱差)都白搭。

**背景**：量化交易中的数据天然存在各种缺陷——缺失值(停牌)、异常值(乌龙指)、量纲不统一(市值vs市盈率)、时间对齐问题(财报滞后)。每条缺陷都可能导致策略回测失真或实盘亏损。原书第3.1节系统梳理了数据处理的核心环节。

**算法定位**：数据工程 / 量化基础设施 / 特征工程前置。

**前置知识**：Pandas基础、金融数据类型概念。

## 2. 核心原理

### 量化数据的五大缺陷

| 缺陷类型 | 典型场景 | 影响 |
|----------|----------|------|
| 缺失值 | 停牌、财务数据未披露 | 特征矩阵不完整，模型无法训练 |
| 异常值 | 乌龙指、数据录入错误 | 扭曲统计分布，影响模型参数 |
| 量纲差异 | 市值(亿)vs换手率(%) | 梯度下降时量纲大的特征主导 |
| 时间对齐 | 年报4月才披露，但日期标记在12月 | 未来信息泄露 |
| 生存者偏差 | 回测只用现存股票，忽略退市股 | 回测收益虚高 |

### 核心处理方法

**缺失值处理**：
1. 删除法：缺失比例<5%的直接删除该行
2. 填充法：均值/中位数填充、前向填充(ffill)、插值法
3. 标记法：将缺失作为一种特殊状态输入模型(XGBoost原生支持)

**异常值处理**：
- Z-score法：|Z|>3视为异常→截尾或剔除
- 分位数法(Winsorize)：将超出P1/P99的值替换为边界值
- 业务规则法：涨跌停板外的不可能价格→直接剔除

**标准化/归一化**：
- Z-score：$(x-\mu)/\sigma$ → 适合大部分场景
- Min-Max：$(x-min)/(max-min)$ → 适合有固定边界的指标
- Robust Scaler：$(x-median)/IQR$ → 抗异常值

**时间对齐**：
- 财务数据按实际披露日期对齐(而非报告期)
- 避免使用"未来信息"构造特征

## 3. 数学公式

### 3.1 Z-score 标准化
$$
x' = \frac{x - \mu}{\sigma}
$$

### 3.2 Winsorize 缩尾
$$
x' = \begin{cases} P_1 & x < P_1 \\ x & P_1 \le x \le P_{99} \\ P_{99} & x > P_{99} \end{cases}
$$

### 3.3 线性插值
$$
y = y_1 + \frac{y_2 - y_1}{x_2 - x_1}(x - x_1)
$$

### 3.4 Robust Scaler
$$
x' = \frac{x - \text{median}}{\text{IQR}}
$$
IQR = Q3 - Q1(四分位距)，不受极端值影响。

## 4. 实战流程

```python
"""
数据预处理完整流程
模拟A股量化数据处理
"""
import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler, RobustScaler

np.random.seed(42)

# ========== 1. 生成带缺陷的模拟数据 ==========
n_rows = 1000
df = pd.DataFrame({
    'close': 20 + np.cumsum(np.random.randn(n_rows) * 0.3),
    'volume': np.random.exponential(1e6, n_rows),
    'pe_ratio': np.random.uniform(5, 100, n_rows),
    'roe': np.random.uniform(-0.2, 0.4, n_rows),
})

# 人为插入缺陷
df.loc[np.random.choice(n_rows, 30), 'pe_ratio'] = np.nan     # 缺失值
df.loc[np.random.choice(n_rows, 10), 'volume'] = 1e10          # 异常值
df.loc[np.random.choice(n_rows, 5), 'roe'] = -100              # 数据错误

print(f"缺失值(pe_ratio): {df['pe_ratio'].isna().sum()}")
print(f"volume 99%分位: {df['volume'].quantile(0.99):.0f}")
print(f"roe 异常值: {(df['roe'] < -10).sum()}")

# ========== 2. 缺失值处理 ==========
df['pe_ratio'] = df['pe_ratio'].fillna(df['pe_ratio'].median())

# ========== 3. 异常值处理(Winsorize) ==========
for col in ['volume', 'roe']:
    p1, p99 = df[col].quantile(0.01), df[col].quantile(0.99)
    df[col] = df[col].clip(p1, p99)

# ========== 4. 标准化 ==========
feature_cols = ['close', 'volume', 'pe_ratio', 'roe']
scaler = StandardScaler()
df_scaled = pd.DataFrame(scaler.fit_transform(df[feature_cols]),
                          columns=[f'{c}_scaled' for c in feature_cols])
df = pd.concat([df, df_scaled], axis=1)

print(f"\n处理后:")
print(f"  pe_ratio均值: {df['pe_ratio'].mean():.2f}, 标准差: {df['pe_ratio'].std():.2f}")
print(f"  volume最大值: {df['volume'].max():.0f}")
print(f"  roe最小值: {df['roe'].min():.4f}")

# ========== 5. 训练/测试时序分割 ==========
split = int(len(df) * 0.8)
train, test = df.iloc[:split], df.iloc[split:]
print(f"\n训练集: {len(train)}行, 测试集: {len(test)}行 (时序分割)")
```

## 5. 应用场景

1. **策略回测数据准备**：预处理后的数据输入回测引擎
2. **因子计算前处理**：缺失/异常值先处理再计算因子
3. **机器模型训练**：标准化后的数据加速收敛
4. **实盘数据监控**：实时检测数据异常→触发预警

## 6. 优缺点分析

**优点**：系统化的数据质量保障、对模型效果有显著提升、可复用(建立标准化pipeline)
**缺点**：处理方式选择主观(不同填充策略影响不同)、过度清洗可能丢失真实信号

## 7-14. 综合章节

**常见问题**：
- 时序数据用随机K折CV(造成未来信息泄露)→用时序CV或Walk-Forward验证
- 全数据集一次性标准化(用了测试集的均值方差)→先split再分别标准化
- 缺失值全填0(相当于告诉模型0是正常值)→用中位数/均值或独立标记
- 不考虑退市股(幸存者偏差)→回测时保留退市股的最后数据

**关键公式**：Z-score、Winsorize、Min-Max标准化、线性插值

**学习路径**：Pandas基础→数据清洗→标准化→特征工程→实盘数据pipeline

**练习题**：
- 基础：某因子序列[1, 2, NaN, 4, 100]，如何清洗？→ NaN用均值(2.33)或中位数(2)填充；100是异常值→用Winsorize替换为P99边界值(~4)。
- 进阶：时序数据的前向填充(ffill)和线性插值有什么区别？何时用哪个？→ ffill用上一有效值填充(适合"停牌期间数据不变"的假设)；线性插值在两个已知点间估计(适合"连续变化"但偶尔缺失的序列)。开盘价缺失用ffill，日内价格缺失用线性插值。
