## 1. 算法基础认知

**一句话定义：** 波斯纳注意定向理论（Posner's Attention Orienting Theory）由美国心理学家迈克尔·波斯纳于1980年提出，认为视觉注意力如同一束"聚光灯"投射在视觉场景中，可以在空间中移动（定向和重定向），其范围可以像变焦镜头一样缩放，且注意的集中程度在焦点处最高并向周围逐渐衰减。

**直觉类比：** 想象你拿着一个手电筒在黑暗的房间里找东西。手电筒的光束就是注意力——你可以把光集中在一个小区域（聚焦放大），也可以扫视整个房间（移动方向）。有些时候是突然的声响让你转头（外源性定向），有些时候是你有意识地寻找某个特定物品（内源性定向）。

**历史背景：** 1980年，波斯纳通过著名的"空间线索实验"（spatial cueing paradigm）验证了注意定向的机制，提出了注意定向理论的框架。该实验是认知心理学史上的经典实验之一。

**算法定位：** 视觉注意力认知理论，解释了注意在空间中的分配和移动机制。该理论对计算机视觉领域的注意力机制、显著性检测模型有深远影响。

## 2. 核心原理

### 2.1 核心思想

波斯纳认为注意力在空间中的投射和移动由三个操作组成：
1. **脱离（Disengage）：** 注意力从当前位置释放
2. **转移（Move/Shift）：** 注意力移动到新位置
3. **接入（Engage）：** 注意力在新位置锁定目标

### 2.2 两种定向系统

| 维度 | 外源性定向（Exogenous） | 内源性定向（Endogenous） |
|------|------------------------|------------------------|
| 触发方式 | 外部刺激自动触发 | 内在目标和意图驱动 |
| 加工方向 | 自下而上（Bottom-up） | 自上而下（Top-down） |
| 意识控制 | 无意识 | 有意识 |
| 响应速度 | 快（~100ms） | 慢（~300ms） |
| 持续时间 | 短（容易被抑制） | 长（可持续维持） |
| 典型例子 | 突然的闪光吸引注意 | 按地图寻找路标 |

### 2.3 空间线索实验（经典范式）

```
试验流程：
1. 注视点（+）出现在屏幕中央（500-1000ms）
2. 线索出现：箭头指向左/右（外源性：闪烁；内源性：符号）
3. 目标出现：在线索指向位置（有效试验 80%）或相反位置（无效试验 20%）
4. 被试按键反应

实验结果：
- 有效试验：RT ≈ 250ms（注意已就位）
- 无效试验：RT ≈ 350ms（需要重新定向）
- 线索效应：RT_diff = RT_invalid - RT_valid ≈ 100ms
```

## 3. 数学公式与推导

### 3.1 注意力空间分布模型

波斯纳聚光灯模型的数学形式为二维高斯分布：

$$A(x, y) = \frac{1}{2\pi\sigma_x\sigma_y} \exp\left(-\frac{(x-\mu_x)^2}{2\sigma_x^2} - \frac{(y-\mu_y)^2}{2\sigma_y^2}\right)$$

其中：
- $(\mu_x, \mu_y)$：注意焦点位置（聚光灯中心）
- $\sigma_x, \sigma_y$：注意范围（光束半径）
- $A(x, y)$：位置 $(x, y)$ 处的注意力强度

**归一化条件：** $\iint A(x, y) dx dy = 1$

### 3.2 变焦模型（Zoom Lens）

注意范围可以动态调整：

$$\sigma(t) = \sigma_0 + (\sigma_{target} - \sigma_0) \cdot (1 - e^{-t/\tau})$$

其中 $\tau$ 是变焦时间常数，$\sigma_0$ 是初始范围，$\sigma_{target}$ 是目标范围。

### 3.3 反应时间模型

**有效试验（注意已在目标位置）：**

$$RT_{valid} = RT_{base} + \epsilon_{motor}$$

**无效试验（注意需要重新定向）：**

$$RT_{invalid} = RT_{base} + \underbrace{t_{disengage}}_{\text{脱离时间}} + \underbrace{t_{move}(d)}_{\text{移动时间}} + \underbrace{t_{engage}}_{\text{接入时间}} + \epsilon_{motor}$$

其中移动时间与距离 $d$ 的关系：

$$t_{move}(d) = \alpha \cdot d + \beta$$

$\alpha$ 是移动成本系数（约 0.5-1.0 ms/度视角），$\beta$ 是固定启动成本。

**外源性 vs 内源性定向的反应时间：**

$$RT_{exo} = RT_{base} + \gamma_{exo} \quad (\text{快速，自动})$$
$$RT_{endo} = RT_{base} + \gamma_{endo} + \alpha \cdot d \quad (\text{较慢，需计划})$$

其中 $\gamma_{exo} < \gamma_{endo}$。

### 3.4 线索有效性效应

$$CE = RT_{invalid} - RT_{valid}$$

$CE$ 越大，说明线索对注意定向的影响越强。

### 3.5 抑制返回（Inhibition of Return, IoR）

当注意被外源性线索吸引后又回到原位置时，对该位置的注意受到抑制：

$$A_{IoR}(x, y) = A(x, y) \cdot (1 - \eta \cdot e^{-(t-t_0)/\tau_{IoR}})$$

其中 $\eta$ 是抑制强度（约 0.3-0.5），$\tau_{IoR}$ 是抑制衰减时间常数。

## 4. 训练过程讲解（认知实验模拟）

### 4.1 空间线索实验模拟流程

```
1. 初始状态: 注意力位于屏幕中央注视点
2. 线索呈现（50-100ms）:
   - 外源性: 在目标位置出现短暂闪光
   - 内源性: 中央箭头指向目标方向
3. 延迟间隔（SOA: 100-1000ms）
4. 目标呈现:
   - 有效: 目标在线索位置（~80%）
   - 无效: 目标在相反位置（~20%）
5. 反应记录: 测量反应时和准确率
```

### 4.2 外源性定向的计算过程

```python
def exogenous_orienting(current_focus, cue_location, soa):
    """
    模拟外源性定向过程
    cue_location: 线索出现的空间位置
    soa: 线索-目标间隔（ms）
    """
    if soa < 50:  # 线索呈现时间太短
        return current_focus  # 注意来不及移动
    elif soa < 300:  # 正常外源性定向
        # 快速自动吸引到线索位置
        return cue_location
    else:  # SOA过长时出现抑制返回
        # 注意被线索吸引又返回，抑制原位置
        return current_focus  # 返回原始位置
```

### 4.3 内源性定向的计算过程

```python
def endogenous_orienting(current_focus, target_location, steps=5):
    """
    模拟内源性定向过程（有意地、逐步移动）
    """
    path = []
    for step in range(steps):
        # 逐步向目标移动（类似平滑追踪）
        progress = (step + 1) / steps
        intermediate = current_focus + (target_location - current_focus) * progress
        path.append(intermediate)
    return path[-1], path  # 返回最终位置和移动轨迹
```

## 5. 应用场景

### 5.1 认知心理学
- **注意缺陷/多动障碍（ADHD）评估：** ADHD患者注意脱离困难，无效试验的RT更长
- **老龄化研究：** 老年人内源性定向能力下降
- **脑损伤评估：** 顶叶损伤患者注意脱离障碍（忽视综合征）

### 5.2 计算机视觉
- **显著性检测模型：** 模拟外源性注意（自下而上）
- **视觉导航：** 智能体的注意力聚焦与移动策略
- **目标检测：** 使用"注意焦点"加速候选区域的筛选

### 5.3 人机交互
- **界面设计：** 使用外源性线索（颜色、动画）引导用户注意
- **驾驶辅助：** 警告信号的视觉呈现位置设计
- **游戏设计：** 控制玩家的注意焦点以增强沉浸感

### 5.4 神经科学
- **无创脑刺激研究：** TMS/tDCS 调节注意定向相关脑区
- **眼动追踪：** 注意定向与眼动的关系

---

## 6. 优缺点分析

### 6.1 优点
1. **实验证据扎实：** 空间线索实验范式简单、可重复性强
2. **内外源二分法简洁清晰：** 抓住了注意定向的核心区别
3. **神经科学支持：** 上丘（外源性）、顶叶（脱离）、丘脑枕（接入）等脑区支持
4. **数学模型完善：** 高斯分布、RT模型等提供了定量预测

### 6.2 缺点
1. **局限于空间位置：** 忽视基于物体和基于特征的注意定向
2. **变焦机制描述粗糙：** 注意范围如何动态缩放的具体机制不清晰
3. **实验范式单一：** 主要依赖视觉空间注意实验
4. **个体差异考虑不足：** 不同个体的注意定向能力差异大

## 7. 调库实现（Python + NumPy模拟）

```python
"""
波斯纳注意定向理论的完整计算模拟
模拟空间线索实验的注意定向过程
"""
import numpy as np
import matplotlib.pyplot as plt


class PosnerOrientingModel:
    """波斯纳注意定向模型"""
    
    def __init__(self, visual_field_size=(100, 100)):
        self.field_h, self.field_w = visual_field_size
        self.focus = np.array([self.field_w // 2, self.field_h // 2])
        self.spread = 15.0
        self.attention_map = None
        self.RT_base = 200  # 基础反应时间(ms)
    
    def gaussian_attention(self, focus=None, spread=None):
        """计算高斯注意分布"""
        if focus is None:
            focus = self.focus
        if spread is None:
            spread = self.spread
        
        y, x = np.mgrid[0:self.field_h, 0:self.field_w]
        dist2 = ((x - focus[0])**2 + (y - focus[1])**2) / (2 * spread**2)
        self.attention_map = np.exp(-dist2)
        return self.attention_map
    
    def exogenous_orient(self, cue_location, soa=150):
        """
        外源性定向：外部刺激自动吸引注意
        cue_location: (x, y) 线索位置
        soa: 线索-目标间隔(ms)
        返回: 新的注意焦点和反应时间
        """
        if soa < 50:
            # SOA太短，来不及反应
            RT = self.RT_base + 100
            return self.focus, RT
        
        if 50 <= soa <= 300:
            # 有效定向：注意被吸引到线索位置
            self.focus = np.array(cue_location)
            self.spread = 12  # 外源性聚焦范围较小
            RT = self.RT_base + 30  # 外源性响应快
            
            # 抑制返回：当SOA > 300ms时，注意返回并抑制原位置
            if soa > 250:
                self.spread = 18  # 注意范围扩大（返回）
                inhibition_mask = 1 - 0.4 * np.exp(-(soa - 250) / 200)
                self.attention_map = self.gaussian_attention() * inhibition_mask
            else:
                self.attention_map = self.gaussian_attention()
            
            return self.focus, RT
        
        # SOA > 300: 抑制返回
        self.spread = 20
        self.focus = np.array([self.field_w // 2, self.field_h // 2])
        RT = self.RT_base + 80
        return self.focus, RT
    
    def endogenous_orient(self, target_location, distance_weight=0.5):
        """
        内源性定向：有意识地移动注意
        target_location: (x, y) 目标位置
        """
        start_focus = self.focus.copy()
        target = np.array(target_location)
        distance = np.linalg.norm(target - start_focus)
        
        # 逐步移动（模拟有意定向）
        n_steps = max(3, int(distance / 5))
        focus_path = [start_focus]
        
        for step in range(1, n_steps + 1):
            intermediate = start_focus + (target - start_focus) * (step / n_steps)
            focus_path.append(intermediate.astype(int))
        
        self.focus = target.astype(int)
        self.spread = 18  # 内源性定向范围较大
        self.attention_map = self.gaussian_attention()
        
        # 内源性反应时间
        RT = self.RT_base + 100 + distance * distance_weight
        
        return self.focus, RT, focus_path
    
    def spatial_cueing_experiment(self, n_trials=100, valid_ratio=0.8):
        """
        模拟空间线索实验
        返回: valid_RTs, invalid_RTs
        """
        valid_RTs = []
        invalid_RTs = []
        
        for _ in range(n_trials):
            # 随机选择目标位置（简化：左/右）
            target_side = np.random.choice(['left', 'right'])
            target_x = 25 if target_side == 'left' else 75
            target_y = 50
            
            # 线索
            cue_side = target_side  # 线索总是指向某一侧
            
            # 有效性
            is_valid = np.random.random() < valid_ratio
            if is_valid:
                target_x = 25 if cue_side == 'left' else 75
            else:
                target_x = 75 if cue_side == 'left' else 25
            
            # 重置注意到中央
            self.focus = np.array([50, 50])
            
            # 执行定向
            soa = np.random.randint(100, 300)
            new_focus, RT, _ = self.endogenous_orient(
                (target_x, target_y), distance_weight=0.8
            )
            
            if is_valid:
                valid_RTs.append(RT)
            else:
                invalid_RTs.append(RT)
        
        return np.array(valid_RTs), np.array(invalid_RTs)


def run_posner_demo():
    """运行波斯纳模型演示"""
    np.random.seed(42)
    model = PosnerOrientingModel()
    
    print("=" * 50)
    print("波斯纳注意定向理论 - 空间线索实验模拟")
    print("=" * 50)
    
    # 1. 初始注意分布
    print("\n[1] 初始注意分布（注视中心）")
    attn = model.gaussian_attention(focus=(50, 50), spread=15)
    print(f"    注意中心: (50, 50)")
    print(f"    注意范围(σ): 15")
    
    # 2. 外源性定向
    print("\n[2] 外源性定向模拟（突然闪光）")
    new_focus, RT = model.exogenous_orient((80, 50), soa=150)
    print(f"    线索位置: (80, 50)")
    print(f"    新注意焦点: {new_focus}")
    print(f"    反应时间: {RT:.1f}ms")
    
    # 3. 内源性定向
    print("\n[3] 内源性定向模拟（有意搜索）")
    model.focus = np.array([50, 50])
    new_focus, RT, path = model.endogenous_orient((20, 50))
    print(f"    目标位置: (20, 50)")
    print(f"    移动步数: {len(path)}")
    print(f"    反应时间: {RT:.1f}ms")
    
    # 4. 空间线索实验
    print("\n[4] 空间线索实验（100次试验）")
    valid_RTs, invalid_RTs = model.spatial_cueing_experiment(n_trials=200)
    print(f"    有效试验平均RT: {valid_RTs.mean():.1f}ms")
    print(f"    无效试验平均RT: {invalid_RTs.mean():.1f}ms")
    print(f"    线索效应(CE): {invalid_RTs.mean() - valid_RTs.mean():.1f}ms")
    
    return model, valid_RTs, invalid_RTs


if __name__ == "__main__":
    model, valid_RTs, invalid_RTs = run_posner_demo()
```

## 8. 手工代码实现（核心算法手写）

```python
"""
波斯纳注意定向理论的手工实现
不依赖外部库，仅用Python核心功能
"""
import math
import random


class SimplePosnerModel:
    """手工实现的波斯纳模型"""
    
    def __init__(self, field_size=100):
        self.field_size = field_size
        self.focus_x = field_size // 2
        self.focus_y = field_size // 2
        self.spread = 15.0
        self.center_x = field_size // 2
        self.center_y = field_size // 2
    
    def gaussian_weight(self, x, y):
        """计算位置(x, y)处的注意强度（手工高斯）"""
        dx = x - self.focus_x
        dy = y - self.focus_y
        dist2 = dx*dx + dy*dy
        sigma2 = 2 * self.spread * self.spread
        return math.exp(-dist2 / sigma2)
    
    def attention_at(self, x, y):
        """快速计算某位置的注意强度"""
        return self.gaussian_weight(x, y)
    
    def orient(self, target_x, target_y, mode='exogenous'):
        """
        定向到目标位置
        mode: 'exogenous' 或 'endogenous'
        返回: 反应时间(ms)
        """
        if mode == 'exogenous':
            # 快速自动定向
            self.focus_x = target_x
            self.focus_y = target_y
            self.spread = 12
            RT = 200 + random.randint(10, 30)
        else:
            # 慢速有意定向
            distance = math.sqrt(
                (target_x - self.focus_x)**2 + 
                (target_y - self.focus_y)**2
            )
            # 逐步移动
            steps = max(1, int(distance / 8))
            for step in range(1, steps + 1):
                ratio = step / steps
                self.focus_x = self.center_x + (target_x - self.center_x) * ratio
                self.focus_y = self.center_y + (target_y - self.center_y) * ratio
            
            self.spread = 18
            RT = 200 + int(distance * 1.5) + random.randint(20, 60)
        
        self.focus_x = int(self.focus_x)
        self.focus_y = int(self.focus_y)
        return RT
    
    def run_spatial_cueing_trial(self, valid=True):
        """执行一次空间线索试验"""
        # 重置到中心
        self.focus_x = self.center_x
        self.focus_y = self.center_y
        
        if valid:
            # 有效：目标在线索侧
            target_x = 20 if random.random() < 0.5 else 80
            target_y = 50
        else:
            # 无效：目标在相反侧
            target_x = 80 if random.random() < 0.5 else 20
            target_y = 50
        
        RT = self.orient(target_x, target_y, mode='endogenous')
        return RT, valid
    
    def run_experiment(self, n_trials=100, valid_ratio=0.8):
        """运行完整实验"""
        valid_RTs = []
        invalid_RTs = []
        
        for _ in range(n_trials):
            is_valid = random.random() < valid_ratio
            RT, valid = self.run_spatial_cueing_trial(valid=is_valid)
            
            if valid:
                valid_RTs.append(RT)
            else:
                invalid_RTs.append(RT)
        
        avg_valid = sum(valid_RTs) / len(valid_RTs) if valid_RTs else 0
        avg_invalid = sum(invalid_RTs) / len(invalid_RTs) if invalid_RTs else 0
        
        print(f"手工模拟 - 空间线索实验结果:")
        print(f"  有效试验平均RT: {avg_valid:.1f}ms (n={len(valid_RTs)})")
        print(f"  无效试验平均RT: {avg_invalid:.1f}ms (n={len(invalid_RTs)})")
        print(f"  线索效应: {avg_invalid - avg_valid:.1f}ms")
        
        return valid_RTs, invalid_RTs


if __name__ == "__main__":
    random.seed(42)
    model = SimplePosnerModel()
    model.run_experiment(n_trials=100)
```

## 11. 常见问题与易错点

### Q1：外源性定向和内源性定向哪个更快？
**答：** 外源性定向更快（~100ms vs ~300ms），因为它是自动化的、不需要意识参与。内源性定向需要有意地计划和执行，速度慢。

### Q2：线索效应（CE）为什么重要？
**答：** CE反映了注意定向的效率。CE越大，说明注意在空间中的移动越有效。ADHD患者的CE通常小于正常人。

### Q3：什么是"抑制返回"？
**答：** 当注意力被外源性线索吸引到某个位置，然后又返回后，对原来位置的注意会受到抑制——这是为了促进视觉搜索的效率，避免重复注意已经检查过的位置。

### Q4：波斯纳理论与深度学习有何关联？
**答：** 关联包括：（1）自注意力机制中的位置编码类似于注意的空间分布；（2）Transformer的Query-Key-Value对应内源性-外源性注意；（3）视觉transformer的滑动窗口类似注意的变焦机制。

## 12. 学习总结

### 12.1 核心贡献
波斯纳注意定向理论是认知心理学中影响最为深远的注意力理论之一。它揭示了注意在空间中的三个基本操作（脱离、转移、接入），区分了外源性和内源性两种定向模式，为注意力的计算建模奠定了基础。

### 12.2 关键实验发现
- 空间线索效应 ~80ms
- 外源性定向快但短效，内源性定向慢但长效
- 抑制返回在SOA>300ms后出现

### 12.3 关键公式回顾
- 注意分布：$A(x,y) = (1/2\pi\sigma^2)\exp(-(r^2/2\sigma^2))$
- 反应时间：$RT = RT_{base} + t_{disengage} + t_{move} + t_{engage}$
- 外源性RT：$RT_{exo} = 200 + \delta_{exo}$
- 内源性RT：$RT_{endo} = 200 + \alpha \cdot d + \delta_{endo}$

## 13. 练习题与思考题（含答案）

**题目1：** 简述波斯纳注意定向理论的三个核心操作。
**答案：** （1）脱离（Disengage）：注意力从当前位置释放；（2）转移（Move/Shift）：注意力移动到新位置；（3）接入（Engage）：注意力在新位置锁定目标。

**题目2：** 在空间线索实验中，为什么无效试验的反应时间更长？
**答案：** 因为注意已经被线索引导到了错误位置，当目标出现在相反位置时，注意需要先脱离当前位置（disengage）、再转移到正确位置（shift）、最后接入目标（engage），这三个操作增加了反应时间。

**题目3：** 外源性定向和内源性定向的本质区别是什么？
**答案：** 外源性定向由外部刺激自动触发，自下而上，不受意识控制，响应速度快但持续时间短；内源性定向由内在目标和意图驱动，自上而下，受意识控制，响应速度慢但有目的性且可持续维持。

**题目4：** 什么是抑制返回（Inhibition of Return, IoR）？它在认知上有什么功能？
**答案：** 抑制返回是指注意被吸引到某个位置又返回后，对该位置的注意受到抑制的现象。功能是促进视觉搜索效率——避免反复注意已经检查过的位置，鼓励注意探索新位置。
