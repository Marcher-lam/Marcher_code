## 1. 算法基础认知

**一句话定义：** 迁移学习将源任务上学到的知识迁移到目标任务，大幅减少训练数据需求和训练时间。

**直觉类比：** 已学会"骑自行车"的人学"骑摩托车"，不需要从零学平衡——复用已有技能即可。迁移学习让神经网络"复用"源任务学到的通用特征，只微调任务相关层。

**历史背景：** 迁移学习在深度学习时代极其重要。ImageNet 预训练→特定任务微调成为 CV 标准范式；BERT/GPT 确立了 NLP 的"预训练-微调"范式。

**算法定位：** 机器学习方法论、预训练-微调范式。

**前置知识：** CNN、神经网络训练、过拟合、PyTorch。

---

## 2. 核心原理

### 四种迁移策略

| 场景 | 数据量 | 相似度 | 策略 |
|------|--------|--------|------|
| 小数据 + 高相似 | 小 | 高 | 冻结底层，只训练分类器 |
| 大数据 + 高相似 | 大 | 高 | 冻结少量底层，微调其余 |
| 小数据 + 低相似 | 小 | 低 | 冻结底层，训练高层+分类器 |
| 大数据 + 低相似 | 大 | 低 | 从头训练（用预训练权重初始化） |

### 两种方式

1. **特征提取**：冻结全部预训练层，只训练新分类头
2. **微调**：用预训练权重初始化，在新数据上继续训练

---

## 3. 数学公式

### 差分学习率

微调时对不同层使用不同学习率：

$$\theta_l' = \theta_l - \eta_l \nabla_{\theta_l} \mathcal{L}$$

浅层 $\eta_l$ 小（接近冻结），深层 $\eta_l$ 大。

---

## 4. 训练过程讲解

| 超参数 | 特征提取 | 微调 |
|--------|---------|------|
| lr | 1e-3 | 1e-5 ~ 1e-4 |
| epochs | 10~20 | 5~10 |
| 冻结层 | 全部 | 部分或无 |

---

## 5. 应用场景

1. **图像分类**：ImageNet 预训练 → 医学/农业等领域
2. **NLP**：BERT/GPT 预训练 → 情感分析、问答
3. **目标检测**：COCO 预训练 → 特定场景
4. **语音识别**：大规模预训练 → 特定语言

---

## 6. 优缺点分析

### 优点
1. **数据需求少**：少量标注即可获得好效果
2. **训练快**：从好的初始点出发

### 缺点
1. **源-目标不匹配**：领域差异大时效果有限
2. **负迁移**：源知识可能干扰目标任务

## 7. 调库实现

```python
import torch
import torch.nn as nn
import torchvision.models as models

# 加载预训练 ResNet-50
model = models.resnet50(pretrained=True)

# 方法1：特征提取
for param in model.parameters():
    param.requires_grad = False
model.fc = nn.Linear(2048, 10)

# 方法2：差分学习率微调
optimizer = torch.optim.Adam([
    {'params': model.layer4.parameters(), 'lr': 1e-5},
    {'params': model.fc.parameters(), 'lr': 1e-3}
])

# HuggingFace NLP 迁移
from transformers import BertForSequenceClassification
model = BertForSequenceClassification.from_pretrained('bert-base-chinese', num_labels=2)
print(f"可训练参数: {sum(p.numel() for p in model.parameters() if p.requires_grad):,}")
```

## 8. 手工代码实现

```python
import torch
import torch.nn as nn

class TransferModel(nn.Module):
    def __init__(self, backbone, num_classes=10, freeze=True):
        super().__init__()
        self.backbone = backbone
        self.classifier = nn.Linear(256, num_classes)
        if freeze:
            for p in self.backbone.parameters():
                p.requires_grad = False

    def forward(self, x):
        return self.classifier(self.backbone(x))

class Backbone(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(3, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(128, 256, 3, padding=1), nn.ReLU(), nn.AdaptiveAvgPool2d(1),
            nn.Flatten()
        )
    def forward(self, x): return self.net(x)

model = TransferModel(Backbone(), num_classes=5, freeze=True)
x = torch.randn(4, 3, 32, 32)
print(f"输出: {model(x).shape}")
print(f"可训练参数: {sum(p.numel() for p in model.parameters() if p.requires_grad):,}")
```

## 9-14. 评估/问题/总结/练习/路径

### 练习题

**题1：** 迁移学习为什么有效？

**参考答案：** 深度网络浅层学习通用特征（边缘、纹理），这些特征跨任务通用。迁移学习复用通用特征，只重新学习任务特定部分。

### 学习路径
- 前置：CNN、RNN
- 进阶：Adapter、LoRA、Prefix-Tuning
- 推荐：Pan & Yang, "A Survey on Transfer Learning" (2010)
