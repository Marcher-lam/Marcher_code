# 在蒙特卡洛方法和时序差分方法中取得平衡 学习文档

> 用一句话说明这个算法的核心价值：作为蒙特卡洛与时序差分的折中方案，多步方法通过累积N步奖励再使用目标网络，平衡了偏差与方差，提升DQN训练稳定性。

## 1. 算法基础认知

在蒙特卡洛方法与时序差分方法之间取得平衡的技术，常被称为**多步方法（Multi-step Methods）**，是深度Q网络（DQN）的重要进阶技巧。

**一句话定义**：在Q-learning更新时，不直接使用1步后的目标值，而是累积N步的奖励，直到第N步后才使用目标网络Q值计算回报，从而结合蒙特卡洛低偏差与时序差分低方差的优势。

**直觉类比**：就像预测天气时，既参考最近1天的观测（TD，偏差大但方差小），也参考最近N天的平均（MC，偏差小但方差大），��一个折中值N来平衡两者。

**历史背景**：由DeepMind等机构在DQN改进过程中提出，作为Rainbow DQN的六大核心技巧之一，被证明能显著提升训练稳定性与最终性能。

**算法定位**：
- 属于DQN的进阶训练技巧，不改变DQN核心框架
- 可与其他DQN改进（DDQN、PER、Dueling等）叠加使用
- 解决1步TD偏差大、蒙特卡洛方差大的问题
- 超参数N（步数）可灵活调整以适配不同任务

**前置知识**：
- 深度Q网络（DQN）基础
- 蒙特卡洛方法与时序差分（TD）的原理与差异
- PyTorch 深度学习框架

## 2. 核心原理

多步方法的核心思想是：**将N步的真实奖励累积后，再使用目标网络计算剩余回报**，目标值计算公式变为：

$$G_t^{(N)} = \sum_{k=0}^{N-1} \gamma^k r_{t+k+1} + \gamma^N \max_{a'} \hat{Q}(s_{t+N}, a')$$

其中：
- 前N步的奖励是真实采样得到的（蒙特卡洛部分）
- 第N步后的回报由目标网络$\hat{Q}$估计（时序差分部分）

**TD($\lambda$)算法**：
TD($\lambda$)是另一种在MC与TD之间取得平衡的方法，通过**资格迹（Eligibility Traces）**机制，将不同步数的TD误差加权平均：
$$TD_{error} = \sum_{n=1}^{\infty} \lambda^{n-1} \cdot \delta_t^{(n)}$$
其中 $\delta_t^{(n)}$ 是n步TD误差：
$$\delta_t^{(n)} = r_{t+1} + \gamma r_{t+2} + \dots + \gamma^{n-1} r_{t+n} + \gamma^n V(s_{t+n}) - V(s_t)$$

**资格迹机制（Eligibility Traces）**：
资格迹 $e_t(s)$ 是一种记忆机制，追踪每个状态被"访问"的"资格"：
$$e_t(s) = \gamma \lambda e_{t-1}(s) + \mathbf{1}(s_t = s)$$
更新时，所有被访问过的状态都会根据其资格迹获得更新：
$$\Delta V(s) = \alpha \cdot e_t(s) \cdot \delta_t$$

**前向视角与后向视角**：
- **前向视角（Forward View）**：计算$TD(\lambda)$回报需要等待回合结束，累积所有未来折扣奖励，与蒙特卡洛类似
- **后向视角（Backward View）**：通过资格迹在线更新，当前误差实时传播到历史状态，无需等待回合结束

两者数学等价，但后向视角更实用：
$$V(s_t) \leftarrow V(s_t) + \alpha \cdot e_t(s_t) \cdot \delta_t$$
对于任意状态 $s$，其在当前时刻的资格迹反映了"历史贡献度"。

**$\lambda$参数的作用**：
| $\lambda$ 值 | 特性 | 偏差/方差 |
|------------|------|----------|
| $\lambda = 0$ | 等价于1步TD | 偏差最大，方差最小 |
| $\lambda \in (0,1)$ | 加权多步TD | 平衡偏差与方差 |
| $\lambda = 1$ | 等价于蒙特卡洛 | 偏差最小，方差最大 |

**关键优势**：
- 减少目标值对Q网络估计的依赖（N越大，真实奖励占比越高，偏差越小）
- 控制方差：N不会像纯蒙特卡洛那样累积大量奖励导致方差爆炸
- 灵活调整：通过超参数N在偏差与方差之间取得平衡
- 适应性强：不同任务可自动/手动调整N值

## 3. 数学公式与推导

**符号约定表**：

| 符号 | 含义 | 维度/范围 |
|------|------|-----------|
| $N$ | 多步累积的步数 | 正整数（通常3~20） |
| $\gamma$ | 折扣因子 | $[0,1]$ |
| $G_t^{(N)}$ | N步回报目标 | $\mathbb{R}$ |
| $\hat{Q}$ | 目标Q网络 | 神经网络 |
| $\lambda$ | TD($\lambda$)混合参数 | $[0,1]$ |
| $e_t(s)$ | 资格迹 | $\mathbb{R}$ |

**多步目标推导**：
标准1步TD目标：$y_t = r_{t+1} + \gamma \max_{a'} \hat{Q}(s_{t+1}, a')$

N步TD目标：
$$
\begin{align*}
y_t^{(N)} &= r_{t+1} + \gamma r_{t+2} + \dots + \gamma^{N-1} r_{t+N} + \gamma^N \max_{a'} \hat{Q}(s_{t+N}, a') \\
&= \sum_{k=0}^{N-1} \gamma^k r_{t+k+1} + \gamma^N \max_{a'} \hat{Q}(s_{t+N}, a')
\end{align*}
$$

**TD($\lambda$)回报**：
前向视角定义的$TD(\lambda)$回报：
$$G_t^{(\lambda)} = (1-\lambda) \sum_{n=1}^{\infty} \lambda^{n-1} \sum_{k=1}^{n} \gamma^{k-1} r_{t+k} + \gamma^n V(s_{t+n})$$

资格迹更新公式：
$$e_t(s) = \gamma \lambda e_{t-1}(s) + \mathbf{1}(s_t = s)$$
$$V(s_t) \leftarrow V(s_t) + \alpha \cdot \delta_t \cdot e_t(s_t)$$

其中TD误差：
$$\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t)$$

**DQN损失函数更新**：
$$L(\theta) = \mathbb{E}\left[ \left( y_t^{(N)} - Q(s_t, a_t; \theta) \right)^2 \right]$$

**多步与TD($\lambda$)的关系**：
多步方法可以视为TD($\lambda$)的离散版本：
- N步方法对应固定的 $\lambda$，权重集中在第N步
- TD($\lambda$)对应连续加权，权重按 $\lambda^k$ 指数衰减

## 4. 训练过程讲解

**数据预处理**：
- 使用经验回放池存储$(s_t, a_t, r_{t+1}, s_{t+1}, done)$五元组
- 采样时一次性取出连续N步的经验（或累积N步奖励后计算目标）

**参数初始化**：
| 参数 | 作用 | 推荐值 |
|------|------|--------|
| N（步数） | 多步累积步数 | 3~5（简单任务）、5~20（复杂任务） |
| $\lambda$ | TD($\lambda$)混合参数 | 0.9~0.95 |
| $\gamma$ | 折扣因子 | 0.99 |
| 学习率 | Q网络更新步长 | 1e-4 |

**$\lambda$参数调优指南**：

| 任务类型 | 推荐 $\lambda$ | 原因 |
|---------|-------------|------|
| 短回合任务 | 0.9~0.99 | 偏差影响小，多步更准 |
| 长回合高方差任务 | 0.5~0.9 | 需要控制方差 |
| 奖励延迟任务 | 0.8~0.95 | 多步减少延迟影响 |
| 在线学习 | 0.3~0.7 | 方差敏感，需要快速更新 |

**迭代过程（多步DQN）**：
1. 初始化Q网络$Q$、目标网络$\hat{Q}$，经验池
2. 每个时间步：
   a. 用$\epsilon$-贪心策略选择动作$a_t$，执行得到$(s_t, a_t, r_{t+1}, s_{t+1}, done)$
   b. 存储经验到回放池
   c. 若累积了N步或回合结束，计算多步目标$y_t^{(N)}$
   d. 从回放池采样batch，计算损失$L(\theta)$并反向传播更新$Q$
   e. 每隔C步更新目标网络$\hat{Q} \leftarrow Q$
3. 重复2直到收敛。

**迭代过程（TD($\lambda$)）**：
1. 初始化值函数$V$，资格迹$e(s) = 0$
2. 每个时间步：
   a. 执行动作，得到奖励$r$，进入状态$s'$
   b. 计算TD误差：$\delta = r + \gamma V(s') - V(s)$
   c. 更新资格迹：$e(s) \leftarrow \gamma \lambda e(s) + 1$
   d. 对所有状态$s$：$V(s) \leftarrow V(s) + \alpha \cdot \delta \cdot e(s)$
   e. 更新资格迹衰减：$e(s) \leftarrow \gamma \lambda e(s)$
3. 重复直到回合结束或收敛。

**自适应调整策略**：
- **基于状态不确定性**：在不确定性高的状态使用较小的N/$\lambda$
- **基于回合长度**：长回合任务可使用较大的N
- **课程式调整**：训练初期用小N（高方差控制），后期逐渐增大N

## 5. 应用场景

**典型应用**：

1. **Atari游戏（如Breakout）**：
   - N取5~10，平衡短期奖励与长期回报
   - 适用性：游戏奖励稀疏，多步累积能更准确评估动作价值

2. **机器人连续控制**：
   - N取3~5，避免单步TD的高偏差
   - 适用性：动作连续，奖励延迟，多步回报更稳定

3. **TD($\lambda$)特定应用**：
   - $\lambda$取0.9~0.95，用于SARSA($\lambda$)等在线学习方法
   - 适用性：在线学习场景，资格迹机制避免回合重置

4. **长时序任务（如Dota2、AI-StarCraft）**：
   - N取10~20或使用TD($\lambda$)的高$\lambda$值
   - 适用性：超长回合，折扣因子接近1，单步TD偏差极大

**适用场景特征**：
- 奖励有一定延迟，单步TD偏差大
- 纯蒙特卡洛方差过高，训练不稳定
- 可叠加其他DQN改进技巧（如Rainbow）

**不适用场景**：
- 奖励即时、无延迟的简单任务（如CartPole），N=1即可
- 超参数N难以调优的场景，可先使用标准DQN

**更多应用示例**：

| 应用领域 | 推荐N/$\lambda$ | 理由 |
|---------|----------------|------|
| 游戏（短期） | N=1~3 | 反馈及时，无需多步 |
| 游戏（长期） | N=5~10 | 延迟奖励需要累积 |
| 机器人控制 | N=3~5 | 连续动作需要稳定 |
| 自动驾驶 | N=10~20 | 超长决策时序 |
| 推荐系统 | $\lambda$=0.8 | 在线更新，方差可控 |

## 6. 优缺点分析

**优点**：
1. **偏差小**：累积N步真实奖励，减少对Q值估计的依赖
2. **方差可控**：N值限制真实奖励累积长度，避免蒙特卡洛的高方差
3. **兼容性强**：可与DDQN、PER、Dueling等所有DQN改进叠加
4. **TD($\lambda$)在线可用**：资格迹机制支持在线学习，无需等待回合结束
5. **灵活平衡**：通过N或$\lambda$参数在偏差/方差间连续调节

**缺点**：
1. **超参数敏感**：N值或$\lambda$需要针对任务调优，过大导致方差升高，过小偏差增大
2. **实现复杂**：需要存储连续N步经验，或维护资格迹
3. **训练内存增加**：需缓存更多连续经验用于多步目标计算
4. **离线TD($\lambda$)需特殊处理**：资格迹在后向视角与前向视角需不同处理

**与单步TD、纯蒙特卡洛对比**：
| 特性 | 多步方法（N步） | TD($\lambda$) | 单步TD | 纯蒙特卡洛 |
|------|----------------|--------------|--------|------------|
| 偏差 | 中（N越大偏差越小） | 连续可调 | 高 | 低 |
| 方差 | 中（N越大方差越大） | 连续可调 | 低 | 高 |
| 实现在线学习 | 难（需N步缓存） | 易（资格迹） | 易 | 难 |
| 实现复杂度 | 中 | 中高 | 低 | 高 |
| 训练稳定性 | 高 | 中高 | 中 | 低 |

## 7. 调库实现

基于PyTorch实现多步DQN（N=5），训练CartPole环境：

```python
import torch
import torch.nn as nn
import torch.optim as optim
import gym
import random
from collections import deque
import numpy as np

class DQN(nn.Module):
    def __init__(self, state_dim, action_dim):
        super(DQN, self).__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, 128), nn.ReLU(),
            nn.Linear(128, 128), nn.ReLU(),
            nn.Linear(128, action_dim)
        )
    def forward(self, x):
        return self.net(x)

class MultiStepReplayBuffer:
    def __init__(self, capacity=10000, n_steps=5, gamma=0.99):
        self.capacity = capacity
        self.n_steps = n_steps
        self.gamma = gamma
        self.buffer = deque(maxlen=capacity)
        self.n_step_buffer = deque(maxlen=n_steps)
    
    def push(self, state, action, reward, next_state, done):
        self.n_step_buffer.append((state, action, reward, next_state, done))
        if len(self.n_step_buffer) == self.n_steps or done:
            state, action = self.n_step_buffer[0][0], self.n_step_buffer[0][1]
            n_reward = 0
            for i, (_, _, r, next_s, d) in enumerate(self.n_step_buffer):
                n_reward += (self.gamma ** i) * r
                if d:
                    next_state = next_s
                    break
            last_state = self.n_step_buffer[-1][3]
            last_done = self.n_step_buffer[-1][4]
            self.buffer.append((state, action, n_reward, last_state, last_done))
    
    def sample(self, batch_size):
        batch = random.sample(self.buffer, batch_size)
        states, actions, rewards, next_states, dones = zip(*batch)
        return (torch.FloatTensor(states), 
                torch.LongTensor(actions).unsqueeze(1),
                torch.FloatTensor(rewards).unsqueeze(1),
                torch.FloatTensor(next_states),
                torch.FloatTensor(dones).unsqueeze(1))
    
    def __len__(self):
        return len(self.buffer)

class TDLambdaAgent:
    """TD(lambda)实现：使用资格迹后向视角"""
    def __init__(self, state_dim, action_dim, lambda_=0.9, gamma=0.99, lr=1e-3):
        self.lambda_ = lambda_
        self.gamma = gamma
        self.epsilon = 1.0
        self.epsilon_min = 0.01
        self.epsilon_decay = 0.995
        
        self.q_net = DQN(state_dim, action_dim)
        self.eligibility = {s: 0.0 for s in range(1000)}  # 简化：离散化状态空间
        
        self.optimizer = optim.Adam(self.q_net.parameters(), lr=lr)
        self.loss_fn = nn.MSELoss()
        self.replay_buffer = deque(maxlen=10000)
    
    def compute_td_error(self, state, action, reward, next_state, done):
        state_q = self.q_net(torch.FloatTensor(state).unsqueeze(0))
        next_q = self.q_net(torch.FloatTensor(next_state).unsqueeze(0))
        target_q = reward + self.gamma * next_q.max().item() * (1 - done)
        td_error = target_q - state_q[0, action].item()
        return td_error
    
    def update(self, state, action, reward, next_state, done, batch_size=64):
        td_error = self.compute_td_error(state, action, reward, next_state, done)
        
        if len(self.replay_buffer) >= batch_size:
            batch = random.sample(self.replay_buffer, batch_size)
            states, actions, rewards, next_states, dones = zip(*batch)
            states = torch.FloatTensor(states)
            actions = torch.LongTensor(actions).unsqueeze(1)
            rewards = torch.FloatTensor(rewards).unsqueeze(1)
            next_states = torch.FloatTensor(next_states)
            dones = torch.FloatTensor(dones).unsqueeze(1)
            
            q_values = self.q_net(states).gather(1, actions)
            with torch.no_grad():
                next_q = self.q_net(next_states).max(1)[0].unsqueeze(1)
                target_q = rewards + self.gamma * next_q * (1 - dones)
            
            loss = self.loss_fn(q_values, target_q)
            self.optimizer.zero_grad()
            loss.backward()
            self.optimizer.step()
        
        self.epsilon = max(self.epsilon_min, self.epsilon * self.epsilon_decay)

class MultiStepDQN:
    def __init__(self, state_dim, action_dim, n_steps=5):
        self.n_steps = n_steps
        self.gamma = 0.99
        self.epsilon = 1.0
        self.epsilon_min = 0.01
        self.epsilon_decay = 0.995
        
        self.q_net = DQN(state_dim, action_dim)
        self.target_net = DQN(state_dim, action_dim)
        self.target_net.load_state_dict(self.q_net.state_dict())
        
        self.optimizer = optim.Adam(self.q_net.parameters(), lr=1e-4)
        self.loss_fn = nn.MSELoss()
        self.replay_buffer = MultiStepReplayBuffer(n_steps=n_steps, gamma=self.gamma)
    
    def select_action(self, state):
        if random.random() < self.epsilon:
            return random.randint(0, 1)
        state = torch.FloatTensor(state).unsqueeze(0)
        with torch.no_grad():
            q_values = self.q_net(state)
        return q_values.argmax().item()
    
    def update(self, batch_size=64):
        if len(self.replay_buffer) < batch_size:
            return
        states, actions, rewards, next_states, dones = self.replay_buffer.sample(batch_size)
        
        q_values = self.q_net(states).gather(1, actions)
        with torch.no_grad():
            next_q = self.target_net(next_states).max(1)[0].unsqueeze(1)
            target_q = rewards + (self.gamma ** self.n_steps) * next_q * (1 - dones)
        
        loss = self.loss_fn(q_values, target_q)
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()
        
        self.epsilon = max(self.epsilon_min, self.epsilon * self.epsilon_decay)
    
    def update_target_net(self):
        self.target_net.load_state_dict(self.q_net.state_dict())

if __name__ == "__main__":
    env = gym.make('CartPole-v1')
    agent = MultiStepDQN(
        state_dim=env.observation_space.shape[0],
        action_dim=env.action_space.n,
        n_steps=5
    )
    episodes = 500
    for ep in range(episodes):
        state = env.reset()
        total_reward = 0
        done = False
        while not done:
            action = agent.select_action(state)
            next_state, reward, done, _ = env.step(action)
            agent.replay_buffer.push(state, action, reward, next_state, done)
            agent.update()
            total_reward += reward
            state = next_state
        if (ep+1) % 50 == 0:
            print(f"Episode {ep+1}, Reward: {total_reward}, Epsilon: {agent.epsilon:.3f}")
```

## 8. 手工代码实现

从零实现多步回报计算和TD($\lambda$)：

```python
import numpy as np

def compute_n_step_return(rewards, next_state, target_q_func, n_steps=5, gamma=0.99):
    """计算N步回报目标"""
    n_step_return = 0
    for k, r in enumerate(rewards):
        n_step_return += (gamma ** k) * r
    with torch.no_grad():
        next_q = target_q_func(next_state).max().item()
    target = n_step_return + (gamma ** n_steps) * next_q
    return target

def compute_td_lambda_return(rewards, values, gamma=0.99, lambda_=0.9):
    """
    计算TD(lambda)回报（前向视角）
    rewards: 奖励列表
    values: 值函数列表 [V(s_t), V(s_{t+1}), ...]
    """
    T = len(rewards)
    G_lambda = 0
    for n in range(1, T + 1):
        n_step_return = 0
        for k in range(n):
            if k < len(rewards):
                n_step_return += (gamma ** k) * rewards[k]
        if n < len(values):
            n_step_return += (gamma ** n) * values[n]
        G_lambda += (lambda_ ** (n - 1)) * n_step_return
    G_lambda *= (1 - lambda_)
    if T < len(values):
        G_lambda += (lambda_ ** T) * values[T] / (1 - lambda_)
    return G_lambda

def eligibility_trace_update(value_table, state, td_error, gamma=0.99, lambda_=0.9, alpha=0.1):
    """
    资格迹更新（后向视角）
    value_table: 值函数表（字典）
    state: 当前状态
    td_error: TD误差
    """
    if state not in value_table:
        value_table[state] = {'V': 0.0, 'e': 0.0}
    value_table[state]['e'] = gamma * lambda_ * value_table[state]['e'] + 1.0
    value_table[state]['V'] += alpha * td_error * value_table[state]['e']
    return value_table

    rewards = [1.0, 0.5, 0.8, 0.3, 1.2]
    values = [0.0, 0.5, 0.7, 0.6, 0.8, 0.9]
```

```python
def evaluate_multi_step(agent, env, episodes=20):
    agent.epsilon = 0
    rewards = []
    for _ in range(episodes):
        state = env.reset()
        total_reward = 0
        done = False
        while not done:
            state_tensor = torch.FloatTensor(state).unsqueeze(0)
            with torch.no_grad():
                action = agent.q_net(state_tensor).argmax().item()
            state, reward, done, _ = env.step(action)
            total_reward += reward
        rewards.append(total_reward)
    avg_reward = np.mean(rewards)
    print(f"多步DQN(N={agent.n_steps})测试平均奖励: {avg_reward:.2f} (解决阈值475)")

def compare_n_and_lambda(agent_class, state_dim, action_dim, env, n_values, lambda_values):
```

## 11. 常见问题与易错点

1. **N值或$\lambda$选择不当**
   - 现象：N过大导致方差爆炸，N过小偏差大；$\lambda$过大方差高，过小偏差大
   - 解决：从N=3~5或$\lambda$=0.9开始尝试，根据任务复杂度调整

2. **多步缓冲区实现错误**
   - 现象：回报计算错误，训练不收敛
   - 解决：确保累积N步奖励时折扣因子正确应用，回合结束提前终止累积

3. **目标网络更新频率与N不匹配**
   - 现象：目标值滞后，训练不稳定
   - 解决：目标网络更新频率C应大于N，或与N成正比

4. **TD($\lambda$)资格迹泄漏**
   - 现象：跨回合的资格迹累积导致错误更新
   - 解决：回合结束时重置所有资格迹，或使用衰减因子清零

5. **N步与$\gamma$交互**
   - 现象：N过大导致有效折扣过大，偏差反而增加
   - 解决：确保 $\gamma^N$ 与任务时间尺度匹配

6. **非策略学习偏差**
   - 现象：多步方法在非策略设置下可能产生偏差
   - 解决：使用重要性采样修正，或限制N的大小

## 12. 学习总结

**核心思想**：通过累积N步真实奖励再使用目标网络，在蒙特卡洛的低偏差与时序差分的低方差之间取得平衡，提升DQN训练效果。

**关键公式**：
- N步回报目标：$y_t^{(N)} = \sum_{k=0}^{N-1} \gamma^k r_{t+k+1} + \gamma^N \max_{a'} \hat{Q}(s_{t+N}, a')$
- TD($\lambda$)回报：$G_t^{(\lambda)} = (1-\lambda) \sum_{n=1}^{\infty} \lambda^{n-1} G_t^{(n)}$
- 资格迹：$e_t(s) = \gamma \lambda e_{t-1}(s) + \mathbf{1}(s_t = s)$

**与前序算法关系**：
- 是DQN的进阶技巧，不改变DQN核心框架
- 可与DDQN、PER、Dueling等所有DQN改进叠加
- 是Rainbow DQN的核心组件之一
- TD($\lambda$)是SARSA等在线方法的理论基础

## 13. 练习题与思考题

**基础题**：
1. 多步方法为什么要平衡蒙特卡洛与时序差分？
   参考答案：蒙特卡洛使用真实完整回报，偏差小但方差大；时序差分使用1步目标，方差小但偏差大。多步方法取折中，平衡两者优劣。

2. N值的选择有什么影响？
   参考答案：N越大，真实奖励占比越高，偏差越小但方差越大；N越小，越接近单步TD，偏差大但方差小。

3. 解释资格迹的作用。
   参考答案：资格迹 $e_t(s)$ 追踪每个状态的历史访问资格，TD误差通过资格迹实时更新所有历史状态，实现前向视角的TD($\lambda$)回报在在线场景下的等价计算。

**进阶题**：
1. 推导N步回报目标的公式。
   参考答案：$y_t^{(N)} = \sum_{k=0}^{N-1} \gamma^k r_{t+k+1} + \gamma^N \max_{a'} \hat{Q}(s_{t+N}, a')$，前N步用真实奖励，第N步后用目标网络估计。

2. TD($\lambda$)的前向视角与后向视角为什么等价？
   参考答案：前向视角计算加权多步回报，后向视角通过资格迹实时更新。数学上可证明 $\sum_s e_t(s) \delta_t$ 等价于 $(1-\lambda)\sum \lambda^{n-1} \delta_t^{(n)}$。

3. 如何自适应调整N或$\lambda$？
   参考答案：基于状态不确定性（如TD误差绝对值）动态调整：在不确定性高的状态使用较小的N/$\lambda$，在稳定状态使用较大的值。

**开放题**：
1. 多步方法有哪些常见改进方向？
   参考答案：自适应调整N值（根据状态不确定性）、结合优先级经验回放、与分布式Q函数结合、课程式调整N等。

2. TD($\lambda$)与多步方法的区别和联系？
   参考答案：两者都平衡MC与TD。多步方法使用固定的N，权重集中在第N步；TD($\lambda$)使用连续加权，权重按 $\lambda^k$ 指数衰减。TD($\lambda$)支持在线学习，多步方法需要缓存N步经验。
