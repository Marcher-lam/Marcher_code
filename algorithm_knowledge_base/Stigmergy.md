# Stigmergy 间接通信 学习文档

> 多智能体系统中通过环境传递信息的协调机制。

## 1. 算法基础认知

Stigmergy（间接通信）是多智能体系统中的一种通信机制，智能体通过修改环境来传递信息，而不是直接交换消息。

**直觉类比**：蚂蚁在觅食过程中，会在地面上留下信息素。其他蚂蚁闻到信息素后就会跟随这条路径。这就是"用环境说话"的通信方式。

**前置知识**：多智能体系统

## 2. 核心原理

**核心机制**：
1. 智能体修改环境状态
2. 其他智能体观察环境变化
3. 基于环境信息行动

## 3. 数学公式

**信息素更新**：
$$\tau_{ij} \leftarrow (1-\rho)\tau_{ij} + \Delta\tau$$
