## 审核流程

### 第一关：自动化检查（脚本执行）

运行 `python scripts/audit.py` 自动检测以下项目：

| 检查项 | 通过条件 |
|--------|---------|
| 文件存在 | 249 个 .md 文件全部存在 |
| 章节数量 | 恰好 14 个 `##` 二级标题 |
| 章节标题 | 标题与规范完全一致 |
| 占位符检测 | 不含"请根据"、"…补充"、"待完善"等占位词 |
| 代码块格式 | 所有 ` ``` ` 正确配对 |
| 代码缩进 | Python 代码块无缩进错误 |
| 数学公式 | 包含至少一个 LaTeX 公式（`$` 或 `$$`） |
| 字数下限 | 每个文件不少于 200 行（不含空行） |

### 第二关：内容质量审核（人工 / AI 审核）

对每个文件逐项检查：

#### 2.1 算法基础认知 (Section 1)
- [ ] 有一句话定义
- [ ] 有直觉类比
- [ ] 有历史背景
- [ ] 有算法定位（类型、输入输出）
- [ ] 有前置知识列表

#### 2.2 核心原理 (Section 2)
- [ ] 核心思想解释清晰
- [ ] 工作流程描述完整
- [ ] 关键概念已解释
- [ ] 有几何/直观解释

#### 2.3 数学公式与推导 (Section 3)
- [ ] 有符号约定表
- [ ] 目标函数/损失函数明确定义
- [ ] 推导步骤无跳步
- [ ] 每步推导有文字解释
- [ ] 最终解/算法步骤明确
- [ ] LaTeX 格式正确

#### 2.4 训练过程 (Section 4)
- [ ] 数据预处理要求已说明
- [ ] 初始化方式已说明
- [ ] 迭代过程步骤清晰
- [ ] 收敛条件已说明
- [ ] 超参数及推荐范围已列出

#### 2.5 应用场景 (Section 5)
- [ ] 至少 3 个具体应用
- [ ] 每个应用说明了为什么适合该算法
- [ ] 有不适用场景说明
- [ ] **非通用模板**（不是千篇一律的"金融风控、医疗诊断"）

#### 2.6 优缺点分析 (Section 6)
- [ ] 至少 3 个优点
- [ ] 至少 3 个缺点
- [ ] 缺点有对应解决思路
- [ ] 有与同类算法的对比表格
- [ ] **非通用套话**

#### 2.7 调库实现 (Section 7)
- [ ] 使用正确的库和正确的导入
- [ ] 包含完整数据准备代码
- [ ] 包含训练代码
- [ ] 包含预测和评估代码
- [ ] 有详细中文注释
- [ ] 代码可复制直接运行
- [ ] 有预期输出示例

#### 2.8 手工代码实现 (Section 8)
- [ ] 使用 NumPy / PyTorch（非调库）
- [ ] 实现了真正的算法逻辑（非空壳 pass）
- [ ] 有类结构（fit/predict 方法）
- [ ] 有详细中文注释
- [ ] 附带测试代码
- [ ] 测试代码可运行
- [ ] 有预期输出注释

#### 2.9 可视化 (Section 9)
- [ ] 有可视化代码
- [ ] 代码可运行
- [ ] 图表有标题和标签
- [ ] 有文字解读图表含义

#### 2.10 模型评估 (Section 10)
- [ ] 使用了正确的评估指标
- [ ] 解释了为什么选这些指标
- [ ] 有评估代码
- [ ] 有结果解读

#### 2.11 常见问题与易错点 (Section 11)
- [ ] 有数据层面的常见错误
- [ ] 有模型层面的常见错误
- [ ] 有调参层面的常见误区
- [ ] **非通用模板**（不是"标准化、过拟合"这种万能套话）

#### 2.12 学习总结 (Section 12)
- [ ] 有核心思想回顾
- [ ] 列出了关键公式
- [ ] 有与前序算法的联系
- [ ] 有后续学习方向

#### 2.13 练习题 (Section 13)
- [ ] 至少 2 道基础题 + 1 道进阶题 + 1 道思考题
- [ ] 每道题有完整参考答案
- [ ] 题目针对该算法（非通用模板）
- [ ] 答案有推理过程

#### 2.14 学习路径 (Section 14)
- [ ] 有前置算法建议
- [ ] 有平行算法建议
- [ ] 有进阶算法建议
- [ ] 有推荐外部资源
- [ ] **非通用模板**

### 第三关：代码运行验证

对所有文件的代码块进行运行验证：

```bash
# 提取并运行每个文件的 Python 代码块
python scripts/validate_code.py
```

检查：
- [ ] 调库实现代码运行无报错
- [ ] 手工实现代码运行无报错
- [ ] 输出与预期一致
- [ ] 可视化代码能生成图表
