# 优先遍历 学习文档

> 基于优先级的规划算法，Dyna-Q的高效改进版本

---

## 1. 算法基础认知

**一句话定义**：优先遍历（Prioritized Sweeping）是一种基于优先级的规划算法，通过优先处理价值变化大的状态来提高规划效率，是Dyna-Q的重要改进。

**直觉类比**：想象您在整理一个凌乱的房间。与其随机打扫（像Dyna-Q），您应该先注意到"最乱"的地方（比如衣服堆在地上）优先处理，然后再处理次乱的地方。这就是优先遍历的核心：用价值变化的大小来决定更新的优先级。

**历史背景**：1993年由Moore和Atkeson提出，作为Dyna的改进，旨在减少无效的随机更新，将计算资源集中在最有价值的状态上。

**算法定位**：
- 类型：强化学习 → 基于模型的规划
- 输出：价值函数改进
- 模型类型：基于模型的规划方法

**前置知识**：
- Dyna架构基础
- 价值迭代理解

## 2. 核心原理

### 2.1 核心思想

**核心insight**：不是所有状态更新都同等重要，那些"TD误差大"的状态对价值函数的改进贡献更大。

Dyna-Q的随机更新效率低，很多更新是"无意义"的：
- 对已经收敛的状态做重复更新
- 对远离目标的状态做低效更新

优先遍历的核心改进：根据TD误差大小排序更新优先级。

核心思想可以概括为：**用TD误差作为优先级指标，每次选择误差最大的状态进行反向更新，提高规划效率。**

### 2.2 工作流程

1. **初始化**：设置优先级队列PQ，最大容量M，更新次数n
   - 价值函数V(s)，模型M(s,a)

2. **环境交互**：从真实环境获取经验
   - 观察(s,a,r,s')
   - 更新模型M(s,a)
   - 计算TD误差δ = |r + γV(s') - V(s)|
   - 如果δ > θ，加入优先队列

3. **规划迭代**（重复n次）：
   - 从队列取出最大优先级的状态s
   - 对s做反向更新（所有到达s的前驱动作）
   - 更新传播的优先级

4. **返回步骤2**（继续环境交互）

### 2.3 关键概念解释

- **TD误差（TD Error）**：当前估计与目标的差异
- **优先级队列**：按误差大小排序的待更新状态
- **反向更新（Backups）**：从目标状态向前驱状态传播价值
- **反向规划**：与前向模型使用相反的方向更新

### 2.4 几何/直观解释

```
优先队列（按优先级排序）：
┌─────────────────────┐
│ s:5.0  δ=0.8  ↑
│ s:3.0  δ=0.5  ↑
│ s:2.0  δ=0.3  ↑
│ s:1.0  δ=0.1  ↑
└─────────────────────┘

每次取出δ最大的状态进行反向更新
```

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 |
|------|------|
| $P$ | 优先级队列 |
| $p(s)$ | 状态s的优先级 |
| $θ$ | 优先级阈值 |
| $δ(s,s',a)$ | TD误差 |
| $b(s)$ | 从s可达的后继状态集合 |

### 3.2 优先级定义

**TD误差**：
$$ p(s) = |r + \gamma V(s') - V(s)| $$

或者用最大：
$$ p(s) = \max_{a,s'} |r + \gamma V(s') - V(s)| $$

### 3.3 反向更新公式

对于每个前驱状态$s_{pre}$和动作$a$：
$$ p(s_{pre}) = \max_{a'} |r + \gamma V(s) - V(s_{pre})| $$
$$ V(s_{pre}) \leftarrow \max_{a'} [r + \gamma V(s)] $$

### 3.4 算法步骤

```
优先遍历算法：
初始化：V(s)=0, PQ为空
repeat：
    交互环境获取(s,a,r,s')
    模型存储 M(s,a) = (r,s')
    计算 p = |r + γV(s') - V(s)|
    if p > θ:
        PQ.push(s, p)
    
    for j in range(n):
        if PQ空: break
        s = PQ.pop()
        for每个前驱 (s_prev, a):
            r, _ = M(s_prev, a)
            p_new = |r + γV(s) - V(s_prev)|
            if p_new > θ:
                PQ.push(s_prev, p_new)
            V(s_prev) ← max_a [r + γV(s)]
```

## 4. 训练过程讲解

### 4.1 关键参数

| 超参数 | 作用 | 推荐范围 |
|--------|------|----------|
| 队列大小M | 存储容量 | 10000-100000 |
| 每次迭代n | 规划次数 | 5-50 |
| 阈值θ | 过滤小误差 | 0.001-0.1 |

### 4.2 收敛条件

- 优先级队列为空
- 所有状态TD误差 < θ

## 6. 优缺点分析

### 6.1 优点

1. **效率高**：集中资源在重要更新上
2. **收敛快**：比随机Dyna更快收敛
3. **可扩展**：适合大规模问题

### 6.2 缺点

1. **需要模型**：需要环境模型
2. **参数敏感**：阈值设置影响大
3. **实现复杂**：比Dyna复杂

## 7. 代码实现

### 7.1 优先遍历核心实现

```python
"""
优先遍历（Prioritized Sweeping）实现
"""

import numpy as np
from collections import defaultdict
import heapq


class PrioritizedSweeping:
    """优先遍历规划器"""
    
    def __init__(self, theta=0.1, max_pq_size=10000, planning_steps=5):
        self.theta = theta
        self.max_pq_size = max_pq_size
        self.planning_steps = planning_steps
        self.V = defaultdict(lambda: 0.0)
        self.model = {}
        self.pq = []  # (priority, state) 用heap实现
        
    def priority(self, s, a, r, s_next):
        """计算优先级"""
        return abs(r + 0.9 * self.V[s_next] - self.V[s])
    
    def update_priority_queue(self, s, priority):
        """更新优先级队列"""
        if priority > self.theta:
            heapq.heappush(self.pq, (-priority, s))
            if len(self.pq) > self.max_pq_size:
                heapq.heappop(self.pq)
    
    def plan(self):
        """执行规划步骤"""
        for _ in range(self.planning_steps):
            if not self.pq:
                break
            neg_priority, s = heapq.heappop(self.pq)
            
            for (s_prev, a), (r, _) in self.model.items():
                if s_prev == s:
                    p = self.priority(s_prev, a, r, s)
                    self.V[s_prev] = max(self.V[s_prev], r + 0.9 * self.V[s])
                    self.update_priority_queue(s_prev, p)
    
    def update(self, s, a, r, s_next):
        """环境交互后的更新"""
        key = (s, a)
        self.model[key] = (r, s_next)
        
        p = self.priority(s, a, r, s_next)
        self.update_priority_queue(s, p)
        
        self.V[s] = r + 0.9 * self.V[s_next]
        self.plan()


if __name__ == "__main__":
    print("=" * 50)
    print("优先遍历演示")
    print("=" * 50)
    
    np.random.seed(42)
    
    solver = PrioritizedSweeping(theta=0.1, planning_steps=5)
    
    for episode in range(10):
        s = 0
        for step in range(20):
            a = np.random.choice([0, 1])
            s_next = s + (1 if a == 1 else -1)
            if s_next < 0 or s_next > 9:
                r = -10
                s_next = s
            elif s_next == 9:
                r = 10
            else:
                r = -1
            
            solver.update(s, a, r, s_next)
            s = s_next
            
            if s == 9:
                break
        
        if episode % 2 == 0:
            print(f"Episode {episode}: V(0)={solver.V[0]:.3f}, 队列大小={len(solver.pq)}")
    
    print("\n✓ 程序执行完毕")
```
