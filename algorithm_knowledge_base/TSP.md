# 旅行商问题 学习文档

> 组合优化的经典NP难问题。

## 1. 算法基础认知

TSP（Traveling Salesman Problem）是组合优化中最经典的NP难问题。给定一组城市和城市间的距离，求访问所有城市一次并回到起点的最短路径。

**直觉类比**：推销员要去很多城市推销产品，如何规划路线使总路程最短？

## 2. 核心原理

- 访问每个城市恰好一次
- 回到起点
- 最小化总距离

## 3. 数学公式

$$\min \sum_{i,j} d_{ij} x_{ij}$$

$$s.t. \sum_j x_{ij} = 1, \sum_i x_{ij} = 1$$
