# 缩放点积注意力（Scaled Dot-Product Attention）学习文档

> Transformer的核心注意力计算机制——通过缩放防止softmax梯度消失。

## 1. 算法基础认知

### 一句话定义

缩放点积注意力是Transformer中使用的一种高效注意力计算方法，通过除以 $\sqrt{d_k}$ 来防止点积过大导致Softmax梯度消失。

### 直觉类比

想象你要在图书馆里找一本书。你有一个"查询"（Query），对比每本书的"索引"（Key），找到最相关的几本，然后取那些书的内容（Value）。

但如果书的索引很长（高维Key），点积结果会很大，导致softmax输出接近one-hot（只有一本书相关），梯度几乎为0。除以 $\sqrt{d_k}$ 就像"标准化"比较分数，让softmax正常工作。

### 历史背景

- **2017年**：Transformer论文（"Attention Is All You Need"）首次提出
- **核心洞察**：$d_k$ 很大时，点积的方差很大，导致softmax梯度消失
- **缩放因子 $\sqrt{d_k}$**：将点积方差重新调整为1

### 算法定位

缩放点积注意力是**Transformer的核心组件**，是最广泛使用的注意力机制实现。

## 2. 核心原理

### 2.1 计算公式

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

### 2.2 为什么要缩放？

当 $d_k$ 很大时，$QK^T$ 的方差很大。假设 $q$ 和 $k$ 是均值为0、方差为1的独立随机变量，则点积 $q^T k = \sum_{i=1}^{d_k} q_i k_i$ 的方差为 $d_k$。

大的方差导致：
- softmax输入值很大（在指数函数的饱和区）
- softmax输出接近one-hot（只有一个位置概率接近1）
- 梯度几乎为0 → 难以训练

### 2.3 缩放的效果

除以 $\sqrt{d_k}$ 后，点积的方差重新调整为1：
$$\text{Var}\left(\frac{q^T k}{\sqrt{d_k}}\right) = \frac{d_k}{d_k} = 1$$

这使得softmax的输入在合理范围内，梯度可以有效传播。

## 3. 数学公式与推导

### 3.1 方差推导

假设 $q_i \sim \mathcal{N}(0,1)$，$k_i \sim \mathcal{N}(0,1)$，且独立：

$$E[q_i k_i] = E[q_i]E[k_i] = 0$$

$$\text{Var}(q_i k_i) = E[(q_i k_i)^2] - E[q_i k_i]^2 = E[q_i^2]E[k_i^2] = 1 \times 1 = 1$$

因此：
$$\text{Var}(q^T k) = \text{Var}\left(\sum_{i=1}^{d_k} q_i k_i\right) = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = d_k$$

标准差为 $\sqrt{d_k}$。除以 $\sqrt{d_k}$ 后方差为1。

### 3.2 点积意义

点积衡量两个向量的相似度：
$$q^T k = \|q\| \|k\| \cos(\theta)$$

在注意力中，它表示Query和Key的匹配程度。

### 3.3 完整推导

注意力输出：
$$\text{Attention}(Q, K, V) = AV$$

其中 $A = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)$。

$A$ 的每一行是一个概率分布，表示每个Query位置对Key位置的关注程度。

## 4. 训练过程

缩放点积注意力没有可训练参数（参数在Q/K/V投影中）。它的训练体现在：
1. Q, K, V的线性投影通过学习不断调整
2. 注意力权重在训练中逐渐分化出不同的关注模式
3. 缩放保证梯度的稳定传播

### 4.1 训练细节
- 无需特殊初始化
- Dropout通常应用在注意力权重上
- 掩码（mask）用于解码器的因果注意力

## 5. 应用场景

1. **Transformer核心**：所有Transformer模型的核心计算
2. **视觉Transformer**：ViT中的自注意力
3. **跨模态注意力**：文本-图像对齐
4. **图注意力网络**：GAT中的注意力计算

## 6. 优缺点

### 优点
1. **简单高效**：矩阵运算，GPU友好
2. **数学优雅**：缩放保证数值稳定性
3. **可并行**：一次性计算所有位置的关系

### 缺点
1. **$O(n^2)$复杂度**：序列长度平方增长
2. **缺乏位置感知**：需要额外位置编码
3. **对长序列不友好**：计算和内存消耗大

## 7. 调库实现

```python
"""
缩放点积注意力的完整PyTorch实现
"""

import torch
import torch.nn as nn
import torch.nn.functional as F
import math


def scaled_dot_product_attention(Q, K, V, mask=None, dropout=None):
    """缩放点积注意力

    参数:
        Q: (B, h, Lq, d_k) Query
        K: (B, h, Lk, d_k) Key
        V: (B, h, Lv, d_v) Value
        mask: (B, 1, Lq, Lk) 掩码
        dropout: Dropout层

    返回:
        output: (B, h, Lq, d_v)
        attention_weights: (B, h, Lq, Lk)
    """
    d_k = Q.size(-1)

    # (B, h, Lq, Lk)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)

    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))

    # Softmax
    attn_weights = F.softmax(scores, dim=-1)

    if dropout is not None:
        attn_weights = dropout(attn_weights)

    # 加权和
    output = torch.matmul(attn_weights, V)

    return output, attn_weights


class ScaledDotProductAttention(nn.Module):
    """nn.Module版本的缩放点积注意力"""

    def __init__(self, dropout=0.0):
        super().__init__()
        self.dropout = nn.Dropout(dropout)

    def forward(self, Q, K, V, mask=None):
        return scaled_dot_product_attention(Q, K, V, mask, self.dropout if self.training else None)


# PyTorch 2.0原生实现
def flash_attention(Q, K, V, mask=None):
    """使用PyTorch 2.0的flash attention"""
    return F.scaled_dot_product_attention(Q, K, V, attn_mask=mask)


def demo():
    """缩放点积注意力演示"""

    # 基本使用
    batch, heads, seq_len, d_k = 2, 8, 16, 64
    Q = torch.randn(batch, heads, seq_len, d_k)
    K = torch.randn(batch, heads, seq_len, d_k)
    V = torch.randn(batch, heads, seq_len, d_k)

    output, attn = scaled_dot_product_attention(Q, K, V)
    print(f"基本使用:")
    print(f"  Q/K/V: ({batch}, {heads}, {seq_len}, {d_k})")
    print(f"  输出: {output.shape}")
    print(f"  注意力权重: {attn.shape}")

    # 缩放演示：比较有无缩放
    print(f"\n缩放对softmax的影响:")
    d_k_small = 8
    d_k_large = 512

    q_s = torch.randn(1, 1, 1, d_k_small)
    k_s = torch.randn(1, 1, 5, d_k_small)
    q_l = torch.randn(1, 1, 1, d_k_large)
    k_l = torch.randn(1, 1, 5, d_k_large)

    # 无缩放
    scores_small = (q_s @ k_s.transpose(-2, -1))
    scores_large = (q_l @ k_l.transpose(-2, -1))
    attn_small = F.softmax(scores_small, dim=-1)
    attn_large = F.softmax(scores_large, dim=-1)

    # 有缩放
    attn_small_scaled = F.softmax(scores_small / math.sqrt(d_k_small), dim=-1)
    attn_large_scaled = F.softmax(scores_large / math.sqrt(d_k_large), dim=-1)

    print(f"  d_k={d_k_small}: 无缩放熵={-(attn_small * torch.log(attn_small+1e-8)).sum(-1).item():.4f}, "
          f"有缩放熵={-(attn_small_scaled * torch.log(attn_small_scaled+1e-8)).sum(-1).item():.4f}")
    print(f"  d_k={d_k_large}: 无缩放熵={-(attn_large * torch.log(attn_large+1e-8)).sum(-1).item():.4f}, "
          f"有缩放熵={-(attn_large_scaled * torch.log(attn_large_scaled+1e-8)).sum(-1).item():.4f}")
    print(f"  (高维无缩放≈one-hot → 熵≈0，有缩放保持合理熵值)")

    # 因果掩码
    print(f"\n因果掩码（自回归）:")
    causal_mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1) == 0
    output_causal, attn_causal = scaled_dot_product_attention(
        Q, K, V, mask=causal_mask.unsqueeze(0).unsqueeze(0))
    print(f"  causal掩码形状: {causal_mask.shape}")
    print(f"  causal注意力: {attn_causal.shape}")

    # FLOPs估计
    flops = 2 * batch * heads * seq_len * seq_len * d_k
    print(f"\n  单次前向FLOPs: ~{flops/1e6:.1f}M")


if __name__ == "__main__":
    demo()
```

## 8. 手工实现

```python
"""缩放点积注意力手工实现"""
import numpy as np

def scaled_dot_product_attention_numpy(Q, K, V, mask=None):
    """手工缩放点积注意力"""
    d_k = Q.shape[-1]
    scores = Q @ K.transpose(0, 1, 3, 2) / np.sqrt(d_k)

    if mask is not None:
        scores = np.where(mask, scores, -1e9)

    # 数值稳定的softmax
    scores = scores - scores.max(axis=-1, keepdims=True)
    attn = np.exp(scores) / np.exp(scores).sum(axis=-1, keepdims=True)

    output = attn @ V
    return output, attn

def test():
    np.random.seed(42)
    B, H, L, D = 2, 4, 8, 32
    Q = np.random.randn(B, H, L, D)
    K = np.random.randn(B, H, L, D)
    V = np.random.randn(B, H, L, D)
    out, attn = scaled_dot_product_attention_numpy(Q, K, V)
    print(f"手工实现: Q{K.shape} -> out={out.shape}")
    print(f"注意力每行和: {attn[0,0,0].sum():.4f} (should be 1.0)")

if __name__ == "__main__":
    test()
```

"""缩放点积注意力可视化"""
import matplotlib.pyplot as plt
import numpy as np

def visualize_scaled_vs_unscaled(save_path='scale_comparison.png'):
    """对比有无缩放的softmax输出分布"""
    d_k_values = [8, 32, 128, 512]
    fig, axes = plt.subplots(2, 4, figsize=(14, 6))

    np.random.seed(42)
    n_keys = 10

    for idx, d_k in enumerate(d_k_values):
        q = np.random.randn(d_k)
        K = np.random.randn(n_keys, d_k)

        scores = K @ q
        scores_scaled = scores / np.sqrt(d_k)

        def softmax(x):
            e = np.exp(x - x.max())
            return e / e.sum()

        attn_unscaled = softmax(scores)
        attn_scaled = softmax(scores_scaled)

        axes[0, idx].bar(range(n_keys), attn_unscaled)
        axes[0, idx].set_title(f'd_k={d_k}, 无缩放')
        axes[0, idx].set_ylim(0, 1)

        axes[1, idx].bar(range(n_keys), attn_scaled)
        axes[1, idx].set_title(f'd_k={d_k}, 有缩放')
        axes[1, idx].set_ylim(0, 1)

    plt.suptitle('有无缩放对softmax输出的影响\n(高维无缩放→One-Hot, 有缩放→合理分布)',
                 fontsize=13, fontweight='bold')
    plt.tight_layout()
    plt.savefig(save_path, dpi=150)
    print(f"已保存到 {save_path}")

"""缩放点积注意力评估"""

def analyze_attention_entropy(attention_weights):
    """分析注意力分布的熵"""
    B, H, Lq, Lk = attention_weights.shape
    entropies = []
    for b in range(B):
        for h in range(H):
            attn = attention_weights[b, h]
            ent = -(attn * torch.log(attn + 1e-8)).sum(dim=-1).mean()
            entropies.append(ent.item())
    return np.mean(entropies), np.std(entropies)

def benchmark_attention_speed():
    """基准测试不同序列长度的速度"""
    import time
    for seq_len in [64, 128, 256, 512]:
        Q = torch.randn(1, 8, seq_len, 64)

## 11. 常见问题与易错点

**Q1: 缩放因子为什么是 $\sqrt{d_k}$ 而不是 $d_k$ 或 $d_k^2$？**
因为点积的方差是 $d_k$，标准差是 $\sqrt{d_k}$。除以标准差使方差归一化为1。

**Q2: 如果不缩放会怎么样？**
高维 $d_k$ 时，softmax输入值很大（方差大），输出接近one-hot，梯度消失，模型无法训练。

**Q3: 缩放因子对不同的 $d_k$ 值效果不同吗？**
是的。$d_k$ 越小，缩放的影响越小。$d_k=1$ 时完全无影响。

**Q4: 缩放点积注意力和加性注意力的区别？**
加性注意力（Bahdanau）使用一个小型MLP计算score，不依赖点积。缩放点积注意力更高效（矩阵乘法），但对 $d_k$ 敏感需要缩放。

## 12. 学习总结

- 缩放点积注意力是Transformer的最核心计算
- 公式：$\text{softmax}(QK^T / \sqrt{d_k}) V$
- 缩放因子 $\sqrt{d_k}$ 防止softmax梯度消失
- 复杂度 $O(n^2)$ 是主要瓶颈
- 所有现代LLM和ViT都基于此机制

## 13. 练习题

**基础题：**

1. 缩放点积注意力的计算公式是什么？缩放因子是什么？
> **答案：** $\text{Attention}(Q,K,V) = \text{softmax}(QK^T / \sqrt{d_k}) V$，缩放因子为 $\sqrt{d_k}$。

2. 为什么要缩放 $QK^T$ 的点积？
> **答案：** 点积的方差为 $d_k$，高维时softmax进入饱和区导致梯度消失。

**进阶题：**

3. 当 $d_k=1$ 时，缩放点积注意力和普通点积注意力等价吗？
> **答案：** 等价。因为 $\sqrt{1}=1$，缩放不影响结果。

4. 写出 $d_k$ 维向量点积的方差推导过程。
> **答案：** $\text{Var}(q^T k) = \sum_i \text{Var}(q_i k_i) = d_k \cdot 1 = d_k$。因为 $q_i, k_i \sim \mathcal{N}(0,1)$ 独立，$E[q_i k_i]=0$，$E[(q_i k_i)^2]=1$。
