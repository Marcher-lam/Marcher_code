## 1. 算法基础认知

**一句话定义**：多臂赌博机（Multi-Armed Bandit）是一个序贯决策问题，智能体在多个"手臂"（动作）之间选择，每个动作产生随机收益，用于学习哪个动作最优。

**直觉类比**：就像是您进入一家有k台老虎机的赌场。每台机器有不同的平均回报，但您不知道哪台最好。您每拉一次把手（选择一个动作），就会获得一个奖励（收益）。问题是：您应该一直拉同一台机器（利用已知信息），还是尝试新机器（探索）？这就是著名的"探索-利用"困境。

**历史背景**：多臂赌博机问题源于统计学研究，最早可以追溯到1933年Thompson的著作。在强化学习领域，它作为最简单的序贯决策问题，是理解探索-利用权衡的标准测试平台。Sutton和Barto在《强化学习》第2版中将此问题作为基础章节，可见其重要性。

**算法定位**：
- 类型：强化学习 → 探索-利用基础模型
- 输出：动作选择策略
- 模型类型：参数模型（但参数是每个动作的价值估计）

**前置知识**：
- 概率论：期望、方差、概率分布
- 统计学：样本均值、置信区间
- 线性代数：向量运算（理解即可）

## 2. 核心原理

### 2.1 核心思想

多臂赌博机的核心在于**探索-利用权衡（Exploration-Exploitation Trade-off）**。智能体需要在：
- **利用（Exploitation）**：选择当前估计收益最高的动作
- **探索（Exploration）**：尝试其他动作以获得更准确的估计

之间做出权衡。这是一个所有强化学习问题都面临的根本性困境。

核心思想可以概括为：**通过在线学习，在不断尝试中估计每个动作的真实价值，同时尽量选择已知最优的动作。**

### 2.2 工作流程

1. **初始化**：设置动作数量 k，学习率 α，探索率 ε（或置信度上界参数c）
   - 输入：臂的数量 k
   - 输出：每个动作的估计价值 Q(a) = 0

2. **选择动作**：根据当前策略选择动作 a_t
   - ε-贪心：以概率 ε 随机选择，以概率 1-ε 选择argmax Q(a)
   - UCB：以公式 a_t = argmax [Q(a) + c * sqrt(ln(t)/N(a))] 选择

3. **执行并观察**：执行动作 a_t，获得奖励 R_t
   - 输入：当前动作
   - 输出：奖励值

4. **更新估计**：更新动作价值的估计
   - Q(a_t) ← Q(a_t) + α[R_t - Q(a_t)]（增量式更新）

5. **重复**：返回步骤2，直到达到终止条件

### 2.3 关键概念解释

- **探索（Exploration）**：尝试新动作，获取更多信息
- **利用（Exploitation）**：选择已知最优的动作，最大化当前收益
- **探索-利用困境（Exploration-Exploitation Dilemma）**：无法同时最大化短期和长期收益的矛盾
- **动作价值（Action Value）**：选择某个动作获得的期望奖励
- **遗憾（Regret）**：最优动作期望收益与实际获得的收益之差

### 2.4 几何/直观解释

想象一个k=3的赌博机问题：
- 每个动作的真实价值（您不知道）：Q*(1)=3.0, Q*(2)=2.5, Q*(3)=1.0
- 您的估计值随时间变化
- 最优策略应该快速发现Q*(1)是最优的，然后大部分时间选择它

在图表中，y轴是估计价值Q，x轴是时间。理想的学习曲线应该快速收敛到Q*(1)=3附近。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 | 维度 |
|------|------|------|
| $k$ | 动作（臂）的数量 | 标量 |
| $a_t$ | 第t时刻选择的动作 | 标量 |
| $R_t$ | 第t时刻获得的奖励 | 标量 |
| $Q(a)$ | 动作a的估计价值 | 标量 |
| $N(a)$ | 动作a被选择的次数 | 标量 |
| $Q^*(a)$ | 动作a的真实价值 | 标量 |
| $\alpha$ | 学习率/步长 | 标量 |
| $\varepsilon$ | 探索率 | 标量 |

### 3.2 问题形式化

给定一个k臂赌博机，我们的目标是学习一个策略$\pi$，使得累积奖励最大化。

$$ \text{目标：} \max_{\pi} \mathbb{E}\left[\sum_{t=1}^{T} R_t \mid \pi \right] $$

其中每个动作$a$的真实价值定义为：
$$ Q^*(a) = \mathbb{E}[R_t \mid a_t = a] $$

### 3.3 目标函数/损失函数

**动作价值估计的目标**：最小化估计值与真实价值的均方误差

$$ \text{最小化：} \mathbb{E}[(Q(a) - Q^*(a))^2] $$

但我们不知道$Q^*$，所以采用**样本均值**作为估计：

**样本平均方法**：
$$ Q(a) = \frac{\sum_{i=1}^{n_a} R_i}{n_a} $$

其中$n_a$是动作a被选择的次数。

**增量式更新**（更常用）：
$$ Q_{n+1}(a) = Q_n(a) + \frac{1}{n}[R_n - Q_n(a)] $$

### 3.4 推导过程

**Step 1：估计值更新**

由增量式更新公式展开：
$$ Q_{n+1}(a) = Q_n(a) + \alpha [R_n - Q_n(a)] $$

其中$\alpha = 1/n$是样本均值的情况。当$\alpha$固定时，这是指数移动平均。

**Step 2：ε-贪心动作选择**

$$ a_t = \begin{cases} text{random action with probability } varepsilon, \ argmax_a Q(a) with probability 1-varepsilon end{cases} $$

**Step 3：UCB（置信度上界）选择**

$$ a_t = argmax_a \left[ Q(a) + c \sqrt{\frac{\ln t}{N(a)}} \right] $$

其中第二项是探索奖励，$c$是探索常数。

### 3.5 最终解/算法步骤

**ε-贪心算法**：
```
初始化：Q(a) = 0 for all a, N(a) = 0
for t = 1, 2, ...:
    if random() < ε:
        a_t = random action
    else:
        a_t = argmax_a Q(a)
    
    R_t = get_reward(a_t)
    N(a_t) = N(a_t) + 1
    Q(a_t) = Q(a_t) + (R_t - Q(a_t)) / N(a_t)
```

**UCB算法**：
```
初始化：Q(a) = 0, N(a) = 1 for all a
for t = 1, 2, ...:
    a_t = argmax_a [Q(a) + c * sqrt(ln(t) / N(a))]
    
    R_t = get_reward(a_t)
    N(a_t) = N(a_t) + 1
    Q(a_t) = Q(a_t) + (R_t - Q(a_t)) / N(a_t)
```

## 4. 训练过程讲解

### 4.1 数据预处理

多臂赌博机一般不需要预处理，因为：
- 数据来自环境实时交互，不是静态数据集
- 奖励已经是数值形式

但需要设计**奖励函数**：
- 如果建模为伯努利赌博机，奖励为0或1
- 如果建模为高斯赌博机，奖励服从正态分布

### 4.2 参数初始化

- **Q(a)初始化**：可以设为0（保守），或设为乐观值（如Q(a)=5）以鼓励探索
- **N(a)初始化**：设为0或1（避免除零）

### 4.3 迭代过程

```
# 每个时间步
1. 根据策略选择动作 a_t
2. 从环境获得奖励 R_t
3. 更新计数 N(a_t) += 1
4. 更新价值估计 Q(a_t)
5. 记录累积奖励
```

### 4.4 收敛条件

- 达到最大迭代次数
- 估计价值变化小于阈值
- 累积遗憾低于阈值

### 4.5 超参数及推荐范围

| 超参数 | 作用 | 推荐范围 | 默认值 |
|--------|------|----------|--------|
| ε | 探索率 | 0.05-0.2 | 0.1 |
| α | 学习率 | 0.01-0.2 | 0.1 |
| c | UCB探索常数 | 1-2 | √2 |
| k | 臂的数量 | 5-10 | 10 |

## 5. 应用场景

### 5.1 典型应用（3-5个）

**应用1：网站推荐系统**
- 问题类型：动作选择
- 为什么适合：每个用户请求相当于拉一次"臂"，点击率是不同的奖励
- 实际案例：新闻网站选择展示哪条新闻

**应用2：临床试验**
- 问题类型：治疗方案选择
- 为什么适合：每个患者是一个试验，康复情况是奖励
- 实际案例：新药测试中患者分配

**应用3：自适应定价**
- 问题类型：价���决��
- 为什么适合：不同价格有不同的购买概率作为奖励
- 实际案例：电商动态定价

**应用4：机器人任务调度**
- 问题类型：动作序列规划
- 为什么适合：每个动作有不同的时间/能量消耗作为负奖励
- 实际案例：多机器人任务分配

### 5.2 适用数据特征

- 离散动作空间
- 重复交互场景
- 即时奖励（无延迟）
- 单一状态（非MDP）

### 5.3 不适用场景

1. **连续动作空间**：需要用其他方法（如策略梯度）
2. **延迟奖励**：需要完整的MDP建模（如TD学习）
3. **状态相关**：需要状态信息（需要扩展为Contextual Bandit）
4. **合作/竞争环境**：需要MARL方法

## 6. 优缺点分析

### 6.1 优点（3-5个）

1. **数学简洁**：有清晰的形式化和理论保证
   - 可计算累积遗憾上界

2. **无状态依赖**：不需要environment模型

3. **易于实现**：基础版本只需几十行代码

4. **理论完备**：有大量分析工具

5. **可扩展性强**：是其他RL方法的基础

### 6.2 缺点（3-5个）

1. **无状态建模**：无法处理状态相关决策
   - 解决：Contextual Bandit

2. **假设stationary**：假设奖励分布不变

3. **探索策略粗糙**：ε-贪心不是最优探索
   - 解决：UCB、Thompson Sampling

4. **无法处理延迟奖励**：只能处理一步奖励

### 6.3 与同类算法对比

| 维度 | 多臂赌博机 | Contextual Bandit | MDP |
|------|-----------|----------------|-----|
| 状态信息 | 无 | 有（但固定） | 有 |
| 奖励延迟 | 无 | 无 | 可能延迟 |
| 复杂度 | 低 | 中 | 高 |
| 求解难度 | 易 | 中 | 难 |

```python
"""
多臂赌博机（Multi-Armed Bandit）调库实现
使用ε-贪心和UCB两种策略
"""

import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

class MultiArmedBandit:
    """k臂赌博机"""
    
    def __init__(self, k=10, reward_std=1.0):
        """
        初始化赌博机
        
        Args:
            k: 臂的数量
            reward_std: 奖励的标准差
        """
        self.k = k
        self.reward_std = reward_std
        self.true_rewards = np.random.randn(k)
        
    def pull(self, arm):
        """拉取指定臂，返回奖励"""
        reward = self.true_rewards[arm] + np.random.randn() * self.reward_std
        return reward
    
    def get_optimal_arm(self):
        """返回最优臂的真实价值"""
        return np.argmax(self.true_rewards)


class EpsilonGreedy:
    """ε-贪心算法"""
    
    def __init__(self, k, epsilon=0.1):
        self.k = k
        self.epsilon = epsilon
        self.Q = np.zeros(k)
        self.N = np.zeros(k)
        
    def select_action(self):
        """选择动作"""
        if np.random.random() < self.epsilon:
            return np.random.randint(self.k)
        return np.argmax(self.Q)
    
    def update(self, action, reward):
        """更新Q值"""
        self.N[action] += 1
        self.Q[action] += (reward - self.Q[action]) / self.N[action]


class UCB:
    """置信度上界算法"""
    
    def __init__(self, k, c=2.0):
        self.k = k
        self.c = c
        self.Q = np.zeros(k)
        self.N = np.zeros(k)
        self.total_steps = 0
        
    def select_action(self):
        """选择动作"""
        self.total_steps += 1
        if self.total_steps <= self.k:
            return self.total_steps - 1
        
        ucb_values = self.Q + self.c * np.sqrt(np.log(self.total_steps) / self.N)
        return np.argmax(ucb_values)
    
    def update(self, action, reward):
        """更新Q值"""
        self.N[action] += 1
        self.Q[action] += (reward - self.Q[action]) / self.N[action]


def run_experiment(bandit, agent, n_steps=1000, n_runs=2000):
    """运行实验"""
    rewards = np.zeros((n_runs, n_steps))
    optimal_choices = np.zeros((n_runs, n_steps))
    
    for run in range(n_runs):
        bandit = MultiArmedBandit(k=10)
        agent.__init__(bandit.k)
        
        optimal_arm = bandit.get_optimal_arm()
        
        for step in range(n_steps):
            action = agent.select_action()
            reward = bandit.pull(action)
            agent.update(action, reward)
            
            rewards[run, step] = reward
            optimal_choices[run, step] = (action == optimal_arm)
    
    avg_rewards = np.mean(rewards, axis=0)
    avg_optimal = np.mean(optimal_choices, axis=0)
    cumulative_regret = np.cumsum(optimal_arm - avg_rewards)
    
    return avg_rewards, avg_optimal, cumulative_regret


if __name__ == "__main__":
    print("=" * 50)
    print("多臂赌博机实验")
    print("=" * 50)
    
    n_steps = 1000
    n_runs = 2000
    
    print("\n运行ε-贪心算法实验...")
    bandit = MultiArmedBandit(k=10)
    eps_rewards, eps_optimal, eps_regret = run_experiment(bandit, EpsilonGreedy, n_steps, n_runs)
    
    print("运行UCB算法实验...")
    bandit = MultiArmedBandit(k=10)
    ucb_rewards, ucb_optimal, ucb_regret = run_experiment(bandit, UCB, n_steps, n_runs)
    
    print(f"\nε-贪心: 平均奖励={eps_rewards[-1]:.3f}, 最优选择率={eps_optimal[-1]:.3f}")
    print(f"UCB: 平均奖励={ucb_rewards[-1]:.3f}, 最优选择率={ucb_optimal[-1]:.3f}")
    
    plt.figure(figsize=(12, 4))
    
    plt.subplot(1, 3, 1)
    plt.plot(eps_rewards, label='ε-greedy')
    plt.plot(ucb_rewards, label='UCB')
    plt.xlabel('Steps')
    plt.ylabel('Average Reward')
    plt.title('Average Reward over Time')
    plt.legend()
    
    plt.subplot(1, 3, 2)
    plt.plot(eps_optimal, label='ε-greedy')
    plt.plot(ucb_optimal, label='UCB')
    plt.xlabel('Steps')
    plt.ylabel('Optimal Rate')
    plt.title('Optimal Action Rate')
    plt.legend()
    
    plt.subplot(1, 3, 3)
    plt.plot(eps_regret, label='ε-greedy')
    plt.plot(ucb_regret, label='UCB')
    plt.xlabel('Steps')
    plt.ylabel('Cumulative Regret')
    plt.title('Cumulative Regret')
    plt.legend()
    
    plt.tight_layout()
    plt.savefig('multi_armed_bandit_results.png', dpi=300)
    plt.show()
    
    print("\n✓ 程序执行完毕")
```

## 8. 手工代码实现

### 8.1 核心算法手写

```python
"""
多臂赌博机 手工实现
仅依赖NumPy，从零实现ε-贪心和UCB算法
"""

import numpy as np


class MultiArmedBanditManual:
    """手工实现的多臂赌博机"""
    
    def __init__(self, k=10, reward_std=1.0):
        self.k = k
        self.reward_std = reward_std
        self.true_rewards = np.random.randn(k)
        
    def pull(self, arm):
        reward = self.true_rewards[arm] + np.random.randn() * self.reward_std
        return reward
    
    def get_optimal_arm(self):
        return np.argmax(self.true_rewards)


class EpsilonGreedyManual:
    """ε-贪心算法手工实现"""
    
    def __init__(self, k=10, epsilon=0.1, initial_value=0.0):
        self.k = k
        self.epsilon = epsilon
        self.Q = np.full(k, initial_value)
        self.N = np.zeros(k)
        
    def select_action(self):
        if np.random.random() < self.epsilon:
            return np.random.randint(self.k)
        return np.argmax(self.Q)
    
    def update(self, action, reward):
        self.N[action] += 1
        self.Q[action] += (reward - self.Q[action]) / self.N[action]
        
    def reset(self, k=None, epsilon=None):
        if k is not None:
            self.k = k
        if epsilon is not None:
            self.epsilon = epsilon
        self.Q = np.full(self.k, 0.0)
        self.N = np.zeros(self.k)


class UCBManual:
    """UCB算法手工实现"""
    
    def __init__(self, k=10, c=2.0):
        self.k = k
        self.c = c
        self.Q = np.zeros(k)
        self.N = np.zeros(k)
        self.total_steps = 0
        
    def select_action(self):
        self.total_steps += 1
        
        if self.total_steps <= self.k:
            return self.total_steps - 1
        
        ucb_values = self.Q + self.c * np.sqrt(np.log(self.total_steps) / (self.N + 1e-10))
        return np.argmax(ucb_values)
    
    def update(self, action, reward):
        self.N[action] += 1
        self.Q[action] += (reward - self.Q[action]) / self.N[action]
    
    def reset(self, k=None, c=None):
        if k is not None:
            self.k = k
        if c is not None:
            self.c = c
        self.Q = np.zeros(self.k)
        self.N = np.zeros(self.k)
        self.total_steps = 0


if __name__ == "__main__":
    np.random.seed(42)
    
    print("运行手工实现的多臂赌博机实验...")
    
    n_steps = 1000
    n_runs = 500
    
    eps_rewards = []
    ucb_rewards = []
    
    for run in range(n_runs):
        bandit = MultiArmedBanditManual(k=10)
        
        agent1 = EpsilonGreedyManual(k=10, epsilon=0.1)
        agent2 = UCBManual(k=10, c=2.0)
        
        run_rewards1 = []
        run_rewards2 = []
        
        for step in range(n_steps):
            action1 = agent1.select_action()
            reward1 = bandit.pull(action1)
            agent1.update(action1, reward1)
            run_rewards1.append(reward1)
            
            action2 = agent2.select_action()
            reward2 = bandit.pull(action2)
            agent2.update(action2, reward2)
            run_rewards2.append(reward2)
        
        eps_rewards.append(np.mean(run_rewards1[-100:]))
        ucb_rewards.append(np.mean(run_rewards2[-100:]))
    
    print(f"ε-贪心平均奖励: {np.mean(eps_rewards):.4f}")
    print(f"UCB平均奖励: {np.mean(ucb_rewards):.4f}")
```

```python
def visualize_learning_curve():
```

```python
def tune_epsilon():
```

## 11. 常见问题与易错点

### 11.1 数据层面常见错误

**错误1：奖励分布假设错误**

现象：学习效果差

原因：真实奖励可能不是高斯分布

解决方案：了解环境Reward生成机制

**错误2：Stationary假设不成立**

现象：估计价值持续变化

原因：环境奖励分布随时间变化

解决方案：使用非 stationary 方法

### 11.2 模型层面常见错误

**错误1：ε设置不当**

ε过大：探索太多，利用不够
ε过小：陷入局部最优

解决方案：用网格搜索找最优ε

**错误2：初始值过于乐观**

现象：初期表现过度乐观

解决：非乐观初始值或衰减ε

## 12. 学习总结

### 12.1 核心要点回顾

✓ **核心思想**：探索-利用权衡

✓ **数学本质**：样本均值估计动作价值

✓ **优化目标**：最大化累积奖励

✓ **适用场景**：单步决策、无状态

✓ **局限性**：无法处理状态相关问题

### 12.2 关键公式汇总

1. **增量更新**：
$$ Q_{n+1} = Q_n + \frac{1}{n}(R_n - Q_n) $$

2. **ε-贪心**：
$$ a = begin{cases} random & text{if } u < varepsilon \ argmax Q & text{otherwise} end{cases} $$

3. **UCB**：
$$ a = argmax_a left[ Q(a) + c sqrt{frac{ln t}{N(a)}} right] $$

### 12.3 最佳实践

- 先用ε-贪心，再用UCB对比
- 可视化学习曲线监控
- 用累积遗憾评估算法

- 选择其他动作的概率：各0.05
