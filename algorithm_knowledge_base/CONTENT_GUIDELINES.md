```python
class LinearRegressionManual:
    """
    手工实现的线性回归算法

    使用梯度下降法进行优化
    """

    def __init__(self, learning_rate=0.01, n_iterations=1000):
        """
        初始化参数

        Args:
            learning_rate: 学习率
            n_iterations: 迭代次数
        """
        self.learning_rate = learning_rate
        self.n_iterations = n_iterations
        self.weights = None
        self.bias = None

    def fit(self, X, y):
        """
        训练模型

        Args:
            X: 训练数据，形状(n_samples, n_features)
            y: 标签，形状(n_samples,)
        """
        n_samples, n_features = X.shape

        # 参数初始化
        self.weights = np.zeros(n_features)
        self.bias = 0

        # 梯度下降优化
        for _ in range(self.n_iterations):
            # 计算预测值
            y_pred = self._predict(X)

            # 计算梯度
            dw = (1/n_samples) * np.dot(X.T, (y_pred - y))
            db = (1/n_samples) * np.sum(y_pred - y)

            # 更新参数
            self.weights -= self.learning_rate * dw
            self.bias -= self.learning_rate * db

    def _predict(self, X):
        """预测函数"""
        return np.dot(X, self.weights) + self.bias

    def predict(self, X):
        """
        对新数据进行预测

        Args:
            X: 测试数据

        Returns:
            预测值
        """
        return self._predict(X)
```

```markdown
### 13.1 基础练习

**练习1：概念理解**

问题：线性回归中的"线性"指的是什么？
A. 特征与标签的关系是线性的
B. 模型参数与预测值的关系是线性的
C. 特征之间是线性的
D. 以上都不是

答案：B

解析：
线性回归中的"线性"是指模型对参数是线性的，即预测值可以表示为参数的线性组合。特征本身可以通过变换（如x², log(x)）引入非线性关系。

### 13.2 进阶思考

**思考1：改进分析**

问题：如果数据中存在大量异常值，标准线性回归会表现不佳，为什么？有哪些改进方法？

答案：
标准线性回归使用均方误差作为损失函数，对异常值非常敏感（平方会放大误差）。

改进方法：
1. 使用鲁棒回归（如RANSAC、Huber Regression）
2. 使用L1损失（MAE）代替L2损失（MSE）
3. 使用分位数回归
4. 对异常值进行预处理（检测和删除）
```
