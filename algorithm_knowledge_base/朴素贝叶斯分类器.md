## 1. 算法基础认知

### 1.1 什么是朴素贝叶斯

朴素贝叶斯（Naive Bayes）是一种基于贝叶斯定理的概率分类算法。它的"朴素"假设是特征之间相互独立，即一个特征的出现与其他特征无关。虽然这个假设在现实中很少成立，但算法在许多实际任务中表现惊人地好。

### 1.2 直觉类比

想象你在街上看到一只猫在淋雨。你可能会想："要不要把猫带进来？"你根据"是猫"、"在淋雨"、"看起来很湿"这几个线索独立判断，每个线索都给你一个"这可能需要帮助"的信号。朴素贝叶斯正是这样，把每个特征的独立信息结合起来做决策。

### 1.3 历史背景

朴素贝叶斯算法在60年代被正式提出，最初用于垃圾邮件过滤。由于其简单、高效的特性，至今仍在NLP领域被广泛使用。在文本分类任务中，它通常是一个很好的基线模型。

### 1.4 算法定位

朴素贝叶斯是一种**监督学习**的**概率分类算法**，常用于：
- 文本分类（垃圾邮件检测、情感分析）
- 文档分类
- 多类别分类问题

### 1.5 前置知识

- 基础概率论（条件概率、贝叶斯定理）
- Python编程
- 朴素假设的含义

## 2. 核心原理

### 2.1 核心思想

使用贝叶斯定理：
$$P(类别|特征) = \frac{P(特征|类别) times P(类别)}{P(特征)}$$

在分类时，我们比较不同类别的后验概率，选择概率最大的类别。由于分母$P(特征)$对所有类别相同，只需比较：
$$P(类别|特征) propto P(特征|类别) times P(类别)$$

### 2.2 工作流程

1. **训练阶段**：
   - 统计每个类别中每个特征出现的次数
   - 计算先验概率 $P(类别)$
   - 计算似然 $P(特征|类别)$

2. **预测阶段**：
   - 给定新样本的特征
   - 计算各类别的后验概率
   - 选择概率最大的类别

### 2.3 关键概念

- 先验概率 $P(类别)$：训练数据中该类别的比例
- 似然 $P(特征|类别)$：该类别中该特征出现的条件概率
- 词袋模型：文本被表示为词频向量

### 2.4 几何解释

在词袋模型中，每个文档是一个高维稀疏向量（词汇表大小）。朴素贝叶斯实际上是在高维空间中为每个类别找到一个"典型"向量，然后计算新向量与各类别典型向量的相似度。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 |
|------|------|
| $c$ | 类别 |
| $d$ | 文档 |
| $V$ | 词汇表 |
| $w_i$ | 词汇表中的词 |
| $P(c)$ | 类别$c$的先验概率 |
| $P(w_i\|c)$ | 词$w_i$在类别$c$中出现的条件概率 |

### 3.2 问题形式化

给定文档$d$，判断它属于哪个类别：
$$hat{c} = argmax_c P(c|d) = argmax_c P(d|c) times P(c)$$

### 3.3 目标函数

对于词袋模型，假设词之间相互独立：
$$P(d|c) = prod_{i in d} P(w_i|c)$$

### 3.4 逐步推导

实际计算时使用对数避免下溢：
$$log P(c|d) propto log P(c) + sum_{w in d} log P(w|c)$$

使用拉普拉斯平滑：
$$P(w_i|c) = frac{C(w_i, c) + alpha}{C(c) + alpha times |V|}$$

### 3.5 最终公式

预测时选择使以下值最大的类别：
$$score(c, d) = log P(c) + sum_{w in d} log left( frac{C(w, c) + 1}{C(c) + |V|} right)$$

## 4. 训练过程

### 4.1 数据预处理

```python
from sklearn.feature_extraction.text import CountVectorizer

# 创建词袋
vectorizer = CountVectorizer()
X_train = vectorizer.fit_transform(train_texts)
```

这会创建词袋矩阵，每行是一个文档，每列是一个词的出现次数。

### 4.2 参数初始化

朴素贝叶斯没有显式的"神经网络权重"这样的参数需要初始化。模型参数直接从训练数据统计得到。

### 4.3 迭代过程

训练是直接的一次性统计过程，不涉及迭代：
1. 遍历所有训练文档
2. 统计每个类别的文档数 $\rightarrow$ 先验概率
3. 统计每个类别中每个词的出现次数 $\rightarrow$ 似然

### 4.4 收敛条件

由于是直接统计，训练天然就是"收敛"的——遍历完所有训练数据即可。

### 4.5 超参数表

| 超参数 | 作用 | 推荐范围 | 默认值 |
|--------|------|---------|--------|
| alpha | 平滑参数 | 0.0-2.0 | 1.0 |

## 5. 应用场景

### 5.1 典型应用

1. **垃圾邮件检测**
   - 适合原因：词袋表示+类别判断，简单有效
   - 特征：邮件文本中的词

2. **情感分析**
   - 适合原因：判断文本正面/负面
   - 特征：文本中的情感词

3. **文档分类**
   - 适合原因：多类别分类
   - 特征：文档中的词

4. **文本分类**
   - 适合原因：新闻分类、主题分类
   - 特征：文档的词袋表示

### 5.2 适用数据特征

- 文本数据
- 类别数量有限
- 特征之间相对独立（理想情况）

### 5.3 不适用场景

- 特征之间高度相关
- 需要复杂特征组合
- 小样本数据

print("\n" + "-" * 40)
print("自定义朴素贝叶斯实现")
print("-" * 40)

class NaiveBayesClassifier:
    """简单的朴素贝叶斯分类器实现"""
    
    def __init__(self, alpha=1.0):
        self.alpha = alpha  # 平滑参数
        self.class_priors = {}  # 先验概率
        self.word_probs = {}  # 词的条件概率
        self.classes = set()
        self.vocab = set()
        
    def fit(self, X, y):
        """训练模型
        
        X: 文档列表
        y: 标签列表
        """
        # 统计类别
        from collections import Counter
        class_counts = Counter(y)
        
        self.classes = set(y)
        total_docs = len(y)
        
        # 计算先验概率（log形式）
        for c in self.classes:
            self.class_priors[c] = np.log(class_counts[c] / total_docs)
        
        # 统计词频
        word_counts_per_class = {c: Counter() for c in self.classes}
        total_words_per_class = {c: 0 for c in self.classes}
        
        for doc, label in zip(X, y):
            words = set(doc) if isinstance(doc, (set, list)) else set(doc.split())
            self.vocab.update(words)
            word_counts_per_class[label].update(words)
            total_words_per_class[label] += len(doc) if isinstance(doc, list) else len(doc.split())
        
        # 计算条件概率（log形式）
        V = len(self.vocab)
        
        for c in self.classes:
            self.word_probs[c] = {}
            for word in self.vocab:
                count = word_counts_per_class[c].get(word, 0)
                # 拉普拉斯平滑
                prob = (count + self.alpha) / (total_words_per_class[c] + self.alpha * V)
                self.word_probs[c][word] = np.log(prob)
        
        return self
    
    def predict(self, X):
        """预测
        
        X: 文档列表
        """
        predictions = []
        
        for doc in X:
            words = set(doc) if isinstance(doc, (set, list)) else set(doc.split())
            
            best_class = None
            best_score = float('-inf')
            
            for c in self.classes:
                score = self.class_priors[c]
                
                for word in words:
                    if word in self.word_probs[c]:
                        score += self.word_probs[c][word]
                
                if score > best_score:
                    best_score = score
                    best_class = c
            
            predictions.append(best_class)
        
        return predictions

# 训练自定义模型
custom_nb = NaiveBayesClassifier(alpha=1.0)

## 9. 可视化与结果理解

### 9.1 特征重要性可视化

每个词对分类的贡献可以通过对数似然比来衡量：

```python
import matplotlib.pyplot as plt

def plot_feature_importance(model, feature_names, top_n=20):
    """可视化特征重要性"""
    # 计算每个词的对数似然比
    log_likelihood_ratio = {}
    for word in model.vocab:
        if word in model.word_probs[0] and word in model.word_probs[1]:
            llr = model.word_probs[1][word] - model.word_probs[0][word]
            log_likelihood_ratio[word] = llr
    
    # 排序取top N
    sorted_words = sorted(log_likelihood_ratio.items(), key=lambda x: x[1])
    
    # 可视化
    words = [w for w, _ in sorted_words[-top_n:]]
    values = [v for _, v in sorted_words[-top_n:]]
    
    plt.figure(figsize=(10, 6))
    plt.barh(words, values)
    plt.xlabel('Log Likelihood Ratio')
    plt.title('Feature Importance for Classification')
    plt.show()
```

### 9.2 结果解读

- 正的对数似然比：该词偏向正类
- 负的对数似然比：该词偏向负类
- 绝对值越大，区分能力越强

## 12. 学习总结

### 核心思想

朴素贝叶斯基于贝叶斯定理，通过特征独立性假设简化计算，实现快速分类。

### 关键公式

$$P(c|d) = P(c) \cdot \prod_{w \in d} P(w|c)$$

### 后续学习
