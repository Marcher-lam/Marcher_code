# 随机删除与随机交换 学习文档

> 通过删除和交换操作增强模型对词缺失和语序变化的鲁棒性

## 1. 算法基础认知

随机删除（Random Deletion）和随机交换（Random Swap）是两种经典的文本数据增强技术，它们通过对原始句子进行"删词"和"换词"操作，生成语义相似但表达形式不同的新文本。这两种方法虽然简单，但在提高模型鲁棒性和泛化能力方面具有显著效果。

**随机删除**的核心思想是按照一定的概率随机删除句子中的词语，模拟信息不完整或噪声干扰的场景。这种方法可以帮助模型学会从残缺的信息中恢复完整的语义，提高对关键词的关注度。在实际应用中，即使句子中缺少一些非关键词，人类仍然能够理解其主要含义，随机删除正是模拟了这种能力。例如，"这部电影非常精彩，我强烈推荐"经过随机删除可能变成"电影精彩，推荐"，虽然丢失了一些修饰词，但核心语义仍然保留。

**随机交换**则是随机选择句子中的两个词语，交换它们的位置，创造语序的微小变化。这种方法基于这样一个观察：在许多语言中，词语顺序的局部调整并不一定完全改变句子的含义，特别是对于某些词序相对灵活的语言（如中文）。例如，"我昨天去了公园"交换后可能变成"昨天我去了公园"，语义基本不变。通过随机交换，模型可以学习到词序变化下的语义不变性，提高对语序扰动的鲁棒性。

这两种方法通常与同义词替换、随机插入等方法结合使用，形成综合的数据增强策略。在少样本学习、对抗训练、以及需要高鲁棒性的NLP任务中，随机删除和随机交换都是重要的工具。

需要注意的是，这两种方法都有一定的风险：随机删除可能删除关键实体或否定词，导致语义完全改变；随机交换可能生成不符合语法的句子。因此，在实际应用中，需要合理控制操作的比例和次数，并考虑对关键词语（如实体、否定词）进行保护。

## 2. 核心原理

随机删除和随机交换的核心原理可以从多个理论角度来理解：

**随机删除的原理：**

1. **信息瓶颈理论**：随机删除可以看作是在信息瓶颈框架下的一种应用。通过随机丢弃部分词语，强制模型关注最重要的信息（关键词），学习更鲁棒的特征表示。这与Dropout正则化有相似之处，都是通过在训练时引入噪声来防止过拟合。

2. **鲁棒性训练**：在真实应用场景中，输入文本可能存在噪声（如OCR错误、语音识别错误导致的词缺失）。通过在训练时模拟这种噪声，模型可以学会对词缺失的鲁棒性，提高在实际应用中的稳定性。

3. **注意力机制促进**：删除非关键词后，剩余的关键词在句子中的相对重要性增加，这有助于模型（特别是基于注意力的模型）学会识别和关注最重要的词语。

**随机交换的原理：**

1. **语序不变性学习**：自然语言具有一定的语序灵活性。通过随机交换词语，模型可以学习到局部词序变化不影响全局语义的特性，从而提高对语序扰动的鲁棒性。

2. **数据空间扩展**：从几何角度看，随机交换将原始数据点在特征空间中"扩散"到其邻域。假设原始句子对应特征空间中的点 $\mathbf{x}$，通过交换操作生成的新句子对应点 $\mathbf{x}'$ 位于 $\mathbf{x}$ 的邻域内。这种邻域采样有助于学习更平滑的决策边界。

3. **语法鲁棒性**：虽然随机交换可能偶尔产生不符合语法的句子，但在大量训练后，模型可以学会忽略局部的语法噪声，关注更高层次的语义信息。

**算法流程详解：**

**随机删除算法：**
1. 输入句子 $S = (w_1, w_2, ..., w_n)$
2. 对于句子中的每个词 $w_i$，以概率 $p$ 决定是否保留
3. 如果保留，加入新句子；否则跳过
4. 如果新句子为空，随机选择一个词保留（确保至少保留一个词）
5. 输出新句子 $S' = (w_{i_1}, w_{i_2}, ..., w_{i_m})$，其中 $m \leq n$

**随机交换算法：**
1. 输入句子 $S = (w_1, w_2, ..., w_n)$ 和交换次数 $k$
2. 重复 $k$ 次：
   a. 随机选择两个不同的位置 $i$ 和 $j$（$i \neq j$）
   b. 交换 $w_i$ 和 $w_j$
3. 输出新句子 $S'$

**操作次数的选择：**

- **随机删除**：通常删除比例为10%-30%。过高的删除比例可能导致语义丢失。
- **随机交换**：通常交换1-2次。过多的交换会使句子变得难以理解。

**关键词语保护：**

在实际应用中，通常需要保护某些关键词语不被删除或交换：
- 实体词（人名、地名、组织机构名）
- 否定词（not, never, no等）
- 句子中的第一个词和最后一个词（可能影响句子结构）

可以通过命名实体识别（NER）或词性标注（POS tagging）来识别需要保护的词。

## 3. 数学公式与推导

**随机删除的概率模型**

设原始句子为 $S = (w_1, w_2, ..., w_n)$。定义保留指示变量：

$$r_i = \begin{cases} 
1 & \text{如果 } w_i \text{ 被保留} \\
0 & \text{如果 } w_i \text{ 被删除}
\end{cases}$$

每个词被保留的概率为 $1-p$，其中 $p$ 是删除概率。因此：

$$P(r_i = 1) = 1 - p$$

删除后的句子长度 $m = \sum_{i=1}^{n} r_i$ 服从二项分布：

$$m \sim \text{Binomial}(n, 1-p)$$

其期望值和方差为：

$$E[m] = n(1-p)$$
$$\text{Var}[m] = np(1-p)$$

**至少保留一个词的概率**

如果所有词都被删除（$m=0$），需要随机保留一个词。所有词都被删除的概率为：

$$P(m=0) = p^n$$

当 $p=0.2, n=10$ 时，$P(m=0) = 0.2^{10} \approx 0.0000001$，概率极低。

**随机交换的组合数学**

从 $n$ 个位置中选择2个不同位置的方法数为：

$$C(n, 2) = \frac{n(n-1)}{2}$$

进行 $k$ 次交换，每次有 $C(n, 2)$ 种选择，因此总的可能交换序列数为：

$$N_{swap} = [C(n, 2)]^k = \left[\frac{n(n-1)}{2}\right]^k$$

**交换后的句子相似度**

设原始句子为 $S$，交换后的句子为 $S'$。词重叠率为：

$$\text{Overlap}(S, S') = \frac{|S \cap S'|}{|S \cup S'|} = 1$$

因为交换不改变词集合，只改变顺序。

**语言模型概率变化**

使用语言模型 $LM$ 评估交换前后的概率变化。设 $P(S|LM)$ 是原始句子的概率，$P(S'|LM)$ 是交换后句子的概率。

交换质量可以通过概率比来衡量：

$$\text{Quality} = \frac{P(S'|LM)}{P(S|LM)}$$

如果 $\text{Quality} \approx 1$，说明交换后的句子在语言模型视角下仍然合理。如果 $\text{Quality} \ll 1$，说明交换可能破坏了语法结构。

**删除与交换的联合概率**

如果对一个句子先执行删除（概率 $p$），再执行交换（次数 $k$），联合概率为：

$$P(S'|S) = P_{\text{delete}}(S'_{\text{del}}|S) \cdot P_{\text{swap}}(S'|S'_{\text{del}})$$

其中 $S'_{\text{del}}$ 是删除后的句子。

**信息保留率**

删除操作后，保留的信息比例可以用词数比例来近似：

$$I_{\text{retain}} = \frac{m}{n} = 1 - p$$

对于语义信息，由于不同词的重要性不同，信息保留率可能高于或低于词数比例。关键词的保留至关重要。

## 4. 训练过程讲解

随机删除和随机交换作为数据增强技术，其训练过程主要涉及如何在模型训练流程中集成这些增强方法。

**离线增强流程（Offline Augmentation）**

最常用的方法，在训练开始前生成所有增强样本：

1. **准备原始数据**：加载训练集 $D = \{(x_i, y_i)\}_{i=1}^N$

2. **设置增强参数**：
   - 删除概率 $p$（如0.2）
   - 交换次数 $k$（如1-2次）
   - 每个原始样本生成的增强样本数（如1-2个）

3. **生成增强样本**：
   ```
   for each sentence x in D:
       for j in 1 to n_aug:
           x_del = random_deletion(x, p)
           x_swap = random_swap(x, k)  # 或应用于x_del
           add (x_del, y) to D_del
           add (x_swap, y) to D_swap
   ```

4. **合并数据集**：$D_{train} = D \cup D_{del} \cup D_{swap}$

5. **训练模型**：使用 $D_{train}$ 训练模型

**在线增强流程（Online Augmentation）**

在训练过程中动态生成增强样本：

```python
class TextDataset:
    def __getitem__(self, idx):
        text = self.texts[idx]
        label = self.labels[idx]
        
        if self.training:  # 只在训练时增强
            # 随机选择增强方法
            aug_method = random.choice(['delete', 'swap', 'none'])
            if aug_method == 'delete':
                text = random_deletion(text, p=0.2)
            elif aug_method == 'swap':
                text = random_swap(text, k=1)
            # 'none'表示不增强，使用原始文本
        
        return text, label
```

**超参数选择**

关键超参数包括：

1. **删除概率 $p$**：通常为0.1-0.3。过高会导致语义丢失。
2. **交换次数 $k$**：通常为1-2次。过高会使句子语法混乱。
3. **增强样本比例**：多少比例的训练样本进行增强。可以为100%（所有样本都增强），或50%（一半增强，一半原始）。
4. **关键词语保护**：是否保护实体、否定词等。

这些超参数应该在验证集上进行网格搜索或随机搜索。

**训练注意事项**

1. **标签一致性**：随机删除和交换假设这些操作不改变句子的标签。对于大多数分类任务，这个假设是合理的。但对于自然语言推理（NLI）等任务，删除关键词可能改变语义关系，需要谨慎。

2. **避免过度增强**：过度删除或交换可能导致句子难以理解，引入过多噪声。建议限制操作强度。

3. **评估增强效果**：在验证集上比较不同增强策略的效果，选择最佳配置。

## 5. 应用场景

**1. 文本分类任务**
在情感分析、新闻分类等任务中，随机删除可以强制模型关注关键词。例如，在垃圾邮件检测中，删除一些修饰词后，模型仍能基于核心词汇（如"免费"、"中奖"）做出判断。随机交换可以帮助模型学习到词序变化下的语义不变性。

**2. 鲁棒性测试与对抗训练**
通过随机删除和交换，可以生成对抗样本，测试模型的鲁棒性。例如，在关键位置删除或交换词语，观察模型预测是否改变。这可以用于识别模型的脆弱点，并通过对抗训练提高鲁棒性。

**3. 少样本学习（Few-shot Learning）**
在数据有限的场景下，随机删除和交换可以快速扩充训练集，增加数据多样性。特别是在专业领域（如医疗、法律），标注数据获取成本高昂，这些简单有效的增强方法可以最大化利用现有数据。

**4. 问答系统训练**
在构建问答系统时，用户的问题可能包含冗余信息或语序变化。通过随机删除，可以模拟用户提问中的信息缺失；通过随机交换，可以模拟不同的提问方式。这有助于模型适应各种表达方式，提高系统鲁棒性。

**5. 机器翻译鲁棒性**
在机器翻译中，输入文本可能包含噪声或语序变化。通过在训练数据中加入随机删除和交换的增强样本，翻译模型可以学会处理不完美输入，提高在实际应用中的稳定性。

## 6. 优缺点分析

**优点：**

1. **实现极其简单**：随机删除和交换的代码非常简短，不需要外部资源（如词典、预训练模型），易于理解和维护。

2. **计算成本低**：这两种操作只涉及列表操作，几乎没有计算开销，可以高效地大规模应用。

3. **提高鲁棒性**：通过模拟信息缺失和语序变化，帮助模型学会从不完整或扰动的信息中提取语义，提高实际应用中的稳定性。

4. **不需要外部资源**：与同义词替换不同，这两种方法不需要WordNet等词典资源，适用于任何语言和领域。

5. **与其他方法互补**：随机删除和交换通常与同义词替换、随机插入等方法结合使用，形成综合增强策略，效果往往优于单一方法。

**缺点：**

1. **可能删除关键词语**：随机删除可能删除否定词（"not"）、实体词等，导致语义完全改变。例如，"This is not good"删除"not"后变成"This is good"，情感完全反转。

2. **可能生成不合语法的句子**：随机交换可能产生不符合语法的句子，特别是在词序严格的语言中。过多的交换会使句子难以理解。

3. **语义漂移风险**：虽然删除和交换通常保持词集合不变（交换）或只减少（删除），但在敏感任务中（如NLI），删除关键词可能改变句子的语义关系。

4. **语言差异性**：某些语言（如德语）的词序比英语更严格，随机交换可能导致更大的语法问题。需要根据语言特点调整策略。

5. **删除概率难以调优**：删除概率过高会导致信息丢失，过低则增强效果不明显。最佳概率依赖于句子长度和任务特性，需要实验确定。

**对比表：**

| 特性 | 随机删除 | 随机交换 | 同义词替换 | 随机插入 |
|------|---------|---------|-----------|---------|
| 实现难度 | 极低 | 极低 | 低 | 低 |
| 计算成本 | 极低 | 极低 | 低（需查词典） | 低（需查词典） |
| 改变长度 | 减少 | 不变 | 不变 | 增加 |
| 语法风险 | 低 | 中高 | 低 | 中 |
| 语义保持 | 中 | 中 | 高 | 高 |
| 外部资源 | 不需要 | 不需要 | 需要（词典） | 需要（词典） |
| 适用语言 | 所有 | 词序灵活的语言 | 有词典资源的语言 | 有词典资源的语言 |

## 7. 调库实现

以下是随机删除和随机交换的完整实现，包含详细注释：

```python
import random
import pandas as pd
import numpy as np
from typing import List, Optional, Set

class RandomDeletionSwap:
    """
    随机删除与随机交换增强器
    包含两种增强方法：随机删除和随机交换
    """
    
    def __init__(
        self,
        delete_prob: float = 0.2,
        swap_times: int = 1,
        protect_entities: bool = False,
        seed: Optional[int] = None
    ):
        """
        初始化增强器
        
        参数:
            delete_prob: 删除概率（0-1之间）
            swap_times: 交换次数
            protect_entities: 是否保护实体词（简化版，实际应使用NER）
            seed: 随机种子
        """
        self.delete_prob = delete_prob
        self.swap_times = swap_times
        self.protect_entities = protect_entities
        
        if seed is not None:
            random.seed(seed)
            np.random.seed(seed)
        
        # 简化的实体词列表（实际应使用NER工具）
        self.entity_words = set(['apple', 'google', 'microsoft', 'china', 'america'])
    
    def random_deletion(self, sentence: str) -> str:
        """
        随机删除：按照概率p随机删除词语
        
        参数:
            sentence: 原始句子
        
        返回:
            删除后的句子
        """
        words = sentence.split()
        
        if len(words) <= 1:
            return sentence
        
        # 决定是否保留每个词
        new_words = []
        for word in words:
            # 保护实体词（如果启用）
            if self.protect_entities and word.lower() in self.entity_words:
                new_words.append(word)
            elif random.uniform(0, 1) > self.delete_prob:
                new_words.append(word)
        
        # 如果所有词都被删除，随机保留一个词
        if len(new_words) == 0:
            rand_idx = random.randint(0, len(words) - 1)
            new_words = [words[rand_idx]]
        
        return ' '.join(new_words)
    
    def random_swap(self, sentence: str, swap_times: Optional[int] = None) -> str:
        """
        随机交换：随机选择两个词交换位置
        
        参数:
            sentence: 原始句子
            swap_times: 交换次数，如果为None则使用self.swap_times
        
        返回:
            交换后的句子
        """
        words = sentence.split()
        
        if len(words) <= 1:
            return sentence
        
        k = swap_times if swap_times is not None else self.swap_times
        new_words = words.copy()
        
        for _ in range(k):
            # 随机选择两个不同的位置
            idx1, idx2 = random.sample(range(len(new_words)), 2)
            # 交换
            new_words[idx1], new_words[idx2] = new_words[idx2], new_words[idx1]
        
        return ' '.join(new_words)
    
    def augment_dataset(
        self,
        texts: List[str],
        n_augments: int = 1,
        method: str = 'both',  # 'delete', 'swap', 'both'
        keep_original: bool = True
    ) -> List[str]:
        """
        增强整个数据集
        
        参数:
            texts: 原始文本列表
            n_augments: 每个原始样本生成的增强样本数
            method: 增强方法
            keep_original: 是否保留原始样本
        
        返回:
            增强后的文本列表
        """
        augmented = []
        
        if keep_original:
            augmented.extend(texts)
        
        for text in texts:
            for _ in range(n_augments):
                if method == 'delete' or method == 'both':
                    aug_del = self.random_deletion(text)
                    if aug_del != text:
                        augmented.append(aug_del)
                
                if method == 'swap' or method == 'both':
                    aug_swap = self.random_swap(text)
                    if aug_swap != text:
                        augmented.append(aug_swap)
        
        return augmented
```

## 8. 手工代码实现

以下是从零开始实现的随机删除和交换类，不依赖任何外部库：

```python
import random
from typing import List, Set, Optional

class RandomDeletionSwapFromScratch:
    """
    随机删除与随机交换从零实现
    不依赖任何外部库
    """
    
    def __init__(
        self,
        delete_prob: float = 0.2,
        swap_times: int = 1,
        min_word_length: int = 2,
        protect_negations: bool = True,
        seed: Optional[int] = None
    ):
        """
        初始化增强器
        
        参数:
            delete_prob: 删除概率
            swap_times: 交换次数
            min_word_length: 最小词长度（短于此长度的词不会被删除）
            protect_negations: 是否保护否定词
            seed: 随机种子
        """
        self.delete_prob = delete_prob
        self.swap_times = swap_times
        self.min_word_length = min_word_length
        self.protect_negations = protect_negations
        
        if seed is not None:
            random.seed(seed)
        
        # 否定词列表
        self.negation_words = set(['not', 'no', 'never', "n't", 'cannot', 'cant'])
    
    def _should_protect(self, word: str) -> bool:
        """判断是否应该保护该词不被删除"""
        word_lower = word.lower()
        
        # 保护否定词
        if self.protect_negations and word_lower in self.negation_words:
            return True
        
        # 保护短词
        if len(word) < self.min_word_length:
            return True
        
        return False
    
    def random_deletion(self, sentence: str) -> str:
        """
        随机删除实现
        
        参数:
            sentence: 原始句子
        
        返回:
            删除后的句子
        """
        words = sentence.split()
        
        if len(words) <= 1:
            return sentence
        
        new_words = []
        for word in words:
            # 检查是否应该保护
            if self._should_protect(word):
                new_words.append(word)
            else:
                # 按概率决定是否删除
                if random.random() > self.delete_prob:
                    new_words.append(word)
        
        # 确保至少保留一个词
        if len(new_words) == 0:
            # 随机选择一个词保留
            idx = random.randint(0, len(words) - 1)
            new_words = [words[idx]]
        
        return ' '.join(new_words)
    
    def random_swap(self, sentence: str, swap_times: Optional[int] = None) -> str:
        """
        随机交换实现
        
        参数:
            sentence: 原始句子
            swap_times: 交换次数
        
        返回:
            交换后的句子
        """
        words = sentence.split()
        
        if len(words) <= 1:
            return sentence
        
        k = swap_times if swap_times is not None else self.swap_times
        new_words = words.copy()
        
        for _ in range(k):
            # 随机选择两个不同的位置
            idx1 = random.randint(0, len(new_words) - 1)
            idx2 = random.randint(0, len(new_words) - 1)
            while idx2 == idx1:  # 确保两个位置不同
                idx2 = random.randint(0, len(new_words) - 1)
            
            # 交换
            new_words[idx1], new_words[idx2] = new_words[idx2], new_words[idx1]
        
        return ' '.join(new_words)
    
    def augment_mixed(self, sentence: str) -> str:
        """
        混合增强：先删除，再交换（或反之）
        
        参数:
            sentence: 原始句子
        
        返回:
            增强后的句子
        """
        # 随机选择顺序
        if random.random() < 0.5:
            result = self.random_deletion(sentence)
            result = self.random_swap(result)
        else:
            result = self.random_swap(sentence)
            result = self.random_deletion(result)
        
        return result
    
    def augment_batch(
        self,
        sentences: List[str],
        n_aug: int = 1,
        method: str = 'mixed',
        keep_original: bool = True
    ) -> List[str]:
        """
        批量增强
        
        参数:
            sentences: 句子列表
            n_aug: 每个句子生成的增强样本数
            method: 增强方法 ('delete', 'swap', 'mixed')
            keep_original: 是否保留原始句子
        
        返回:
            增强后的句子列表
        """
        result = []
        if keep_original:
            result.extend(sentences)
        
        for sentence in sentences:
            for _ in range(n_aug):
                if method == 'delete':
                    augmented = self.random_deletion(sentence)
                elif method == 'swap':
                    augmented = self.random_swap(sentence)
                elif method == 'mixed':
                    augmented = self.augment_mixed(sentence)
                else:
                    raise ValueError(f"Unknown method: {method}")
                
                if augmented != sentence:
                    result.append(augmented)
        
        return result


# ============================================
# 使用示例
# ============================================

if __name__ == "__main__":
    # 创建增强器
    augmenter = RandomDeletionSwapFromScratch(
        delete_prob=0.2,

    )
```

6. **词重叠率**：交换后的重叠率应为1（因为词集合不变），删除后的重叠率应小于1（因为删除了词）。

1. **准确率（Accuracy）**：分类正确的样本比例。随机删除和交换的目的是提高泛化能力。

2. **不同删除概率的效果**：比较删除概率为0（基线）、0.1、0.2、0.3、0.4时的性能，找到最佳删除概率。

3. **数据集大小变化**：每次增强都会增加训练样本，观察数据量增长情况。

**结果解读：**

- 如果随机删除和交换有效，应该看到准确率的提升（但可能不如同义词替换显著）。
- 如果删除概率过高（如0.4），可能导致性能下降，因为删除了过多关键信息。
- 通常删除概率在0.1-0.2之间效果最佳。

## 11. 常见问题与易错点

**数据层面问题：**

1. **否定词被删除**："This is not good"如果删除"not"，语义完全反转。解决方法：维护否定词表，保护这些词不被删除。

2. **实体词被删除**：命名实体（人名、地名）被删除可能导致句子语义不明确。解决方法：使用NER工具识别实体，保护这些词。

3. **删除所有词**：如果删除概率过高或句子很短，可能所有词都被删除。解决方法：在删除后检查句子是否为空，如果为空则随机保留一个词。

**模型层面问题：**

1. **交换破坏语法**：随机交换可能生成不符合语法的句子，影响模型学习。解决方法：限制交换次数（如最多1-2次），或基于句法树选择交换位置。

2. **标签不一致风险**：在某些敏感任务（如自然语言推理）中，删除关键词可能改变句子的语义关系。解决方法：在这些任务中谨慎使用，或只删除非关键词。

3. **过度增强**：对训练集进行过多增强（如每个样本生成10个增强版本）可能导致训练集过大，且引入过多噪声。解决方法：通常每个样本生成1-2个增强样本即可。

**调参问题：**

1. **删除概率选择**：删除概率太高会导致信息丢失，太低则增强效果不明显。解决方法：在验证集上实验不同删除概率（0.1, 0.2, 0.3），选择最佳配置。

2. **交换次数选择**：交换次数过多会使句子语法混乱。解决方法：通常1-2次足够，除非句子很长。

3. **保护词设置**：哪些词应该被保护？这取决于任务。解决方法：根据任务特点，维护保护词表（否定词、实体词、关键词等）。

## 12. 学习总结

随机删除和随机交换是两种简单而有效的文本数据增强技术。随机删除通过按概率删除词语，模拟信息缺失场景，强制模型关注关键词；随机交换通过交换词语位置，模拟语序变化，提高模型对词序扰动的鲁棒性。

从原理层面，这两种方法基于信息瓶颈理论和鲁棒性训练思想。随机删除可以看作是一种Dropout-like的正则化，随机交换则帮助模型学习语序不变性。它们不需要外部资源（如词典、预训练模型），适用于任何语言和领域。

在实践层面，我们学习了如何实现随机删除和交换，包括如何保护关键词语（否定词、实体词）、如何控制删除概率和交换次数、以及如何将这两种方法结合使用。关键要点包括：确保至少保留一个词（删除操作）、合理选择交换位置、以及根据具体任务调整保护策略。

随机删除和交换通常与其他增强方法（如同义词替换、随机插入）结合使用，形成综合的增强策略。在少样本学习、鲁棒性测试、对抗训练等场景中，这些简单的方法往往能带来显著的性能提升。

需要注意的是，这两种方法都有一定的风险：删除关键词语可能改变语义，交换可能生成不合语法的句子。因此，在实际应用中，应该谨慎选择操作强度，保护关键词语，并在验证集上评估效果。

总之，随机删除和随机交换是轻量级、易实现、通用的增强方法，特别适合作为文本增强工具箱的基础组件。掌握这些技术，将为构建更鲁棒的NLP系统提供支持。

   <details>
   <summary>答案</summary>
   ```python
   import random
   
   def simple_random_deletion(sentence, p=0.2):
       """简单随机删除"""
       words = sentence.split()
       if len(words) <= 1:
           return sentence
       
       new_words = []
       for word in words:
           if random.random() > p:  # 保留概率 1-p
               new_words.append(word)
       
       # 确保至少保留一个词
       if len(new_words) == 0:
           idx = random.randint(0, len(words) - 1)
           new_words = [words[idx]]
       
       return ' '.join(new_words)
   
   # 测试
   sent = "This is a test sentence with several words."
   print(f"Original: {sent}")
   for i in range(3):
       print(f"Deleted {i+1}: {simple_random_deletion(sent)}")
   ```

2. **实现简单随机交换**：实现一个随机交换函数，随机选择两个词交换位置。

   <details>
   <summary>答案</summary>
   ```python
   import random
   
   def simple_random_swap(sentence, k=1):
       """简单随机交换"""
       words = sentence.split()
       if len(words) <= 1:
           return sentence
       
       new_words = words.copy()
       for _ in range(k):
           idx1, idx2 = random.sample(range(len(new_words)), 2)
           new_words[idx1], new_words[idx2] = new_words[idx2], new_words[idx1]
       
       return ' '.join(new_words)
   
   # 测试
   sent = "The quick brown fox jumps over the lazy dog."
   print(f"Original: {sent}")
   for i in range(3):
       print(f"Swapped {i+1}: {simple_random_swap(sent)}")
   ```

3. **保护否定词的删除**：改进随机删除算法，保护否定词（not, no, never等）不被删除。

   <details>
   <summary>答案</summary>
   ```python
   import random
   
   def protected_deletion(sentence, p=0.2):
       """保护否定词的删除"""
       negation_words = {'not', 'no', 'never', "n't", 'cannot'}
       
       words = sentence.split()
       if len(words) <= 1:
           return sentence
       
       new_words = []
       for word in words:
           # 检查是否为否定词
           if word.lower() in negation_words:
               new_words.append(word)  # 否定词强制保留
           elif random.random() > p:
               new_words.append(word)
       
       # 确保至少保留一个词
       if len(new_words) == 0:
           # 优先保留否定词
           neg_words = [w for w in words if w.lower() in negation_words]
           if neg_words:
               return neg_words[0]
           else:
               idx = random.randint(0, len(words) - 1)
               return words[idx]
       
       return ' '.join(new_words)
   
   # 测试
   test_sentences = [
       "This is not a good product.",
       "I would never recommend this to anyone.",
       "The service is good and not expensive.",
   ]

       print(f"Deleted:  {protected_deletion(sent)}\n")
   ```

   ```python
   def syntax_aware_swap(sentence):

       if len(words) <= 1:
           return sentence
       
       # POS tagging
       pos_tags = nltk.pos_tag(words)
       
       # 按词性分组位置
       adj_positions = [i for i, (w, pos) in enumerate(pos_tags) if pos.startswith('J')]  # 形容词
       noun_positions = [i for i, (w, pos) in enumerate(pos_tags) if pos.startswith('N')]  # 名词
       adv_positions = [i for i, (w, pos) in enumerate(pos_tags) if pos.startswith('R')]  # 副词
       verb_positions = [i for i, (w, pos) in enumerate(pos_tags) if pos.startswith('V')]  # 动词
       
       # 尝试在同类词性内交换
       new_words = words.copy()
       swapped = False
       
       if len(adj_positions) >= 2:
           idx1, idx2 = random.sample(adj_positions, 2)
           new_words[idx1], new_words[idx2] = new_words[idx2], new_words[idx1]
           swapped = True
       elif len(noun_positions) >= 2:
           idx1, idx2 = random.sample(noun_positions, 2)
           new_words[idx1], new_words[idx2] = new_words[idx2], new_words[idx1]
           swapped = True
       
       # 如果没有同类词性可交换，就随机交换
       if not swapped:
           idx1, idx2 = random.sample(range(len(words)), 2)
           new_words[idx1], new_words[idx2] = new_words[idx2], new_words[idx1]
       
       return ' '.join(new_words)
   ```
