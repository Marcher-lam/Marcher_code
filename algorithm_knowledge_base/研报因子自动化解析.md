# 研报因子自动化解析 学习文档

> 用大模型自动阅读研报PDF，像雷达扫描一样从海量文本中提取可回测的量化因子。
> 来源线索：本节内容根据原书中关于"研报因子的自动化解析与建模"（第3章3.3节）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：利用大语言模型自动解析金融研报PDF，提取量化因子定义、公式和参数，自动生成可运行Python代码的端到端流程。

**直觉类比**：翻译机器人——输入一本外文说明书(研报PDF)，自动提取其中的配方(因子定义)和操作步骤(计算公式)，输出一份中文操作手册(可运行代码)。

**背景**：传统因子提取依赖人工研读—理解—编码，1份研报耗时4-8小时。大模型的长文本理解能力(NLP)突破后，1分钟即可完成从研报到因子代码的全流程，效率提升近10000倍。这是原书作者团队在全球量化大赛TOP10的核心竞争力。

**算法定位**：AI+量化 / NLP应用 / 流程自动化 / 因子挖掘。

**前置知识**：PDF文本处理、提示词工程基础、Python代码生成概念。

## 2. 核心原理

**端到端五步流程**：

1. **PDF文本提取**：pdfplumber/PyMuPDF将PDF转为纯文本（图表需OCR）
2. **提示词设计**：设计结构化提示词引导大模型提取因子信息
3. **大模型解析**：调用大模型API(Moonshot/GPT-4等长文本模型)，输出JSON
4. **代码自动生成**：模板引擎将JSON映射为Python因子计算函数
5. **回测集成**：自动拼装回测模块，验证因子有效性

**关键设计——提示词模板**：
> 解析以下研报文本，抽取所有量化因子名称（英文命名）、计算公式及回测参数，输出JSON格式：{"因子名": {"公式": "...", "周期": N, "方向": "多/空/多空"}, ...}。若无明确公式，则根据描述推断生成。

**输出格式控制**：要求JSON标准格式，便于后续代码解析。

## 3-4. 核心公式与流程

研报因子解析的数学体现在"公式描述的自然语言→数学表达式"的映射：
- "收盘价20日均线"→ `df['close'].rolling(20).mean()`
- "价格高于均线做多" → `signal = 1 when close > MA(close, 20)`

## 5. 应用场景

- 券商/基金批量复现研报因子
- 个人量化研究员快速原型开发
- 因子库自动化扩展与管理
- 策略竞赛和学术研究的加速器

**适用**：任何需要从文本中提取结构化策略信息的场景
**不适用**：研报质量极差(无公式只有空话)、需要复杂图表OCR的场景

## 6. 优缺点分析

**优点**：效率提升巨大、减少人为理解偏差、可扩展(同时解析数百份研报)
**缺点**：PDF质量依赖(扫描件/图表难解析)、大模型幻觉(编造不存在的公式)、公式推断可能不准确需人工复核

## 7. 调库实现

```python
"""
研报因子自动化解析（模拟实现，无需API Key）
"""
import json
import re


class ResearchReportParser:
    """模拟大模型的研报解析器（基于规则+模板的简化实现）"""

    def __init__(self):
        # 常见因子模式库
        self.patterns = [
            (r'(\d+)日均线', 'MA', lambda m: f"df['close'].rolling({m}).mean()"),
            (r'MACD.*?(\d+).*?(\d+).*?(\d+)', 'MACD', lambda m: f"MACD(df, {m[0]},{m[1]},{m[2]})"),
            (r'RSI.*?(\d+)', 'RSI', lambda m: f"RSI(df, {m})"),
            (r'换手率.*?(\d+)日', 'Turnover', lambda m: f"df['turnover_rate'].rolling({m}).mean()"),
            (r'成交量.*?(\d+)日.*?均', 'VolMA', lambda m: f"df['volume'].rolling({m}).mean()"),
        ]

    def parse(self, text):
        """解析研报文本，提取因子"""
        factors = {}

        for pattern, name, code_gen in self.patterns:
            matches = re.findall(pattern, text)
            for match in matches:
                if isinstance(match, tuple):
                    params = [int(x) for x in match]
                else:
                    params = [int(match)]
                factor_key = f"{name}_{'_'.join(map(str, params))}"
                factors[factor_key] = {
                    'formula': code_gen(params),
                    'params': params,
                }

        return factors

    def generate_code(self, factors):
        """生成Python代码"""
        code_lines = ['import pandas as pd', 'import numpy as np', '']
        code_lines.append('# === 自动生成的因子计算函数 ===')
        for name, detail in factors.items():
            code_lines.append(f'def calc_{name.lower()}(df):')
            code_lines.append(f'    """因子: {name}"""')
            code_lines.append(f'    df["{name}"] = {detail["formula"]}')
            code_lines.append('    return df')
            code_lines.append('')
        return '\n'.join(code_lines)


class SimpleBacktestEngine:
    """简化的回测引擎"""

    @staticmethod
    def backtest(df, factor_col, direction='long'):
        df['signal'] = 0
        if direction == 'long':
            df.loc[df[factor_col] > df['close'], 'signal'] = 1
        df['ret'] = df['close'].pct_change().shift(-1) * df['signal']
        df['cum_ret'] = (1 + df['ret']).cumprod()
        return df


# ========== 测试 ==========
if __name__ == '__main__':
    # 模拟研报片段
    report_text = """
    我们提出基于20日均线的动量因子(Momentum_MA20)，其公式为收盘价20日移动平均，
    若价格高于均线做多，低于均线做空。
    此外，RSI的14日指标在超买超卖区有反转信号。
    5日换手率均值可作为活跃度参考。
    """

    parser = ResearchReportParser()
    factors = parser.parse(report_text)
    print("提取的因子:")
    print(json.dumps(factors, indent=2, ensure_ascii=False))

    print("\n生成的代码:")
    print(parser.generate_code(factors))
```

## 8-14. 综合章节

**关键流程**：PDF提取→提示词→大模型→JSON→代码→回测

**常见问题**：
- PDF提取不完整(扫描件/图表)→多工具交叉验证(pdfplumber+PyMuPDF+OCR)
- 大模型输出JSON格式不规范→提示词明确要求和异常捕获+正则修正
- 回测参数遗漏→提示词要求输出完整参数(周期/方向/阈值)
- 生成代码和原始数据字段不匹配→代码模板加入字段映射和异常处理

**学习路径**：PDF文本处理→提示词工程设计→大模型API调用→代码模板设计→回测集成

**练习题**：
- 基础：一段研报文字"我们采用股价突破60日最高价作为买入信号"，请写出对应的因子提取结果。→ 因子名:Breakout_High60, 公式:df['close'] > df['high'].rolling(60).max(), 方向:多
- 进阶：如果大模型输出了错误公式（如把"收盘价/开盘价-1"理解成"收盘价-开盘价"），如何自动检测和修正？→ 对生成代码做沙箱测试——输入模拟数据运行，检查输出是否合理(值域/符号)，异常就发送第二轮纠正prompt。
- 开放：设计一个"多轮交互式解析"流程，让大模型自我检查和完善输出。→ 第一轮：提取所有因子名称；第二轮：逐一提取每个因子的公式、参数、方向；第三轮：对照原始文本检查是否有遗漏或矛盾；第四轮：输出最终JSON。每轮都可以用上一轮的答案作为约束。
