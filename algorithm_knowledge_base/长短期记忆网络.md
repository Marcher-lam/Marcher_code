# 长短期记忆网络 学习文档

## 1. 算法基础认知
解决RNN梯度消失的改进结构，通过门控机制控制信息流。

## 2. 核心原理
输入门、遗忘门、输出门协同工作：$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$

## 3. 数学公式
遗忘门：$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$
输入门：$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$
细胞状态：$c_t = f_t * c_{t-1} + i_t * 	ilde{c}_t$

## 4. 训练过程
与RNN类似，但门控机制更复杂。

## 5. 应用场景
- 机器翻译
- 文本摘要
- 语音识别

## 6. 优缺点
优点：捕捉长期依赖；缺点：参数多、计算慢

## 8. 手工实现
```python
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

class LSTMScratch:
    def __init__(self, input_size, hidden_size):
        self.input_size = input_size
        self.hidden_size = hidden_size
        # 门控参数初始化
        self.W_f = np.random.randn(input_size + hidden_size, hidden_size) * 0.01
        self.W_i = np.random.randn(input_size + hidden_size, hidden_size) * 0.01
        self.W_c = np.random.randn(input_size + hidden_size, hidden_size) * 0.01
        self.W_o = np.random.randn(input_size + hidden_size, hidden_size) * 0.01
    
    def forward(self, X):
        T = X.shape[1]
        h = np.zeros((1, self.hidden_size))
        c = np.zeros((1, self.hidden_size))
        
        for t in range(T):
            x_t = X[:, t, :]
            concat = np.concatenate([x_t, h], axis=1)
            
            f_t = sigmoid(concat @ self.W_f)
            i_t = sigmoid(concat @ self.W_i)
            c_tilde = np.tanh(concat @ self.W_c)
            o_t = sigmoid(concat @ self.W_o)
            
            c = f_t * c + i_t * c_tilde
            h = o_t * np.tanh(c)
        
        return h
```
