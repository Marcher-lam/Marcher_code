# 自编码器学习文档

## 1. 算法基础认知

自编码器（Autoencoder, AE）是一种无监督学习的神经网络，其目标是学习数据的压缩表示。自编码器通过编码器（Encoder）将输入数据映射到一个低维的潜在空间，然后通过解码器（Decoder）从这个潜在表示重建原始输入。这种"自编码"的过程使得网络能够学习到数据的关键特征。

自编码器的核心思想类似于数据压缩：找到一个高效的数据表示。自编码器不需要人工标注的标签，因为它使用的是重建损失（Reconstruction Loss）——衡量输出与输入的差异。这种自监督的特性使得自编码器在特征学习、异常检测、数据降维等任务中有广泛应用。

### 1.1 自编码器的类型

自编码器有多种变体：

1. **基础自编码器（Basic AE）**：最简单的编码器-解码器结构
2. **去噪自编码器（Denoising AE, DAE）**：输入添加噪声，学习去噪
3. **稀疏自编码器（Sparse AE）**：对隐藏层添加稀疏约束
4. **变分自编码器（Variational AE, VAE）**：学习潜在变量的分布
5. **卷积自编码器（Convolutional AE）**：用于图像
6. **序列到序列自编码器**：用于序列数据

### 1.2 应用场景

1. **特征提取**：学习数据的紧凑表示
2. **数据降维**：将高维数据映射到低维空间
3. **异常检测**：异常点的重建误差大
4. **图像去噪**：去除图像噪声
5. **生成模型**：从潜在空间采样生成新数据

## 2. 核心原理

### 2.1 基础自编码器

自编码器由编码器和解码器组成：

**编码器**：$\mathbf{z} = f(\mathbf{x})$

**解码器**：$\hat{\mathbf{x}} = g(\mathbf{z})$

**损失函数**：$L = \|\mathbf{x} - \hat{\mathbf{x}}\|^2$（均方误差）

或者使用交叉熵：
$$L = -\sum_{i} x_i \log(\hat{x}_i) + (1-x_i) \log(1-\hat{x}_i)$$

### 2.2 变分自编码器（VAE）

VAE是一种生成模型，它学习潜在变量的分布：

**编码器**：$q(\mathbf{z}|\mathbf{x}) = \mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\sigma}^2)$

**解码器**：$p(\mathbf{x}|\mathbf{z})$

**损失函数（ELBO）**：
$$L_{ELBO} = \mathbb{E}_{q(\mathbf{z}|\mathbf{x})}[\log p(\mathbf{x}|\mathbf{z})] - D_{KL}(q(\mathbf{z}|\mathbf{x}) \| p(\mathbf{z}))$$

KL散度项鼓励潜在分布接近标准正态分布：
$$D_{KL} = -\frac{1}{2}\sum_{j=1}^{J}(1 + \log(\sigma_j^2) - \mu_j^2 - \sigma_j^2)$$

### 2.3 去噪自编码器

去噪自编码器的目标是学习从损坏的输入恢复原始输入：

$$\hat{\mathbf{x}} = g(f(\tilde{\mathbf{x}}))$$

其中 $\tilde{\mathbf{x}}$ 是添加噪声后的输入：
- 高斯噪声：$\tilde{\mathbf{x}} = \mathbf{x} + \epsilon, \epsilon \sim \mathcal{N}(0, \sigma^2)$
- Mask噪声：随机将部分输入置为0
- 椒盐噪声：随机将部分输入替换为极值

## 3. 数学推导

### 3.1 潜在空间维度

设输入维度为 $d_{in}$，潜在空间维度为 $d_{latent}$：

- $d_{latent} < d_{in}$：欠完备自编码器（Undercomplete）- 强制学习压缩
- $d_{latent} = d_{in}$：完全自编码器 - 可能只是复制
- $d_{latent} > d_{in}$：过完备自编码器（Overcomplete）- 需要正则化

### 3.2 VAE的重参数化技巧

VAE中从分布采样需要反向传播，使用重参数化技巧：

$$\mathbf{z} = \boldsymbol{\mu} + \boldsymbol{\sigma} \odot \boldsymbol{\epsilon}$$
其中 $\boldsymbol{\epsilon} \sim \mathcal{N}(0, \mathbf{I})$

### 3.3 信息论视角

自编码器可以看作最大化输入和输出之间的互信息：
$$I(\mathbf{x}; \hat{\mathbf{x}}) = \sum \mathbf{x},\hat{\mathbf{x}} P(\mathbf{x},\hat{\mathbf{x}}) \log \frac{P(\hat{\mathbf{x}}|\mathbf{x})}{P(\hat{\mathbf{x}})}$$

### 4.1 基础自编码器

```python
import torch
import torch.nn as nn


class Autoencoder(nn.Module):
    """基础自编码器"""
    def __init__(self, input_dim, hidden_dim, latent_dim):
        super(Autoencoder, self).__init__()
        
        # 编码器
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, latent_dim),
            nn.ReLU()
        )
        
        # 解码器
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, input_dim),
            nn.Sigmoid()  # 输出在[0,1]
        )
    
    def forward(self, x):
        z = self.encoder(x)
        x_recon = self.decoder(z)
        return x_recon, z
    
    def encode(self, x):
        return self.encoder(x)
    
    def decode(self, z):
        return self.decoder(z)


class ConvAutoencoder(nn.Module):
    """卷积自编码器（用于图像）"""
    def __init__(self, in_channels=3):
        super(ConvAutoencoder, self).__init__()
        
        # 编码器
        self.encoder = nn.Sequential(
            # 编码器通过卷积和池化减小空间维度，同时增加通道数
            nn.Conv2d(in_channels, 64, kernel_size=3, stride=1, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 64 -> 32
            
            nn.Conv2d(64, 128, kernel_size=3, stride=1, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 32 -> 16
            
            nn.Conv2d(128, 256, kernel_size=3, stride=1, padding=1),
            nn.ReLU(),
            nn.AdaptiveAvgPool2d((1, 1))  # 全局池化到1x1
        )
        
        # 解码器
        self.decoder = nn.Sequential(
            nn.ConvTranspose2d(256, 128, kernel_size=3, stride=1, padding=1),
            nn.ReLU(),
            nn.Upsample(scale_factor=2),  # 1 -> 2
            
            nn.ConvTranspose2d(128, 64, kernel_size=3, stride=1, padding=1),
            nn.ReLU(),
            nn.Upsample(scale_factor=2),  # 2 -> 4
            
            nn.ConvTranspose2d(64, in_channels, kernel_size=3, stride=1, padding=1),
            nn.Sigmoid()
        )
    
    def forward(self, x):
        z = self.encoder(x)
        x_recon = self.decoder(z)
        return x_recon, z


def train_ae():
    """训练自编码器"""
    # 数据
    torch.manual_seed(42)
    x_train = torch.randn(1000, 784)  # MNIST风格的28x28
    
    # 模型
    model = Autoencoder(input_dim=784, hidden_dim=256, latent_dim=64)
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
    criterion = nn.MSELoss()
    
    # 训练
    model.train()
    for epoch in range(100):
        optimizer.zero_grad()
        
        x_recon, z = model(x_train)
        loss = criterion(x_recon, x_train)
        
        loss.backward()
        optimizer.step()
        
        if (epoch + 1) % 10 == 0:
            print(f"Epoch {epoch+1}, Loss: {loss.item():.4f}")
    
    return model
```

### 4.2 变分自编码器（VAE）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class VAE(nn.Module):
    """变分自编码器"""
    def __init__(self, input_dim, hidden_dim, latent_dim):
        super(VAE, self).__init__()
        
        self.latent_dim = latent_dim
        
        # 编码器：输出均值和log方���
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU()
        )
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        
        # 解码器
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, input_dim),
            nn.Sigmoid()
        )
    
    def encode(self, x):
        h = self.encoder(x)
        mu = self.fc_mu(h)
        logvar = self.fc_logvar(h)
        return mu, logvar
    
    def decode(self, z):
        return self.decoder(z)
    
    def reparameterize(self, mu, logvar):
        """重参数化"""
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std
    
    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        x_recon = self.decode(z)
        return x_recon, mu, logvar
    
    def loss_function(self, x_recon, x, mu, logvar, beta=1.0):
        """
        VAE损失函数：重建 + beta * KL
        
        Parameters:
            x_recon: 重建的输入
            x: 原始输入
            mu: 均值
            logvar: log方差
            beta: KL权重
        """
        # 重建损失（交叉熵）
        recon_loss = F.binary_cross_entropy(x_recon, x, reduction='sum')
        
        # KL散度
        kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
        
        # 总损失
        loss = recon_loss + beta * kl_loss
        
        return loss, recon_loss, kl_loss


class ConditionalVAE(nn.Module):
    """条件VAE"""
    def __init__(self, input_dim, hidden_dim, latent_dim, num_classes):
        super(ConditionalVAE, self).__init__()
        
        self.latent_dim = latent_dim
        
        # 编码器（包含条件）
        self.encoder = nn.Sequential(
            nn.Linear(input_dim + num_classes, hidden_dim),
            nn.ReLU()
        )
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        
        # 解码器（包含条件）
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim + num_classes, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, input_dim),
            nn.Sigmoid()
        )
    
    def encode(self, x, c):
        """编码"""
        h = self.encoder(torch.cat([x, c], dim=-1))
        return self.fc_mu(h), self.fc_logvar(h)
    
    def decode(self, z, c):
        """解码"""
        return self.decoder(torch.cat([z, c], dim=-1))
    
    def forward(self, x, c):
        """前向"""
        mu, logvar = self.encode(x, c)
        z = self.reparameterize(mu, logvar)
        x_recon = self.decode(z, c)
        return x_recon, mu, logvar
    
    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std


class BetaVAE(nn.Module):
    """Beta-VAE（解开潜在表示）"""
    def __init__(self, input_dim, hidden_dim, latent_dim, beta=1.0):
        super(BetaVAE, self).__init__()
        self.beta = beta
        
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, input_dim),
            nn.Sigmoid()
        )
    
    def encode(self, x):
        h = self.encoder(x)
        return self.fc_mu(h), self.fc_logvar(h)
    
    def decode(self, z):
        return self.decoder(z)
    
    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar
    
    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std
    
    def loss_function(self, x_recon, x, mu, logvar):
        """Beta-VAE损失"""
        recon = F.binary_cross_entropy(x_recon, x, reduction='sum')
        
        # KL权重是beta
        kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
        
        # 总损失
        loss = recon + self.beta * kl
        
        return loss
```

### 4.3 去噪自编码器

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class DenoisingAutoencoder(nn.Module):
    """去噪自编码器"""
    def __init__(self, input_dim, hidden_dim, latent_dim):
        super(DenoisingAutoencoder, self).__init__()
        
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, latent_dim),
            nn.ReLU()
        )
        
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, input_dim),
            nn.Sigmoid()
        )
    
    def forward(self, x):
        z = self.encode(x)
        return self.decode(z)
    
    def encode(self, x):
        return self.encoder(x)
    
    def decode(self, z):
        return self.decoder(z)


def add_noise(x, noise_type='gaussian', noise_level=0.3):
    """添加噪声"""
    if noise_type == 'gaussian':
        noise = torch.randn_like(x) * noise_level
        x_noisy = x + noise
    elif noise_type == 'mask':
        # 随机mask
        mask = torch.rand_like(x) > noise_level
        x_noisy = x * mask.float()
    elif noise_type == 'salt_pepper':
        # 椒盐噪声
        mask = torch.rand_like(x)
        x_noisy = torch.where(mask < noise_level/2, torch.zeros_like(x), 
                        torch.where(mask < noise_level, torch.ones_like(x), x))
    else:
        x_noisy = x
    
    return x_noisy


def train_denoising_ae():
    """训练去噪自编码器"""
    # 数据
    x_train = torch.randn(1000, 784)
    
    # 模型
    model = DenoisingAutoencoder(784, 256, 64)
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
    criterion = nn.MSELoss()
    
    model.train()
    for epoch in range(50):
        optimizer.zero_grad()
        
        # 添加噪声
        x_noisy = add_noise(x_train, 'gaussian', 0.3)
        
        # 重建（从噪声输入）
        x_recon = model(x_noisy)
        
        # 损失：对原始输入的重建
        loss = criterion(x_recon, x_train)
        
        loss.backward()
        optimizer.step()
        
        if (epoch + 1) % 10 == 0:
            print(f"Epoch {epoch+1}, Loss: {loss.item():.4f}")
    
    return model
```
