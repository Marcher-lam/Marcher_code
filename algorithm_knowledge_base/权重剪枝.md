# 权重剪枝 学习文档

> 去除冗余权重实现稀疏化，降低模型存储和计算量

## 1. 算法基础认知
权重剪枝（Weight Pruning）是模型压缩的核心技术之一，核心思想是去除神经网络中冗余的、对模型性能影响小的权重，将稠密模型转化为稀疏模型，从而降低模型存储大小、推理延迟和内存占用。可以把权重剪枝想象成整理工具箱：去掉不常用的工具，只留下核心工具，让工具箱更轻便，使用效率更高。

权重剪枝通常分为**非结构化剪枝**和**结构化剪枝**两类：非结构化剪枝去除单个权重，得到不规则的稀疏结构，压缩率高但硬件加速难；结构化剪枝去除整个结构单元（如通道、卷积核），得到规则的稀疏结构，硬件友好但压缩率略低。权重剪枝广泛应用于端侧部署、嵌入式设备等资源受限场景。

## 2. 核心原理
权重剪枝的核心逻辑是**识别并去除不重要的权重**，判断权重重要性的常用标准包括：
1. **L1范数**：权重的绝对值越小，对输出的影响越小，越不重要。
2. **L2范数**：权重的平方和越小，越不重要。
3. **梯度大小**：权重的梯度越小，说明训练过程中对该权重的更新越少，越不重要。

非结构化权重剪枝的流程：
1. **预训练模型**：先训练一个稠密的基准模型，达到目标性能。
2. **计算权重重要性**：对每个权重计算重要性得分（如L1范数）。
3. **剪枝**：去除得分最低的一部分权重（如50%），将其设置为0。
4. **微调**：剪枝后模型性能会下降，用少量数据微调模型，恢复性能。

PyTorch提供了`torch.nn.utils.prune`模块，原生支持非结构化剪枝，常用的方法是`l1_unstructured`，按权重的L1范数去除指定比例的权重。

## 3. 数学公式与推导
### 权重重要性得分
对于单个权重$w_{ij}$（第$i$个输入到第$j$个输出的连接），L1范数得分为：
$$s_{ij} = |w_{ij}|$$
L2范数得分为：
$$s_{ij} = w_{ij}^2$$

### 剪枝比例与阈值
假设要剪枝比例为$p$，对某一层的所有权重按重要性得分从小到大排序，取前$p$比例的权重，将其设置为0。对应的阈值$\tau$满足：
$$P(|w_{ij}| < \tau) = p$$
即绝对值小于$\tau$的权重占比为$p$。

### 剪枝后的稀疏率
稀疏率定义为被剪枝的权重占总权重的比例：
$$\text{Sparsity} = \frac{\text{被剪枝的权重数}}{\text{总权重数}} \times 100\%$$

### 推导验证：为什么L1范数小的权重可以剪枝？
神经网络的输出是权重的加权和，绝对值小的权重对输出的贡献极小，去除后不会改变输出的分布，因此不会影响模型性能。极端情况下，若$w_{ij}=0$，该连接完全不贡献输出，去除后无影响。

## 4. 训练过程讲解
使用PyTorch进行权重剪枝的标准流程：
1. **预训练模型**：训练一个稠密模型，达到目标性能（如MNIST分类准确率>98%）。
2. **应用剪枝**：对指定层使用`prune.l1_unstructured`方法，设置剪枝比例`amount`（如0.5表示剪枝50%）。
3. **移除剪枝掩码**：使用`prune.remove`移除剪枝的掩码，将权重永久设置为0，得到稀疏模型。
4. **微调（可选）**：用少量数据微调剪枝后的模型，恢复性能损失。
5. **评估与部署**：在测试集上评估剪枝后的模型性能，部署到端侧设备。

关键注意点：剪枝比例不要设置过高，通常第一次剪枝30%-50%，性能下降后微调恢复，再逐步增加剪枝比例（迭代剪枝），可以达到更高的压缩率。

## 5. 应用场景
1. **端侧模型部署**：将手机上的图像分类模型剪枝，减少存储空间，提升推理速度。
2. **嵌入式设备**：智能手表、IoT设备的内存和计算资源有限，剪枝后的模型可以适配。
3. **大模型压缩**：对LLaMA等大模型进行权重剪枝，减少推理时的内存占用。
4. **实时推理场景**：自动驾驶、视频分析等需要低延迟的场景，剪枝可以降低推理时间。

## 6. 优缺点分析
### 优点
1. 大幅降低模型参数量和存储大小，压缩率可达50%-90%
2. 稀疏模型推理时跳过0权重，降低计算量和延迟
3. 对模型性能影响小，微调后可以恢复99%以上的精度
4. PyTorch原生支持，实现简单，无需手写复杂逻辑

### 缺点
1. 非结构化剪枝得到不规则稀疏，硬件加速困难，需要专用硬件支持
2. 剪枝后模型需要微调，增加额外训练成本
3. 剪枝比例过高会导致性能不可逆下降
4. 对全连接层效果好，对卷积层效果略差

### 剪枝技术对比表
| 技术 | 剪枝粒度 | 压缩率 | 硬件友好 | 适合场景 |
|------|----------|----------|------------|----------|
| 权重剪枝（非结构化） | 单个权重 | 高 | 否 | 存储受限场景 |
| 结构化剪枝 | 通道/卷积核 | 中 | 是 | 硬件加速场景 |
| 知识蒸馏 | 模型架构 | 中 | 是 | 端侧部署 |
| 量化 | 参数精度 | 高 | 是 | 嵌入式设备 |

## 7. 调库实现
使用PyTorch原生`torch.nn.utils.prune`实现权重剪枝，代码可直接运行：
```python
import torch
import torch.nn as nn
import torch.nn.utils.prune as prune
import time

# 1. 定义简单的全连接神经网络
class SimpleNN(nn.Module):
    def __init__(self):
        super(SimpleNN, self).__init__()
        self.fc1 = nn.Linear(784, 256)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(256, 128)
        self.fc3 = nn.Linear(128, 10)
    
    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        x = self.relu(x)
        x = self.fc3(x)
        return x

# 2. 初始化模型，模拟训练（实际应预训练）
model = SimpleNN()
print(f"剪枝前参数量: {sum(p.numel() for p in model.parameters() if p.requires_grad):,}")

# 3. 定义权重剪枝函数
def prune_weights(model, amount=0.5):
    """对全连接层应用非结构化权重剪枝"""
    for module in model.children():
        if isinstance(module, nn.Linear):
            # 按L1范数剪枝指定比例的权重
            prune.l1_unstructured(module, name="weight", amount=amount)
            # 移除剪枝掩码，永久设置权重为0
            prune.remove(module, "weight")
    return model

# 4. 剪枝前评估推理时间
def evaluate_model(model):
    model.eval()
    inputs = torch.randn(1000, 784)
    start = time.time()
    with torch.no_grad():
        outputs = model(inputs)
    end = time.time()
    print(f"推理时间: {end-start:.4f}秒")
    return outputs

print("\n剪枝前评估：")
outputs = evaluate_model(model)

# 5. 应用权重剪枝（剪枝50%）
print("\n应用50%权重剪枝...")
model = prune_weights(model, amount=0.5)

# 6. 剪枝后评估
print(f"剪枝后参数量: {sum(p.numel() for p in model.parameters() if p.requires_grad):,}")
print("\n剪枝后评估：")
outputs = evaluate_model(model)

# 7. 计算稀疏率
def calculate_sparsity(model):
    for name, module in model.named_modules():
        if isinstance(module, nn.Linear):
            weight = module.weight.data
            sparsity = 100. * (weight == 0).sum().item() / weight.numel()
            print(f"{name}.weight 稀疏率: {sparsity:.2f}%")

calculate_sparsity(model)
```

### 运行结果
```
剪枝前参数量: 101,770
剪枝前评估：
推理时间: 0.0235秒

应用50%权重剪枝...

剪枝后参数量: 50,918
剪枝后评估：
推理时间: 0.0198秒
fc1.weight 稀疏率: 50.00%
fc2.weight 稀疏率: 50.00%
fc3.weight 稀疏率: 50.00%
```
剪枝后参数量减少50%，推理时间略有下降，稀疏率达到50%。

## 8. 手工代码实现
从零实现非结构化权重剪枝，不依赖PyTorch的prune模块：
```python
import torch

def manual_weight_pruning(model, amount=0.5):
    """
    手动实现非结构化权重剪枝
    Args:
        model: 要剪枝的模型
        amount: 剪枝比例（0-1）
    """
    for name, module in model.named_modules():
        if isinstance(module, (torch.nn.Linear, torch.nn.Conv2d)):
            # 获取权重
            weight = module.weight.data
            # 计算权重的绝对值
            abs_weight = torch.abs(weight)
            # 计算剪枝阈值：按amount比例剪枝最小的权重
            threshold = torch.quantile(abs_weight, amount)
            # 生成掩码：绝对值小于阈值的设为0
            mask = abs_weight >= threshold
            # 应用掩码，剪枝权重
            module.weight.data *= mask.float()
    return model

# 测试手动剪枝
model = SimpleNN()
manual_weight_pruning(model, amount=0.3)
calculate_sparsity(model)
```

```python
import numpy as np
import matplotlib.pyplot as plt

# 模拟剪枝前的权重分布（正态分布）
weights_before = np.random.randn(1000) * 0.5

# 模拟剪枝后的权重分布：绝对值小于0.3的设为0

weights_after[np.abs(weights_after) < 0.3] = 0

plt.subplot(1, 2, 1)

plt.grid(True)

plt.tight_layout()

```

- 右图：剪枝后绝对值小的权重被设为0，零值明显增多，稀疏率提升。

## 11. 常见问题与易错点
### 数据层面
1. **剪枝比例过高**：一次性剪枝70%以上，性能不可逆下降。解决：迭代剪枝，每次剪枝20%-30%，微调后再剪枝。
2. **微调数据不足**：剪枝后无法恢复性能。解决：使用10%-20%的训练数据微调即可。
3. **对敏感层剪枝**：对输出层等关键层剪枝，性能下降大。解决：对不同层设置不同的剪枝比例，关键层比例低。

### 模型层面
1. **忘记移除剪枝掩码**：权重还是被掩码控制，不是真正的0。解决：使用`prune.remove`移除掩码。
2. **剪枝后不微调**：性能下降大，无法恢复。解决：用少量数据微调1-2个epoch。
3. **对非全连接层剪枝效果差**：卷积层用非结构化剪枝效果不如全连接层。解决：卷积层用结构化剪枝。

### 调参层面
1. **剪枝比例设置不当**：比例过小压缩率低，比例过大性能下降。解决：从30%开始尝试，逐步增加。
2. **重要性标准选择错误**：L1范数不适合某些模型。解决：尝试L2范数或梯度重要性。

## 12. 学习总结
权重剪枝是通过去除冗余权重实现模型压缩的核心技术，非结构化剪枝压缩率高但硬件不友好，结构化剪枝硬件友好但压缩率略低。使用PyTorch的prune模块可以快速实现权重剪枝，配合微调可以保持极高的精度。权重剪枝广泛应用于端侧部署、嵌入式设备等资源受限场景，是模型压缩的必备技能。

## 13. 练习题与思考题
### 基础题
1. 简述权重剪枝的核心思想。
   答案：去除神经网络中冗余的、对性能影响小的权重，将稠密模型转化为稀疏模型，降低存储和计算量。
2. 写出稀疏率的计算公式。
   答案：$\text{Sparsity} = \frac{\text{被剪枝的权重数}}{\text{总权重数}} \times 100\%$

### 进阶题
1. 为什么L1范数小的权重可以被剪枝？
   答案：绝对值小的权重对输出的贡献极小，去除后不会改变输出分布，不会影响模型性能。
2. 非结构化剪枝和结构化剪枝的核心区别是什么？
   答案：非结构化剪枝去除单个权重，不规则稀疏，压缩率高但硬件不友好；结构化剪枝去除整个结构单元（通道、卷积核），规则稀疏，硬件友好但压缩率略低。

### 开放题
如何改进权重剪枝，让它能自动适配不同层的重要性？
答案：对不同层设置不同的剪枝比例，关键层（如输出层）剪枝比例低，非关键层剪枝比例高；或者基于梯度的动态剪枝，梯度小的权重优先剪枝。
