# 夏普比率与风险指标体系 学习文档

> 用量化指标衡量"每承担一分风险赚了多少收益"——量化策略的终极评分卡。
> 来源线索：本节内容根据原书中关于量化交易策略分类（第1章1.4.2节"资产配置量化交易策略"及贯穿全书）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：夏普比率是衡量单位风险所获超额收益的核心指标，与最大回撤、Calmar比率、波动率共同构成量化策略的风险评估体系。

**直觉类比**：成绩单——年化收益率是"总分"，夏普比率是"绩点"(考虑了你选课难度后的评价)。A学生总分90但选的全是水课(低风险)，B学生总分92但选的都是硬课(高风险)，夏普比率可能认为A比B更优秀。

**历史背景**：威廉·夏普(William F. Sharpe)在1966年提出夏普比率，1990年与马科维茨、默顿共同获得诺贝尔经济学奖。这个指标源于现代投资组合理论中的资本市场线(CML)，至今仍是量化投资领域使用最广泛的风险调整收益指标。

**算法定位**：风险评估 / 策略评价 / 绩效归因。

**前置知识**：收益率计算、标准差概念、无风险利率概念。

## 2. 核心原理

**夏普比率本质**：衡量每单位波动率(风险)换来的超额收益。
$$
\text{Sharpe} = \frac{\bar{R} - R_f}{\sigma_R}
$$
分子是平均超额收益，分母是收益波动率。

**重要变体**：
- **年化夏普**：日收益夏普 × √252、月收益夏普 × √12
- **无风险利率**：中国常用一年期国债收益率(约2-3%)
- **信息比率(IR)**：主动收益/跟踪误差，衡量择时/选股能力

**风险指标体系全景**：

| 指标 | 公式/含义 | 关注什么 |
|------|----------|----------|
| 夏普比率 | (收益-无风险)/σ | 单位风险的超额回报 |
| 最大回撤(MDD) | max(1 - NAV(t)/Peak(t)) | 最坏情况下的亏损幅度 |
| Calmar比率 | 年化收益/最大回撤 | 一分回撤换来的收益 |
| 波动率 | std(收益) | 收益的不确定性 |
| VaR(95%) | 5%最差情景的损失 | 日常风险的量化边界 |
| CVaR/Expected Shortfall | 超出VaR的平均损失 | 尾部风险(黑天鹅) |
| 索提诺比率 | (收益-无风险)/下行σ | 只关注"不好的波动" |
| 胜率 | 盈利交易/总交易 | 策略的稳定性 |

## 3. 数学公式与推导

### 3.1 夏普比率
$$
S = \frac{\mathbb{E}[R - R_f]}{\sqrt{\text{Var}[R]}}
$$

年化转换：
$$
S_{\text{annual}} = S_{\text{daily}} \times \sqrt{252}
$$

### 3.2 最大回撤
$$
\text{MDD}_T = \max_{t \in [0,T]} \left( \frac{\max_{s \in [0,t]} \text{NAV}(s) - \text{NAV}(t)}{\max_{s \in [0,t]} \text{NAV}(s)} \right)
$$

### 3.3 Calmar比率
$$
\text{Calmar} = \frac{\text{AnnualReturn}}{\text{MDD}}
$$

### 3.4 索提诺比率
$$
\text{Sortino} = \frac{\mathbb{E}[R - R_f]}{\sqrt{\frac{1}{N}\sum \min(R_i - R_f, 0)^2}}
$$
分母只包含下行偏差(低于R_f的部分)。

## 4. 计算过程讲解

```python
"""
风险指标体系完整计算
"""
import numpy as np
import pandas as pd

def calculate_risk_metrics(returns, rf_annual=0.03):
    """
    returns: 日收益率序列
    rf_annual: 年化无风险利率
    """
    rf_daily = rf_annual / 252
    excess = returns - rf_daily

    # 年化收益(复利)
    total_return = (1 + returns).prod()
    n_years = len(returns) / 252
    annual_return = total_return ** (1 / n_years) - 1

    # 波动率
    annual_vol = returns.std() * np.sqrt(252)

    # 夏普比率
    sharpe = (excess.mean() / returns.std()) * np.sqrt(252) if returns.std() > 0 else 0

    # 最大回撤
    cum = (1 + returns).cumprod()
    running_max = cum.cummax()
    drawdown = (cum - running_max) / running_max
    max_dd = drawdown.min()

    # Calmar比率
    calmar = annual_return / abs(max_dd) if max_dd != 0 else 0

    # 索提诺比率
    downside = returns[returns < rf_daily]
    downside_std = downside.std() * np.sqrt(252) if len(downside) > 0 else 0.0001
    sortino = (annual_return - rf_annual) / downside_std

    # 胜率
    win_rate = (returns > 0).mean()

    # VaR (95%)
    var_95 = np.percentile(returns, 5)

    # CVaR
    cvar_95 = returns[returns <= var_95].mean()

    return {
        '年化收益': annual_return,
        '年化波动率': annual_vol,
        '夏普比率': sharpe,
        '最大回撤': max_dd,
        'Calmar比率': calmar,
        '索提诺比率': sortino,
        '胜率': win_rate,
        'VaR(95%)': var_95,
        'CVaR(95%)': cvar_95,
    }


# 测试
np.random.seed(42)
strategy_ret = np.random.randn(1000) * 0.015 + 0.001    # 策略日收益
benchmark_ret = np.random.randn(1000) * 0.012 + 0.0005  # 基准日收益

strategy_metrics = calculate_risk_metrics(strategy_ret)
benchmark_metrics = calculate_risk_metrics(benchmark_ret)

print("策略 vs 基准 风险指标对比:")
for key in strategy_metrics:
    s_val = strategy_metrics[key]
    b_val = benchmark_metrics[key]
    better = '✓' if (key in ['最大回撤', '年化波动率', 'VaR(95%)', 'CVaR(95%)'] and s_val > b_val) or \
              (key not in ['最大回撤', '年化波动率', 'VaR(95%)', 'CVaR(95%)'] and s_val > b_val) else ''
    print(f"  {key}: 策略={s_val:.4f}, 基准={b_val:.4f} {better}")
```

## 5. 应用场景

- 策略选择：比较多个备选策略，选夏普最高的
- 杠杆决策：高夏普策略可以加杠杆放大收益
- 风险监控：最大回撤超阈值→暂停策略
- 投资者沟通：用统一指标向LP/Fund of Funds汇报

## 6. 优缺点分析

**夏普比率的优点**：简单直观、公认标准、便于比较
**夏普比率的缺点**：假设收益正态分布(实际金融收益肥尾)、对上行波动和下行波动不加区分、数据时长敏感(牛市中的夏普虚高)

## 7-14. 综合章节

**易错点**：
- 年化错误：月夏普不能直接 ×√252(月收益独立时才成立)
- 向上波动惩罚：高收益的正波动同样增加分母σ，降低夏普
- 短期夏普不可靠：至少需要3年以上日数据才能得出稳定夏普估计
- 忽略尾部风险：夏普不能识别策略的"隐藏炸弹"(小概率巨亏)

**学习路径**：均值-方差理论→夏普比率→现代投资组合理论→风险管理体系

**练习题**：
- 基础：A策略年化收益=15%、波动率=10%；B策略年化=20%、波动率=20%。RF=3%。谁夏普更高？→ A=12%/10%=1.2, B=17%/20%=0.85。A更优。
- 进阶：为什么"夏普比率最高的策略不是最优投资选择"？→ 夏普只衡量单位风险的超额收益，不考虑策略容量(规模)、流动性、最大回撤容忍度、以及投资者效用函数的非线性。真正的最优策略需要结合这些因素。
