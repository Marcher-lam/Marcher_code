# 神经风格迁移 学习文档

> 将一张图像的内容与另一张图像的艺术风格融合。

> 来源线索：本节内容根据原书中关于"神经风格迁移"的相关章节（第6章）整理、扩展与教学化改写。

---

## 1. 算法基础认知

**一句话定义：** 神经风格迁移通过分别提取内容图像的内容特征和风格图像的 Gram 矩阵风格特征，优化生成图像使两者同时匹配，实现艺术风格融合。

**直觉类比：** 想象用梵高的笔触重新画一张照片——保留照片的内容（建筑、人物），但用梵高的色彩和纹理。风格迁移就是让 CNN 分别理解"画了什么"（内容）和"怎么画的"（风格），然后把两者融合。

**历史背景：** 神经风格迁移由 Gatys 等人于 2015 年提出（论文 "A Neural Algorithm of Artistic Style"），引发了 AI 艺术热潮。后续发展出快速风格迁移（Johnson et al., 2016）、AdaIN 风格迁移等改进。

**算法定位：** 计算机视觉、图像风格化、AI 艺术。

**前置知识：** CNN、Gram 矩阵、梯度下降、VGG 网络、PyTorch。

---

## 2. 核心原理

### 核心思想

预训练 CNN 的不同层编码了不同信息：
- **浅层特征图**：纹理、颜色（风格信息）
- **深层特征图**：物体类别、布局（内容信息）

**Gram 矩阵**可以提取风格信息（特征之间的相关性），而内容特征直接用特征图表示。

### 损失函数

$$\mathcal{L}_{total} = \alpha \mathcal{L}_{content} + \beta \mathcal{L}_{style}$$

- $\mathcal{L}_{content}$：生成图像与内容图像在深层特征上的 MSE
- $\mathcal{L}_{style}$：生成图像与风格图像在多层 Gram 矩阵上的 MSE
- $\alpha, \beta$：内容和风格的权重比

### Gram 矩阵

$$G^l = F^l \cdot (F^l)^T$$

其中 $F^l \in \mathbb{R}^{N_l \times M_l}$ 是第 $l$ 层的特征图展平后的矩阵。Gram 矩阵编码了特征之间的共现关系——即"哪些纹理经常一起出现"。

---

## 3. 数学公式

### 内容损失

$$\mathcal{L}_{content} = \sum_{l \in L_c} \|F^l_{gen} - F^l_{content}\|^2$$

### 风格损失

$$\mathcal{L}_{style} = \sum_{l \in L_s} w_l \|G^l_{gen} - G^l_{style}\|^2$$

### 优化

从白噪声或内容图像开始，通过 L-BFGS 或 Adam 优化像素值。

| 超参数 | 推荐范围 | 默认 |

| 内容层 | conv4_2 | conv4_2 |

## 7-8. 代码实现

```python
import torch
import torch.nn as nn
import torchvision.models as models

class StyleTransfer:
    def __init__(self, content_layers=['21'], style_layers=['0','5','10','19','28']):
        self.vgg = models.vgg19(pretrained=True).features.eval()
        self.content_layers = content_layers
        self.style_layers = style_layers
        # 冻结所有参数
        for p in self.vgg.parameters():
            p.requires_grad = False

    def gram_matrix(self, x):
        B, C, H, W = x.shape
        F = x.view(C, H * W)
        return torch.mm(F, F.t()) / (C * H * W)

    def extract_features(self, x):
        features = {}
        for i, layer in enumerate(self.vgg):
            x = layer(x)
            name = str(i)
            if name in self.content_layers:
                features['content_' + name] = x
            if name in self.style_layers:
                features['style_' + name] = self.gram_matrix(x)
        return features

    def transfer(self, content_img, style_img, steps=200, style_weight=1e6):
        generated = content_img.clone().requires_grad_(True)
        optimizer = torch.optim.Adam([generated], lr=0.01)
        content_targets = self.extract_features(content_img)
        style_targets = self.extract_features(style_img)

        for step in range(steps):
            optimizer.zero_grad()
            gen_features = self.extract_features(generated)
            content_loss = sum(
                (gen_features[k] - content_targets[k]).pow(2).mean()
                for k in gen_features if k.startswith('content')
            )
            style_loss = sum(
                (gen_features[k] - style_targets[k]).pow(2).mean()
                for k in gen_features if k.startswith('style')
            )
            loss = content_loss + style_weight * style_loss
            loss.backward()
            optimizer.step()
            if (step+1) % 50 == 0:
                print(f"Step {step+1}: content={content_loss.item():.4f}, style={style_loss.item():.4f}")
        return generated.detach()

# 测试
st = StyleTransfer()
content = torch.randn(1, 3, 224, 224)
style = torch.randn(1, 3, 224, 224)
result = st.transfer(content, style, steps=50)
print(f"风格迁移结果: {result.shape}")
```

## 9-14. 练习与路径

**题1：** Gram 矩阵为什么能表示风格？

**参考答案：** Gram 矩阵 $G_{ij} = \sum_k F_{ik} F_{jk}$ 衡量特征 $i$ 和特征 $j$ 在空间上的共现关系。纹理风格就是"哪些视觉模式经常一起出现"——例如印象派的"短笔触"和"明亮色彩"总是同时出现。Gram 矩阵丢弃了空间位置信息，只保留了特征间的统计关系，恰好对应风格的无位置特性。

### 学习路径
- 前置：CNN、VGG、Gram 矩阵
- 进阶：快速风格迁移（Feed-forward）、AdaIN 风格迁移
- 推荐：Gatys et al., "A Neural Algorithm of Artistic Style" (2015)
