# 分词学习文档

> 分词是将文本分割成词（或子词）序列的过程，是NLP的基础步骤。

## 1. 算法基础认知

### 1.1 什么是分词

分词（Tokenization）将文本分割成模型可处理的基本单元（词、子词、字符）。

### 1.2 分词方法

| 方法 | 说明 | 例子 |
|------|------|------|
| 词级别 | 按空格/标点分割 | hello world |
| 子词级别 | BPE, WordPiece | hel##lo wor##ld |
| 字符级别 | 按字符分割 | h e l l o |

### 1.3 常见分词器

- **BPE (Byte Pair Encoding)**：常用 GPT
- **WordPiece**：常用 BERT
- **SentencePiece**：Google开源

## 2. 调库实现

### 2.1 词级别分词

```python
import nltk
from nltk.tokenize import word_tokenize

text = "Hello, world!"
tokens = word_tokenize(text)
print(tokens)  # ['Hello', ',', 'world', '!']
```

### 2.2 子词级别分词

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("gpt2")
text = "Hello, world!"
tokens = tokenizer.tokenize(text)
print(tokens)  # ['Hello', ',', 'world', '!']
ids = tokenizer.encode(text)
print(ids)  # [15495, 11, 995, 0]
```

### 2.3 中文分词

```python
import jieba

text = "我爱自然语言处理"
words = jieba.lcut(text)
print(words)  # ['我', '爱', '自然语言处理']
```

## 3. BPE算法实现

```python
from collections import Counter

def get_vocab(texts):
    vocab = Counter()
    for text in texts:
        words = text.split()
        for word in words:
            vocab[word] += 1
    return vocab

def get_pairs(vocab):
    pairs = Counter()
    for word, freq in vocab.items():
        symbols = word.split()
        for i in range(len(symbols) - 1):
            pairs[(symbols[i], symbols[i+1])] += freq
    return pairs

def merge_pair(vocab, pair):
    new_vocab = {}
    bigram = ' '.join(pair)
    replacement = ''.join(pair)
    for word, freq in vocab.items():
        new_word = word.replace(bigram, replacement)
        new_vocab[new_word] = freq
    return new_vocab
```

## 4. 优缺点

| 分词方法 | 优点 | 缺点 |
|----------|------|------|
| 词级别 | 简单直观 | OOV问题严重 |
| 子词级别 | OOV友好 | 需要训练 |
| 字符级别 | 无OOV | 序列太长 |

## 5. 学习总结

分词是NLP的第一步，选择合适的分词方法对模型性能至关重要。

## 6. 练习题

**题目**：为什么需要子词分词？

**答案**：子词分词可以处理未登录词（OOV），通过组合已知子词表示新词。
