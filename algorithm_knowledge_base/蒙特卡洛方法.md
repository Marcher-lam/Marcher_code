# 蒙特卡洛方法 学习文档

> 用一句话说明这个算法的核心价值：通过采样完整轨迹来估计价值函数或策略梯度，无需知道环境模型，是强化学习中最基础的免模型学习方法之一，为后续策略梯度、深度强化学习提供了核心采样思想。

## 1. 算法基础认知

蒙特卡洛方法（Monte Carlo Method，MC）是一种基于随机采样的强化学习算法，通过采集完整的状态-动作轨迹，计算累积回报的平均值来估计价值函数或优化策略，全程无需依赖环境的状态转移概率、奖励函数等动力学模型。

**一句话定义**：MC方法通过多次采样完整的回合制轨迹，用实际获得的累积折扣回报的平均值，估计任意状态/状态-动作对的价值，或通过策略梯度直接优化策略参数。

**历史背景**：
- 算法名称源自摩纳哥的蒙特卡洛赌场，1949年物理学家Nicholas Metropolis首次提出"蒙特卡洛方法"概念，用于解决曼哈顿计划中的中子扩散问题。
- 强化学习领域的MC方法由Richard Sutton和Andrew Barto在1988年的《Reinforcement Learning: An Introduction》第一版中正式系统化，成为早期表格型强化学习的核心方法。
- 1959年Arthur Samuel将MC思想用于西洋跳棋学习，实现了首个自我对弈的AI系统，是MC在RL中的早期经典应用。

**蒙特卡洛方法的发展历程（详细版）**：

**起源与早期发展（1940s-1970s）**：
- 1940年代：John von Neumann和Stanislaw Ulam在曼哈顿计划中首次使用随机模拟方法解决中子扩散和核反应堆临界性问题。
- 1949年：Nicholas Metropolis和Stanislaw Ulam发表《The Monte Carlo Method》，正式命名并系统化该方法。
- 1950s-1960s：MC方法被应用于统计物理、计算化学等领域，成为重要的数值计算工具。

**在强化学习中的引入（1970s-1990s）**：
- 1979年：Chris Watkins在博士论文中首次将MC与Q-learning结合，为表格型RL奠定基础。
- 1988年：Sutton的博士论文《Learning to Predict by the Methods of Temporal Differences》对比了MC和TD方法，明确了各自的优劣。
- 1989年：Watkins和Dayan证明Q-learning在特定条件下的收敛性，MC方法被广泛应用于策略评估。
- 1990s：MC成为早期强化学习的主要方法之一，与TD方法共同构成RL的基础。

**现代发展与应用（2000s-至今）**：
- 2013年：DeepMind的DQN结合了MC采样和深度学习，在Atari游戏中取得突破。
- 2017年：Highway Env等环境专门用于MC方法的测试和改进。
- 2020s：MC方法被广泛应用于离线强化学习（Offline RL）、模型基RL（Model-based RL）等前沿领域。

**直觉类比（3-5个）**：
1. **通勤时间估算**：你想知道从家到公司的平均通勤时间，连续记录100次完整的通勤行程（从出家门到进公司），计算100次时间的平均值，就是MC估计的价值。MC方法就是通过这种方式，用多次完整轨迹的平均回报估计状态价值。
2. **咖啡店等待时间**：估算网红咖啡店的平均等待时间，你连续30天记录从排队到拿到咖啡的完整时间，取平均值。不需要知道咖啡师做咖啡的速度（环境模型），只需要实际采样完整流程。
3. **篮球运动员得分**：估算某篮球运动员的平均单场得分，观看他50场比赛的完整录像，记录每场得分取平均。不需要知道他的训练计划、体力变化（隐藏状态），只需要完整比赛的观测。
4. **班级平均身高**：想知道一个班级的平均身高，随机测量30个学生的身高，取平均值。每个学生的测量就是一次"轨迹采样"，平均值就是MC估计的结果。

## 2. 核心原理

MC方法的核心思想是**用实际采样的完整轨迹的平均回报，近似真实的价值函数期望**，完全依赖环境交互数据，不引入任何环境模型的假设。

**工作流程（详细版）**：
1. **初始化**：初始化价值函数 $V(s)$ 或动作价值函数 $Q(s,a)$ 为0或随机值，初始化策略 $\pi(a|s)$（通常为随机均匀策略或ε-贪婪策略）。
2. **轨迹采样**：使用当前策略 $\pi$ 与环境交互，生成完整的轨迹 $\tau = (s_0, a_0, r_1, s_1, a_1, r_2, ..., s_T)$，其中 $s_T$ 是终止状态。
3. **回报计算**：对轨迹中每个时刻 $t$ 的状态 $s_t$，计算从该状态开始的累积折扣回报 $G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + ... + \gamma^{T-t-1} r_T$，其中 $\gamma \in [0,1)$ 是折扣因子。
4. **价值更新**：
   - **首次访问MC（First-visit MC）**：仅使用每个轨迹中第一次访问状态 $s$ 的回报 $G_t$ 来更新 $V(s)$。
   - **每次访问MC（Every-visit MC）**：使用每个轨迹中每次访问状态 $s$ 的回报 $G_t$ 来更新 $V(s)$。
5. **策略改进**：如果是指控制任务，根据更新后的 $Q(s,a)$ 选择贪心策略 $\pi_{new}(s) = \arg\max_a Q(s,a)$，重复步骤2-4直到策略收敛。

**关键概念解释**：
- **轨迹（Trajectory）**：从初始状态到终止状态的完整状态-动作-奖励序列，必须包含明确的终止点，是MC方法的基本数据单元。
- **回报（Return）**：$G_t$ 是从时刻 $t$ 开始的所有未来折扣奖励的总和，反映了状态 $s_t$ 的长期价值。
- **首次访问MC vs 每次访问MC**：
  - 首次访问：每个轨迹中状态 $s$ 只贡献一次回报，方差更小，适用于非马尔可夫环境。
  - 每次访问：每个轨迹中状态 $s$ 每次出现都贡献回报，数据利用率更高，收敛更快，仅适用于马尔可夫环境。
- **自举（Bootstrap）**：MC方法**不使用**自举，完全依赖真实的回报采样，因此估计是无偏的；而TD方法使用下一个状态的估计价值自举，是有偏的。

**ASCII流程图**：
```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ 初始化V/Q/π │     │ 生成完整轨迹τ │     │ 计算所有G_t  │
└──────┬──────┘     └──────┬──────┘     └──────┬──────┘
       │                   │                   │
       └───────────────────┼───────────────────┘

                    └──────┬──────┘

                    │ 策略改进？    │──是─▶ 更新π为贪心策略

```

**与同类算法对比（3-5个）**：
1. **MC vs 时序差分（TD）**：
   - MC需要完整轨迹，TD单步更新
   - MC无偏，TD有偏
   - MC高方差，TD低方差
   - MC仅适用于回合制，TD适用于持续任务
2. **MC vs 动态规划（DP）**：
   - MC免模型，DP需要完整环境模型
   - MC基于采样，DP基于全宽度备份
   - MC适用于大型状态空间，DP仅适用于小型状态空间
3. **MC vs 策略梯度（REINFORCE）**：
   - MC既可以做策略评估也可以做控制，REINFORCE仅用于策略优化
   - MC通常学习价值函数，REINFORCE直接优化策略参数
   - 两者都使用完整轨迹的回报，核心采样逻辑一致
4. **MC vs 重要性采样（Importance Sampling）**：
   - 普通MC是同策略（On-policy），只能评估当前采样的策略
   - 结合重要性采样的MC可以做到异策略（Off-policy），评估任意策略的价值

**工程经验**：
- 对于长轨迹任务，使用增量式更新 $V(s) \leftarrow V(s) + \alpha (G_t - V(s))$，其中 $\alpha = 1/N(s)$，避免存储所有轨迹占用内存。
- 策略梯度任务中，使用基线（Baseline）减法 $G_t' = G_t - V(s_t)$，可以大幅降低回报方差，提升训练稳定性。
- 奖励裁剪（Reward Clipping）：将奖励限制到 $[-1, 1]$ 区间，避免极端奖励导致回报方差过大。

## 3. 数学公式与推导

**完整符号约定表**：
| 符号 | 含义 | 维度/范围 | 单位/说明 |
|------|------|-----------|-----------|
| $\tau$ | 完整轨迹 | $(s_0,a_0,r_1,s_1,...,s_T)$ | 无单位，序列长度 $T$ 是随机变量 |
| $G_t$ | 时刻 $t$ 的累积折扣回报 | $\mathbb{R}$ | 与奖励单位一致，通常奖励为标量 |
| $V^\pi(s)$ | 策略 $\pi$ 下状态 $s$ 的真实价值 | $\mathbb{R}$ | 长期折扣奖励的期望 |
| $Q^\pi(s,a)$ | 策略 $\pi$ 下状态 $s$ 执行动作 $a$ 的真实价值 | $\mathbb{R}$ | 同上 |
| $N(s)$ | 状态 $s$ 的访问次数 | $\mathbb{N}^+$ | 非负整数，采样次数越多越准确 |
| $N(s,a)$ | 状态 $s$ 执行动作 $a$ 的次数 | $\mathbb{N}^+$ | 同上 |
| $\gamma$ | 折扣因子 | $[0,1)$ | 无单位，接近1重视长期奖励，接近0重视短期 |
| $\alpha$ | 学习率 | $(0,1]$ | 无单位，控制更新步长，通常设为 $1/N(s)$ |

**问题形式化**：
对于给定策略 $\pi$，状态价值函数的定义为：
$$V^\pi(s) = \mathbb{E}_\pi \left[ G_t | s_t = s \right] = \mathbb{E}_\pi \left[ \sum_{k=0}^\infty \gamma^k r_{t+k+1} | s_t = s \right]$$
MC方法的目标是通过采样轨迹，用样本均值近似上述期望。

**首次访问MC估计推导（逐步版）**：
1. 根据大数定律，当采样次数 $N \to \infty$ 时，样本均值收敛到真实期望：
   $$V^\pi(s) = \lim_{N\to\infty} \frac{1}{N} \sum_{i=1}^N G_t^{(i)}$$
   其中 $G_t^{(i)}$ 是第 $i$ 次轨迹中状态 $s$ 的首次访问回报。
2. 对于有限采样次数 $N$，MC估计为：
   $$V(s) = \frac{\sum_{i=1}^N G_t^{(i)}}{N}$$
3. 增量式更新推导：设第 $N$ 次采样后 $V_N = \frac{1}{N} \sum_{i=1}^N G_i$，则第 $N+1$ 次更新后：
   $$V_{N+1} = \frac{1}{N+1} \sum_{i=1}^{N+1} G_i = \frac{N V_N + G_{N+1}}{N+1} = V_N + \frac{1}{N+1} (G_{N+1} - V_N)$$
   令 $\alpha = \frac{1}{N+1}$，就得到增量更新公式：
   $$V(s) \leftarrow V(s) + \alpha (G_t - V(s))$$

**每次访问MC估计**：
$$V(s) = \frac{\sum_{\text{所有轨迹}} \sum_{t: s_t=s} G_t}{\text{状态s被访问的总次数}}$$
每次访问MC的增量更新公式与首次访问一致，仅需对所有访问时刻 $t$ 执行更新。

**MC策略梯度推导（REINFORCE基础）**：
1. 策略优化的目标是最大化期望累积回报：
   $$\bar{R}_\theta = \mathbb{E}_{\tau \sim p_\theta(\tau)} \left[ \sum_{t=0}^T \gamma^t r_{t+1} \right] = \mathbb{E}_{\tau \sim p_\theta(\tau)} [R(\tau)]$$
   其中 $p_\theta(\tau) = p(s_0) \prod_{t=0}^{T-1} \pi_\theta(a_t|s_t) p(s_{t+1}|s_t,a_t)$ 是轨迹的概率。
2. 对目标函数求梯度：
   $$
   \begin{align}
   \nabla \bar{R}_\theta &= \nabla \mathbb{E}_{\tau \sim p_\theta(\tau)} [R(\tau)] \\
   &= \nabla \sum_\tau R(\tau) p_\theta(\tau) \\
   &= \sum_\tau R(\tau) \nabla p_\theta(\tau) \\
   &= \sum_\tau R(\tau) p_\theta(\tau) \frac{\nabla p_\theta(\tau)}{p_\theta(\tau)} \\
   &= \sum_\tau R(\tau) p_\theta(\tau) \nabla \log p_\theta(\tau) \\
   &= \mathbb{E}_{\tau \sim p_\theta(\tau)} \left[ R(\tau) \nabla \log p_\theta(\tau) \right]
   \end{align}
   $$
3. 代入轨迹概率的对数梯度：
   $$\log p_\theta(\tau) = \sum_{t=0}^{T-1} \log \pi_\theta(a_t|s_t)$$
   因此梯度可以简化为：
   $$\nabla \bar{R}_\theta = \mathbb{E}_{\tau \sim p_\theta(\tau)} \left[ \sum_{t=0}^{T-1} R(\tau) \nabla \log \pi_\theta(a_t|s_t) \right]$$
4. 用采样轨迹近似期望，得到MC策略梯度估计：
   $$\nabla \bar{R}_\theta \approx \frac{1}{N} \sum_{n=1}^N \sum_{t=0}^{T_n-1} G_t^n \nabla \log \pi_\theta(a_t^n | s_t^n)$$
   其中 $G_t^n$ 是第 $n$ 条轨迹中时刻 $t$ 的回报，$T_n$ 是第 $n$ 条轨迹的长度。

**伪代码（首次访问MC策略评估）**：
```
初始化 V(s) = 0，N(s) = 0 对所有状态s
循环直到收敛：
    生成完整轨迹 τ = (s0,a0,r1,s1,...,sT)
    从后往前计算轨迹中每个时刻的回报 G_t
    遍历轨迹中的每个时刻t：
        如果 这是轨迹中首次访问s_t：
            N(s_t) += 1
            V(s_t) += (G_t - V(s_t)) / N(s_t)
```

**无偏性证明**：
MC估计的期望等于真实价值：
$$
\begin{align}
\mathbb{E}[V(s)] &= \mathbb{E} \left[ \frac{1}{N} \sum_{i=1}^N G_t^{(i)} \right] \\
&= \frac{1}{N} \sum_{i=1}^N \mathbb{E}[G_t^{(i)}] \\
&= \frac{1}{N} \sum_{i=1}^N V^\pi(s) \\
&= V^\pi(s)
\end{align}
$$
因此MC估计是无偏的，仅当采样次数 $N \to \infty$ 时方差为0。

## 4. 训练过程讲解

**数据预处理细节（以典型环境为例）**：
1. **CartPole-v1环境**：
   - 状态：4维向量 $[位置, 速度, 角度, 角速度]$，范围分别为 $[-2.4, 2.4]$、$[-\infty, \infty]$、$[-0.2095, 0.2095]$（弧度）、$[-\infty, \infty]$
   - 预处理：无需归一化（Gym已标准化），离散化可按阈值划分为左/右、正/负等类别，用于表格型MC。
2. **CliffWalking-v0环境**：
   - 状态：0~47的整数（4×12网格的位置），无需预处理。
   - 动作：0~3的整数（上、下、左、右），无需预处理。
3. **Atari游戏（如Pong-v5）**：
   - 状态：210×160×3的RGB图像，预处理步骤：灰度化→裁剪→缩放至84×84→帧堆叠（4帧）→归一化到[0,1]。

**参数初始化表（不同环境推荐值）**：
| 环境 | $\gamma$ | $\alpha$ | 采样回合数 | $\epsilon$（探索率） |
|------|----------|----------|------------|----------------------|
| CartPole-v1 | 0.99 | 0.01 或 $1/N$ | 1000 | 0.1（衰减至0.01） |
| CliffWalking-v0 | 0.9 | 0.1 或 $1/N$ | 5000 | 0.1（衰减至0.05） |
| 简单网格世界 | 0.9 | 0.1 | 1000 | 0.2（衰减至0.01） |

**完整训练流程（以MC策略迭代为例）**：
1. **环境初始化**：创建Gym环境，设置随机种子保证可复现。
2. **参数初始化**：初始化 $Q(s,a)$ 为全0，初始化策略 $\pi$ 为均匀随机策略，$\epsilon=0.1$。
3. **回合循环（外层）**：
   - 重置环境，获取初始状态 $s_0$。
   - **轨迹生成（内层）**：
     - 使用ε-贪婪策略选择动作 $a_t$，执行动作得到 $r_{t+1}, s_{t+1}$。
     - 记录 $(s_t, a_t, r_{t+1})$ 到轨迹列表，直到环境返回 $done=True$。
   - **回报计算**：从轨迹最后一个时刻开始，反向计算 $G_t = r_{t+1} + \gamma G_{t+1}$，存储所有 $G_t$。
   - **价值更新**：遍历轨迹中的每个 $(s_t, a_t, G_t)$，如果是首次访问则更新 $Q(s_t,a_t)$。
   - **策略改进**：对每个状态 $s$，更新 $\pi(s) = \arg\max_a Q(s,a)$（ε-贪婪）。
   - **探索率衰减**：$\epsilon \leftarrow \epsilon \times 0.995$。
4. **收敛判断**：当连续100个回合的平均回报变化小于1，或达到最大回合数时停止训练。

**工程调试技巧**：
- 检查状态访问次数：如果某些状态的 $N(s,a) < 10$，说明探索不足，需增大 $\epsilon$ 或改进探索策略。
- 检查回报方差：如果回报的标准差大于均值的2倍，说明方差过高，需增加采样次数或使用基线减法。
- 保存检查点：每100回合保存一次 $Q$ 表和策略，避免训练中断丢失进度。

**收敛条件**：
1. 价值函数变化：$\max_s |V_{new}(s) - V_{old}(s)| < 10^{-3}$
2. 策略变化：$\sum_s \mathbb{I}(\pi_{new}(s) \neq \pi_{old}(s)) == 0$
3. 回报收敛：连续100回合的平均回报波动小于5%

## 5. 应用场景

**典型应用案例（5个，含完整定义）**：
1. **回合制游戏AI（象棋、围棋）**：
   - 状态：棋盘当前局面，用离散编码表示（如象棋用12种棋子×64格）。
   - 动作：所有合法走法，用离散编码表示。
   - 奖励：赢+1，输-1，和棋0，每步额外-0.01鼓励快速结束。
   - 适用性：有明确的对局结束状态，可采样完整对局轨迹，无需知道对手的策略模型。
2. **机器人路径规划**：
   - 状态：机器人在网格世界中的 $(x,y)$ 坐标，共 $N_x \times N_y$ 个状态。
   - 动作：上、下、左、右4个离散动作。
   - 奖励：每步-1，到达目标+100，撞墙-10。
   - 适用性：任务有明确终止状态（到达目标或步数超限），MC可学习到最优路径。
3. **推荐系统会话评估**：
   - 状态：用户当前会话的历史点击/购买行为序列。
   - 动作：推荐的商品ID，离散空间。
   - 奖励：点击+1，购买+5，忽略0，会话结束（关闭APP）+ 用户停留时间×0.1。
   - 适用性：用户会话有明确结束点，可采样完整会话轨迹评估推荐策略。
4. **临床试验优化**：
   - 状态：患者的生命体征（血压、心率、血糖）、病史等离散化特征。
   - 动作：药物剂量调整（增加/保持/减少），3个离散动作。
   - 奖励：治疗有效+10，副作用-5，患者出院+100，病情恶化-20。
   - 适用性：每个患者的治疗过程是一个完整回合，可采样轨迹优化用药策略。
5. **金融期货日内交易**：
   - 状态：当前价格、成交量、均线等离散化特征。
   - 动作：买入/卖出/持有，3个离散动作。
   - 奖励：每笔交易净利润，日内收盘强制平仓，回合结束。
   - 适用性：每个交易日是一个完整回合，可采样交易轨迹优化策略。

**适用场景特征表**：
| 特征 | 说明 |
|------|------|
| 任务类型 | 必须是回合制，有明确的终止状态 |
| 环境模型 | 未知或复杂，无法获取状态转移概率 |
| 采样成本 | 较低，可多次采样完整轨迹 |
| 状态性质 | 可以是非马尔可夫状态，MC无偏性不受影响 |
| 更新需求 | 不需要实时更新，可等待回合结束再学习 |

**不适用场景及替代方案**：
1. **持续任务（无终止状态）**：如机器人持续导航，无明确终点 → 替代方案：时序差分（TD）方法。
2. **大规模/连续状态空间**：如Atari游戏原始图像、机器人连续状态 → 替代方案：深度Q网络（DQN）、Actor-Critic。
3. **需要实时决策**：如自动驾驶，每步都需要更新策略 → 替代方案：TD、DDPG等单步更新算法。
4. **高采样成本**：如工业机器人调试，每次采样成本极高 → 替代方案：模型-based RL、离线RL。

## 6. 优缺点分析

**优点（5个，含条件）**：
1. **免模型，无偏估计**：
   - 条件：采样次数足够多，满足大数定律。
   - 说明：无需环境动力学模型，估计是无偏的，比TD方法更可靠，适用于大多数真实场景。
2. **适用于非马尔可夫环境**：
   - 条件：使用首次访问MC，完整记录轨迹。
   - 说明：不依赖马尔可夫性质假设，适用于部分可观测环境（POMDP）的简化场景。
3. **实现简单，逻辑直观**：
   - 条件：无复杂自举或递归计算。
   - 说明：核心逻辑仅包含采样、回报计算、平均更新，适合强化学习入门学习。
4. **可直接用于策略优化**：
   - 条件：结合策略梯度框架。
   - 说明：MC是REINFORCE等策略梯度算法的基础，可直接优化参数化策略。
5. **并行采样效率高**：
   - 条件：多个智能体同时采样轨迹。
   - 说明：轨迹之间完全独立，可并行生成，大幅提升采样效率。

**缺点（5个，含问题/解决方案）**：
1. **高方差，收敛慢**：
   - 问题：回报 $G_t$ 是多个随机奖励的和，方差随轨迹长度指数增长，学习不稳定。
   - 解决方案：使用基线减法、奖励裁剪、增加采样次数。
2. **仅适用于回合制任务**：
   - 问题：必须等待回合结束才能更新，无法用于持续任务。
   - 解决方案：使用时序差分（TD）方法，或截断MC（Truncated MC）用于长轨迹。
3. **采样效率低**：
   - 问题：长轨迹需要等待很久才能更新，学习效率低。
   - 解决方案：使用n步TD、多步返回，平衡MC和TD的优缺点。
4. **状态访问不均**：
   - 问题：随机策略可能导致某些状态很少被访问，价值估计不准。
   - 解决方案：使用ε-贪婪探索、UCB探索，或重要性采样做异策略MC。
5. **内存占用高（批量更新）**：
   - 问题：存储所有轨迹的回报，内存消耗大。
   - 解决方案：使用增量式更新，无需存储历史轨迹。

**与同类算法对比表**：
| 特性 | MC | TD(0) | DP | REINFORCE |
|------|----|-------|----|-----------|
| 模型依赖 | 否 | 否 | 是 | 否 |
| 有偏/无偏 | 无偏 | 有偏 | 无偏 | 无偏 |
| 方差 | 高 | 低 | 低 | 高 |
| 适用任务 | 回合制 | 回合+持续 | 回合+持续 | 回合制 |
| 更新频率 | 回合结束 | 每步 | 每步 | 回合结束 |
| 收敛速度 | 慢 | 快 | 快 | 慢 |

## 7. 调库实现

使用Python、NumPy、Gymnasium实现完整的MC策略评估与控制，包含详细注释和工程优化：

```python
import numpy as np
import gymnasium as gym
import random
from collections import defaultdict
import matplotlib.pyplot as plt

class MonteCarloAgent:
    """蒙特卡洛强化学习智能体，支持首次/每次访问MC，支持策略评估和控制"""
    
    def __init__(self, num_states, num_actions, gamma=0.9, alpha="incremental", 
                 visit_type="first-visit", epsilon=0.1):
        """
        初始化MC智能体
        参数：
        num_states: 状态总数，离散状态空间大小
        num_actions: 动作总数，离散动作空间大小
        gamma: 折扣因子，控制长期奖励的权重，推荐0.9~0.99
        alpha: 学习率，可选"incremental"（1/N）或自定义浮点值
        visit_type: 访问类型，"first-visit"或"every-visit"
        epsilon: ε-贪婪探索率，控制随机探索的概率
        """
        self.num_states = num_states
        self.num_actions = num_actions
        self.gamma = gamma
        self.alpha = alpha
        self.visit_type = visit_type
        self.epsilon = epsilon
        
        # 初始化动作价值函数Q(s,a)，使用字典存储避免稀疏状态浪费内存
        self.Q = defaultdict(lambda: np.zeros(num_actions))
        # 初始化访问次数
        self.N = defaultdict(lambda: np.zeros(num_actions))
        # 初始化策略为均匀随机策略
        self.policy = defaultdict(lambda: np.ones(num_actions) / num_actions)
        
    def choose_action(self, state):
        """ε-贪婪策略选择动作"""
        if random.random() < self.epsilon:
            return random.randint(0, self.num_actions - 1)
        else:
            return np.argmax(self.Q[state])
    
    def generate_episode(self, env, max_steps=1000):
        """
        生成一条完整轨迹
        返回：轨迹列表，每个元素为(state, action, reward)
        """
        episode = []
        state, _ = env.reset()
        steps = 0
        
        while steps < max_steps:
            action = self.choose_action(state)
            next_state, reward, terminated, truncated, _ = env.step(action)
            episode.append((state, action, reward))
            state = next_state
            steps += 1
            if terminated or truncated:
                break
                
        return episode
    
    def compute_returns(self, episode):
        """
        从后往前计算轨迹中每个时刻的回报G_t
        返回：回报列表，与episode长度一致
        """
        T = len(episode)
        G = np.zeros(T)
        g_return = 0
        
        # 反向遍历轨迹计算回报
        for t in reversed(range(T)):
            state, action, reward = episode[t]
            g_return = reward + self.gamma * g_return
            G[t] = g_return
            
        return G
    
    def update_q_value(self, state, action, G):
        """增量式更新Q值"""
        self.N[state][action] += 1
        if self.alpha == "incremental":
            alpha = 1 / self.N[state][action]
        else:
            alpha = self.alpha
        self.Q[state][action] += alpha * (G - self.Q[state][action])
    
    def policy_evaluation(self, env, num_episodes=1000, max_steps=1000):
        """MC策略评估，评估当前策略的价值函数"""
        for episode_idx in range(num_episodes):
            # 1. 生成轨迹
            episode = self.generate_episode(env, max_steps)
            # 2. 计算回报
            G = self.compute_returns(episode)
            # 3. 更新Q值
            visited = set() if self.visit_type == "first-visit" else None
            
            for t, (state, action, _) in enumerate(episode):
                if self.visit_type == "first-visit":
                    if (state, action) not in visited:
                        visited.add((state, action))
                        self.update_q_value(state, action, G[t])
                else:  # every-visit
                    self.update_q_value(state, action, G[t])
                    
        return self.Q
    
    def policy_improvement(self):
        """策略改进，更新为ε-贪婪贪心策略"""
        for state in self.Q.keys():
            best_action = np.argmax(self.Q[state])
            # ε-贪婪策略：以epsilon概率随机，否则选最优
            new_policy = np.ones(self.num_actions) * (self.epsilon / self.num_actions)
            new_policy[best_action] += 1 - self.epsilon
            self.policy[state] = new_policy
    
    def train(self, env, num_iterations=10, num_episodes=1000, max_steps=1000):
        """
        MC策略迭代训练
        返回：训练过程中的奖励历史
        """
        reward_history = []
        
        for iteration in range(num_iterations):
            # 1. 策略评估
            self.policy_evaluation(env, num_episodes, max_steps)
            
            # 2. 策略改进
            self.policy_improvement()
            
            # 3. 评估当前策略
            avg_reward = self.evaluate_policy(env, num_episodes=20)
            reward_history.append(avg_reward)
            
            # 4. 衰减探索率
            self.epsilon *= 0.995
            
            print(f"迭代 {iteration+1}/{num_iterations}, 平均奖励: {avg_reward:.2f}, ε: {self.epsilon:.4f}")
            
        return reward_history
    
    def evaluate_policy(self, env, num_episodes=20, max_steps=1000):
        """评估当前策略的性能，关闭探索"""
        total_reward = 0
        original_epsilon = self.epsilon
        self.epsilon = 0  # 关闭探索
        
        for _ in range(num_episodes):
            state, _ = env.reset()
            episode_reward = 0
            steps = 0
            while steps < max_steps:
                action = np.argmax(self.Q[state])
                next_state, reward, terminated, truncated, _ = env.step(action)
                episode_reward += reward
                state = next_state
                steps += 1
                if terminated or truncated:
                    break
            total_reward += episode_reward
            
        self.epsilon = original_epsilon  # 恢复探索率
        return total_reward / num_episodes

# 主函数：训练CliffWalking环境
if __name__ == "__main__":
```

```python
import numpy as np
import random

class MCBase:
    """从零实现的蒙特卡洛核心逻辑，仅依赖NumPy"""
    
    def __init__(self, num_states, num_actions, gamma=0.9):
        self.S = num_states
        self.A = num_actions
        self.gamma = gamma
        # 初始化Q表和访问次数
        self.Q = np.zeros((num_states, num_actions))
        self.N = np.zeros((num_states, num_actions))
    
    def generate_episode(self, env, max_steps=100):
        """生成轨迹，假设env有reset()和step(action)方法，返回(state, action, reward)"""
        episode = []
        state = env.reset()
        for _ in range(max_steps):
            # 随机策略采样
            action = random.randint(0, self.A - 1)
            next_state, reward, done, _ = env.step(action)
            episode.append((state, action, reward))
            state = next_state
            if done:
                break
        return episode
    
    def first_visit_mc(self, episode):
        """首次访问MC更新Q值"""
        T = len(episode)
        G = 0
        # 反向计算回报
        for t in reversed(range(T)):
            state, action, reward = episode[t]
            G = reward + self.gamma * G
            # 检查是否首次访问
            if (state, action) not in [(s, a) for s, a, _ in episode[:t]]:
                self.N[state][action] += 1
                self.Q[state][action] += (G - self.Q[state][action]) / self.N[state][action]
    
    def every_visit_mc(self, episode):
        """每次访问MC更新Q值"""
        T = len(episode)
        G = 0
        for t in reversed(range(T)):
            state, action, reward = episode[t]
            G = reward + self.gamma * G
            self.N[state][action] += 1
            self.Q[state][action] += (G - self.Q[state][action]) / self.N[state][action]

            next_state = 2
        reward = -1 if next_state < 2 else 10  # 到达状态2得10分
        done = (next_state == 2)
```

## 10. 模型评估

完整的MC模型评估代码，包含多维度指标和超参数交叉验证：

```python
def evaluate_mc_agent(agent, env, num_episodes=100, max_steps=100):
    """
    评估MC智能体的性能
    返回：平均奖励、奖励标准差、平均步数、成功率
    """
    total_rewards = []
    total_steps = []
    success_count = 0
    
    original_epsilon = agent.epsilon
    agent.epsilon = 0  # 关闭探索，使用贪心策略
    
    for episode in range(num_episodes):
        state, _ = env.reset()
        episode_reward = 0
        steps = 0
        
        while steps < max_steps:
            action = np.argmax(agent.Q[state])
            next_state, reward, terminated, truncated, _ = env.step(action)
            episode_reward += reward
            steps += 1
            state = next_state
            if terminated or truncated:
                break
        
        total_rewards.append(episode_reward)
        total_steps.append(steps)
        # CliffWalking中到达终点（状态47）为成功
        if next_state == 47:
            success_count += 1
    
    agent.epsilon = original_epsilon  # 恢复探索率
    
    mean_reward = np.mean(total_rewards)
    std_reward = np.std(total_rewards)
    mean_steps = np.mean(total_steps)
    success_rate = success_count / num_episodes
    
    print(f"评估结果（{num_episodes}回合）：")
    print(f"平均奖励：{mean_reward:.2f} ± {std_reward:.2f}")
    print(f"平均步数：{mean_steps:.2f}")
    print(f"成功率：{success_rate:.2%}")
    
    return mean_reward, std_reward, mean_steps, success_rate

def cross_validate_hyperparams():
    """交叉验证选择最佳超参数（gamma和alpha）"""
    import gymnasium as gym
    env = gymnasium.make("CliffWalking-v0")
    gammas = [0.8, 0.9, 0.95]
    alphas = [0.01, 0.1, "incremental"]
    
    results = {}
    
    for gamma in gammas:
        for alpha in alphas:
            agent = MonteCarloAgent(
                num_states=env.observation_space.n,
                num_actions=env.action_space.n,
                gamma=gamma,
                alpha=alpha,
                visit_type="first-visit",
                epsilon=0.1
            )
            # 训练5轮，每轮1000回合
            agent.train(env, num_iterations=5, num_episodes=1000)
            # 评估
            mean_reward, _, _, _ = evaluate_mc_agent(agent, env, num_episodes=20)
            results[(gamma, alpha)] = mean_reward
            print(f"gamma={gamma}, alpha={alpha}, 平均奖励={mean_reward:.2f}")
    
    # 找到最佳参数
    best_params = max(results, key=results.get)
    print(f"\n最佳超参数：gamma={best_params[0]}, alpha={best_params[1]}, 奖励={results[best_params]:.2f}")
    env.close()
```

**评估指标说明**：
1. **平均奖励**：越接近环境最优奖励（CliffWalking为-13）越好。
2. **奖励标准差**：越小说明策略越稳定，MC方法通常标准差较大。
3. **平均步数**：越短说明路径越优，CliffWalking最优路径为13步。
4. **成功率**：到达终点的回合占比，越高说明策略越可靠。

**评估流程注意事项**：
- 评估时必须关闭探索（epsilon=0），使用贪心策略，否则结果会包含随机探索的噪声。
- 交叉验证时需要划分训练集和测试集，避免过拟合超参数。
- 多次运行取平均，避免单次运行的随机性影响结果。

## 11. 常见问题与易错点

### 数据层面（3个）
1. **轨迹不完整**
   - 现象：价值估计持续偏高或偏低，不收敛。
   - 原因：回合未终止就停止采样（如max_steps设置过小），得到的回报 $G_t$ 不是完整轨迹的回报。
   - 解决方案：确保`env.step`返回`done=True`才停止轨迹，或设置足够大的`max_steps`覆盖最长轨迹长度。
2. **状态访问不均匀**
   - 现象：某些状态的 $N(s,a) < 10$，价值估计波动大。
   - 原因：探索策略不佳（如epsilon过小），导致状态覆盖不全。
   - 解决方案：增大epsilon，或使用UCB、熵正则化等改进探索策略。
3. **奖励未归一化**
   - 现象：回报 $G_t$ 数值过大（如1000+），导致Q值更新震荡。
   - 原因：奖励尺度不一致，未做归一化处理。
   - 解决方案：奖励裁剪到[-1,1]，或z-score标准化奖励。

### 模型层面（3个）
1. **高方差导致学习不稳定**
   - 现象：训练曲线波动大，奖励忽高忽低。
   - 原因：回报 $G_t$ 是多个随机奖励的累加，方差随轨迹长度增长。
   - 解决方案：使用基线减法、奖励裁剪、增加采样次数。
2. **首次/每次访问选择错误**
   - 现象：非马尔可夫环境下估计有偏，马尔可夫环境下收敛慢。
   - 原因：非马尔可夫环境使用每次访问MC，马尔可夫环境使用首次访问MC。
   - 解决方案：非马尔可夫环境用首次访问，马尔可夫环境用每次访问。
3. **增量更新学习率设置错误**
   - 现象：Q值不收敛或收敛慢。
   - 原因：手动设置alpha过小（收敛慢）或过大（震荡），未使用 $1/N(s)$。
   - 解决方案：优先使用`alpha="incremental"`，或设置alpha=0.01~0.1。

### 调参层面（2个）
1. **折扣因子gamma选择不当**
   - 现象：gamma过大导致回报方差爆炸，gamma过小导致策略短视。
   - 原因：未根据任务长度调整gamma，短轨迹任务用大gamma，长轨迹用小gamma。
   - 解决方案：短轨迹（<100步）用0.9~0.99，长轨迹（>1000步）用0.8~0.9。
2. **探索率epsilon衰减过快**
   - 现象：训练早期就陷入局部最优，无法继续优化。
   - 原因：epsilon衰减速度过快，探索不足。
   - 解决方案：使用缓慢衰减（如`epsilon *= 0.9995`），或自适应epsilon（根据状态访问次数调整）。

### 调试技巧
- 打印状态访问次数：检查是否有状态未被访问，调整探索策略。
- 打印回报分布：如果回报标准差大于均值的2倍，说明方差过高，需要优化。
- 固定随机种子：保证结果可复现，方便对比不同参数的效果。

**工程最佳实践**：
- 保存训练检查点：每100回合保存Q表和策略，避免训练中断丢失进度。
- 使用TensorBoard记录训练曲线，实时监控奖励、epsilon、探索覆盖率等指标。
- 并行采样：使用多进程同时生成轨迹，提升采样效率。

## 12. 学习总结

### 核心思想回顾
蒙特卡洛方法通过**采样完整轨迹、计算平均回报**来估计价值函数或优化策略，完全免模型，无偏但高方差，是强化学习最基础的免模型方法，为后续TD、策略梯度算法提供了核心采样思想。

### ASCII思维导图
```
蒙特卡洛方法（MC）
├── 核心思想：采样完整轨迹 → 平均回报 → 估计价值/优化策略
├── 关键特性
│   ├── 免模型：无需环境动力学
│   ├── 无偏估计：大数定律保证
│   ├── 高方差：回报累加导致
│   └── 仅回合制：需完整轨迹
├── 两种类型
│   ├── 首次访问MC：非马尔可夫适用，方差小
│   └── 每次访问MC：马尔可夫适用，收敛快
└── 应用场景
    ├── 回合制游戏AI
    ├── 机器人路径规划
    ├── 推荐系统评估
    └── 临床试验优化
```

### 关键公式总结（3个，需牢记）
1. **回报计算**：$G_t = r_{t+1} + \gamma r_{t+2} + ... + \gamma^{T-t-1} r_T$ → 反映状态 $s_t$ 的长期价值。
2. **MC估计**：$V(s) = \frac{1}{N} \sum_{i=1}^N G_t^{(i)}$ → 用样本均值近似真实期望。
3. **策略梯度**：$\nabla \bar{R}_\theta = \mathbb{E}[G_t \nabla \log \pi_\theta(a|s)]$ → REINFORCE算法的核心公式。

### 与前序/后续算法的关系
- **前序**：动态规划（DP）→ MC是DP的免模型版本，用采样代替全宽度备份。
- **平行**：时序差分（TD）→ MC是TD的n=∞特殊情况，TD是MC的单步近似。
- **后续**：
  - TD → n步TD、Actor-Critic → 结合MC和TD的优势。
  - MC → REINFORCE → PPO/TRPO → 现代策略优化算法。
  - MC → DQN → 深度强化学习 → 处理大规模状态空间。

## 13. 练习题与思考题

### 基础题（5道，含隐藏答案）

1. **什么是首次访问MC和每次访问MC？它们有什么区别？适用场景是什么？**
   <details>
   <summary>点击查看参考答案</summary>
   - 首次访问MC：仅使用每个轨迹中第一次访问状态s的回报G_t来更新V(s)。<br>
   - 每次访问MC：每个轨迹中每次访问状态s都使用其回报G_t来更新V(s)。<br>
   - 区别：首次访问方差更小但数据利用率低；每次访问收敛更快但方差更大。<br>
   - 适用场景：非马尔可夫环境用首次访问，马尔可夫环境用每次访问。
   </details>

2. **为什么MC方法只能用于回合制任务？如果要用MC处理持续任务，有什么改进方法？**
   <details>
   <summary>点击查看参考答案</summary>
   - MC需要完整轨迹计算回报G_t，持续任务无终止状态，无法获得完整轨迹。<br>
   - 改进方法：使用截断MC（Truncated MC），设置最大轨迹长度T，将超过T的部分截断，用V(s_T)近似剩余回报。
   </details>

3. **MC估计是无偏的，为什么还会有方差？如何降低方差？**
   <details>
   <summary>点击查看参考答案</summary>
   - 无偏性是指估计的期望等于真实值，但每次采样的G_t是随机变量，方差由奖励的随机性导致。<br>
   - 降低方差方法：基线减法、奖励裁剪、增加采样次数、使用重要性采样。
   </details>

4. **MC方法的核心优势是什么？相比TD方法有什么不足？**
   <details>
   <summary>点击查看参考答案</summary>
   - 核心优势：免模型、无偏估计、适用于非马尔可夫环境。<br>
   - 不足：仅适用于回合制、高方差、收敛慢、无法实时更新。
   </details>

5. **在MC策略梯度中，为什么要使用log概率的梯度？**
   <details>
   <summary>点击查看参考答案</summary>
   - 利用公式$\nabla f(x) = f(x) \nabla \log f(x)$，将梯度的期望从对轨迹概率的梯度转换为对log概率的期望，避免直接求轨迹概率的梯度（轨迹概率难以计算）。
   </details>

### 进阶题（2道，含推导）
1. **推导首次访问MC估计的无偏性，并说明为什么每次访问MC在马尔可夫环境下也是无偏的。**

   <summary>点击查看参考答案</summary>

   </details>

### 前置学习顺序（5步）
1. **概率论基础**：掌握期望、大数定律、方差、正态分布等概念，理解MC方法的数学基础。
2. **马尔可夫决策过程（MDP）**：理解状态、动作、奖励、回报、价值函数的定义，掌握MDP的基本框架。
3. **动态规划（DP）**：学习策略评估、策略改进、值迭代、策略迭代，理解MC是DP的免模型版本。
4. **蒙特卡洛方法（当前）**：掌握MC的核心原理、两种类型、数学推导、代码实现。
5. **时序差分（TD）**：学习TD(0)、Sarsa、Q-learning，对比MC和TD的区别，理解自举的概念。
