# 分组查询注意力 (Grouped Query Attention / GQA) 学习文档

> GQA是一种高效的大型语言模型注意力机制，是多头注意力(MHA)和多查询注意力(MQA)之间的折中方案，显著减少KV Cache的同时保持强大的建模能力

---

## 1. 算法基础认知

### 1.1 一句话定义

**分组查询注意力（Grouped Query Attention，GQA）** 是一种在大型语言模型中使用的注意力架构优化技术，它将Query头分成多个组，每组Query共享同一个Key-Value头，从而在保持多头注意力的强大表达能力的同时，大幅减少推理时的KV Cache内存占用。

### 1.2 直觉类比

想象你在做一个复杂的阅读理解（像GPT大模型）：在传统方法（MHA）中，你为每个问题（Query）都配备一个独立的记忆助手（独立的KV），人太多（70B参数）导致助手们占满了整个办公室！而GQA的方案是：请几个资深助手（8个KV），每10个问题（Query）共享一个助手，每个资深助手管理10个问题。这样办公室不拥挤了（内存节省87.5%），但回答质量仍然很好（因为资深助手能同时处理多个相关问题）。

### 1.3 历史背景

| 年份 | 里程碑 |
|------|--------|
| 2017 | Transformer (MHA原始) |
| 2019 | Multi-Query Attention (MQA) - 1个KV |

## 2. 核心原理

### 2.1 MHA vs MQA vs GQA

| 方法 | Query头 | KV头 | KV Cache | 表达力 |
|------|---------|------|----------|--------|
| **MHA** | n_q | n_q | n_q × d_k | 最强 |
| **MQA** | n_q | 1 | 1 × d_k | 弱 |
| **GQA** | n_q | n_kv (<<n_q) | n_kv × d_k | 中等 |

### 2.2 GQA分组机制

**分组映射**：
$$\text{group}(i) = \lfloor \frac{i \cdot n_{kv}}{n_q} \rfloor$$

其中 $i$ 是Query头的索引，$n_{kv}$ 是KV头的数量。

**示例**（LLaMA 2-70B）：
- $n_q = 64$ 个Query头
- $n_{kv} = 8$ 个KV头
- 每8个Query头 → 共享1个KV头

### 2.3 工作流程

```python
def gqa_attention(Q, K, V, num_groups):
    """
    Q: (batch, num_heads, seq_len, head_dim)
    K: (batch, num_kv_heads, seq_len, head_dim)
    V: (batch, num_kv_heads, seq_len, head_dim)
    """
    
    # 分组复制KV
    # 将KV从 (batch, num_kv_heads, ...) 扩展到 (batch, num_heads, ...)
    num_heads = Q.shape[1]
    num_kv_heads = K.shape[1]
    group_size = num_heads // num_kv_heads
    
    # repeat_interleave: 每个KV头复制group_size次
    K = K.repeat_interleave(group_size, dim=1)
    V = V.repeat_interleave(group_size, dim=1)
    
    # 标准注意力计算
    attn_output = scaled_dot_product_attention(Q, K, V)
    
    return attn_output
```

### 2.4 注意力计算

```
原始 (MHA):
Q₀ ----→ K₀, V₀ → attn₀ → output
Q₁ ----→ K₁, V₁ → attn₁ → output
...
Q₆₃ → K₆₃, V₆₃ → attn₆₃ → output

GQA:
Q₀ ┐                           → K₀, V₀ → attn₀~₇ → output
Q₁ ┤
Q₂ ┤
...  group 0                     (8个Query共享1个KV)
Q₇ ┘                          

Q₈ ┐                           → K₁, V₁ → attn₈~₁₅ → output
Q₉ ┤
...
Q₆₃                           → K₇, V₇ → output
```

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 |
|------|------|
| $n_q$ | Query头数量 |
| $n_{kv}$ | Key-Value头数量 |
| $d_k$ | 每个头的维度 |
| $B$ | batch size |
| $L$ | 序列长度 |
| $g = n_q / n_{kv}$ | 每组大小 |

### 3.2 查询投影

**标准MHA**：
$$Q_i = hW_i^Q, \quad i = 1, ..., n_q$$
$$K_i = hW_i^K, \quad i = 1, ..., n_q$$
$$V_i = hW_i^V, \quad i = 1, ..., n_q$$

**GQA（减少KV头）**：
$$Q_i = hW_i^Q, \quad i = 1, ..., n_q$$
$$K_j = hW_j^K, \quad j = 1, ..., n_{kv}$$
$$V_j = hW_j^V, \quad j = 1, ..., n_{kv}$$

### 3.3 分组广播

**将KV扩展到Query维度**：
$$K_i = K_{\text{group}(i)}$$
$$V_i = V_{\text{group}(i)}$$

或者使用数学表示（repeat操作）：
$$K_i = \text{Repeat}(K_{\lfloor i \cdot n_{kv} / n_q \rfloor}, g)$$

### 3.4 注意力输出

**每组独立计算attention**：
$$\text{head}_i = \text{Attention}(Q_i, K_{\text{group}(i)}, V_{\text{group}(i)})$$

**最终输出**：
$$O = \text{Concat}(\text{head}_1, ..., \text{head}_{n_q}) \cdot W^O$$

### 3.5 内存分析

**KV Cache公式**：
$$\text{KV}_{MHA} = 2 \cdot L \cdot n_q \cdot d_k \cdot \text{bytes}$$
$$\text{KV}_{GQA} = 2 \cdot L \cdot n_{kv} \cdot d_k \cdot \text{bytes}$$

**节省比例**：
$$\text{Saving} = \frac{n_q - n_{kv}}{n_q} = 1 - \frac{n_{kv}}{n_q}$$

### 3.6 复杂度分析

| 操作 | 复杂度 |
|------|--------|
| Q投影 | $O(B \cdot L \cdot n_q \cdot d_k)$ |
| KV投影 | $O(B \cdot L \cdot n_{kv} \cdot d_k)$ |
| 注意力 | $O(B \cdot L^2 \cdot n_q \cdot d_k)$ |
| 总计算 | 同MHA（注意力是主要瓶颈） |
| **KV Cache** | 减少 $n_q / n_{kv}$ 倍 |

## 4. PyTorch实现

### 4.1 基础GQA模块

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class GroupedQueryAttention(nn.Module):
    """分组查询注意力"""
    
    def __init__(self, d_model, num_heads, num_kv_heads, dropout=0.0):
        super(GroupedQueryAttention, self).__init__()
        
        assert d_model % num_heads == 0
        assert num_heads % num_kv_heads == 0
        
        self.d_model = d_model
        self.num_heads = num_heads
        self.num_kv_heads = num_kv_heads
        self.head_dim = d_model // num_heads
        self.num_groups = num_heads // num_kv_heads
        
        # Q投影（每个头独立）
        self.W_Q = nn.Linear(d_model, d_model)
        
        # KV投影（更少的头）
        self.W_K = nn.Linear(d_model, num_kv_heads * self.head_dim)
        self.W_V = nn.Linear(d_model, num_kv_heads * self.head_dim)
        
        # 输出投影
        self.W_O = nn.Linear(d_model, d_model)
        
        self.dropout = nn.Dropout(dropout)
        
        # 缩放因子
        self.scale = self.head_dim ** -0.5
    
    def forward(self, x, mask=None, use_cache=False, past_kv=None):
        """
        Args:
            x: (batch, seq_len, d_model)
            mask: (seq_len, seq_len) or None
            use_cache: 是否使用KV cache
            past_kv: 缓存的KV (tuple of (K, V)) or None
        
        Returns:
            output: (batch, seq_len, d_model)
            present: 新的KV cache (if use_cache else None)
        """
        batch_size, seq_len, _ = x.size()
        
        # ==================== Q投影 ====================
        # (batch, seq_len, d_model) → (batch, seq_len, num_heads, head_dim)
        Q = self.W_Q(x).view(
            batch_size, seq_len, self.num_heads, self.head_dim
        ).transpose(1, 2)
        
        # ==================== KV投影 ====================
        if past_kv is not None:
            # 展开缓存：past_K, past_V shape: (batch, num_kv_heads, past_len, head_dim)
            past_K, past_V = past_kv
            
            # 当前token的KV
            K_curr = self.W_K(x).view(
                batch_size, seq_len, self.num_kv_heads, self.head_dim
            ).transpose(1, 2)
            V_curr = self.W_V(x).view(
                batch_size, seq_len, self.num_kv_heads, self.head_dim
            ).transpose(1, 2)
            
            # 拼接
            K = torch.cat([past_K, K_curr], dim=2)
            V = torch.cat([past_V, V_curr], dim=2)
        else:
            K = self.W_K(x).view(
                batch_size, seq_len, self.num_kv_heads, self.head_dim
            ).transpose(1, 2)
            V = self.W_V(x).view(
                batch_size, seq_len, self.num_kv_heads, self.head_dim
            ).transpose(1, 2)
        
        present = (K, V) if use_cache else None
        
        # ==================== KV复制到Query维度 ====================
        # 将 (batch, kv_heads, seq, dim) 复制到 (batch, q_heads, seq, dim)
        # 如果 seq_len=1（推理），只复制一次
        K = K.repeat_interleave(self.num_groups, dim=1)
        V = V.repeat_interleave(self.num_groups, dim=1)
        
        # ==================== 注意力计算 ====================
        # 缩放点积
        attn_scores = torch.matmul(Q, K.transpose(-2, -1)) * self.scale
        
        # Mask（如果有）
        if mask is not None:
            attn_scores = attn_scores.masked_fill(mask == 0, float('-inf'))
        
        # Softmax
        attn_weights = F.softmax(attn_scores, dim=-1)
        attn_weights = self.dropout(attn_weights)
        
        # 加权求和
        attn_output = torch.matmul(attn_weights, V)
        
        # ==================== 输出 ====================
        # (batch, num_heads, seq, head_dim) → (batch, seq, d_model)
        attn_output = attn_output.transpose(1, 2).contiguous().view(
            batch_size, seq_len, self.d_model
        )
        output = self.W_O(attn_output)
        
        return output, present


class GQATransformerLayer(nn.Module):
    """GQA + FFN的完整Transformer层"""
    
    def __init__(self, d_model, num_heads, num_kv_heads, d_ff, dropout=0.0):
        super(GQATransformerLayer, self).__init__()
        
        # GQA
        self.attention = GroupedQueryAttention(
            d_model, num_heads, num_kv_heads, dropout
        )
        self.attn_norm = nn.LayerNorm(d_model)
        
        # FFN
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.SiLU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout)
        )
        self.ffn_norm = nn.LayerNorm(d_model)
    
    def forward(self, x, mask=None, use_cache=False, past_kv=None):
        # 注意力 + 残差
        attn_output, present = self.attention(
            x, mask, use_cache, past_kv
        )
        x = self.attn_norm(x + attn_output)
        
        # FFN + 残差
        ffn_output = self.ffn(x)
        x = self.ffn_norm(x + ffn_output)
        
        return x, present
```

### 4.2 增量推理优化

```python
class GQAWithKVCache(nn.Module):
    """支持增量推理的GQA"""
    
    def __init__(self, d_model, num_heads, num_kv_heads):
        super().__init__()
        
        self.attention = GroupedQueryAttention(
            d_model, num_heads, num_kv_heads
        )
        
        # 缓存统计
        self.kv_cache = None
    
    def forward_step(self, x_new, position_ids=None):
        """单步推理"""
        batch_size = x_new.shape[0]
        
        # 处理单个token（推理模式）
        if x_new.shape[1] == 1:
            use_cache = True
        else:
            use_cache = False
        
        output, present = self.attention(
            x_new, use_cache=use_cache, past_kv=self.kv_cache
        )
        
        # 更新KV cache
        if use_cache and present is not None:
            if self.kv_cache is None:
                self.kv_cache = present
            else:
                past_K, past_V = self.kv_cache
                new_K, new_V = present
                self.kv_cache = (
                    torch.cat([past_K, new_K], dim=2),
                    torch.cat([past_V, new_V], dim=2)
                )
        
        return output
    
    def reset_cache(self):
        """重置KV cache"""
        self.kv_cache = None
```

### 4.3 完整模型

```python
class GQAModel(nn.Module):
    """使用GQA的完整语言模型"""
    
    def __init__(self, vocab_size, d_model, num_layers, 
                 num_heads, num_kv_heads, d_ff, max_seq_len=2048):
        super(GQAModel, self).__init__()
        
        # 词嵌入
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.position_embedding = nn.Embedding(max_seq_len, d_model)
        
        # Transformer层
        self.layers = nn.ModuleList([
            GQATransformerLayer(d_model, num_heads, num_kv_heads, d_ff)
            for _ in range(num_layers)
        ])
        
        self.norm = nn.LayerNorm(d_model)
        self.lm_head = nn.Linear(d_model, vocab_size, bias=False)
        
        # 权重绑定（可选）
        self.lm_head.weight = self.embedding.weight
    
    def forward(self, input_ids, position_ids=None, use_cache=False):
        # 嵌入
        h = self.embedding(input_ids)
        
        if position_ids is not None:
            h = h + self.position_embedding(position_ids)
        
        # Transformer层
        past_kv = None
        
        for layer in self.layers:
            h, present = layer(h, use_cache=use_cache, past_kv=past_kv)
            past_kv = present
        
        # 输出logits
        h = self.norm(h)
        logits = self.lm_head(h)
        
        return logits, past_kv
```

import torch
import numpy as np
import matplotlib.pyplot as plt


def demo_gqa():
    """GQA演示"""

## 6. 应用场景

### 6.1 大语言模型

| 模型 | 使用GQA |

| LLaMA 3 | 是 |

### 6.2 为什么使用GQA

1. **KV Cache瓶颈**：70B模型，4096上下文，KV Cache占几十GB显存
2. **推理速度**：减少KV Cache提高批量大小
3. **保持质量**：比MQA表达能力更强

## 7. 优缺点分析

### 7.1 优点

| 优点 | 说明 |
|------|------|
| **显著节省内存** | KV Cache减少 4-8 倍 |
| **保持表达能力** | 比MQA更好 |
| **实现简单** | 只需KV复制 |
| **训练无影响** | 只影响推理 |

### 7.2 缺点

| 缺点 | 说明 | 缓解 |
|------|------|------|
| **可能轻微损失** | 在极端情况下 | 增加KV头 |
| **实现复杂性** | 需要推理优化 | 使用库 |

## 8. 常见问题与易错点

### 8.1 问题：KV分组数量选择

建议：
- $n_{kv} \ge 4$：足够多样
- 常用值：4, 8, 16

### 8.2 问题：训练vs推理

- 训练：可以不用GQA（用完整MHA）
- 推理：使用GQA节省内存

## 9. 学习总结

### 9.1 核心要点

1. **Query分组**：$n_q$ 个Query头分 $n_{kv}$ 组
2. **KV共享**：每组共享1个KV头
3. **KV复制**：推理时复制KV到Query维度

### 9.2 关键公式

$$\text{KV}_{GQA} = \text{KV}_{MHA} \cdot \frac{n_{kv}}{n_q}$$

### 9.3 学习路径

Transformer → MHA → MQA → GQA → LLaMA
