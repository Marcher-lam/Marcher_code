### 1.5 发展历史（扩展版）

**详细历史脉络**：

**起源与早期发展（1930s-1950s）**：
- 1933年：Thompson提出汤普森采样，首次用贝叶斯方法解决多臂老虎机问题
- 1939年：H. Robbins提出随机近似算法（Robbins-Monro algorithm），用于在线决策
- 1952年：Herbert Robbins在《Some Aspects of the Sequential Design of Experiments》中系统阐述随机逼近理论

**理论成熟期（1960s-1980s）**：
- 1964年：Bellman提出动态规划，与老虎机问题形成对应关系
- 1969年：Lai和Herbert Robbins在论文《Asymptotically Efficient Adaptive Allocation Rules》中证明了下界
- 1979年：Berry和Fristedt在《Bandit Problems: Sequential Allocation of Experiments》中系统总结Bandit问题

**现代发展与应用期（1980s至今）**：
- 1985年：Lai和Robbins完善了Bayes最优策略理论
- 1990s：UCB1算法的提出，给出有限时间内的后悔上界
- 2000s-2010s：汤普森采样和UCB在工业界广泛应用（广告、推荐系统）
- 2010s-2020s：上下文老虎机（Contextual Bandit）的发展，加入用户/上下文特征
- 2020s至今：深度学习方法与Bandit结合，处理大规模动作空间

### 1.4 学习前置清单
#### 数学基础
- 概率论：期望、方差、伯努利分布、高斯分布、贝叶斯定理

**详细数学知识要求**：

**1. 概率论核心概念**：
- **伯努利分布（Bernoulli）**：$P(X=1) = p, P(X=0) = 1-p$，描述二值随机变量（点击/未点击）
  - 期望：$\mathbb{E}[X] = p$
  - 方差：$\text{Var}(X) = p(1-p)$
- **高斯分布（Gaussian）**：$X \sim \mathcal{N}(\mu, \sigma^2)$，描述连续随机变量（奖励通常服从高斯）
  - 概率密度：$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$
  - 期望：$\mathbb{E}[X] = \mu$
  - 方差：$\text{Var}(X) = \sigma^2$

- **期望与方差的直观理解**：
  - 期望：大量试验的平均值，如掷1000次骰子的平均点数
  - 方差：期望的偏离程度，方差越大，估计越不稳定
  - MC方法的方差高是因为回报是多个随机奖励的累加

**2. 微积分基础**：
- **导数定义**：$f'(x) = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h}$
- **梯度下降**：$x_{t+1} = x_t - \alpha \nabla f(x_t)$，沿梯度下降方向迭代
- **多元函数导数**：$\nabla f(\mathbf{x}) = [\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots]$

- **后悔函数的梯度**：
  - 总后悔$R_T = T\mu^* - \sum_{t=1}^T r_t$
  - 对状态$a$的后悔贡献：$\Delta_a = \mu^* - \mu_a$
  - 最优动作后悔为0，次优动作后悔为正

**3. 信息论基础（选学，但很有用）**：
- **熵（Entropy）**：$H(\pi) = -\sum_x \pi(x) \log \pi(x)$，衡量策略的随机性
  - 熵越大，策略越随机（探索性强）
  - 熵越小，策略越确定（利用性强）
- **KL散度**：$D_{KL}(P || Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$，衡量两个概率分布的差异
  - 用于后悔下界证明：$D_{KL}(p_1 || p_2) \geq \frac{(\mu_1 - \mu_2)^2}{2 \mu_1}$

**4. 贝叶斯定理（用于汤普森采样）**：
- **贝叶斯公式**：$P(\mu|X) = \frac{P(X|\mu)P(\mu)}{P(X)}$
- **贝叶斯学习**：
  - 先验：$P(\mu)$（如$\mathcal{N}(0, 1)$）
  - 似然：$P(X|\mu) = \prod_{t=1}^T P(x_t|\mu)$
  - 后验：$P(\mu|X)$ ∝ P(X|\mu)P(\mu)$
- **汤普森采样**：从后验分布采样动作，天然平衡探索与利用

**5. 大数定律（MC方法的理论基础）**：
- **弱大数定律**：$\frac{1}{N}\sum_{i=1}^N X_i \overset{p}{\to} \mathbb{E}[X]$（几乎必然收敛）
- **意义**：MC估计$V(s) = \frac{1}{N}\sum_{i=1}^N G_t^{(i)}$收敛到真实价值$V^\pi(s)$

## 2. 核心原理
### 2.1 核心机制：探索与利用的权衡
多臂老虎机的核心矛盾是**探索（Exploration）**与**利用（Exploitation）**的平衡：
- 探索：尝试未知臂，获取奖励分布信息，降低不确定性
- 利用：选择当前估计最优的臂，获取已知最高奖励

#### 机制ASCII示意图
```
+-------------------+      选择臂a_t       +-------------------+
|   老虎机环境       | --------------------> |     智能体         |
| (K个臂，每个臂有   | <-------------------- | (维护每个臂的估计Q_a |
|  未知平均奖励μ_a)  |   返回奖励r_t        |   和拉动次数N_a)   |
+-------------------+                       +-------------------+
```

### 2.2 相关算法对比
| 算法 | 探索策略 | 后悔上界 | 计算复杂度 | 适用场景 |
|------|----------|----------|------------|----------|
| ε-贪婪 | 概率ε随机选臂 | $O(\\sqrt{T})$ | $O(1)$/步 | 简单场景、快速迭代 |
| UCB1 | 选$Q_a + \\sqrt{2\\ln t / N_a}$ | $O(\\sqrt{T})$ | $O(1)$/步 | 理论保障要求高 |
| 汤普森采样 | 从后验分布采样 | $O(\\log T)$（贝叶斯） | $O(K)$/步 | 贝叶斯建模场景 |
| 梯度Bandit | Softmax选择，梯度更新 | $O(T^{2/3})$ | $O(K)$/步 | 大动作空间 |

### 2.3 工程经验
1. 乐观初始化：将初始Q值设为高于所有可能奖励的值（如奖励为0-1时设Q=5），强制早期探索
2. 探索衰减：ε随步数指数衰减（$\\epsilon_t = \\epsilon_0 \\times 0.995^t$），后期减少无效探索
3. 非平稳适配：对于奖励分布变化的场景，使用滑动窗口或步长更新（$Q_{new} = (1-\\alpha)Q_{old} + \\alpha r$）

### 2.4 几何直观解释
每个臂的奖励分布可视为一维高斯分布$N(\\mu_a, \\sigma^2)$，智能体的目标是找到均值$\\mu_a$最大的分布：
- 探索是采样所有分布，缩小均值估计的方差
- 利用是选择当前均值估计最大的分布，获取高奖励
- 后悔来源于选择了非最优分布带来的奖励损失

## 3. 数学公式与推导
### 3.1 符号表
| 符号 | 含义 | 维度/范围 |
|------|------|-----------|
| $K$ | 臂的总数 | 正整数 $K \\geq 2$ |
| $\\mu_a$ | 第a个臂的真实平均奖励 | 实数，点击率场景$\\mu_a \\in [0,1]$ |
| $\\mu^*$ | 最优臂平均奖励 $\\mu^* = \\max_{a=1..K} \\mu_a$ | 实数 |
| $Q_a(t)$ | 第t步第a个臂的估计Q值 | 实数 |
| $N_a(t)$ | 第t步第a个臂的拉动次数 | 正整数 $N_a(t) \\geq 0$ |
| $r_t$ | 第t步的奖励 | 与$\\mu_a$同分布 |
| $R_T$ | T步总后悔 | 非负实数 $R_T \\geq 0$ |

### 3.2 核心公式推导
#### 总后悔定义
后悔是智能体未选择最优臂带来的累计奖励损失：
$$R_T = T\\mu^* - \\sum_{t=1}^T r_t$$
其中$T\\mu^*$是始终选择最优臂的理论最大奖励，$\\sum r_t$是实际获得的总奖励。

#### Q值增量更新推导
对于每个臂a，拉动$N_a$次后，Q值是所有奖励的平均：
$$Q_a = \\frac{1}{N_a} \\sum_{i=1}^{N_a} r_i$$
当获得第$N_a+1$次奖励$r_{new}$时，新Q值为：
$$Q_{a,new} = \\frac{1}{N_a+1} \\left( \\sum_{i=1}^{N_a} r_i + r_{new} \\right) = \\frac{N_a Q_a + r_{new}}{N_a + 1} = Q_a + \\frac{r_{new} - Q_a}{N_a + 1}$$
这就是增量更新的来源，避免存储所有历史奖励。

### 3.3 算法伪代码（ε-贪婪）
```
初始化：K个臂的Q值=0，N_a=0，ε=初始探索率
for t=1 to T:
    以概率ε：随机选择臂a
    否则：选择a = argmax(Q_a)
    获得奖励r ~ 臂a的真实分布
    N_a = N_a + 1
    Q_a = Q_a + (r - Q_a)/N_a
    ε = ε * 衰减率
end for
```

### 3.4 后悔下界证明（Lai-Robbins下界）
对于两个臂的伯努利分布$\\mu_1 > \\mu_2$，任何算法的期望后悔满足：
$$\\lim_{T \\to \\infty} \\frac{\\mathbb{E}[R_T]}{\\log T} \\geq \\frac{\\mu_1 - \\mu_2}{KL(\\mu_2 || \\mu_1)}$$
其中$KL$是KL散度，证明核心是利用Chernoff界限制错误选择次优臂的概率。

## 4. 训练过程讲解
### 4.1 数据预处理
多臂老虎机无传统意义上的特征数据，仅需定义：
1. 臂的数量K
2. 每个臂的奖励分布（模拟场景）或实时奖励流（真实场景）
3. 可选：环境是否为非平稳（奖励分布是否随时间变化）

### 4.2 参数初始化表
| 参数 | 推荐值（平稳场景） | 推荐值（非平稳场景） | 说明 |
|------|------------------|------------------|------|
| 初始Q值 | 0（或5，乐观初始化） | 0 | 乐观初始化鼓励早期探索 |
| ε初始值 | 0.1 | 0.2 | 非平稳场景需要更高探索率 |
| ε衰减率 | 0.995 | 0.99 | 非平稳场景衰减更慢 |
| 步长α（非平稳） | - | 0.1 | 用于滑动窗口更新 |

### 4.3 训练流程
1. 初始化智能体参数（Q值、计数、ε）
2. 循环T步：
   a. 根据当前策略选择臂a
   b. 获取环境返回的奖励r
   c. 更新臂a的Q值和拉动次数
   d. 衰减探索率ε
3. 训练结束后统计累积奖励、后悔、臂选择分布

#### 工程技巧
- 真实场景中不依赖真实均值，仅用Q值和计数更新
- 记录每步的累积后悔，用于监控收敛情况
- 设置最大探索率下限（如ε≥0.01），避免完全停止探索

### 4.4 收敛与调试
#### 收敛条件
- Q值与真实均值的误差小于阈值（如$|Q_a - \\mu_a| < 0.01$）
- 探索率ε衰减到接近0
- 累积后悔增长速率趋近平缓

#### 常见问题调试
| 现象 | 原因 | 解决方案 |
|------|------|----------|
| Q值全部接近0 | 探索率过低，陷入次优 | 提高初始ε，使用乐观初始化 |
| 后悔增长过快 | 探索率过高 | 提高衰减率，降低初始ε |
| Q值波动大 | 奖励方差大 | 增加拉动次数，使用步长平滑 |

## 5. 应用场景
### 5.1 完整应用案例
#### 案例1：在线广告点击率优化
- 臂：5版广告素材
- 状态：无（或用户基础特征，升级为上下文老虎机）

- 奖励：用户点击（1）或未点击（0）

- 臂：3种癌症治疗方案
- 动作：给患者分配某方案
- 奖励：患者治愈（1）或未治愈（0）
- 目标：总治愈人数最大化

#### 案例3：推荐系统商品推荐
- 臂：10个推荐商品
- 动作：给用户展示某商品
- 奖励：用户购买（1）或未购买（0）
- 目标：总交易额最大化

#### 案例4：超参数自动调优
- 臂：8组超参数组合（学习率、batch size等）
- 动作：用某组超参数训练模型
- 奖励：验证集准确率（0-1）
- 目标：平均验证准确率最大化

#### 案例5：A/B测试流量分配
- 臂：2版网页设计
- 动作：给用户展示某版网页
- 奖励：用户转化（1）或未转化（0）
- 目标：总转化量最大化

### 5.2 适用场景特征
| 特征 | 说明 |
|------|------|
| 无状态/弱状态 | 当前决策不影响未来状态 |
| 即时反馈 | 动作后立即获得奖励 |
| 平稳分布 | 奖励分布不随时间变化（或变化缓慢） |
| 小动作空间 | 臂的数量K≤100（大空间用梯度Bandit） |

### 5.3 不适用场景与替代方案
| 不适用场景 | 问题 | 替代方案 |
|----------|------|----------|
| 有用户特征 | 无状态无法适配个性化 | 上下文老虎机 |

## 6. 优缺点分析
### 6.1 优点
1. **实现简单**：核心逻辑仅需几十行代码，无复杂依赖
   - 条件：臂数量K≤1000，无需复杂策略
   - 说明：ε-贪婪、UCB等策略都易于实现
2. **无模型依赖**：不需要假设奖励分布形式，适配任意分布
   - 条件：仅需要奖励反馈，不需要环境模型
   - 说明：相比MDP不需要状态转移概率
3. **在线学习**：每步实时更新，支持流式数据
   - 条件：奖励实时返回
   - 说明：适合动态变化的线上场景
4. **低计算成本**：每步计算复杂度O(1)~O(K)，适合高并发
   - 条件：K≤10000
   - 说明：UCB、ε-贪婪每步仅需简单计算
5. **理论保障充分**：多篇论文给出后悔上界，性能可预期
   - 条件：平稳环境
   - 说明：UCB1、汤普森采样都有严格后悔界

### 6.2 缺点
1. **无状态建模能力**：无法利用上下文特征，适配性差
   - 问题：无法根据用户特征个性化决策
   - 解决方案：升级为上下文老虎机
2. **平稳假设限制**：无法适配快速变化的非平稳环境
   - 问题：奖励分布变化后Q值过时
   - 解决方案：使用滑动窗口、步长更新
3. **探索成本固有**：前期探索会带来较高后悔
   - 问题：前100步可能选择大量次优臂
   - 解决方案：乐观初始化、探索衰减
4. **无法处理延迟奖励**：动作后很久才获得奖励时失效
   - 问题：临床试验需要几个月才获得结果
   - 解决方案：使用强化学习（DQN等）
5. **冷启动问题**：新上线的臂没有历史数据，难以评估
   - 问题：新广告没有点击数据，初始Q值为0
   - 解决方案：乐观初始化、新臂加权探索

### 6.3 算法对比
| 算法 | 后悔速率 | 实现难度 | 适用场景 |
|------|----------|----------|----------|
| 多臂老虎机 | $O(\\sqrt{T})$/$O(\\log T)$ | 低 | 无状态、即时奖励 |
| 上下文老虎机 | $O(\\sqrt{T})$ | 中 | 有状态特征、即时奖励 |
| 强化学习（DQN） | $O(T)$（无理论界） | 高 | 有状态、延迟奖励 |

```python
        Args:
            n_arms: 臂的数量
            epsilon: 初始探索概率（0~1）
            initial_q: 初始Q值（乐观初始化可设为5.0）
        """
        self.n_arms = n_arms
        self.epsilon = epsilon
        self.q_values = np.full(n_arms, initial_q, dtype=np.float64)  # 64位浮点保证精度
        self.pull_counts = np.zeros(n_arms, dtype=np.int64)  # 拉动次数用64位整数
        self.cumulative_reward = 0.0  # 累积奖励
        self.cumulative_regret = 0.0  # 累积后悔
        self.true_means = None  # 真实均值（仅模拟用，真实场景未知）
    
    def set_true_means(self, true_means: List[float]):
        """设置真实均值（仅模拟环境使用）"""
        assert len(true_means) == self.n_arms, "真实均值长度必须等于臂的数量"
        self.true_means = np.array(true_means, dtype=np.float64)
    
    def select_arm(self) -> int:
        """选择臂：ε概率探索，否则利用"""
        if random.random() < self.epsilon:
            return random.randint(0, self.n_arms - 1)  # 探索：随机选臂
        else:
            # 利用：选Q值最大的臂，多个最大值时随机选
            max_q = np.max(self.q_values)
            candidate_arms = np.where(self.q_values == max_q)[0]
            return random.choice(candidate_arms)
    
    def update(self, arm: int, reward: float):
        """更新Q值和统计信息"""
        self.pull_counts[arm] += 1
        # 增量更新Q值：避免存储所有历史奖励
        self.q_values[arm] += (reward - self.q_values[arm]) / self.pull_counts[arm]
        self.cumulative_reward += reward
        # 计算后悔（仅模拟用）
        if self.true_means is not None:
            optimal_reward = np.max(self.true_means)
            self.cumulative_regret += optimal_reward - reward
    
    def decay_epsilon(self, decay_rate: float = 0.995):
        """指数衰减探索率，保留1%最小探索率"""
        self.epsilon *= decay_rate
        self.epsilon = max(self.epsilon, 0.01)

def simulate_mab(
    n_arms: int = 5,
    n_steps: int = 1000,
    epsilon: float = 0.1,
    seed: int = 42
) -> Tuple[EpsilonGreedyMAB, np.ndarray, np.ndarray]:
    """
    模拟多臂老虎机训练过程
    Args:
        n_arms: 臂的数量
        n_steps: 总训练步数
        epsilon: 初始探索率
        seed: 随机种子（保证可复现）
    Returns:
        训练好的智能体, 累积奖励序列, 累积后悔序列
    """
    np.random.seed(seed)
    random.seed(seed)
    # 生成真实均值：最优臂均值比其他臂高0.2
    true_means = np.random.uniform(0, 1, n_arms)
    true_means[0] = np.max(true_means) + 0.2
    # 初始化智能体（乐观初始化Q=5.0）
    agent = EpsilonGreedyMAB(n_arms=n_arms, epsilon=epsilon, initial_q=5.0)
    agent.set_true_means(true_means.tolist())
    # 记录序列
    cumulative_rewards = np.zeros(n_steps, dtype=np.float64)
    cumulative_regrets = np.zeros(n_steps, dtype=np.float64)
    # 训练循环
    for t in range(n_steps):
        arm = agent.select_arm()
        # 生成奖励：高斯分布N(μ_a, 0.1^2)
        reward = np.random.normal(true_means[arm], 0.1)
        agent.update(arm, reward)
        agent.decay_epsilon(0.995)
        cumulative_rewards[t] = agent.cumulative_reward
        cumulative_regrets[t] = agent.cumulative_regret
    # 打印结果
    print(f"真实均值：{np.round(true_means, 2)}")
    print(f"最终Q值：{np.round(agent.q_values, 2)}")
    print(f"最终累积奖励：{agent.cumulative_reward:.2f}")
    print(f"最终累积后悔：{agent.cumulative_regret:.2f}")
    print(f"最优臂拉动次数：{agent.pull_counts[0]}/{n_steps}")
    return agent, cumulative_rewards, cumulative_regrets

if __name__ == "__main__":
    # 运行模拟
    agent, rewards, regrets = simulate_mab(n_arms=5, n_steps=1000, epsilon=0.1)
```

### 8.1 纯Python核心实现（无第三方库）
```python
import random
from typing import List

class ScratchMAB:
    """纯手工实现多臂老虎机核心逻辑（仅用Python标准库）"""
    def __init__(self, n_arms: int):
        self.n_arms = n_arms
        self.q_values = [0.0 for _ in range(n_arms)]  # Q值列表
        self.pull_counts = [0 for _ in range(n_arms)]  # 拉动次数
    
    def select_arm_epsilon_greedy(self, epsilon: float) -> int:
        """ε-贪婪选择臂"""
        if random.random() < epsilon:
            return random.randint(0, self.n_arms - 1)
        else:
            max_q = max(self.q_values)
            best_arms = [i for i, q in enumerate(self.q_values) if q == max_q]
            return random.choice(best_arms)
    
    def update_q(self, arm: int, reward: float):
        """增量更新Q值"""
        self.pull_counts[arm] += 1
        n = self.pull_counts[arm]
        self.q_values[arm] += (reward - self.q_values[arm]) / n
    
    def run(self, true_means: List[float], n_steps: int, epsilon: float = 0.1) -> None:
        """运行模拟（伯努利奖励场景）"""
        assert len(true_means) == self.n_arms, "真实均值长度不匹配"
        total_reward = 0.0
        optimal_arm = true_means.index(max(true_means))
        for t in range(n_steps):
            arm = self.select_arm_epsilon_greedy(epsilon)
            # 伯努利奖励：点击率场景
            reward = 1 if random.random() < true_means[arm] else 0
            self.update_q(arm, reward)
            total_reward += reward
            if (t + 1) % 200 == 0:
                print(f"步数{t+1}：总奖励{total_reward}，最优臂拉动{self.pull_counts[optimal_arm]}次")
        print(f"最终Q值：{[round(q, 2) for q in self.q_values]}")
        print(f"真实均值：{[round(m, 2) for m in true_means]}")
        print(f"总奖励：{total_reward}")

if __name__ == "__main__":
    # 测试：3个臂，点击率0.3、0.5、0.7
    mab = ScratchMAB(n_arms=3)
    true_means = [0.3, 0.5, 0.7]
    mab.run(true_means, n_steps=1000, epsilon=0.1)
```

## 11. 常见问题与易错点
### 5.1 常见陷阱
1. **忘记衰减探索率**
   - 现象：训练后期仍有10%概率随机选臂，后悔持续偏高
   - 原因：固定ε导致无效探索
   - 解决：使用指数衰减或自适应ε

2. **乐观初始化值设置过低**
   - 现象：前期探索不足，陷入次优臂
   - 原因：初始Q=0无法鼓励探索
   - 解决：设置为奖励上限的2倍（如奖励0-1则设Q=2）

3. **非平稳场景使用固定Q值更新**
   - 现象：奖励分布变化后Q值过时，性能下降
   - 原因：未适配分布变化
   - 解决：使用步长更新$Q_{new} = (1-\\alpha)Q_{old} + \\alpha r$

4. **拉动次数未做整数更新**
   - 现象：Q值更新出现浮点误差，结果不稳定
   - 原因：用浮点数记录拉动次数
   - 解决：拉动次数用整数类型（int64）

5. **忽略最优臂的拉动占比**
   - 现象：最优臂拉动次数不足50%，性能差
   - 原因：探索率过高或Q值更新错误
   - 解决：监控臂选择分布，调整探索率

### 11.2 调试技巧
1. 打印前10步的臂选择、奖励、Q值，验证更新逻辑
2. 绘制Q值变化曲线，检查是否趋近真实均值
3. 对比不同ε的累积后悔，选择最优探索率

### 11.3 工程最佳实践
1. 生产环境中记录每步的臂选择、奖励、Q值，用于离线分析
2. 设置探索率报警：如果最优臂占比低于50%，触发报警
3. 定期重置Q值：非平稳场景下每周重置一次Q值，重新探索

多臂老虎机的核心是**平衡探索与利用**，通过在线更新Q值逐步逼近最优臂，最小化总后悔。

## 13. 练习题与思考题
### 13.1 基础题（5道）
1. 多臂老虎机的核心矛盾是什么？
<details>
<summary>答案</summary>
探索与利用的矛盾：探索是尝试未知臂获取信息，利用是选择已知最优臂获取高奖励，需要平衡两者最小化总后悔。
</details>

2. 什么是后悔？如何计算总后悔？
<details>
<summary>答案</summary>
后悔是未选择最优臂带来的奖励损失，总后悔$R_T = T\\mu^* - \\sum_{t=1}^T r_t$，其中$\\mu^*$是最优臂平均奖励。
</details>

3. 乐观初始化的作用是什么？
<details>
<summary>答案</summary>
将初始Q值设为高于真实奖励的值，强制智能体早期探索所有臂，避免陷入次优。
</details>

4. ε-贪婪和UCB的核心区别是什么？
<details>
<summary>答案</summary>
ε-贪婪是随机探索，无理论后悔界；UCB是基于置信上界的确定性探索，有$O(\\sqrt{T})$后悔上界。
</details>

5. 多臂老虎机适用于什么场景？
<details>
<summary>答案</summary>
适用于无状态、即时反馈、平稳奖励的场景，如在线广告、A/B测试、推荐系统。
</details>

### 13.2 进阶题（2道）
1. 推导ε-贪婪算法的期望后悔上界。
<details>
<summary>推导思路</summary>
期望后悔由两部分组成：探索带来的后悔（每次探索概率ε，期望损失$\\Delta_a = \\mu^* - \\mu_a$）和利用带来的错误选择后悔。最终上界为$O(\\frac{K}{\\epsilon} + \\epsilon T)$，最优ε为$\\sqrt{K/T}$，得到$O(\\sqrt{KT})$后悔。
</details>

2. 如何修改多臂老虎机适配非平稳环境？
<details>
<summary>答案</summary>
使用步长更新$Q_{new} = (1-\\alpha)Q_{old} + \\alpha r$，或滑动窗口仅保留最近N步的奖励，或定期重置Q值。
</details>
