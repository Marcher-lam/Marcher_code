## 2. 核心原理

### 本质目标

通过形式化验证与动态知识映射，实现模型决策过程的可验证性与人类认知的兼容性。

### 三大维度

1. **推理路径可视化**：生成带有置信度权重的因果链
2. **注意力语义对齐**：物理方程编码为可微约束矩阵
3. **规则动态兼容**：实时验证推理结果

### 关键技术

- **逻辑链追溯(CoT)**：Chain of Thought，推理步骤的显式化
- **注意力热力图**：展示输入与输出的关联
- **形式化验证**：数学证明决策合理性

## 3. 数学公式与推导

### 注意力权重

$$A_{i,j} = \frac{exp(Q_i \cdot K_j)}{\sum_k exp(Q_i \cdot K_k)}$$

表示输入j对输出i的贡献程度。

### 特征重要性

$$SHAP_i = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|! (|F|-|S|-1)!}{|F|!} [f(S \cup \{i\}) - f(S)]$$

### 可解释性评分

$$Score_{explain} = \alpha \cdot Coherence + \beta \cdot Stability + \gamma \cdot Simplicity$$

## 7. 调库实现

```python
import numpy as np
import torch
import torch.nn as nn

class ExplainableLayer(nn.Module):
    """可解释注意力层"""
    
    def __init__(self, hidden_size, num_heads=4):
        super().__init__()
        self.attention = nn.MultiheadAttention(
            hidden_size, num_heads, batch_first=True
        )
        self.explain_weights = None
        
    def forward(self, x):
        out, weights = self.attention(x, x, x)
        self.explain_weights = weights
        return out
    
    def get_explanation(self):
        """生成解释"""
        if self.explain_weights is None:
            return None
        # 转换为numpy
        weights = self.explain_weights.detach().numpy()
        # 取平均
        avg_weights = weights.mean(axis=0)
        return avg_weights

class ExplanationGenerator:
    """解释生成器"""
    
    def __init__(self, model):
        self.model = model
        
    def generate_reasoning_chain(self, input_data):
        """生成推理链"""
        # 简化实现：返回模拟推理步骤
        steps = [
            "检测到输入数据",
            "计算特征表示",
            "与历史模式匹配",
            "生成最终预测"
        ]
        return steps
        
    def highlight_important_features(self, input_data):
        """重要特征高亮"""
        # 模拟：返回特征重要性
        importance = np.random.rand(input_data.shape[1])
        importance = importance / importance.sum()
        return importance

# 使用示例
print("=== 可解释性模块 ===\n")

model = ExplainableLayer(hidden_size=256, num_heads=4)
generator = ExplanationGenerator(model)

input_data = torch.randn(1, 10, 256)
output = model(input_data)

explanation = generator.generate_reasoning_chain(input_data)
print("推理步骤:")
for i, step in enumerate(explanation):
    print(f"  {i+1}. {step}")
```

## 8. 手工代码实现

```python
import numpy as np

class SimpleExplainer:
    """简化版解释器"""
    
    def __init__(self, model_weights):
        self.weights = model_weights
        
    def compute_feature_importance(self, features):
        """计算特征重要性"""
        importance = np.abs(self.weights.flatten()) * np.abs(features)
        importance = importance / importance.sum()
        return importance
        
    def generate_explanation(self, prediction, features, top_k=3):
        """生成解释"""
        # 特征重要性
        importance = self.compute_feature_importance(features)
        
        # 选Top-K重要特征
        top_indices = np.argsort(importance)[-top_k:]
        
        explanation = []
        for idx in top_indices:
            explanation.append({
                'feature': f'特征{idx}',
                'importance': importance[idx],
                'value': features[idx]
            })
        
        return explanation
        
    def format_explanation(self, prediction, features):
        """格式化解释"""
        explanation = self.generate_explanation(prediction, features)
        
        text = f"预测结果: 类{prediction}\n\n"
        text += "重要特征:\n"
        for i, exp in enumerate(explanation):
            text += f"{i+1}. {exp['feature']}: {exp['importance']:.3f}\n"
            
        return text
```

## 10. 模型评估

### 评估指标

1. **解释完整性**：是否覆盖所有决策因素
2. **解释一致性**：相似输入的解释相似性
3. **计算效率**：解释生成速度
4. **用户理解度**：人类对解释的理解程度

### 计算代码

```python
def evaluate_explainability(explanations, features, predictions):
    """评估可解释性"""
    # 1. 特征覆盖率
    covered = sum(1 for exp in explanations if exp['importance'] > 0.1)
    coverage = covered / len(features)
    
    # 2. 解释一致性
    consistency = np.std([exp['importance'] for exp in explanations])
    
    print(f"可解释性评估:")
    print(f"  - 特征覆盖率: {coverage:.1%}")
    print(f"  - 解释一致性: {consistency:.3f}")
    
    return {'coverage': coverage, 'consistency': consistency}
```
