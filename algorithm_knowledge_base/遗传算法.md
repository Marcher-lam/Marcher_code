# 遗传算法 学习文档

> 模拟自然选择和遗传机制的优化算法。

## 1. 算法基础认知

遗传算法（Genetic Algorithm, GA）是进化计算中最著名的方法，模拟自然选择和遗传机制来求解优化问题。

## 2. 核心原理

- 编码（基因）
- 选择（适者生存）
- 交叉（基因交换）
- 变异（基因突变）

## 3. 数学公式

**适应度**：
$$f_{adjusted} = f - f_{min} \text{ 或 } \frac{f - f_{avg}}{f_{max} - f_{avg}}$$

## 4. 训练过程讲解

**参数**：
| 参数 | 作用 | 典型值 |
|------|------|--------|
| pop_size | 种群大小 | 50-200 |
| pc | 交叉概率 | 0.6-0.9 |
| pm | 变异概率 | 0.01-0.1 |
