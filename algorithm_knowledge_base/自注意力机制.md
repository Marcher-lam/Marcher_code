# 自注意力机制学习文档

> 让序列中任意位置直接交互的注意力机制

---

## 1. 算法基础认知

### 1.1 一句话定义

自注意力机制（Self-Attention Mechanism）是深度学习领域最重要的创新之一，它是Transformer架构的核心组成部分。自注意力允许序列中的每个位置同时关注序列中的所有其他位置，直接建模任意两个位置之间的依赖关系，而不需要通过顺序计算（如RNN中的时间步）或局部卷积（如CNN中的卷积核）来传递信息。

### 1.2 直觉类比

想象你在读一本小说：
- **RNN方式**：从第一页逐页读到最后一页
- **CNN方式**：每次读一小段（卷积窗口）
- **自注意力**：翻到任意一页，直接跳到相关页面

自注意力就像"量子阅读"——每个位置都能同时看到整个序列！

## 2. 核心原理

### 2.1 基础公式

自注意力的核心：计算序列内部元素之间的相似度来确定注意力权重，然后用这些权重对序列表示进行加权求和。

给定序列 $X = [x_1, x_2, ..., x_n]$，输出相同长度的序列：

$$\text{Attention}(X) = [\text{Attn}(x_1), \text{Attn}(x_2), ..., \text{Attn}(x_n)]$$

其中：
$$\text{Attn}(x_i) = \sum_{j=1}^{n} \alpha_{i,j} \cdot v_j$$

权重通过 softmax 归一化：
$$\alpha_{i,j} = \frac{\exp(e_{i,j})}{\sum_{k=1}^{n} \exp(e_{i,k})}$$

### 2.2 缩放点积注意力

注意力分数：
$$e_{i,j} = \frac{q_i^T k_j}{\sqrt{d_k}}$$

完整公式：
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

其中 $Q=XW^Q$, $K=XW^K$, $V=XW^V$

### 2.3 多头自注意力

单头只能捕捉一种依赖，多头并行捕捉多种：

$$\text{MultiHead}(X) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O$$

每个头的计算：
$$\text{head}_i = \text{Attention}(XW_i^Q, XW_i^K, XW_i^V)$$

## 3. 数学公式与推导

### 3.1 Q/K/V映射

设输入序列 $X \in \mathbb{R}^{n \times d}$：

1. **线性投影**：
$$Q = XW^Q, K = XW^K, V = XW^V$$

其中 $W^Q, W^K, W^V \in \mathbb{R}^{d \times d}$

2. **注意力分数**：
$$E = \frac{QK^T}{\sqrt{d_k}}, E \in \mathbb{R}^{n \times n}$$

3. **Softmax归一化**：
$$A = \text{softmax}(E), A \in \mathbb{R}^{n \times n}$$

4. **加权求和**：
$$O = AV, O \in \mathbb{R}^{n \times d}$$

### 3.2 为什么需要缩放因子？

设 $q$ 和 $k$ 是独立同分布随机向量，均值0方差1：

$$\mathbb{E}[q^T k] = \mathbb{E}[q]^T \mathbb{E}[k] = 0$$

$$\text{Var}(q^T k) = d_k \cdot \text{Var}(q) \cdot \text{Var}(k) = d_k$$

当 $d_k$ 很大时，点积方差很大，softmax接近one-hot分布，梯度很小。除以 $\sqrt{d_k}$ 可以归一化方差：

$$\text{Var}\left(\frac{q^T k}{\sqrt{d_k}}\right) = 1$$

### 3.3 位置编码

自注意力是位置无关的，需要位置编码：

$$x_i' = x_i + p_i$$

**正弦/余弦编码**：
$$p_{i,2j} = \sin\left(\frac{i}{10000^{2j/d}}\right)$$
$$p_{i,2j+1} = \cos\left(\frac{i}{10000^{2j/d}}\right)$$

### 3.4 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|----------|------------|
| Q/K/V投影 | O(n·d²) | O(n·d) |
| 注意力计算 | O(n²·d) | O(n²) |
| 总计 | O(n²·d) | O(n²) |

## 4. PyTorch实现

### 4.1 基础自注意力

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class SelfAttention(nn.Module):
    """自注意力层"""
    
    def __init__(self, d_model, n_heads, dropout=0.1):
        super(SelfAttention, self).__init__()
        
        assert d_model % n_heads == 0
        
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        
        self.W_Q = nn.Linear(d_model, d_model)
        self.W_K = nn.Linear(d_model, d_model)
        self.W_V = nn.Linear(d_model, d_model)
        self.W_O = nn.Linear(d_model, d_model)
        
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        """
        Args:
            x: (batch, seq_len, d_model)
            mask: (batch, seq_len, seq_len)
        
        Returns:
            output: (batch, seq_len, d_model)
            attention_weights: (batch, n_heads, seq_len, seq_len)
        """
        batch_size, seq_len, _ = x.size()
        
        # 线性投影
        Q = self.W_Q(x)
        K = self.W_K(x)
        V = self.W_V(x)
        
        # 分头 (batch, n_heads, seq_len, d_k)
        Q = Q.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        
        # 缩放点积注意力
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        # 掩码处理
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        
        # Softmax
        attn_weights = F.softmax(scores, dim=-1)
        attn_weights = self.dropout(attn_weights)
        
        # 加权求和
        context = torch.matmul(attn_weights, V)
        
        # 合并头
        context = context.transpose(1, 2).contiguous().view(
            batch_size, seq_len, self.d_model)
        
        output = self.W_O(context)
        
        return output, attn_weights
```

### 4.2 多头注意力（完整）

```python
class MultiHeadSelfAttention(nn.Module):
    """多头自注意力（带残差）"""
    
    def __init__(self, d_model, n_heads, dropout=0.1):
        super(MultiHeadSelfAttention, self).__init__()
        
        self.self_attn = SelfAttention(d_model, n_heads, dropout)
        self.norm = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        attn_output, attn_weights = self.self_attn(x, mask)
        x = self.norm(x + self.dropout(attn_output))
        
        return x, attn_weights


class TransformerBlock(nn.Module):
    """Transformer块"""
    
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super(TransformerBlock, self).__init__()
        
        self.self_attn = SelfAttention(d_model, n_heads, dropout)
        self.norm1 = nn.LayerNorm(d_model)
        
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout)
        )
        self.norm2 = nn.LayerNorm(d_model)
    
    def forward(self, x, mask=None):
        # 自注意力 + 残差
        attn_output, _ = self.self_attn(x, mask)
        x = self.norm1(x + attn_output)
        
        # 前馈 + 残差
        ffn_output = self.ffn(x)
        x = self.norm2(x + ffn_output)
        
        return x
```

### 4.3 位置���码

```python
class SinusoidalPositionalEncoding(nn.Module):
    """正弦位置编码"""
    
    def __init__(self, d_model, max_len=5000, dropout=0.1):
        super(SinusoidalPositionalEncoding, self).__init__()
        self.dropout = nn.Dropout(p=dropout)
        
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * 
                    (-math.log(10000.0) / d_model))
        
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        
        pe = pe.unsqueeze(0)
        self.register_buffer('pe', pe)
    
    def forward(self, x):
        x = x + self.pe[:, :x.size(1)]
        return self.dropout(x)


class LearnedPositionalEncoding(nn.Module):
    """可学习位置编码"""
    
    def __init__(self, d_model, max_len=5000, dropout=0.1):
        super(LearnedPositionalEncoding, self).__init__()
        self.dropout = nn.Dropout(p=dropout)
        self.pe = nn.Embedding(max_len, d_model)
    
    def forward(self, x):
        batch_size, seq_len, _ = x.size()
        position_ids = torch.arange(seq_len, device=x.device)
        position_ids = position_ids.unsqueeze(0).expand(batch_size, seq_len)
        
        x = x + self.pe(position_ids)
        return self.dropout(x)
```


### 4.4 完整Transformer编码器

```python
class TransformerEncoder(nn.Module):
    """Transformer编码器"""
    
    def __init__(self, vocab_size, d_model=512, n_heads=8, n_layers=6,
                 d_ff=2048, dropout=0.1, max_len=5000):
        super(TransformerEncoder, self).__init__()
        
        self.d_model = d_model
        
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.pos_encoding = SinusoidalPositionalEncoding(d_model, max_len, dropout)
        
        self.layers = nn.ModuleList([
            TransformerBlock(d_model, n_heads, d_ff, dropout)
            for _ in range(n_layers)
        ])
        
        self.norm = nn.LayerNorm(d_model)
    
    def forward(self, x, mask=None):
        # 嵌入 + 位置编码
        x = self.embedding(x) * math.sqrt(self.d_model)
        x = self.pos_encoding(x)
        
        # 逐层通过
        for layer in self.layers:
            x = layer(x, mask)
        
        return self.norm(x)


class MaskCreator:
    """掩码创建工具"""
    
    @staticmethod
    def create_padding_mask(seq, pad_idx=0):
        """填充掩码"""
        return (seq != pad_idx)
    
    @staticmethod
    def create_causal_mask(seq_len):
        """因果掩码（解码器用）"""
        mask = torch.triu(
            torch.ones(seq_len, seq_len), 
            diagonal=1
        ).bool()
        return mask
    
    @staticmethod
    def create_causal_padding_mask(seq, pad_idx=0):
        """因果+填充掩码"""
        padding_mask = MaskCreator.create_padding_mask(seq, pad_idx)
        seq_len = seq.size(1)
        causal_mask = MaskCreator.create_causal_mask(seq_len)
        return padding_mask & ~causal_mask
```

### 6.1 Linear Attention

```python
class LinearAttention(nn.Module):
    """线性注意力（O(n)复杂度）"""
    
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        
        # 核函数
        self.k_proj = nn.Linear(d_model, d_model)
        self.v_proj = nn.Linear(d_model, d_model)
        self.q_proj = nn.Linear(d_model, d_model)
    
    def forward(self, x):
        K = self.k_proj(x)
        V = self.v_proj(x)
        Q = self.q_proj(x)
        
        # 特征映射
        K = torch.relu(K)
        
        # 简化注意力
        attn = torch.matmul(Q, K.transpose(-2, -1))
        attn = attn / math.sqrt(self.d_k)
        
        return torch.matmul(attn, V)
```

### 6.2 Relative Position Attention

```python
class RelativePositionAttention(nn.Module):
    """相对位置注意力"""
    
    def __init__(self, d_model, n_heads, max_relative=20):
        super().__init__()
        self.relative_embeddings = nn.Embedding(2 * max_relative + 1, d_model)
    
    def forward(self, x):
        # 计算相对位置
        seq_len = x.size(1)
        
        # 相对位置ID
        ids = torch.arange(seq_len, device=x.device)
        relative_ids = ids.unsqueeze(0) - ids.unsqueeze(1)
        relative_ids = relative_ids.clamp(-max_relative, max_relative)
        
        # 添加偏置
        bias = self.relative_embeddings(relative_ids + max_relative)
        
        return x + bias
```

## 7. 常见问题

### Q1: 自注意力的时间复杂度？

O(n²·d)，其中n是序列长度。序列长时瓶颈。

### Q2: 为什么用多层？

- 6-12层逐步提取特征
- 浅层：局部特征
- 深层：全局特征

### Q3: mask的作用？

- 填充掩码：忽略padding
- 因果掩码：防止看到未来
- 跨段落掩码：段落边界

def simple_self_attention(x):
    """简化版自注意力"""
    d = x.size(-1)
    
    # Q=K=V=X
    scores = torch.matmul(x, x.transpose(-2, -1)) / math.sqrt(d)
    attn = F.softmax(scores, dim=-1)
    
    return torch.matmul(attn, x)
