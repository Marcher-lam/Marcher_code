# 文本数据预处理 学习文档

> 为NLP模型提供高质量、规范化的文本输入

## 1. 算法基础认知

文本数据预处理是自然语言处理（NLP）任务中至关重要的第一步，它直接影响着后续模型训练的效果和性能。在实际应用中，原始文本数据往往包含大量的噪声信息，如HTML标签、特殊符号、标点符号、多余的空格、不一致的大小写格式等。这些噪声不仅会干扰模型的学习过程，还会增加计算的复杂度，降低模型的泛化能力。

文本数据预处理的核心目标是将原始、非结构化的文本数据转换为规范化、结构化的形式，使其能够被机器学习模型有效处理。这个过程涉及多个步骤，包括但不限于：文本清洗（去除HTML标签、特殊字符）、标准化（统一大小写、规范化空格）、分词（将文本切分为词语或字符序列）、去除停用词等。

与计算机视觉领域不同，文本数据是非结构化的，具有高度的灵活性和多样性。同一段语义内容可能以多种不同的形式呈现，例如"Hello World!"、"hello world"和"HELLO WORLD!"在语义上是相同的，但在字符串层面却完全不同。通过预处理，我们可以消除这些不必要的差异，使模型能够专注于学习文本的语义信息，而不是被表面的字符串差异所干扰。

此外，预处理还有助于解决数据稀疏问题。在大规模语料库中，如果不进行预处理，模型可能需要为每个变体形式单独学习表示，这会造成参数空间的浪费。通过规范化处理，可以将相似的文本形式映射到统一的表示，从而提高数据利用效率。

文本预处理不仅适用于传统的NLP任务（如文本分类、情感分析），对于现代深度学习模型（如BERT、GPT等）同样重要。虽然这些预训练模型具有一定的鲁棒性，但合理的预处理仍然能够提升模型性能，加速训练收敛，并减少过拟合的风险。

## 2. 核心原理

文本数据预处理的原理基于信息论和语言学的基本假设：原始文本中包含的信息对于特定任务而言，并非所有字符和格式都具有同等重要性。预处理通过去除无关信息、规范化表示形式，使得文本数据更加紧凑、一致，便于模型学习有效的特征表示。

预处理流程通常包括以下几个核心步骤，每个步骤都针对特定的噪声类型或格式问题：

**大小写规范化**：英语等语言中，大小写通常不改变词义，但在字符串层面却代表不同的token。将所有文本转换为小写（或大写）可以显著减少词汇表的大小，避免模型为同一词的不同大小写形式学习不同的表示。例如，"Natural"、"natural"和"NATURAL"应该被视为同一个词。

**去除特殊字符和标点符号**：标点符号和特殊字符（如@、#、$、%等）在大多数NLP任务中并不携带关键的语义信息，反而可能增加噪声。通过正则表达式可以高效地识别并移除这些字符。但需要注意，某些任务（如情感分析）中，感叹号、问号等可能携带情感信息，需要根据具体任务决定是否保留。

**HTML标签清理**：在网络爬虫获取的文本数据中，经常包含HTML标签（如`<p>`、`</div>`、`<br>`等）。这些标签对于理解文本内容没有帮助，反而会干扰分词和特征提取。使用正则表达式（如`<.*?>`）可以匹配并移除这些标签。

**数字处理**：数字在文本中的处理方式多样。在某些情况下，数字可能包含重要信息（如价格、年份），需要保留；而在其他情况下，数字可能被视为噪声。常见的处理策略包括：完全移除数字、将数字替换为特殊标记（如`<NUM>`）、或将数字标准化（如将"123"和"456"都转换为`<NUM>`）。

**空格规范化**：文本中可能包含多种空格字符（空格、制表符、换行符、全角空格等）以及连续的多个空格。规范化空格可以确保词语之间有统一的间隔，避免因空格不一致导致的分词错误。

**处理中文特殊问题**：中文文本预处理还面临一些特殊挑战，如全角/半角字符转换、中文标点符号处理、繁体/简体转换等。全角空格（\u3000）需要转换为半角空格，以确保分词器能够正确识别词语边界。

预处理的核心思想是在保留语义信息的前提下，尽可能简化文本的表示形式。这需要权衡：过度预处理可能丢失有用信息（如大小写可能表示专有名词），而预处理不足则可能保留过多噪声。优秀的预处理流程应该根据具体的任务需求和数据集特点进行定制。

## 3. 数学公式与推导

虽然文本预处理主要是一个工程实践过程，但我们可以从信息论的角度来理解其数学原理。

**信息熵与数据清洗**

根据信息论，文本数据的信息熵可以表示为：

$$H(X) = -\sum_{x \in X} p(x) \log p(x)$$

其中 $X$ 表示所有可能的文本单元（字符、词或子词），$p(x)$ 是单元 $x$ 出现的概率。

预处理的目标是最大化"有效信息"与"总信息"的比值。我们可以将文本数据 $T$ 分解为有效信息部分 $I$ 和噪声部分 $N$：

$$T = I \cup N, \quad I \cap N = \emptyset$$

预处理函数 $P$ 的目标是找到一个映射：

$$P: T \rightarrow T'$$

使得：

$$\frac{|I \cap T'|}{|T'|} > \frac{|I \cap T|}{|T|}$$

即预处理后的文本中，有效信息的密度更高。

**词汇表压缩率**

预处理通过规范化可以显著压缩词汇表大小。假设原始文本中有 $V$ 个不同的token，经过大小写规范化后，词汇表大小可以减少为：

$$V_{lower} = V - |\{w \in V : \exists w' \in V, w' = lower(w), w' \neq w\}|$$

这表示所有因大小写差异而产生的重复token被合并。

**正则表达式的形式化**

正则表达式用于模式匹配，其数学基础是有限状态自动机（Finite State Automaton, FSA）。一个正则表达式 $r$ 可以转换为一个FSA $M = (Q, \Sigma, \delta, q_0, F)$，其中：
- $Q$ 是状态集合
- $\Sigma$ 是字母表（如所有Unicode字符）
- $\delta: Q \times \Sigma \rightarrow Q$ 是转移函数
- $q_0 \in Q$ 是初始状态
- $F \subseteq Q$ 是接受状态集合

例如，正则表达式 `r'[^\w\s]'` 对应的FSA会接受所有非单词字符和非空格字符，用于匹配特殊字符。

**标点符号去除的数学表示**

定义标点符号集合 $P = \{p_1, p_2, ..., p_n\}$，文本 $T$ 可以表示为字符序列 $c_1, c_2, ..., c_m$。去除标点符号的操作可以表示为：

$$T' = \{c_i : c_i \notin P, i = 1, 2, ..., m\}$$

用集合表示即为：$T' = T \setminus P$

**空格规范化的概率模型**

假设文本中空格的分布遵循某种概率分布。连续的多个空格可以视为重复采样的结果。规范化操作可以表示为：

$$\text{normalize\_spaces}(s) = \begin{cases} 
\text{single\_space} & \text{if } s \in \{\text{space}^+\} \\
s & \text{otherwise}
\end{cases}$$

其中 $\text{space}^+$ 表示一个或多个空格字符的序列。

**中文全角/半角转换**

全角字符和半角字符在Unicode中的编码有固定的偏移量。对于ASCII可打印字符（32-126），全角形式从65281开始，转换公式为：

$$\text{halfwidth}(c) = \begin{cases}
chr(ord(c) - 65248) & \text{if } 65281 \leq ord(c) \leq 65374 \\
chr(32) & \text{if } ord(c) = 12288 \text{ (全角空格)} \\
c & \text{otherwise}
\end{cases}$$

这种转换可以确保中文文本中的英文字符和标点与标准ASCII字符一致，便于后续处理。

## 4. 训练过程讲解

文本数据预处理本身不涉及模型训练，它是训练前的数据准备阶段。然而，理解预处理在整个机器学习流程中的位置和执行方式至关重要。

**预处理流程的执行步骤**

1. **数据加载**：首先从数据源（文件、数据库、API等）加载原始文本数据。数据可能包含各种编码格式（UTF-8、GBK等），需要正确识别和转换。

2. **定义预处理管道**：根据任务需求，设计一个由多个预处理步骤组成的数据处理管道（pipeline）。每个步骤都是一个纯函数，接收文本输入并返回处理后的文本。

3. **批量处理**：对于大规模数据集，通常需要批量处理文本。可以使用pandas的`apply`方法、Python的列表推导式，或者更高效的向量化操作。

4. **缓存中间结果**：对于耗时的预处理操作（如复杂的分词），可以考虑将预处理后的数据缓存到磁盘，避免重复计算。

**预处理与模型训练的集成**

在现代深度学习框架中，预处理可以作为数据加载器（DataLoader）的一部分，实现在线预处理：

```python
# 伪代码示例
class TextDataset:
    def __init__(self, texts, preprocess_fn):
        self.texts = texts
        self.preprocess_fn = preprocess_fn
    
    def __getitem__(self, idx):
        text = self.texts[idx]
        processed = self.preprocess_fn(text)  # 在线预处理
        return processed
```

这种方式的优点是节省内存，缺点是每个epoch都需要重新预处理。

**预处理的参数选择**

预处理涉及多个超参数，如：
- 是否保留数字？如何处理？
- 标点符号的保留策略？
- 停用词表的选择？
- 最小词频阈值？

这些参数的选择应该通过实验确定，在验证集上评估不同预处理策略的效果。

**常见的预处理错误**

1. **数据泄漏**：在预处理阶段使用整个数据集的信息（如计算全局词汇表、TF-IDF等），然后划分训练集和测试集。这会导致测试集信息泄漏到训练中。

2. **预处理顺序错误**：例如，先分词再去标点，可能导致标点符号附着在词语上，难以去除。正确的顺序应该是先去除标点，再分词。

3. **忽略边界情况**：空字符串、None值、极短文本等边界情况需要特殊处理，否则可能导致程序崩溃或模型训练失败。

## 5. 应用场景

**1. 文本分类任务**
在情感分析、垃圾邮件检测、新闻分类等文本分类任务中，预处理是标准流程。例如，在电影评论情感分析中，去除HTML标签、标点符号，统一大小写，可以让模型专注于情感词的学习，而不是被格式差异干扰。预处理后的文本更加规范，有利于提取有效的情感特征。

**2. 机器翻译**
神经机器翻译系统需要处理源语言和目标语言的文本。预处理包括：统一标点符号格式、处理数字（如将数字转换为特殊token）、分词（中文需要分词，英文可以使用BPE等子词分词）。良好的预处理可以减少翻译错误，提高BLEU分数。

**3. 搜索引擎和文档检索**
搜索引擎需要对文档和查询进行预处理，以便进行索引和匹配。预处理步骤包括：去除停用词、词干提取（stemming）、词形还原（lemmatization）等。这使得搜索"running"能够匹配包含"run"的文档，提高检索的召回率。

**4. 大型语言模型（LLM）预训练**
在GPT、BERT等大型模型的预训练过程中，预处理尤为重要。虽然这些模型具有一定的鲁棒性，但合理的预处理可以减少噪声，提高训练效率。例如，去除低质量的网页内容、规范化Unicode字符、处理特殊token等。

**5. 中文NLP任务**
中文文本预处理面临特殊挑战：没有天然的词边界、存在全角/半角字符、繁体/简体差异等。预处理包括：繁体转简体、全角转半角、中文分词等。例如，在中文命名实体识别任务中，正确的分词是准确识别实体的前提。

## 6. 优缺点分析

**优点：**

1. **提高数据质量**：预处理能够有效去除噪声和无关信息，使模型专注于学习有用的特征，提高训练效率和模型性能。

2. **减少词汇表大小**：通过大小写规范化、词干提取等操作，可以显著减少唯一token的数量，降低模型参数量，减少过拟合风险。

3. **增强模型泛化能力**：规范化的文本表示使模型能够学习到更通用的模式，而不是记忆特定格式的细节，从而提高对未见数据的泛化能力。

4. **提高训练速度**：去除冗余信息后，输入序列变短，计算量减小，训练速度加快。同时，更小的词汇表也意味着更高效的embedding查找。

5. **统一数据格式**：预处理确保数据具有一致的格式，便于批处理和数据流水线管理，减少因格式不一致导致的错误。

**缺点：**

1. **可能丢失有用信息**：过度预处理可能移除对任务有用的信息。例如，在情感分析中，感叹号可能表示强烈的情感，全部移除可能降低模型性能。

2. **任务依赖性**：预处理策略高度依赖于具体任务，没有通用的"最佳"预处理流程。需要针对每个任务进行调整和实验。

3. **计算开销**：对于大规模数据集，预处理可能非常耗时，尤其是复杂的分词、词形还原等操作。需要权衡预处理时间和收益。

4. **不可逆性**：某些预处理操作（如去除标点符号）是不可逆的，一旦执行就无法恢复原始文本。这在需要原始文本进行解释或后处理时可能造成问题。

5. **语言和领域适应性**：预处理规则通常针对特定语言或领域设计。将英文的预处理流程直接应用于中文可能无效，甚至有害。需要针对不同的语言和领域定制预处理策略。

**对比表：**

| 预处理操作 | 适用场景 | 优点 | 缺点 |
|-----------|---------|------|------|
| 大小写规范化 | 英文文本分类、检索 | 减少词汇表，提高一致性 | 可能丢失专有名词信息 |
| 去除标点 | 通用NLP任务 | 减少噪声，简化文本 | 可能丢失情感或语法信息 |
| 数字处理 | 通用任务 | 减少稀疏性 | 可能丢失数值信息 |
| 去除HTML标签 | 网络文本处理 | 清理网页噪声 | 无（通常是必要的） |
| 中文分词 | 中文NLP任务 | 明确词边界 | 分词错误会传播到后续任务 |

## 7. 调库实现

以下是使用Python标准库和主流NLP库进行文本预处理的完整实现：

```python
import re
import string
import pandas as pd
import numpy as np
from typing import List, Optional
import unicodedata

# ============================================
# 英文文本预处理
# ============================================

def preprocess_english_text(
    text: str,
    lowercase: bool = True,
    remove_punctuation: bool = True,
    remove_numbers: bool = True,
    remove_html: bool = True,
    remove_extra_spaces: bool = True,
    remove_stopwords: bool = False,
    stopwords_list: Optional[List[str]] = None
) -> str:
    """
    英文文本预处理函数
    
    参数:
        text: 原始文本字符串
        lowercase: 是否转换为小写
        remove_punctuation: 是否去除标点符号
        remove_numbers: 是否去除数字
        remove_html: 是否去除HTML标签
        remove_extra_spaces: 是否去除多余空格
        remove_stopwords: 是否去除停用词
        stopwords_list: 停用词列表，如果remove_stopwords为True则需要提供
    
    返回:
        预处理后的文本字符串
    """
    if not isinstance(text, str):
        return ""
    
    # 1. 去除前后空格
    text = text.strip()
    
    # 2. 转换为小写
    if lowercase:
        text = text.lower()
    
    # 3. 去除HTML标签
    if remove_html:
        text = re.sub(r'<[^<]+?>', '', text)  # 去除HTML标签
        text = re.sub(r'&[a-z]+;', '', text)   # 去除HTML实体如 &nbsp; &amp;等
    
    # 4. 去除数字
    if remove_numbers:
        text = re.sub(r'\d+', '', text)
    
    # 5. 去除标点符号
    if remove_punctuation:
        # 使用string.punctuation包含所有英文标点
        text = text.translate(str.maketrans('', '', string.punctuation))
    
    # 6. 去除多余空格
    if remove_extra_spaces:
        text = re.sub(r'\s+', ' ', text)
        text = text.strip()
    
    # 7. 去除停用词（可选）
    if remove_stopwords and stopwords_list:
        words = text.split()
        words = [w for w in words if w not in stopwords_list]
        text = ' '.join(words)
    
    return text


# ============================================
# 中文文本预处理
# ============================================

def preprocess_chinese_text(
    text: str,
    remove_punctuation: bool = True,
    remove_extra_spaces: bool = True,
    fullwidth_to_halfwidth: bool = True,
    traditional_to_simplified: bool = False  # 需要opencc库支持
) -> str:
    """
    中文文本预处理函数
    
    参数:
        text: 原始中文文本字符串
        remove_punctuation: 是否去除标点符号
        remove_extra_spaces: 是否去除多余空格
        fullwidth_to_halfwidth: 是否将全角字符转换为半角
        traditional_to_simplified: 是否将繁体转换为简体（需要额外库）
    
    返回:
        预处理后的文本字符串
    """
    if not isinstance(text, str):
        return ""
    
    # 1. 去除前后空格
    text = text.strip()
    
    # 2. 全角转半角
    if fullwidth_to_halfwidth:
        text = fullwidth_to_halfwidth_convert(text)
    
    # 3. 繁体转简体（如果需要）
    if traditional_to_simplified:
        try:
            import opencc
            converter = opencc.OpenCC('t2s.json')  # 繁体到简体
            text = converter.convert(text)
        except ImportError:
            print("警告: 需要安装opencc库来进行繁简转换: pip install opencc")
    
    # 4. 去除标点符号
    if remove_punctuation:
        # 匹配所有中文标点符号和特殊字符，保留汉字、数字、英文字母和空格
        text = re.sub(r'[^\u4e00-\u9fa5a-zA-Z0-9\s]', '', text)
    
    # 5. 去除多余空格
    if remove_extra_spaces:
        text = re.sub(r'\s+', ' ', text)
        text = text.strip()
    
    return text


def fullwidth_to_halfwidth_convert(text: str) -> str:
    """
    将全角字符转换为半角字符
    
    参数:
        text: 包含全角字符的文本
    
    返回:
        转换后的文本
    """
    result = []
    for char in text:
        code = ord(char)
        # 全角空格（\u3000）转为半角空格
        if code == 0x3000:
            result.append(' ')
        # 全角字符（\uFF01-\uFF5E）转为半角字符
        elif 0xFF01 <= code <= 0xFF5E:
            result.append(chr(code - 0xFEE0))
        else:
            result.append(char)
    return ''.join(result)
```

## 8. 手工代码实现

以下是从零开始实现的文本预处理类，不依赖外部NLP库，完全使用Python标准库实现：

```python
import re
import string
from typing import List, Set, Optional, Callable
from collections import Counter

class TextPreprocessor:
    """
    文本预处理器类 - 从零实现
    支持英文和中文文本的基础预处理操作
    """
    
    def __init__(
        self,
        language: str = 'english',
        lowercase: bool = True,
        remove_punctuation: bool = True,
        remove_numbers: bool = True,
        remove_html: bool = True,
        normalize_spaces: bool = True,
        remove_stopwords: bool = False,
        custom_stopwords: Optional[Set[str]] = None
    ):
        """
        初始化预处理器
        
        参数:
            language: 文本语言，'english' 或 'chinese'
            lowercase: 是否转为小写（仅英文有效）
            remove_punctuation: 是否去除标点
            remove_numbers: 是否去除数字
            remove_html: 是否去除HTML标签
            normalize_spaces: 是否规范化空格
            remove_stopwords: 是否去除停用词
            custom_stopwords: 自定义停用词集合
        """
        self.language = language
        self.lowercase = lowercase
        self.remove_punctuation = remove_punctuation
        self.remove_numbers = remove_numbers
        self.remove_html = remove_html
        self.normalize_spaces = normalize_spaces
        self.remove_stopwords = remove_stopwords
        
        # 初始化停用词
        self.stopwords = custom_stopwords if custom_stopwords else set()
        if remove_stopwords and not custom_stopwords:
            if language == 'english':
                self.stopwords = self._get_default_english_stopwords()
            elif language == 'chinese':
                self.stopwords = self._get_default_chinese_stopwords()
    
    def _get_default_english_stopwords(self) -> Set[str]:
        """获取默认英文停用词"""
        return {
            'i', 'me', 'my', 'myself', 'we', 'our', 'ours', 'ourselves', 'you',
            'your', 'yours', 'yourself', 'yourselves', 'he', 'him', 'his',
            'himself', 'she', 'her', 'hers', 'herself', 'it', 'its', 'itself',
            'they', 'them', 'their', 'theirs', 'themselves', 'what', 'which',
            'who', 'whom', 'this', 'that', 'these', 'those', 'am', 'is', 'are',
            'was', 'were', 'be', 'been', 'being', 'have', 'has', 'had', 'having',
            'do', 'does', 'did', 'doing', 'a', 'an', 'the', 'and', 'but', 'if',
            'or', 'because', 'as', 'until', 'while', 'of', 'at', 'by', 'for',
            'with', 'about', 'against', 'between', 'into', 'through', 'during',
            'before', 'after', 'above', 'below', 'to', 'from', 'up', 'down',
            'in', 'out', 'on', 'off', 'over', 'under', 'again', 'further',
            'then', 'once', 'here', 'there', 'when', 'where', 'why', 'how',
            'all', 'any', 'both', 'each', 'few', 'more', 'most', 'other', 'some',
            'such', 'no', 'nor', 'not', 'only', 'own', 'same', 'so', 'than',
            'too', 'very', 's', 't', 'can', 'will', 'just', 'don', 'should',
            'now'
        }
    
    def _get_default_chinese_stopwords(self) -> Set[str]:
        """获取默认中文停用词（简化版）"""
        return {
            '的', '了', '在', '是', '我', '有', '和', '就', '不', '人', '都',
            '一', '一个', '上', '也', '很', '到', '说', '要', '去', '你',
            '会', '着', '没有', '看', '好', '自己', '这', '他', '她', '它',
            '那', '些', '什么', '怎么', '吗', '呢', '吧', '啊', '嗯', '哦'
        }
    
    def _remove_html_tags(self, text: str) -> str:
        """去除HTML标签"""
        # 去除HTML标签如 <p>, </div>, <br/> 等
        text = re.sub(r'<[^>]+>', '', text)
        # 去除HTML实体如 &nbsp;, &amp;, &lt; 等
        text = re.sub(r'&[a-zA-Z]+;', '', text)
        return text
    
    def _fullwidth_to_halfwidth(self, text: str) -> str:
        """全角转半角"""
        result = []
        for char in text:
            code = ord(char)
            if code == 0x3000:  # 全角空格
                result.append(' ')
            elif 0xFF01 <= code <= 0xFF5E:  # 全角字符区
                result.append(chr(code - 0xFEE0))
            else:
                result.append(char)
        return ''.join(result)
    
    def process(self, text: str) -> str:
        """
        执行完整的预处理流程
        
        参数:
            text: 原始文本
        
        返回:
            预处理后的文本
        """
        if not isinstance(text, str):
            return ""
        
        # 去除首尾空格
        text = text.strip()
        
        # 去除HTML标签
        if self.remove_html:
            text = self._remove_html_tags(text)
        
        # 语言特定处理
        if self.language == 'english':
            # 英文：转为小写
            if self.lowercase:
                text = text.lower()
            
            # 去除数字
            if self.remove_numbers:
                text = re.sub(r'\d+', '', text)
            
            # 去除标点符号
            if self.remove_punctuation:
                # 使用str.maketrans创建转换表
                translator = str.maketrans('', '', string.punctuation)
                text = text.translate(translator)
        
        elif self.language == 'chinese':
            # 中文：全角转半角
            text = self._fullwidth_to_halfwidth(text)
            
            # 去除标点符号（保留汉字、数字、英文字母）
            if self.remove_punctuation:
                text = re.sub(r'[^\u4e00-\u9fa5a-zA-Z0-9\s]', '', text)
            
            # 中文通常不去除数字，除非特别指定
            if self.remove_numbers:
                text = re.sub(r'\d+', '', text)
        
        # 规范化空格
        if self.normalize_spaces:
            text = re.sub(r'\s+', ' ', text)
            text = text.strip()
        
        # 去除停用词
        if self.remove_stopwords and self.stopwords:
            words = text.split()
            words = [w for w in words if w not in self.stopwords]
            text = ' '.join(words)
        
        return text
    
    def process_batch(self, texts: List[str]) -> List[str]:
        """批量处理文本列表"""
        return [self.process(text) for text in texts]
    
    def get_vocab(self, texts: List[str]) -> Counter:
        """从文本列表中构建词汇表"""
        vocab = Counter()
        for text in texts:
            processed = self.process(text)
            words = processed.split()
            vocab.update(words)
        return vocab


# ============================================
# 使用示例
# ============================================

if __name__ == "__main__":
```

## 10. 模型评估

虽然文本预处理本身不是模型，但我们可以评估预处理对下游任务的影响。以下是评估预处理效果的几种方法：

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import MultinomialNB
from sklearn.metrics import accuracy_score, classification_report
import numpy as np

# 示例：评估预处理对文本分类的影响
# 使用简单的情感分析数据集（简化版）

# 模拟数据：正面和负面评论
texts = [
    "This product is amazing! I love it so much!",
    "Absolutely terrible, worst purchase ever.",
    "Great quality, highly recommend!!!",
    "Poor quality, broke after 2 days. 123 dollars wasted.",
    "Excellent service and fast shipping!",
    "Very disappointed :( not worth the money @#$.",
    "Best buy ever! 5 stars *****",
    "Horrible experience, would not buy again...",
] * 10  # 重复10次以增加数据量

labels = [1, 0, 1, 0, 1, 0, 1, 0] * 10  # 1=正面, 0=负面

# 不预处理的向量化
vectorizer_raw = TfidfVectorizer()
X_raw = vectorizer_raw.fit_transform(texts)

# 预处理后的向量化
processor = TextPreprocessor(
    language='english',
    lowercase=True,
    remove_punctuation=True,
    remove_numbers=True,
    remove_html=False,
    normalize_spaces=True,
    remove_stopwords=True
)

processed_texts = [processor.process(text) for text in texts]
vectorizer_processed = TfidfVectorizer()
X_processed = vectorizer_processed.fit_transform(processed_texts)

# 划分训练集和测试集
X_raw_train, X_raw_test, y_train, y_test = train_test_split(
    X_raw, labels, test_size=0.3, random_state=42
)
X_proc_train, X_proc_test, _, _ = train_test_split(
    X_processed, labels, test_size=0.3, random_state=42
)

# 训练模型（原始文本）
clf_raw = MultinomialNB()
clf_raw.fit(X_raw_train, y_train)
y_pred_raw = clf_raw.predict(X_raw_test)
acc_raw = accuracy_score(y_test, y_pred_raw)

# 训练模型（预处理后文本）
clf_proc = MultinomialNB()
clf_proc.fit(X_proc_train, y_train)
y_pred_proc = clf_proc.predict(X_proc_test)
acc_proc = accuracy_score(y_test, y_pred_proc)

print("=" * 60)
print("预处理效果评估：文本分类准确率")
print("=" * 60)
print(f"原始文本 - 词汇表大小: {len(vectorizer_raw.vocabulary_)}")
print(f"原始文本 - 分类准确率: {acc_raw:.4f}")
print()
print(f"预处理后 - 词汇表大小: {len(vectorizer_processed.vocabulary_)}")
print(f"预处理后 - 分类准确率: {acc_proc:.4f}")
print()
print(f"词汇表压缩: {(1 - len(vectorizer_processed.vocabulary_)/len(vectorizer_raw.vocabulary_))*100:.1f}%")
print(f"准确率变化: {(acc_proc - acc_raw)*100:+.1f}%")

# 特征数量对比
print("\n" + "=" * 60)
print("特征维度对比")
print("=" * 60)
print(f"原始文本特征数: {X_raw.shape[1]}")
print(f"预处理后特征数: {X_processed.shape[1]}")
print(f"特征压缩率: {(1 - X_processed.shape[1]/X_raw.shape[1])*100:.1f}%")
```

**评估指标说明：**

1. **词汇表大小**：预处理后词汇表的唯一词数量。越小表示压缩效果越好，但过度压缩可能丢失信息。

2. **分类准确率**：通过比较预处理前后的分类准确率，可以评估预处理是否有助于模型学习更好的特征。

3. **特征维度**：TF-IDF向量的维度。预处理可以减少特征维度，降低计算复杂度，减少过拟合风险。

4. **训练速度**：预处理后的数据通常更简洁，可以加快模型训练速度（可以通过time模块测量）。

**结果解读：**

在理想情况下，预处理应该能够：
- 减少词汇表大小（压缩率10%-50%是合理的）
- 保持或提高分类准确率
- 加快模型训练速度
- 减少模型过拟合

如果预处理后准确率下降，可能是过度预处理导致丢失了有用信息，需要调整预处理策略。

## 11. 常见问题与易错点

**数据层面问题：**

1. **编码问题**：读取文本文件时可能遇到编码错误。不同来源的文本可能使用UTF-8、GBK、Latin-1等不同编码。解决方法：使用`open(file, encoding='utf-8', errors='ignore')`或在读取时尝试多种编码。

2. **空值和异常值**：数据集中可能包含None、空字符串、或极短的文本。这些需要在预处理前进行过滤或特殊处理，否则可能导致后续处理出错。例如：`df = df[df['text'].notna() & (df['text'].str.len() > 0)]`

3. **语言混合问题**：文本可能包含多种语言（如中英文混合）。通用的预处理流程可能无法正确处理。解决方法：检测文本语言，或使用针对不同语言的预处理管道。

**模型层面问题：**

1. **预处理不一致**：训练时使用了预处理，但推理时忘记使用相同的预处理步骤。这会导致模型输入分布不一致，严重影响性能。必须确保训练、验证、测试使用完全相同的预处理流程。

2. **信息丢失**：过度预处理可能移除对任务有用的信息。例如，在情感分析中去除标点符号可能导致丢失感叹号、问号等情感线索。解决方法：根据具体任务调整预处理策略，保留有用的信息。

3. **停用词移除不当**：盲目使用停用词表可能移除对特定任务有用的词。例如，在情感分析中，"not"是一个重要的否定词，如果将其作为停用词移除，可能完全改变句子的情感。应该使用针对任务的定制停用词表。

**调参问题：**

1. **预处理顺序错误**：不同预处理步骤的顺序很重要。例如，应该先去除HTML标签，再进行小写转换；先去除标点，再分词。错误的顺序可能导致某些模式无法正确匹配。

2. **正则表达式过于激进**：使用过于宽泛的正则表达式可能移除过多内容。例如，`r'[^a-zA-Z\s]'`会移除所有非字母字符，包括数字、标点，甚至某些语言的重音符号。应该根据具体需求精确设计正则表达式。

**调试建议：**

- 始终保留原始数据的备份
- 在预处理管道中添加日志，记录处理前后的文本数量、长度分布等
- 随机抽样检查预处理结果，确保符合预期
- 使用单元测试验证预处理函数的边界情况处理

## 12. 学习总结

文本数据预处理是自然语言处理流程中不可或缺的基础环节，它直接影响着后续所有模型的效果。通过本章的学习，我们深入理解了预处理的原理、方法和实践技巧。

预处理的核心思想是在保留语义信息的前提下，尽可能消除文本中的噪声和无关信息，使文本表示更加规范、一致。主要操作包括：大小写规范化、去除特殊字符和标点、HTML标签清理、数字处理、空格规范化等。对于中文文本，还需要处理全角/半角转换、繁体/简体转换等特殊问题。

从工程实践角度，我们学习了如何使用Python标准库和正则表达式实现高效的预处理函数，如何封装可复用的预处理类，以及如何批量化处理大规模文本数据。同时，我们也探讨了预处理效果的评估方法，包括词汇表压缩率、对下游任务性能的影响等。

预处理的挑战在于平衡：过度预处理会丢失有用信息，预处理不足则保留过多噪声。这需要根据具体任务、数据集特点和模型架构来灵活调整预处理策略。优秀的预处理流程应该是任务驱动的，而不是盲目套用通用模板。

此外，我们还认识到预处理的一致性至关重要：训练、验证、测试必须使用完全相同的预处理流程，否则会导致数据分布不一致，严重影响模型性能。在实际应用中，建议将预处理流程封装为可配置的管道，并加入充分的单元测试和日志，确保流程的可靠性和可复现性。

   <details>
   <summary>答案</summary>
   合理顺序：
   1. 去除HTML标签（先清理最外层的噪声）
   2. 转换为小写（在去除标点之前，确保所有字母格式一致）
   3. 去除标点（此时标点符号独立于词语，易于匹配）
   4. 分词（将文本切分为词语）
   5. 去除停用词（在分词后进行）
   
   原因：如果先分词再去HTML标签，标签可能附着在词语上难以去除；如果先去除标点再转小写，顺序上影响不大，但通常先转小写更合理。

2. **正则表达式设计**：编写一个正则表达式，匹配并移除文本中的所有URL（以http://或https://开头的字符串）。

   <details>
   <summary>答案</summary>
   ```python
   import re
   
   def remove_urls(text):
       # 匹配http://或https://开头，直到遇到空格或字符串结束
       pattern = r'https?://\S+'
       return re.sub(pattern, '', text)
   
   # 测试
   text = "Visit my website at https://www.example.com for more info!"
   print(remove_urls(text))  # 输出: Visit my website at  for more info!
   ```

**进阶题：**

3. **中文分词预处理**：设计一个预处理流程，处理包含中英文混合的文本。要求：保留英文单词的原格式，对中文进行分词（可以使用jieba库），并去除中文标点符号。

   <details>
   <summary>答案</summary>
   ```python
   import re
   import jieba  # 需要先安装: pip install jieba
   
   def preprocess_mixed_text(text):
       # 分离中英文（简化方法：按字符判断）
       # 这里使用正则表达式找到所有中文字符和所有英文单词
       
       # 去除中文标点
       text = re.sub(r'[^\u4e00-\u9fa5a-zA-Z0-9\s]', '', text)
       
       # 对中文部分使用jieba分词
       # 使用一个技巧：将英文单词替换为占位符，分词后再恢复
       import re
       english_words = re.findall(r'[a-zA-Z]+', text)
       for i, word in enumerate(english_words):
           text = text.replace(word, f'__ENG_{i}__', 1)
       
       # 中文分词
       words = jieba.lcut(text)
       
       # 恢复英文单词
       result = []
       eng_idx = 0
       for word in words:
           if word.startswith('__ENG_') and word.endswith('__'):
               result.append(english_words[eng_idx])
               eng_idx += 1
           else:
               result.append(word)
       
       return ' '.join(result)
   
   # 测试
   text = "我在学习NLP，Python非常有用！"
   print(preprocess_mixed_text(text))
   ```
   </details>

4. **预处理管道设计**：设计一个可配置的预处理管道类，支持添加多个预处理步骤，并能够保存/加载配置。要求使用装饰器或函数式编程思想。

   <details>
   <summary>答案</summary>
   ```python
   from typing import List, Callable, Any
   import json
   
   class PreprocessingPipeline:
       def __init__(self, steps=None):
           self.steps = steps if steps else []
       
       def add_step(self, func: Callable[[str], str], name: str = None):
           """添加一个预处理步骤"""
           self.steps.append({
               'func': func,
               'name': name or func.__name__
           })
           return self  # 支持链式调用
       
       def process(self, text: str) -> str:
           """执行整个预处理管道"""
           result = text
           for step in self.steps:
               result = step['func'](result)
           return result
       
       def process_batch(self, texts: List[str]) -> List[str]:
           """批量处理"""
           return [self.process(text) for text in texts]
       
       def save_config(self, filepath: str):
           """保存管道配置（仅保存函数名，实际使用时需要重新注册函数）"""
           config = {
               'steps': [step['name'] for step in self.steps]
           }
           with open(filepath, 'w') as f:
               json.dump(config, f)
   
   # 使用示例
   pipeline = PreprocessingPipeline()
   pipeline.add_step(lambda x: x.lower(), 'lowercase')
   pipeline.add_step(lambda x: re.sub(r'\d+', '', x), 'remove_numbers')
   pipeline.add_step(lambda x: re.sub(r'[^\w\s]', '', x), 'remove_punct')
   
   test = "Hello World 123!!!"
   print(pipeline.process(test))  # 输出: hello world
   ```
   </details>

**开放题：**

5. **预处理策略选择**：在不同的NLP任务中（文本分类、命名实体识别、机器翻译、情感分析），预处理策略应该如何调整？请选择两个任务，详细对比其预处理需求的差异。

   <details>
   <summary>参考答案要点</summary>
   - **文本分类**：可以较为激进地去除标点、数字、停用词，因为类别信息通常在关键词中。
   - **命名实体识别（NER）**：需要保留大小写信息（人名、地名等专有名词），不能去除标点（可能影响实体边界识别），通常不做停用词去除。
   - **机器翻译**：需要保留所有语义信息，包括标点、数字格式等，预处理相对保守。
   - **情感分析**：标点符号（如感叹号、问号）可能携带情感信息，需要谨慎处理；否定词（not, never等）必须保留。
   
   对比示例：NER vs 文本分类
   - NER需要保留："Apple Inc. announced..." 中的 "Inc." 和大小写
   - 文本分类可以去除："Apple Inc. announced..." -> "apple announced"
