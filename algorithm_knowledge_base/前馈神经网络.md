# 前馈神经网络 学习文档

## 1. 算法基础认知
多层感知机，信息前向传播，无反馈连接。

## 2. 核心原理
通过非线性激活函数构建复杂函数映射：$oldsymbol{y} = f(oldsymbol{W}oldsymbol{x} + oldsymbol{b})$

## 3. 数学推导
反向传播算法计算梯度：$\delta^{(l)} = ((W^{(l+1)})^T \delta^{(l+1)}) \odot \sigma'(z^{(l)})$

## 4. 训练过程
1. 前向传播
2. 计算损失
3. 反向传播
4. 参数更新

## 5. 应用场景
- 图像识别
- 自然语言处理
- 结构化数据分析

## 6. 优缺点
优点：强大的非线性拟合能力；缺点：需要大量数据、黑箱

## 8. 手工实现
```python
import numpy as np

class NeuralNetworkScratch:
    def __init__(self, layer_sizes, lr=0.01):
        self.layer_sizes = layer_sizes
        self.lr = lr
        self.weights = []
        self.biases = []
        
        # 初始化权重
        for i in range(len(layer_sizes) - 1):
            w = np.random.randn(layer_sizes[i], layer_sizes[i+1]) * 0.01
            b = np.zeros((1, layer_sizes[i+1]))
            self.weights.append(w)
            self.biases.append(b)
    
    def _relu(self, x):
        return np.maximum(0, x)
    
    def _relu_derivative(self, x):
        return (x > 0).astype(float)
    
    def forward(self, X):
        activations = [X]
        for w, b in zip(self.weights, self.biases):
            z = activations[-1] @ w + b
            a = self._relu(z) if z is not self.weights[-1] else z
            activations.append(a)
        return activations
    
    def train(self, X, y, epochs=1000):
        for epoch in range(epochs):
            # 前向传播
            activations = self.forward(X)
            
            # 计算损失（MSE）
            loss = np.mean((activations[-1] - y) ** 2)
            
            # 反向传播
            deltas = [None] * len(self.weights)
            deltas[-1] = 2 * (activations[-1] - y) / y.shape[0]
            
            for l in range(len(self.weights) - 2, -1, -1):
                deltas[l] = (deltas[l+1] @ self.weights[l+1].T) * self._relu_derivative(activations[l+1])
            
            # 更新权重
            for l in range(len(self.weights)):
                self.weights[l] -= self.lr * (activations[l].T @ deltas[l])
                self.biases[l] -= self.lr * np.sum(deltas[l], axis=0, keepdims=True)
```
