# 多主体强化学习 学习文档

> 研究多个智能体在共享环境中通过学习协调行为的强化学习框架。

## 1. 算法基础认知

多主体强化学习（Multi-Agent Reinforcement Learning, MARL）是强化学习的扩展，研究多个智能体（Agent）在同一环境中如何学习协调行为以完成复杂任务。与单智能体强化学习相比，MARL面临更多挑战：非平稳性、通信、信任、联盟形成等。

**直觉类比**：想象一支篮球队。传统强化学习就像一个人练习投篮，而多主体强化学习就像一支球队训练如何配合——谁传球、谁挡拆、谁投篮。每个球员不仅要学习自己的最佳动作，还要考虑队友的位置和动作。

**历史背景**：MARL研究始于1990年代，是DAI（分布式人工智能）的重要分支。

**前置知识**：单智能体RL、MDP、博弈论基础

## 2. 核心原理

**核心挑战**：
- **非平稳性**：其他智能体的学习导致环境变化
- **尺度爆炸**：状态空间和动作空间指数增长
- **信用分配**：难以确定每个智能体的贡献
- **通信协调**：智能体间需要信息交换

**通信方式**：
1. **直接通信**：显式消息传递
2. **间接通信（Stigmergy）**：通过环境传递信息
3. **混合通信**：结合两者

## 3. 数学公式与推导

**符号约定**：
| 符号 | 含义 |
|------|------|
| n | 智能体数量 |
| s | 联合状态 |
| a | 联合动作 |
| r_i | 智能体i的奖励 |
| π_i | 智能体i的策略 |

**联合MDP**：
$$V^{\pi}(s) = \sum_a \pi(a|s) [R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^{\pi}(s')]$$

**随机博弈**：
$$Q_i^{\pi}(s, a) = R_i(s,a) + \gamma \sum_{s'} P(s'|s,a) V_i^{\pi}(s')$$

## 4. 训练过程讲解

**算法分类**：
1. **中心化训练**：全局信息可用
2. **去中心化执行**：执行时只使用局部信息
3. **通信学习**：学习通信协议

**主要方法**：
- Independent Q-Learning
- Nash Q-Learning
- Team Q-Learning
- QMIX
- MAPPO

## 5. 应用场景

- **机器人协作**：多机器人搬运、编队
- **交通信号控制**：多路口协调
- **游戏AI**：团队游戏
- **资源分配**：云计算调度

## 6. 优缺点分析

**优点**：
1. 可处理复杂协作任务
2. 可扩展性强
3. 适应动态环境

**缺点**：
1. 收敛困难（因非平稳性）
2. 尺度爆炸
3. 设计难度大

## 7. 调库实现

```python
"""
多主体强化学习实现示例
"""
import numpy as np
import matplotlib.pyplot as plt

class MultiAgentSystem:
    """多智能体系统"""
    def __init__(self, n_agents, n_states, n_actions, alpha=0.1, gamma=0.95, epsilon=0.2):
        self.n_agents = n_agents
        self.n_states = n_states
        self.n_actions = n_actions
        self.alpha = alpha
        self.gamma = gamma
        self.epsilon = epsilon
        
        self.Q = np.zeros((n_states,) + (n_actions,) * n_agents)
    
    def choose_joint_action(self, state):
        """选择联合动作"""
        joint_action = []
        for i in range(self.n_agents):
            if np.random.random() < self.epsilon:
                a = np.random.randint(self.n_actions)
            else:
                a = np.argmax(self.Q[state[:len(joint_action)+1]])
            joint_action.append(a)
        return tuple(joint_action)
    
    def update(self, state, joint_action, reward, next_state):
        """更新Q值"""
        self.Q[state + joint_action] += self.alpha * (
            reward + self.gamma * np.max(self.Q[next_state]) - self.Q[state + joint_action]
        )

class SimpleCooperativeEnv:
    """简单协作环境"""
    def __init__(self, n_agents=2):
        self.n_agents = n_agents
        self.n_states = 4
        self.n_actions = 2
        self.goal_state = 3
    
    def reset(self):
        return 0
    
    def step(self, joint_action):
        reward = 0
        done = False
        
        if sum(joint_action) == 0:
            state = 1
        elif sum(joint_action) == 2:
            state = 2
        elif set(joint_action) == {0, 1}:
            state = 3
            reward = 1
            done = True
        else:
            state = 0
        
        return state, reward, done, {}

def train_marl(env, agents, n_episodes=500):
    rewards = []
    
    for ep in range(n_episodes):
        state = env.reset()
        total_reward = 0
        done = False
        
        while not done:
            joint_action = agents.choose_joint_action(state)
            next_state, reward, done, _ = env.step(joint_action)
            
            agents.update(state, joint_action, reward, next_state)
            
            state = next_state
            total_reward += reward
        
        agents.decay_epsilon()
        rewards.append(total_reward)
    
    return rewards

np.random.seed(42)
env = SimpleCooperativeEnv(2)
agents = MultiAgentSystem(2, 4, 2)

print("开始训练多主体强化学习...")
rewards = train_marl(env, agents, 500)

print("训练完成")
print("奖励:", rewards[-10:])

# 可视化
plt.figure(figsize=(10, 5))
plt.plot(rewards, alpha=0.3)
plt.plot(np.convolve(rewards, np.ones(50)/50, mode='valid'), label='50期平均')
plt.xlabel('回合')
plt.ylabel('奖励')
plt.title('多主体强化学习训练曲线')
plt.legend()
plt.grid(True)
plt.savefig('marl_training.png', dpi=150)
plt.show()
```

## 8. 手工代码实现

```python
"""
多主体强化学习手工实现
"""
import numpy as np

class MAVLLearner:
    """多智能体视觉学习器"""
    def __init__(self, n_agents, n_states, n_actions, gamma=0.95):
        self.n_agents = n_agents
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma
        self.Q = np.zeros((n_states,) + (n_actions,) * n_agents)
    
    def get_joint_action(self, state):
        actions = []
        for _ in range(self.n_agents):
            actions.append(np.random.randint(self.n_actions))
        return tuple(actions)
    
    def update_joint_q(self, state, action, reward, next_state):
        idx = state + action
        next_idx = next_state + (slice(None),) * self.n_agents
        
        self.Q[idx] += 0.1 * (reward + self.gamma * np.max(self.Q[next_idx]) - self.Q[idx])

# 测试
env = SimpleCooperativeEnv()
learner = MAVLLearner(2, 4, 2)

for ep in range(200):
    s = env.reset()
    done = False
    
    while not done:
        a = learner.get_joint_action(s)
        s_next, r, done, _ = env.step(a)
        learner.update_joint_q(s, a, r, s_next)
        s = s_next

print("Q值形状:", learner.Q.shape)
print("最大Q值:", np.max(learner.Q))
```
