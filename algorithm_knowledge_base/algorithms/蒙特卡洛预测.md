# 蒙特卡洛预测 学习文档

## 1. 算法基础认知
### 1.1 一句话定义
蒙特卡洛预测（Monte Carlo Prediction）是一种用于估计马尔可夫决策过程中状态值函数的方法，通过采样完整轨迹并平均状态出现的回报来实现，属于无模型强化学习方法。

### 1.2 直觉类比
想象你想知道某个餐厅的平均口碑。你不知道具体评价是怎么计算的，但你挨个去体验，记录每次的总评，最后把该餐厅所有评分平均起来，这就是蒙特卡洛预测的核心——用大量采样样本的平均值来估计真实期望。

### 1.3 历史背景
蒙特卡洛方法起源于1940年代曼哈顿计划中的原子弹模拟，在强化学习中由Sutton在1988年系统化提出。蒙特卡洛预测是理解动态规划与时序差分学习的桥梁，是强化学习的基础算法之一。

### 1.4 算法定位
- 类型：无监督学习/强化学习
- 输出：状态值函数 $V(s)$ 或状态-动作值函数 $Q(s,a)$
- 模型类别：无模型（非参数化估计）

### 1.5 前置知识
- 强化学习基础（MDP、Bellman方程）
- 概率论基础（期望、大数定律）
- Python 编程（NumPy）

## 2. 核心原理
### 2.1 核心思想
蒙特卡洛预测的核心思想是利用"经验平均"代替"期望"：通过采样足够多的完整轨迹，用样本均值来估计每个状态的真实值函数。根据处理方式不同，可分为首次访问蒙特卡洛和每次访问蒙特卡洛。

### 2.2 工作流程
1. 初始化：$V(s) = 0, Returns(s) = []$ 对所有状态
2. 采样：用当前策略在环境中采样一条完整轨迹
3. 记录：记录轨迹中每个状态首次出现的位置和对应回报
4. 更新：对轨迹中每个状态s，将G加入Returns(s)
5. 重复：重复步骤2-4直到收敛

### 2.3 关键概念解释
- **首次访问MC**：只对每个回合中状态首次出现时更新
- **每次访问MC**：对每次出现都更新（包括同一回合中多次出现）
- **回报G**：从该状态开始的折扣累积奖励

### 2.4 几何/直观解释
值函数本质是状态的期望回报。蒙特卡洛通过采样将无限期望转化为有限平均。随着采样增多，大数定律保证样本均值趋近真实期望。

## 3. 数学公式与推导
### 3.1 符号约定
| 符号 | 含义 |
|------|------|
| $V(s)$ | 状态s的值函数 |
| $G_t$ | 从时刻t开始的折扣回报 |
| $R_t$ | 时刻t的奖励 |
| $\gamma$ | 折扣因子 |
| $N(s)$ | 状态s被访问的次数 |

### 3.2 问题形式化
给定策略$\pi$下的状态值函数：
$$V^\pi(s) = \mathbb{E}_\pi[G_t | S_t = s]$$

### 3.3 目标函数/损失函数
无显式目标函数。通过均方误差收敛：
$$MSE = \sum_s (V(s) - V^\pi(s))^2$$

### 3.4 推导过程
从定义出发：
$$V^\pi(s) = \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k R_{t+k} | S_t = s\right]$$

对于一条轨迹 $S_t, S_{t+1}, ...$，回报为：
$$G_t = R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + ...$$

蒙特卡洛估计：
$$V(s) \leftarrow \frac{1}{N(s)} \sum_{i=1}^{N(s)} G_i(s)$$

其中 $G_i(s)$ 是第i次访问状态s时获得的回报。

增量更新形式：
$$V(s) \leftarrow V(s) + \alpha(G - V(s))$$

### 3.5 最终解/算法步骤
```
首次访问MC算法：
Initialize:
    V(s) = 0 for all s
    Returns(s) = empty list for all s

Loop for many episodes:
    1. Generate episode: S0, A0, R1, S1, A1, R2, ..., ST
    2. G = 0
    3. For t = T-1 down to 0:
        G = γ * G + R_{t+1}
        If St not appeared before in this episode:
            Append G to Returns(St)
            V(St) = average(Returns(St))
```

### 3.6 扩展公式补充

**蒙特卡洛估计的无偏性**
设$V(s)$的真实值为$\nu(s) = \mathbb{E}[G|S=s]$。

使用$n$个独立样本$G_1, ..., G_n$估计：
$$\hat{V}_n = \frac{1}{n}\sum_{i=1}^n G_i$$

则：
$$\mathbb{E}[\hat{V}_n] = \nu(s)$$
$$\text{Var}(\hat{V}_n) = \frac{\sigma^2(s)}{n}$$

其中$\sigma^2(s) = \text{Var}(G|S=s)$。

**首次访问vs每次访问**
- 首次访问MC：每个回合只更新状态首次出现时的回报
- 每次访问MC：每个回合中每次出现都更新

每次访问MC的方差更大，因为样本之间有相关性（来自同一轨迹）。

**增量蒙特卡洛更新**
使用增量形式避免存储所有回报：
$$V_{n+1} = \frac{n}{n+1}V_n + \frac{1}{n+1}G_{n+1} = V_n + \frac{1}{n+1}(G_{n+1} - V_n)$$

这可以写成一般形式：
$$V(s) \leftarrow V(s) + \alpha(G - V(s))$$

其中$\alpha = 1/n$。

**覆盖率和收敛速度**
覆盖率$\iota(s) = P(\text{状态s在轨迹中出现})$。

如果$\iota(s) = 0$，则无法估计$V(s)$。需要探索性策略确保所有状态有非零覆盖率。

估计误差：
$$\|\hat{V}_n - V^*\| = O_p\left(\sqrt{\frac{\text{Var}(G|S)}{n\iota(s)}}\right)$$

**偏差-方差权衡**
使用函数逼近时，蒙特卡洛方法存在偏差：
$$\hat{V} = \phi^T w$$

$w$的估计有偏当与真值不完全线性相关时。

方差随逼近函数复杂度增加而增加。

## 4. ���练过程讲解
### 4.1 数据预处理
不需要显式预处理。奖励保持原值，可能需要根据问题进行缩放。

### 4.2 参数初始化
- V(s) = 0（零初始化）
- N(s) = 0（计数初始化）

### 4.3 迭代过程
```
while not converged:
    generate episode using current policy
    compute G for each visited state
    update V(s) with incremental average
```

### 4.4 收敛条件
- 最大迭代次数
- V(s)变化小于阈值

### 4.5 超参数及推荐范围
- 折扣因子γ：0.9-0.99
- 学习率α：0.01-0.1
- 采样回合数：1000+

## 5. 应用场景
### 5.1 典型应用
- **游戏AI**：估计状态值函数
- **策略评估**：评估给定策略
- **扑克/棋类**：游戏树价值估计

### 5.2 适用数据特征
- episodic环境
- 无模型（不知道转移概率）
- 可采样完整轨迹

### 5.3 不适用场景
- 连续环境（无终点）
- 需要快速实时的在线学习
- 高状态空间复杂度

## 6. 优缺点分析
### 6.1 优点
- 无需环境模型
- 无偏差（vs bootstrapping方法）
- 易于实现
- 理论基础扎实

### 6.2 缺点
- 需要完整轨迹
- 方差较高
- 只能用于episodic问题
- 学习慢

### 6.3 与同类算法对比

| 算法 | 偏差 | 方差 | 样本效率 | 适用场景 |
|------|-----|-----|---------|--------|---------|
| MC预测 | 无 | 高 | 低 | episodic |
| TD学习 | 低 | 中 | 中 | continuing |
| DP | 有偏 | 零 | N/A | 需要模型 |

### 7.2 完整代码示例
```python
import numpy as np
import matplotlib.pyplot as plt
import gym

class GridWorldEnv:
    """简单网格世界环境"""
    def __init__(self, size=4):
        self.size = size
        self.state = 0
        self.target = size * size - 1
    
    def reset(self):
        self.state = 0
        return self.state
    
    def step(self, action):
        row, col = self.state // self.size, self.state % self.size
        
        if action == 0: row = max(0, row - 1)
        elif action == 1: row = min(self.size - 1, row + 1)
        elif action == 2: col = max(0, col - 1)
        elif action == 3: col = min(self.size - 1, col + 1)
        
        new_state = row * self.size + col
        reward = 1.0 if new_state == self.target else -0.1
        done = new_state == self.target
        self.state = new_state
        
        return new_state, reward, done, {}

class MonteCarloPrediction:
    """MC预测算法"""
    def __init__(self, n_states, n_actions, gamma=0.9, alpha=0.1):
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma
        self.alpha = alpha
        
        self.V = np.zeros(n_states)
        self.returns = {s: [] for s in range(n_states)}
    
    def first_visit_mc(self, episode):
        visited = set()
        G = 0
        states = []
        
        for transition in reversed(episode):
            state, action, reward = transition
            G = self.gamma * G + reward
            states.insert(0, state)
        
        first_occurrences = {}
        for t, s in enumerate(states):
            if s not in first_occurrences:
                first_occurrences[s] = t
        
        for s, t in first_occurrences.items():
            G_t = sum(states[t][2] * (self.gamma ** i) for i in range(t, len(states)))
            self.returns[s].append(G_t)
            self.V[s] = np.mean(self.returns[s])
        
        return self.V
    
    def every_visit_mc(self, episode):
        G = 0
        states = []
        
        for transition in reversed(episode):
            state, action, reward = transition
            G = self.gamma * G + reward
            states.insert(0, (state, G))
        
        for state, G in states:
            self.returns[state].append(G)
            self.V[state] = np.mean(self.returns[state])
        
        return self.V

def collect_episode(env, policy, max_steps=100):
    """采集一条轨迹"""
    episode = []
    state = env.reset()
    
    for _ in range(max_steps):
        action = policy(state)
        next_state, reward, done, _ = env.step(action)
        episode.append((state, action, reward))
        state = next_state
        if done:
            break
    
    return episode

def random_policy(state):
    """随机策略"""
    return np.random.randint(4)

def run_gridworld_experiment(size=4, num_episodes=1000):
    """网格世界实验"""
    env = GridWorldEnv(size)
    n_states = size * size
    n_actions = 4
    
    mc = MonteCarloPrediction(n_states, n_actions, gamma=0.9, alpha=0.1)
    
    errors = []
    
    for episode_num in range(num_episodes):
        traj = collect_episode(env, random_policy)
        mc.every_visit_mc(traj)
        
        if episode_num % 100 == 0:
            true_values = np.zeros(n_states)
            optimal = (size - 1) + (size - 1) * 0.1 * (size * size)
            error = np.mean(np.abs(mc.V - true_values[:size]))
            errors.append(error)
    
    return mc.V, errors

def visualize_values(V, size=4):
    """可视化值函数"""
    import matplotlib.pyplot as plt
    
    V_matrix = V.reshape(size, size)
    plt.figure(figsize=(6, 5))
    plt.imshow(V_matrix, cmap='viridis')
    plt.colorbar(label='V(s)')
    plt.title('State Value Function')
    
    for i in range(size):
        for j in range(size):
            plt.text(j, i, f'{V_matrix[i,j]:.2f}', ha='center', va='center', color='white')
    
    plt.show()

def compare_mc_methods(size=4, num_episodes=500):
    """比较首次访问和每次访问MC"""
    env = GridWorldEnv(size)
    n_states = size * size
    n_actions = 4
    
    mc_first = MonteCarloPrediction(n_states, n_actions)
    mc_every = MonteCarloPrediction(n_states, n_actions)
    
    errors_first = []
    errors_every = []
    
    for episode_num in range(num_episodes):
        traj = collect_episode(env, random_policy)
        
        mc_first.first_visit_mc(traj)
        mc_every.every_visit_mc(traj)
        
        if episode_num % 50 == 0:
            true_vals = np.zeros(n_states)
            
            err_f = np.mean(np.abs(mc_first.V - true_vals))
            err_e = np.mean(np.abs(mc_every.V - true_vals))
            
            errors_first.append(err_f)
            errors_every.append(err_e)
    
    plt.figure(figsize=(10, 5))
    plt.plot(errors_first, label='First-visit MC')
    plt.plot(errors_every, label='Every-visit MC')
    plt.xlabel('Episode / 50')
    plt.ylabel('Mean Absolute Error')
    plt.title('First-visit vs Every-visit MC')
    plt.legend()
    plt.grid(True)
    plt.show()

if __name__ == "__main__":
    values, errors = run_gridworld_experiment()
    visualize_values(values)
    compare_mc_methods()
```

## 13. 练习题与思考题与思考题
### 13.1 基础练习题
1. MC预测和TD学习的本质区别是什么？
2. 为什么MC需要完整轨迹而TD不需要？
3. 首次访问MC是否比每次访问MC更高效？

### 13.2 进阶思考题
1. 如何用MC估计动作值函数Q(s,a)？
2. MC能否用于非平稳环境？
3. 如何结合MC和TD的优点？

### 13.3 详细答案与解析
**答案1**：MC用真实回报的平均，TD用-bootstrap估计。

**答案2**：MC需要G定义在回合结束时，TD只需一步后状态。

**答案3**：首次访问理论上更有效，但实现更复杂。
