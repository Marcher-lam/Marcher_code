# 循环神经网络 (Recurrent Neural Network, RNN)

> 处理序列数据的核心架构，通过隐藏状态在时间步之间传递信息

---

## 1. 算法基础认知

### 1.1 一句话定义

循环神经网络是一类专门用于处理序列数据的神经网络架构，通过引入循环连接（隐藏状态）使网络能够在每个时间步利用之前的信息，从而捕捉序列中的时序依赖关系。RNN的核心创新在于参数共享——无论序列多长，都使用相同的权重矩阵。

### 1.2 直觉类比

RNN就像人类阅读文章：
- 我们不是孤立地理解每个单词
- 阅读当前单词时，大脑保留着之前句子的"记忆"
- "machine learning" → 读到"learning"时，我们记得前面的"machine"
- RNN的隐藏状态就是这种"工作记忆"

### 1.3 发展历程

| 时间 | 里程碑 |
|------|--------|
| 1986 | Jordan网络、Elman网络 |
| 1990 | BPTT反向传播算法 |
| 1997 | LSTM长短期记忆网络 |
| 2014 | GRU门控循环单元 |
| 2017 | Transformer（注意力替换RNN） |

## 2. 核心原理

### 2.1 RNN递归结构

RNN的核心公式：

$$h_t = \tanh(W_{xh} x_t + W_{hh} h_{t-1} + b_h)$$

$$y_t = W_{hy} h_t + b_y$$

其中：
- $x_t \in \mathbb{R}^{d_{input}}$：时刻t的输入
- $h_t \in \mathbb{R}^{d_{hidden}}$：时刻t的隐藏状态
- $y_t \in \mathbb{R}^{d_{output}}$：时刻t的输出
- $W_{xh} \in \mathbb{R}^{d_{hidden} \times d_{input}}$：输入到隐藏
- $W_{hh} \in \mathbb{R}^{d_{hidden} \times d_{hidden}}$：隐藏到隐藏（循环）
- $W_{hy} \in \mathbb{R}^{d_{output} \times d_{hidden}}$：隐藏到输出

### 2.2 多种架构模式

根据输入输出关系分类：

1. **一对一（One-to-One）**：每个时间步有输入输出
   - 等同于前馈网络

2. **多对一（Many-to-One）**：读入序列，输出一个
   - 情感分类、意图识别

3. **一对多（One-to-Many）**：一个输入生成序列
   - 图像 Captioning

4. **多对多（Many-to-Many）**：序列到序列
   - 机器翻译、词性标注

### 2.3 参数共享

RNN的关键特性：参数在所有时间步共享

- 优点：对序列长度无限制、减少参数量、平移不变性
- 代价：需要BPTT训练

### 2.4 BPTT反向传播

BPTT（Backpropagation Through Time）算法：

1. **前向传播**：计算所有时间步的隐藏状态和输出
2. **计算损失**：某时刻或所有时刻的损失
3. **反向传播**：从后向前传播梯度

**梯度公式**：
$$\frac{\partial L}{\partial W_{hh}} = \sum_{t=1}^{T} \frac{\partial L}{\partial h_t} \frac{\partial h_t}{\partial W_{hh}}$$

$$\frac{\partial h_t}{\partial h_{t-1}} = W_{hh}^T \cdot \text{diag}(\tanh'(z_t))$$

## 3. 数学公式与推导

### 3.1 梯度消失与爆炸

RNN训练的核心问题。

**反向传播梯度**（从t传播到0）：
$$\frac{\partial h_t}{\partial h_{k}} = \prod_{i=k+1}^{t} \frac{\partial h_i}{\partial h_{i-1}}$$

$$= \prod_{i=k+1}^{t} W_{hh}^T \cdot \text{diag}(\tanh'(z_i))$$

**分析**：
- 若 $\|W_{hh}\| > 1$：梯度指数增长 → 爆炸
- 若 $\|W_{hh}\| < 1$：梯度指数衰减 → 消失
- 衰减速度：$\lambda^k$（k为距离）

### 3.2 梯度裁剪

解决梯度爆炸：

```python
# 裁剪梯度范数
def clip_gradients(model, max_norm):
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm)
```

**公式**：
$$\mathbf{g} \leftarrow \begin{cases} \mathbf{g} \cdot \frac{max\_norm}{\|\mathbf{g}\|} & \text{if } \|\mathbf{g}\| > max\_norm \\ \mathbf{g} & \text{otherwise} \end{cases}$$

### 3.3 LSTM原理

LSTM（Long Short-Term Memory）通过门控解决梯度消失：

**遗忘门**：
$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$$

**输入门**：
$$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$$

**候选细胞状态**：
$$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$$

**细胞状态更新**：
$$C_t = f_t \circ C_{t-1} + i_t \circ \tilde{C}_t$$

**输出门**：
$$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$$

**隐藏状态**：
$$h_t = o_t \circ \tanh(C_t)$$

其中 $[h_{t-1}, x_t]$ 表示拼接，$\circ$ 表示逐元素乘法，$\sigma$ 是Sigmoid。

### 3.4 GRU原理

GRU（Gated Recurrent Unit）——LSTM的简化版本：

**更新门**：
$$z_t = \sigma(W_z \cdot [h_{t-1}, x_t])$$

**重置门**：
$$r_t = \sigma(W_r \cdot [h_{t-1}, x_t])$$

**候选隐藏状态**：
$$\tilde{h}_t = \tanh(W \cdot [r_t \circ h_{t-1}, x_t])$$

**隐藏状态更新**：
$$h_t = (1 - z_t) \circ h_{t-1} + z_t \circ \tilde{h}_t$$

### 4.2 完整RNN实现

```python
import torch.nn as nn

class SimpleRNN(nn.Module):
    """简单RNN分类器"""
    
    def __init__(self, input_size, hidden_size, num_classes, num_layers=1):
        super().__init__()
        
        self.hidden_size = hidden_size
        self.num_layers = num_layers
        
        # RNN层
        self.rnn = nn.RNN(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,
            dropout=0 if num_layers == 1 else 0.5
        )
        
        # 分类层
        self.fc = nn.Linear(hidden_size, num_classes)
    
    def forward(self, x):
        """
        Args:
            x: (batch, seq_len, input_size)
        
        Returns:
            logits: (batch, num_classes)
        """
        # RNN前向
        output, hidden = self.rnn(x)
        # output: (batch, seq_len, hidden_size)
        # hidden: (num_layers, batch, hidden_size)
        
        # 取最后一个时间步
        last_output = output[:, -1, :]  # (batch, hidden_size)
        
        # 分类
        logits = self.fc(last_output)
        
        return logits
```

```python
class LSTMClassifier(nn.Module):
    """LSTM分类器"""
    
    def __init__(self, input_size, hidden_size, num_classes, num_layers=1, dropout=0):
        super().__init__()
        
        self.hidden_size = hidden_size
        self.num_layers = num_layers
        
        # LSTM层
        self.lstm = nn.LSTM(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,
            dropout=dropout if num_layers > 1 else 0,
            bidirectional=False
        )
        
        # 全连接层
        self.fc = nn.Linear(hidden_size, num_classes)
    
    def forward(self, x):
        """
        Args:
            x: (batch, seq_len, input_size)
        
        Returns:
            logits: (batch, num_classes)
        """
        # LSTM
        output, (h_n, c_n) = self.lstm(x)
        
        # 取最后一个隐藏状态
        last_hidden = h_n[-1]  # (batch, hidden_size)
        
        # 分类
        logits = self.fc(last_hidden)
        
        return logits
```

### 4.4 训练循环

```python
def train_model(model, dataloader, epochs=10, lr=0.001):
    """训练模型"""
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    model = model.to(device)
    
    criterion = nn.CrossEntropyLoss()
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    
    for epoch in range(epochs):
        model.train()
        total_loss = 0
        correct = 0
        total = 0
        
        for X_batch, y_batch in dataloader:
            X_batch = X_batch.to(device)
            y_batch = y_batch.to(device)
            
            # 前向
            outputs = model(X_batch)
            loss = criterion(outputs, y_batch)
            
            # 反向
            optimizer.zero_grad()
            loss.backward()
            
            # 梯度裁剪
            torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
            
            optimizer.step()
            
            total_loss += loss.item()
            _, predicted = outputs.max(1)
            total += y_batch.size(0)
            correct += predicted.eq(y_batch).sum().item()
        
        acc = 100.0 * correct / total
        avg_loss = total_loss / len(dataloader)
        
        if (epoch + 1) % 2 == 0:
            print(f"Epoch {epoch+1}/{epochs} - Loss: {avg_loss:.4f} - Acc: {acc:.2f}%")
    
    return model


# 训练示例
model = LSTMClassifier(input_size=5, hidden_size=64, num_classes=2)
model = train_model(model, dataloader)
```

## 8. 手工代码实现

### 8.1 基础RNN从零实现

```python
import numpy as np

class RNNScratch:
    """从零实现的RNN"""
    
    def __init__(self, input_size, hidden_size, output_size):
        self.input_size = input_size
        self.hidden_size = hidden_size
        self.output_size = output_size
        
        # 初始化权重
        scale = 0.1
        
        self.W_xh = np.random.randn(hidden_size, input_size) * scale
        self.W_hh = np.random.randn(hidden_size, hidden_size) * scale
        self.W_hy = np.random.randn(output_size, hidden_size) * scale
        
        self.b_h = np.zeros((hidden_size, 1))
        self.b_y = np.zeros((output_size, 1))
    
    def tanh(self, x):
        """Tanh激活"""
        return np.tanh(x)
    
    def tanh_derivative(self, x):
        """Tanh导数"""
        return 1 - np.tanh(x) ** 2
    
    def forward(self, X):
        """
        前向传播
        
        Args:
            X: (seq_len, input_size)
        
        Returns:
            output: (seq_len, output_size)
            hidden: (seq_len, hidden_size)
        """
        seq_len = X.shape[0]
        
        # 存储状态
        self.hidden_states = np.zeros((seq_len, self.hidden_size))
        self.inputs = X
        
        # 初始化隐藏状态
        h_prev = np.zeros((self.hidden_size, 1))
        
        # 逐时间步
        for t in range(seq_len):
            x_t = X[t:t+1].T  # (input_size, 1)
            
            # 前向计算
            h_t = self.tanh(
                self.W_xh @ x_t + 
                self.W_hh @ h_prev + 
                self.b_h
            )
            
            self.hidden_states[t] = h_t.flatten()
            h_prev = h_t
        
        # 输出层
        self.hidden_states[-1] = h_prev.flatten()
        output = self.W_hy @ h_prev + self.b_y
        
        return output.flatten()
    
    def backward(self, X, y_true, learning_rate=0.01):
        """反向传播"""
        seq_len = X.shape[0]
        
        # 初始梯度
        dL_dy = 2 * (y_true - self.forward(X))  # 简单MSE
        
        # 输出权重梯度
        dL_dWhy = np.outer(dL_dy, self.hidden_states[-1])
        
        # 隐藏状态梯度
        dL_dh = self.W_hy.T @ dL_dy
        
        # 初始化权重梯度
        dW_xh = np.zeros_like(self.W_xh)
        dW_hh = np.zeros_like(self.W_hh)
        
        # 反向传播通过时间
        for t in reversed(range(seq_len)):
            x_t = X[t:t+1].T if t == 0 else X[t-1:t].T
            h_prev = self.hidden_states[t-1:t].T if t > 0 else np.zeros((self.hidden_size, 1))
            
            # tanh导数
            dh_raw = dL_dh * self.tanh_derivative(self.W_xh @ x_t + self.W_hh @ h_prev + self.b_h)
            
            # 权重梯度
            dW_xh += np.outer(dh_raw, x_t)
            dW_hh += np.outer(dh_raw, h_prev)
            
            # 回传梯度
            dL_dh = self.W_hh.T @ dh_raw
        
        # 梯度裁剪
        for grad in [dW_xh, dW_hh, dL_dWhy]:
            np.clip(grad, -5, 5, out=grad)
        
        # 更新权重
        self.W_xh -= learning_rate * dW_xh
        self.W_hh -= learning_rate * dW_hh
        self.W_hy -= learning_rate * dL_dWhy
    
    def predict(self, X):
        """预测"""
        output = self.forward(X)
        return np.argmax(output)


# 测试
rnn = RNNScratch(input_size=5, hidden_size=10, output_size=2)

# 输入序列
X = np.random.randn(5, 5)
y = np.array([1])

# 训练几次
for _ in range(100):
    rnn.backward(X, y, learning_rate=0.01)

print(f"预测: {rnn.predict(X)}")
```

### 8.2 完整LSTM实现

```python
import torch
import torch.nn as nn

class LSTMCell(nn.Module):
    """LSTM单元（从零实现）"""
    
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size
        
        # 门控权重
        self.Wf = nn.Linear(input_size + hidden_size, hidden_size)
        self.Wi = nn.Linear(input_size + hidden_size, hidden_size)
        self.Wc = nn.Linear(input_size + hidden_size, hidden_size)
        self.Wo = nn.Linear(input_size + hidden_size, hidden_size)
    
    def forward(self, x, h_prev, c_prev):
        """前向传播"""
        # 拼接
        combined = torch.cat([h_prev, x], dim=-1)
        
        # 门控
        f = torch.sigmoid(self.Wf(combined))  # 遗忘门
        i = torch.sigmoid(self.Wi(combined))  # 输入门
        c_tilde = torch.tanh(self.Wc(combined))  # 候选
        
        # 更新细胞状态
        c = f * c_prev + i * c_tilde
        
        # 输出门
        o = torch.sigmoid(self.Wo(combined))
        h = o * torch.tanh(c)
        
        return h, c


class LSTMScratch(nn.Module):
    """从零实现的LSTM"""
    
    def __init__(self, input_size, hidden_size, num_layers=1):
        super().__init__()
        self.hidden_size = hidden_size
        self.num_layers = num_layers
        
        # LSTM层
        self.cells = nn.ModuleList([
            LSTMCell(input_size if i == 0 else hidden_size, hidden_size)
            for i in range(num_layers)
        ])
    
    def forward(self, x):
        """
        Args:
            x: (batch, seq_len, input_size)
        
        Returns:
            output: (batch, seq_len, hidden_size)
            last_state: ((num_layers, batch, hidden_size), (num_layers, batch, hidden_size))
        """
        batch_size, seq_len, _ = x.shape
        
        # 初始化状态
        h = [torch.zeros(batch_size, self.hidden_size, device=x.device) 
             for _ in range(self.num_layers)]
        c = [torch.zeros(batch_size, self.hidden_size, device=x.device) 
             for _ in range(self.num_layers)]
        
        outputs = []
        
        # 逐时间步
        for t in range(seq_len):
            x_t = x[:, t, :]
            
            for layer in range(self.num_layers):
                h[layer], c[layer] = self.cells[layer](x_t, h[layer], c[layer])
                x_t = h[layer]
            
            outputs.append(h[-1])
        
        # 堆叠输出
        output = torch.stack(outputs, dim=1)
        
        return output, (torch.stack(h), torch.stack(c))
```

## 9. 可视化与结果理解

```python
from sklearn.metrics import accuracy_score, precision_recall_fscore_support

def evaluate_model(model, dataloader):
    """评估模型"""
    model.eval()
    
    all_preds = []
    all_labels = []
    
    with torch.no_grad():
        for X_batch, y_batch in dataloader:
            outputs = model(X_batch)
            _, predicted = outputs.max(1)
            
            all_preds.extend(predicted.numpy())
            all_labels.extend(y_batch.numpy())
    
    # 指标
    acc = accuracy_score(all_labels, all_preds)
    precision, recall, f1, _ = precision_recall_fscore_support(
        all_labels, all_preds, average='binary'
    )
    
    print(f"Accuracy: {acc:.4f}")
    print(f"Precision: {precision:.4f}")
    print(f"Recall: {recall:.4f}")
    print(f"F1: {f1:.4f}")
```

## 12. 学习总结

### 12.1 核心要点

1. **公式**：$h_t = \tanh(W_{xh}x_t + W_{hh}h_{t-1})$
2. **参数共享**：所有时间步用相同权重
3. **BPTT**：反向传播通过时间
4. **梯度问题**：消失/爆炸
5. **LSTM**：细胞状态+门控

### 12.2 实用技巧

- 梯度裁剪不可少
- 先用LSTM/GRU
- 数据量少用截断BPTT
- 双向可提升效果

### 12.3 适用场景

- 文本序列
- 时间序列
- 语音识别
- 序列标注

## 13. 练习题与思考题

### 13.1 基础题

**练习1**：RNN前向计算
```
给定：
- W_xh = [[1], [0]], W_hh = [[0.5]], b_h = 0
- x_0=1, h_0=0
- tanh(0.5) ≈ 0.46

求：h_1
```

**答案**：
$$h_1 = \tanh(W_{xh}x_1 + W_{hh}h_0 + b_h)$$
$$= \tanh(1 \times 1 + 0.5 \times 0 + 0)$$
$$= \tanh(1) ≈ 0.46$$
