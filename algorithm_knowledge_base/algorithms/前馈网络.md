# 前馈网络 (Feed Forward Network, FFN) 学习文档

## 1. 算法基础认知

### 1.1 定义与背景

前馈网络（Feed Forward Network，简称FFN）是Transformer架构中的核心组件之一，也被称为Position-Wise Feed Forward Network（逐位置前馈网络）或Multi-Layer Perceptron（MLP）。在Transformer的原始论文"Attention Is All You Need"中，FFN与自注意力机制共同构成了编码器和解码器的基本计算单元。

**FFN在Transformer中的作用：**

Transformer的核心计算可以表示为：
$$\text{FFN}(\mathbf{x}) = \text{FFN}(\text{Attention}(\mathbf{x}))$$

FFN的主要功能包括：
1. **特征变换**：将注意力提取的特征映射到更高维空间
2. **非线性引入**：通过激活函数引入非线性，提升模型表达能力
3. **信息整合**：整合来自不同位置的信息

**为什么需要FFN？**

虽然自注意力机制能够建模任意位置之间的依赖关系，但它本身是一个线性操作（通过点积实现）。缺乏非线性意味着堆叠多层注意力也无法建模复杂函数。FFN通过引入非线性激活函数，解决了这一问题。

### 1.2 应用场景

| 场景 | 说明 |
|------|------|
| Transformer FFN | 标准Transformer架构的核心组件 |
| 大语言模型FFN | LLaMA、GPT等模型的FFN变体 |
| MoE专家网络 | MoE中的 Expert 网络 |
| 多模态模型 | 视觉、语言FFN |

## 2. 核心原理

### 2.1 标准FFN架构

**单层FFN：**

$$\text{FFN}(\mathbf{x}) = \text{GELU}(\mathbf{x}\mathbf{W}_1 + \mathbf{b}_1)\mathbf{W}_2 + \mathbf{b}_2$$

其中：
- 输入维度：$d_{model}$
- 中间维度：$d_{ffn} = d_{model} \times 4$（默认值）
- 激活函数：GELU（Gaussian Error Linear Unit）

**参数数量：**

$$|\mathbf{W}_1| = d_{model} \times d_{ffn}$$
$$|\mathbf{W}_2| = d_{ffn} \times d_{model}$$

总参数：$2 \times d_{model} \times d_{ffn} = 8 \times d_{model}^2$

### 2.2 Swish 激活函数

**Swish定义：**

$$\text{Swish}(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}}$$

**Swish的性质：**
- 光滑连续，非单调
- 在负值区域有微弱的负值输出
- 已被验证在深层网络中优于ReLU和GELU

### 2.3 Gated Linear Units (GLU)

**GLU核心思想：**

GLU通过引入门控机制控制信息流动：
$$\text{GLU}(\mathbf{x}) = \sigma(\mathbf{x}\mathbf{W}_g + \mathbf{b}_g) \odot (\mathbf{x}\mathbf{W} + \mathbf{b})$$

其中$\odot$表示逐元素乘法。

**FFN with GLU (FFN-L)**：

$$\text{FFN-L}(\mathbf{x}) = (\phi(\mathbf{x}\mathbf{W}_g) \odot (\mathbf{x}\mathbf{W}_1))\mathbf{W}_2 + \mathbf{b}_2$$

其中$\phi$是可选的激活函数。

**GLU变体**：
- SwiGLU: 使用Swish门控
- ReGLU: 使用ReLU门控
- GEGLU: 使用GELU门控

## 3. PyTorch实现

### 3.1 标准FFN实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math
from typing import Optional


class FeedForwardNetwork(nn.Module):
    """
    标准FFN实现
    
    公式: FFN(x) = GELU(xW_1 + b_1)W_2 + b_2
    """
    
    def __init__(
        self,
        dim: int,
        ffn_dim: Optional[int] = None,
        dropout: float = 0.0,
        bias: bool = True,
    ):
        super().__init__()
        
        if ffn_dim is None:
            ffn_dim = dim * 4
            
        self.dim = dim
        self.ffn_dim = ffn_dim
        
        # 升维投影
        self.w1 = nn.Linear(dim, ffn_dim, bias=bias)
        
        # 降维投影
        self.w2 = nn.Linear(ffn_dim, dim, bias=bias)
        
        # Dropout
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        前向传播
        
        Args:
            x: [batch, seq_len, dim]
            
        Returns:
            output: [batch, seq_len, dim]
        """
        # 升维 -> 激活 -> Dropout -> 降维
        x = self.w1(x)
        x = F.gelu(x)
        x = self.dropout(x)
        x = self.w2(x)
        x = self.dropout(x)
        
        return x


class SwishFeedForward(nn.Module):
    """
    使用Swish激活函数的FFN
    """
    
    def __init__(
        self,
        dim: int,
        ffn_dim: Optional[int] = None,
        dropout: float = 0.0,
    ):
        super().__init__()
        
        if ffn_dim is None:
            ffn_dim = dim * 4
            
        self.dim = dim
        self.ffn_dim = ffn_dim
        
        self.w1 = nn.Linear(dim, ffn_dim)
        self.w2 = nn.Linear(ffn_dim, dim)
        
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        x = self.w1(x)
        x = x * torch.sigmoid(x)  # Swish: x * sigmoid(x)
        x = self.dropout(x)
        x = self.w2(x)
        
        return x
```

### 3.2 GLU变体实现

```python
class GLUFeedForward(nn.Module):
    """
    Gated Linear Unit (GLU) FFN
    
    GLU(x) = (gate(x) * up(x))down
    """
    
    def __init__(
        self,
        dim: int,
        ffn_dim: Optional[int] = None,
        dropout: float = 0.0,
        glu_act: str = "silu",
    ):
        super().__init__()
        
        # GLU 通常将维度设置为相同的倍数
        if ffn_dim is None:
            ffn_dim = dim * 4
            
        self.dim = dim
        self.ffn_dim = ffn_dim
        
        # 门控参数 (gate)
        self.w_gate = nn.Linear(dim, ffn_dim)
        
        # 向上投影
        self.w_up = nn.Linear(dim, ffn_dim)
        
        # 向下投影
        self.w_down = nn.Linear(ffn_dim, dim)
        
        self.dropout = nn.Dropout(dropout)
        
        # 激活函数选择
        if glu_act == "silu":
            self.act_fn = nn.SiLU()
        elif glu_act == "gelu":
            self.act_fn = nn.GELU()
        elif glu_act == "relu":
            self.act_fn = nn.ReLU()
        else:
            raise ValueError(f"Unknown activation: {glu_act}")
            
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # 门控
        gate = self.act_fn(self.w_gate(x))
        
        # 向上
        up = self.w_up(x)
        
        # 门控 * 向上
        hidden = gate * up
        
        # Dropout
        hidden = self.dropout(hidden)
        
        # 向下投影
        output = self.w_down(hidden)
        
        return output


class SwiGLUFeedForward(nn.Module):
    """
    SwiGLU: 使用SiLU作为门控的GLU
    
    这是LLaMA等模型使用的FFN变体
    """
    
    def __init__(
        self,
        dim: int,
        ffn_dim: Optional[int] = None,
        dropout: float = 0.0,
    ):
        super().__init__()
        
        # SwiGLU 通常需要 2/3 的维度扩展
        if ffn_dim is None:
            # 为了保持参数数量接近，增加到 dim * 8/3
            ffn_dim = int(dim * 8 / 3)
            # 维度需要是 256 的倍数
            ffn_dim = ((ffn_dim + 255) // 256) * 256
            
        self.dim = dim
        self.ffn_dim = ffn_dim
        
        # Gate 和 Up 合并为一个矩阵以提高效率
        self.w_input = nn.Linear(dim, ffn_dim * 2)
        
        # Down 投影
        self.w_output = nn.Linear(ffn_dim, dim)
        
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # 一次矩阵乘法得到 gate 和 up
        x_hidden = self.w_input(x)
        
        # 分割
        gate, up = x_hidden.chunk(2, dim=-1)
        
        # SwiGLU: silu(gate) * up
        hidden = nn.functional.silu(gate) * up
        
        hidden = self.dropout(hidden)
        
        output = self.w_output(hidden)
        
        return output
```

### 3.3 完整Transformer Block

```python
class TransformerBlockWithFFN(nn.Module):
    """
    完整的Transformer Block带有FFN
    """
    
    def __init__(
        self,
        dim: int,
        num_heads: int = 8,
        ffn_dim: int = None,
        dropout: float = 0.0,
        attn_dropout: float = 0.0,
        ffn_type: str = "gelu",  # "gelu", "swiglu", "swish"
    ):
        super().__init__()
        
        if ffn_dim is None:
            ffn_dim = dim * 4
            
        self.dim = dim
        self.num_heads = num_heads
        
        # 自注意力
        self.self_attn = nn.MultiheadAttention(
            dim, num_heads, dropout=attn_dropout, batch_first=True
        )
        self.norm1 = nn.LayerNorm(dim)
        
        # FFN
        if ffn_type == "gelu":
            self.ffn = FeedForwardNetwork(dim, ffn_dim, dropout)
        elif ffn_type == "glu":
            self.ffn = GLUFeedForward(dim, ffn_dim, dropout)
        elif ffn_type == "swiglu":
            self.ffn = SwiGLUFeedForward(dim, ffn_dim, dropout)
        elif ffn_type == "swish":
            self.ffn = SwishFeedForward(dim, ffn_dim, dropout)
        else:
            raise ValueError(f"Unknown FFN type: {ffn_type}")
            
        self.norm2 = nn.LayerNorm(dim)
        
    def forward(
        self,
        x: torch.Tensor,
        key_padding_mask: Optional[torch.Tensor] = None,
    ) -> torch.Tensor:
        """
        前向传播
        
        Args:
            x: [batch, seq_len, dim]
            key_padding_mask: [batch, seq_len]
        """
        batch_size, seq_len, _ = x.shape
        
        # 自注意力 + 残差
        residual = x
        x = self.norm1(x)
        x, _ = self.self_attn(x, x, x, key_padding_mask=key_padding_mask)
        x = residual + x
        
        # FFN + 残差
        residual = x
        x = self.norm2(x)
        x = self.ffn(x)
        x = residual + x
        
        return x
```

### 3.4 FFN的硬件优化版本

```python
class FusedFeedForward(nn.Module):
    """
    融合的FFN实现，内存更高效
    """
    
    def __init__(self, dim: int, ffn_dim: int = None, dropout: float = 0.0):
        super().__init__()
        
        if ffn_dim is None:
            ffn_dim = dim * 4
            
        self.dim = dim
        self.ffn_dim = ffn_dim
        
        # 融合权重矩阵
        # 合并 W1 和 W2 以提高内存效率
        self.w12 = nn.Linear(dim, ffn_dim * 2, bias=False)
        self.b1 = nn.Parameter(torch.zeros(ffn_dim))
        self.b2 = nn.Parameter(torch.zeros(dim))
        
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # 一次矩阵乘法
        hidden = self.w12(x)
        
        # 分割
        hidden1, hidden2 = hidden.chunk(2, dim=-1)
        
        # GELU 激活
        hidden1 = F.gelu(hidden1 + self.b1)
        
        # 输出 + Dropout
        output = hidden1 @ self.w12.weight[:self.dim, :].transpose(0, 1)
        output = output + self.b2
        output = self.dropout(output)
        
        return output
```

ffn = FeedForwardNetwork(dim=512, ffn_dim=2048)

### 4.2 对比不同FFN变体

```python
def compare_ffn_variants():
    """对比不同FFN变体的参数量和计算"""
    dim = 512
    x = torch.randn(2, 32, dim)
    
    variants = {
        "Standard GELU": FeedForwardNetwork(dim),
        "Swish": SwishFeedForward(dim),
        "GLU": GLUFeedForward(dim),
        "SwiGLU": SwiGLUFeedForward(dim),
    }
    
    for name, ffn in variants.items():
        output = ffn(x)
        params = sum(p.numel() for p in ffn.parameters())
        
        print(f"{name}:")
        print(f"  Parameters: {params}")
        print(f"  Output shape: {output.shape}")

compare_ffn_variants()
```

### 4.3 在Transformer中使用

```python
# 创建完整的Transformer模型
class SimpleTransformer(nn.Module):
    def __init__(self, num_layers, dim, num_heads, vocab_size):
        super().__init__()
        
        self.embedding = nn.Embedding(vocab_size, dim)
        self.layers = nn.ModuleList([
            TransformerBlockWithFFN(dim, num_heads)
            for _ in range(num_layers)
        ])
        self.norm = nn.LayerNorm(dim)
        self.lm_head = nn.Linear(dim, vocab_size, bias=False)
        
    def forward(self, input_ids):
        x = self.embedding(input_ids)
        
        for layer in self.layers:
            x = layer(x)
            
        x = self.norm(x)
        logits = self.lm_head(x)
        
        return logits

# 使用
model = SimpleTransformer(num_layers=6, dim=512, num_heads=8, vocab_size=30000)
input_ids = torch.randint(0, 30000, (2, 32))
logits = model(input_ids)

print(f"Model output: {logits.shape}")
```
