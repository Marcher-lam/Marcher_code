## 1. 算法基础认知

**一句话定义：** MAP 在 MLE 的基础上引入先验分布，通过最大化后验概率 $p(\theta|D)$ 进行参数估计，等价于带正则化的 MLE。

**直觉类比：** MLE 像一个"只看数据的裁判"，数据说什么就信什么。MAP 像一个"有经验的裁判"——数据说了什么，但也会参考自己的经验（先验知识）。当数据充足时，MAP 和 MLE 结果几乎相同；当数据稀少时，先验知识会"拉"住估计值防止过拟合。

**历史背景：** MAP 是贝叶斯统计的核心方法，将先验知识和观测数据统一在贝叶斯框架下。在机器学习中，L2 正则化（岭回归）等价于高斯先验的 MAP 估计。

**算法定位：** 贝叶斯参数估计、正则化方法。

**前置知识：** MLE、贝叶斯定理、先验/后验分布。

## 2-3. 核心原理与数学公式

### 贝叶斯定理

$$p(\theta|D) = \frac{p(D|\theta) \cdot p(\theta)}{p(D)}$$

MAP 最大化后验：

$$\hat{\theta}_{MAP} = \arg\max_\theta p(\theta|D) = \arg\max_\theta [\log p(D|\theta) + \log p(\theta)]$$

### MAP = MLE + 正则化

$$\hat{\theta}_{MAP} = \arg\max_\theta \underbrace{\log p(D|\theta)}_{\text{似然项}} + \underbrace{\log p(\theta)}_{\text{先验项（正则化）}}$$

### 高斯先验 → L2 正则化

$p(\theta) = \mathcal{N}(0, \sigma^2)$ 时：

$$\log p(\theta) = -\frac{1}{2\sigma^2}\|\theta\|^2 + C$$

MAP 目标等价于：$\min_\theta -\log p(D|\theta) + \lambda\|\theta\|^2$（L2 正则化）

### 拉普拉斯先验 → L1 正则化

$p(\theta) = \text{Laplace}(0, b)$ 时，MAP 等价于 L1 正则化（LASSO）。

## 4-8. 代码实现

```python
import numpy as np

# MAP 估计：一维正态分布 + 高斯先验
np.random.seed(42)
data = np.random.randn(10) * 2 + 3  # 少量数据

# MLE
mu_mle = data.mean()
# MAP (高斯先验 mu ~ N(0, tau^2))
tau2 = 4.0  # 先验方差
sigma2 = 4.0  # 数据方差（已知）
n = len(data)
mu_map = (n * data.mean() / sigma2) / (n / sigma2 + 1 / tau2)
print(f"MLE: {mu_mle:.4f}, MAP: {mu_map:.4f}, 真实: 3.0")
print(f"MAP 被先验'拉向'0（先验均值）")

# MAP 线性回归 = 岭回归
from sklearn.linear_model import Ridge
X = np.random.randn(50, 5)
y = X @ np.array([1, 2, 0, 0, 0]) + np.random.randn(50) * 0.5
ridge = Ridge(alpha=1.0).fit(X, y)
print(f"岭回归(MAP)系数: {ridge.coef_.round(2)}")
```

## 9-14. 练习与路径

**题1：** MAP 和 MLE 的关系是什么？

**参考答案：** 当先验 $p(\theta)$ 为均匀分布（无信息先验）时，MAP = MLE。MAP 相当于 MLE 加上先验约束，防止过拟合。数据量越大，先验影响越小，MAP 趋近 MLE。

### 学习路径
- 前置：MLE、贝叶斯定理
- 平行：贝叶斯推断
- 进阶：变分推断、MCMC


## 3. 数学公式与推导

极大后验估计的数学基础：

### 损失函数
$$L(\theta) = \frac{1}{N} \sum_{i=1}^{N} \ell(y_i, f(x_i; \theta)) + \lambda R(\theta)$$

### 优化目标
$$\theta^* = \arg\min_\theta L(\theta)$$

梯度下降更新：
$$\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)$$

## 8. 手工代码实现（核心算法手写 + 注释）

以下是从零实现：

```python
import numpy as np

class 极大后验估计Scratch:
    def __init__(self, lr=0.01, n_iter=1000):
        self.lr, self.n_iter, self.losses = lr, n_iter, []
    def fit(self, X, y):
        n, d = X.shape
        self.w, self.b = np.zeros(d), 0.0
        for _ in range(self.n_iter):
            err = X @ self.w + self.b - y
            self.losses.append(np.mean(err**2))
            self.w -= self.lr * (2/n) * X.T @ err
            self.b -= self.lr * (2/n) * np.sum(err)
        return self
    def predict(self, X): return X @ self.w + self.b

np.random.seed(42)
X = np.random.randn(200, 3)
y = 2*X[:,0] - X[:,1] + 0.5*X[:,2] + np.random.randn(200)*0.1
m = 极大后验估计Scratch().fit(X, y)
print(f"Loss: {m.losses[-1]:.6f}")
```
