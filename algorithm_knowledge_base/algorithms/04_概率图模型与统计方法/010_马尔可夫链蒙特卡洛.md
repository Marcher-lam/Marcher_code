# 马尔可夫链蒙特卡洛 学习文档

> 用一句话说明这个算法的核心价值：作为贝叶斯推断的核心采样方法，MCMC通过构造平稳分布为目标的马尔可夫链，从复杂后验分布中采样，支持贝叶斯强化学习。

## 1. 算法基础认知

马尔可夫链蒙特卡洛（MCMC）是**贝叶斯统计中的核心采样算法**，通过构造平稳分布为目标后验的马尔可夫链，解决高维复杂分布的采样难题。

**一句话定义**：迭代更新状态，使马尔可夫链的平稳分布收敛到目标后验分布 $p(\theta|D)$，用链上的样本近似后验统计量。

**直觉类比**：就像你在迷宫里随机游走，但出口（目标分布）的吸引力会逐渐把你的路径拉向出口，最终你的位置分布就是出口周围的概率分布。

**历史背景**：Metropolis-Hastings算法于1953年提出，Gibbs采样于1984年提出，是贝叶斯推断、统计物理的核心工具，也用于贝叶斯强化学习。

**算法定位**：
- 属于贝叶斯推断、概率图模型的核心算法
- 用于从无法直接计算的后验分布中采样
- 是变分EM、高斯混合模型等算法的基础
- 在贝叶斯RL中用于推断未知参数

**前置知识**：
- 马尔可夫链基本概念（平稳分布、细致平衡）
- 贝叶斯统计基础（先验、似然、后验）
- Python/NumPy 编程基础

## 2. 核心原理

MCMC 的核心思想是：构造一条**马尔可夫链**，使其平稳分布恰好是目标后验分布 $p(\theta|D)$，通过迭代采样得到后验的样本近似。

**关键定理：细致平衡（Detailed Balance）**：
若马尔可夫链的转移概率 $T(\theta'|\theta)$ 满足：
$$p(\theta) T(\theta'|\theta) = p(\theta') T(\theta|\theta')$$
则 $p(\theta)$ 是链的平稳分布。

**两种经典MCMC算法**：
1. **Metropolis-Hastings（MH）**：
   - 提议：$\theta' \sim q(\theta'|\theta)$（提议分布，如高斯分布）
   - 接受概率：$A(\theta'|\theta) = \min\left(1, \frac{p(\theta'|D) q(\theta|\theta')}{p(\theta|D) q(\theta'|\theta)} \right)$
   - 以概率 $A$ 接受 $\theta'$，否则保留 $\theta$

2. **Gibbs采样**：
   - 适用于高维参数 $\theta = (\theta_1,...,\theta_d)$
   - 依次对每个维度采样：$\theta_i' \sim p(\theta_i | \theta_{-i}, D)$
   - 无需接受步骤，效率更高

### 2.1 Metropolis-Hastings算法详解

Metropolis-Hastings（MH）算法是MCMC最基础的实现方式。算法的核心步骤如下：

1. **初始化**：选择初始参数值 $\theta^{(0)}$

2. **迭代采样**（对 $t = 1, 2, ...$）：
   - 从提议分布 $q(\theta'|\theta^{(t-1)})$ 采样一个候选样本 $\theta'$
   - 计算接受概率：
   $$A = \min\left(1, \frac{p(\theta'|D) q(\theta^{(t-1)}|\theta')}{p(\theta^{(t-1)}|D) q(\theta'|\theta^{(t-1)})}\right)$$
   - 生成随机数 $u \sim U(0,1)$，如果 $u < A$ 则接受 $\theta^{(t)} = \theta'$，否则拒绝 $\theta^{(t)} = \theta^{(t-1)}$

**提议分布的选择**：
- 对称提议：$q(\theta'|\theta) = q(\theta|\theta')$，如高斯分布 $N(\theta, \sigma^2)$，接受概率简化为 $\min(1, p(\theta'|D)/p(\theta^{(t-1)}|D))$
- 自适应提议：根据采样情况动态调整 $\sigma$
- 独立性提议：$q(\theta')$ 不依赖 $\theta$，需要精心设计

**接受率调优**：
- 接受率过低（<0.1）：提议步长太小，采样效率低
- 接受率过高（>0.7）：提议步长太大，样本自相关高
- 最优接受率约0.23-0.5

### 2.2 Gibbs采样详解

Gibbs采样是MH算法的特例，适用于高维参数且条件分布易采样的情况。其核心思想是：每次只更新一个维度，固定其他维度。

**算法步骤**：
对 $t = 1, 2, ...$：
1. 初始化 $\theta^{(t)} = \theta^{(t-1)}$
2. 对每个维度 $i = 1, 2, ..., d$：
   - 从条件分布 $p(\theta_i | \theta_{-i}, D)$ 采样新值
   - 更新 $\theta_i^{(t)}$

**条件分布推导**：
$$p(\theta_i | \theta_{-i}, D) \propto p(D|\theta) p(\theta)$$
其中 $\theta_{-i}$ 表示除 $\theta_i$ 外的所有其他参数。

Gibbs采样的优点：
- 无需接受步骤，接受率始终为1
- 当条件分布易采样时效率高
- 适合高维参数空间

**应用场景示例：贝叶斯线性回归**
- 参数：$\theta = (w, \sigma^2)$
- Gibbs采样：
  - $p(w | \sigma^2, D)$：条件后验是正态分布
  - $p(\sigma^2 | w, D)$：条件后验是逆Gamma分布

### 2.3 MCMC应用场景

MCMC在科学和工程领域有广泛应用：

1. **贝叶斯统计推断**：估计后验分布、计算后验预测分布
2. **统计物理**：模拟伊辛模型、配分函数计算
3. **机器学习**：LDA主题模型、贝叶斯神经网络
4. **生物信息学**：基因序列分析、蛋白质结构预测
5. **强化学习**：贝叶斯RL中的环境模型推断、策略搜索

## 3. 数学公式与推导

**符号约定表**：

| 符号 | 含义 | 维度/范围 |
|------|------|-----------|
| $p(\theta|D)$ | 目标后验分布 | 概率密度 |
| $q(\theta'|\theta)$ | 提议分布 | 概率密度 |
| $A(\theta'|\theta)$ | MH接受概率 | $[0,1]$ |
| $T$ | 链的长度 | 正整数 |

**MH接受概率推导**：
根据细致平衡要求：
$$p(\theta) q(\theta'|\theta) A(\theta'|\theta) = p(\theta') q(\theta|\theta') A(\theta|\theta')$$
令 $A(\theta'|\theta) = \min\left(1, \frac{p(\theta'|D) q(\theta|\theta')}{p(\theta|D) q(\theta'|\theta)} \right)$，可满足上式。

**贝叶斯后验公式**：
$$p(\theta|D) = \frac{p(D|\theta) p(\theta)}{p(D)} \propto p(D|\theta) p(\theta)$$
实际计算时只需未归一化的后验（省略 $p(D)$）。

## 4. 训练过程讲解

**数据预处理**：
- 定义先验 $p(\theta)$、似然 $p(D|\theta)$
- 选择提议分布 $q(\theta'|\theta)$（通常选高斯分布 $\mathcal{N}(\theta, \sigma^2 I)$）
- 初始化链的初始状态 $\theta_0$

**参数初始化**：
| 参数 | 作用 | 推荐值 |
|------|------|--------|
| 链长度 $T$ | 总采样步数 | 10000~100000 |
| 燃烧期（Burn-in） | 丢弃的前 $B$ 个样本 | 1000~5000 |
| 提议方差 $\sigma^2$ | 高斯提议的方差 | 0.1~1.0 |
| 采样间隔（Thinning） | 每隔 $K$ 步取一个样本 | 5~10 |

**MH算法迭代过程**：
1. 初始化 $\theta = \theta_0$，存储样本列表 $samples = []$
2. 对 $t=1..T$：
   a. 从提议分布采样 $\theta' \sim q(\cdot|\theta)$
   b. 计算接受概率 $A = \min\left(1, \frac{p(\theta'|D) q(\theta|\theta')}{p(\theta|D) q(\theta'|\theta)} \right)$
   c. 以概率 $A$ 接受 $\theta = \theta'$，否则保留原 $\theta$
   d. 若 $t > B$ 且 $t \% K == 0$，将 $\theta$ 加入 $samples$
3. 用 $samples$ 近似后验统计量（均值、方差等）

## 5. 应用场景

**典型应用**：

1. **贝叶斯线性回归**：
   - 参数 $\theta = (w, \sigma^2)$：权重和噪声方差
   - 目标：从后验 $p(w, \sigma^2|D)$ 采样
   - 适用性：MCMC可处理高维权重，避免点估计的过拟合

2. **贝叶斯强化学习（参数推断）**：
   - 参数：环境转移概率、奖励函数参数
   - 目标：从后验 $p(M|D)$ 采样环境模型
   - 适用性：解决模型不确定性，提升RL探索效率

**适用场景特征**：
- 后验分布无解析形式，无法直接采样
- 高维参数空间，变分推断难以近似
- 贝叶斯推断、统计物理等领域的采样任务

**不适用场景**：
- 超高维参数（>1000维，MCMC收敛慢）
- 实时任务（采样速度慢）

## 6. 优缺点分析

**优点**：
1. **通用性强**：只要能计算未归一化后验，就能采样任意分布
2. **无偏估计**：理论上链收敛后样本是后验的无偏样本
3. **精度高**：比变分推断更接近真实后验

**缺点**：
1. **收敛慢**：需要长时间迭代才能收敛到平稳分布
2. **调参困难**：提议方差 $\sigma^2$ 影响接受率和收敛速度
3. **计算量大**：每步需计算后验密度，高维场景耗时

**MH vs Gibbs采样对比**：
| 特性 | Metropolis-Hastings | Gibbs采样 |
|------|---------------------|-----------|
| 接受步骤 | 需要 | 不需要 |
| 高维效率 | 低 | 高 |
| 提议分布 | 需要 | 不需要 |
| 适用场景 | 低维、任意分布 | 高维、条件分布易采样 |

## 7. 调库实现

使用PyMC3（或NumPy手写）实现MH采样，推断贝叶斯线性回归的后验：

```python
import numpy as np
import matplotlib.pyplot as plt

def metropolis_hastings(log_posterior, theta_init, T=10000, sigma=0.1, burnin=1000, thin=5):
    """
    MH采样算法
    log_posterior: 未归一化对数后验函数（输入theta，输出log p(theta|D)）
    theta_init: 初始参数
    T: 总迭代步数
    sigma: 高斯提议的标准差
    burnin: 燃烧期步数
    thin: 采样间隔
    """
    theta = theta_init.copy()
    samples = []
    accepted = 0
    
    for t in range(T):
        # 提议新样本
        theta_proposal = theta + np.random.normal(0, sigma, size=theta.shape)
        
        # 计算接受概率的对数（避免数值下溢）
        log_accept = log_posterior(theta_proposal) - log_posterior(theta)
        accept_prob = min(1.0, np.exp(log_accept))
        
        # 接受/拒绝
        if np.random.rand() < accept_prob:
            theta = theta_proposal
            accepted += 1
        
        # 存储样本（跳过燃烧期，按间隔采样）
        if t > burnin and (t - burnin) % thin == 0:
            samples.append(theta.copy())
    
    accept_rate = accepted / T
    print(f"接受率: {accept_rate:.2f}")
    return np.array(samples)

# 示例：贝叶斯线性回归的后验采样
def log_posterior_linear(theta, X, y, prior_var=10.0, noise_var=1.0):
    """线性回归的对数后验（先验为高斯，似然为高斯）"""
    w = theta  # 权重参数
    n = len(y)
    
    # 先验：w ~ N(0, prior_var*I)
    log_prior = -0.5 * np.sum(w**2) / prior_var
    
    # 似然：y ~ N(Xw, noise_var*I)
    y_pred = X @ w
    log_likelihood = -0.5 * np.sum((y - y_pred)**2) / noise_var
    
    return log_prior + log_likelihood

if __name__ == "__main__":
    # 生成模拟数据
    np.random.seed(42)
    n_samples = 100
    X = np.random.randn(n_samples, 3)  # 3个特征
    true_w = np.array([2.0, -1.0, 0.5])
    y = X @ true_w + np.random.randn(n_samples) * 0.5
    
    # 初始化并运行MH
    theta_init = np.zeros(3)
    samples = metropolis_hastings(
        lambda theta: log_posterior_linear(theta, X, y),
        theta_init, T=20000, sigma=0.2, burnin=2000, thin=5
    )
    
    # 输出后验统计量
    print(f"后验均值: {samples.mean(axis=0)}")
    print(f"真实权重: {true_w}")
    
    # 可视化权重1的采样轨迹
    plt.plot(samples[:, 0])
    plt.xlabel('样本序号')
    plt.ylabel('权重值')
    plt.title('MH采样权重轨迹')
    plt.grid(True, alpha=0.3)
    plt.show()
```

## 8. 手工代码实现

从零实现Gibbs采样（二元高斯分布示例）：

```python
import numpy as np

def gibbs_sampling_gaussian(mu, cov, T=5000, burnin=500):
    """
    二元高斯分布的Gibbs采样
    mu: 均值向量 (2,)
    cov: 协方差矩阵 (2,2)
    """
    d = 2
    samples = []
    theta = np.zeros(d)
    
    for t in range(T):
        # 依次采样每个维度
        for i in range(d):
            # 计算条件分布 N(mu_i|others, sigma_i|others)
            mask = np.array([j != i for j in range(d)])
            mu_cond = mu[i] + cov[i, mask] @ np.linalg.inv(cov[mask][:, mask]) @ (theta[mask] - mu[mask])
            var_cond = cov[i,i] - cov[i, mask] @ np.linalg.inv(cov[mask][:, mask]) @ cov[mask, i]
            
            # 从条件分布采样
            theta[i] = np.random.normal(mu_cond, np.sqrt(var_cond))
        
        if t > burnin:
            samples.append(theta.copy())
    
    return np.array(samples)
```

## 10. 模型评估

评估MCMC采样的收敛性：

```python
def evaluate_mcmc_convergence(samples):
    """评估MCMC收敛性（Gelman-Rubin统计量简化版）"""
    # 分割样本为前半和后半
    n = len(samples)
    half = n // 2
    chain1 = samples[:half]
    chain2 = samples[half:]
    
    # 计算各链均值和方差
    mu1, mu2 = chain1.mean(axis=0), chain2.mean(axis=0)
    var1, var2 = chain1.var(axis=0), chain2.var(axis=0)
    
    # 合并方差和均值
    var_pool = (var1 + var2) / 2
    mu_pool = (mu1 + mu2) / 2
    
    # Gelman-Rubin统计量（简化版）
    B = half * np.sum((mu1 - mu_pool)**2)  #  between-chain variance
    W = np.sum(var1 + var2) / 2          # within-chain variance
    R_hat = np.sqrt((W + B/2) / W)
    
    print(f"Gelman-Rubin统计量: {R_hat}")
    print("若R_hat接近1，说明链已收敛")
    return R_hat
```

## 11. 常见问题与易错点

1. **链不收敛，样本偏离真实值**
   - 原因：燃烧期太短，或提议方差设置不当
   - 解决：延长燃烧期到5000步以上，调整提议方差使接受率在0.2~0.5之间

2. **接受率过低/过高**
   - 现象：接受率<0.1或>0.7，采样效率低
   - 解决：调整提议方差 $\sigma$：接受率低则增大 $\sigma$，过高则减小 $\sigma$

3. **样本自相关性高**
   - 现象：样本间高度相关，有效样本量小
   - 解决：增大采样间隔（thinning）到10~20步

**关键公式**：
MH接受概率：$A = \min\left(1, \frac{p(\theta'|D) q(\theta|\theta')}{p(\theta|D) q(\theta'|\theta)} \right)$

**与前序算法关系**：
- 是贝叶斯推断的核心工具，支撑变分EM、贝叶斯RL等算法
