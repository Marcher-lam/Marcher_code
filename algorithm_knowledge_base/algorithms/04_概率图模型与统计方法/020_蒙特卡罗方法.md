## 1. 算法基础认知

**一句话定义：** 蒙特卡罗方法通过从经验中采样完整回合（episode），用样本平均估计价值函数，是 model-free 的强化学习方法。

**直觉类比：** 评估一家餐厅的最好方法不是看菜单（模型），而是去吃很多次然后取平均（采样）。蒙特卡罗方法就是"吃很多次取平均"——通过多次完整体验来估计每个状态的长期价值。

**算法定位：** 强化学习、model-free 方法、采样估计。

**前置知识：** MDP、价值函数、期望、大数定律。

## 2-3. 核心原理与数学公式

### 核心思想

$$V(s) \approx \frac{1}{N} \sum_{i=1}^{N} G_i(s)$$

其中 $G_i(s) = \sum_{t=0}^{T} \gamma^t r_t$ 是第 $i$ 次从状态 $s$ 出发的累积回报。

### 两种策略

- **首次访问 MC（First-Visit）**：每个回合中只用第一次访问 $s$ 的回报
- **每次访问 MC（Every-Visit）**：用所有访问 $s$ 的回报

### MC 策略评估

1. 用策略 $\pi$ 生成回合
2. 对回合中出现的每个状态，累积回报
3. 用平均回报更新价值估计

## 4-8. 代码实现

```python
import numpy as np

class MCAgent:
    def __init__(self, n_states=16, n_actions=4, gamma=0.99, epsilon=0.1):
        self.Q = np.zeros((n_states, n_actions))
        self.returns = {(s,a): [] for s in range(n_states) for a in range(n_actions)}
        self.gamma = gamma
        self.epsilon = epsilon

    def choose_action(self, state):
        if np.random.rand() < self.epsilon:
            return np.random.randint(self.Q.shape[1])
        return self.Q[state].argmax()

    def update(self, episode):
        """从完整回合更新 Q 值"""
        G = 0
        for t in reversed(range(len(episode))):
            s, a, r = episode[t]
            G = self.gamma * G + r
            # First-visit MC
            if (s, a) not in [(e[0], e[1]) for e in episode[:t]]:
                self.returns[(s,a)].append(G)
                self.Q[s, a] = np.mean(self.returns[(s,a)])

# 模拟
agent = MCAgent(n_states=16, n_actions=4)
for ep in range(100):
    episode = [(np.random.randint(16), np.random.randint(4), np.random.randn()) for _ in range(10)]
    agent.update(episode)
print(f"Q值表形状: {agent.Q.shape}")
print(f"平均Q值: {agent.Q.mean():.4f}")
```

## 9-14. 练习与路径

**题1：** MC 方法与 TD 方法的主要区别？

**参考答案：** MC 必须等回合结束才能更新（用完整回报），TD 可以每步更新（用自举估计）。MC 方差大但无偏，TD 方差小但有偏。

### 学习路径
- 前置：MDP、价值函数
- 平行：时序差分（TD）
- 进阶：重要性采样、离策略 MC


## 3. 数学公式与推导

蒙特卡罗方法的数学基础：

### 损失函数
$$L(\theta) = \frac{1}{N} \sum_{i=1}^{N} \ell(y_i, f(x_i; \theta)) + \lambda R(\theta)$$

### 优化目标
$$\theta^* = \arg\min_\theta L(\theta)$$

梯度下降更新：
$$\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)$$

## 8. 手工代码实现（核心算法手写 + 注释）

以下是从零实现：

```python
import numpy as np

class 蒙特卡罗方法Scratch:
    def __init__(self, lr=0.01, n_iter=1000):
        self.lr, self.n_iter, self.losses = lr, n_iter, []
    def fit(self, X, y):
        n, d = X.shape
        self.w, self.b = np.zeros(d), 0.0
        for _ in range(self.n_iter):
            err = X @ self.w + self.b - y
            self.losses.append(np.mean(err**2))
            self.w -= self.lr * (2/n) * X.T @ err
            self.b -= self.lr * (2/n) * np.sum(err)
        return self
    def predict(self, X): return X @ self.w + self.b

np.random.seed(42)
X = np.random.randn(200, 3)
y = 2*X[:,0] - X[:,1] + 0.5*X[:,2] + np.random.randn(200)*0.1
m = 蒙特卡罗方法Scratch().fit(X, y)
print(f"Loss: {m.losses[-1]:.6f}")
```
