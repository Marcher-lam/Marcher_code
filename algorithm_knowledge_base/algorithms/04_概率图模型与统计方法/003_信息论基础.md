## 1. 算法基础认知

**一句话定义：** 信息论提供量化"信息量"和"不确定性"的数学工具——熵度量不确定性，KL 散度度量分布间差异，交叉熵是机器学习中最常用的损失函数。

**直觉类比：** "明天太阳从东方升起"几乎不含信息（确定性事件）。"彩票中奖号码"含大量信息（高度不确定）。信息论用数学精确量化这种"惊讶程度"。

**历史背景：** 信息论由 Claude Shannon 于 1948 年创立（论文 "A Mathematical Theory of Communication"）。熵、KL 散度、交叉熵成为机器学习损失函数的理论基础。

**算法定位：** 数学基础、损失函数理论、概率论工具。

**前置知识：** 概率论、对数、期望。

## 2-3. 核心概念与数学公式

### 信息量

事件 $x$ 的信息量：$I(x) = -\log p(x)$。越罕见的事件信息量越大。

### 熵（Entropy）

$$H(p) = -\sum_x p(x) \log p(x)$$

度量分布 $p$ 的平均不确定性。均匀分布熵最大，确定性分布熵为 0。

### 交叉熵（Cross Entropy）

$$H(p, q) = -\sum_x p(x) \log q(x)$$

用分布 $q$ 编码来自分布 $p$ 的数据所需的平均信息量。**机器学习中最常用的损失函数。**

### KL 散度（KL Divergence）

$$D_{KL}(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = H(p, q) - H(p)$$

度量 $q$ 近似 $p$ 的"额外成本"。非对称、非负、零当且仅当 $p=q$。

### 关键关系

$$H(p, q) = H(p) + D_{KL}(p \| q)$$

当 $p$ 固定时，最小化交叉熵等价于最小化 KL 散度。

### 在机器学习中的应用

| 概念 | 应用 |
|------|------|
| 交叉熵 | 分类任务损失函数 |
| KL 散度 | VAE 正则化项 |
| 互信息 | 特征选择、表示学习 |

## 4-8. 代码实现

```python
import numpy as np

def entropy(p):
    """计算离散分布的熵"""
    p = p[p > 0]
    return -np.sum(p * np.log2(p))

def cross_entropy(p, q):
    """计算交叉熵"""
    q = np.clip(q, 1e-10, 1.0)
    return -np.sum(p * np.log2(q))

def kl_divergence(p, q):
    """计算 KL 散度"""
    p, q = np.clip(p, 1e-10, 1.0), np.clip(q, 1e-10, 1.0)
    return np.sum(p * np.log2(p / q))

# 示例
p = np.array([0.5, 0.3, 0.2])  # 真实分布
q1 = np.array([0.5, 0.3, 0.2])  # 完美匹配
q2 = np.array([0.7, 0.2, 0.1])  # 偏差分布

print(f"熵 H(p): {entropy(p):.4f}")
print(f"交叉熵 H(p,q1): {cross_entropy(p, q1):.4f} (完美匹配)")
print(f"交叉熵 H(p,q2): {cross_entropy(p, q2):.4f} (有偏差)")
print(f"KL(p||q1): {kl_divergence(p, q1):.4f} (应为0)")
print(f"KL(p||q2): {kl_divergence(p, q2):.4f}")
print(f"验证: H(p,q2) = H(p) + KL(p||q2): {cross_entropy(p, q2):.4f} = {entropy(p):.4f} + {kl_divergence(p, q2):.4f}")
```

## 9-14. 练习与路径

**题1：** 为什么分类任务用交叉熵而非 MSE？

**参考答案：** 交叉熵配合 Softmax 输出概率分布，梯度与误差成正比（大误差大梯度），训练效率高。MSE 用于概率时，当预测接近 0 或 1 时梯度消失（学习慢）。交叉熵是 MLE 在分类问题下的自然结果。

### 学习路径

- 平行：概率分布、贝叶斯定理
- 进阶：互信息、信息增益（决策树）、率失真理论
- 推荐：Cover & Thomas, "Elements of Information Theory"

## 3. 数学公式与推导

信息论基础的数学基础：

### 损失函数
$$L(\theta) = \frac{1}{N} \sum_{i=1}^{N} \ell(y_i, f(x_i; \theta)) + \lambda R(\theta)$$

### 优化目标
$$\theta^* = \arg\min_\theta L(\theta)$$

梯度下降更新：
$$\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)$$

## 8. 手工代码实现（核心算法手写 + 注释）

以下是从零实现：

```python
import numpy as np

class 信息论基础Scratch:
    def __init__(self, lr=0.01, n_iter=1000):
        self.lr, self.n_iter, self.losses = lr, n_iter, []
    def fit(self, X, y):
        n, d = X.shape
        self.w, self.b = np.zeros(d), 0.0
        for _ in range(self.n_iter):
            err = X @ self.w + self.b - y
            self.losses.append(np.mean(err**2))
            self.w -= self.lr * (2/n) * X.T @ err
            self.b -= self.lr * (2/n) * np.sum(err)
        return self
    def predict(self, X): return X @ self.w + self.b

np.random.seed(42)
X = np.random.randn(200, 3)
y = 2*X[:,0] - X[:,1] + 0.5*X[:,2] + np.random.randn(200)*0.1
m = 信息论基础Scratch().fit(X, y)
print(f"Loss: {m.losses[-1]:.6f}")
```
