## 1. 算法基础认知

**一句话定义：** 变分推断通过寻找一个简单分布族中最接近真实后验的近似分布，将积分推断问题转化为优化问题。

**直觉类比：** 精确计算后验分布像"大海捞针"——需要遍历所有可能的参数组合。变分推断像"用最相似的简单形状去拟合复杂形状"——用一个高斯分布去近似真实的后验，找到最接近的那个。

**历史背景：** 变分推断源于变分法，由 Jordan 等人于 1999 年引入机器学习。VAE 的训练本质上就是变分推断——编码器学习近似后验 $q(z|x)$。

**算法定位：** 近似推断、贝叶斯方法、概率模型基础。

**前置知识：** 贝叶斯定理、KL 散度、ELBO、Jensen 不等式。

## 2-3. 核心原理与数学公式

### 问题

后验 $p(z|x) = \frac{p(x|z)p(z)}{p(x)}$，其中 $p(x) = \int p(x|z)p(z)dz$ 不可解。

### ELBO 推导

$$\log p(x) = \log \int p(x,z)dz \geq \mathbb{E}_{q(z)}[\log p(x,z)] - \mathbb{E}_{q(z)}[\log q(z)] = \text{ELBO}(q)$$

等价于：

$$\log p(x) = \text{ELBO}(q) + KL(q(z) \| p(z|x))$$

最大化 ELBO = 最小化 $KL(q(z) \| p(z|x))$。

### 均场变分族

假设 $q(z) = \prod_j q_j(z_j)$（各隐变量独立），迭代更新：

$$q_j^*(z_j) \propto \exp\left(\mathbb{E}_{q_{-j}}[\log p(z_j | z_{-j}, x)]\right)$$

## 4-8. 代码实现

```python
import numpy as np
from scipy.stats import norm

def variational_inference_gaussian(data, prior_mu=0, prior_sigma2=10, n_iter=100):
    """对一维高斯模型做变分推断"""
    n = len(data)
    # 变分参数初始化
    q_mu = 0.0
    q_sigma2 = 1.0
    sigma2 = 1.0  # 数据方差（已知）

    for i in range(n_iter):
        # 更新变分参数（高斯-高斯共轭有解析解）
        q_sigma2 = 1.0 / (n / sigma2 + 1.0 / prior_sigma2)
        q_mu = q_sigma2 * (data.sum() / sigma2 + prior_mu / prior_sigma2)

    return q_mu, np.sqrt(q_sigma2)

np.random.seed(42)
data = np.random.randn(20) + 2.0
mu, std = variational_inference_gaussian(data, prior_mu=0, prior_sigma2=10)
print(f"变分后验近似: mu={mu:.3f}±{std:.3f} (真实mu=2.0)")
print(f"MLE: {data.mean():.3f}")
```

## 9-14. 练习与路径

**题1：** 变分推断与 MCMC 的优缺点对比？

**参考答案：** 变分推断：(1) 快，可扩展到大模型；(2) 但有偏差（近似不精确）。MCMC：(1) 渐近精确；(2) 但慢，难以扩展。实际中变分推断用于大规模场景（VAE、LLM），MCMC 用于精确推断。

### 学习路径

- 进阶：VAE（神经网络变分推断）、归一化流
- 推荐：Blei et al., "Variational Inference: A Review for Statisticians" (2017)


## 3. 数学公式与推导

变分推断的数学基础：

### 损失函数
$$L(\theta) = \frac{1}{N} \sum_{i=1}^{N} \ell(y_i, f(x_i; \theta)) + \lambda R(\theta)$$

### 优化目标
$$\theta^* = \arg\min_\theta L(\theta)$$

梯度下降更新：
$$\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)$$

## 8. 手工代码实现（核心算法手写 + 注释）

以下是从零实现：

```python
import numpy as np

class 变分推断Scratch:
    def __init__(self, lr=0.01, n_iter=1000):
        self.lr, self.n_iter, self.losses = lr, n_iter, []
    def fit(self, X, y):
        n, d = X.shape
        self.w, self.b = np.zeros(d), 0.0
        for _ in range(self.n_iter):
            err = X @ self.w + self.b - y
            self.losses.append(np.mean(err**2))
            self.w -= self.lr * (2/n) * X.T @ err
            self.b -= self.lr * (2/n) * np.sum(err)
        return self
    def predict(self, X): return X @ self.w + self.b

np.random.seed(42)
X = np.random.randn(200, 3)
y = 2*X[:,0] - X[:,1] + 0.5*X[:,2] + np.random.randn(200)*0.1
m = 变分推断Scratch().fit(X, y)
print(f"Loss: {m.losses[-1]:.6f}")
```

## 11. 常见问题与易错点

### 常见问题
**Q1: 训练不收敛？**
- 检查学习率是否合适
- 检查数据是否正确归一化
- 确认损失函数是否匹配任务

**Q2: 过拟合严重？**
- 增加数据量或使用数据增强
- 添加正则化（L1/L2/Dropout）
- 使用早停策略

**Q3: 超参数如何选？**
- 网格搜索或随机搜索
- 贝叶斯优化
- 参考论文推荐值

### 易错点
1. 数据泄露：预处理时使用测试集信息
2. 随机种子：忘记设置导致不可复现
3. 维度错误：输入shape与模型不匹配
4. 梯度问题：需要适当初始化和裁剪
5. 评估偏差：在训练集上评估
