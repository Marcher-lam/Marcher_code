# 隐马尔可夫 学习文档

> 用一句话说明这个算法的核心价值：作为经典时序概率模型，隐马尔可夫模型通过隐藏状态序列建模观测数据，解决序列标注、语音识别等问题。

## 1. 算法基础认知

隐马尔可夫模型（Hidden Markov Model, HMM）是**时序数据的概率图模型**，假设观测数据由隐藏的马尔可夫链生成，通过隐藏状态解释观测序列。

**一句话定义**：由初始状态分布 $\pi$、状态转移矩阵 $A$、观测概率矩阵 $B$ 组成，解决评估、解码、学习三类问题。

**直觉类比**：就像你听朋友在隔壁房间说话（观测序列），通过声音猜测他正在做的活动（隐藏状态：吃饭、睡觉、工作），活动之间按马尔可夫链转移。

**历史背景**：由Baum等人于1960s-1970s提出，L.R.Rabiner于1989年发表经典教程，是语音识别、自然语言处理的基础模型。

**算法定位**：
- 属于概率图模型、无监督/半监督学习
- 处理时序数据，隐藏状态不可直接观测
- 三类经典问题：评估（Forward/Backward）、解码（Viterbi）、学习（Baum-Welch）
- 在RL中用于POMDP建模、状态压缩

**前置知识**：
- 马尔可夫链基础（状态转移、平稳分布）
- EM算法（Baum-Welch是EM的特例）
- 概率论基础（条件概率、联合分布）

## 2. 核心原理

HMM的核心思想是：假设系统按**隐藏的马尔可夫链**在状态间转移，每个隐藏状态生成一个观测值，通过三类算法解决不同问题。

**模型参数**：
$$\lambda = (A, B, \pi)$$
- $\pi$：初始状态分布，$\pi_i = P(q_1 = i)$
- $A$：状态转移矩阵，$A_{ij} = P(q_{t+1}=j | q_t=i)$
- $B$：观测概率矩阵，$B_{jk} = P(o_t=k | q_t=j)$

**三类经典问题**：
1. **评估问题**：给定模型 $\lambda$ 和观测序列 $O$，计算 $P(O|\lambda)$
   - 解法：前向算法（Forward）或后向算法（Backward）
2. **解码问题**：给定模型 $\lambda$ 和观测序列 $O$，求最可能的隐藏状态序列 $Q^*$
   - 解法：维特比算法（Viterbi）
3. **学习问题**：给定观测序列 $O$，估计模型参数 $\lambda$ 最大化 $P(O|\lambda)$
   - 解法：鲍姆-韦尔奇算法（Baum-Welch，即EM算法）

### 2.1 前向-后向算法详解

前向-后向算法是HMM最核心的算法，用于计算评估问题和学习问题中的后验概率。

**前向算法（Forward Algorithm）**：
计算前向概率 $\alpha_t(i) = P(o_1, o_2, ..., o_t, q_t = i | \lambda)$。

初始化（$t=1$）：
$$\alpha_1(i) = \pi_i \cdot b_i(o_1)$$

递推（$t = 2, 3, ..., T$）：
$$\alpha_{t}(j) = \left[ \sum_{i=1}^{N} \alpha_{t-1}(i) \cdot a_{ij} \right] \cdot b_j(o_t)$$

终止：
$$P(O|\lambda) = \sum_{i=1}^{N} \alpha_T(i)$$

复杂度：$O(T \cdot N^2)$，相比暴力枚举 $O(N^T)$ 大幅降低。

**后向算法（Backward Algorithm）**：
计算后向概率 $\beta_t(i) = P(o_{t+1}, o_{t+2}, ..., o_T | q_t = i, \lambda)$。

初始化（$t=T$）：
$$\beta_T(i) = 1$$

递推（$t = T-1, T-2, ..., 1$）：
$$\beta_t(i) = \sum_{j=1}^{N} a_{ij} \cdot b_j(o_{t+1}) \cdot \beta_{t+1}(j)$$

**联合后验概率**：
给定观测序列 $O$，时刻 $t$ 处于状态 $i$ 的概率：
$$\gamma_t(i) = \frac{\alpha_t(i) \beta_t(i)}{P(O|\lambda)} = \frac{\alpha_t(i) \beta_t(i)}{\sum_{j=1}^{N} \alpha_t(j) \beta_t(j)}$$

### 2.2 维特比解码详解

维特比算法（Viterbi Algorithm）用于找最可能的隐藏状态序列，本质上是动态规划。

**算法步骤**：

1. **初始化**（$t=1$）：
$$\delta_1(i) = \pi_i \cdot b_i(o_1)$$
$$\psi_1(i) = 0$$

2. **递推**（$t = 2, 3, ..., T$）：
对每个状态 $j$：
$$\delta_t(j) = \max_{1 \leq i \leq N} [\delta_{t-1}(i) \cdot a_{ij}] \cdot b_j(o_t)$$
$$\psi_t(j) = \arg\max_{1 \leq i \leq N} [\delta_{t-1}(i) \cdot a_{ij}]$$

3. **终止**：
$$P^* = \max_{1 \leq i \leq N} \delta_T(i)$$
$$q_T^* = \arg\max_{1 \leq i \leq N} \delta_T(i)$$

4. **回溯**（$t = T-1, T-2, ..., 1$）：
$$q_t^* = \psi_{t+1}(q_{t+1}^*)$$

**与前向算法的区别**：
- 前向算法：求和 $\sum$，计算所有路径的概率之和
- 维特比算法：取最大 $\max$，找概率最大的单一路径

### 2.3 HMM应用场景详解

HMM在实际中有广泛的应用：

**语音识别**：
- 隐藏状态：音素（phoneme）或音节（syllable）
- 观测：声学特征（如MFCC、PLP）
- 应用：传统语音识别系统的核心组件，现代系统仍使用HMM作为声学模型的一部分

**自然语言处理**：
- 词性标注：隐藏状态=词性标签，观测=单词
- 中文分词：隐藏状态={B,M,E,S}，观测=汉字
- 句法分析：隐藏状态=句法标签，观测=词性

**生物信息学**：
- 基因预测：隐藏状态={外显子、内含子、基因间区}，观测=DNA序列
- 蛋白质结构预测：隐藏状态=二级结构，观测=氨基酸序列

**强化学习**：
- POMDP建模：当智能体只能观察到部分状态时，可以用HMM建模环境
- 状态压缩：将复杂状态序列压缩为少数隐藏状态

## 3. 数学公式与推导

**符号约定表**：

| 符号 | 含义 | 维度/范围 |
|------|------|-----------|
| $N$ | 隐藏状态数 | 正整数 |
| $M$ | 观测符号数 | 正整数 |
| $T$ | 观测序列长度 | 正整数 |
| $\alpha_t(i)$ | 前向概率 | $P(o_1,...,o_t, q_t=i|\lambda)$ |
| $\beta_t(i)$ | 后向概率 | $P(o_{t+1},...,o_T | q_t=i, \lambda)$ |

**前向算法推导**：
$$\alpha_1(i) = \pi_i B_i(o_1)$$
$$\alpha_{t+1}(j) = \left( \sum_{i=1}^N \alpha_t(i) A_{ij} \right) B_j(o_{t+1})$$
最终 $P(O|\lambda) = \sum_{i=1}^N \alpha_T(i)$

**维特比算法推导**：
定义 $\delta_t(i)$ 为时刻 $t$ 以状态 $i$ 结束的最大概率路径概率：
$$\delta_1(i) = \pi_i B_i(o_1)$$
$$\delta_{t+1}(j) = \max_{i=1..N} [\delta_t(i) A_{ij}] B_j(o_{t+1})$$
同时记录路径指针 $\psi_{t+1}(j) = \arg\max_{i} [\delta_t(i) A_{ij}]$

**Baum-Welch（EM）更新公式**：
- E步：计算 $\gamma_t(i) = P(q_t=i|O,\lambda)$, $\xi_t(i,j) = P(q_t=i, q_{t+1}=j|O,\lambda)$
- M步：
  $$\pi_i = \gamma_1(i)$$
  $$A_{ij} = \frac{\sum_{t=1}^{T-1} \xi_t(i,j)}{\sum_{t=1}^{T-1} \gamma_t(i)}$$
  $$B_j(k) = \frac{\sum_{t=1}^T \mathbb{1}(o_t=k) \gamma_t(j)}{\sum_{t=1}^T \gamma_t(j)}$$

## 4. 训练过程讲解

**数据预处理**：
- 观测序列 $O = (o_1,...,o_T)$，离散符号或连续值（连续观测用高斯混合 $B_j(o) = \sum_m c_{jm} \mathcal{N}(o|\mu_{jm}, \Sigma_{jm})$）
- 确定隐藏状态数 $N$、观测符号数 $M$

**参数初始化**：
| 参数 | 作用 | 推荐值 |
|------|------|--------|
| $N$ | 隐藏状态数 | 根据先验知识或BIC选择 |
| 最大迭代次数 | Baum-Welch停止条件 | 100~500 |
| 收敛阈值 | 对数似然变化阈值 | 1e-6 |

**Baum-Welch迭代过程**：
1. 初始化 $\lambda^{(0)} = (A^{(0)}, B^{(0)}, \pi^{(0)})$
2. 对 $k=0,1,...$：
   a. **E步**：用前向-后向算法计算 $\gamma_t(i)$, $\xi_t(i,j)$
   b. **M步**：更新 $A^{(k+1)}, B^{(k+1)}, \pi^{(k+1)}$
   c. 计算对数似然变化，若 $|\log P(O|\lambda^{(k+1)}) - \log P(O|\lambda^{(k)})| < \epsilon$ 则停止
3. 输出最终模型 $\lambda$

## 5. 应用场景

**典型应用**：

1. **词性标注（Part-of-Speech Tagging）**：
   - 隐藏状态：名词、动词、形容词等词性
   - 观测序列：句子中的单词
   - 适用性：HMM是早期NLP序列标注的基础模型

2. **语音识别**：
   - 隐藏状态：音素、音节
   - 观测序列：音频特征（MFCC）
   - 适用性：HMM是传统语音识别的核心模型

3. **POMDP建模（强化学习）**：
   - 隐藏状态：真实环境状态
   - 观测序列：智能体观察到的部分状态
   - 适用性：HMM用于建模部分可观测环境

**适用场景特征**：
- 时序数据，存在隐藏状态
- 隐藏状态满足马尔可夫性
- 观测由隐藏状态生成

**不适用场景**：
- 非时序数据（用高斯混合等）
- 隐藏状态不满足马尔可夫性（用RNN等）
- 观测与历史相关（用高阶HMM）

## 6. 优缺点分析

**优点**：
1. **时序建模能力强**：自然处理时序数据，考虑状态转移
2. **理论上严谨**：基于概率图模型，有完整的EM学习算法
3. **可解释性好**：隐藏状态有明确物理意义

**缺点**：
1. **马尔可夫假设限制**：假设隐藏状态仅依赖前一状态，无法建模长依赖
2. **初始化敏感**：Baum-Welch易陷入局部最优
3. **状态数需预设**：无法自动选择隐藏状态数

**与CRF对比**：
| 特性 | HMM | CRF |
|------|-----|-----|
| 模型类型 | 生成式（联合概率 $P(O,Q)$） | 判别式（条件概率 $P(Q|O)$） |
| 特征灵活性 | 低（仅用观测概率） | 高（可自定义任意特征） |
| 性能 | 中等 | 更优（尤其NLP任务） |

```python
import numpy as np
from hmmlearn import hmm
import matplotlib.pyplot as plt

# 示例：模拟词性标注数据
# 隐藏状态：0=名词，1=动词，2=形容词（N=3）
# 观测：0=单词1，1=单词2，...，4=单词5（M=5）

# 生成模拟数据
np.random.seed(42)
n_samples = 100  # 100个句子
seq_length = 10   # 每个句子10个单词

X = []  # 观测序列（展平）
lengths = []  # 每个句子的长度
true_states = []  # 真实隐藏状态（用于评估）

for _ in range(n_samples):
    # 随机生成隐藏状态序列（简单马尔可夫链）
    states = np.random.choice(3, size=seq_length, p=[0.5, 0.3, 0.2])
    # 根据状态生成观测（每个状态对应不同的单词分布）
    if states[0] == 0:
        obs = np.random.choice(5, size=seq_length, p=[0.6,0.2,0.1,0.05,0.05])
    elif states[0] == 1:
        obs = np.random.choice(5, size=seq_length, p=[0.1,0.6,0.2,0.05,0.05])
    else:
        obs = np.random.choice(5, size=seq_length, p=[0.05,0.1,0.6,0.2,0.05])
    X.append(obs)
    lengths.append(seq_length)
    true_states.extend(states)

X = np.concatenate(X).reshape(-1, 1)  # hmmlearn要求二维输入
lengths = np.array(lengths)

# 初始化HMM模型
model = hmm.MultinomialHMM(n_components=3, n_iter=100, tol=1e-6, random_state=42)
model.n_features = 5  # 观测符号数

# 训练（Baum-Welch）
model.fit(X, lengths)

# 预测隐藏状态（解码）
pred_states = model.predict(X, lengths)

# 评估准确率（简单匹配，不考虑排列）
from sklearn.metrics import accuracy_score
# 注意：HMM的状态标签可能和真实标签有排列，这里简化评估
print(f"模型状态转移矩阵:\n{model.transmat_}")
print(f"模型观测概率矩阵:\n{model.emissionprob_}")
print(f"初始状态分布: {model.startprob_}")

# 对数似然

print(f"对数似然: {log_likelihood:.2f}")
```

## 8. 手工代码实现

从零实现维特比（Viterbi）解码算法：

```python
import numpy as np

def viterbi(O, N, M, pi, A, B):
    """
    维特比算法解码，求最可能的隐藏状态序列
    O: 观测序列，长度T
    N: 隐藏状态数
    M: 观测符号数
    pi: 初始状态分布，shape (N,)
    A: 转移矩阵，shape (N,N)
    B: 观测概率矩阵，shape (N,M)
    """
    T = len(O)
    delta = np.zeros((T, N))
    psi = np.zeros((T, N), dtype=int)  # 路径指针
    
    # 初始化
    delta[0] = pi * B[:, O[0]]
    
    # 递推
    for t in range(1, T):
        for j in range(N):
            prob = delta[t-1] * A[:, j] * B[j, O[t]]
            delta[t, j] = np.max(prob)
            psi[t, j] = np.argmax(prob)
    
    # 回溯最优路径
    states = np.zeros(T, dtype=int)
    states[T-1] = np.argmax(delta[T-1])
    for t in range(T-2, -1, -1):
        states[t] = psi[t+1, states[t+1]]
    
    return states, delta[T-1].max()

# 示例运行
if __name__ == "__main__":
    N, M = 2, 3
    pi = np.array([0.6, 0.4])
    A = np.array([[0.7, 0.3], [0.4, 0.6]])
    B = np.array([[0.5, 0.4, 0.1], [0.1, 0.4, 0.5]])
    O = np.array([0, 1, 2, 1, 0])  # 观测序列
    
    best_path, prob = viterbi(O, N, M, pi, A, B)
    print(f"最优隐藏状态序列: {best_path}")
    print(f"序列概率: {prob:.4f}")
```

```python
def evaluate_hmm(model, X_test, lengths_test, true_states=None):
    """评估HMM模型"""
    # 1. 对数似然（越高越好）
    log_likelihood = model.score(X_test, lengths_test)
    print(f"测试集对数似然: {log_likelihood:.2f}")
    
    # 2. 解码准确率（如果已知真实状态）
    if true_states is not None:
        pred_states = model.predict(X_test, lengths_test)
        # 注意标签排列问题，这里简化计算
        from sklearn.metrics import accuracy_score
        acc = accuracy_score(true_states, pred_states)
        print(f"解码准确率: {acc:.2f}")
    
    # 3. 模型收敛性（训练曲线）
    # hmmlearn的history_属性记录每次迭代的对数似然
    if hasattr(model, 'history_'):
        plt.plot(model.history_['log_likelihood'])
        plt.xlabel('迭代次数')
        plt.ylabel('对数似然')
        plt.title('Baum-Welch收敛曲线')
        plt.grid(True, alpha=0.3)
        plt.show()
    
    return log_likelihood
```

## 11. 常见问题与易错点

1. **标签排列问题**
   - 现象：预测的状态标签与真实标签不对应，准确率极低
   - 解决：使用排列匹配（permutation matching）对齐标签，或仅评估对数似然

2. **Baum-Welch局部最优**
   - 现象：不同初始化得到不同模型
   - 解决：多次随机初始化，选择对数似然最高的结果

3. **过拟合**
   - 现象：训练似然高，测试似然低
   - 解决：使用贝叶斯HMM（添加先验），或减少状态数 $N$

## 12. 学习总结

**核心思想**：通过隐藏的马尔可夫链建模时序数据，用三类算法解决评估、解码、学习问题。

**关键公式**：
- 前向概率：$\alpha_{t+1}(j) = \left( \sum_i \alpha_t(i) A_{ij} \right) B_j(o_{t+1})$
- 维特比：$\delta_{t+1}(j) = \max_i [\delta_t(i) A_{ij}] B_j(o_{t+1})$

**与前序算法关系**：
- 是马尔可夫链的扩展（加入隐藏状态和观测）
- Baum-Welch是EM算法的特例
- 是条件随机场（CRF）的生成式对比模型

## 13. 练习题与思考题

**基础题**：
1. 解释HMM的三个基本假设？
   参考答案：① 马尔可夫性：隐藏状态仅依赖前一状态；② 观测独立性：观测仅依赖当前隐藏状态；③ 齐次性：转移概率不随时间变化。

2. 维特比算法与前向算法的区别？
   参考答案：维特比找最大概率路径（max），前向算法计算所有可能路径的概率和（sum）。

**进阶题**：
1. 推导前向算法的递推公式。
   参考答案：$\alpha_{t+1}(j) = P(o_1..o_{t+1}, q_{t+1}=j) = \sum_i P(o_1..o_t, q_t=i) P(q_{t+1}=j|q_t=i) P(o_{t+1}|q_{t+1}=j) = \sum_i \alpha_t(i) A_{ij} B_j(o_{t+1})$。

**开放题**：
1. HMM在强化学习中有哪些应用？
   参考答案：POMDP建模（隐藏状态为环境真实状态）、智能体状态压缩、时序状态分割。

## 14. 学习路径建议

**前置算法**：
- 马尔可夫链：理解状态转移和齐次性

**平行算法**：
- 条件随机场（CRF）：判别式时序模型，性能更优

**进阶算法**：
- 层次HMM：建模多级隐藏状态
- 循环神经网络（RNN）：建模长依赖时序数据
