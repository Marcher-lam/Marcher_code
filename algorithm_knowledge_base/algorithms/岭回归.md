# 岭回归 学习文档

> 线性回归的L2正则化版本，通过在损失函数中加入权重的L2范数惩罚项，解决多重共线性问题并防止过拟合

---

## 1. 算法基础认知

### 一句话定义
岭回归是在线性回归的损失函数中加入L2正则化项（权重平方和）的改进算法，通过惩罚大权重来抑制过拟合和多重共线性。

### 直觉类比
想象你在画一条拟合线，普通线性回归会尽量让线穿过所有点（包括异常点）。岭回归就像给这条线加了一个"弹簧约束"——线可以弯曲来拟合数据，但会被"拉回"接近直线的状态，这样既拟合了数据，又不会过度扭曲。

### 历史背景
岭回归由Hoerl和Kennard于1970年提出，专门解决设计矩阵$X^T X$接近奇异（多重共线性）时，普通最小二乘法（OLS）的不稳定性问题。"岭回归"名称来源于其几何解释：在参数空间中，约束区域形如山脊（ridge）。

### 算法定位
- 类型：监督学习 → 回归
- 输出：连续值
- 模型类型：参数模型、线性模型、正则化线性回归

### 前置知识
- 线性回归基础：最小二乘法、正规方程
- 线性代数：矩阵求逆、特征值分解
- 优化理论：凸优化、拉格朗日乘数法
- 统计基础：偏差-方差权衡
- Python基础：NumPy、scikit-learn

## 2. 核心原理

### 2.1 核心思想
岭回归的核心思想是：**在最小化均方误差的同时，约束权重向量的L2范数不要太大**，即：
$$\min_w ||Xw - y||^2_2 + \lambda ||w||^2_2$$

其中$\lambda \geq 0$是正则化强度：
- $\lambda = 0$：退化为普通线性回归
- $\lambda \to \infty$：所有权重趋向0，欠拟合

### 2.2 工作流程

1. **输入**：训练集 $D = \{(x_i, y_i)\}_{i=1}^m$，正则化参数 $\lambda$
2. **标准化**：对每个特征标准化（均值0，方差1）
3. **求解**：计算岭回归解析解 $w = (X^T X + \lambda I)^{-1} X^T y$
4. **预测**：对新样本 $x_{new}$，预测 $\hat{y} = x_{new}^T w$
5. **输出**：训练好的权重 $w$ 和偏置 $b$

### 2.3 关键概念解释

- **L2正则化**：对权重的平方和进行惩罚，使权重变小但不为0
- **正则化参数 $\lambda$**：控制正则化强度，需通过交叉验证选择
- **偏差-方差权衡**：$\lambda$ 增大 → 偏差增大、方差减小；$\lambda$ 减小 → 偏差减小、方差增大
- **多重共线性**：特征之间高度相关，导致 $X^T X$ 接近奇异
- **岭迹图**：随着 $\lambda$ 变化，观察权重的变化轨迹

### 2.4 几何/直观解释
从**约束优化**角度看，岭回归等价于：
$$\min_w ||Xw - y||^2_2 \quad \text{s.t.} \quad ||w||^2_2 \leq t$$

几何上，这是在球状约束区域（L2范数球）内寻找使残差平方和最小的点。球心在原点，半径由 $t$ 控制。

从**贝叶斯视角**看，岭回归等价于线性回归的**最大后验估计（MAP）**，其中权重 $w$ 服从零均值高斯先验：$w \sim \mathcal{N}(0, \sigma^2/\lambda I)$。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 | 维度 |
|------|------|----------|
| $X$ | 输入特征矩阵（已添加偏置列或中心化） | $m \times n$ |
| $y$ | 真实值向量 | $m \times 1$ |
| $w$ | 权重向量（不含偏置，或已包含在 $X$ 中） | $n \times 1$ |
| $\lambda$ | 正则化参数（L2惩罚系数） | 标量 |
| $I$ | 单位矩阵 | $n \times n$ |
| $\hat{w}$ | 岭回归估计的权重 | $n \times 1$ |

### 3.2 问题形式化
给定训练集 $D = \{(x_i, y_i)\}_{i=1}^m$，岭回归希望学习权重 $w$ 使得以下目标函数最小化：

$$J(w) = ||Xw - y||^2_2 + \lambda ||w||^2_2$$

等价于：
$$J(w) = (Xw - y)^T (Xw - y) + \lambda w^T w$$

### 3.3 目标函数/损失函数
岭回归的损失函数由两部分组成：

1. **数据拟合项**（均方误差）：
   $$L_{data}(w) = \sum_{i=1}^m (w^T x_i - y_i)^2 = ||Xw - y||^2_2$$

2. **正则化项**（L2惩罚）：
   $$L_{reg}(w) = \lambda ||w||^2_2 = \lambda w^T w$$

**为什么使用L2正则化？**
- 使损失函数严格凸（即使 $X^T X$ 奇异），保证唯一解
- 惩罚大权重，防止模型过于复杂（过拟合）
- 在贝叶斯框架下对应高斯先验，具有概率解释

### 3.4 推导过程

**解析解推导（正规方程）**：

对 $J(w)$ 求导并令导数为0：

$$J(w) = (Xw - y)^T (Xw - y) + \lambda w^T w$$

展开：
$$J(w) = w^T X^T X w - 2y^T X w + y^T y + \lambda w^T w$$

对 $w$ 求导（矩阵求导公式：$\frac{\partial}{\partial w}(w^T A w) = 2Aw$，$\frac{\partial}{\partial w}(b^T w) = b$）：

$$\frac{\partial J}{\partial w} = 2X^T X w - 2X^T y + 2\lambda w = 0$$

整理：
$$(X^T X + \lambda I) w = X^T y$$

**岭回归解**：
$$\hat{w}_{ridge} = (X^T X + \lambda I)^{-1} X^T y$$

**关键洞察**：
- 加入 $\lambda I$ 后，$X^T X + \lambda I$ 总是可逆的（正定）
- 当 $\lambda > 0$ 时，特征值最小为 $\lambda$，远离0，避免了奇异问题

### 3.5 最终解/算法步骤

**岭回归训练（解析解）**：
```
输入：训练集 D={(xᵢ, yᵢ)}ᵢ₌₁ᵐ, 正则化参数 λ
输出：权重向量 w

1. 数据预处理：
   a. 对每个特征标准化（均值0，方差1）
   b. 可选：中心化y（减去均值）

2. 构造设计矩阵 X（m×n），添加偏置列或单独处理偏置

3. 计算岭回归解：
   w = (XᵀX + λI)⁻¹ Xᵀ y

4. 如果y被中心化，恢复偏置：b = ȳ - wᵀx̄

5. 返回 w, b
```

**梯度下降版本**（当数据量大时）：
```
输入：训练集 D, 学习率 α, 正则化参数 λ, 轮数 E
输出：权重向量 w

1. 初始化 w = 0
2. 对轮数 e=1 到 E：
   a. 计算梯度：∇w = (2/m) Xᵀ(Xw - y) + 2λw
   b. 更新：w = w - α∇w
3. 返回 w
```

```python
from sklearn.preprocessing import StandardScaler

X1 = np.random.randn(n_samples)  # 特征1
X2 = X1 * 0.95 + np.random.randn(n_samples) * 0.1  # 特征2与特征1高度相关
X3 = np.random.randn(n_samples)  # 特征3独立
X = np.column_stack([X1, X2, X3])

print(f"特征相关系数矩阵:")
import pandas as pd
df = pd.DataFrame(X, columns=['X1', 'X2', 'X3'])
print(df.corr())
print()

# 1. 标准化（岭回归至关重要！）
# 因为L2惩罚对所有特征一视同仁，必须标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 2. 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(
    X_scaled, y, test_size=0.3, random_state=42

print(f"训练集: {X_train.shape}, 测试集: {X_test.shape}")

```

**预处理要点**：
1. **必须标准化**：岭回归的正则化对所有特征一视同仁，如果特征尺度不同，相当于对不同特征施加了不同的惩罚
2. **处理多重共线性**：岭回归专门解决此问题，但严重共线性仍需考虑删除特征
3. **偏置项处理**：通常单独处理偏置（不对偏置正则化），或中心化数据后包含在权重中

### 4.2 参数初始化

```python
# ============================================
# 岭回归参数设置
# ============================================
class RidgeRegression:
    """手写岭回归实现"""
    
    def __init__(self, alpha=1.0, fit_intercept=True):
        """
        初始化岭回归
        
        参数:
            alpha: 正则化强度 λ (sklearn中用alpha表示)
            fit_intercept: 是否拟合偏置项
        """
        self.alpha = alpha
        self.fit_intercept = fit_intercept
        self.w_ = None
        self.intercept_ = 0.0
        
    def fit(self, X, y):
        """
        训练岭回归
        
        注意：X应该已经标准化，y可选中心化
        """
        m, n = X.shape
        
        if self.fit_intercept:
            # 中心化y，单独处理偏置
            self.intercept_ = np.mean(y)
            y_centered = y - self.intercept_
            
            # 岭回归解析解（不对偏置正则化）
            # 在X前添加一列1（偏置项），但不对其正则化
            X_aug = np.column_stack([np.ones(m), X])
            
            # 构造正则化矩阵：偏置项对应位置为0，其他为alpha
            reg_matrix = np.zeros((n+1, n+1))
            reg_matrix[1:, 1:] = self.alpha * np.eye(n)
            
            # 计算解
            A = X_aug.T @ X_aug + reg_matrix
            b = X_aug.T @ y
            
            try:
                w_aug = np.linalg.solve(A, b)
                self.intercept_ += w_aug[0]  # 偏置
                self.w_ = w_aug[1:]  # 权重
            except np.linalg.LinAlgError:
                # 如果还是奇异，使用伪逆
                self.w_ = np.linalg.pinv(A) @ b
                self.intercept_ = self.w_[0]
                self.w_ = self.w_[1:]
        else:
            # 不对偏置单独处理
            A = X.T @ X + self.alpha * np.eye(n)
            self.w_ = np.linalg.solve(A, X.T @ y)
        
        return self
    
    def predict(self, X):
        """预测"""
        return X @ self.w_ + self.intercept_

# 测试初始化
model = RidgeRegression(alpha=1.0)
print(f"模型初始化完成：alpha={model.alpha}")
```

**初始化建议**：
1. **alpha（λ）**：常用范围 [1e-5, 1e-2, 1e-1, 1, 10, 100]，通过交叉验证选择
2. **fit_intercept**：通常设为True，除非数据已中心化
3. **权重初始化**：解析解不需要迭代初始化；梯度下降可初始化为0

### 4.3 迭代过程（梯度下降版本）

```python
def train_ridge_gd(X, y, alpha=1.0, lr=0.01, epochs=1000):
    """使用梯度下降训练岭回归"""
    m, n = X.shape
    w = np.zeros(n)  # 初始化权重为0
    
    losses = []
    
    for epoch in range(epochs):
        # 前向传播
        y_pred = X @ w
        error = y_pred - y
        
        # 计算损失（带L2正则化）
        loss = np.mean(error ** 2) + alpha * np.sum(w ** 2)
        losses.append(loss)
        
        # 计算梯度
        # ∇w = (2/m) Xᵀ(Xw - y) + 2αw
        grad = (2/m) * (X.T @ error) + 2 * alpha * w
        
        # 更新权重
        w -= lr * grad
        
        if (epoch + 1) % 200 == 0:
            print(f"Epoch {epoch+1}/{epochs}, Loss: {loss:.6f}")
    
    return w, losses

# 测试梯度下降
print("\n使用梯度下降训练岭回归...")
w_gd, losses_gd = train_ridge_gd(X_train, y_train, alpha=1.0, lr=0.01, epochs=1000)
print(f"梯度下降最终权重: {w_gd}")
```

**迭代过程说明**：
1. **梯度计算**：注意正则化项的梯度是 $2\lambda w$
2. **学习率**：建议从0.01开始尝试
3. **收敛**：损失应单调下降并趋于平稳

### 4.4 收敛条件

```python
def check_ridge_convergence(losses, window=10, threshold=1e-6):
    """检查岭回归是否收敛"""
    if len(losses) < window:
        return False
    
    recent_losses = losses[-window:]
    loss_change = abs(recent_losses[-1] - np.mean(recent_losses[:-1]))
    
    if loss_change < threshold:
        print(f"收敛！损失变化: {loss_change:.8f} < {threshold}")
        return True
    return False

# 岭回归的解析解不存在传统意义上的"收敛"问题
# 因为解析解是一次性计算得到的
# 但梯度下降版本需要检查收敛
```

**收敛相关要点**：
1. **解析解**：一次计算完成，无迭代收敛问题
2. **梯度下降**：监控损失变化，通常几百到几千轮收敛
3. **早停**：如果损失不再下降，提前停止

### 4.5 超参数及推荐范围

| 超参数 | 作用 | 推荐范围 | 默认值 |
|--------|------|----------|--------|
| `alpha` (λ) | 控制L2正则化强度 | 1e-5 ~ 1000 | 1.0 |
| `fit_intercept` | 是否拟合偏置项 | True/False | True |
| `solver` | 求解器（sklearn） | 'auto', 'svd', 'cholesky', 'lsqr' | 'auto' |
| `tol` | 迭代求解的容忍度 | 1e-5 ~ 1e-3 | 1e-4 |

**选择建议**：
1. **alpha选择**：使用交叉验证（如GridSearchCV）在多个alpha值上测试
2. **小alpha**：数据量大、特征少、信噪比高
3. **大alpha**：特征多、样本少、存在多重共线性

## 5. 应用场景

### 5.1 典型应用

**应用1：经济预测（存在多重共线性）**
- 场景：使用多个经济指标预测GDP，指标间往往高度相关
- 为什么适合：经济学数据常有共线性，岭回归能稳定估计
- 实现：对指标标准化后拟合岭回归，选择最优alpha

**应用2：基因数据分析（高维数据）**
- 场景：基因表达数据（数万个基因→数千样本）
- 为什么适合：岭回归能处理 $p \gg n$ 的情况，且权重收缩防止过拟合
- 实现：使用很大的alpha，或结合Lasso（弹性网络）

**应用3：图像重建（病态逆问题）**
- 场景：从模糊/噪声图像恢复清晰图像
- 为什么适合：图像重建常是病态问题，岭回归提供稳定解
- 实现：岭回归作为正则化手段，alpha控制平滑程度

### 5.2 适用数据特征

1. **存在多重共线性**：特征之间高度相关
2. **高维数据**：$p > n$ 或 $p \approx n$
3. **需要稳定估计**：普通线性回归方差太大
4. **希望权重非零**：不想做特征选择（用L1用Lasso）
5. **数据已标准化**：岭回归对尺度敏感

### 5.3 不适用场景

1. **需要特征选择**：岭回归不将权重压缩到0 → 使用Lasso
2. **数据量小且特征少**：普通线性回归可能更好（alpha=0）
3. **非线性关系**：需使用多项式回归或树模型
4. **分类问题**：使用逻辑回归、SVM等
5. **特征尺度差异巨大且未标准化**：岭回归结果不可靠

## 6. 优缺点分析

### 6.1 优点

| 优点 | 说明 | 成立条件 |
|------|------|----------|
| 解决多重共线性 | 加入λI使XᵀX可逆 | λ > 0 |
| 降低模型方差 | 偏差-方差权衡，减少过拟合 | 合适的λ |
| 解析解存在 | 一次计算完成，无需迭代 | 数据量适中 |
| 稳定估计 | 权重估计的方差减小 | 存在共线性时 |
| 适用于p>n | 高维数据也能处理 | λ足够大 |

### 6.2 缺点

| 缺点 | 说明 | 缓解方法 |
|------|------|----------|
| 不稀疏 | 所有权重都非零，不做特征选择 | 使用Lasso或弹性网络 |
| 需调参 | λ需交叉验证选择 | 使用GridSearchCV |
| 对尺度敏感 | 必须标准化，否则结果不公 | 使用StandardScaler |
| 解释性降低 | 权重被压缩，不如OLS直观 | 报告标准化系数 |
| 贝叶斯假设 | 隐含高斯先验，可能不符合实际 | 使用其他先验（如拉普拉斯→L1） |

## 7. 调库实现（Python + 完整代码 + 注释）

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import Ridge, RidgeCV
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.metrics import mean_squared_error, r2_score
import pandas as pd

# ============================================
# 使用scikit-learn实现岭回归
# ============================================
print("=" * 60)
print("岭回归调库实现（scikit-learn）")
print("=" * 60)

# 生成带多重共线性的数据
np.random.seed(42)
n_samples = 200
n_features = 5

# 创建相关特征
X = np.random.randn(n_samples, 2)  # 两个独立特征
X = np.column_stack([
    X[:, 0],  # 特征1
    X[:, 0] * 0.9 + np.random.randn(n_samples) * 0.1,  # 特征2（与特征1高度相关）
    X[:, 1],  # 特征3
    X[:, 1] * 0.8 + np.random.randn(n_samples) * 0.2,  # 特征4（与特征3高度相关）
    np.random.randn(n_samples)  # 特征5（独立）
])

# 真实关系（只有部分特征有用）
true_weights = np.array([2.0, 1.5, -1.0, 0.0, 0.5])
y = X @ true_weights + np.random.randn(n_samples) * 0.5

print(f"特征矩阵形状: {X.shape}")
print(f"真实权重: {true_weights}")
print(f"特征相关系数矩阵:")
df = pd.DataFrame(X, columns=[f'X{i+1}' for i in range(n_features)])
print(df.corr().round(2))
print()

# 1. 数据标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(
    X_scaled, y, test_size=0.3, random_state=42
)

# 2. 使用RidgeCV自动选择最优alpha（交叉验证）
alphas = np.logspace(-5, 5, 100)  # 从10^-5到10^5
ridge_cv = RidgeCV(alphas=alphas, store_cv_values=True)
ridge_cv.fit(X_train, y_train)

print(f"最优alpha: {ridge_cv.alpha_:.6f}")
print(f"交叉验证分数（负MSE）: {ridge_cv.cv_values_.mean(axis=0).min():.4f}")
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np
import matplotlib.pyplot as plt

class RidgeRegressionManual:
    """手动实现的岭回归（解析解和梯度下降）"""
    
    def __init__(self, alpha=1.0, fit_intercept=True, solver='analytic'):
        """
        初始化岭回归
        
        参数:
            alpha: 正则化强度 λ
            fit_intercept: 是否拟合偏置
            solver: 'analytic'（解析解）或 'gd'（梯度下降）
        """
        self.alpha = alpha
        self.fit_intercept = fit_intercept
        self.solver = solver
        self.coef_ = None
        self.intercept_ = 0.0
        self.losses_ = []
        
    def fit_analytic(self, X, y):
        """使用解析解训练（正规方程）"""
        m, n = X.shape
        
        if self.fit_intercept:
            # 中心化y
            self.intercept_ = np.mean(y)
            y_centered = y - self.intercept_
            
            # 添加偏置列到X
            X_aug = np.column_stack([np.ones(m), X])
            n_aug = n + 1
            
            # 正则化矩阵：偏置项不惩罚
            reg_matrix = np.zeros((n_aug, n_aug))
            reg_matrix[1:, 1:] = self.alpha * np.eye(n)
            
            # 岭回归解
            A = X_aug.T @ X_aug + reg_matrix
            b = X_aug.T @ y
            
            w_aug = np.linalg.solve(A, b)
            self.intercept_ += w_aug[0]
            self.coef_ = w_aug[1:]
        else:
            # 直接求解
            A = X.T @ X + self.alpha * np.eye(n)
            self.coef_ = np.linalg.solve(A, X.T @ y)
        
        return self
    
    def fit_gd(self, X, y, lr=0.01, epochs=1000, verbose=True):
        """使用梯度下降训练"""
        m, n = X.shape
        
        if self.fit_intercept:
            self.intercept_ = np.mean(y)
            y_centered = y - self.intercept_
        else:
            y_centered = y
        
        # 初始化权重
        self.coef_ = np.zeros(n)
        
        self.losses_ = []
        
        for epoch in range(epochs):
            # 前向传播
            y_pred = X @ self.coef_ + (self.intercept_ if not self.fit_intercept else 0)
            error = y_pred - y_centered
            
            # 计算损失
            loss = np.mean(error ** 2) + self.alpha * np.sum(self.coef_ ** 2)
            self.losses_.append(loss)
            
            # 计算梯度
            # ∇w = (2/m) Xᵀ(Xw - y) + 2αw
            grad_w = (2/m) * (X.T @ error) + 2 * self.alpha * self.coef_
            grad_b = (2/m) * np.sum(error) if self.fit_intercept else 0
            
            # 更新
            self.coef_ -= lr * grad_w
            if self.fit_intercept:
                self.intercept_ -= lr * grad_b
            
            if verbose and (epoch + 1) % 200 == 0:
                print(f"Epoch {epoch+1}/{epochs}, Loss: {loss:.6f}")
        
        return self
    
    def fit(self, X, y):
        """训练模型"""
        if self.solver == 'analytic':
            return self.fit_analytic(X, y)
        elif self.solver == 'gd':
            return self.fit_gd(X, y)
        else:
            raise ValueError(f"Unknown solver: {self.solver}")
    
    def predict(self, X):
        """预测"""
        return X @ self.coef_ + self.intercept_

# ============================================
```

## 11. 常见问题与易错点

### 11.1 忘记标准化特征，导致正则化不公平
**原因**：
岭回归的L2惩罚对所有特征一视同仁。如果特征A的取值范围是[0, 1]，特征B的取值范围是[0, 1000]，那么对特征B的惩罚实际比对特征A大得多（因为权重需要更大才能产生影响），这不符合正则化的初衷。

**解决方案**：
```python
from sklearn.preprocessing import StandardScaler

# 必须先标准化！
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 然后再训练岭回归
ridge = Ridge(alpha=1.0)
ridge.fit(X_scaled, y)

# 预测新数据时也要标准化
X_new_scaled = scaler.transform(X_new)
y_pred = ridge.predict(X_new_scaled)
```

### 11.2 混淆岭回归和Lasso（L1正则化）
**原因**：
用户可能不清楚L1和L2正则化的区别，或错误地认为岭回归可以做特征选择。

**解决方案**：
```python
# 岭回归（L2）：不做特征选择，所有权重非零
from sklearn.linear_model import Ridge
ridge = Ridge(alpha=1.0)

# Lasso（L1）：可以做特征选择，部分权重精确为0
from sklearn.linear_model import Lasso
lasso = Lasso(alpha=0.1)

# 弹性网络（L1+L2）：结合两者优点
from sklearn.linear_model import ElasticNet
enet = ElasticNet(alpha=0.5, l1_ratio=0.5)  # l1_ratio=0→L2, =1→L1

# 对比权重
ridge.fit(X_scaled, y)
lasso.fit(X_scaled, y)
enet.fit(X_scaled, y)

print("岭回归权重（都非零）:", ridge.coef_)
print("Lasso权重（部分可能为0）:", lasso.coef_)
print("弹性网络权重:", enet.coef_)
```

### 11.3 alpha选择不当，导致欠拟合或过拟合
**原因**：
- alpha太小：正则化效果弱，可能过拟合（接近线性回归）
- alpha太大：正则化过强，权重全部被压缩到接近0，欠拟合

**解决方案**：
```python

import numpy as np
```

## 12. 学习总结

### 核心要点回顾：
1. **损失函数**：$J(w) = ||Xw - y||^2_2 + \lambda ||w||^2_2$
2. **解析解**：$w = (X^T X + \lambda I)^{-1} X^T y$
3. **作用**：解决多重共线性，降低方差，防止过拟合
4. **与Lasso区别**：L2不稀疏，L1稀疏（特征选择）
5. **关键超参数**：$\lambda$（alpha），需交叉验证选择

### 从岭回归到其他算法：
```
线性回归（无正则化）
    ↓
岭回归（L2正则化，不稀疏）
    ↓
Lasso（L1正则化，稀疏）
    ↓
弹性网络（L1+L2，结合优点）
    ↓
其他正则化：SCAD、MCP等
```

### 实践建议：
1. **默认流程**：StandardScaler → RidgeCV → 评估
2. **alpha选择**：从 `np.logspace(-4, 4, 100)` 开始搜索
3. **诊断**：绘制岭迹图，观察权重变化
4. **报告**：给出最优alpha、R²、权重解释
5. **对比**：与线性回归、Lasso对比，选择最优模型

## 13. 练习题与思考题（含答案）

### 练习题

**习题1：基础计算**
问题：给定简单数据：X = [[1], [2], [3], [4], [5]]，y = [2, 4, 5, 4, 5]，计算岭回归在 $\lambda=1$ 时的解析解。假设已添加偏置列。

<details>
<summary>答案</summary>

数据矩阵（含偏置列）：
$$X = \begin{bmatrix} 1 & 1 \\ 1 & 2 \\ 1 & 3 \\ 1 & 4 \\ 1 & 5 \end{bmatrix}, \quad y = \begin{bmatrix} 2 \\ 4 \\ 5 \\ 4 \\ 5 \end{bmatrix}$$

计算：
$$X^T X = \begin{bmatrix} 5 & 15 \\ 15 & 55 \end{bmatrix}$$

添加正则化：
$$X^T X + \lambda I = \begin{bmatrix} 5+1 & 15 \\ 15 & 55+1 \end{bmatrix} = \begin{bmatrix} 6 & 15 \\ 15 & 56 \end{bmatrix}$$

$$X^T y = \begin{bmatrix} 20 \\ 66 \end{bmatrix}$$

求解 $(X^T X + \lambda I)w = X^T y$：
$$\begin{bmatrix} 6 & 15 \\ 15 & 56 \end{bmatrix} \begin{bmatrix} b \\ w_1 \end{bmatrix} = \begin{bmatrix} 20 \\ 66 \end{bmatrix}$$

使用克莱姆法则或消元法解得：
$b = 2.118$, $w_1 = 0.530$

所以岭回归方程：$\hat{y} = 0.530x + 2.118$

对比普通线性回归（$\lambda=0$）：$b=2.2, w_1=0.6$。可以看到岭回归的权重更小（收缩）。

**习题2：编程实践**
问题：使用Python手写实现岭回归，并使用梯度下降训练。在带噪声的线性数据上测试，比较不同alpha值的效果。

<details>
<summary>答案</summary>

```python
import numpy as np
import matplotlib.pyplot as plt

class RidgeRegressionGD:
    def __init__(self, alpha=1.0, lr=0.01, epochs=1000):
        self.alpha = alpha
        self.lr = lr
        self.epochs = epochs
        self.w = None
        self.b = None
        self.losses = []
    
    def fit(self, X, y):
        m, n = X.shape
        self.w = np.zeros(n)
        self.b = 0.0
        
        for epoch in range(self.epochs):
            y_pred = X @ self.w + self.b
            error = y_pred - y
            
            # 损失（带L2正则化）
            loss = np.mean(error**2) + self.alpha * np.sum(self.w**2)
            self.losses.append(loss)
            
            # 梯度
            dw = (2/m) * (X.T @ error) + 2 * self.alpha * self.w
            db = (2/m) * np.sum(error)
            
            # 更新
            self.w -= self.lr * dw
            self.b -= self.lr * db
        
        return self
    
    def predict(self, X):
        return X @ self.w + self.b

# 生成数据
np.random.seed(42)
X = np.random.randn(100, 1)
y = 2 * X[:, 0] + 1 + np.random.randn(100) * 0.5

# 标准化
X_scaled = (X - X.mean()) / X.std()

# 测试不同alpha
alphas = [0.0, 0.1, 1.0, 10.0]
plt.figure(figsize=(12, 4))

for i, alpha in enumerate(alphas):
    model = RidgeRegressionGD(alpha=alpha, lr=0.01, epochs=500)
    model.fit(X_scaled, y)
    
    plt.subplot(1, 4, i+1)
    plt.scatter(X_scaled, y, alpha=0.5, label='Data')
    x_test = np.linspace(X_scaled.min(), X_scaled.max(), 100).reshape(-1, 1)
    y_pred = model.predict(x_test)
    plt.plot(x_test, y_pred, 'r-', linewidth=2, label=f'α={alpha}')
    plt.xlabel('X (scaled)')
    plt.ylabel('y')
    plt.title(f'Ridge Regression (α={alpha})')
    plt.legend()
    plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# 观察权重随alpha的变化
print("权重随alpha的变化:")
for alpha in alphas:
    model = RidgeRegressionGD(alpha=alpha, lr=0.01, epochs=500)
    model.fit(X_scaled, y)
    print(f"α={alpha:4.1f}, 权重={model.w[0]:.4f}, 偏置={model.b:.4f}")
```

**习题3：理论推导**
问题：推导岭回归的贝叶斯视角。证明：岭回归等价于线性回归的高斯先验MAP估计。

<details>
<summary>答案</summary>

**贝叶斯设定**：
- 似然函数（噪声为高斯分布）：
$$p(y|X,w) = \prod_{i=1}^m \mathcal{N}(y_i | w^T x_i, \sigma^2) \propto \exp\left(-\frac{1}{2\sigma^2} \sum_{i=1}^m (w^T x_i - y_i)^2\right)$$

- 先验（权重服从零均值高斯分布）：
$$p(w) = \mathcal{N}(w | 0, \tau^2 I) \propto \exp\left(-\frac{1}{2\tau^2} w^T w\right)$$

**最大后验估计（MAP）**：
根据贝叶斯定理，后验 $\propto$ 似然 × 先验：
$$p(w|X,y) \propto p(y|X,w) p(w)$$

取对数：
$$\log p(w|X,y) = -\frac{1}{2\sigma^2} \sum_{i=1}^m (w^T x_i - y_i)^2 - \frac{1}{2\tau^2} w^T w + \text{const}$$

最大化后验概率等价于最小化负对数后验：
$$\min_w \frac{1}{2\sigma^2} ||Xw - y||^2_2 + \frac{1}{2\tau^2} ||w||^2_2$$

令 $\lambda = \frac{\sigma^2}{\tau^2}$，得到岭回归的目标函数：
$$\min_w ||Xw - y||^2_2 + \lambda ||w||^2_2$$

**结论**：岭回归等价于线性回归的MAP估计，其中权重服从高斯先验 $\mathcal{N}(0, \tau^2 I)$，正则化参数 $\lambda = \sigma^2/\tau^2$。
</details>

### 思考题

**思考题1**：岭回归和Lasso（L1正则化）各有什么优缺点？如何选择？

<details>
<summary>答案</summary>

| 方面 | 岭回归（L2） | Lasso（L1） |
|------|------------|------------|
| 解的性质 | 所有权重非零 | 部分权重精确为0（稀疏） |
| 特征选择 | 不能 | 能（自动特征选择） |
| 共线性处理 | 好（分摊权重） | 差（随机选一个） |
| 贝叶斯先验 | 高斯先验 | 拉普拉斯先验 |
| 数值稳定性 | 稳定 | 可能不稳定（非严格凸） |

**选择建议**：
1. **需要特征选择** → Lasso 或 弹性网络
2. **存在多重共线性** → 岭回归（Lasso可能随机选特征）
3. **p >> n（高维）** → Lasso或弹性网络（稀疏解）
4. **所有特征都可能有用** → 岭回归
5. **不确定** → 弹性网络（L1+L2），通过交叉验证选择l1_ratio

示例：
```python
from sklearn.linear_model import ElasticNet

# 弹性网络：结合L1和L2
# l1_ratio=0 → 纯L2（岭回归）
# l1_ratio=1 → 纯L1（Lasso）
# l1_ratio=0.5 → 各占一半
enet = ElasticNet(alpha=0.5, l1_ratio=0.5)
enet.fit(X_scaled, y)
```

**思考题2**：什么是"岭"？为什么叫岭回归？

<details>
<summary>答案</summary>

**"岭"的几何解释**：

岭回归的名称来源于其几何性质。考虑$S(\beta) = (X\beta - y)^T (X\beta - y)$（残差平方和）作为$\beta$的函数。

在$\beta$空间中，$S(\beta) = c$的等高线是椭圆（或椭球）。如果没有正则化，我们找到使$S(\beta)$最小的$\beta$。

加入约束 $||\beta||^2_2 \leq t$ 后，可行域是一个球（Circle/Sphere）。最优解出现在等高线与球相切的位置。

**为什么叫"岭"？**

更数学化的解释：考虑特征值分解 $X^T X = V \Lambda V^T$，其中$\Lambda = \text{diag}(\lambda_1, ..., \lambda_n)$。

岭回归解为：
$$\hat{\beta}_{ridge} = V \begin{bmatrix} \frac{\lambda_1}{\lambda_1 + \alpha} & & \\ & \ddots & \\ & & \frac{\lambda_n}{\lambda_n + \alpha} \end{bmatrix} V^T X^T y$$

当某个特征值 $\lambda_i$ 很小时（接近0，表示共线性），岭回归的收缩因子 $\frac{\lambda_i}{\lambda_i + \alpha}$ 会显著减小这个方向的权重，从而避免病态问题。在特征值谱上，这些小特征值形成一个"山脊"（ridge），岭回归正是通过这个"岭"来稳定估计。

**总结**：名称来源于其处理小特征值（"岭"）的方式，通过收缩这些方向的权重来稳定估计。
</details>
