# 注意力偏向竞争理论（Biased Competition Theory）学习文档

> 从神经科学角度解释注意力如何通过"竞争"机制选择性地处理视觉信息。

## 1. 算法基础认知

### 一句话定义

注意力偏向竞争理论认为，当视觉场景中有多个对象竞争有限的神经资源时，注意力通过偏向某些对象使其在竞争中获胜，从而优先获得处理。

### 直觉类比

就像在一群人中找自己的朋友——你的注意力会自动偏向熟悉的面孔，让你在"茫茫人海"中快速找到目标。这种"偏向"让你的神经系统优先处理相关信息。

### 历史背景

- **1995年**：Desimone和Duncan提出偏向竞争理论
- **后续研究**：大量神经科学实验验证该理论

### 算法定位

偏向竞争理论是**认知神经科学理论**，为计算模型中的注意力机制提供生物学基础。

---

## 2. 核心原理

### 核心思想

1. **神经资源有限**：视觉系统无法同时处理所有输入
2. **竞争机制**：多个对象竞争注意力资源
3. **偏向机制**：自上而下的信号偏向某些对象
4. **选择处理**：获胜者获得优先处理权

### 工作流程

```
多个视觉对象同时呈现
     ↓
竞争有限的神经处理资源
     ↓
自上而下信号（记忆、任务）产生偏向
     ↓
偏向使特定对象神经活动增强
     ↓
获胜对象获得优先感知和处理
```

---

## 3. 关键机制

### 自下而上的显著性

显著特征（颜色、形状、运动）自动吸引注意力：
- 红色在绿色背景中更突出
- 运动的物体更容易被注意

### 自上而下的偏向

任务相关的对象获得优先：
- 搜索"汽车"时，所有车辆更容易被注意
- 记住要找的人的外貌特征

### 交互作用

两种机制共同决定最终的注意焦点：
$$激活强度 = 显著性 + 任务偏向$$

---

## 4. 神经网络层面的体现

### 感受野竞争

- 视野中多个对象落入同一感受野
- 注意力偏向使目标对象响应更强
- 非目标对象响应被抑制

### 皮层层次

- V1、V2处理底层特征
- V4、IT处理高层对象
- 注意力在多个层次产生偏向

## 5. 计算模型应用

```python
import numpy as np

class BiasedCompetitionModel:
    """简化的偏向竞争模型"""
    
    def __init__(self, num_objects):
        self.num_objects = num_objects
        self.activation = np.zeros(num_objects)
        
    def compute_saliency(self, features):
        """计算自下而上的显著性"""
        # 简化的显著性计算
        return np.linalg.norm(features, axis=-1)
    
    def compute_top_down_bias(self, task_features, target_features):
        """计算自上而下的任务偏向"""
        # 简化的任务匹配
        bias = np.sum(task_features * target_features, axis=-1)
        return bias
    
    def competition(self, saliency, bias, attention_limit=1):
        """竞争机制"""
        # 组合显著性+偏向
        total_activation = saliency + 0.5 * bias
        
        # 胜者通吃机制
        winner = np.argmax(total_activation)
        winners = [winner]
        
        return winners
    
    def forward(self, objects_features, task_features):
        saliency = self.compute_saliency(objects_features)
        bias = self.compute_top_down_bias(task_features, objects_features)
        winner = self.competition(saliency, bias)
        return winner

if __name__ == "__main__":

    task = np.random.rand(10)
```

## 6. 与深度学习的关系

### 注意力机制中的体现

- **显著性检测**：计算输入的"显著性图"
- **任务驱动注意力**：Query决定关注什么
- **竞争机制**：Softmax归一化实现soft竞争

### 应用示例

```python
import torch
import torch.nn.functional as F

def biased_attention(query, keys, task_bias=None):
    """
    带偏向的注意力计算
    """
    # 基础注意力分数
    scores = torch.matmul(query, keys.transpose(-2, -1))
    
    # 添加任务偏向
    if task_bias is not None:
        scores = scores + task_bias
    
    # Softmax归一化（实现竞争）
    attention = F.softmax(scores, dim=-1)
    
    return attention
```

## 3. 数学公式与推导

注意力偏向竞争理论的数学基础：

### 前向传播
$$h = \sigma(W_1 x + b_1), \quad \hat{y} = W_2 h + b_2$$

### 损失函数（交叉熵）
$$L = -\frac{1}{N} \sum_{i=1}^{N} \sum_{c=1}^{C} y_{ic} \log \hat{y}_{ic}$$

### 反向传播（链式法则）
$$\frac{\partial L}{\partial W} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial W}$$

```python
import torch, torch.nn as nn, torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset, random_split

# 数据准备
X = torch.randn(1000, 20)
y = torch.randint(0, 2, (1000,))
dataset = TensorDataset(X, y)
train_set, test_set = random_split(dataset, [800, 200])
train_loader = DataLoader(train_set, batch_size=32, shuffle=True)

# 定义模型
class Model(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(20,128), nn.ReLU(), nn.Dropout(0.2), nn.Linear(128,2))
    def forward(self, x): return self.net(x)

# 训练
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = Model().to(device)
opt = optim.Adam(model.parameters(), lr=0.001)
crit = nn.CrossEntropyLoss()
for epoch in range(50):
    for bx, by in train_loader:
        bx, by = bx.to(device), by.to(device)
        opt.zero_grad()
        crit(model(bx), by).backward()
        opt.step()
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import torch, torch.nn as nn, torch.nn.functional as F

class 注意力偏向竞争理论Net(nn.Module):
    def __init__(self, dim_in=20, dim_h=64, dim_out=2):
        super().__init__()
        self.fc1, self.fc2 = nn.Linear(dim_in, dim_h), nn.Linear(dim_h, dim_out)
    def forward(self, x): return self.fc2(F.relu(self.fc1(x)))

def train(model, X, y, epochs=100, lr=0.001):
    opt = torch.optim.Adam(model.parameters(), lr=lr)
    for ep in range(epochs):
        opt.zero_grad()
        loss = nn.CrossEntropyLoss()(model(X), y)
        loss.backward(); opt.step()
        if (ep+1)%20==0: print(f"Ep{ep+1} loss={loss.item():.4f}")

m = 注意力偏向竞争理论Net()
train(m, torch.randn(500,20), torch.randint(0,2,(500,)))
```
