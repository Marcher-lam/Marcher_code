# 动态注意力 (Dynamic Attention) 学习文档

## 1. 算法基础认知

### 1.1 定义与背景

动态注意力（Dynamic Attention）是一类根据输入内容动态调整注意力机制的技术总称。与标准Transformer中使用固定的注意力模式不同，动态注意力能够根据输入的复杂度、重要性或位置信息自适应地调整注意力分配，从而在计算效率和模型表达能力之间取得更好的平衡。

**发展历程：**

1. **2017**：原始Transformer使用标准注意力
2. **2019**：Reformer提出局部+全局注意力
3. **2020**：Longformer/Attention使用滑动窗口
4. **2021**：Swin Transformer使用层级注意力
5. **2022**：Dynamic Convolution等动态方法
6. **2023**：LongNet等自适应方法

**核心问题：**

标准注意力的$O(N^2)$复杂度在长序列上成为瓶颈，动态注意力通过以下方式解决：
- 只关注重要的token（动态选择）
- 使用稀疏模式（固定稀疏）
- 滑动窗口（局部优先）

### 1.2 应用场景

| 场景 | 说明 |
|------|------|
| 长文本模型 | LongBERT、Longformer |
| 高效推理 | FlashAttention优化 |
| 视觉模型 | Swin-UNETR |
| 多模态 | 动态跨模态注意力 |
| 生产部署 | 降低延迟的关键技术 |

## 2. 核心原理

### 2.1 稀疏注意力

**标准注意力：**

$$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d}}\right)V$$

$O(N^2)$复杂度。

**稀疏模式：**

只计算部分位置对：

$$\text{SparseAttention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d}}\odot M\right)V$$

其中$M$是稀疏掩码。

**常见模式：**

| 模式 | 说明 | 复杂度 |
|------|------|--------|
| 全局 | 所有token可相互注意 | $O(N^2)$ |
| 局部 | 固定窗口内注意 | $O(N \times w)$ |
| 随机 | 随机采样注意 | $O(N \times r)$ |
| 膨胀 | 步长膨胀 | $O(N \times d)$ |

### 2.2 滑窗注意力

**Longformer Attention：**

- 局部窗口：$w = 256$
- 全局token：$[CLS]$等特殊token
- 复杂度：$O(N \times w)$

**Window Attention：**

```
位置:  0  1  2  3  4  5  6  7
窗口:  [--|--|--|--|--|--|--|--]
      i-127  ...  i  ...  i+127
```

### 2.3 内容动态注意力

**核心思想：**

根据输入内容的重要性动态分配注意力：

$$\text{_importance}_i = \text{sigmoid}(W_i \cdot x_i)$$

**实现方式：**

1. **重要性分数**：计算token重要性
2. **Top-K选择**：选择最重要的K个
3. **加权softmax**：基于重要性加权

## 3. PyTorch实现

### 3.1 滑窗注意力

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Optional, Tuple
import math


class SlidingWindowAttention(nn.Module):
    """
    滑窗注意力
    
    只关注固定窗口内的token，大幅降低复杂度
    """
    
    def __init__(
        self,
        hidden_size: int,
        num_heads: int,
        window_size: int = 512,
        dropout: float = 0.0,
    ):
        super().__init__()
        
        assert hidden_size % num_heads == 0
        
        self.hidden_size = hidden_size
        self.num_heads = num_heads
        self.head_dim = hidden_size // num_heads
        self.window_size = window_size
        self.dropout = nn.Dropout(dropout)
        
        self.scale = self.head_dim ** -0.5
        
        # QKV投影
        self.q_proj = nn.Linear(hidden_size, hidden_size)
        self.k_proj = nn.Linear(hidden_size, hidden_size)
        self.v_proj = nn.Linear(hidden_size, hidden_size)
        self.o_proj = nn.Linear(hidden_size, hidden_size)
        
    def forward(
        self,
        hidden_states: torch.Tensor,
        mask: Optional[torch.Tensor] = None,
    ) -> torch.Tensor:
        """
        前向传播
        
        Args:
            hidden_states: [batch, seq_len, hidden_size]
            mask: 注意力掩码
        """
        batch_size, seq_len, _ = hidden_states.shape
        
        # QKV投影
        q = self.q_proj(hidden_states)
        k = self.k_proj(hidden_states)
        v = self.v_proj(hidden_states)
        
        # Reshape
        q = q.view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        k = k.view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        v = v.view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        
        # 创建掩码
        # shape: [1, 1, seq_len, seq_len]
        if mask is None:
            mask = self._create_window_mask(seq_len, q.device)
        
        # 计算注意力
        if seq_len <= self.window_size:
            # 短序列：标准注意力
            attn_scores = torch.matmul(q, k.transpose(-2, -1)) * self.scale
            attn_scores = attn_scores + mask
            
            attn_weights = F.softmax(attn_scores, dim=-1)
            attn_weights = self.dropout(attn_weights)
            
            output = torch.matmul(attn_weights, v)
        else:
            # 长序列：滑动窗口
            output = self._sliding_window_attention(q, k, v, mask)
        
        # Reshape
        output = output.transpose(1, 2).contiguous()
        output = output.view(batch_size, seq_len, self.hidden_size)
        
        return self.o_proj(output)
    
    def _create_window_mask(self, seq_len: int, device: torch.device) -> torch.Tensor:
        """创建滑窗掩码"""
        mask = torch.zeros(1, 1, seq_len, seq_len, device=device, dtype=torch.float)
        
        # 对角及以下为-inf（不关注）
        for i in range(seq_len):
            start = max(0, i - self.window_size)
            mask[:, :, i, :start] = float('-inf')
            
        return mask
    
    def _sliding_window_attention(
        self,
        q: torch.Tensor,
        k: torch.Tensor,
        v: torch.Tensor,
        mask: torch.Tensor,
    ) -> torch.Tensor:
        """滑动窗口注意力实现"""
        batch_size, num_heads, seq_len, head_dim = q.shape
        window = self.window_size
        
        output = torch.zeros_like(q)
        
        # 分块处理
        for i in range(0, seq_len, window):
            end = min(i + window, seq_len)
            seq_len_i = end - i
            
            # 获取窗口内的Q,K,V
            q_i = q[:, :, i:end, :]
            k_i = k[:, :, i:end, :]
            v_i = v[:, :, i:end, :]
            
            # 窗口掩码
            mask_i = mask[:, :, i:end, :]
            
            # 注意力计算
            attn_scores = torch.matmul(q_i, k_i.transpose(-2, -1)) * self.scale
            attn_scores = attn_scores + mask_i
            
            attn_weights = F.softmax(attn_scores, dim=-1)
            attn_weights = self.dropout(attn_weights)
            
            output[:, :, i:end, :] = torch.matmul(attn_weights, v_i)
        
        return output
```

### 2.3.2 稀疏注意力

```python
class SparseAttention(nn.Module):
    """
    稀疏注意力
    
    支持多种稀疏模式的注意力机制
    """
    
    def __init__(
        self,
        hidden_size: int,
        num_heads: int,
        sparse_type: str = "fixed",  # "fixed", "random", "dilated"
        num_local: int = 256,
        num_random: int = 8,
        dilate_rate: int = 2,
        dropout: float = 0.0,
    ):
        super().__init__()
        
        self.hidden_size = hidden_size
        self.num_heads = num_heads
        self.head_dim = hidden_size // num_heads
        self.sparse_type = sparse_type
        self.num_local = num_local
        self.num_random = num_random
        self.dilate_rate = dilate_rate
        self.dropout = nn.Dropout(dropout)
        self.scale = self.head_dim ** -0.5
        
        # 投影
        self.q_proj = nn.Linear(hidden_size, hidden_size)
        self.k_proj = nn.Linear(hidden_size, hidden_size)
        self.v_proj = nn.Linear(hidden_size, hidden_size)
        self.o_proj = nn.Linear(hidden_size, hidden_size)
        
    def forward(
        self,
        hidden_states: torch.Tensor,
    ) -> torch.Tensor:
        """前向传播"""
        batch_size, seq_len, _ = hidden_states.shape
        
        # QKV
        q = self.q_proj(hidden_states).view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        k = self.k_proj(hidden_states).view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        v = self.v_proj(hidden_states).view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        
        if self.sparse_type == "fixed":
            output = self._fixed_sparse_attention(q, k, v)
        elif self.sparse_type == "random":
            output = self._random_sparse_attention(q, k, v)
        elif self.sparse_type == "dilated":
            output = self._dilated_sparse_attention(q, k, v)
        else:
            raise ValueError(f"Unknown sparse type: {self.sparse_type}")
        
        output = output.transpose(1, 2).contiguous()
        output = output.view(batch_size, seq_len, self.hidden_size)
        
        return self.o_proj(output)
    
    def _fixed_sparse_attention(
        self,
        q: torch.Tensor,
        k: torch.Tensor,
        v: torch.Tensor,
    ) -> torch.Tensor:
        """固定稀疏：局部+随机"""
        batch_size, num_heads, seq_len, head_dim = q.shape
        output = torch.zeros_like(q)
        
        # 本地窗口
        local_start = max(0, seq_len - self.num_local)
        
        # 局部注意
        q_local = q[:, :, local_start:, :]
        k_local = k[:, :, local_start:, :]
        v_local = v[:, :, local_start:, :]
        
        attn_scores = torch.matmul(q_local, k_local.transpose(-2, -1)) * self.scale
        attn_weights = F.softmax(attn_scores, dim=-1)
        output[:, :, local_start:, :] = torch.matmul(attn_weights, v_local)
        
        # 全局位置：使用token 0作为全局
        q_global = q[:, :, :1, :]
        k_global = k
        
        attn_scores_global = torch.matmul(q_global, k_global.transpose(-2, -1)) * self.scale
        attn_weights_global = F.softmax(attn_scores_global, dim=-1)
        output[:, :, :1, :] = torch.matmul(attn_weights_global, v)
        
        return output
    
    def _random_sparse_attention(
        self,
        q: torch.Tensor,
        k: torch.Tensor,
        v: torch.Tensor,
    ) -> torch.Tensor:
        """随机稀疏注意力"""
        batch_size, num_heads, seq_len, head_dim = q.shape
        output = torch.zeros_like(q)
        
        # 对于每个query位置
        for i in range(seq_len):
            # 选取随机位置
            random_indices = torch.randperm(seq_len)[:self.num_random]
            
            # 选取本地位置
            local_start = max(0, i - self.num_local // 2)
            local_indices = torch.arange(local_start, min(i + self.num_local // 2, seq_len))
            
            # 合并所有key_indices
            key_indices = torch.cat([random_indices, local_indices]).unique()
            
            # 注意力计算
            q_i = q[:, :, i:i+1, :]
            k_i = k[:, :, key_indices, :]
            v_i = v[:, :, key_indices, :]
            
            attn_scores = torch.matmul(q_i, k_i.transpose(-2, -1)) * self.scale
            attn_weights = F.softmax(attn_scores, dim=-1)
            output[:, :, i:i+1, :] = torch.matmul(attn_weights, v_i)
        
        return output
    
    def _dilated_sparse_attention(
        self,
        q: torch.Tensor,
        k: torch.Tensor,
        v: torch.Tensor,
    ) -> torch.Tensor:
        """膨胀稀疏注意力"""
        batch_size, num_heads, seq_len, head_dim = q.shape
        output = torch.zeros_like(q)
        
        dilation = self.dilate_rate
        
        # 对于每个query
        for i in range(seq_len):
            # 膨胀选择
            indices = torch.arange(0, seq_len, dilation) % seq_len
            
            k_i = k[:, :, indices, :]
            v_i = v[:, :, indices, :]
            
            q_i = q[:, :, i:i+1, :]
            
            attn_scores = torch.matmul(q_i, k_i.transpose(-2, -1)) * self.scale
            attn_weights = F.softmax(attn_scores, dim=-1)
            output[:, :, i:i+1, :] = torch.matmul(attn_weights, v_i)
        
        return output
```

### 3.3 动态卷积注意力

```python
class DynamicConvolutionAttention(nn.Module):
    """
    动态卷积注意力
    
    将卷积的动态权重与注意力结合
    """
    
    def __init__(
        self,
        hidden_size: int,
        num_heads: int,
        kernel_size: int = 7,
        dropout: float = 0.0,
    ):
        super().__init__()
        
        self.hidden_size = hidden_size
        self.num_heads = num_heads
        self.head_dim = hidden_size // num_heads
        self.kernel_size = kernel_size
        self.scale = self.head_dim ** -0.5
        
        # QKV投影
        self.q_proj = nn.Linear(hidden_size, hidden_size)
        self.k_proj = nn.Linear(hidden_size, hidden_size)
        self.v_proj = nn.Linear(hidden_size, hidden_size)
        
        # 动态卷积核
        self.kernel_proj = nn.Linear(hidden_size, num_heads * kernel_size)
        
        self.o_proj = nn.Linear(hidden_size, hidden_size)
        self.dropout = nn.Dropout(dropout)
        
    def forward(
        self,
        hidden_states: torch.Tensor,
    ) -> torch.Tensor:
        """前向传播"""
        batch_size, seq_len, _ = hidden_states.shape
        
        # QKV
        q = self.q_proj(hidden_states)
        k = self.k_proj(hidden_states)
        v = self.v_proj(hidden_states)
        
        # Reshape
        q = q.view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        k = k.view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        v = v.view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        
        # 动态卷积核权重
        kernel_weights = self.kernel_proj(hidden_states)
        kernel_weights = kernel_weights.view(batch_size, seq_len, self.num_heads, self.kernel_size)
        kernel_weights = F.softmax(kernel_weights, dim=-1)
        
        # 使用深度卷积
        k_dynamic = self._dynamic_conv(k, kernel_weights)
        
        # 标准注意力
        attn_scores = torch.matmul(q, k_dynamic.transpose(-2, -1)) * self.scale
        attn_weights = F.softmax(attn_scores, dim=-1)
        attn_weights = self.dropout(attn_weights)
        
        output = torch.matmul(attn_weights, v)
        
        # Reshape
        output = output.transpose(1, 2).contiguous()
        output = output.view(batch_size, seq_len, self.hidden_size)
        
        return self.o_proj(output)
    
    def _dynamic_conv(
        self,
        k: torch.Tensor,
        weights: torch.Tensor,
    ) -> torch.Tensor:
        """动态卷积"""
        batch_size, num_heads, seq_len, head_dim = k.shape
        padding = self.kernel_size // 2
        
        # Padding
        k_padded = k.transpose(1, 2)  # [batch, seq_len, num_heads, head_dim]
        k_padded = k_padded.transpose(2, 3)  # [batch, num_heads, head_dim, seq_len]
        
        # 使用depthwise convolution
        output = F.conv1d(
            k_padded.reshape(-1, 1, seq_len),
            weights.transpose(1, 2).reshape(-1, self.num_heads, self.kernel_size),
            padding=padding,
            groups=batch_size * num_heads,
        )
        
        output = output.view(batch_size, num_heads, head_dim, seq_len)
        output = output.transpose(3, 2)  # [batch, num_heads, seq_len, head_dim]
        
        return output.transpose(1, 2)  # [batch, num_heads, seq_len, head_dim]
```

def compare_complexity():
    """对比不同注意力的复杂度"""
    
    seq_len = 8192
    
    # 标准注意力
    full_complexity = seq_len ** 2
    
    # 滑窗注意力
    window_size = 256
    window_complexity = seq_len * window_size
    
    # 稀疏注意力
    sparse_complexity = seq_len * window_size + seq_len * 8
    
    print(f"标准注意力: O({full_complexity:,})")
    print(f"滑窗注意力: O({window_complexity:,})")
    print(f"稀疏注意力: O({sparse_complexity:,})")
    print(f"节省比例: {(1 - window_complexity/full_complexity) * 100:.2f}%")

compare_complexity()

## 3. 数学公式与推导

动态注意力的数学基础：

### 前向传播
$$h = \sigma(W_1 x + b_1), \quad \hat{y} = W_2 h + b_2$$

### 损失函数（交叉熵）
$$L = -\frac{1}{N} \sum_{i=1}^{N} \sum_{c=1}^{C} y_{ic} \log \hat{y}_{ic}$$

### 反向传播（链式法则）
$$\frac{\partial L}{\partial W} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial W}$$
