# 门控网络学习文档

## 1. 算法基础认知

门控网络（Gating Network）是一类通过"门控"机制控制信息流动的神经网络结构。门控机制的核心思想是使用一个额外的神经网络（或简单的线性变换）来动态决定应该"传递"多少信息、哪些信息需要被"过滤"。这种机制使得网络能够自适应地学习长期依赖的选择性记忆。

门控网络受到逻辑门的启发——就像电路中的门可以打开或关闭来控制电流的流动，门控网络中的"门"可以打开或关闭来控制信息的流动。这种设计使得网络能够有效地处理梯度流动问题，从而学习长序列中的依赖关系。

### 1.1 门控网络的核心思想

门控机制的本质是一个"软开关"：

$$\text{gate}(\mathbf{x}) = \sigma(\mathbf{W} \cdot \mathbf{x} + \mathbf{b})$$

其中 $\sigma$ 是Sigmoid函数，其输出在 $(0, 1)$ 区间，类似于电路中的电阻：

- 接近1：门打开，信息通过
- 接近0：门关闭，信息被阻断
- 之间的值：部分信息通过

### 1.2 门控网络的发展历程

1. **LSTM（1997）**：长短期记忆网络，最经典的门控网络
2. **GRU（2014）**：门控循环单元，LSTM的简化版本
3. **Highway Networks（2015）**：高速公路网络，残差连接的增强
4. **Squeeze-and-Excitation（2017）**：通道注意力机制
5. **GLU（2017）**：门控线性单元，Transformer的重要组件

## 2. 核心原理

### 2.1 Sigmoid门控

最基础的门控机制是Sigmoid门控：

$$\mathbf{g} = \sigma(\mathbf{W}_g \mathbf{x} + \mathbf{b}_g)$$

$$\mathbf{h}' = \mathbf{g} \odot \mathbf{h} + (1 - \mathbf{g}) \odot \mathbf{x}$$

这就是Highway Networks中的"变换门"和"携带门"。

### 2.2 GLU（门控线性单元）

GLU是一种更高效的门控机制，由Facebook在2017年提出：

$$\text{GLU}(\mathbf{x}) = \sigma(\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1) \odot (\mathbf{W}_2 \mathbf{x} + \mathbf{b}_2)$$

**与标准门控的区别**：
- 标准：$\mathbf{g} \odot \mathbf{h}$（需要额外计算$\mathbf{h}$）
- GLU：直接使用输入的两个线性变换$\odot$

### 2.3 SiLU（Sigmoid Linear Unit）

SiLU，也称为Swish-1，是Google提出的激活函数：

$$\text{SiLU}(x) = x \cdot \sigma(x)$$

**性质**：
- 平滑的非单调函数
- 自门控（非显式学习，而是基于输入）
- 在Transformer中广泛使用（约等于GELU的近似）

## 3. 数学公式与推导

### 3.1 门控机制详解

对于输入 $\mathbf{x} \in \mathbb{R}^n$，门控机制定义为：

**门控权重**：
$$\mathbf{g} = \sigma(\mathbf{W}_g \mathbf{x} + \mathbf{b}_g)$$

**门控输出**：
$$\mathbf{y} = \mathbf{g} \odot \mathbf{f}(\mathbf{x})$$

其中 $\mathbf{f}$ 可以是恒等变换或其他非线性变换。

### 3.2 Highway Networks

高速公路网络使用两个门控：

**变换门（transform gate）**：
$$\mathbf{t} = \sigma(\mathbf{W}_t \mathbf{x} + \mathbf{b}_t)$$

**携带门（carry gate）**：
$$\mathbf{c} = \sigma(\mathbf{W}_c \mathbf{x} + \mathbf{b}_c)$$

**输出**：
$$\mathbf{y} = \mathbf{t} \odot \mathbf{f}(\mathbf{x}) + (1 - \mathbf{t}) \odot \mathbf{x}$$

当 $\mathbf{t} \approx 1$ 时，信息传递通过"高速公路"；当 $\mathbf{t} \approx 0$ 时，信息被"携带"。

### 3.3 LSTM门控详解

LSTM有三个门控：

**遗忘门**：
$$\mathbf{f}_t = \sigma(\mathbf{W}_f [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_f)$$

**输入门**：
$$\mathbf{i}_t = \sigma(\mathbf{W}_i [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_i)$$

**输出门**：
$$\mathbf{o}_t = \sigma(\mathbf{W}_o [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_o)$$

**细胞状态更新**：
$$\mathbf{C}_t = \mathbf{f}_t \odot \mathbf{C}_{t-1} + \mathbf{i}_t \odot \tanh(\mathbf{W}_C [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_C)$$

## 4. 实现代码

### 4.1 GLU实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class GatedLinearUnit(nn.Module):
    """门控线性单元（GLU）"""
    def __init__(self, in_features, out_features, dropout=0.0):
        super(GatedLinearUnit, self).__init__()
        
        # 门控部分和变换部分
        self.gate_linear = nn.Linear(in_features, out_features)
        self.transform_linear = nn.Linear(in_features, out_features)
        
        self.dropout = nn.Dropout(dropout)
        self.sigmoid = nn.Sigmoid()
    
    def forward(self, x):
        """
        参数:
            x: (batch, seq_len, in_features)
        返回:
            output: (batch, seq_len, out_features)
        """
        # 计算门控信号
        gate = self.sigmoid(self.gate_linear(x))
        
        # 计算变换
        transform = self.transform_linear(x)
        
        # 门控乘积
        output = gate * transform
        output = self.dropout(output)
        
        return output


class GLUBlock(nn.Module):
    """GLU块"""
    def __init__(self, dim, num_layers=2, dropout=0.0):
        super(GLUBlock, self).__init__()
        
        self.layers = nn.ModuleList([
            GatedLinearUnit(
                in_features=dim,
                out_features=dim,
                dropout=dropout
            ) for _ in range(num_layers)
        ])
        
        self.norm = nn.LayerNorm(dim)
    
    def forward(self, x):
        residual = x
        for layer in self.layers:
            x = layer(x)
            x = self.norm(x)
        
        return x + residual


class PositionwiseGLU(nn.Module):
    """位置-wise GLU（用于Transformer位置前馈网络）"""
    def __init__(self, d_model, d_ff, dropout=0.1):
        super(PositionwiseGLU, self).__init__()
        
        # GLU需要4倍输出维度
        self.glu = nn.Sequential(
            nn.Linear(d_model, d_ff * 2),
            nn.GLU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout)
        )
        
        self.norm = nn.LayerNorm(d_model)
    
    def forward(self, x):
        return self.norm(x + self.glu(x))


class MultiHeadGLU(nn.Module):
    """多头GLU"""
    def __init__(self, d_model, num_heads, dropout=0.1):
        super(MultiHeadGLU, self).__init__()
        
        self.num_heads = num_heads
        self.d_model = d_model
        self.head_dim = d_model // num_heads
        
        # QKV投影
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        
        # GLU门控
        self.W_gate = nn.Linear(d_model, d_model)
        
        # 输出投影
        self.W_o = nn.Linear(d_model, d_model)
        
        self.dropout = nn.Dropout(dropout)
        self.scale = self.head_dim ** -0.5
    
    def forward(self, q, k, v, mask=None):
        batch_size = q.size(0)
        
        # 线性变换
        q = self.W_q(q).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        k = self.W_k(k).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        v = self.W_v(v).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        
        # GLU门控
        gate = self.W_gate(q).sigmoid()
        q_gated = gate * q
        
        # 注意力分数（简化）
        scores = torch.matmul(q_gated, k.transpose(-2, -1)) * self.scale
        
        if mask is not None:
            scores = scores.masked_fill(mask, float('-inf'))
        
        attn = F.softmax(scores, dim=-1)
        attn = self.dropout(attn)
        
        # 加权
        output = torch.matmul(attn, v)
        
        # 合并头
        output = output.transpose(1, 2).contiguous().view(batch_size, -1, self.d_model)
        
        return self.W_o(output)
```

### 4.2 SiLU/Swish实现

```python
class SiLU(nn.Module):
    """SiLU激活函数（Sigmoid Linear Unit / Swish-1）"""
    def __init__(self):
        super(SiLU, self).__init__()
        # SiLU是 stateless的，可以直接用F.silu
    
    def forward(self, x):
        return F.silu(x)


class Swish(nn.Module):
    """Swish激活函数"""
    def __init__(self, learnable_beta=False):
        super(Swish, self).__init__()
        
        if learnable_beta:
            self.beta = nn.Parameter(torch.ones(1))
        else:
            self.register_parameter('beta', None)
    
    def forward(self, x):
        if self.beta is not None:
            return x * torch.sigmoid(self.beta * x)
        else:
            return x * torch.sigmoid(x)


class GLUActivation(nn.Module):
    """GLU使用的激活函数集合"""
    def __init__(self, activation='swish'):
        super(GLUActivation, self).__init__()
        
        self.activation_name = activation
        
        if activation == 'silu':
            self.activation = F.silu
        elif activation == 'gelu':
            self.activation = F.gelu
        elif activation == 'relu':
            self.activation = F.relu
        else:
            raise ValueError(f"Unknown activation: {activation}")
    
    def forward(self, x):
        return self.activation(x)
```

### 4.3 门控残差网络

```python
class GatedResidual(nn.Module):
    """门控残差连接"""
    def __init__(self, d_model, dropout=0.1):
        super(GatedResidual, self).__init__()
        
        self.gate_linear = nn.Linear(d_model, d_model)
        self.dropout = nn.Dropout(dropout)
        self.sigmoid = nn.Sigmoid()
    
    def forward(self, x, residual):
        """门控残差
        
        x: 主路径输出
        residual: 残差连接
        """
        gate = self.sigmoid(self.gate_linear(x))
        
        # 门控选择
        output = gate * x + (1 - gate) * residual
        output = self.dropout(output)
        
        return output


class GatedConv2d(nn.Module):
    """门控卷积"""
    def __init__(self, in_channels, out_channels, kernel_size=3, stride=1, padding=1):
        super(GatedConv2d, self).__init__()
        
        self.conv = nn.Conv2d(in_channels, out_channels, kernel_size, stride, padding)
        self.gate_conv = nn.Conv2d(in_channels, out_channels, 1)
        self.sigmoid = nn.Sigmoid()
    
    def forward(self, x):
        feature = self.conv(x)
        gate = self.sigmoid(self.gate_conv(x))
        
        return feature * gate
```

### 4.4 SE-Net（通道注意力）

```python
class SqueezeExcitation(nn.Module):
    """Squeeze-and-Excitation模块"""
    def __init__(self, channels, reduction=16):
        super(SqueezeExcitation, self).__init__()
        
        self.avg_pool = nn.AdaptiveAvgPool2d(1)
        
        self.fc = nn.Sequential(
            nn.Linear(channels, channels // reduction, bias=False),
            nn.ReLU(inplace=True),
            nn.Linear(channels // reduction, channels, bias=False),
            nn.Sigmoid()
        )
    
    def forward(self, x):
        # Squeeze
        b, c, _, _ = x.size()
        y = self.avg_pool(x).view(b, c)
        
        # Excitation
        y = self.fc(y).view(b, c, 1, 1)
        
        # Scale
        return x * y.expand_as(x)


class SEBlock(nn.Module):
    """带SE的残差块"""
    def __init__(self, channels, reduction=16):
        super(SEBlock, self).__init__()
        
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1)
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=1)
        self.se = SqueezeExcitation(channels, reduction)
        self.relu = nn.ReLU(inplace=True)
        self.sigmoid = nn.Sigmoid()
    
    def forward(self, x):
        residual = x
        
        out = self.conv1(x)
        out = self.relu(out)
        out = self.conv2(out)
        
        # SE门控
        out = self.se(out)
        
        # 残差连接
        out = out + residual
        
        return self.relu(out)
```
