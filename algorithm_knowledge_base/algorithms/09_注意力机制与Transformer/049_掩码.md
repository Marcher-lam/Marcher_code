# 掩码 (Masking Mechanisms)

> 深度学习中控制信息流动的关键技术，让模型聚焦于真正重要的部分

---

## 1. 算法基础认知

### 1.1 一句话定义

掩码是一类用于在深度学习模型（尤其是序列模型）中控制信息流动的技术。通过遮蔽或选择性忽略特定位置的信息，使模型能够正确处理变长序列、避免信息泄露、实现特定训练目标。

### 1.2 直觉类比

掩码就像"会议室里的时间管理"：
- 每个人的发言时间有限（序列长度）
- 有人迟到了（Padding填充）
- 需要确保发言人不能听到自己之后的内容（因果掩码）
- 经理可以随时打断不需要听的内容（注意力掩码）

### 1.3 发展历程

| 时间 | 里程碑 |
|------|--------|
| 2013 | Seq2Seq注意力 |
| 2015 | 神经机器翻译中的mask |
| 2017 | Transformer原始论文 |
| 2018 | BERT MLM训练 |
| 2020+ | Flash Attention各种mask优化 |

## 2. 核心原理

### 2.1 Padding Mask（填充掩码）

处理变长序列时，将短序列填充到统一长度。Padding Mask标记哪些位置是填充的，以便在计算时忽略。

**数学定义**：
$$M_{pad,i,j} = \begin{cases} 0 & \text{if } x_j \neq PAD \\ -\infty & \text{if } x_j = PAD \end{cases}$$

**在Softmax中的应用**：
$$\text{Attention}(Q, K, V, M_{pad}) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}} + M_{pad}\right)V$$

Softmax的性质：$e^{-\infty} = 0$，确保填充位置的注意力权重为0。

**PyTorch实现**：
```python
def create_padding_mask(sequences, pad_token_id=0):
    """
    创建Padding Mask
    
    Args:
        sequences: token_ids, shape (batch, seq_len)
        pad_token_id: 填充token的id
    
    Returns:
        mask: shape (batch, 1, 1, seq_len) - True表示需要mask的位置
    """
    # 将填充位置设为True
    mask = (sequences == pad_token_id)  # (batch, seq_len)
    # 扩展维度用于attention
    mask = mask.unsqueeze(1).unsqueeze(2)  # (batch, 1, 1, seq_len)
    return mask
```

### 2.2 Causal Mask（因果掩码 / Look-ahead Mask）

在自回归模型中，确保当前位置只能看到之前的位置，防止信息"穿越"。

**下三角矩阵**：
$$M_{causal,i,j} = \begin{cases} 0 & \text{if } i \ge j \text{ (可以访问)} \\ -\infty & \text{if } i < j \text{ (不能访问)} \end{cases}$$

**示例**（seq_len=5）：
$$
\begin{bmatrix}
0 & -\infty & -\infty & -\infty & -\infty \\
0 & 0 & -\infty & -\infty & -\infty \\
0 & 0 & 0 & -\infty & -\infty \\
0 & 0 & 0 & 0 & -\infty \\
0 & 0 & 0 & 0 & 0
\end{bmatrix}
$$

**PyTorch实现**：
```python
def create_causal_mask(seq_len, device='cpu'):
    """
    创建因果掩码（下三角）
    
    Returns:
        mask: shape (1, 1, seq_len, seq_len)
    """
    # 下三角矩阵
    mask = torch.triu(
        torch.ones(seq_len, seq_len, device=device), 
        diagonal=1
    )  # 对角线以上为1
    
    # 转换为-inf
    mask = mask.masked_fill(mask == 1, float('-inf'))
    mask = mask.masked_fill(mask == 0, 0.0)
    
    # 扩展维度
    mask = mask.unsqueeze(0).unsqueeze(0)  # (1, 1, seq_len, seq_len)
    
    return mask

# 测试
mask = create_causal_mask(5)
print(mask)
# tensor([[[[0., -inf, -inf, -inf, -inf],
#           [0., 0., -inf, -inf, -inf],
#           [0., 0., 0., -inf, -inf],
#           [0., 0., 0., 0., -inf],
#           [0., 0., 0., 0., 0.]]]]])
```

### 2.3 Attention Mask（注意力掩码）

通用注意力掩码，可在任意位置设置需要遮蔽的注意力。

**组合掩码**：
$$M_{combined} = \max(M_{padding}, M_{causal})$$

因为：$\max(0, -\infty) = 0$, $\max(-\infty, -\infty) = -\infty$

### 2.4 实际掩码使用示例

```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    """
    缩放点积注意力（支持掩码）
    
    Args:
        Q: (batch, heads, seq_len, d_k)
        K: (batch, heads, seq_len, d_k)
        V: (batch, heads, seq_len, d_v)
        mask: (batch, 1, seq_len, seq_len) 或 (batch, 1, 1, seq_len)
    
    Returns:
        output: (batch, heads, seq_len, d_v)
        attention_weights: (batch, heads, seq_len, seq_len)
    """
    d_k = Q.size(-1)
    
    # 计算注意力分数
    scores = torch.matmul(Q, K.transpose(-2, -1)) / torch.sqrt(torch.tensor(d_k))
    
    # 应用掩码
    if mask is not None:
        scores = scores.masked_fill(mask, float('-inf'))
    
    # Softmax
    attention_weights = F.softmax(scores, dim=-1)
    
    # 加权求和
    output = torch.matmul(attention_weights, V)
    
    return output, attention_weights
```

## 3. 数学公式与推导

### 3.1 多头注意力中的掩码

**带掩码的多头注意力**：
$$\text{MultiHead}(Q, K, V, M) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O$$

其中每个头：
$$\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V, M)$$

### 3.2 掩码与Softmax

Softmax对掩码的处理：
$$softmax(x_i + m_i) = \frac{e^{x_i + m_i}}{\sum_j e^{x_j + m_j}}$$

当 $m_i = -\infty$：
$$e^{-\infty} = 0 \Rightarrow softmax(x_i) = 0$$

### 3.3 解码器掩码设计

**编码器掩码**：
- Padding Mask：忽略填充位置
- 位置对等（bidirectional）

**解码器掩码**：
- Padding Mask：忽略填充位置
- Causal Mask：只能看之前（unidirectional）
- 两者组合：$M = M_{pad} \lor M_{causal}$

## 4. 训练过程讲解

### 4.1 完整Transformer掩码实现

```python
import torch
import torch.nn as nn
import math

class TransformerEncoder(nn.Module):
    """Transformer编码器（带掩码）"""
    
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(d_model, n_heads, dropout=dropout)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Linear(d_ff, d_model)
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, padding_mask=None):
        """
        Args:
            x: (seq_len, batch, d_model)
            padding_mask: (batch, seq_len)
        
        Returns:
            output: (seq_len, batch, d_model)
        """
        # Self Attention +残差
        attn_output, _ = self.self_attn(
            x, x, x, 
            key_padding_mask=padding_mask,
            need_weights=False
        )
        x = self.norm1(x + self.dropout(attn_output))
        
        # FFN +残差
        ffn_output = self.ffn(x)
        x = self.norm2(x + self.dropout(ffn_output))
        
        return x


class TransformerDecoder(nn.Module):
    """Transformer解码器（带掩码）"""
    
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(d_model, n_heads, dropout=dropout)
        self.cross_attn = nn.MultiheadAttention(d_model, n_heads, dropout=dropout)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Linear(d_ff, d_model)
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, encoder_output, padding_mask=None, causal_mask=None):
        """
        Args:
            x: (seq_len, batch, d_model)
            encoder_output: (enc_seq_len, batch, d_model)
            padding_mask: (batch, seq_len)
            causal_mask: (seq_len, seq_len)
        
        Returns:
            output: (seq_len, batch, d_model)
        """
        # Self Attention（需要causal + padding掩码）
        combined_mask = padding_mask.unsqueeze(1).unsqueeze(2)  # (batch, 1, 1, seq_len)
        if causal_mask is not None:
            # 组合掩码：padding OR causal
            causal_mask = causal_mask.unsqueeze(0).unsqueeze(0)  # (1, 1, seq_len, seq_len)
            attn_mask = torch.max(combined_mask, causal_mask)
        else:
            attn_mask = combined_mask
        
        attn_output, _ = self.self_attn(
            x, x, x,
            key_padding_mask=padding_mask,
            attn_mask=attn_mask,
            need_weights=False
        )
        x = self.norm1(x + self.dropout(attn_output))
        
        # Cross Attention（只需要padding掩码）
        cross_output, _ = self.cross_attn(
            x, encoder_output, encoder_output,
            key_padding_mask=padding_mask,
            need_weights=False
        )
        x = self.norm2(x + self.dropout(cross_output))
        
        # FFN
        ffn_output = self.ffn(x)
        x = self.norm3(x + self.dropout(ffn_output))
        
        return x
```

### 4.2 完整训练流程

```python
class TransformerModel(nn.Module):
    """完整Transformer模型"""
    
    def __init__(self, vocab_size, d_model, n_heads, n_layers, d_ff, max_len=5000):
        super().__init__()
        
        # 词嵌入
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.pos_encoding = PositionalEncoding(d_model, max_len)
        
        # 编码器
        self.encoder_layers = nn.ModuleList([
            TransformerEncoder(d_model, n_heads, d_ff)
            for _ in range(n_layers)
        ])
        
        # 解码器
        self.decoder_layers = nn.ModuleList([
            TransformerDecoder(d_model, n_heads, d_ff)
            for _ in range(n_layers)
        ])
        
        # 输出
        self.output = nn.Linear(d_model, vocab_size)
        
        self.d_model = d_model
    
    def forward(self, src, tgt, src_pad_mask=None, tgt_pad_mask=None, causal_mask=None):
        """
        Args:
            src: (src_len, batch)
            tgt: (tgt_len, batch)
            src_pad_mask: (batch, src_len)
            tgt_pad_mask: (batch, tgt_len)
            causal_mask: (tgt_len, tgt_len)
        """
        # 嵌入
        src = (self.embedding(src) + self.pos_encoding(src)) * math.sqrt(self.d_model)
        tgt = (self.embedding(tgt) + self.pos_encoding(tgt)) * math.sqrt(self.d_model)
        
        # 编码
        for layer in self.encoder_layers:
            src = layer(src, src_pad_mask)
        
        # 解码
        for layer in self.decoder_layers:
            tgt = layer(tgt, src, tgt_pad_mask, causal_mask)
        
        # 输出
        output = self.output(tgt)
        
        return output


# 训练示例
def train_step(model, optimizer, src, tgt, src_pad, tgt_pad):
    """单步训练"""
    model.train()
    
    # 创建causal掩码
    tgt_seq_len = tgt.size(0)
    causal_mask = torch.triu(
        torch.full((tgt_seq_len, tgt_seq_len), float('-inf')),
        diagonal=1
    )
    
    # 前向
    output = model(src, tgt, src_pad, tgt_pad, causal_mask)
    
    # 移位（teacher forcing）
    output = output[:-1].contiguous().view(-1, model.output.out_features)
    labels = tgt[1:].contiguous().view(-1)
    
    # 损失
    loss = nn.CrossEntropyLoss()(output, labels)
    
    # 反向
    optimizer.zero_grad()
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step()
    
    return loss.item()
```

## 8. 手工代码实现

### 8.1 位置编码

```python
import numpy as np

class PositionalEncoding:
    """位置编码（正弦版本）"""
    
    def __init__(self, d_model, max_len=5000):
        self.d_model = d_model
        
        # 创建位置编码矩阵
        pe = np.zeros((max_len, d_model))
        
        position = np.arange(max_len).reshape(-1, 1)
        div_term = np.exp(
            np.arange(0, d_model, 2) * (-np.log(10000.0) / d_model)
        )
        
        pe[:, 0::2] = np.sin(position * div_term)
        pe[:, 1::2] = np.cos(position * div_term)
        
        self.pe = pe
    
    def __call__(self, x):
        """应用位置编码"""
        # x: (seq_len, batch, d_model)
        seq_len = x.size(0)
        x = x + torch.tensor(self.pe[:seq_len], dtype=x.dtype, device=x.device)
        return x


class LearnedPositionalEncoding:
    """可学习的位置编码"""
    
    def __init__(self, d_model, max_len=5000):
        self.embedding = nn.Embedding(max_len, d_model)
    
    def __call__(self, x):
        """应用位置编码"""
        seq_len = x.size(0)
        positions = torch.arange(seq_len, device=x.device)
        return x + self.embedding(positions)
```

### 8.2 完整掩码工具

```python
import torch
import torch.nn as nn

class MaskFactory:
    """掩码工厂"""
    
    @staticmethod
    def padding(sequences, pad_token_id=0):
        """Padding Mask"""
        return sequences == pad_token_id
    
    @staticmethod
    def causal(seq_len, device='cpu'):
        """Causal Mask (下三角)"""
        mask = torch.triu(
            torch.ones(seq_len, seq_len, device=device),
            diagonal=1
        )
        return mask.masked_fill(mask == 1, float('-inf')).masked_fill(mask == 0, 0.0)
    
    @staticmethod
    def combine(padding_mask, causal_mask):
        """组合掩码"""
        # padding_mask: (batch, seq_len)
        # causal_mask: (seq_len, seq_len)
        if causal_mask is not None:
            # 广播并取max
            combined = torch.max(
                padding_mask.unsqueeze(2),  # (batch, seq_len, 1)
                causal_mask.unsqueeze(0).unsqueeze(0)  # (1, 1, seq_len, seq_len)
            )
        else:
            combined = None
        return combined
    
    @staticmethod
    def cross_attention(source_padding, target_padding):
        """Cross Attention掩码（只需要source的padding）"""
        return source_padding
```

```python
import seaborn as sns

def visualize_attention(attention_weights, token_ids, tokenizer, save_path=None):
```

```python
def compare_masks(Q, K, V):
```

```python
def test_masks():

    out1, _ = scaled_dot_product_attention(Q, K, V, mask=None)
    
    # 2. Causal
    causal = torch.triu(torch.ones(seq_len, seq_len), diagonal=1) * float('-inf')
    out2, _ = scaled_dot_product_attention(Q, K, V, mask=causal)
    
    # 3. Padding
    pad = torch.zeros(batch, 1, 1, seq_len, dtype=torch.bool)
    pad[0, 0, 0, 5:] = True  # batch 0有padding
    out3, _ = scaled_dot_product_attention(Q, K, V, mask=pad)
    
    print("掩码测试通过 ✓")
    print(f"  无掩码输出: {out1.shape}")
    print(f"  Causal输出: {out2.shape}")
    print(f"  Padding输出: {out3.shape}")
```

## 12. 学习总结

### 12.1 核心要点

1. **Padding Mask**：忽略填充位置（$-\infty$）
2. **Causal Mask**：下三角，只看过去
3. **组合**：max $(padding, causal)$
4. **Softmax**：$e^{-\infty}=0$

### 12.2 实用技巧

- Padding使用torch.where()或.masked_fill()
- Causal使用torch.triu()
- 组合使用torch.max()
- 注意维度扩展

### 12.3 适用场景

- 序列到序列
- 自回归生成
- 变长序列
- 预训练掩码
