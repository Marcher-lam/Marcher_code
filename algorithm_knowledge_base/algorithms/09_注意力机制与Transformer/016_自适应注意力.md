# 自适应注意力学习文档

## 1. 算法基础认知

自适应注意力（Adaptive Attention）是一种能够根据输入动态调整注意力权重和注意范围的机制。与传统的固定注意力机制不同，自适应注意力可以学习在不同位置分配不同的注意力强度，并在必要时动态调整感受野的大小。

自适应注意力的核心思想包括：
1. **动态感受野**：根据输入内容自动调整注意力的覆盖范围
2. **自适应权重**：根据上下文动态计算注意力权重
3. **门控机制**：通过门控信号控制注意力的开启和关闭

典型的自适应注意力变体包括：
- Adaptively-Spatial Convolution Network (ACNet)
- Dynamic Convolution
- Spatial Pyramid Adaptive Attention
- Adaptive Attention Span

## 2. 核心原理

### 2.1 自适应注意力机制

自适应注意力的核心公式为：

$$\alpha_i = \text{ softmax }\left( \frac{\mathbf{q} \cdot \mathbf{k}_i}{\sqrt{d_k}} \cdot s_i \right)$$

其中 $s_i$ 是第 $i$ 个位置的自适应缩放因子，定义为：

$$s_i = \sigma(\mathbf{w}_s \cdot \mathbf{x}_i + b_s)$$

### 2.2 动态卷积

动态卷积的核心思想是根据输入动态生成卷积核：

$$\mathbf{W}_{dyn} = \sum_{j=1}^{K} \pi_j(\mathbf{x}) \cdot \mathbf{W}_j$$

其中 $\pi_j(\mathbf{x})$ 是输入关于第 $j$ 个基卷积核的权重：

$$\pi_j(\mathbf{x}) = \frac{\exp(\mathbf{w}_j^T \mathbf{x} + b_j)}{\sum_{k=1}^{K} \exp(\mathbf{w}_k^T \mathbf{x} + b_k)}$$

### 2.3 自适应注意力范围

自适应注意力范围通过学习一个注意力半径参数来确定：

$$r^* = \text{MLP}(\mathbf{x})$$

实际注意力范围为：

$$R = \text{clip}(r^*, r_{min}, r_{max})$$

## 3. 数学公式与推导

### 3.1 Adaptively-Spatial Convolution

ACNet的自适应空间卷积可以表示为：

$$Y_{ac}(i,j) = \sum_{m=-R}^{R} \sum_{n=-R}^{R} W_{adaptive}(i,j,m,n) \cdot X(i+m, j+n)$$

其中自适应卷积核为：

$$W_{adaptive}(i,j,m,n) = \frac{W_{static}(m,n) \cdot \alpha(i,j)}{Z(i,j)}$$

$alpha(i,j)$ 是位置 $(i,j)$ 处的注意力权重。

### 3.2 注意力权重计算

注意力权重的计算过程：

1. **Query-Key-Value投影**：
   $$\mathbf{q} = \mathbf{W}_Q \mathbf{x}, \quad \mathbf{k} = \mathbf{W}_K \mathbf{x}, \quad \mathbf{v} = \mathbf{W}_V \mathbf{x}$$

2. **相似度计算**：
   $$e_{ij} = \frac{\mathbf{q}_i \cdot \mathbf{k}_j^T}{\sqrt{d_k}}$$

3. **自适应缩放**：
   $$s_{ij} = \text{sigmoid}(w_{adapt}[\mathbf{x}_i; \mathbf{x}_j] + b_{adapt})$$

4. **Softmax归一化**：
   $$\alpha_{ij} = \frac{\exp(e_{ij} \cdot s_{ij})}{\sum_{j} \exp(e_{ij} \cdot s_{ij})}$$

### 3.3 动态卷积核生成

设我们有 $K$ 个基卷积核 $\{\mathbf{W}_1, \dots, \mathbf{W}_K\}$，动态卷积核的生成过程：

1. **注意力权重计算**：
   $$\pi_j = \frac{\exp(\mathbf{w}_j^T \mathbf{g} + b_j)}{\sum_{k=1}^{K} \exp(\mathbf{w}_k^T \mathbf{g} + b_k)}$$

2. **动态核生成**：
   $$\mathbf{W}_{dyn} = \sum_{j=1}^{K} \pi_j \mathbf{W}_j$$

3. **偏置生成**：
   $$b_{dyn} = \sum_{j=1}^{K} \pi_j b_j$$

## 4. 训练过程讲解

### 4.1 前向传播

自适应注意力的前向传播过程：
1. 对输入进行Query、Key、Value投影
2. 计算基础注意力分数
3. 根据输入生成自适应缩放因子
4. 将缩放因子应用到注意力分数
5. 进行Softmax归一化
6. 计算加权输出

### 4.2 反向传播

反向传播的关键是计���自适应缩放因子的梯度：

$$\frac{\partial L}{\partial s_{ij}} = \sum_{k} \frac{\partial L}{\partial \alpha_{ik}} \cdot \alpha_{ik} \cdot (e_{ij} - \sum_{l} \alpha_{il} e_{il})$$

然后通过链式法则传播到输入和参数。

## 5. 应用场景

### 5.1 图像识别

在图像识别中，自适应注意力可以：
- 根据图像内容动态调整感受野
- 对重要区域分配更多注意力
- 抑制背景干扰

### 5.2 目标检测

在目标检测中：
- 对不同尺度的目标使用不同的注意力范围
- 动态调整特征提取的感受野
- 自适应特征融合

### 5.3 语义分割

在语义分割中：
- 自适应多尺度特征聚合
- 动态边界增强
- 上下文自适应传播

### 5.4 序列建模

在NLP任务中：
- 自适应注意力跨度
- 动态上下文窗口
- 内容感知的注意力分配

## 6. 优缺点分析

### 优点

1. **灵活性高**：可以根据输入内容动态调整注意力
2. **感受野自适应**：自动适应不同尺度的特征
3. **参数高效**：相比固定大感受野，参数量更少
4. **性能提升**：通常能带来显著的性能提升
5. **可解释性**：注意力权重可提供一定的可解释性

### 缺点

1. **计算复杂度高**：动态计算注意力权重增加开销
2. **训练不稳定**：自适应机制可能导致训练不稳定
3. **内存占用**：需要存储额外的动态参数
4. **调参困难**：需要仔细调整多个超参数
5. **推理延迟**：动态计算增加了推理时间

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class AdaptiveAttention(nn.Module):
    """
    自适应注意力机制
    
    参数:
        dim: 输入维度
        num_heads: 注意力头数
        qkv_bias: 是否使用QKV偏置
        attn_drop: 注意力Dropout率
        proj_drop: 输出Dropout率
        adaptive_scale: 是否使用自适应缩放
    """
    
    def __init__(self, dim, num_heads=8, qkv_bias=True, attn_drop=0., proj_drop=0., 
                 adaptive_scale=True):
        super(AdaptiveAttention, self).__init__()
        
        self.dim = dim
        self.num_heads = num_heads
        self.head_dim = dim // num_heads
        self.scale = self.head_dim ** -0.5
        self.adaptive_scale = adaptive_scale
        
        # QKV投影
        self.qkv = nn.Linear(dim, dim * 3, bias=qkv_bias)
        
        # 自适应缩放网络
        if adaptive_scale:
            self.adaptive_fc = nn.Sequential(
                nn.Linear(dim, dim),
                nn.ReLU(inplace=True),
                nn.Linear(dim, num_heads, bias=True)
            )
        
        self.attn_drop = nn.Dropout(attn_drop)
        self.proj = nn.Linear(dim, dim)
        self.proj_drop = nn.Dropout(proj_drop)
    
    def forward(self, x, mask=None):
        """
        前向传播
        
        参数:
            x: 输入张量 (B, N, C)
            mask: 可选的注意力掩码
        
        返回:
            输出张量 (B, N, C)
        """
        B, N, C = x.shape
        
        # QKV投影
        qkv = self.qkv(x).reshape(B, N, 3, self.num_heads, self.head_dim).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]
        
        # 计算注意力分数
        attn = (q @ k.transpose(-2, -1)) * self.scale
        
        # 自适应缩放
        if self.adaptive_scale:
            # 生成自适应缩放因子
            adaptive_weights = self.adaptive_fc(x)  # (B, N, num_heads)
            adaptive_weights = adaptive_weights.unsqueeze(-1).expand(-1, -1, -1, N)  # (B, H, N, N)
            attn = attn * torch.sigmoid(adaptive_weights)
        
        # 应用掩码
        if mask is not None:
            attn = attn.masked_fill(mask.unsqueeze(0).unsqueeze(0), float('-inf'))
        
        # Softmax归一化
        attn = F.softmax(attn, dim=-1)
        attn = self.attn_drop(attn)
        
        # 加权求和
        out = (attn @ v).transpose(1, 2).reshape(B, N, C)
        
        # 输出投影
        out = self.proj(out)
        out = self.proj_drop(out)
        
        return out


class AdaptiveSpatialConv2d(nn.Module):
    """
    自适应空间卷积
    
    参数:
        in_channels: 输入通道数
        out_channels: 输出通道数
        kernel_size: 卷积核大小
        adaptive_range: 自适应范围的上界
    """
    
    def __init__(self, in_channels, out_channels, kernel_size=3, adaptive_range=7):
        super(AdaptiveSpatialConv2d, self).__init__()
        
        self.in_channels = in_channels
        self.out_channels = out_channels
        self.kernel_size = kernel_size
        self.adaptive_range = adaptive_range
        self.padding = kernel_size // 2
        
        # 静态卷积核
        self.static_conv = nn.Conv2d(
            in_channels, out_channels, 
            kernel_size=kernel_size,
            padding=self.padding,
            bias=False
        )
        
        # 自适应注意力权重生成
        self.adaptive_weight = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Conv2d(in_channels, in_channels // 4, 1),
            nn.ReLU(inplace=True),
            nn.Conv2d(in_channels // 4, kernel_size * kernel_size, 1),
            nn.Sigmoid()
        )
        
        # 输出归一化
        self.bn = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU(inplace=True)
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: 输入张量 (B, C, H, W)
        
        返回:
            输出张量 (B, C', H, W)
        """
        # 静态卷积
        static_out = self.static_conv(x)
        
        # 生成注意力权重
        attn_weight = self.adaptive_weight(x)  # (B, K*K, 1, 1)
        attn_weight = attn_weight.view(1, 1, self.kernel_size, self.kernel_size)
        
        # 应用注意力
        # 使用im2col实现加权卷积
        B, C, H, W = x.shape
        
        # 简单的注意力应用：通过可学习的注意力掩码
        out = static_out * attn_weight
        
        out = self.bn(out)
        out = self.relu(out)
        
        return out


class DynamicConvolution(nn.Module):
    """
    动态卷积
    
    参数:
        dim: 输入维度
        num_kernels: 基卷积核数量
        reduction: 注意力计算的降维比例
    """
    
    def __init__(self, dim, num_kernels=4, reduction=16):
        super(DynamicConvolution, self).__init__()
        
        self.dim = dim
        self.num_kernels = num_kernels
        
        # 基础卷积核
        self.kernels = nn.Parameter(
            torch.randn(num_kernels, dim, dim)
        )
        
        # 注意力网络
        self.attention = nn.Sequential(
            nn.Linear(dim, dim // reduction),
            nn.ReLU(inplace=True),
            nn.Linear(dim // reduction, num_kernels),
            nn.Softmax(dim=-1)
        )
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: 输入张量 (B, N, C)
        
        返回:
            输出张量 (B, N, C)
        """
        # 生成注意力权重
        B, N, C = x.shape
        
        # 使用平均池化生成全局注意力
        x_pooled = x.mean(dim=1)  # (B, C)
        attn_weights = self.attention(x_pooled)  # (B, num_kernels)
        
        # 动态卷积核
        dynamic_kernel = torch.einsum('bn,bkn->bk', attn_weights, self.kernels)  # (B, C)
        
        # 应用动态卷积
        out = torch.einsum('bnc,bc->bnc', x, dynamic_kernel)
        
        return out


class AdaptiveSpanAttention(nn.Module):
    """
    自适应注意力跨度
    
    参数:
        dim: 输入维度
        num_heads: 注意力头数
        max_span: 最大注意力跨度
    """
    
    def __init__(self, dim, num_heads=8, max_span=128):
        super(AdaptiveSpanAttention, self).__init__()
        
        self.dim = dim
        self.num_heads = num_heads
        self.max_span = max_span
        self.head_dim = dim // num_heads
        
        # QKV投影
        self.qkv = nn.Linear(dim, dim * 3, bias=False)
        
        # 注意力跨度预测
        self.span_predictor = nn.Sequential(
            nn.Linear(dim, dim // 4),
            nn.ReLU(inplace=True),
            nn.Linear(dim // 4, num_heads),
            nn.Sigmoid()
        )
        
        self.proj = nn.Linear(dim, dim)
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: 输入张量 (B, N, C)
        
        返回:
            输出张量 (B, N, C)
        """
        B, N, C = x.shape
        
        # QKV投影
        qkv = self.qkv(x).reshape(B, N, 3, self.num_heads, self.head_dim).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]
        
        # 预测注意力跨度
        span_weights = self.span_predictor(x)  # (B, N, H)
        span_values = (span_weights * self.max_span).long().clamp(1, N)  # (B, N, H)
        
        # 计算注意力
        attn = q @ k.transpose(-2, -1) / self.head_dim ** 0.5
        
        # 应用自适应跨度掩码
        mask = torch.ones(B, self.num_heads, N, N, device=x.device)
        for b in range(B):
            for h in range(self.num_heads):
                for i in range(N):
                    max_j = min(i + span_values[b, i, N)
                    min_j = max(0, i - span_values[b, i])
                    mask[b, h, i, min_j:max_j] = 0
        
        attn = attn.masked_fill(mask.bool(), float('-inf'))
        attn = F.softmax(attn, dim=-1)
        
        # 加权输出
        out = (attn @ v).transpose(1, 2).reshape(B, N, C)
        out = self.proj(out)
        
        return out


class AdaptiveMultiScaleAttention(nn.Module):
    """
    自适应多尺度注意力
    
    参数:
        in_channels: 输入通道数
        scales: 尺度列表
    """
    
    def __init__(self, in_channels, scales=[1, 2, 4, 8]):
        super(AdaptiveMultiScaleAttention, self).__init__()
        
        self.in_channels = in_channels
        self.scales = scales
        
        # 多尺度分支
        self.branches = nn.ModuleList()
        for scale in scales:
            self.branches.append(
                nn.Sequential(
                    nn.Conv2d(in_channels, in_channels // len(scales), 
                              kernel_size=3, padding=scale, dilation=scale),
                    nn.BatchNorm2d(in_channels // len(scales)),
                    nn.ReLU(inplace=True)
                )
            )
        
        # 自适应权重融合
        self.fusion = nn.Sequential(
            nn.Conv2d(in_channels, in_channels, 1, bias=False),
            nn.BatchNorm2d(in_channels),
        )
        
        self.attention = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Conv2d(in_channels, in_channels // 4, 1),
            nn.ReLU(inplace=True),
            nn.Conv2d(in_channels // 4, len(scales), 1),
            nn.Sigmoid()
        )
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: 输入张量 (B, C, H, W)
        
        返回:
            输出张量 (B, C, H, W)
        """
        # 多尺度特征提取
        branch_outputs = []
        for branch in self.branches:
            out = branch(x)
            branch_outputs.append(out)
        
        # 融合
        fused = torch.cat(branch_outputs, dim=1)
        
        # 自适应权重
        attn_weights = self.attention(x)  # (B, num_scales, 1, 1)
        
        # 应用注意力权重
        for i, branch_out in enumerate(branch_outputs):
            branch_out = branch_out * attn_weights[:, i:i+1]
        
        # 再次融合
        fused = torch.cat(branch_outputs, dim=1)
        
        # 输出
        out = self.fusion(fused)
        
        return out
```

## 8. 手工代码实现（核心算法手写）

```python
import numpy as np


def adaptive_attention_manual(q, k, v, adaptive_weights):
    """
    手动实现自适应注意力
    
    参数:
        q: Query (B, H, N, D)
        k: Key (B, H, M, D)
        v: Value (B, H, M, D)
        adaptive_weights: 自适应权重 (B, H, N, M)
    
    返回:
        output: 加权输出 (B, H, N, D)
    """
    B, H, N, D = q.shape
    _, _, M, _ = k.shape
    
    # 基础注意力分数
    scale = D ** 0.5
    attn = np.matmul(q, k.transpose(0, 1, 3, 2)) / scale
    
    # 应用自适应权重
    attn = attn * adaptive_weights
    
    # Softmax
    attn_exp = np.exp(attn - np.max(attn, axis=-1, keepdims=True))
    attn_soft = attn_exp / np.sum(attn_exp, axis=-1, keepdims=True)
    
    # 加权输出
    output = np.matmul(attn_soft, v)
    
    return output


def dynamic_convolution_manual(x, kernels, attention_weights):
    """
    手动实现动态卷积
    
    参数:
        x: 输入 (B, N, C)
        kernels: 基卷积核 (K, C, C)
        attention_weights: 注意力权重 (B, K)
    
    返回:
        output: 输出 (B, N, C)
    """
    B, N, C = x.shape
    K = kernels.shape[0]
    
    # 加权求和生成动态核
    dynamic_kernel = np.einsum('bk,kcd->bcd', attention_weights, kernels)
    
    # 应用动态核
    output = np.einsum('bnc,bc->bnc', x, dynamic_kernel)
    
    return output


def adaptive_span_manual(q, k, v, max_span):
    """
    手动实现自适应跨度注意力
    
    参数:
        q: Query (B, H, N, D)
        k: Key (B, H, N, D)
        v: Value (B, H, N, D)
        max_span: 最大跨度
    
    返回:
        output: 输出
    """
    B, H, N, D = q.shape
    
    # 基础注意力分数
    scale = D ** 0.5
    attn = np.matmul(q, k.transpose(0, 1, 3, 2)) / scale
    
    # 创建跨度掩码
    mask = np.ones((B, H, N, N))
    for b in range(B):
        for h in range(H):
            for i in range(N):
                # 动态计算span
                span_i = min(max_span, i + 1, N - i)
                for j in range(N):
                    if abs(j - i) >= span_i:
                        mask[b, h, i, j] = 0
    
    attn = attn + np.log(mask + 1e-9)
    
    # Softmax
    attn_soft = softmax(attn, axis=-1)
    
    # 输出
    output = np.matmul(attn_soft, v)
    
    return output


def softmax(x, axis=-1):
    """Softmax函数"""
    exp_x = np.exp(x - np.max(x, axis=axis, keepdims=True))
    return exp_x / np.sum(exp_x, axis=axis, keepdims=True)
```

```python
import torch
import torch.nn as nn
import time


def compute_attention_entropy(attn_weights):
    """
    计算注意力熵
    
    参数:
        attn_weights: 注意力权重 (B, H, N, N)
    
    返回:
        注意力熵
    """
    # 避免log(0)
    attn_weights = attn_weights + 1e-9
    entropy = -torch.sum(attn_weights * torch.log(attn_weights), dim=-1)
    return entropy.mean()


def compute_attention_sparsity(attn_weights, threshold=0.01):
    """
    计算注意力稀疏度
    
    参数:
        attn_weights: 注意力权重
        threshold: 稀疏阈值
    
    返回:
        稀疏度
    """
    sparse_count = (attn_weights < threshold).sum(dim=-1)
    return sparse_count.float() / attn_weights.shape[-1]
```

## 11. 常见问题与易错点

### 常见问题

1. **自适应权重计算不稳定**
   - 原因：自适应网络输出可能过大或过小
   - 解决方法：使用sigmoid约束到[0,1]范围

2. **训练时和推理时行为不一致**
   - 原因：Dropout等层在训练和推理时的行为不同
   - 解决方法：注意eval和train模式的切换

3. **内存占用过大**
   - 原因：注意力矩阵的存储需要大量内存
   - 解决方法：使用稀疏注意力或分块计算

### 易错点

1. **混淆自适应缩放和注意力权重**
   - 自适应缩放是位置的缩放因子，不是注意力权重
   
2. **忽视维度匹配**
   - QKV的维度必须匹配num_heads * head_dim = dim

3. **Mask应用错误**
   - 正确应用掩码，避免信息泄露

4. **梯度流问题**
   - 深层自适应注意力可能导致梯度流不稳定
