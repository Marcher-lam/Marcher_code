## 1. 算法基础认知

**一句话定义：** 邓肯基于物体注意力理论（Duncan's Object-Based Attention）是由剑桥大学心理学家约翰·邓肯于1984年提出的视觉注意模型，认为注意力的选择基本单元不是空间位置，而是"知觉物体"——具有完整性的视觉对象。

**直觉类比：** 当你看一幅有很多物体的画时，你不是先"决定看哪个位置"，而是先"决定看哪个东西"。比如，你可能先注意到一只大熊猫，然后才去关注它的耳朵、眼睛等细节。这是因为"大熊猫"是一个完整的"物体"，比单个位置更容易被选中。

**历史背景：** 1984年，邓肯发表开创性论文，通过系统的视觉认知对比实验证明了基于空间注意力的不合理性，确立了基于物体注意力在视觉认知研究中的地位。

**算法定位：** 这是一个认知心理学理论，属于"物体优先"（Object优先）选择理论。在计算建模中，可以用物体分割+物体级注意力来模拟。

**前置知识：**
- 格式塔（Gestalt）理论基本概念
- 视觉感知基础
- 奈塞尔两阶段理论

## 2. 核心原理

### 2.1 核心思想

邓肯基于物体注意力的核心主张是：**注意力选择的基本单元是"知觉物体"而非空间位置**。

关键证据来自邓肯的对比实验：
- 实验1：报告苹果的颜色（1个物体，1个特征）→ 正确率高
- 实验2：报告香蕉的颜色和形状（1个物体，2个特征）→ 正确率几乎不变
- 实验3：报告苹果的颜色和香蕉的形状（2个物体，2个特征）→ 正确率显著下降

这说明：同一物体上的多个特征可以同时被加工，不同物体的特征会相互干扰。

### 2.2 工作流程

```
视觉输入 → 物体分割（格式塔原则） → 物体表征生成 → 物体级注意力选择 → 特征融合 → 意识加工
```

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 |
|------|------|
| $O_i$ | 第 $i$ 个知觉物体 |
| $F_{i,j}$ | 物体 $i$ 的第 $j$ 个特征 |
| $A(O_i)$ | 对物体 $O_i$ 的注意力权重 |
| $P(follow)$ | 特征Follow概率 |

### 3.2 物体级注意力模型

设场景中有 $N$ 个物体 $O_1, O_2, ..., O_N$，每个物体有 $M$ 个特征。

物体选择概率：

$$P(O_k) = \frac{\exp(A(O_k))}{\sum_{i=1}^{N} \exp(A(O_i))}$$

其中 $A(O_k)$ 是物体 $O_k$ 的注意力分数。

特征Follow概率（在选择了物体 $O_k$ 的条件下）：

$$P(F_{k,j}|O_k) = \begin{cases} 1 & \text{如果特征属于同一物体} \\ \alpha < 1 & \text{如果特征属于不同物体} \end{cases}$$

## 7. 调库实现

```python
"""
邓肯基于物体注意力的计算模拟
模拟物体级注意力选择机制
"""

import numpy as np
from scipy.ndimage import label


class ObjectBasedAttention:
    """基于物体注意力的计算模型"""
    
    def __init__(self, n_objects=3):
        self.n_objects = n_objects
        self.attention_weights = np.random.rand(n_objects)
        self.attention_weights /= self.attention_weights.sum()
    
    def segment_objects(self, image):
        """简单的物体分割"""
        # 使用阈值分割
        binary = np.mean(image, axis=2) > 0.5
        labeled, n = label(binary)
        return labeled, min(n, self.n_objects)
    
    def compute_object_attention(self, features):
        """计算物体级注意力"""
        # 基于特征的吸引力
        attention_scores = np.array([np.mean(f) for f in features])
        attention_probs = np.exp(attention_scores) / np.sum(np.exp(attention_scores))
        return attention_probs
    
    def forward(self, image, features):
        """完整前向传播"""
        labeled, n_objects = self.segment_objects(image)
        attention_probs = self.compute_object_attention(features)
        return attention_probs


if __name__ == "__main__":
    # 测试
    np.random.seed(42)
    image = np.random.rand(64, 64, 3)
    features = [np.random.rand(64, 64) for _ in range(3)]
    
    model = ObjectBasedAttention(n_objects=3)
    attention = model.forward(image, features)
    print("物体注意力概率:", attention)
```

## 8. 手工代码实现

```python
import numpy as np


class DuncanAttentionModel:
    """邓肯基于物体注意力模型的简化实现"""
    
    def __init__(self):
        self.same_object_cost = 0.1  # 同一物体特征处理成本
        self.diff_object_cost = 0.8  # 不同物体特征处理成本
    
    def compute_attention_cost(self, object_ids):
        """计算不同物体配置下的注意力成本"""
        unique_objects = len(set(object_ids))
        if unique_objects == 1:
            return self.same_object_cost
        return self.diff_object_cost * (unique_objects - 1)
    
    def predict_accuracy(self, condition):
        """预测不同实验条件下的正确率"""
        conditions = {
            'same_feature': 0.95,
            'same_object_two_features': 0.92,
            'diff_objects_two_features': 0.58
        }
        return conditions.get(condition, 0.5)


if __name__ == "__main__":
    model = DuncanAttentionModel()
    print("邓肯实验条件正确率预测:")
    for cond in ['same_feature', 'same_object_two_features', 'diff_objects_two_features']:
        print(f"  {cond}: {model.predict_accuracy(cond):.2f}")
```

## 11. 常见问题与易错点

1. **混淆物体与位置：** 邓肯理论强调物体优先，但空间位置在注意选择中仍有作用
2. **物体定义模糊：** 什么算"一个物体"需要明确的边界定义
3. **忽视特征类型：** 不同类型特征的加工方式可能不同

---

## 12. 学习总结

邓肯基于物体注意力理论的核心贡献在于：通过实验证明了注意力选择的基本单元是"知觉物体"而非空间位置。这一发现改变了视觉认知研究的方向，为后续的物体级注意力模型奠定了基础。

邓肯的对比实验表明：当要求报告同一物体上的多个特征时，正确率几乎不变；但当要求报告不同物体上的特征时，正确率显著下降。这说明特征需要被"捆绑"在同一个物体上才能高效加工。

这一理论对计算机视觉中的物体检测、显著性预测等任务有重要启发——应该先检测物体，再在物体级别进行特征分析。

## 13. 练习题与思考题

### 基础题

**题目1：** 解释邓肯实验中"1物体2特征"比"2物体2特征"正确率更高的原因。

**答案：** 因为1物体2特征条件下，两个特征都属于同一个物体，根据基于物体注意力理论，它们可以同时被加工而不会相互干扰。而在2物体2特征条件下，特征属于不同物体，注意力需要在不同物体之间切换，导致加工效率降低，正确率下降。

### 进阶题

**题目2：** 讨论"基于物体注意力"与"基于空间注意力"的关系。

**答案：** 两者并非互斥。空间是物体存在的载体，物体是空间内容的组织形式。邓肯的贡献在于强调物体的组织作用，但实际视觉加工中两者协同工作。
