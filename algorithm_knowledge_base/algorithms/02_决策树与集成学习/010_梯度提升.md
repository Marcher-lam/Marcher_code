# 梯度提升 学习文档

## 1. 算法基础认知

梯度提升是传统机器学习领域中的一种重要算法/方法。它通过数据驱动的方式，从观测数据中学习模式并建立预测或决策模型，实现对未知数据的泛化。

梯度提升在机器学习发展历程中具有重要地位，理论基础不断完善，应用范围持续拓展。理解梯度提升对于掌握更高级算法和技术具有重要意义。

迭代训练弱学习器，通过梯度下降最小化损失函数。

## 2. 核心原理

梯度提升的核心原理：

1. **数据驱动决策**：通过分析训练数据中的统计规律，构建输入到输出的映射关系
2. **优化目标**：定义合适的损失函数，通过优化算法寻找最优参数
3. **泛化能力**：模型需在未见数据上表现良好，而不仅是拟合训练数据

梯度提升的关键在于平衡模型复杂度与泛化能力，通过合理的正则化和模型选择取得良好效果。

使用损失函数的负梯度作为新弱学习器的目标。

## 8. 手工实现
```python
import numpy as np
from sklearn.tree import DecisionTreeRegressor

class GradientBoostingScratch:
    def __init__(self, n_trees=100, lr=0.1, max_depth=3):
        self.n_trees = n_trees
        self.lr = lr
        self.max_depth = max_depth
        self.trees = []
    
    def fit(self, X, y):
        # 初始化预测值为均值
        pred = np.mean(y)
        
        for _ in range(self.n_trees):
            # 计算负梯度（残差）
            residuals = y - pred
            
            # 拟合残差
            tree = DecisionTreeRegressor(max_depth=self.max_depth)
            tree.fit(X, residuals)
            
            # 更新预测
            pred += self.lr * tree.predict(X)
            self.trees.append(tree)
    
    def predict(self, X):
        pred = np.mean([tree.predict(X) for tree in self.trees])
        return pred
```


## 3. 数学公式与推导

梯度提升的数学基础：

### 损失函数
$$L(\theta) = \frac{1}{N} \sum_{i=1}^{N} \ell(y_i, f(x_i; \theta)) + \lambda R(\theta)$$

### 优化目标
$$\theta^* = \arg\min_\theta L(\theta)$$

梯度下降更新：
$$\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)$$

## 11. 常见问题与易错点

### 常见问题
**Q1: 训练不收敛？**
- 检查学习率是否合适
- 检查数据是否正确归一化
- 确认损失函数是否匹配任务

**Q2: 过拟合严重？**
- 增加数据量或使用数据增强
- 添加正则化（L1/L2/Dropout）
- 使用早停策略

**Q3: 超参数如何选？**
- 网格搜索或随机搜索
- 贝叶斯优化
- 参考论文推荐值

### 易错点
1. 数据泄露：预处理时使用测试集信息
2. 随机种子：忘记设置导致不可复现
3. 维度错误：输入shape与模型不匹配
4. 梯度问题：需要适当初始化和裁剪
5. 评估偏差：在训练集上评估
