# 线性回归 学习文档

## 1. 算法基础认知

### 一句话定义
线性回归是最基础的监督学习算法，通过找到输入特征与连续输出之间的线性关系来进行预测。

### 直觉类比
线性回归就像用一把直尺拟合散点图上的数据点——我们试图画一条直线，让这条直线尽可能地穿过所有点，使得每个点到直线的垂直距离（误差）的总和最小。

### 历史背景
线性回归的历史可以追溯到19世纪初。1805年，法国数学家勒让德（Adrien-Marie Legendre）首次提出了最小二乘法，用于计算天文观测数据。1809年，高斯（Carl Friedrich Gauss）进一步发展了这一方法，并将其应用于天文学研究。最小二乘法成为统计学和数值分析中最基础的工具之一。

### 算法定位
- **监督学习**：需要带标签的训练数据
- **回归任务**：预测连续值（如房价、气温、销量）
- **参数模型**：模型参数在训练前就确定（如权重向量）
- **线性模型**：假设输入与输出是线性关系

### 前置知识
- 基础线性代数（矩阵运算、向量的点积和范数）
- 基础概率统计（期望、方差、正态分布）
- 基础微积分（偏导数、梯度）
- Python基础（NumPy、matplotlib）

## 2. 核心原理

### 核心思想
线性回归的核心思想是假设输出变量y与输入特征向量x之间存在线性关系：y = θ₀ + θ₁x₁ + θ₂x₂ + ... + θₙxₙ。我们的目标是找到最优的参数向量θ，使得预测值与真实值之间的误差最小。

### 工作流程

1. **数据准备**
   - 输入：训练数据集 D = {(x₁, y₁), (x₂, y₂), ..., (xₘ, yₘ)}，其中 xᵢ ∈ ℝⁿ，yᵢ ∈ ℝ
   - 输出：特征矩阵 X 和标签向量 y

2. **特征处理**
   - 添加偏置列：将特征矩阵 X 扩展为 [1, X]，便于学习截距项
   - 特征标准化：使不同量纲的特征具有可比性

3. **参数学习**
   - 输入：特征矩阵 X (m×n)，标签向量 y (m)
   - 计算正规方程：θ = (XᵀX)⁻¹Xᵀy
   - 输出：参数向量 θ (n)

4. **预测**
   - 输入：新样本特征 x' 和学习到的参数 θ
   - 计算：y' = x'ᵀθ
   - 输出：预测值 y'

5. **评估**
   - 计算MSE、MAE、R²等评估指标
   - 分析模型拟合效果

### 关键概念解释

| 概念 | 解释 |
|------|------|
| 权重向量 θ | 决定每个特征对预测值的贡献大小，θᵢ为正表示正相关，为负表示负相关 |
| 偏置项 θ₀ | 当所有特征都为0时的基准预测值，即直线在y轴上的截距 |
| 残差 | 预测值与真实值之间的差值 eᵢ = yᵢ - ŷᵢ |
| 学习率 α | 梯度下降中每次迭代的参数更新步长 |
| 正则化 | 防止过拟合，在损失函数中添加惩罚项 |

### 几何/直观解释
线性回归在几何上表现为在n+1维空间中寻找一个超平面，使所有数据点到该超平面的垂直距离的平方和最小。在二维情况下，这就是找到一条直线，使所有数据点到直线的垂直距离的平方和最小。

从几何角度看，最小二乘法对应于在特征张成的子空间中寻找一个向量，使其最接近目标向量y。这个子空间是由特征矩阵X的列向量张成的。残差向量 e = y - Xθ 与特征子空间正交，这就是所谓的"正交投影"。

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 | 维度 |
|------|------|------|
| m | 训练样本数量 | 标量 |
| n | 特征数量 | 标量 |
| X | 特征矩阵（包含偏置列） | m × (n+1) |
| y | 目标向量 | m × 1 |
| θ | 参数向量（权重+偏置） | (n+1) × 1 |
| ŷ | 预测值向量 | m × 1 |
| e | 残差向量 | m × 1 |
| α | 学习率 | 标量 |
| λ | 正则化参数 | 标量 |

### 问题形式化
给定训练数据集 D = {(x₁, y₁), (x₂, y₂), ..., (xₘ, yₘ)}，其中 xᵢ ∈ ℝⁿ，yᵢ ∈ ℝ。我们希望学习一个线性模型：

$$h_\theta(x) = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_n x_n = X\theta$$

使得预测值 ŷ 与真实值 y 的误差最小。

### 目标函数/损失函数
线性回归使用**均方误差（MSE）**作为损失函数：

$$J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2 = \frac{1}{2m} \|X\theta - y\|^2$$

选择MSE的原因：
1. **数学性质好**：处处可导，便于优化
2. **几何意义**：最小二乘法对应正交投影
3. **统计含义**：当误差服从正态分布时，MSE是最大似然估计
4. **惩罚力度**：对较大误差的惩罚更重，符合实际需求

### 推导过程

**方法一：正规方程（闭式解）**

Step 1: 展开损失函数
$$J(\theta) = \frac{1}{2m}(X\theta - y)^\top (X\theta - y)$$

Step 2: 对θ求导
$$frac{partial J}{partial theta} = \frac{1}{2m}(2X^\top X\theta - 2X^\top y) = \frac{1}{m}(X^\top X\theta - X^\top y)$$

Step 3: 令导数为0
$$X^\top X\theta = X^\top y$$

Step 4: 两边左乘 (XᵀX)⁻¹
$$(X^\top X)^{-1} X^\top X\theta = (X^\top X)^{-1} X^\top y$$

Step 5: 得到闭式解
$$\theta = (X^\top X)^{-1} X^\top y$$

**说明**：正规方程的解存在需要满足 XᵀX 可逆，即特征之间不存在完全共线性。如果 XᵀX 接近奇异矩阵（如特征高度相关），则需要使用正则化（岭回归）。

**方法二：梯度下降**

Step 1: 损失函数对θⱼ的偏导数
$$frac{partial}{partial \theta_j} J(\theta) = \frac{1}{m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)}) x_j^{(i)}$$

Step 2: 参数更新规则
$$\theta_j := \theta_j - alpha \cdot \frac{1}{m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)}) x_j^{(i)}$$

Step 3: 重复直至收敛

### 最终解/算法步骤

**正规方程解**：
$$\boxed{\theta = (X^\top X)^{-1} X^\top y}$$

**梯度下降算法**：
```
输入：学习率 α，迭代次数 T
初始化：θ = 0

for t in range(T):
    predictions = X @ θ
    errors = predictions - y
    gradient = (1/m) * X.T @ errors
    θ = θ - α * gradient

输出：θ
```

### 迭代过程（梯度下降）

```python
def fit_gradient_descent(X, y, alpha=0.1, iterations=1000):
    m, n = X.shape
    theta = np.zeros(n)
    
    for i in range(iterations):
        # 前向传播
        predictions = X @ theta
        
        # 计算误差
        errors = predictions - y
        
        # 计算梯度
        gradient = (1/m) * X.T @ errors
        
        # 参数更新
        theta = theta - alpha * gradient
        
        # 记录损失
        loss = (1/(2*m)) * np.sum(errors ** 2)
    
    return theta

# 使用正规方程
def fit_normal equation(X, y):
    # X.T @ X 可能奇异，添加小的正则化项
    theta = np.linalg.inv(X.T @ X + 1e-10 * np.eye(X.shape[1])) @ X.T @ y
    return theta
```

### 收敛条件

```python
def has_converged(prev_loss, current_loss, threshold=1e-6):
    return abs(prev_loss - current_loss) < threshold
```

常用的收敛判断条件：
1. 损失变化小于阈值：|Jₜ₊₁ - Jₜ| < ε
2. 梯度范数小于阈值：||∇J|| < ε
3. 达到最大迭代次数

### 超参数表

| 超参数 | 作用 | 推荐范围 | 默认值 |
|--------|------|----------|--------|
| 学习率 α | 控制参数更新步长 | 0.001 ~ 1.0 | 0.1 |
| 迭代次数 T | 梯度下降的迭代轮数 | 100 ~ 10000 | 1000 |
| 容差 ε | 收敛判断阈值 | 1e-6 ~ 1e-3 | 1e-6 |

学习率选择建议：
- 数据量小（m < 1000）：可使用正规方程
- 数据量大：使用批量梯度下降，学习率从0.1开始尝试
- 如果损失不下降反而上升：学习率过大，减少为原来的1/10

## 5. 应用场景

### 3个典型应用

**应用1：房价预测**
- 场景：基于房屋面积、卧室数量、房龄等特征预测房价
- 为什么适合：房价与各特征之间存在近似线性关系，可以用线性回归建模
- 具体实现：特征包括面积（平方英尺）、卧室数、浴室数、房龄、距市中心距离等

**应用2：销售额预测**
- 场景：基于广告投入、促销活动、季节因素预测月度销售额
- 为什么适合：销售额受多因素影响，线性回归可以量化各因素的贡献
- 具体实现：特征包括广告预算（TV、Radio、Online）、促销折扣、人口数量、季节指数等

**应用3：趋势预测**
- 场景：基于历史数据预测股票指数、GDP增长率等
- 为什么适合：长期趋势可以用线性模型近似
- 具体实现：特征包括时间趋势、滞后一期值、宏观经济指标

### 适用数据特征

1. **线性关系**：特征与目标变量之间存在近似线性关系
2. **低噪声**：目标变量的变异主要由特征决定
3. **无共线性**：特征之间不存在完全线性相关
4. **特征数量适中**：特征数 < 样本数，或者使用正则化
5. **连续型目标**：目标变量是连续值

### 不适用场景

1. **非线性关系**：特征与目标之间存在非线性关系（如二次、指数关系）
2. **高噪声**：目标变量的变异主要由随机因素决定
3. **分类问题**：目标变量是离散类别（如垃圾邮件检测）
4. **复杂模式**：需要多个特征的高阶交互才能建模
5. **小样本大特征**：样本数远小于特征数时容易过拟合

## 6. 优缺点分析

### 3-5个优点

| 优点 | 说明 | 成立条件 |
|------|------|----------|
| 简单直观 | 模型形式易于理解和解释 | 通用 |
| 可解释性强 | 每个系数的含义明确 | 特征有明确含义 |
| 计算效率高 | 正规方程可一次性求解 | n < 10000, XᵀX可逆 |
| 理论基础扎实 | 最小二乘有完善的统计理论 | 误差服从正态分布 |
| 可扩展性强 | 可以容易地添加正则化、扩展为多项式 | 通用 |

### 3-5个缺点

| 缺点 | 说明 | 解决思路 |
|------|------|----------|
| 线性假设过强 | 假设特征与目标是线性关系 | 使用多项式回归、核SVM等 |
| 对异常值敏感 | 异常点会显著影响参数估计 | 使用鲁棒回归、异常值检测 |
| 特征共线性 | 特征高度相关时 XᵀX 接近奇异 | 使用岭回归（L2正则化） |
| 无法处理非线性 | 只能拟合平面，无法拟合曲面 | 使用特征变换、多项式特征 |
| 欠拟合风险 | 简单模型可能无法捕捉复杂模式 | 增加特征、使用更复杂模型 |

### 与同类算法对比表

| 对比项 | 线性回归 | 岭回归 | LASSO回归 | 多项式回归 |
|--------|----------|--------|-----------|------------|
| 正则化 | 无 | L2 | L1 | 可选 |
| 解的稀疏性 | 否 | 否 | 是 | 否 |
| 处理共线性 | 差 | 好 | 中 | 差 |
| 计算复杂度 | O(n³) | O(n³) | O(n³) | O(n³) |
| 特征选择 | 否 | 否 | 是 | 否（需手动） |

## 8. 手工代码实现

### NumPy手写class

```python
import numpy as np

class LinearRegressionManual:
    """
    线性回归手动实现
    支持正规方程和梯度下降两种方法
    """
    
    def __init__(self, method='normal', alpha=0.1, n_iters=1000, regularization=0.0):
        """
        初始化
        
        参数:
            method: 'normal' 或 'gradient'
            alpha: 梯度下降学习率
            n_iters: 迭代次数
            regularization: 正则化系数
        """
        self.method = method
        self.alpha = alpha
        self.n_iters = n_iters
        self.regularization = regularization
        self.theta = None
        self.loss_history = []
    
    def _add_bias(self, X):
        """添加偏置列"""
        return np.c_[np.ones((X.shape[0], 1)), X]
    
    def fit(self, X, y):
        """
        训练模型
        
        参数:
            X: 特征矩阵 (m, n)
            y: 目标向量 (m,)
        """
        X = np.array(X)
        y = np.array(y).reshape(-1, 1)
        
        # 添加偏置列
        X = self._add_bias(X)
        
        if self.method == 'normal':
            self.theta = self._fit_normal(X, y)
        else:
            self.theta = self._fit_gradient(X, y)
        
        return self
    
    def _fit_normal(self, X, y):
        """正规方程方法"""
        # 计算 X.T @ X + λI
        n_features = X.shape[1]
        XtX = X.T @ X + self.regularization * np.eye(n_features)
        
        # 求逆（处理奇异矩阵）
        try:
            theta = np.linalg.inv(XtX) @ X.T @ y
        except np.linalg.LinAlgError:
            # 使用伪逆
            theta = np.linalg.pinv(XtX) @ X.T @ y
        
        return theta.flatten()
    
    def _fit_gradient(self, X, y):
        """梯度下降方法"""
        m, n = X.shape
        self.theta = np.zeros(n)
        
        for i in range(self.n_iters):
            # 前向传播
            predictions = X @ self.theta
            
            # 计算误差
            errors = predictions - y.flatten()
            
            # 计算梯度
            gradient = (1/m) * X.T @ errors + (self.regularization/m) * self.theta
            
            # 参数更新
            self.theta = self.theta - self.alpha * gradient
            
            # 记录损失
            loss = self._compute_loss(X, y)
            self.loss_history.append(loss)
        
        return self.theta
    
    def _compute_loss(self, X, y):
        """计算MSE损失"""
        m = X.shape[0]
        predictions = X @ self.theta
        errors = predictions - y.flatten()
        loss = (1/(2*m)) * np.sum(errors ** 2)
        return loss
    
    def predict(self, X):
        """
        预测
        
        参数:
            X: 特征矩阵 (m, n)
        
        返回:
            预测值向量
        """
        X = np.array(X)
        X = self._add_bias(X)
        return (X @ self.theta).flatten()
    
    def score(self, X, y):
        """
        计算R²分数
        
        参数:
            X: 特征矩阵
            y: 真实值
        
        返回:
            R²分数
        """
        y_pred = self.predict(X)
        y_true = np.array(y).flatten()
        ss_res = np.sum((y_true - y_pred) ** 2)
        ss_tot = np.sum((y_true - np.mean(y_true)) ** 2)
        return 1 - ss_res / ss_tot
```

## 10. 模型评估

### 评估指标选择

| 指标 | 公式 | 适用场景 | 优劣 |
|------|------|----------|------|
| MSE | (1/m)∑(y-ŷ)² | 回归 | 对大误差惩罚重 |
| RMSE | √MSE | 回归 | 与y同量纲 |
| MAE | (1/m)∑|y-ŷ| | 回归 | 对异常值鲁棒 |
| R² | 1 - SS_res/SS_tot | 回归 | 解释模型拟合度 |

选择原因：
- MSE：最常用，对大误差敏感
- MAE：当数据有异常值时更鲁棒
- R²：相对指标，便于不同模型比较

### 交叉验证代码


## 11. 常见问题与易错点

### 数据层面

**问题1：特征量纲差异大**
- 现象：模型收敛慢，系数解释不合理
- 原因：不同特征数值范围差异大
- 解决：使用StandardScaler标准化

**问题2：存在异常值**
- 现象：模型被少数异常点带偏
- 原因：MSE对大误差敏感
- 解决：使用MAE损失或异常值检测

**问题3：特征共线性**
- 现象：XᵀX求逆时数值不稳定
- 原因：特征之间高度相关
- 解决：使用岭回归或特征选择

### 模型层面

**问题4：线性假设不成立**
- 现象：R²很低，预测不准
- 原因：数据本身不是线性关系
- 解决：使用多项式回归或特征变换

**问题5：过拟合**
- 现象：训练R²高，测试R²低
- 原因：模型太复杂，样本太少
- 解决：增加样本、正则化、简化模型

### 调参层面

**问题6：学习率选择不当**
- 现象：损失不下降或震荡
- 原因：学习率过大或过小
- 解决：从0.1开始，根据损失曲线调整

## 12. 学习总结

### 核心要点回顾

1. **模型形式**：y = θ₀ + θ₁x₁ + ... + θₙxₙ
2. **损失函数**：MSE = (1/2m)∑(ŷ - y)²
3. **求解方法**：正规方程 θ = (XᵀX)⁻¹Xᵀy 或梯度下降
4. **数值稳定**：使用标准化使不同特征可比
5. **评估指标**：MSE、MAE、R²

### 关键公式汇总

$$text{假设函数: } h_\theta(x) = \theta^T x = theta_0 + \sum_{j=1}^{n} theta_j x_j$$

$$text{损失函数: } J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2$$

$$text{正规方程解: } \theta = (X^T X)^{-1} X^T y$$

$$text{梯度下降更新: } \theta_j := \theta_j - alpha \cdot \frac{1}{m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)}) x_j^{(i)}$$

$$text{R²分数: } R^2 = 1 - \frac{sum_{i=1}^{m}(y_i - \hat{y}_i)^2}{sum_{i=1}^{m}(y_i - \bar{y})^2}$$

### 与其他算法的联系

- **岭回归**：线性回归 + L2正则化，解决共线性问题
- **LASSO回归**：线性回归 + L1正则化，特征选择
- **多项式回归**：线性回归 + 多项式特征，非线性建模
- **逻辑回归**：线性回归 + sigmoid，分类任务

## 13. 练习题与思考题与思考题

### 2道基础题

**练习1：概念理解**
> 给定训练数据 (x, y)：(1, 2), (2, 4), (3, 5), (4, 4), (5, 5)，使用最小二乘法求线性回归的参数。

**答案**：
设 y = θ₀ + θ₁x
- X = [[1,1], [1,2], [1,3], [1,4], [1,5]]
- y = [2, 4, 5, 4, 5]ᵀ

使用正规方程 θ = (XᵀX)⁻¹Xᵀy：
- XᵀX = [[5, 15], [15, 55]]
- Xᵀy = [20, 68]ᵀ
- (XᵀX)⁻¹ = (1/200)[[55, -15], [-15, 5]]
- θ = (1/200)[55×20-15×68, -15×20+5×68]ᵀ = [1.4, 0.7]ᵀ

所以：y = 1.4 + 0.7x

**练习2：手动计算**
> 给定数据点 (1, 3), (2, 5), (3, 4)，求预测值和残差。

**答案**：
设 y = θ₀ + θ₁x

XᵀX = [[3, 6], [6, 14]]，Xᵀy = [12, 25]
解方程：θ₀ = 2.33，θ₁ = 0.67

预测值：2.33+0.67×1=3.0, 2.33+0.67×2=3.67, 2.33+0.67×3=4.0
残差：3-3=0, 5-3.67=1.33, 4-4=0
