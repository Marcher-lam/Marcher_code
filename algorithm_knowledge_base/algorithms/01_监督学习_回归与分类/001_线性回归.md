# 线性回归 (Linear Regression)

> 机器学习最基础的监督学习算法，理解优化的起点

---

## 1. 算法基础认知

### 1.1 一句话定义

线性回归是最基础的监督学习算法，用于预测连续数值型目标变量。它假设目标变量与输入特征之间存在线性关系，通过最小化预测值与真实值之间的平方误差来学习模型参数。

### 1.2 直觉类比

线性回归就像"画一条直线来拟合点"：
- 给定二维平面上的散点 $(x, y)$
- 找到一条直线 $y = wx + b$
- 使得所有点到直线的垂直距离平方和最小
- 这条直线就是最优的线性回归模型

### 1.3 发展历程

- **1805**: Legendre提出最小二乘法
- **19世纪**: 高斯提出统计解释
- **20世纪**: 线性回归成为统计学的核心方法
- **现在**: 机器学习的基础算法

---

## 2. 核心原理

### 2.1 模型定义

线性回归模型假设目标变量与特征的线性关系：

$$y = \mathbf{w}^T \mathbf{x} + b = w_1 x_1 + w_2 x_2 + ... + w_n x_n + b$$

其中：
- $\mathbf{x} \in \mathbb{R}^n$：输入特征向量
- $\mathbf{w} \in \mathbb{R}^n$：权重向量
- $b \in \mathbb{R}$：偏置项（截距）

**向量形式**（将偏置并入权重）：
$$\hat{y} = \mathbf{w}^T \mathbf{x}$$

其中 $\mathbf{w} = [w_0, w_1, ..., w_n]^T$，$\mathbf{x} = [1, x_1, ..., x_n]^T$

### 2.2 损失函数

使用均方误差（MSE）作为损失函数：

$$J(\mathbf{w}) = \frac{1}{2m} \sum_{i=1}^{m} (\hat{y}^{(i)} - y^{(i)})^2 = \frac{1}{2m} \| \mathbf{X}\mathbf{w} - \mathbf{y} \|_2^2$$

### 2.3 概率解释

从概率角度，最小二乘法有深刻的统计意义：

**假设**：误差服从高斯分布
$$\epsilon^{(i)} \sim \mathcal{N}(0, \sigma^2)$$

**推导**：
$$y^{(i)} = \mathbf{w}^T \mathbf{x}^{(i)} + \epsilon^{(i)}$$

$$p(y^{(i)}|\mathbf{x}^{(i)}, \mathbf{w}) = \mathcal{N}(y^{(i)}|\mathbf{w}^T\mathbf{x}^{(i)}, \sigma^2)$$

最大似然估计等价于最小二乘！

---

## 3. 数学公式与推导

### 3.1 正规方程

对损失函数求导并设为零，得到解析解：

$$\mathbf{X}^T \mathbf{X} \mathbf{w} = \mathbf{X}^T \mathbf{y}$$

$$\mathbf{w} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

**优点**：一次计算得到最优解
**缺点**：$O(n^3)$ 复杂度，$\mathbf{X}^T\mathbf{X}$ 可能奇异

### 3.2 梯度下降

迭代优化算法：

$$\mathbf{w} := \mathbf{w} - \alpha \nabla J(\mathbf{w})$$

**权重更新**（批量梯度下降）：
$$w_j := w_j - \alpha \frac{1}{m} \sum_{i=1}^{m} (\hat{y}^{(i)} - y^{(i)}) x_j^{(i)}$$

**向量化**：
$$\mathbf{w} := \mathbf{w} - \alpha \frac{1}{m} \mathbf{X}^T (\mathbf{X}\mathbf{w} - \mathbf{y})$$

### 3.3 随机梯度下降（SGD）

每次用一个样本更新：
$$w_j := w_j - \alpha (\hat{y}^{(i)} - y^{(i)}) x_j^{(i)}$$

**小批量SGD**（常用）：
$$w_j := w_j - \alpha \frac{1}{B} \sum_{i \in B} (\hat{y}^{(i)} - y^{(i)}) x_j^{(i)}$$

### 3.4 正则化

#### L2正则化（Ridge）

$$J(\mathbf{w}) = \frac{1}{2m} \| \mathbf{X}\mathbf{w} - \mathbf{y} \|_2^2 + \lambda \|\mathbf{w}\|_2^2$$

$$\mathbf{w} = (\mathbf{X}^T\mathbf{X} + \lambda \mathbf{I})^{-1} \mathbf{X}^T \mathbf{y}$$

#### L1正则化（Lasso）

$$J(\mathbf{w}) = \frac{1}{2m} \| \mathbf{X}\mathbf{w} - \mathbf{y} \|_2^2 + \lambda \|\mathbf{w}\|_1$$

#### Elastic Net

$$J(\mathbf{w}) = \frac{1}{2m} \| \mathbf{X}\mathbf{w} - \mathbf{y} \|_2^2 + \lambda (\rho \|\mathbf{w}\|_1 + \frac{(1-\rho)}{2}\|\mathbf{w}\|_2^2)$$

### 4.2 正规方程实现

```python
def normal_equation(X, y):
    """正规方程求解线性回归"""
    # 添加偏置列
    X_b = np.c_[np.ones((X.shape[0], 1)), X]
    
    # 计算解析解
    theta = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y
    return theta

# 使用
theta = normal_equation(X_train, y_train)
print(f"参数: {theta}")
```

### 4.3 梯度下降实现

```python
def gradient_descent(X, y, lr=0.01, n_iters=1000):
    """批量梯度下降"""
    m, n = X.shape
    
    # 初始化
    X_b = np.c_[np.ones((m, 1)), X]
    theta = np.zeros(n + 1)
    
    for _ in range(n_iters):
        # 计算预测
       预测 = X_b @ theta
        
        # 计算梯度
        gradient = (1/m) * X_b.T @ (预测 - y)
        
        # 更新参数
        theta -= lr * gradient
    
    return theta

# 使用
theta = gradient_descent(X_train, y_train, lr=0.01, n_iters=1000)
print(f"最终参数: {theta}")
```

### 4.4 完整线性回归类

```python
class LinearRegression:
    """线性回归（支持正规方程和梯度下降）"""
    
    def __init__(self, method='normal', lr=0.01, n_iters=1000, reg=None, reg_lambda=0.1):
        self.method = method      # 'normal' 或 'gd'
        self.lr = lr           # 学习率（梯度下降）
        self.n_iters = n_iters  # 迭代次数
        self.reg = reg         # 'l1', 'l2', 或 None
        self.reg_lambda = reg_lambda
        self.theta = None
    
    def fit(self, X, y):
        """训练模型"""
        if self.method == 'normal':
            self.theta = self._fit_normal(X, y)
        else:
            self.theta = self._fit_gd(X, y)
        return self
    
    def _fit_normal(self, X, y):
        """正规方程"""
        m, n = X.shape
        X_b = np.c_[np.ones((m, 1)), X]
        
        if self.reg == 'l2':
            # Ridge回归
            I = np.eye(n + 1)
            I[0, 0] = 0  # 不惩罚偏置
            self.theta = np.linalg.inv(X_b.T @ X_b + self.reg_lambda * I) @ X_b.T @ y
        else:
            self.theta = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y
        
        return self.theta
    
    def _fit_gd(self, X, y):
        """梯度下降"""
        m, n = X.shape
        X_b = np.c_[np.ones((m, 1)), X]
        self.theta = np.zeros(n + 1)
        
        for _ in range(self.n_iters):
            预测 = X_b @ self.theta
            gradient = (1/m) * X_b.T @ (预测 - y)
            
            # 正则化
            if self.reg == 'l2':
                gradient[1:] += (self.reg_lambda / m) * self.theta[1:]
            
            self.theta -= self.lr * gradient
        
        return self.theta
    
    def predict(self, X):
        """预测"""
        m = X.shape[0]
        X_b = np.c_[np.ones((m, 1)), X]
        return X_b @ self.theta
    
    def score(self, X, y):
        """R²分数"""
        预测 = self.predict(X)
        ss_res = np.sum((y - 预测) ** 2)
        ss_tot = np.sum((y - np.mean(y)) ** 2)
        return 1 - ss_res / ss_tot
```

## 6. 优缺点分析

### 6.1 优点

| 优点 | 说明 |
|------|------|
| 简单易实现 | 算法直观，易于理解 |
| 可解释性强 | 系数直接表示特征重要性 |
| 计算效率高 | O(n³)复杂度可接受 |
| 正则化选项 | L1/L2/Elastic Net |
| 理论基础扎实 | 统计意义明确 |

### 6.2 缺点

| 缺点 | 说明 |
|------|------|
| 线性假设 | 只能拟合线性关系 |
| 对异常值敏感 | MSE易受异常值影响 |
| 特征相关问题 | 多重共线性导致不稳定 |
| 欠拟合风险 | 复杂关系无法捕捉 |

### 6.3 改进方法

1. **多项式特征**：处理非线性
2. **基函数**：径向基函数等
3. **正则化**：处理多重共线性
4. **集成方法**：提升鲁棒性

## 8. 手工代码实现

### 8.1 完整实现

```python
import numpy as np

class LinearRegressionScratch:
    """线性回归从零实现"""
    
    def __init__(self, lr=0.01, n_iters=1000, batch_size=32, verbose=False):
        self.lr = lr
        self.n_iters = n_iters
        self.batch_size = batch_size
        self.verbose = verbose
        self.weights = None
        self.bias = None
    
    def fit(self, X, y):
        """训练"""
        n_samples, n_features = X.shape
        
        # 初始化参数
        self.weights = np.zeros(n_features)
        self.bias = 0
        
        # 训练
        for i in range(self.n_iters):
            # 选择批量（随机梯度下降）
            if self.batch_size == n_samples:
                batch_X, batch_y = X, y
            else:
                idx = np.random.choice(n_samples, self.batch_size, replace=False)
                batch_X, batch_y = X[idx], y[idx]
            
            # 前向传播
            y_pred = np.dot(batch_X, self.weights) + self.bias
            
            # 计算梯度
            dw = (1/batch_size) * np.dot(batch_X.T, (y_pred - batch_y))
            db = (1/batch_size) * np.sum(y_pred - batch_y)
            
            # 更新参数
            self.weights -= self.lr * dw
            self.bias -= self.lr * db
            
            # 打印损失
            if self.verbose and i % 100 == 0:
                loss = self._mse(y, np.dot(X, self.weights) + self.bias)
                print(f"Iter {i}: MSE = {loss:.4f}")
        
        return self
    
    def _mse(self, y_true, y_pred):
        """均方误差"""
        return np.mean((y_true - y_pred) ** 2)
    
    def predict(self, X):
        """预测"""
        return np.dot(X, self.weights) + self.bias
    
    def score(self, X, y):
        """R²分数"""
        y_pred = self.predict(X)
        ss_res = np.sum((y - y_pred) ** 2)
        ss_tot = np.sum((y - np.mean(y)) ** 2)
        return 1 - ss_res / ss_tot
```

## 12. 学习总结

### 12.1 核心要点

1. **模型**：$y = \mathbf{w}^T\mathbf{x} + b$
2. **损失**：MSE = $\frac{1}{m}\sum(\hat{y} - y)^2$
3. **正规方程**：$\mathbf{w} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$
4. **梯度下降**：$w := w - \alpha \nabla J$
5. **正则化**：L1(Lasso)、L2(Ridge)、Elastic Net

### 12.2 实用技巧

- 特征标准化很关键
- 先用正规方程尝试
- 数据量大用SGD
- Ridge处理共线性

### 12.3 适用场景

- 线性关系数据
- 快速基线模型
- 特征重要性分析
- 统计学分析

## 13. 练习题与思考题

### 13.1 基础题

**练习1**：正规方程推导
```
给定：
- X: m x n 矩阵
- y: m x 1 向量
- 损失: J(w) = 1/2m ||Xw - y||²
求：dJ/dw = 0 时的w
```

**答案**：
$$\frac{\partial J}{\partial \mathbf{w}} = \frac{1}{m} \mathbf{X}^T (\mathbf{X}\mathbf{w} - \mathbf{y}) = 0$$

$$\mathbf{X}^T \mathbf{X} \mathbf{w} = \mathbf{X}^T \mathbf{y}$$

$$\mathbf{w} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

**练习2**：梯度计算
```
给定：
- 损失: J(w) = 1/2m Σ(ŷ - y)²
- ŷ = wx
求：∂J/∂w
```

**答案**：
$$\frac{\partial J}{\partial w} = \frac{1}{m} \sum (wx - y) \cdot x = \frac{1}{m} \mathbf{x}^T (\mathbf{X}\mathbf{w} - \mathbf{y})$$
