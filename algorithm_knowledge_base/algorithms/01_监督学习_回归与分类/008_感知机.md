# 感知机 学习文档

> 感知机是二分类的线性模型，通过迭代更新权重来找到分离超平面

---

## 1. 算法基础认知

### 一句话定义
感知机是一种二分类线性分类模型，通过寻找一个超平面将数据集分为两类。

### 直觉类比
想象你在桌子上散布着红色和蓝色的弹珠，感知机就像用一根直尺在桌面上划一条直线，使得直线一侧都是红色弹珠，另一侧都是蓝色弹珠。如果划得不理想，就不断调整直尺的位置，直到找到最佳分界线。

### 历史背景
感知机由Frank Rosenblatt于1957年提出，是第一个具有学习能力的神经网络模型。1958年，Rosenblatt在Cornell航空实验室制造了名为Mark I Perceptron的物理机器，能够识别简单的形状。感知机是后来多层感知机和深度学习的基础。

### 算法定位
- 类型：监督学习 → 分类（二分类）
- 输出：离散类别（+1 或 -1）
- 模型类型：参数模型、判别模型

### 前置知识
- 线性代数：向量点积、超平面方程
- 基础微积分：梯度概念
- Python基础：NumPy数组操作
- 机器学习基础：分类问题、线性可分性

## 2. 核心原理

### 2.1 核心思想
感知机的核心思想是：对于线性可分的数据，通过不断调整权重向量，使得误分类样本到超平面的距离减小，最终找到一个能完全正确分类的超平面。

如果样本被误分类，就根据误分类样本更新权重：
- 如果正样本被分为负类，将权重向量向该样本方向移动
- 如果负样本被分为正类，将权重向量远离该样本方向

### 2.2 工作流程

1. **初始化**
   - 输入：训练数据集 $D = \{(x_1, y_1), (x_2, y_2), ..., (x_n, y_n)\}$，其中 $y_i \in \{+1, -1\}$
   - 初始化权重向量 $w = 0$，偏置 $b = 0$
   - 设置学习率 $\eta \in (0, 1]$

2. **迭代训练**
   - 遍历训练集，对每个样本 $(x_i, y_i)$ 计算预测值：$\hat{y}_i = \text{sign}(w \cdot x_i + b)$
   - 如果 $\hat{y}_i \neq y_i$（误分类），则更新参数：
     $$w \leftarrow w + \eta y_i x_i$$
     $$b \leftarrow b + \eta y_i$$
   - 重复直到所有样本都被正确分类或达到最大迭代次数

3. **输出模型**
   - 最终得到权重 $w$ 和偏置 $b$，超平面方程为 $w \cdot x + b = 0$

### 2.3 关键概念解释

- **权重向量 $w$**：决定了超平面的法线方向，$w$ 的每个分量对应一个特征的重要性
- **偏置 $b$**：决定了超平面与原点的距离
- **误分类点**：不满足 $y_i(w \cdot x_i + b) > 0$ 的样本
- **线性可分**：存在超平面能完全正确划分两类数据
- **学习率 $\eta$**：控制每次参数更新的步长

### 2.4 几何/直观解释
在二维空间中，感知机寻找一条直线 $w_1 x_1 + w_2 x_2 + b = 0$ 来分隔两类点。权重点 $w$ 垂直于这条直线，指向正类一侧。当某个样本被误分类时，我们把它"推"向正确的一侧：如果是正样本被分为负类，就增加 $w$（使超平面向负类方向移动）；反之亦然。

对于一个误分类样本 $(x_i, y_i)$，其到超平面的距离为：
$$\frac{|w \cdot x_i + b|}{\|w\|}$$
感知机的学习就是不断减小误分类点到超平面的距离。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 | 维度 |
|------|------|------|
| $n$ | 样本数量 | 标量 |
| $d$ | 特征维度 | 标量 |
| $x_i$ | 第 $i$ 个样本的特征向量 | $d \times 1$ |
| $y_i$ | 第 $i$ 个样本的标签 | $+1$ 或 $-1$ |
| $w$ | 权重向量 | $d \times 1$ |
| $b$ | 偏置项 | 标量 |
| $\eta$ | 学习率 | 标量 |
| $\text{sign}(z)$ | 符号函数：$z \geq 0$ 输出 $+1$，否则 $-1$ |

### 3.2 问题形式化
给定线性可分训练集 $D = \{(x_1, y_1), (x_2, y_2), ..., (x_n, y_n)\}$，其中 $x_i \in \mathbb{R}^d$，$y_i \in \{+1, -1\}$。

我们的目标是找到参数 $w$ 和 $b$，使得对于所有样本：
$$y_i(w \cdot x_i + b) > 0, \quad i = 1,2,...,n$$

这等价于找到一个超平面 $w \cdot x + b = 0$，使得正类样本都在超平面的一侧（$w \cdot x + b > 0$），负类样本都在另一侧（$w \cdot x + b < 0$）。

### 3.3 目标函数/损失函数
感知机使用**误分类点到超平面距离的总和**作为损失函数：

$$L(w, b) = -\sum_{x_i \in M} y_i(w \cdot x_i + b)$$

其中 $M$ 是误分类点的集合。

**为什么选择这个损失函数？**
1. **直观意义**：误分类点越少，损失越小；当没有误分类点时，损失为0
2. **可导性**：虽然符号函数不可导，但损失函数关于 $w$ 和 $b$ 是线性的，易于优化
3. **几何意义**：对应误分类点到超平面的距离之和（忽略分母 $\|w\|$ 不影响优化方向）

### 3.4 推导过程

**Step 1: 损失函数的梯度**
对于误分类样本 $(x_i, y_i) \in M$，计算损失函数对参数的偏导：

$$\frac{\partial L}{\partial w} = -\sum_{x_i \in M} y_i x_i$$
$$\frac{\partial L}{\partial b} = -\sum_{x_i \in M} y_i$$

**Step 2: 随机梯度下降**
由于误分类点集合 $M$ 依赖于当前参数，我们采用随机梯度下降：每次随机选取一个误分类点 $(x_i, y_i)$，计算梯度并更新：

$$\frac{\partial L_i}{\partial w} = -y_i x_i$$
$$\frac{\partial L_i}{\partial b} = -y_i$$

**Step 3: 参数更新规则**
$$w \leftarrow w - \eta \cdot (-y_i x_i) = w + \eta y_i x_i$$
$$b \leftarrow b - \eta \cdot (-y_i) = b + \eta y_i$$

这正是感知机学习算法中的更新公式。

### 3.5 最终解/算法步骤

**感知机学习算法（原始形式）**：

```
输入：训练集 D = {(x₁,y₁),...,(xₙ,yₙ)}，yᵢ∈{+1,-1}，学习率 η∈(0,1]
输出：权重 w，偏置 b

1. 初始化 w = 0, b = 0
2. 重复：
   对于 i = 1 到 n：
       如果 yᵢ(w·xᵢ + b) ≤ 0:
           w ← w + η yᵢ xᵢ
           b ← b + η yᵢ
3. 直到所有样本都被正确分类或达到最大迭代次数
```

**收敛定理**：如果训练集是线性可分的，那么感知机算法会在有限步内收敛。Novikoff定理证明，误分类次数不超过 $\frac{R^2}{\gamma^2}$，其中 $R = \max_i \|x_i\|$，$\gamma$ 是几何间隔。

### 4.1 数据预处理

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 感知机对特征尺度敏感，标准化可以加速收敛

X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

```

标准化的原因：
1. 不同特征的量纲可能差异很大，导致权重更新不平衡
2. 标准化后，不同特征对损失函数的贡献更均衡
3. 加速收敛，减少迭代次数

### 4.2 参数初始化

```python
def initialize_parameters(n_features):
    """
    初始化感知机参数
    
    参数:
        n_features: 特征维度
    
    返回:
        w: 权重向量（初始化为0）
        b: 偏置（初始化为0）
    """
    # 方法1：零初始化（传统感知机使用）
    w = np.zeros(n_features)
    b = 0.0
    
    # 方法2：小随机值初始化（可选）
    # w = np.random.randn(n_features) * 0.01
    # b = 0.0
    
    return w, b
```

零初始化的原因：感知机是线性模型，零初始化可以保证初始超平面通过原点，然后逐步调整。

### 4.3 迭代过程

```python
def train_perceptron(X, y, learning_rate=0.1, max_iters=1000):
    """
    训练感知机模型
    
    参数:
        X: 特征矩阵 (n_samples, n_features)
        y: 标签向量 (n_samples,)，值为 +1 或 -1
        learning_rate: 学习率
        max_iters: 最大迭代次数
    
    返回:
        w: 训练后的权重向量
        b: 训练后的偏置
        mistakes_history: 每轮误分类数历史
    """
    n_samples, n_features = X.shape
    w, b = initialize_parameters(n_features)
    mistakes_history = []
    
    for iteration in range(max_iters):
        n_mistakes = 0
        
        # 遍历所有样本
        for i in range(n_samples):
            # 计算预测值
            prediction = np.sign(np.dot(X[i], w) + b)
            if prediction == 0:
                prediction = -1  # 处理边界情况
            
            # 检查是否误分类
            if prediction != y[i]:
                n_mistakes += 1
                # 更新参数
                w += learning_rate * y[i] * X[i]
                b += learning_rate * y[i]
        
        mistakes_history.append(n_mistakes)
        
        # 如果没有误分类，收敛
        if n_mistakes == 0:
            print(f"第 {iteration+1} 轮收敛！")
            break
    
    return w, b, mistakes_history
```

### 4.4 收敛条件

```python
def check_convergence(mistakes_history, tol=0):
    """
    检查是否收敛
    
    收敛条件：
    1. 连续多轮误分类数为0
    2. 或达到最大迭代次数
    """
    if len(mistakes_history) == 0:
        return False
    
    # 检查最后一轮是否无误分类
    return mistakes_history[-1] <= tol
```

常用收敛条件：
1. **无误分类点**：所有样本都被正确分类
2. **最大迭代次数**：防止无限循环（即使数据线性不可分）
3. **权重变化很小**：$\|w_{new} - w_{old}\| < \epsilon$

### 4.5 超参数及推荐范围

| 超参数 | 作用 | 推荐范围 | 默认值 |
|--------|------|----------|--------|
| 学习率 $\eta$ | 控制参数更新步长 | 0.01 ~ 1.0 | 0.1 |
| 最大迭代次数 | 防止无限循环 | 100 ~ 10000 | 1000 |

学习率选择建议：
- 数据简单、线性可分性好：可用较大学习率（0.5-1.0）
- 数据复杂、接近线性不可分：用小学习率（0.01-0.1）
- 如果训练过程中损失震荡：减小学习率

## 5. 应用场景

### 5.1 典型应用

**应用1：垃圾邮件分类**
- 场景：根据邮件内容特征（词频等）判断是否为垃圾邮件
- 为什么适合：邮件特征通常是高维稀疏向量，感知机可以学习线性边界
- 实现：将邮件转换为TF-IDF特征，使用感知机进行二分类

**应用2：在线学习场景**
- 场景：数据流不断到来，需要实时更新模型
- 为什么适合：感知机是错误驱动的学习算法，可以高效地进行在线更新
- 实现：每来一个新样本，如果是误分类就更新权重，否则跳过

**应用3：简单图像分类**
- 场景：区分手写数字（如区分0和1）
- 为什么适合：当两类图像差别明显时，可以用线性边界分离
- 实现：将图像像素展开为向量，使用感知机训练

### 5.2 适用数据特征

1. **线性可分或近似线性可分**：数据存在线性边界
2. **二分类问题**：感知机原生只支持二分类
3. **特征维度适中**：维度不是特别高（高维可以用随机梯度变体）
4. **噪声较少**：噪声会导致线性不可分，感知机无法收敛

### 5.3 不适用场景

1. **线性不可分数据**：感知机无法收敛，会一直震荡
2. **多分类问题**：需要扩展（如OvO、OvR策略）
3. **非线性问题**：需要用核方法或神经网络
4. **数据有重叠**：两类数据混合严重，难以用直线分开

## 6. 优缺点分析

### 6.1 优点

| 优点 | 说明 | 成立条件 |
|------|------|----------|
| 简单易懂 | 模型思想和算法步骤都非常直观 | 通用 |
| 计算效率高 | 训练和预测都很快，适合大规模数据 | 特征维度不是特别高 |
| 在线学习 | 可以逐个样本更新，适合数据流场景 | 在线学习设置 |
| 理论基础扎实 | 有收敛定理保证（线性可分情况） | 数据线性可分 |
| 内存友好 | 只需要存储权重向量，不需要保存所有数据 | 随机梯度训练 |

### 6.2 缺点

| 缺点 | 说明 | 缓解方法 |
|------|------|----------|
| 只能处理线性可分数据 | 对于线性不可分数据不收敛 | 使用核感知机或多层感知机 |
| 仅支持二分类 | 原生不支持多分类 | 使用OvO、OvR等策略扩展 |
| 结果依赖初始化和样本顺序 | 不同顺序可能得到不同超平面 | 多次运行取平均或使用投票感知机 |
| 对噪声敏感 | 噪声点可能导致无法收敛 | 使用口袋算法（Pocket Algorithm） |
| 超平面不唯一 | 可能得到多个可行解 | 可以使用最大间隔感知机 |

```python
def plot_decision_boundary(X, y, model, title="感知机决策边界"):
    """
    绘制决策边界和数据点
    """
    # 创建网格
    h = 0.02
    x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
    y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
    xx, yy = np.meshgrid(np.arange(x_min, x_max, h),
                         np.arange(y_min, y_max, h))
    
    # 预测网格点的类别
    grid_points = np.c_[xx.ravel(), yy.ravel()]
    if hasattr(model, 'predict'):
        Z = model.predict(grid_points)
        # 转换回{-1, +1}
        if model.__class__.__name__ == 'Perceptron' and Z.min() >= 0:
            Z = np.where(Z == 0, -1, 1)
    else:
        # 使用我们自己训练的模型
        predictions = []
        for point in grid_points:
            pred = np.sign(np.dot(point, model[0]) + model[1])
            predictions.append(pred if pred != 0 else -1)
        Z = np.array(predictions)
    
    Z = Z.reshape(xx.shape)
    
    # 绘制等高线图
    plt.figure(figsize=(10, 8))
    plt.contourf(xx, yy, Z, alpha=0.3, cmap=plt.cm.RdBu)
    
    # 绘制数据点

    plt.scatter(X[:, 0], X[:, 1], c=colors, edgecolors='k', s=50, alpha=0.7)
    
    plt.title(title)
    plt.xlabel('特征1')
    plt.ylabel('特征2')
    plt.show()

# 使用sklearn模型可视化
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

class PerceptronManual:
    """
    手动实现的感知机类
    完全从零实现，不依赖任何机器学习库
    """
    
    def __init__(self, learning_rate=0.1, max_iters=1000):
        """
        初始化感知机
        
        参数:
            learning_rate: 学习率
            max_iters: 最大迭代次数
        """
        self.lr = learning_rate
        self.max_iters = max_iters
        self.w = None  # 权重向量
        self.b = 0.0   # 偏置
        self.loss_history = []  # 损失历史（误分类数）
        
    def sign(self, z):
        """
        符号函数
        
        参数:
            z: 输入值
            
        返回:
            +1 如果 z >= 0，否则 -1
        """
        return 1 if z >= 0 else -1
    
    def fit(self, X, y):
        """
        训练感知机
        
        参数:
            X: 特征矩阵 (n_samples, n_features)
            y: 标签向量 (n_samples,)，值为 -1 或 +1
        """
        n_samples, n_features = X.shape
        
        # 1. 初始化参数
        self.w = np.zeros(n_features)
        self.b = 0.0
        
        print("开始训练感知机...")
        print(f"样本数: {n_samples}, 特征数: {n_features}")
        
        # 2. 迭代训练
        for epoch in range(self.max_iters):
            n_mistakes = 0
            
            # 遍历所有样本
            for i in range(n_samples):
                # 计算预测值
                linear_output = np.dot(X[i], self.w) + self.b
                prediction = self.sign(linear_output)
                
                # 如果误分类，更新参数
                if prediction != y[i]:
                    n_mistakes += 1
                    # 感知机更新规则
                    self.w += self.lr * y[i] * X[i]
                    self.b += self.lr * y[i]
            
            # 记录本轮误分类数
            self.loss_history.append(n_mistakes)
            
            # 打印训练进度（每100轮或收敛时）
            if (epoch + 1) % 100 == 0 or n_mistakes == 0:
                print(f"Epoch {epoch+1}/{self.max_iters}, 误分类数: {n_mistakes}")
            
            # 如果没有误分类，收敛
            if n_mistakes == 0:
                print(f"✅ 在第 {epoch+1} 轮收敛！")
                break
        else:
            print(f"⚠️ 达到最大迭代次数 {self.max_iters}，未完全收敛")
        
        return self
    
    def predict(self, X):
        """
        预测新样本的类别
        
        参数:
            X: 特征矩阵 (n_samples, n_features)
            
        返回:
            预测的标签向量 (+1 或 -1)
        """
        linear_output = np.dot(X, self.w) + self.b
        predictions = np.array([self.sign(val) for val in linear_output])
        return predictions
    
    def score(self, X, y):
        """
        计算模型在测试集上的准确率
        
        参数:
            X: 特征矩阵
            y: 真实标签
            
        返回:
            准确率
        """
        predictions = self.predict(X)
        accuracy = np.mean(predictions == y)
        return accuracy
    
    def get_params(self):
        """
        获取模型参数
        
        返回:
            (权重向量 w, 偏置 b)
        """
        return self.w, self.b
```

```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score
```

### 11.1 训练不收敛，误分类数一直不降为0
**原因**：
- 数据不是线性可分的
- 学习率设置过大，导致在最优解附近震荡
- 特征没有标准化，导致权重更新不平衡

**原因**：过拟合？实际上感知机是简单线性模型，很少过拟合。更可能是：
- 数据分布不一致（训练集和测试集来自不同分布）
- 训练集太小，偶然得到了一个不适合测试集的决策边界

### 11.3 标签必须是{-1, +1}，不能是{0, 1}
**问题**：许多数据集使用{0, 1}标签，直接使用会导致错误

**正确做法**：
```python

```

### 11.4 特征标准化非常重要
**错误示例**：

### 11.5 感知机 doesn't 支持多分类
**误解**：直接使用感知机做多分类会失败

**解决方案**：使用一对多(OvR)或一对一(OvO)策略

## 12. 学习总结

### 核心要点回顾：
1. **感知机是最简单的神经网络**：只有一个神经元，是深度学习的基石
2. **线性分类器**：只能处理线性可分数据，寻找一个超平面分隔两类
3. **错误驱动学习**：只在误分类时更新权重，类似于人类从错误中学习
4. **收敛定理**：线性可分数据保证收敛，但解不唯一
5. **在线学习**：可以逐个样本更新，适合数据流场景

### 从感知机到深度学习：
```
感知机 (1957)
    ↓
多层感知机 (1980s) - 增加隐藏层，引入非线性
    ↓
反向传播 (1986) - 有效训练多层网络
    ↓
深度学习 (2006-至今) - 更深的网络，更优的激活函数
```

### 实践建议：
1. 总是标准化特征
2. 设置合理的学习率（通常0.1左右）
3. 对于线性不可分数据，考虑使用核方法或多层感知机
4. 如果是多分类问题，使用OvR或OvO策略扩展

**习题1：基础理解**
问题：假设二维空间中有三个点：(1,1)标签+1，(-1,-1)标签+1，(0,1)标签-1。如果初始权重w=(0,0)，b=0，学习率η=1，经过一轮训练后，权重和偏置分别是多少？

<details>
<summary>答案</summary>

遍历三个点：
1. (1,1): w·x+b = 0*1+0*1+0 = 0，sign(0)=+1，预测正确，不更新
2. (-1,-1): w·x+b = 0*(-1)+0*(-1)+0 = 0，sign(0)=+1，但真实标签是+1，预测正确？等等，标签是+1，预测是+1，正确。不更新。
3. (0,1): w·x+b = 0*0+0*1+0 = 0，sign(0)=+1，但真实标签是-1，误分类！
   更新：w = w + η*y*x = (0,0) + 1*(-1)*(0,1) = (0,-1)
        b = b + η*y = 0 + 1*(-1) = -1

一轮后：w = (0, -1)，b = -1

验证：对(0,1)：w·x+b = 0*0 + (-1)*1 + (-1) = -2，sign(-2) = -1，正确分类。
但检查其他点：(1,1)：0*1+(-1)*1+(-1) = -2，sign(-2)=-1，但真实标签是+1，误分类！
所以一轮训练后还有误分类点。
</details>

**习题3：理论推导**
问题：证明对于线性可分数据，感知机算法会在有限步内收敛。

<details>
<summary>答案</summary>

这是Novikoff定理的内容。简要证明思路：

1. 由于数据线性可分，存在||w*||=1的单位向量w*和γ>0，使得对所有样本：
   y_i(w*·x_i) ≥ γ

2. 设感知机第k次误分类时的权重为w_k，可以证明：
   w_k·w* ≥ kηγ

3. 另一方面，由权重更新规则：
   ||w_k||² = ||w_{k-1} + η y_i x_i||² 
            = ||w_{k-1}||² + 2η y_i w_{k-1}·x_i + η²||x_i||²
            ≤ ||w_{k-1}||² + η² R² (因为y_i(w_{k-1}·x_i) ≤ 0)
   递推得：||w_k||² ≤ kη² R²

4. 结合两式：kηγ ≤ w_k·w* ≤ ||w_k|| ≤ ηR√k
   解得：k ≤ (R/γ)²

因此误分类次数有上界，算法会在有限步内收敛。
</details>

### 思考题

**思考题1**：感知机和逻辑回归都是线性分类器，它们有什么区别？

<details>
<summary>答案</summary>

| 方面 | 感知机 | 逻辑回归 |
|------|--------|----------|
| 输出 | 离散类别{-1,+1} | 概率值(0,1) |
| 损失函数 | 误分类点到超平面距离 | 对数损失（交叉熵） |
| 收敛性 | 线性可分保证收敛 | 总是收敛（凸优化） |
| 类别边界 | 不唯一，依赖更新顺序 | 唯一，最大化对数似然 |
| 概率解释 | 无 | 有（sigmoid函数） |

核心区别：感知机是硬分类，逻辑回归是软分类（给出概率）。
</details>

**思考题2**：如果数据不是线性可分的，有什么改进方法？

<details>
<summary>答案</summary>

1. **口袋算法 (Pocket Algorithm)**：保留历史上最好的权重，即使后续更新导致表现变差也保留最佳解
2. **核感知机**：通过核函数隐式映射到高维空间，使数据线性可分
3. **多层感知机**：增加隐藏层和非线性激活函数
4. **投票感知机**：训练多个感知机，通过投票做决策
5. **使用其他模型**：如SVM（有最大间隔）、逻辑回归等
</details>
