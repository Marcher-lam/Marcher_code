# 前馈神经网络 学习文档

> 最基础的人工神经网络结构，信息从输入层单向流动到输出层，无反馈连接

---

## 1. 算法基础认知

### 一句话定义
前馈神经网络是一种多层网络结构，数据从输入层经过多个隐藏层变换，最终到达输出层，整个过程无循环或反馈连接。

### 直觉类比
想象一个多层过滤系统：原始材料（输入）进入第一层，每层进行筛选和转换，最终得到成品（输出）。每一层都有可学习的"过滤器"（权重），整个流程是单向的，不会回头修改前面的层。

### 历史背景
前馈神经网络的概念可以追溯到1943年McCulloch-Pitts神经元模型。1958年Rosenblatt提出感知机（单层前馈网络）。1986年Rumelhart等人提出反向传播算法，使得训练多层前馈网络成为可能，开启了现代深度学习时代。

### 算法定位
- 类型：监督学习 → 分类或回归
- 输出：连续值（回归）或类别概率（分类）
- 模型类型：参数模型、判别模型、深度学习

### 前置知识
- 线性代数：矩阵乘法、向量运算
- 微积分：链式法则、梯度计算
- 优化基础：梯度下降、随机梯度下降
- 激活函数：sigmoid、tanh、ReLU等
- Python基础：PyTorch/TensorFlow、NumPy

## 2. 核心原理

### 2.1 核心思想
前馈神经网络的核心思想是：**通过多层非线性变换，将输入空间映射到输出空间，每一层学习输入的不同抽象表示**。

对于一个L层网络，前向传播为：
$$a^{(0)} = x \quad (\text{输入})$$
$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)} \quad (\text{线性变换})$$
$$a^{(l)} = \sigma(z^{(l)}) \quad (\text{激活函数})$$
最终输出为 $a^{(L)}$。

### 2.2 工作流程

1. **初始化**
   - 输入：训练集 $D = \{(x_1, y_1), (x_2, y_2), ..., (x_m, y_m)\}$，网络结构（层数、每层神经元数）
   - 初始化权重 $W^{(l)}$ 和偏置 $b^{(l)}$（通常用随机初始化）
   - 设置超参数：学习率 $\alpha$、批次大小 $B$、训练轮数 $E$

2. **训练（对轮数 $e=1$ 到 $E$）**
   - a. **小批次采样**：从训练集中随机采样 $B$ 个样本
   - b. **前向传播**：对每个样本计算网络输出 $\hat{y}_i$
   - c. **计算损失**：$J = \frac{1}{B} \sum_{i=1}^{B} L(y_i, \hat{y}_i) + \lambda \Omega(\theta)$（可能加正则化）
   - d. **反向传播**：计算损失对网络参数的梯度 $\frac{\partial J}{\partial W^{(l)}}, \frac{\partial J}{\partial b^{(l)}}$
   - e. **参数更新**：$W^{(l)} \leftarrow W^{(l)} - \alpha \cdot \frac{\partial J}{\partial W^{(l)}}$

3. **输出最终模型**
   - 训练好的网络参数 $\theta = \{W^{(1)}, b^{(1)}, ..., W^{(L)}, b^{(L)}\}$

### 2.3 关键概念解释

- **层（Layer）**：网络的结构单元，包含线性变换和激活函数
- **前向传播**：数据从输入到输出的计算过程
- **反向传播**：利用链式法则计算梯度的算法
- **激活函数**：引入非线性，使网络能学习复杂函数
- **损失函数**：衡量预测值与真实值的差异
- **过拟合**：网络参数太多，记住训练数据，泛化能力差

### 2.4 几何/直观解释
从函数逼近角度看，前馈神经网络通过多层非线性变换，可以逼近任意连续函数（通用逼近定理）。每一层都在学习输入的不同层次表示：浅层学习低级特征（如边缘），深层学习高级特征（如形状、物体）。

从几何看，网络通过线性变换（权重矩阵）将输入空间扭曲，然后通过激活函数进行非线性变换，最终将不同类别的数据点分开（分类）或拟合复杂函数（回归）。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 | 维度 |
|------|------|----------|
| $L$ | 网络层数（不包括输入层） | 标量 |
| $n^{(l)}$ | 第 $l$ 层的神经元数量 | 标量 |
| $x$ | 输入向量 | $n^{(0)} \times 1$ |
| $y$ | 真实标签/值 | 标量或向量 |
| $W^{(l)}$ | 第 $l$ 层的权重矩阵 | $n^{(l)} \times n^{(l-1)}$ |
| $b^{(l)}$ | 第 $l$ 层的偏置 | $n^{(l)} \times 1$ |
| $a^{(l)}$ | 第 $l$ 层的激活值（输出） | $n^{(l)} \times 1$ |
| $z^{(l)}$ | 第 $l$ 层的线性组合值 | $n^{(l)} \times 1$ |
| $\sigma$ | 激活函数 | 函数：$R \rightarrow R$ |

### 3.2 问题形式化
给定训练集 $D = \{(x_i, y_i)\}_{i=1}^{m}$，我们希望学习网络参数 $\theta = \{W^{(l)}, b^{(l)}\}_{l=1}^{L}$ 使得损失函数最小化：

$$\min_\theta \frac{1}{m} \sum_{i=1}^{m} L(y_i, f(x_i; \theta)) + \lambda \Omega(\theta)$$

其中 $f(x; \theta)$ 是前馈网络的输出，$\Omega(\theta)$ 是正则化项（如L2正则化）。

### 3.3 目标函数/损失函数
前馈网络可以使用**各种损失函数**，取决于任务：

- **回归**：均方误差 $L(y, \hat{y}) = \frac{1}{2}(y - \hat{y})^2$
- **二分类**：交叉熵损失 $L(y, \hat{y}) = -[y \log \hat{y} + (1-y) \log(1-\hat{y})]$
- **多分类**：多类交叉熵 $L(y, \hat{y}) = -\sum_{c=1}^{C} y_c \log \hat{y}_c$

**为什么使用这些损失？**
1. **与输出匹配**：回归输出连续值，分类输出概率
2. **凸性**：配合合适的激活函数，损失是凸的（单层）或平滑的
3. **梯度良好**：这些损失的梯度形式简单，便于反向传播

### 3.4 推导过程

**Step 1: 前向传播**

对于第 $l$ 层（$l=1,...,L$）：

$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$$
$$a^{(l)} = \sigma^{(l)}(z^{(l)})$$

其中 $a^{(0)} = x$（输入），$\sigma^{(l)}$ 是第 $l$ 层的激活函数。

**Step 2: 反向传播（链式法则）**

以权重 $W^{(l)}$ 为例，计算 $\frac{\partial J}{\partial W^{(l)}}$：

定义第 $l$ 层的误差项 $\delta^{(l)} = \frac{\partial J}{\partial z^{(l)}}$。

对于输出层 $L$：
$$\delta^{(L)} = \frac{\partial J}{\partial a^{(L)}} \odot \sigma'(z^{(L)})$$

对于隐藏层 $l = L-1, ..., 1$：
$$\delta^{(l)} = (W^{(l+1)^T \delta^{(l+1)}) \odot \sigma'(z^{(l)})$$

然后：
$$\frac{\partial J}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^T$$
$$\frac{\partial J}{\partial b^{(l)}} = \delta^{(l)}$$

**Step 3: 参数更新**

$$W^{(l)} \leftarrow W^{(l)} - \alpha \cdot \frac{\partial J}{\partial W^{(l)}}$$
$$b^{(l)} \leftarrow b^{(l)} - \alpha \cdot \frac{\partial J}{\partial b^{(l)}}$$

### 3.5 最终解/算法步骤

**前馈神经网络训练（小批次梯度下降）**：

```
输入：训练集 D, 网络结构, 学习率 α, 批次大小 B, 轮数 E
输出：训练好的网络参数 θ

1. 初始化参数 θ = {W⁽ˡ⁾, b⁽ˡ⁾}
2. 对轮数 e=1 到 E：
   a. 将数据随机打乱
   b. 对批次 b=1 到 ⌈m/B⌉：
      i. 小批次：{(xᵢ, yᵢ)}ᵢ∈batch_b
      ii. 前向传播：计算所有样本的输出 ŷᵢ
      iii. 计算批次损失 J = (1/B) ∑ᵢ L(yᵢ, ŷᵢ)
      iv. 反向传播：计算所有参数的梯度
      v. 更新参数：θ ← θ - α · ∇J(θ)
3. 返回 θ
```

```python
import numpy as np
```

预处理要点：
1. **特征标准化**：神经网络对特征尺度敏感，必须标准化
2. **独热编码**：对于多分类，标签需要独热编码或直接使用索引（配合CrossEntropyLoss）
3. **数据增强**：对于图像等数据，可以使用数据增强提高泛化
4. **批次化**：训练时通常使用批次，需要设置合适的批次大小

### 4.2 参数初始化

```python
class FeedforwardNet(nn.Module):
    """前馈神经网络"""
    def __init__(self, input_dim, hidden_dims=[64, 32], output_dim=2):
        """
        初始化网络
        
        参数:
            input_dim: 输入维度
            hidden_dims: 隐藏层维度列表，如[64, 32]表示两个隐藏层
            output_dim: 输出维度（类别数或回归输出维度）
        """
        super(FeedforwardNet, self).__init__()
        
        # 构建网络层
        layers = []
        prev_dim = input_dim
        
        for hidden_dim in hidden_dims:
            layers.append(nn.Linear(prev_dim, hidden_dim))
            layers.append(nn.ReLU())  # 激活函数
            prev_dim = hidden_dim
        
        # 输出层（无激活函数，因为后面会加Softmax或根据任务）
        layers.append(nn.Linear(prev_dim, output_dim))
        
        self.network = nn.Sequential(*layers)
        
    def forward(self, x):
        """前向传播"""
        return self.network(x)

# 初始化网络
input_dim = X_train_tensor.shape[1]  # 10
model = FeedforwardNet(input_dim=input_dim, hidden_dims=[64, 32], output_dim=2)

print(f"网络结构:")
print(model)
print(f"总参数数: {sum(p.numel() for p in model.parameters())}")
```

初始化建议：
1. **权重初始化**：常用Xavier初始化（tanh/sigmoid）或He初始化（ReLU）
2. **偏置**：通常初始化为0
3. **激活函数**：隐藏层常用ReLU，输出层根据任务选择
4. **层数**：1-3层对于简单任务足够，深层用于复杂任务

### 4.3 迭代过程（训练循环）

```python
def train_epoch(model, X_train, y_train, criterion, optimizer, batch_size=32):
    """训练一个epoch"""
    model.train()  # 设置为训练模式
    total_loss = 0.0
    n_samples = X_train.shape[0]
    n_batches = (n_samples + batch_size - 1) // batch_size
    
    # 随机打乱数据
    indices = torch.randperm(n_samples)
    X_shuffled = X_train[indices]
    y_shuffled = y_train[indices]
    
    for batch in range(n_batches):
        # 获取批次数据
        start = batch * batch_size
        end = min(start + batch_size, n_samples)
        
        X_batch = X_shuffled[start:end]
        y_batch = y_shuffled[start:end]
        
        # 前向传播
        outputs = model(X_batch)
        loss = criterion(outputs, y_batch)
        
        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item()
    
    return total_loss / n_batches

def evaluate(model, X_test, y_test):
    """评估模型"""
    model.eval()  # 设置为评估模式
    with torch.no_grad():
        outputs = model(X_test)
        _, predicted = torch.max(outputs, 1)
        accuracy = (predicted == y_test).float().mean().item()
    return accuracy

# 训练设置
criterion = nn.CrossEntropyLoss()  # 内置Softmax
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 训练循环
n_epochs = 50
train_losses = []
test_accuracies = []

print("开始训练前馈神经网络...")
for epoch in range(n_epochs):
    # 训练
    avg_loss = train_epoch(model, X_train_tensor, y_train_tensor, criterion, optimizer, batch_size=32)
    train_losses.append(avg_loss)
    
    # 评估
    test_acc = evaluate(model, X_test_tensor, y_test_tensor)
    test_accuracies.append(test_acc)
    
    if (epoch + 1) % 10 == 0:
        print(f"Epoch {epoch+1}/{n_epochs}, Loss: {avg_loss:.4f}, Test Acc: {test_acc:.4f}")

print(f"训练完成！最终测试准确率: {test_accuracies[-1]:.4f}")
```

### 4.4 收敛条件

前馈神经网络通常训练固定的轮数，但可以监控：

```python
def check_convergence(losses_history, window=10, threshold=1e-4):
    """检查是否收敛"""
    if len(losses_history) < window:
        return False
    # 检查最近窗口内的损失变化
    recent_losses = losses_history[-window:]
    loss_change = abs(recent_losses[-1] - np.mean(recent_losses[:-1]))
    return loss_change < threshold
```

收敛相关要点：
1. **损失曲线**：应单调下降并趋于平稳
2. **训练/测试准确率**：训练准确率应上升，测试准确率应上升然后平稳
3. **早停**：如果测试准确率开始下降，则停止（过拟合）
4. **学习率调整**：如果损失震荡，减小学习率

### 4.5 超参数及推荐范围

| 超参数 | 作用 | 推荐范围 | 默认值 |
|--------|------|----------|--------|
| `hidden_dims` (隐藏层维度) | 网络宽度和深度 | [64], [128, 64], [256,128,64] | [64, 32] |
| `learning_rate` (学习率) | 控制更新步长 | 1e-4 ~ 1e-2 | 1e-3 |
| `batch_size` (批次大小) | 每次更新的样本数 | 32 ~ 256 | 32 |
| `n_epochs` (训练轮数) | 训练迭代轮数 | 50 ~ 500 | 100 |
| `activation` (激活函数) | 引入非线性 | ReLU, tanh, sigmoid | ReLU |
| `optimizer` (优化器) | 更新参数的算法 | Adam, SGD, RMSprop | Adam |
| `weight_decay` (L2正则化) | 防止过拟合 | 1e-5 ~ 1e-3 | 0 |

选择建议：
1. **网络结构**：从简单开始（1-2层），逐步增加复杂度
2. **学习率**：使用Adam优化器，默认1e-3通常不错
3. **批次大小**：32-128是常用范围，太小不稳定，太大内存消耗大
4. **早停**：监控验证损失，及时停止防止过拟合

## 5. 应用场景

### 5.1 典型应用

**应用1：图像分类**
- 场景：识别图像中的物体（如猫、狗、汽车）
- 为什么适合：深层网络可以学习层次特征表示
- 实现：卷积神经网络（CNN）是前馈网络的变体，专门处理图像

**应用2：房价预测（回归）**
- 场景：根据房屋特征预测房价
- 为什么适合：可以学习特征间的复杂非线性关系
- 实现：多层网络，输出层为线性（无激活），使用MSE损失

**应用3：文本分类**
- 场景：判断文本情感（正面/负面）
- 为什么适合：可以学习文本的语义表示
- 实现：将词嵌入作为网络输入，或使用RNN/LSTM处理序列

### 5.2 适用数据特征

1. **结构化数据**：表格数据，特征为向量形式
2. **非线性关系**：需要学习复杂函数映射
3. **大规模数据**：神经网络可以从大量数据中受益
4. **高维输入**：如图像（像素）、文本（词向量）
5. **需要端到端学习**：直接从原始输入学习，无需手工特征

### 5.3 不适用场景

1. **数据量小**：神经网络容易过拟合 → 使用线性模型或SVM
2. **需要可解释性**：神经网络是黑盒模型 → 使用决策树、线性回归
3. **特征工程关键**：人工特征可能更好 → 使用线性模型、GBDT
4. **实时推理要求极高**：神经网络前向传播可能需要较多计算 → 使用简单模型
5. **数据标注成本高**：神经网络需要大量标注数据 → 使用半监督、迁移学习

## 6. 优缺点分析

### 6.1 优点

| 优点 | 说明 | 成立条件 |
|------|------|----------|
| 函数逼近能力强 | 理论上可逼近任意连续函数 | 足够宽/深的网络 |
| 端到端学习 | 直接从原始输入学习，无需手工特征 | 合适网络结构 |
| 适合大规模数据 | 数据越多通常性能越好 | 数据量充足 |
| 灵活性高 | 可以适应各种任务（分类、回归等） | 任务定义清晰 |
| 特征学习 | 自动学习数据表示 | 深度网络 |

### 6.2 缺点

| 缺点 | 说明 | 缓解方法 |
|------|------|----------|
| 需要大量数据 | 小数据容易过拟合 | 使用正则化、数据增强、迁移学习 |
| 黑盒模型 | 决策过程难以解释 | 使用可解释性技术（如SHAP） |
| 调参复杂 | 超参数多，需要仔细调优 | 使用自动机器学习（AutoML） |
| 训练时间长 | 需要GPU加速训练 | 使用预训练模型、模型压缩 |
| 容易过拟合 | 参数多，记忆训练数据 | 使用正则化、Dropout、早停 |

```python
import numpy as np

class FeedforwardNetManual:
    """手动实现的前馈神经网络（用于教学）"""
    
    def __init__(self, input_dim, hidden_dims=[64], output_dim=2, activation='relu'):
        """
        初始化网络（使用适合初始化）
        
        参数:
            input_dim: 输入维度
            hidden_dims: 隐藏层维度列表
            output_dim: 输出维度
            activation: 激活函数类型
        """
        self.activation_type = activation
        self.weights_ = []  # 权重矩阵列表
        self.biases_ = []   # 偏置向量列表
        self.activations_ = []  # 存储前向传播的激活值（用于反向传播）
        self.zs_ = []  # 存储线性组合值
        
        # 初始化参数
        prev_dim = input_dim
        layer_dims = hidden_dims + [output_dim]
        
        for i, layer_dim in enumerate(layer_dims):
            # Xavier/Glorot初始化（适合tanh/sigmoid）
            if activation in ['tanh', 'sigmoid']:
                limit = np.sqrt(6 / (prev_dim + layer_dim))
            else:  # He初始化（适合ReLU）
                limit = np.sqrt(2 / prev_dim)
            
            # 权重初始化
            W = np.random.randn(prev_dim, layer_dim) * limit
            b = np.zeros((1, layer_dim))
            
            self.weights_.append(W)
            self.biases_.append(b)
            prev_dim = layer_dim
    
    def activate(self, z, activation_type=None):
        """激活函数"""
        if activation_type is None:
            activation_type = self.activation_type
            
        if activation_type == 'relu':
            return np.maximum(0, z)
        elif activation_type == 'tanh':
            return np.tanh(z)
        elif activation_type == 'sigmoid':
            return 1 / (1 + np.exp(-np.clip(z, -100, 100)))
        elif activation_type == 'softmax':
            # 数值稳定版本
            z_stable = z - np.max(z, axis=1, keepdims=True)
            exp_z = np.exp(z_stable)
            return exp_z / np.sum(exp_z, axis=1, keepdims=True)
        else:
            return z  # 线性激活
    
    def activate_derivative(self, z, activation_type=None):
        """激活函数的导数"""
        if activation_type is None:
            activation_type = self.activation_type
            
        if activation_type == 'relu':
            return (z > 0).astype(float)
        elif activation_type == 'tanh':
            return 1 - np.tanh(z)**2
        elif activation_type == 'sigmoid':
            s = 1 / (1 + np.exp(-np.clip(z, -100, 100)))
            return s * (1 - s)
        else:
            return np.ones_like(z)
    
    def forward(self, X):
        """前向传播"""
        self.activations_ = [X]  # 输入层激活值
        self.zs_ = []  # 线性组合值
        
        a_prev = X
        
        for i in range(len(self.weights_) - 1):  # 隐藏层
            z = np.dot(a_prev, self.weights_[i]) + self.biases_[i]
            self.zs_.append(z)
            
            a = self.activate(z)
            self.activations_.append(a)
            a_prev = a
        
        # 输出层（无激活或使用Softmax）
        z_out = np.dot(a_prev, self.weights_[-1]) + self.biases_[-1]
        self.zs_.append(z_out)
        
        # 分类使用Softmax，回归使用线性
        if self.activation_type == 'softmax':
            a_out = self.activate(z_out, 'softmax')
        else:
            a_out = z_out  # 线性激活
            
        self.activations_.append(a_out)
        return a_out
    
    def backward(self, X, y, learning_rate=0.01):
        """反向传播，更新参数"""
        m = X.shape[0]  # 样本数
        
        # 计算输出层误差
        # 对于交叉熵损失和Softmax，梯度简化为 (a_out - y_onehot)
        a_out = self.activations_[-1]
        
        # 将y转换为独热编码
        n_classes = self.weights_[-1].shape[1]
        y_onehot = np.zeros((m, n_classes))
        y_onehot[np.arange(m), y] = 1
        
        delta = a_out - y_onehot  # 简化梯度
        
        # 反向传播
        for i in range(len(self.weights_) - 1, -1, -1):
            # 计算梯度
            grad_W = np.dot(self.activations_[i].T, delta) / m
            grad_b = np.mean(delta, axis=0, keepdims=True)
            
            # 更新参数
            self.weights_[i] -= learning_rate * grad_W
            self.biases_[i] -= learning_rate * grad_b
            
            # 计算上一层的误差
            if i > 0:
                delta = np.dot(delta, self.weights_[i].T) * self.activate_derivative(self.zs_[i-1])
    
    def train(self, X, y, n_epochs=100, learning_rate=0.01, batch_size=32):
        """训练网络"""
        n_samples = X.shape[0]
        losses = []
        
        for epoch in range(n_epochs):
            # 随机打乱数据
            indices = np.random.permutation(n_samples)
            X_shuffled = X[indices]
            y_shuffled = y[indices]
            
            epoch_loss = 0
            
            # 小批次训练
            for start in range(0, n_samples, batch_size):
                end = min(start + batch_size, n_samples)
                X_batch = X_shuffled[start:end]
                y_batch = y_shuffled[start:end]
                
                # 前向传播
                outputs = self.forward(X_batch)
                
                # 计算损失（交叉熵）
                # 简化：使用负对数似然
                y_onehot = np.zeros((end-start, outputs.shape[1]))
                y_onehot[np.arange(end-start), y_batch] = 1
                loss = -np.mean(y_onehot * np.log(outputs + 1e-10))
                epoch_loss += loss
                
                # 反向传播
                self.backward(X_batch, y_batch, learning_rate)
            
            losses.append(epoch_loss / (n_samples // batch_size))
            
            if (epoch + 1) % 20 == 0:
                print(f"Epoch {epoch+1}/{n_epochs}, Loss: {losses[-1]:.4f}")
        
        return losses
    
    def predict(self, X):
        """预测类别"""
        outputs = self.forward(X)
        return np.argmax(outputs, axis=1)
```

## 12. 学习总结

### 核心要点回顾：
1. **前向传播**：$a^{(l)} = \sigma(W^{(l)} a^{(l-1)} + b^{(l)}$
2. **反向传播**：链式法则计算梯度
3. **损失函数**：根据任务选择（MSE、交叉熵等）
4. **优化器**：SGD、Adam等更新参数
5. **正则化**：Dropout、L2、早停防止过拟合

### 从前馈神经网络到其他模型：
```
前馈神经网络 (基础)
    ↓
卷积神经网络 (CNN) - 引入卷积层，适合图像
    ↓
循环神经网络 (RNN) - 处理序列数据
    ↓
Transformer - 自注意力机制，颠覆NLP
    ↓
现代深度模型 (BERT, GPT, ViT等)
```

### 实践建议：
1. **默认结构**：2-3个隐藏层，每层64-256个神经元
2. **激活函数**：隐藏层用ReLU，输出层根据任务选择
3. **优化器**：使用Adam，学习率1e-3
4. **正则化**：Dropout(0.5)、L2正则化
5. **监控**：损失曲线、训练/测试准确率

```python
scaler = StandardScaler()

X_test_scaled = scaler.transform(X_test)

# 转换为张量
X_train_tensor = torch.FloatTensor(X_train_scaled)
y_train_tensor = torch.LongTensor(y_train)

# 定义网络
model = nn.Sequential(
    nn.Linear(5, 64),
    nn.ReLU(),
    nn.Linear(64, 2)
)

# 训练
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

for epoch in range(100):
    model.train()
    optimizer.zero_grad()
    outputs = model(X_train_tensor)
    loss = criterion(outputs, y_train_tensor)
    loss.backward()
    optimizer.step()

# 评估
```

**习题3：理论推导**
问题：推导三层网络（输入-隐藏-输出）的反向传播公式。

<details>
<summary>答案</summary>

假设三层网络：
- 输入 $x$，隐藏层 $h = \sigma(W_1 x + b_1)$
- 输出层 $z = W_2 h + b_2$，然后Softmax

损失：交叉熵 $J = -\sum_c y_c \log \text{softmax}(z)_c$

输出层梯度：
$$\delta^{(2)} = \frac{\partial J}{\partial z} = \text{softmax}(z) - y$$

隐藏层梯度：
$$\delta^{(1)} = (W_2^T \delta^{(2)}) \odot \sigma'(z^{(1)})$$

参数梯度：
$$\frac{\partial J}{\partial W_2} = \delta^{(2)} h^T$$
$$\frac{\partial J}{\partial W_1} = \delta^{(1)} x^T$$

这就是反向传播的核心：从输出层往回传播误差。
</details>

### 思考题

**思考题1**：前馈神经网络和线性模型有什么区别？各适用什么场景？

<details>
<summary>答案</summary>

| 方面 | 前馈神经网络 | 线性模型（如逻辑回归） |
|------|----------|----------|
| 非线性 | 通过激活函数引入非线性 | 线性模型，无隐藏层 |
| 表达能力 | 可逼近复杂函数 | 只能学习线性边界 |
| 数据需求 | 需要大量数据 | 小数据也可以 |
| 可解释性 | 黑盒，难解释 | 参数有清晰含义 |
| 训练时间 | 长，需要GPU | 快，几秒内完成 |

**适用场景**：
- **前馈神经网络**：图像、语音、文本等复杂数据，数据量大
- **线性模型**：表格数据、需要可解释性、小数据集

趋势：预训练+微调使得神经网络在小数据集上也能表现良好。
</details>

**思考题2**：什么时候用CNN，什么时候用RNN/LSTM，什么时候用Transformer？

<details>
<summary>答案</summary>

| 数据类型 | 推荐架构 | 原因 |
|----------|----------|------|
| 图像/空间数据 | CNN (卷积神经网络） | 局部连接、权值共享，适合网格数据 |
| 序列/时间数据 | RNN/LSTM/GRU | 擅长建模时序依赖，但有梯度消失问题 |
| 长序列/并行需求 | Transformer (自注意力） | 并行计算，捕获长距离依赖 |
| 多模态数据 | Transformer变体（如CLIP） | 灵活处理多种模态 |
| 小数据集 | 简单CNN或MLP | 参数量小，不易过拟合 |

核心区别：数据结构和任务决定架构选择。
</details>

## 14. 学习路径建议

### 初级阶段（掌握基础）
1. 理解神经元、激活函数、前向/反向传播
2. 手动计算两层网络的前向/反向传播
3. 使用PyTorch实现简单分类网络
4. 理解损失函数和优化器的作用

**学习时间**：2-3周**

### 中级阶段（理解原理和扩展）
1. 掌握各种激活函数的性质和选择
2. 学习正则化技术（Dropout、Batch Norm等）
3. 理解梯度消失/爆炸问题及解决方案
4. 学习CNN、RNN等变体结构

**学习时间**：3-4周**

### 高级阶段（深度学习前沿）
1. 学习Transformer架构和自注意力机制
2. 掌握预训练模型（BERT、GPT）的使用和微调
3. 研究生成模型（VAE、GAN、Diffusion）
4. 探索多模态学习、元学习等前沿方向

**学习时间**：4-6周**

### 实践项目建议
1. **基础项目**：MNIST手写数字分类（使用MLP）
2. **进阶项目**：CIFAR-10图像分类（使用CNN）
3. **挑战项目**：情感分析（使用RNN/LSTM或Transformer）
