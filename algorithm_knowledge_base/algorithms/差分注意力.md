# 差分注意力学习文档

## 1. 算法基础认知

差分注意力（Differential Attention）是一种新型的注意力机制，由微软研究院在2024年提出，应用于Diff Transformer模型中。与传统的自注意力机制不同，差分注意力通过计算Query与Key之间的差分关系来增强模型的表达能力和训练稳定性。

差分注意力的核心创新点：
1. **差分路径**：并行计算查询与键的正、负差异
2. **稳定性提升**：减少梯度消失问题
3. **表达能力增强**：能够区分正负相关性

这种机制受到了差分卷积（DCNv2）的启发，将"差异"的概念引入到注意力计算中。在传统的注意力机制中，我们计算Query和Key之间的相似度；在差分注意力中，我们进一步分解这种相似度为正负两部分。

差分注意力的应用场景：
- Diff Transformer
- 长文本建模
- 需要高稳定性的训练场景

## 2. 核心原理

### 2.1 传统注意力回顾

标准的多头注意力（MHA）计算公式：

$$\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

其中 $Q$ 是查询矩阵，$K$ 是键矩阵，$V$ 是值矩阵。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

def standard_attention_example():
    """标准注意力示例"""
    
    # 输入
    Q = torch.randn(2, 8, 10, 64)  # [B, H, N, D]
    K = torch.randn(2, 8, 20, 64)
    V = torch.randn(2, 8, 20, 64)
    
    # 计算注意力
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    attention_weights = F.softmax(scores, dim=-1)
    output = torch.matmul(attention_weights, V)
    
    return output
```

### 2.2 差分注意力机制

差分注意力的核心计算：

$$Q_{diff}^+ = Q - K$$
$$Q_{diff}^- = Q + K$$

分别计算两部分的注意力：
$$attn^+ = \text{Softmax}\left(\frac{Q_{diff}^+ K^T}{\sqrt{d_k}}\right)V$$
$$attn^- = \text{Softmax}\left(\frac{Q_{diff}^- K^T}{\sqrt{d_k}}\right)V$$

最终输出：
$$\text{Output} = attn^+ - attn^-$$

```python
class DifferentialAttention(nn.Module):
    """差分注意力机制"""
    
    def __init__(self, dim, num_heads=8):
        super().__init__()
        
        self.num_heads = num_heads
        self.head_dim = dim // num_heads
        self.scale = math.sqrt(self.head_dim)
        
        # 线性投影
        self.q_proj = nn.Linear(dim, dim)
        self.k_proj = nn.Linear(dim, dim)
        self.v_proj = nn.Linear(dim, dim)
        self.o_proj = nn.Linear(dim, dim)
        
    def forward(self, x):
        """
        参数:
            x: [B, N, D] 或 [B, N, H, D]
            
        返回:
            output: [B, N, D]
        """
        B, N, D = x.shape
        
        # 投影并reshape到多头
        Q = self.q_proj(x).view(B, N, self.num_heads, self.head_dim).transpose(1, 2)
        K = self.k_proj(x).view(B, N, self.num_heads, self.head_dim).transpose(1, 2)
        V = self.v_proj(x).view(B, N, self.num_heads, self.head_dim).transpose(1, 2)
        
        # ========== 差分计算 ==========
        # Q_pos = Q - K
        # Q_neg = Q + K
        Q_pos = Q - K
        Q_neg = Q + K
        
        # ========== 正向注意力 ==========
        attn_pos = torch.matmul(Q_pos, K.transpose(-2, -1)) / self.scale
        attn_pos = F.softmax(attn_pos, dim=-1)
        out_pos = torch.matmul(attn_pos, V)
        
        # ========== 负向注意力 ==========
        attn_neg = torch.matmul(Q_neg, K.transpose(-2, -1)) / self.scale
        attn_neg = F.softmax(attn_neg, dim=-1)
        out_neg = torch.matmul(attn_neg, V)
        
        # ========== 差分输出 ==========
        out_diff = out_pos - out_neg
        
        # 重新reshape
        out_diff = out_diff.transpose(1, 2).contiguous().view(B, N, D)
        
        # 输出投影
        output = self.o_proj(out_diff)
        
        return output


def differential_attention_math():
    """差分注意力的数学推导"""
    
    # 步骤1: 计算差分
    Q_diff_pos = Q - K  # 正向差分
    Q_diff_neg = Q + K  # 负向差分
    
    # 步骤2: 注意力计算
    # 对于每个位置i和j
    # score(i,j)^+ = (q_i - k_j) · k_j = q_i·k_j - k_j·k_j
    # score(i,j)^- = (q_i + k_j) · k_j = q_i·k_j + k_j·k_j
    
    # 步骤3: 差分的效果
    # out^+ = Σ α_ij^+ v_j
    # out^- = Σ α_ij^- v_j
    # output = out^+ - out^-
    
    # 这相当于使用 (q_i - k_j) 和 (q_i + k_j) 的差异
    # 更好地捕捉正负相关性
```

### 2.3 差分Transformer层

差分Transformer的整体结构：

```python
class DiffTransformerLayer(nn.Module):
    """差分Transformer层"""
    
    def __init__(self, dim, num_heads=8, mlp_ratio=4, dropout=0.1):
        super().__init__()
        
        # 差分注意力
        self.norm1 = nn.LayerNorm(dim)
        self.attn = DifferentialAttention(dim, num_heads)
        
        # FFN
        self.norm2 = nn.LayerNorm(dim)
        self.mlp = nn.Sequential(
            nn.Linear(dim, dim * mlp_ratio),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(dim * mlp_ratio, dim),
            nn.Dropout(dropout)
        )
        
    def forward(self, x):
        # 差分注意力 + 残差
        x = x + self.attn(self.norm1(x))
        
        # FFN + 残差
        x = x + self.mlp(self.norm2(x))
        
        return x
```

## 3. 数学公式与推导

### 3.1 详细的数学推导

差分注意力的核心公式可以展开为：

$$\text{DiffAttn}(Q, K, V) = \text{Softmax}\left(\frac{(Q-K)K^T}{\sqrt{d_k}}\right)V - \text{Softmax}\left(\frac{(Q+K)K^T}{\sqrt{d_k}}\right)V$$

让我们简化这个公式：

设 $A = \frac{QK^T}{\sqrt{d_k}}$，$B = \frac{KK^T}{\sqrt{d_k}}$

则：
$$\text{Attn}^+ = \text{Softmax}(A - B)V$$
$$\text{Attn}^- = \text{Softmax}(A + B)V$$

差分注意力的优势：
1. **非对称性**：能够区分 $q > k$ 和 $q < k$ 的情况
2. **稳定性**：正负抵消减少了大值的影响
3. **信息保留**：保留了原始相似度信息

```python
def detailed_derivation():
    """详细推导"""
    
    # 假设
    # Query: [N, D]
    # Key: [M, D]
    # Value: [M, D]
    
    # 1. 原始相似度
    similarity = torch.matmul(Q, K.t()) / math.sqrt(D)  # [N, M]
    
    # 2. 差分项
    diff_term = torch.matmul(K, K.t()) / math.sqrt(D)  # [M, M]
    
    # 3. 正向注意力
    # A_minus = similarity - diff_term
    pos_scores = similarity.unsqueeze(1) - diff_term.unsqueeze(0)
    pos_attn = F.softmax(pos_scores, dim=-1)
    pos_out = torch.matmul(pos_attn, V)
    
    # 4. 负向注意力
    # A_plus = similarity + diff_term
    neg_scores = similarity.unsqueeze(1) + diff_term.unsqueeze(0)
    neg_attn = F.softmax(neg_scores, dim=-1)
    neg_out = torch.matmul(neg_attn, V)
    
    # 5. 最终输出
    output = pos_out - neg_out
    
    return output
```

### 3.2 梯度分析

差分注意力的梯度计算：

$$\frac{\partial L}{\partial q_i} = \frac{\partial L}{\partial out} \cdot \frac{\partial out}{\partial q_i}$$

其中：
- $\frac{\partial out}{\partial q_i} = \frac{\partial out^+}{\partial q_i} - \frac{\partial out^-}{\partial q_i}$

��减少了梯度消失，因为正负注意力可以相互抵消。

```python
def gradient_analysis():
```

## 4. PyTorch实现

### 4.1 完整实现

```python
class DifferentialAttentionModule(nn.Module):
    """差分注意力模块"""
    
    def __init__(
        self,
        dim,
        num_heads=8,
        qkv_bias=True,
        attn_drop=0.0,
        proj_drop=0.0
    ):
        super().__init__()
        
        self.num_heads = num_heads
        self.head_dim = dim // num_heads
        self.scale = self.head_dim ** -0.5
        
        self.qkv = nn.Linear(dim, dim * 3, bias=qkv_bias)
        self.attn_drop = nn.Dropout(attn_drop)
        self.proj = nn.Linear(dim, dim)
        self.proj_drop = nn.Dropout(proj_drop)
        
    def forward(self, x, return_attention=False):
        """
        参数:
            x: [B, N, D]
            return_attention: 是否返回注意力权重
            
        返回:
            output: [B, N, D]
            (optional) attention: [B, H, N, N]
        """
        B, N, D = x.shape
        H = self.num_heads
        
        # QKV投影
        qkv = self.qkv(x).reshape(B, N, 3, H, self.head_dim).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]  # 各自 [B, H, N, D_h]
        
        # ========== 差分注意力 ==========
        # 正向: Q - K
        q_pos = q - k
        # 负向: Q + K
        q_neg = q + k
        
        # 正向注意力
        attn_pos = torch.matmul(q_pos, k.transpose(-2, -1)) * self.scale
        attn_pos = attn_pos.softmax(dim=-1)
        attn_pos = self.attn_drop(attn_pos)
        out_pos = torch.matmul(attn_pos, v)
        
        # 负向注意力
        attn_neg = torch.matmul(q_neg, k.transpose(-2, -1)) * self.scale
        attn_neg = attn_neg.softmax(dim=-1)
        attn_neg = self.attn_drop(attn_neg)
        out_neg = torch.matmul(attn_neg, v)
        
        # 差分输出
        out = out_pos - out_neg
        
        # 重新reshape
        out = out.transpose(1, 2).reshape(B, N, D)
        out = self.proj(out)
        out = self.proj_drop(out)
        
        if return_attention:
            return out, attn_pos - attn_neg
        return out
```

### 4.2 Diff Transformer模型

```python
class DiffTransformer(nn.Module):
    """Diff Transformer"""
    
    def __init__(
        self,
        vocab_size,
        max_len=512,
        dim=512,
        num_heads=8,
        num_layers=6,
        mlp_ratio=4,
        dropout=0.1
    ):
        super().__init__()
        
        # 词嵌入
        self.token_embed = nn.Embedding(vocab_size, dim)
        self.pos_embed = nn.Parameter(torch.zeros(1, max_len, dim))
        
        # Transformer层
        self.layers = nn.ModuleList([
            DiffTransformerLayer(dim, num_heads, mlp_ratio, dropout)
            for _ in range(num_layers)
        ])
        
        self.norm = nn.LayerNorm(dim)
        
        # 分类头
        self.head = nn.Linear(dim, vocab_size)
        
        # 初始化
        nn.init.trunc_normal_(self.pos_embed, std=0.02)
        self.apply(self._init_weights)
        
    def _init_weights(self, m):
        if isinstance(m, nn.Linear):
            nn.init.trunc_normal_(m.weight, std=0.02)
            if m.bias is not None:
                nn.init.constant_(m.bias, 0)
        elif isinstance(m, nn.LayerNorm):
            nn.init.constant_(m.bias, 0)
            nn.init.constant_(m.weight, 1.0)
    
    def forward(self, x, mask=None):
        """
        参数:
            x: [B, N] 词索引
            mask: [B, N] 可选的mask
            
        返回:
            logits: [B, N, vocab_size]
        """
        B, N = x.shape
        
        # 嵌入
        x = self.token_embed(x) + self.pos_embed[:, :N]
        
        # 注意力掩码（可选）
        if mask is not None:
            # 创建causal mask
            causal_mask = torch.triu(
                torch.ones(N, N, device=x.device),
                diagonal=1
            ).bool()
        
        # Transformer层
        for layer in self.layers:
            x = layer(x)
        
        x = self.norm(x)
        
        # 分类
        logits = self.head(x)
        
        return logits
```

```python
class StandardTransformerLayer(nn.Module):
    """标准Transformer层（对比用）"""
    
    def __init__(self, dim, num_heads=8, mlp_ratio=4):
        super().__init__()
        
        self.norm1 = nn.LayerNorm(dim)
        self.attn = nn.MultiheadAttention(dim, num_heads, batch_first=True)
        self.norm2 = nn.LayerNorm(dim)
        self.mlp = nn.Sequential(
            nn.Linear(dim, dim * mlp_ratio),
            nn.GELU(),
            nn.Linear(dim * mlp_ratio, dim)
        )
        
    def forward(self, x, mask=None):
        # 注意力
        attn_out, _ = self.attn(x, x, x, attn_mask=mask)
        x = self.norm1(x + attn_out)
        
        # FFN
        x = self.norm2(x + self.mlp(x))
        
        return x
```

```python
def stable_training():
    """稳定训练"""
    
    # 模型
    model = DiffTransformer(
        vocab_size=50000,
        max_len=4096,
        dim=2048,
        num_heads=16,
        num_layers=24
    )
    
    optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4)
    
    # 训练循环
    for step in range(1000):
        # 模拟数据
        x = torch.randint(0, 50000, (4, 512))
        
        # 前向
        output = model(x)
        loss = F.cross_entropy(
            output.view(-1, 50000),
            x.view(-1)
        )
        
        # 反向
        optimizer.zero_grad()
        loss.backward()
        
        # 梯度裁剪
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        
        optimizer.step()
        
        if step % 100 == 0:
            print(f"Step {step}: Loss = {loss.item():.4f}")
```

## 6. 优缺点分析

### 6.1 优点

1. **稳定性高**：正负注意力抵消减少梯度爆炸
2. **表达能力强**：能够捕捉正负相关性
3. **计算量适中**：与标准注意力相当
4. **内存友好**：不需要额外内存

### 6.2 缺点

1. **实现复杂**：需要计算两路注意力
2. **参数量略多**：需要额外的投影
3. **效果不确定**：对于某些任务可能没有提升

### 6.3 适用场景

- 长序列建模
- 大模型训练
- 稳定训练需求

## 8. 手工代码实现

```python
class ManualDifferentialAttention:
    """手动实现差分注意力"""
    
    @staticmethod
    def compute_attention_scores(Q, K, temperature=1.0):
        """
        计算注意力分数
        
        参数:
            Q: [.., N, D]
            K: [.., M, D]
            temperature: 温度参数
            
        返回:
            pos_scores: 正向注意力分数
            neg_scores: 负向注意力分数
        """
        # 正向差分: Q - K
        Q_pos = Q.unsqueeze(-2) - K.unsqueeze(-3)
        
        # 负向差分: Q + K
        Q_neg = Q.unsqueeze(-2) + K.unsqueeze(-3)
        
        # 计算分数
        pos_scores = torch.matmul(Q_pos, K.unsqueeze(-1).transpose(-2, -1)).squeeze(-1) / temperature
        neg_scores = torch.matmul(Q_neg, K.unsqueeze(-1).transpose(-2, -1)).squeeze(-1) / temperature
        
        return pos_scores, neg_scores
    
    @staticmethod
    def apply_attention(attention_weights, V):
        """应用注意力"""
        return torch.matmul(attention_weights, V)
```

## 12. 学习总结

### 12.1 核心要点

1. **差分计算**：
   - 正向：Q - K
   - 负向：Q + K

2. **差分输出**：
   - Attention⁺ - Attention⁻

3. **优势**：
   - 更稳定
   - 更强表达
