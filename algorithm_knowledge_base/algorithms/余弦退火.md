# 余弦退火学习率调度器学习文档

## 1. 算法基础认知

余弦退火（Cosine Annealing）是一种常用的学习率调度策略，最初由Loshchilov和Hutter在2017年的论文中提出。这种调度器模拟了余弦函数的变化规律，将学习率从初始值逐渐降低到接近零，理论上能够更好地探索损失函数 landscape，找到更优的极小值点。

学习率是深度学习训练中最重要的超参数之一：
1. **学习率过大**：训练不稳定，可能跳过最优解
2. **学习率过小**：收敛太慢，容易陷入局部极小值
3. **合适的学习率调度**：能够平衡探索和收敛

与传统的step decay（阶跃下降）和exponential decay（指数下降）相比，余弦退火有以下优势：
- 更平滑的下降曲线
- 理论上有更好的收敛性质
- 在训练后期能更精细地搜索最优解

## 2. 核心原理

### 2.1 基本余弦退火

基本余弦退火的数学公式：

$$\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})\left(1 + \cos\left(\frac{T_{curr}}{T_{max}}\pi\right)\right)$$

其中：
- $\eta_t$：当前学习率
- $\eta_{\max}$：最大学习率（初始学习率）
- $\eta_{\min}$：最小学习率（通常设为0或一个很小的值）
- $T_{curr}$：当前迭代次数
- $T_{max}$：总迭代次数（或一个周期内的迭代次数）
- $\cos$：余弦函数

```python
import numpy as np
import matplotlib.pyplot as plt

def cosine_annealing_schedule(
    T_cur: int,
    T_max: int,
    eta_max: float = 1e-3,
    eta_min: float = 0
) -> float:
    """
    余弦退火学习率计算
    
    参数:
        T_cur: 当前迭代次数
        T_max: 总迭代次数
        eta_max: 最大学习率
        eta_min: 最小学习率
        
    返回:
        eta: 当前学习率
    """
    return eta_min + (eta_max - eta_min) * (1 + np.cos(np.pi * T_cur / T_max)) / 2


def plot_cosine_annealing():
    """绘制余弦退火曲线"""
    T_max = 100000
    iterations = np.arange(T_max + 1)
    
    # 计算学习率
    lr_values = [
        cosine_annealing_schedule(i, T_max, eta_max=1e-3, eta_min=0)
        for i in iterations
    ]
    
    plt.figure(figsize=(10, 4))
    plt.plot(iterations, lr_values)
    plt.xlabel('Iteration')
    plt.ylabel('Learning Rate')
    plt.title('Cosine Annealing Schedule')
    plt.grid(True)
    plt.show()


def compare_schedulers():
    """比较不同的学习率调度策略"""
    T_max = 100000
    iterations = np.arange(T_max + 1)
    
    # 1. 余弦退火
    cosine_lr = [
        cosine_annealing_schedule(i, T_max, eta_max=1e-3, eta_min=0)
        for i in iterations
    ]
    
    # 2. 阶跃下降
    step_lr = []
    for i in iterations:
        if i < 30000:
            lr = 1e-3
        elif i < 60000:
            lr = 1e-4
        else:
            lr = 1e-5
        step_lr.append(lr)
    
    # 3. 指数下降
    exp_lr = [1e-3 * (0.9999 ** i) for i in iterations]
    
    # 绘制
    plt.figure(figsize=(12, 4))
    
    plt.subplot(1, 3, 1)
    plt.plot(iterations, cosine_lr)
    plt.title('Cosine Annealing')
    
    plt.subplot(1, 3, 2)
    plt.plot(iterations, step_lr)
    plt.title('Step Decay')
    
    plt.subplot(1, 3, 3)
    plt.plot(iterations, exp_lr)
    plt.title('Exponential Decay')
    
    plt.tight_layout()
    plt.show()
```

### 2.2 带Warm Restarts的余弦退火

带Warm Restarts的余弦退火（SGDR - Stochastic Gradient with Warm Restarts）在每个周期结束时不是直接降到最小值，而是重启到��大学习率，然后再次下降。

$$\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})\left(1 + \cos\left(\frac{T_{cur}}{T_{i}}\pi\right)\right)$$

其中 $T_i$ 是第i个周期的迭代次数。

```python
def cosine_annealing_with_restarts(
    T_cur: int,
    T_max: int,
    num_cycles: int = 4,
    eta_max: float = 1e-3,
    eta_min: float = 0
) -> float:
    """
    带Warm Restarts的余弦退火
    
    参数:
        T_cur: 当前迭代次数
        T_max: 总迭代次数
        num_cycles: 周期数
        eta_max: 最大学习率
        eta_min: 最小学习率
        
    返回:
        eta: 当前学习率
    """
    # 计算当前周期
    cycle_length = T_max / num_cycles
    cycle = int(T_cur / cycle_length)
    
    # 周期内迭代
    cycle_progress = T_cur % cycle_length
    
    # 计算学习率
    return eta_min + (eta_max - eta_min) * (
        1 + np.cos(np.pi * cycle_progress / cycle_length)
    ) / 2


def plot_annealing_with_restarts():
    """绘制带Restarts的余弦退火"""
    T_max = 100000
    num_cycles = 4
    
    iterations = np.arange(T_max + 1)
    
    lr_values = [
        cosine_annealing_with_restarts(i, T_max, num_cycles, eta_max=1e-3, eta_min=0)
        for i in iterations
    ]
    
    plt.figure(figsize=(10, 4))
    plt.plot(iterations, lr_values)
    plt.xlabel('Iteration')
    plt.ylabel('Learning Rate')
    plt.title('Cosine Annealing with Warm Restarts')
    plt.grid(True)
    plt.show()
```

### 2.3 数学推导

余弦退火的理论基础：

1. **为什么使用余弦？**
   - 余弦函数在 $[0, \pi]$ 区间单调递减，且变化率在两端小、中间大
   - 这符合训练的需求：前期快速下降，后期精细调整

2. **为什么需要Restarts？**
   - 帮助跳出局部极小值
   - 在不同的 loss landscape 区域搜索

3. **与模拟退火的关系**
   - 类似于模拟退火的温度调度
   - 余弦函数可以看作是温度的余弦衰减

## 3. PyTorch实现

### 3.1 基本实现

```python
import torch
from torch.optim.lr_scheduler import _LRScheduler
import math

class CosineAnnealingLR(_LRScheduler):
    """
    余弦退火学习率调度器
    """
    
    def __init__(
        self,
        optimizer,
        T_max,
        eta_min=0,
        last_epoch=-1
    ):
        """
        参数:
            optimizer: 优化器
            T_max: 最大迭代次数
            eta_min: 最小学习率
            last_epoch: 上一个epoch（用于恢复训练）
        """
        self.T_max = T_max
        self.eta_min = eta_min
        super().__init__(optimizer, last_epoch)
    
    def get_lr(self):
        """计算当前学习率"""
        return [
            self.eta_min + (base_lr - self.eta_min) *
            (1 + math.cos(math.pi * self.last_epoch / self.T_max)) / 2
            for base_lr in self.base_lrs
        ]


class CosineAnnealingWarmRestarts(_LRScheduler):
    """
    带Warm Restarts的余弦退火
    """
    
    def __init__(
        self,
        optimizer,
        T_max,
        T_mult=1,
        eta_min=0,
        last_epoch=-1
    ):
        """
        参数:
            optimizer: 优化器
            T_max: 第一个周期的长度
            T_mult: 周期长度的乘法因子（默认1）
            eta_min: 最小学习率
            last_epoch: 上一个epoch
        """
        self.T_max = T_max
        self.T_mult = T_mult
        self.eta_min = eta_min
        self.T_cur = last_epoch
        super().__init__(optimizer, last_epoch)
    
    def get_lr(self):
        """计算当前��习率"""
        if self.T_cur == -1:
            return self.base_lrs
        
        T_i = self.T_max
        while self.T_cur >= T_i:
            self.T_cur -= T_i
            T_i *= self.T_mult
        
        return [
            self.eta_min + (base_lr - self.eta_min) *
            (1 + math.cos(math.pi * self.T_cur / T_i)) / 2
            for base_lr in self.base_lrs
        ]
    
    def step(self, epoch=None):
        """更新学习率"""
        if epoch is None:
            epoch = self.last_epoch + 1
        self.T_cur = epoch
        self.last_epoch = epoch
        
        for param_group, lr in zip(self.optimizer.param_groups, self.get_lr()):
            param_group['lr'] = lr
```

### 3.2 更灵活的版本

```python
class FlexibleCosineAnnealingLR(_LRScheduler):
    """
    灵活的余弦退火调度器
    """
    
    def __init__(
        self,
        optimizer,
        T_max,
        warmup_epochs=0,
        warmup_start_lr=0,
        eta_min=0,
        last_epoch=-1,
        decay_rate=0.5,
        decay_epochs=None
    ):
        """
        参数:
            optimizer: 优化器
            T_max: 最大迭代次数
            warmup_epochs: warmup epoch数
            warmup_start_lr: warmup起始学习率
            eta_min: 最小学习率
            last_epoch: 上一个epoch
            decay_rate: 阶跃下降的衰减率
            decay_epochs: 阶跃下降的epoch列表
        """
        self.T_max = T_max
        self.warmup_epochs = warmup_epochs
        self.warmup_start_lr = warmup_start_lr
        self.eta_min = eta_min
        self.decay_rate = decay_rate
        self.decay_epochs = decay_epochs or []
        
        super().__init__(optimizer, last_epoch)
    
    def get_lr(self):
        """计算当前学习率"""
        if self.last_epoch < self.warmup_epochs:
            # Warmup阶段
            alpha = self.last_epoch / self.warmup_epochs
            return [
                self.warmup_start_lr + (base_lr - self.warmup_start_lr) * alpha
                for base_lr in self.base_lrs
            ]
        
        # 主阶段
        T_cur = self.last_epoch - self.warmup_epochs
        T_max = self.T_max - self.warmup_epochs
        
        # 计算余弦退火
        lr = self.eta_min + (
            self.base_lrs[0] - self.eta_min
        ) * (1 + math.cos(math.pi * T_cur / T_max)) / 2
        
        # 应用阶跃衰减
        for decay_epoch in self.decay_epochs:
            if self.last_epoch >= decay_epoch:
                lr *= self.decay_rate
        
        return [lr] * len(self.base_lrs)


class OneCycleLR(_LRScheduler):
    """
    One Cycle学习率调度器
    """
    
    def __init__(
        self,
        optimizer,
        max_lr,
        total_steps,
        pct_start=0.3,
        div_factor=25,
        final_div_factor=1e4,
        last_epoch=-1
    ):
        """
        参数:
            optimizer: 优化器
            max_lr: 最大学习率
            total_steps: 总步数
            pct_start: warmup比例
            div_factor: warmup除数
            final_div_factor: 最终除数
            last_epoch: 上一个epoch
        """
        self.max_lr = max_lr
        self.total_steps = total_steps
        self.pct_start = pct_start
        self.div_factor = div_factor
        self.final_div_factor = final_div_factor
        
        super().__init__(optimizer, last_epoch)
    
    def get_lr(self):
        """计算当前学习率"""
        step = self.last_epoch
        
        # Warmup阶段
        if step < self.total_steps * self.pct_start:
            pct = step / (self.total_steps * self.pct_start)
            return [
                self.max_lr * pct / self.div_factor
                + base_lr * (1 - pct / self.div_factor)
                for base_lr in self.base_lrs
            ]
        
        # Annealing阶段
        pct = (step - self.total_steps * self.pct_start) / (
            self.total_steps * (1 - self.pct_start)
        )
        
        # 余弦退火
        cos_anneal = (1 + math.cos(math.pi * pct)) / 2
        
        # 计算学习率
        return [
            self.max_lr * cos_anneal / self.final_div_factor
            + base_lr * (1 - cos_anneal / self.final_div_factor)
            for base_lr in self.base_lrs
        ]
```

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset

def training_example():
    """训练示例"""
    
    # 创建模型
    model = nn.Sequential(
        nn.Linear(784, 256),
        nn.ReLU(),
        nn.Dropout(0.2),
        nn.Linear(256, 128),
        nn.ReLU(),
        nn.Dropout(0.2),
        nn.Linear(128, 10)
    )
    
    # 创建数据
    X = torch.randn(10000, 784)
    y = torch.randint(0, 10, (10000,))
    dataset = TensorDataset(X, y)
    dataloader = DataLoader(dataset, batch_size=64)
    
    # 优化器
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
    
    # 调度器 - Cosine Annealing
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
        optimizer,
        T_max=100,
        eta_min=1e-6
    )
    
    # 训练循环
    model.train()
    for epoch in range(100):
        for batch_X, batch_y in dataloader:
            # 前向传播
            output = model(batch_X)
            loss = nn.functional.cross_entropy(output, batch_y)
            
            # 反向传播
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
        
        # 更新学习率
        scheduler.step()
        
        # 打印学习率
        if epoch % 10 == 0:
            lr = optimizer.param_groups[0]['lr']
            print(f"Epoch {epoch}: lr = {lr:.6f}")
```

### 3.4 OneCycleLR实现

```python
import math

class OneCycleLRScheduler:
    """
    One Cycle学习率调度（手动实现）
    """
    
    def __init__(
        self,
        optimizer,
        max_lr,
        total_steps,
        momentum_range=(0.85, 0.95)
    ):
        self.optimizer = optimizer
        self.max_lr = max_lr
        self.total_steps = total_steps
        self.momentum_range = momentum_range
        self.step_count = 0
    
    def step(self):
        """更新学习率"""
        pct = self.step_count / self.total_steps
        
        if pct < 0.3:
            # Warmup
            pct = pct / 0.3
            lr = self.max_lr * pct / 25  # div_factor
        else:
            # Cosine annealing
            pct = (pct - 0.3) / 0.7
            lr = self.max_lr * (1 + math.cos(math.pi * pct)) / 2 / 10000
        
        # 更新学习率
        for param_group in self.optimizer.param_groups:
            param_group['lr'] = lr
        
        self.step_count += 1
        
        return lr


def train_with_one_cycle():
    """使用OneCycle训练"""
    
    model = nn.Linear(10, 2)
    optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
    
    scheduler = OneCycleLRScheduler(
        optimizer,
        max_lr=0.01,
        total_steps=1000
    )
    
    x = torch.randn(100, 10)
    y = torch.randint(0, 2, (100,))
    
    for i in range(1000):
        optimizer.zero_grad()
        loss = nn.functional.cross_entropy(model(x), y)
        loss.backward()
        scheduler.step()
        optimizer.step()
```

## 4. 数学公式与推导

### 4.1 理论基础

余弦退火的数学原理：

1. **损失函数 landscape**
   - 深度神经网络的损失函数通常是非凸的
   - 存在多个局部极小值和鞍点
   - 学习率调度帮助找到更好的极小值

2. **学习率与收敛**
   - 大学习率：帮助跳出不良的局部极小值
   - 小学习率：精细搜索
   - 余弦退火平滑地过渡

3. **为什么是余弦？**
   - 余弦在 $[0, \pi]$ 的积分更好
   - 变化率适合训练过程
   - 可以证明收敛性

### 4.2 与其他调度器的比较

| 调度器 | 优点 | 缺点 |
|--------|------|------|
| Step Decay | 简单 | 可能突变 |
| Exponential | 平滑 | 下降太快 |
| Cosine | 理论好 | 实现复杂 |
| OneCycle | 最优结果 | 需要调参 |

```python
def compare_schedulers():
    """比较调度器"""
    
    schedules = {}
    
    # Step Decay
    lr_step = []
    for i in range(100):
        if i < 30:
            lr = 1e-3
        elif i < 60:
            lr = 1e-4
        else:
            lr = 1e-5
        lr_step.append(lr)
    schedules['step'] = lr_step
    
    # Cosine
    lr_cosine = [
        1e-6 + (1e-3 - 1e-6) * (1 + np.cos(np.pi * i / 100)) / 2
        for i in range(100)
    ]
    schedules['cosine'] = lr_cosine
    
    # OneCycle
    lr_onecycle = []
    for i in range(100):
        pct = i / 100
        if pct < 0.3:
            pct = pct / 0.3
            lr = 1e-3 * pct / 25
        else:
            pct = (pct - 0.3) / 0.7
            lr = 1e-3 * (1 + np.cos(np.pi * pct)) / 2 / 10000
        lr_onecycle.append(max(lr, 1e-6))
    schedules['onecycle'] = lr_onecycle
    
    return schedules
```
