# 多头注意力 (Multi-Head Attention) 学习文档

## 1. 算法基础认知

### 1.1 定义

多头注意力（Multi-Head Attention, MHA）是 Transformer 架构的核心组件，由 Vaswani 等人在 2017 年提出。它通过将注意力机制并行运行多次（多头），使模型能够同时关注来自不同表示子空间的信息。

**数学定义：**

$$
\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h) W^O
$$

其中每个注意力头为：

$$
\text{head}_i = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V) = \text{softmax}\left(\frac{Q W_i^Q (K W_i^K)^\top}{\sqrt{d_k}}\right) V W_i^V
$$

### 1.2 直观类比

**多眼观察类比：**
- 单头注意力 = 一个人用一只眼睛观察
- 多头注意力 = 一个人用多只眼睛同时观察，每个眼睛关注不同的特征
- 比如：一只眼睛看颜色，一只眼睛看形状，一只眼睛看运动方向

### 1.3 为什么需要多头

**单头注意力的局限：**
- 只能捕获一种类型的关系
- 表达能力有限

**多头注意力的优势：**
- 不同头可以学习不同的注意力模式
- 增强模型表达能力
- 稳定训练

## 2. 核心原理

### 2.1 Scaled Dot-Product Attention

**标准注意力公式：**

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

**为什么要除以 $\sqrt{d_k}$：**

设 $q, k \in \mathbb{R}^{d_k}$ 服从均值为 0、方差为 1 的独立分布，则：

$$
q \cdot k = \sum_{i=1}^{d_k} q_i k_i
$$

根据独立随机变量的方差叠加：
$$
\text{Var}(q \cdot k) = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = d_k \cdot \text{Var}(q_i) \cdot \text{Var}(k_i) = d_k
$$

因此点积的方差与 $d_k$ 成正比，需要缩放 $\sqrt{d_k}$ 来保持梯度的稳定。

### 2.2 多头机制推导

**输入变换：**

对于输入 $X \in \mathbb{R}^{L \times d_{model}}$：
$$
Q_i = X W_i^Q, \quad K_i = X W_i^K, \quad V_i = X W_i^V
$$

其中 $W_i^Q, W_i^K, W_i^V \in \mathbb{R}^{d_{model} \times d_k}$，$d_k = d_{model} / h$

**计算每个头：**
$$
\text{head}_i = \text{Attention}(Q_i, K_i, V_i)
$$

**合并输出：**
$$
\text{MultiHead}(X) = \text{Concat}(\text{head}_1, ..., \text{head}_h) W^O
$$

其中 $W^O \in \mathbb{R}^{hd_v \times d_{model}}$

**完整流程图：**

```
输入 X [L, d_model]
    │
    ├──→ W_Q₁ → Q₁ [L, d_k] ──┐
    ├──→ W_Q₂ → Q₂ [L, d_k] ──┤
    └──→ ...                  │
                               │ (h 个头并行计算)
    ├──→ W_K₁ → K₁ [L, d_k] ──┤
    ├──→ W_K₂ → K₂ [L, d_k] ──┤
    └──→ ...                  │
                               ▼
    ├──→ W_V₁ → V₁ [L, d_v] ──┤→ Attention → head₁
    ├──→ W_V₂ → V₂ [L, d_v] ──┤→ Attention → head₂
    └──→ ...                  │
                               ▼
                         Concat [L, hd_v]
                               │
                               ▼
                         W_O [hd_v, d_model]
                               │
                               ▼
                         Output [L, d_model]
```

### 2.3 不同注意力类型

| 类型 | 说明 | 公式 |
|------|------|------|
| **Self-Attention** | Q=K=V=X | $\text{Attention}(X, X, X)$ |
| **Encoder-Decoder** | Q=解码器, K,V=编码器 | $\text{Attention}(X_{dec}, X_{enc}, X_{enc})$ |
| **Cross-Attention** | 自定义 Q, K, V | $\text{Attention}(Q, K, V)$ |

### 3.2 手写实现（完整）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class MultiHeadAttention(nn.Module):
    """多头注意力机制的手写实现"""
    
    def __init__(self, d_model, num_heads, dropout=0.1):
        super().__init__()
        assert d_model % num_heads == 0, "d_model 必须能被 num_heads 整除"
        
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads  # 每个头的维度
        
        # QKV 投影矩阵
        self.W_Q = nn.Linear(d_model, d_model)
        self.W_K = nn.Linear(d_model, d_model)
        self.W_V = nn.Linear(d_model, d_model)
        
        # 输出投影
        self.W_O = nn.Linear(d_model, d_model)
        
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, query, key, value, mask=None):
        """
        参数：
            query, key, value: [batch, seq_len, d_model]
            mask: [batch, seq_len, seq_len] 或 [batch, 1, seq_len, seq_len]
        返回：
            output: [batch, seq_len, d_model]
            attention_weights: [batch, num_heads, seq_len, seq_len]
        """
        batch_size = query.size(0)
        
        # 1. QKV 投影
        Q = self.W_Q(query)  # [B, L, d_model]
        K = self.W_K(key)
        V = self.W_V(value)
        
        # 2. 分多头：reshape 到 [B, num_heads, seq_len, d_k]
        Q = Q.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        
        # 3. Scaled Dot-Product Attention
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        # 4. Mask（可选）
        if mask is not None:
            # 处理不同维度的 mask
            if mask.dim() == 2:
                # [seq_len, seq_len] -> [1, 1, seq_len, seq_len]
                mask = mask.unsqueeze(0).unsqueeze(0)
            elif mask.dim() == 3:
                # [batch, seq_len, seq_len] -> [batch, 1, seq_len, seq_len]
                mask = mask.unsqueeze(1)
            scores = scores.masked_fill(mask == 0, float('-inf'))
        
        # 5. Softmax
        attention_weights = F.softmax(scores, dim=-1)
        attention_weights = self.dropout(attention_weights)
        
        # 6. 加权求和
        context = torch.matmul(attention_weights, V)  # [B, num_heads, L, d_k]
        
        # 7. 合并多头：transpose -> view
        context = context.transpose(1, 2).contiguous()  # [B, L, num_heads, d_k]
        context = context.view(batch_size, -1, self.d_model)  # [B, L, d_model]
        
        # 8. 输出投影
        output = self.W_O(context)
        
        return output, attention_weights

# 测试
mha = MultiHeadAttention(d_model=512, num_heads=8)
x = torch.randn(4, 10, 512)
output, attn = mha(x, x, x)
print(f"Output shape: {output.shape}")
print(f"Attention shape: {attn.shape}")
```

### 3.3 Self-Attention 完整示例

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class SelfAttentionBlock(nn.Module):
    """带残差和 LayerNorm 的 Self-Attention 块"""
    
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super().__init__()
        self.attention = MultiHeadAttention(d_model, num_heads, dropout)
        self.norm1 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout),
        )
        self.norm2 = nn.LayerNorm(d_model)
    
    def forward(self, x, mask=None):
        # Pre-LN 风格（更稳定）
        # Self-Attention + 残差
        x_norm = self.norm1(x)
        attn_out, _ = self.attention(x_norm, x_norm, x_norm, mask)
        x = x + attn_out
        
        # FFN + 残差
        x_norm = self.norm2(x)
        ffn_out = self.ffn(x_norm)
        x = x + ffn_out
        
        return x

# 测试
block = SelfAttentionBlock(d_model=512, num_heads=8, d_ff=2048)
x = torch.randn(4, 10, 512)
out = block(x)
print(f"Input: {x.shape}, Output: {out.shape}")
```

### 4.1 注意力权重可视化

```python
import torch
import matplotlib.pyplot as plt
import numpy as np

def visualize_attention_patterns():
    """可视化不同头学习到的注意力模式"""
    
    torch.manual_seed(42)
    
    # 创建模型
    mha = MultiHeadAttention(d_model=64, num_heads=8)
    
    # 输入序列（模拟自然语言）
    x = torch.randn(1, 16, 64)  # batch=1, seq_len=16, d_model=64
    
    # 添加一些结构：让某些位置更相关
    x[0, 5, :] += 2.0  # 第5个位置更重要
    x[0, 6, :] += 2.0  # 与第5个位置相关
    
    # 前向传播
    with torch.no_grad():
        _, attention_weights = mha(x, x, x)
    
    # attention_weights: [batch, num_heads, seq_len, seq_len]
    attention_weights = attention_weights[0].numpy()  # [num_heads, seq_len, seq_len]
    
    # 绘图：显示每个头的注意力模式
    fig, axes = plt.subplots(2, 4, figsize=(16, 8))
    axes = axes.flatten()
    
    for i in range(8):
        ax = axes[i]
        im = ax.imshow(attention_weights[i], cmap='viridis', aspect='auto')
        ax.set_title(f'Head {i+1}')
        ax.set_xlabel('Key Position')
        ax.set_ylabel('Query Position')
        plt.colorbar(im, ax=ax)
    
    plt.suptitle('Multi-Head Attention Patterns', fontsize=14)
    plt.tight_layout()
    plt.savefig('mha_patterns.png', dpi=150)
    plt.show()
    
    # 打印某些头的关注重点
    print("\n不同头对位置的关注程度：")
    for i in range(3):  # 前3个头
        print(f"Head {i+1} 对位置5的关注:", attention_weights[i, :, 5].mean())

visualize_attention_patterns()
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

def causal_mask_attention():
    """演示因果 Mask（用于 Decoder）"""
    
    batch_size = 2
    seq_len = 8
    d_model = 64
    num_heads = 4
    
    mha = MultiHeadAttention(d_model, num_heads)
    
    # 创建因果 Mask（上三角为 0）

    mask = ~mask  # 转换为 True（可见）/ False（不可见）
```

### 4.3 Cross-Attention 示例

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

def cross_attention_example():
    """Cross-Attention 示例：Query 来自 Decoder，K/V 来自 Encoder"""
    
    class EncoderDecoderAttention(nn.Module):
        def __init__(self, d_model, num_heads):
            super().__init__()
            self.mha = MultiHeadAttention(d_model, num_heads)
            # 或者使用 PyTorch 内置
            self.mha_pytorch = nn.MultiheadAttention(d_model, num_heads, batch_first=True)
        
        def forward(self, decoder_hidden, encoder_hidden, mask=None):
            # decoder_hidden 作为 Query
            # encoder_hidden 作为 Key 和 Value
            output, _ = self.mha(decoder_hidden, encoder_hidden, encoder_hidden, mask)
            return output
    
    # 测试
    model = EncoderDecoderAttention(d_model=512, num_heads=8)
    
    # Encoder 输出
    encoder_output = torch.randn(2, 20, 512)  # [batch, enc_seq, d_model]
    
    # Decoder 当前 hidden state
    decoder_hidden = torch.randn(2, 10, 512)  # [batch, dec_seq, d_model]
    
    output = model(decoder_hidden, encoder_output)
    print(f"Encoder output: {encoder_output.shape}")
    print(f"Decoder hidden: {decoder_hidden.shape}")
    print(f"Cross attention output: {output.shape}")

cross_attention_example()
```

## 5. 应用场景
### 5.1 典型应用（5个）

**应用1：Transformer编码器/解码器**
- 案例描述：多头注意力是Transformer的核心组件，编码器中使用双向自注意力，解码器中使用掩码自注意力和交叉注意力。
- 技术特点：多个头分别捕捉不同的语义/语法关系，拼接后通过输出投影整合。
- 为什么适合：不同头可以关注不同的上下文模式，提升特征表达能力。

**应用2：机器翻译**
- 案例描述：在Transformer的编码器-解码器架构中，多头注意力用于源语言内部建模、目标语言内部建模以及源-目标语言对齐。
- 技术特点：交叉注意力中，解码器的Query与编码器的Key/Value计算注意力，实现源-目标对齐。
- 为什么适合：多头可以捕捉不同层次的对齐关系（如词级、短语级）。

**应用3：文本分类（BERT）**
- 案例描述：BERT使用多头自注意力（12/16个头）编码文本，通过[CLS] token或池化得到句向量用于分类。
- 技术特点：双向注意力，每个头可以关注不同的上下文信息。
- 为什么适合：多头能捕捉文本中的多种语义关系，提升分类准确性。

**应用4：图像分类（ViT）**
- 案例描述：Vision Transformer将图像分成patch，每个patch作为一个token，使用多头自注意力捕捉patch间的关系。
- 技术特点：每个头可以关注图像的不同区域（如局部纹理、全局结构）。
- 为什么适合：多头能同时捕捉局部和全局特征，替代传统CNN。

**应用5：多模态融合**
- 案例描述：在多模态模型（如DeepSeek-VL2）中，多头注意力用于融合图像patch和文本token的特征。
- 技术特点：图像和文本的token一起输入Transformer，通过多头自注意力实现跨模态交互。
- 为什么适合：不同头可以关注不同的模态组合（如文本-图像、图像-图像）。

### 5.2 适用数据特征
- 特征类型：序列数据（文本、图像patch、多模态token）
- 数据规模：适合中大规模数据（万级到亿级样本）
- 噪声容忍度：中等（对标注噪声较敏感）
- 序列长度：适合中等长度（<4096 tokens，长序列需优化）

### 5.3 不适用场景
- 极短序列（<10 tokens）：单头注意力已足够
- 计算资源极度受限：多头增加计算量（头数×单头复杂度）
- 需要严格可解释性：多头权重难以直观解释

## 6. 优缺点分析
### 6.1 优点（4个）

1. **捕捉多样化特征**：不同头可以学习不同的注意力模式
   - 在什么条件下成立：多头数≥8时
   - 技术细节：每个头独立计算注意力，捕捉不同的语义/语法关系

2. **提升模型表达能力**：多头拼接增加了特征维度，增强非线性
   - 在什么条件下成立：数据充足时
   - 技术细节：输出投影矩阵整合多头信息，增加模型容量

3. **并行计算高效**：每个头的计算可并行，训练速度快
   - 在什么条件下成立：使用GPU训练时
   - 技术细节：多头计算可通过张量重塑批量处理

4. **适应不同任务需求**：不同头可以关注不同类型的依赖
   - 在什么条件下成立：任务需要多种特征时（如语法+语义）
   - 技术细节：某些头可能关注局部上下文，某些关注全局依赖

### 6.2 缺点（3个）

1. **计算量增加**：多头数增加会导致计算量和参数量上升
   - 问题场景：头数过多（>32）导致显存溢出
   - 解决思路：减少头数、使用稀疏注意力、使用MLA（多头潜在注意力）

2. **参数量增加**：输出投影矩阵维度为d_model×d_model
   - 问题场景：模型需轻量化时
   - 解决思路：使用低秩分解、分组查询注意力（GQA）、多头潜在注意力（MLA）

3. **头之间可能冗余**：不同头可能学习到相似的注意力模式
   - 问题场景：头数过多但数据不足时
   - 解决思路：使用头剪枝、稀疏激活（如MoE多头）

### 6.3 与同类算法对比
| 维度 | 多头注意力 | 单头注意力 | 分组查询注意力（GQA） |
|------|-----------|----------|----------------------|
| 特征多样性 | ⭐⭐⭐⭐⭐ | ⭐（单一模式） | ⭐⭐⭐（分组多样） |
| 计算量 | ⭐⭐⭐（头数×单头） | ⭐（最小） | ⭐⭐（分组减少） |
| 参数量 | ⭐⭐⭐（输出投影大） | ⭐（最小） | ⭐⭐（减少投影） |
| 适用场景 | 大模型、复杂任务 | 小模型、简单任务 | 推理效率优先 |

**选择建议**：
- 选择多头注意力：大模型、复杂任务、需要高表达能力
- 选择单头注意力：小模型、简单任务、资源受限
- 选择GQA：推理效率优先、保持多头表达能力

### 7.2 完整代码示例（PyTorch原生多头注意力）
```python
"""
多头注意力 调库实现
数据集：使用内置的序列数据
目标：演示多头注意力的基本使用
"""

import torch
import torch.nn as nn
import matplotlib.pyplot as plt
import seaborn as sns

class MultiHeadAttention(nn.Module):
    """多头注意力实现"""
    def __init__(self, d_model, n_heads, dropout=0.1):
        super().__init__()
        assert d_model % n_heads == 0, "d_model必须能被n_heads整除"
        
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        
        # QKV投影矩阵
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        
        # 输出投影
        self.W_o = nn.Linear(d_model, d_model)
        
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, Q, K, V, mask=None):
        """
        Args:
            Q: 查询，shape (batch, seq_len, d_model)
            K: 键，shape (batch, seq_len, d_model)
            V: 值，shape (batch, seq_len, d_model)
            mask: 注意力掩码，shape (batch, 1, seq_len, seq_len)
        Returns:
            output: 输出，shape (batch, seq_len, d_model)
            attn_weights: 注意力权重，shape (batch, n_heads, seq_len, seq_len)
        """
        batch_size, seq_len, _ = Q.shape
        
        # 线性投影
        Q = self.W_q(Q)  # (batch, seq_len, d_model)
        K = self.W_k(K)
        V = self.W_v(V)
        
        # 重塑为多头：(batch, seq_len, n_heads, d_k) -> (batch, n_heads, seq_len, d_k)
        Q = Q.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        
        # 缩放点积注意力
        scores = torch.matmul(Q, K.transpose(-2, -1)) / (self.d_k ** 0.5)
        
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        
        attn_weights = torch.softmax(scores, dim=-1)
        attn_weights = self.dropout(attn_weights)
        
        # 加权求和
        context = torch.matmul(attn_weights, V)  # (batch, n_heads, seq_len, d_k)
        
        # 拼接多头：(batch, n_heads, seq_len, d_k) -> (batch, seq_len, d_model)
        context = context.transpose(1, 2).contiguous().view(batch_size, seq_len, self.d_model)
        
        # 输出投影
        output = self.W_o(context)
        
        return output, attn_weights
```

```python
"""
多头注意力 手工实现
仅依赖NumPy，从零实现多头注意力
"""

import numpy as np

class MultiHeadAttentionManual:
    """手工实现多头注意力"""
    
    def __init__(self, d_model, n_heads):
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        
        # 初始化QKV投影矩阵（简化：随机初始化）
        self.W_q = np.random.randn(d_model, d_model) * 0.01
        self.W_k = np.random.randn(d_model, d_model) * 0.01
        self.W_v = np.random.randn(d_model, d_model) * 0.01
        self.W_o = np.random.randn(d_model, d_model) * 0.01
        
    def softmax(self, x):
        """softmax函数"""
        x_max = np.max(x, axis=-1, keepdims=True)
        exp_x = np.exp(x - x_max)
        return exp_x / np.sum(exp_x, axis=-1, keepdims=True)
    
    def forward(self, Q, K, V):
        """
        Args:
            Q, K, V: shape (batch, seq_len, d_model)
        Returns:
            output: shape (batch, seq_len, d_model)
            attn_weights: shape (batch, n_heads, seq_len, seq_len)
        """
        batch, seq_len, _ = Q.shape
        
        # 线性投影
        Q_proj = np.dot(Q, self.W_q)  # (batch, seq_len, d_model)
        K_proj = np.dot(K, self.W_k)
        V_proj = np.dot(V, self.W_v)
        
        # 重塑为多头
        Q_proj = Q_proj.reshape(batch, seq_len, self.n_heads, self.d_k).transpose(0, 2, 1, 3)
        K_proj = K_proj.reshape(batch, seq_len, self.n_heads, self.d_k).transpose(0, 2, 1, 3)
        V_proj = V_proj.reshape(batch, seq_len, self.n_heads, self.d_k).transpose(0, 2, 1, 3)
        
        # 缩放点积注意力
        scores = np.matmul(Q_proj, K_proj.transpose(0, 1, 3, 2)) / (self.d_k ** 0.5)
        attn_weights = self.softmax(scores)
        
        # 加权求和
        context = np.matmul(attn_weights, V_proj)
        
        # 拼接多头
        context = context.transpose(0, 2, 1, 3).reshape(batch, seq_len, self.d_model)
        
        # 输出投影
        output = np.dot(context, self.W_o)
        
        return output, attn_weights
```

## 11. 常见问题与易错点
### 11.1 数据层面常见错误
**错误1：d_model不能被n_heads整除**
- **现象**：AssertionError或输出形状错误
- **原因**：多头拆分时每个头的维度d_k = d_model / n_heads必须为整数
- **解决方案**：
```python
# 确保d_model是n_heads的整数倍
d_model = 512
n_heads = 8  # 512 / 8 = 64，合法
assert d_model % n_heads == 0, "d_model必须能被n_heads整除"
```

**错误2：序列长度不一致未正确处理**
- **现象**：训练或推理报错（shape不匹配）
- **原因**：未使用padding+attention mask处理不同长度的序列
- **解决方案**：
```python
# 创建attention mask（1表示真实token，0表示padding）
attention_mask = (input_ids != padding_token_id).unsqueeze(1).unsqueeze(2)
# 在注意力计算时应用mask
scores = scores.masked_fill(attention_mask == 0, -1e9)
```

### 11.2 模型层面常见错误
**错误1：梯度消失/爆炸**
- **现象**：损失为NaN或无穷大，模型参数变成NaN
- **原因**：层数过深或初始化不当
- **解决方案**：
```python
# 1. 使用残差连接（必须）
x = x + attn_output  # 残差连接

# 2. 使用Layer Normalization（必须）
x = LayerNorm(x)

# 3. 使用梯度裁剪
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

**错误2：过拟合**
- **现象**：训练集表现很好（准确率95%），验证集表现差（60%）
- **原因**：模型参数多（多头增加参数量）、数据少
- **解决方案**：
```python
# 1. 增加训练数据（数据增强）
# 2. 使用正则化
dropout = nn.Dropout(p=0.1)  # 在注意力和前馈网络后应用

# 3. 早停策略
if val_loss_not_improved_epochs >= patience:
    break
```

### 11.3 调参层面常见误区
**误区1：头数越多越好**
- **过大**：计算成本增加（头数×每个头的复杂度），可能过拟合
- **过小**：无法捕捉多样化特征
- **推荐**：
  - Base模型：8-12头
  - Large模型：16-32头
  - 关系：n_heads × d_k = d_model

**误区2：忽略输出投影的重要性**
- **后果**：多头信息无法有效整合
- **正确做法**：保留输出投影矩阵，或使用低秩分解减少参数

## 12. 学习总结
### 12.1 核心要点回顾
✓ **核心思想**：将QKV拆分为多个头并行计算注意力，捕捉多样化特征  
✓ **数学本质**：MultiHead(Q,K,V) = Concat(head_1,...,head_h)W^O  
✓ **优化目标**：最小化下游任务损失（如交叉熵、BLEU）  
✓ **适用场景**：序列建模、长距离依赖、并行训练  
✓ **局限性**：计算量增加，参数量上升，头之间可能冗余  

### 12.2 关键公式汇总
**1. 单头注意力：**
$$ \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V) = \text{softmax}\left(\frac{QW_i^Q (KW_i^K)^T}{\sqrt{d_k}}\right) VW_i^V $$

**2. 多头注意力：**
$$ \text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,...,\text{head}_h)W^O $$

**3. 缩放因子：**
$$ \frac{1}{\sqrt{d_k}} \text{防止点积结果过大，避免softmax梯度消失} $$

### 12.3 最佳实践
**数据预处理：**
- ✓ 确保d_model能被n_heads整除
- ✓ 使用padding mask处理变长序列
- ✓ 对输入进行Layer Normalization

**模型设计：**
- ✓ 选择合适的头数（8-12头适合大多数任务）
- ✓ 添加残差连接（每个子层后）
- ✓ 使用Dropout防止过拟合（推荐p=0.1-0.3）

**训练技巧：**
- ✓ 使用学习率预热（warmup）
- ✓ 使用梯度裁剪防止梯度爆炸
- ✓ 使用AdamW优化器（带权重衰减）

- **前置算法**：缩放点积注意力、Layer Normalization
- **后续算法**：Transformer、BERT、GPT、ViT

## 13. 练习题与思考题
### 13.1 基础练习（2题）

**练习1：概念理解**
问题：多头注意力中，每个头的作用是？
A. 增加模型参数量，提升拟合能力
B. 不同头可以学习不同的注意力模式，捕捉多样化特征
C. 减少计算复杂度，从O(n²)降到O(n)
D. 替代位置编码，提供位置信息

**答案与解析：**
答案：B
解析：多头注意力的核心思想是将QKV拆分为h个头，每个头独立计算注意力，从而捕捉不同的语义/语法关系。A错误，多头不是为了增加参数；C错误，多头不减少复杂度（总复杂度不变）；D错误，多头不能替代位置编码。

---

**练习2：手动计算**
问题：给定d_model=512，n_heads=8，计算每个头的维度d_k。

**答案与解析：**
解：
$$ d_k = \frac{d_{model}}{n_{heads}} = \frac{512}{8} = 64 $$
每个头的维度为64，8个头拼接后为8×64=512，与d_model一致。

### 13.2 进阶思考（2题）

**思考1：改进分析**
问题：多头注意力中，不同头可能学习到相似的注意力模式，如何改进？

**答案与解析：**
改进方法：
1. **头剪枝**：移除冗余的头，减少计算量
2. **稀疏激活**：使用MoE多头，每个token只激活部分头
3. **正则化**：添加头多样性损失，鼓励不同头学习不同的模式
4. **使用GQA/MQA**：分组查询注意力、多查询注意力，减少头的冗余

---

**思考2：对比分析**
问题：对比多头注意力和分组查询注意力（GQA）在结构和应用上的区别。

**答案与解析：**
| 维度 | 多头注意力 | 分组查询注意力（GQA） |
|------|-----------|----------------------|
| Query头数 | h | h（与多头相同） |
| Key/Value头数 | h | h/g（g为分组数，g<h） |
| 计算量 | ⭐⭐⭐（h个QKV） | ⭐⭐（减少KV头数） |
| 推理效率 | ⭐⭐（KV缓存大） | ⭐⭐⭐（KV缓存小） |
| 适用场景 | 训练、复杂任务 | 推理、效率优先 |

选择建议：
- 选择多头注意力：训练、复杂任务、需要高表达能力
- 选择GQA：推理效率优先、保持多头表达能力

### 13.3 开放思考（1题）

**思考3：创新扩展**
问题：如何将多头注意力应用到图像识别任务中？请设计一个简单的应用方案（Vision Transformer, ViT）。

**答案与解析：**
创新应用场景：图像分类、目标检测、图像分割

实施方案：
1. **图像分块（Patch Embedding）**：
   - 将图像（如224×224×3）分成patch（如16×16）
   - 得到N = (224/16)² = 196个patch
   - 每个patch展平为16×16×3=768维向量
   - 通过线性投影降维到d_model（如768→512）

2. **添加位置编码**：
   - 为每个patch添加位置编码（可学习）
   - 形状：(batch, N, d_model)

3. **多头自注意力**：
   - 将patch序列输入多头自注意力
   - 每个头可以关注图像的不同区域（局部/全局）

4. **分类头**：
   - 使用[CLS]位置的输出或所有patch平均池化
   - 通过全连接层输出分类logits

潜在挑战：
1. **计算量**：patch数N=196时，注意力矩阵196×196≈38416，可行
   - 解决：对于高分辨率图像，增大patch size（如32×32）

2. **位置信息**：图像是2D结构
   - 解决：使用2D位置编码或在patch embedding中融入2D位置信息

### C. 常见问题FAQ
**Q1：多头注意力中，每个头的维度d_k为什么等于d_model / n_heads？**
A：为了拼接后维度与输入一致。每个头输出d_k维，h个头拼接后为h×d_k = d_model，再通过输出投影W^O（d_model×d_model）得到最终输出。

**Q2：多头注意力为什么比单头好？**
A：单头只能学习一种注意力模式，而多头可以学习多种模式（如局部上下文、全局依赖、语法关系、语义关系等），从而提升模型的表达能力。

**Q3：如何选择合适的头数？**
A：头数越多，能捕捉的模式越多，但计算量和参数量也越大。一般建议：
- 小模型（d_model=128-256）：4-8头
- 中模型（d_model=512-768）：8-12头
- 大模型（d_model=1024+）：16-32头
