# 朴素贝叶斯 学习文档

## 1. 算法基础认知

### 1.1 一句话定义
朴素贝叶斯（Naive Bayes）是一种基于贝叶斯定理的条件概率分类算法，它在"条件独立假设"的前提下，通过计算样本属于各类别的后验概率来进行分类预测。因其算法简单、效率高且在许多文本分类任务中表现优异而被广泛使用。

### 1.2 直觉类比
朴素贝叶斯的工作方式就像是一个"经验主义"的分类器。想象你是一个新入职的房产中介，有个客户打电话来问："我想买一套带花园的房子，大概500万左右，你有什么推荐？"你虽然没有见过这个客户，但你根据过往的经验可以快速做出判断：如果过去来找这种条件的客户，最终成交的大多是郊区别墅，你会首先推荐郊区别墅。这就是朴素贝叶斯的基本思想——基于历史数据中的统计规律来做出预测。具体来说，它会查看过去满足"花园+500万"条件的房子分布在各类别中的比例，然后选择概率最高的类别进行推荐。

### 1.3 历史背景
朴素贝叶斯分类器的理论基础可以追溯到18世纪英国数学家Thomas Bayes提出的贝叶斯定理。现代朴素贝叶斯分类器的实际应用始于1950年代，当时在垃圾邮件过滤和文本分类中得到应用。1960年代，Maron在论文中发表了关于自动索引的朴素贝叶斯方法，这被认为是将朴素贝叶斯应用于信息检索的开创性工作。此后，朴素贝叶斯因其简单高效的特点成为机器学习中不可或缺的baseline模型，尤其在垃圾邮件过滤、文本分类和情感分析等领域表现出色。

### 1.4 算法定位
- **类型**：监督学习（Supervised Learning）
- **输出**：离散类别（后验概率）
- **模型类别**：生成模型（Generative Model）
- **学习范式**：参数化学习（学习先验概率和条件概率）
- **求解方法**：最大似然估计或贝叶斯估计

### 1.5 前置知识
- **概率论**：条件概率、全概率公式、贝叶斯定理
- **统计学习**：最大似然估计、拉普拉斯平滑
- **Python编程**：NumPy、scikit-learn

## 2. 核心原理

### 2.1 核心思想
朴素贝叶斯分类器基于贝叶斯定理进行分类预测。其核心思想是：给定一个待分类的样本x，我们需要计算它在各类别c下的后验概率P(c|x)，然后选择后验概率最大的类别作为预测结果。贝叶斯定理告诉我们：
$$P(c|x) = \frac{P(x|c) \cdot P(c)}{P(x)}$$
由于P(x)是常数，分类问题等价于最大化P(x|c)·P(c)。

朴素贝叶斯的"朴素"之处在于它做了一个强假设：**条件独立性假设**，即假设给定类别c时，特征x的各维度之间相互独立。这意味着：
$$P(x|c) = P(x_1, x_2, ..., x_d | c) = \prod_{j=1}^{d} P(x_j | c)$$
这个假设虽然在实际中很少成立，但使得复杂的多元概率估计问题变得简单可行。

### 2.2 工作流程
1. **学习先验概率**：从训练数据中学习每个类别的先验概率P(c)
2. **学习条件概率**：从训练数据中学习每个特征在各类别下的条件概率P(x_j|c)
3. **计算后验概率**：对新样本x，计算各类别的后验概率P(c|x) ∝ P(c)·∏P(x_j|c)
4. **选择类别**：选择后验概率最大的类别作为预测结果

### 2.3 关键概念解释
- **先验概率P(c)**：在看到任何特征之前，样本属于类别c的概率。它反映了类别在训练数据中的分布比例。
- **条件概率P(x_j|c)**：在给定类别c的条件下，特征x_j取某个值的概率。它反映了在该类别中该特征取值的统计规律。
- **后验概率P(c|x)**：在观察到特征x的条件下，样本属于类别c的概率。它是我们最终用于分类的概率。
- **条件独立假设**：朴素贝叶斯的核心假设，假设各特征条件独立。这个假设大大简化了计算，但也限制了模型的表达能力。

### 2.4 几何/直观解释
在特征空间中，朴素贝叶斯可以看作是对每个类别分别建立了一个概率模型。对于高斯朴素贝叶斯，每个类别的数据被建模为一个高斯分布；对于多项式朴素贝叶斯，每个类别的特征被建模为一个多项分布。这些分布在特征空间中形成了不同的"概率等高线"，新样本根据其落在哪个类别的"概率山"最高而被分类。

## 3. 数学公式与推导

### 3.1 符号约定
| 符号 | 含义 |
|------|------|
| X ∈ R^(n×d) | 特征矩阵，n个样本，d维特征 |
| y ∈ {c_1, c_2, ..., c_k}^n | 标签向量，k个类别 |
| P(c) | 类别c的先验概率 |
| P(x_j \| c) | 类别c下特征x_j的条件概率 |
| P(c \| x) | 特征x条件下类别c的后验概率 |
| α | 拉普拉斯平滑参数 |

### 3.2 问题形式化
**贝叶斯分类器**：
$$\hat{c} = \arg\max_{c} P(c|x) = \arg\max_{c} \frac{P(x|c) \cdot P(c)}{P(x)}$$

由于P(x)是常数，等价于：
$$\hat{c} = \arg\max_{c} P(x|c) \cdot P(c)$$

**朴素贝叶斯**（使用条件独立假设）：
$$\hat{c} = \arg\max_{c} \left[ P(c) \cdot \prod_{j=1}^{d} P(x_j|c) \right]$$

### 3.3 目标函数/损失函数
朴素贝叶斯通常使用**0-1损失函数**，但由于其使用最大后验概率分类，隐含地最小化了分类错误率。

为了避免概率连乘造成的数值下溢，通常使用对数形式：
$$\hat{c} = \arg\max_{c} \left[ \log P(c) + \sum_{j=1}^{d} log P(x_j|c) \right]$$

### 3.4 推导过程
**Step 1：贝叶斯定理**

根据贝叶斯定理：
$$P(c|x) = \frac{P(x|c) \cdot P(c)}{P(x)}$$

**Step 2：应用条件独立假设**

根据条件独立假设：
$$P(x|c) = P(x_1, x_2, ..., x_d | c) = \prod_{j=1}^{d} P(x_j | c)$$

**Step 3：计算后验概率**

$$P(c|x) \propto P(c) \cdot \prod_{j=1}^{d} P(x_j | c)$$

**Step 4：分类决策**

选择后验概率最大的类别：
$$\hat{c} = \arg\max_{c} P(c) \cdot \prod_{j=1}^{d} P(x_j | c)$$

### 3.5 常见朴素贝叶斯变体
1. **高斯朴素贝叶斯（GaussianNB）**：假设连续特征服从正态分布
   $$P(x_j|c) = \frac{1}{\sqrt{2\pi\sigma_c^2}} \exp\left(-\frac{(x_j - \mu_c)^2}{2\sigma_c^2}\right)$$

2. **多项式朴素贝叶斯（MultinomialNB）**：适用于离散计数特征（如词频）
   $$P(x_j|c) = \frac{count(x_j, c) + \alpha}{count(c) + \alpha \cdot |V|}$$

3. **伯努利朴素贝叶斯（BernoulliNB）**：适用于二元特征
   $$P(x_j|c) = \begin{cases} P(x_j=1|c) & x_j=1 \\ 1-P(x_j=1|c) & x_j=0 \end{cases}$$

4. **补充朴素贝叶斯（ComplementNB）**：多项式朴素贝叶斯的改进版本

## 4. 训练过程讲解

### 4.1 数据预处理
1. **特征类型处理**
   - 连续特征：可以直接使用高斯朴素贝叶斯，或离散化后使用多项式朴素贝叶斯
   - 离散类别特征：需要进行编码（如标签编码或独热编码）
   - 计数特征（词频）：使用多项式朴素贝叶斯

2. **标准化**
   对于高斯朴素贝叶斯，标准化不是必需的。但对于其他算法，可能需要进行特征缩放。

3. **缺失值处理**
   - 删除含有缺失值的样本
   - 用众数/均值填充

### 4.2 参数估计
1. **先验概率估计（最大似然估计）**：
   $$P(c) = \frac{count(c)}{n}$$

2. **条件概率估计（拉普拉斯平滑）**：
   $$P(x_j=v|c) = \frac{count(x_j=v, c) + \alpha}{count(c) + \alpha \cdot |V_j|}$$

   其中|V_j|是特征x_j可能取值的个数，α是平滑参数（��常取1）。

### 4.3 超参数
- **alpha**：拉普拉斯平滑参数，默认1.0
- **norm**：是否归一化权重，默认True（对于补充朴素贝叶斯）

## 5. 应用场景

### 5.1 典型应用
1. **垃圾邮件过滤**
   - 使用词频作为特征
   - 经典的朴素贝叶斯应用场景
   
2. **文本分类**
   - 文档分类、情感分析、主题分类
   - 配合TF-IDF特征效果更佳
   
3. **多分类快速baseline**
   - 当需要快速建立baseline时
   - 实时性要求高的场景

### 5.2 适用数据特征
- **特征类型**：离散或类别型
- **文本数据**：词频、TF-IDF
- **数据量**：中小规模
- **特征维度**：中到高维

### 5.3 不适用场景
- **高度相关的特征**：条件独立假设失效
- **连续特征且非线性**：可能不如SVM或神经网络
- **需要高精度**：可能需要更复杂的模型

---

## 6. 优缺点分析

### 6.1 优点
1. **简单高效**：算法简单，训练和预测速度快
2. **概率输出**：可以输出后验概率
3. **抗噪声**：对噪声有一定的鲁棒性
4. **少参数**：几乎没有需要调优的参数
5. **条件独立假设**：在许多实际问题上表现良好

### 6.2 缺点
1. **条件独立假设**：这个假设在现实中很少成立
2. **零概率问题**：如果某个特征值在某个类别下从未出现，会导致概率为0
3. **分类精度有限**：可能不如更复杂的模型

## 8. 手工代码实现（NumPy）

```python
"""
朴素贝叶斯分类器 - 纯NumPy实现
作者：算法学习文档
功能：从零实现朴素贝叶斯分类器
"""

import numpy as np
import matplotlib.pyplot as plt

class GaussianNBFromScratch:
    """
    高斯朴素贝叶斯的完整实现
    """
    
    def __init__(self):
        self.class_prior_ = None  # 先验概率
        self.theta_ = None       # 每个类别各特征的均值
        self.var_ = None        # 每个类别各特征的方差
        self.classes_ = None    # 类别列表
        
    def fit(self, X, y):
        """训练模型"""
        X = np.array(X)
        y = np.array(y)
        
        n_samples, n_features = X.shape
        self.classes_ = np.unique(y)
        n_classes = len(self.classes_)
        
        # 计算先验概率
        self.class_prior_ = np.zeros(n_classes)
        for i, c in enumerate(self.classes_):
            self.class_prior_[i] = np.sum(y == c) / n_samples
        
        # 计算均值和方差
        self.theta_ = np.zeros((n_classes, n_features))
        self.var_ = np.zeros((n_classes, n_features))
        
        for i, c in enumerate(self.classes_):
            X_c = X[y == c]
            self.theta_[i] = X_c.mean(axis=0)
            # 方差需要加上平滑项
            self.var_[i] = X_c.var(axis=0) + 1e-9
        
        return self
    
    def _pdf(self, X, class_idx):
        """计算高斯概率密度"""
        mean = self.theta_[class_idx]
        var = self.var_[class_idx]
        
        # 高斯概率密度函数
        diff = X - mean
        exponent = -diff ** 2 / (2 * var)
        pdf = np.exp(exponent) / np.sqrt(2 * np.pi * var)
        
        return pdf
    
    def predict_proba(self, X):
        """预测后验概率"""
        X = np.array(X)
        
        log_prior = np.log(self.class_prior_)
        log_proba = np.zeros((X.shape[0], len(self.classes_)))
        
        for i in range(len(self.classes_)):
            # 计算对数条件概率
            # log P(x|c) = sum(log p(x_j|c))
            pdf = self._pdf(X, i)
            # 避免log(0)
            pdf = np.maximum(pdf, 1e-9)
            log_cond = np.sum(np.log(pdf), axis=1)
            log_proba[i] = log_prior[i] + log_cond
        
        # 归一化（使用softmax）
        log_proba_max = np.max(log_proba, axis=0, keepdims=True)
        log_proba -= log_proba_max
        proba = np.exp(log_proba)
        proba /= proba.sum(axis=0, keepdims=True)
        
        return proba.T
    
    def predict(self, X):
        """预测类别"""
        proba = self.predict_proba(X)
        return self.classes_[np.argmax(proba, axis=1)]


class MultinomialNBFromScratch:
    """
    多项式朴素贝叶斯的实现
    """
    
    def __init__(self, alpha=1.0):
        self.alpha = alpha  # 平滑参数
        self.class_log_prior_ = None
        self.feature_log_prob_ = None
        self.classes_ = None
        
    def fit(self, X, y):
        """训练模型"""
        X = np.array(X)
        y = np.array(y)
        
        self.classes_ = np.unique(y)
        n_classes = len(self.classes_)
        n_features = X.shape[1]
        
        # 计算对数先验概率
        self.class_log_prior_ = np.zeros(n_classes)
        for i, c in enumerate(self.classes_):
            count = np.sum(y == c)
            self.class_log_prior_[i] = np.log(count / len(y))
        
        # 计算对数条件概率
        self.feature_log_prob_ = np.zeros((n_classes, n_features))
        
        for i, c in enumerate(self.classes_):
            X_c = X[y == c]
            # 拉普拉斯平滑
            count = X_c.sum(axis=0) + self.alpha
            # 归一化
            log_prob = np.log(count / count.sum())
            self.feature_log_prob_[i] = log_prob
        
        return self
    
    def predict_proba(self, X):
        """预测后验概率"""
        X = np.array(X)
        
        # 计算对数后验概率
        log_proba = self.class_log_prior_ + X @ self.feature_log_prob_.T
        
        # 归一化
        log_proba_max = np.max(log_proba, axis=1, keepdims=True)
        log_proba -= log_proba_max
        proba = np.exp(log_proba)
        proba /= proba.sum(axis=1, keepdims=True)
        
        return proba
    
    def predict(self, X):
        """预测类别"""
        proba = self.predict_proba(X)
        return self.classes_[np.argmax(proba, axis=1)]


class BernoulliNBFromScratch:
    """
    伯努利朴素贝叶斯的实现
    """
    
    def __init__(self, alpha=1.0):
        self.alpha = alpha
        self.class_log_prior_ = None
        self.feature_log_prob_ = None
        self.classes_ = None
        
    def fit(self, X, y):
        """训练模型"""
        X = np.array(X)
        y = np.array(y)
        
        self.classes_ = np.unique(y)
        n_classes = len(self.classes_)
        n_features = X.shape[1]
        
        # 对数先验
        self.class_log_prior_ = np.zeros(n_classes)
        for i, c in enumerate(self.classes_):
            count = np.sum(y == c)
            self.class_log_prior_[i] = np.log(count / len(y))
        
        # 对数条件概率
        self.feature_log_prob_ = np.zeros((n_classes, n_features))
        
        for i, c in enumerate(self.classes_):
            X_c = X[y == c]
            # 计数: 特征为1的样本数
            counts = X_c.sum(axis=0) + self.alpha
            # 样本总数 + 平滑
            total = len(X_c) + 2 * self.alpha  # *2 因为有两个可能的值: 0, 1
            self.feature_log_prob_[i] = np.log(counts / total)
        
        return self
    
    def predict(self, X):
        """预测类别"""
        X = np.array(X)
        
        # 二值化
        X_binary = (X > 0).astype(int)
        
        # 计算对数后验
        log_proba = self.class_log_prior_ + X_binary @ self.feature_log_prob_.T
        
        return self.classes_[np.argmax(log_proba, axis=1)]
```

## 11. 常见问题与易错点

### 11.1 常见问题
1. **零概率问题**
   - 原因：某个特征值在某个类别下从未出现
   - 解决：使用拉普拉斯平滑

2. **下溢问题**
   - 原因：多个小数相乘导致数值下溢
   - 解决：使用对数形式计算

### 11.2 易错点
1. **忽略特征类型**
   - 连续特征用高斯，计数特征用多项式

2. **忽略数据预处理**
   - 文本需要向量化

### 13.2 简答题
1. **为什么朴素贝叶斯需要条件独立假设？**
   答案：为了简化P(x|c)的计算，否则需要估计高维协方差矩阵，计算复杂度高且需要大量数据。

2. **拉普拉斯平滑的作用？**
   答案：避免零概率问题。如果某个特征值在某类下从未出现，会导致整个后验概率为0。
