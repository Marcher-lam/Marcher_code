# 词嵌入（Word Embedding）学习文档

> 将离散的词映射到连续的向量空间——让语义相近的词在向量空间中也相近。

## 1. 算法基础认知

### 一句话定义

词嵌入是把文字转换为向量的技术，让语义相近的词在向量空间中也相近。

### 直觉类比

词嵌入就像给每个单词一个"坐标"——"国王"和"王后"可能坐标很近（都在皇室区域），"苹果"和"橙子"也很近（都是水果），但"汽车"离它们都很远。

更神奇的是，词嵌入支持向量运算：国王 - 男人 + 女人 ≈ 王后。

### 历史背景

- **2003年**：Bengio提出神经概率语言模型（NNLM），首次学习词嵌入
- **2013年**：Mikolov提出Word2Vec（CBOW + Skip-gram）
- **2014年**：Pennington提出GloVe（矩阵分解 + 上下文统计）
- **2018年**：BERT提出上下文相关的动态词嵌入

### 算法定位

词嵌入是**NLP基础技术**，用于将离散符号转换为连续表示。

## 2. 核心原理

### 2.1 分布式假设

"一个词的语义由其上下文决定"（"You shall know a word by the company it keeps"）

- "他喝了一杯____" → 很可能是"水"、"茶"、"咖啡"
- 出现在类似上下文中的词，语义也相似

### 2.2 静态嵌入 vs 动态嵌入

**静态嵌入（Word2Vec, GloVe）**：
- 每个词一个固定向量
- 优点：简单高效
- 缺点：无法处理多义词

**动态嵌入（ELMo, BERT）**：
- 根据上下文生成不同的向量
- 优点：上下文感知，处理多义词
- 缺点：计算量大

### 2.3 嵌入矩阵

词嵌入本质上是一个查找表 $E \in \mathbb{R}^{|V| \times d}$，其中 $|V|$ 是词表大小，$d$ 是嵌入维度。每个词索引 $i$ 对应一个 $d$ 维向量 $E[i]$。

## 3. 数学公式与推导

### 3.1 Word2Vec: Skip-gram

给定中心词 $w_t$，预测上下文词 $w_{t+j}$：

$$\max \frac{1}{T} \sum_{t=1}^T \sum_{-c \leq j \leq c, j \neq 0} \log p(w_{t+j} | w_t)$$

其中：
$$p(w_o | w_c) = \frac{\exp(u_o^T v_c)}{\sum_{w \in V} \exp(u_w^T v_c)}$$

$v_c$ 是中心词的嵌入，$u_o$ 是上下文词的嵌入。

### 3.2 Word2Vec: CBOW

给定上下文词，预测中心词：

$$\max \frac{1}{T} \sum_{t=1}^T \log p(w_t | w_{t-c}, ..., w_{t+c})$$

其中上下文嵌入取平均：
$$h = \frac{1}{2c} \sum_{j \neq 0} v_{w_{t+j}}$$

### 3.3 GloVe

基于全局共现统计：

$$J = \sum_{i,j=1}^V f(X_{ij}) (w_i^T w_j + b_i + b_j - \log X_{ij})^2$$

其中 $X_{ij}$ 是词 $i$ 和 $j$ 的共现次数，$f$ 是权重函数（截断高频）。

### 3.4 负采样（Negative Sampling）

为加速训练，用负采样近似softmax：

$$\log \sigma(u_o^T v_c) + \sum_{k=1}^K \mathbb{E}_{w_k \sim P_n(w)} [\log \sigma(-u_k^T v_c)]$$

其中 $K$ 个负样本从噪声分布 $P_n(w)$ 采样。

## 4. 训练过程

### 4.1 Word2Vec训练流程
1. 滑动窗口在语料上生成(中心词, 上下文词)对
2. 对每个正样本对，采样K个负样本
3. 优化二分类损失（正样本高分，负样本低分）
4. 更新词嵌入矩阵 $E$

### 4.2 GloVe训练流程
1. 统计全局共现矩阵 $X$
2. 加权最小二乘优化
3. 同时学习词嵌入和偏置

### 4.3 训练技巧
- 高频词下采样（如"the", "a"）
- 动态学习率
- 嵌入维度通常50~300

## 5. 应用场景

1. **NLP基础**：作为所有NLP模型的输入层
2. **语义相似度**：计算词向量余弦相似度
3. **文本分类**：词嵌入 + 分类器
4. **命名实体识别**：词嵌入作为特征
5. **机器翻译**：跨语言词嵌入对齐

## 6. 优缺点

### 优点
1. **稠密表示**：相比one-hot，语义信息丰富
2. **语义计算**：支持向量运算和相似度计算
3. **迁移学习**：预训练嵌入可用于下游任务
4. **降维**：从 $|V|$ 维降到 $d$ 维

### 缺点
1. **静态**：多义词无法区分
2. **OOV**：无法处理未登录词
3. **偏见**：语料中的偏见会被学习
4. **维度选择**：需要人工选择嵌入维度

"""
词嵌入的完整实现（Word2Vec + GloVe）
"""

import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np
import math


class Word2VecSkipGram(nn.Module):
    """Word2Vec Skip-gram模型

    参数:
        vocab_size: 词表大小
        embed_dim: 嵌入维度
    """

    def __init__(self, vocab_size, embed_dim):
        super().__init__()
        self.center_embeddings = nn.Embedding(vocab_size, embed_dim)
        self.context_embeddings = nn.Embedding(vocab_size, embed_dim)

        # 初始化
        nn.init.xavier_uniform_(self.center_embeddings.weight)
        nn.init.xavier_uniform_(self.context_embeddings.weight)

    def forward(self, center_words, context_words, negative_words):
        """
        参数:
            center_words: (B,) 中心词索引
            context_words: (B,) 正样本上下文词索引
            negative_words: (B, K) 负样本词索引

        返回:
            loss: 标量损失
        """
        batch_size = center_words.size(0)

        # 正样本得分
        center_emb = self.center_embeddings(center_words)  # (B, D)
        context_emb = self.context_embeddings(context_words)  # (B, D)
        pos_scores = (center_emb * context_emb).sum(dim=1)  # (B,)
        pos_loss = F.logsigmoid(pos_scores).mean()

        # 负样本得分
        neg_emb = self.context_embeddings(negative_words)  # (B, K, D)
        center_exp = center_emb.unsqueeze(1).expand(-1, negative_words.size(1), -1)
        neg_scores = (center_exp * neg_emb).sum(dim=2)  # (B, K)
        neg_loss = F.logsigmoid(-neg_scores).sum(dim=1).mean()

        return -(pos_loss + neg_loss)


class Word2VecCBOW(nn.Module):
    """Word2Vec CBOW模型"""

    def __init__(self, vocab_size, embed_dim):
        super().__init__()
        self.embeddings = nn.Embedding(vocab_size, embed_dim)
        self.output = nn.Linear(embed_dim, vocab_size)

    def forward(self, context_words, target_words):
        # context_words: (B, window_size*2)
        # target_words: (B,)
        context_emb = self.embeddings(context_words)  # (B, W, D)
        context_mean = context_emb.mean(dim=1)  # (B, D)
        logits = self.output(context_mean)  # (B, V)
        loss = F.cross_entropy(logits, target_words)
        return loss


class GloVe(nn.Module):
    """GloVe模型

    基于共现矩阵的加权最小二乘
    """

    def __init__(self, vocab_size, embed_dim, x_max=100, alpha=0.75):
        super().__init__()
        self.w_i = nn.Embedding(vocab_size, embed_dim)
        self.w_j = nn.Embedding(vocab_size, embed_dim)
        self.b_i = nn.Embedding(vocab_size, 1)
        self.b_j = nn.Embedding(vocab_size, 1)
        self.x_max = x_max
        self.alpha = alpha

        nn.init.xavier_uniform_(self.w_i.weight)
        nn.init.xavier_uniform_(self.w_j.weight)

    def forward(self, i_idx, j_idx, cooccurrence):
        w_i = self.w_i(i_idx)
        w_j = self.w_j(j_idx)
        b_i = self.b_i(i_idx).squeeze()
        b_j = self.b_j(j_idx).squeeze()

        # 预测log共现
        pred = (w_i * w_j).sum(dim=1) + b_i + b_j
        target = torch.log(cooccurrence + 1e-8)

        # 权重函数
        weight = (cooccurrence / self.x_max).clamp(max=1.0) ** self.alpha

        loss = (weight * (pred - target) ** 2).mean()
        return loss


def create_embeddings_from_text():
    """从文本创建简单的词嵌入"""
    from collections import Counter

    # 简单语料
    corpus = [
        "我 爱 机器 学习",
        "深度 学习 很 有趣",
        "机器 学习 需要 数学",
        "自然 语言 处理 也 用 机器 学习",
    ]

    # 构建词表
    word_counts = Counter()
    for sentence in corpus:
        word_counts.update(sentence.split())

    vocab = {word: idx for idx, (word, _) in enumerate(word_counts.items())}
    vocab_size = len(vocab)

    print(f"词表大小: {vocab_size}")
    for word, idx in vocab.items():
        print(f"  {word}: {idx}")

    # 生成训练数据（CBOW）
    window_size = 2
    data = []
    for sentence in corpus:
        tokens = sentence.split()
        for i, target in enumerate(tokens):
            context = []
            for j in range(max(0, i-window_size), min(len(tokens), i+window_size+1)):
                if j != i:
                    context.append(tokens[j])
            if len(context) > 0:
                data.append((context, target))

    print(f"\n训练样本数: {len(data)}")
    for ctx, tgt in data[:3]:
        print(f"  上下文: {ctx} -> 目标: {tgt}")

    return vocab, data


def demo():
    """词嵌入演示"""
    print("=== 词嵌入演示 ===\n")

    # 1. 基本嵌入层
    vocab_size, embed_dim = 1000, 128
    embedding = nn.Embedding(vocab_size, embed_dim)

    # 模拟输入
    token_ids = torch.randint(0, vocab_size, (4, 10))
    embedded = embedding(token_ids)
    print(f"嵌入层: 输入{token_ids.shape} -> 输出{embedded.shape}")

    # 2. Word2Vec Skip-gram
    model = Word2VecSkipGram(vocab_size, embed_dim)
    center = torch.randint(0, vocab_size, (32,))
    positive = torch.randint(0, vocab_size, (32,))
    negative = torch.randint(0, vocab_size, (32, 5))
    loss = model(center, positive, negative)
    print(f"Skip-gram损失: {loss.item():.4f}")

    # 3. 相似度计算
    word_vecs = embedding.weight.detach()
    word_a = word_vecs[10]
    word_b = word_vecs[20]
    word_c = word_vecs[30]

    cos_ab = F.cosine_similarity(word_a.unsqueeze(0), word_b.unsqueeze(0))
    cos_ac = F.cosine_similarity(word_a.unsqueeze(0), word_c.unsqueeze(0))
    print(f"\n余弦相似度: 词10-词20={cos_ab.item():.4f}, 词10-词30={cos_ac.item():.4f}")

    # 4. 简单语料演示
    vocab, data = create_embeddings_from_text()
    print(f"\n参数量: {sum(p.numel() for p in model.parameters()):,}")

    demo()

```python
"""词嵌入核心手工实现"""
import numpy as np

def skipgram_handcraft(center_idx, context_idx, embeddings, neg_samples, lr=0.01):
    """手工Skip-gram单步更新"""
    D = embeddings.shape[1]
    v_c = embeddings[center_idx].copy()
    u_o = embeddings[context_idx].copy()

    # 正样本梯度
    score = np.dot(v_c, u_o)
    sigma = 1 / (1 + np.exp(-score))
    grad_pos = (sigma - 1)

    # 更新
    embeddings[center_idx] -= lr * grad_pos * u_o
    embeddings[context_idx] -= lr * grad_pos * v_c

    # 负样本
    for neg_idx in neg_samples:
        u_k = embeddings[neg_idx].copy()
        score_neg = np.dot(v_c, u_k)
        sigma_neg = 1 / (1 + np.exp(-score_neg))
        grad_neg = sigma_neg

        embeddings[center_idx] -= lr * grad_neg * u_k
        embeddings[neg_idx] -= lr * grad_neg * v_c

    return embeddings

def test():
    V, D = 100, 50
    emb = np.random.randn(V, D) * 0.1
    emb = skipgram_handcraft(5, 12, emb, [3, 7, 20])
    print(f"词嵌入更新完成: {emb.shape}")

if __name__ == "__main__":
    test()
```

"""词嵌入评估"""

def word_similarity_evaluation(embeddings, word_pairs):
    """评估词嵌入的语义相似度"""
    from scipy.stats import spearmanr
    predicted = []
    human_scores = []
    for w1, w2, human_score in word_pairs:
        if w1 in embeddings and w2 in embeddings:
            v1 = embeddings[w1]
            v2 = embeddings[w2]
            cos = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2) + 1e-8)
            predicted.append(cos)
            human_scores.append(human_score)
    rho, _ = spearmanr(predicted, human_scores)
    return rho

def analogy_evaluation(embeddings, analogies):
    """评估词嵌入的类比推理能力"""
    correct = 0
    total = 0
    for a, b, c, d in analogies:
        if all(w in embeddings for w in [a, b, c]):
            v_a = embeddings[a]
            v_b = embeddings[b]
            v_c = embeddings[c]
            target = v_b - v_a + v_c
            # 找到最接近的词（排除a,b,c）
            scores = {w: np.dot(target, v) / (np.linalg.norm(target) * np.linalg.norm(v) + 1e-8)
                      for w, v in embeddings.items() if w not in [a, b, c]}
            predicted = max(scores, key=scores.get)
            if predicted == d:
                correct += 1
            total += 1
    return correct / max(total, 1)

def demo_eval():
    print("=== 词嵌入评估演示 ===")
    words = ['king', 'queen', 'man', 'woman', 'paris', 'france', 'berlin', 'germany']
    np.random.seed(42)
    emb = {w: np.random.randn(50) for w in words}
    analogies = [('king', 'queen', 'man', 'woman'),
                 ('paris', 'france', 'berlin', 'germany')]
    acc = analogy_evaluation(emb, analogies)
    print(f"类比推理准确率: {acc:.2f}")

if __name__ == "__main__":
    demo_eval()

## 11. 常见问题与易错点

**Q1: OOV（未登录词）怎么处理？**
三种方法：1) 使用 `<unk>` 特殊token 2) 使用子词嵌入（如FastText的字符n-gram）3) 基于形态学猜测。

**Q2: 嵌入维度如何选择？**
经验法则：$d \approx \sqrt[4]{|V|}$ 或使用50~300。更大的维度可以编码更多语义，但过大会导致过拟合和计算开销。

**Q3: Word2Vec和GloVe的区别？**
Word2Vec基于预测（局部上下文窗口），GloVe基于全局共现统计（矩阵分解）。GloVe训练更快，语义一致性更好。

**Q4: 为什么嵌入向量中会出现"国王-男人+女人≈王后"这种性质？**
因为词嵌入学习到的向量空间存在线性子结构——语义差异（如性别、时态、单复数）对应固定的向量偏移。

## 12. 学习总结

- 词嵌入将离散符号转换为连续稠密向量
- 核心原则：分布式假设—语义由上下文决定
- 主要方法：Word2Vec（预测）、GloVe（统计）、FastText（子词）
- 静态嵌入：简单但无法处理多义词
- 动态嵌入：BERT等上下文感知嵌入成为新标准

## 13. 练习题

**基础题：**

1. 什么是分布式假设？
> **答案：** "You shall know a word by the company it keeps"——出现在相似上下文中的词具有相似的语义。

2. Word2Vec的两种架构分别是什么？
> **答案：** CBOW（上下文预测中心词）和Skip-gram（中心词预测上下文）。

**进阶题：**

3. 为什么负采样可以加速Word2Vec训练？
> **答案：** 原始的softmax需要计算所有词的概率（$|V|$次），负采样将其简化为二分类（K+1次，K通常5~20），大幅降低计算量。

4. 静态词嵌入和动态词嵌入的主要区别是什么？
> **答案：** 静态嵌入每个词只有一个固定向量（如Word2Vec），无法处理多义词。动态嵌入根据上下文生成不同向量（如BERT），可以区分"苹果（水果）"和"苹果（公司）"。

import torch, torch.nn as nn, torch.nn.functional as F

class 词嵌入Net(nn.Module):
    def __init__(self, dim_in=20, dim_h=64, dim_out=2):
        super().__init__()
        self.fc1, self.fc2 = nn.Linear(dim_in, dim_h), nn.Linear(dim_h, dim_out)
    def forward(self, x): return self.fc2(F.relu(self.fc1(x)))

def train(model, X, y, epochs=100, lr=0.001):
    opt = torch.optim.Adam(model.parameters(), lr=lr)
    for ep in range(epochs):
        opt.zero_grad()
        loss = nn.CrossEntropyLoss()(model(X), y)
        loss.backward(); opt.step()
        if (ep+1)%20==0: print(f"Ep{ep+1} loss={loss.item():.4f}")

m = 词嵌入Net()
train(m, torch.randn(500,20), torch.randint(0,2,(500,)))
