# 解码器学习文档

## 1. 算法基础认知

解码器（Decoder）是Seq2Seq（Sequence to Sequence）架构中的核心组件，负责根据编码器提取的表示生成目标序列。与编码器将可变长度的输入映射到固定维度表示不同，解码器是一个自回归（Autoregressive）生成模型，根据已生成的内容预测下一个token。

解码器的核心挑战在于：给定编码器表示 $c$（或上下文序列）和已生成的部分序列 $\mathbf{y}_{<t}$，预测下一个token $y_t$。这个过程是自回归的——每一步的输出作为下一步的输入。

### 1.1 解码器的工作模式

解码器有两种基本工作模式：

1. **训练模式（Teacher Forcing）**：每一步输入的是真实的目标序列（ground truth），而非模型之前的预测。这样可以并行计算整个序列，提高训练效率。

2. **推理模式（Autoregressive Decoding）**：每一步输入的是模型之前生成的token，必须逐个生成，无法并行。

### 1.2 解码器的发展历程

1. **基础RNN解码器（2014）**：将编码器表示作为初始隐藏状态
2. **注意力增强解码器（2015）**：注意力机制连接编码器和解码器
3. **Transformer解码器（2017）**：纯注意力机制的解码器，使用掩码自注意力
4. **GPT系列（2018-2020）**：单向Transformer，生成式预训练
5. **大规模语言模型（2020-）**：数千亿参数的解码器

---

## 2. 核心原理

### 2.1 RNN解码器

基于RNN的解码器是最基础的解码器架构。设 $h_t$ 为第 $t$ 步的隐藏状态，$c$ 为编码器表示：

$$h_t = \text{RNN}(y_{t-1}, h_{t-1}, c)$$

$$P(y_t | y_{<t}, c) = \text{softmax}(W h_t + b)$$

其中 $y_{t-1}$ 是上一步的输出（训练时为真实token，推理时为预测token）。

### 2.2 注意力增强解码器

注意力机制允许解码器在生成每个token时"查看"编码器的所有隐藏状态：

**上下文向量计算**：
$$\alpha_{t,i} = \frac{\exp(\text{score}(h_{t-1}, h_i^c))}{\sum_{j=1}^{T} \exp(\text{score}(h_{t-1}, h_j^c))}$$

$$c_t = \sum_{i=1}^{T} \alpha_{t,i} h_i^c$$

**评分函数**：
- **Dot-product**（点积）：$\text{score}(h, s) = h^T s$
- **General**（通用）：$\text{score}(h, s) = h^T W s$
- **Concat**（拼接）：$\text{score}(h, s) = v^T \tanh(W[h; s])$

### 2.3 Transformer解码器

Transformer解码器使用两种注意力机制：

1. **掩码自注意力（Masked Self-Attention）**：仅允许当前位置attend到之前的位置
2. **编码器-解码器注意力（Cross-Attention）**：attend到编码器的输出

**掩码自注意力公式**：
$$\text{MaskedAttn}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}} + M\right)V$$

其中 $M$ 是下三角掩码矩阵：
$$M_{i,j} = \begin{cases} 0 & i \ge j \\ -\infty & i < j \end{cases}$$

## 3. 数学公式与推导

### 3.1 序列到序列概率

给定输入序列 $\mathbf{x}$ 和目标序列 $\mathbf{y}$，Seq2Seq模型的目标是最大化：

$$\log P(\mathbf{y}|\mathbf{x}) = \sum_{t=1}^{T} \log P(y_t | y_{<t}, \mathbf{x}, \theta)$$

这个分解利用了链式法则：
$$P(\mathbf{y}|\mathbf{x}) = \prod_{t=1}^{T} P(y_t | y_{<t}, \mathbf{x})$$

### 3.2 解码策略

#### 3.2.1 贪婪解码（Greedy Decoding）

每一步选择概率最高的token：
$$y_t = \arg\max_k P(y_k | y_{<t}, \mathbf{x})$$

优点：速度快
缺点：可能陷入局部最优

#### 3.2.2 束搜索（Beam Search）

维护 $B$ 个最可能的完整序列：

```
初始化：B=1, beam = [(start_token, log_prob=0)]
for step in range(max_len):
    candidates = []
    for (seq, score) in beam:
        if seq ends: candidates.append((seq, score))
        else:
            probs = model.predict_next(seq)
            top_k = probs.top(B)
            for (token, p) in top_k:
                candidates.append((seq + token, score + log(p)))
    beam = candidates.nlargest(B, score)
```

最终选择得分最高的序列：
$$\text{Score}(\mathbf{y}) = \frac{1}{T^{\alpha}} \sum_{t=1}^{T} \log P(y_t)$$

长度归一化（$\alpha \approx 0.6$）可以改善结果。

#### 3.2.3 采样策略

1. **温度采样**：$P_i = \frac{exp(x_i/T)}{\sum_j exp(x_j/T)}$，$T>1$ 增加多样性，$T<1$ 增加确定性
2. **Top-k采样**：限制采样范围到概率最高的k个token
3. **Top-p（核采样）**：限制累积概率到p，动态调整候选集

### 4.1 PyTorch TransformerDecoder

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class TransformerDecoderModel(nn.Module):
    """Transformer解码器模型"""
    def __init__(self, vocab_size, d_model=512, nhead=8, num_layers=6, dim_feedforward=2048, dropout=0.1, max_len=5000):
        super(TransformerDecoderModel, self).__init__()
        
        self.d_model = d_model
        self.vocab_size = vocab_size
        
        # 词嵌入
        self.embedding = nn.Embedding(vocab_size, d_model)
        
        # 位置编码
        self.positional_encoding = PositionalEncoding(d_model, dropout, max_len)
        
        # 解码器层
        decoder_layer = nn.TransformerDecoderLayer(
            d_model=d_model,
            nhead=nhead,
            dim_feedforward=dim_feedforward,
            dropout=dropout,
            batch_first=True
        )
        
        # 多层解码器
        self.transformer_decoder = nn.TransformerDecoder(
            decoder_layer,
            num_layers=num_layers
        )
        
        # 输出层
        self.output_projection = nn.Linear(d_model, vocab_size)
        
        # 初始化
        self._init_weights()
    
    def _init_weights(self):
        """参数初始化"""
        for p in self.parameters():
            if p.dim() > 1:
                nn.init.xavier_uniform_(p)
    
    def forward(self, tgt, memory, tgt_mask=None, memory_mask=None, tgt_key_padding_mask=None, memory_key_padding_mask=None):
        """
        参数:
            tgt: 目标序列 (batch, tgt_len)
            memory: 编码器输出 (batch, src_len, d_model)
            tgt_mask: 目标序列mask (tgt_len, tgt_len)
            memory_mask: 编码器mask (src_len, src_len)
            tgt_key_padding_mask: 目标padding mask (batch, tgt_len)
            memory_key_padding_mask: 编码器padding mask (batch, src_len)
        返回:
            output: (batch, tgt_len, vocab_size)
        """
        # 嵌入 + 位置编码
        tgt_emb = self.embedding(tgt) * math.sqrt(self.d_model)
        tgt_emb = self.positional_encoding(tgt_emb)
        
        # 解码器
        output = self.transformer_decoder(
            tgt_emb, memory,
            tgt_mask=tgt_mask,
            memory_mask=memory_mask,
            tgt_key_padding_mask=tgt_key_padding_mask,
            memory_key_padding_mask=memory_key_padding_mask
        )
        
        # 输出投影
        output = self.output_projection(output)
        
        return output
    
    def generate_square_subsequent_mask(self, sz):
        """生成因果mask（下三角）"""
        mask = torch.triu(torch.ones(sz, sz), diagonal=1).bool()
        return mask
    
    def greedy_decode(self, start_token, end_token, max_len, memory, memory_key_padding_mask=None):
        """贪婪解码"""
        batch_size = memory.size(0)
        
        # 初始化
        ys = torch.full((batch_size, 1), start_token, dtype=torch.long, device=memory.device)
        finished = torch.zeros(batch_size, dtype=torch.bool, device=memory.device)
        
        for step in range(max_len - 1):
            # 生成mask
            tgt_mask = self.generate_square_subsequent_mask(ys.size(1)).to(memory.device)
            
            # 预测
            out = self.forward(ys, memory, tgt_mask=tgt_mask, memory_key_padding_mask=memory_key_padding_mask)
            next_token = out[:, -1, :].argmax(dim=-1).unsqueeze(1)
            
            # 更新
            ys = torch.cat([ys, next_token], dim=1)
            
            # 检查是否结束
            finished = finished | (next_token == end_token).squeeze()
            if finished.all():
                break
        
        return ys
    
    def beam_search_decode(self, start_token, end_token, max_len, memory, beam_size=3):
        """束搜索解码"""
        batch_size = memory.size(0)
        
        if batch_size > 1:
            raise ValueError("Beam search only supports batch_size=1")
        
        # 编码器输出需要复制beam_size份
        memory = memory.repeat(beam_size, 1, 1)
        
        # 初始化beam
        ys = torch.full((beam_size, 1), start_token, dtype=torch.long, device=memory.device)
        scores = torch.zeros(beam_size, device=memory.device)
        
        # 完整序列
        complete_sequences = []
        complete_scores = []
        
        for step in range(max_len - 1):
            # 生成mask
            tgt_mask = self.generate_square_subsequent_mask(ys.size(1)).to(memory.device)
            
            # 预测
            out = self.forward(ys, memory, tgt_mask=tgt_mask)
            log_probs = F.log_softmax(out[:, -1, :], dim=-1)
            
            # 选择top-k
            top_log_probs, top_indices = log_probs.topk(beam_size, dim=-1)
            
            # 扩展beam
            candidates = []
            for i in range(beam_size):
                for j in range(beam_size):
                    token = top_indices[i, j].item()
                    score = scores[i] + top_log_probs[i, j].item()
                    candidates.append((ys[i].tolist(), score, token))
            
            # 按score排序
            candidates.sort(key=lambda x: x[1], reverse=True)
            candidates = candidates[:beam_size]
            
            # 更新
            new_ys = []
            new_scores = []
            for seq, score, token in candidates:
                if token == end_token or len(seq) >= max_len:
                    complete_sequences.append(seq)
                    complete_scores.append(score)
                    beam_size -= 1
                else:
                    new_ys.append(seq + [token])
                    new_scores.append(score)
            
            if beam_size == 0:
                break
            
            ys = torch.tensor(new_ys, dtype=torch.long, device=memory.device)
            scores = torch.tensor(new_scores, dtype=torch.float32, device=memory.device)
        
        # 返回最佳
        if complete_sequences:
            best_idx = complete_scores.index(max(complete_scores))
            return complete_sequences[best_idx]
        else:
            return ys[0].tolist()


class PositionalEncoding(nn.Module):
    """正弦位置编码"""
    def __init__(self, d_model, dropout=0.1, max_len=5000):
        super(PositionalEncoding, self).__init__()
        self.dropout = nn.Dropout(p=dropout)
        
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model))
        
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        
        pe = pe.unsqueeze(0)
        self.register_buffer('pe', pe)
    
    def forward(self, x):
        x = x + self.pe[:, :x.size(1), :]
        return self.dropout(x)


# 训练示例
def train_seq2seq():
    """Seq2Seq训练示例"""
    import torch.utils.data as data
    
    # 参数
    vocab_size = 10000
    d_model = 256
    nhead = 4
    num_layers = 3
    batch_size = 32
    
    # 数据（模拟）
    src_seq = torch.randint(1, vocab_size, (2000, 50))
    tgt_seq = torch.randint(1, vocab_size, (2000, 40))
    
    # 创建mask
    src_padding_mask = (src_seq == 0)
    tgt_padding_mask = (tgt_seq == 0)
    
    dataset = data.TensorDataset(src_seq, tgt_seq, src_padding_mask, tgt_padding_mask)
    train_loader = data.DataLoader(dataset, batch_size=batch_size, shuffle=True)
    
    # 模型
    model = TransformerDecoderModel(vocab_size, d_model, nhead, num_layers)
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-4)
    criterion = nn.CrossEntropyLoss(ignore_index=0)
    
    # 训练
    model.train()
    for epoch in range(3):
        total_loss = 0
        for src, tgt, src_mask, tgt_mask in train_loader:
            optimizer.zero_grad()
            
            # 编码器
            encoder_layer = nn.TransformerEncoder(
                nn.TransformerEncoderLayer(d_model, nhead, batch_first=True),
                num_layers
            )
            memory = encoder_layer(torch.randn_like(src).abs() * d_model**0.5)  # 简化

            # 解码器（教师强制）
            output = model(tgt, memory, tgt_key_padding_mask=tgt_mask)
            
            # 损失
            output = output[:, :-1, :].contiguous().view(-1, vocab_size)
            tgt_labels = tgt[:, 1:].contiguous().view(-1)
            loss = criterion(output, tgt_labels)
            
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
        
        print(f"Epoch {epoch+1}, Loss: {total_loss/len(train_loader):.4f}")
```

### 4.2 束搜索实现

```python
import torch
import torch.nn.functional as F


def beam_search(model, encoder_output, start_id, end_id, max_len, beam_size=5, length_penalty=0.6):
    """
    束搜索解码
    
    参数:
        model: Seq2Seq模型 (decoder)
        encoder_output: 编码器输出
        start_id: 开始token id
        end_id: 结束token id
        max_len: 最大长度
        beam_size: 束宽
        length_penalty: 长度惩罚
    
    返回:
        best_sequence: 最佳序列
    """
    device = encoder_output.device
    batch_size = encoder_output.size(0)
    
    if batch_size != 1:
        raise ValueError("Beam search only works with batch_size=1")
    
    # 重复encoder_output
    encoder_output = encoder_output.repeat(beam_size, 1, 1)
    
    # 初始化beam
    seqs = torch.full((beam_size, 1), start_id, dtype=torch.long, device=device)
    scores = torch.zeros(beam_size, device=device)
    
    # 完整序列
    complete_seqs = []
    complete_scores = []
    
    # 缓存
    past = None
    
    for step in range(max_len):
        # 使用缓存的key/value进行加速
        if past is None:
            output, past = model.forward_with_cache(seqs, encoder_output, past)
        else:
            output, past = model.forward_with_cache(seqs[:, -1], encoder_output, past, use_cache=True)
        
        # 最后一词的log概率
        log_probs = F.log_softmax(output[:, -1], dim=-1)
        
        # 总分 = 已有点-log + 当前log
        total_scores = scores.unsqueeze(1) + log_probs
        
        # 展平并排序
        total_scores_flat = total_scores.view(-1)
        top_scores, top_indices = total_scores_flat.topk(beam_size, dim=-1)
        
        # 新beam
        new_seqs = []
        new_scores = []
        
        for idx, score in zip(top_indices.tolist(), top_scores.tolist()):
            beam_idx = idx // model.vocab_size
            token_idx = idx % model.vocab_size
            
            current_seq = torch.cat([seqs[beam_idx], torch.tensor([token_idx], device=device)])
            
            if token_idx == end_id or current_seq.size(0) >= max_len:
                # 完成
                penalized_score = score / (current_seq.size(0) ** length_penalty)
                complete_seqs.append(current_seq.tolist())
                complete_scores.append(penalized_score)
            else:
                new_seqs.append(current_seq)
                new_scores.append(score)
        
        if not new_seqs:
            break
        
        seqs = torch.stack(new_seqs)
        scores = torch.tensor(new_scores, device=device)
        
        if len(new_seqs) < beam_size:
            beam_size = len(new_seqs)
    
    # 返回最佳
    if complete_seqs:
        best_idx = complete_scores.index(max(complete_scores))
        return complete_seqs[best_idx]
    else:
        return seqs[0].tolist()


def temperature_sampling(log_probs, temperature=1.0, top_k=0):
    """
    温度采样
    
    参数:
        log_probs: log概率 (vocab_size,)
        temperature: 温度
        top_k: top-k采样，0表示不使用
    
    返回:
        sampled_token: 采样的token id
    """
    if temperature != 1.0:
        log_probs = log_probs / temperature
    
    probs = F.softmax(log_probs, dim=-1)
    
    if top_k > 0:
        top_probs, top_indices = probs.topk(top_k)
        probs = torch.zeros_like(probs)
        probs[top_indices] = top_probs
        probs = probs / probs.sum()
    
    return torch.multinomial(probs, 1).item()
```
