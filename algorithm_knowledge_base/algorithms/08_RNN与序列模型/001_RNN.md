## 1. 算法基础认知

**一句话定义：** RNN 通过隐状态在时间步之间传递信息，使网络能够处理变长序列数据，捕捉时序依赖关系。

**直觉类比：** 普通神经网络像"金鱼记忆"——每次输入都是全新的，不记得之前看过什么。RNN 则像"边读边记的读者"——读每个词时都带着对前文的记忆，理解新内容时参考之前的上下文。这种"记忆传递"使 RNN 能理解"我喜欢苹果，但不喜欢__"这样的上下文依赖。

**历史背景：** RNN 的概念可追溯到 1986 年 Rumelhart 等人的工作。基础的 RNN 在处理长序列时存在梯度消失问题，后来发展出 LSTM（1997）和 GRU（2014）等改进架构。

**算法定位：** 序列建模、时序预测、自然语言处理基础架构。

**前置知识：** 全连接网络、激活函数、梯度下降、PyTorch。

## 2. 核心原理

### 核心思想

RNN 的关键创新是**隐状态（Hidden State）**的循环传递。在每个时间步，RNN 不仅接收当前输入，还接收上一个时间步的隐状态，将两者结合产生新的隐状态和输出。

### 工作流程

1. 初始化隐状态 $h_0$（通常为零向量）
2. 对每个时间步 $t$：
   - 接收输入 $x_t$ 和上一隐状态 $h_{t-1}$
   - 计算新隐状态：$h_t = f(W_{xh} x_t + W_{hh} h_{t-1} + b_h)$
   - 计算输出：$o_t = W_{ho} h_t + b_o$
3. 可使用最后一个隐状态（句子编码）或所有输出（序列标注）

### 关键概念

- **隐状态（Hidden State）**：网络内部的"记忆"，编码了之前所有时间步的信息
- **参数共享**：所有时间步使用相同的权重矩阵，大幅减少参数量
- **沿时间反向传播（BPTT）**：RNN 的反向传播需要沿时间步展开
- **梯度消失/爆炸**：RNN 的核心问题，长序列中梯度指数级衰减或增长

## 3. 数学公式与推导

### 前向传播

给定输入序列 $\{x_1, x_2, \ldots, x_T\}$，RNN 的前向传播为：

$$h_t = \tanh(W_{xh} x_t + W_{hh} h_{t-1} + b_h)$$

$$o_t = W_{ho} h_t + b_o$$

其中：
- $W_{xh} \in \mathbb{R}^{d \times h}$：输入到隐状态的权重
- $W_{hh} \in \mathbb{R}^{h \times h}$：隐状态到隐状态的权重
- $W_{ho} \in \mathbb{R}^{h \times m}$：隐状态到输出的权重

### 等价拼接形式

可将输入和隐状态拼接后用一个大矩阵运算：

$$h_t = \tanh([W_{xh} | W_{hh}] \cdot [x_t; h_{t-1}] + b_h)$$

### 梯度消失分析

反向传播时，梯度经过多步连乘：

$$\frac{\partial h_T}{\partial h_1} = \prod_{t=2}^{T} \frac{\partial h_t}{\partial h_{t-1}} = \prod_{t=2}^{T} W_{hh}^T \cdot \text{diag}(\tanh'(z_t))$$

当 $T$ 很大时，若 $W_{hh}$ 的特征值小于 1，梯度指数衰减（消失）；大于 1 则指数增长（爆炸）。

### 参数量

$$\text{参数量} = (d + h) \times h + h + h \times m + m$$

## 4. 训练过程讲解

### 数据预处理
- 文本序列 → token 序列 → 嵌入向量
- 序列填充（padding）到统一长度
- 构建 (输入, 目标) 对（如语言模型中预测下一个词）

### 迭代过程
1. 前向传播：沿时间步依次计算隐状态和输出
2. 计算损失：所有时间步的损失之和 $\mathcal{L} = \sum_{t=1}^{T} \mathcal{L}_t$
3. BPTT：沿时间步反向传播梯度
4. 更新参数

### 超参数表

| 超参数 | 推荐范围 | 默认 |
|--------|----------|------|
| hidden_size | 64 ~ 512 | 128 |
| num_layers | 1 ~ 4 | 2 |
| lr | 1e-4 ~ 1e-2 | 1e-3 |
| seq_length | 32 ~ 256 | 64 |
| dropout | 0.1 ~ 0.5 | 0.2 |

## 6. 优缺点分析

### 优点
1. **处理变长序列**：可处理任意长度的输入序列
2. **参数共享**：所有时间步共享参数，效率高
3. **上下文感知**：利用历史信息处理当前输入

### 缺点
1. **梯度消失/爆炸**：难以捕捉长距离依赖（>10步）
2. **串行计算**：无法像 CNN 那样并行处理序列
3. **训练不稳定**：对学习率和初始化敏感

### 与同类对比

| 特性 | RNN | CNN | Transformer |
|------|-----|-----|-------------|
| 序列建模 | 天然支持 | 局部窗口 | 全局注意力 |
| 并行性 | 差 | 好 | 好 |
| 长距离依赖 | 弱 | 中 | 强 |
| 参数效率 | 高 | 中 | 低 |

## 7. 调库实现

```python
import torch
import torch.nn as nn

# 使用 PyTorch 的 RNN 模块
class TextClassifier(nn.Module):
    def __init__(self, vocab_size=10000, embed_dim=128, hidden_size=256, num_classes=2):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.rnn = nn.RNN(embed_dim, hidden_size, num_layers=2,
                          batch_first=True, dropout=0.2)
        self.fc = nn.Linear(hidden_size, num_classes)

    def forward(self, x):
        # x: (batch, seq_len)
        embeds = self.embedding(x)  # (batch, seq_len, embed_dim)
        output, hidden = self.rnn(embeds)  # hidden: (num_layers, batch, hidden_size)
        logits = self.fc(hidden[-1])  # 取最后一层的隐状态
        return logits

# 测试
model = TextClassifier()
x = torch.randint(0, 10000, (32, 50))  # batch=32, seq_len=50
logits = model(x)
print(f"输入: {x.shape}")
print(f"输出: {logits.shape}")
print(f"参数量: {sum(p.numel() for p in model.parameters()):,}")
```

## 8. 手工代码实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleRNN:
    """NumPy 风格的 RNN 前向传播（用于理解核心逻辑）"""
    def __init__(self, input_size, hidden_size, output_size):
        self.d = input_size
        self.h = hidden_size
        self.m = output_size
        scale = 0.01
        # 权重初始化
        self.W_xh = torch.randn(input_size, hidden_size) * scale
        self.W_hh = torch.randn(hidden_size, hidden_size) * scale
        self.b_h = torch.zeros(hidden_size)
        self.W_ho = torch.randn(hidden_size, output_size) * scale
        self.b_o = torch.zeros(output_size)

    def forward(self, x_seq):
        """x_seq: (seq_len, input_size)"""
        h = torch.zeros(self.h)
        outputs = []
        for t in range(x_seq.shape[0]):
            h = torch.tanh(x_seq[t] @ self.W_xh + h @ self.W_hh + self.b_h)
            o = h @ self.W_ho + self.b_o
            outputs.append(o)
        return torch.stack(outputs), h

class PyTorchRNN(nn.Module):
    """用 PyTorch 从零实现 RNN"""
    def __init__(self, input_size=64, hidden_size=128, output_size=10):
        super().__init__()
        self.hidden_size = hidden_size
        self.W_xh = nn.Linear(input_size, hidden_size)
        self.W_hh = nn.Linear(hidden_size, hidden_size, bias=False)
        self.W_ho = nn.Linear(hidden_size, output_size)

    def forward(self, x):
        # x: (batch, seq_len, input_size)
        batch_size, seq_len, _ = x.shape
        h = torch.zeros(batch_size, self.hidden_size, device=x.device)
        outputs = []
        for t in range(seq_len):
            h = torch.tanh(self.W_xh(x[:, t, :]) + self.W_hh(h))
            outputs.append(self.W_ho(h))
        return torch.stack(outputs, dim=1), h  # (batch, seq_len, output_size), (batch, hidden_size)

# 测试
model = PyTorchRNN(input_size=32, hidden_size=64, output_size=10)
x = torch.randn(4, 20, 32)  # batch=4, seq_len=20, input_size=32
outputs, h_n = model(x)
print(f"输入: {x.shape}")
print(f"输出序列: {outputs.shape}, 最终隐状态: {h_n.shape}")
print(f"参数量: {sum(p.numel() for p in model.parameters()):,}")
```

## 9-14. 可视化/评估/问题/总结/练习/路径

### 可视化
RNN 的隐状态随时间步的变化可以用折线图展示。每个维度的隐状态值反映了网络对不同信息的"记忆强度"。语言模型中，名词后隐状态会出现明显变化。

### 评估指标
- 语言模型：困惑度（PPL）
- 分类任务：准确率、F1
- 序列标注：token 级准确率

### 常见问题
1. **梯度爆炸**：梯度范数急剧增长 → 使用梯度裁剪（gradient clipping）
2. **梯度消失**：无法学习长距离依赖 → 使用 LSTM/GRU
3. **序列太长**：内存不足 → 使用截断 BPTT（TBPTT）

### 练习题

**题1：** RNN 的参数共享意味着什么？为什么不用每个时间步独立的参数？

**参考答案：** 参数共享指所有时间步使用相同的 $W_{xh}$、$W_{hh}$ 等权重。好处：(1) 大幅减少参数量；(2) 模型能处理任意长度的序列；(3) 同一特征在不同位置可以用相同方式处理。如果每步用不同参数，模型无法泛化到未见过的序列长度。

**题2（开放）：** RNN 为什么难以被 Transformer 完全替代？

**参考答案思路：** RNN 的串行性质在某些场景反而是优势——在线推理时只需维护一个隐状态，内存开销恒定，适合流式处理（实时语音识别、在线翻译）。Transformer 的注意力机制复杂度随序列长度二次增长，而 RNN 是线性的。

### 学习路径
- 前置：全连接网络、梯度下降、BPTT
- 平行：CNN（对比序列 vs 空间建模）
- 进阶：LSTM、GRU、双向 RNN、Transformer
- 推荐：Goodfellow et al., "Deep Learning" 第10章

## 11. 常见问题与易错点

### 常见问题
**Q1: 训练不收敛？**
- 检查学习率是否合适
- 检查数据是否正确归一化
- 确认损失函数是否匹配任务

**Q2: 过拟合严重？**
- 增加数据量或使用数据增强
- 添加正则化（L1/L2/Dropout）
- 使用早停策略

**Q3: 超参数如何选？**
- 网格搜索或随机搜索
- 贝叶斯优化
- 参考论文推荐值

### 易错点
1. 数据泄露：预处理时使用测试集信息
2. 随机种子：忘记设置导致不可复现
3. 维度错误：输入shape与模型不匹配
4. 梯度问题：需要适当初始化和裁剪
5. 评估偏差：在训练集上评估
