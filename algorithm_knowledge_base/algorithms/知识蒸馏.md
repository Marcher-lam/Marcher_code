# 知识蒸馏学习文档

## 1. 算法基础认知

知识蒸馏（Knowledge Distillation）是一种模型压缩技术，其核心思想是将大型复杂模型（称为教师模型，Teacher Model）所学习到的知识"蒸馏"到一个更小更高效的学生模型（Student Model）中。这种技术最早由Hinton等人于2015年在论文《Distilling the Knowledge in a Neural Network》中提出。

传统模型压缩方法（如剪枝、量化）直接删除或简化参数，往往会造成性能下降。而知识蒸馏通过让学生模型学习教师模型的"软标签"（Soft Labels），保留了模型内部的dark knowledge，实现了"教师"到"学生"的知识传递。

### 1.1 知识蒸馏的本质

神经网络的知识不仅仅体现在预测的标签上，更体现在：

1. **logits输出**：未归一化的输出向量，包含类别间的相对关系
2. **中间表示**：隐藏层的激活模式
3. **特征图**：卷积层的特征响应
4. **注意力权重**：各层之间的注意力分布

知识蒸馏正是通过让学生模型学习这些"暗知识"，实现高效且性能接近的模型。

### 1.2 应用场景

1. **模型压缩**：将大模型部署到资源受限的设备
2. **模型集成**：将多个模型的知识整合到单个模型
3. **持续学习**：在保持旧任务性能的同时学习新任务
4. **跨架构迁移**：不同架构之间的知识传递

## 2. 核心原理

### 2.1 基础知识蒸馏

设教师模型的logits为 $z_t$，学生模型的logits为 $z_s$，真实标签为 $y$，温度为 $T$，则：

**教师损失（硬标签）**：
$$\mathcal{L}_{hard} = \text{CE}(y, \text{softmax}(z_s))$$

**蒸馏损失（软标签）**：
$$\mathcal{L}_{soft} = \text{KL}(y_t, y_s) = \text{softmax}(z_t/T) \log\frac{\text{softmax}(z_t/T)}{\text{softmax}(z_s/T)}$$

**总损失**：
$$\mathcal{L} = \alpha \cdot \mathcal{L}_{hard} + (1-\alpha) \cdot T^2 \cdot \mathcal{L}_{soft}$$

其中 $T^2$ 是温度缩放因子，用于补偿softmax在高温下的梯度尺度。

### 2.2 温度参数

温度 $T$ 控制了softmax的"软度"：

- $T = 1$：标准softmax
- $T > 1$：分布更均匀，类别间的差异被压缩
- $T \to \infty$：接近均匀分布
- $T \to 0$：趋近于argmax

高温下的softmax使得教师模型类别间的相对关系更加清晰：

$$\text{softmax}(z_i/T) = \frac{\exp(z_i/T)}{\sum_j \exp(z_j/T)}$$

### 2.3 高级蒸馏方法

**特征蒸馏**：直接匹配中间层的特征表示
$$\mathcal{L}_{feat} = \|f_s - f_t\|^2$$

**注意力蒸馏**：匹配注意力权重
$$\mathcal{L}_{attn} = \|\text{Attention}(Q_s, K_s, V_s) - \text{Attention}(Q_t, K_t, V_t)\|^2$$

**关系蒸馏**：匹配样本间的关系
$$\mathcal{L}_{rel} = \|\text{sim}(x_i, x_j) - \text{sim}(x_i', x_j')\|^2$$

---

## 3. 数学推导

### 3.1 KL散度

蒸馏损失使用KL散度衡量分布差异：

$$D_{KL}(P \| Q) = \sum_i P(i) \log \frac{P(i)}{Q(i)}$$

代入软标签：
$$D_{KL}(y_t \| y_s) = \sum_i y_t^{(i)} \log y_t^{(i)} - \sum_i y_t^{(i)} \log y_s^{(i)}$$

梯度：
$$\frac{\partial D_{KL}}{\partial z_s} = \text{softmax}(z_s/T) - \text{softmax}(z_t/T)$$

### 3.2 损失权重分析

设 $\alpha$ 为损失权重，则总损失为：

$$\mathcal{L} = \alpha \mathcal{L}_{hard} + (1-\alpha) T^2 \mathcal{L}_{soft}$$

实践中往往设置 $\alpha$ 和 $T$ 的常用组合：

| 场景 | $\alpha$ | $T$ |
|------|---------|------|
| 一般 | 0.5 | 4-20 |
| 小学生 | 0.3 | 10-20 |
| 特征蒸馏 | 0.5 | 1 |

## 4. 实现代码

### 4.1 基础知识蒸馏

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class KnowledgeDistillationLoss(nn.Module):
    """知识蒸馏损失"""
    def __init__(self, alpha=0.5, temperature=4.0):
        super(KnowledgeDistillationLoss, self).__init__()
        self.alpha = alpha
        self.temperature = temperature
    
    def forward(self, student_logits, teacher_logits, labels):
        """
        参数:
            student_logits: 学生模型输出 (batch, num_classes)
            teacher_logits: 教师模型输出 (batch, num_classes)
            labels: 真实标签 (batch,)
        """
        # 硬标签损失
        hard_loss = F.cross_entropy(student_logits, labels)
        
        # 软标签损失
        soft_loss = F.kl_div(
            F.log_softmax(student_logits / self.temperature, dim=-1),
            F.softmax(teacher_logits / self.temperature, dim=-1),
            reduction='batchmean'
        ) * (self.temperature ** 2)
        
        # 总损失
        loss = self.alpha * hard_loss + (1 - self.alpha) * soft_loss
        
        return loss


def train_with_distillation(student_model, teacher_model, train_loader, 
                           optimizer, alpha=0.5, temperature=4.0, device='cpu'):
    """知识蒸馏训练"""
    teacher_model.eval()  # 教师模型不更新
    student_model.train()
    
    criterion = KnowledgeDistillationLoss(alpha, temperature)
    
    for student_batch, labels in train_loader:
        student_batch = student_batch.to(device)
        labels = labels.to(device)
        
        # 获取教师输出
        with torch.no_grad():
            teacher_logits = teacher_model(student_batch)
        
        # 获取学生输出
        student_logits = student_model(student_batch)
        
        # 计算损失
        loss = criterion(student_logits, teacher_logits, labels)
        
        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    
    return loss.item()


# 示例
class SimpleModel(nn.Module):
    """简单的分类模型"""
    def __init__(self, input_dim, hidden_dim, num_classes):
        super(SimpleModel, self).__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, num_classes)
        )
    
    def forward(self, x):
        return self.net(x)


def demo_distillation():
    """知识蒸馏演示"""
    # 数据

    train_loader = torch.utils.data.DataLoader(dataset, batch_size=64, shuffle=True)
    
    # 教师模型（大模型）
    teacher_model = SimpleModel(784, 512, 10)
    teacher_model.load_state_dict(torch.load('teacher.pth') if False else {
        'net.0.weight': torch.randn(512, 784) * 0.01,
```

### 4.2 中间特征蒸馏

```python
class FeatureDistillationLoss(nn.Module):
    """特征蒸馏损失"""
    def __init__(self, layer_mappings=None, loss_type='mse'):
        super(FeatureDistillationLoss, self).__init__()
        self.layer_mappings = layer_mappings  # {student_layer: teacher_layer}
        self.loss_type = loss_type
    
    def forward(self, student_features, teacher_features):
        """
        参数:
            student_features: dict, {layer_name: features}
            teacher_features: dict, {layer_name: features}
        """
        loss = 0
        for s_layer, t_layer in self.layer_mappings.items():
            s_feat = student_features[s_layer]
            t_feat = teacher_features[t_layer]
            
            # 维度对齐（如有需要）
            if s_feat.shape != t_feat.shape:
                s_feat = self.adjust_dim(s_feat, t_feat.shape)
            
            if self.loss_type == 'mse':
                loss += F.mse_loss(s_feat, t_feat)
            elif self.loss_type == 'cosine':
                loss += 1 - F.cosine_similarity(s_feat, t_feat).mean()
        
        return loss
    
    def adjust_dim(self, x, target_shape):
        """调整维度"""
        if x.shape[1] != target_shape[1]:
            # 使用1x1卷积调整通道数
            x = F.adaptive_avg_pool2d(x, (1, 1))
            x = x.view(x.size(0), -1)
        return x


class CombinedDistillationLoss(nn.Module):
    """组合蒸馏损失"""
    def __init__(self, alpha=0.5, temperature=4.0, beta=0.01):
        super(CombinedDistillationLoss, self).__init__()
        self.alpha = alpha
        self.temperature = temperature
        self.beta = beta
        
        self.kd_loss = KnowledgeDistillationLoss(alpha, temperature)
        self.feat_loss = FeatureDistillationLoss()
    
    def forward(self, student_logits, teacher_logits, student_features, 
               teacher_features, labels):
        # Logits蒸馏
        kd_loss = self.kd_loss(student_logits, teacher_logits, labels)
        
        # 特征蒸馏
        feat_loss = self.feat_loss(student_features, teacher_features)
        
        # 总损失
        loss = kd_loss + self.beta * feat_loss
        
        return loss
```

### 4.3 注意力蒸馏

```python
class AttentionDistillationLoss(nn.Module):
    """注意力蒸馏损失"""
    def __init__(self):
        super(AttentionDistillationLoss, self).__init__()
    
    def forward(self, student_attn, teacher_attn):
        """
        注意力形状: (batch, num_heads, seq_len, seq_len)
        """
        # 展平空间维度
        student_attn = student_attn.view(student_attn.size(0), -1)
        teacher_attn = teacher_attn.view(teacher_attn.size(0), -1)
        
        # 计算差异
        loss = F.mse_loss(student_attn, teacher_attn)
        
        return loss


def get_attention_weights(model, x):
    """提取注意力权重"""
    attention_weights = []
    
    def hook(module, input, output_attn):
        attention_weights.append(output_attn)
    
    # 注册hook
    hooks = []
    for name, module in model.named_modules():
        if 'attention' in name.lower():
            hooks.append(module.register_forward_hook(hook))
    
    with torch.no_grad():
        model(x)
    
    # 移除hook
    for hook in hooks:
        hook.remove()
    
    return attention_weights
```

```python
def self_distillation_train(model, train_loader, optimizer, num_stages=3):
    """
    自蒸馏：使用模型的历史版本作为教师
    
    参数:
        num_stages: 蒸馏轮数
    """
    for stage in range(num_stages):
        # 当前教师：模型的 EMA 版本
        teacher_model = copy.deepcopy(model)
        for param, ema_param in zip(model.parameters(), teacher_model.parameters()):
            if ema_param requires_grad:
                # EMA更新
                ema_param.data = 0.99 * param.data + 0.01 * ema_param.data
        
        # 教师不更新
        for param in teacher_model.parameters():
            param.requires_grad = False
        
        # 使用知识蒸馏训练
        criterion = KnowledgeDistillationLoss(alpha=0.5, temperature=4.0)
        
        model.train()
        for x, y in train_loader:
            with torch.no_grad():
                teacher_logits = teacher_model(x)
            
            student_logits = model(x)
            loss = criterion(student_logits, teacher_logits, y)
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
        
        print(f"Stage {stage+1} complete")
        
        # 清理
        del teacher_model
    
    return model
```
