# 扩散模型学习文档

## 1. 算法基础认知

扩散模型（Diffusion Model）是一类基于概率的生成模型，其核心思想是通过一个逐步添加噪声的正向过程（Forward Process）和一个逐步去噪的逆向过程（Reverse Process）来学习数据分布。扩散模型在2020年代快速发展，特别是在图像生成领域取得了令人瞩目的成就，如DALL-E、Stable Diffusion、Midjourney等。

扩散模型的理论基础来源于非平衡热力学（Non-equilibrium Thermodynamics）。它模拟了物理世界中粒子从高浓度区域向低浓度区域扩散的过程。在机器学习中，数据通过多步噪声污染被破坏，而模型学习如何逆转这一过程恢复原始数据。

### 1.1 扩散模型的核心思想

扩散模型的工作原理可以类比为"打磨原石"：

1. **正向过程（加噪）**：将原始数据逐步添加噪声，最终变成纯噪声
2. **逆向过程（去噪）**：学习如何从噪声恢复原始数据

这个过程类似于从一幅完成的画作逐步刮掉颜料，最终只剩画布，然后模型学习如何一步一步恢复画作。

### 1.2 扩散模型的发展历程

1. **DDPM（2020）**：Denoising Diffusion Probabilistic Models，基础扩散模型
2. **DDIM（2021）**：Denoising Diffusion Implicit Models，隐式扩散，加速采样
3. **Stable Diffusion（2022）**：潜在扩散模型，效率大幅提升
4. **ControlNet（2023）**：条件控制生成
5. **SDEdit（2022）**：编辑式生成

## 2. 核心原理

### 2.1 正向过程（Forward Process）

正向过程是一个固定的马尔可夫链（Markov Chain），逐步向数据添加高斯噪声：

$$q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t} x_{t-1}, \beta_t \mathbf{I})$$

其中 $\beta_t$ 是第 $t$ 步的噪声方差调度，通常 $0.0001 < \beta_t < 0.002$。

**关键性质**：由于高斯噪声的可加性，可以直接计算任意时间步 $t$ 的分布：

$$q(x_t | x_0) = \mathcal{N}(x_t; \sqrt{\bar{\alpha}_t} x_0, (1-\bar{\alpha}_t) \mathbf{I})$$

其中 $\alpha_t = 1 - \beta_t$，$\bar{\alpha}_t = \prod_{i=1}^{t} \alpha_i$。

### 2.2 逆向过程（Reverse Process）

逆向过程是学习的去噪过程，同样是高斯马尔可夫链：

$$p_\theta(x_{t-1} | x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \sigma_t^2 \mathbf{I})$$

**目标**：预测噪声 $\epsilon$，而不是直接预测均值。设 $x_t$ 为第 $t$ 步的有噪声样本，$x_0$ 为原始样本：

$$x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon$$

预测 $\hat{\epsilon} = \epsilon_\theta(x_t, t)$，则：

$$\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}} \left( x_t - \frac{1-\alpha_t}{\sqrt{1-\bar{\alpha}_t}} \hat{\epsilon} \right)$$

### 2.3 训练目标

简化损失函数（简化的L2损失）：

$$\mathcal{L}_{simple} = \| \epsilon - \epsilon_\theta(x_t, t) \|^2$$

更完整的ELBO（Evidence Lower Bound）损失：

$$\mathcal{L}_{ELBO} = \mathbb{E}_{t, \epsilon} \left[ \| \epsilon - \epsilon_\theta(x_t, t) \|^2 \right]$$

## 3. 数学公式与推导

### 3.1 方差调度

常见的方差调度策略：

**线性调度（Linear）**：
$$\beta_t = \beta_{start} + \frac{t}{T} (\beta_{end} - \beta_{start})$$

**余弦调度（Cosine）**：
$$\bar{\alpha}_t = \frac{f(t)}{f(0)}, f(t) = \cos^2 \left( \frac{t/T + s}{1+s} \cdot \frac{\pi}{2} \right)$$

### 3.2 采样过程

**DDPM采样**：
```python
# x_T ~ N(0, I)
for t in reversed(range(T)):
    z = N(0, I) if t > 0 else 0
    x_{t-1} = (x_t - (1-alpha)/sqrt(1-bar) * eps_theta) / sqrt(alpha) + sigma * z
```

**DDIM采样**（确定性）：
```python
for t in reversed(range(T)):
    x_{t-1} = sqrt(alpha_{t-1}) * (x_t - sqrt(1-alpha_t) * eps) / sqrt(alpha_t) 
            + sqrt(1-alpha_{t-1}) * eps
```

### 3.3 条件生成

条件扩散模型使用额外信息 $y$（文本、图像等）：

$$p_\theta(x | y) = \mathcal{N}(x; \mu_\theta(x_t, t, y), \sigma_t^2 \mathbf{I})$$

通过Classifier-Free Guidance：
$$\hat{\epsilon} = \epsilon_\theta(x_t, t) + w \cdot (\epsilon_\theta(x_t, t, y) - \epsilon_\theta(x_t, t))$$

import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class DiffusionSchedule:
    """扩散模型的时间调度"""
    
    @staticmethod
    def get_linear_schedule(beta_start=0.0001, beta_end=0.02, num_steps=1000):
        """线性调度"""
        betas = torch.linspace(beta_start, beta_end, num_steps)
        alphas = 1 - betas
        alphas_cumprod = torch.cumprod(alphas, dim=0)
        alphas_cumprod_prev = F.pad(alphas_cumprod[:-1], (1, 0), value=1.0)
        
        return {
            'betas': betas,
            'alphas': alphas,
            'alphas_cumprod': alphas_cumprod,
            'alphas_cumprod_prev': alphas_cumprod_prev
        }
    
    @staticmethod
    def get_cosine_schedule(num_steps, s=0.008):
        """余弦调度"""
        steps = torch.arange(num_steps + 1, dtype=torch.float32)
        x = (steps / num_steps + s) / (1 + s) * math.pi / 2
        alphas_cumprod = torch.cos(x) ** 2
        alphas_cumprod = alphas_cumprod / alphas_cumprod[0]
        
        betas = alphas_cumprod[1:] / alphas_cumprod[:-1]
        betas = torch.clamp(betas, 0.0001, 0.9999)
        
        alphas = 1 - betas
        alphas_cumprod_prev = F.pad(alphas_cumprod[:-1], (1, 0), value=1.0)
        
        return {
            'betas': betas,
            'alphas': alphas,
            'alphas_cumprod': alphas_cumprod,
            'alphas_cumprod_prev': alphas_cumprod_prev
        }


class SimpleUNet(nn.Module):
    """简化的U-Net用于扩散模型"""
    def __init__(self, in_channels=3, out_channels=3, time_dim=256, base_channels=64):
        super(SimpleUNet, self).__init__()
        
        self.time_mlp = nn.Sequential(
            nn.Linear(1, time_dim),
            nn.SiLU(),
            nn.Linear(time_dim, time_dim)
        )
        
        # 下采样
        self.down1 = self._make_block(in_channels + time_dim, base_channels)
        self.down2 = self._make_block(base_channels, base_channels * 2)
        self.down3 = self._make_block(base_channels * 2, base_channels * 4)
        
        # 中间层
        self.mid = self._make_block(base_channels * 4, base_channels * 4)
        
        # 上采样
        self.up1 = self._make_block(base_channels * 4, base_channels * 2)
        self.up2 = self._make_block(base_channels * 2, base_channels)
        self.up3 = nn.Conv2d(base_channels, out_channels, 3, padding=1)
        
        # 时间维度的处理
        self.time_conv = nn.Conv2d(time_dim, time_dim, 3, padding=1)
    
    def _make_block(self, in_ch, out_ch):
        return nn.Sequential(
            nn.Conv2d(in_ch, out_ch, 3, padding=1),
            nn.GroupNorm(32, out_ch),
            nn.SiLU(),
            nn.Conv2d(out_ch, out_ch, 3, padding=1),
            nn.GroupNorm(32, out_ch),
            nn.SiLU()
        )
    
    def forward(self, x, t):
        """前向传播
        
        x: (batch, channels, height, width)
        t: (batch,) 时间步
        """
        # 时间嵌入
        t_emb = t.float().unsqueeze(-1) / 1000
        t_emb = self.time_mlp(t_emb)
        t_emb = t_emb.unsqueeze(-1).unsqueeze(-1)
        
        # 下采样
        x1 = self.down1(torch.cat([x, t_emb.expand_as(x)], dim=1))
        x2 = self.down2(F.max_pool2d(x1, 2) + self.time_conv(F.interpolate(t_emb, scale_factor=2)))
        
        # 中间
        x3 = self.mid(F.max_pool2d(x2, 2))
        
        # 上采样
        x = self.up1(F.interpolate(x3, scale_factor=2))
        x = self.up2(F.interpolate(x, scale_factor=2))
        x = self.up3(x)
        
        return x


class DDPM(nn.Module):
    """Denoising Diffusion Probabilistic Model"""
    def __init__(self, model, num_steps=1000, beta_schedule='linear'):
        super(DDPM, self).__init__()
        
        self.model = model
        self.num_steps = num_steps
        
        # 获取调度
        if beta_schedule == 'linear':
            self.schedule = DiffusionSchedule.get_linear_schedule(num_steps=num_steps)
        else:
            self.schedule = DiffusionSchedule.get_cosine_schedule(num_steps)
        
        # 注册为buffer
        for key, val in self.schedule.items():
            self.register_buffer(key, val)
    
    def q_sample(self, x0, t, noise=None):
        """正向过程：添加噪声
        
        x0: 原始图像
        t: 时间步
        noise: 噪声（可选）
        """
        if noise is None:
            noise = torch.randn_like(x0)
        
        sqrt_alpha_cumprod_t = torch.sqrt(self.alphas_cumprod[t]).view(-1, 1, 1, 1)
        sqrt_one_minus_alpha_cumprod_t = torch.sqrt(1 - self.alphas_cumprod[t]).view(-1, 1, 1, 1)
        
        return sqrt_alpha_cumprod_t * x0 + sqrt_one_minus_alpha_cumprod_t * noise
    
    def p_mean_variance(self, x, t):
        """逆向过程：计算均值和方差"""
        batch_size = x.shape[0]
        
        # 预测噪声
        t_batch = t * torch.ones(batch_size, dtype=torch.long, device=x.device)
        predicted_noise = self.model(x, t_batch)
        
        # 计算均值
        sqrt_alpha_t = torch.sqrt(self.alphas[t]).view(-1, 1, 1, 1)
        beta_t = self.betas[t].view(-1, 1, 1, 1)
        
        predicted_noise_clipped = torch.clamp(predicted_noise, -10, 10)
        model_mean = (x - (1 - sqrt_alpha_t) / torch.sqrt(1 - self.alphas_cumprod[t]).view(-1, 1, 1, 1) * predicted_noise_clipped) / sqrt_alpha_t
        
        # 最后一个时间步不需要噪声
        variance = torch.where(t == 0, torch.zeros_like(x), beta_t)
        
        return model_mean, variance
    
    def p_sample(self, x, t):
        """采样：单步去噪"""
        model_mean, variance = self.p_mean_variance(x, t)
        
        noise = torch.randn_like(x) if t[0] > 0 else torch.zeros_like(x)
        
        return model_mean + torch.sqrt(variance) * noise
    
    @torch.no_grad()
    def sample(self, shape, device):
        """完整采样过程"""
        x = torch.randn(shape, device=device)
        
        for t in range(self.num_steps - 1, -1, -1):
            t_batch = torch.full((shape[0],), t, dtype=torch.long, device=device)
            x = self.p_sample(x, t_batch)
        
        return x
    
    def training_step(self, x0):
        """训练步骤"""
        batch_size = x0.shape[0]
        t = torch.randint(0, self.num_steps, (batch_size,), device=x0.device)
        noise = torch.randn_like(x0)
        
        # 加噪
        xt = self.q_sample(x0, t, noise)
        
        # 预测噪声
        predicted_noise = self.model(xt, t)
        
        # 损失
        loss = F.mse_loss(predicted_noise, noise)
        
        return loss


def train_diffusion():
    """训练扩散模型示例"""
    import torchvision
    from torch.utils.data import DataLoader
    
    # 数据（简化的随机数据）
    x_train = torch.randn(1000, 3, 32, 32)
    train_loader = DataLoader(x_train, batch_size=32, shuffle=True)
    
    # 模型
    model = SimpleUNet(in_channels=3, out_channels=3)
    ddpm = DDPM(model, num_steps=1000)
    
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-4)
    
    # 训练
    ddpm.train()
    for epoch in range(10):
        total_loss = 0
        for batch in train_loader:
            loss = ddpm.training_step(batch)
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
        
        print(f"Epoch {epoch+1}, Loss: {total_loss/len(train_loader):.4f}")
    
    return ddpm
```

class ConditionalDDPM(nn.Module):
    """条件扩散模型"""
    def __init__(self, model, num_steps=1000):
        super(ConditionalDDPM, self).__init__()
        
        self.model = model  # 接收条件输入
        self.num_steps = num_steps
        
        schedule = DiffusionSchedule.get_linear_schedule(num_steps=num_steps)
        for key, val in schedule.items():
            self.register_buffer(key, val)
    
    @torch.no_grad()
    def sample(self, shape, condition, guidance_scale=3.0):
        """带条件的采样
        
        condition: 条件输入（如文本embedding）
        guidance_scale: Guidance权重
        """
        x = torch.randn(shape, device=condition.device)
        
        for t in range(self.num_steps - 1, -1, -1):
            t_batch = torch.full((shape[0],), t, dtype=torch.long, device=condition.device)
            
            # 预测噪声（有条件和无条件）
            if guidance_scale > 1:
                noise_uncond = self.model(x, t_batch, None)
                noise_cond = self.model(x, t_batch, condition)
                
                # Classifier-free guidance
                noise = noise_uncond + guidance_scale * (noise_cond - noise_uncond)
            else:
                noise = self.model(x, t_batch, condition)
            
            # 去噪步骤
            alpha_t = self.alphas[t]
            alpha_cumprod_t = self.alphas_cumprod[t]
            
            x = (x - (1 - alpha_t) / torch.sqrt(1 - alpha_cumprod_t) * noise) / torch.sqrt(alpha_t)
            
            if t > 0:
                beta_t = self.betas[t]
                x += torch.sqrt(beta_t) * torch.randn_like(x)
        
        return x
```

### 5.1 FID分数

```python
def compute_fid(real_features, generated_features):
    """计算FID分数"""
    from scipy import linalg
    
    mu1, sigma1 = real_features.mean(axis=0), np.cov(real_features, rowvar=False)
    mu2, sigma2 = generated_features.mean(axis=0), np.cov(generated_features, rowvar=False)
    
    diff = mu1 - mu2
    covmean = linalg.sqrtm(sigma1 @ sigma2)
    
    if np.iscomplexobj(covmean):
        covmean = covmean.real
    
    fid = diff @ diff + np.trace(sigma1 + sigma2 - 2 * covmean)
    
    return fid
```

## 8. 练习题

### 8.1 简答题

1. **为什么扩散模型需要很多步？**
   - **答案**：每步只做微小的噪声去除，多步累积实现复杂分布学习

2. **DDPM和DDIM的区别？**
   - **答案**：DDIM是确定性的，可以更少步数采样

3. **Classifier-Free Guidance的作用？**
   - **答案**：在无条件模型基础上添加条件引导，提升质量
