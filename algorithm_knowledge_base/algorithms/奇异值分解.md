# 奇异值分解 学习文档

> 矩阵分解方法，将任意矩阵分解为三个特殊矩阵的乘积，用于降维、压缩、去噪等

---

## 1. 算法基础认知

### 一句话定义
奇异值分解（SVD）是将任意实数矩阵 $A_{m \times n}$ 分解为 $U \Sigma V^T$ 的形式，其中 $U$ 和 $V$ 是正交矩阵，$\Sigma$ 是对角矩阵。

### 直觉类比
想象你有一张高清图片（矩阵），SVD就像把这张图片分解成三个部分：旋转、缩放、再旋转。通过只保留最大的几个缩放值（奇异值），你可以得到这张图片的压缩版本，同时保留大部分信息。

### 历史背景
SVD由数学家 Eugenio Beltrami 在1873年首次提出，后来在1908年由Carl Runge独立重新发现。20世纪中后期，SVD成为数值线性代数和统计学中的核心工具，广泛应用于主成分分析（PCA）、推荐系统、图像压缩等领域。

### 算法定位
- 类型：无监督学习 → 矩阵分解、降维
- 输出：矩阵 $U, \Sigma, V^T$
- 模型类型：线性代数方法、矩阵分解

### 前置知识
- 线性代数：矩阵乘法、正交矩阵、特征值/特征向量
- 线性代数：秩、特征值分解（EVD）
- 数值分析：矩阵范数、低秩近似
- Python基础：NumPy、线性代数函数

## 2. 核心原理

### 2.1 核心思想
SVD的核心思想是：**任意矩阵 $A$ 可以表示为三个特殊矩阵的乘积，其中对角矩阵 $\Sigma$ 包含了矩阵的"奇异值"，代表了矩阵在各个方向上的"能量"或"重要性"**。

对于 $A_{m \times n}$，SVD将其分解为：
$$A = U \Sigma V^T$$

其中：
- $U_{m \times m}$：左奇异向量矩阵，列是正交的
- $\Sigma_{m \times n}$：对角矩阵，对角线元素是非负实数 $\sigma_1 \geq \sigma_2 \geq ... \geq \sigma_r \geq 0$（奇异值），$r = \text{rank}(A)$
- $V_{n \times n}^T$：右奇异向量矩阵，$V$ 的列是正交的

### 2.2 工作流程

1. **输入矩阵**
   - 输入：矩阵 $A \in \mathbb{R}^{m \times n}$
   - 确定秩 $r = \text{rank}(A)$

2. **计算SVD**
   - 计算 $AA^T$ 的特征分解得到 $U$ 和 $\Sigma^2$
   - 计算 $A^T A$ 的特征分解得到 $V$
   - 或者使用数值算法（如Golub-Kahan算法）直接计算

3. **截断SVD（可选）**
   - 选择前 $k$ 个奇异值（$k < r$）
   - 构造秩为 $k$ 的近似矩阵：$A_k = U_k \Sigma_k V_k^T$

4. **输出结果**
   - 完整的 $U, \Sigma, V^T$，或截断版本

### 2.3 关键概念解释

- **奇异值**：$\sigma_i$，表示矩阵在第 $i$ 个方向上的"能量"
- **左奇异向量**：$U$ 的列，是 $AA^T$ 的特征向量
- **右奇异向量**：$V$ 的列，是 $A^T A$ 的特征向量
- **弗罗贝尼乌斯范数**：$\| A \|_F = \sqrt{\sum_{i=1}^r \sigma_i^2}$
- **低秩近似**：用前 $k$ 个奇异值近似原矩阵，实现降维或压缩

### 2.4 几何/直观解释
从几何角度看，SVD表示：任何线性变换 $A$ 可以分解为三个简单的变换：
1. **旋转/反射**（$V^T$）：将输入向量旋转到新的坐标系
2. **缩放**（$\Sigma$）：在各个坐标轴上按奇异值缩放
3. **旋转/反射**（$U$）：再次旋转到输出空间

因此，奇异值表示矩阵在各个方向上的"拉伸"程度。最大的奇异值对应的方向是矩阵"最重要的方向"。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 | 维度 |
|------|------|------|
| $A$ | 输入矩阵 | $m \times n$ |
| $m$ | 行数 | 标量 |
| $n$ | 列数 | 标量 |
| $r$ | 矩阵秩 | 标量，$r \leq \min(m, n)$ |
| $U$ | 左奇异向量矩阵 | $m \times m$ （或 $m \times r$） |
| $\Sigma$ | 奇异值对角矩阵 | $m \times n$ （或 $r \times r$） |
| $V$ | 右奇异向量矩阵 | $n \times n$ （或 $n \times r$） |
| $\sigma_i$ | 第 $i$ 个奇异值 | 标量，$\sigma_1 \geq \sigma_2 \geq ... \geq 0$ |

### 3.2 问题形式化
给定矩阵 $A \in \mathbb{R}^{m \times n}$，我们希望找到分解：
$$A = U \Sigma V^T$$

其中 $U$ 和 $V$ 是正交矩阵（$\(U^T U = I\), \(V^T V = I$），$\Sigma$ 是对角矩阵，对角线元素非负且非增。

### 3.3 目标函数/损失函数
SVD本身不是优化问题，而是矩阵分解的存在性定理。但可以将其视为**优化问题**：找到秩为 $k$ 的矩阵 $A_k$ 使得弗罗贝尼乌斯范数误差最小：

$$\min_{\text{rank}(X) \leq k} \| A - X \|_F$$

Eckart-Young定理证明：最优解就是截断SVD：$\(A_k = U_k \Sigma_k V_k^T$。

### 3.4 推导过程

**Step 1: 与特征值分解的关系**

考虑 $AA^T$ 和 $A^T A$：
- $AA^T$ 是 $m \times m$ 半正定矩阵，有特征值分解：$AA^T = U \Lambda U^T$
- $A^T A$ 是 $n \times n$ 半正定矩阵，有特征值分解：$A^T A = V \Lambda V^T$

可以证明：$\Lambda$ 相同，$\sigma_i = \sqrt{\lambda_i}$。

**Step 2: 构造SVD**

令 $U$ 是 $AA^T$ 的特征向量矩阵（正交），$\Sigma$ 的对角线是 $\sqrt{\lambda_i}$（补零使尺寸匹配），$V$ 是 $A^T A$ 的特征向量矩阵。

那么可以验证：$A = U \Sigma V^T$。

**Step 3: 截断SVD的最优性**

对于秩为 $k$ 的近似，$A_k = U_k \Sigma_k V_k^T$ 最小化 $\| A - A_k \|_F$。

定理（Eckart-Young）：
$$\min_{\text{rank}(X) \leq k} \| A - X \|_F = \sqrt{\sum_{i=k+1}^r \sigma_i^2}$$

即，用前 $k$ 个奇异值近似，丢弃的误差是剩余奇异值的平方和。

### 3.5 最终解/算法步骤

**SVD算法（概念性）**：

```
输入：矩阵 A (m×n)
输出：U (m×m), Σ (m×n, 对角), Vᵀ (n×n)

1. 计算 AAᵀ 并特征值分解：AAᵀ = U Λ Uᵀ
2. 计算 AᵀA 并特征值分解：AᵀA = V Λ Vᵀ
3. 奇异值 σᵢ = √λᵢ，构成对角矩阵 Σ
4. 如果 m > n 或 n > m，适当补零使 Σ 尺寸为 m×n
5. 返回 U, Σ, Vᵀ
```

**截断SVD（降维）**：

```
输入：矩阵 A, 目标秩 k
输出：A_k ≈ U_k Σ_k V_kᵀ

1. 计算完整SVD：A = U Σ Vᵀ
2. 取前 k 列/行：U_k (m×k), Σ_k (k×k), V_k (n×k)
3. 计算近似：A_k = U_k Σ_k V_kᵀ
4. 返回 A_k, U_k, Σ_k, V_kᵀ
```

### 4.2 参数初始化

SVD不是迭代算法，没有参数初始化。但截断SVD需要选择秩 $k$。

```python
def choose_k_by_explained_variance(sigma, threshold=0.95):
    """
    根据解释方差比例选择 k
    
    参数:
        sigma: 奇异值数组（降序）
        threshold: 解释方差比例阈值（如0.95表示保留95%方差）
    
    返回:
        选择的 k
    """
    total_var = np.sum(sigma ** 2)
    explained = np.cumsum(sigma ** 2) / total_var
    
    # 找到第一个达到阈值的k
    k = np.argmax(explained >= threshold) + 1
    return k, explained

# 示例：选择保留95%方差的k
# k, explained = choose_k_by_explained_variance(sigma, threshold=0.95)
# print(f"选择 k={k}, 解释方差比例: {explained[k-1]:.4f}")
```

选择建议：
1. **解释方差**：通常选择使累积解释方差达到95%的k
2. **拐点法**：绘制奇异值图，选择拐点处的k
3. **业务需求**：根据压缩率或降维目标选择k
4. **交叉验证**：对于某些应用，使用交叉验证选择k

### 4.3 迭代过程

SVD不是迭代算法，它是通过矩阵分解（通常使用Golub-Kahan算法）一次性计算。但解释过程可以按步骤：

```python
def svd_manual_conceptual(A):
    """
    概念性SVD计算（非数值稳定，仅用于教学）
    实际中使用np.linalg.svd
    """
    m, n = A.shape
    
    # 1. 计算 A@Aᵀ 和 Aᵀ@A
    AAT = A @ A.T
    ATA = A.T @ A
    
    # 2. 特征值分解
    # 注意：实际中直接使用数值稳定的SVD算法
    # 这里仅为演示概念
    eigvals_left, U = np.linalg.eig(AAT)
    eigvals_right, V = np.linalg.eig(ATA)
    
    # 3. 奇异值是特征值的平方根
    sigma = np.sqrt(np.abs(eigvals_left[:min(m, n)]))
    sigma_sorted = np.sort(sigma)[::-1]  # 降序
    
    # 4. 构造对角矩阵（简化）
    Sigma = np.zeros((m, n))
    for i, s in enumerate(sigma_sorted):
        if i < min(m, n):
            Sigma[i, i] = s
    
    return U, Sigma, V.T  # 注意V需要转置

# 注意：这个实现不是数值稳定的，实际中使用np.linalg.svd
```

### 4.4 收敛条件

SVD不是迭代算法，没有收敛条件。数值算法（如Golub-Kahan）有迭代过程，但那是数值线性代数范畴。

但对于**随机SVD**或**增量SVD**，可能有收敛条件。

### 4.5 超参数及推荐范围

| 超参数 | 作用 | 推荐范围 | 默认值 |
|--------|------|----------|--------|
| `full_matrices` | 是否返回完整U和V | `True` 或 `False` | `True` |
| `compute_uv` | 是否计算U和V | `True` 或 `False` | `True` |
| `k` (截断SVD) | 目标秩 | 1 ~ min(m,n) | 取决于应用 |

选择建议：
1. **截断SVD**：选择k使得解释方差达到95%或99%
2. **内存考虑**：如果m,n很大，设置`full_matrices=False`节省内存
3. **只计算奇异值**：如果不需要U和V，设置`compute_uv=False`

## 5. 应用场景

### 5.1 典型应用

**应用1：图像压缩**
- 场景：将高清图片压缩为更小的表示
- 为什么适合：图片矩阵可以用低秩矩阵近似，丢弃小的奇异值
- 实现：对图片矩阵（或颜色通道矩阵）做SVD，保留前k个奇异值

**应用2：推荐系统（矩阵完成）**
- 场景：根据用户-物品评分矩阵预测缺失评分
- 为什么适合：评分矩阵通常是低秩的（用户偏好和物品特征维度低）
- 实现：使用SVD或其变体（如FunkSVD）进行矩阵分解

**应用3：自然语言处理（LSA）**
- 场景：从词-文档矩阵中提取主题
- 为什么适合：SVD可以提取最重要的语义维度（主题）
- 实现：对TF-IDF矩阵做SVD，得到文档在低维语义空间中的表示

### 5.2 适用数据特征

1. **矩阵数据**：数据是矩阵形式（如图像、评分矩阵）
2. **低秩结构**：矩阵近似低秩，可以用少数列向量表示
3. **需要降维**：将高维数据投影到低维空间
4. **去噪**：小的奇异值通常对应噪声，丢弃它们可以降噪
5. **矩阵补全**：用于推荐系统等缺失数据场景

### 5.3 不适用场景

1. **非矩阵数据**：如序列、图等非矩阵结构 → 使用其他方法
2. **稀疏矩阵且非常大**：计算完整SVD可能很慢 → 使用随机SVD或迭代方法
3. **需要概率框架**：SVD是确定性的 → 使用概率矩阵分解（PMF）
4. **动态数据**：新数据到来需要重新计算SVD → 使用增量SVD
5. **分类/回归问题**：SVD是矩阵分解，不是预测模型 → 使用其他算法

## 6. 优缺点分析|

### 6.1 优点

| 优点 | 说明 | 成立条件 |
|------|------|----------|
| 最优低秩近似 | Eckart-Young定理保证 | 弗罗贝尼乌斯范数意义下 |
| 几何解释清晰 | 对应旋转-缩放-旋转变换 | 通用 |
| 广泛应用 | PCA、推荐系统、压缩等都基于SVD | 通用 |
| 数值稳定 | 现代SVD算法（如Golub-Kahan）很稳定 | 使用数值稳定的实现 |
| 无监督 | 不需要标签数据 | 通用 |

### 6.2 缺点|

| 缺点 | 说明 | 缓解方法 |
|------|------|----------|
| 计算复杂度高 | $O(mn^2)$ 或 $O(m^2n)$，对大矩阵慢 | 使用随机SVD、截断SVD |
| 存储开销大 | 完整SVD需要存储U和V，可能很大 | 使用截断SVD，只保留前k个 |
| 对缺失值敏感 | 不能直接处理缺失值 | 使用矩阵完成技术 |
| 不是概率模型 | 无法给出不确定性估计 | 使用贝叶斯矩阵分解 |
| 解释性有限 | 奇异向量不一定有直观含义 | 结合领域知识解释 |

## 7. 调库实现（Python + 完整代码 + 注释）

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.decomposition import TruncatedSVD
from sklearn.datasets import make_low_rank_matrix

# ============================================
# 1. 基本使用：对随机矩阵进行SVD
# ============================================
print("=" * 60)
print("示例1：SVD基本使用")
print("=" * 60)

# 创建随机矩阵
np.random.seed(42)
A = np.random.randn(6, 4) * 10

print(f"矩阵 A ({A.shape}):")
print(np.round(A, 2))

# 使用NumPy的SVD
# full_matrices=False: 返回"经济"版本，U (m×k), Sigma (k,), Vᵀ (k×n)，其中k=min(m,n)
U, sigma, Vt = np.linalg.svd(A, full_matrices=False)

print(f"\nU 形状: {U.shape}")
print(f"奇异值 sigma 形状: {sigma.shape}")
print(f"Vᵀ 形状: {Vt.shape}")

print(f"\n奇异值（降序）: {np.round(sigma, 2)}")

# 重构矩阵
# Sigma需要变成对角矩阵
Sigma = np.diag(sigma)
A_reconstructed = U @ Sigma @ Vt

print(f"\n重构矩阵 A_reconstructed:")
print(np.round(A_reconstructed, 2))

# 计算重构误差（弗罗贝尼乌斯范数）
reconstruction_error = np.linalg.norm(A - A_reconstructed, 'fro')
print(f"\n重构误差（弗罗贝尼乌斯范数）: {reconstruction_error:.10f}")

# ============================================
# 2. 截断SVD：降维
# ============================================
print("\n" + "=" * 60)
print("示例2：截断SVD与降维")
print("=" * 60)

# 创建低秩矩阵（秩为3）
X_low_rank = make_low_rank_matrix(n_samples=100, n_features=20, rank=3, random_state=42)

print(f"低秩矩阵形状: {X_low_rank.shape}")
print(f"真实秩: 3")

# 使用sklearn的TruncatedSVD进行降维到2维
svd = TruncatedSVD(n_components=2, random_state=42)
X_reduced = svd.fit_transform(X_low_rank)

print(f"降维后形状: {X_reduced.shape}")
print(f"解释方差比例: {svd.explained_variance_ratio_}")
print(f"累积解释方差: {np.sum(svd.explained_variance_ratio_):.4f}")

# ============================================
# 3. 图像压缩示例
# ============================================
print("\n" + "=" * 60)
print("示例3：图像压缩（使用SVD）")
print("=" * 60)

# 创建一个简单的"图像"矩阵（使用随机数据模拟）
image = np.random.randn(100, 80) * 50
# 添加一些结构（模拟真实图像）
for i in range(100):
    image[i, :] += 10 * np.sin(i / 10)

print(f"原始图像形状: {image.shape}")

# 对图像矩阵进行SVD
U, sigma, Vt = np.linalg.svd(image, full_matrices=False)

# 选择保留不同数量的奇异值进行压缩
ks = [5, 10, 20, 50]
plt.figure(figsize=(12, 10))

for i, k in enumerate(ks):
    # 截断SVD重构
    U_k = U[:, :k]
    sigma_k = np.diag(sigma[:k])
    Vt_k = Vt[:k, :]
    
    image_compressed = U_k @ sigma_k @ Vt_k
    
    # 计算压缩比
    original_size = image.size
    compressed_size = U_k.size + sigma_k.size + Vt_k.size
    compression_ratio = original_size / compressed_size
    
    # 绘制
    plt.subplot(2, 2, i+1)
    plt.imshow(image_compressed, cmap='gray')
    plt.title(f'k={k}, 压缩比={compression_ratio:.1f}x')
    plt.axis('off')

plt.suptitle('SVD图像压缩（不同k值）', fontsize=16)
plt.tight_layout()
plt.show()

# 绘制奇异值衰减曲线
plt.figure(figsize=(10, 6))
plt.plot(range(1, len(sigma)+1), sigma, 'b-', linewidth=2)
plt.xlabel('奇异值索引')
plt.ylabel('奇异值')
plt.title('奇异值衰减曲线')
plt.grid(True, alpha=0.3)
plt.show()
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

class SVDManual:
    """
    手动实现的SVD（概念性，非数值稳定）
    用于教学目的，实际应用请使用np.linalg.svd
    """
    
    def __init__(self, compute_uv=True, full_matrices=True):
        """
        初始化SVD
        
        参数:
            compute_uv: 是否计算U和Vᵀ
            full_matrices: 是否返回完整的U和V（尺寸m×m和n×n）
        """
        self.compute_uv = compute_uv
        self.full_matrices = full_matrices
        self.U_ = None
        self.sigma_ = None
        self.Vt_ = None
        
    def fit(self, A):
        """
        对矩阵A进行SVD分解
        
        参数:
            A: 输入矩阵 (m, n)
        
        返回:
            self
        """
        m, n = A.shape
        
        if not self.compute_uv:
            # 只计算奇异值（奇异值是AAᵀ特征值的平方根）
            # 注意：这不是数值稳定的实现
            AAT = A @ A.T
            eigvals = np.linalg.eigvalsh(AAT)  # 使用对称矩阵特征值分解
            # 取非负特征值的平方根
            self.sigma_ = np.sqrt(np.abs(eigvals[:min(m, n)]))
            return self
        
        # 1. 计算AAᵀ的特征分解得到U
        AAT = A @ A.T
        # 使用对称矩阵的特征值分解（更稳定）
        eigvals_left, U = np.linalg.eigh(AAT)
        
        # 2. 计算AᵀA的特征分解得到V
        ATA = A.T @ A
        eigvals_right, V = np.linalg.eigh(ATA)
        
        # 3. 奇异值是特征值的平方根，按降序排列
        idx_left = np.argsort(eigvals_left)[::-1]  # 降序
        U = U[:, idx_left]
        sigma = np.sqrt(np.abs(eigvals_left[idx_left]))
        
        idx_right = np.argsort(eigvals_right)[::-1]
        V = V[:, idx_right]
        
        # 4. 构造对角矩阵Sigma
        k = min(m, n)
        if self.full_matrices:
            Sigma = np.zeros((m, n))
            np.fill_diagonal(Sigma, np.pad(sigma, (0, max(0, m-n)), side='right') if m > n else \
                                np.pad(sigma, (0, max(0, n-m)), side='left') if n > m else \
                                sigma)
        else:
            Sigma = np.diag(sigma)
        
        self.U_ = U
        self.sigma_ = sigma
        self.Vt_ = V.T
        
        return self
    
    def reconstruct(self, k=None):
        """
        重构矩阵，可选择截断到秩k
        
        参数:
            k: 保留的奇异值数量，None表示使用所有
            
        返回:
            重构的矩阵
        """
        if self.U_ is None:
            raise ValueError("请先调用fit方法")
            
        if k is None:
            # 使用所有奇异值
            Sigma_full = np.zeros((self.U_.shape[1], self.Vt_.shape[0]))
            np.fill_diagonal(Sigma_full, self.sigma_)
            return self.U_ @ Sigma_full @ self.Vt_
        else:
            # 截断到秩k
            U_k = self.U_[:, :k]
            sigma_k = self.sigma_[:k]
            Vt_k = self.Vt_[:k, :]
            return U_k @ np.diag(sigma_k) @ Vt_k
    
    def explained_variance_ratio(self):
        """
        计算每个奇异值解释的方差比例
        """
        total_var = np.sum(self.sigma_ ** 2)
        return self.sigma_ ** 2 / total_var
```

## 10. 模型评估

```python
import numpy as np
from sklearn.metrics import mean_squared_error

def evaluate_svd(A, k_values):
    """
    评估SVD低秩近似的性能
    
    参数:
        A: 原始矩阵
        k_values: 要测试的k值列表
    
    返回:
        评估结果字典
    """
    U, sigma, Vt = np.linalg.svd(A, full_matrices=False)
    
    results = {
        'k': [],
        'reconstruction_error': [],
        'explained_variance_ratio': [],
        'compression_ratio': []
    }
    
    for k in k_values:
        # 低秩近似
        A_k = U[:, :k] @ np.diag(sigma[:k]) @ Vt[:k, :]
        
        # 重构误差
        error = np.linalg.norm(A - A_k, 'fro')
        results['k'].append(k)
        results['reconstruction_error'].append(error)
        
        # 解释方差比例
        explained = np.sum(sigma[:k] ** 2) / np.sum(sigma ** 2)
        results['explained_variance_ratio'].append(explained)
        
        # 压缩比
        original_size = A.size
        compressed_size = U[:, :k].size + k + Vt[:k, :].size
        compression_ratio = original_size / compressed_size
        results['compression_ratio'].append(compression_ratio)
    
    return results
```

### 11.1 对于大型矩阵，SVD计算太慢或内存不足
**原因**：
- 完整SVD复杂度 $O(mn^2)$ 或 $O(m^2n)$
- 存储完整U和V可能很大

**解决方案**：
```python

X_reduced = svd.fit_transform(X)

from sklearn.utils.extmath import randomized_svd
U, sigma, Vt = randomized_svd(X, n_components=50, random_state=42)

# 3. 使用稀疏SVD（如果矩阵稀疏）
from scipy.sparse.linalg import svds
# 假设X是稀疏矩阵
```


### 11.4 混淆SVD和PCA
**问题**：SVD和PCA有什么关系？

**解释**：
- **SVD**是矩阵分解技术，用于任意矩阵
- **PCA**是降维方法，通常通过对数据中心化后的协方差矩阵做特征值分解实现
- **关系**：对数据中心化后的矩阵 $X$ 做SVD，可以直接得到PCA结果（主成分）
- 实际上，`sklearn.decomposition.PCA` 内部使用SVD（或特征值分解）

### 11.5 奇异值很小，是否应该丢弃？
**问题**：小的奇异值对应噪声还是信号？

**解决方案**：
1. **诊断**：绘制奇异值衰减曲线，快速衰减后平坦的部分可能是噪声
2. **理论**：根据随机矩阵理论，噪声奇异值会集中在某个值附近
3. **实践**：保留解释方差95%-99%的奇异值，丢弃其余

## 12. 学习总结

### 核心要点回顾：
1. **SVD分解**：$A = U \Sigma V^T$，将任意矩阵分解为旋转-缩放-旋转
2. **奇异值**：表示矩阵在各个方向上的"能量"，按降序排列
3. **低秩近似**：截断SVD $A_k = U_k \Sigma_k V_k^T$ 是秩为 $k$ 的最优近似
4. **Eckart-Young定理**：截断SVD在弗罗贝尼乌斯范数意义下是最优低秩近似
5. **应用广泛**：PCA、图像压缩、推荐系统、LSA等都基于SVD

### 从SVD到其他技术：
```
SVD (矩阵分解)
    ↓
PCA (主成分分析) - 使用SVD实现降维
    ↓
TruncatedSVD - 截断版本，直接降维
    ↓
随机SVD - 大型矩阵的近似SVD
    ↓
NMF/PMF - 非负/概率矩阵分解
```

### 实践建议：
1. **优先使用截断SVD**：对于降维，直接指定目标维度k
2. **选择k**：根据解释方差比例（如95%）或拐点法
3. **大矩阵**：使用随机SVD或稀疏SVD
4. **评估**：绘制奇异值衰减曲线，监控解释方差
5. **与PCA关系**：对数据中心化后做SVD就是PCA

**习题1：基础计算**
问题：计算矩阵 $A = \begin{bmatrix} 3 & 0 \\ 0 & 2 \end{bmatrix}$ 的SVD。

<details>
<summary>答案</summary>

矩阵 $A$ 是对角矩阵，所以：
- 奇异值就是对角线元素的绝对值：$\sigma_1 = 3, \sigma_2 = 2$
- 左奇异向量矩阵 $U = I$（单位矩阵）
- 右奇异向量矩阵 $V = I$（单位矩阵）

因此：
$$U = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}, \quad \Sigma = \begin{bmatrix} 3 & 0 \\ 0 & 2 \end{bmatrix}, \quad V^T = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$$

验证：$U \Sigma V^T = I \cdot \Sigma \cdot I^T = \Sigma = A$。
</details>

**习题3：理论推导**
问题：证明对于对称半正定矩阵 $S$，其SVD就是特征值分解。

<details>
<summary>答案</summary>

对称半正定矩阵 $S$ 满足 $S = S^T$ 且所有特征值 $\lambda_i \geq 0$。

特征值分解：$S = Q \Lambda Q^T$，其中 $Q$ 是正交矩阵（$Q^T Q = I$），$\Lambda$ 是对角矩阵，对角线是特征值 $\lambda_i \geq 0$。

现在构造SVD：
- 令 $U = Q$
- 令 $\Sigma = \Lambda$（因为 $\lambda_i \geq 0$，所以 $\Sigma$ 的对角线就是 $\sqrt{\lambda_i} = \lambda_i$？不，奇异值是特征值的平方根）

啊，需要修正：对于对称半正定矩阵，奇异值就是特征值的绝对值（因为特征值非负，所以奇异值=特征值）。

因此，SVD为：$S = U \Sigma V^T$，其中 $U = Q$，$\Sigma = \Lambda$，$V = Q$。由于 $S$ 对称，$U = V$。

所以：$S = Q \Lambda Q^T = U \Sigma V^T$，其中 $U = V = Q$，$\Sigma = \Lambda$。这就是SVD形式。
</details>

### 思考题|

**思考题1**：SVD和PCA有什么区别与联系？

<details>
<summary>答案</summary>

| 方面 | SVD | PCA |
|------|-----|------|
| 本质 | 矩阵分解技术 | 降维方法 |
| 输入 | 任意矩阵 $A$ | 数据中心化后的矩阵 $X$ |
| 输出 | $U, \Sigma, V^T$ | 主成分（载荷和得分） |
| 关系 | PCA可以通过对中心化矩阵做SVD实现 | SVD是PCA的一种实现方式 |
| 应用 | 矩阵近似、压缩、去噪 | 降维、特征提取、可视化 |

核心联系：对数据中心化后的矩阵 $X_c = X - \mu$ 做SVD：$X_c = U \Sigma V^T$，那么：
- 主成分方向就是 $V$ 的列
- 主成分得分就是 $U \Sigma$
- 解释方差比例就是 $\sigma_i^2 / \sum_j \sigma_j^2$

因此，PCA通常用SVD实现（数值更稳定）。
</details>

**思考题2**：为什么SVD可以用于图像压缩？原理是什么？

<details>
<summary>答案</summary>

图像可以表示为矩阵（灰度图）或矩阵的集合（彩色图的每个通道）。图像矩阵通常具有低秩结构：相邻像素高度相关，所以信息集中在少数几个方向上。

SVD将图像矩阵 $I$ 分解为 $U \Sigma V^T$。大多数图像的奇异值快速衰减，意味着前几个奇异值就包含了图像的大部分信息（能量）。

压缩原理：
1. 只保留前 $k$ 个奇异值（$k \ll \text{rank}(I)$）
2. 存储 $U_k$ ($m \times k$)、$\Sigma_k$ ($k \times k$)、$V_k^T$ ($k \times n$) 而不是完整的 $m \times n$ 图像
3. 重构时计算 $I_k = U_k \Sigma_k V_k^T$，得到压缩后的近似图像

压缩比大约为 $\frac{m \times n}{m \times k + k + k \times n}$，当 $k$ 较小时，压缩比很大。而由于图像是低秩的，即使 $k$ 很小（如10），重构图像仍然质量不错。
</details>

1. 理解截断SVD和低秩近似（Eckart-Young定理）
2. 掌握SVD在PCA中的应用
3. 学习如何选择秩 $k$（解释方差、拐点法）
4. 比较SVD与特征值分解的异同

**学习时间**：1-2周**

### 高级阶段（扩展到复杂应用）
1. 学习随机SVD，用于大型矩阵
2. 理解SVD在推荐系统中的应用（矩阵完成）
3. 掌握SVD在自然语言处理中的应用（LSA）
4. 研究SVD的变体：非负矩阵分解（NMF）、概率矩阵分解（PMF）

**学习时间**：2-4周**

### 实践项目建议
1. **基础项目**：图像压缩（使用SVD）
2. **进阶项目**：人脸 recognition（使用SVD+PCA进行降维）
3. **挑战项目**：简单的推荐系统（使用矩阵分解）

### 推荐资源
- **书籍**：《线性代数及其应用》（David C. Lay）第7章；《统计学习方法》（李航）第14章（PCA部分）
- **课程**：Gilbert Strang的线性代数课程（MIT OpenCourseWare）
- **论文**：原始论文（Eckart & Young, 1936）
- **代码**：NumPy和SciPy的线性代数模块
- **实践**：图像压缩任务、推荐系统入门（如MovieLens数据集）
