
# 奇异值分解 学习文档

## 1. 算法基础认知
### 1.1 一句话定义
SVD（Singular Value Decomposition，奇异值分解）是一种将任意矩阵分解为三个矩阵乘积的矩阵分解技术，揭示了矩阵的内在结构，是线性代数中最重要的分解方法之一。

### 1.2 直觉类比
想象你有一本关于某主题的书，SVD就像找出这本书的"核心内容"：最重要的主题（第一奇异值对应的主题）、次要的主题（第二奇异值对应的主题）等。通过只保留前几个最重要的主题，你就能用很少的内容大致了解全书——这就是SVD降维的核心思想。

### 1.3 历史背景
SVD的理论基础由Eugenio Beltrami和Camille Jordan在19世纪建立。现代计算SVD的算法由Gene Golub和William Kahan在1965年提出。SVD是数值线性代数、信号处理、统计学习等领域最核心的工具之一。

### 1.4 算法定位
- 类型：矩阵分解
- 输出：三个矩阵（U, Σ, V）
- 模型类别：线性代数基础工具

### 1.5 前置知识
- 线性代数（矩阵运算、特征值）
- Python 编程（NumPy）

## 2. 核心原理
### 2.1 核心思想
SVD的核心思想是"矩阵的谱分解"——将任意矩阵分解为正交矩阵、对角矩阵和正交矩阵的乘积，揭示矩阵在行方向和列方向的"能量"分布。

### 2.2 工作流程
1. 对矩阵 $A$ 进行SVD分解
2. 得到 $A = U \Sigma V^T$
3. 截取前k个奇异值和对应的向量
4. 使用低秩近似进行降维或压缩

### 2.3 关键概念解释
- **奇异值**：矩阵"能量"的度量
- **左奇异向量**：行空间的标准正交基
- **右奇异向量**：列空间的标准正交基
- **低秩近似**：用较少的信息近似原矩阵

### 2.4 几何解释
从几何角度看，SVD将线性变换分解为旋转→缩放→旋转。U和V是旋转矩阵，Σ是对角缩放矩阵。奇异值表示在各个方向上的缩放因子。

## 3. 数学公式与推导
### 3.1 符号约定
| 符号 | 含义 |
|------|------|
| $A$ | 待分解矩阵 $(m \times n)$ |
| $U$ | 左奇异向量矩阵 $(m \times m)$ |
| $\Sigma$ | 奇异值对角矩阵 $(m \times n)$ |
| $V$ | 右奇异向量矩阵 $(n \times n)$ |
| $\sigma_i$ | 第i个奇异值 |

### 3.2 问题形式化
对任意矩阵 $A \in \mathbb{R}^{m \times n}$，存在正交矩阵 $U \in \mathbb{R}^{m \times m}$ 和 $V \in \mathbb{R}^{n \times n}$，以及对角矩阵 $\Sigma \in \mathbb{R}^{m \times n}$，使得：
$$A = U \Sigma V^T$$

其中 $\Sigma = \text{diag}(\sigma_1, \sigma_2, ..., \sigma_r)$，$r = \min(m,n)$，且 $\sigma_1 \geq \sigma_2 \geq ... \geq \sigma_r \geq 0$。

### 3.3 目标函数
低秩近似（截断SVD）：
$$\min_{A_k} \|A - A_k\|_F \quad \text{s.t.} \quad \text{rank}(A_k) = k$$

最优解为 $A_k = U_k \Sigma_k V_k^T$。

### 3.4 推导过程
**方法1：通过特征值分解**
1. 计算 $AA^T$ 的特征值分解：$AA^T = U \Lambda U^T$
2. 计算 $A^TA$ 的特征值分解：$A^TA = V \Lambda V^T$
3. 奇异值 $\sigma_i = \sqrt{\lambda_i}$
4. U和V由特征向量构成

**方法2：直接SVD**
使用Golub-Reinsch等算法直接计算。

### 3.5 最终解/算法步骤
1. 对 $A$ 进行SVD分解
2. 选择前k个奇异值
3. 构造低秩近似
4. 用于降维、压缩等任务

## 4. 训练过程讲解
### 4.1 数据预处理
- 数据中心化（如用于PCA）
- 处理缺失值
- 标准化（可选）

### 4.2 参数初始化
SVD是确定性分解，无参数初始化。

### 4.3 迭代过程
SVD通常通过闭式解计算，无需迭代。

### 4.4 收敛条件
SVD一次性完成，不涉及收敛。

### 4.5 超参数及推荐范围
- n_components (k): 保留的奇异值数量
- 算法：'randomized'（大数据）或 'arpack'

## 5. 应用场景
### 5.1 典型应用
- **数据降维**：PCA等价于SVD
- **图像压缩**：保留主要奇异值
- **推荐系统**：矩阵分解
- **噪声过滤**：去除小奇异值

### 5.2 适用数据特征
- 任意实数矩阵
- 需要发现潜在结构
- 需要数据压缩

### 5.3 不适用场景
- 复数矩阵（需要复数SVD）
- 稀疏矩阵（推荐截断SVD）
- 实时计算要求极高

## 6. 优缺点分析
### 6.1 优点
- 适用于任意矩阵
- 数值稳定
- 理论优美
- 应用广泛

### 6.2 缺点
- 计算复杂度较高
- 存储需求大
- 只能处理线性结构

### 6.3 与同类算法对比

| 算法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| SVD | 通用，稳定 | O(min(m²n, mn²)) | 一般矩阵分解 |
| QR分解 | 快速 | 信息损失 | 最小二乘 |
| 特征分解 | 快速（方阵） | 限于方阵 | 对称矩阵 |
| 随机SVD | 大规模友好 | 近似 | 大数据 |

## 8. 手工代码实现
### 8.1 核心算法手写
```python
import numpy as np

class SVDManual:
    """手工实现奇异值分解（基于特征值分解）"""
    
    def __init__(self, n_components=None):
        self.n_components = n_components
        self.U = None
        self.s = None
        self.Vt = None
        
    def fit(self, A):
        """执行SVD分解"""
        A = np.array(A)
        m, n = A.shape
        
        # 方法：基于特征值分解
        # 计算 A^T @ A 的特征值分解
        AtA = A.T @ A
        eigenvalues, V = np.linalg.eig(AtA)
        
        # 奇异值是特征值的平方根
        s = np.sqrt(np.abs(eigenvalues))
        
        # 按降序排序
        idx = np.argsort(s)[::-1]
        s = s[idx]
        V = V[:, idx]
        
        # 计算 U
        U = np.zeros((m, len(s)))
        for i, sigma in enumerate(s):
            if sigma > 1e-10:
                U[:, i] = (A @ V[:, i]) / sigma
        
        # 截断（如果指定了n_components）
        if self.n_components is not None and self.n_components < len(s):
            U = U[:, :self.n_components]
            s = s[:self.n_components]
            V = V[:, :self.n_components]
        
        self.U = U
        self.s = s
        self.Vt = V.T
        
        return self
    
    def transform(self, A):
        """投影到奇异向量空间"""
        # 相当于 U^T @ A（当n_components < m时）
        if self.n_components is not None:
            return self.U.T @ A
        return self.s[:, np.newaxis] * (self.Vt @ A.T).T
    
    def inverse_transform(self, A_reduced):
        """从降维表示重构"""
        if self.n_components is not None:
            return A_reduced @ self.Vt[:self.n_components, :]
        return self.U @ np.diag(self.s) @ self.Vt
    
    @staticmethod
    def truncated_power_iteration(A, k, n_iter=5):
        """随机SVD（幂迭代版本）"""
        m, n = A.shape
        
        # 随机初始化Q
        np.random.seed(42)
        Q = np.random.randn(n, k)
        
        for _ in range(n_iter):
            # QR分解
            Q, _ = np.linalg.qr(A @ Q)
            Q, _ = np.linalg.qr(A.T @ Q)
        
        # B矩阵
        B = Q.T @ A
        
        # 对B进行SVD
        Ub, sb, Vtb = np.linalg.svd(B, full_matrices=False)
        
        # 得到A的SVD
        U = Q @ Ub
        s = sb
        Vt = Vtb
        
        return U, s, Vt

# 测试
```
