# 量价特征工程 学习文档

> 用机器学习方法构造和筛选量价特征，突破线性因子模型的收益天花板。
> 来源线索：本节内容根据原书中关于"机器学习量价特征工程"（第3章3.7节）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：量价特征工程是基于成交量、价格等基础市场数据，通过统计变换、特征衍生和机器学习筛选构建预测因子体系的技术方法。

**直觉类比**：厨师做菜——原始数据是食材（量、价），基础指标是切配好的原料（换手率、振幅），衍生因子是调味组合（尾盘拉升强度=尾盘量比×价格偏离），机器学习筛选是品菜淘汰不好的菜品。

**背景**：传统 Fama-French 三因子等线性模型在日益复杂的市场中逐渐失效。随机森林、XGBoost 等非线性模型能够自动挖掘量价数据中的复杂模式，为因子挖掘带来了新范式。

**算法定位**：特征工程 / 量化因子 / 机器学习应用 / 阿尔法策略。

**前置知识**：Pandas 数据处理、基础量价指标概念、随机森林/XGBoost 基本原理。

## 2. 核心原理

**核心思想**：量价特征是量化策略的"原料"，好的特征输入比复杂的模型更重要。量价特征工程分为三个层次：

1. **基础指标层**：直接可从行情数据计算的标准指标
2. **衍生因子层**：通过组合、变换、非线性映射得到的增强因子
3. **特征筛选层**：用机器学习的重要性排序挑选核心因子

**十大基础量价指标**：

| 指标 | 含义 | 市场解读 |
|------|------|----------|
| 换手率 | 成交量/流通股本 | 市场参与热度 |
| 振幅 | (高-低)/昨收 | 日内波动程度 |
| 量比 | 当前量/5日均量 | 放量/缩量信号 |
| 大单净流入率 | (大买-大卖)/成交额 | 主力资金方向 |
| 异动成交量占比 | 最大5分钟量/日总量 | 集中成交异常 |
| 收盘价偏离度 | (收盘-均价)/均价 | 尾盘资金态度 |
| 资金流向 | 主动买额-主动卖额 | 日内资金博弈 |
| 价格波动率 | 收益率标准差 | 风险度量 |
| 尾盘拉升强度 | 尾盘量比×价格偏离 | 收盘前主力动作 |
| 量价相关系数 | vol与price滚动相关 | 量价配合程度 |

**衍生因子示例**：
- 尾盘拉升强度 = 收盘前5分钟成交量占比 × 价格偏离度
- 异动成交量占比 = 当日最大5分钟成交量 / 日成交量
- 大单净流入率 = (大单买入金额 - 大单卖出金额) / 日成交额

## 3. 数学公式与推导

### 3.1 换手率
$$
\text{TurnoverRate} = \frac{\text{Volume}}{\text{FloatShares}}
$$

### 3.2 振幅
$$
\text{Amplitude} = \frac{\text{High} - \text{Low}}{\text{PrevClose}}
$$

### 3.3 收盘价偏离度
$$
\text{CloseBias} = \frac{\text{Close} - \text{AvgPrice}}{\text{AvgPrice}}, \quad \text{AvgPrice} = \frac{\text{Amount}}{\text{Volume}}
$$

### 3.4 尾盘拉升强度
$$
\text{TailStrength} = \frac{V_{\text{last5min}}}{V_{\text{total}}} \times \text{CloseBias}
$$

### 3.5 特征标准化
$$
x_{\text{norm}} = \frac{x - \mu}{\sigma} \quad \text{(Z-score)}
$$
$$
x_{\text{minmax}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}} \quad \text{(Min-Max)}
$$

## 4. 训练过程讲解

### 4.1 数据采集
- 行情数据：日线/分钟线（开盘、收盘、最高、最低、成交量、成交额）
- 大单数据：逐笔成交中的大单标记（>20万或>50万）
- 来源：Tushare、聚宽、米筐、Wind

### 4.2 特征构造流程
1. 计算10个基础量价指标
2. 设计 3-5 个衍生因子
3. 对特征做缺失值填充和异常值截尾
4. 特征标准化（Z-score 或 Min-Max）
5. 计算特征相关性矩阵（识别冗余特征）

### 4.3 特征筛选
- 用随机森林 + XGBoost 各训练一轮
- 取两个模型的特征重要性排序的交集（top 5-7）
- 去除两两相关性 > 0.8 的冗余特征

### 4.4 主要超参数

| 超参数 | 推荐值 |
|--------|--------|
| 均量平滑窗口 | 5日 |
| 尾盘定义 | 收盘前5分钟 |
| 大单阈值 | 20万元 |
| 特征数量（最终） | 5-10个 |

## 5. 应用场景

1. **选股/收益预测**（原书3.7节）：量价特征 → XGBoost 预测未来收益率 → 构建多空组合
2. **风格识别**：根据量价特征聚类识别当前市场风格（趋势/震荡/高波动）
3. **风控增强**：量价异常指标作为预警信号（如放量下跌）
4. **行业轮动**：各行业板块的量价特征排名筛选强势板块

**适用**：A股/港股/美股等流动性好的市场、日内到月度频率
**不适用**：极端低流动性品种、基本面主导的长期投资

## 6. 优缺点分析

### 优点
| 优点 | 说明 |
|------|------|
| 非线性 | 机器学习挖掘传统线性模型看不到的模式 |
| 自动化 | 从特征构造到筛选可全流程自动化 |
| 可解释 | 特征重要性排名直观展示哪些因子有效 |
| 可扩展 | 任意数量的新因子可不断加入体系 |

### 缺点
| 缺点 | 缓解思路 |
|------|----------|
| 过拟合风险高 | 严格时序交叉验证 + 特征数量控制 |
| 数据噪音大 | 滚动平滑 + 异常值截尾 |
| 市场适应性 | 每季度重新训练和评估特征有效性 |
| 黑箱倾向 | 保留特征重要性 + SHAP 值解释 |

## 7. 调库实现

```python
"""
量价特征工程：10个基础指标 + 3个衍生因子 + 特征重要性筛选
"""
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from xgboost import XGBRegressor
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['Arial Unicode MS', 'SimHei']
plt.rcParams['axes.unicode_minus'] = False

np.random.seed(42)
n_days = 500

# ========== 1. 模拟日线行情数据 ==========
close = 20 + np.cumsum(np.random.randn(n_days) * 0.3)
high = close + np.abs(np.random.randn(n_days) * 0.15)
low = close - np.abs(np.random.randn(n_days) * 0.15)
open_p = close - np.random.randn(n_days) * 0.1
volume = np.random.exponential(1e7, n_days)
amount = volume * close
pre_close = np.roll(close, 1)
pre_close[0] = close[0]

# 模拟大单数据
big_buy = np.random.exponential(5e6, n_days)
big_sell = np.random.exponential(4e6, n_days)
float_shares = 2e9  # 流通股本

df = pd.DataFrame({
    'open': open_p, 'high': high, 'low': low, 'close': close,
    'volume': volume, 'amount': amount, 'pre_close': pre_close,
    'big_buy': big_buy, 'big_sell': big_sell,
})

# ========== 2. 计算 10 个基础量价特征 ==========
df['turnover_rate'] = df['volume'] / float_shares      # 换手率
df['amplitude'] = (df['high'] - df['low']) / df['pre_close']  # 振幅
df['volume_ratio'] = df['volume'] / df['volume'].rolling(5).mean()  # 量比
df['avg_price'] = df['amount'] / df['volume']
df['close_bias'] = (df['close'] - df['avg_price']) / df['avg_price']  # 收盘偏离
df['volatility'] = df['close'].pct_change().rolling(10).std()  # 波动率
df['capital_flow'] = df['big_buy'] - df['big_sell']  # 资金流向
df['corr_vol_price'] = df['volume'].rolling(20).corr(df['close'])  # 量价相关
df['net_big_rate'] = (df['big_buy'] - df['big_sell']) / df['amount']  # 大单净率

# ========== 3. 计算 3 个衍生因子 ==========
# 尾盘拉升强度（简化：用收盘价偏离近似）
df['tail_strength'] = df['close_bias'] * df['volume_ratio']

# 异动成交量占比（简化：用单日对5日均量比近似）
df['abnormal_vol'] = df['volume'] / df['volume'].rolling(5).mean() - 1

# 量价背离度
df['divergence'] = np.sign(df['close'].pct_change()) != np.sign(df['volume_ratio'] - 1)
df['divergence'] = df['divergence'].astype(float)

# 目标变量：未来 5 日收益
df['future_ret'] = df['close'].shift(-5) / df['close'] - 1
df = df.dropna()

feature_cols = ['turnover_rate', 'amplitude', 'volume_ratio', 'close_bias',
                'volatility', 'capital_flow', 'corr_vol_price', 'net_big_rate',
                'tail_strength', 'abnormal_vol']
X = df[feature_cols].values
y = df['future_ret'].values

# ========== 4. 特征筛选（重要性排序） ==========
# 时序分割：前 80% 训练，后 20% 测试
split = int(len(X) * 0.8)
X_train, X_test = X[:split], X[split:]
y_train, y_test = y[:split], y[split:]

# 随机森林
rf = RandomForestRegressor(n_estimators=150, max_depth=6, random_state=42)
rf.fit(X_train, y_train)

# XGBoost
xgb = XGBRegressor(n_estimators=150, max_depth=4, learning_rate=0.05, random_state=42)
xgb.fit(X_train, y_train)

# ========== 5. 特征重要性与可视化 ==========
importance_df = pd.DataFrame({
    '特征': feature_cols,
    'RF重要性': rf.feature_importances_,
    'XGB重要性': xgb.feature_importances_,
}).sort_values('XGB重要性', ascending=True)

fig, ax = plt.subplots(figsize=(10, 5))
x_pos = np.arange(len(feature_cols))
width = 0.35
ax.barh(x_pos + width/2, importance_df['RF重要性'], width, label='Random Forest', color='steelblue')
ax.barh(x_pos - width/2, importance_df['XGB重要性'], width, label='XGBoost', color='darkorange')
ax.set_yticks(x_pos)
ax.set_yticklabels(importance_df['特征'])
ax.set_xlabel('特征重要性')
ax.set_title('量价特征重要性排序（RF vs XGBoost）')
ax.legend()
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# 输出 Top5 特征
top5 = importance_df.nlargest(5, 'XGB重要性')
print("Top5 重要量价特征（按XGBoost重要性）:")
for _, row in top5.iterrows():
    print(f"  {row['特征']}: RF={row['RF重要性']:.3f}, XGB={row['XGB重要性']:.3f}")
```

## 8. 手工代码实现

```python
"""
量价特征工程手工实现：从零实现 3 个衍生因子 + 特征标准化
"""
import numpy as np


class VolumePriceFeatureEngineer:
    """量价特征工程引擎"""

    @staticmethod
    def tail_strength(close, volume, window=5):
        """计算滚动尾盘强度指标（简化版）"""
        n = len(close)
        result = np.full(n, np.nan)
        for i in range(window, n):
            last_vol = volume[i-window+1:i+1].sum()
            total_vol = volume[max(0, i-19):i+1].sum()
            vol_ratio = last_vol / (total_vol + 1e-8)
            price_bias = (close[i] - close[i-window+1:i+1].mean()) / (close[i-window+1:i+1].mean() + 1e-8)
            result[i] = vol_ratio * price_bias
        return result

    @staticmethod
    def abnormal_volume_ratio(volume, lookback=20, compare_window=5):
        """异动成交量占比"""
        n = len(volume)
        result = np.full(n, np.nan)
        for i in range(lookback, n):
            max_short = 0
            for j in range(i - lookback + compare_window, i - compare_window + 1):
                short_vol = volume[j:j+compare_window].sum()
                max_short = max(max_short, short_vol)
            result[i] = max_short / (volume[i-lookback+1:i+1].sum() + 1e-8)
        return result

    @staticmethod
    def rolling_zscore(x, window=20):
        """滚动 Z-score 标准化"""
        n = len(x)
        result = np.full(n, np.nan)
        for i in range(window - 1, n):
            seg = x[i-window+1:i+1]
            mu, sigma = np.mean(seg), np.std(seg)
            result[i] = (x[i] - mu) / (sigma + 1e-8)
        return result

    @staticmethod
    def rolling_rank(x, window=20):
        """滚动排名（0-1归一化）"""
        n = len(x)
        result = np.full(n, np.nan)
        for i in range(window - 1, n):
            seg = x[i-window+1:i+1]
            result[i] = (np.sum(seg < x[i]) + 0.5 * np.sum(seg == x[i])) / window
        return result

    def build_features(self, close, volume):
        """构造完整特征矩阵"""
        features = {}
        features['tail_strength'] = self.tail_strength(close, volume)
        features['abnormal_vol'] = self.abnormal_volume_ratio(volume)
        features['volatility'] = self.rolling_zscore(np.diff(close, prepend=close[0]) / (np.abs(close) + 1e-8))
        return features


# ============ 测试 ============
if __name__ == '__main__':
    np.random.seed(42)
    n = 300

    close = 50 + np.cumsum(np.random.randn(n) * 0.5)
    volume = np.random.exponential(5000, n)

    engineer = VolumePriceFeatureEngineer()
    feats = engineer.build_features(close, volume)

    for name, values in feats.items():
        valid = ~np.isnan(values)
        print(f"{name}: 均值={np.mean(values[valid]):.4f}, 标准差={np.std(values[valid]):.4f}")
```

from sklearn.metrics import mean_squared_error, r2_score

# 使用选定特征的预测
top_features = top5['特征'].tolist()

## 11. 常见问题与易错点

- **特征冗余**：相关性 > 0.85 的特征只保留一个，否则模型不稳定
- **数据泄露**：不能用 t+1 信息构造 t 时刻的特征——严格检查每个特征的时间约束
- **未处理缺失值**：停牌日的指标为 NaN，需填充或剔除
- **特征未标准化**：不同量纲指标直接输入可能让某些特征主导模型
- **单一模型依赖**：只用 RF 或只用 XGB 的特征排名有偏差——交叉验证两模型

## 12. 学习总结

**核心回顾**：量价特征工程是量化策略的基石。基础指标 + 衍生因子 + ML 筛选构成三层金字塔体系。好的特征工程比调模型参数更重要。

**关键公式**：尾盘拉升强度 = 尾盘成交量占比 × 价格偏离度，异动占比 = 最大短时量 / 周期总量

**后续方向**：深度因子挖掘（AutoEncoder 提取隐特征）、图神经网络挖掘产业链关联、Transformer 时间序列特征提取

## 13. 练习题与思考题

**题1**（基础）：列举 5 个常用的量价基础指标，并说明各自的市场含义。
**参考答案**：换手率(参与热度)、量比(放量缩量)、振幅(日内波动)、收盘偏离度(尾盘资金态度)、波动率(风险水平)。

**题2**（进阶）：尾盘拉升强度和次日开盘收益的关系是什么？如何利用这个关系构建策略？
**参考答案**：尾盘拉升通常意味着有资金在收盘前集中买入，次日大概率高开。策略：筛选尾盘拉升强度 > 某阈值的股票，尾盘买入、次日开盘卖出。但需防范主力"尾盘诱多"——结合次日是否有实际利好验证。

**题3**（开放）：如果一个量价因子在回测中表现优秀但实盘失效，可能的原因有哪些？
**参考答案**：(1)过拟合历史数据、(2)市场结构改变（如涨跌停制度调整）、(3)因子拥挤（太多人在用此因子，alpha衰减）、(4)交易成本（回测忽略了滑点/冲击成本）、(5)数据窥探偏差（反复测试后选中的因子）。对策：样本外验证、纸交易过渡期、监控因子 IC 衰减。
