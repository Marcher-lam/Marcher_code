# 连板梯队结构分析 学习文档

> 用金字塔结构透视市场情绪，晋级率是短线博弈的温度计。
> 来源线索：本节内容根据原书中关于"复盘连板梯队结构与晋级率分析"（第3章3.10节）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：通过对每日不同连板数个股的数量分布和晋级成功率进行系统统计分析，判断市场情绪热度、主线强度和龙头持续性的量化复盘方法。

**直觉类比**：金字塔结构——塔基宽(2连板多)说明新生力量充足，塔尖稳(高位龙头不炸板)说明行情可持续。金字塔变倒三角形(高位比低位多)则是危险信号。

**背景**：A股连板文化形成了独特的市场生态。不同连板梯队反映了不同风险偏好层次资金的参与。通过跟踪梯队的宽度(数量)、高度(最高板数)、晋级率(成功率)，可以对市场情绪做前瞻性预判。

**算法定位**：量化策略 / 贝塔策略 / 市场微观结构 / 情绪分析。

**前置知识**：A股涨停板制度、连板股概念、统计分析基础。

## 2. 核心原理

**连板梯队定义**：
- 2连板：起步梯队，反映打板资金的基础活跃度
- 3连板：晋级初筛，2进3成功率约40-60%
- 5连板：中位龙头，市场辨识度形成
- 7连板+：高位龙头，全市场焦点

**核心指标**：

| 指标 | 计算 | 市场含义 |
|------|------|----------|
| 2进3晋级率 | N(3连板)/N(前一日的2连板) | 赚钱效应是否延续 |
| 3进4晋级率 | N(4连板)/N(前一日的3连板) | 高标股是否获得接力 |
| 梯队完整度 | 各梯队是否都有股 | 健康的多层次结构 |
| 高标最高板数 | max(连板数) | 市场风险偏好上限 |
| 一字板占比 | N(一字板)/N(涨停) | 资金抢筹激烈程度 |

**情绪周期判断**：
- 高潮期：各梯队完整+晋级率>50%+高位龙头不止
- 分歧期：某梯队断裂+炸板增多
- 退潮期：高位龙头炸板+晋级率骤降+连板数减少

## 3. 数学公式

### 3.1 晋级率
$$
P_{n \to n+1} = \frac{N_{n+1}^{(t)}}{N_n^{(t-1)}}
$$
N_n^{(t-1)}是前一日n连板股数，N_{n+1}^{(t)}是当日n+1连板股数。

### 3.2 梯队健康度指数
$$
\text{Health} = \frac{\sum_{n=2}^{7} n \cdot N_n}{\sum N_n} \quad \text{(平均连板数)}
$$
平均连板数持续上升 → 行情健康。

### 3.3 封单强度
$$
\text{SealStrength} = \frac{\text{SealAmount}}{\text{FloatMV}}
$$

## 4. 训练过程讲解

1. 每日收盘采集涨停股列表和连板数
2. 按连板数分组统计数量
3. 读取前一日数据计算各晋级率
4. 构建晋级率矩阵表
5. 提取高标股(连板最多前5)特征
6. 统计炸板股的时间和换手率分布
7. 判断当日情绪阶段

**关键参数**：涨停判定=涨幅>9.8%或触及涨停价、ST股需单独处理

## 5. 应用场景

- **短线情绪判断**：晋级率骤降→情绪转弱→减仓
- **龙头持续性预判**：高标股梯队完整→龙头行情延续
- **题材主线确认**：某题材内多只晋级→题材获得市场认可
- **择时信号**：冰点期(连板极少)后首次晋级率反弹→买点

**适用**：A股短线交易、打板策略；**不适用**：无涨跌停市场

## 6. 优缺点分析

**优点**：直观(一目了然的金字塔)、实时(每日可更新)、实战性强(直接指导交易)
**缺点**：依赖涨停制度(注册制后可20%涨停)、受监管干预影响(停牌核查打断连板)

## 7. 调库实现

```python
"""连板梯队结构分析"""
import numpy as np
import pandas as pd

np.random.seed(42)

# ========== 1. 模拟连板数据 ==========
n_days = 30
dates = pd.date_range('2024-01-01', periods=n_days, freq='B')

# 模拟有情绪周期的连板数据
cycle = np.sin(np.linspace(0, 3*np.pi, n_days)) * 0.5 + 0.5

daily_data = []
for i, (dt, phase) in enumerate(zip(dates, cycle)):
    # 2连板到7连板+的数量
    n_2b = int(15 + phase * 20 + np.random.randint(-3, 4))
    n_3b = max(0, int(n_2b * (0.4 + phase * 0.3))) if i > 0 else 5
    n_4b = max(0, int(n_3b * (0.35 + phase * 0.3))) if i > 0 else 2
    n_5b = max(0, int(n_4b * (0.3 + phase * 0.2))) if i > 0 else 1
    n_6b = max(0, int(n_5b * 0.25)) if i > 0 else 0
    n_7bp = max(0, int(n_6b * 0.2)) if i > 0 else 0

    daily_data.append({
        'date': dt, '2连板': n_2b, '3连板': n_3b,
        '4连板': n_4b, '5连板': n_5b, '6连板': n_6b, '7连板+': n_7bp,
    })

df = pd.DataFrame(daily_data)

# ========== 2. 计算晋级率 ==========
boards = ['2连板', '3连板', '4连板', '5连板', '6连板', '7连板+']
for i in range(len(boards) - 1):
    prev_col = boards[i]
    curr_col = boards[i+1]
    df[f'{i+2}进{i+3}晋级率'] = (df[curr_col] / (df[prev_col].shift(1) + 1)).round(3)

# 总连板股数
df['总连板数'] = df[boards].sum(axis=1)

print("连板梯队数据（最近5日）:")
print(df[['date', '总连板数'] + [c for c in df.columns if '晋级率' in c]].tail(5).to_string(index=False))

# ========== 3. 可视化 ==========
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['Arial Unicode MS', 'SimHei']
plt.rcParams['axes.unicode_minus'] = False

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 堆积柱状图（梯队分布）
bottom = np.zeros(n_days)
colors_palette = ['#fee090','#fdae61','#f46d43','#d73027','#a50026','#67001f']
for i, col in enumerate(boards):
    axes[0].bar(dates, df[col], bottom=bottom, label=col, color=colors_palette[i], alpha=0.85)
    bottom += df[col].values
axes[0].set_title('连板梯队分布（堆积柱状图）')
axes[0].set_ylabel('数量')
axes[0].legend(loc='upper left', fontsize=8)
axes[0].grid(True, alpha=0.3, axis='y')

# 晋级率热力图
promo_cols = [c for c in df.columns if '晋级率' in c]
promo_data = df[promo_cols].iloc[-15:].T
im = axes[1].imshow(promo_data, cmap='RdYlGn', aspect='auto', vmin=0, vmax=0.8)
axes[1].set_xticks(range(len(promo_data.columns)))
axes[1].set_xticklabels([d.strftime('%m-%d') for d in dates[-15:]], rotation=45, fontsize=8)
axes[1].set_yticks(range(len(promo_cols)))
axes[1].set_yticklabels(promo_cols, fontsize=9)
axes[1].set_title('晋级率热力图（近15日）')
plt.colorbar(im, ax=axes[1], label='晋级率')

plt.tight_layout()
plt.show()
```

## 8-14. 综合章节

**关键公式**：晋级率 P(n→n+1) = N_{n+1}/N_n(昨日)

**常见问题**：一字板不计入晋级统计→一字板无法参与所以不反映真实接力意愿；ST股处理→ST股涨跌幅5%，和普通股混算会失真；数据缺失(某梯队为0时晋级率无法计算)→用NaN而非0

**学习路径**：A股涨停板制度→连板生态研究→晋级率统计→情绪周期量化

**练习题**：
- 基础：昨日2连板=20只、今日3连板=8只。2进3晋级率=？→ 8/20=40%
- 进阶：2进3=50%、3进4=30%、4进5=20%。这说明什么？→ 晋级率依层递减，但这不是异常——高位板天然晋级概率低。关键是和近期对比：如果过去5日均值是55%/35%/25%，则今日偏低→情绪转弱。

**推荐资源**：淘股吧/tgb连板复盘帖、同花顺涨停复盘功能、各大量化平台连板因子库

## 11. 常见问题与易错点

### 常见问题
**Q1: 训练不收敛？**
- 检查学习率是否合适
- 检查数据是否正确归一化
- 确认损失函数是否匹配任务

**Q2: 过拟合严重？**
- 增加数据量或使用数据增强
- 添加正则化（L1/L2/Dropout）
- 使用早停策略

**Q3: 超参数如何选？**
- 网格搜索或随机搜索
- 贝叶斯优化
- 参考论文推荐值

### 易错点
1. 数据泄露：预处理时使用测试集信息
2. 随机种子：忘记设置导致不可复现
3. 维度错误：输入shape与模型不匹配
4. 梯度问题：需要适当初始化和裁剪
5. 评估偏差：在训练集上评估
