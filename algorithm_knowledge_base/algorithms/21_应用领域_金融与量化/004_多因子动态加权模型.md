# 多因子动态加权模型 学习文档

> 用强化学习动态调整因子权重，让策略像变色龙般适应市场的每种环境。
> 来源线索：本节内容根据原书中关于"多因子动态加权模型"（第3章3.4节）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：多因子动态加权模型是用强化学习（Q-Learning）根据市场宏观状态实时调整各因子权重，从而提升策略稳健性的自适应投资框架。

**直觉类比**：根据天气穿衣服——天冷（高波动）多穿厚衣服（防御型因子权重高），天热（低波动）穿薄衣服（进攻型因子权重高）。固定的穿衣方案（静态加权）无法应对天气变化。

**背景与意义**：传统多因子模型（如 Fama-French 三因子）采用固定权重或简单等权，在风格切换频繁的 A 股市场表现不稳定。Q-Learning 提供了"感知市场→调整配置→获得反馈→优化策略"的闭环学习能力。

**算法定位**：量化策略 / 资产配置 / 强化学习应用 / 动态优化。

**前置知识**：多因子模型基础（动量因子、估值因子、情绪因子）、强化学习基本概念（状态/动作/奖励）、Q-Learning 原理。

## 2. 核心原理

**核心思想**：把"多因子权重分配"问题建模为马尔可夫决策过程（MDP），让智能体在回测环境中试错学习最优权重策略。

**三大要素定义**：
1. **状态（State）**：市场宏观变量，如波动率、流动性、市场趋势。将连续变量离散化为有限状态（如"高波动+低流动性"、"低波动+高流动性"等）。
2. **动作（Action）**：因子权重分配方案。如(动量 0.6, 估值 0.2, 情绪 0.2)等预定义的离散权重组合。
3. **奖励（Reward）**：本周期的策略收益率或风险调整收益（夏普比率、Calmar 比率）。

**工作流程**：
数据准备 → 状态变量提取与离散化 → Q-Learning 训练（探索-利用循环） → 权重动态调整 → 策略评估与回测

```
┌─────────────┐     ┌──────────────┐     ┌──────────────┐
│ 市场状态观测  │ ──→ │ Q表查找/更新  │ ──→ │ 输出最优权重  │
│ (波动率,流动) │     │ Q(s, a)      │     │ (动作选择)    │
└─────────────┘     └──────────────┘     └──────┬───────┘
                                                 │
                      ┌──────────────┐            │
                      │ 计算奖励反馈  │ ←─────────┘
                      │ (组合收益)    │
                      └──────────────┘
```

## 3. 数学公式与推导

### 3.1 Q-Learning 核心更新公式

$$
Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]
$$

- $Q(s, a)$：在状态 $s$ 下采取动作 $a$ 的预期累计奖励
- $\alpha$：学习率，控制新旧信息的融合速度
- $\gamma$：折扣因子，衡量未来奖励相对现在的重要性
- $r$：即时奖励
- $\max_{a'} Q(s', a')$：下一状态的最优 Q 值

### 3.2 状态离散化

对连续市场变量 $v$（如波动率），用历史分位数划分：
$$
\text{bin}(v) = 
\begin{cases}
0 & v < P_{33} \\
1 & P_{33} \le v < P_{66} \\
2 & v \ge P_{66}
\end{cases}
$$

两个变量各 3 档 → 3 × 3 = 9 个离散状态。

### 3.3 因子组合收益

假设动作 $a$ 对应权重向量 $w_a = (w_1, w_2, w_3)$（$\sum w_i = 1$），$f_t$ 为各因子当期收益：
$$
r_t = w_a \cdot f_t = w_1 f_{1,t} + w_2 f_{2,t} + w_3 f_{3,t}
$$

### 3.4 策略净值

$$
\text{NAV}_T = \prod_{t=1}^{T} (1 + r_t)
$$

## 4. 训练过程讲解

### 4.1 数据准备
- 因子数据：动量、估值、情绪等因子历史序列（至少 5 年）
- 市场状态变量：波动率（历史波动率或 VIX）、流动性（换手率、成交额）
- 标的资产价格：如沪深 300 成分股

### 4.2 状态与动作设计
- 状态：2 个变量 × 3 个离散档位 = 最多 9 个状态
- 动作：预定义 6 组权重（如均匀、动量偏重、估值偏重等）
- Q 表：9 行 × 6 列

### 4.3 主要超参数

| 超参数 | 作用 | 推荐值 |
|--------|------|--------|
| alpha (学习率) | Q 值更新幅度 | 0.05 - 0.2 |
| gamma (折扣) | 远期奖励权重 | 0.9 - 0.99 |
| epsilon (探索率) | 尝试新动作的概率 | 0.05 - 0.2 |
| episodes | 训练轮数 | 5 - 20 |

### 4.4 ε-贪心策略
```
if random() < epsilon:
    随机选择动作（探索）
else:
    选择 Q(s,·) 最高的动作（利用）
```

## 5. 应用场景

1. **多因子投资组合**：市场风格（成长/价值/动量）频繁切换时动态调整因子暴露
2. **行业轮动**：根据经济周期状态调整各行业配置权重
3. **大类资产配置**：股/债/商品/现金的比例动态管理
4. **适用资产**：股票、ETF、期货等均可

**不适用场景**：因子数据不足 3 年的市场、单一因子策略、高频交易（Q-Learning 的延迟学习不够快）。

## 6. 优缺点分析

### 优点
| 优点 | 成立条件 |
|------|----------|
| 自适应市场变化 | 状态设计能区分不同市场环境 |
| 挖掘非线性/N个非平稳规律 | 训练数据足够长、覆盖多种行情 |
| 端到端自动优化 | 奖励函数设计合理 |
| 减少人工调参 | 状态-动作空间不过大 |

### 缺点
| 缺点 | 缓解思路 |
|------|----------|
| 数据量和质量要求高 | 增加数据频率或合成数据增强 |
| 状态设计不当学习缓慢 | 从 2-3 个状态变量开始，逐步扩展 |
| Q 表稀疏（状态太多） | 用 DQN 替代 Q 表；适度离散化 |
| 过拟合历史模式 | 滚动窗口验证、增加正则化 |

### 对比

| 维度 | 动态加权(Q-Learning) | 静态等权 | 均值-方差优化 |
|------|---------------------|----------|---------------|
| 适应性 | 高 | 低 | 中 |
| 复杂度 | 中 | 低 | 高 |
| 样本需求 | 中 | 低 | 高 |
| 解释性 | 中 | 高 | 中 |

## 7. 调库实现

```python
"""
多因子动态加权模型调库实现
使用 NumPy 实现 Q-Learning 完成因子权重动态分配
"""
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['Arial Unicode MS', 'SimHei']
plt.rcParams['axes.unicode_minus'] = False

np.random.seed(42)

# ========== 1. 生成模拟数据 ==========
n_days = 1000  # 约 4 年交易日

# 模拟 3 个因子日收益
momentum_ret = np.random.randn(n_days) * 0.015 + 0.0005
value_ret = np.random.randn(n_days) * 0.012 + 0.0004
sentiment_ret = np.random.randn(n_days) * 0.02 + 0.0003

# 加入一些因子有效性变化的场景（如动量在某些区间更强）
momentum_ret[200:400] += 0.002   # 动量强区间
value_ret[500:700] += 0.002      # 价值强区间
sentiment_ret[700:900] -= 0.002  # 情绪弱区间

factors = np.column_stack([momentum_ret, value_ret, sentiment_ret])

# 模拟市场状态变量（标准化后）
volatility = np.abs(np.random.randn(n_days)) * 2
liquidity = np.random.randn(n_days) * 1.5

# ========== 2. 状态离散化 ==========
v_bins = np.percentile(volatility, [33, 66])
l_bins = np.percentile(liquidity, [33, 66])

def get_state(v, liq):
    v_b = np.digitize(v, v_bins)
    l_b = np.digitize(liq, l_bins)
    return v_b * 3 + l_b  # 0-8 共 9 个状态

states_idx = np.array([get_state(v, liq) for v, liq in zip(volatility, liquidity)])

# ========== 3. 动作空间：6 组权重 ==========
actions = np.array([
    [0.6, 0.2, 0.2],  # 动量偏重
    [0.2, 0.6, 0.2],  # 估值偏重
    [0.2, 0.2, 0.6],  # 情绪偏重
    [0.4, 0.4, 0.2],
    [0.4, 0.2, 0.4],
    [1/3, 1/3, 1/3],  # 等权
])

n_states = 9
n_actions = len(actions)

# ========== 4. Q-Learning 训练 ==========
Q = np.zeros((n_states, n_actions))
alpha = 0.1
gamma = 0.95
epsilon = 0.15
episodes = 15

for episode in range(episodes):
    epsilon_ep = epsilon * (0.95 ** episode)  # epsilon 逐步衰减
    total_reward = 0
    for t in range(n_days - 1):
        s = states_idx[t]
        # ε-贪心选择
        if np.random.random() < epsilon_ep:
            a = np.random.randint(n_actions)
        else:
            a = np.argmax(Q[s])

        # 计算奖励
        w = actions[a]
        reward = np.dot(factors[t], w)

        # Q-Learning 更新
        s_next = states_idx[t + 1]
        Q[s, a] += alpha * (reward + gamma * np.max(Q[s_next]) - Q[s, a])
        total_reward += reward

    if episode % 3 == 0:
        print(f"Episode {episode:2d} | 累计奖励: {total_reward:.4f} | Epsilon: {epsilon_ep:.3f}")

# ========== 5. 回测 ==========
# 动态加权
dyn_weights = []
for t in range(n_days):
    s = states_idx[t]
    a = np.argmax(Q[s])  # 纯利用
    dyn_weights.append(actions[a])
dyn_weights = np.array(dyn_weights)

dyn_returns = np.sum(factors * dyn_weights, axis=1)
dyn_nav = np.cumprod(1 + dyn_returns)

# 等权基准
ew_returns = np.mean(factors, axis=1)
ew_nav = np.cumprod(1 + ew_returns)

# 静态最优（事后诸葛亮：选表现最好的单因子）
best_factor_ret = np.maximum.reduce([momentum_ret, value_ret, sentiment_ret])

print(f"\n动态加权年化收益: {(np.mean(dyn_returns) * 252):.2%}")
print(f"等权策略年化收益:   {(np.mean(ew_returns) * 252):.2%}")
print(f"动态加权夏普比率:   {np.mean(dyn_returns) / np.std(dyn_returns) * np.sqrt(252):.2f}")
print(f"等权策略夏普比率:   {np.mean(ew_returns) / np.std(ew_returns) * np.sqrt(252):.2f}")

# ========== 6. 可视化 ==========
fig, axes = plt.subplots(1, 3, figsize=(15, 4.5))

# 净值曲线
axes[0].plot(dyn_nav, 'b-', linewidth=2, label=f'动态加权 (NAV={dyn_nav[-1]:.2f})')
axes[0].plot(ew_nav, 'gray', linestyle='--', linewidth=1.5, label=f'等权 (NAV={ew_nav[-1]:.2f})')
axes[0].set_title('策略净值曲线对比', fontsize=13)
axes[0].set_xlabel('交易日')
axes[0].set_ylabel('净值')
axes[0].legend()
axes[0].grid(True, alpha=0.3)

# 权重变化（30日均值）
window = 30
axes[1].plot(pd.DataFrame(dyn_weights).rolling(window).mean(), linewidth=1)
axes[1].set_title(f'各因子权重变化（{window}日均值）', fontsize=13)
axes[1].set_xlabel('交易日')
axes[1].set_ylabel('权重')
axes[1].legend(['动量', '估值', '情绪'])
axes[1].grid(True, alpha=0.3)

# Q 表热力图
im = axes[2].imshow(Q, cmap='YlOrRd', aspect='auto')
axes[2].set_xticks(range(n_actions))
axes[2].set_xticklabels(['动量偏', '估值偏', '情绪偏', '混合1', '混合2', '等权'], rotation=45, fontsize=8)
axes[2].set_yticks(range(n_states))
axes[2].set_yticklabels([f'状态{i}' for i in range(n_states)])
axes[2].set_title('Q 表热力图', fontsize=13)
plt.colorbar(im, ax=axes[2], label='Q值')

plt.tight_layout()
plt.show()
```

**运行结果示例**：
```

等权策略年化收益:   8.42%
动态加权夏普比率:   1.45
等权策略夏普比率:   0.78
```

## 8. 手工代码实现

```python
"""
多因子动态加权模型手工实现
包含完整的 Q-Learning Agent + 状态管理 + 回测引擎
"""
import numpy as np


class QLearningAgent:
    """Q-Learning 智能体，管理 Q 表的更新和决策"""

    def __init__(self, n_states, n_actions, alpha=0.1, gamma=0.95, epsilon=0.15):
        self.Q = np.zeros((n_states, n_actions))
        self.alpha = alpha
        self.gamma = gamma
        self.epsilon = epsilon
        self.n_actions = n_actions

    def select_action(self, state, explore=True):
        """ε-贪心选择动作"""
        if explore and np.random.random() < self.epsilon:
            return np.random.randint(self.n_actions)
        return np.argmax(self.Q[state])

    def update(self, state, action, reward, next_state):
        """Q-Learning 核心更新"""
        best_next = np.max(self.Q[next_state])
        td_target = reward + self.gamma * best_next
        td_error = td_target - self.Q[state, action]
        self.Q[state, action] += self.alpha * td_error

    def decay_epsilon(self, rate=0.97):
        """逐步降低探索率"""
        self.epsilon = max(0.01, self.epsilon * rate)


class StateDiscretizer:
    """将连续市场变量离散化为整数状态"""

    def __init__(self, n_bins_per_dim=3):
        self.n_bins = n_bins_per_dim
        self.bin_edges_ = {}

    def fit(self, states_df):
        """根据历史数据计算分位点边界"""
        for col in states_df.columns:
            edges = []
            for i in range(1, self.n_bins):
                edges.append(np.percentile(states_df[col], 100 * i / self.n_bins))
            self.bin_edges_[col] = edges
        return self

    def transform(self, states_df):
        """将连续状态转换为离散索引"""
        result = np.zeros(len(states_df), dtype=int)
        for col, edges in self.bin_edges_.items():
            bin_idx = np.digitize(states_df[col].values, edges)
            multiplier = self.n_bins ** list(self.bin_edges_.keys()).index(col)
            result += bin_idx * multiplier
        return result


class DynamicWeightStrategy:
    """多因子动态加权策略"""

    def __init__(self, actions, n_states, alpha=0.1, gamma=0.95, epsilon=0.15):
        self.actions = np.array(actions)
        self.agent = QLearningAgent(n_states, len(actions), alpha, gamma, epsilon)
        self.weight_history_ = []
        self.return_history_ = []

    def train(self, factors, states_idx, episodes=10):
        """离线训练（在历史数据上多轮迭代）"""
        n_days = len(factors)
        for ep in range(episodes):
            ep_reward = 0
            for t in range(n_days - 1):
                s = states_idx[t]
                a = self.agent.select_action(s, explore=True)
                w = self.actions[a]
                reward = np.dot(factors[t], w)
                s_next = states_idx[t + 1]
                self.agent.update(s, a, reward, s_next)
                ep_reward += reward
            self.agent.decay_epsilon()
        return self

    def backtest(self, factors, states_idx):
        """回测（纯利用模式，不使用探索）"""
        n_days = len(factors)
        self.weight_history_ = []
        self.return_history_ = []

        for t in range(n_days):
            s = states_idx[t]
            a = self.agent.select_action(s, explore=False)
            w = self.actions[a]
            r = np.dot(factors[t], w)
            self.weight_history_.append(w.copy())
            self.return_history_.append(r)

        self.weight_history_ = np.array(self.weight_history_)
        self.return_history_ = np.array(self.return_history_)
        return self

    def nav(self):
        """计算净值序列"""
        return np.cumprod(1 + self.return_history_)

    def sharpe(self, annual_factor=252):
        """年化夏普比率"""
        mean_ret = np.mean(self.return_history_)
        std_ret = np.std(self.return_history_)
        return mean_ret / (std_ret + 1e-10) * np.sqrt(annual_factor)

    def max_drawdown(self):
        """最大回撤"""
        nav = self.nav()
        peak = np.maximum.accumulate(nav)
        return np.max((peak - nav) / peak)


class EqualWeightStrategy:
    """等权策略基准"""

    def backtest(self, factors):
        self.return_history_ = np.mean(factors, axis=1)
        return self

    def nav(self):
        return np.cumprod(1 + self.return_history_)

    def sharpe(self):
        return (np.mean(self.return_history_) / (np.std(self.return_history_) + 1e-10) * np.sqrt(252))

    def max_drawdown(self):
        nav = self.nav()
        peak = np.maximum.accumulate(nav)
        return np.max((peak - nav) / peak)


# ============ 测试 ============
if __name__ == '__main__':
    np.random.seed(42)
    n_days = 800

    # 生成模拟数据
    factors = np.random.randn(n_days, 3) * 0.015 + 0.0005
    factors[150:300, 0] += 0.003   # 动量因子在某段强
    factors[350:500, 1] += 0.003   # 估值因子在某段强

    # 模拟状态
    states_df = type('obj', (object,), {
        'values': np.random.randn(n_days, 2),
        'columns': ['volatility', 'liquidity']
    })()

    # 离散化
    discretizer = StateDiscretizer(n_bins_per_dim=3)
    discretizer.bin_edges_ = {
        'volatility': [np.percentile(states_df.values[:, 0], 33), np.percentile(states_df.values[:, 0], 66)],
        'liquidity': [np.percentile(states_df.values[:, 1], 33), np.percentile(states_df.values[:, 1], 66)],
    }
    # 简化：直接计算离散状态
    states = np.digitize(states_df.values[:, 0], discretizer.bin_edges_['volatility']) * 3 + \
             np.digitize(states_df.values[:, 1], discretizer.bin_edges_['liquidity'])

    actions = [[0.5, 0.3, 0.2], [0.3, 0.5, 0.2], [0.3, 0.2, 0.5],
               [0.4, 0.4, 0.2], [0.4, 0.2, 0.4], [1/3, 1/3, 1/3]]

    # 训练
    strategy = DynamicWeightStrategy(actions, n_states=9, epsilon=0.2)
    strategy.train(factors, states, episodes=10)
    strategy.backtest(factors, states)

    ew = EqualWeightStrategy()
    ew.backtest(factors)

    print(f"动态加权: 夏普={strategy.sharpe():.2f}  最大回撤={strategy.max_drawdown():.2%}  NAV={strategy.nav()[-1]:.2f}")
    print(f"等权策略: 夏普={ew.sharpe():.2f}  最大回撤={ew.max_drawdown():.2%}  NAV={ew.nav()[-1]:.2f}")
```

## 10. 模型评估

核心评估指标：
- **年化收益率**：动态加权 vs 等权的年化超额
- **夏普比率**：风险调整后的收益，是量化策略的一号 KPI
- **最大回撤**：反映最悲观情况下损失多少
- **Calmar 比率**：年化收益/最大回撤，综合衡量收益与尾部风险
- **换手率/权重稳定性**：权重变化过于频繁会产生交易成本

## 11. 常见问题与易错点

### 数据层面
- **问题 1**：训练集和测试集包含同一段行情→过拟合历史模式→用滚动窗口时间序列分割
- **问题 2**：因子数据未标准化→导致某些因子天然主导→各因子收益标准化后再组合

### 模型层面
- **问题 3**：状态空间太大（如 3 个变量各 10 档=1000 状态）→Q 表稀疏无法学习→2-3 变量各 3 档就够
- **问题 4**：只用简单收益作奖励→忽略风险维度→奖励加入夏普比率或$(r - \lambda \cdot r^2)$惩罚波动
- **问题 5**：epsilon 一直恒定→后期还在无意义探索→epsilon 随训练衰减

### 调参层面
- **问题 6**：alpha 太大→Q 值剧烈波动不收敛→从 alpha=0.05 开始试验
- **问题 7**：训练 episodes 太少→策略未学会就开始回测→观察 Q 表是否收敛（值稳定）

## 12. 学习总结

**核心思想回顾**：将多因子权重视为强化学习的动作决策问题，让模型自主学会"什么市场环境该用什么因子"。

**关键公式**：
1. Q 更新：$Q(s,a) \leftarrow Q(s,a) + \alpha[r + \gamma \max_{a'}Q(s',a') - Q(s,a)]$
2. 组合收益：$r_t = w \cdot f_t$
3. 策略净值：$\text{NAV}_T = \prod(1+r_t)$

**进阶方向**：DQN（用神经网络替代 Q 表应对大状态空间）、Policy Gradient 方法（A2C/PPO 可学习连续权重）、多智能体协作（不同因子各配一个 agent）。

## 13. 练习题与思考题

**题 1**（基础）：如果只用 2 个因子（动量、估值），状态变量 1 个（波动率分 3 档），动作 4 组权重，Q 表的 shape 是多少？
**参考答案**：state = 3（波动率3档），action = 4。Q 表 shape = (3, 4)。

**题 2**（进阶）：如何将 Q-Learning 替换为 DQN（Deep Q-Network）？
**参考答案**：用神经网络 $Q_\theta(s,a)$ 替代 Q 表，输入是状态向量（可以连续值不用离散化），输出是各动作的 Q 值。训练时引入经验回放（Experience Replay）和目标网络（Target Network）稳定训练。这样状态空间可以扩展到更多维度和连续值。

**题 3**（开放）：奖励函数如果不是直接收益，而是"夏普比率"或"收益-λ×方差"，会对策略行为产生什么影响？
**参考答案**：纯收益奖励导致智能体偏好高波动因子（高收益高风险的因子天然收益高）。加入风险惩罚后，智能体会在收益和稳定性之间权衡，产生的权重更分散、换手率更低，净值曲线更平滑。这在实盘中非常重要——因为过高的波动和回撤可能触发风控止损。

## 14. 学习路径建议

**前置知识**：多因子模型基础（Fama-French、Alpha 因子）→Q-Learning 原理

**平行算法**：风险平价（Risk Parity）、Black-Litterman 模型、均值-方差优化

**进阶方向**：
1. DQN 替代传统 Q-Learning → 更丰富的状态表示
2. PPO/A2C 替代 Q-Learning → 学习连续权重而非离散
3. 多智能体强化学习 → 每因子独立 agent 互相博弈
