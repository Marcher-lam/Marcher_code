## 1. 算法基础认知

**一句话定义**：通过对龙虎榜游资席位的历史买卖行为、持仓周期和操作风格进行系统分析，构建跟投策略的量化方法。

**直觉类比**：刑侦探案——通过分析嫌疑人的行动轨迹、作案手法、偏好时间、习惯工具，来预测其下一次行动。游资席位分析就是"金融侦探"工作。

**背景**：A股龙虎榜制度要求满足涨跌幅偏离值/换手率等条件的股票披露前五买卖席位。知名游资席位（如华泰荣超、中信溧阳路）的操作模式往往具有一定规律性和可预测性。

**算法定位**：量化策略 / 另类数据 / 行为金融 / 跟投策略。

**前置知识**：A股龙虎榜制度、席位概念、游资文化。

## 2. 核心原理

**游资席位行为分析框架**：

| 分析维度 | 核心指标 | 策略意义 |
|----------|----------|----------|
| 买卖方向 | 买入/卖出金额比 | 净买入>净卖出 → 整体看多 |
| 持仓周期 | 从买入到卖出的天数 | 1-2天=超短；5-10天=波段 |
| 操作风格 | 打板/低吸/追涨 | 匹配自身策略风格 |
| 板块偏好 | 最常操作的行业 | 结合板块轮动判断 |

**跟投策略逻辑**：
1. 筛选过去3个月胜率>55%的席位
2. 当这些席位当日大量买入(占成交额>5%)
3. 次日开盘跟随买入
4. 持有2-5个交易日
5. 止损：-5%

## 3. 数学公式

### 3.1 席位净买入强度
$$
\text{NetIntensity} = \frac{\text{BuyAmount} - \text{SellAmount}}{\text{TotalTurnover}}
$$

### 3.2 席位胜率（滚动3个月）
$$
\text{WinRate} = \frac{\sum \mathbb{1}[ret_i > 0]}{\text{TotalTrades}}
$$
ret_i 是买入后N日的收益率。

### 3.3 跟投信心评分
$$
\text{Confidence} = \text{WinRate} \times \min(1, \frac{\text{TradeCount}}{20}) \times \frac{\text{NetIntensity}}{0.05}
$$

## 4. 训练过程讲解

- 采集近1年龙虎榜数据（每交易日披露）
- 提取席位名称、买卖金额、股票代码
- 按席位汇总历史交易记录
- 计算各席位胜率、平均收益、盈亏比
- 每日监控龙虎榜更新，匹配高分席位信号
- 跟投回测（考虑T+1数据滞后）

**关键参数**：胜率计算窗口=60交易日、持仓周期=3日、跟投金额=总资金的5%单票

## 5. 应用场景

- A股短线跟投：跟随胜率高的知名游资
- 主力资金监控：判断市场整体资金情绪
- 涨停板策略辅助：游资聚集的股票关注度高

**适用**：A股（龙虎榜制度）、游资活跃的题材炒作期
**不适用**：龙虎榜数据缺失的市场、纯机构主导的蓝筹行情

## 6. 优缺点分析

**优点**：跟随确定性的资金方向、信号明确、回测可行
**缺点**：数据T+1滞后（今天看到的数据是昨天的）、游资策略会变化、知名席位可能故意反向操作（反跟投陷阱）

## 7. 调库实现

```python
"""游资席位分析 + 跟投策略"""
import numpy as np
import pandas as pd

np.random.seed(42)

# ========== 1. 模拟龙虎榜数据 ==========
seats = ['华泰荣超', '中信溧阳路', '国泰君安上海', '东方财富拉萨', '中金财富']
n_records = 300

df = pd.DataFrame({
    'date': np.random.choice(pd.date_range('2024-01-01', periods=100, freq='B'), n_records),
    'seat': np.random.choice(seats, n_records),
    'stock': [f'{600000 + np.random.randint(1,500):06d}' for _ in range(n_records)],
    'buy_amount': np.random.exponential(500, n_records),
    'sell_amount': np.random.exponential(300, n_records),
    'total_turnover': np.random.exponential(2000, n_records),
})

# ========== 2. 席位分析 ==========
# 净买入强度
df['net_intensity'] = (df['buy_amount'] - df['sell_amount']) / df['total_turnover']

# 模拟未来收益（净买入强度高的股票有一定正收益倾向）
df['future_ret_3d'] = df['net_intensity'] * 3 + np.random.randn(n_records) * 2

# 各席位胜率统计
seat_stats = df.groupby('seat').agg(
    交易次数=('date', 'count'),
    胜率=('future_ret_3d', lambda x: (x > 0).mean()),
    平均收益=('future_ret_3d', 'mean'),
    平均净买入强度=('net_intensity', 'mean'),
).round(3)

print("席位行为分析:")
print(seat_stats.sort_values('胜率', ascending=False).to_string())

# ========== 3. 跟投回测 ==========
# 筛选高胜率席位(>55%) + 高净买入(>3%)
top_seats = seat_stats[seat_stats['胜率'] > 0.55].index
follow_df = df[(df['seat'].isin(top_seats)) & (df['net_intensity'] > 0.03)]

if len(follow_df) > 0:
    follow_ret = follow_df['future_ret_3d']
    print(f"\n跟投策略: 信号={len(follow_df)}次, "
          f"胜率={(follow_ret>0).mean():.0%}, "
          f"均收益={follow_ret.mean():.2f}%")
```

## 8. 手工代码实现

```python
"""游资分析手工实现"""
import numpy as np
from collections import defaultdict

class SeatTracker:
    def __init__(self):
        self.trades = defaultdict(list)

    def record(self, seat, buy, sell, turnover, future_ret):
        self.trades[seat].append({
            'net_intensity': (buy - sell) / turnover,
            'future_ret': future_ret,
        })

    def seat_stats(self, min_trades=10):
        stats = {}
        for seat, trades in self.trades.items():
            if len(trades) < min_trades: continue
            rets = [t['future_ret'] for t in trades]
            stats[seat] = {
                'trades': len(trades),
                'win_rate': np.mean([r > 0 for r in rets]),
                'avg_ret': np.mean(rets),
            }
        return stats

# 测试
if __name__ == '__main__':
    tracker = SeatTracker()
    np.random.seed(42)
    for _ in range(200):
        tracker.record(
            np.random.choice(['A席位', 'B席位']),
            np.random.exponential(500), np.random.exponential(300),
            np.random.exponential(2000), np.random.randn() * 2
        )
    stats = tracker.seat_stats()
    for s, st in stats.items():
        print(f"{s}: 胜率={st['win_rate']:.0%}, 均收益={st['avg_ret']:.2f}%")
```

## 9-14. 综合章节

**关键公式**：净买入强度 = (买入-卖出)/成交额，跟投信心 = 胜率 × 经验系数 × 净买入强度比例

**常见问题**：T+1数据滞后(最大的局限)——可结合盘中分时数据提前预判席位可能的操作方向；游资刻意反向操作(拉升出货)——不能单一依靠席位，需结合量价关系综合判断

**学习路径**：龙虎榜制度 → 席位分类 → 行为模式统计 → 多信号融合跟投

**练习题**：
- 基础：某席位过去30笔交易胜率=60%、平均收益=2.5%。净买入强度=5%。是否值得跟投？→ 胜率>55%、收益为正、净买入强度高 → 值得跟投
- 进阶：为什么统计胜率要用"买入后持有N日的收益"而不是"次日收益"？→ 游资建仓后可能在2-3天内逐步拉升出货，仅看次日收益可能只捕捉到洗盘而非主升段，3-5日窗口更合理
- 开放：如何用机器学习替代简单的胜率统计？→ 构造特征矩阵(席位ID、板块、市场情绪、买入力度、持仓集中度等)，用XGBoost训练"跟投是否盈利"的二分类模型，输出跟投概率

**推荐资源**：东方财富龙虎榜数据、A股席位数据库、跟投策略回测框架

## 11. 常见问题与易错点

### 常见问题
**Q1: 训练不收敛？**
- 检查学习率是否合适
- 检查数据是否正确归一化

- 增加数据量或使用数据增强
- 添加正则化（L1/L2/Dropout）
- 使用早停策略

**Q3: 超参数如何选？**
