## 1. 算法基础认知

**一句话定义**：从价格、量能、市值、题材、资金五个维度系统提取龙头股的共性特征，构建评分模型筛选具备龙头潜力的标的。

**直觉类比**：球探选拔足球新星——不是看一场比赛，而是综合评估速度、技术、意识、体能、心理素质五个维度，和历史球星的标准对比打分。

**背景**：A股龙头股往往在多个维度上展现出与普通涨停股显著性差异。仅靠单一指标（如连板高度）判断龙头容易误判，需要多维度系统评估。

**算法定位**：量化策略 / 贝塔策略 / 多因子选股 / 特征工程。

**前置知识**：A股涨停板机制、技术分析基础、多因子模型概念。

## 2. 核心原理

**五维特征体系**：

| 维度 | 核心指标 | 龙头股典型特征 |
|------|----------|---------------|
| 价格 | 首板涨幅、封板时间 | 越早封板越好（9:35前最佳） |
| 量能 | 换手率、封单额/流通市值 | 适中换手+大封单 |
| 市值 | 流通市值 | 20-80亿偏小盘 |
| 题材 | 新颖度、板块效应、政策力度 | 新题材+政策支撑+板块联动 |
| 资金 | 龙虎榜净买、主力净流入 | 知名游资+机构同时买入 |

**综合评分流程**：
1. 每个维度 0-20 分，满分 100 分
2. 归一化各指标后加权求和
3. 得分 > 70 → 龙头候选
4. 每日更新候选池

## 3. 数学公式

$$
S_{total} = \sum_{d=1}^{5} w_d \cdot \text{Score}_d
$$

各维度得分 = 该维度内多个子指标的加权：
$$
\text{Score}_d = \sum_{j} w_{d,j} \cdot \text{norm}(indicator_{d,j}) \times 20
$$

权重可以通过历史龙头股样本的XGBoost重要性来优化。

## 4. 训练过程讲解

**步骤**：
1. 建立历史龙头股样本库（近2年 5连板+个股）
2. 计算每个样本的五维指标
3. 用XGBoost训练龙头vs普通涨停的分类器
4. 提取特征重要性作为各维度权重
5. 每日扫描全市场涨停股，输出龙头概率评分
6. 滚动更新：每季度用新样本重新训练

## 5. 应用场景

- **超短线打板**：只在龙头评分>80的标的上重仓
- **题材主线识别**：某个题材多只高评分股出现→主线确认
- **仓位管理增强**：龙头评分趋势上升→加大风险暴露
- **回撤控制**：龙头评分连续下降→市场情绪转弱→减仓

## 6. 优缺点分析

**优点**：系统性（五维度覆盖全面）、可复制（机器评分客观）、可进化（权重自动优化）
**缺点**：历史依赖（市场生态变化后历史样本失效）、数据要求高（部分维度如龙虎榜数据滞后）、过拟合风险

## 7. 调库实现

```python
"""龙头股五维评分系统"""
import numpy as np
import pandas as pd

np.random.seed(42)
n_stocks = 100

# 模拟涨停股的五维数据
df = pd.DataFrame({
    'seal_time_min': np.random.uniform(0, 60, n_stocks),  # 封板时间(开盘后分钟)
    'turnover_rate': np.random.uniform(2, 20, n_stocks),
    'seal_amount_ratio': np.random.uniform(1, 15, n_stocks),  # 封单/流通市值%
    'market_cap': np.random.uniform(5e8, 200e9, n_stocks),
    'topic_score': np.random.uniform(0, 1, n_stocks),  # 题材评分
    'net_capital_inflow': np.random.randn(n_stocks) * 0.5,
})

# 各维度评分（归一化后映射到0-20）
def norm_score(series, reverse=False):
    mn, mx = series.min(), series.max()
    s = (series - mn) / (mx - mn + 1e-8)
    return (1 - s if reverse else s) * 20

df['price_score'] = norm_score(df['seal_time_min'], reverse=True)
df['volume_score'] = (
    norm_score(df['turnover_rate']) * 0.4 +
    norm_score(df['seal_amount_ratio']) * 0.6
)
df['mv_score'] = norm_score(df['market_cap'], reverse=True)
df['topic_score_20'] = norm_score(df['topic_score'])
df['capital_score'] = norm_score(df['net_capital_inflow'])

weights = [0.20, 0.25, 0.20, 0.20, 0.15]
df['total_score'] = (
    weights[0]*df['price_score'] + weights[1]*df['volume_score'] +
    weights[2]*df['mv_score'] + weights[3]*df['topic_score_20'] +
    weights[4]*df['capital_score']
)

leaders = df.nlargest(10, 'total_score')
print("Top10 龙头候选:")
print(leaders[['total_score']].round(1).to_string())
```

## 11. 常见问题与易错点

### 常见问题
**Q1: 训练不收敛？**
- 检查学习率是否合适
- 检查数据是否正确归一化
- 确认损失函数是否匹配任务

**Q2: 过拟合严重？**
- 增加数据量或使用数据增强
- 添加正则化（L1/L2/Dropout）
- 使用早停策略

**Q3: 超参数如何选？**
- 网格搜索或随机搜索
- 贝叶斯优化
- 参考论文推荐值

### 易错点
1. 数据泄露：预处理时使用测试集信息
2. 随机种子：忘记设置导致不可复现
3. 维度错误：输入shape与模型不匹配
4. 梯度问题：需要适当初始化和裁剪
5. 评估偏差：在训练集上评估
