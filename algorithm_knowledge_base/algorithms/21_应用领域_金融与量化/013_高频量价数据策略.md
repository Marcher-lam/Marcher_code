## 1. 算法基础认知

**一句话定义**：基于Tick/分钟级高频行情数据，通过识别量价微观模式（大单异动、流动性突变、量价背离）构建超短线交易策略的方法。

**直觉类比**：高速摄像机——普通摄像机(日线数据)只能看到人的行走轨迹，高速摄像机(Tick数据)能捕捉到每一步的肌肉运动。高频量价策略就是用"高速摄像机"看市场，捕捉慢速数据看不到的微结构机会。

**背景**：随着市场微观结构理论的发展和高频数据获取成本的下降，基于Tick/分钟数据的策略从机构专属逐渐向更广泛的量化开发者扩散。A股高频量价策略的年化收益潜力远超日频策略，但技术门槛和成本也较高。

**算法定位**：量化策略 / 贝塔策略 / 高频交易 / 微观结构建模。

**前置知识**：高频数据结构、市场微观结构基础、行情传输机制。

## 2. 核心原理

**四大高频量价信号模式**：

1. **量价背离**：价格创新高但成交量递减 → 上涨乏力 → 做空
2. **大单异动**：单笔成交远超近期均值 → 主力资金进出信号
3. **流动性突变**：盘口深度骤降→波动加大→做多/做空波动率
4. **成交密集区突破**：价格突破近期成交量最大的价位→方向确认

**核心挑战**：
- 信号与噪声的区分：高频数据的信噪比远低于日频
- 交易成本：频繁交易的手续费和滑点是高频策略最大杀手
- 竞争激烈：同样的信号逻辑可能有几百家量化机构在用

## 3. 数学公式

### 3.1 异常检测
$$
\text{Z-score}_t = \frac{X_t - \mu_{\text{rolling}}}{\sigma_{\text{rolling}}}
$$

### 3.2 高频量价相关
滚动窗口(如100 tick)的量价相关系数：
$$
\rho_t = \frac{\sum (V_i - \bar{V})(P_i - \bar{P})}{\sqrt{\sum (V_i-\bar{V})^2 \sum (P_i-\bar{P})^2}}
$$
$\rho_t$由正转负 → 量价背离信号。

### 3.3 微观结构波动率
$$
\sigma_{\text{micro}} = \sqrt{\frac{1}{N}\sum (r_i - \bar{r})^2}
$$
$r_i$为tick级收益率。

## 4. 训练过程讲解

**数据采集**：3秒/1秒/Tick级数据，需考虑存储(千万行/日/品种)
**预处理**：时间对齐、异常tick过滤、涨跌停期间特殊处理
**特征构造**：滚动统计(均值/标准差/分位数)、大单标记、量价相关
**信号逻辑**：设定多条件触发的做多/做空调控
**回测**：必须逐笔回测(不能用向量化)，加入佣金+滑点+冲击成本

## 5. 应用场景

- **日内T+0回转**：可转债/ETF的当日买卖套利
- **高频做市**：在买卖价差中持续获利
- **算法执行优化**：大单拆分后选择最优执行时点
- **统计套利**：配对品种的短期价差捕捉

**适用**：高流动性品种、T+0品种(可转债/期货/ETF)；**不适用**：T+1且无对冲工具的纯股票、极端低流动性

## 6. 优缺点分析

**优点**：信号丰富(一天有数千个交易机会)、与低频策略低相关(组合优化)、策略容量可调
**缺点**：数据成本高、技术门槛高、交易成本敏感、模型衰减快(市场微结构变化快)

## 7. 调库实现

```python
"""高频量价数据策略（模拟分钟级数据）"""
import numpy as np
import pandas as pd

np.random.seed(42)
n_bars = 500  # 模拟500根分钟K线

# ========== 1. 生成分钟级数据 ==========
price = 50 + np.cumsum(np.random.randn(n_bars) * 0.05)
volume = np.random.exponential(50000, n_bars)

# 构造量价背离信号
df = pd.DataFrame({'price': price, 'volume': volume})

# 滚动统计（20期）
window = 20
df['price_ma'] = df['price'].rolling(window).mean()
df['volume_ma'] = df['volume'].rolling(window).mean()
df['volume_std'] = df['volume'].rolling(window).std()

# 量价相关
df['corr'] = df['price'].rolling(window).corr(df['volume'])

# ========== 2. 信号生成 ==========
df['signal'] = 0
# 价格创新高 + 量缩 → 做空
df.loc[(df['price'] > df['price'].rolling(50).max().shift(1)) &
       (df['volume'] < df['volume_ma'] * 0.7), 'signal'] = -1
# 价格创新低 + 量缩 → 做多（底背离）
df.loc[(df['price'] < df['price'].rolling(50).min().shift(1)) &
       (df['volume'] < df['volume_ma'] * 0.7), 'signal'] = 1
# 量大异动(Z>2)→趋势跟随
df['vol_z'] = (df['volume'] - df['volume_ma']) / (df['volume_std'] + 1e-8)
df.loc[(df['vol_z'] > 2) & (df['price'] > df['price_ma']), 'signal'] = 1
df.loc[(df['vol_z'] > 2) & (df['price'] < df['price_ma']), 'signal'] = -1

# ========== 3. 回测 ==========
df['future_ret'] = df['price'].shift(-5) / df['price'] - 1
df['strategy_ret'] = df['signal'] * df['future_ret']
df = df.dropna()

trades = df[df['signal'] != 0]
print(f"信号数: {len(trades)} | 胜率: {(trades['strategy_ret']>0).mean():.0%}")
print(f"总收益: {df['strategy_ret'].sum():.4f}")

# ========== 4. 可视化 ==========
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['Arial Unicode MS', 'SimHei']
plt.rcParams['axes.unicode_minus'] = False

fig, axes = plt.subplots(2, 1, figsize=(14, 7))
axes[0].plot(df['price'], 'gray', linewidth=0.6, label='价格')
buy = df[df['signal'] == 1]
sell = df[df['signal'] == -1]
axes[0].scatter(buy.index, buy['price'], c='r', s=15, marker='^', label='买入')
axes[0].scatter(sell.index, sell['price'], c='g', s=15, marker='v', label='卖出')
axes[0].set_title('高频量价策略信号')
axes[0].legend(fontsize=8)
axes[0].grid(True, alpha=0.3)

axes[1].bar(df.index, df['volume'], alpha=0.5, color='steelblue', label='成交量')
axes[1].set_title('成交量与大单异动')
axes[1].grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

**常见问题**：向量化回测不可靠→必须事件驱动逐笔回测；交易成本忽略→佣金+印花税(0.1%)+滑点(0.1%)是高频的三大杀手；数据生存者偏差→用到了事后才有的价格

**练习题**：
- 基础：100 tick内量价相关系数从+0.6降到-0.3，说明什么？→量价从"价涨量增"变为"价涨量缩"，上涨乏力，考虑做空。
- 进阶：为什么"量在价先"在高频中很重要？→高频中，成交量(尤其是大单)的变化往往领先价格1-3秒。先看到量大增→证明有资金在行动→再判断价格方向，比直接追价更可靠。

## 11. 常见问题与易错点

### 常见问题
**Q1: 训练不收敛？**
- 检查学习率是否合适
- 检查数据是否正确归一化
- 确认损失函数是否匹配任务

**Q2: 过拟合严重？**
- 增加数据量或使用数据增强
- 添加正则化（L1/L2/Dropout）
- 使用早停策略

**Q3: 超参数如何选？**
- 网格搜索或随机搜索
- 贝叶斯优化
- 参考论文推荐值

### 易错点
1. 数据泄露：预处理时使用测试集信息
2. 随机种子：忘记设置导致不可复现
3. 维度错误：输入shape与模型不匹配
4. 梯度问题：需要适当初始化和裁剪
5. 评估偏差：在训练集上评估
