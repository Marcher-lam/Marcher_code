## 1. 算法基础认知

**一句话定义**：通过分析历史连板龙头股的首板共性特征，构建"模仿因子"筛选当前市场中具备类似特征的潜在龙头股的量化选股方法。

**直觉类比**：研究历年高考状元的共同学习习惯（早起、刷题、错题本），然后寻找具备同样习惯的学弟学妹，提前预测下一个状元。

**背景**：A股市场中，龙头股的五连板及以上行情往往伴随资金集中流入和板块轮动。这些龙头股在首板阶段通常具备共同特征：小市值、换手率偏高、题材新颖。通过复盘总结这些共性，可以构建"模仿因子"来早期识别。

**算法定位**：量化策略 / 资产配置 / 选股框架 / 行为金融应用。

**前置知识**：A股涨停板制度、基本面基础（市值、换手率）、统计描述（中位数、分位数）。

## 2. 核心原理

**模仿因子三要素**：
1. **小市值**：5连板龙头首板阶段市值中位数约 30-80 亿。小盘股容易被资金主导拉升。
2. **新题材**：题材首次出现在近 3 个月内的"新概念"更具想象空间。
3. **低换手率（相对区间）**：首板换手率不超过龙头股样本的 75% 分位数——说明筹码相对集中。

**工作流程**：
1. 筛选近一年 5连板及以上龙头股
2. 提取首板日期的市值、换手率、题材首次出现时间
3. 统计中位数和分位数区间
4. 每日扫描全市场，计算模仿因子得分
5. 高分股作为候选标的，结合当日的资金流向和题材热度确认
6. 模拟"首板买入+持有N日"策略进行回测

## 3. 数学公式

### 3.1 模仿因子得分
每个条件满足得 1 分，满分 3 分：
```
score = I(市值 < median_mv) + I(题材为3个月内新出现) + I(换手率 < P75 换手率)
```

### 3.2 市值阈值
$threshold_{mv} = median(mv_{leader\_samples})$

### 3.3 新题材判定
$is\_new\_topic = (trade\_date - topic\_first\_date) < 90 \text{ days}$

## 5. 应用场景

- **A股短线选股**：结合每日资金流向监控，筛选模仿因子高分的潜在龙头
- **题材轮动跟踪**：监控板块资金流入流出，寻找轮动切换信号

**适用**：题材炒作活跃的A股阶段、中小盘成长股
**不适用**：蓝筹白马主导的"抱团"行情、注册制下壳价值下降期

## 7. 调库实现

```python
"""
资金流向与板块轮动：龙头股特征提取 + 模仿因子选股
"""
import numpy as np
import pandas as pd

np.random.seed(42)

# ========== 1. 模拟历史龙头股样本 ==========
n_leader_samples = 50  # 近一年 50 个龙头股

# 模拟首板日的特征
leader_mv = np.random.uniform(2e9, 15e9, n_leader_samples)  # 20亿-150亿市值
leader_turnover = np.random.uniform(3, 15, n_leader_samples)  # 换手率 3%-15%

median_mv = np.median(leader_mv)
turnover_p25, turnover_p75 = np.percentile(leader_turnover, [25, 75])

print(f"龙头股首板特征统计:")
print(f"  市值中位数: {median_mv/1e8:.1f} 亿")
print(f"  换手率区间:  {turnover_p25:.1f}% - {turnover_p75:.1f}%")

# ========== 2. 模拟当日全市场数据 ==========
n_today = 500  # 当日 500 只股票扫描

today_mv = np.random.uniform(5e8, 100e9, n_today)
today_turnover = np.random.uniform(0.5, 25, n_today)
# 模拟题材新颖度：随机 20% 是近 3 月新题材
today_new_topic = np.random.random(n_today) < 0.2

# ========== 3. 计算模仿因子得分 ==========
mimic_score = np.zeros(n_today)
mimic_score += (today_mv < median_mv).astype(int)
mimic_score += today_new_topic.astype(int)
mimic_score += (today_turnover < turnover_p75).astype(int)

# ========== 4. 筛选候选股 ==========
candidates = pd.DataFrame({
    '股票编号': np.arange(n_today),
    '市值(亿)': today_mv / 1e8,
    '换手率(%)': today_turnover,
    '新题材': today_new_topic,
    '模仿得分': mimic_score,
}).sort_values('模仿得分', ascending=False)

print(f"\n3分股票数: {(mimic_score==3).sum()}")
print(f"2分股票数: {(mimic_score==2).sum()}")
print("\nTop10 候选股:")
print(candidates.head(10).to_string(index=False))

# ========== 5. 模拟回测 ==========
# 假设对 3 分股执行 首板买入+持有5日
n_3star = (mimic_score == 3).sum()
if n_3star > 0:
    future_rets = np.random.normal(0.02, 0.08, n_3star)  # 模拟 5 日收益
    win_rate = (future_rets > 0).mean()
    avg_ret = future_rets.mean()
    print(f"\n回测(持有5日): 胜率={win_rate:.0%}  平均收益={avg_ret:.2%}")
```

## 8. 手工代码实现

```python
"""
模仿因子手写实现
"""
import numpy as np

class MimicFactorEngine:
    """模仿因子选股引擎"""

    def __init__(self):
        self.median_mv = None
        self.turnover_p75 = None

    def fit(self, leader_mv, leader_turnover):
        """从历史龙头股学习特征分布"""
        self.median_mv = np.median(leader_mv)
        self.turnover_p75 = np.percentile(leader_turnover, 75)
        return self

    def score(self, mv, turnover, is_new_topic):
        """计算模仿因子得分"""
        score = 0
        if mv < self.median_mv: score += 1
        if is_new_topic: score += 1
        if turnover < self.turnover_p75: score += 1
        return score

    def screen(self, mv_array, turnover_array, new_topic_array, min_score=2):
        """批量筛选"""
        scores = np.array([
            self.score(mv, to, nt)
            for mv, to, nt in zip(mv_array, turnover_array, new_topic_array)
        ])
        return np.where(scores >= min_score)[0], scores


# 测试
if __name__ == '__main__':
    np.random.seed(42)
    engine = MimicFactorEngine()
    engine.fit(np.random.uniform(2e9, 15e9, 50),
               np.random.uniform(3, 15, 50))
    idx, scores = engine.screen(
        np.random.uniform(5e8, 100e9, 500),
        np.random.uniform(0.5, 25, 500),
        np.random.random(500) < 0.2
    )
    print(f"筛选出 {len(idx)} 只候选股（得分>=2）")
```

## 11. 常见问题与易错点

### 常见问题
**Q1: 训练不收敛？**
- 检查学习率是否合适
- 检查数据是否正确归一化
- 确认损失函数是否匹配任务

**Q2: 过拟合严重？**
- 增加数据量或使用数据增强
- 添加正则化（L1/L2/Dropout）
- 使用早停策略

**Q3: 超参数如何选？**
- 网格搜索或随机搜索
- 贝叶斯优化
- 参考论文推荐值

### 易错点
1. 数据泄露：预处理时使用测试集信息
2. 随机种子：忘记设置导致不可复现
3. 维度错误：输入shape与模型不匹配
4. 梯度问题：需要适当初始化和裁剪
5. 评估偏差：在训练集上评估
