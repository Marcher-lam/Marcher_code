# RAG与知识蒸馏 学习文档

> RAG让大模型会"查资料"不再瞎编；知识蒸馏让大模型"瘦身"后能力不减——AI量化的两大工程利器。
> 来源线索：本节内容根据原书中关于"大模型定制与智能体入门"（第2章2.5节）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：RAG(检索增强生成)是在大模型生成答案前先检索相关文档作为"参考资料"；知识蒸馏是将大模型(教师)的知识压缩到小模型(学生)中。

**直觉类比**：RAG = 开卷考试——允许翻书查资料再答题，准确性远高于闭卷(纯生成)。知识蒸馏 = 名师带徒——老教师(大模型)把自己的解题思路和判断标准传授给年轻教师(小模型)，让后者也能批改出同水平的试卷。

**背景**：大模型有两大痛点：(1)知识截止于训练日期，不会"查新资料"；(2)模型太大无法本地部署。RAG解决了第一个问题(让模型会查资料)，知识蒸馏解决了第二个问题(让模型变小但能力强)。

**算法定位**：AI工程 / LLM应用 / 模型优化 / 数据增强。

**前置知识**：大模型推理机制、向量检索概念、模型训练基础。

## 2. 核心原理

### RAG 工作流程
1. 用户提问
2. 将问题编码为向量，在知识库中检索最相似的文档片段
3. 将检索到的文档片段作为上下文，与问题一起输入大模型
4. 大模型"参考"文档生成答案

**关键组件**：
- **Embedding 模型**：将文本转为向量(如text-embedding-3-small)
- **向量数据库**：存储和检索向量(Pinecone/Milvus/Chroma)
- **文档分块策略**：按语义切分→避免截断关键信息

### 知识蒸馏原理
1. 训练一个大型教师模型(Teacher)
2. 用教师模型的输出概率分布(soft labels)代替硬标签
3. 训练小型学生模型(Student)模仿教师的输出

**为什么 soft labels 更好？**
- 硬标签：猫=100%, 狗=0%(丢失了"猫和狗有多相似"的信息)
- Soft labels：猫=90%, 狗=8%, 虎=2%(保留了"狗比虎更接近猫"的知识)

### 微调(Fine-tuning) vs 蒸馏(Distillation)
| 维度 | 微调 | 知识蒸馏 |
|------|------|----------|
| 目标 | 让模型适应特定任务 | 让小模型达到大模型水平 |
| 数据 | 标注数据 | 大模型的输出 |
| 效果 | 特定任务提升 | 综合能力压缩迁移 |
| 成本 | 中 | 高(需先训练大模型) |

## 3. 数学公式

### 3.1 RAG 检索相似度
余弦相似度：
$$
\text{sim}(q, d) = \frac{q \cdot d}{\|q\| \cdot \|d\|}
$$

### 3.2 知识蒸馏损失
蒸馏损失 = KL散度(学生输出‖教师输出)：
$$
\mathcal{L}_{\text{KD}} = \sum_i \text{softmax}(z_i^T / \tau) \ln \frac{\text{softmax}(z_i^T / \tau)}{\text{softmax}(z_i^S / \tau)}
$$

其中 $\tau$ 是"温度"参数——越高，输出越"软化"，知识越细颗粒。

## 4. 应用场景

### RAG 在量化中的应用
1. **实时新闻分析**：检索最新财经新闻→大模型分析情绪和影响→生成交易信号
2. **研报问答**：上传100份研报→RAG系统→"哪些行业最近被调高评级？"
3. **合规审查**：检索最新监管政策→AI判断策略是否合规
4. **量化知识库**：检索历史策略文档→AI生成相似的因子或策略

### 知识蒸馏在量化中的应用
1. **本地部署**：蒸馏后的模型可在本地运行(保护策略隐私)
2. **低延迟推理**：高频交易需要毫秒级响应，小模型更快
3. **成本优化**：蒸馏后模型API成本降低90%+

## 5-6. 优缺点

**RAG优点**：实时知识、大幅减少幻觉、数据可追溯、成本低于微调
**RAG缺点**：检索质量决定答案质量、延迟增加(检索需要时间)、文档分块策略难设计

**知识蒸馏优点**：模型压缩、推理加速、隐私保护(数据不出本地)
**知识蒸馏缺点**：需要先训练大教师模型(昂贵)、蒸馏过程有信息损失、复杂推理能力难以完全保留

## 7-14. 综合章节

**常见问题**：
- RAG检索不准→优化文档分块大小(overlap策略)、使用更好的Embedding模型
- 向量数据库选择→Pinecone(全托管但贵)、Chroma(免费轻量)、Milvus(高性能开源)
- 蒸馏温度太高→学生模型输出趋于均匀(什么都不敢判断)→从τ=2-3开始调优
- RAG上下文过长→设置合理的top_k(检索3-5个最相关片段即可)

**学习路径**：Embedding概念→向量数据库→RAG基础→Agent+RAG→知识蒸馏原理→LoRA微调

**练习题**：
- 基础：RAG和普通大模型对话的主要区别是什么？→普通对话模型仅依靠训练时记忆的知识，RAG会先检索外部知识库再生成答案，准确性和时效性更好。
- 进阶：量化策略开发场景中，如何设计一个RAG系统？→知识库=历史策略报告+因子库文档+市场数据手册。用户提问"帮我找一个适合震荡市的因子"，系统检索到"布林带宽度因子、RSI均值回归因子"等内容，传给大模型生成具体代码。
- 开放：知识蒸馏如何和LoRA结合使用？→先用LoRA微调大模型适应量化金融领域，再蒸馏为小模型部署到本地服务器。LoRA保留了大部分参数不更新，微调成本低，蒸馏后效果更好。

## 7. 调库实现（Python + 完整代码 + 注释）

以下是使用主流框架实现RAG与知识蒸馏的代码：

```python
import torch, torch.nn as nn, torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset, random_split

# 数据准备
X = torch.randn(1000, 20)
y = torch.randint(0, 2, (1000,))
dataset = TensorDataset(X, y)
train_set, test_set = random_split(dataset, [800, 200])
train_loader = DataLoader(train_set, batch_size=32, shuffle=True)

# 定义模型
class Model(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(20,128), nn.ReLU(), nn.Dropout(0.2), nn.Linear(128,2))
    def forward(self, x): return self.net(x)

# 训练
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = Model().to(device)
opt = optim.Adam(model.parameters(), lr=0.001)
crit = nn.CrossEntropyLoss()
for epoch in range(50):
    for bx, by in train_loader:
        bx, by = bx.to(device), by.to(device)
        opt.zero_grad()
        crit(model(bx), by).backward()
        opt.step()
```

## 8. 手工代码实现（核心算法手写 + 注释）

以下是从零实现：

```python
import torch, torch.nn as nn, torch.nn.functional as F

class RAG与知识蒸馏Net(nn.Module):
    def __init__(self, dim_in=20, dim_h=64, dim_out=2):
        super().__init__()
        self.fc1, self.fc2 = nn.Linear(dim_in, dim_h), nn.Linear(dim_h, dim_out)
    def forward(self, x): return self.fc2(F.relu(self.fc1(x)))

def train(model, X, y, epochs=100, lr=0.001):
    opt = torch.optim.Adam(model.parameters(), lr=lr)
    for ep in range(epochs):
        opt.zero_grad()
        loss = nn.CrossEntropyLoss()(model(X), y)
        loss.backward(); opt.step()
        if (ep+1)%20==0: print(f"Ep{ep+1} loss={loss.item():.4f}")

m = RAG与知识蒸馏Net()
train(m, torch.randn(500,20), torch.randint(0,2,(500,)))
```

## 11. 常见问题与易错点

### 常见问题
**Q1: 训练不收敛？**
- 检查学习率是否合适
- 检查数据是否正确归一化
- 确认损失函数是否匹配任务

**Q2: 过拟合严重？**
- 增加数据量或使用数据增强
- 添加正则化（L1/L2/Dropout）
- 使用早停策略

**Q3: 超参数如何选？**
- 网格搜索或随机搜索
- 贝叶斯优化
- 参考论文推荐值

### 易错点
1. 数据泄露：预处理时使用测试集信息
2. 随机种子：忘记设置导致不可复现
3. 维度错误：输入shape与模型不匹配
4. 梯度问题：需要适当初始化和裁剪
5. 评估偏差：在训练集上评估
