# 路由器 (Router) 学习文档

## 1. 算法基础认知

### 1.1 定义与背景

路由器（Router）是 Mixture of Experts（混合专家模型，MoE）架构中的核心组件，负责决定每个输入 token 应该由哪个（或哪些）专家网络处理。在 MoE 系统中，路由器扮演着"分诊台"的角色，类似于医院系统中的导诊护士，根据患者的症状（输入特征）将其分配给相应的专科医生（专家网络）。

路由器机制的概念最早在 1991 年由 Jordan 和 Jacobs 在论文"Hierarchical Mixture of Experts"中提出，用于实现自适应的专家选择。2017 年，Google 的 Shazeer 等人在"Outrageously Large Neural Networks"论文中正式提出了 Top-K Gating 机制，成为现代 MoE 系统中路由器设计的主流范式。

**核心问题**：在拥有 N 个专家的 MoE 系统中，如何高效地为每个输入选择最合适的专家？

### 1.2 应用场景

| 场景 | 说明 |
|------|------|
| 大语言模型路由 | GPT-4、Mixtral、DeepSeek-V3 等 MoE 大模型的核心组件 |
| 多任务学习 | 根据任务类型路由到不同专家处理 |
| 特征路由 | 根据输入特征的不同方面路由到不同专家 |
| 动态计算分配 | 算力紧张时动态调整路由策略 |

## 2. 核心原理

### 2.1 路由器类型

#### 2.1.1 Token-Dropping Router

每个 token 选择 top-k 个专家。如果选中的专家达到容量上限，多余的 token 会被丢弃。这种方法简单直接，但可能导致信息丢失。

#### 2.1.2 Expert Choice Router

Expert Choice Router 是一种"反向"路由机制：由专家来选择它们想要处理的 token，而非让 token 选择专家。每个专家维护一个容量，选出评分最高的 token 进行处理。

公式表示：

$$\text{score}_i(\mathbf{x}) = \mathbf{v}_i^T \mathbf{x} + b_i$$

其中 $\mathbf{v}_i$ 是专家 $i$ 的可学习评分向量。

每个专家选择评分最高的 $C$ 个 token（容量）：

$$\text{TopK}_i(\text{score}_i(\mathbf{x}), C)$$

#### 2.1.3 Hash Router

使用哈希函数将输入映射到专家索引，避免了可学习参数，但灵活性较低：

$$\text{expert}_i = \text{hash}(\mathbf{x}) \mod N$$

#### 2.1.4 Linear Router

最简单的线性门控，直接通过线性变换 + softmax：

$$\mathbf{g} = \text{softmax}(\mathbf{W}_g \mathbf{x} + \mathbf{b}_g)$$

### 2.2 Top-K Gating 核心公式

给定输入 $\mathbf{x} \in \mathbb{R}^d$，路由器计算专家选择分数：

$$\mathbf{s} = \mathbf{W}_r \mathbf{x} + \mathbf{b}_r$$

其中 $\mathbf{W}_r \in \mathbb{R}^{N \times d}$，$\mathbf{b}_r \in \mathbb{R}^N$。

温度参数控制分布的锐度：

$$p_i = \frac{\exp(s_i / T)}{\sum_j \exp(s_j / T)}$$

当 $T \to 0$ 时，$p$ 趋近于 one-hot 分布（确定性选择）；当 $T \to \infty$ 时，$p$ 趋近于均匀分布（随机选择）。

Top-K 选择：

$$\text{indices} = \text{TopK}(\mathbf{s}, k)$$

对应的权重（可选择归一化）：

$$w_i = \frac{\exp(s_i / T)}{\sum_{j \in \text{indices}} \exp(s_j / T)}$$

### 2.3 负载均衡

路由器需要将输入尽量均匀地分配到各个专家，防止某些专家过载而其他专家利用不足。

辅助 loss：

$$\mathcal{L}_{lb} = \alpha \cdot N \cdot \sum_{i=1}^{N} f_i \cdot p_i$$

其中 $f_i$ 是专家 $i$ 的使用频率（moving average），$p_i$ 是对应的门控概率。

## 3. PyTorch 实现

### 3.1 标准 Top-K Router 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Tuple, Optional


class TopKRouter(nn.Module):
    """
    Top-K 路由器实现
    
    Args:
        dim: 输入维度
        num_experts: 专家数量
        top_k: 激活的专家数量
        capacity_factor: 专家容量因子
        eval_capacity_factor: 推理时的容量因子
        noisy_gate: 是否使用噪声门控
    """
    
    def __init__(
        self,
        dim: int,
        num_experts: int = 8,
        top_k: int = 2,
        capacity_factor: float = 1.0,
        eval_capacity_factor: float = 1.0,
        noisy_gate: bool = True,
    ):
        super().__init__()
        self.dim = dim
        self.num_experts = num_experts
        self.top_k = top_k
        self.capacity_factor = capacity_factor
        self.eval_capacity_factor = eval_capacity_factor
        self.noisy_gate = noisy_gate
        
        # 门控网络
        self.gate = nn.Linear(dim, num_experts, bias=False)
        
        # 噪声标准差（可学习或固定）
        if noisy_gate:
            self.noise_std = nn.Parameter(torch.tensor(0.5))
        else:
            self.register_parameter('noise_std', None)
        
        # 路由统计
        self.register_buffer('expert_metrics', torch.zeros(num_experts, 3))
        
    def forward(
        self,
        x: torch.Tensor,
        training: bool = None,
    ) -> Tuple[torch.Tensor, torch.Tensor, dict]:
        """
        前向传播
        
        Args:
            x: 输入 tensor, shape [batch, seq_len, dim] 或 [num_tokens, dim]
            training: 是否训练模式
            
        Returns:
            weights: 专家权重
            indices: 专家索引
            metrics: 路由统计信息
        """
        if training is None:
            training = self.training
            
        batch_size, seq_len, dim = x.shape
        x_flat = x.view(-1, dim)  # [num_tokens, dim]
        num_tokens = x_flat.shape[0]
        
        # 计算门控分数
        logits = self.gate(x_flat)  # [num_tokens, num_experts]
        
        # 添加噪声（训练时）
        if training and self.noisy_gate and self.noise_std is not None:
            noise = torch.randn_like(logits) * F.softplus(self.noise_std)
            logits = logits + noise
        
        # 获取 top-k
        top_k_logits, top_k_indices = torch.topk(logits, self.top_k, dim=-1)
        
        # 归一化权重
        weights = F.softmax(top_k_logits, dim=-1)
        
        # 掩码：哪些位置被专家处理
        mask = torch.zeros_like(logits).scatter_(-1, top_k_indices, 1.0)
        
        # 更新统计
        if training:
            expert_mask = mask  # [num_tokens, num_experts]
            # 每个专家处理的 token 数量
            expert_counts = expert_mask.sum(dim=0)  # [num_experts]
            
            # 每个 token 的权重和
            weight_sum = (weights.sum(dim=-1) > 0).float()  # [num_tokens]
            
            # 更新移动平均
            with torch.no_grad():
                self.expert_metrics[:, 0] = (
                    0.99 * self.expert_metrics[:, 0] + 
                    0.01 * expert_counts
                )
                self.expert_metrics[:, 1] = (
                    0.99 * self.expert_metrics[:, 1] + 
                    0.01 * weight_sum
                )
        
        metrics = {
            'logits': logits,
            'indices': top_k_indices,
            'weights': weights,
            'mask': mask,
            'expert_usage': self.expert_metrics[:, 0],
        }
        
        return weights, top_k_indices, metrics
    
    def load_balancing_loss(self) -> torch.Tensor:
        """
        计算负载均衡 loss
        """
        if self.expert_metrics.sum() == 0:
            return torch.tensor(0.0, device=next(self.parameters()).device)
        
        # 归一化使用率
        usage = self.expert_metrics[:, 0] / (self.expert_metrics[:, 0].sum() + 1e-8)
        
        # 期望均匀分布
        target = torch.ones_like(usage) / self.num_experts
        
        # MSE loss
        loss = F.mse_loss(usage, target)
        
        return loss


class ExpertChoiceRouter(nn.Module):
    """
    Expert Choice Router - Expert 选择 Token
    
    这种路由器由专家选择它们想要处理的 token，
    而非让 token 选择专家
    """
    
    def __init__(
        self,
        dim: int,
        num_experts: int,
        capacity: int = 128,
    ):
        super().__init__()
        self.dim = dim
        self.num_experts = num_experts
        self.capacity = capacity
        
        # 专家评分网络（每个专家有自己的评分向量）
        self.scores = nn.ModuleList([
            nn.Linear(dim, 1) for _ in range(num_experts)
        ])
        
    def forward(self, x: torch.Tensor) -> Tuple[torch.Tensor, dict]:
        """
        Args:
            x: [batch, seq_len, dim]
        Returns:
            output: [batch, seq_len, dim]
            metrics: 统计信息
        """
        batch_size, seq_len, dim = x.shape
        x_flat = x.view(-1, dim)
        num_tokens = x_flat.shape[0]
        
        # 计算每个专家对每个 token 的评分
        all_scores = []
        for i in range(self.num_experts):
            score_i = self.scores[i](x_flat)  # [num_tokens, 1]
            all_scores.append(score_i)
        
        all_scores = torch.cat(all_scores, dim=-1)  # [num_tokens, num_experts]
        
        # 每个专家选择评分最高的 capacity 个 token
        output = torch.zeros_like(x_flat)
        tokens_per_expert = torch.zeros(num_tokens, dtype=torch.long, device=x.device)
        
        for i in range(self.num_experts):
            expert_scores = all_scores[:, i]
            
            # Top capacity 选择
            if num_tokens > self.capacity:
                _, top_indices = torch.topk(expert_scores, self.capacity)
            else:
                top_indices = torch.arange(num_tokens, device=x.device)
            
            # 处理选中的 token
            selected_x = x_flat[top_indices]
            expert_output = self.scores[i](selected_x).squeeze(-1)
            
            output[top_indices] += expert_output.unsqueeze(-1)
            tokens_per_expert[top_indices] = 1
        
        output = output.view(batch_size, seq_len, dim)
        
        metrics = {
            'scores': all_scores,
            'tokens_per_expert': tokens_per_expert,
        }
        
        return output, metrics


class HashRouter(nn.Module):
    """
    Hash Router - 使用哈希函数进行路由
    无需可学习参数，简单但灵活性有限
    """
    
    def __init__(
        self,
        num_experts: int,
        num_groups: int = 1,
    ):
        super().__init__()
        self.num_experts = num_experts
        self.num_groups = num_groups
        
        # 专家分组
        self.expert_groups = [
            list(range(num_experts)) for _ in range(num_groups)
        ]
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        Args:
            x: [batch, seq_len, dim]
        Returns:
            expert_indices: [batch, seq_len]
        """
        batch_size, seq_len, dim = x.shape
        
        # 基于输入模长的哈希
        norm = torch.norm(x, dim=-1)  # [batch, seq_len]
        
        # 映射到专家索引
        expert_indices = (norm * 1000).long() % self.num_experts
        
        return expert_indices
```

### 3.2 路由策略实现

```python
class AdaptiveRouter(nn.Module):
    """
    Adaptive Router - 根据输入动态调整路由策略
    
    可以根据:
    - 输入复杂度
    - 算力可用性
    - 任务类型
    自动调整 top-k 和专家选择
    """
    
    def __init__(
        self,
        dim: int,
        num_experts: int,
        min_k: int = 1,
        max_k: int = 4,
    ):
        super().__init__()
        self.dim = dim
        self.num_experts = num_experts
        self.min_k = min_k
        self.max_k = max_k
        
        # 复杂度评估网络
        self.complexity_net = nn.Sequential(
            nn.Linear(dim, dim // 2),
            nn.ReLU(),
            nn.Linear(dim // 2, 1),
            nn.Sigmoid(),
        )
        
        # 门控网络
        self.gate = nn.Linear(dim, num_experts)
        
    def forward(self, x: torch.Tensor) -> Tuple[torch.Tensor, int]:
        """
        自动决定使用多少个专家
        
        Returns:
            output: 专家输出
            k: 实际使用的专家数量
        """
        batch_size, seq_len, dim = x.shape
        x_flat = x.view(-1, dim)
        
        # 评估输入复杂度
        complexity = self.complexity_net(x_flat.mean(dim=0, keepdim=True))
        
        # 动态调整 k
        k = int(self.min_k + complexity.item() * (self.max_k - self.min_k))
        k = max(self.min_k, min(self.max_k, k))
        
        # 标准 Top-K 路由
        logits = self.gate(x_flat)
        top_k_logits, top_k_indices = torch.topk(logits, k)
        weights = F.softmax(top_k_logits, dim=-1)
        
        return weights, top_k_indices, k
```

## 4. 代码示例

### 4.1 基础使用

```python
import torch

# 创建路由器
router = TopKRouter(
    dim=512,
    num_experts=8,
    top_k=2,
)

# 前向传播
x = torch.randn(2, 32, 512)  # [batch, seq_len, dim]
weights, indices, metrics = router(x)

print(f"Weights shape: {weights.shape}")
print(f"Indices shape: {indices.shape}")
print(f"Expert usage: {metrics['expert_usage']}")
```

### 4.2 负载均衡训练

```python
# 训练循环
optimizer = torch.optim.AdamW(router.parameters(), lr=1e-4)

for epoch in range(10):
    x = torch.randn(4, 64, 512)
    
    # 前向
    weights, indices, metrics = router(x)
    
    # 主 loss
    main_loss = weights.mean()
    
    # 负载均衡 loss
    load_balance_loss = router.load_balancing_loss()
    
    # 总 loss
    total_loss = main_loss + 0.01 * load_balance_loss
    
    # 反向传播
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
    
    print(f"Epoch {epoch}: lb_loss={load_balance_loss.item():.4f}")
```

```python
def compare_routers():
    """对比不同的路由策略"""
    dim = 256
    num_experts = 8
    x = torch.randn(4, 32, dim)
    
    # Top-K Router
    topk_router = TopKRouter(dim, num_experts, top_k=2)
    _, _, metrics_topk = topk_router(x)
    
    # Expert Choice Router
    ec_router = ExpertChoiceRouter(dim, num_experts, capacity=64)
    _, metrics_ec = ec_router(x)
    
    print("Top-K Router expert usage:")
    print(metrics_topk['expert_usage'])
    print("\nExpert Choice Router tokens per expert:")
    print(metrics_ec['tokens_per_expert'])
```

## 3. 数学公式与推导

路由器的数学基础：

### 前向传播
$$h = \sigma(W_1 x + b_1), \quad \hat{y} = W_2 h + b_2$$

### 损失函数（交叉熵）
$$L = -\frac{1}{N} \sum_{i=1}^{N} \sum_{c=1}^{C} y_{ic} \log \hat{y}_{ic}$$

### 反向传播（链式法则）
$$\frac{\partial L}{\partial W} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial W}$$
