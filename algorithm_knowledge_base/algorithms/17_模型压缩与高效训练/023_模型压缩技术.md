# 模型压缩技术 学习文档

> 通过量化、剪枝、蒸馏等技术减小模型体积，降低计算和存储开销。

## 1. 算法基础认知

模型压缩技术是通过各种技术手段减小深度学习模型的体积和计算复杂度的技术集合，目的是使得大型模型能够在资源受限的设备上运行。

### 历史背景

- **2015年**：知识蒸馏提出（Hinton等）
- **2017年**：量化网络兴起
- **2020年以后**：大模型时代，压缩技术成为部署关键

### 直觉类比

模型压缩就像"减肥"：通过各种方法（量化似"压缩脂肪"、剪枝似"割舍冗余"、蒸馏似"名师指导"）让大块头变精干。

### 前置知识

- 深度学习基础
- 神经网络结构
- PyTorch框架

## 2. 核心原理

### 参数重要性分级压缩

核心思想：不同参数对模型输出的重要性不同，通过分析权重对输出的敏感度：

- **关键参数**：高精度保留（如高层语义层）
- **次要参数**：高倍率压缩（如底层特征提取）

### 多模态联合压缩

将文本、图像模型的压缩过程置于统一优化空间，通过跨模态注意力共享实现联合压缩。

### 工作流程

```
1. 重要性分析 → 2. 分级压缩 → 3. 联合优化 → 4. 验证部署
```

## 3. 数学公式与推导

### 参数敏感性

$$S_{ij} = \left|\frac{\partial L}{\partial w_{ij}} \cdot w_{ij}\right|$$

参数$w_{ij}$的敏感度，等于损失函数对参数的梯度乘以参数值。

### 量化误差

均匀量化：
$$w_q = \text{round}\left(\frac{w - w_{min}}{w_{max} - w_{min}} \cdot (2^b - 1)\right)$$

其中$b$是量化位数。

### 压缩率计算

$$\text{Compression Ratio} = \frac{\text{原始参数数量}}{\text{压缩后参数数量}}$$

## 4. 训练过程讲解

### 压缩流程

1. **训练原始模型**：在高性能设备上训练大模型
2. **分析重要性**：计算参数敏感性
3. **执行压缩**：量化/剪枝/蒸馏
4. **微调校正**：小数据集微调恢复精度

### 超参数表

| 参数 | 作用 | 推荐范围 |
|------|------|---------|
| 量化位数 | 压缩程度 | 4-16bit |

| 蒸馏温度 | 软化分布 | 2-10 |
| 学习率 | 微调步长 | 1e-5-1e-3 |

## 6. 优缺点分析

### 优点

1. **体积减小**：模型可部署到移动端
2. **速度提升**：推理速度显著加快
3. **能耗降低**：移动设备续航提升
4. **部署灵活**：适应不同硬件

### 缺点

1. **精度损失**：可能有精度下降
2. **实现复杂**：多种技术需要配合
3. **性能波动**：不同任务效果不同

## 7. 调库实现

```python
import torch
import torch.nn as nn

class ModelCompressor:
    """模型压缩工具"""
    
    def __init__(self, model):
        self.model = model
        self.original_size = self._get_model_size(model)
        
    def _get_model_size(self, model):
        """计算模型参数量"""
        return sum(p.numel() for p in model.parameters())
        
    def quantize_dynamic(self):
        """动态量化"""
        quantized_model = torch.quantization.quantize_dynamic(
            self.model,
            {nn.Linear, nn.LSTM},
            dtype=torch.qint8
        )
        return quantized_model
        
    def prune_by_threshold(self, threshold=0.01):
        """按照阈值剪枝"""
        for name, param in self.model.named_parameters():
            if 'weight' in name:
                mask = torch.abs(param.data) > threshold
                param.data = param.data * mask.float()
        return self.model
        
    def get_compression_stats(self):
        """获取压缩统计"""
        current_size = self._get_model_size(self.model)
        ratio = self.original_size / current_size if current_size > 0 else 0
        return {
            'original': self.original_size,
            'current': current_size,
            'ratio': ratio
        }

# 使用示例
print("=== 模型压缩工具 ===")

# 创建示例模型
model = nn.Sequential(
    nn.Linear(512, 256),
    nn.ReLU(),
    nn.Linear(256, 10)
)

compressor = ModelCompressor(model)
stats = compressor.get_compression_stats()
print(f"原始参数量: {stats['original']:,}")
```

```python
import numpy as np

class SimpleQuantizer:
    """简单量化器（纯Python实现）"""
    
    def __init__(self, num_bits=8):
        self.num_bits = num_bits
        self.num_levels = 2 ** num_bits
        
    def quantize(self, weights):
        """
        参数量化
        
        Args:
            weights: 原始参数数组
        Returns:
            量化后的参数
        """
        w_min = weights.min()
        w_max = weights.max()
        
        # 归一化到 [0, 1]
        normalized = (weights - w_min) / (w_max - w_min + 1e-8)
        
        # 量化到整数
        quantized = np.round(normalized * (self.num_levels - 1)).astype(np.int32)
        
        return quantized, (w_min, w_max)
        
    def dequantize(self, quantized, bounds):
        """
        反量化
        
        Args:
            quantized: 量化值
            bounds: (w_min, w_max)
        Returns:
            恢复的浮点值
        """
        w_min, w_max = bounds
        
        # 反归一化
        normalized = quantized / (self.num_levels - 1)
        
        # 恢复到原始范围
        dequantized = normalized * (w_max - w_min) + w_min
        
        return dequantized

class SimplePruner:
    """简单剪枝器"""
    
    def __init__(self, threshold=0.01):
        self.threshold = threshold
        
    def prune(self, weights):
        """
        权重剪枝
        
        Args:
            weights: 原始权重
        Returns:
            剪枝后的权重
        """
        mask = np.abs(weights) > self.threshold
        pruned = weights * mask.astype(np.float32)
        
        return pruned, mask

# 测试
if __name__ == "__main__":
    # 创建示例权重
    weights = np.random.randn(100, 50) * 0.5
    print(f"原始权重形状: {weights.shape}")
    print(f"原始权重范围: [{weights.min():.3f}, {weights.max():.3f}]")
    
    # 量化测试
    print("\n=== 量化测试 ===")
    quantizer = SimpleQuantizer(num_bits=4)  # 4位量化
    quantized, bounds = quantizer.quantize(weights)
    print(f"量化后值范围: [{quantized.min()}, {quantized.max()}]")
    print(f"原始范围: {bounds}")
    
    # 恢复
    restored = quantizer.dequantize(quantized, bounds)
    error = np.abs(weights - restored).mean()
    print(f"恢复后平均误差: {error:.6f}")
    
    # 剪枝测试
    print("\n=== 剪枝测试 ===")
    pruner = SimplePruner(threshold=0.1)
    pruned, mask = pruner.prune(weights)
    alive_ratio = mask.sum() / mask.size
    print(f"存活参数比例: {alive_ratio:.1%}")
    print(f"剪枝后稀疏度: {1-alive_ratio:.1%}")
```

## 10. 模型评估

### 评估指标

1. **压缩率**：原始/压缩后参数比
2. **精度保持**：压缩前后精度差异
3. **推理加速**：速度提升倍数
4. **内存占用**：实际显存使用

### 计算代码

```python
import numpy as np

def evaluate_compression(original_model, compressed_model, test_data, test_labels):
    """评估压缩效果"""
    original_params = sum(p.numel() for p in original_model.parameters())
    compressed_params = sum(p.numel() for p in compressed_model.parameters())
    
    compression_ratio = original_params / compressed_params
    
    # 精度评估
    from sklearn.metrics import accuracy_score
    original_pred = original_model(test_data)
    compressed_pred = compressed_model(test_data)
    
    accuracy_保留了 = accuracy_score(test_labels, original_pred)
    accuracy_压缩后 = accuracy_score(test_labels, compressed_pred)
    accuracy_loss = accuracy_保留了 - accuracy_压缩后
    
    print(f"压缩评估:")
    print(f"  - 压缩率: {compression_ratio:.1f}x")
    print(f"  - 原精度: {accuracy_保留了:.2%}")
    print(f"  - 现精度: {accuracy_压缩后:.2%}")
    print(f"  - 精度损失: {accuracy_loss:.2%}")
    
    return {
        'compression_ratio': compression_ratio,
        'accuracy': accuracy_压缩后,
        'accuracy_loss': accuracy_loss
    }
```

## 11. 常见问题与易错点

### 数据层面

1. **量化饱和**：��些层量化后信息丢失严重
   - 解决方案：排除敏感层，使用混合精度

2. **分布变化**：训练和推理数据分布不同
   - 解决方案：使用校准数据估计范围

### 模型层面

1. **剪枝破坏结构**：错误剪枝导致模型无法运行
   - 解决方案：逐步剪枝并验证

2. **蒸馏不收敛**：学生模型学习困难
   - 解决方案：使用中间层监督

### 调参层面

1. **过度压缩**：压缩率过高导致精度崩溃
   - 解决方案：设置精度下限

2. **微调不当**：导致过拟合
   - 解决方案：使用较小学习率
