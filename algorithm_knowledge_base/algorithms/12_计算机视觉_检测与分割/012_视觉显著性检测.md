# 视觉显著性检测（Visual Saliency Detection）学习文档

> 检测图像中最吸引人注意的区域，模拟人类视觉系统的注意力选择机制。

## 1. 算法基础认知

### 一句话定义

视觉显著性检测是预测人类视觉注意力的任务，输出图像中每个位置被注意的概率分布。

### 直觉类比

在繁忙的街道上，你首先注意的是红灯、看板上的美女——这些"突出"的地方就是显著区域。显著性检测就是让计算机预测这些区域。

### 历史背景

- **1985年**：Koch和Ullman提出生物启发模型
- **1998年**：Itti等人提出经典ITTI模型
- **2013年**：深度学习开始应用于显著检测
- **2017年**：深度学习方法成为主流

### 算法定位

视觉显著性检测是**计算机视觉任务**，属于监督学习/无监督学习。

---

## 2. 核心原理

### 经典ITTI模型

1. 构建图像多尺度高斯金字塔
2. 提取特征：颜色、强度、方向
3. 计算特征图差异
4. 多尺度特征融合
5. 生成显著图

### 深度学习方法

1. 编码器提取特征（CNN/ViT）
2. 多尺度特征融合
3. 解码头生成显著图

---

## 3. 数学公式

### 中心-周围差（Center-Surround）

$$D(c, s) = |I_c - I_s|$$

其中$c$为中心尺度，$s$为周围尺度。

### 显著度计算

$$S(x, y) = \sum_{f} D_f(x, y)$$

## 4. 调库实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class DeepSaliencyModel(nn.Module):
    """基于深度学习的显著目标检测模型"""
    def __init__(self):
        super(DeepSaliencyModel, self).__init__()
        
        # 编码器 - 使用ResNet结构
        self.conv1 = nn.Sequential(
            nn.Conv2d(3, 64, 3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(64, 64, 3, padding=1),
            nn.ReLU(inplace=True)
        )
        self.pool1 = nn.MaxPool2d(2)
        
        self.conv2 = nn.Sequential(
            nn.Conv2d(64, 128, 3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(128, 128, 3, padding=1),
            nn.ReLU(inplace=True)
        )
        self.pool2 = nn.MaxPool2d(2)
        
        # 解码头
        self.up1 = nn.ConvTranspose2d(128, 64, 2, stride=2)
        self.upconv1 = nn.Sequential(
            nn.Conv2d(128, 64, 3, padding=1),
            nn.ReLU(inplace=True)
        )
        
        self.up2 = nn.ConvTranspose2d(64, 32, 2, stride=2)
        self.upconv2 = nn.Sequential(
            nn.Conv2d(64, 32, 3, padding=1),
            nn.ReLU(inplace=True)
        )
        
        self.output = nn.Conv2d(32, 1, 1)
        
    def forward(self, x):
        # 编码
        c1 = self.conv1(x)
        p1 = self.pool1(c1)
        
        c2 = self.conv2(p1)
        
        # 解码
        u1 = self.up1(c2)
        cat1 = torch.cat([u1, c1], dim=1)
        d1 = self.upconv1(cat1)
        
        u2 = self.up2(d1)
        cat2 = torch.cat([u2, x], dim=1)
        d2 = self.upconv2(cat2)
        
        out = torch.sigmoid(self.output(d2))
        return out

# 使用预训练模型
def use_pretrained_saliency():
```

```python
import numpy as np
import cv2

class IttiSaliencyModel:
    """经典ITTI显著性模型"""
    
    def __init__(self):
        self.scales = [2, 3, 4]
        
    def gaussian_pyramid(self, img, num_levels):
        """构建高斯金字塔"""
        pyramid = [img]
        for i in range(1, num_levels):
            img = cv2.pyrDown(pyramid[-1])
            pyramid.append(img)
        return pyramid
    
    def compute_center_surround(self, center_pyr, surround_pyr):
        """计算中心-周围差"""
        difference = []
        
        for c, s in zip(center_pyr, surround_pyr):
            # 调整大小匹配
            s_resized = cv2.resize(s, (c.shape[1], c.shape[0]))
            
            # 计算差值
            if len(c.shape) == 3:
                diff = np.abs(c.astype(float) - s_resized.astype(float)).mean(axis=2)
            else:
                diff = np.abs(c.astype(float) - s_resized.astype(float))
            
            # 归一化
            diff = (diff - diff.min()) / (diff.max() - diff.min() + 1e-8)
            difference.append(diff)
        
        return difference
    
    def compute_saliency(self, img):
        """计算显著图"""
        # 转灰度图
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
        
        # 构建高斯金字塔
        gray_pyr = self.gaussian_pyramid(gray, 5)
        
        # 构建颜色金字塔
        if len(img.shape) == 3:
            hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
            h_pyr = self.gaussian_pyramid(hsv[:,:,0], 5)
            s_pyr = self.gaussian_pyramid(hsv[:,:,1], 5)
        else:
            h_pyr = gray_pyr
            s_pyr = gray_pyr
        
        # 计算特征
        # 这里简化的特征计算
        
        # 返回显著图
        saliency = gray_pyr[0].astype(float) / 255.0
        
        return saliency
```

## 6. 评估指标

```python
import numpy as np

def evaluate_saliency(pred, gt):
    """评估显著图质量"""
    from sklearn.metrics import roc_auc_score
    
    # MAE - 平均绝对误差
    mae = np.mean(np.abs(pred - gt))
    
    # E-measure
    # 这里简化
    
    # F-measure
    threshold = np.mean(pred)
    pred_binary = (pred > threshold).astype(float)
    intersection = np.sum(pred_binary * gt)
    precision = intersection / (np.sum(pred_binary) + 1e-8)
    recall = intersection / (np.sum(gt) + 1e-8)
    f_measure = 2 * precision * recall / (precision + recall + 1e-8)
    
    return {'MAE': mae, 'F-measure': f_measure}
```

## 11. 常见问题与易错点

### 常见问题
**Q1: 训练不收敛？**
- 检查学习率是否合适
- 检查数据是否正确归一化
- 确认损失函数是否匹配任务

**Q2: 过拟合严重？**
- 增加数据量或使用数据增强
- 添加正则化（L1/L2/Dropout）
- 使用早停策略

**Q3: 超参数如何选？**
- 网格搜索或随机搜索
- 贝叶斯优化
- 参考论文推荐值

### 易错点
1. 数据泄露：预处理时使用测试集信息
2. 随机种子：忘记设置导致不可复现
3. 维度错误：输入shape与模型不匹配
4. 梯度问题：需要适当初始化和裁剪
5. 评估偏差：在训练集上评估
