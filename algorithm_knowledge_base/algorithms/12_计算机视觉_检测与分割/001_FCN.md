# FCN（全卷积神经网络）学习文档

> 语义分割的先驱网络，将传统卷积网络的全连接层替换为卷积层，实现像素级图像分割

---

## 1. 算法基础认知

**一句话定义**：FCN是一种用于语义分割的全卷积神经网络，通过将传统CNN的全连接层替换为1x1卷积层，实现输入图像到分割掩码的端到端映射。

**直觉类比**：FCN就像一台"图像打印机"——传统CNN把图像压缩成一个固定的向量（像把整幅画打包成一个信封），而FCN保留了空间信息（像把画分成网格，每个格子单独处理），最终打印出与原图尺寸相同的分割地图。

**历史背景**：2015年，Long等人在CVPR上发表FCN论文，首次提出将CNN的全连接层转换为卷积层的方法，开创了深度学习语义分割的先河。此后 U-Net、DeepLab 等方法都受到FCN的启发。

**算法定位**：
- 类型：监督学习 → 图像分割 → 语义分割
- 输出：与输入尺寸相同的分割掩码
- 模型类型：全卷积神经网络

**前置知识**：
- [必备]：CNN基础（卷积、池化）
- [必备]：图像分割概念
- [扩展]：UpNet、DeepLab

---

## 2. 核心原理

### 2.1 核心思想

FCN的核心思想是**用卷积层替代传统CNN的全连接层，保持空间信息**。这样网络可以接受任意尺寸的输入，并输出对应尺寸的分割结果。

核心思想可以概括为：**将分类网络的"图像→向量"转变为"图像→图像"的像素级映射**。

### 2.2 工作流程

1. **特征提取**：使用VGG等backbone提取特征
2. **卷积分类**：将全连接层转为1x1卷积
3. **上采样**：使用转置卷积或双线性插值恢复分辨率
4. **跳跃连接**：融合不同层次的特征（FCN-8s）

### 2.3 关键概念解释

- **全卷积（Fully Convolutional）**：整个网络只有卷积层，没有全连接层

- **跳跃连接（Skip Connection）**：融合不同层的特征，提升边界精度

- **转置卷积（Transposed Conv）**：上采样的可学习替代方案

- **感受野**：输出像素对应的输入区域

### 2.4 几何/直观解释

在特征空间中，FCN通过一步步卷积提取层级特征，最后通过上采样恢复到原始分辨率。每个层次有不同的语义信息：浅层保留边缘，深层包含类别语义。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 | 维度 |
|------|------|------|
| $X$ | 输入图像 | $H \times W \times 3$ |
| $F$ | 特征图 | $H' \times W' \times C'$ |
| $Y$ | 分割掩码 | $H \times W \times C$ |
| $W$ | 卷积核 | $k \times k$ |

### 3.2 问题形式化

给定输入图像 $X$，FCN学习映射 $f: X \to Y$：

$$Y = f(X; \theta)$$

其中 $Y_{(i,j,c)} = P(label=c | pixel_{i,j})$

### 3.3 目标函数

**像素级交叉熵**：
$$L = -\sum_{i,j,c} Y_{ij}^{(true)} \log(\hat{Y}_{ij,c})$$

### 3.4 网络结构

**FCN-8s**：
```
输入图像 (224x224)
    ↓
Conv1-7 (VGG backbone)
    ↓
FC6 (1x1 conv, 4096)
    ↓
FC7 (1x1 conv, 4096)
    ↓
Score Fr (1x1 conv, num_classes)
    ↓
pool4 → 2x up → + score_fr
    ↓
pool3 → 4x up → + 融合结果
    ↓
32x up → 输出分割
```

## 6. 优缺点分析

### 6.1 优点

1. **端到端**：输入到输出直接学习
2. **任意尺寸输入**：不受固定输入限制
3. **经典架构**：后续方法的基础

### 6.2 缺点

1. **边界模糊**：分辨率恢复导致边界不精确
2. **感受野限制**：大物体分割可能有问题
3. **特征融合不足**：仅用跳跃连接

```python
"""
FCN 语义分割实现
"""

import torch
import torch.nn as nn
import torch.nn.functional as F


class FCN8s(nn.Module):
    """FCN-8s分割网络"""
    
    def __init__(self, num_classes=21, pretrained=False):
        super().__init__()
        
        # VGG backbone (简化的)
        self.conv1 = nn.Sequential(
            nn.Conv2d(3, 64, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(64, 64, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )
        
        self.conv2 = nn.Sequential(
            nn.Conv2d(64, 128, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(128, 128, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )
        
        self.conv3 = nn.Sequential(
            nn.Conv2d(128, 256, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(256, 256, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(256, 256, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )
        
        self.conv4 = nn.Sequential(
            nn.Conv2d(256, 512, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(512, 512, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(512, 512, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )
        
        self.conv5 = nn.Sequential(
            nn.Conv2d(512, 512, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(512, 512, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(512, 512, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )
        
        # 分类层
        self.fc6 = nn.Conv2d(512, 4096, 7)
        self.fc7 = nn.Conv2d(4096, 4096, 1)
        self.score = nn.Conv2d(4096, num_classes, 1)
        
        # pool3/4 特征
        self.score_pool3 = nn.Conv2d(256, num_classes, 1)
        self.score_pool4 = nn.Conv2d(512, num_classes, 1)
    
    def forward(self, x):
        # VGG backbone
        x1 = self.conv1(x)
        x2 = self.conv2(x1)
        x3 = self.conv3(x2)
        x4 = self.conv4(x3)
        x5 = self.conv5(x4)
        
        # 分类
        fc6 = F.relu(self.fc6(x5))
        fc7 = F.relu(self.fc7(fc6))
        score = self.score(fc7)
        
        # 上采样
        up32 = F.interpolate(score, scale_factor=32, mode='bilinear', align_corners=False)
        
        # 跳跃连接
        pool4 = self.score_pool4(x4)
        up4 = F.interpolate(pool4, scale_factor=4, mode='bilinear', align_corners=False)
        
        pool3 = self.score_pool3(x3)
        up3 = F.interpolate(pool3, scale_factor=8, mode='bilinear', align_corners=False)
        
        # 融合
        out = up32 + up4 + up3
        
        return F.interpolate(out, scale_factor=8, mode='bilinear', align_corners=False)


# 训练示例
def train_fcn():
    model = FCN8s(num_classes=21)
```

```python
"""
简化版FCN
"""

class SimpleFCN(nn.Module):
    def __init__(self, num_classes=21):
        super().__init__()
        
        # 编码器
        self.encoder = nn.Sequential(
            nn.Conv2d(3, 64, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            
            nn.Conv2d(64, 128, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            
            nn.Conv2d(128, 256, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        
        # 解码器
        self.decoder = nn.Sequential(
            nn.ConvTranspose2d(256, 128, 4, stride=2, padding=1),
            nn.ReLU(),
            
            nn.ConvTranspose2d(128, 64, 4, stride=2, padding=1),
            nn.ReLU(),
            
            nn.Conv2d(64, num_classes, 1)
        )
    
    def forward(self, x):
        x = self.encoder(x)
        x = self.decoder(x)
        return x
```

```python
def compute_miou(pred, label, num_classes):
    ious = []
    for c in range(num_classes):
        pred_c = pred == c
        label_c = label == c
        intersection = (pred_c & label_c).sum()
        union = pred_c.sum() + label_c.sum() - intersection
        if union > 0:
            ious.append(intersection / union)
    return sum(ious) / len(ious)
```

## 8. 手工代码实现（核心算法手写 + 注释）

以下是从零实现：

```python
import torch, torch.nn as nn, torch.nn.functional as F

class FCNNet(nn.Module):
    def __init__(self, dim_in=20, dim_h=64, dim_out=2):
        super().__init__()
        self.fc1, self.fc2 = nn.Linear(dim_in, dim_h), nn.Linear(dim_h, dim_out)
    def forward(self, x): return self.fc2(F.relu(self.fc1(x)))

def train(model, X, y, epochs=100, lr=0.001):
    opt = torch.optim.Adam(model.parameters(), lr=lr)
    for ep in range(epochs):
        opt.zero_grad()
        loss = nn.CrossEntropyLoss()(model(X), y)
        loss.backward(); opt.step()
        if (ep+1)%20==0: print(f"Ep{ep+1} loss={loss.item():.4f}")

m = FCNNet()
train(m, torch.randn(500,20), torch.randint(0,2,(500,)))
```
