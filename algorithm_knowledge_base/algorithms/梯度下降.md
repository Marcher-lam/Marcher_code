# 梯度下降学习文档

## 1. 算法基础认知

梯度下降（Gradient Descent）是机器学习和深度学习中最重要的优化算法之一。它的核心思想非常简单直观：**沿着函数梯度的相反方向迭代更新参数，逐步逼近函数的最小值点**。想象一下你站在一座山峰的某处，想要最快到达山谷底部，你只需要每次都沿着当前位置最陡的下坡方向走一步，这就是梯度下降的基本思想。

梯度下降算法由法国数学家Augustin-Louis Cauchy在1847年首次提出，至今已有近180年的历史。在机器学习中，我们通常需要最小化一个损失函数（Loss Function），这个损失函数衡量模型预测值与真实值之间的差异。通过梯度下降，我们可以找到使损失函数最小化的模型参数，从而获得最优的预测模型。

梯度下降算法之所以重要，是因为它在理论上保证了：如果学习率（步长）选择适当，每次迭代都会使目标函数的值下降（或至少不上升）。这种保证使得梯度下降成为处理大规模优化问题的首选方法。在深度学习中，神经网络的训练本质上就是一个高度非凸的优化问题，梯度下降及其变体是训练神经网络的基础工具。

理解梯度下降对于理解机器学习和深度学习至关重要。无论是传统的线性回归、逻辑回归，还是现代的大语言模型训练，都离不开梯度下降或其变体。掌握梯度下降的原理、公式推导和代码实现，是成为一名合格的机器学习工程师的必要前提。

## 2. 核心原理

梯度下降的核心原理可以从几何和代数两个角度来理解。从几何角度来说，梯度指向函数增长最快的方向，因此梯度的相反方向就是函数下降最快的方向。从代数角度来说，我们可以使用泰勒展开来严格证明梯度下降的收敛性。

设我们有目标函数 $f(\theta)$，其中 $\theta$ 是我们需要优化的参数向量。梯度下降的更新公式为：

$$\theta_{t+1} = \theta_t - \eta \cdot \nabla f(\theta_t)$$

其中 $\eta > 0$ 是学习率（learning rate），$\nabla f(\theta_t)$ 是函数在 $\theta_t$ 处的梯度。这个公式的直观解释是：我们从当前位置 $\theta_t$ 出发，沿着梯度的相反方向移动一个步长 $\eta$，得到新的位置 $\theta_{t+1}$。

为什么要沿着梯度的相反方向？因为梯度 $\nabla f(\theta)$ 指向函数增长最快的方向。如果我们想要最小化函数，我们应该向梯度的相反方向移动。类比来说，如果你在登山时想要最快到达山谷，你應該沿着最陡的下坡方向走，而不是向上走或者平着走。

学习率 $\eta$ 是一个非常重要的超参数。如果学习率太小，收敛速度会很慢；如果学习率太大，可能导致震荡甚至发散。合适的学习率需要通过实践和调参来确定。在后面的章节中，我们会详细介绍学习率的选择策略和自适应方法。

## 3. 数学公式与推导

### 3.1 梯度下降的严格推导

我们使用一阶泰勒展开来推导梯度下降算法。假设目标函数 $f(\theta)$ 在点 $\theta_t$ 附近足够平滑，我们可以将其展开为：

$$f(\theta) \approx f(\theta_t) + \nabla f(\theta_t)^T (\theta - \theta_t)$$

我们希望在一次迭代中最小化目标函数的下降量，即最小化 $f(\theta) - f(\theta_t)$。设 $\Delta \theta = \theta - \theta_t$，则：

$$f(\theta) - f(\theta_t) \approx \nabla f(\theta_t)^T \Delta \theta$$

为了使这个表达式最小化（且为负值），我们需要在梯度的相反方向上选择 $\Delta \theta$。根据柯西-施瓦��不等式：

$$\nabla f(\theta_t)^T \Delta \theta \geq \|\nabla f(\theta_t)\| \cdot \|\Delta \theta\|$$

当 $\Delta \theta$ 与 $\nabla f(\theta_t)$ 方向相反（即 $\Delta \theta = -\eta \nabla f(\theta_t)$）时，上式取等号，此时函数值下降最快。这就推导出了梯度下降的更新公式。

### 3.2 批量梯度下降（Batch Gradient Descent）

批量梯度下降使用整个训练数据集来计算梯度。每次迭代都需要计算所有样本的梯度，然后更新参数。其更新公式为：

$$\theta_{t+1} = \theta_t - \eta \cdot \frac{1}{N} \sum_{i=1}^{N} \nabla L(x_i, y_i, \theta_t)$$

其中 $N$ 是训练样本数量，$\nabla L(x_i, y_i, \theta_t)$ 是第 $i$ 个样本的损失函数梯度。

批量梯度下降的优点是：收敛路径平滑，能稳定地到达全局最优点（对于凸函数）或局部最优点（对于非凸函数）。缺点是：每次迭代需要计算所有样本的梯度，当数据集很大时，计算开销巨大。

### 3.3 随机梯度下降（Stochastic Gradient Descent, SGD）

随机梯度下降每次只使用一个样本来计算梯度和更新参数。每次迭代随机选择一个样本 $(x_i, y_i)$，更新公式为：

$$\theta_{t+1} = \theta_t - \eta \cdot \nabla L(x_i, y_i, \theta_t)$$

随机梯度下降的优点是：计算速度快，可以处理大规模数据集。缺点是：收敛路径会有噪声，可能在最优解附近来回震荡。

### 3.4 小批量梯度下降（Mini-batch Gradient Descent）

小批量梯度下降是批量梯度下降和随机梯度下降的折中。每次使用一小批样本（通常32-256个）来计算梯度：

$$\theta_{t+1} = \theta_t - \eta \cdot \frac{1}{B} \sum_{i \in \mathcal{B}_t} \nabla L(x_i, y_i, \theta_t)$$

其中 $B$ 是批量大小（batch size），$\mathcal{B}_t$ 是第 $t$ 次迭代的批次。

小批量梯度下降综合了批量梯度下降的稳定性和随机梯度下降的速度，是深度学习中最常用的优化方法。

### 3.5 收敛性分析

对于凸函数，假设学习率满足 $\sum_{t=0}^{\infty} \eta_t = \infty$ 和 $\sum_{t=0}^{\infty} \eta_t^2 < \infty$，则梯度下降算法以概率1收敛到全局最优解。对于非凸函数（如深度神经网络），我们只能保证收敛到 stationary point（梯度为零的点），但不能保证达到全局最优。

梯度下降的收敛速度在凸函数情况下可以达到 $O(1/t)$，在使用适当的学习率衰减策略时可以达到 $O(1/\sqrt{t})$。对于强凸函数，收敛速度可以达到线性收敛 $O(\rho^t)$，其中 $\rho \in (0, 1)$。

## 4. 训练过程讲解

### 4.1 标准梯度下降训练流程

使用梯度下降训练模型的完整流程如下：

1. **初始化参数**：随机初始化模型参数 $\theta_0$
2. **计算梯度**：计算损失函数关于参数的梯度 $\nabla L(\theta_t)$
3. **更新参数**：$\theta_{t+1} = \theta_t - \eta \cdot \nabla L(\theta_t)$
4. **检查收敛**：如果梯度范数 $\|\nabla L(\theta_t)\| < \epsilon$ 或损失函数变化小于阈值，停止训练
5. **返回步骤2**：继续迭代直到收敛

### 4.2 学习率调度策略

学习率是梯度下降最重要的超参数。以下是几种常用的学习率调度策略：

1. **固定学习率**：保持学习率不变，直到训练后期手动减小
2. **学习率衰减**：$ \eta_t = \eta_0 / (1 + dt) $，其中 $d$ 是衰减率
3. **指数衰减**：$ \eta_t = \eta_0 \cdot e^{-dt} $
4. **阶梯衰减**：每隔一定步数将学习率减小为原来的一半
5. **余弦退火**（Cosine Annealing）：$ \eta_t = \eta_{min} + 0.5 \cdot (\eta_{max} - \eta_{min}) \cdot (1 + \cos(\pi t / T)) $
6. **warmup**：训练初期逐渐增大学习率，然后逐渐减小

### 4.3 梯度下降的Python实现

以下是使用NumPy实现三种梯度下降算法的代码：

```python
import numpy as np

class GradientDescentOptimizer:
    """梯度下降优化器"""
    
    def __init__(self, learning_rate=0.01):
        self.learning_rate = learning_rate
    
    def update(self, params, gradients):
        """
        参数更新
        
        参数:
            params: 当前参数
            gradients: 损失函数关于参数的梯度
        
        返回:
            更新后的参数
        """
        return params - self.learning_rate * gradients


class StochasticGradientDescent:
    """随机梯度下降优化器"""
    
    def __init__(self, learning_rate=0.01, momentum=0.0, weight_decay=0.0):
        self.learning_rate = learning_rate
        self.momentum = momentum  # 动量
        self.weight_decay = weight_decay  # 权重衰减
        self.velocity = None  # 速度（动量项）
    
    def update(self, params, gradients):
        """带动量的随机梯度下降更新"""
        if self.velocity is None:
            self.velocity = np.zeros_like(params)
        
        # 权重衰减
        if self.weight_decay > 0:
            gradients = gradients + self.weight_decay * params
        
        # 动量更新
        self.velocity = self.momentum * self.velocity + gradients
        
        return params - self.learning_rate * self.velocity


class MiniBatchGradientDescent:
    """小批量梯度下降优化器"""
    
    def __init__(self, learning_rate=0.01, batch_size=32, momentum=0.9, 
                 nesterov=True, weight_decay=1e-4):
        self.learning_rate = learning_rate
        self.batch_size = batch_size
        self.momentum = momentum
        self.nesterov = nesterov  # Nesterov动量
        self.weight_decay = weight_decay
        self.velocity = None
        self.running_lr = learning_rate
    
    def compute_gradients(self, X, y, model, params):
        """计算小批量数据的梯度"""
        # 随机选择批量数据
        batch_indices = np.random.choice(len(X), self.batch_size, replace=False)
        X_batch = X[batch_indices]
        y_batch = y[batch_indices]
        
        # 前向传播
        predictions = model.forward(X_batch, params)
        
        # 计算损失
        loss = model.compute_loss(predictions, y_batch)
        
        # 反向传播
        gradients = model.backward(X_batch, y_batch, predictions)
        
        return loss, gradients
    
    def step(self, X, y, model, params):
        """单步更新"""
        loss, gradients = self.compute_gradients(X, y, model, params)
        
        if self.velocity is None:
            self.velocity = np.zeros_like(params)
        
        # Nesterov动量
        if self.nesterov:
            v_prev = self.velocity.copy()
            self.velocity = self.momentum * self.velocity + gradients
            params = params - self.learning_rate * (
                self.momentum * v_prev + (1 - self.momentum) * self.velocity
            )
        else:
            self.velocity = self.momentum * self.velocity + gradients
            params = params - self.learning_rate * self.velocity
        
        return params, loss
    
    def learning_rate_schedule(self, epoch):
        """学习率调度"""
        # 余弦退火调度
        self.running_lr = self.learning_rate * 0.5 * (1 + np.cos(np.pi * epoch / 100))
        
    def fit(self, X, y, model, n_epochs=100):
        """训练模型"""
        n_samples = len(X)
        params = model.initialize_params(X.shape[1])
        
        losses = []
        for epoch in range(n_epochs):
            self.learning_rate_schedule(epoch)
            
            # 打乱数据
            indices = np.random.permutation(n_samples)
            X_shuffled = X[indices]
            y_shuffled = y[indices]
            
            epoch_loss = 0.0
            n_batches = n_samples // self.batch_size
            
            for i in range(n_batches):
                start_idx = i * self.batch_size
                end_idx = start_idx + self.batch_size
                
                X_batch = X_shuffled[start_idx:end_idx]
                y_batch = y_shuffled[start_idx:end_idx]
                
                loss, gradients = self.compute_gradients(X_batch, y_batch, model, params)
                params, _ = self.step(X_batch, y_batch, model, params)
                
                epoch_loss += loss
            
            avg_loss = epoch_loss / n_batches
            losses.append(avg_loss)
            
            if epoch % 10 == 0:
                print(f"Epoch {epoch}: Loss = {avg_loss:.6f}, LR = {self.running_lr:.6f}")
        
        return params, losses
```

### 4.4 使用PyTorch实现

以下是使用PyTorch实现梯度下降的代码：

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset


class LinearRegressionModel(nn.Module):
    """线性回归模型"""
    
    def __init__(self, input_dim):
        super(LinearRegressionModel, self).__init__()
        self.linear = nn.Linear(input_dim, 1)
    
    def forward(self, x):
        return self.linear(x)


def train_with_sgd(model, X_train, y_train, learning_rate=0.01, 
                  batch_size=32, n_epochs=100):
    """
    使用随机梯度下降训练模型
    
    参数:
        model: PyTorch模型
        X_train: 训练数据特征
        y_train: 训练数据标签
        learning_rate: 学习率
        batch_size: 批量大小
        n_epochs: 训练轮数
    
    返回:
        训练后的模型
    """
    # 创建数据加载器
    train_dataset = TensorDataset(X_train, y_train)
    train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)
    
    # 使用SGD优化器
    optimizer = optim.SGD(model.parameters(), lr=learning_rate, momentum=0.9)
    
    # 学习率调度器
    scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=n_epochs)
    
    # 损失函数
    criterion = nn.MSELoss()
    
    # 训练循环
    model.train()
    for epoch in range(n_epochs):
        epoch_loss = 0.0
        for batch_X, batch_y in train_loader:
            # 前向传播
            predictions = model(batch_X).squeeze()
            loss = criterion(predictions, batch_y)
            
            # 反向传播
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            epoch_loss += loss.item()
        
        scheduler.step()
        
        if epoch % 10 == 0:
            avg_loss = epoch_loss / len(train_loader)
            current_lr = optimizer.param_groups[0]['lr']
            print(f"Epoch {epoch}: Loss = {avg_loss:.6f}, LR = {current_lr:.6f}")
    
    return model


def train_with_adam(model, X_train, y_train, learning_rate=0.001, 
                   batch_size=32, n_epochs=100):
    """
    使用Adam优化器训练模型
    
    Adam是一种自适应学习率方法，结合了动量法和RMSProp的优点
    """
    train_dataset = TensorDataset(X_train, y_train)
    train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)
    
    # Adam优化器
    optimizer = optim.Adam(model.parameters(), lr=learning_rate, betas=(0.9, 0.999))
    
    # 损失函数
    criterion = nn.MSELoss()
    
    # 训练循环
    model.train()
    for epoch in range(n_epochs):
        epoch_loss = 0.0
        for batch_X, batch_y in train_loader:
            predictions = model(batch_X).squeeze()
            loss = criterion(predictions, batch_y)
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            epoch_loss += loss.item()
        
        if epoch % 10 == 0:
            avg_loss = epoch_loss / len(train_loader)
            print(f"Epoch {epoch}: Loss = {avg_loss:.6f}")
    
    return model


# 示例使用
if __name__ == "__main__":
    # 生成模拟数据
    torch.manual_seed(42)
    n_samples = 1000
    n_features = 5
    
    X = torch.randn(n_samples, n_features)
    true_weights = torch.randn(n_features, 1)
    y = X @ true_weights + 0.1 * torch.randn(n_samples, 1)
    
    # 创建模型
    model = LinearRegressionModel(n_features)
    
    # 训练模型
    model = train_with_sgd(model, X, y, learning_rate=0.05, batch_size=64, n_epochs=100)
    
    # 评估模型
    model.eval()
    with torch.no_grad():
        predictions = model(X)
        mse = nn.MSELoss()(predictions, y)
        print(f"Final MSE: {mse.item():.6f}")
```
