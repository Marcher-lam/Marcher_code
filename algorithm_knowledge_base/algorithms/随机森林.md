# 随机森林 算法学习文档

## 1. 算法基础认知

随机森林（Random Forest）是由美国统计学家Leo Breiman于2001年提出的集成学习算法，它是Bagging（Bootstrap Aggregating）思想与决策树算法的结合。在机器学习领域，随机森林是一种强大且通用的分类和回归方法，因其优异的性能和高稳定性而广泛应用于各种实际场景。

随机森林的核心思想是"三个臭皮匠顶个诸葛亮"。通过构建大量的决策树，并综合所有树的预测结果来做最终决策，随机森林能够显著降低单个决策树可能存在的过拟合风险，提高模型的泛化能力。

与单个决策树相比，随机森林具有几个关键特点：首先，它使用Bootstrap Sampling（自助采样）从原始训练集中有放回地抽取多个子样本，每个子样本用于训练一棵决策树；其次，在每棵树的节点分裂时，随机森林只考虑部分特征而不是所有特征，这增加了树之间的多样性；最后，随机森林的最终预测是所有决策树预测的投票（分类）或平均值（回归）。

随机森林在2000年代的机器学习比赛中表现优异，是当时最流行的算法之一。即使在深度学习快速发展的今天，随机森林仍然是在表格数据上非常有效的算法，其可解释性和稳定性使其在金融、医疗等领域仍然很受欢迎。

## 2. 核心原理

随机森林的核心原理建立在Bagging和随机特征选择的基础上。

### 2.1 Bootstrap Sampling（自助采样）

给定包含N个样本的训练集，自助采样从中均匀地、有放回地抽取N个样本，形成一个新的训练子集。由于是有放回抽样，每个子集中可能包含重复的样本，同时原训练集中大约有36.8%的样本不会被选中。这些未被选中的样本称为Out-Of-Bag（OOB）样本，可以用于评估模型性能。

自助采样的目的是增加各个决策树之间的差异性。由于每个子样本不同，训练出的决策树也不同，这使得随机森林成为一个"森林"而不是多棵相同的树。

### 2.2 随机特征选择

在每棵决策树的节点分裂时，随机森林不是在所有候选特征中选择最优特征，而是随机选择一个特征子集（通常大小为 $\sqrt{m}$，其中m是总特征数），然后在这个子集中选择最优特征。

随机特征选择的目的是进一步增加树之间的多样性。如果每棵树都使用相同的特征选择策略，它们的结构可能非常相似。通过引入随机性，随机森林中的每棵树都不同，最终的预测更加稳健。

### 2.3 集成预测

对于分类问题，随机森林的最终预测是所有决策树的投票结果，即选择票数最多的类别。对于回归问题，随机森林的最终预测是所有决策树预测值的平均值。

这种集成方式能够有效降低方差，提高模型的稳定性。根据集成学习的理论，当各个基学习器的预测相互独立时，集成模型的方差会显著降低。

## 3. 数学公式与推导

### 3.1 自助采样的数学分析

设原始训练集包含N个样本，每次自助采样抽取N个样本。由于是有放回抽样，每个样本被选中的概率为 $1 - (1 - 1/N)^N$。

当N足够大时，这个概率趋近于 $1 - e^{-1} \approx 0.632$。因此，大约有36.8%的样本不会被选中，这些是OOB样本。

一个样本在N次采样中从未被选中的概率为 $(1 - 1/N)^N \approx e^{-1} \approx 0.368$。

### 3.2 随机特征子集大小

对于分类问题，通常随机特征子集的大小为 $\sqrt{m}$，其中m是特征总数。这是因为每个节点只需要考虑足够多的特征来找到好的分裂，不需要考虑所有特征。

对��回归问题，随机特征子集的大小通常为 $m/3$，这比分类问题略大，因为回归问题需要更多的特征来确保预测的准确性。

### 3.3 方差降低的数学推导

设随机森林包含T棵决策树，每棵树的预测为 $h_t(x)$，集成预测为 $H(x) = \frac{1}{T} \sum_t h_t(x)$。

假设各决策树的预测独立同分布，且 $E[h_t(x)] = \mu(x)$，$Var[h_t(x)] = \sigma^2(x)$。

则集成预测的期望为：

$$E[H(x)] = \frac{1}{T} \sum_t E[h_t(x)] = \mu(x)$$

集成预测的方差为：

$$Var[H(x)] = \frac{1}{T^2} \sum_t Var[h_t(x)] = \frac{\sigma^2(x)}{T}$$

（忽略各树之间的协方差）

当各树之间存在正相关时（即树的结构相似），方差降低的效果会减弱。随机森林通过引入随机性来降低各树之间的相关性，从而使方差降低更加显著。

### 3.4 特征重要性

随机森林的特征重要性可以通过两种方式计算：基尼重要性（Gini Importance）和置换重要性（Permutation Importance）。

基尼重要性基于各特征对基尼指数减少量的贡献。设特征j在所有树上的平均基尼减少量为 $GI_j$，则特征重要性为：

$$Importance_j = \frac{GI_j}{\sum_k GI_k}$$

置换重要性通过随机打乱某个特征的值来测量预测误差的增加。如果打乱某个特征后误差显著增加，说明该特征重要。

### 3.5 OOB误差估计

对于每个样本，随机森林使用那些没有在对应bootstrap sample中包含该样本的树来预测。然后计算这些预测的误差作为OOB误差。

OOB误差是无偏的，可以在不需要验证集的情况下估计模型的泛化误差。

## 4. 训练过程讲解

### 4.1 随机森林的训练

随机森林的训练过程可以分为以下几个步骤：

第一步，Bootstrap Sampling。从原始训练集中有放回地抽取N个样本，形成一个子样本集。这个过程重复T次，生成T个子样本集。

第二步，构建基决策树。对每个子样本集，使用随机选择的特征子集构建决策树。在每个节点上：

- 随机选择一个特征子集（大小为 $\sqrt{m}$ 或 $m/3$）
- 在该子集中选择最优特征进行分裂
- 递归构建子树直到满足停止条件

第三步，集成预测。对于新样本，将所有T棵树的预测综合起来：

- 分类：投票选择最多的类别
- 回归：计算所有预测的平均值

### 4.2 决策树的构建

在随机森林中，每棵决策树都是独立构建的。决策树的构建过程与CART类似，但有以下不同：

分裂特征的选择只考虑随机选择的特征子集，而不是所有特征。这增加了树之间的多样性。

树的生长通常不进行剪枝，让树完全生长。这增加了单棵树的复杂度，但通过集成可以降低过拟合风险。

### 4.3 预测过程

对于新样本，预测过程非常简单：

第一步，将样本输入到每一棵决策树中，获取每棵树的预测。

第二步，对于分类问题，统计票数，选择票数最多的类别。对于回归问题，计算所有预测的平均值。

这个过程可以在多个CPU核心上并行执行，因为各棵树的预测是独立的。

### 4.4 OOB误差计算

OOB误差的计算过程如下：

对于每个样本i，找到那些bootstrap sample不包含样本i的决策树。

使用这些树对样本i进行预测，计算预测误差。

对所有样本的OOB误差求平均，得到OOB误差。

## 5. 应用场景

随机森林在实际应用中非常广泛，主要用于以下场景：

在金融风控领域，随机森林可以用于信用评分和风险评估。由于其可以处理大量特征并自动进行特征选择，随机森林非常适合信用评分卡模型。输入客户的各种信息，输出信用评分或是否批准贷款。

在医疗诊断领域，随机森林可以���于疾病预测和诊断辅助。随机森林的可解释性可以帮助医生理解决策依据，同时其高准确性可以提高诊断的可靠性。

在市场营销领域，随机森林可以用于客户流失预测和购买预测。通过分析客户的历史行为和特征，随机森林可以预测客户是否会流失或购买某产品。

在图像分类领域，随机森林也可以用于特征分类。虽然深度学习在图像领域更流行，但随机森林在某些场景下仍然有效，特别是当数据量有限时。

在特征选择领域，随机森林的特征重要性可以用于识别重要的特征。这对于降维和特征工程非常有价值。

## 6. 优缺点分析

### 6.1 优点

随机森林算法具有以下显著优点：

首先，随机森林具有很高的准确性。通过集成大量决策树，随机森林通常能达到很高的预测准确性，在很多数据集上表现优异。

其次，随机森林具有很强的稳定性。随机森林对方差进行了有效控制，对数据中的噪声和异常值不敏感。

第三，随机森林可以处理高维数据。随机特征选择使得随机森林可以处理大量特征，而不会出现严重的过拟合。

第四，随机森林可以并行训练和预测。这使得随机森林可以在大规模数据集上高效运行。

第五，随机森林可以提供OOB误差估计。这使得可以在不需要验证集的情况下评估模型性能。

第六，随机森林可以计算特征重要性。这对于特征选择和模型解释非常有价值。

第七，随机森林具有很好的可解释性。可以可视化单棵决策树，理解模型的决策逻辑。

### 6.2 缺点

随机森林算法也存在一些缺点：

首先，随机森林的模型较大。由于包含大量决策树，随机森林的模型大小可能很大，预测时间较长。

其次，随机森林可能对回归问题表现不佳。在某些回归问题上，随机森林的预测可能是保守的平均值，对极端值的预测不准确。

第三，随机森林的可解释性不如单棵决策树。虽然可以查看单棵树，但整体的决策逻辑不那么直观。

第四，随机森林的超参数（如树的数量、最大深度）需要手动设置，虽然通常使用默认值效果也不错。

## 7. 调库实现

### 7.1 分类问题实现

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.metrics import (
    classification_report, confusion_matrix, accuracy_score, roc_curve, auc
)
from sklearn.datasets import load_iris, make_classification


def random_forest_classification():
    """随机森林分类器 - sklearn实现"""
    
    iris = load_iris()
    X, y = iris.data, iris.target
    
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=0.3, random_state=42, stratify=y
    )
    
    rf_clf = RandomForestClassifier(
        n_estimators=100,        # 树的数量
        max_depth=None,           # 最大深度，None表示不限制
        min_samples_split=2,     # 最小分裂样本数
        min_samples_leaf=1,       # 叶节点最小样本数
        max_features='sqrt',       # 分裂时考虑的特征数
        bootstrap=True,           # 使用bootstrap sampling
        oob_score=True,          # 计算OOB分数
        random_state=42,
        n_jobs=-1               # 使用所有CPU核心
    )
    
    rf_clf.fit(X_train, y_train)
    y_pred = rf_clf.predict(X_test)
    
    print("=" * 60)
    print("随机森林分类器 - sklearn实现")
    print("=" * 60)
    print(f"\n准确率: {accuracy_score(y_test, y_pred):.4f}")
    print(f"OOB分数: {rf_clf.oob_score_:.4f}")
    print(f"\n混淆矩阵:\n{confusion_matrix(y_test, y_pred)}")
    print(f"\n分类报告:\n{classification_report(y_test, y_pred)}")
    
    # 特征重要性
    print(f"\n特征重要性:")
    for name, imp in zip(iris.feature_names, rf_clf.feature_importances_):
        print(f"  {name}: {imp:.4f}")
    
    return rf_clf


def random_forest_binary_classification():
    """随机森林二分类示例"""
    
    X, y = make_classification(
        n_samples=500, n_features=10, n_informative=5,
        n_redundant=2, n_classes=2, random_state=42
    )
    
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=0.3, random_state=42
    )
    
    rf_clf = RandomForestClassifier(
        n_estimators=200,
        max_depth=10,
        oob_score=True,
        random_state=42
    )
    
    rf_clf.fit(X_train, y_train)
    y_pred = rf_clf.predict(X_test)
    y_prob = rf_clf.predict_proba(X_test)[:, 1]
    
    print(f"\n二分类准确率: {accuracy_score(y_test, y_pred):.4f}")
    print(f"OOB分数: {rf_clf.oob_score_:.4f}")
    
    # ROC曲线
    fpr, tpr, _ = roc_curve(y_test, y_prob)
    roc_auc = auc(fpr, tpr)
    print(f"AUC: {roc_auc:.4f}")
    
    return rf_clf


def random_forest_feature_importance():
    """随机森林特征重要性可视化"""
    
    iris = load_iris()
    X, y = iris.data, iris.target
    
    rf_clf = RandomForestClassifier(n_estimators=100, random_state=42)
    rf_clf.fit(X, y)
    
    importance = rf_clf.feature_importances_
    indices = np.argsort(importance)[::-1]
    
    plt.figure(figsize=(10, 6))
    plt.barh(range(len(importance)), importance[indices], color='steelblue')
    plt.yticks(range(len(importance)), np.array(iris.feature_names)[indices])
    plt.xlabel('重要性')
    plt.title('随机森林 - 特征重要性')
    plt.tight_layout()
    plt.savefig('rf_feature_importance.png', dpi=150)
    plt.show()


if __name__ == '__main__':
    rf_clf = random_forest_classification()
    rf_clf = random_forest_binary_classification()
    random_forest_feature_importance()
```

### 7.2 回归问题实现

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score


def random_forest_regression():
    """随机森林回归器 - sklearn实现"""
    
    np.random.seed(42)
    
    n_samples = 200
    X = np.sort(np.random.rand(n_samples) * 10, axis=0).reshape(-1, 1)
    y = np.sin(X).ravel() + np.random.randn(n_samples) * 0.1
    
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=0.3, random_state=42
    )
    
    rf_reg = RandomForestRegressor(
        n_estimators=100,
        max_depth=None,
        min_samples_split=2,
        min_samples_leaf=1,
        max_features='sqrt',
        oob_score=True,
        random_state=42,
        n_jobs=-1
    )
    
    rf_reg.fit(X_train, y_train)
    y_pred = rf_reg.predict(X_test)
    
    print("=" * 60)
    print("随机森林回归器 - sklearn实现")
    print("=" * 60)
    print(f"\nMSE: {mean_squared_error(y_test, y_pred):.4f}")
    print(f"RMSE: {np.sqrt(mean_squared_error(y_test, y_pred)):.4f}")
    print(f"R²: {r2_score(y_test, y_pred):.4f}")
    print(f"OOB分数: {rf_reg.oob_score_:.4f}")
    
    return rf_reg


def visualize_regression():
    """可视化随机森林回归结果"""
    
    np.random.seed(42)
    
    X = np.sort(np.random.rand(100) * 10).reshape(-1, 1)
    y = np.sin(X).ravel() + np.random.randn(100) * 0.1
    
    rf_reg = RandomForestRegressor(n_estimators=100, max_depth=5, random_state=42)
    rf_reg.fit(X, y)
    
    X_plot = np.linspace(0, 10, 200).reshape(-1, 1)
    y_pred = rf_reg.predict(X_plot)
    
    plt.figure(figsize=(10, 6))
    plt.scatter(X, y, alpha=0.5, label='真实值')
    plt.plot(X_plot, y_pred, 'r-', linewidth=2, label='预测值')
    plt.xlabel('X')
    plt.ylabel('y')
    plt.title('随机森林回归')
    plt.legend()
    plt.tight_layout()
    plt.savefig('rf_regression.png', dpi=150)
    plt.show()


if __name__ == '__main__':
    random_forest_regression()
    visualize_regression()
```

### 7.3 代码解释

上述代码展示了sklearn中随机森林的实现方式。关键参数说明：

- `n_estimators`：树的数量，通常100-500足够
- `max_depth`：树的最大深度，None表示不限制
- `min_samples_split`：分裂所需的最小样本数
- `min_samples_leaf`：叶节点最小样本数
- `max_features`：分裂时考虑的特征数，'sqrt'表示使用 $\sqrt{m}$
- `bootstrap`：是否使用bootstrap sampling
- `oob_score`：是否计算OOB分数
- `random_state`：随机种子
- `n_jobs`：并行计算的CPU核心数

## 8. 手工代码实现

### 8.1 完整NumPy实现

```python
import numpy as np
from collections import Counter
import copy


class RandomForest:
    """
    随机森林的纯NumPy实现
    
    支持分类和回归问题
    """
    
    def __init__(self, n_estimators=100, max_depth=None, min_samples_split=2,
                 min_samples_leaf=1, max_features='sqrt', task_type='classification',
                 random_state=None):
        self.n_estimators = n_estimators
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.min_samples_leaf = min_samples_leaf
        self.max_features = max_features
        self.task_type = task_type
        self.random_state = random_state
        self.trees = []
        self.oob_samples_list = []
        
    def _gini(self, y):
        """计算基尼指数"""
        if len(y) == 0:
            return 0.0
        
        counter = Counter(y)
        n = len(y)
        gini = 1.0
        
        for count in counter.values():
            p = count / n
            gini -= p * p
        
        return gini
    
    def _mse(self, y):
        """计算均方误差"""
        if len(y) == 0:
            return 0.0
        
        mean = np.mean(y)
        return np.mean((y - mean) ** 2)
    
    def _find_best_split(self, X, y, feature_indices):
        """找到最佳分裂"""
        if self.task_type == 'classification':
            criterion = self._gini
            criterion_parent = self._gini(y)
        else:
            criterion = self._mse
            criterion_parent = self._mse(y)
        
        best_gain = -1
        best_feature = None
        best_threshold = None
        
        for idx in feature_indices:
            unique_values = np.unique(X[:, idx])
            
            for i in range(len(unique_values) - 1):
                threshold = (unique_values[i] + unique_values[i + 1]) / 2
                
                left_mask = X[:, idx] <= threshold
                right_mask = X[:, idx] > threshold
                
                if np.sum(left_mask) < self.min_samples_leaf or np.sum(right_mask) < self.min_samples_leaf:
                    continue
                
                y_left, y_right = y[left_mask], y[right_mask]
                
                if self.task_type == 'classification':
                    gain = (criterion_parent - 
                           (len(y_left) / len(y) * criterion(y_left) - 
                           (len(y_right) / len(y) * criterion(y_right)))
                else:
                    gain = (criterion_parent - 
                           (len(y_left) / len(y) * criterion(y_left) - 
                           (len(y_right) / len(y) * criterion(y_right)))
                
                if gain > best_gain:
                    best_gain = gain
                    best_feature = idx
                    best_threshold = threshold
        
        return best_feature, best_threshold
    
    def _build_tree(self, X, y, feature_indices, depth=0):
        """构建决策树"""
        n_samples = len(y)
        
        if self.task_type == 'classification':
            if len(set(y)) == 1:
                return {'class': y[0]}
        else:
            if n_samples < self.min_samples_split:
                return {'value': np.mean(y)}
        
        if len(feature_indices) == 0:
            if self.task_type == 'classification':
                return {'class': Counter(y).most_common(1)[0][0]}
            else:
                return {'value': np.mean(y)}
        
        if self.max_depth is not None and depth >= self.max_depth:
            if self.task_type == 'classification':
                return {'class': Counter(y).most_common(1)[0][0]}
            else:
                return {'value': np.mean(y)}
        
        best_feature, best_threshold = self._find_best_split(X, y, feature_indices)
        
        if best_feature is None:
            if self.task_type == 'classification':
                return {'class': Counter(y).most_common(1)[0][0]}
            else:
                return {'value': np.mean(y)}
        
        tree = {
            'feature': best_feature,
            'threshold': best_threshold,
            'children': {}
        }
        
        left_mask = X[:, best_feature] <= best_threshold
        right_mask = X[:, best_feature] > best_threshold
        
        remaining_features = [f for f in feature_indices if f != best_feature]
        
        if np.sum(left_mask) >= self.min_samples_leaf:
            tree['children']['<='] = self._build_tree(
                X[left_mask], y[left_mask], remaining_features, depth + 1
            )
        else:
            if self.task_type == 'classification':
                tree['children']['<='] = {'class': Counter(y).most_common(1)[0][0]}
            else:
                tree['children']['<='] = {'value': np.mean(y)}
        
        if np.sum(right_mask) >= self.min_samples_leaf:
            tree['children']['>'] = self._build_tree(
                X[right_mask], y[right_mask], remaining_features, depth + 1
            )
        else:
            if self.task_type == 'classification':
                tree['children']['>'] = {'class': Counter(y).most_common(1)[0][0]}
            else:
                tree['children']['>'] = {'value': np.mean(y)}
        
        return tree
    
    def _predict_single(self, x, tree):
        """预测单个样本"""
        if self.task_type == 'classification':
            if 'class' in tree:
                return tree['class']
        else:
            if 'value' in tree:
                return tree['value']
        
        feature_idx = tree['feature']
        threshold = tree['threshold']
        
        if x[feature_idx] <= threshold:
            return self._predict_single(x, tree['children']['<='])
        else:
            return self._predict_single(x, tree['children']['>'])
    
    def _bootstrap_sample(self, X, y, random_state):
        """Bootstrap sampling"""
        np.random.seed(random_state)
        n = len(y)
        indices = np.random.choice(n, size=n, replace=True)
        
        oob_indices = np.array([i for i in range(n) if i not in indices])
        
        return X[indices], y[indices], oob_indices
    
    def fit(self, X, y):
        """训练随机森林"""
        X = np.array(X)
        y = np.array(y)
        
        n_features = X.shape[1]
        
        if self.max_features == 'sqrt':
            max_features = int(np.sqrt(n_features))
        elif self.max_features == 'log2':
            max_features = int(np.log2(n_features))
        else:
            max_features = int(self.max_features)
        
        max_features = max(1, max_features)
        
        self.trees = []
        
        for i in range(self.n_estimators):
            X_boot, y_boot, oob_indices = self._bootstrap_sample(
                X, y, self.random_state + i if self.random_state else i
            )
            
            self.oob_samples_list.append(oob_indices)
            
            if len(X_boot) == 0:
                continue
            
            feature_indices = list(range(n_features))
            np.random.seed((self.random_state or 0) + i)
            np.random.shuffle(feature_indices)
            feature_indices = feature_indices[:max_features]
            
            tree = self._build_tree(X_boot, y_boot, feature_indices)
            self.trees.append(tree)
        
        return self
    
    def predict(self, X):
        """预测新样本"""
        X = np.array(X)
        
        predictions = []
        for x in X:
            tree_predictions = []
            
            for tree in self.trees:
                pred = self._predict_single(x, tree)
                tree_predictions.append(pred)
            
            if self.task_type == 'classification':
                counter = Counter(tree_predictions)
                predictions.append(counter.most_common(1)[0][0])
            else:
                predictions.append(np.mean(tree_predictions))
        
        return np.array(predictions)
    
    def get_oob_score(self, X, y):
        """计算OOB分数"""
        X = np.array(X)
        y = np.array(y)
        
        oob_predictions = {}
        
        for tree_idx, oob_indices in enumerate(self.oob_samples_list):
            if len(oob_indices) == 0:
                continue
            
            for idx in oob_indices:
                if idx not in oob_predictions:
                    oob_predictions[idx] = []
                
                pred = self._predict_single(X[idx], self.trees[tree_idx])
                oob_predictions[idx].append(pred)
        
        correct = 0
        total = 0
        
        for idx, preds in oob_predictions.items():
            if len(preds) == 0:
                continue
            
            if self.task_type == 'classification':
                counter = Counter(preds)
                pred = counter.most_common(1)[0][0]
            else:
                pred = np.mean(preds)
            
            if pred == y[idx]:
                correct += 1
            
            total += 1
        
        return correct / total if total > 0 else 0


def demo():
```

### 8.2 代码关键点解释

上述代码是随机森林的完整NumPy实现，包括以下关键部分：

`_bootstrap_sample`方法实现了自助采样，返回bootstrap子样本和OOB样本的索引。这是随机森林的核心，通过bootstrap sampling增加各棵树之间的差异性。

`_find_best_split`方法在随机选择的特征子集中寻找最佳分裂，实现随机特征选择。

`_build_tree`方法递归构建决策树，与 CART 类似但在特征选择时只考虑随机选择的子集。

`predict`方法对所有树的预测进行投票（分类）或平均（回归），实现集成预测。

`get_oob_score`方法计算OOB误差，提供无偏的泛化误差估计。

## 11. 常见问题与易错点

### 11.1 树的数量选择

树的数量是随机森林最重要的超参数。通常100-200棵树足够，更多树可能提高准确性但增加计算开销。在资源有限时，可以选择较小的数量。

### 11.2 最大深度设置

默认不限制最大深度可以让树完全生长，这有利于提高准确性。但对于噪声数据，可能需要限制深度来防止过拟合。

### 11.3 特征数量选择

`max_features`参数控制每棵树使用的特征数量。较小的值增加树之间的多样性但可能降低单棵树的准确性。通常使用'sqrt'（分类）或'm/3'（回归）。

### 11.4 预测时间

由于包含大量决策树，随机森林的预测时间比单棵树长。在实时预测场景中可能不是最佳选择。

### 11.5 特征重要性解释

特征重要性是随机森林的有价值输出，但可能偏向于取值数量较多的特征。在解释时需要注意这一点。

## 12. 学习总结

随机森林是经典的集成学习算法，通过Bagging和随机特征选择创建大量决策树并进行集成预测。其核心贡献包括：

使用Bootstrap Sampling增加各棵树之间的差异性。通过自助采样，大约36.8%的样本不被包含在每个bootstrap子集中，这增加了树的随机性。

使用随机特征选择在分裂时只考虑部分特征。这进一步增加了树之间的多样性，使集成预测更加稳定。

使用OOB样本提供无偏的泛化误差估计。这使得可以在不需要验证集的情况下评估模型性能。

使用特征重要性提供特征排序。这对于特征选择和模型解释非常有价值。

随机森林是许多高级算法的基础，包括Extra Trees、GBDT等。学习随机森林对于理解决策树和集成学习的原理非常重要。

### 13.2 计算题

假设训练集有100个样本，计算Bootstrap抽样中样本未被选中的概率。

解：一个样本在100次抽样中从未被选中的概率为：

$$P(未被选中) = (1 - 1/100)^{100} \approx e^{-1} \approx 0.368$$

因此，大约有36.8个样本不会被选中。

### 13.3 思考题

1. 随机森林如何降低过拟合？
   
   答案：随机森林通过两种方式降低过拟合：第一，Bootstrap Sampling使得每棵树使用不同的训练数据，增加了模型的多样性；第二，随机特征选择使得每棵树使用不同的特征进行分裂。这两种随机性使得各棵树的预测errors相互独立，通过集成平均可以显著降低方差。

2. OOB误差与验证集误差有什么区别？
   
   答案：OOB误差是使用那些没有在对应bootstrap sample中的样本进行预测计算的误差。由于bootstrap sample大约只包含63%的训练样本，OOB误差是对未见数据的误差估计，是无偏的泛化误差估计。验证集误差是通过在独立的验证集上评估得到的误差，两者都可以用来估计模型的泛化能力。

3. 随机森林与单棵决策树相比有什么优势？
   
   答案：随机森林相对于单棵决策树的优势包括：更高的预测准确性；更强的稳定性和抗噪声能力；可以提供OOB误差估计；可以计算特征重要性；不容易过拟合。
