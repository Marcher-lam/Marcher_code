# 多层感知机 学习文档

## 1. 算法基础认知
### 1.1 一句话定义
多层感知机（Multi-Layer Perceptron，MLP）是一种前馈神经网络，由输入层、一个或多个隐藏层和输出层组成，通过非线性激活函数实现对复杂函数的逼近，是深度学习的基础模型。

### 1.2 直觉类比
想象成一家多层分工的工厂：原材料（输入特征）进入第一层工人（隐藏层），工人加工后传递给下一层，最终产品（输出）从最后一层出来。每层工人只与相邻层交流，不能跨层直接沟通，这就是"前馈"的含义。

### 1.3 历史背景
多层感知机由Rosenblatt于1958年提出感知机（单层）概念，但Minsky和Papert在1969年证明单层感知机无法解决XOR问题。直到1986年Rumelhart等人提出反向传播算法，多层感知机才真正可行。

### 1.4 算法定位
- 类型：监督学习
- 输出：连续值或离散类别
- 模型类别：参数模型/神经网络

### 1.5 前置知识
- 线性代数基础
- 微积分（链式法则）
- NumPy编程

## 2. 核心原理
### 2.1 核心思想
多层感知机的核心思想是通过叠加多层非线性变换，使得网络能够逼近任意复杂函数。每层将输入映射到新的特征空间，多层叠加实现逐层抽象。

### 2.2 工作流程
1. 输入层接收特征向量
2. 隐藏层进行线性变换+非线性激活
3. 逐层传递直到输出层
4. 计算损失并反向传播梯度
5. 更新参数，重复训练

### 2.3 关键概念解释
- **激活函数**：ReLU、Sigmoid、Tanh等，为网络引入非线性
- **反向传播**：从后向前计算梯度的算法
- **通用近似定理**：单隐藏层网络可逼近任意连续函数

### 2.4 几何/直观解释
每一层可以理解为在做一个"特征变换"，将数据从原始空间映射到新的空间。多层后，数据在新空间中变得更容易被分开。

## 3. 数学公式与推导
### 3.1 符号约定
| 符号 | 含义 |
|------|------|
| $x \in \mathbb{R}^d$ | 输入向量 |
| $y \in \mathbb{R}^K$ | 输出向量（K类） |
| $W^{(l)}$ | 第l层的权重矩阵 |
| $b^{(l)}$ | 第l层的偏置向量 |
| $a^{(l)}$ | 第l层的激活值 |
| $z^{(l)}$ | 第l层的线性组合 |

### 3.2 问题形式化
给定训练数据$\{(x_i, y_i)\}$，学习参数$\{W^{(l)}, b^{(l)}\}$使得网络输出$\hat{y}$接近真实标签。

### 3.3 目标函数/损失函数
对于分类使用交叉熵损失：
$$L = -\frac{1}{n}\sum_{i=1}^n \sum_{k=1}^K y_{ik} \log(\hat{y}_{ik})$$

对于回归使用MSE损失：
$$L = \frac{1}{2n}\sum_{i=1}^n \|y_i - \hat{y}_i\|^2$$

### 3.4 推导过程
**前向传播**：
$$z^{(1)} = W^{(1)}x + b^{(1)}$$
$$a^{(1)} = \sigma(z^{(1)})$$
$$z^{(2)} = W^{(2)}a^{(1)} + b^{(2)}$$
$$\hat{y} = softmax(z^{(2)})$$

**反向传播**（以MSE损失为例）：
设输出层误差$\delta^{(2)} = (a^{(2)} - y) \odot \sigma'(z^{(2)})$，则：
$$\frac{\partial L}{\partial W^{(2)}} = \delta^{(2)} (a^{(1)})^T$$
$$\frac{\partial L}{\partial b^{(2)}} = \delta^{(2)}$$

隐藏层误差：
$$\delta^{(1)} = (W^{(2)})^T \delta^{(2)} \odot \sigma'(z^{(1)})$$

### 3.5 最终解/算法步骤
参数更新（梯度下降）：
$$W^{(l)} := W^{(l)} - \alpha \cdot \frac{\partial L}{\partial W^{(l)}}$$
$$b^{(l)} := b^{(l)} - \alpha \cdot \frac{\partial L}{\partial b^{(l)}}$$

## 4. 训练过程讲解
### 4.1 数据预处理
- 特征标准化（Z-score或MinMax）
- 类别编码（one-hot）
- 去除异常值

### 4.2 参数初始化
- Xavier初始化：$W \sim N(0, \sqrt{2/n_{in}})$
- He初���化：$W \sim N(0, \sqrt{2/n_{in}})$

### 4.3 迭代过程
```python
# 伪代码
for epoch in range(max_epochs):
    for batch in data_loader:
        # 前向传播
        activations = forward(batch_x)
        # 计算损失
        loss = compute_loss(activations[-1], batch_y)
        # 反向传播
        gradients = backward(loss)
        # 更新参数
        update_parameters(gradients, learning_rate)
```

### 4.4 收敛条件
- 损失变化小于阈值
- 达到最大迭代次数
- 验证集损失不再下降

### 4.5 超参数及推荐范围
- hidden_layer_sizes: (100,) 或 (128, 64)
- activation: relu, tanh, logistic
- alpha: 0.0001-0.01（L2正则化）
- learning_rate: 0.001-0.1
- batch_size: 32-256

## 5. 应用场景
### 5.1 典型应用
- **图像分类**：手写数字识别（MNIST）
- **文本分类**：情感分析、垃圾邮件检测
- **回归预测**：价格预测、评分估计

### 5.2 适用数据特征
- 中等规模数据
- 特征可以是连续的
- 需要学习非线性关系

### 5.3 不适用场景
- 极大规模数据（用深度学习）
- 需要可解释性
- 数据量过小

## 6. 优缺点分析
### 6.1 优点
- 可以逼近任意复杂函数
- 灵活的网络结构
- 可处理各种类型数据

### 6.2 缺点
- 容易过拟合
- 训练耗时
- 超参数多

### 6.3 与同类算法对比
| 特性 | MLP | 逻辑回归 | 决策树 |
|------|-----|----------|--------|
| 非线性 | 是 | 否 | 是 |
| 可解释性 | 低 | 高 | 高 |
| 训练速度 | 慢 | 快 | 中 |

## 8. 手工代码实现
### 8.1 核心算法手写
```python
"""
多层感知机手工实现
"""
import numpy as np
from typing import Tuple, List

class MultiLayerPerceptron:
    """手工实现的多层感知机"""

    def __init__(
        self,
        layer_sizes: List[int],
        activation: str = 'relu',
        learning_rate: float = 0.01,
        max_iterations: int = 1000,
        batch_size: int = 32,
        alpha: float = 0.001
    ):
        """
        初始化MLP

        参数:
            layer_sizes: 各层神经元数量 [input, hidden1, hidden2, ..., output]
            activation: 激活函数类型
            learning_rate: 学习率
            max_iterations: 最大迭代次数
            batch_size: 批量大小
            alpha: L2正则化系数
        """
        self.layer_sizes = layer_sizes
        self.activation_name = activation
        self.learning_rate = learning_rate
        self.max_iterations = max_iterations
        self.batch_size = batch_size
        self.alpha = alpha
        self.weights = []
        self.biases = []
        self.losses = []

        # 初始化参数
        self._init_parameters()

    def _init_parameters(self):
        """使用He初始化参数"""
        np.random.seed(42)
        for i in range(len(self.layer_sizes) - 1):
            n_in = self.layer_sizes[i]
            n_out = self.layer_sizes[i + 1]
            # He初始化
            std = np.sqrt(2.0 / n_in)
            self.weights.append(np.random.randn(n_in, n_out) * std)
            self.biases.append(np.zeros((1, n_out)))

    def _activation(self, x: np.ndarray) -> np.ndarray:
        """激活函数"""
        if self.activation_name == 'relu':
            return np.maximum(0, x)
        elif self.activation_name == 'sigmoid':
            return 1 / (1 + np.exp(-np.clip(x, -500, 500)))
        elif self.activation_name == 'tanh':
            return np.tanh(x)
        else:
            return x

    def _activation_derivative(self, x: np.ndarray) -> np.ndarray:
        """激活函数的导数"""
        if self.activation_name == 'relu':
            return (x > 0).astype(float)
        elif self.activation_name == 'sigmoid':
            s = 1 / (1 + np.exp(-np.clip(x, -500, 500)))
            return s * (1 - s)
        elif self.activation_name == 'tanh':
            return 1 - np.tanh(x) ** 2
        else:
            return np.ones_like(x)

    def _softmax(self, x: np.ndarray) -> np.ndarray:
        """Softmax函数"""
        exp_x = np.exp(x - np.max(x, axis=1, keepdims=True))
        return exp_x / np.sum(exp_x, axis=1, keepdims=True)

    def _forward(self, X: np.ndarray) -> Tuple[List[np.ndarray], List[np.ndarray]]:
        """
        前向传播

        返回:
            (activations, z_values)的元组列表
        """
        activations = [X]
        z_values = []

        for i in range(len(self.weights)):
            z = activations[-1] @ self.weights[i] + self.biases[i]
            z_values.append(z)

            if i < len(self.weights) - 1:
                a = self._activation(z)
            else:
                a = self._softmax(z)
            activations.append(a)

        return activations, z_values

    def _compute_loss(self, y_pred: np.ndarray, y_true: np.ndarray) -> float:
        """交叉熵损失"""
        m = y_true.shape[0]
        # 避免log(0)
        y_pred = np.clip(y_pred, 1e-10, 1 - 1e-10)
        loss = -np.sum(y_true * np.log(y_pred)) / m

        # L2正则化
        for w in self.weights:
            loss += self.alpha * np.sum(w ** 2) / (2 * m)

        return loss

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'MultiLayerPerceptron':
        """
        训练模型

        参数:
            X: (n_samples, n_features)
            y: one-hot编码 (n_samples, n_classes)
        """
        n_samples = X.shape[0]
        n_classes = y.shape[1]

        for iteration in range(self.max_iterations):
            # 随机选择批量
            indices = np.random.choice(n_samples, self.batch_size, replace=False)
            X_batch = X[indices]
            y_batch = y[indices]

            # 前向传播
            activations, z_values = self._forward(X_batch)

            # 计算损失
            loss = self._compute_loss(activations[-1], y_batch)
            self.losses.append(loss)

            # 反向传播
            m = X_batch.shape[0]
            deltas = [None] * len(self.weights)

            # 输出层delta
            deltas[-1] = activations[-1] - y_batch

            # 隐藏层delta
            for l in range(len(self.weights) - 2, -1, -1):
                deltas[l] = (deltas[l + 1] @ self.weights[l + 1].T) * self._activation_derivative(z_values[l])

            # 更新参数
            for l in range(len(self.weights)):
                self.weights[l] -= self.learning_rate * (
                    activations[l].T @ deltas[l] / m + self.alpha * self.weights[l]
                )
                self.biases[l] -= self.learning_rate * np.mean(deltas[l], axis=0)

            if (iteration + 1) % 100 == 0:
                print(f"迭代 {iteration + 1}, 损失: {loss:.4f}")

        return self

    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        """预测概率"""
        activations, _ = self._forward(X)
        return activations[-1]

    def predict(self, X: np.ndarray) -> np.ndarray:
        """预测类别"""
        return np.argmax(self.predict_proba(X), axis=1)


# ============ 使用示例 ============
if __name__ == "__main__":
    from sklearn.datasets import make_classification
    from sklearn.metrics import accuracy_score
    from sklearn.model_selection import train_test_split
    from sklearn.preprocessing import StandardScaler

    print("=" * 50)
    print("MLP手工实现测试")
    print("=" * 50)

    # 生成数据
    X, y = make_classification(n_samples=1000, n_features=10, n_classes=3, random_state=42)

    # One-hot编码
    n_classes = len(np.unique(y))
    y_onehot = np.zeros((len(y), n_classes))
    y_onehot[np.arange(len(y)), y] = 1

    # 标准化
    scaler = StandardScaler()
    X = scaler.fit_transform(X)

    # 划分
    X_train, X_test, y_train, y_test = train_test_split(X, y_onehot, test_size=0.2, random_state=42)

    # 训练
    mlp = MultiLayerPerceptron(
        layer_sizes=[10, 32, 16, 3],
        activation='relu',
        learning_rate=0.01,
        max_iterations=500,
        batch_size=32
    )
    mlp.fit(X_train, y_train)

    # 预测
    y_pred = mlp.predict(X_test)
    y_true = np.argmax(y_test, axis=1)

    acc = accuracy_score(y_true, y_pred)
    print(f"\n手工实现准确率: {acc:.4f}")
```

```python
train_acc = []
test_acc = []
for d in depths:
    layers = tuple([32] * d + [2])
    mlp = MLPClassifier(hidden_layer_sizes=layers, max_iter=200, random_state=42)
    mlp.fit(X[:800], y[:800])
    train_acc.append(mlp.score(X[:800], y[:800]))
    test_acc.append(mlp.score(X[800:], y[800:]))
ax3.plot(depths, train_acc, 'b-o', label='Train')
ax3.plot(depths, test_acc, 'r-o', label='Test')
ax3.set_xlabel('Depth')
ax3.set_ylabel('Accuracy')
ax3.set_title('Network Depth Effect')
ax3.legend()

# 4. 激活函数比较
ax4 = axes[1, 1]
activations = ['relu', 'tanh', 'logistic']
for act in activations:
    mlp = MLPClassifier(hidden_layer_sizes=(64,), activation=act, max_iter=200, random_state=42)
    mlp.fit(X[:800], y[:800])
    ax4.plot(mlp.loss_curve_, label=act)
ax4.set_xlabel('Iteration')
ax4.set_ylabel('Loss')
ax4.set_title('Activation Function')
ax4.legend()

plt.tight_layout()
plt.show()
```

## 12. 学习总结
### 12.1 核心要点
- 多层非线性变换实现复杂函数逼近
- 反向传播计算梯度
- 激活函数引入非线性
- 通用近似定理保证表达能力

### 12.2 关键公式
前向：$a^{(l)} = \sigma(W^{(l)} a^{(l-1)} + b^{(l)})$

反向：$\delta^{(l)} = (W^{(l+1)})^T \delta^{(l+1)} \odot \sigma'(z^{(l)})$

### 12.3 学习路径
前置：线性回归、逻辑回归
后续：CNN、RNN、Transformer
