# 分词学习文档

## 1. 算法基础认知

分词（Tokenization）是自然语言处理中的基础步骤，它将连续的文本字符序列分解为更小的、可处理的单元（称为token）。分词是文本预处理的关键环节，它直接影响后续模型的表现。好的分词策略应该能够：

1. **保持语义完整性**：将语义相关的字符归为一个token
2. **控制词汇表大小**：合理限制token数量，避免稀疏问题
3. **处理OOV问题**：更好处理未登录词（Out-of-Vocabulary）
4. **保持一致性**：相同文本应该产生相同的分词结果

### 1.1 分词的发展历程

1. **基于词典的分词（1980s）**：正向最大匹配、逆向最大匹配
2. **基于统计的分词（1990s）**：HMM、CRF
3. **子词分词（2010s）**：BPE、WordPiece
4. **SentencePiece（2018）**： Google的统一分词框架
5. **字符级分词（2020s）**：直接使用字符/字节

### 1.2 分词的重要性

分词在NLP流水线中的位置：

```
原始文本 → 分词(Tokenization) → 数值化(Numericalization) → 嵌入(Embedding) → 模型(Model) → 输出(Output)
```

正确的分词使得：
- 模型更有效地学习语义表示
- 减少词汇表大小，降低计算成本
- 更好地处理多语言和未知词

## 2. 核心原理

### 2.1 基于词典的分词

基于词典的分词使用预先构建的词典进行匹配：

**正向最大匹配（Forward Maximum Matching, FMM）**：
```
1. 从左到右扫描
2. 尝试匹配最长词
3. 切分并移至下一位置
```

**逆向最大匹配（Backward Maximum Matching, BMM）**：
- 从右到左扫描
- 其他相同

**双向最大匹配（Bi-directional Maximum Matching）**：
- 同时执行FMM和BMM
- 选择词数较少的结果

### 2.2 子词分词

子词分词（Subword Tokenization）是更现代的方法，它平衡了词级和字符级的表示：

**子词的优势**：
- 词汇表紧凑：最多约32K个token
- 处理OOV：未知词可以分解为已知子词
- 语义完整：子词仍保留语义信息

### 2.3 BPE（Byte Pair Encoding）

BPE是一种简单的贪心算法：

1. **初始化**：每个字符作为一个簇
2. **迭代**：找到最频繁的相邻簇对，合并为一个新簇
3. **终止**：达到目标词汇量

**BPE合并操作**：
```
原始: "lower", "lower", "lowest"
字符级: l o w e r

迭代1: lo → lower (出现2次)
词汇表: lower, lowest

迭代2: er → lowest (出现1次，但最频繁的是low e r中的某个)
...

最终词汇表包含所有原始字符 + 合并的token
```

### 2.4 WordPiece

WordPiece是BPE的改进，由Google在语音搜索中使用：

1. **初始化**：每个Unicode字符作为一个token
2. **评估**：使用语言模型评估每个可能合并的评分
3. **选择**：选择使语言模型困惑度增加最少的合并
4. **终止**：达到目标词汇量

WordPiece使用**似然增益**评估：
$$\text{score}(x, y) = \log P([xy]) - \log P([x]) - \log P([y])$$

### 2.5 SentencePiece

SentencePiece是一个统一的框架，它解决了：

1. **文本还原**：保留空格信息
2. **统一处理**：不依赖语言
3. **直接训练**：从原始文本训练

**SentencePiece的特殊token**：
- `<unk>`：未知词
- `<s>`/`<s>`：句子开始/结束
- `<pad>`：填充

## 3. 数学公式与推导

### 3.1 BPE的合并频率

设token $a$ 和 $b$ 的出现频率为 $f(a)$ 和 $f(b)$，相邻对 $(a,b)$ 的频率为 $f(a,b)$：

$$\text{score}_{(a,b)} = f(a,b)$$

每次选择 $score$ 最高的相邻对进行合并。

### 3.2 WordPiece的对数似然

设词汇表 $V$，句子 $S = s_1 s_2 ... s_n$，语言模型：

$$P(S) = \prod_{i=1}^{n} P(s_i | s_{<i})$$

使用词汇表 $V \cup \{[xy]\}$ 的困惑度：
$$PP([xy]) = \exp \left( -\frac{1}{N} \sum_{i=1}^{N} \log P(s_i) \right)$$

选择困惑度增加最小的候选。

### 3.3 Unigram Language Model

Unigram模型是SentencePiece使用的：

$$P(x_1^n) = \prod_{i=1}^{n} P(x_i | x_1^{i-1})$$

训练时使用EM算法优化。

### 4.1 BPE实现

```python
import re
from collections import defaultdict


class BPE:
    """字节对编码（Byte Pair Encoding）"""
    def __init__(self, vocab_size=10000):
        self.vocab_size = vocab_size
        self.vocab = {}
        self.merges = []
    
    def get_stats(self, word_frequencies):
        """计算相邻对的频率"""
        pairs = defaultdict(int)
        
        for word, freq in word_frequencies.items():
            # word是字符列表
            for i in range(len(word) - 1):
                pair = (word[i], word[i+1])
                pairs[pair] += freq
        
        return pairs
    
    def merge_vocab(self, pair, word_frequencies):
        """合并最常见的对"""
        new_word_frequencies = {}
        
        bigram = re.escape(pair[0] + pair[1])
        
        for word, freq in word_frequencies.items():
            # 替换
            word_str = ''.join(word)
            new_word = re.sub(bigram, pair[0] + pair[1], word_str)
            
            # 检查是否实际发生了合并
            if len(new_word) < len(word_str):
                new_word_frequencies[tuple(new_word)] = freq
        
        return word_frequencies
    
    def train(self, text, min_frequency=2):
        """训练BPE
        
        参数:
            text: 训练文本
            min_frequency: 最小频率阈值
        """
        # 1. 字符级分词
        word_frequencies = defaultdict(int)
        
        for word in text.split():
            # 使用空格作为分隔
            word_chars = tuple(word) + ('</w>',)  # 添加词边界标记
            word_frequencies[word_chars] += 1
        
        # 初始化基础词汇表（所有单字符）
        vocab = set()
        for word in word_frequencies.keys():
            vocab.update(word)
        self.vocab = {v: i for i, v in enumerate(vocab)}
        
        # 2. 迭代合并
        num_merges = self.vocab_size - len(self.vocab)
        
        for i in range(num_merges):
            pairs = self.get_stats(word_frequencies)
            
            if not pairs:
                break
            
            # 找到最频繁的对
            best = max(pairs, key=pairs.get)
            
            if pairs[best] < min_frequency:
                break
            
            # 合并
            self.merges.append(best)
            
            word_frequencies = self.merge_vocab(best, word_frequencies)
                # 更新词汇表
            new_token = best[0] + best[1]
            self.vocab[new_token] = len(self.vocab)
        
        self.word_frequencies = word_frequencies
    
    def encode(self, text):
        """编码文本"""
        tokens = []
        
        for word in text.split():
            word_chars = tuple(word) + ('</w>',)
            
            # 贪心匹配合并
            i = 0
            while i < len(word_chars) - 1:
                # 尝试最长匹配
                for j in range(len(word_chars), i, -1):
                    candidate = ''.join(word_chars[i:j])
                    if candidate in self.vocab:
                        tokens.append(candidate)
                        break
                else:
                    tokens.append(word_chars[i])
                
                i += 1 if j == i + 1 else j - i
        
        return tokens
    
    def decode(self, tokens):
        """解码"""
        return ''.join(tokens).replace('</w>', ' ')
```

### 4.2 WordPiece实现

```python
import math
from collections import defaultdict


class WordPiece:
    """WordPiece分词器"""
    def __init__(self, vocab_size=10000):
        self.vocab_size = vocab_size
        self.vocab = {}
        self.word_frequencies = {}
    
    def train(self, text, min_frequency=100):
        """训练WordPiece
        
        参数:
            text: 训练文本（分词后的词序列）
            min_frequency: 最小频率
        """
        # 1. 统计词频
        self.word_frequencies = defaultdict(int)
        for word in text.split():
            self.word_frequencies[word] += 1
        
        # 过滤低频词
        for word in list(self.word_frequencies.keys()):
            if self.word_frequencies[word] < min_frequency:
                del self.word_frequencies[word]
        
        # 2. 初始化词汇表（所有单字符 + [UNK]）
        vocab = set()
        for word in self.word_frequencies.keys():
            vocab.update(list(word))
        
        self.vocab = {v: i for i, v in enumerate(sorted(vocab))}
        self.vocab['[UNK]'] = len(self.vocab)
        
        # 3. 贪心合并
        while len(self.vocab) < self.vocab_size:
            # 计算每个候选的评分
            best_score = -float('inf')
            best_pair = None
            
            for word in self.word_frequencies:
                # 检查所有可能的合并
                if len(word) < 2:
                    continue
                
                for i in range(len(word) - 1):
                    candidate = word[:i+1]
                    if candidate not in self.vocab:
                        score = self._get_score(word)
                        if score > best_score:
                            best_score = score
                            best_pair = candidate
            
            if best_pair is None:
                break
            
            # 添加到词汇表
            self.vocab[best_pair] = len(self.vocab)
    
    def _get_score(self, word):
        """计算合并评分"""
        # 简化版：使用词频率作为评分
        return self.word_frequencies.get(word, 0)
    
    def encode(self, text):
        """编码"""
        tokens = []
        
        for word in text.split():
            start = 0
            while start < len(word):
                # 尝试最长匹配
                end = len(word)
                found = False
                
                while end > start:
                    candidate = word[start:end]
                    
                    if candidate in self.vocab:
                        tokens.append(candidate)
                        found = True
                        break
                    
                    end -= 1
                
                if not found:
                    tokens.append('[UNK]')
                    start += 1
                else:
                    start = end
        
        return tokens
    
    def decode(self, tokens):
        """解码"""
        return ''.join(tokens)
```

### 4.3 SentencePiece

```python
import sentencepiece as spm


class SentencePieceTokenizer:
    """SentencePiece分词器"""
    def __init__(self, model_path=None):
        self.sp = None
        
        if model_path:
            self.load(model_path)
    
    def train(self, text_path, vocab_size=8000, model_type='unigram', character_coverage=0.9995):
        """训练SentencePiece
        
        参数:
            text_path: 训练文本路径
            vocab_size: 词汇表大小
            model_type: 模型类型 (unigram, bpe, char, word)
            character_coverage: 字符覆盖率
        """
        # 训练参数
        self.vocab_size = vocab_size
        self.model_type = model_type
        
        # 使用sentencepiece训练
        spm.SentencePieceTrainer.train(
            input=text_path,
            model_prefix='sp_model',
            vocab_size=vocab_size,
            model_type=model_type,
            character_coverage=character_coverage,
            pad_id=0,
            unk_id=1,
            bos_id=2,
            eos_id=3,
            pad_piece='<pad>',
            unk_piece='<unk>',
            bos_piece='<s>',
            eos_piece='</s>'
        )
        
        # 加载模型
        self.sp = spm.SentencePieceProcessor()
        self.sp.load('sp_model.model')
        
        return self
    
    def load(self, model_path):
        """加载模型"""
        self.sp = spm.SentencePieceProcessor()
        self.sp.load(model_path)
    
    def encode(self, text, out_type='int'):
        """编码
        
        参数:
            text: 输入文本
            out_type: 输出类型 ('int', 'str')
        """
        return self.sp.encode(text, out_type=out_type)
    
    def decode(self, ids):
        """解码"""
        if isinstance(ids[0], int):
            return self.sp.decode_ids(ids)
        else:
            return self.sp.decode_pieces(ids)
    
    def get_piece_size(self):
        """获取词汇表大小"""
        return self.sp.get_piece_size()
    
    def id_to_piece(self, id):
        """ID转token"""
        return self.sp.id_to_piece(id)
    
    def piece_to_id(self, piece):
        """token转ID"""
        return self.sp.piece_to_id(piece)
```

```python
import torch
import jieba


class ChineseTokenizer:
    """中文分词器（基于jieba）"""
    def __init__(self, custom_dict=None):
        self.jieba = jieba
        
        if custom_dict:
            self.load_dict(custom_dict)
    
    def load_dict(self, dict_path):
        """加载自定义词典"""
        jieba.load_userdict(dict_path)
    
    def cut(self, text, mode='default'):
        """分词
        
        参数:
            text: 输入文本
            mode: 分词模式 ('default', 'search', 'invoice')
        """
        if mode == 'default':
            return self.jieba.cut(text)
        elif mode == 'search':
            return self.jieba.cut_for_search(text)
        elif mode == 'invoice':
            return self.jieba.cut(text, HMM=True)
    
    def add_word(self, word, freq=None, tag=None):
        """添加词语"""
        self.jieba.add_word(word, freq, tag)
    
    def tokenize(self, text):
        """返回分词后的列表"""
        return list(self.jieba.cut(text))


class BERTChineseTokenizer:
    """BERT中文分词器"""
    def __init__(self, vocab_file):
        from transformers import BertTokenizer
        
        self.tokenizer = BertTokenizer.from_pretrained(vocab_file)
    
    def tokenize(self, text):
        """分词"""
        return self.tokenizer.tokenize(text)
    
    def encode(self, text, add_special_tokens=True):
        """编码"""
        return self.tokenizer.encode(text, add_special_tokens=add_special_tokens)
    
    def decode(self, ids, skip_special_tokens=True):
        """解码"""
        return self.tokenizer.decode(ids, skip_special_tokens=skip_special_tokens)
```

```python
class TokenEmbedder:
    """Token嵌入"""
    def __init__(self, vocab):
        self.vocab = vocab
        self.pad_idx = vocab.get('[PAD]', 0)
        self.unk_idx = vocab.get('[UNK]', 1)
        self.bos_idx = vocab.get('[CLS]', 2)
        self.eos_idx = vocab.get('[SEP]', 3)
    
    def encode(self, tokens, max_length=None, padding=True, truncation=False):
        """编码为ID"""
        ids = [self.vocab.get(t, self.unk_idx) for t in tokens]
        
        if max_length:
            if padding:
                ids = ids + [self.pad_idx] * (max_length - len(ids))
            
            if truncation and len(ids) > max_length:
                ids = ids[:max_length]
        
        return ids
    
    def decode(self, ids):
        """ID转token"""
        reverse_vocab = {v: k for k, v in self.vocab.items()}
        return [reverse_vocab.get(i, '[UNK]') for i in ids]
```

```python
    print(f"SentencePiece tokens: {tokens}")
    
    return bpe, sp
```

## 6. 评估指标

### 6.1 分词评估

```python
def evaluate_tokenization(pred_tokens, true_tokens):
    """评估分词结果
    
    参数:
        pred_tokens: 预测的分词
        true_tokens: 真实的分词
    """
    # 转换为集合
    pred_set = set(pred_tokens)
    true_set = set(true_tokens)
    
    # 精确率、召回率、F1
    correct = len(pred_set & true_set)
    precision = correct / len(pred_set) if pred_set else 0
    recall = correct / len(true_set) if true_set else 0
    f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0
    
    return {
        'precision': precision,
        'recall': recall,
        'f1': f1
    }
```

## 7. 常见问题与解决

### 7.1 问题分析

1. **分词不一致**：同一文本产生不同结果
   - 解决：固定词典，设置随机种子
   
2. **OOV问题**：未登录词无法处理
   - 解决：使用子词分词
   
3. **词汇表过大**：导致稀疏
   - 解决：限制词汇表大小，使用子词

### 8.1 简答题

1. **为什么需要子词分词？**
   - **答案**：词级分词词汇表过大，字符级语义不清，子词是折中方案

2. **BPE和WordPiece的区别？**
   - **答案**：BPE使用频率选择，WordPiece使用语言模型评分

3. **SentencePiece的优势？**
   - **答案**：不需要预处理文本可直接训练，支持多种模型类型
