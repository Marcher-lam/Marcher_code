## 1. 算法基础认知

### 1.1 一句话定义

情感分析是自然语言处理领域的核心任务之一，旨在识别文本中表达的情感倾向性。从简单的二分类任务（正面/负面）到细粒度情感分析（多种情感类别），情感分析技术在舆情监控、产品评价、社交媒体分析等领域有着广泛的应用。

### 1.2 直觉类比

想象你在阅读一条豆瓣评论：
- "这部电影太精彩了，看得我热泪盈眶！" → 正面情感
- "浪费了两个小时，完全是垃圾片。" → 负面情感

情感分析就是让机器自动识别这些主观判断的过程。

## 2. 核心原理

### 2.1 任务定义

给定文本x，预测情感标签y：

- **二分类**：y ∈ {正面, 负面}
- **多分类**：y ∈ {positive, negative, neutral}
- **细粒度**：y ∈ [0, 1] 连续值
- **多标签**：多情感同时存在

### 2.2 主要方法

**基于词典**：
```python
positive_words = ['good', 'great', 'excellent', 'wonderful']
negative_words = ['bad', 'terrible', 'awful', 'horrible']

def lexicon_analysis(text):
    words = text.lower().split()
    score = sum(1 for w in words if w in positive_words) - \
            sum(1 for w in words if w in negative_words)
    return 'positive' if score > 0 else 'negative'
```

**基于机器学习**：
- 特征提取：TF-IDF, n-grams, word embeddings
- 分类器：SVM, Logistic Regression, Naive Bayes

**基于深度学习**：
- CNN：局部特征提取
- RNN：序列建模
- Attention：重点关注
- Transformer：预训练语言模型

### 2.3 方面级情感分析（ABSA）

```python
# 方面级情感分析
# "The food is great, but the service is terrible"
# 方面1: food → positive
# 方面2: service → negative

class ABSA:
    def __init__(self, aspects):
        self.aspects = aspects
    
    def analyze(self, text):
        results = {}
        for aspect in self.aspects:
            # 定位方面
            aspect_pos = text.find(aspect)
            if aspect_pos >= 0:
                # 获取上下文
                context = extract_context(text, aspect_pos)
                # 预测情感
                sentiment = self.classifier(context)
                results[aspect] = sentiment
        return results
```

## 3. 数学公式与推导

### 3.1 文本表示

**词嵌入**：
$$\mathbf{v}_i = \text{Embedding}(w_i)$$

**句子嵌入**（平均池化）：
$$\mathbf{v}_{sent} = \frac{1}{n}\sum_{i=1}^{n} \mathbf{v}_i$$

**BERT表示**：
$$H = \text{BERT}(x_1, x_2, ..., x_n)$$
$$h_{cls} = H_{[CLS]}$$

### 3.2 情感分类

**二分类交叉熵**：
$$L = -[y \log \hat{y} + (1-y)\log(1-\hat{y})]$$

**多分类交叉熵**：
$$L = -\sum_{c=1}^{K} y_c \log \hat{y}_c$$

**Sigmoid输出**（多标签）：
$$\hat{y}_c = \sigma(w_c \cdot x + b_c)$$

### 3.3 损失函数

**Focal Loss**（处理类别不平衡）：
$$L = -\alpha_t (1-\hat{y})^\gamma \log(\hat{y})$$

**Label Smoothing**（正则化）：
$$\hat{y}_c = (1-\epsilon)\hat{y}_c + \epsilon/K$$

## 4. PyTorch实现

### 4.1 基础模型

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class TextCNN(nn.Module):
    """TextCNN for sentiment analysis"""
    def __init__(self, vocab_size, embed_dim, num_classes, num_filters=100, filter_sizes=[2, 3, 4, 5]):
        super(TextCNN, self).__init__()
        
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        
        # 多尺度卷积
        self.convs = nn.ModuleList([
            nn.Conv1d(embed_dim, num_filters, kernel_size=fs)
            for fs in filter_sizes
        ])
        
        self.dropout = nn.Dropout(0.5)
        self.fc = nn.Linear(len(filter_sizes) * num_classes, num_classes)
    
    def forward(self, x):
        # (batch, seq_len) -> (batch, embed_dim, seq_len)
        x = self.embedding(x).transpose(1, 2)
        
        conv_outputs = []
        for conv in self.convs:
            conv_out = F.relu(conv(x))
            pooled = torch.max(conv_out, dim=2)[0]
            conv_outputs.append(pooled)
        
        x = torch.cat(conv_outputs, dim=1)
        x = self.dropout(x)
        x = self.fc(x)
        
        return x


class BiLSTM(nn.Module):
    """BiLSTM for sentiment analysis"""
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_classes, num_layers=2):
        super(BiLSTM, self).__init__()
        
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, num_layers=num_layers, 
                        bidirectional=True, batch_first=True, dropout=0.3)
        
        self.dropout = nn.Dropout(0.5)
        self.fc = nn.Linear(hidden_dim * 2, num_classes)
    
    def forward(self, x):
        x = self.embedding(x)
        output, (hidden, cell) = self.lstm(x)
        
        # 双向拼接最后隐藏状态
        hidden = torch.cat([hidden[-2], hidden[-1]], dim=1)
        hidden = self.dropout(hidden)
        x = self.fc(hidden)
        
        return x
```

### 4.2 BERT模型

```python
class BERTClassifier(nn.Module):
    """BERT-based sentiment classifier"""
    def __init__(self, model_name, num_classes, dropout=0.1):
        super(BERTClassifier, self).__init__()
        
        from transformers import BertModel
        self.bert = BertModel.from_pretrained(model_name)
        
        self.dropout = nn.Dropout(dropout)
        self.classifier = nn.Linear(768, num_classes)
    
    def forward(self, input_ids, attention_mask):
        outputs = self.bert(input_ids=input_ids, attention_mask=attention_mask)
        
        # 使用[CLS]token
        pooled = outputs.pooler_output
        pooled = self.dropout(pooled)
        logits = self.classifier(pooled)
        
        return logits


class BERTWithAspect(nn.Module):
    """BERT with aspect embedding"""
    def __init__(self, model_name, num_aspects, num_classes):
        super().__init__()
        
        from transformers import BertModel
        self.bert = BertModel.from_pretrained(model_name)
        
        self.aspect_embedding = nn.Embedding(num_aspects, 768)
        self.classifier = nn.Sequential(
            nn.Linear(768 * 2, 256),
            nn.ReLU(),
            nn.Dropout(0.1),
            nn.Linear(256, num_classes)
        )
    
    def forward(self, input_ids, attention_mask, aspect_ids):
        bert_output = self.bert(input_ids=input_ids, attention_mask=attention_mask)
        
        # [CLS]
        cls_output = bert_output.pooler_output
        
        # Aspect embedding
        aspect_output = self.aspect_embedding(aspect_ids).squeeze(1)
        
        # 拼接
        combined = torch.cat([cls_output, aspect_output], dim=1)
        logits = self.classifier(combined)
        
        return logits
```

## 5. 代码示例

### 5.1 完整训练流程

```python
from transformers import BertTokenizer, AdamW, get_linear_schedule_with_warmup
from sklearn.metrics import accuracy_score, f1_score, classification_report


def train_epoch(model, dataloader, optimizer, scheduler, device):
    model.train()
    total_loss = 0
    
    for batch in dataloader:
        optimizer.zero_grad()
        
        input_ids = batch['input_ids'].to(device)
        attention_mask = batch['attention_mask'].to(device)
        labels = batch['label'].to(device)
        
        outputs = model(input_ids, attention_mask)
        loss = F.cross_entropy(outputs, labels)
        
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        optimizer.step()
        scheduler.step()
        
        total_loss += loss.item()
    
    return total_loss / len(dataloader)


def evaluate(model, dataloader, device):
    model.eval()
    predictions = []
    true_labels = []
    
    with torch.no_grad():
        for batch in dataloader:
            input_ids = batch['input_ids'].to(device)
            attention_mask = batch['attention_mask'].to(device)
            labels = batch['label'].to(device)
            
            outputs = model(input_ids, attention_mask)
            preds = torch.argmax(outputs, dim=1)
            
            predictions.extend(preds.cpu().numpy())
            true_labels.extend(labels.cpu().numpy())
    
    accuracy = accuracy_score(true_labels, predictions)
    f1 = f1_score(true_labels, predictions, average='binary')
    
    return accuracy, f1, classification_report(true_labels, predictions)


def train_model(model, train_loader, val_loader, device, num_epochs=3):
    optimizer = AdamW(model.parameters(), lr=2e-5)
    total_steps = len(train_loader) * num_epochs
    scheduler = get_linear_schedule_with_warmup(
        optimizer, 
        num_warmup_steps=0,
        num_training_steps=total_steps
    )
    
    best_f1 = 0
    
    for epoch in range(num_epochs):
        train_loss = train_epoch(model, train_loader, optimizer, scheduler, device)
        accuracy, f1, report = evaluate(model, val_loader, device)
        
        print(f'Epoch {epoch+1}')
        print(f'Train Loss: {train_loss:.4f}')
        print(f'Val Accuracy: {accuracy:.4f}, F1: {f1:.4f}')
        print(report)
        
        if f1 > best_f1:
            best_f1 = f1
            torch.save(model.state_dict(), 'best_model.pt')
    
    return model
```

### 5.2 推理

```python
def predict_sentiment(text, model, tokenizer, device):
    model.eval()
    
    encoding = tokenizer(
        text,
        max_length=128,
        padding='max_length',
        truncation=True,
        return_tensors='pt'
    )
    
    input_ids = encoding['input_ids'].to(device)
    attention_mask = encoding['attention_mask'].to(device)
    
    with torch.no_grad():
        outputs = model(input_ids, attention_mask)
        probs = F.softmax(outputs, dim=1)
        pred = torch.argmax(probs, dim=1).item()
    
    sentiment = 'positive' if pred == 1 else 'negative'
    confidence = probs[0][pred].item()
    
    return {
        'text': text,
        'sentiment': sentiment,
        'confidence': confidence,
        'probabilities': probs[0].cpu().numpy()
    }


def batch_predict(texts, model, tokenizer, device):
    results = []
    for text in texts:
        result = predict_sentiment(text, model, tokenizer, device)
        results.append(result)
    return results
```

```python
class SentimentMonitor:
    def __init__(self, model, keywords):
        self.model = model
        self.keywords = keywords
    
    def monitor(self, texts):
        results = []
        for text in texts:
            # 检查关键词
            if any(kw in text for kw in self.keywords):
                result = predict_sentiment(text, self.model)
                results.append(result)
        
        # 统计
        stats = {
            'total': len(results),
            'positive': sum(1 for r in results if r['sentiment'] == 'positive'),
            'negative': sum(1 for r in results if r['sentiment'] == 'negative'),
        }
        
        return results, stats
```

## 7. 常见问题与易错点

### Q1: 类别不平衡？

**原因**：数据集中正面样本远多于负面

**解决方案**：
```python
# 类别权重
class_weights = torch.tensor([1.0, 3.0])  # 增加负面权重

criterion = FocalLoss(alpha=0.25, gamma=2.0)
```
