# GNN 图神经网络 学习文档

> 图神经网络（Graph Neural Network），处理图结构数据的深度学习框架，消息传递机制的统一框架。

---

## 1. 算法基础认知

### 1.1 什么是GNN？

GNN是用于处理图结构数据的深度学习模型的统称，最早由Scarselli等人于2009年提出。经过多年发展，GNN已成为处理图、点云、分子等非欧几里得结构数据的核心框架。GNN的核心思想是"消息传递"——通过迭代聚合邻居信息来更新节点表征，这使其能够捕获图中的局部结构和全局模式。

### 1.2 发展历程

- **2009年**：GNN原论文（Scarselli et al.）
- **2013年**：Graph Esnake Networks
- **2015年**：Interaction Networks
- **2017年**：GCN、GraphSAGE
- **2018年**：GAT、MPNN
- **2019-2024年**：Transformer for Graphs、GIN等

### 1.3 核心定位

GNN不是单一算法，而是一个通用框架：
- **谱域方法**：GCN、ChebNet
- **空域方法**：GraphSAGE、GAT、GIN
- **统一框架**：MPNN（Message Passing Neural Network）

---

## 2. 核心原理

### 2.1 消息传递框架（MPNN）

Gilmer等人于2017年提出MPNN统一框架，将GNN分解为两个阶段：

**消息阶段**：
$$m_v^{t+1} = \sum_{u \in \mathcal{N}(v)} M_t(h_v^t, h_u^t, e_{uv})$$

其中M是消息函数。

**更新阶段**：
$$h_v^{t+1} = U_t(h_v^t, m_v^{t+1})$$

其中U是更新函数。

### 2.2 聚合与更新

**聚合（AGGREGATE）**：
- Mean：均值聚合
- Max：最大池化
- Sum：求和聚合
- LSTM：序列聚合
- Attention：注意力聚合

**更新（UPDATE）**：
$$h_v^{(l+1)} = UPDATE(h_v^{(l)}, AGGREGATE(\{h_u^{(l)}: u \in \mathcal{N}(v)\}))$$

### 2.3 池化操作

**节点池化**：
- Global Mean Pooling
- Global Max Pooling
- Global Sum Pooling
- Attention Pooling

**图池化**：
- DiffPool
- SAGPool

---

## 3. 数学公式与推导

### 3.1 MPNN通用公式

设第l层的节点表征为$h_v^{(l)}$：

**消息计算**：
$$m_{u \to v}^{(l)} = MSG(h_u^{(l)}, h_v^{(l)}, e_{uv})$$

**消息聚合**：
$$m_v^{(l)} = AGG(\{m_{u \to v}^{(l)}: u \in \mathcal{N}(v)\})$$

**节点更新**：
$$h_v^{(l+1)} = UPDATE(h_v^{(l)}, m_v^{(l)})$$

### 3.2 各种GNN变体

| 变体 | 消息函数 | 聚合方式 |
|------|---------|---------|
| GCN | $W h_u$ | D^{-1/2}AD^{-1/2} |
| GraphSAGE | $W h_u$ | MEAN/MAX/LSTM |
| GAT | $a_{uv} W h_u$ | Attention |
| GIN | $W h_u$ | SUM + MLP |

### 3.3 表达力分析

**WL同构测试**：
- GNN的表达力不超过1-WL同构测试
- GIN达到1-WL同构测试能力

### 4.1 节点分类

```python
"""
GNN 节点分类训练
"""
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.datasets import Planetoid
from torch_geometric.nn import GCNConv, SAGEConv, GATConv
import matplotlib.pyplot as plt

# 数据
dataset = Planetoid(root='/tmp/Cora', name='Cora')
data = dataset[0]

# GNN模型
class GNN(nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels, 
                 conv_type='gcn', num_layers=2):
        super(GNN, self).__init__()
        
        self.convs = nn.ModuleList()
        
        for i in range(num_layers):
            in_ch = in_channels if i == 0 else hidden_channels
            out_ch = out_channels if i == num_layers - 1 else hidden_channels
            
            if conv_type == 'gcn':
                self.convs.append(GCNConv(in_ch, out_ch))
            elif conv_type == 'sage':
                self.convs.append(SAGEConv(in_ch, out_ch))
            elif conv_type == 'gat':
                self.convs.append(GATConv(in_ch, out_ch, heads=4, concat=(i < num_layers - 1)))
    
    def forward(self, x, edge_index):
        for i, conv in enumerate(self.convs):
            x = conv(x, edge_index)
            if i < len(self.convs) - 1:
                x = F.relu(x)
                x = F.dropout(x, p=0.5, training=self.training)
        return x

# 训练
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = GNN(dataset.num_features, 16, dataset.num_classes).to(device)
data = data.to(device)

optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

for epoch in range(200):
    model.train()
    optimizer.zero_grad()
    out = model(data.x, data.edge_index)
    loss = F.cross_entropy(out[data.train_mask], data.y[data.train_mask])
    loss.backward()
    optimizer.step()
    
    if epoch % 20 == 0:
        model.eval()
        pred = out.argmax(dim=1)
        train_acc = (pred[data.train_mask] == data.y[data.train_mask]).float().mean()
        val_acc = (pred[data.val_mask] == data.y[data.val_mask]).float().mean()
        print(f'Epoch {epoch}: Loss={loss:.4f}, Train={train_acc:.4f}, Val={val_acc:.4f}')
```

"""
自定义消息传递GNN
"""
from torch_geometric.nn import MessagePassing

class MyGNNConv(MessagePassing):
    """
    自定义消息传递层
    
    消息函数: m_{uv} = MLP(h_u, h_v)
    聚合函数: AGG(m_{uv})
    更新函数: h_v' = UPDATE(h_v, m_v)
    """
    def __init__(self, in_channels, out_channels, aggr='add'):
        super().__init__(aggr=aggr)
        
        # 消息网络
        self.mlp = nn.Sequential(
            nn.Linear(in_channels * 2, out_channels),
            nn.ReLU(),
            nn.Linear(out_channels, out_channels)
        )
        
        # 更新网络
        self.update = nn.Sequential(
            nn.Linear(in_channels + out_channels, out_channels),
            nn.ReLU()
        )
        
        self.in_channels = in_channels
        self.out_channels = out_channels
    
    def forward(self, x, edge_index):
        # 传递消息
        return self.propagate(edge_index, x=x)
    
    def message(self, x_i, x_j):
        """消息函数"""
        return self.mlp(torch.cat([x_i, x_j], dim=1))
    
    def update(self, aggr_out, x):
        """更新函数"""
        return self.update(torch.cat([x, aggr_out], dim=1))

## 8. 手工代码实现（PyTorch）

### 8.1 基础MPNN层

```python
"""
GNN 手工实现
消息传递神经网络核心
"""
import torch
import torch.nn as nn
import torch.nn.functional as F

class MessagePassingLayer(nn.Module):
    """
    基础消息传递层
    
    消息: m_uv = W * h_u
    聚合: m_v = SUM(m_uv for u in N(v))
    更新: h_v' = sigma(UPDATE(h_v, m_v))
    """
    def __init__(self, in_channels, out_channels, aggr='add'):
        super().__init__()
        
        self.in_channels = in_channels
        self.out_channels = out_channels
        self.aggr = aggr
        
        # 消息变换矩阵
        self.W_msg = nn.Linear(in_channels, out_channels, bias=False)
        
        # 更新网络
        self.W_update = nn.Linear(in_channels + out_channels, out_channels)
    
    def forward(self, x, edge_index):
        """
        参数:
            x: 节点特征 [N, in_channels]
            edge_index: 边索引 [2, E]
        
        返回:
            x: 更新后的特征 [N, out_channels]
        """
        N = x.size(0)
        
        # 消息阶段：计算每条边的消息
        source = edge_index[0]  # 源节点
        target = edge_index[1]  # 目标节点
        
        # 对源节点进行变换 (消息)
        msg = self.W_msg(x[source])  # [E, out_channels]
        
        # 聚合阶段：根据目标节点聚合
        out = torch.zeros(N, self.out_channels, device=x.device)
        
        if self.aggr == 'add' or self.aggr == 'sum':
            index = target
            out = out.scatter_add(0, index.unsqueeze(-1).expand_as(msg), msg)
        elif self.aggr == 'mean':
            # 平均需要除以计数
            out = out.scatter_add(0, index.unsqueeze(-1).expand_as(msg), msg)
            counts = torch.zeros(N, device=x.device)
            counts = counts.scatter_add(0, index, torch.ones(edge_index.size(1), device=x.device))
            counts = counts.unsqueeze(-1) + 1e-8
            out = out / counts
        elif self.aggr == 'max':
            for i in range(N):
                mask = target == i
                if mask.sum() > 0:
                    out[i] = msg[mask].max(dim=0)[0]
        
        # 更新阶段
        x_new = self.W_update(torch.cat([x, out], dim=1))
        x_new = F.relu(x_new)
        
        return x_new

class GraphGNN(nn.Module):
    """
    多层GNN
    """
    def __init__(self, in_channels, hidden_channels, out_channels, num_layers=2):
        super().__init__()
        
        self.layers = nn.ModuleList()
        
        for i in range(num_layers):
            in_ch = in_channels if i == 0 else hidden_channels
            out_ch = out_channels if i == num_layers - 1 else hidden_channels
            self.layers.append(MessagePassingLayer(in_ch, out_ch))
    
    def forward(self, x, edge_index):
        for layer in self.layers:
            x = layer(x, edge_index)
        return x
```

### 8.2 GIN实现

```python
"""
GIN (Graph Isomorphism Network) 实现
最强大的GNN变体之一
达到WL测试能力
"""
class GINLayer(nn.Module):
    """
    GIN层
    
    聚合: h_N = SUM(h_u for u in N(v))
    更新: h_v' = MLP(h_v + h_N)
    
    关键: 使用SUM而非MEAN/MAX
    """
    def __init__(self, in_channels, out_channels):
        super().__init__()
        
        # MLP: 两层linear + ReLU + 层归一化
        self.mlp = nn.Sequential(
            nn.Linear(in_channels, out_channels),
            nn.ReLU(),
            nn.Linear(out_channels, out_channels)
        )
        
        self.eps = nn.Parameter(torch.zeros(1))
    
    def forward(self, x, edge_index):
        source = edge_index[0]
        target = edge_index[1]
        
        # 聚合邻居
        N = x.size(0)
        out = torch.zeros(N, x.size(1), device=x.device)
        out = out.scatter_add(0, target, x[source])
        
        # 加上自身特征 (1+eps) * h_v
        h_new = (1 + self.eps) * x + out
        
        # MLP变换
        h_new = self.mlp(h_new)
        
        return h_new

class GIN(nn.Module):
    """GIN模型"""
    def __init__(self, in_channels, hidden_channels, out_channels):
        super().__init__()
        
        self.conv1 = GINLayer(in_channels, hidden_channels)
        self.conv2 = GINLayer(hidden_channels, out_channels)
    
    def forward(self, x, edge_index):
        x = F.relu(self.conv1(x, edge_index))
        x = self.conv2(x, edge_index)
        return x
```

## 12. 学习总结

### 12.1 核心要点

**核心思想**：消息传递
$$m_v^{(l)} = AGG(\{MSG(h_u^{(l)}): u \in \mathcal{N}(v)\})$$
$$h_v^{(l+1)} = UPDATE(h_v^{(l)}, m_v^{(l)})$$

**关键组件**：
- 消息函数：变换邻居特征
- 聚合函数：汇总邻居信息
- 更新函数：结合自身特征

### 12.2 GNN vs 其他模型

### 13.2 简答题

**1. 过平滑问题是什么？**
答：随着GNN层数增加，所有节点的表征趋于一致，无法区分不同节点。这是因为每层都在聚合邻居信息，多层后信息趋同。

**2. 如何解决过平滑？**
答：
- 减少层数（通常2-3层）
- 添加残差连接
- 使用不同层输出
- DenseGraph
