## 1. 算法基础认知

### 1.1 发展背景

T5 由 Google Research 于 2019 年在论文《Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer》中提出，提出"Text-to-Text"统一框架，将所有 NLP 任务转换为文本生成任务。

### 1.2 核心定位

| 特性 | 说明 |
|------|------|
| 架构 | Encoder-Decoder |
| 任务 | 文本到文本 |
| 输入格式 | 统一 "task: input" |
| 输出格式 | 预测文本 |

### 1.3 模型系列

| 模型 | 参数量 | 层数 |
|------|--------|------|
| T5-Small | 60M | 6 |
| T5-Base | 220M | 12 |
| T5-Large | 770M | 24 |
| T5-3B | 3B | 24 |
| T5-11B | 11B | 24 |

---

## 2. 核心原理

### 2.1 Text-to-Text 框架

所有任务统一为：input → output

| 任务 | 输入 | 输出 |
|------|------|------|
| 翻译 | "translate English to German: Hello" | "Hallo" |
| 分类 | "sst2: This is good" | "positive" |
| 问答 | "question: What is AI? context: AI is..." | "answer" |
| 摘要 | "summarize: long text..." | "short summary" |

### 2.2 注意力机制

- Encoder：双向自注意力
- Decoder：因果自注意力 + Cross-attention

### 2.3 C4 数据集

 Colossal Clean Crawled Corpus：750GB 清洗后的网络文本

## 3. 数学公式与推导

### 3.1 编码器前向

$$h = \text{Encoder}(x)$$

### 3.2 解码器生成

$$P(y_t | y_{<t}, x) = \text{Decoder}(h, y_{<t})$$

### 3.3 损失函数

$$\mathcal{L} = -\sum_{t} \log P(y_t)$$

## 6. 调库实现

### 6.1 HuggingFace

```python
import torch
from transformers import T5Tokenizer, T5ForConditionalGeneration

class T5Model:
    """T5 文本到文本模型"""
    
    def __init__(self, model_name="t5-base"):
        self.tokenizer = T5Tokenizer.from_pretrained(model_name)
        self.model = T5ForConditionalGeneration.from_pretrained(model_name)
        
    def generate(self, input_text, max_length=512):
        """文本生成"""
        inputs = self.tokenizer(
            input_text, 
            return_tensors="pt", 
            padding=True,
            truncation=True,
            max_length=max_length
        )
        
        outputs = self.model.generate(
            **inputs,
            max_new_tokens=max_length,
            num_beams=3
        )
        
        return self.tokenizer.decode(outputs[0], skip_special_tokens=True)
    
    def translate(self, text, source="English", target="German"):
        """翻译任务"""
        task = f"translate {source} to {target}:"
        input_text = f"{task} {text}"
        
        inputs = self.tokenizer(input_text, return_tensors="pt")
        outputs = self.model.generate(**inputs)
        
        return self.tokenizer.decode(outputs[0], skip_special_tokens=True)
    
    def summarize(self, text):
        """摘要任务"""
        input_text = f"summarize: {text}"
        
        inputs = self.tokenizer(input_text, return_tensors="pt")
        outputs = self.model.generate(**inputs)
        
        return self.tokenizer.decode(outputs[0], skip_special_tokens=True)
    
    def question(self, question, context):
        """问答任务"""
        input_text = f"question: {question} context: {context}"
        
        inputs = self.tokenizer(input_text, return_tensors="pt")
        outputs = self.model.generate(**inputs)
        
        return self.tokenizer.decode(outputs[0], skip_special_tokens=True)


def demo():
    print("=== T5 演示 ===\n")
    
    # 加载模型
    model = T5Model("t5-small")
    
    # 翻译演示
    result = model.translate("Hello world")
    print(f"翻译: {result}")
    
    # 摘要演示
    text = "This is a long article about machine learning. It covers supervised learning, unsupervised learning, and reinforcement learning. Machine learning is a subset of artificial intelligence."
    summary = model.summarize(text)
    print(f"摘要: {summary}")
    
    return model


if __name__ == "__main__":
    demo()
```

## 7. 手工代码实现

### 7.1 T5 核心组件

```python
import torch
import torch.nn as nn
import math

class T5Embedding(nn.Module):
    """T5 嵌入"""
    
    def __init__(self, vocab_size, embed_dim):
        super().__init__()
        
        # 共享嵌入
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        
    def forward(self, x):
        return self.embedding(x)


class T5Encoder(nn.Module):
    """T5 编码器"""
    
    def __init__(self, num_layers, embed_dim, num_heads):
        super().__init__()
        
        self.layers = nn.ModuleList([
            T5EncoderLayer(embed_dim, num_heads)
            for _ in range(num_layers)
        ])
        
    def forward(self, x, mask=None):
        for layer in self.layers:
            x = layer(x, mask)
        return x


class T5Decoder(nn.Module):
    """T5 解码器"""
    
    def __init__(self, num_layers, embed_dim, num_heads):
        super().__init__()
        
        self.layers = nn.ModuleList([
            T5DecoderLayer(embed_dim, num_heads)
            for _ in range(num_layers)
        ])
        
    def forward(self, x, encoder_output, mask=None, enc_mask=None):
        for layer in self.layers:
            x = layer(x, encoder_output, mask, enc_mask)
        return x


def demo():
    print("=== T5 手工实现演示 ===\n")
    print(f"架构: Encoder-Decoder")
    print(f"任务: 文本→文本")
    print(f"优势: 统一框架")


if __name__ == "__main__":
    demo()
```

## 8. 优缺点分析

### 8.1 优点

1. **统一框架**：所有 NLP 任务
2. **多任务学习**：共享参数
3. **可扩展**：任意任务

### 8.2 缺点

1. **输入格式**：需要特殊前缀
2. **推理速度**：逐 token 生成
3. **显存需求**：Encoder-Decoder 大

### 8.3 改进版本

- **T5.1.1**：改进训练
- **mT5**：多语言版本
- **FLAN-T5**：指令微调
