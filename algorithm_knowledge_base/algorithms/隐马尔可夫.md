# 隐马尔可夫模型 学习文档

> 用于建模时间序列数据的统计模型，包含隐藏状态序列和可观测输出序列

---

## 1. 算法基础认知

### 一句话定义
隐马尔可夫模型（HMM）是一种统计模型，用于描述含有隐含未知参数的马尔可夫过程，通过可观测序列推断隐藏状态序列。

### 直觉类比
想象一个朋友每天根据天气（隐藏状态：晴天、雨天）选择活动（观测：散步、购物、清洁）。你只能看到他每天的活动，但想推断天气情况。HMM就是你用来根据观测序列推断隐藏天气序列的工具。

### 历史背景
HMM由Leonard E. Baum等人在1960年代提出，最早用于语音识别。1980年代，HMM成为语音识别的主流模型，后来扩展到生物信息学（如基因预测）、自然语言处理等领域。

### 算法定位
- 类型：有监督/无监督学习 → 序列建模、状态推断
- 输出：隐藏状态序列、观测概率、模型参数
- 模型类型：生成模型、时序模型

### 前置知识
- 概率论基础：条件概率、联合概率、贝叶斯定理
- 马尔可夫链：马尔可夫性质（无记忆性）
- 概率图模型：有向图、条件独立性
- 期望最大化（EM）算法思想
- Python基础：NumPy、动态规划

## 2. 核心原理

### 2.1 核心思想
HMM的核心思想是：**观测序列是由隐藏的马尔可夫链生成，每个隐藏状态产生一个观测，通过观测序列推断最可能状态序列**。

HMM由以下要素组成：
1. **隐藏状态集合** $Q = \{q_1, q_2, ..., q_N\}$，状态数为 $N$
2. **观测集合** $V = \{v_1, v_2, ..., v_M\}$，观测数为 $M$
3. **状态转移概率矩阵** $A = [a_{ij}]$，其中 $a_{ij} = P(s_{t+1}=q_j | s_t=q_i)$
4. **观测概率矩阵** $B = [b_j(k)]$，其中 $b_j(k) = P(o_t=v_k | s_t=q_j)$
5. **初始状态分布** $\pi_i = P(s_1=q_i)$

### 2.2 工作流程

1. **模型定义**
   - 输入：观测序列 $O = (o_1, o_2, ..., o_T)$，可能的状态数 $N$
   - 确定模型参数 $\lambda = (A, B, \pi)$，或需要学习它们

2. **三个基本问题**
   - **概率计算问题**：给定模型 $\lambda$ 和观测序列 $O$，计算 $P(O|\lambda)$（前向-后向算法）
   - **学习问题**：给定观测序列 $O$，估计模型参数 $\lambda$ 使得 $P(O|\lambda)$ 最大（Baum-Welch算法，即EM）
   - **解码问题**：给定模型 $\lambda$ 和观测序列 $O$，找到最可能的状态序列（Viterbi算法）

3. **模型应用**
   - 使用Viterbi算法进行状态解码
   - 使用Baum-Welch算法进行参数学习（无监督）
   - 计算观测序列概率（评估模型好坏）

### 2.3 关键概念解释

- **隐藏状态**：不可直接观测的状态序列，服从马尔可夫链
- **观测值**：每个状态下产生的可观测输出
- **齐次马尔可夫假设**：状态转移概率与时间无关，只与当前状态有关
- **观测独立性假设**：观测只依赖于当前状态，与历史无关
- **前向概率** $\alpha_t(i)$：时刻 $t$ 处于状态 $q_i$ 且观测到 $o_1, o_2, ..., o_t$ 的概率
- **后向概率** $\beta_t(i)$：时刻 $t$ 处于状态 $q_i$ 的条件下，从 $t+1$ 到 $T$ 的观测序列概率

### 2.4 有机/直观解释
想象一个病人在就诊，他的真实健康状态（健康、感冒、发烧）是隐藏的，医生只能看到症状（咳嗽、发烧、正常）。HMM就是医生用来根据症状序列推断健康状态序列的模型。隐藏状态（健康状态）之间的转移遵循马尔可夫链，每种健康状态会产生不同的症状概率。

从时序角度看，HMM在自然语言处理中常用于词性标注：隐藏状态是词性（名词、动词等），观测是单词，通过单词序列推断最可能的词性序列。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 | 维度/类型 |
|------|------|----------|
| $N$ | 隐藏状态数量 | 标量 |
| $M$ | 观测符号数量 | 标量 |
| $T$ | 观测序列长度 | 标量 |
| $Q$ | 隐藏状态集合 | $\{q_1, ..., q_N\}$ |
| $V$ | 观测集合 | $\{v_1, ..., v_M\}$ |
| $A$ | 状态转移概率矩阵 | $N \times N$ |
| $B$ | 观测概率矩阵 | $N \times M$ |
| $\pi$ | 初始状态分布 | $N \times 1$ |
| $O$ | 观测序列 | $(o_1, o_2, ..., o_T)$ |
| $s_t$ | 时刻 $t$ 的状态 | $q_i \in Q$ |
| $o_t$ | 时刻 $t$ 的观测 | $v_k \in V$ |
| $\alpha_t(i)$ | 前向概率 | 标量 |
| $\beta_t(i)$ | 后向概率 | 标量 |

### 3.2 问题形式化
HMM有三个经典问题：

**问题1：概率计算**
给定模型 $\lambda = (A, B, \pi)$ 和观测序列 $O = (o_1, o_2, ..., o_T)$，计算概率 $P(O|\lambda)$。

**问题2：学习问题**
给定观测序列 $O$，调整模型参数 $\lambda = (A, B, \pi)$ 使得 $P(O|\lambda)$ 最大。

**问题3：解码问题**
给定模型 $\lambda$ 和观测序列 $O$，找到最优状态序列 $S^* = (s_1^*, s_2^*, ..., s_T^*)$ 使得 $P(S^*|O, \lambda)$ 最大。

### 3.3 目标函数/损失函数
对于学习问题，HMM使用**极大似然估计**：

$$\max_{\lambda} P(O|\lambda) = \max_{\lambda} \sum_{S} P(O, S|\lambda)$$

其中 $S$ 是所有可能的状态序列。由于直接最大化困难，使用EM算法（Baum-Welch算法）迭代优化。

### 3.4 推导过程

**前向算法（Forward Algorithm）**

定义前向概率：
$$\alpha_t(i) = P(o_1, o_2, ..., o_t, s_t = q_i | \lambda)$$

递推公式：
1. 初始化：$\alpha_1(i) = \pi_i b_i(o_1), \quad i=1,2,...,N$
2. 递推：对于 $t=1,2,...,T-1$,
   $$\alpha_{t+1}(j) = \left[ \sum_{i=1}^{N} \alpha_t(i) a_{ij} \right] b_j(o_{t+1}), \quad j=1,2,...,N$$
3. 终止：$P(O|\lambda) = \sum_{i=1}^{N} \alpha_T(i)$

**后向算法（Backward Algorithm）**

定义后向概率：
$$\beta_t(i) = P(o_{t+1}, o_{t+2}, ..., o_T | s_t = q_i, \lambda)$$

递推公式：
1. 初始化：$\beta_T(i) = 1, \quad i=1,2,...,N$
2. 递推：对于 $t=T-1, T-2, ..., 1$,
   $$\beta_t(i) = \sum_{j=1}^{N} a_{ij} b_j(o_{t+1}) \beta_{t+1}(j), \quad i=1,2,...,N$$

**Viterbi算法（解码）**

定义 $\delta_t(i)$：时刻 $t$ 到达状态 $q_i$ 的最大概率路径的概率：
$$\delta_t(i) = \max_{s_1, s_2, ..., s_{t-1}} P(s_1, s_2, ..., s_{t-1}, s_t=q_i, o_1, o_2, ..., o_t | \lambda)$$

递推：
1. 初始化：$\delta_1(i) = \pi_i b_i(o_1), \quad \psi_1(i) = 0$
2. 递推：对于 $t=2,3,...,T$,
   $$\delta_t(j) = \max_{1 \leq i \leq N} [\delta_{t-1}(i) a_{ij}] \cdot b_j(o_t)$$
   $$\psi_t(j) = \arg\max_{1 \leq i \leq N} [\delta_{t-1}(i) a_{ij}]$$
3. 终止：$P^* = \max_{1 \leq i \leq N} \delta_T(i), \quad s_T^* = \arg\max_{1 \leq i \leq N} \delta_T(i)$
4. 回溯：$s_t^* = \psi_{t+1}(s_{t+1}^*), \quad t=T-1, T-2, ..., 1$

**Baum-Welch算法（EM for HMM）**

E步：计算期望：
$$\xi_t(i,j) = P(s_t=q_i, s_{t+1}=q_j | O, \lambda) = \frac{\alpha_t(i) a_{ij} b_j(o_{t+1}) \beta_{t+1}(j)}{P(O|\lambda)}$$
$$\gamma_t(i) = P(s_t=q_i | O, \lambda) = \sum_{j=1}^{N} \xi_t(i,j) = \frac{\alpha_t(i) \beta_t(i)}{P(O|\lambda)}$$

M步：重新估计参数：
$$\bar{\pi}_i = \gamma_1(i)$$
$$\bar{a}_{ij} = \frac{\sum_{t=1}^{T-1} \xi_t(i,j)}{\sum_{t=1}^{T-1} \gamma_t(i)}$$
$$\bar{b}_j(k) = \frac{\sum_{t=1}^{T} \gamma_t(j) \cdot I(o_t=v_k)}{\sum_{t=1}^{T} \gamma_t(j)}$$

### 3.5 最终解/算法步骤

**Viterbi算法**（解码问题）：

```
输入：模型 λ=(A,B,π)，观测序列 O=(o₁,...,oₜ)
输出：最优状态序列 S*=(s₁*,...,sₜ*)

1. 初始化：
   δ₁(i) = πᵢ bᵢ(o₁), i=1,...,N
   ψ₁(i) = 0

2. 递推（对 t=2,...,T）：
   δₜ(j) = maxᵢ [δₜ₋₁(i) aᵢⱼ] · bⱼ(oₜ)
   ψₜ(j) = arg maxᵢ [δₜ₋₁(i) aᵢⱼ]

3. 终止：
   P* = maxᵢ δₜ(i)
   sₜ* = arg maxᵢ δₜ(i)

4. 回溯（对 t=T-1,...,1）：
   sₜ* = ψₜ₊₁(sₜ₊₁*)

5. 返回 S*
```

## 4. 训练过程讲解

### 4.1 数据预处理

```python
import numpy as np
from hmmlearn import hmm
import matplotlib.pyplot as plt

# ============================================
# 示例数据：模拟天气和活动
# ============================================
# 隐藏状态：0=晴天，1=雨天
# 观测：0=散步，1=购物，2=清洁

# 生成模拟数据
np.random.seed(42)
n_samples = 100
# 真实参数（用于生成数据）
true_transmat = np.array([[0.7, 0.3],  # 晴天->晴天，晴天->雨天
                          [0.4, 0.6]]) # 雨天->晴天，雨天->雨天
true_emission = np.array([[0.6, 0.3, 0.1],  # 晴天：散步/购物/清洁
                           [0.1, 0.4, 0.5]]) # 雨天：散步/购物/清洁
true_startprob = np.array([0.6, 0.4])  # 初始状态分布

# 生成状态序列和观测序列
states = np.zeros(n_samples, dtype=int)
observations = np.zeros(n_samples, dtype=int)
states[0] = np.random.choice(2, p=true_startprob)
observations[0] = np.random.choice(3, p=true_emission[states[0]])

for t in range(1, n_samples):
    states[t] = np.random.choice(2, p=true_transmat[states[t-1]])
    observations[t] = np.random.choice(3, p=true_emission[states[t]])

print(f"生成了 {n_samples} 个观测")
print(f"状态序列（前10个）: {states[:10]}")
print(f"观测序列（前10个）: {observations[:10]}")

# HMM学习需要观测序列是二维数组（样本数，特征数=1）
X = observations.reshape(-1, 1)
lengths = [n_samples]  # 一个长序列
```

预处理要点：
1. **序列数据**：HMM输入是序列，需要保持时序关系
2. **观测编码**：通常需要将观测符号编码为整数（0到M-1）
3. **多序列**：HMM可以处理多个独立序列，`lengths`参数指定每个序列长度
4. **初始化**：需要指定状态数N，观测数M（或自动推断）

### 4.2 参数初始化

```python
def initialize_hmm_params(n_states, n_observations):
    """
    随机初始化HMM参数
    
    参数:
        n_states: 隐藏状态数
        n_observations: 观测符号数
    
    返回:
        startprob: 初始状态分布 (n_states,)
        transmat: 状态转移矩阵 (n_states, n_states)
        emissionprob: 观测概率矩阵 (n_states, n_observations)
    """
    # 1. 初始状态分布（随机，确保和为1）
    startprob = np.random.rand(n_states)
    startprob = startprob / startprob.sum()
    
    # 2. 状态转移矩阵（每行和为1）
    transmat = np.random.rand(n_states, n_states)
    transmat = transmat / transmat.sum(axis=1, keepdims=True)
    
    # 3. 观测概率矩阵（每行和为1）
    emissionprob = np.random.rand(n_states, n_observations)
    emissionprob = emissionprob / emissionprob.sum(axis=1, keepdims=True)
    
    return startprob, transmat, emissionprob
```

初始化方法：
1. **随机初始化**：如上，随机生成并归一化
2. **均匀初始化**：所有概率均匀分配
3. **K-Means初始化**：用K-Means对观测聚类初始化状态
4. **使用先验知识**：如果有领域知识，可以手动设置

### 4.3 迭代过程（Baum-Welch算法）

```python
def baum_welch_iteration(X, lengths, startprob, transmat, emissionprob, n_iter=100):
    """
    Baum-Welch算法（EM for HMM），简化版
    
    注意：实际应用中建议使用hmmlearn等库，这里仅为演示原理
    """
    n_states = transmat.shape[0]
    n_samples = len(X)
    
    # 前向-后向算法（实际需要实现）
    # 这里简化，假设我们已经有了hmmlearn的模型
    from hmmlearn import hmm
    
    model = hmm.MultinomialHMM(n_components=n_states, n_iter=n_iter, random_state=42)
    model.startprob_ = startprob.copy()
    model.transmat_ = transmat.copy()
    model.emissionprob_ = emissionprob.copy()
    
    # 使用hmmlearn的fit方法（已实现Baum-Welch）
    model.fit(X, lengths)
    
    return model

# 初始化参数
```

### 4.4 收敛条件

Baum-Welch算法收敛条件：
1. **对数似然变化很小**：$|\log P(O|\lambda^{(k+1)}) - \log P(O|\lambda^{(k)})| < \epsilon$
2. **参数变化很小**：$\| \lambda^{(k+1)} - \lambda^{(k)} \| < \epsilon$
3. **达到最大迭代次数**

```python
def check_convergence(log_likelihoods, tol=1e-4):
    """
    检查是否收敛
    """
    if len(log_likelihoods) < 2:
        return False
    return abs(log_likelihoods[-1] - log_likelihoods[-2]) < tol
```

| `n_components` | 隐藏状态数 N | 取决于问题（2~10） | 必须指定 |

4. **观测模型**：MultinomialHMM（离散观测）、GaussianHMM（连续观测）

## 5. 应用场景

### 5.1 典型应用

**应用1：词性标注（Part-of-Speech Tagging）**
- 场景：给定单词序列，标注每个单词的词性（名词、动词等）
- 为什么适合：单词是观测，词性是隐藏状态，符合HMM假设
- 实现：使用监督学习（已知状态和观测）或无监督学习（Baum-Welch）

**应用2：语音识别**
- 场景：将声学信号转换为文字
- 为什么适合：声音特征序列是观测，音素或单词是隐藏状态
- 实现：使用连续HMM（GaussianHMM）对声学特征建模

**应用3：基因预测**
- 场景：根据DNA序列预测基因区域（外显子、内含子）
- 为什么适合：DNA碱基是观测，基因区域类型是隐藏状态
- 实现：使用离散HMM，DNA碱基作为观测

### 5.2 适用数据特征

1. **时序数据**：数据具有顺序关系，时间步之间有依赖
2. **隐藏状态**：存在不可直接观测的状态，但能影响观测
3. **马尔可夫性**：当前状态只依赖于前一个状态（一阶马尔可夫）
4. **观测独立性**：观测只依赖于当前状态，与历史无关
5. **中等规模状态空间**：状态数N不能太大，否则计算复杂

### 5.3 不适用场景

1. **非时序数据**：数据点之间没有顺序关系 → 使用其他模型
2. **长程依赖**：当前状态依赖于很久之前的状态 → 使用RNN、LSTM
3. **状态数太多**：计算复杂度 $O(T \cdot N^2)$ 随N平方增长
4. **观测依赖历史**：当前观测依赖于多个过去状态 → HMM假设不满足
5. **需要判别模型**：HMM是生成模型，判别任务可能不如CRF

## 6. 优缺点分析

### 6.1 优点

| 优点 | 说明 | 成立条件 |
|------|------|----------|
| 建模时序数据 | 自然地建模状态间的转移和观测生成 | 数据具有时序结构 |
| 无监督学习 | Baum-Welch算法可以从无标注数据学习 | 有足够的观测数据 |
| 概率框架 | 提供概率解释，可以计算似然 | 通用 |
| 解码高效 | Viterbi算法 $O(T \cdot N^2)$ 找到最优序列 | 通用 |
| 灵活 | 可以处理离散/连续观测，多序列 | 选择合适的观测模型 |

### 6.2 缺点

| 缺点 | 说明 | 缓解方法 |
|------|------|----------|
| 齐次马尔可夫假设 | 转移概率不随时间变化，现实中可能不成立 | 使用非齐次HMM或更高阶 |
| 观测独立性假设 | 观测只依赖于当前状态，限制性强 | 使用更灵活的观测模型 |
| 局部最优 | Baum-Welch是EM算法，可能陷入局部最优 | 多次随机初始化，选最好 |
| 状态数需要预先指定 | 实际中往往不知道正确状态数 | 使用模型选择准则（AIC/BIC） |
| 计算复杂度 | $O(T \cdot N^2)$，对大状态数慢 | 使用更高效的实现或近似 |

```python
import numpy as np
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import numpy as np

class HMMManual:
    """
    手动实现的隐马尔可夫模型（离散观测）
    实现Viterbi算法进行解码
    """
    
    def __init__(self, n_states, n_observations, random_state=None):
        """
        初始化HMM
        
        参数:
            n_states: 隐藏状态数
            n_observations: 观测符号数
            random_state: 随机种子
        """
        if random_state is not None:
            np.random.seed(random_state)
            
        self.n_states = n_states
        self.n_observations = n_observations
        
        # 初始化参数
        # 初始状态分布
        self.startprob_ = np.random.rand(n_states)
        self.startprob_ = self.startprob_ / self.startprob_.sum()
        
        # 状态转移矩阵
        self.transmat_ = np.random.rand(n_states, n_states)
        self.transmat_ = self.transmat_ / self.transmat_.sum(axis=1, keepdims=True)
        
        # 观测概率矩阵
        self.emissionprob_ = np.random.rand(n_states, n_observations)
        self.emissionprob_ = self.emissionprob_ / self.emissionprob_.sum(axis=1, keepdims=True)
        
    def _observation_prob(self, state, observation):
        """
        计算在给定状态下观测到特定符号的概率
        """
        return self.emissionprob_[state, observation]
    
    def viterbi(self, observations):
        """
        Viterbi算法：找到最可能的状态序列
        
        参数:
            observations: 观测序列，每个元素是观测符号的索引 (0到M-1)
            
        返回:
            log_prob: 最优路径的对数概率
            state_sequence: 最优状态序列
        """
        T = len(observations)
        N = self.n_states
        
        # delta[t, i]: 时刻t到达状态i的最大对数概率
        delta = np.zeros((T, N))
        # psi[t, i]: 时刻t到达状态i的路径中，t-1时刻的状态
        psi = np.zeros((T, N), dtype=int)
        
        # 1. 初始化
        for i in range(N):
            delta[0, i] = np.log(self.startprob_[i]) + np.log(self._observation_prob(i, observations[0]))
        
        # 2. 递推
        for t in range(1, T):
            for j in range(N):
                # 计算所有可能的前序状态i的得分
                scores = np.zeros(N)
                for i in range(N):
                    scores[i] = delta[t-1, i] + np.log(self.transmat_[i, j]) + \
                                np.log(self._observation_prob(j, observations[t]))
                
                delta[t, j] = np.max(scores)
                psi[t, j] = np.argmax(scores)
        
        # 3. 终止
        log_prob = np.max(delta[T-1, :])
        last_state = np.argmax(delta[T-1, :])
        
        # 4. 回溯
        state_sequence = np.zeros(T, dtype=int)
        state_sequence[T-1] = last_state
        for t in range(T-2, -1, -1):
            state_sequence[t] = psi[t+1, state_sequence[t+1]]
        
        return log_prob, state_sequence
    
    def forward(self, observations):
        """
        前向算法：计算P(O|lambda)
        """
        T = len(observations)
        N = self.n_states
        
        # alpha[t, i]: 前向概率
        alpha = np.zeros((T, N))
        
        # 初始化
        for i in range(N):
            alpha[0, i] = self.startprob_[i] * self._observation_prob(i, observations[0])
        
        # 递推
        for t in range(1, T):
            for j in range(N):
                alpha[t, j] = np.sum(alpha[t-1, :] * self.transmat_[:, j]) * \
                            self._observation_prob(j, observations[t])
        
        # 终止
        prob = np.sum(alpha[T-1, :])
        return prob, alpha
    
    def predict(self, X):
        """
        预测状态序列（对多个序列）
        """
        # X是二维数组，每行为一个观测
        # 假设是一个序列
        observations = X.flatten()
        _, state_seq = self.viterbi(observations)
        return state_seq
```

## 10. 模型评估

```python
from sklearn.metrics import accuracy_score, confusion_matrix
import numpy as np

def evaluate_hmm(model, X, lengths, states_true=None):
    """
    评估HMM模型
    """
    print("=" * 60)
    print("HMM模型评估报告")
    print("=" * 60)
    
    # 1. 计算对数似然（模型对数据的拟合程度）
    log_likelihood = model.score(X, lengths)
    print(f"对数似然: {log_likelihood:.4f}")
    print(f"困惑度 (Perplexity): {np.exp(-log_likelihood/len(X)):.4f}")
    
    # 2. 解码状态并比较（如果有真实状态）
    if states_true is not None:
        states_pred = model.predict(X, lengths)
        
        # 注意：HMM有标签切换问题（状态0和1可能交换）
        # 简单对齐：尝试两种对齐方式，选最好的
        acc1 = accuracy_score(states_true, states_pred)
        acc2 = accuracy_score(states_true, 1 - states_pred)  # 切换标签
        
        if acc2 > acc1:
            states_pred = 1 - states_pred
            acc1 = acc2
        
        print(f"\n解码准确率: {acc1:.4f}")
        
        # 混淆矩阵
        cm = confusion_matrix(states_true, states_pred)
        print("\n混淆矩阵:")
        print("         预测")
        print("       状态0  状态1")
        print(f"真实 状态0 [{cm[0,0]:3d}, {cm[0,1]:3d}]")
        print(f"     状态1 [{cm[1,0]:3d}, {cm[1,1]:3d}]")
    
    # 3. 模型参数
    print(f"\n模型参数:")
    print(f"初始状态分布: {model.startprob_}")
    print(f"状态转移矩阵:\n{model.transmat_}")
    print(f"观测概率矩阵:\n{model.emissionprob_}")
    
    # 4. 检查随机矩阵性质
    print(f"\n参数检查:")
    print(f"初始分布和: {model.startprob_.sum():.6f}")
    print(f"转移矩阵每行的和: {model.transmat_.sum(axis=1)}")
    print(f"观测概率矩阵每行的和: {model.emissionprob_.sum(axis=1)}")
    
    return log_likelihood
```

## 11. 常见问题与易错点

### 11.1 解码状态与真实状态对不上（标签切换问题）
**原因**：HMM的状态标签是任意的，状态0和状态1可能交换。

**解决方案**：
```python
# 尝试两种对齐方式
states_pred = model.predict(X)
acc1 = accuracy_score(states_true, states_pred)
acc2 = accuracy_score(states_true, 1 - states_pred)

if acc2 > acc1:
    states_pred = 1 - states_pred
    print("状态标签已切换以对齐")
```

### 11.2 模型陷入局部最优，每次训练结果不同
**原因**：Baum-Welch算法（EM）对初始化敏感。

**解决方案**：
```python
# 多次初始化，选择最好的
best_model = None
best_score = -np.inf

for i in range(10):  # 尝试10次
    model = hmm.MultinomialHMM(n_components=2, n_iter=500, random_state=i)
    model.fit(X, lengths)
    score = model.score(X, lengths)
    
    if score > best_score:
        best_score = score
        best_model = model

print(f"最好对数似然: {best_score:.4f}")
```

### 11.3 状态数N不知道，如何选择？
**问题**：HMM需要预先指定状态数N，但实际中往往未知。

**解决方案**：
```python
# 使用BIC选择状态数
import numpy as np

bic_scores = []
n_states_range = range(2, 8)

for n in n_states_range:
    model = hmm.MultinomialHMM(n_components=n, n_iter=500, random_state=42)
    model.fit(X, lengths)
    log_likelihood = model.score(X, lengths)
    
    # BIC = -2 * log_likelihood + k * log(n_samples)
    k = n * (n-1) + n * 3 + (n-1)  # 参数数量（近似）
    bic = -2 * log_likelihood + k * np.log(len(X))
    bic_scores.append(bic)
    print(f"n_states={n}: BIC={bic:.4f}")

# 选择BIC最小的模型
best_n = n_states_range[np.argmin(bic_scores)]
print(f"\n最好状态数: {best_n}")
```

### 11.4 对数概率为-inf或计算溢出
**问题**：概率连乘导致下溢，或参数中有0导致log(0)。

**解决方案**：
1. **使用对数空间计算**：hmmlearn默认使用对数
2. **添加平滑**：避免概率为0
```python
# 在参数估计时添加平滑
model.emissionprob_ = (model.emissionprob_ * 0.9) + 0.01  # 平滑
model.emissionprob_ = model.emissionprob_ / model.emissionprob_.sum(axis=1, keepdims=True)
```

### 11.5 连续观测如何处理？
**问题**：上面的例子是离散观测，连续观测（如音频特征）需要处理。

**解决方案**：
```python
# 使用GaussianHMM（高斯观测模型）
```

## 12. 学习总结

### 核心要点回顾：
1. **两个序列**：隐藏状态序列（马尔可夫链）和观测序列
2. **三个问题**：概率计算（前向-后向）、学习（Baum-Welch）、解码（Viterbi）
3. **两个假设**：齐次马尔可夫性、观测独立性
4. **EM算法**：Baum-Welch是EM在HMM中的应用
5. **概率框架**：完全的概率生成模型

### 从HMM到更先进的模型：
```
HMM (隐马尔可夫模型)
    ↓
MEMM (最大熵马尔可夫模型) - 判别式，更灵活
    ↓
CRF (条件随机场) - 判别模型，考虑整个观测序列
    ↓
RNN/LSTM - 神经网络处理序列，捕捉长程依赖
    ↓
Transformer - 注意力机制，并行处理序列
```

### 实践建议：
1. **确定状态数**：使用BIC、AIC或领域知识
2. **多次初始化**：避免局部最优
3. **选择合适的观测模型**：离散用MultinomialHMM，连续用GaussianHMM
4. **注意标签切换**：比较解码结果时考虑状态对齐
5. **检查收敛**：监控对数似然变化

### 练习题

**习题1：基础计算**
问题：一个HMM有2个状态（晴天=0，雨天=1），3个观测（散步=0，购物=1，清洁=2）。已知：
- 初始分布：$\pi = [0.6, 0.4]$
- 转移矩阵：$A = \begin{bmatrix} 0.7 & 0.3 \\ 0.4 & 0.6 \end{bmatrix}$
- 观测矩阵：$B = \begin{bmatrix} 0.6 & 0.3 & 0.1 \\ 0.1 & 0.4 & 0.5 \end{bmatrix}$

观测序列为散步、散步、购物。计算该序列的概率 $P(O|\lambda)$（使用前向算法）。

<details>
<summary>答案</summary>

使用前向算法：

**初始化**：
$\alpha_1(0) = \pi_0 \cdot b_0(o_1) = 0.6 \times 0.6 = 0.36$
$\alpha_1(1) = \pi_1 \cdot b_1(o_1) = 0.4 \times 0.1 = 0.04$

**递推**：
时刻2，观测 $o_2 = 0$（散步）：
$\alpha_2(0) = [\alpha_1(0) \times a_{00} + \alpha_1(1) \times a_{10}] \times b_0(o_2)$
$= [0.36 \times 0.7 + 0.04 \times 0.4] \times 0.6$
$= [0.252 + 0.016] \times 0.6 = 0.268 \times 0.6 = 0.1608$

$\alpha_2(1) = [\alpha_1(0) \times a_{01} + \alpha_1(1) \times a_{11}] \times b_1(o_2)$
$= [0.36 \times 0.3 + 0.04 \times 0.6] \times 0.1$
$= [0.108 + 0.024] \times 0.1 = 0.132 \times 0.1 = 0.0132$

时刻3，观测 $o_3 = 1$（购物）：
$\alpha_3(0) = [\alpha_2(0) \times a_{00} + \alpha_2(1) \times a_{10}] \times b_0(o_3)$
$= [0.1608 \times 0.7 + 0.0132 \times 0.4] \times 0.3$
$= [0.11256 + 0.00528] \times 0.3 = 0.11784 \times 0.3 = 0.035352$

$\alpha_3(1) = [\alpha_2(0) \times a_{01} + \alpha_2(1) \times a_{11}] \times b_1(o_3)$
$= [0.1608 \times 0.3 + 0.0132 \times 0.6] \times 0.4$
$= [0.04824 + 0.00792] \times 0.4 = 0.05616 \times 0.4 = 0.022464$

**终止**：
$P(O|\lambda) = \alpha_3(0) + \alpha_3(1) = 0.035352 + 0.022464 = 0.057816$

因此，序列（散步，散步，购物）的概率约为0.0578。
</details>

**习题2：编程实践**

**习题3：理论推导**
问题：推导Viterbi算法的递推公式。

<details>
<summary>答案</summary>

Viterbi算法寻找最优状态序列 $S^* = \arg\max_S P(S|O, \lambda)$。

根据贝叶斯定理，$P(S|O, \lambda) \propto P(O, S|\lambda)$。

所以：
$$S^* = \arg\max_S P(O, S|\lambda)$$

定义 $\delta_t(i) = \max_{s_1, ..., s_{t-1}} P(s_1, ..., s_{t-1}, s_t=q_i, o_1, ..., o_t|\lambda)$。

递推：
$$\delta_{t+1}(j) = \max_{s_1, ..., s_t} P(s_1, ..., s_t, s_{t+1}=q_j, o_1, ..., o_{t+1}|\lambda)$$
$$= \max_i [\delta_t(i) \cdot a_{ij}] \cdot b_j(o_{t+1})$$

并保存路径：$\psi_{t+1}(j) = \arg\max_i [\delta_t(i) \cdot a_{ij}]$。

最后，最优概率 $P^* = \max_i \delta_T(i)$，最优最后状态 $s_T^* = \arg\max_i \delta_T(i)$。

回溯得到完整序列：$s_t^* = \psi_{t+1}(s_{t+1}^*)$。
</details>

### 思考题

**思考题1**：HMM和马尔可夫链有什么区别？

<details>
<summary>答案</summary>

| 方面 | 马尔可夫链 | HMM |
|------|--------------|-----|
| 可观测性 | 状态可直接观测 | 状态隐藏，不可直接观测 |
| 观测 | 就是状态本身 | 每个状态产生一个观测 |
| 参数 | 只有转移矩阵和初始分布 | 还有观测概率矩阵 |
| 问题 | 预测下一个状态 | 从观测推断状态，学习参数 |
| 应用 | 简单时序预测 | 语音识别、词性标注等 |

核心区别：马尔可夫链的状态是可观测的，HMM的状态是隐藏的，只能观测到由状态生成的观测。
</details>

**思考题2**：HMM和CRF有什么区别？各适用什么场景？

<details>
<summary>答案</summary>

| 方面 | HMM | CRF |
|------|-----|-----|
| 模型类型 | 生成模型：$P(O, S)$ | 判别模型：$P(S|O)$ |
| 假设 | 观测独立性（给定状态） | 观测可以依赖整个序列 |
| 特征 | 只能用状态生成观测的概率 | 可以使用任意特征函数 |
| 训练 | EM算法（Baum-Welch） | 梯度下降（对数似然） |
| 全局最优 | 只能局部最优（EM） | 可以是凸优化（线性链CRF） |
| 适用场景 | 简单时序建模，数据量少 | 复杂时序标注，大数据 |

核心区别：HMM是生成模型，CRF是判别模型。CRF更灵活，可以建模观测之间的依赖，但训练更复杂。HMM更简单，适合传统任务。
</details>
