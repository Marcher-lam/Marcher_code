# 隐马尔可夫 学习文档

## 1. 算法基础认知
### 1.1 一句话定义
隐马尔可夫模型（Hidden Markov Model, HMM）是一个stateless序列生成模型，用于建模不可见的状态序列和可观测的输出序列之间的关系，广泛用于语音识别、自然语言处理等时序建模领域。

### 1.2 直觉类比
想象你在听一个人描述他口袋里的硬币状态，但他只能用"轻"或"重"来描述（观测）。由于硬币可能是多种面值的组合，你实际上看不到他具体有哪些硬币（隐藏状态），只能推断。HMM就是用来在这种"只能看到结果，推断隐藏原因"场景下进行建模和推断的经典方法。

### 1.3 历史背景
HMM由Baum在1960年代提出，最初用于语音识别。1970年代Rabiner将其系统化，现在已成为语音识别、基因序列分析、手势识别等领域的标准方法。

### 1.4 算法定位
- 类型：stateless序列生成模型
- 输出：序列概率、状态序列
- 模型类别：概率图模型

### 1.5 前置知识
- 概率论基础
- 贝叶斯定理
- Python 编程（NumPy）

## 2. 核心原理
### 2.1 核心思想
HMM的核心思想是：有一个"隐藏"的状态序列按马尔可夫链演化，每个状态产生一个可观测的输出。通过观测序列，可以推断隐藏状态序列（解码），或学习模型参数（学习）。

### 2.2 工作流程
1. **学习**：用Baum-Welch算法（EM）学习参数
2. **解码**：用Viterbi算法找最可能的状态序列
3. **评估**：用前向算法计算观测概率

### 2.3 关键概念解释
- **初始概率$\pi$**：$P(s_1 = i)$
- **转移概率$A$**：$P(s_{t+1}=j | s_t=i)$
- **发射概率$B$**：$P(o_t = v | s_t=i)$
- **前向算法**：计算观测概率
- **Viterbi算法**：解码最优路径

### 2.4 几何/直观解释
HMM可看作一个双层图：上层是隐藏状态（圆），下层是观测（方），转移概率连接状态，发射概率连接状态和观测。

## 3. 数学公式与推导
### 3.1 符号约定
| 符号 | 含义 |
|------|------|
| $S$ | 状态集合，$|S|=N$ |
| $O$ | 观测集合，$|O|=M$ |
| $A$ | 转移矩阵$N\times N$ |
| $B$ | 发射矩阵$N\times M$ |
| $\pi$ | 初始概率向量 |

### 3.2 问题形式化
给定观测序列 $O = (o_1, o_2, ..., o_T)$：

1. **评估**：计算 $P(O|\lambda)$
2. **解码**：找到最可能的状态序列 $S^*$
3. **学习**：更新参数 $\lambda = (\pi, A, B)$

### 3.3 目标函数/损失函数
**评估**：$P(O|\lambda) = \sum_S P(O|S,\lambda)P(S|\lambda)$

**解码**：$S^* = \arg\max_S P(S|O,\lambda)$

### 3.4 推导过程
**前向算法**：
$$\alpha_t(j) = P(o_1,...,o_t, s_t=j|\lambda)$$
$$\alpha_1(j) = \pi_j b_j(o_1)$$
$$\alpha_t(j) = \sum_i \alpha_{t-1}(i) a_{ij} b_j(o_t)$$

**Viterbi算法**（类似但用max）：
$$\delta_t(j) = \max_{s_1,...,s_{t-1}} P(s_1,...,s_{t-1}, o_1,...,o_{t-1}, s_t=j|\lambda)$$

### 3.5 最终解/算法步骤
**前向算法**：
```
α[j] = π[j] * B[j][o₁]
for t = 2 to T:
    for j in states:
        α[j] = B[j][o_t] * sum_i(α[i] * A[i][j])
return sum_j α[j]
```

**Viterbi算法**：
```
δ[j] = π[j] * B[j][o₁]
backpointers = []
for t = 2 to T:
    for j in states:
        δ[j], BP[j] = max_i(δ[i] * A[i][j]) * B[j][o_t]
    backpointers.append(BP)
回溯得到最优状态序列
```

## 4. 训练过程讲解
### 4.1 数据预处理
观测和状态编码为整数索引。

### 4.2 参数初始化
- 初始概率：均匀或随机
- 转移概率：均匀
- 发射概率：从数据估计

### 4.3 迭代过程
**Baum-Welch（EM算法）**：
```
E步：用前向后向计算γ_t(i)和ξ_t(i,j)
M步：更新参数最大化期望似然
重复直到收敛
```

### 4.4 收敛条件
- 对数似然变化小于阈值
- 最大迭代次数

### 4.5 超参数及推荐范围
- 状态数N：5-20
- 最大迭代：100
- 收敛阈值：1e-4

## 5. 应用场景
### 5.1 典型应用

### 5.2 适用数据特征

- 有隐藏状态

### 5.3 不适用场景

## 6. 优缺点分析
### 6.1 优点
- 理论基础扎实
- 计算效率高
- 可解释性强

### 6.2 缺点
- 马尔可夫假设限制
- 状态数指数爆炸

```python
import numpy as np
import matplotlib.pyplot as plt
from hmmlearn import hmm
import warnings
warnings.filterwarnings('ignore')

class SimpleHMM:
    """简化版HMM实现"""
    def __init__(self, n_states, n_observations):
        self.n_states = n_states
        self.n_obs = n_observations
        
        self.startprob = np.ones(n_states) / n_states
        self.transmat = np.ones((n_states, n_states)) / n_states
        self.emissionmat = np.ones((n_states, n_observations)) / n_observations
    
    def forward(self, observations):
        """前向算法"""
        T = len(observations)
        alpha = self.startprob * self.emissionmat[:, observations[0]]
        
        for t in range(1, T):
            alpha = self.emissionmat[:, observations[t]] * (alpha @ self.transmat)
        
        return np.sum(alpha)
    
    def viterbi(self, observations):
        """Viterbi算法"""
        T = len(observations)
        n_states = self.n_states
        
        V = np.zeros((T, n_states))
        bp = np.zeros((T, n_states), dtype=int)
        
        V[0] = self.startprob * self.emissionmat[:, observations[0]]
        
        for t in range(1, T):
            for j in range(n_states):
                probs = V[t-1] * self.transmat[:, j] * self.emissionmat[j, observations[t]]
                V[t, j] = np.max(probs)
                bp[t, j] = np.argmax(probs)
        
        states = np.zeros(T, dtype=int)
        states[-1] = np.argmax(V[-1])
        
        for t in range(T-2, -1, -1):
            states[t] = bp[t+1, states[t+1]]
        
        return states
    
    def fit(self, X, max_iter=100, tol=1e-4):
        """简化的Baum-Welch（EM）"""
        n_samples = len(X)
        
        for iteration in range(max_iter):
            old_prob = sum(self.forward(x) for x in X)
            
            gamma_sum = np.zeros(self.n_states)
            xi_sum = np.zeros((self.n_states, self.n_states))
            
            for x in X:
                T = len(x)
                alpha = np.zeros((T, self.n_states))
                beta = np.zeros((T, self.n_states))
                gamma = np.zeros((T, self.n_states))
                
                alpha[0] = self.startprob * self.emissionmat[:, x[0]]
                for t in range(1, T):
                    alpha[t] = self.emissionmat[:, x[t]] * (alpha[t-1] @ self.transmat)
                
                beta[-1] = 1
                for t in range(T-2, -1, -1):
                    beta[t] = (beta[t+1] * self.emissionmat[:, x[t+1]]) @ self.transmat.T
                
                gamma = alpha * beta
                gamma = gamma / (gamma.sum(axis=1, keepdims=True) + 1e-8)
                
                gamma_sum += gamma.sum(axis=0)
                
                for t in range(T-1):
                    xi = np.outer(alpha[t], beta[t+1] * self.emissionmat[:, x[t+1]]) * self.transmat
                    xi_sum += xi / (xi.sum() + 1e-8)
            
            self.startprob = gamma_sum[0] / (gamma_sum.sum() + 1e-8)
            self.transmat = xi_sum / (xi_sum.sum(axis=1, keepdims=True) + 1e-8)
            self.emissionmat = np.zeros((self.n_states, self.n_obs))
            for x in X:
                T = len(x)
                alpha = self.startprob * self.emissionmat[:, x[0]]
                for t in range(1, T):
                    alpha = self.emissionmat[:, x[t]] * (alpha @ self.transmat)
                alpha = alpha / (alpha.sum() + 1e-8)
                
                for t in range(T):
                    self.emissionmat[:, x[t]] += alpha
            
            self.emissionmat = self.emissionmat / (self.emissionmat.sum(axis=1, keepdims=True) + 1e-8)
            
            new_prob = sum(self.forward(x) for x in X)
            if abs(new_prob - old_prob) < tol:
                break
        
        return self

def generate_hmm_data(n_states=3, n_obs=5, length=100, n_seq=10):
    """生成HMM示例数据"""
    np.random.seed(42)
    transmat = np.random.rand(n_states, n_states)
    transmat = transmat / transmat.sum(axis=1, keepdims=True)
    
    emissionmat = np.random.rand(n_states, n_obs)
    emissionmat = emissionmat / emissionmat.sum(axis=1, keepdims=True)
    
    startprobs = np.random.rand(n_states)
    startprobs = startprobs / startprobs.sum()
    
    sequences = []
    state_seqs = []
    
    for _ in range(n_seq):
        states = [np.random.choice(n_states, p=startprobs)]
        obs = [np.random.choice(n_obs, p=emissionmat[states[0]]]
        
        for _ in range(length):
            new_state = np.random.choice(n_states, p=transmat[states[-1]])
            new_obs = np.random.choice(n_obs, p=emissionmat[new_state])
            states.append(new_state)
            obs.append(new_obs)
        
        sequences.append(obs)
        state_seqs.append(states)
    
    return sequences, transmat, emissionmat, startprobs

def simple_example():
    """简单示例"""
    obs_seq = [0, 1, 1, 0, 2, 1, 0, 2, 2, 0]
    
    hmm = SimpleHMM(n_states=2, n_observations=3)
    hmm.fit([obs_seq], max_iter=50)
    
    states = hmm.viterbi(obs_seq)
    prob = hmm.forward(obs_seq)
    
    print(f"Observations: {obs_seq}")
    print(f"Decoded states: {states}")
    print(f"Probability: {prob:.6f}")
    print(f"Transition matrix:\n{hmm.transmat}")
    print(f"Emission matrix:\n{hmm.emissionmat}")

def example_speech():
    """语音识别简化示例"""
    np.random.seed(123)
    
    sequences, true_A, true_B, true_pi = generate_hmm_data(n_states=3, n_obs=6, length=50, n_seq=5)
    
    model = hmm.MultinomialHMM(n_components=3, n_iter=100)
    model.fit(np.array(sequences[0]).reshape(-1, 1))
    
    predictions = model.predict(np.array(sequences[0]).reshape(-1, 1))
    
    plt.figure(figsize=(12, 4))
    plt.subplot(1, 2, 1)
    plt.plot(sequences[0], label='Observations')
    plt.xlabel('Time')
    plt.ylabel('Observation')
    plt.title('Observation Sequence')
    
    plt.subplot(1, 2, 2)
    plt.plot(predictions, label='Predicted States')
    plt.xlabel('Time')
    plt.ylabel('State')
    plt.title('Decoded States')
    plt.tight_layout()
    plt.show()

if __name__ == "__main__":
    simple_example()
    example_speech()
```

## 12. 学习总结
### 12.1 核心要点回顾
- HMM是双层马尔可夫模型
- 前向算法求观测概率
- Viterbi算法解码最优路径
- Baum-Welch学习参数

### 12.2 关键公式汇总
$$\alpha_t(j) = b_j(o_t) \sum_i \alpha_{t-1}(i) a_{ij}$$

$$S^* = \arg\max_s \prod_t P(s_t|s_{t-1})P(o_t|s_t)$$

### 12.3 与前序/后续算法联系
- 前置：马尔可夫链
- 同级：CRF
- 进阶：RNN/LSTM
