# 可解释性注意力学习文档

> 可解释性注意力（Interpretable Attention）是深度学习中通过可视化、分析注意力权重来理解模型决策过程的技术，是打开深度学习"黑盒"的重要窗口

---

## 1. 算法基础认知

### 1.1 一句话定义

**可解释性注意力**指的是通过分析Transformer等模型中注意力权重的分布模式、可视化热力图、计算注意力统计量等方式理解模型的内部工作机制，使深度学习模型的决策过程变得可解释、可理解。

### 1.2 经典类比

| 类比 | 解释 |
|------|------|
| 聚光灯 | 注意力就像聚光灯，照亮输入中当前token需要关注的部分 |
| 软通道 | 注意力权重在多个"通道"（头）间分配，每个通道关注不同信息 |
| 概率分布 | 注意力权重本质上是对所有位置的概率分布，表示"关注强度" |

## 2. 核心原理

### 2.1 注意力机制回顾

Scaled Dot-Product Attention的定义：
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

对于Multi-Head Attention：
$$\text{MHA}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O$$

其中每个头：
$$\text{head}_i = \text{Attention}(QW_i^Q, KW_i^KV, VW_i^V)$$

### 2.2 注意力权重分析

**注意力矩阵** $A \in \mathbb{R}^{L \times L}$（L是序列长度）：
$$A_{i,j} = \text{softmax}\left(\frac{q_i^T k_j}{\sqrt{d_k}}\right)$$

$A_{i,j}$表示位置i的位置j的注意力权重。

**关键统计量**：

| 统计量 | 公式 | 含义 |
|--------|------|------|
| 集中度 | $C_i = \sum_j A_{i,j}^2$ | 注意力的集中程度 |
| 熵 | $H_i = -\sum_j A_{i,j}\log A_{i,j}$ | 注意力分布的不确定性 |
| 峰值位置 | $p_i = \arg\max_j A_{i,j}$ | 最关注的位置 |
| 有效宽度 | $w_i = \arg\max_j A_{i,j} > \theta$ | 注意力覆盖的范围 |

### 2.3 头部分类

研究发现不同注意力头往往有不同的功能：

| 类型 | 特征 | 示例 |
|------|------|------|
| **语法头** | 关注邻近位置，注意距离短 | 依存句法分析 |
| **语义头** | 关注远距离，语义相关 | 共指消解 |
| **对角头** | 大量关注自身位置 | 位置编码相关 |
| **全局头** | 关注所有位置 | 信息聚合 |
| **稀疏头** | 只关注少数位置 | 关键信息提取 |

## 3. 数学公式与推导

### 3.1 注意力集中度

**Gini系数形式的集中度**：
$$G_i = \frac{\sum_j (A_{i,j} - \bar{A})^2}{\sum_j A_{i,j}^2} = 1 - \frac{1}{L}\sum_j L A_{i,j}^2$$

其中$\bar{A} = \frac{1}{L}\sum_j A_{i,j}$。

**简化形式**：
$$C_i = \sum_j A_{i,j}^2$$

- $C_i \approx 1$：高度集中
- $C_i \approx 1/L$：完全均匀

### 3.2 注意力熵

**熵的定义**：
$$H_i = -\sum_{j=1}^{L} A_{i,j} \log_2 A_{i,j}$$

**性质**：
- $H_i \in [0, \log_2 L]$
- $H_i = 0$：完全确定性（聚焦一点）
- $H_i = \log_2 L$：完全不确定（均匀分布）

### 3.3 层间信息流

**自底向上的语义流**：

| 层级 | 注意力特征 | 信息类型 |
|------|-----------|----------|
| 浅层（1-4） | 位置相关 | 局部特征 |
| 中层（5-8） | 语法结构 | 短语/依存 |
| 深层（9-12） | 语义聚合 | 全局语义 |

### 3.4 注意力模式提取

**模式聚类**：
$$P = \text{K-Means}(A, k)$$

使用K-Means对注意力矩阵进行聚类，发现典型模式。

## 4. Python实现

### 4.1 注意力提取

```python
import torch
import torch.nn as nn
import numpy as np


class AttentionExtractor:
    """注意力权重提取器"""
    
    def __init__(self, model, layer_indices=None):
        self.model = model
        self.layer_indices = layer_indices or list(range(model.config.n_layers))
        self.attention_weights = {}
        self.hooks = []
    
    def register_hooks(self):
        """注册前向钩子"""
        for layer_idx in self.layer_indices:
            layer = self.model.transformer.h[layer_idx]
            attn_layer = layer.attn
            
            def create_hook(layer_idx):
                def hook(module, input, output):
                    if isinstance(output, tuple):
                        attn = output[1]
                    else:
                        attn = output
                    self.attention_weights[layer_idx] = attn.detach().cpu()
                return hook
            
            handle = attn_layer.register_forward_hook(create_hook(layer_idx))
            self.hooks.append(handle)
    
    def remove_hooks(self):
        """移除钩子"""
        for hook in self.hooks:
            hook.remove()
        self.hooks.clear()
    
    def extract_attention(self, input_ids):
        """提取注意力权重"""
        self.register_hooks()
        
        with torch.no_grad():
            _ = self.model(input_ids)
        
        self.remove_hooks()
        
        return self.attention_weights
```

### 4.2 注意力分析

```python
class AttentionAnalyzer:
    """注意力分析器"""
    
    @staticmethod
    def compute_concentration(attn_weights):
        """计算注意力集中度"""
        return np.sum(attn_weights ** 2, axis=-1)
    
    @staticmethod
    def compute_entropy(attn_weights, eps=1e-10):
        """计算注意力熵"""
        return -np.sum(
            attn_weights * np.log(attn_weights + eps),
            axis=-1
        )
    
    @staticmethod
    def compute_focus(attn_weights, threshold=0.1):
        """计算注意力焦点数量"""
        return np.sum(attn_weights > threshold, axis=-1)
    
    @staticmethod
    def find_peak_positions(attn_weights):
        """找出峰值位置"""
        return np.argmax(attn_weights, axis=-1)
    
    def analyze_head(self, attn_weights):
        """分析单个头"""
        return {
            'mean': np.mean(attn_weights),
            'std': np.std(attn_weights),
            'max': np.max(attn_weights),
            'concentration': self.compute_concentration(attn_weights),
            'entropy': self.compute_entropy(attn_weights),
            'focus_count': self.compute_focus(attn_weights),
            'peak_position': self.find_peak_positions(attn_weights)
        }
    
    def analyze_layer(self, layer_attn_weights):
        """分析整个层"""
        results = []
        for head_idx, attn in enumerate(layer_attn_weights[0]):
            results.append(self.analyze_head(attn))
        return results
```

### 4.4 深度分析

```python
class DeepAttentionAnalyzer:
    """深度注意力分析"""
    
    def __init__(self, model):
        self.model = model
        self.analyzer = AttentionAnalyzer()
    
    def analyze_patterns(self, input_ids):
        """分析注意力模式"""
        extractor = AttentionExtractor(self.model)
        attention_weights = extractor.extract_attention(input_ids)
        
        patterns = {}
        
        for layer_idx, attn in attention_weights.items():
            layer_patterns = []
            
            for head_idx in range(attn.shape[1]):
                head_attn = attn[0, head_idx].numpy()
                
                pattern = self._classify_pattern(head_attn)
                layer_patterns.append(pattern)
            
            patterns[layer_idx] = layer_patterns
        
        return patterns
    
    def _classify_pattern(self, attn):
        """分类注意力模式"""
        mean_attn = np.mean(attn, axis=0)
        
        diagonal_ratio = np.mean(np.diag(attn))
        if diagonal_ratio > 0.3:
            return 'diagonal'
        
        entropy = self.analyzer.compute_entropy(attn.mean(axis=0))
        if entropy < 1.0:
            return 'sparse'
        
        mean_focus = self.analyzer.compute_focus(attn.mean(axis=0))
        if mean_focus < 5:
            return 'focused'
        
        return 'distributed'
    
    def find_syntactic_heads(self, patterns):
        """找出语法功能头"""
        syntactic_patterns = {'dependency', 'position', 'local'}
        
        syntactic_heads = []
        
        for layer_idx, layer_patterns in patterns.items():
            for head_idx, pattern in enumerate(layer_patterns):
                if pattern in syntactic_patterns:
                    syntactic_heads.append({
                        'layer': layer_idx,
                        'head': head_idx,
                        'pattern': pattern
                    })
        
        return syntactic_heads
    
    def find_semantic_heads(self, patterns):
        """找出语义功能头"""
        semantic_patterns = {'coreference', 'global'}
        
        semantic_heads = []
        
        for layer_idx, layer_patterns in patterns.items():
            for head_idx, pattern in enumerate(layer_patterns):
                if pattern in semantic_patterns:
                    semantic_heads.append({
                        'layer': layer_idx,
                        'head': head_idx,
                        'pattern': pattern
                    })
        
        return semantic_heads
```

## 8. 手工代码实现

### 8.1 完整的注意力分析系统

```python
class AttentionAnalysisSystem:
    """完整的注意力分析系统"""
    
    def __init__(self, model, tokenizer):
        self.model = model
        self.tokenizer = tokenizer
        self.analyzer = AttentionAnalyzer()
        self.visualizer = AttentionVisualizer()
    
    def analyze_text(self, text, save_path=None):
        """分析文本的注意力"""
        inputs = self.tokenizer(text, return_tensors="pt")
        
        with torch.no_grad():
            outputs = self.model(**inputs)
            attentions = outputs.attentions
        
        results = {
            'text': text,
            'tokens': self.tokenizer.convert_ids_to_tokens(
                inputs['input_ids'][0]
            ),
            'layer_analysis': [],
            'head_analysis': []
        }
        
        for layer_idx, layer_attn in enumerate(attentions):
            layer_result = self._analyze_layer(layer_attn)
            results['layer_analysis'].append(layer_result)
        
        return results
    
    def _analyze_layer(self, layer_attn):
        """分析单层"""
        attn = layer_attn[0].numpy()
        
        head_results = []
        for head_idx in range(attn.shape[0]):
            head_attn = attn[head_idx]
            
            head_result = {
                'summary': self.analyzer.analyze_head(head_attn),
                'pattern': self._classify_head(head_attn)
            }
            head_results.append(head_result)
        
        return {
            'heads': head_results,
            'aggregate': self._aggregate_layer(attn)
        }
    
    def _classify_head(self, head_attn):
        """分类头部"""
        mean_attn = head_attn.mean(axis=0)
        entropy = self.analyzer.compute_entropy(mean_attn)
        concentration = self.analyzer.compute_concentration(mean_attn)
        
        if concentration > 0.5:
            return 'focused'
        elif entropy > 3.0:
            return 'distributed'
        else:
            return 'moderate'
    
    def _aggregate_layer(self, layer_attn):
        """聚合层级别分析"""
        all_attn = layer_attn.mean(axis=0)
        
        return {
            'mean_attention': np.mean(all_attn),
            'max_attention': np.max(all_attn),
            'entropy': self.analyzer.compute_entropy(all_attn),
            'concentration': self.analyzer.compute_concentration(all_attn)
        }
```

### 9.2 注意力模式分析

```python
def analyze_attention_patterns(attentions):
    """分析注意力模式"""
    patterns = {
        'local': [],
        'global': [],
        'diagonal': [],
        'sparse': []
    }
    
    for layer_idx, layer_attn in enumerate(attentions):
        for head_idx in range(layer_attn.shape[1]):
            head_attn = layer_attn[0, head_idx].numpy()
            mean_attn = head_attn.mean(axis=0)
            
            diagonal = np.mean(np.diag(head_attn))
            entropy = -np.sum(mean_attn * np.log(mean_attn + 1e-10))
            concentration = np.sum(mean_attn ** 2)
            
            if diagonal > 0.3:
                patterns['diagonal'].append((layer_idx, head_idx))
            elif concentration > 0.5:
                patterns['sparse'].append((layer_idx, head_idx))
            elif entropy > 3.0:
                patterns['global'].append((layer_idx, head_idx))
            else:
                patterns['local'].append((layer_idx, head_idx))
    
    return patterns
```

## 10. 模型评估

### 10.1 评估指标

| 指标 | 公式 | 含义 |
|------|------|------|
| 注意力熵 | $H = -\sum A \log A$ | 分布均匀性 |
| 集中度 | $C = \sum A^2$ | 注意力集中程度 |
| 关注宽度 | $W = \\{j: A > \\theta\\}$ | 有效范围 |
| 头部一致性 | $I = \\text{IoU}(H_i, H_j)$ | 头部功能相似 |

### 10.2 头部重要性

```python
def compute_head_importance(attentions, labels):
    """计算头部重要性"""
    importance = []
    
    for layer_idx, layer_attn in enumerate(attentions):
        for head_idx in range(layer_attn.shape[1]):
            head_attn = layer_attn[0, head_idx].numpy()
            correlation = np.corrcoef(
                head_attn.flatten(),
                labels.flatten()
            )[0, 1]
            importance.append({
                'layer': layer_idx,
                'head': head_idx,
                'correlation': correlation
            })
    
    return sorted(importance, key=lambda x: x['correlation'], reverse=True)
```

## 11. 常见问题与易错点

### 11.1 问题：注意力不等于因果

**原因**：注意力是相关性而非因果性

**解决方案**：结合干预实验

### 11.2 问题：高维注意力难以解释

**原因**：12+层，每层12+头

**解决方案**：聚类、降维聚合

### 11.3 问题：模式主观性强

**原因**：需要领域知识判断

**解决方案**：建立标准化分类体系

## 12. 学习总结

### 12.1 核心要点

1. **注意力权重** = 位置间相关性
2. **统计分析** = 熵、集中度
3. **分类头部** = 语法/语义/对角
4. **层级演化** = 局部→全局

### 12.2 关键公式

- 注意力：$\text{softmax}(QK^T / \sqrt{d})$
- 熵：$-\sum A \log A$
- 集中度：$\sum A^2$

```
  ↓
```
