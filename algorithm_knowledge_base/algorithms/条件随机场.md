# 条件随机场 学习文档

## 1. 算法基础认知
### 1.1 一句话定义
条件随机场（Conditional Random Field, CRF）是一种用于序列标注的概率判别模型，直接建模给定观测序列条件下标签序列的条件概率，无需如HMM般的独立假设，广泛用于自然语言处理中的命名实体识别、词性标注等任务。

### 1.2 直觉类比
想象你在给一段英文句子标注词性。一个词的词性不仅取决于它本身（动词、名词等），还受邻近词的影响——比如"run"在"I run fast"中是动词，在"water run"中可能是名词。CRF就是能够同时考虑整个句子上下文来标注每个词的工具，它学会了词与词之间的"朋友关系"。

### 1.3 历史背景
CRF由Lafferty等人在2001年提出，结合了最大熵模型和隐马尔可夫模型的优点。此后在NLP领域成为序列标注的基准方法，特别是在命名实体识别、分词、浅层语法分析等任务中表现优异。

### 1.4 算法定位
- 类型：stateless判别模型
- 输出：序列标签概率
- 模型类别：概率图模型/判别模型

## 2. 核心原理
### 2.1 核心思想
CRF的核心思想是绕过生成模型，直接建模条件概率$P(Y|X)$。通过定义特征函数（描述观测与标签的关系），使用对数线性模型，学习在给定观测序列下各标签序列的得分，最终通过归一化（配分函数）得到概率。

### 2.2 工作流程
1. **特征设计**：定义状态特征和转移特征函数
2. **学习**：使用极大似然或感知机学习权重
3. **预测**：用Viterbi解码找最优标签序列

### 2.3 关键概念解释
- **状态特征**：$f_i(s, o_i)$，描述当前位置观测与标签的关系
- **转移特征**：$f_{i}(s_{i-1}, s_i, o)$，描述相邻标签间的关系
- **势函数**：$\exp(\sum_k \lambda_k f_k)$
- **配分函数**：$Z(x) = \sum_y \exp(\sum_k \lambda_k f_k)$保证概率归一化

### 2.4 几何/直观解释
CRF可看作在标注图上的无向条件概率模型。边的势函数（转移特征）捕捉标签依赖，点的势函数（状态特征）捕捉观测-标签关系。

## 3. 数学公式与推导
### 3.1 符号约定
| 符号 | 含义 |
|------|------|
| $X = (x_1,...,x_T)$ | 输入序列 |
| $Y = (y_1,...,y_T)$ | 标签序列 |
| $\lambda$ | 特征权重 |
| $Z(x)$ | 配分函数 |
| $F_k(y, x)$ | 特征向量 |

### 3.2 问题形式化
给定观测序列$X$，求条件概率最大的标签序列：
$$Y^* = \arg\max_Y P(Y|X)$$

其中：
$$P(Y|X) = \frac{1}{Z(x)} \exp\left(\sum_{i=1}^{T} \sum_{k} \lambda_k f_k(y_{i-1}, y_i, x, i)\right)$$

### 3.3 目标函数/损失函数
极大似然：
$$L(\lambda) = \sum_{(x,y)} \log P(y|x) - \frac{\lambda^2}{2\sigma^2}$$

或感知机损失：
$$L = \sum_{(x,y)} 1 - [y^* = y_{pred}]$$

### 3.4 推导过程
配分函数确保概率和为1：
$$Z(x) = \sum_y \exp(E(y,x))$$

对数配分函数的梯度：
$$\frac{\partial log Z}{\partial \lambda_k} = \sum_y f_k(y,x) P(y|x)$$

使用前向-后向算法可高效计算。

### 3.5 最终解/算法步骤
**学习（梯度上升）**：
```
初始化权重λ
repeat:
    for each (x,y):
        计算当前梯度
        λ ← λ + η · gradient
until 收敛
```

**预测（Viterbi解码）**：
```
δ[1,j] = λ·f₀(y₁) + λ·f₁(y₁,x₁)
for i = 2 to T:
    for j:
        δ[i,j] = max_k δ[i-1,k] + λ·f(y_{i-1},y_i,x,i)
    回溯找最优路径
```

## 4. 训练过程讲解
### 4.1 数据预处理
- 分词

### 4.2 参数初始化
- λ = 0 或小随机值
- L2正则化系数

### 4.3 迭代过程
```
for epoch in range(max_epochs):
    for (x,y) in train_data:
        forward_backward计算梯度
        梯度上升更新λ
```

### 4.4 收敛条件
- 最大迭代次数
- 验证集F1不再提升

### 4.5 超参数及推荐范围
- 学习率：0.01-0.1
- L2正则：0.1-1.0
- 迭代次数：100-500

## 5. 应用场景
### 5.1 典型应用
- **命名实体识别**：识别人名、地名、机构名
- **词性标注**：标注每个词的词性
- **浅层语法分析**：Chunking
- **分词**：中文分词

### 5.2 适用数据特征
- 序列输入
- 有标签数据
- 标签间有依赖

### 5.3 不适用场景
- 训练数据少
- 无标签依赖
- 实时要求高

## 6. 优缺点分析
### 6.1 优点
- 可建模任意特征
- 克服HMM独立性假设
- 可学习复杂转移模式
- 有全局最优解

### 6.2 缺点
- 需要特征工程
- 训练速度较慢
- 特征选择影响大

### 6.3 与同类算法对比

| 算法 | 特征利用 | 建模能力 | 速度 |
|------|---------|---------|------|
| HMM | 简单 | 有限 | 快 |
| CRF | 复杂 | 强 | 中 |
| BiLSTM-CRF | 复杂 | 最强 | 慢 |

### 7.2 完整代码示例
```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.metrics import classification_report
from collections import defaultdict
import re

class SimpleCRF:
    """简化版CRF"""
    def __init__(self, n_tags):
        self.n_tags = n_tags
        self.weights = defaultdict(float)
    
    def get_features(self, sent, i):
        """提取特征"""
        word = sent[i]
        
        features = {
            'bias': 1.0,
            'word.lower': word.lower(),
            'word[-3:]': word[-3:] if len(word) > 2 else word,
            'word.isupper': word.isupper(),
            'word.istitle': word.istitle(),
            'word.isdigit': word.isdigit(),
        }
        
        if i > 0:
            features['prev_word.lower'] = sent[i-1].lower()
            features['prev_word.istitle'] = sent[i-1].istitle()
        else:
            features['BOS'] = True
        
        if i < len(sent) - 1:
            features['next_word.lower'] = sent[i+1].lower()
            features['next_word.istitle'] = sent[i+1].istitle()
        else:
            features['EOS'] = True
        
        return features
    
    def score(self, sent, tags):
        """计算得分"""
        score = 0.0
        for i, tag in enumerate(tags):
            features = self.get_features(sent, i)
            for key, val in features.items():
                fkey = f'{key}={val}:{tag}'
                score += self.weights.get(fkey, 0)
            
            if i > 0:
                trans = f'{tags[i-1]}->{tag}'
                score += self.weights.get(trans, 0)
        
        return score
    
    def forward_backward(self, sent):
        """前向后向算法（简化）"""
        n = len(sent)
        
        alpha = np.zeros((n, self.n_tags))
        beta = np.zeros((n, self.n_tags))
        
        for j in range(self.n_tags):
            features = self.get_features(sent, 0)
            for key, val in features.items():
                fkey = f'{key}={val}:{j}'
                alpha[0, j] += self.weights.get(fkey, 0)
        
        alpha[0] = np.exp(alpha[0])
        alpha[0] = alpha[0] / alpha[0].sum()
        
        return alpha, beta
    
    def fit(self, X, y, lr=0.1, n_iter=100):
        """训练"""
        for epoch in range(n_iter):
            for sent, tags in zip(X, y):
                best_tags = self.predict(sent)
                
                for i, (pred_tag, true_tag) in enumerate(zip(best_tags, tags)):
                    if pred_tag != true_tag:
                        features = self.get_features(sent, i)
                        
                        for key, val in features.items():
                            fkey = f'{key}={val}:{true_tag}'
                            self.weights[fkey] += lr
                            
                            fkey_bad = f'{key}={val}:{pred_tag}'
                            self.weights[fkey_bad] -= lr
                        
                        if i > 0:
                            self.weights[f'{pred_tag}->{true_tag}'] += lr
                            self.weights[f'{tags[i-1]}->{true_tag}'] += lr
    
    def predict(self, sent):
        """预测（简化Viterbi）"""
        n = len(sent)
        V = np.zeros((n, self.n_tags))
        back = np.zeros((n, self.n_tags), dtype=int)
        
        for j in range(self.n_tags):
            features = self.get_features(sent, 0)
            for key, val in features.items():
                fkey = f'{key}={val}:{j}'
                V[0, j] += self.weights.get(fkey, 0)
        
        for i in range(1, n):
            for j in range(self.n_tags):
                features = self.get_features(sent, i)
                scores = []
                for k in range(self.n_tags):
                    s = V[i-1, k]
                    s += self.weights.get(f'{k}->{j}', 0)
                    for key, val in features.items():
                        fkey = f'{key}={val}:{j}'
                        s += self.weights.get(fkey, 0)
                    scores.append(s)
                
                V[i, j] = max(scores)
                back[i, j] = np.argmax(scores)
        
        tags = [np.argmax(V[-1])]
        for i in range(n-1, 0, -1):
            tags.insert(0, back[i, tags[0]])
        
        return tags

def word2features(sent, i):
    """特征提取"""
    word = sent[i]
    
    features = {
        'bias': 1.0,
        'word.lower': word.lower(),
        'word[-3:]': word[-3:],
        'word.isupper': word.isupper(),
        'word.istitle': word.istitle(),
        'word.isdigit': word.isdigit(),
    }
    
    if i > 0:
        word1 = sent[i-1].lower()
        features.update({
            '-1:word.lower': word1,
            '-1:word.istitle': sent[i-1].istitle(),
        })
    else:
        features['BOS'] = True
    
    if i < len(sent) - 1:
        word1 = sent[i+1].lower()
        features.update({
            '+1:word.lower': word1,
            '+1:word.istitle': sent[i+1].istitle(),
        })
    else:
        features['EOS'] = True
    
    return features

def sent2features(sent):
    return [word2features(sent, i) for i in range(len(sent))]

def sent2labels(labels):
    return labels

def simple_training():
    """简单训练示例"""
    X_train = [
        ['John', 'lives', 'in', 'New', 'York'],
        ['Mary', 'likes', 'to', 'play', 'tennis'],
        ['Peter', 'works', 'at', 'Google'],
    ]
    y_train = [
        ['PER', 'O', 'O', 'LOC', 'LOC'],
        ['PER', 'O', 'O', 'O', 'O'],
        ['PER', 'O', 'O', 'ORG'],
    ]
    
    tag_to_id = {'O': 0, 'PER': 1, 'LOC': 2, 'ORG': 3}
    id_to_tag = {v:k for k,v in tag_to_id.items()}
    
    crf = SimpleCRF(len(tag_to_id))
    crf.fit(X_train, [[tag_to_id[t] for t in s] for s in y_train])
    
    test = ['John', 'works', 'at', 'Google', 'in', 'New', 'York']
    pred = crf.predict(test)
    
    print(f"Input: {test}")
    print(f"Pred: {[id_to_tag[p] for p in pred]}")

def advanced_example():
    """使用sklearn-crfsuite的示例"""
    try:
        import sklearn_crfsuite
    except ImportError:
        print("sklearn-crfsuite未安装，跳过")
        return
    
    X_train = [
        ['John', 'lives', 'in', 'Paris'],
        ['Mary', 'works', 'at', 'Google'],
    ]
    y_train = [
        ['PER', 'O', 'O', 'LOC'],
        ['PER', 'O', 'O', 'ORG'],
    ]
    
    X_feat = [sent2features(s) for s in X_train]
    y_feat = [sent2labels(l) for l in y_train]
    
    crf = sklearn_crfsuite.CRF(
        algorithm='lbfgs',
        c1=0.1,
        c2=0.1,
        max_iterations=100,
    )
    crf.fit(X_feat, y_feat)
    
    test = ['John', 'lives', 'in', 'New', 'York']
    test_feat = [sent2features(test)]
    pred = crf.predict(test_feat)[0]
    
    print(f"Test: {test}")
    print(f"Pred: {pred}")

if __name__ == "__main__":
    simple_training()
    advanced_example()
```

## 12. 学习总结
### 12.1 核心要点回顾
- CRF是判别模型，直接建模条件概率
- 可使用任意复杂特征
- Viterbi解码找最优标签序列

### 12.2 关键公式汇总
$$P(y|x) = \frac{1}{Z(x)} \exp\left(\sum_i \lambda \cdot f(y_{i-1}, y_i, x, i)\right)$$

$$y^* = \arg\max_y \sum_i \lambda \cdot f(y_{i-1}, y_i, x, i)$$

### 12.3 与前序/后续算法联系
- 前置：HMM、ME模型
- 同级：BiLSTM
- 进阶：BiLSTM-CRF、Transformer
