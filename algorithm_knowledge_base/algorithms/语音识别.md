# 语音识别（Automatic Speech Recognition, ASR）学习文档

## 1. 算法基础认知

语音识别（ASR）是人机交互核心技术之一，旨在将人类语音转换为对应的文本内容。这项技术使机器能够"听懂"人类的语言，是语音助手、智能音箱、客服机器人等应用的基础。

语音识别的发展经历了从GMM-HMM（高斯混合模型-隐马尔可夫模型）到深度学习的重大变革。早期的方法依赖于MFCC等人工设计的声学特征，配合GMM进行声学建模。2010年后，随着深度学习在语音识别领域的应用，ASR的性能得到了显著提升，特别是端到端（End-to-End）模型的出现简化了传统ASR系统的pipeline。

现代语音识别系统通常包含声学模型（Acoustic Model）、语言模型（Language Model）和解码器三个核心组件。声学模型负责将声学特征转换为音素或字符单元，语言模型提供语言先验知识，解码器负责结合两者进行最终解码。

理解语音识别的原理对于从事语音交互、对话系统、智能家居等领域的开发至关重要。语音作为人类最自然的交流方式，ASR技术将持续在人和机器之间搭建沟通的桥梁。

## 2. 核心原理

### 2.1 语音信号预处理

语音信号是连续的模拟信号，需要经过采样、量化、分帧、加窗等预处理步骤才能被计算机处理。

**采样与量化**：将模拟信号转换为数字信号，通常采样率为16kHz（电话语音）或16kHz以上（远场语音）。

**分帧**：将连续的语音信号切分成短时帧，通常每帧25ms，帧移10ms。分帧的目的是因为语音信号具有短时平稳性。
$$\text{帧数} = \frac{\text{信号长度} - \text{帧长}}{\text{帧移}} + 1$$

**加窗**：使用汉宁窗（Hanning Window）或汉明窗（Hamming Window）减少频谱泄漏。
$$w[n] = 0.5 \cdot (1 - \cos(\frac{2\pi n}{N-1}))$$

### 2.2 声学特征提取

声学特征是描述语音信号的紧凑表示，常见的特征包括MFCC、FBANK和Log-Mel特征。

**MFCC（Mel-Frequency Cepstral Coefficients）**：基于Mel频标的倒谱系数，与人类听觉感知高度相关。

提取流程：
1. 对每帧信号进行快速傅里叶变换（FFT）得到频谱
2. 使用Mel滤波器组进行滤波
3. 取对数得到对数频谱
4. 进行离散余弦变换（DCT）得到MFCC

Mel滤波器组的设计：
$$f_{mel} = 2595 \cdot \log_{10}(1 + \frac{f}{700})$$
$$f = 700 \cdot (10^{f_{mel}/2595} - 1)$$

**Log-Mel特征**：相比MFCC保留了更多细节信息，是深度学习模型常用的特征。

### 2.3 声学模型

声学模型建立声学特征到音素或字符的映射关系。传统的GMM-HMM模型使用高斯混合模型对每个音素的声学特征进行建模。

深度学习时代，常见的声学模型包括：
- **DNN-HMM**：用深度神经网络替代GMM
- **CNN**：利用卷积操作提取局部特征
- **RNN/LSTM**：建模时序依赖关系
- **Transformer**：利用注意力机制建模长距离依赖

### 2.4 端到端ASR

端到端ASR将声学特征直接映射到字符序列，大大简化了系统复杂度。

**Connectionist Temporal Classification ( CTC)**：不需要序列对齐，通过blank和重复机制处理变长输出。

**RNN-Transducer (RNN-T)**：结合encoder和预测网络，适合流式识别。

**Attention-based Encoder-Decoder**：利用注意力机制进行对齐，常见于神经机器翻译。

## 3. 数学公式与推导

### 3.1 MFCC特征提取

对输入语音信号$x[n]$，帧长$N$，帧移$K$：

**步骤1：FFT**
$$X[k] = \sum_{n=0}^{N-1} x[n] \cdot w[n] \cdot e^{-j2\pi kn/N}$$

**步骤2：Mel��波器组**
$$Y_m = \sum_{k} |X[k]|^2 \cdot H_m[k]$$

其中$H_m[k]$是第$m$个Mel滤波器的频率响应。

**步骤3：对数**
$$logY_m = \log(Y_m + \epsilon)$$

**步骤4：DCT**
$$c[n] = \sum_{m=0}^{M-1} logY_m \cdot \cos(\frac{\pi n (m + 0.5)}{M})$$

### 3.2 CTC损失函数

对于输入序列$O = (o_1, o_2, ..., o_T)$和标签序列$L = (l_1, l_2, ..., l_U)$，CTC定义路径$\pi$为去掉blank和连续重复后等于$L$的所有路径。

前向概率：
$$\alpha(t, u) = \alpha(t-1, u) \cdot y_t^{\pi_u} + \alpha(t-1, u-1) \cdot y_t^{\pi_{u-1}}$$

CTC损失：
$$L_{CTC} = -\log \sum_{\pi \in B^{-1}(L)} \prod_{t=1}^{T} y_t^{\pi_t}$$

其中$B^{-1}(L)$是所有映射到$L$的路径集合，$y_t^{\pi_t}$是$t$时刻输出$\pi_t$的概率。

### 3.3 注意力机制

编码器输出序列$H = (h_1, h_2, ..., h_T)$，解码器逐步生成输出$Y = (y_1, y_2, ...)$。

**上下文向量**：
$$c_t = \sum_{i=1}^{T} \alpha_{t,i} \cdot h_i$$

**注意力权重**：
$$\alpha_{t,i} = \frac{\exp(e_{t,i})}{\sum_{j=1}^{T} \exp(e_{t,j})}$$

**能量函数**：
$$e_{t,i} = \text{score}(s_{t-1}, h_i)$$

其中$s_{t-1}$是解码器状态。

### 3.4 端到端ASR损失

编码器-解码器架构的损失为：
$$L = -\log P(Y|X; \theta)$$

$$P(Y|X) = \prod_{t} P(y_t|y_{<t}, X; \theta)$$

```python
import torch
import torchaudio
import numpy as np

class SpeechDataset(torch.utils.data.Dataset):
    def __init__(self, audio_paths, transcripts, feature_fn='mfcc'):
        self.audio_paths = audio_paths
        self.transcripts = transcripts
        self.feature_fn = feature_fn
        
        # 定义特征提取器
        self.sample_rate = 16000
        self.n_fft = 400
        self.n_mels = 80
        self.n_mfcc = 40
        self.win_length = 400
        self.hop_length = 160
        
    def __len__(self):
        return len(self.audio_paths)
    
    def __getitem__(self, idx):
        # 加载音频
        waveform, sr = torchaudio.load(self.audio_paths[idx])
        
        # 重采样（如果需要）
        if sr != self.sample_rate:
            waveform = torchaudio.functional.resample(waveform, sr, self.sample_rate)
        
        # 提取特征
        if self.feature_fn == 'mfcc':
            feature = torchaudio.feature.MFCC(
                sample_rate=self.sample_rate,
                n_mfcc=self.n_mfcc,
                melkwargs={'n_fft': self.n_fft, 'n_mels': self.n_mels, 
                         'hop_length': self.hop_length}
            )(waveform)
        elif self.feature_fn == 'fbank':
            feature = torchaudio.feature.MelSpectrogram(
                sample_rate=self.sample_rate,
                n_fft=self.n_fft,
                n_mels=self.n_mels,
                hop_length=self.hop_length
            )(waveform)
            feature = torch.log(feature + 1e-8)
        
        return feature.squeeze(0), self.transcripts[idx]
```

### 4.2 声学模型实现

```python
import torch.nn as nn
import torch.nn.functional as F

class CNNEncoder(nn.Module):
    """CNN编码器用于声学特征提取"""
    
    def __init__(self, input_dim=40, hidden_dim=512, num_layers=3):
        super(CNNEncoder, self).__init__()
        
        self.conv_layers = nn.ModuleList()
        for i in range(num_layers):
            in_channels = input_dim if i == 0 else hidden_dim
            self.conv_layers.append(nn.Sequential(
                nn.Conv1d(in_channels, hidden_dim, kernel_size=3, padding=1),
                nn.BatchNorm1d(hidden_dim),
                nn.ReLU(),
                nn.Dropout(0.1)
            ))
        
        self.lstm = nn.LSTM(
            hidden_dim, hidden_dim // 2,
            num_layers=2, batch_first=True, bidirectional=True
        )
    
    def forward(self, x):
        # x: (batch, time, features)
        x = x.transpose(1, 2)  # (batch, features, time)
        
        for conv in self.conv_layers:
            x = conv(x)
        
        x = x.transpose(1, 2)  # (batch, time, features)
        x, _ = self.lstm(x)
        
        return x


class TransformerEncoder(nn.Module):
    """Transformer编码器"""
    
    def __init__(self, input_dim=512, num_layers=6, nhead=8, dim_feedforward=2048):
        super(TransformerEncoder, self).__init__()
        
        self.positional_encoding = PositionalEncoding(input_dim)
        
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=input_dim, nhead=nhead, 
            dim_feedforward=dim_feedforward, batch_first=True
        )
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers)
    
    def forward(self, x):
        x = self.positional_encoding(x)
        x = self.transformer(x)
        return x


class PositionalEncoding(nn.Module):
    """位置编码"""
    
    def __init__(self, d_model, max_len=5000):
        super(PositionalEncoding, self).__init__()
        
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * (-np.log(10000.0) / d_model))
        
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        pe = pe.unsqueeze(0)
        
        self.register_buffer('pe', pe)
    
    def forward(self, x):
        x = x + self.pe[:, :x.size(1)]
        return x


class Seq2SeqASR(nn.Module):
    """Seq2Seq ASR模型"""
    
    def __init__(self, vocab_size, input_dim=512, hidden_dim=512, 
                 num_encoder_layers=6, num_decoder_layers=6, nhead=8):
        super(Seq2SeqASR, self).__init__()
        
        self.encoder = TransformerEncoder(
            input_dim, num_encoder_layers, nhead
        )
        
        self.decoder = nn.Embedding(vocab_size, input_dim)
        self.lstm = nn.LSTM(input_dim, hidden_dim, num_decoder_layers, batch_first=True)
        
        self.output = nn.Linear(hidden_dim, vocab_size)
        
    def forward(self, x, target=None, teacher_forcing_ratio=0.5):
        # 编码
        encoder_output = self.encoder(x)
        
        # 解码
        if target is not None:
            # 训练模式
            decoder_input = self.decoder(target[:, :-1])
            decoder_output, _ = self.lstm(decoder_input)
            output = self.output(decoder_output)
        else:
            # 推理模式（贪婪解码）
            output = []
            decoder_input = self.decoder(torch.zeros(1, 1).long().to(x.device))

                decoder_output, (h, c) = self.lstm(decoder_input)
                logit = self.output(decoder_output.squeeze(1))

        return output
```

### 4.3 CTC训练

```python
class CTCLoss(nn.Module):
    """CTC损失函数封装"""
    
    def __init__(self, blank=0):
        super(CTCLoss, self).__init__()
        self.blank = blank
    
    def forward(self, log_probs, targets, input_lengths, target_lengths):
        # log_probs: (T, N, C)
        # targets: (N, max_T)
        
        T, N, C = log_probs.shape
        log_probs = log_probs.log_softmax(dim=-1)
        
        loss = F.ctc_loss(log_probs, targets, input_lengths, target_lengths, 
                         blank=self.blank, zero_infinity=True)
        
        return loss


def train_ctc_model(model, train_loader, optimizer, device, num_epochs=50):
    model.train()
    criterion = CTCLoss(blank=0)
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=num_epochs)
    
    for epoch in range(num_epochs):
        total_loss = 0
        
        for features, targets, input_lengths, target_lengths in train_loader:
            features = features.to(device)
            targets = targets.to(device)
            
            optimizer.zero_grad()
            
            # 前向传播
            log_probs = model(features)  # (T, N, C)
            
            # 计算CTC损失
            loss = criterion(log_probs, targets, input_lengths, target_lengths)
            
            # 反向传播
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 5.0)
            optimizer.step()
            
            total_loss += loss.item()
        
        scheduler.step()
        
        print(f'Epoch {epoch+1}, Loss: {total_loss/len(train_loader):.4f}')
```

```python
def greedy_decode(log_probs):
    """贪婪解码"""
    predictions = log_probs.argmax(dim=-1)  # (T, N)
    predictions = predictions.transpose(0, 1)  # (N, T)
    
    decoded = []
    for pred in predictions:
        # 去除连续重复和blank
        result = []
        prev = -1
        for p in pred:
            if p != 0 and p != prev:
                result.append(p.item())
            prev = p.item()
        decoded.append(result)
    
    return decoded


def beam_search_decode(log_probs, beam_width=10, blank=0):
    """束搜索解码"""
    T, N, C = log_probs.shape
    log_probs = log_probs.log_softmax(dim=-1)
    
    # 初始化
    beams = [{'seq': [], 'score': 0.0}]
    
    for t in range(T):
        new_beams = []
        
        for beam in beams:
            for c in range(C):
                new_seq = beam['seq'].copy()
                new_score = beam['score'] + log_probs[t, 0, c].item()
                
                # 处理blank
                if c == blank:
                    new_beams.append({'seq': new_seq, 'score': new_score})
                    continue
                
                # 处理连续重复
                if new_seq and new_seq[-1] == c:
                    new_beams.append({'seq': new_seq, 'score': new_score})
                    continue
                
                # 添加新字符
                new_seq.append(c)
                new_beams.append({'seq': new_seq, 'score': new_score})
        
        # 保留top-k beams
        new_beams.sort(key=lambda x: x['score'], reverse=True)
        beams = new_beams[:beam_width]
    
    return beams[0]['seq']
```
