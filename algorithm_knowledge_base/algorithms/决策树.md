# 决策树 学习文档

## 1. 算法基础认知

### 1.1 一句话定义
决策树（Decision Tree）是一种基于树结构进行决策的监督学习方法，它通过递归地选择最优特征对数据集进行划分，直到每个子集都属于同一类别或达到停止条件，从而构建一个树形的决策模型。

### 1.2 直觉类比
决策树的工作方式非常类似于人类日常决策的过程。想象你在考虑是否要去参加一个户外音乐节，你会问自己一系列问题："天气好吗？如果天气不好就不去。""天气好的话，有伴吗？没有伴就不太想去。""有伴的话，距离远吗？太远就不去了。""距离不远，又有伴，我就去。"每一个问题就是一个特征的判断，每个问题的不同答案会引导你走向不同的分支，最终到达一个决定"去"或"不去"的叶子节点。这就是决策树的核心思想——通过一系列特征的是/否问题来进行决策。

### 1.3 历史背景
决策树算法的历史可以追溯到1960年代。1963年，Morgan和Sonquist提出了ID3算法的前身——AID算法，用于解决社会学调查中的分层问题。1972年，Sonquist、Morgan和Bunt首先提出了CHAID算法（Chi-squared Automatic Interaction Detector）。1986年，Ross Quinlan在论文"Induction of Decision Trees"中正式提出了ID3算法，该算法使用信息增益作为特征选择标准。1993年，Quinlan进一步提出了C4.5算法，改进了ID3，使用信息增益率来克服偏向选择取值多的特征的问题。与此同时，Breiman等人于1984年提出了CART（Classification and Regression Trees）算法，该算法使用基尼指数作为划分标准，可以处理分类和回归问题。如今，决策树是机器学习中最流行的算法之一，也是集成学习方法（如随机森林、梯度提升树）的基础。

### 1.4 算法定位
- **类型**：监督学习（Supervised Learning）
- **输出**：离散类别（分类树）或连续值（回归树）
- **模型类别**：非参数模型（树模型）
- **学习范式**：递归划分学习
- **求解方法**：贪心算法

### 1.5 前置知识
- **信息论**：信息熵、条件熵、信息增益
- **算法复杂度**：递归、剪枝
- **Python编程**：NumPy、scikit-learn

## 2. 核心原理

### 2.1 核心思想
决策树的核心思想是"分而治之"（Divide and Conquer）。算法从根节点开始，递归地选择最优特征进行划分，将数据集分成更小的子集。这个过程持续进行，直到每个子集都纯净（只包含同一类别的样本）或满足停止条件。决策树的构建过程是一个贪心的过程——每一步都选择当前最优的特征进行划分，但不保证全局最优。这种方法简单直观，可以自然地处理分类和回归问题，并且得到的模型具有很好的可解释性。

### 2.2 工作流程
1. **选择最优特征**：从当前数据集的所有特征中选择一个最优的特征作为划分依据
2. **划分数据集**：根据该特征的不同取值，将数据集划分成若干子集
3. **递归构建**：对每个子集重复步骤1-2，直到满足停止条件
4. **剪枝（可选）**：对生成的决策树进行剪枝，防止过拟合

### 2.3 关键概念解释
- **信息熵**：度量数据集纯度的指标，越接近0表示数据集越纯净，越大表示越混杂。熵的公式为：
  $$H(S) = -\sum_{i=1}^{k} p_i \log_2 p_i$$
  其中p_i是类别i的样本占比。

- **信息增益**：划分前后熵的减少量，衡量特征对分类的帮助。公式为：
  $$IG(S, A) = H(S) - \sum_{v \in Values(A)} \frac{|S_v|}{|S|} H(S_v)$$

- **基尼指数**：CART算法使用的划分标准，度量数据集的混杂程度：
  $$Gini(S) = 1 - \sum_{i=1}^{k} p_i^2$$

- **决策边界**：决策树在特征空间中形成的划分边界，可以是非线性的。

### 2.4 几何/直观解释
在二维特征空间中，决策树的每个节点相当于一条与坐标轴平行的划分线。每次划分都在某个特征维度上设定一个阈值，将特征空间分成两部分。这个过程持续进行，最终在特征空间中形成若干个矩形区域，每个区域对应一个叶子节点（类别）。决策树的决策边界是与坐标轴平行的直线组成的多边形，这是决策树的重要特点——只能进行轴平行的划分。

## 3. 数学公式与推导

### 3.1 符号约定
| 符号 | 含义 |
|------|------|
| S | 训练数据集 |
| A | 特征集合 |
| A_v | 特征A取值为v的子集 |
| H(S) | 数据集S的信息熵 |
| IG(S, A) | 特征A对S的信息增益 |
| Gini(S) | 基尼指数 |
| D | 树的深度 |

### 3.2 问题形式化
**决策树学习的目标**：构建一个能够正确分类训练数据的决策树，同时保持适当的复杂度以具有良好的泛化能力。

形式化表达为：
$$\min_T \text{Loss}(T) + \lambda |T|$$

其中Loss(T)是模型在训练数据上的损失，|T|是树的复杂度（叶节点数）。

### 3.3 信息熵与信息增益
**信息熵**：
$$H(S) = -\sum_{i=1}^{k} p_i \log_2 p_i$$

其中k是类别数，p_i是类别i在S中的比例。

**条件熵**（给定特征A的条件下的熵）：
$$H(S|A) = \sum_{v \in Values(A)} \frac{|S_v|}{|S|} H(S_v)$$

**信息增益**：
$$IG(S, A) = H(S) - H(S|A)$$

信息增益越大，说明使用特征A划分后数据集越纯净。

**信息增益率**（C4.5使用）：
$$IGR(S, A) = \frac{IG(S, A)}{H(S)}$$

信息增益率可以克服信息增益偏向选择取值多的特征的问题。

### 3.4 基尼指数
**基尼指数**（CART算法使用）：
$$Gini(S) = 1 - \sum_{i=1}^{k} p_i^2$$

基尼指数越小，表示数据集越纯净。

**特征划分后的加权基尼指数**：
$$Gini_A(S) = \sum_{v \in Values(A)} \frac{|S_v|}{|S|} Gini(S_v)$$

选择使Gini_A(S)最小的特征A进行划分。

### 3.5 连续特征处理
对于连续特征，决策树使用阈值进行二元划分：
- 将连续特征的所有取值排序
- 在相邻两个值之间的中点尝试划分
- 选择使信息增益或基尼指数最大的阈值

## 4. 训练过程讲解

### 4.1 数据预处理
1. **特征类型**
   - 离散特征：直接作为划分依据
   - 连续特征：在每个可能的中点尝试划分

2. **缺失值处理**
   - 删除含有缺失值的样本
   - 用众数/均值填充
   - 分配到最可能的分支

3. **特征选择**
   - 信息增益（ID3）
   - 信息增益率（C4.5）
   - 基尼指数（CART）

### 4.2 ID3算法流程
```
输入：训练集S，特征集A
输出：决策树T

1. 如果S中所有样本属于同一类别C，返回单节点树T，标记为类别C
2. 如果A为空，返回S中多数类
3. 否则，从A中选择使信息增益最大的特征A*
4. 对于A*的每个可能值v，创建一个子节点
5. 根据A*=v将S划分为子集S_v
6. 对每个子集S_v：
   - 如果S_v为空，添加到父节点，标记为S中多数类
   - 否则，递归调用ID3(S_v, A\{A*})
7. 返回决策树T
```

### 4.3 停止条件
- 所有样本属于同一类别
- 没有更多特征可供划分
- 达到最大深度
- 节点中样本数少于最小阈值

### 4.4 超参数
- **max_depth**：树的最大深度
- **min_samples_split**：节点划分的最小样本数
- **min_samples_leaf**：叶节点的最小样本数
- **criterion**：划分标准（entropy/gini）

## 6. 优缺点分析

### 6.1 优点
1. **可解释性强**：可以直观地可视化决策过程
2. **处理简单**：不需要特征预处理（除连续特征）
3. **多类型特征**：可以同时处理离散和连续特征
4. **缺失值处理**：可以自然地处理缺失值
5. **计算效率高**：预测只需O(树的深度)，而不是O(样本数)

### 6.2 缺点
1. **容易过拟合**：树可能过于复杂
2. **偏向选择**：偏向选择取值多的特征（使用信息增益时）
3. **局部最优**：贪心算法不保证全局最优
4. **边界限制**：只能进行轴平行的划分

## 8. 手工代码实现（NumPy）

```python
"""
决策树分类器 - 纯NumPy实现
作者：算法学习文档
功能：从零实现决策树分类器
"""

import numpy as np
import matplotlib.pyplot as plt

class DecisionTreeNode:
    """决策树节点类"""
    def __init__(self, feature=None, threshold=None, left=None, right=None, 
                 value=None, class_label=None):
        self.feature = feature      # 划分特征
        self.threshold = threshold  # 划分阈值
        self.left = left          # 左子树
        self.right = right        # 右子树
        self.value = value        # 节点数据（用于可视化）
        self.class_label = class_label  # 叶节点的类别
        
    def is_leaf(self):
        return self.class_label is not None


class DecisionTreeClassifierFromScratch:
    """
    决策树分类器的完整实现（基于ID3/CART算法）
    """
    
    def __init__(self, max_depth=10, min_samples_split=2, 
                 min_samples_leaf=1, criterion='gini'):
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.min_samples_leaf = min_samples_leaf
        self.criterion = criterion
        self.root = None
        self.classes_ = None
        self.n_classes_ = None
        
    def _entropy(self, y):
        """计算信息熵"""
        if len(y) == 0:
            return 0
        
        counts = np.bincount(y)
        probs = counts / len(y)
        
        # 避免log(0)
        probs = probs[probs > 0]
        return -np.sum(probs * np.log2(probs))
    
    def _gini(self, y):
        """计算基尼指数"""
        if len(y) == 0:
            return 0
        
        counts = np.bincount(y)
        probs = counts / len(y)
        return 1 - np.sum(probs ** 2)
    
    def _impurity(self, y):
        """计算不纯度"""
        if self.criterion == 'entropy':
            return self._entropy(y)
        else:
            return self._gini(y)
    
    def _best_split(self, X, y):
        """找到最优划分"""
        n_samples, n_features = X.shape
        best_gain = -1
        best_feature = None
        best_threshold = None
        
        # 父节点的不纯度
        parent_impurity = self._impurity(y)
        
        for feature in range(n_features):
            # 获取该特征的所有唯一值
            thresholds = np.unique(X[:, feature])
            
            # 尝试在相邻值的中点划分
            for i in range(len(thresholds) - 1):
                threshold = (thresholds[i] + thresholds[i + 1]) / 2
                
                # 划分
                left_mask = X[:, feature] <= threshold
                right_mask = ~left_mask
                
                # 检查是否满足最小叶节点大小
                if np.sum(left_mask) < self.min_samples_leaf or \
                   np.sum(right_mask) < self.min_samples_leaf:
                    continue
                
                # 计算加权不纯度
                n = len(y)
                n_left, n_right = np.sum(left_mask), np.sum(right_mask)
                impurity_left = self._impurity(y[left_mask])
                impurity_right = self._impurity(y[right_mask])
                
                gain = parent_impurity - \
                      (n_left / n) * impurity_left - \
                      (n_right / n) * impurity_right
                
                if gain > best_gain:
                    best_gain = gain
                    best_feature = feature
                    best_threshold = threshold
        
        return best_feature, best_threshold, best_gain
    
    def _build_tree(self, X, y, depth=0):
        """递归构建决策树"""
        n_samples = len(y)
        
        # 停止条件
        if n_samples < self.min_samples_split or \
           depth >= self.max_depth or \
           len(np.unique(y)) == 1:
            # 返回叶节点
            class_label = np.bincount(y).argmax()
            return DecisionTreeNode(class_label=class_label)
        
        # 找到最优划分
        feature, threshold, gain = self._best_split(X, y)
        
        if feature is None or gain <= 0:
            class_label = np.bincount(y).argmax()
            return DecisionTreeNode(class_label=class_label)
        
        # 划分数据
        left_mask = X[:, feature] <= threshold
        right_mask = ~left_mask
        
        # 递归构建子树
        left = self._build_tree(X[left_mask], y[left_mask], depth + 1)
        right = self._build_tree(X[right_mask], y[right_mask], depth + 1)
        
        return DecisionTreeNode(
            feature=feature,
            threshold=threshold,
            left=left,
            right=right
        )
    
    def fit(self, X, y):
        """训练模型"""
        X = np.array(X)
        y = np.array(y)
        
        self.classes_ = np.unique(y)
        self.n_classes_ = len(self.classes_)
        
        # 将标签映射到连续的整数
        self.class_map_ = {c: i for i, c in enumerate(self.classes_)}
        y_mapped = np.array([self.class_map_[c] for c in y])
        
        self.root = self._build_tree(X, y_mapped)
        
        return self
    
    def _predict_single(self, x, node):
        """预测单个样本"""
        if node.is_leaf():
            return self.classes_[node.class_label]
        
        if x[node.feature] <= node.threshold:
            return self._predict_single(x, node.left)
        else:
            return self._predict_single(x, node.right)
    
    def predict(self, X):
        """预测多样本"""
        X = np.array(X)
        predictions = np.zeros(len(X), dtype=int)
        
        for i in range(len(X)):
            predictions[i] = self._predict_single(X[i], self.root)
        
        return predictions
    
    def predict_proba(self, X):
        """预测各类别的概率"""
        X = np.array(X)
        proba = np.zeros((len(X), self.n_classes_))
        
        for i in range(len(X)):
            class_label = self._predict_single(X[i], self.root)
            idx = np.where(self.classes_ == class_label)[0][0]
            proba[i, idx] = 1.0
        
        return proba


def create_test_data():
    """创建测试数据"""

    X += noise
    
    return X, y
```

## 11. 常见问题与易错点

### 11.1 常见问题
1. **过拟合**
   - 解决：限制树的深度、最小叶节点数、剪枝

2. **偏向选择取值多的特征**
   - 解决：使用信息增益率（C4.5）或基尼指数（CART）

### 11.2 易错点
1. **忽略树的大小限制**
   - 树可能无限生长

2. **不进行剪枝**
   - 导致过拟合

## 13. 练习题与思考题（含答案）

### 13.1 选择题
1. **决策树使用什么标准进行特征选择？**
   A. 信息增益   B. 准确率   C. 召回率   D. F1分数
   **答案：A**

2. **决策树的优点？**
   A. 可解释性强   B. 需要大量数据   C. 总是线性   D. 需要特征标准化
   **答案：A**

3. **什么情况下需要剪枝？**
   A. 欠拟合   B. 过拟合   C. 准确率太高   D. 数据量太小
   **答案：B**

### 13.2 简答题
1. **信息熵的公式是什么？**
   $$H(S) = -\sum_{i=1}^{k} p_i \log_2 p_i$$

2. **为什么C4.5使用信息增益率而不是信息增益？**
   因为信息增益偏向选择取值多的特征，导致过拟合。信息增益率通过除以特征的熵来克服这个问题。

3. **决策树的缺点？**
   - 容易过拟合
   - 贪心算法不保证全局最优
   - 只能进行轴平行的划分
