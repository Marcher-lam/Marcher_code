# 决策树 (Decision Tree)

> 构建可解释的分类与回归模型，从根到叶的路径蕴含决策逻辑

---

## 1. 算法基础认知

### 1.1 一句话定义

决策树是一种树形结构的监督学习算法，通过递归地选择最优特征进行分裂，构建从根到叶的决策路径。每个内部节点代表一个特征的判断，每个分支代表判断结果，每个叶节点代表最终类别（分类）或数值（回归）。

### 1.2 直觉类比

决策树就像生活中的"问答游戏"：
- "今天天气怎么样？"
  - "晴天" → "湿度高吗？" 
    - "是" → 不出门
    - "否" → 出门
  - "下雨" → 不出门

通过一系列二元选择（是/否），最终做出决策。这种if-then规则形式使得模型具有极强的可解释性。

### 1.3 发展历程

- **1986**: Quinlan提出ID3算法
- **1993**: Quinlan提出C4.5算法
- **1984**: Breiman等人提出CART算法
- **2001**: Random Forest诞生
- **2014**: XGBoost/LightGBM等梯度提升树

## 2. 核心原理

### 2.1 信息熵 (Entropy)

信息熵是衡量数据集纯度的核心指标，源自信息论。

**定义**：对于包含K个类别的数据集S，信息熵定义为：
$$H(S) = -\sum_{k=1}^{K} p_k \log_2 p_k$$

其中 $p_k$ 是第k类样本所占比例。

**性质**：
- 当所有样本属于同一类时，$H(S) = 0$（完全纯）
- 当各类样本均匀分布时，$H(S)$ 取最大值（完全杂）
- $H(S) \in [0, \log_2 K]$

**直观理解**：信息熵表示"不确定性"或"信息量"。纯数据集的不确定性为0。

**示例计算**：
```
数据集: 10个样本，6个正类(+)，4个负类(-)
p(+) = 6/10 = 0.6, p(-) = 4/10 = 0.4
H(S) = -(0.6*log2(0.6) + 0.4*log2(0.4))
     = -(0.6*(-0.737) + 0.4*(-1.322))
     = 0.442 + 0.529 = 0.971
```

### 2.2 信息增益 (Information Gain)

信息增益衡量使用特征A分裂后，信息熵的减少量。

**定义**：
$$Gain(S, A) = H(S) - \sum_{v \in Values(A)} \frac{|S_v|}{|S|} \cdot H(S_v)$$

其中：
- $Values(A)$：特征A的所有可能取值
- $S_v$：特征A取值为v的子集
- $\frac{|S_v|}{|S|}$：子集权重（样本比例）

**选择标准**：选择信息增益最大的特征作为分裂节点。

**偏向多值问题**：当特征取值数量很多时（如ID），每个取值可能只包含少量样本，导致信息增益虚高。

### 2.3 基尼指数 (Gini Impurity)

CART算法使用基尼指数作为分裂标准，计算更高效。

**定义**：
$$Gini(S) = 1 - \sum_{k=1}^{K} p_k^2$$

**性质**：
- 纯数据集：$Gini(S) = 0$
- 均匀分布：$Gini(S) = 1 - \frac{1}{K}$
- 基尼指数本质是熵的近似，计算更简单（无需对数）

**基尼增益**：
$$GiniGain(S, A) = Gini(S) - \sum_{v \in Values(A)} \frac{|S_v|}{|S|} \cdot Gini(S_v)$$

### 2.4 增益率 (Gain Ratio)

C4.5使用增益率解决多值偏好问题。

**定义**：
$$SplitInfo(S, A) = -\sum_{v \in Values(A)} \frac{|S_v|}{|S|} \log_2 \frac{|S_v|}{|S|}$$

$$GainRatio(S, A) = \frac{Gain(S, A)}{SplitInfo(S, A)}$$

$SplitInfo$ 本质上是特征A的熵，惩罚取值过多的特征。

## 3. 数学公式与推导

### 3.1 ID3算法流程

```
ID3(S, A):
    if S中所有样本同属一类:
        return 单节点树，类别=该类
    if A为空:
        return 单节点树，类别=S中多数类
    
    计算S的信息熵H(S)
    for each 特征a in A:
        计算Gain(S, a)
    选择增益最大的特征a*作为分裂节点
    
    for each a*的取值v:
        创建子节点Sv
        ID3(Sv, A - {a*})
    
    return 决策树
```

### 3.2连续值特征处理

对于连续值特征（如年龄、收入），需要先将连续值离散化：

1. 对特征值排序：$x_1 \leq x_2 \leq ... \leq x_n$
2. 选择候选分割点：$t_i = \frac{x_i + x_{i+1}}{2}$
3. 计算每个t的信息增益/基尼增益
4. 选择最优分割点

**二叉分裂公式**：
$$Gain(S, a, t) = H(S) - \frac{|S_L|}{|S|}H(S_L) - \frac{|S_R|}{|S|}H(S_R)$$

其中 $S_L = \{x|x_a \leq t\}, S_R = \{x|x_a > t\}$

### 3.3 回归树平方误差

CART回归树使用平方误差最小化：

**节点纯度度量**：
$$MSE = \frac{1}{|S|} \sum_{i \in S}(y_i - \bar{y})^2$$

其中 $\bar{y} = \frac{1}{|S|}\sum_{i \in S} y_i$ 为节点均值。

**最优分割**：
选择使加权MSE最小的特征和分割点。
$$\arg\min_{a, t} \left( \frac{|S_L|}{|S|}MSE(S_L) + \frac{|S_R|}{|S|}MSE(S_R) \right)$$

### 4.2 熵与增益计算实现

```python
def calculate_entropy(y):
    """计算信息熵"""
    if len(y) == 0:
        return 0
    
    counts = Counter(y)
    probabilities = np.array([count / len(y) for count in counts.values()])
    
    # 避免log(0)
    entropy = -np.sum(probabilities * np.log2(probabilities + 1e-9))
    return entropy

def calculate_information_gain(X, y, feature_idx):
    """计算信息增益"""
    # 原始数据熵
    entropy_before = calculate_entropy(y)
    
    # 按特征值分组
    feature_values = X[:, feature_idx]
    unique_values = np.unique(feature_values)
    
    # 加权平均子集熵
    weighted_entropy = 0
    for val in unique_values:
        mask = feature_values == val
        y_subset = y[mask]
        weight = np.sum(mask) / len(y)
        weighted_entropy += weight * calculate_entropy(y_subset)
    
    return entropy_before - weighted_entropy

# 测试
print(f"原始熵: {calculate_entropy(y):.4f}")
print(f"特征0增益: {calculate_information_gain(X, y, 0):.4f}")
print(f"特征1增益: {calculate_information_gain(X, y, 1):.4f}")
```

### 4.3 决策树构建

```python
class DecisionTree:
    def __init__(self, max_depth=None, min_samples_split=2):
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.tree = None
    
    def _best_split(self, X, y):
        """找到最优分裂"""
        n_samples, n_features = X.shape
        best_gain = -np.inf
        best_feature = None
        best_threshold = None
        
        for feature_idx in range(n_features):
            # 尝试所有唯一值作为阈值
            thresholds = np.unique(X[:, feature_idx])
            for threshold in thresholds:
                # 二分类裂
                left_mask = X[:, feature_idx] <= threshold
                right_mask = ~left_mask
                
                if np.sum(left_mask) < self.min_samples_split or \
                   np.sum(right_mask) < self.min_samples_split:
                    continue
                
                # 计算增益
                gain = self._information_gain(y, left_mask, right_mask)
                
                if gain > best_gain:
                    best_gain = gain
                    best_feature = feature_idx
                    best_threshold = threshold
        
        return best_feature, best_threshold, best_gain
    
    def _information_gain(self, y, left_mask, right_mask):
        """计算信息增益"""
        n = len(y)
        if n == 0:
            return 0
        
        entropy_before = calculate_entropy(y)
        entropy_left = calculate_entropy(y[left_mask])
        entropy_right = calculate_entropy(y[right_mask])
        
        n_left, n_right = np.sum(left_mask), np.sum(right_mask)
        
        return entropy_before - (n_left/n * entropy_left + n_right/n * entropy_right)
    
    def _build_tree(self, X, y, depth=0):
        """递归构建决策树"""
        n_samples = len(y)
        
        # 停止条件
        if (self.max_depth is not None and depth >= self.max_depth) or \
           n_samples < self.min_samples_split or \
           len(np.unique(y)) == 1:
            return Counter(y).most_common(1)[0][0]
        
        # 找最优分裂
        best_feature, best_threshold, best_gain = self._best_split(X, y)
        
        if best_gain <= 0:
            return Counter(y).most_common(1)[0][0]
        
        # 分裂数据
        left_mask = X[:, best_feature] <= best_threshold
        right_mask = ~left_mask
        
        # 递归构建子树
        left_tree = self._build_tree(X[left_mask], y[left_mask], depth+1)
        right_tree = self._build_tree(X[right_mask], y[right_mask], depth+1)
        
        return {
            'feature': best_feature,
            'threshold': best_threshold,
            'left': left_tree,
            'right': right_tree
        }
    
    def fit(self, X, y):
        """训练模型"""
        self.tree = self._build_tree(X, y)
    
    def _predict_single(self, x, tree):
        """预测单个样本"""
        if not isinstance(tree, dict):
            return tree
        
        if x[tree['feature']] <= tree['threshold']:
            return self._predict_single(x, tree['left'])
        else:
            return self._predict_single(x, tree['right'])
    
    def predict(self, X):
        """预测"""
        return np.array([self._predict_single(x, self.tree) for x in X])
```

## 6. 优缺点分析

### 6.1 优点

| 优点 | 说明 |
|------|------|
| 可解释性强 | if-then规则易于理解 |
| 无需特征缩放 | 不受特征尺度影响 |
| 处理混合特征 | 可处理数值和类别特征 |
| 能做特征选择 | 自动进行特征选择 |
| 可视化 | 树结构可直观展示 |

### 6.2 缺点

| 缺点 | 说明 |
|------|------|
| 容易过拟合 | 完整树容易过拟合训练数据 |
| 对噪声敏感 | 数据变化可能导致完全���同���树 |
| 贪心局限 | 局部最优不一定是全局最优 |
| 忽略特征关联 | 假设特征独立分裂 |
| 不平衡问题 | 偏向多数类 |

## 8. 手工代码实现

### 8.1 完整ID3实现

```python
import numpy as np
from collections import Counter

def entropy(y):
    """计算信息熵"""
    counts = Counter(y)
    probs = [c / len(y) for c in counts.values()]
    return -np.sum(p * np.log2(p + 1e-9) for p in probs if p > 0)

def gini(y):
    """计算基尼指数"""
    counts = Counter(y)
    probs = [c / len(y) for c in counts.values()]
    return 1 - np.sum(p**2 for p in probs)

def information_gain(X, y, feature_idx, threshold, criterion='entropy'):
    """计算信息增益"""
    mask_low = X[:, feature_idx] <= threshold
    mask_high = ~mask_low
    
    if criterion == 'entropy':
        metric = entropy
    else:
        metric = gini
    
    n = len(y)
    gain = metric(y)
    
    if np.sum(mask_low) > 0:
        gain -= (np.sum(mask_low) / n) * metric(y[mask_low])
    if np.sum(mask_high) > 0:
        gain -= (np.sum(mask_high) / n) * metric(y[mask_high])
    
    return gain

class ID3Classifier:
    """ID3决策树分类器"""
    
    def __init__(self, max_depth=None, min_samples_leaf=1):
        self.max_depth = max_depth
        self.min_samples_leaf = min_samples_leaf
        self.tree = None
    
    def _find_best_split(self, X, y):
        """找最优分裂"""
        best_gain = -np.inf
        best_feature = None
        best_threshold = None
        
        n_features = X.shape[1]
        
        for feature in range(n_features):
            # 尝试不同阈值
            thresholds = np.unique(X[:, feature])
            for threshold in thresholds:
                if np.sum(X[:, feature] <= threshold) < self.min_samples_leaf:
                    continue
                if np.sum(X[:, feature] > threshold) < self.min_samples_leaf:
                    continue
                
                gain = information_gain(X, y, feature, threshold)
                
                if gain > best_gain:
                    best_gain = gain
                    best_feature = feature
                    best_threshold = threshold
        
        return best_feature, best_threshold, best_gain
    
    def _build_tree(self, X, y, depth=0):
        """递归构建树"""
        n_samples = len(y)
        n_classes = len(np.unique(y))
        
        # 停止条件
        if (self.max_depth and depth >= self.max_depth) or \
           n_samples < 2 * self.min_samples_leaf or \
           n_classes == 1:
            return Counter(y).most_common(1)[0][0]
        
        # 找最优分裂
        feature, threshold, gain = self._find_best_split(X, y)
        
        if gain <= 0:
            return Counter(y).most_common(1)[0][0]
        
        # 分裂
        left_mask = X[:, feature] <= threshold
        right_mask = ~left_mask
        
        left = self._build_tree(X[left_mask], y[left_mask], depth + 1)
        right = self._build_tree(X[right_mask], y[right_mask], depth + 1)
        
        return {
            'feature': feature,
            'threshold': threshold,
            'left': left,
            'right': right
        }
    
    def fit(self, X, y):
        """训练"""
        self.tree = self._build_tree(X, y)
        return self
    
    def _predict_one(self, x, tree):
        """预测单个样本"""
        if not isinstance(tree, dict):
            return tree
        if x[tree['feature']] <= tree['threshold']:
            return self._predict_one(x, tree['left'])
        return self._predict_one(x, tree['right'])
    
    def predict(self, X):
        """预测"""
        return np.array([self._predict_one(x, self.tree) for x in X])
```

```python
import matplotlib.pyplot as plt
import numpy as np

def plot_decision_boundary(model, X, y):
    """绘制决策边界"""
    h = 0.02
    x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
    y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
    
    xx, yy = np.meshgrid(np.arange(x_min, x_max, h),
                     np.arange(y_min, y_max, h))
    
    Z = model.predict(np.c_[xx.ravel(), yy.ravel()])
    Z = Z.reshape(xx.shape)
    
    plt.figure(figsize=(10, 8))
    plt.contourf(xx, yy, Z, alpha=0.3, cmap='RdYlGn')
    plt.scatter(X[:, 0], X[:, 1], c=y, cmap='RdYlGn', edgecolors='k')
    plt.xlabel('Feature 1')
    plt.ylabel('Feature 2')
    plt.title('Decision Tree Boundary')
```

```python
    DecisionTreeClassifier(max_depth=5),
    X, y, cv=5, scoring='accuracy'
)

print(f"CV Accuracy: {scores.mean():.4f} (+/- {scores.std()*2:.4f})")
```

## 11. 常见问题与易错点

### 11.1 过拟合问题

**问题**：树太深，对训练数据拟合过度

**解决方案**：
```python
# 预剪枝
clf = DecisionTreeClassifier(
    max_depth=5,           # 限制深度
    min_samples_split=10,  # 分裂最小样本
    min_samples_leaf=5,   # 叶节点最小样本
    ccp_alpha=0.01      # 成本复杂度剪枝
)
```

### 11.2 不平衡数据

**问题**：少数类被忽略

**解决方案**：
```python
clf = DecisionTreeClassifier(
    class_weight='balanced'  # 自动平衡
)

# 或手动设置权重
clf = DecisionTreeClassifier(
    class_weight={0: 1, 1: 10}  # 少数类权重更高
)
```

### 11.3 连续值处理不当

**问题**：未对连续值特征进行最佳分割

**解决**：确保算法遍历所有候选分割点。

### 11.4 特征选择偏差

**问题**：ID3偏向多值特征

**解决**：使用C4.5的增益率或CART的基尼指数

## 12. 学习总结

### 12.1 核心要点

1. **信息熵**：衡量数据纯度，$H(S) = -\sum p_i \log_2 p_i$
2. **信息增益**：分裂后熵的减少量，选择最大增益的特征
3. **基尼指数**：CART使用，$Gini = 1 - \sum p_i^2$
4. **剪枝策略**：预剪枝（max_depth）或后剪枝（ccp_alpha）

### 12.2 实用技巧

- 优先使用基尼指数（计算更快）
- 限制树的深度防止过拟合
- 使用集成方法（随机森林、梯度提升）提升性能
- 结合特征重要性进行特征选择

## 13. 练习题与思考题

### 13.1 基础题

**练习1**：计算信息熵
```
数据集: 15个样本，9正6负
计算信息熵H(S)
```

**答案**：
```
p(+) = 9/15 = 0.6, p(-) = 6/15 = 0.4
H(S) = -(0.6*log2(0.6) + 0.4*log2(0.4))
     = -(0.6*(-0.737) + 4*(-1.322))
     = 0.442 + 0.529 = 0.971
```

**练习2**：计算信息增益
```
特征A取值: sunny(3正1负), rainy(1正2负), overcast(2正0负)
计算Gain(S, A)
```

**答案**：
```
H(S) = 0.971
H(sunny) = -(0.75*log2(0.75) + 0.25*log2(0.25)) = 0.811
H(rainy) = -(0.33*log2(0.33) + 0.67*log2(0.67)) = 0.918
H(overcast) = 0 (纯)

Gain = 0.971 - (4/15)*0.811 - (3/15)*0.918
     = 0.971 - 0.216 - 0.184
     = 0.571
```
