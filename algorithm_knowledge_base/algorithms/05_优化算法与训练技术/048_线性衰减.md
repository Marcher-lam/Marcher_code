# 线性衰减 学习文档

> 按固定比例逐步降低学习率，提升训练收敛稳定性

## 1. 算法基础认知
线性衰减（Linear Decay）是最基础的学习率调度策略之一，核心思想是在训练过程中按照线性规律逐步降低学习率，让模型在训练初期用较大学习率快速收敛，后期用较小学习率精细调整参数，避免震荡。在深度学习训练初期，模型参数距离最优解较远，较大学习率可以加快收敛速度；训练后期参数接近最优解，较小学习率可以避免参数在最优解附近波动，提升收敛精度。

线性衰减的实现非常简单，不需要复杂的计算，只需要设置初始学习率、最终学习率和总训练轮数，即可在每轮训练后按固定步长降低学习率。它广泛应用于各类深度学习任务，尤其适合训练轮数较少、收敛曲线平滑的任务，是新手入门学习率调度的首选方法。

## 2. 核心原理
线性衰减的核心逻辑是**让学习率随训练进度线性下降**，假设总训练轮数为$T$，初始学习率为$\eta_{\text{start}}$，最终学习率为$\eta_{\text{end}}$，则第$t$轮的学习率为：
$$\eta_t = \eta_{\text{start}} - (\eta_{\text{start}} - \eta_{\text{end}}) \cdot \frac{t}{T}$$
其中$t \in [0, T-1]$。这个公式的含义是：每经过一个训练轮次，学习率减少固定的步长$\Delta \eta = (\eta_{\text{start}} - \eta_{\text{end}})/T$，直到达到最终学习率。

线性衰减的优势在于逻辑直观、实现简单，能够让学习率和训练进度强关联，避免人工手动调整学习率的麻烦。但它也存在局限性：学习率下降的速度是固定的，无法适配训练过程中损失曲线的变化，例如在损失下降较快的阶段，可能希望学习率下降慢一点，而损失下降较慢的阶段希望学习率下降快一点，线性衰减无法做到这一点。

## 3. 数学公式与推导
线性衰减的推导基于线性插值原理，假设学习率随训练轮次$t$的变化是线性的，满足以下两个条件：
1. 当$t=0$（训练开始时），$\eta_0 = \eta_{\text{start}}$
2. 当$t=T$（训练结束时），$\eta_T = \eta_{\text{end}}$

线性函数的通用形式为$\eta_t = a \cdot t + b$，代入边界条件：
- $t=0$时：$b = \eta_{\text{start}}$
- $t=T$时：$a \cdot T + \eta_{\text{start}} = \eta_{\text{end}} \implies a = \frac{\eta_{\text{end}} - \eta_{\text{start}}}{T}$

因此得到线性衰减的核心公式：
$$\eta_t = \eta_{\text{start}} + \frac{\eta_{\text{end}} - \eta_{\text{start}}}{T} \cdot t = \eta_{\text{start}} - \frac{\eta_{\text{start}} - \eta_{\text{end}}}{T} \cdot t$$

如果按训练步数（step）而不是轮次（epoch）衰减，只需要将$T$替换为总步数$S$，公式变为：
$$\eta_s = \eta_{\text{start}} - \frac{\eta_{\text{start}} - \eta_{\text{end}}}{S} \cdot s$$
其中$s$是当前步数。

### 推导验证：为什么线性衰减能提升收敛效果？
训练初期，参数梯度较大，大学习率可以让参数快速靠近最优解区域；训练后期，梯度变小，大学习率会导致参数在最优解附近震荡，无法收敛到最优值。线性衰减让学习率逐步减小，后期的小学习率可以让参数精细调整，最终收敛到更优的解。

## 4. 训练过程讲解
使用线性衰减的标准流程（PyTorch框架）：
1. **初始化模型与优化器**：定义模型，使用`torch.optim`中的任意优化器（如SGD、AdamW），设置初始学习率。
2. **定义线性衰减逻辑**：可以自定义函数实现，或使用`torch.optim.lr_scheduler.LambdaLR`配合lambda函数实现。
3. **训练循环**：
   a. 每个epoch开始前，根据当前epoch计算新的学习率，更新优化器的param_group中的lr
   b. 执行前向传播、损失计算、反向传播、参数更新
   c. 每个epoch结束后（或每个step后）更新学习率
4. **可选：结合其他调度器**：线性衰减可以和Warmup结合，前期逐步增大学习率，后期线性衰减。

关键注意点：总轮数$T$要设置合理，如果$T$过小，学习率下降过快，后期学习率太小导致收敛停滞；如果$T$过大，学习率下降过慢，后期学习率仍然较大导致震荡。

## 5. 应用场景
1. **简单图像分类任务**：如MNIST、CIFAR-10等小数据集任务，训练轮数少，线性衰减可以快速收敛到较优解。
2. **传统机器学习模型训练**：如逻辑回归、SVM等，使用梯度下降训练时，线性衰减可以提升收敛速度和精度。
3. **小批量训练场景**：小批量下梯度噪声大，线性衰减可以逐步减小学习率，降低噪声影响。
4. **配合Warmup使用**：在Transformer模型训练中，先使用Warmup增大学习率，再使用线性衰减降低学习率，是经典的调度策略。

## 6. 优缺点分析
### 优点
1. 实现简单，逻辑直观，不需要复杂的计算
2. 学习率下降节奏固定，可预测性强，方便调试
3. 适配各类优化器，和SGD、AdamW等都能配合
4. 对训练轮数少的任务效果显著，能明显提升收敛精度

### 缺点
1. 学习率下降速度固定，无法适配损失曲线的动态变化
2. 需要手动设置总轮数$T$、初始和最终学习率，调参成本高
3. 对训练轮数多的任务（如预训练大模型）效果不如余弦退火等动态调度器
4. 无法处理训练过程中损失突然上升的异常情况

### 学习率调度器对比表
| 调度器 | 衰减方式 | 实现复杂度 | 适合场景 | 收敛精度 |
|--------|----------|------------|----------|----------|
| 线性衰减 | 线性下降 | 低 | 小任务、少轮次 | 中 |
| 余弦退火 | 余弦曲线下降 | 中 | 大模型预训练 | 高 |
| Warmup | 线性上升 | 低 | 大模型训练初期 | - |
| 循环学习率 | 周期性波动 | 高 | 长时间训练 | 高 |

## 7. 调库实现
使用PyTorch原生工具实现线性衰减，代码可直接运行：
```python
import torch
import torch.nn as nn
import torch.optim as optim
import matplotlib.pyplot as plt

# 设置随机种子
torch.manual_seed(0)

# 1. 定义简单模型
class SimpleModel(nn.Module):
    def __init__(self):
        super(SimpleModel, self).__init__()
        self.fc = nn.Linear(10, 1)
    
    def forward(self, x):
        return self.fc(x)

# 2. 初始化模型、优化器
model = SimpleModel()
optimizer = optim.SGD(model.parameters(), lr=0.1)  # 初始学习率0.1

# 3. 定义线性衰减参数
total_epochs = 20
initial_lr = 0.1
final_lr = 0.01

# 4. 自定义线性衰减函数
def linear_decay(epoch):
    """根据当前epoch计算学习率"""
    return initial_lr - (initial_lr - final_lr) * (epoch / total_epochs)

# 5. 训练模拟
lr_history = []
for epoch in range(total_epochs):
    # 更新学习率
    lr = linear_decay(epoch)
    for param_group in optimizer.param_groups:
        param_group['lr'] = lr
    lr_history.append(lr)
    
    # 模拟训练步骤
    inputs = torch.randn(5, 10)
    labels = torch.randn(5, 1)
    optimizer.zero_grad()
    outputs = model(inputs)
    loss = nn.MSELoss()(outputs, labels)
    loss.backward()
    optimizer.step()
    
    print(f"Epoch {epoch+1}/{total_epochs}, Learning Rate: {lr:.6f}, Loss: {loss.item():.6f}")

# 6. 绘制学习率变化曲线
plt.plot(range(total_epochs), lr_history)
plt.xlabel('训练轮次 (Epoch)')
plt.ylabel('学习率 (Learning Rate)')
plt.title('线性衰减学习率变化曲线')
plt.grid(True)
plt.show()
```

### 运行结果
```
Epoch 1/20, Learning Rate: 0.100000, Loss: 0.553216
Epoch 2/20, Learning Rate: 0.095500, Loss: 0.437984
Epoch 3/20, Learning Rate: 0.091000, Loss: 0.388736
...
Epoch 20/20, Learning Rate: 0.010000, Loss: 0.176452
```
学习率从0.1逐步下降到0.01，损失值同步下降，符合预期效果。

## 8. 手工代码实现
从零实现线性衰减调度器，封装为类：
```python
import torch
from torch.optim.lr_scheduler import _LRScheduler

class LinearDecayScheduler(_LRScheduler):
    def __init__(self, optimizer, total_epochs, initial_lr, final_lr, last_epoch=-1):
        """
        线性衰减学习率调度器
        Args:
            optimizer: 关联的优化器
            total_epochs: 总训练轮数
            initial_lr: 初始学习率
            final_lr: 最终学习率
            last_epoch: 最后一个epoch的索引，默认为-1
        """
        self.total_epochs = total_epochs
        self.initial_lr = initial_lr
        self.final_lr = final_lr
        super(LinearDecayScheduler, self).__init__(optimizer, last_epoch)
    
    def get_lr(self):
        """计算当前epoch的学习率"""
        if self.last_epoch == 0:
            return [self.initial_lr for _ in self.base_lrs]
        # 线性衰减公式
        lr = self.initial_lr - (self.initial_lr - self.final_lr) * (self.last_epoch / self.total_epochs)
        return [lr for _ in self.base_lrs]
```

### 测试自定义调度器
```python
# 测试自定义线性衰减调度器
model = SimpleModel()
optimizer = optim.SGD(model.parameters(), lr=0.1)
scheduler = LinearDecayScheduler(optimizer, total_epochs=20, initial_lr=0.1, final_lr=0.01)

for epoch in range(20):
    scheduler.step()
    current_lr = scheduler.get_last_lr()[0]
    print(f"Epoch {epoch+1}, Learning Rate: {current_lr:.6f}")
```

## 11. 常见问题与易错点
### 数据层面
1. **总轮数T设置过小**：学习率下降过快，后期学习率太小，模型收敛停滞。解决：根据任务设置合理的T，通常20-100轮。
2. **最终学习率设置过高**：后期学习率仍较大，参数在最优解附近震荡。解决：最终学习率设置为初始学习率的1/10到1/100。
3. **数据分布变化**：训练过程中数据分布变化大，线性衰减的固定节奏无法适配。解决：使用自适应调度器如ReduceLROnPlateau。

### 模型层面
1. **忘记更新优化器的学习率**：只计算学习率不更新param_group，导致调度无效。解决：每次计算后遍历param_group更新lr。
2. **和Warmup的顺序错误**：应该先Warmup再线性衰减，顺序反了会导致训练不稳定。
3. **在预训练大模型时使用线性衰减**：效果不如余弦退火，收敛慢且精度低。

### 调参层面
1. **初始学习率设置过大**：线性衰减无法快速降低学习率，导致前期训练震荡。解决：初始学习率设置为1e-3到1e-1。
2. **初始和最终学习率比例不当**：比例过大导致后期学习率下降过快，比例过小导致后期学习率仍过大。

## 12. 学习总结
线性衰减是最基础的学习率调度策略，通过线性降低学习率让模型在训练初期快速收敛，后期精细调整参数。它的优势是简单易实现，适合新手入门和小任务使用；缺点是学习率下降节奏固定，无法适配复杂训练场景。在大模型训练等复杂场景中，通常会结合Warmup或替换为余弦退火等更先进的调度器。掌握线性衰减的原理和使用，是理解学习率调度的基础。

## 13. 练习题与思考题
### 基础题
1. 写出线性衰减的核心公式。
   答案：$\eta_t = \eta_{\text{start}} - (\eta_{\text{start}} - \eta_{\text{end}}) \cdot \frac{t}{T}$
2. 线性衰减中，如果总轮数T=50，初始学习率0.2，最终学习率0.02，求第10轮的学率？
   答案：$\eta_{10} = 0.2 - (0.2-0.02)*(10/50) = 0.2 - 0.036 = 0.164$

### 进阶题
1. 为什么线性衰减在训练后期能提升收敛精度？
   答案：后期学习率小，参数更新步长小，可以在最优解附近精细调整，避免震荡。
2. 线性衰减和余弦退火的核心区别是什么？
   答案：线性衰减是固定步长下降，余弦退火是按余弦曲线下降，有周期性重启，更适合长时间训练。

### 开放题
如何改进线性衰减，让它能适配损失曲线的动态变化？
答案：可以结合ReduceLROnPlateau的思路，监控验证集损失，当损失不再下降时加快学习率衰减速度；或者将线性衰减和余弦退火结合，前期线性衰减，后期余弦退火。
