# 蚁群优化 学习文档

> 模拟蚂蚁觅食行为的群体智能优化算法。

## 1. 算法基础认知

蚁群优化（Ant Colony Optimization, ACO）是一种基于种群寻优的元启发式算法，由Dorigo等人在1992年提出模拟蚂蚁觅食行为。算法通过模拟蚂蚁在移动过程中释放信息素并根据信息素浓度选择路径来实现优化。

**直觉类比**：观察蚂蚁觅食：一群蚂蚁在寻找食物时，会在走过的路径上留下一种叫做"信息素"的化学物质。短路径上信息素浓度高，因为蚂蚁往返次数多。其他蚂蚁会倾向于走信息素浓度高的路径，从而找到最短路径。这就是ACO的核心思想。

**历史背景**：ACO由Marco Dorigo在1992年提出，源自对蚂蚁真实行为的观察。

**前置知识**：组合优化基础、图论基础

## 2. 核心原理

**蚂蚁行为模拟**：
1. 随机搜索食物
2. 发现食物后返回巢穴并留下信息素
3. 其他蚂蚁跟随信息素
4. 信息素随时间蒸发

**核心公式**：
- 状态转移概率
- 信息素更新
- 信息素蒸发

## 3. 数学公式与推导

**符号约定**：
| 符号 | 含义 |
|------|------|
| τ_ij | 边(i,j)上的信息素 |
| η_ij | 启发因子（如距离的倒数） |
| α | 信息素重要程度 |
| β | 启发因子重要程度 |
| ρ | 信息素蒸发率 |

**状态转移概率**：
$$P_{ij}^k = \frac{[\tau_{ij}]^\alpha [\eta_{ij}]^\beta}{\sum_l [\tau_{il}]^\alpha [\eta_{il}]^\beta}$$

**信息素更新**：
$$\tau_{ij} \leftarrow (1-\rho)\tau_{ij} + \Delta\tau_{ij}$$

其中$\Delta\tau_{ij} = \sum_k \Delta\tau_{ij}^k$

## 4. 训练过程讲解

**算法流程**：
```
1. 初始化信息素
2. 对每只蚂蚁：
   a) 按概率选择下一城市
   b) 构建完整路径
3. 更新信息素
4. 重复直到收敛
```

**参数**：
| 参数 | 作用 | 范围 |
|------|------|------|
| α | 信息素影响 | 0-5 |
| β | 启发式影响 | 0-10 |
| ρ | 蒸发率 | 0-1 |
| m | 蚂蚁数量 | 10-50 |

## 5. 应用场景

- 旅行商问题（TSP）
- 车辆路径问题（VRP）
- 图着色问题
- 网络路由

## 6. 优缺点分析

**优点**：
1. 全局搜索能力强
2. 分布式计算
3. 适用于离散优化
4. 鲁棒性好

**缺点**：
1. 收敛速度慢
2. 参数敏感
3. 易陷入局部最优

## 7. 调库实现

```python
"""
蚁群优化算法实现 - 解决TSP
"""
import numpy as np
import matplotlib.pyplot as plt
from scipy.spatial import distance_matrix

class ACO_TSP:
    """蚁群优化解决TSP"""
    def __init__(self, n_ants=20, n_iter=100, alpha=1.0, beta=2.0, rho=0.5, q=100.0):
        self.n_ants = n_ants
        self.n_iter = n_iter
        self.alpha = alpha
        self.beta = beta
        self.rho = rho
        self.Q = q
        self.best_route = None
        self.best_length = float('inf')
        self.history = []
    
    def fit(self, cities):
        """
        训练
        cities: numpy array, shape (n_cities, 2)
        """
        n_cities = len(cities)
        
        # 计算距离矩阵
        self.dist_matrix = distance_matrix(cities, cities)
        # 启发式矩阵：距离的倒数
        self.eta = 1.0 / (self.dist_matrix + 1e-10)
        np.fill_diagonal(self.eta, 0)
        
        # 初始化信息素
        tau = np.ones((n_cities, n_cities))
        
        for iteration in range(self.n_iter):
            # ===== 构建解 =====
            all_routes = []
            all_lengths = []
            
            for _ in range(self.n_ants):
                route = self._construct_solution(tau, n_cities)
                length = self._route_length(route)
                all_routes.append(route)
                all_lengths.append(length)
                
                if length < self.best_length:
                    self.best_length = length
                    self.best_route = route.copy()
            
            self.history.append(self.best_length)
            
            # ===== 更新信息素 =====
            tau = (1 - self.rho) * tau
            
            for route, length in zip(all_routes, all_lengths):
                deposit = self.Q / length
                for i in range(n_cities - 1):
                    j, k = route[i], route[i+1]
                    tau[j, k] += deposit
                    tau[k, j] += deposit
                
                # 回到起点
                j, k = route[-1], route[0]
                tau[j, k] += deposit
                tau[k, j] += deposit
            
            if (iteration + 1) % 20 == 0:
                print(f"迭代 {iteration+1}: 最佳路径长度 = {self.best_length:.2f}")
        
        return self.best_route, self.best_length
    
    def _construct_solution(self, tau, n_cities):
        """构建解"""
        route = [np.random.randint(n_cities)]
        visited = set(route)
        
        for _ in range(n_cities - 1):
            current = route[-1]
            
            # 计算概率
            probs = []
            for next_city in range(n_cities):
                if next_city not in visited:
                    tau_val = tau[current, next_city] ** self.alpha
                    eta_val = self.eta[current, next_city] ** self.beta
                    probs.append(tau_val * eta_val)
                else:
                    probs.append(0)
            
            probs = np.array(probs)
            probs /= probs.sum()
            
            next_city = np.random.choice(n_cities, p=probs)
            route.append(next_city)
            visited.add(next_city)
        
        return route
    
    def _route_length(self, route):
        """计算路径长度"""
        length = 0
        for i in range(len(route) - 1):
            length += self.dist_matrix[route[i], route[i+1]]
        length += self.dist_matrix[route[-1], route[0]]
        return length

# 测试：城市坐标
np.random.seed(42)
n_cities = 15
cities = np.random.rand(n_cities, 2) * 100

print("开始ACO优化...")
aco = ACO_TSP(n_ants=20, n_iter=100, alpha=1.0, beta=2.0, rho=0.5)
best_route, best_length = aco.fit(cities)

print(f"\n最佳路径长度: {best_length:.2f}")
print(f"最佳路径: {best_route}")

# 可视化
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 城市和路径

ax.scatter(cities[:, 0], cities[:, 1], c='red', s=100, label='城市')

route_cities = cities[best_route]
ax.plot(route_cities[:, 0], route_cities[:, 1], 'b-', linewidth=2, label='路径')

       [route_cities[-1][1], route_cities[0][1]], 'b-', linewidth=2)

ax.set_title(f'ACO最优路径 (长度={best_length:.2f})')
ax.legend()
```

## 8. 手工代码实现

```python
"""
蚁群优化手工实现
"""
import numpy as np

class ACOTSPManual:
    """ACO手工实现"""
    def __init__(self, n_ants=15, n_iter=50, alpha=1.0, beta=1.5, rho=0.5):
        self.n_ants = n_ants
        self.n_iter = n_iter
        self.alpha = alpha
        self.beta = beta
        self.rho = rho
        self.best_route = None
        self.best_length = float('inf')
    
    def solve(self, cities):
        n = len(cities)
        dist = np.zeros((n, n))
        for i in range(n):
            for j in range(n):
                dist[i, j] = np.linalg.norm(cities[i] - cities[j])
        
        eta = 1.0 / (dist + 1e-10)
        np.fill_diagonal(eta, 0)
        
        tau = np.ones((n, n))
        
        for _ in range(self.n_iter):
            routes = []
            lengths = []
            
            for _ in range(self.n_ants):
                route = [0]
                visited = {0}
                
                while len(route) < n:
                    curr = route[-1]
                    probs = []
                    for next_city in range(n):
                        if next_city in visited:
                            probs.append(0)
                        else:
                            tau_val = tau[curr, next_city] ** self.alpha
                            eta_val = eta[curr, next_city] ** self.beta
                            probs.append(tau_val * eta_val)
                    
                    probs = np.array(probs)
                    probs /= probs.sum()
                    next_city = np.random.choice(n, p=probs)
                    route.append(next_city)
                    visited.add(next_city)
                
                length = sum(dist[route[i], route[i+1]] for i in range(n-1))
                length += dist[route[-1], route[0]]
                
                routes.append(route)
                lengths.append(length)
                
                if length < self.best_length:
                    self.best_length = length
                    self.best_route = route.copy()
            
            tau = (1 - self.rho) * tau
            
            for route, length in zip(routes, lengths):
                deposit = 1.0 / length
                for i in range(n-1):
                    j, k = route[i], route[i+1]
                    tau[j, k] += deposit
                    tau[k, j] += deposit
        
        return self.best_route, self.best_length

# 测试
cities = np.array([[0, 0], [1, 3], [4, 1], [3, 4], [2, 2]])
solver = ACOTSPManual()
route, length = solver.solve(cities)
print(f"最佳路径: {route}, 长度: {length:.2f}")
```

## 11. 常见问题与易错点

### 常见问题
**Q1: 训练不收敛？**
- 检查学习率是否合适
- 检查数据是否正确归一化
- 确认损失函数是否匹配任务

**Q2: 过拟合严重？**
- 增加数据量或使用数据增强
- 添加正则化（L1/L2/Dropout）
- 使用早停策略

**Q3: 超参数如何选？**
- 网格搜索或随机搜索
- 贝叶斯优化
- 参考论文推荐值

### 易错点
1. 数据泄露：预处理时使用测试集信息
2. 随机种子：忘记设置导致不可复现
3. 维度错误：输入shape与模型不匹配
4. 梯度问题：需要适当初始化和裁剪
5. 评估偏差：在训练集上评估
