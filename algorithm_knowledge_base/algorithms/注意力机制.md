# 注意力机制学习文档

## 1. 算法基础认知

注意力机制（Attention Mechanism）是深度学习中最重要的技术突破之一，它让神经网络能够"选择性地"关注输入的某些部分，而不是同等对待全部信息。灵感来源于人类的视觉注意力系统——当我们观察场景时，会自然地聚焦于重要区域，而忽略背景中的次要细节。在深度学习中，注意力机制使模型能够动态地决定哪些输入特征对当前任务最有价值。

注意力机制最早在计算机视觉领域提出，随后被广泛应用于自然语言处理。2014年，Bahdanau等人将注意力引入机器翻译，提出了"对齐"（Alignment）的概念，让模型能够自动学习源语言和目标语言之间的词对应关系。这一创新显著提升了翻译质量，并成为后续许多模型的基础。

理解注意力机制对于学习现代深度学习模型至关重要。从最初的Seq2Seq模型，到后来的Transformer、BERT、GPT，甚至是视觉Transformer，注意力机制无处不在。掌握注意力机制的本质、数学原理和各种变体，是成为深度学习专家的必备知识。

## 2. 核心原理

注意力机制的核心原理可以概括为三个步骤：**计算注意力分数→Softmax归一化→加权求和**。给定查询（Query）、键（Key）和值（Value），注意力的计算过程为：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

其中 $Q \in \mathbb{R}^{n_q \times d_k}$ 是查询向量，$K \in \mathbb{R}^{n_k \times d_k}$ 是键向量，$V \in \mathbb{R}^{n_k \times d_v}$ 是值向量。注意力分数 $QK^T$ 衡量查询和键之间的相关性，Softmax将分数转换为概率分布，最后用这个分布对值进行加权求和。

在机器翻译中，$Q$ 来自解码器的当前状态，$K$ 和 $V$ 来自编码器的输出（源语言表示）。注意力权重 $\alpha_{i,j}$ 表示目标语言位置 $i$ 对源语言位置 $j$ 的关注程度。加权求和得到的上下文向量 $c_i = \sum_j \alpha_{i,j} v_j$ 包含了源语言中与当前位置最相关的信息。

注意力机制的优势在于：
1. **动态选择**：根据当前上下文动态决定关注哪些部分
2. **长距离依赖**：直接建立任意位置之间的联系
3. **可解释性**：注意力权重可以可视化，理解模型决策
4. **并行计算**：所有位置的注意力可以并行计算

## 3. 数学公式与推导

### 3.1 注意力机制的基本形式

设输入序列 $X = [x_1, x_2, ..., x_n]$，注意力机制通过一个查询向量 $q$ 来计算对每个输入的注意力：

$$e_i = \text{score}(q, x_i)$$

$$\alpha_i = \frac{\exp(e_i)}{\sum_{j=1}^{n} \exp(e_j)}$$

$$c = \sum_{i=1}^{n} \alpha_i x_i$$

其中 $e_i$ 是注意力分数，$\alpha_i$ 是归一化后的注意力权重，$c$ 是上下文向量。

### 3.2 注意力分数的不同计算方式

**加性注意力（Bahdanau）**：
$$e = v^T \tanh(W_q q + W_k k)$$

**点积注意力（Scaled Dot-Product）**：
$$e = \frac{q^T k}{\sqrt{d_k}}$$

**双线性注意力（Luong）**：
$$e = q^T W k$$

**拼接注意力**：
$$e = w^T [q; k]$$

### 3.3 缩放点积注意力的推导

设查询向量 $q \in \mathbb{R}^{d_k}$ 和键向量 $k \in \mathbb{R}^{d_k}$ 是独立同分布的随机向量，均值为0，方差为1。点积 $s = q^T k$ 的期望为：

$$E[s] = E[q^T k] = E[q]^T E[k] = 0$$

方差为：
$$\text{Var}(s) = E[s^2] - E[s]^2 = E\left[\sum_i q_i^2 k_i^2\right] = d_k \cdot \text{Var}(q) \cdot \text{Var}(k) = d_k$$

当 $d_k$ 很大时，点积的方差为 $d_k$，标准差为 $\sqrt{d_k}$。Softmax函数在输入值很大时会接近one-hot分布，梯度很小。除以 $\sqrt{d_k}$ 可以将方差归一化到1，使Softmax工作在梯度较大的区域。

### 3.4 多头注意力

单头注意力只能捕捉一种类型的相关性，多头注意力通过并行运行多个注意力"头"来捕捉多种相关性：

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O$$

其中 $\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$。每个头有独立的参数矩阵，可以学习不同类型的关系。

### 3.5 注意力权重可视化解释

注意力权重 $\alpha_{i,j}$ 的含义：
- $\alpha_{i,j} \approx 0$：位置 $i$ 几乎不关注位置 $j$
- $\alpha_{i,j} \approx 1$：位置 $i$ 只关注位置 $j$
- $\sum_j \alpha_{i,j} = 1$：所有注意力权重的和为1（概率分布）

## 4. 训练过程讲解

### 4.1 基础注意力实现

以下是PyTorch实现的标准注意力机制：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class Attention(nn.Module):
    """基础注意力模块"""
    
    def __init__(self, d_model, d_k, d_v):
        super(Attention, self).__init__()
        
        self.d_k = d_k
        self.d_v = d_v
        
        self.W_Q = nn.Linear(d_model, d_k)
        self.W_K = nn.Linear(d_model, d_k)
        self.W_V = nn.Linear(d_model, d_v)
        
        self.W_O = nn.Linear(d_v, d_model)
    
    def forward(self, Q, K, V, mask=None):
        """
        Args:
            Q: (batch, q_len, d_model)
            K: (batch, k_len, d_model)
            V: (batch, k_len, d_model)
            mask: (batch, q_len, k_len)
        
        Returns:
            output: (batch, q_len, d_model)
            attention weights: (batch, q_len, k_len)
        """
        batch_size = Q.size(0)
        
        Q = self.W_Q(Q)
        K = self.W_K(K)
        V = self.W_V(V)
        
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        
        attn_weights = F.softmax(scores, dim=-1)
        
        context = torch.matmul(attn_weights, V)
        
        output = self.W_O(context)
        
        return output, attn_weights


class MultiHeadAttention(nn.Module):
    """多头注意力"""
    
    def __init__(self, d_model, n_heads, dropout=0.1):
        super(MultiHeadAttention, self).__init__()
        
        assert d_model % n_heads == 0, "d_model must be divisible by n_heads"
        
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        
        self.W_Q = nn.Linear(d_model, d_model)
        self.W_K = nn.Linear(d_model, d_model)
        self.W_V = nn.Linear(d_model, d_model)
        self.W_O = nn.Linear(d_model, d_model)
        
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, Q, K, V, mask=None):
        batch_size = Q.size(0)
        
        Q = self.W_Q(Q).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_K(K).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_V(V).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        if mask is not None:
            if mask.dim() == 2:
                mask = mask.unsqueeze(1).unsqueeze(2)
            elif mask.dim() == 3:
                mask = mask.unsqueeze(1)
            scores = scores.masked_fill(mask == 0, -1e9)
        
        attn_weights = F.softmax(scores, dim=-1)
        attn_weights = self.dropout(attn_weights)
        
        context = torch.matmul(attn_weights, V)
        
        context = context.transpose(1, 2).contiguous().view(batch_size, -1, self.d_model)
        
        output = self.W_O(context)
        
        return output, attn_weights


class AdditiveAttention(nn.Module):
    """加性注意力（Bahdanau attention）"""
    
    def __init__(self, d_model):
        super(AdditiveAttention, self).__init__()
        
        self.W_a = nn.Linear(d_model, d_model)
        self.U_a = nn.Linear(d_model, d_model)
        self.v = nn.Linear(d_model, 1)
    
    def forward(self, Q, K, V, mask=None):
        """
        Args:
            Q: (batch, q_len, d_model)
            K: (batch, k_len, d_model)
            V: (batch, k_len, d_model)
        """
        q_expanded = self.W_a(Q).unsqueeze(2)
        k_expanded = self.U_a(K).unsqueeze(1)
        
        e = self.v(torch.tanh(q_expanded + k_expanded)).squeeze(-1)
        
        if mask is not None:
            e = e.masked_fill(mask == 0, -1e9)
        
        attn_weights = F.softmax(e, dim=-1)
        
        context = torch.matmul(attn_weights, V)
        
        return context, attn_weights


class DotProductAttention(nn.Module):
    """点积注意力（无缩放）"""
    
    def __init__(self):
        super(DotProductAttention, self).__init__()
    
    def forward(self, Q, K, V, mask=None):
        scores = torch.matmul(Q, K.transpose(-2, -1))
        
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        
        attn_weights = F.softmax(scores, dim=-1)
        context = torch.matmul(attn_weights, V)
        
        return context, attn_weights
```

```python
def create_padding_mask(seq, pad_idx=0):
    """创建padding mask"""
    return (seq == pad_idx)


def create_causal_mask(seq_len):
    """创建因果mask（上三角）"""
    mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1) == 1
    return mask


def create_cross_mask(src_seq, tgt_seq):
    """创建交叉mask"""
    src_mask = torch.zeros(src_seq.size(1), tgt_seq.size(1))
    src_mask = src_mask.masked_fill(torch.arange(tgt_seq.size(1)).unsqueeze(0) > 
                                 torch.arange(src_seq.size(1)).unsqueeze(1), 1)
    return src_mask.bool()


class MaskedAttention(nn.Module):
    """带掩码的注意力"""
    
    def __init__(self, d_model):
        super(MaskedAttention, self).__init__()
        
        self.attention = Attention(d_model, d_model, d_model)
    
    def forward(self, Q, K, V, mask):
        output, weights = self.attention(Q, K, V, mask)
        
        return output, weights
```

## 5. 应用场景

注意力机制的应用非常广泛：

### 5.1 机器翻译

编码器-解码器架构中，注意力允许解码器关注源语言的不同部分，实现对齐翻译。

### 5.2 文本摘要

根据当前生成位置，从原文中选择最相关的词来生成摘要。

### 5.3 问答系统

从问题出发，在给定上下文（文档）中找到答案位置。

### 5.4 图像标注

用注意力选择图像中与描述最相关的区域。

### 5.5 语音识别

在声学模型和语言模型之间建立注意力连接。

### 5.6 推荐系统

根据用户历史，注意力选择性地关注item的某些特征。

## 6. 优缺点分析

### 6.1 优点

1. **提升性能**：显著提升各种NLP任务的效果
2. **并行化**：比RNN更易并行计算
3. **可解释性**：注意力权重可可视化
4. **通用性**：适用于多种任务和数据类型

### 6.2 缺点

1. **计算复杂度**：$O(n^2)$ 的时间和空间
2. **内存消耗**：注意力矩阵需要大��内��
3. **位置信息**：需要额外编码位置（对自注意力）
4. **长序列问题**：对非常长的序列仍有问题

### 6.3 改进方法

1. **稀疏注意力**：只关注部分位置
2. **局部+全局**：结合局部和全局注意力
3. **线性注意力**：使用核函数近似
4. **分层注意力**：如Swin的分层设计

```python
import torch
import torch.nn as nn
import math


def train_with_attention():
    """带注意力的Seq2Seq训练"""
    
    class Encoder(nn.Module):
        def __init__(self, vocab_size, d_model, n_layers):
            super(Encoder, self).__init__()
            self.embedding = nn.Embedding(vocab_size, d_model)
            self.lstm = nn.LSTM(d_model, d_model, n_layers, batch_first=True)
        
        def forward(self, x):
            embedded = self.embedding(x)
            output, (hidden, cell) = self.lstm(embedded)
            return output, hidden, cell
    
    class AttentionDecoder(nn.Module):
        def __init__(self, vocab_size, d_model, n_layers):
            super(AttentionDecoder, self).__init__()
            self.embedding = nn.Embedding(vocab_size, d_model)
            self.attention = nn.Linear(d_model * 2, d_model)
            self.lstm = nn.LSTM(d_model * 2, d_model, n_layers, batch_first=True)
            self.output = nn.Linear(d_model, vocab_size)
        
        def forward(self, x, encoder_output):
            embedded = self.embedding(x)
            
            attn_weights = torch.bmm(encoder_output, encoder_output.transpose(1,2))
            attn_weights = F.softmax(attn_weights, dim=-1)
            
            context = torch.bmm(attn_weights, encoder_output)
            
            lstm_input = torch.cat([embedded, context], dim=-1)
            
            output, (hidden, cell) = self.lstm(lstm_input)
            
            output = self.output(output)
            
            return output, attn_weights
    
    return Encoder, AttentionDecoder


class TransformerAttention(nn.Module):
    """Transformer中的注意力"""
    
    def __init__(self, d_model, n_heads):
        super(TransformerAttention, self).__init__()
        
        self.attention = nn.MultiheadAttention(d_model, n_heads)
        self.norm = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(0.1)
    
    def forward(self, x, mask=None):
        attn_output, attn_weights = self.attention(x, x, x, attn_mask=mask)
        x = self.norm(x + self.dropout(attn_output))
        
        return x, attn_weights


def visualize_attention(attn_weights, src_tokens, tgt_tokens):
    """可视化注意力"""
    import matplotlib.pyplot as plt
    import numpy as np
    
    fig, ax = plt.subplots(figsize=(10, 10))
    
    im = ax.imshow(attn_weights, cmap='viridis')
    
    ax.set_xticks(range(len(src_tokens)))
    ax.set_yticks(range(len(tgt_tokens)))
    ax.set_xticklabels(src_tokens, rotation=90)
    ax.set_yticklabels(tgt_tokens)
    
    plt.colorbar(im)
    ax.set_title("Attention Weights")
    
    return fig


class AttentionPooling(nn.Module):
    """注意力池化"""
    
    def __init__(self, d_model):
        super(AttentionPooling, self).__init__()
        
        self.attention_scores = nn.Linear(d_model, 1)
        self.softmax = nn.Softmax(dim=-2)
    
    def forward(self, x):
        """
        x: (batch, seq_len, d_model)
        """
        scores = self.attention_scores(x).squeeze(-1)
        
        weights = self.softmax(scores.unsqueeze(-2)).transpose(-2, -1)
        
        pooled = torch.sum(x * weights.squeeze(-2), dim=-2)
        
        return pooled, weights.squeeze(-2)


class ConcatenateAttention(nn.Module):
    """拼接注意力"""
    
    def __init__(self, d_model):
        super(ConcatenateAttention, self).__init__()
        
        self.W = nn.Linear(d_model * 2, d_model)
        self.v = nn.Linear(d_model, 1)
    
    def forward(self, query, key_value):
        """
        query: (batch, q_len, d_model)
        key_value: (batch, k_len, d_model)
        """
        q_expanded = query.unsqueeze(2)
        k_expanded = key_value.unsqueeze(1)
        
        concatenated = torch.cat([q_expanded, k_expanded], dim=-1)
        
        e = self.v(torch.tanh(self.W(concatenated))).squeeze(-1)
        
        attn_weights = F.softmax(e, dim=-1)
        
        context = torch.bmm(attn_weights, key_value)
        
        return context, attn_weights


def demo():
    """演示"""
    d_model = 512
    n_heads = 8
    seq_len = 10
    batch = 2
    
    x = torch.randn(batch, seq_len, d_model)
    
    attn = TransformerAttention(d_model, n_heads)
    output, weights = attn(x)
    
    print(f"Input shape: {x.shape}")
    print(f"Output shape: {output.shape}")
    print(f"Attention weights shape: {weights.shape}")


if __name__ == "__main__":
    demo()
```

```python
import numpy as np
import math


class NumPyAttention:
    """NumPy实现的注意力"""
    
    def __init__(self, d_k):
        self.d_k = d_k
    
    def softmax(self, x, axis=-1):
        exp_x = np.exp(x - np.max(x, axis=axis, keepdims=True))
        return exp_x / np.sum(exp_axis, axis=axis, keepdims=True)
    
    def forward(self, Q, K, V, mask=None):
        """
        Q: (q_len, d_k)
        K: (k_len, d_k)
        V: (k_len, d_v)
        """
        scores = np.dot(Q, K.T) / math.sqrt(self.d_k)
        
        if mask is not None:
            scores = np.where(mask, -1e9, scores)
        
        attn_weights = self.softmax(scores, axis=-1)
        
        context = np.dot(attn_weights, V)
        
        return context, attn_weights


class NumPyMultiHeadAttention:
    """NumPy实现的多头注意力"""
    
    def __init__(self, d_model, n_heads):
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        
        scale = 0.01
        
        self.W_Q = np.random.randn(d_model, d_model) * scale
        self.W_K = np.random.randn(d_model, d_model) * scale
        self.W_V = np.random.randn(d_model, d_model) * scale
        self.W_O = np.random.randn(d_model, d_model) * scale
    
    def forward(self, x, mask=None):
        """
        x: (batch, seq_len, d_model)
        """
        batch_size, seq_len, _ = x.shape
        
        Q = np.einsum('bld,dd->bld', x, self.W_Q)
        K = np.einsum('bld,dd->bld', x, self.W_K)
        V = np.einsum('bld,dd->bld', x, self.W_V)
        
        Q = Q.reshape(batch_size, seq_len, self.n_heads, self.d_k).transpose(0, 2, 1, 3)
        K = K.reshape(batch_size, seq_len, self.n_heads, self.d_k).transpose(0, 2, 1, 3)
        V = V.reshape(batch_size, seq_len, self.n_heads, self.d_k).transpose(0, 2, 1, 3)
        
        attn = NumPyAttention(self.d_k)
        
        heads = []
        for i in range(self.n_heads):
            head_out, head_weights = attn.forward(Q[:, i], K[:, i], V[:, i],
                                                  mask[:, i] if mask is not None else None)
            heads.append(head_out)
        
        concatenated = np.concatenate(heads, axis=-1)
        
        output = np.einsum('bld,dd->bld', concatenated, self.W_O)
        
        return output

    output = attn.forward(x)

    print(f"Output shape: {output.shape}")

    demo()
```

```python
import matplotlib.pyplot as plt
import numpy as np


def plot_attention_patterns():
    """可视化注意力模式"""
    
    fig, axes = plt.subplots(2, 2, figsize=(12, 12))
    
    patterns = ['Local', 'Global', 'Sparse', 'Random']
    seq_len = 20
    
    for ax, pattern in zip(axes.flatten(), patterns):
        attn = np.zeros((seq_len, seq_len))
        
        if pattern == 'Local':
            for i in range(seq_len):
                for j in range(max(0, i-2), min(seq_len, i+3)):
                    attn[i, j] = 1
        
        elif pattern == 'Global':
            attn[:] = 1
        
        elif pattern == 'Sparse':
```
