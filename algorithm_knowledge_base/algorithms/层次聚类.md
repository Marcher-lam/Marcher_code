# 层次聚类（Hierarchical Clustering）学习文档

> 基于树状结构（树形图）进行数据聚类的方法，通过构建层次化的嵌套簇来发现数据的层次结构

---

## 1. 算法基础认知

**一句话定义**：层次聚类是一种构建数据层次化嵌套结构的聚类方法，通过自底向上（凝聚）或自顶向下（分裂）的方式逐步形成簇的层次结构，最终输出一个树状图（dendrogram）来表示数据的层次关系。

**直觉类比**：层次聚类就像整理一个大型图书馆的书籍——首先按学科大类分（文学、科学、历史），然后每个大类继续细分（文学下分小说、诗歌、戏剧），最后细分到具体每本书。这种分层结构让你可以按不同粒度查看和组织数据。

**历史背景**：层次聚类的概念可追溯到20世纪60年代的数值分类学。Kaufman和Rousseeuw在2009年的著作中系统介绍了AGNES（凝聚层次聚类）和DIANA（分裂层次聚类）算法，使其成为聚类分析的基础方法之一。

**算法定位**：
- 类型：无监督学习 → 聚类
- 输出：树状图（dendrogram）+ 聚类标签
- 模型类型：层次聚类模型

**前置知识**：
- [必备]：聚类基础概念（簇、距离）
- [必备]：树状数据结构
- [扩展]：其他聚类算法（K-Means）

## 2. 核心原理

### 2.1 核心思想

层次聚类的核心思想是**通过逐步合并或分割数据点，构建一个层次化的簇结构**。与K-Means不同，层次聚类不需要预先指定簇的数量，可以从生成的层次树中选择任意级别的划分。

核心思想可以概括为：**以距离度量为基础，通过最近邻合并/分割原则，逐步构建数据的层次树结构**。

### 2.2 工作流程

**凝聚层次聚类（AGNES）**：
1. 初始状态：每个数据点作为一个单独的簇
2. 计算所有簇对之间的距离
3. 合并最近的两个簇
4. 重复步骤2-3，直至所有数据合并为一个簇
5. 输出树状图，选择合适的切割层级

**分裂层次聚类（DIANA）**：
1. 初始状态：所有数据点作为一个簇
2. 选择一个簇，使用K-Means等方法分裂
3. 重复分裂过程
4. 直至每个数据点单独成簇
5. 输出树状图

### 2.3 关键概念解释

- **树状图（Dendrogram）**：层次聚类的可视化树形图，展示簇的合并/分裂过程

- **链接方法（Linkage Method）**：定义簇间距离的计算方式
  - 最近链接（Single）：簇中最近两点距离
  - 最远链接（Complete）：簇中最远两点距离
  - 平均链接（Average）：簇中所有点对距离的平均
  - Ward：合并后簇内方差增量

- **距离度量**：点间距离（欧氏距离、曼哈顿距离、余弦相似度）

- **切割树状图**：在某个层级切断树状图得到指定数量的簇

### 2.4 几何/直观解释

在数据空间中，层次聚类的结果可以看作一组嵌套的球体。每一层合并/分割都对应一个包含更小或更大球的容器。树状图的Y轴表示合并/分割时的距离，X轴表示数据点。通过在不同高度切割，可以得到不同粒度的聚类结果。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 | 维度 |
|------|------|------|
| $X$ | 数据矩阵 | $n \times d$ |
| $d(i,j)$ | 点 $i$ 和 $j$ 之间的距离 | scalar |
| $D(C_i, C_j)$ | 簇 $C_i$ 和 $C_j$ 之间的距离 | scalar |
| $L$ | 树状图的切割层级 | scalar |

### 3.2 问题形式化

给定数据 $X = \{x_1, ..., x_n\}$，层次聚类的目标是构建数据的层次结构：

$$h = \text{HierarchicalCluster}(X)$$

其中 $h$ 是一个树状结构，每个内部节点表示一次簇的合并/分割。

### 3.3 链接方法

**Single Linkage**：
$$D(C_i, C_j) = \min_{x \in C_i, y \in C_j} d(x, y)$$

**Complete Linkage**：
$$D(C_i, C_j) = \max_{x \in C_i, y \in C_j} d(x, y)$$

**Average Linkage**：
$$D(C_i, C_j) = \frac{1}{|C_i||C_j|} \sum_{x \in C_i}\sum_{y \in C_j} d(x, y)$$

**Ward Linkage**：
$$D(C_i \cup C_j) - D(C_i) - D(C_j)$$

其中 $D(C) = \sum_{x \in C} \|x - \mu_C\|^2$，$\mu_C$ 是簇 $C$ 的中心。

### 3.4 合并过程

```
初始：C = [{x1}, {x2}, ..., {xn}]
repeat:
    find (Ci, Cj) with min D(Ci, Cj)
    Cnew = Ci ∪ Cj
    C = C - {Ci, Cj} ∪ {Cnew}
until |C| = 1
```

## 5. 应用场景

### 5.1 典型应用（3-5个）

**应用1：基因表达数据分析**
- 问题类型：发现基因的功能层次关系
- 为什么适合：基因数据有自然的层次结构
- 实际案例：微阵列数据分析

**应用2：文档组织**
- 问题类型：按主题层次组织文档
- 为什么适合：文档内容有主题层次

**应用3：客户细分**
- 问题类型：发现客户的多层次细分
- 为什么适合：客户特征有层级关系

**应用4：图像分割**
- 问题类型：图像的区域层次分割
- 为什么适合：图像区域有空间层次

### 5.2 适用数据特征

- 数据有自然的层次结构
- 需要不同粒度的聚类结果
- 数据量不大（O(n²)复杂度）

### 5.3 不适用场景

- 数据量大（计算复杂度过高）
- 数据没有明显层次结构
- 需要快速结果

---

## 6. 优缺点分析

### 6.1 优点（3-5个）

1. **层次结构**：输出完整的层次树
2. **无需预设K**：可事后选择簇数量
3. **可解释性强**：树状图直观
4. **确定性结果**：给定数据结果确定

### 6.2 缺点（3-5个）

1. **计算复杂**：O(n²)空间和时间
2. **对噪声敏感**：噪声影响合并
3. **不可逆**：合并后无法分割
4. **内存限制**：大数据有挑战

### 6.3 与同类算法对比

| 维度 | 层次聚类 | K-Means | DBSCAN |
|------|----------|--------|-------|
| 层次 | 有 | 无 | 可有 |
| K预设 | 不需要 | 需要 | 不需要 |
| 复杂度 | O(n²) | O(kn) | O(nlogn) |
| 形状 | 任意 | 球形 | 任意 |

```python
"""
层次聚类 调库实现

import numpy as np
import matplotlib.pyplot as plt
from scipy.cluster.hierarchy import linkage, dendrogram, fcluster
from scipy.spatial.distance import pdist
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import make_blobs


# ===============================
# 1. 数据准备
# ===============================
def generate_sample_data():
    """生成示例数据"""
    np.random.seed(42)
    
    # 生成三簇数据，有层次结构
    X1, _ = make_blobs(n_samples=50, centers=[[0, 0]], cluster_std=0.3)
    X2, _ = make_blobs(n_samples=30, centers=[[3, 3]], cluster_std=0.3)
    X3, _ = make_blobs(n_samples=20, centers=[[6, 0]], cluster_std=0.3)
    
    # 合并
    X = np.vstack([X1, X2, X3])
    
    return X


# ===============================
# 2. 层次聚类实现
# ===============================
class HierarchicalClustering:
    """层次聚类"""
    
    def __init__(self, method='ward', metric='euclidean'):
        """
        Args:
            method: 链接方法 (ward/complete/average/single)
            metric: 距离度量
        """
        self.method = method
        self.metric = metric
        self.Z = None
        self.labels_ = None
    
    def fit(self, X):
        """
        训练层次聚类
        
        Args:
            X: 数据矩阵 (n_samples, n_features)
        """
        # 标准化
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        
        # 层次聚类
        self.Z = linkage(X_scaled, method=self.method, metric=self.metric)
        
        return self
    
    def get_clusters(self, n_clusters):
        """获取指定数量的簇"""
        self.labels_ = fcluster(self.Z, n_clusters, criterion='maxclust')
        return self.labels_
    
    def get_dendrogram(self):
        """返回树状图"""
        return self.Z
    
    def plot_dendrogram(self, X=None, labels=None):
        """绘制树状图"""
        plt.figure(figsize=(12, 6))
        
        if labels is not None:
            dendrogram(self.Z, leaf_rotation=90, leaf_font_size=6)
        else:
            dendrogram(self.Z)
        
        plt.title(f'层次聚类树状图 (method={self.method})')
        plt.xlabel('样本')
        plt.ylabel('距离')
        
        return plt


# ===============================
# 3. 评估
# ===============================
def evaluate_clustering(X, labels):
    """评估聚类质量"""
    from sklearn.metrics import silhouette_score, calinski_harabasz_score
    
    # 轮廓系数
    silhouette = silhouette_score(X, labels)
    
    # CH指数
    ch = calinski_harabasz_score(X, labels)
    
    print(f"轮廓系数: {silhouette:.4f}")
    print(f"CH指数: {ch:.4f}")
    
    return silhouette, ch


# ===============================
# 4. 主程序

if __name__ == "__main__":
```

## 8. 手工代码实现

### 8.1 核心算法手写

```python
"""
层次聚类 手工实现
核心：简化版凝聚层次聚类
"""

import numpy as np
from scipy.spatial.distance import pdist, squareform


class HierarchicalClusteringManual:
    """手工实现的层次聚类"""
    
    def __init__(self, method='single'):
        self.method = method
        self.Z = None
        self.labels_ = None
    
    def _compute_distance(self, X):
        """计算距离矩阵"""
        distances = pdist(X, metric='euclidean')
        return squareform(distances)
    
    def _cluster_distance(self, C1, C2):
        """计算簇间距离"""
        if self.method == 'single':
            # 最近点距离
            min_dist = float('inf')
            for i in C1:
                for j in C2:
                    dist = self.dist_matrix[i][j]
                    if dist < min_dist:
                        min_dist = dist
            return min_dist
        
        elif self.method == 'complete':
            # 最远点距离
            max_dist = 0
            for i in C1:
                for j in C2:
                    dist = self.dist_matrix[i][j]
                    if dist > max_dist:
                        max_dist = dist
            return max_dist
        
        elif self.method == 'average':
            # 平均距离
            total = 0
            count = 0
            for i in C1:
                for j in C2:
                    total += self.dist_matrix[i][j]
                    count += 1
            return total / count
    
    def fit(self, X):
        """拟合数据"""
        n = X.shape[0]
        
        # 初始化：每个点一个簇
        clusters = [{i} for i in n]
        
        # 距离矩阵
        self.dist_matrix = self._compute_distance(X)
        
        # 记录合并过程
        self.Z = np.zeros((n-1, 4))
        
        # 合并步骤
        step = 0
        cluster_id = n
        
        while len(clusters) > 1 and step < n-1:
            min_dist = float('inf')
            merge = (0, 1)
            
            # 找到最近的簇对
            for i in range(len(clusters)):
                for j in range(i+1, len(clusters)):
                    d = self._cluster_distance(list(clusters[i]), list(clusters[j]))
                    if d < min_dist:
                        min_dist = d
                        merge = (i, j)
            
            # 记录合并
            C1, C2 = clusters[merge[0]], clusters[merge[1]]
            self.Z[step] = [min(C1), min(C2), min_dist, len(C1)+len(C2)]
            
            # 合并簇
            new_cluster = list(C1) + list(C2)
            clusters.pop(merge[1])
            clusters.pop(merge[0])
            clusters.append(set(new_cluster))
            
            step += 1
    
    def get_clusters(self, n_clusters):
        """获取指定数量的簇"""
        n = len(self.Z) + 1
        
        if n_clusters > n:
            n_clusters = n
        
        # 构建合并树
        self.labels_ = np.zeros(n, dtype=int)
        
        for step in range(n - n_clusters):
            if step == 0:
                clusters = self.Z[step:]
            else:
                clusters = self.Z[step:]
        
        # 简化：使用fcluster类似逻辑
        from scipy.cluster.hierarchy import fcluster
        self.labels_ = fcluster(self.Z, n_clusters, criterion='maxclust')
        
        return self.labels_


# ===============================
# 测试代码
# ===============================
if __name__ == "__main__":

    # 生成数据

    print(f"数据形状: {X.shape}")
    print(f"聚类标签: {labels}")
    print(f"簇分布: {np.bincount(labels)}")
```

|------|------|----------|
| 轮廓系数 | 簇内紧密度与簇间分离度 | $\frac{b-a}{max(a,b)}$ |

## 11. 常见问题与易错点

### 11.1 数据层面常见错误

**错误1：未标准化数据**
- 现象：聚类结果偏向大尺度特征
- 解决：使用StandardScaler

**错误2：距离度量不当**
- 现象：结果不符合预期
- 解决：根据数据特性选择合适度量

### 11.2 算法层面常见错误

**错误1：选择错误的链接方法**
- Single容易产生链式效应
- Complete趋向于创建紧凑球形簇
- Ward最小化簇内方差

**错误2：切割层级选择不当**
- 解决：参考树状图或使用评估指标

### 11.3 调参层面常见误区

- **只关注K**：层次聚类不需要预设K
- **忽略树状图**：树状图含重要信息

### 12.2 关键公式汇总

**Single Linkage**：
$$D(C_i, C_j) = \min_{x \in C_i, y \in C_j} d(x, y)$$

**Complete Linkage**：
$$D(C_i, C_j) = \max_{x \in C_i, y \in C_j} d(x, y)$$

**Ward Linkage**：
$$D = \sum_{C} \sum_{x \in C} \|x - \mu_C\|^2$$

- ✓ 使用轮廓系数选择最佳K

### C. 常见问题FAQ

**Q1：层次聚类的计算复杂度是多少？**

A：O(n²)时间和O(n²)空间，对大数据有挑战。

**Q2：如何选择链接方法？**

A：
- Ward：最小化簇内方差
- Complete：创建紧凑簇
- Single：发现链状结构

A：需要转换为数值距离（如Gower距离）。
