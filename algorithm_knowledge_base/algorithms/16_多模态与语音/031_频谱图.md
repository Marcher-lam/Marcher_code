# 频谱图学习文档

## 1. 算法基础认知

频谱图（Spectrogram）是音频信号处理中最核心的时频表示方法之一。它将时域信号转换为二维"图像"表示，直观地展示信号的频率成分随时间变化的特性。频谱图通过短时傅里叶变换（STFT）计算得到，是语音识别、音乐分析、声纹识别等任务的基础特征。

频谱图的核心概念包括：
1. **时频分辨率**：时间分辨率和频率分辨率的权衡
2. **窗函数**：用于减少频谱泄漏
3. **Mel尺度**：模拟人耳感知的频率非线性
4. **频谱重构**：从频谱图还原音频信号

典型的频谱图应用包括：
- 语音识别（ASR）
- 音乐信息检索（MIR）
- 声纹识别
- 音频分类

## 2. 核心原理

### 2.1 短时傅里叶变换（STFT）

短时傅里叶变换是计算频谱图的核心算法。其基本思想是：
1. 将信号分割为重叠的短帧
2. 对每帧应用窗函数
3. 对每帧进行离散傅里叶变换（DFT）

STFT的数学定义为：

$$X(m, omega) = sum_{n=-infty}^{infty} x[n] w[n-mR] e^{-jomega n}$$

其中：
- $x[n]$：输入信号
- $w[n]$：窗函数
- $R$：跳距（hop size）
- $m$：帧索引

### 2.2 频谱图计算

频谱图的幅度定义为：

$$S(m, k) = |X(m, k)|^2 = X(m, k) cdot overline{X(m, k)}$$

其中 $k$ 是频率bin的索引，对应于频率：

$$f_k = frac{k}{N} f_s$$

### 2.3 频谱图参数

最重要的STFT参数包括：

1. **帧长（Frame Length）**
   - 常用值：20ms, 25ms, 50ms
   - 影响频率分辨率

2. **跳距（Hop Size）**
   - 常用值：10ms（帧长的一半）
   - 影响时间分辨率

3. **FFT长度（FFT Size）**
   - 常用值：512, 1024, 2048
   - 影响频率bin的数量

## 3. 数学公式与推导

### 3.1 离散傅里叶变换（DFT）

长度为N的离散信号 $x[n]$ 的DFT定义为：

$$X[k] = sum_{n=0}^{N-1} x[n] e^{-j 2pi kn / N}$$

逆变换为：

$$x[n] = frac{1}{N} sum_{k=0}^{N-1} X[k] e^{j 2pi kn / N}$$

### 3.2 窗函数

常用的窗函数包括：

**汉宁窗（Hanning Window）**
$$w[n] = 0.5 - 0.5 cosleft(frac{2pi n}{N-1}right)$$

**汉明窗（Hamming Window）**
$$w[n] = 0.54 - 0.46 cosleft(frac{2pi n}{N-1}right)$$

**Blackman窗**
$$w[n] = 0.42 - 0.5 cosleft(frac{2pi n}{N-1}right) + 0.08 cosleft(frac{4pi n}{N-1}right)$$

### 3.3 Mel尺度变换

Mel尺度模拟人耳对频率的感知，其定义为：

$$m = 2595 log_{10}left(1 + frac{f}{700}right)$$

逆变换：

$$f = 700left(10^{m/2595} - 1right)$$

Mel滤波器组是一组三角滤波器，覆盖从0到Nyquist频率的Mel空间。

### 3.4 频谱图与声音质量

从频谱图重建原始信号需要考虑：

1. **幅度重建**
   $$x_{recon}[n] = sum_{k} |X[k]| e^{j(angle(X[k]) + omega_k n)}$$

2. ** Griffin-Lim算法**
   - 迭代最小化幅度误差
   - 不需要相位信息

## 4. 训练过程讲解

### 4.1 频谱图生成

频谱图生成过程：
1. 对音频信号进行预加重
2. 分帧加窗
3. 应用FFT
4. 计算幅度/功率谱
5. 应用Mel滤波器组（可选）
6. 对数压缩

### 4.2 逆频谱图

从频谱图重建音频：
1. 反Log压缩
2. Mel反变换（可选）
3. Griffin-Lim或神经声码器

## 6. 优缺点分析

### 优点

1. **直观的可视化**：展示频率成分随时间变化
2. **理论基础成熟**：基于傅里叶变换
3. **计算高效**：FFT的复杂度为O(N log N)
4. **泛化性好**：适用于各种音频信号

### 缺点

1. **时间-频率分辨率权衡**：不能同时获得高时间和高频率分辨率
2. **相位信息丢失**：只保留幅度信息
3. **线性假设**：基于线性时不变系统假设
4. **非稀疏表示**：信息冗余

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math
import numpy as np


class STFT(nn.Module):
    """
    短时傅里叶变换模块
    
    参数:
        n_fft: FFT点数
        hop_length: 跳距
        win_length: 窗长
        window: 窗函数类型
    """
    
    def __init__(self, n_fft=2048, hop_length=512, win_length=2048, 
                 window='hann'):
        super(STFT, self).__init__()
        
        self.n_fft = n_fft
        self.hop_length = hop_length
        self.win_length = win_length
        
        # 创建窗函数
        if window == 'hann':
            self.window = torch.hann_window(win_length)
        elif window == 'hamming':
            self.window = torch.hamming_window(win_length)
        elif window == 'blackman':
            self.window = torch.blackman_window(win_length)
        else:
            self.window = torch.ones(win_length)
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: 输入音频信号 (B, T) 或 (B, 1, T)
        
        返回:
            频谱图 (B, F, T')
        """
        # 确保维度正确
        if x.dim() == 2:
            x = x.unsqueeze(1)
        
        # STFT
        result = torch.stft(
            x.squeeze(1),
            n_fft=self.n_fft,
            hop_length=self.hop_length,
            win_length=self.win_length,
            window=self.window.to(x.device),
            return_complex=True
        )
        
        return result
    
    def get_magnitude(self, x):
        """
        获取频谱图幅度
        
        参数:
            x: 输入音频
        
        返回:
            幅度频谱图
        """
        stft_result = self.forward(x)
        return torch.abs(stft_result)
    
    def get_power_spectrogram(self, x):
        """
        获取功率频谱图
        
        参数:
            x: 输入音频
        
        返回:
            功率谱图
        """
        stft_result = self.forward(x)
        return torch.abs(stft_result) ** 2


class MelSpectrogram(nn.Module):
    """
    Mel频谱图
    
    参数:
        sample_rate: 采样率
        n_fft: FFT点数
        hop_length: 跳距
        win_length: 窗长
        n_mels: Mel带数
    """
    
    def __init__(self, sample_rate=16000, n_fft=2048, hop_length=512, 
                 win_length=2048, n_mels=80):
        super(MelSpectrogram, self).__init__()
        
        self.sample_rate = sample_rate
        self.n_fft = n_fft
        self.hop_length = hop_length
        self.win_length = win_length
        self.n_mels = n_mels
        
        # 创建Mel滤波器组
        self.mel_filter = self._create_mel_filter()
        
        # 创建窗函数
        self.window = torch.hann_window(win_length)
        
        # 计算频率
        self.freqs = torch.fft.rfftfreq(n_fft, 1.0 / sample_rate)
        
    def _create_mel_filter(self):
        """创建Mel滤波器组"""
        # fmin和fmax
        fmin = 0
        fmax = self.sample_rate / 2
        
        # Mel变换
        mel_min = self._hz_to_mel(fmin)
        mel_max = self._hz_to_mel(fmax)
        
        # 生成Mel频率点
        mel_points = torch.linspace(mel_min, mel_max, self.n_mels + 2)
        hz_points = self._mel_to_hz(mel_points)
        
        # 转换为bin索引
        bin_points = torch.round(hz_points * self.n_fft / self.sample_rate).long()
        
        # 创建滤波器
        filters = torch.zeros(self.n_mels, self.n_fft // 2 + 1)
        
        for i in range(self.n_mels):
            left = bin_points[i]
            center = bin_points[i + 1]
            right = bin_points[i + 2]
            
            for j in range(left, center):
                filters[i, j] = (j - left) / (center - left)
            for j in range(center, right):
                filters[i, j] = (right - j) / (right - center)
        
        return filters
    
    def _hz_to_mel(self, f):
        """Hz到Mel的转换"""
        return 2595 * torch.log10(1 + f / 700)
    
    def _mel_to_hz(self, m):
        """Mel到Hz的转换"""
        return 700 * (10 ** (m / 2595) - 1)
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: 输入音频 (B, T) 或 (B, 1, T)
        
        返回:
            Mel频谱图 (B, n_mels, T')
        """
        if x.dim() == 2:
            x = x.unsqueeze(1)
        
        # STFT
        stft_result = torch.stft(
            x.squeeze(1),
            n_fft=self.n_fft,
            hop_length=self.hop_length,
            win_length=self.win_length,
            window=self.window.to(x.device),
            return_complex=True
        )
        
        # 幅度谱
        magnitude = torch.abs(stft_result)
        
        # 应用Mel滤波器组
        mel_spec = torch.matmul(self.mel_filter.to(x.device), magnitude)
        
        # 对数压缩
        mel_spec = torch.log(torch.clamp(mel_spec, min=1e-5))
        
        return mel_spec


class MFCC(nn.Module):
    """
    Mel频率倒谱系数（MFCC）
    
    参数:
        sample_rate: 采样率
        n_fft: FFT点数
        hop_length: 跳距
        win_length: 窗长
        n_mfcc: MFCC维度
        n_mels: Mel带数
    """
    
    def __init__(self, sample_rate=16000, n_fft=2048, hop_length=512, 
                 win_length=2048, n_mfcc=40, n_mels=80):
        super(MFCC, self).__init__()
        
        self.sample_rate = sample_rate
        self.n_fft = n_fft
        self.hop_length = hop_length
        self.win_length = win_length
        self.n_mfcc = n_mfcc
        self.n_mels = n_mels
        
        # Mel频谱图
        self.mel_spec = MelSpectrogram(
            sample_rate, n_fft, hop_length, win_length, n_mels
        )
        
        # DCT矩阵
        self.dct_matrix = self._create_dct_matrix()
    
    def _create_dct_matrix(self):
        """创建DCT矩阵"""
        dct_matrix = torch.zeros(self.n_mfcc, self.n_mels)
        
        for i in range(self.n_mfcc):
            dct_matrix[i] = torch.cos(
                math.pi * i * (torch.arange(self.n_mels) + 0.5) / self.n_mels
            )
        
        return dct_matrix
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: 输入音频
        
        返回:
            MFCC特征 (B, n_mfcc, T')
        """
        # Mel频谱图
        mel_spec = self.mel_spec(x)
        
        # 对数
        log_mel_spec = torch.log(torch.clamp(mel_spec, min=1e-5))
        
        # DCT
        mfcc = torch.matmul(self.dct_matrix.to(x.device), log_mel_spec)
        
        return mfcc


class SpectrogramAugment(nn.Module):
    """
    频谱图数据增强
    
    参数:
        time_drop_max: 时间方向最大丢弃长度

        freq_mask_max: 频率方向最大掩码宽度
    """
    
    def __init__(self, time_drop_max=20, freq_drop_max=10, 
                 time_mask_max=10, freq_mask_max=10):
        super(SpectrogramAugment, self).__init__()
        
        self.time_drop_max = time_drop_max
        self.freq_drop_max = freq_drop_max
        self.time_mask_max = time_mask_max
        self.freq_mask_max = freq_mask_max
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: 频谱图 (B, F, T)
        
        返回:
            增强后的频谱图
        """
        B, F, T = x.shape
        
        # 时间方向掩码
        if self.training and self.time_mask_max > 0:
            num_masks = 1
            for _ in range(num_masks):
                t = np.random.randint(0, self.time_mask_max)
                t0 = np.random.randint(0, max(1, T - t))
                x[:, :, t0:t0 + t] = 0
        
        # 频率方向掩码
        if self.training and self.freq_mask_max > 0:
            num_masks = 1
            for _ in range(num_masks):
                f = np.random.randint(0, self.freq_mask_max)
                f0 = np.random.randint(0, max(1, F - f))
                x[:, f0:f0 + f, :] = 0
        
        return x
```

## 8. 手工代码实现（核心算法手写）

```python
import numpy as np
import math


def hann_window(L):
    """创建汉宁窗"""
    n = np.arange(L)
    return 0.5 - 0.5 * np.cos(2 * math.pi * n / (L - 1))


def dft(x):
    """
    离散傅里叶变换
    
    参数:
        x: 输入信号 (N,)
    
    返回:
        X: DFT结果 (N,)
    """
    N = len(x)
    n = np.arange(N)
    
    # 创建旋转因子矩阵
    k = n.reshape(N, 1)
    n = n.reshape(1, N)
    W = np.exp(-2j * math.pi * k * n / N)
    
    return np.dot(W, x)


def idft(X):
    """
    逆离散傅里叶变换
    
    参数:
        X: DFT结果 (N,)
    
    返回:
        x: 逆变换结果 (N,)
    """
    N = len(X)
    k = np.arange(N).reshape(N, 1)
    n = np.arange(N).reshape(1, N)
    W = np.exp(2j * math.pi * k * n / N)
    
    return np.dot(W, X) / N


def stft_manual(x, win_length, hop_length, window):
    """
    手动实现STFT
    
    参数:
        x: 输入信号
        win_length: 窗长
        hop_length: 跳距
        window: 窗函数
    
    返回:
        X: 频谱图
    """
    # 分帧
    num_frames = 1 + (len(x) - win_length) // hop_length
    
    # 存储结果
    n_fft = win_length
    X = np.zeros((n_fft, num_frames), dtype=complex)
    
    # 对每帧进行FFT
    for i in range(num_frames):
        start = i * hop_length
        frame = x[start:start + win_length]
        
        # 加窗
        frame = frame * window[:len(frame)]
        
        # FFT
        X[:, i] = dft(frame)[:n_fft]
    
    return X


def hz_to_mel(hz):
    """Hz到Mel的转换"""
    return 2595 * np.log10(1 + hz / 700)


def mel_to_hz(mel):
    """Mel到Hz的转换"""
    return 700 * (10 ** (mel / 2595) - 1)


def create_mel_filterbank(sample_rate, n_fft, n_mels):
    """创建Mel滤波器组"""
    fmin = 0
    fmax = sample_rate / 2
    
    # Mel频率
    mel_min = hz_to_mel(fmin)
    mel_max = hz_to_mel(fmax)
    
    # 等间距Mel点
    mel_points = np.linspace(mel_min, mel_max, n_mels + 2)
    hz_points = mel_to_hz(mel_points)
    
    # 转换为bin
    bin_points = np.round(hz_points * (n_fft + 1) / sample_rate).astype(int)
    
    # 创��三��滤波器
    filters = np.zeros((n_mels, n_fft // 2 + 1))
    
    for i in range(n_mels):
        left = bin_points[i]
        center = bin_points[i + 1]
        right = bin_points[i + 2]
        
        for j in range(left, center):
            filters[i, j] = (j - left) / (center - left)
        for j in range(center, right):
            filters[i, j] = (right - j) / (right - center)
    
    return filters


def mel_spectrogram_manual(x, sample_rate, n_fft, hop_length, win_length, n_mels):
    """手动实现Mel频谱图"""
    # 窗函数
    window = hann_window(win_length)
    
    # STFT
    X = stft_manual(x, win_length, hop_length, window)
    
    # 幅度
    magnitude = np.abs(X[:n_fft // 2 + 1, :])
    
    # Mel滤波器组
    mel_filter = create_mel_filterbank(sample_rate, n_fft, n_mels)
    
    # 应用Mel滤波器
    mel_spec = np.dot(mel_filter.T, magnitude)
    
    # 对数
    mel_spec = np.log(np.maximum(mel_spec, 1e-10))
    
    return mel_spec
```

## 11. 常见问题与易错点

### 常见问题

1. **时间-频率分辨率权衡**
   - 长帧：频率分辨率高，时间分辨率低
   - 短帧：时间分辨率高，频率分辨率低

2. **频谱泄漏**
   - 原因：信号非周期性，应用矩形窗
   - 解决方法：使用渐变窗

3. **相位问题**
   - 只保留幅度会丢失相位信息
   - Griffin-Lim可以近似重建

### 易错点

1. **混淆采样率和Nyquist频率**
   - Nyquist = sample_rate / 2

2. **窗长和FFT长度混淆**
   - 窗长应<=FFT长度

3. **Mel尺度线性与非线性**
   - Mel尺度是非线性的

## 12. 学习总结

### 核心要点

1. **频谱图是音频的时频表示**
   - STFT计算
   - 展示频率随时间变化

2. **Mel频谱图更符合人耳感知**
   - 非线性Mel尺度
   - 对数压缩

3. **参数选择很重要**
   - 帧长：影响频率分辨率
   - 跳距：影响时间分辨率

### 关键公式

- STFT: $X(m, omega) = sum_n x[n] w[n-mR] e^{-jomega n}$
- Mel: $m = 2595 log_{10}(1 + f/700)$

### 最佳实践

1. 语音识别：20ms帧长，10ms跳距，80 Mel带
2. 音乐分析：更长帧长，更多频率bin
3. 实时应用：小的帧长和跳距
