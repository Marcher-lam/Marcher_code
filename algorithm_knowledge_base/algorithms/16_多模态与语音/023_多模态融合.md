## 1. 算法基础认知

### 1.1 一句话定义

**多模态融合**是指将来自不同模态（如图像、文本、音频、视频等）的特征表示进行整合，以获得更全面的信息表示的技术框架。它是多模态学习的核心任务之一，使得模型能够像人类一样综合多种感官信息进行理解和决策。

### 1.2 直觉类比

想象你正在观看一场足球比赛直播：如果你只能看到画面（视觉模态），你可能错过了解说员的评论（语音模态）；如果你只能听到解说（听觉模态），你就看不到球员的表情和动作。多模态融合就像你的大脑同时处理视觉和听觉信息——它整合两种信息，给你一个完整的比赛理解。这就是多模态融合的核心思想：1+1>2！

## 2. 核心原理

### 2.1 融合时机分类

| 融合时机 | 结构 | 优点 | 缺点 |
|----------|------|------|------|
| **早期融合** | 输入层 | 联合学习 | 难同步 |
| **晚期融合** | 输出层 | 灵活 | 丢失交互 |
| **混合融合** | 中间层 | 平衡 | 复杂 |

### 2.2 早期融合（Early Fusion）

在模型的输入层进行特征拼接：

```python
class EarlyFusion(nn.Module):
    def __init__(self, img_dim, text_dim, hidden_dim):
        super().__init__()
        
        # 独立的特征提取
        self.img_encoder = nn.Linear(img_dim, hidden_dim)
        self.text_encoder = nn.Linear(text_dim, hidden_dim)
        
        # 融合后的联合层
        self.fusion_layer = nn.Linear(hidden_dim * 2, hidden_dim)
    
    def forward(self, img_feat, text_feat):
        # 独立编码
        img_h = self.img_encoder(img_feat)
        text_h = self.text_encoder(text_feat)
        
        # 特征拼接
        fused = torch.cat([img_h, text_h], dim=-1)
        
        # 联合变换
        output = self.fusion_layer(fused)
        
        return output
```

### 2.3 晚期融合（Late Fusion）

在输出层进行决策融合：

```python
class LateFusion(nn.Module):
    def __init__(self, num_modalities, num_classes):
        super().__init__()
        
        # 每个模态独立的头
        self.heads = nn.ModuleList([
            nn.Linear(dim, num_classes)
            for dim in dims
        ])
        
        # 融合策略
        self.fusion_weight = nn.Parameter(torch.ones(num_modalities))
    
    def forward(self, modalities_features):
        # 独立预测
        logits = [head(feat) for head, feat in zip(self.heads, modalities_features)]
        
        # 加权融合
        weights = F.softmax(self.fusion_weight, dim=0)
        fused_logits = sum(w * l for w, l in zip(weights, logits))
        
        return fused_logits
```

### 2.4 混合融合（Hybrid Fusion）

结合早期和晚期融合的优点：

```python
class HybridFusion(nn.Module):
    def __init__(self, img_dim, text_dim, hidden_dim):
        super().__init__()
        
        # 早期融合
        self.img_proj = nn.Linear(img_dim, hidden_dim)
        self.text_proj = nn.Linear(text_dim, hidden_dim)
        
        # 中间层交互
        self.cross_attention = nn.MultiheadAttention(hidden_dim, num_heads=4)
        
        # 晚期融合
        self.classifier = nn.Linear(hidden_dim * 2, hidden_dim)
        self.output = nn.Linear(hidden_dim, num_classes)
    
    def forward(self, img_feat, text_feat):
        # 早期
        img_h = self.img_proj(img_feat)
        text_h = self.text_proj(text_feat)
        
        # 中间交互
        cross_out, _ = self.cross_attention(img_h, text_h, text_h)
        
        # 晚期
        combined = torch.cat([cross_out, img_h], dim=-1)
        out = self.output(self.classifier(combined))
        
        return out
```

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 |
|------|------|
| $x^v$ | 视觉特征 |
| $x^t$ | 文本特征 |
| $E_v$ | 视觉编码器 |
| $E_t$ | 文本编码器 |
| $F$ | 融合模块 |

### 3.2 早期融合公式

$$h_{fused} = F([E_v(x^v); E_t(x^t)])$$

其中 $[;]$ 表示拼接，$F$ 是联合变换网络。

### 3.3 Cross-Modal Attention

**Query-Key-Value 注意力**：

$$h_{v \rightarrow t} = \text{Attention}(Q_t, K_v, V_v)$$

$$h_{t \rightarrow v} = \text{Attention}(Q_v, K_t, V_t)$$

其中：
- $Q$ (Query): 来自目标模态
- $K$ (Key): 来自源模态  
- $V$ (Value): 来自源模态

### 3.4 Gated Fusion

**门控机制**：

$$g = \sigma(W_g[h^v; h^t] + b_g)$$

$$h_{fused} = g \odot h^v + (1-g) \odot h^t$$

### 3.5 对比学习融合（CLIP-style）

**对比目标**：

$$\mathcal{L}_{contrastive} = -\log \frac{\exp(sim(I_i, T_i) / \tau)}{\sum_j \exp(sim(I_i, T_j) / \tau)}$$

### 3.6 复杂度分析

| 融合方法 | 时间复杂度 | 空间复杂度 |
|----------|------------|------------|
| 早期 | $O(d^2)$ | $O(d)$ |
| 晚期 | $O(kd)$ | $O(k)$ |
| 交叉注意力 | $O(n^2 d)$ | $O(n^2)$ |

## 4. PyTorch实现

### 4.1 基础融合模块

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class SimpleFusion(nn.Module):
    """简单的特征拼接融合"""
    
    def __init__(self, img_dim, text_dim, hidden_dim):
        super().__init__()
        
        self.img_proj = nn.Linear(img_dim, hidden_dim)
        self.text_proj = nn.Linear(text_dim, hidden_dim)
        
        self.output = nn.Linear(hidden_dim * 2, hidden_dim)
    
    def forward(self, img_feat, text_feat):
        img_h = self.img_proj(img_feat)
        text_h = self.text_proj(text_feat)
        
        fused = torch.cat([img_h, text_h], dim=-1)
        
        return self.output(fused)


class ConcatFusion(nn.Module):
    """拼接+变换融合"""
    
    def __init__(self, dims, output_dim):
        super().__init__()
        
        total_dim = sum(dims)
        
        self.fusion = nn.Sequential(
            nn.Linear(total_dim, output_dim),
            nn.LayerNorm(output_dim),
            nn.ReLU(),
            nn.Dropout(0.1)
        )
    
    def forward(self, *features):
        concatenated = torch.cat(features, dim=-1)
        return self.fusion(concatenated)


class WeightedSumFusion(nn.Module):
    """加权求和融合"""
    
    def __init__(self, num_modalities):
        super().__init__()
        
        self.weights = nn.Parameter(torch.ones(num_modalities))
    
    def forward(self, *features):
        weights = F.softmax(self.weights, dim=0)
        
        fused = sum(w * f for w, f in zip(weights, features))
        
        return fused
```

### 4.2 Cross-Modal Attention

```python
class CrossModalAttention(nn.Module):
    """跨模态注意力"""
    
    def __init__(self, dim, num_heads=8):
        super().__init__()
        
        self.cross_attn = nn.MultiheadAttention(
            dim, num_heads, batch_first=True
        )
        
        self.norm = nn.LayerNorm(dim)
        
        self.img_to_text = nn.Linear(dim, dim)
        self.text_to_img = nn.Linear(dim, dim)
    
    def forward(self, img_feat, text_feat, return_attention=False):
        """
        Args:
            img_feat: (B, N, D)
            text_feat: (B, M, D)
        
        Returns:
            img_output: (B, N, D)
            text_output: (B, M, D)
        """
        
        # 图像到文本的注意力
        img_to_text, attn_v2t = self.cross_attn(
            text_feat, img_feat, img_feat,
            return_attention=True
        )
        text_output = self.norm(text_feat + img_to_text)
        
        # 文本到图像的注意力
        text_to_img, attn_t2v = self.cross_attn(
            img_feat, text_feat, text_feat,
            return_attention=True
        )
        img_output = self.norm(img_feat + text_to_img)
        
        if return_attention:
            return img_output, text_output, (attn_v2t, attn_t2v)
        
        return img_output, text_output


class CrossModalTransformer(nn.Module):
    """跨模态Transformer融合"""
    
    def __init__(self, dim, num_layers=6, num_heads=8):
        super().__init__()
        
        # 可学习的模态特定位置编码
        self.img_pos_embed = nn.Parameter(torch.ones(1, 197, dim) * 0.1)
        self.text_pos_embed = nn.Parameter(torch.ones(1, 77, dim) * 0.1)
        
        # Transformer层
        self.layers = nn.ModuleList([
            TransformerLayer(dim, num_heads)
            for _ in range(num_layers)
        ])
        
        self.norm = nn.LayerNorm(dim)
    
    def forward(self, img_feat, text_feat):
        # 添加位置编码
        img_feat = img_feat + self.img_pos_embed[:, :img_feat.shape[1]]
        text_feat = text_feat + self.text_pos_embed[:, :text_feat.shape[1]]
        
        # 跨模态Transformer
        for layer in self.layers:
            img_feat, text_feat = layer(img_feat, text_feat)
        
        return self.norm(img_feat), self.norm(text_feat)


class TransformerLayer(nn.Module):
    """单层Transformer"""
    
    def __init__(self, dim, num_heads):
        super().__init__()
        
        # 图像路径
        self.img_attn = nn.MultiheadAttention(dim, num_heads, batch_first=True)
        self.img_norm = nn.LayerNorm(dim)
        
        # 文本路径
        self.text_attn = nn.MultiheadAttention(dim, num_heads, batch_first=True)
        self.text_norm = nn.LayerNorm(dim)
        
        # FFN
        self.ffn = nn.Sequential(
            nn.Linear(dim, dim * 4),
            nn.GELU(),
            nn.Dropout(0.1),
            nn.Linear(dim * 4, dim),
            nn.Dropout(0.1)
        )
        
        self.ffn_norm = nn.LayerNorm(dim)
    
    def forward(self, img_feat, text_feat):
        # 图像自注意力 + 文本作为context
        img_out, _ = self.img_attn(img_feat, text_feat, text_feat)
        img_feat = self.img_norm(img_feat + img_out)
        
        # 文本自注意力 + 图像作为context
        text_out, _ = self.text_attn(text_feat, img_feat, img_feat)
        text_feat = self.text_norm(text_feat + text_out)
        
        # FFN
        img_feat = self.ffn_norm(img_feat + self.ffn(img_feat))
        text_feat = self.ffn_norm(text_feat + self.ffn(text_feat))
        
        return img_feat, text_feat
```

### 4.3 对比学习融合（CLIP-style）

```python
class CLIPFusion(nn.Module):
    """CLIP风格的多模态融合"""
    
    def __init__(self, image_dim, text_dim, embed_dim, temperature=0.07):
        super().__init__()
        
        # 图像投影
        self.image_proj = nn.Linear(image_dim, embed_dim)
        
        # 文本投影
        self.text_proj = nn.Linear(text_dim, embed_dim)
        
        # 温度参数
        self.temperature = nn.Parameter(torch.ones([]) * temperature)
        
        # 投影到logits
        self.image_output = nn.Linear(embed_dim, embed_dim, bias=False)
        self.text_output = nn.Linear(embed_dim, embed_dim, bias=False)
    
    def forward(self, image_features, text_features, return_sim=False):
        # 投影
        image_h = self.image_proj(image_features)
        text_h = self.text_proj(text_features)
        
        # L2归一化
        image_h = F.normalize(image_h, dim=-1)
        text_h = F.normalize(text_h, dim=-1)
        
        # 计算相似度
        logits = (image_h @ text_h.transpose(-2, -1)) / self.temperature
        
        if return_sim:
            return logits
        
        # 对比损失
        labels = torch.arange(len(image_features), device=image_features.device)
        
        loss_img = F.cross_entropy(logits, labels)
        loss_text = F.cross_entropy(logits.T, labels)
        
        loss = (loss_img + loss_text) / 2
        
        return loss
    
    def get_image_features(self, image_features):
        """获取图像特征"""
        image_h = self.image_proj(image_features)
        image_h = F.normalize(image_h, dim=-1)
        return self.image_output(image_h)
    
    def get_text_features(self, text_features):
        """获取文本特征"""
        text_h = self.text_proj(text_features)
        text_h = F.normalize(text_h, dim=-1)
        return self.text_output(text_h)
```

### 4.4 门控融合

```python
class GatedFusion(nn.Module):
    """门控融合"""
    
    def __init__(self, dim):
        super().__init__()
        
        # 门控网络
        self.gate = nn.Sequential(
            nn.Linear(dim * 2, dim),
            nn.Sigmoid()
        )
        
        # 变换网络
        self.transform = nn.Linear(dim * 2, dim)
    
    def forward(self, feat1, feat2):
        """融合两个特征"""
        
        # 拼接
        combined = torch.cat([feat1, feat2], dim=-1)
        
        # 门控
        gate = self.gate(combined)
        
        # 变换
        transformed = self.transform(combined)
        
        # 门控融合
        output = gate * feat1 + (1 - gate) * transformed
        
        return output


class MultiModalEncoder(nn.Module):
    """多模态编码器（结合多种融合方法）"""
    
    def __init__(self, img_dim, text_dim, hidden_dim, num_layers=6):
        super().__init__()
        
        # 早期融合
        self.early_fusion = nn.Linear(img_dim + text_dim, hidden_dim)
        
        # 交叉注意力
        self.cross_attn_layers = nn.ModuleList([
            CrossModalAttention(hidden_dim)
            for _ in range(3)
        ])
        
        # 门控融合层
        self.gated_fusion = GatedFusion(hidden_dim)
        
        # 单独的编码层
        self.img_encoder_layers = nn.ModuleList([
            nn.TransformerEncoderLayer(hidden_dim, 4, hidden_dim*4, 0.1, batch_first=True)
            for _ in range(3)
        ])
        
        self.text_encoder_layers = nn.ModuleList([
            nn.TransformerEncoderLayer(hidden_dim, 4, hidden_dim*4, 0.1, batch_first=True)
            for _ in range(3)
        ])
    
    def forward(self, img_feat, text_feat):
        # 早期fusion
        early_out = self.early_fusion(torch.cat([img_feat, text_feat], dim=-1))
        
        # 单独编码
        img_h = img_feat
        text_h = text_feat
        
        for layer in self.img_encoder_layers:
            img_h = layer(img_h)
        
        for layer in self.text_encoder_layers:
            text_h = layer(text_h)
        
        # 交叉注意力
        for cross_layer in self.cross_attn_layers:
            img_h, text_h = cross_layer(img_h, text_h)
        
        # 门控融合
        fused = self.gated_fusion(img_h, text_h)
        
        return img_h, text_h, fused
```

import torch

def demo_multimodal_fusion():
    """多模态融合演示"""
    
    print("=" * 60)
    print("多模态融合演示")
    print("=" * 60)
    
    batch_size = 4
    img_dim = 768   # 图像特征维度
    text_dim = 512   # 文本特征维度
    hidden_dim = 256

    print(f"文本特征: {text_features.shape}")
    
    # 早期融合
    early_fusion = ConcatFusion([img_dim, text_dim], hidden_dim)
    early_out = early_fusion(img_features, text_features)

    cross_attn = CrossModalAttention(hidden_dim)

## 8. 手工代码实现（核心算法手写 + 注释）

以下是从零实现：

```python
import torch, torch.nn as nn, torch.nn.functional as F

class 多模态融合Net(nn.Module):
    def __init__(self, dim_in=20, dim_h=64, dim_out=2):
        super().__init__()
        self.fc1, self.fc2 = nn.Linear(dim_in, dim_h), nn.Linear(dim_h, dim_out)
    def forward(self, x): return self.fc2(F.relu(self.fc1(x)))

def train(model, X, y, epochs=100, lr=0.001):
    opt = torch.optim.Adam(model.parameters(), lr=lr)
    for ep in range(epochs):
        opt.zero_grad()
        loss = nn.CrossEntropyLoss()(model(X), y)
        loss.backward(); opt.step()
        if (ep+1)%20==0: print(f"Ep{ep+1} loss={loss.item():.4f}")

m = 多模态融合Net()
train(m, torch.randn(500,20), torch.randint(0,2,(500,)))
```
