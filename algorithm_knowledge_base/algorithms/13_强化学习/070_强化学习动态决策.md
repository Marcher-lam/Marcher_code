# 强化学习动态决策 学习文档

> 通过强化学习实现动态环境下的自主决策，平衡效率与安全约束。

## 1. 算法基础认知

强化学习动态决策是指智能体通过与环境交互，自主学习最优决策策略的技术，核心目标是在动态变化的环境中做出最优选择。

### 历史背景

- **2013年**：Deep Q Network (DQN) 提出
- **2016年**：AlphaGo战胜李世石
- **2020年**：DeepSeek-R1采用GRPO算法

### 直觉类比

强化学习就像"驯马"：通过奖励和惩罚让马（智能体）学会最优行为，而不是直接告诉它怎么做。

### 前置知识

- Python编程基础
- 神经网络基础
- 概率论基础

## 2. 核心原理

### 核心概念

- **状态(S)**：环境的当前情况
- **动作(A)**：可以采取的行动
- **奖励(R)**：动作带来的回报
- **策略(π)**：状态到动作的映射

### GRPO (分组相对策略优化)

DeepSeek-R1采用GRPO替代传统PPO：
- 通过组内动作采样与相对奖励计算
- 计算复杂度从 $O(N^2)$ 降至 $O(N \cdot logN)$

### 安全屏障函数

将安全约束嵌入策略网络：
- 温度阈值 → 硬约束
- 压力边界 → 动作空间限制

## 3. 数学公式与推导

### 回报计算

$$G_t = R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + ...$$

$\gamma$是折扣因子。

### 价值函数

$$V(s) = E[G_t | s_0 = s]$$

在状态s下的期望回报。

### Q函数

$$Q(s, a) = E[G_t | s_0 = s, a_0 = a]$$

在状态s下采取动作a的期望回报。

### GRPO目标

$$J(\theta) = E_{s,a}[R(s,a)] - \beta \cdot KL(\pi_\theta || \pi_{old})$$

## 6. 优缺点分析

### 优点

1. **自学习**：无需标注数据
2. **长期规划**：考虑延迟奖励
3. **适应性**：应对环境变化
4. **通用性**：适用于各种决策问题

### 缺点

1. **样本效率**：需要大量交互
2. **训练不稳定**：收敛困难
3. **奖励设计**：奖励函数设计困难
4. **安全性**：探索可能危险

## 7. 调库实现

```python
import torch
import torch.nn as nn
import torch.optim as optim

class PolicyNetwork(nn.Module):
    """策略网络"""
    def __init__(self, state_dim, action_dim):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(state_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Linear(32, action_dim)
        )
        
    def forward(self, state):
        logits = self.network(state)
        return torch.softmax(logits, dim=-1)

class ValueNetwork(nn.Module):
    """价值网络"""
    def __init__(self, state_dim):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(state_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Linear(32, 1)
        )
        
    def forward(self, state):
        return self.network(state)

class SimplePPO:
    """简化PPO算法"""
    def __init__(self, state_dim, action_dim, lr=3e-4):
        self.policy = PolicyNetwork(state_dim, action_dim)
        self.value = ValueNetwork(state_dim)
        self.optimizer = optim.Adam(
            list(self.policy.parameters()) + 
            list(self.value.parameters()),
            lr=lr
        )
        
    def get_action(self, state):
        probs = self.policy(state)
        action = torch.multinomial(probs, 1)
        return action.item(), probs[action]
        
    def update(self, states, actions, rewards):
        # 简化的更新
        states = torch.stack(states)
        actions = torch.tensor(actions)
        rewards = torch.tensor(rewards)
        
        # 策略损失
        probs = self.policy(states)
        action_probs = probs.gather(1, actions.unsqueeze(1)).squeeze()
        loss = -action_probs.mean() * rewards.mean()
        
        # 更新
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()
        
        return loss.item()
```

## 8. 手工代码实现

```python
import numpy as np
import random

class MultiArmedBandit:
    """多臂老虎机"""
    
    def __init__(self, n_arms=5):
        self.n_arms = n_arms
        self.true_probs = np.random.rand(n_arms) * 0.5 + 0.3
        
    def pull(self, arm):
        """拉动杠杆"""
        if random.random() < self.true_probs[arm]:
            return 1.0  # 奖励
        return 0.0

class EpsilonGreedy:
    """epsilon-greedy算法"""
    
    def __init__(self, n_arms, epsilon=0.1):
        self.n_arms = n_arms
        self.epsilon = epsilon
        self.counts = np.zeros(n_arms)
        self.values = np.zeros(n_arms)
        self.total_pulls = 0
        
    def select_action(self):
        """选择动作"""
        if random.random() < self.epsilon:
            return random.randint(0, self.n_arms - 1)
        return np.argmax(self.values)
        
    def update(self, arm, reward):
        """更新Q值"""
        self.total_pulls += 1
        self.counts[arm] += 1
        
        # 增量更新
        self.values[arm] += (reward - self.values[arm]) / self.counts[arm]

# 测试
if __name__ == "__main__":
    env = MultiArmedBandit(n_arms=5)
    agent = EpsilonGreedy(n_arms=5, epsilon=0.1)
    
    print("=== 多臂老虎机实验 ===\n")
    
    # 训练
    for episode in range(100):
        arm = agent.select_action()
        reward = env.pull(arm)
        agent.update(arm, reward)
    
    # 结果
    print(f"真实概率: {env.true_probs.round(3)}")
    print(f"估计概率: {agent.values.round(3)}")
    print(f"选择次数: {agent.counts}")
    print(f"推荐杠杆: {np.argmax(agent.values)}")
```

```python
def evaluate_rl_agent(agent, env, num_episodes=100):
    """评估强化学习智能体"""
    rewards = []
    
    for _ in range(num_episodes):
        state = env.reset()
        total_reward = 0
        
        for _ in range(100):
            action = agent.get_action(state)
            state, reward, done = env.step(action)
            total_reward += reward
            
            if done:
                break
                
        rewards.append(total_reward)
        
    avg_reward = np.mean(rewards)
    std_reward = np.std(rewards)
    
    print(f"强化学习评估:")
    print(f"  - 平均奖励: {avg_reward:.1f} ± {std_reward:.1f}")

    print(f"  - 最小奖励: {min(rewards):.1f}")
    
    return {'avg_reward': avg_reward, 'std_reward': std_reward}
```

## 11. 常见问题与易错点

### 数据层面

1. **奖励稀疏**：长期任务无即时反馈
   - 解决方案：设计中间奖励

2. **部分可观测**：无法看到完整环境
   - 解决方案：信念状态估计

### 模型层面

1. **奖励黑客**：智能体找到取巧方法
   - 解决方案：奖励塑形

2. **灾难性遗忘**：新技能覆盖旧技能
   - 解决方案：经验回放

### 调参层面

1. **学习率不当**：训练不稳定
   - 解决方案：学习率调度

2. **探索不足**：陷入局部最优
   - 解决方案：增加噪声
