# 汤普森采样 学习文档

## 1. 算法基础认知
### 1.1 发展历史
汤普森采样（Thompson Sampling）是贝叶斯框架下的经典探索策略：
- 1933年：William R. Thompson首次提出后验采样思想，用于临床试验
- 1935年：Thompson将方法扩展到多臂老虎机场景
- 2011年：Chapelle等人证明汤普森采样在工业场景的性能优于UCB，引发研究热潮
- 2012年：Agrawal & Goyal证明汤普森采样的贝叶斯后悔界为$O(K \\ln T)$，与UCB相当
- 2017年：Google将汤普森采样用于YouTube推荐，成为工业界主流算法之一

### 1.2 生活类比
汤普森采样的核心是**根据后验概率采样**：对每个臂的奖励分布维护一个后验，每次采样选择后验均值最大的臂。
| 类比场景 | 后验含义 | 选择逻辑 |
|----------|----------|----------|
| 餐厅选择 | 每个餐厅评分的后验分布（Beta分布） | 从每个后验采样一个评分，选最高的 |
| 临床试验 | 每个疗法治愈率的后验分布 | 采样治愈率，选最高的疗法 |
| 在线广告 | 每个广告点击率的后验分布 | 采样点击率，选最高的广告 |

### 1.3 算法定位
| 维度 | 定位说明 |
|------|----------|
| 学习范式 | 贝叶斯在线学习、强化学习 |
| 模型属性 | 模型-based（维护后验分布） |
| 核心思想 | 后验采样（Probability Matching） |
| 探索类型 | 随机探索（基于后验概率） |
| 理论保障 | 贝叶斯后悔界 $O(K \\ln T)$ |

## 2. 核心原理
### 2.1 核心机制：后验采样
汤普森采样的步骤：
1. 对每个臂a维护奖励分布的后验$P(\\theta_a | \\text{data})$
2. 从每个后验采样一个参数$\\hat{\\theta}_a \\sim P(\\theta_a | \\text{data})$
3. 选择$\\arg\\max_a \\hat{\\theta}_a$作为当前动作
4. 获得奖励后更新后验

#### 机制ASCII示意图
```
+-------------------+                         +-------------------+
|   老虎机环境       |                         |     智能体         |
| (K个臂，μ_a未知)  | ← 返回奖励r_t           | 维护每个臂的后验   |
+-------------------+                         | 采样θ_a ~ 后验     |
                                               | 选max θ_a的臂     |
                                               +-------------------+
        ↑ 选择采样值最大的臂a_t                      |
        +-------------------------------------------+
```

### 2.2 相关算法对比
| 算法 | 探索策略 | 贝叶斯后悔 | 计算复杂度 | 随机性 |
|------|----------|------------|------------|--------|
| ε-贪婪 | 随机探索 | 无 | $O(1)$/步 | 高 |
| UCB1 | 置信上界 | 无 | $O(1)$/步 | 无 |
| 汤普森采样 | 后验采样 | $O(K \\ln T)$ | $O(K)$/步 | 高 |
| 贝叶斯UCB | 贝叶斯置信上界 | $O(K \\ln T)$ | $O(K)$/步 | 无 |

### 2.3 工程经验
1. 伯努利奖励用Beta后验：先验设为Beta(1,1)（均匀分布），更新规则：$S_a$为成功次数，$F_a$为失败次数，后验为Beta($S_a+1, F_a+1$)
2. 高斯奖励用高斯后验：先验设为$N(\\mu_0, \\sigma_0^2)$，更新后得到后验$N(\\mu_n, \\sigma_n^2)$
3. 避免采样开销：当K很大时，用UCB近似汤普森采样
4. 非平稳场景：用折扣因子更新后验参数，或定期重置先验

### 2.4 几何直观解释
每个臂的后验分布是一个概率密度函数：
- 拉动次数少的臂：后验分布宽，采样值波动大，可能被选中（探索）
- 拉动次数多的臂：后验分布窄，采样值接近真实均值，只有确实好才会被选中（利用）
- 采样过程自动平衡探索与利用，无需手动调整参数

> 知识链接：与`多臂老虎机.md`、`UCB.md`同属探索利用核心算法

## 3. 数学公式与推导
### 3.1 符号表（伯努利奖励场景）
| 符号 | 含义 | 维度/范围 |
|------|------|-----------|
| $K$ | 臂的总数 | 正整数 $K \\geq 2$ |
| $S_a$ | 臂a的成功次数（奖励=1） | 非负整数 |
| $F_a$ | 臂a的失败次数（奖励=0） | 非负整数 |
| $\\alpha_a, \\beta_a$ | Beta分布参数 | $\\alpha_a = S_a + 1, \\beta_a = F_a + 1$ |
| $\\hat{\\theta}_a$ | 从后验采样的点击率估计 | $0 \\leq \\hat{\\theta}_a \\leq 1$ |

### 3.2 核心公式推导（伯努利奖励）
伯努利奖励的似然是$Bernoulli(\\theta_a)$，共轭先验是Beta分布：
- 先验：$Beta(\\alpha_0, \\beta_0)$，通常取$\\alpha_0=\\beta_0=1$（均匀分布）
- 后验：$Beta(\\alpha_0 + S_a, \\beta_0 + F_a)$
- 采样：从$Beta(\\alpha_a, \\beta_a)$采样$\\hat{\\theta}_a$

对于高斯奖励$N(\\mu_a, \\sigma^2)$，共轭先验是高斯-逆伽马分布，简化为已知方差时：
- 后验均值：$\\mu_n = \\frac{\\sigma_0^2 \\sum r + \\sigma^2 \\mu_0 n}{\\sigma_0^2 n + \\sigma^2}$
- 后验方差：$\\sigma_n^2 = \\frac{\\sigma_0^2 \\sigma^2}{\\sigma_0^2 n + \\sigma^2}$

### 3.3 算法伪代码（伯努利奖励）
```
初始化：每个臂的S_a=0, F_a=0，先验α=1, β=1
for t=1 to T:
    对每个臂a：从Beta(S_a+1, F_a+1)采样θ_a
    选择a_t = argmax(θ_a)
    获得奖励r_t（0或1）
    if r_t=1: S_{a_t} +=1
    else: F_{a_t} +=1
end for
```

### 3.4 贝叶斯后悔界（Agrawal & Goyal 2012）
汤普森采样的贝叶斯后悔满足：
$$\\mathbb{E}[R_T] \\leq O\\left( \\sum_{a: \\Delta_a >0} \\frac{\\ln T}{\\Delta_a} \\right)$$
与UCB的后悔界同阶，但实践中通常性能更好。

## 4. 训练过程讲解
### 4.1 数据预处理
与多臂老虎机一致，仅需定义奖励类型（伯努利/高斯）和对应分布参数。

### 4.2 参数初始化表
| 参数 | 伯努利场景推荐值 | 高斯场景推荐值 | 说明 |
|------|------------------|----------------|------|
| 先验α | 1（Beta(1,1)均匀） | $\\mu_0=0, \\sigma_0^2=1$ | 无信息先验 |
| 初始S/F | 0 | 0 | 无历史数据 |
| 已知方差σ² | - | 0.1 | 高斯场景假设方差已知 |

### 4.3 训练流程
1. 初始化后验参数（伯努利：S=0,F=0；高斯：μ=0,σ²=1）
2. 循环T步：
   a. 从每个臂的后验采样参数
   b. 选择采样值最大的臂
   c. 获得奖励r
   d. 更新对应臂的后验参数
3. 统计累积奖励、后悔

#### 工程技巧
- 伯努利场景用`numpy.random.beta`采样，高斯场景用`numpy.random.normal`
- 当K>1000时，使用UCB近似汤普森采样：用后验均值+后验标准差作为UCB项
- 非平稳场景：用折扣因子更新S和F：$S = \\lambda S + r$, $F = \\lambda F + (1-r)$，$\\lambda=0.95$

### 4.4 收敛与调试
#### 收敛条件
- 后验分布的标准差小于阈值（如$\\sqrt{\\alpha/(\\alpha+\\beta)^2} < 0.01$）
- 最优臂的拉动占比超过80%
- 采样值的方差逐渐减小

#### 常见问题调试
| 现象 | 原因 | 解决方案 |
|------|------|----------|
| 采样值全为0或1 | 先验设置错误 | 检查Beta参数是否正确 |
| 后验更新不收敛 | 奖励方差过大 | 减小先验方差，增加置信度 |
| 计算开销大 | K太大，每步采样K次 | 用UCB近似，或只采样Top-K臂 |

### 5.2 适用场景特征
| 特征 | 说明 |
|------|------|
| 贝叶斯建模需求 | 需要量化不确定性，输出置信区间 |
| 小样本场景 | 贝叶斯更新利用先验信息，更鲁棒 |

### 5.3 不适用场景与替代方案
| 不适用场景 | 问题 | 替代方案 |
|----------|------|----------|
| 大动作空间（K>1000） | 每步采样K次开销大 | UCB、梯度Bandit |
| 需要确定性结果 | 采样随机性导致结果不可复现 | UCB |

| 延迟奖励 | 无法实时更新后验 | 强化学习（DQN） |

## 6. 优缺点分析
### 6.1 优点
1. **自适应探索，无需调参**
   - 条件：共轭先验选择合适
   - 说明：后验采样自动平衡探索与利用，无需调整探索率或置信参数
2. **贝叶斯后悔界明确**
   - 条件：平稳环境、共轭先验
   - 说明：Agrawal & Goyal 2012证明$O(K \\ln T)$贝叶斯后悔界
3. **小样本性能鲁棒**
   - 条件：有合适的先验信息
   - 说明：贝叶斯更新利用先验，小样本下优于频率派方法
4. **量化不确定性**
   - 条件：需要输出置信区间
   - 说明：后验分布可直接给出点击率的置信区间
5. **工业界验证有效**
   - 条件：点击率、转化率优化场景
   - 说明：Google、YouTube等大规模验证性能优于UCB

### 6.2 缺点
1. **计算开销高于UCB/ε-贪婪**
   - 问题：每步需要采样K次，K大时开销高
   - 解决方案：用UCB近似，或只采样候选子集
2. **结果不可复现**
   - 问题：采样过程有随机性，相同初始条件结果不同
   - 解决方案：固定随机种子，或用UCB替代
3. **先验敏感**
   - 问题：错误的先验导致后验偏差
   - 解决方案：使用无信息先验（如Beta(1,1)）
4. **非平稳场景适配难**
   - 问题：后验分布无法快速适配变化
   - 解决方案：使用折扣因子，定期重置先验
5. **非共轭分布处理复杂**
   - 问题：非伯努利/高斯奖励无解析后验
   - 解决方案：使用MCMC或变分推断，开销大

### 6.3 算法对比
| 算法 | 调参难度 | 小样本性能 | 计算开销 | 可复现性 |
|------|----------|------------|----------|----------|
| 汤普森采样 | 低 | 优 | 中 | 差 |
| UCB1 | 中 | 中 | 低 | 优 |
| ε-贪婪 | 中 | 差 | 低 | 差 |

## 7. 调库实现
### 7.1 完整代码（伯努利奖励，基于NumPy）
```python
import numpy as np
import random
from typing import List, Tuple

class ThompsonSamplingBernoulli:
    """汤普森采样（伯努利奖励）工业级实现"""
    def __init__(self, n_arms: int, prior_alpha: float = 1.0, prior_beta: float = 1.0):
        """
        初始化汤普森采样智能体（伯努利场景）
        Args:
            n_arms: 臂的数量
            prior_alpha: Beta先验α参数（默认1，均匀分布）
            prior_beta: Beta先验β参数（默认1，均匀分布）
        """
        self.n_arms = n_arms
        self.alpha = np.full(n_arms, prior_alpha, dtype=np.float64)
        self.beta = np.full(n_arms, prior_beta, dtype=np.float64)
        self.cumulative_reward = 0.0
        self.cumulative_regret = 0.0
        self.true_means = None
    
    def set_true_means(self, true_means: List[float]):
        """设置真实点击率（仅模拟用）"""
        assert len(true_means) == self.n_arms
        self.true_means = np.array(true_means, dtype=np.float64)
    
    def select_arm(self) -> int:
        """从每个臂的Beta后验采样，选采样值最大的臂"""
        # 从Beta(alpha, beta)采样
        samples = np.random.beta(self.alpha, self.beta)
        # 选采样值最大的臂，平局时随机选
        max_sample = np.max(samples)
        candidate_arms = np.where(samples == max_sample)[0]
        return random.choice(candidate_arms)
    
    def update(self, arm: int, reward: int):
        """更新Beta后验参数：成功加alpha，失败加beta"""
        if reward == 1:
            self.alpha[arm] += 1
        else:
            self.beta[arm] += 1
        self.cumulative_reward += reward
        if self.true_means is not None:
            self.cumulative_regret += np.max(self.true_means) - reward
    
    def get_posterior_mean(self) -> np.ndarray:
        """获取后验均值（alpha/(alpha+beta)）"""
        return self.alpha / (self.alpha + self.beta)

def simulate_thompson_bernoulli(
    n_arms: int = 5,
    n_steps: int = 1000,
    seed: int = 42
) -> Tuple[ThompsonSamplingBernoulli, np.ndarray, np.ndarray]:
    """模拟伯努利奖励汤普森采样"""
    np.random.seed(seed)
    random.seed(seed)
    # 生成真实点击率
    true_means = np.random.uniform(0.1, 0.9, n_arms)
    true_means[0] = np.max(true_means) + 0.1
    # 初始化智能体
    agent = ThompsonSamplingBernoulli(n_arms=n_arms)
    agent.set_true_means(true_means.tolist())
    # 记录序列
    cumulative_rewards = np.zeros(n_steps, dtype=np.float64)
    cumulative_regrets = np.zeros(n_steps, dtype=np.float64)
    # 训练循环
    for t in range(n_steps):
        arm = agent.select_arm()
        # 生成伯努利奖励
        reward = 1 if random.random() < true_means[arm] else 0
        agent.update(arm, reward)
        cumulative_rewards[t] = agent.cumulative_reward
        cumulative_regrets[t] = agent.cumulative_regret
    # 打印结果
    print(f"真实点击率：{np.round(true_means, 2)}")
    print(f"后验均值：{np.round(agent.get_posterior_mean(), 2)}")
    print(f"最终累积奖励：{agent.cumulative_reward:.2f}")
    print(f"最终累积后悔：{agent.cumulative_regret:.2f}")
    return agent, cumulative_rewards, cumulative_regrets

if __name__ == "__main__":
    agent, rewards, regrets = simulate_thompson_bernoulli(n_arms=5, n_steps=1000)
```

## 8. 手工代码实现
### 8.1 纯Python核心实现（伯努利奖励）
```python
import random
import math
from typing import List

class ScratchThompson:
    """纯手工实现汤普森采样（仅用Python标准库）"""
    def __init__(self, n_arms: int, alpha: float = 1.0, beta: float = 1.0):
        self.n_arms = n_arms
        self.alpha = [alpha for _ in range(n_arms)]
        self.beta = [beta for _ in range(n_arms)]
    
    def sample_beta(self, a: float, b: float) -> float:
        """手动采样Beta分布（用Gamma分布变换）"""
        # Beta(a,b) = Gamma(a,1) / (Gamma(a,1)+Gamma(b,1))
        ga = random.gammavariate(a, 1)
        gb = random.gammavariate(b, 1)
        return ga / (ga + gb)
    
    def select_arm(self) -> int:
        """采样并选择最大"""
        samples = [self.sample_beta(self.alpha[a], self.beta[a]) for a in range(self.n_arms)]
        max_sample = max(samples)
        candidates = [a for a, s in enumerate(samples) if s == max_sample]
        return random.choice(candidates)
    
    def update(self, arm: int, reward: int):
        """更新Beta参数"""
        if reward == 1:
            self.alpha[arm] += 1
        else:
            self.beta[arm] += 1
    
    def run(self, true_means: List[float], n_steps: int) -> None:
        """运行模拟"""
        assert len(true_means) == self.n_arms
        total_reward = 0.0
        optimal_arm = true_means.index(max(true_means))
        counts = [0 for _ in range(self.n_arms)]
        for t in range(n_steps):
            arm = self.select_arm()
            counts[arm] += 1
            reward = 1 if random.random() < true_means[arm] else 0
            self.update(arm, reward)
            total_reward += reward
            if (t + 1) % 200 == 0:
                print(f"步数{t+1}：总奖励{total_reward}，最优臂拉动{counts[optimal_arm]}次")
        print(f"后验均值：{[round(self.alpha[a]/(self.alpha[a]+self.beta[a]), 2) for a in range(self.n_arms)]}")
```

## 11. 常见问题与易错点
### 5.1 常见陷阱
1. **使用错误的共轭先验**
   - 现象：后验更新不收敛，采样值异常
   - 原因：伯努利奖励用了高斯先验
   - 解决：伯努利用Beta先验，高斯用高斯先验

2. **采样开销过大导致性能差**
   - 现象：K=10000时训练速度极慢
   - 原因：每步采样10000次
   - 解决：用UCB近似，或只采样Top-K候选臂

3. **先验设置过于集中**
   - 现象：初始采样值接近先验，忽略数据
   - 原因：先验α、β设置过大（如100）
   - 解决：使用无信息先验（α=β=1）

4. **非平稳场景未做适配**
   - 现象：奖励分布变化后后验过时
   - 原因：未使用折扣因子
   - 解决：用折扣更新α、β，或定期重置

5. **后验均值计算错误**
   - 现象：后验均值与真实值偏差大
   - 原因：均值公式用了α/(α+β+1)
   - 解决：Beta后验均值是α/(α+β)

### 11.2 调试技巧
1. 打印前10步的采样值、后验参数，验证更新逻辑
2. 绘制后验分布，检查是否收敛到真实均值
3. 对比汤普森采样与UCB的后悔，验证性能

### 11.3 工程最佳实践
1. 生产环境记录每步的后验参数、采样值、奖励
2. 监控后验校准度，低于90%时调整先验
3. 非平稳场景每周重置一次先验，重新探索

## 12. 学习总结
### 12.1 核心思想回顾
汤普森采样的核心是**后验采样**：通过贝叶斯更新维护每个臂的后验分布，每次采样选择后验均值最大的臂，自动平衡探索与利用。

#### 思维导图（ASCII）
```
                  汤普森采样
                     |
         +-----------+-----------+
         |           |           |
     核心机制      应用场景      相关算法
         |           |           |
   后验采样+概率匹配 广告/推荐  UCB/ε-贪婪
```

### 12.2 必记公式
1. Beta后验：$Beta(\\alpha_0 + S_a, \\beta_0 + F_a)$
2. 采样选择：$a_t = \\arg\\max_a \\hat{\\theta}_a$, $\\hat{\\theta}_a \\sim Beta(\\alpha_a, \\beta_a)$
3. 贝叶斯后悔：$\\mathbb{E}[R_T] \\leq O\\left( \\sum \\frac{\\ln T}{\\Delta_a} \\right)$

## 13. 练习题与思考题
### 13.1 基础题（5道）
1. 汤普森采样的核心思想是什么？
<details>
<summary>答案</summary>
后验采样（概率匹配）：维护每个臂的贝叶斯后验分布，每次从后验采样一个参数，选择采样值最大的臂。
</details>

2. 伯努利奖励的汤普森采样用什么共轭先验？
<details>
<summary>答案</summary>
Beta分布，先验通常设为Beta(1,1)（均匀分布）。
</details>

3. 汤普森采样和UCB的核心区别是什么？
<details>
<summary>答案</summary>
汤普森采样是贝叶斯后验采样，有随机性；UCB是频率派置信上界，无随机性。两者后悔界同阶，但汤普森采样实践中性能更好。
</details>

4. 什么是后验校准度？
<details>
<summary>答案</summary>
95%后验区间包含真实参数的比例，理想值接近95%，说明后验分布正确量化了不确定性。
</details>

5. 汤普森采样适用于什么场景？
<details>
<summary>答案</summary>
适用于贝叶斯建模场景、小样本场景、伯努利/高斯奖励场景，如在线广告、推荐系统。
</details>

### 13.2 进阶题（2道）
1. 推导伯努利奖励的Beta后验更新公式。
<details>
<summary>推导思路</summary>
根据贝叶斯定理：后验∝似然×先验。伯努利似然是$\\theta^S (1-\\theta)^F$，Beta先验是$\\theta^{\\alpha-1}(1-\\theta)^{\\beta-1}$，乘积是$\\theta^{\\alpha+S-1}(1-\\theta)^{\\beta+F-1}$，即Beta($\\alpha+S, \\beta+F$)。
</details>

2. 如何修改汤普森采样适配非平稳环境？
<details>
<summary>答案</summary>
使用折扣因子更新后验参数：$S = \\lambda S + r$, $F = \\lambda F + (1-r)$，λ=0.95；或定期重置先验为初始值。
</details>
