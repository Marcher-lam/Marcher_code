# 设计奖励 学习文档

> 用一句话说明这个算法的核心价值：奖励函数 $R(s,a)$ 将环境状态 $s$ 和动作 $a$ 映射为一个实数，表示在该状态下采取该动作的优劣程度。

## 1. 算法基础认知

设计奖励函数是强化学习任务成功的关键环节。奖励函数定义了智能体在环境中行为的优化目标，决定了智能体应该追求什么样的行为策略。

**一句话定义**：奖励函数 $R(s,a)$ 将环境状态 $s$ 和动作 $a$ 映射为一个实数，表示在该状态下采取该动作的优劣程度。

**直觉类比**：就像老师给学生布置作业并给出评分标准，奖励函数就是老师的评分标准，告诉学生什么行为是好的，什么行为应该避免。

**历史背景**：
- 强化学习发展初期，奖励函数通常由领域专家手工设计
- 随着深度强化学习发展，出现了基于逆强化学习的自动奖励设计方法
- 2010年代：逆向强化学习（IRL）成为自动设计奖励函数的主要方法
- 2010年代后期：生成对抗模仿学习（GAIL）将奖励设计与策略学习结合
- 2020年代：结合大模型和自监督学习，实现更智能的奖励设计

**算法定位**：
- 奖励函数是强化学习的核心组成部分
- 奖励设计直接影响算法收敛速度和最终性能
- 稀疏奖励问题一直是强化学习的挑战
- 逆强化学习提供了从专家演示中自动设计奖励的方法

**前置知识**：
- 强化学习基础（MDP、策略、价值函数）
- 优化理论（梯度下降、拉格朗日乘数法）
- 概率图模型（用于逆强化学习）

## 2. 核心原理

奖励函数的设计本质上是定义智能体的优化目标。设计原则包括：

### 2.1 奖励函数的基本形式

**即时奖励**：$r_t = R(s_t, a_t)$
- 依赖于当前状态和动作
- 可以是稀疏的（只在特定事件发生时给出）
- 可以是密集的（每一步都有反馈）

**累积奖励**：$G_t = \sum_{k=0}^\infty \gamma^k r_{t+k}$
- $\gamma$ 是折扣因子，控制未来奖励的重要性
- 决定了智能体的远见程度

### 2.2 奖励设计的关键考量

**稀疏 vs 密集奖励**：
- **稀疏奖励**：只在任务完成或失败时给出反馈
  - 优点：目标明确，设计简单
  - 缺点：学习信号少，探索困难
  
- **密集奖励**：每一步都有反馈
  - 优点：学习信号丰富，探索效率高
  - 缺点：设计复杂，可能引入偏差

**塑造奖励（Reward Shaping）**：
- 在不改变最优策略的前提下添加额外奖励
- 常用方法：基于势函数的方法、基于特征的方法
- 原则：确保原问题的最优策略仍然是最优的

## 3. 数学公式与推导

### 3.1 奖励函数表示

一般形式：$R: \mathcal{S} \times \mathcal{A} \rightarrow \mathbb{R}$

对于连续状态和动作空间，通常使用参数化形式：
$$
R(s,a; \theta) = \theta^T \phi(s,a)
$$
其中 $\phi(s,a)$ 是状态-动作特征向量，$\theta$ 是参数向量。

### 3.2 逆强化学习的特征匹配

设专家演示为轨迹集合 $\mathcal{D} = \{\tau_1, \tau_2, ..., \tau_m\}$，其中 $\tau = (s_0, a_0, s_1, a_1, ..., s_T)$。

定义特征函数 $F(s,a)$：将状态-动作对映射到特征向量。

**专家特征期望**：
$$
E_{d^{\pi_{expert}}}[F(s,a)]
$$

**学习策略特征期望**：
$$
E_{d^{\pi}}[F(s,a)]
$$

**IRL的目标**：找到奖励函数 $R(s,a) = w^T \phi(s,a)$ 使得：
$$
w = \arg\min_w \left( E_{d^{\pi_{expert}}}[F(s,a)] - E_{d^{\pi_w}}[F(s,a)] \right)^2 + \lambda ||w||^2
$$

### 3.3 最大熵逆强化学习

最大熵IRL框架：
$$
\max_{R} \mathcal{H}(\pi_R) + \alpha \sum_{s,a} d^{\pi_R}(s,a) R(s,a)
$$
其中 $\mathcal{H}(\pi_R)$ 是策略的熵，$\alpha$ 是温度参数。

约束条件：策略 $\pi_R$ 与专家策略 $\pi_{expert}$ 在特征期望上匹配。

## 4. 训练过程讲解

训练过程主要包括：

1. **数据收集**：收集专家演示数据
2. **特征提取**：提取状态-动作特征
3. **参数优化**：
   - 使用最大似然估计
   - 或使用最大熵框架
   - 或使用对抗训练（GAIL）
4. **策略优化**：使用学习到的奖励函数训练策略
5. **评估与迭代**：评估性能并调整

**常用算法**：
- 最大熵逆强化学习（MaxEnt IRL）
- 生成对抗模仿学习（GAIL）
- 逆强化模仿学习（RIL）
- 基于演示的逆强化学习（DAgger）

## 5. 应用场景

- 机器人控制：从专家演示中学习任务
- 自动驾驶：学习人类驾驶行为
- 游戏AI：从高手玩家学习
- 工业优化：基于专家经验设计奖励
- 多智能体系统：协调多个智能体的行为

## 6. 优缺点分析

**优点**：
- 可以从专家演示中自动学习奖励
- 解决奖励设计困难的问题
- 无需明确指定目标函数
- 结合专家知识更有效

**缺点**
- 依赖高质量的专家演示
- 计算复杂度较高
- 可能从专家错误中学习
- 对噪声敏感

## 7. 调库实现

import numpy as np
from sklearn.linear_model import LinearRegression

class InverseRL:
    def __init__(self, feature_dim):
        self.feature_dim = feature_dim
        self.w = None
    
    def extract_features(self, states, actions):
        """提取状态-动作特征"""
        features = []
        for s, a in zip(states, actions):
            # 简单的特征工程
            feature = np.concatenate([
                s,  # 状态特征
                a,  # 动作特征
                s * a,  # 状态-动作交互特征
                s**2,  # 状态平方特征
                a**2   # 动作平方特征
            ])
            features.append(feature)
        return np.array(features)
    
    def fit(self, expert_demonstrations):
        """从专家演示中学习奖励函数"""
        # 提取所有轨迹的特征
        all_features = []
        all_rewards = []  # 假设我们有专家标注的奖励
        
        for traj in expert_demonstrations:
            states, actions, rewards = traj
            features = self.extract_features(states, actions)
            all_features.append(features)
            all_rewards.append(rewards)
        
        X = np.vstack(all_features)
        y = np.concatenate(all_rewards)
        
        # 使用线性回归学习奖励参数
        model = LinearRegression()
        model.fit(X, y)
        self.w = model.coef_
        
        return self
    
    def predict_reward(self, state, action):
        """预测给定状态-动作对的奖励"""
        if self.w is None:
            raise ValueError("Model not fitted yet")
        
        feature = self.extract_features([state], [action])[0]
        return np.dot(self.w, feature)

## 8. 手工代码实现

import numpy as np
from scipy.optimize import minimize

def manual_maxent_irl(features, expert_counts, expert_trajectories, 
                     num_states, num_actions, regularization=0.1):
    """
    手动实现最大熵逆强化学习
    features: 状态-动作特征矩阵
    expert_counts: 专家访问每个状态-动作对的次数
    """
    d = features.shape[1]  # 特征维度
    
    # 目标函数：最大化熵，同时匹配专家特征
    def objective(w):
        # 计算奖励函数
        R = features @ w
        
        # 计算策略（softmax）
        exp_R = np.exp(R)
        policy = exp_R / exp_R.sum()
        
        # 策略的熵
        entropy = -np.sum(policy * np.log(policy + 1e-10))
        
        # 策略的特征期望
        expected_features = policy @ features
        
        # 特征匹配损失
        feature_loss = np.sum((expected_features - expert_counts) ** 2)
        
        # 目标：最大化熵，最小化特征损失
        return -entropy + regularization * feature_loss
    
    # 初始参数
    w0 = np.zeros(d)
    
    # 优化
    result = minimize(objective, w0, method='L-BFGS-B')
    
    return result.x

## 10. 模型评估

评估奖励设计质量的指标：
- **策略性能**：学习到的策略在任务上的表现
- **奖励一致性**：奖励函数是否与专家行为一致
- **泛化能力**：在不同任务上的表现
- **样本效率**：学习所需的数据量

## 11. 常见问题与易错点

- **奖励函数设计不当**：导致次优行为
  - 解决方法：仔细设计奖励项，使用潜在空间距离
- **过拟合专家演示**：学习到专家的错误
  - 解决方法：正则化，使用最大熵框架
- **特征工程不当**：特征不足或冗余
  - 解决方法：自动特征学习，使用神经网络
- **优化困难**：非凸问题导致局部最优
  - 解决方法：多次初始化，使用更好的优化算法
