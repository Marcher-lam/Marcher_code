# 时序差分学习 学习文档

> 用一句话说明这个算法的核心价值：通过单步更新和自举方法，在无需完整轨迹的情况下高效学习价值函数，是连接动态规划和蒙特卡洛方法的桥梁，为现代强化学习提供了核心更新逻辑。

## 1. 算法基础认知

时序差分学习（Temporal Difference Learning，TD）是一种结合蒙特卡洛方法和动态规划优点的免模型强化学习算法，通过单步更新来学习价值函数，无需等待回合结束即可更新。

**一句话定义**：TD方法使用当前奖励 $r_t$ 和下一个状态的估计价值 $V(s_{t+1})$ 来更新当前状态的价值，通过自举方式逐步迭代，兼顾无偏性和低方差。

**历史背景（扩展版）**：
- 1988年Richard Sutton在论文《Learning to Predict by Methods of Temporal Differences》中首次系统化提出TD学习框架，奠定了TD方法的理论基础。
- 1989年Sutton提出TD(λ)，引入多步回报和衰减因子λ，平衡偏差和方差，将MC和TD统一在一个框架下。
- 1990年代TD方法被扩展到Q函数，形成Sarsa、Q-learning等经典表格型算法，成为强化学习最主流的更新范式。
- 2013年DeepMind将TD方法与深度学习结合，提出DQN，在Atari游戏上超越人类水平，开启深度强化学习时代。
- 2016年后TD方法成为现代强化学习（Actor-Critic、PPO、SAC等）的核心更新机制。

**关键论文与里程碑**：
- Sutton, R. S. (1988). "Learning to Predict by the Methods of Temporal Differences". Machine Learning, 3(1-3), 9-44.
- Sutton, R. S., & Barto, A. G. (1987). "A Temporal-Difference Model of Reinforcement Learning". Physiological Psychology and Motivation.
- Watkins, C. J. C. H. (1989). "Learning from Delayed Rewards". PhD Thesis, University of Cambridge.
- Mnih, V., et al. (2013). "Playing Atari with Deep Reinforcement Learning". arXiv:1312.5602.

**直觉类比（3-5个）**：
1. **骑车学平衡**：蒙特卡洛方法需要完成整个旅程后才总结教训，而TD方法每蹬一圈就调整一次姿势，边骑边学，效率更高。
2. **股票投资**：蒙特卡洛需要持有股票到卖出（完整回合）才计算收益，TD方法每天根据当日涨跌和下一日预期调整对当前持仓价值的估计。
3. **烹饪调整**：做菜时蒙特卡洛要等整道菜做完才调整配方，TD方法每加一种调料就尝一口，根据当前味道和下一步预期调整当前调料的用量。
4. **学习考试**：蒙特卡洛要等考完试才总结学习方法，TD方法每做完一套题就根据得分和下一套题的预期难度调整学习策略。

**算法定位表**：
| 维度 | 说明 |
|------|------|
| 模型依赖 | 免模型（Model-free），无需环境动力学 |
| 任务类型 | 适用于回合制和持续任务，无终止状态要求 |
| 更新频率 | 单步更新（每执行一步即可更新） |
| 估计性质 | 有偏估计（使用自举），但方差低于MC |
| 后续算法基础 | Q-learning、Sarsa、DQN、Actor-Critic等绝大多数RL算法的核心 |

## 2. 核心原理

TD方法的核心思想是：**结合动态规划的自举（用当前估计的价值更新自己）和蒙特卡洛的采样（从环境交互获取数据）**，用 $r_t + \gamma V(s_{t+1})$ 近似真实回报 $G_t$，实现单步高效更新。

**工作流程（详细版）**：
1. **初始化**：初始化价值函数 $V(s)$ 或动作价值函数 $Q(s,a)$ 为0或随机值，初始化策略 $\pi(a|s)$（通常为ε-贪婪策略）。
2. **单步交互**：观察当前状态 $s_t$，根据策略选择动作 $a_t$，环境返回奖励 $r_t$ 和下一个状态 $s_{t+1}$。
3. **TD误差计算**：$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$（状态价值）或 $\delta_t = r_t + \gamma Q(s_{t+1},a_{t+1}) - Q(s_t,a_t)$（动作价值）。
4. **价值更新**：$V(s_t) \leftarrow V(s_t) + \alpha \delta_t$，其中 $\alpha$ 是学习率。
5. **状态更新**：$s_t \leftarrow s_{t+1}$，重复步骤2-4直到回合结束或达到最大步数。
6. **多回合迭代**：重复上述过程多个回合直至价值函数收敛。

**关键概念解释**：
- **TD误差（TD Error）**：$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$，表示当前估计的误差，是TD更新的核心。
- **自举（Bootstrap）**：使用当前估计的 $V(s_{t+1})$ 来更新 $V(s_t)$，属于用估计值更新自己，因此是有偏的。
- **TD(0)**：单步TD，仅使用下一个状态的价值，即上述标准流程。
- **TD(λ)**：多步TD，结合1步到无穷多步的回报，用λ加权，平衡偏差和方差。
- **同策略（On-policy）**：如Sarsa，行为策略=目标策略，用实际执行的下一个动作更新。
- **异策略（Off-policy）**：如Q-learning，行为策略≠目标策略，用最大Q值更新。

**ASCII流程图（TD(0)状态价值更新）**：
```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ 初始化V/π   │     │ 观察状态s_t │     │ 选择动作a_t │
└──────┬──────┘     └──────┬──────┘     └──────┬──────┘
       │                   │                   │
       │                   ▼                   ▼
       │              ┌─────────────┐     ┌─────────────┐
       │              │ 执行动作a_t │────▶│ 得到r_t,s_{t+1}│
       │              └─────────────┘     └──────┬──────┘
       │                                     │
       │                     ┌───────────────┘
       ▼                     ▼
┌─────────────┐     ┌──────────────────────────────┐
│ 更新状态s_t │     │ 计算TD误差δ_t = r_t + γV(s_{t+1}) - V(s_t) │
└──────┬──────┘     └──────────────────────────────┘
       │                     │
       │                     ▼
       │              ┌──────────────────┐
       │              │ 更新V(s_t) += αδ_t │
       │              └──────────────────┘
       │                     │
       └─────────────────────┘
```

**与同类算法对比（3-5个）**：
1. **TD vs 蒙特卡洛（MC）**：
   - TD单步更新，MC需要完整轨迹
   - TD有偏（自举），MC无偏
   - TD低方差，MC高方差
   - TD适用于持续任务，MC仅适用于回合制
2. **TD vs 动态规划（DP）**：
   - TD免模型，DP需要完整环境模型
   - TD基于采样，DP基于全宽度备份
   - TD用估计值自举，DP用真实模型计算期望
3. **TD(0) vs TD(λ)**：
   - TD(0)单步，偏差大方差小
   - TD(λ)多步加权，平衡偏差和方差
   - λ=0退化为TD(0)，λ=1接近MC
4. **Sarsa vs Q-learning**：
   - Sarsa同策略，用实际下一个动作更新，保守
   - Q-learning异策略，用最大Q值更新，激进最优

**工程经验**：
- 学习率α通常设置为0.1~0.01，过大导致震荡，过小导致收敛慢。
- 折扣因子γ根据任务长度调整：短任务（<100步）用0.9，长任务（>1000步）用0.99。
- 探索率ε使用衰减策略：从0.1开始，每回合乘以0.995，平衡探索和利用。
- 对于持续任务，设置最大步数防止无限循环。

## 3. 数学公式与推导

**完整符号约定表**：
| 符号 | 含义 | 维度/范围 | 单位/说明 |
|------|------|-----------|-----------|
| $V(s)$ | 状态价值函数 | $\mathbb{R}$ | 长期折扣奖励的期望 |
| $Q(s,a)$ | 动作价值函数 | $\mathbb{R}$ | 同上 |
| $r_t$ | 时刻t的即时奖励 | $\mathbb{R}$ | 与奖励单位一致 |
| $\gamma$ | 折扣因子 | $[0,1)$ | 无单位，接近1重视长期 |
| $\alpha$ | 学习率 | $(0,1]$ | 无单位，控制更新步长 |
| $\lambda$ | TD(λ)衰减因子 | $[0,1]$ | 无单位，控制多步权重 |
| $\delta_t$ | TD误差 | $\mathbb{R}$ | 价值估计的误差信号 |

**TD(0)更新公式推导**：
从状态价值函数的定义出发：
$$V^\pi(s_t) = \mathbb{E}_\pi \left[ G_t | s_t \right] = \mathbb{E}_\pi \left[ r_{t+1} + \gamma G_{t+1} | s_t \right]$$
根据马尔可夫性质，$G_{t+1}$的期望等于 $V^\pi(s_{t+1})$，因此：
$$V^\pi(s_t) = \mathbb{E}_\pi \left[ r_{t+1} + \gamma V^\pi(s_{t+1}) | s_t \right]$$
TD(0)用采样得到的 $r_t + \gamma V(s_{t+1})$ 近似上述期望，通过随机梯度下降最小化均方误差：
$$\min_V \frac{1}{2} \left( (r_t + \gamma V(s_{t+1})) - V(s_t) \right)^2$$
求梯度得更新规则：
$$V(s_t) \leftarrow V(s_t) + \alpha \left( r_t + \gamma V(s_{t+1}) - V(s_t) \right)$$

**TD(λ)多步回报**：
TD(λ)结合n步回报 $G_t^{(n)} = r_{t+1} + \gamma r_{t+2} + ... + \gamma^{n-1} r_{t+n} + \gamma^n V(s_{t+n})$，加权得到λ-回报：
$$G_t^\lambda = (1-\lambda) \sum_{n=1}^\infty \lambda^{n-1} G_t^{(n)}$$
当λ=0时，$G_t^\lambda = r_{t+1} + \gamma V(s_{t+1})$，退化为TD(0)；
当λ=1时，$G_t^\lambda = G_t$（完整回报），接近MC方法。

**Sarsa（同策略TD控制）更新**：
$$Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha \left( r_t + \gamma Q(s_{t+1},a_{t+1}) - Q(s_t,a_t) \right)$$
其中 $a_{t+1}$ 是实际执行的下一个动作，由当前策略选择。

**Q-learning（异策略TD控制）更新**：
$$Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha \left( r_t + \gamma \max_{a'} Q(s_{t+1},a') - Q(s_t,a_t) \right)$$
目标策略是贪心策略 $\arg\max_a Q(s,a)$，行为策略是ε-贪婪策略，因此为异策略。

**伪代码（TD(0)状态价值评估）**：
```
初始化 V(s) = 0 对所有状态s
循环直到收敛：
    重置环境，获取初始状态s
    循环直到回合结束：
        根据策略π选择动作a
        执行动作a，得到r, s'
        计算TD误差δ = r + γV(s') - V(s)
        更新V(s) += αδ
        s = s'
```

**收敛性证明（TD(0)固定策略下）**：
在固定策略π、学习率α满足Robbins-Monro条件（$\sum \alpha_t = \infty, \sum \alpha_t^2 < \infty$）时，TD(0)的更新会收敛到 $V^\pi$，即策略π下的真实状态价值函数。

## 4. 训练过程讲解

**数据预处理细节（以典型环境为例）**：
1. **CartPole-v1环境**：
   - 状态：4维连续向量，范围分别为 $[-2.4, 2.4]$、$[-\infty, \infty]$、$[-0.2095, 0.2095]$、$[-\infty, \infty]$
   - 预处理：表格型TD需离散化（如角度>0.1为右，< -0.1为左），深度TD直接用原始状态。
2. **CliffWalking-v0环境**：
   - 状态：0~47的整数（4×12网格），无需预处理。
   - 动作：0~3的整数（上、下、左、右），无需预处理。
3. **Acrobot-v1环境**：
   - 状态：6维连续向量（两个杆的角度、角速度），需离散化或直接使用函数近似。

**参数初始化表（不同环境推荐值）**：
| 环境 | $\gamma$ | $\alpha$ | $\epsilon$ | 回合数 |
|------|----------|----------|----------|--------|
| CartPole-v1 | 0.99 | 0.01 | 0.1（衰减） | 1000 |
| CliffWalking-v0 | 0.9 | 0.1 | 0.1（衰减） | 500 |
| Acrobot-v1 | 0.95 | 0.05 | 0.2（衰减） | 2000 |

**完整训练流程（以Sarsa为例）**：
1. **环境初始化**：创建Gym环境，设置随机种子。
2. **参数初始化**：初始化 $Q(s,a)$ 为全0，ε=0.1，α=0.1，γ=0.9。
3. **回合循环**：
   - 重置环境，获取初始状态 $s$，用ε-贪婪选择初始动作 $a$。
   - **单步循环**：
     - 执行动作 $a$，得到 $r, s', done$。
     - 如果 $done$ 则目标为 $r$，否则用ε-贪婪选择下一个动作 $a'$，目标为 $r + \gamma Q(s',a')$。
     - 计算TD误差 $\delta = target - Q(s,a)$。
     - 更新 $Q(s,a) += αδ$。
     - 更新 $s \leftarrow s'$，$a \leftarrow a'$。
     - 如果 $done$ 则跳出循环。
   - 衰减探索率：$\epsilon \leftarrow \epsilon \times 0.995$。
4. **收敛判断**：当连续100回合的平均回报变化小于1，或达到最大回合数时停止。

**工程调试技巧**：
- 检查TD误差：如果δ的绝对值持续大于1，说明学习率过大或价值函数初始化不合理。
- 检查Q值范围：正常Q值应在 $[-100, 100]$ 之间，过大可能是奖励未裁剪或γ过大。
- 可视化训练曲线：每100回合打印平均回报，观察是否收敛。

**收敛条件**：
1. TD误差收敛：$\frac{1}{N} \sum |\delta_t| < 0.01$
2. 价值函数变化：$\max_{s,a} |Q_{new}(s,a) - Q_{old}(s,a)| < 10^{-3}$
3. 回报收敛：连续100回合的平均回报波动小于5%

## 5. 应用场景

**典型应用案例（5个，含完整定义）**：
1. **CliffWalking（悬崖寻路）**：
   - 状态：4×12网格位置（48个状态）
   - 动作：上、下、左、右（4个动作）
   - 奖励：每步-1，掉悬崖-100，到达终点0
   - 适用性：TD单步更新效率高，Sarsa保守策略可避免频繁掉崖。
2. **CartPole（推车杆）**：
   - 状态：位置、速度、角度、角速度（4维连续）
   - 动作：向左推、向右推（2个动作）
   - 奖励：每保持平衡一步+1，杆倒或出界终止
   - 适用性：持续任务无终止状态，TD单步更新可实时学习。
3. **游戏AI（Pong、Breakout）**：
   - 状态：游戏画面（84×84灰度图，4帧堆叠）
   - 动作：上、下、不动（3个动作）
   - 奖励：得分变化（+1/-1）
   - 适用性：TD是DQN的核心更新逻辑，适合处理高维状态。
4. **机器人实时导航**：
   - 状态：激光雷达点云、自身位置（高维连续）
   - 动作：线速度、角速度（2维连续）
   - 奖励：接近目标+1，碰撞-10，每步-0.01
   - 适用性：TD单步更新满足实时性要求，无需等待回合结束。
5. **量化交易**：
   - 状态：价格、成交量、技术指标（离散化特征）
   - 动作：买入、卖出、持有（3个动作）
   - 奖励：每笔交易净利润，日内收盘强制平仓
   - 适用性：TD可处理持续交易任务，实时调整策略。

**适用场景特征表**：
| 特征 | 说明 |
|------|------|
| 任务类型 | 回合制或持续任务均可 |
| 环境模型 | 未知或复杂，免模型 |
| 更新需求 | 需要实时/单步更新 |
| 状态空间 | 离散（表格型）或连续（函数近似） |
| 动作空间 | 离散或连续（需结合Actor-Critic） |

**不适用场景及替代方案**：
1. **需要无偏估计的场景**：TD有偏，替代方案：蒙特卡洛方法。
2. **表格型TD处理大规模状态空间**：替代方案：深度Q网络（DQN）、Actor-Critic。
3. **部分可观测环境**：替代方案：部分可观测MDP（POMDP）方法、递归神经网络。

## 6. 优缺点分析

**优点（5个，含条件）**：
1. **低方差，单步更新**：
   - 条件：使用单步奖励和自举，避免累积回报的高方差。
   - 说明：相比MC，TD学习更稳定，收敛更快。
2. **适用于持续任务**：
   - 条件：无需等待回合结束，可处理无终止状态的任务。
   - 说明：比MC应用场景更广，适合机器人、自动驾驶等实时任务。
3. **结合DP和MC优点**：
   - 条件：既有自举（DP）又有采样（MC）。
   - 说明：比DP更实用（免模型），比MC更高效（单步更新）。
4. **工程实现简单**：
   - 条件：仅需存储当前状态和下一个状态的价值。
   - 说明：核心代码仅需10行左右，适合入门实践。
5. **支持异策略学习**：
   - 条件：如Q-learning，行为策略和目标策略分离。
   - 说明：可复用历史经验，样本利用率高于同策略方法。

**缺点（5个，含问题/解决方案）**：
1. **有偏估计**：
   - 问题：使用自举，初始阶段价值估计有偏，影响收敛速度。
   - 解决方案：增加采样次数，或使用TD(λ)平衡偏差和方差。
2. **对初始值敏感**：
   - 问题：初始 $V(s)$ 或 $Q(s,a)$ 过大/过小，导致收敛慢。
   - 解决方案：使用合理初始化（如0），或结合MC初始化。
3. **仅支持离散动作（表格型）**：
   - 问题：无法枚举所有动作求max，难以处理连续动作。
   - 解决方案：使用深度Q网络（DQN）或Actor-Critic处理连续动作。
4. **经验利用率低（同策略）**：
   - 问题：Sarsa等只能使用当前策略采样的经验，样本利用率低。
   - 解决方案：使用异策略方法（Q-learning）或经验回放（DQN）。
5. **λ选择困难（TD(λ)）**：
   - 问题：λ过大接近MC（高方差），过小接近TD(0)（高偏差）。
   - 解决方案：使用交叉验证选择λ，或使用True Online TD(λ)。

**与同类算法对比表**：
| 特性 | TD(0) | MC | DP | DQN |
|------|-------|----|----|-----|

使用Python、NumPy、Gymnasium实现Sarsa和Q-learning，包含详细注释和工程优化：

```python
import numpy as np
import gymnasium as gym
import random
import matplotlib.pyplot as plt

class SarsaAgent:
    """Sarsa算法智能体（同策略TD控制）"""
    def __init__(self, num_states, num_actions, gamma=0.9, alpha=0.1, epsilon=0.1):
        self.num_states = num_states
        self.num_actions = num_actions
        self.gamma = gamma
        self.alpha = alpha
        self.epsilon = epsilon
        self.Q = np.zeros((num_states, num_actions))  # 初始化Q表
        
    def choose_action(self, state):
        """ε-贪婪策略选择动作"""
        if random.random() < self.epsilon:
            return random.randint(0, self.num_actions - 1)
        else:
            return np.argmax(self.Q[state])
    
    def update(self, state, action, reward, next_state, next_action, done):
        """Sarsa更新规则"""
        if done:
            target = reward
        else:
            target = reward + self.gamma * self.Q[next_state][next_action]
        td_error = target - self.Q[state][action]
        self.Q[state][action] += self.alpha * td_error
    
    def train(self, env, num_episodes=500, max_steps=100):
        """训练主函数，返回训练奖励历史"""
        reward_history = []
        for episode in range(num_episodes):
            state, _ = env.reset()
            action = self.choose_action(state)
            episode_reward = 0
            for _ in range(max_steps):
                next_state, reward, terminated, truncated, _ = env.step(action)
                done = terminated or truncated
                next_action = self.choose_action(next_state)
                self.update(state, action, reward, next_state, next_action, done)
                episode_reward += reward
                state = next_state
                action = next_action
                if done:
                    break
            reward_history.append(episode_reward)
            self.epsilon *= 0.995  # 衰减探索率
            if (episode + 1) % 100 == 0:
                avg_reward = np.mean(reward_history[-100:])
                print(f"Sarsa 回合 {episode+1}, 平均奖励: {avg_reward:.2f}")
        return reward_history

class QLearningAgent:
    """Q-learning算法智能体（异策略TD控制）"""
    def __init__(self, num_states, num_actions, gamma=0.9, alpha=0.1, epsilon=0.1):
        self.num_states = num_states
        self.num_actions = num_actions
        self.gamma = gamma
        self.alpha = alpha

    def choose_action(self, state):
        """ε-贪婪策略"""
        if random.random() < self.epsilon:
            return random.randint(0, self.num_actions - 1)
        else:
            return np.argmax(self.Q[state])
    
    def update(self, state, action, reward, next_state, done):
        """Q-learning更新规则（使用max而非实际下一个动作）"""
        if done:
            target = reward
        else:
            target = reward + self.gamma * np.max(self.Q[next_state])
        td_error = target - self.Q[state][action]
        self.Q[state][action] += self.alpha * td_error
    
    def train(self, env, num_episodes=500, max_steps=100):
        """训练主函数"""
        reward_history = []
        for episode in range(num_episodes):
            state, _ = env.reset()
            episode_reward = 0
            for _ in range(max_steps):
                action = self.choose_action(state)
                next_state, reward, terminated, truncated, _ = env.step(action)
                done = terminated or truncated
                self.update(state, action, reward, next_state, done)
                episode_reward += reward
                state = next_state
                if done:
                    break
            reward_history.append(episode_reward)
            self.epsilon *= 0.995
            if (episode + 1) % 100 == 0:
                avg_reward = np.mean(reward_history[-100:])
                print(f"Q-learning 回合 {episode+1}, 平均奖励: {avg_reward:.2f}")
        return reward_history
```

```python
class TD0Base:
    """从零实现的TD(0)状态价值评估"""
    def __init__(self, num_states, gamma=0.9, alpha=0.1):
        self.num_states = num_states
        self.gamma = gamma
        self.alpha = alpha
        self.V = np.zeros(num_states)  # 状态价值函数
        
    def choose_action(self, state, num_actions):
        """随机策略"""
        return random.randint(0, num_actions - 1)
    
    def update(self, state, reward, next_state):
        """TD(0)更新"""
        td_error = reward + self.gamma * self.V[next_state] - self.V[state]
        self.V[state] += self.alpha * td_error
    
    def train(self, env, num_episodes=1000, max_steps=100):
        """训练状态价值函数"""
        for episode in range(num_episodes):
            state, _ = env.reset()
            for _ in range(max_steps):
                action = self.choose_action(state, env.action_space.n)
                next_state, reward, terminated, truncated, _ = env.step(action)
                done = terminated or truncated
                if done:
                    # 终止状态的价值为0
                    td_error = reward - self.V[state]
                    self.V[state] += self.alpha * td_error
                    break
                else:
                    self.update(state, reward, next_state)
                state = next_state
        return self.V
```

## 10. 模型评估

完整的TD模型评估代码，包含多维度指标和超参数交叉验证：

```python
def evaluate_td_agent(agent, env, num_episodes=100, max_steps=100):
    """评估TD智能体的性能，关闭探索"""
    total_rewards = []
    total_steps = []
    cliff_count = 0  # 掉崖次数（CliffWalking专用）
    
    original_epsilon = agent.epsilon
    agent.epsilon = 0  # 关闭探索，使用贪心策略
    
    for episode in range(num_episodes):
        state, _ = env.reset()
        episode_reward = 0
        steps = 0
        while steps < max_steps:
            if hasattr(agent, 'Q'):  # Q-learning/Sarsa
                action = np.argmax(agent.Q[state])
            else:  # TD0状态价值
                action = np.argmax(agent.V[state]) if hasattr(agent.V[state], '__len__') else 0
            next_state, reward, terminated, truncated, _ = env.step(action)
            done = terminated or truncated
            episode_reward += reward
            steps += 1
            state = next_state
            if reward == -100:  # CliffWalking掉崖奖励
                cliff_count += 1
            if done:
                break
    
    agent.epsilon = original_epsilon  # 恢复探索率
    
    mean_reward = np.mean(total_rewards)
    std_reward = np.std(total_rewards)
    mean_steps = np.mean(total_steps)
    success_rate = sum(1 for r in total_rewards if r > -50) / num_episodes  # 非掉崖即为成功
    
    print(f"评估结果（{num_episodes}回合）：")
    print(f"平均奖励：{mean_reward:.2f} ± {std_reward:.2f}")
    print(f"平均步数：{mean_steps:.2f}")
    print(f"掉崖次数：{cliff_count}")
    print(f"成功率：{success_rate:.2%}")
    
    return mean_reward, std_reward, mean_steps, success_rate

def cross_validate_td_hyperparams():
    """交叉验证选择TD算法的最佳超参数"""
    import gymnasium as gym
    env = gymnasium.make("CliffWalking-v0")
    alphas = [0.01, 0.1, 0.2]
    gammas = [0.8, 0.9, 0.95]
    
    results = {}
    for alpha in alphas:
        for gamma in gammas:
            # 训练Q-learning智能体
            agent = QLearningAgent(env.observation_space.n, env.action_space.n, gamma=gamma, alpha=alpha)
            agent.train(env, num_episodes=500)
            # 评估
            mean_reward, _, _, _ = evaluate_td_agent(agent, env)
            results[(alpha, gamma)] = mean_reward
            print(f"alpha={alpha}, gamma={gamma}, 平均奖励={mean_reward:.2f}")
    
    # 找到最佳参数
    best_params = max(results, key=results.get)
    print(f"\n最佳超参数：alpha={best_params[0]}, gamma={best_params[1]}, 奖励={results[best_params]:.2f}")
    env.close()
```

**评估指标说明**：
1. **平均奖励**：越接近环境最优奖励（CliffWalking中Q-learning为-13，Sarsa为-17）越好。
2. **奖励标准差**：越小说明策略越稳定，TD通常比MC更稳定。
3. **掉崖次数**：Sarsa应明显少于Q-learning，体现保守策略优势。
4. **成功率**：到达终点的回合占比，越高说明策略越可靠。

**评估流程注意事项**：
- 评估时必须关闭探索（epsilon=0），否则结果会包含随机探索的噪声。
- TD算法评估无需等待回合结束，可单步评估实时性能。
- 多次运行取平均，避免单次运行的随机性影响结果。

## 11. 常见问题与易错点

### 数据层面（3个）
1. **TD误差不收敛**：
   - 现象：TD误差持续大于0.1，价值函数不收敛。
   - 原因：学习率α过大（震荡）或过小（收敛慢），或γ>=1导致自举不稳定。
   - 解决方案：减小α到0.01~0.1，确保γ<1，检查奖励是否未裁剪。
2. **状态访问不均匀**：
   - 现象：某些状态的Q值更新次数过少，估计不准。
   - 原因：探索策略不佳（如ε过小），导致状态覆盖不全。
   - 解决方案：增大ε，或使用UCB探索替代ε-贪婪。
3. **持续任务无限循环**：
   - 现象：智能体在持续任务中永远不终止，训练无法停止。
   - 原因：未设置最大步数max_steps，或任务确实无终止状态。
   - 解决方案：设置合理的max_steps（如1000步），超时强制终止。

### 模型层面（3个）
1. **Q值不收敛（表格型）**：
   - 现象：Q值震荡或发散，无法稳定。
   - 原因：自举导致有偏，初始阶段偏差大。
   - 解决方案：增加采样次数，或使用TD(λ)平衡偏差和方差。
2. **Sarsa和Q-learning混淆**：
   - 现象：代码中意外使用了max操作（Q-learning）或实际下一个动作（Sarsa）。
   - 原因：未区分同策略和异策略的更新逻辑。
   - 解决方案：Sarsa更新必须传入next_action，Q-learning更新用np.max(Q[next_state])。
3. **对初始值敏感**：
   - 现象：Q表初始化为较大值导致收敛慢，初始化为较小值导致探索不足。
   - 原因：TD自举依赖当前估计，初始值影响后续更新。
   - 解决方案：表格型TD初始化为0，函数近似使用合适的初始化方法。

### 调参层面（2个）
1. **学习率α选择不当**：
   - 现象：α过大导致Q值震荡，α过小导致收敛极慢。
   - 原因：未根据任务特性调整α，短任务用大α，长任务用小α。
   - 解决方案：短任务（<100步）用0.1~0.2，长任务（>1000步）用0.01~0.05。
2. **折扣因子γ选择不当**：
   - 现象：γ过大导致自举不稳定，γ过小导致策略短视。
   - 原因：未根据任务长度调整γ，短任务用大γ，长任务用小γ。
   - 解决方案：短任务用0.9，长任务用0.99，持续任务用0.95。

### 调试技巧
- 打印TD误差：每100步打印平均TD误差，观察是否逐步收敛到0。
- 打印Q值范围：正常Q值应在合理区间，超出范围说明奖励或γ设置不当。
- 可视化策略：定期可视化当前学习到的策略，检查是否符合预期（如Sarsa是否保守）。

**工程最佳实践**：
- 使用experience replay（经验回放）：存储历史经验，随机采样更新，打破相关性，提升稳定性（DQN核心技巧）。
- 使用target network（目标网络）：单独维护一个目标Q网络，定期同步参数，减少自举的偏差（DQN核心技巧）。
- 并行采样：使用多进程同时生成轨迹，提升采样效率，加速训练。

## 12. 学习总结

### 核心思想回顾
时序差分学习通过**单步更新和自举**，结合动态规划和蒙特卡洛方法的优点，在无需完整轨迹的情况下高效学习价值函数，是强化学习最核心的更新范式，支撑了绝大多数现代RL算法。

### ASCII思维导图
```
时序差分学习（TD）
├── 核心思想：单步更新 + 自举 → 兼顾效率和无偏性
├── 关键特性
│   ├── 免模型：无需环境动力学
│   ├── 有偏估计：自举导致
│   ├── 低方差：单步更新导致
│   └── 单步更新：支持持续任务
├── 主要变体
│   ├── TD(0)：单步，偏差大方差小
│   ├── TD(λ)：多步加权，平衡偏差方差
│   ├── Sarsa：同策略TD控制
│   └── Q-learning：异策略TD控制
└── 应用场景
    ├── 回合制+持续任务
    ├── 实时决策场景
    └── 深度RL核心更新逻辑
```

### 关键公式总结（3个，需牢记）
1. **TD(0)更新**：$V(s) \leftarrow V(s) + \alpha (r + \gamma V(s') - V(s))$ → 单步价值更新核心公式。
2. **Sarsa更新**：$Q(s,a) \leftarrow Q(s,a) + \alpha (r + \gamma Q(s',a') - Q(s,a))$ → 同策略控制核心。
3. **Q-learning更新**：$Q(s,a) \leftarrow Q(s,a) + \alpha (r + \gamma \max_{a'} Q(s',a') - Q(s,a))$ → 异策略控制核心。

### 与前序/后续算法的关系
- **前序**：动态规划（DP）→ TD是DP的免模型版本，用采样代替模型计算期望。
- **平行**：蒙特卡洛（MC）→ TD是MC的单步近似（n=1），MC是TD的n=∞特殊情况。
- **后续**：
  - TD → DQN → 深度Q网络，处理大规模状态空间。
  - TD → Actor-Critic → 结合价值学习和策略优化。
  - TD → PPO/DDPG → 现代策略优化算法。

## 13. 练习题与思考题

### 基础题（5道，含隐藏答案）
1. **什么是TD误差？它的含义是什么？**
   <details>
   <summary>点击查看参考答案</summary>
   TD误差 $\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$ 表示当前状态价值估计的误差。<br>
   含义：用单步自举的近似回报与当前估计的差值，指导价值更新方向。
   </details>

2. **解释Sarsa和Q-learning的核心区别，以及同策略和异策略的含义。**
   <details>
   <summary>点击查看参考答案</summary>
   - Sarsa同策略：更新用实际下一个动作 $a'$，行为策略=目标策略。<br>
   - Q-learning异策略：更新用 $\max Q(s',a')$，行为策略（ε-贪婪）≠目标策略（贪心）。<br>
   - 同策略：学习和探索用同一个策略；异策略：学习的目标是贪心策略，与探索策略无关。
   </details>

3. **TD方法为什么是有偏的？它的方差为什么比MC低？**
   <details>
   <summary>点击查看参考答案</summary>
   - 有偏：使用自举，用估计的 $V(s_{t+1})$ 代替真实价值，初始阶段估计有偏。<br>
   - 低方差：仅用单步奖励 $r_t$，而MC用多步累积回报 $G_t$，单步随机性更小。
   </details>

4. **TD(λ)中λ的作用是什么？λ=0和λ=1分别对应什么算法？**
   <details>
   <summary>点击查看参考答案</summary>
   - λ控制多步回报的权重：λ=0为TD(0)（单步，偏差大方差小），λ=1接近MC（多步，偏差小方差大）。<br>
   - λ的作用是平衡偏差和方差，通常取0.9左右效果较好。
   </details>

5. **为什么TD方法可以应用于持续任务，而MC不行？**
   <details>
   <summary>点击查看参考答案</summary>
   TD单步更新，无需等待回合结束，可处理无终止状态的持续任务；MC需要完整轨迹计算回报，持续任务无终止状态，无法应用。
   </details>

### 进阶题（2道，含推导）
1. **推导TD(0)更新公式与贝尔曼方程的关系，并解释为什么TD是动态规划的免模型版本。**
   <details>
   <summary>点击查看参考答案</summary>
   贝尔曼方程：$V^\pi(s) = \mathbb{E}[r + \gamma V^\pi(s') | s]$，TD用采样 $r + \gamma V(s')$ 近似期望，通过随机梯度下降更新，因此是DP的免模型版本。
   </details>

2. **推导TD(λ)的λ-回报公式，并证明当λ=1时接近MC方法。**
   <details>
   <summary>点击查看参考答案</summary>
   λ-回报 $G_t^\lambda = (1-\lambda) \sum_{n=1}^\infty \lambda^{n-1} G_t^{(n)}$，当λ=1时，$G_t^\lambda = G_t^{(n)}$ 当n→∞，即完整回报，接近MC。
   </details>

### 开放讨论题（2道）
1. **在实际工业场景中，TD方法相比MC有哪些优势？如何结合深度学习和TD方法处理大规模状态空间？**
   <details>
   <summary>点击查看参考答案</summary>
   - 优势：单步更新效率高、支持持续任务、低方差更稳定。<br>
   - 结合深度学习：使用神经网络近似Q函数（DQN），用TD误差作为损失函数，实现端到端学习。
   </details>

2. **TD方法的有偏性会带来什么问题？如何缓解自举带来的偏差？**
   <details>
   <summary>点击查看参考答案</summary>
   - 问题：初始阶段价值估计偏差大，导致策略收敛到次优解。<br>
   - 缓解：使用目标网络（Target Network）固定目标Q值，或使用Double Q-learning分离动作选择和Q值评估。
   </details>

### 面试题（2道）
1. **请解释TD、MC、DP三者的核心区别，并说明TD为什么是现代RL的核心。**
   <details>
   <summary>点击查看参考答案</summary>
   - DP需模型、全宽度备份；MC免模型、完整轨迹；TD免模型、单步更新。<br>
   - TD是现代RL核心：单步更新效率高，支持持续任务，是DQN、Actor-Critic等算法的基础。
   </details>

2. **在面试中，如何向非技术背景的面试官解释TD方法和MC方法的区别？**
   <details>
   <summary>点击查看参考答案</summary>
   - MC像考完试才总结学习方法，TD像每做完一套题就调整策略，效率更高；MC需要完整回合，TD每步都能学。
   </details>
