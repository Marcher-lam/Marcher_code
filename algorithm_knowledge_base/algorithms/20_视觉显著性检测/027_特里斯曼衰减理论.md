# 特里斯曼衰减理论 学习文档

> 注意力的"衰减器"模型——信息不会被完全阻断，只是被减弱。

> 来源线索：本节内容根据原书第1章关于"衰减理论"的相关章节整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义：** 特里斯曼衰减理论（Treisman's Attenuation Theory）由美国心理学家安妮·特里斯曼于1960年提出，是布罗德本特过滤器理论的修正模型，认为注意力扮演的不是二元化的过滤器而是"衰减器"——非注意通道的信息不会被完全阻断，只是信号被减弱。

**直觉类比：** 你正在一个嘈杂的派对中和朋友聊天，突然有人在不远处提到你的名字。尽管你没有关注那个方向，你的名字还是"钻进了你的耳朵"。按照特里斯曼的理论，这并不是因为那个方向的声音没有被过滤，而是因为那个声音虽然被减弱了，但你的名字（因为熟悉，阈值低）仍然能够被识别。

**历史背景：** 1960年，特里斯曼在实验中发现被试能注意到非注意通道中的语义信息（如自己的名字），这是布罗德本特"全通或全拒"理论无法解释的。她因此提出了衰减理论，修正了过滤器的"全或无"假设。

**算法定位：** 认知心理学中的早期选择理论，介于布罗德本特过滤器理论（严格早期选择）和多伊奇-诺曼后期选择理论之间。

## 2. 核心原理

### 2.1 核心思想

特里斯曼衰减理论认为注意力的选择过程是一个"衰减"而非"阻断"的过程。与布罗德本特过滤器理论相比，有三个关键差异：

1. **衰减而非阻断：** 注意力不是简单地阻断所有非目标信息，而是将它们"衰减"（减弱）
2. **变阈值机制：** 不同信息有不同的激活阈值。低阈值的信息（如自己的名字）即使被衰减也仍能被激活
3. **自上而下引导：** 注意力选择受到认知因素（期望、经验、知识）的引导

### 2.2 工作流程

```
感觉输入 → 暂时存储 → 衰减器（信号减弱） → 词典（语义加工）
→ 不同阈值(名字:低/陌生词:高) → 认知
```

### 2.3 关键概念

**衰减器（Attenuator）：** 不同于布罗德本特的"全或无"过滤器，衰减器将所有非注意通道的信号减弱，但不完全阻断。

**词典单元（Dictionary Unit）：** 每个词在记忆中都有一个"词典条目"，条目有不同的激活阈值。自己的名字阈值很低，陌生词阈值很高。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 |
|------|------|
| $\alpha \in [0, 1]$ | 衰减系数 |
| $\mathcal{S}_i$ | 第 $i$ 个信息通道 |
| $T_{dict}(w)$ | 单词 $w$ 的词典激活阈值 |
| $I(w)$ | 单词 $w$ 的输入强度 |

### 3.2 衰减模型

设注意通道的衰减系数为 $\alpha = 1$（不衰减），非注意通道的衰减系数为 $\alpha < 1$：

$$I_{focused}(w) = I(w)$$
$$I_{unfocused}(w) = \alpha \cdot I(w), \quad \alpha < 1$$

单词 $w$ 被识别的条件是：$I(w) \geq T_{dict}(w)$

对于自己的名字 $name$：$T_{dict}(name)$ 很小，因此即使 $I_{unfocused}(name) = \alpha \cdot I(name)$ 也可能大于阈值。

### 3.3 激活概率模型

$$P(recognize) = \sigma(I(w) - T_{dict}(w))$$

其中 $\sigma$ 是 sigmoid 函数。

## 4. 训练过程

衰减理论本身不需要"训练"——它是认知模型而非机器学习算法。但可以用计算模型来模拟：

```python
import numpy as np

class AttenuationModel:
    def __init__(self, alpha=0.3):
        self.alpha = alpha  # 非注意通道衰减系数
    
    def set_thresholds(self, word_thresholds):
        """设置词典激活阈值"""
        self.thresholds = word_thresholds
    
    def process(self, input_strength, is_focused, word):
        """处理信息"""
        if is_focused:
            effective_strength = input_strength
        else:
            effective_strength = self.alpha * input_strength
        
        threshold = self.thresholds.get(word, 0.5)
        prob_recognized = 1 / (1 + np.exp(-(effective_strength - threshold)))
        
        return prob_recognized > 0.5
```

## 6. 优缺点分析

### 6.1 优点
1. 更符合实际认知现象，能解释名字效应
2. 引入了自上而下的认知影响
3. 比"全或无"模型更灵活

### 6.2 缺点
1. 衰减系数难以精确量化
2. 阈值的设定缺乏统一标准
3. 没有解释衰减的具体神经机制

## 7. 调库实现

```python
"""
特里斯曼衰减理论的模拟实现
模拟不同注意力条件下的信息识别过程
"""

import numpy as np
import matplotlib.pyplot as plt


class AttenuationSimulator:
    """衰减理论的概率模型模拟"""
    
    def __init__(self, attenuation_coeff=0.3):
        self.alpha = attenuation_coeff
        
        # 词典阈值（低=容易识别）
        self.dictionary = {
            'self_name': 0.1,      # 自己的名字：阈值很低
            'familiar_word': 0.3,   # 熟悉的词：阈值中等
            'novel_word': 0.7,     # 陌生的词：阈值很高
            'random_noise': 0.9,   # 随机噪音：阈值极高
        }
    
    def probability_recognized(self, word, is_focused, input_strength=0.8):
        """计算识别概率"""
        threshold = self.dictionary.get(word, 0.6)
        effective_strength = input_strength if is_focused else self.alpha * input_strength
        prob = 1 / (1 + np.exp(-(effective_strength - threshold) * 5))
        return prob
    
    def simulate_cocktail_party(self):
        """模拟鸡尾酒会效应"""
        words = ['self_name', 'familiar_word', 'novel_word', 'random_noise']
        labels = ['自己名字', '熟悉词汇', '陌生词汇', '随机噪音']
        
        focused_probs = [self.probability_recognized(w, True, 0.8) for w in words]
        unfocused_probs = [self.probability_recognized(w, False, 0.8) for w in words]
        
        print("=" * 50)
        print("特里斯曼衰减理论 - 鸡尾酒会效应模拟")
        print("=" * 50)
        print(f"{'词汇类型':<12} {'注意通道':<10} {'非注意通道':<12} {'阈值':<8}")
        print("-" * 42)
        
        for label, fp, up, word in zip(labels, focused_probs, unfocused_probs, words):
            threshold = self.dictionary[word]
            print(f"{label:<12} {fp:<10.3f} {up:<12.3f} {threshold:<8.2f}")
        
        # 可视化
        fig, ax = plt.subplots(figsize=(10, 6))
        x = np.arange(len(words))
        width = 0.35
        
        ax.bar(x - width/2, focused_probs, width, label='注意通道', color='#4ECDC4')
        ax.bar(x + width/2, unfocused_probs, width, label='非注意通道（衰减）', color='#FF6B6B')
        
        ax.set_xlabel('词汇类型')
        ax.set_ylabel('识别概率')
        ax.set_title('特里斯曼衰减理论模拟：注意 vs 非注意通道')
        ax.set_xticks(x)
        ax.set_xticklabels(labels)
        ax.legend()
        ax.set_ylim(0, 1.1)
        
        plt.tight_layout()
        return fig


def demo():
    sim = AttenuationSimulator(attenuation_coeff=0.3)
    fig = sim.simulate_cocktail_party()
    plt.show()


if __name__ == "__main__":
    demo()
```

## 8. 手工代码实现

```python
import numpy as np


class AttenuationFilter:
    """衰减过滤器的纯NumPy实现"""
    
    def __init__(self, dictionary, attenuation_alpha=0.3):
        """
        dictionary: dict, {word: activation_threshold}
        attenuation_alpha: float, 衰减系数 (0-1)
        """
        self.dictionary = dictionary
        self.alpha = attenuation_alpha
    
    def filter(self, input_signals, attention_channel):
        """
        执行衰减过滤
        input_signals: dict {channel: {word: strength}}
        attention_channel: str, 当前注意通道
        """
        outputs = {}
        for channel, words in input_signals.items():
            outputs[channel] = {}
            for word, strength in words.items():
                if channel == attention_channel:
                    effective_strength = strength
                else:
                    effective_strength = self.alpha * strength
                
                threshold = self.dictionary.get(word, 0.5)
                is_recognized = effective_strength >= threshold
                outputs[channel][word] = {
                    'effective_strength': effective_strength,
                    'threshold': threshold,
                    'recognized': is_recognized
                }
        return outputs


def demo_attenuation():
    dict_units = {
        'your_name': 0.1,
        'hello': 0.3,
        'zwiebel': 0.7,
        'gx7k9': 0.9,
    }
    
    filter = AttenuationFilter(dict_units, 0.3)
    
    # 模拟双耳分听
    inputs = {
        'left_ear': {'your_name': 0.8, 'hello': 0.7, 'gx7k9': 0.6},
        'right_ear': {'your_name': 0.6, 'zwiebel': 0.5, 'hello': 0.4},
    }
    
    print("注意左耳时的处理结果:")
    result = filter.filter(inputs, 'left_ear')
    for channel, words in result.items():
        print(f"  {channel}:")
        for word, info in words.items():
            print(f"    {word}: 强度={info['effective_strength']:.2f}, "
                  f"阈值={info['threshold']:.1f}, 识别={info['recognized']}")


if __name__ == "__main__":
    demo_attenuation()
```

import matplotlib.pyplot as plt


def visualize_attenuation_effect():
    """可视化衰减效果随衰减系数的变化"""
    alphas = np.linspace(0, 1, 100)
    
    fig, ax = plt.subplots(figsize=(10, 6))

    input_strength = 0.8
    for label, threshold in words.items():
        effective = alphas * input_strength
        probs = 1 / (1 + np.exp(-(effective - threshold) * 5))
        ax.plot(alphas, probs, label=f'{label} (阈值={threshold})', linewidth=2)
    
    ax.axvline(x=0.3, color='gray', linestyle='--', alpha=0.5, label='典型衰减系数 (α=0.3)')

    ax.set_title('衰减系数对不同词汇识别概率的影响')
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    plt.tight_layout()

## 11. 常见问题

1. **混淆衰减与阻断：** 衰减是减弱而非直接拒绝
2. **认为阈值固定：** 阈值受经验和上下文影响
3. **忽略自上而下影响：** 期望和知识会影响衰减过程

特里斯曼衰减理论修正了布罗德本特"全或无"的极端假设，引入"衰减"概念，成功解释了"鸡尾酒会效应"中名字的意外注意现象。其核心贡献在于：
1. 建立了衰减器的概念，更加符合实际认知过程

## 13. 练习题

**题目1：** 解释为什么特里斯曼衰减理论能解释"鸡尾酒会效应"而布罗德本特不能。

**答案：** 布罗德本特认为非注意通道的信息被完全拒绝，因此语义信息（如自己的名字）不可能被加工。特里斯曼则认为非注意通道的信息只是被衰减，如果某个词具有很低的激活阈值（如自己的名字），即使衰减后仍能超过阈值被识别。

**题目2：** 比较"衰减"和"阻断"在信息加工中的根本区别。

**答案：** 阻断是"有或无"的二元操作，阻断后的信息完全无法进入认知。衰减是"量的减弱"，衰减后的信息仍可能被加工，只是需要更强的激活条件或更低的阈值。
