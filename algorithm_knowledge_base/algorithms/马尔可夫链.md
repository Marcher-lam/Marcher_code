# 马尔可夫链 学习文档

> 马尔可夫链是一种状态转移仅依赖当前状态的概率模型，通过状态转移矩阵描述系统在不同状态间的随机演化，最终趋于平稳分布。

---

## 1. 算法基础认知

**一句话定义**：一种"未来只取决于现在"的随机过程模型，用概率矩阵刻画状态间的转移规律。

**直觉类比**：想象你在迷宫中走路，每次只能走到相邻的房间，且你选择每个相邻房间的概率是固定的（比如60%走向左边，40%走向右边）。你下一步去哪个房间，完全取决于你现在在哪个房间，而不取决于你之前经过了哪些房间。这种"只看现在、不问过去"的特性就是马尔可夫性质。走的时间足够长后，你会发现在每个房间停留的时间比例趋于稳定 -- 这就是平稳分布。

**历史背景**：马尔可夫链由俄国数学家安德烈-马尔可夫（Andrey Markov）于1906年提出。最初用于研究语言中字母序列的概率规律（马尔可夫证明了普希金诗歌《叶甫盖尼-奥涅金》中元音和辅音的交替可用马尔可夫链建模）。此后，马尔可夫链被广泛应用于物理学、排队论、金融、生物信息学、自然语言处理、计算机视觉（如显著性检测中的GBVS模型）等领域。

**算法定位**：
- 类型：概率模型 --> 随机过程
- 输出：状态转移概率矩阵、平稳分布
- 模型类型：概率图模型（无向图视角）/有向图视角的随机过程

**前置知识**：
- 概率论基础（条件概率、联合概率、期望）
- 线性代数基础（矩阵乘法、特征值与特征向量、矩阵幂次）
- 基本的图论概念（节点、边、邻接矩阵）

## 2. 核心原理

### 2.1 核心思想

马尔可夫链的核心是**马尔可夫性质（Markov Property）**：给定当前状态，未来状态与过去状态条件独立。用数学语言表达：

$$ P(X_{t+1} | X_t, X_{t-1}, \ldots, X_0) = P(X_{t+1} | X_t) $$

这意味着系统的"记忆"仅限于当前状态一步。这个看似简单的假设，蕴含了深刻的数学结构。

核心思想可以概括为：**用一步转移概率矩阵完整描述系统的演化规律，通过矩阵运算推导出多步转移和长期行为**。

为什么马尔可夫性质有用？因为现实中很多系统具有或近似具有这种"短期记忆"特性：今天的天气主要取决于昨天的天气；一个网页的跳转主要取决于当前所在的页面；一段文本中下一个词的出现主要取决于前面的几个词（n-gram语言模型）。

### 2.2 工作流程

1. **定义状态空间**：确定系统的所有可能状态
   - 输入：问题域的状态集合 $\mathcal{S} = \{s_1, s_2, \ldots, s_n\}$
   - 输出：有限的状态空间

2. **构建转移概率矩阵**：确定状态间的转移概率
   - 关键操作：每行是一个概率分布，所有元素之和为1

3. **分析动态行为**：计算多步转移概率
   - 决策点：系统是周期的还是非周期的、是否可约

4. **求平稳分布**：确定系统的长期稳态行为
   - 意义：无论从哪个状态出发，长时间后系统的状态分布趋于固定

### 2.3 关键概念解释

- **状态转移矩阵（Transition Matrix）$P$**：一个 $n \times n$ 的矩阵，其中 $P_{ij}$ 表示从状态 $i$ 转移到状态 $j$ 的概率。矩阵每一行都是一个概率分布（非负且行和为1），这样的矩阵称为**随机矩阵（Stochastic Matrix）**。

- **平稳分布（Stationary Distribution）$\pi$**：一个概率向量 $\pi$，满足 $\pi P = \pi$。直观地说，如果系统当前的状态分布是 $\pi$，经过一步转移后分布仍然是 $\pi$。平稳分布描述了系统在长期运行后的"稳态"行为。

- **不可约性（Irreducibility）**：从任意状态出发，都有可能到达任意其他状态。即状态空间中不存在两个互不可达的子集。如果马尔可夫链不可约，则存在唯一的平稳分布。

- **非周期性（Aperiodicity）**：系统不存在固定的返回周期（如只在偶数步返回某个状态）。不可约且非周期的马尔可夫链称为**遍历的（Ergodic）**，一定收敛到平稳分布。

- **细致平衡条件（Detailed Balance）**：$\pi_i P_{ij} = \pi_j P_{ji}$。这是一个比 $\pi P = \pi$ 更强的条件，满足细致平衡的马尔可夫链称为**可逆的（Reversible）**，在MCMC采样中非常重要。

### 2.4 几何/直观解释

- 状态空间可以想象为一个图：节点是状态，边是转移（边上的权重是转移概率）。
- 转移概率矩阵 $P$ 的行向量表示"从某个节点出发，走向其他各节点的概率"。
- 平稳分布 $\pi$ 是这个图上的"流量平衡"状态：每个节点的流入概率等于流出概率。
- 矩阵 $P^k$ 的含义：从任意状态出发，走 $k$ 步后到达各状态的概率。当 $k \to \infty$，$P^k$ 的每一行都趋于 $\pi$。
- 在《人工智能注意力机制：体系、模型与算法剖析》一书的GBVS模型中，特征图被构造为马尔可夫链，通过寻找其平稳分布来确定显著性区域的位置概率。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 | 维度 |
|------|------|------|
| $X_t$ | 时间步 $t$ 的随机状态 | 标量 |
| $S$ | 状态空间 | 集合 $\{1, 2, \ldots, n\}$ |
| $P$ | 状态转移矩阵 | $n \times n$ |
| $P_{ij}$ | 从状态 $i$ 到 $j$ 的转移概率 | 标量 |
| $\pi$ | 平稳分布向量 | $n \times 1$ |
| $\mu^{(t)}$ | 时间步 $t$ 的状态分布 | $n \times 1$ |
| $n$ | 状态数量 | 标量 |
| $k$ | 转移步数 | 标量 |

### 3.2 问题形式化

给定一个有限状态空间 $\mathcal{S} = \{s_1, s_2, \ldots, s_n\}$ 和状态转移矩阵 $P \in \mathbb{R}^{n \times n}$，我们的目标是：

1. **描述系统的短期行为**：给定初始分布 $\mu^{(0)}$，求 $t$ 步后的状态分布 $\mu^{(t)}$
2. **分析系统的长期行为**：判断是否存在平稳分布 $\pi$，并求出它

### 3.3 目标函数/损失函数

马尔可夫链本身不是一个优化问题，而是一个概率模型。但其核心"目标"可以表述为：

$$ \text{寻找} \ \pi \ \text{使得} \ \pi P = \pi, \quad \sum_i \pi_i = 1, \quad \pi_i \geq 0 $$

这是一个线性方程组问题，可以转化为：

$$ \pi (P - I) = 0, \quad \pi \mathbf{1} = 1 $$

### 3.4 推导过程

**Step 1：Chapman-Kolmogorov方程（多步转移概率）**

$k$ 步转移概率矩阵定义为 $P^{(k)}$，其中 $P^{(k)}_{ij} = P(X_{t+k} = s_j | X_t = s_i)$。

对于两步转移，利用全概率公式和马尔可夫性质：

$$ P^{(2)}_{ij} = P(X_{t+2} = s_j | X_t = s_i) = \sum_{l=1}^{n} P(X_{t+2}=s_j|X_{t+1}=s_l) \cdot P(X_{t+1}=s_l|X_t=s_i) = \sum_{l=1}^{n} P_{lj} \cdot P_{il} $$

这就是矩阵乘法的定义！因此：

$$ P^{(2)} = P \cdot P = P^2 $$

推广到一般情况：

$$ P^{(k)} = P^k $$

这个结论非常优美：**多步转移概率矩阵等于一步转移概率矩阵的幂次**。

**Step 2：状态分布的演化**

设 $\mu^{(t)}$ 为时间步 $t$ 时系统处于各状态的概率向量，则：

$$ \mu^{(t+1)}_j = \sum_{i=1}^{n} \mu^{(t)}_i \cdot P_{ij} $$

用矩阵形式：

$$ \mu^{(t+1)} = \mu^{(t)} P $$

递推可得：

$$ \mu^{(t)} = \mu^{(0)} P^t $$

这个公式给出了系统的完整动态行为描述。

**Step 3：平稳分布的存在性与唯一性**

平稳分布的定义：$\pi P = \pi$

将 $P^k$ 的极限行为分为几种情况：

**定理**：对于有限状态的马尔可夫链，如果它是**不可约的且非周期的**，则：

1. 存在唯一的平稳分布 $\pi$
2. 对任意初始分布 $\mu^{(0)}$，有 $\lim_{t \to \infty} \mu^{(t)} = \pi$
3. 即 $\lim_{t \to \infty} P^t = \mathbf{1} \pi^T$（矩阵的每一行都趋于 $\pi^T$）

**证明思路（收敛性）**：

对于不可约非周期马尔可夫链，Perron-Frobenius定理保证：
- $P$ 有一个模为1的特征值1，其余特征值的模严格小于1
- 对应特征值1的左特征向量就是平稳分布 $\pi$

设 $P$ 的特征值为 $1, \lambda_2, \ldots, \lambda_n$，其中 $|\lambda_i| < 1$ 对所有 $i \geq 2$ 成立。将 $\mu^{(0)}$ 在特征向量上展开：

$$ \mu^{(0)} = \pi + \sum_{i=2}^{n} c_i v_i $$

其中 $v_i$ 是对应特征值 $\lambda_i$ 的左特征向量。则：

$$ \mu^{(t)} = \pi P^t + \sum_{i=2}^{n} c_i \lambda_i^t v_i \to \pi \quad (t \to \infty) $$

因为 $|\lambda_i| < 1$，$\lambda_i^t \to 0$。

**Step 4：平稳分布的求解方法**

**方法一：解线性方程组**

$$ \pi P = \pi \implies \pi (P - I) = 0 $$

这是一个齐次线性方程组，加上归一化条件 $\sum_i \pi_i = 1$，得到：

$$ \begin{bmatrix} (P - I)^T \\ \mathbf{1}^T \end{bmatrix} \pi = \begin{bmatrix} \mathbf{0} \\ 1 \end{bmatrix} $$

**方法二：幂迭代法**

从任意初始分布 $\mu^{(0)}$ 开始，反复迭代 $\mu^{(t+1)} = \mu^{(t)} P$，直到收敛。

**方法三：矩阵幂次法**

计算 $P^t$（$t$ 足够大），取任意一列作为 $\pi$ 的近似。

### 3.5 最终解/算法步骤

```
算法：求马尔可夫链的平稳分布

输入：状态转移矩阵 P (n x n)
输出：平稳分布 pi

方法一：幂迭代法
    初始化: pi = [1/n, 1/n, ..., 1/n]
    for t = 1, 2, ..., max_iter:
        pi_new = pi @ P
        if ||pi_new - pi|| < epsilon:
            return pi_new  # 收敛
        pi = pi_new
    return pi  # 达到最大迭代次数

方法二：解线性方程组
    构造 (P^T - I) @ pi = 0，加上归一化条件
    用 np.linalg.solve 或最小二乘法求解

方法三：特征值法
    求 P^T 的特征值和特征向量
    特征值1对应的左特征向量（归一化后）即为平稳分布
```

## 4. 训练过程讲解

### 4.1 数据预处理

马尔可夫链通常不是从数据中"训练"得到的（尽管可以从序列数据中估计转移概率）。预处理主要涉及：

1. **从序列数据估计转移矩阵**：
   ```python
   # 统计转移频次
   for t in range(len(sequence) - 1):
       i, j = sequence[t], sequence[t+1]
       count_matrix[i][j] += 1

   # 归一化为概率（行归一化）
   P = count_matrix / count_matrix.sum(axis=1, keepdims=True)
   ```

2. **处理零概率**：
   - 加一平滑（Laplace Smoothing）：$P_{ij} = (c_{ij} + 1) / (\sum_k c_{ik} + n)$

### 4.2 参数初始化

- 从数据估计：直接统计频率
- 均匀初始化：$P_{ij} = 1/n$（所有转移等概率）
- 先验设定：根据领域知识设定转移概率

### 4.3 迭代过程

求解平稳分布的迭代过程：

```
初始化 pi = 均匀分布
for t = 1, ..., max_iter:
    pi_new = pi @ P
    计算变化量 delta = ||pi_new - pi||
    pi = pi_new
    if delta < tolerance:
        收敛，停止
```

### 4.4 收敛条件

- 分布变化量 $\|\pi^{(t+1)} - \pi^{(t)}\| < \epsilon$（通常 $\epsilon = 10^{-10}$）
- 达到最大迭代次数（如10000次）
- 注意：只有不可约非周期的马尔可夫链才保证收敛

### 4.5 超参数及推荐范围

| 参数 | 作用 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| max_iter | 最大迭代次数 | 1000-100000 | 10000 |
| tolerance | 收敛阈值 | 1e-8 - 1e-12 | 1e-10 |
| smoothing | 平滑系数（数据估计时） | 0-1 | 0（或小值如1e-6） |

## 5. 应用场景

### 5.1 典型应用（3-5个）

**应用1：自然语言处理（N-gram语言模型）**
- 问题类型：序列建模
- 为什么适合：文本中下一个词的出现概率可以用马尔可夫链近似
- 实际案例：Bigram/Trigram模型中，转移矩阵的行对应当前词，列对应下一个词

**应用2：PageRank网页排名**
- 问题类型：图上的排序
- 为什么适合：网页浏览过程是一个马尔可夫链，用户随机点击链接跳转
- 实际案例：Google的PageRank算法本质上就是求网页图上的平稳分布

**应用3：视觉显著性检测（GBVS模型）**
- 问题类型：计算机视觉中的注意力建模
- 为什么适合：特征图可以被构造为马尔可夫链，平稳分布表示各位置的显著性概率
- 实际案例：在《人工智能注意力机制》一书中，GBVS模型将特征图的节点关系归一化为状态转移概率，通过寻找平稳分布确定显著性区域

**应用4：天气预测**
- 问题类型：时间序列预测
- 为什么适合：天气状态（晴/阴/雨）的转移近似满足马尔可夫性质
- 实际案例：用转移矩阵 $P$ 预测明天的天气概率：$P(\text{明天}=雨) = P_{\text{今天}, \text{雨}}$

**应用5：金融分析**
- 问题类型：市场状态建模
- 为什么适合：市场状态（牛市/熊市/震荡）的转移可以用马尔可夫链建模

### 5.2 适用数据特征

- 数据类型：离散状态序列
- 数据规模：状态数量不宜过大（否则矩阵维度爆炸）
- 序列长度：需要足够长以准确估计转移概率
- 马尔可夫性：数据的"记忆长度"应较短（近似满足马尔可夫性质）

### 5.3 不适用场景

1. 状态空间连续（需要用HMM或马尔可夫跳过程等扩展）
2. 系统具有长期依赖（需要高阶马尔可夫链或RNN/LSTM等）
3. 转移概率随时间变化（非平稳马尔可夫链需要特殊处理）

## 6. 优缺点分析

### 6.1 优点（3-5个）

1. **数学结构优美，理论完善**
   - 存在丰富的收敛性理论
   - 平稳分布的存在性和唯一性有清晰的数学保证

2. **计算简单高效**
   - 状态转移矩阵是稀疏的，计算和存储效率高
   - 幂迭代法非常简单且收敛速度快

3. **可解释性强**
   - 转移概率有明确的概率意义
   - 平稳分布直接对应系统的长期行为

### 6.2 缺点（3-5个）

1. **马尔可夫假设的限制**
   - 现实中很多系统具有长期记忆，不完全满足"只依赖当前状态"
   - 需要用高阶马尔可夫链或隐马尔可夫模型来扩展

2. **状态空间爆炸**
   - 当状态数量 $n$ 很大时，转移矩阵为 $n \times n$，存储和计算代价高
   - 多个变量的联合状态空间呈指数增长

3. **无法处理连续状态**
   - 标准马尔可夫链只能处理离散状态
   - 需要扩展为连续时间的马尔可夫过程

### 6.3 与同类算法对比

| 维度 | 马尔可夫链 | 隐马尔可夫模型(HMM) | MCMC | RNN |
|------|-----------|---------------------|------|-----|
| 状态可观测性 | 完全可观测 | 部分可观测 | N/A | 隐状态 |
| 参数学习 | 统计频率 | EM算法 | 构造转移核 | 反向传播 |
| 长期依赖 | 无 | 无 | 通过设计可处理 | 有 |
| 连续状态 | 不支持 | 不支持（标准版） | 支持 | 支持 |
| 理论基础 | 完善 | 完善 | 完善 | 较弱 |

### 7.2 完整代码示例

```python
"""
马尔可夫链 NumPy实现
数据集：天气状态转移模型（晴天/阴天/雨天）
目标：计算状态转移矩阵、平稳分布、多步转移概率
"""

import numpy as np
import matplotlib.pyplot as plt
from scipy import linalg

np.random.seed(42)


# ===============================
# 1. 马尔可夫链类
# ===============================
class MarkovChain:
    """
    离散时间有限状态马尔可夫链

    属性:
        states: 状态列表
        P: 状态转移矩阵 (n x n)
        n: 状态数量
    """

    def __init__(self, states, transition_matrix):
        """
        初始化马尔可夫链

        Args:
            states: 状态名称列表, 如 ['Sunny', 'Cloudy', 'Rainy']
            transition_matrix: 转移概率矩阵, 每行和为1
        """
        self.states = states
        self.n = len(states)
        self.P = np.array(transition_matrix, dtype=np.float64)
        self._validate()

    def _validate(self):
        """验证转移矩阵的合法性"""
        assert self.P.shape == (self.n, self.n), "转移矩阵维度不正确"
        assert np.allclose(self.P.sum(axis=1), 1.0), "每行概率之和必须为1"
        assert np.all(self.P >= 0), "转移概率必须非负"

    # ===============================
    # 2. 计算多步转移概率
    # ===============================
    def transition_prob(self, k, from_state=None, to_state=None):
        """
        计算k步转移概率

        原理：k步转移矩阵 P^(k) = P^k
        P^k[i,j] = P(X_{t+k}=s_j | X_t=s_i)

        Args:
            k: 步数
            from_state: 起始状态名（可选）
            to_state: 目标状态名（可选）

        Returns:
            如果指定了起止状态，返回标量概率
            否则返回完整的k步转移矩阵
        """
        P_k = np.linalg.matrix_power(self.P, k)

        if from_state is not None and to_state is not None:
            i = self.states.index(from_state)
            j = self.states.index(to_state)
            return P_k[i, j]
        return P_k

    # ===============================
    # 3. 求平稳分布
    # ===============================
    def stationary_distribution_power(self, max_iter=10000, tol=1e-12):
        """
        方法一：幂迭代法求平稳分布

        原理：从任意初始分布出发，反复乘以P，分布收敛到平稳分布
        pi^{(t+1)} = pi^{(t)} @ P

        收敛条件：||pi^{(t+1)} - pi^{(t)}|| < tol

        Returns:
            pi: 平稳分布向量
            convergence_history: 收敛历史
        """
        pi = np.ones(self.n) / self.n  # 均匀初始化
        history = [pi.copy()]

        for t in range(max_iter):
            pi_new = pi @ self.P
            delta = np.linalg.norm(pi_new - pi)
            history.append(pi_new.copy())

            if delta < tol:
                return pi_new, history, t + 1

            pi = pi_new

        return pi, history, max_iter

    def stationary_distribution_eigen(self):
        """
        方法二：特征值法求平稳分布

        原理：平稳分布是 P^T 的特征值1对应的左特征向量
        即 P^T @ pi = pi

        使用 scipy.linalg.eig 求解

        Returns:
            pi: 平稳分布向量
        """
        # 求P^T的特征值和特征向量
        eigenvalues, eigenvectors = linalg.eig(self.P.T)

        # 找到特征值最接近1的特征向量
        idx = np.argmin(np.abs(eigenvalues - 1.0))
        pi = np.real(eigenvectors[:, idx])

        # 归一化为概率分布
        pi = pi / pi.sum()
        return pi

    def stationary_distribution_linear(self):
        """
        方法三：解线性方程组

        原理：pi @ P = pi 等价于 (P^T - I) @ pi = 0
        加上归一化条件 sum(pi) = 1

        构造增广矩阵后用最小二乘法求解

        Returns:
            pi: 平稳分布向量
        """
        n = self.n
        # 构造 (P^T - I)
        A = (self.P.T - np.eye(n))
        # 将最后一个方程替换为归一化条件
        A[-1, :] = 1.0
        b = np.zeros(n)
        b[-1] = 1.0

        # 最小二乘求解
        pi, residuals, rank, sv = linalg.lstsq(A, b)
        return pi

    # ===============================
    # 4. 模拟马尔可夫链
    # ===============================
    def simulate(self, initial_state, n_steps):
        """
        模拟马尔可夫链的运行

        Args:
            initial_state: 初始状态名
            n_steps: 模拟步数

        Returns:
            states: 状态序列
            state_indices: 状态索引序列
        """
        current = self.states.index(initial_state)
        states = [current]

        for _ in range(n_steps):
            # 根据转移概率随机选择下一个状态
            probs = self.P[current]
            next_state = np.random.choice(self.n, p=probs)
            states.append(next_state)
            current = next_state

        state_names = [self.states[s] for s in states]
        return state_names, states

    # ===============================
    # 5. 从数据估计转移矩阵
    # ===============================
    @classmethod
    def from_sequence(cls, states, sequence, smoothing=0):
        """
        从观测序列中估计马尔可夫链的转移矩阵

        Args:
            states: 所有可能的状态列表
            sequence: 观测到的状态序列（整数索引列表）
            smoothing: Laplace平滑系数

        Returns:
            MarkovChain实例
        """
        n = len(states)
        count = np.zeros((n, n), dtype=np.float64)

        # 统计转移频次
        for t in range(len(sequence) - 1):
            i, j = sequence[t], sequence[t + 1]
            count[i][j] += 1

        # 加Laplace平滑
        if smoothing > 0:
            count += smoothing

        # 行归一化得到转移概率矩阵
        P = count / count.sum(axis=1, keepdims=True)

        return cls(states, P)

    # ===============================
    # 6. 分析性质
    # ===============================
    def is_irreducible(self):
        """检查不可约性：从任意状态能否到达任意其他状态"""
        n = self.n
        # 计算可达性矩阵：P + P^2 + ... + P^n
        reachable = np.zeros((n, n), dtype=bool)
        P_power = np.eye(n)
        for _ in range(n):
            P_power = P_power @ self.P
            reachable |= (P_power > 0)

        return reachable.all()

    def is_aperiodic(self):
        """检查非周期性"""
        n = self.n
        # 计算各状态的可能返回步数集合的GCD
        P_power = np.eye(n)
        for k in range(1, n * n + 1):
            P_power = P_power @ self.P
            diag_nonzero = np.diag(P_power) > 0

            if diag_nonzero.all():
                # 如果所有状态都能在k步返回自己，则GCD为1（非周期）
                # 简化检查：如果能找到两个相邻步数使得对角线都非零
                return True
        return False
```

```python
"""
马尔可夫链核心算法手工实现
仅依赖NumPy，展示三种求平稳分布的方法
"""

import numpy as np


def stationary_distribution_power_iteration(P, max_iter=10000, tol=1e-12):
    """
    方法一：幂迭代法求平稳分布

    这是最直观的方法，对应马尔可夫链的物理含义：
    系统经过足够多的转移后，状态分布趋于稳定。

    数学原理：
    pi^{(t+1)} = pi^{(t)} P
    当 t -> inf 时，pi^{(t)} -> pi*

    Args:
        P: 转移概率矩阵 (n x n)
        max_iter: 最大迭代次数
        tol: 收敛阈值

    Returns:
        pi: 平稳分布
        converged: 是否收敛
        n_iters: 实际迭代次数
    """
    n = P.shape[0]
    pi = np.ones(n) / n  # 从均匀分布开始

    for t in range(max_iter):
        pi_new = pi @ P
        # 使用L1范数（概率分布的"总距离"）
        delta = np.sum(np.abs(pi_new - pi))

        if delta < tol:
            return pi_new, True, t + 1

        pi = pi_new

    return pi, False, max_iter


def stationary_distribution_eigenvalue(P):
    """
    方法二：特征值法求平稳分布

    数学原理：
    平稳分布满足 pi P = pi，即 P^T pi = pi
    因此 pi 是 P^T 的特征值1对应的特征向量。

    使用NumPy的特征值分解求解。

    Args:
        P: 转移概率矩阵 (n x n)

    Returns:
        pi: 平稳分布
    """
    eigenvalues, eigenvectors = np.linalg.eig(P.T)

    # 找到最接近1的特征值对应的特征向量
    idx = np.argmin(np.abs(eigenvalues - 1.0))
    pi = np.real(eigenvectors[:, idx])

    # 确保非负（特征向量可能有任意符号）
    pi = np.abs(pi)

    # 归一化
    pi = pi / pi.sum()
    return pi


def stationary_distribution_linear_system(P):
    """
    方法三：解线性方程组

    数学原理：
    pi P = pi  <=>  (P^T - I) pi = 0
    这是一个齐次方程组，有无穷多解。
    加上归一化条件 sum(pi) = 1 后有唯一解。

    构造增广矩阵并求解。

    Args:
        P: 转移概率矩阵 (n x n)

    Returns:
        pi: 平稳分布
    """
    n = P.shape[0]

    # 构造系数矩阵 A 和右侧向量 b
    # 前 n-1 行: (P^T - I) 的前 n-1 行
    A = (P.T - np.eye(n))[:n-1, :]
    b = np.zeros(n - 1)

    # 最后一行: 归一化条件
    A = np.vstack([A, np.ones(n)])
    b = np.append(b, 1.0)

    # 最小二乘求解
    pi, _, _, _ = np.linalg.lstsq(A, b, rcond=None)

    # 确保非负
    pi = np.maximum(pi, 0)
    pi = pi / pi.sum()
    return pi


def verify_stationary_distribution(P, pi, name=""):
    """
    验证平稳分布的正确性

    检查:
    1. pi P = pi (近似)
    2. pi 各分量非负
    3. sum(pi) = 1

    Args:
        P: 转移矩阵
        pi: 候选平稳分布
        name: 方法名称
    """
    print(f"\n{name} 验证:")
    print(f"  pi P  = {np.round(pi @ P, 8)}")
    print(f"  pi    = {np.round(pi, 8)}")
    print(f"  误差  = {np.linalg.norm(pi @ P - pi):.2e}")
    print(f"  非负  = {np.all(pi >= 0)}")
    print(f"  归一  = {abs(pi.sum() - 1.0):.2e}")


def simulate_markov_chain(P, initial_state, n_steps, rng=None):
    """
    手工模拟马尔可夫链

    Args:
        P: 转移矩阵
        initial_state: 初始状态索引
        n_steps: 模拟步数
        rng: 随机数生成器

    Returns:
        trajectory: 状态序列
    """
    if rng is None:
        rng = np.random.default_rng(42)

    trajectory = [initial_state]
    current = initial_state

    for _ in range(n_steps):
        # 根据当前状态的转移概率分布采样下一个状态
        probs = P[current]
        # 使用累积分布函数方法采样
        cumsum = np.cumsum(probs)
        r = rng.random()
        next_state = np.searchsorted(cumsum, r)
        trajectory.append(next_state)
        current = next_state

    return trajectory


def estimate_stationary_from_simulation(P, initial_state, n_steps=100000, burn_in=1000):
    """
    从模拟数据中经验性地估计平稳分布

    原理：对于遍历马尔可夫链，时间平均 = 空间平均
    即各状态出现的频率收敛到平稳分布

    Args:
        P: 转移矩阵
        initial_state: 初始状态
        n_steps: 总模拟步数
        burn_in: 丢弃前burn_in步（消除初始状态的影响）

    Returns:
        empirical_pi: 经验平稳分布
    """
    trajectory = simulate_markov_chain(P, initial_state, n_steps)
    n = P.shape[0]

    # 丢弃burn-in
    trajectory = trajectory[burn_in:]
    counts = np.bincount(trajectory, minlength=n)
    empirical_pi = counts / counts.sum()
    return empirical_pi
```

### 10.2 谱分析

```python
def spectral_analysis(P):
    """
    马尔可夫链的谱分析

    转移矩阵的特征值决定了很多重要性质：
    - lambda_1 = 1: 恒为最大特征值
    - |lambda_2|: 决定收敛速率（越小越快）
    - 谱间隙 = 1 - |lambda_2|: 越大收敛越快
    """
    eigenvalues = np.linalg.eigvals(P)
    eigenvalues_sorted = np.sort(np.abs(eigenvalues))[::-1]

    print("转移矩阵特征值:")
    for i, ev in enumerate(eigenvalues_sorted):
        print(f"  |lambda_{i+1}| = {ev:.6f}")

    spectral_gap = 1 - eigenvalues_sorted[1]
    mixing_time = 1.0 / spectral_gap  # 近似混合时间

    print(f"\n谱间隙: {spectral_gap:.6f}")
    print(f"近似混合时间: {mixing_time:.2f} 步")
```

## 11. 常见问题与易错点

### 11.1 数据层面常见错误

**错误1：转移矩阵行和不为1**

**现象**：
- 计算结果不合理（概率可能出现负数或大于1）
- 平稳分布不存在

**原因**：
- 数据中某些状态从未出现，导致行全为零
- 统计频率未正确归一化

**解决方案**：
```python
# 加Laplace平滑避免零行
count += smoothing
P = count / count.sum(axis=1, keepdims=True)
```

**错误2：从有限序列估计转移矩阵不够准确**

**现象**：
- 估计的平稳分布与理论值偏差大
- 不同序列估计的结果不一致

**解决方案**：使用足够长的序列，或使用贝叶斯估计（Dirichlet先验）

### 11.2 模型层面常见错误

**错误1：忽略不可约性/周期性检查**

**现象**：
- 幂迭代不收敛（周期链在各状态间循环）
- 平稳分布不唯一（可约链有多个吸收分量）

**解决方案**：
```python
# 检查不可约性和非周期性
if not mc.is_irreducible():
    print("警告：马尔可夫链不是不可约的，可能存在多个平稳分布")
if not mc.is_aperiodic():
    print("警告：马尔可夫链是周期性的，幂迭代可能不收敛")
```

**错误2：混淆行向量和列向量**

**现象**：
- 平稳分布计算错误
- 方程写成 $P\pi = \pi$ 而不是 $\pi P = \pi$

**解决方案**：
- 记住：$\pi$ 是行向量，$\pi P = \pi$（左乘）
- 如果要解 $P^T \pi^T = \pi^T$，$\pi^T$ 是列向量

### 11.3 调参层面常见误区

**误区1：认为所有马尔可夫链都有平稳分布**

- 可约链可能有多个平稳分布（每个不可约子集一个）
- 周期链可能没有收敛的平稳分布（但仍有平稳分布，只是不收敛到它）

**误区2：混淆平稳分布和吸收概率**

- 平稳分布描述长期频率，不是被吸收的概率
- 对于吸收型马尔可夫链，平稳分布中吸收态概率为1，其他为0

### 12.1 核心要点回顾

- **核心思想**：系统未来只取决于现在，转移规律用概率矩阵描述
- **数学本质**：随机矩阵的幂次和特征值分析
- **优化目标**：求解 $\pi P = \pi$（线性方程组问题）
- **适用场景**：具有短期记忆的离散状态序列建模

### 12.2 关键公式汇总

**1. 马尔可夫性质**：
$$ P(X_{t+1} | X_t, \ldots, X_0) = P(X_{t+1} | X_t) $$

**2. 多步转移**：
$$ P^{(k)} = P^k $$

**3. 分布演化**：
$$ \mu^{(t)} = \mu^{(0)} P^t $$

**4. 平稳方程**：
$$ \pi P = \pi, \quad \sum_i \pi_i = 1 $$

- 验证转移矩阵的合法性（非负、行和为1）

**练习2：手工计算**

问题：给定3状态马尔可夫链，转移矩阵为：

$$ P = \begin{bmatrix} 0.5 & 0.3 & 0.2 \\ 0.2 & 0.6 & 0.2 \\ 0.1 & 0.4 & 0.5 \end{bmatrix} $$

请手工计算平稳分布 $\pi = [\pi_1, \pi_2, \pi_3]$。

**答案与解析：**

解：

建立方程组 $\pi P = \pi$：

$$ \pi_1 \cdot 0.5 + \pi_2 \cdot 0.2 + \pi_3 \cdot 0.1 = \pi_1 $$
$$ \pi_1 \cdot 0.3 + \pi_2 \cdot 0.6 + \pi_3 \cdot 0.4 = \pi_2 $$
$$ \pi_1 \cdot 0.2 + \pi_2 \cdot 0.2 + \pi_3 \cdot 0.5 = \pi_3 $$

整理（将等号右边的项移到左边）：

$$ -0.5\pi_1 + 0.2\pi_2 + 0.1\pi_3 = 0 \quad \ldots (1) $$
$$ 0.3\pi_1 - 0.4\pi_2 + 0.4\pi_3 = 0 \quad \ldots (2) $$
$$ 0.2\pi_1 + 0.2\pi_2 - 0.5\pi_3 = 0 \quad \ldots (3) $$
$$ \pi_1 + \pi_2 + \pi_3 = 1 \quad \ldots (4) $$

由(1)得：$0.5\pi_1 = 0.2\pi_2 + 0.1\pi_3$，即 $\pi_1 = 0.4\pi_2 + 0.2\pi_3$

由(3)得：$0.2\pi_1 + 0.2\pi_2 = 0.5\pi_3$

代入 $\pi_1$：$0.2(0.4\pi_2 + 0.2\pi_3) + 0.2\pi_2 = 0.5\pi_3$
$$ 0.08\pi_2 + 0.04\pi_3 + 0.2\pi_2 = 0.5\pi_3 $$
$$ 0.28\pi_2 = 0.46\pi_3 $$
$$ \pi_3 = \frac{28}{46}\pi_2 = \frac{14}{23}\pi_2 $$

代入 $\pi_1 = 0.4\pi_2 + 0.2 \cdot \frac{14}{23}\pi_2 = (\frac{9.2 + 2.8}{23})\pi_2 = \frac{12}{23}\pi_2$

由(4)：$\frac{12}{23}\pi_2 + \pi_2 + \frac{14}{23}\pi_2 = 1$
$$ \frac{49}{23}\pi_2 = 1 $$
$$ \pi_2 = \frac{23}{49} \approx 0.4694 $$
$$ \pi_1 = \frac{12}{23} \cdot \frac{23}{49} = \frac{12}{49} \approx 0.2449 $$
$$ \pi_3 = \frac{14}{23} \cdot \frac{23}{49} = \frac{14}{49} \approx 0.2857 $$

因此 $\pi \approx [0.245, 0.469, 0.286]$。

验证：$\pi_1 + \pi_2 + \pi_3 = 12/49 + 23/49 + 14/49 = 49/49 = 1$。

### 13.2 进阶思考（2题）

**思考1：周期性马尔可夫链**

问题：考虑转移矩阵 $P = \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}$。这个马尔可夫链是周期的吗？它有平稳分布吗？幂迭代法会收敛吗？

**答案与解析：**

**周期性分析**：
从状态1出发：$1 \to 2 \to 1 \to 2 \to \cdots$，只能在偶数步回到状态1。因此周期为2，是周期链。

**平稳分布**：
$\pi P = \pi \implies [\pi_1, \pi_2] \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix} = [\pi_2, \pi_1] = [\pi_1, \pi_2]$

因此 $\pi_1 = \pi_2$，加上 $\pi_1 + \pi_2 = 1$，得 $\pi = [0.5, 0.5]$。

**幂迭代**：
- $P^0 = I$
- $P^1 = \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}$
- $P^2 = I$
- $P^3 = P$
- ...

幂迭代 $\mu^{(t+1)} = \mu^{(t)} P$ 会在 $[0,1]$ 和 $[1,0]$ 之间振荡，永不收敛。但如果我们取平均 $\bar{\mu} = \frac{1}{2}(\mu^{(t)} + \mu^{(t+1)})$，它就收敛到 $[0.5, 0.5]$。

**结论**：周期链有平稳分布，但幂迭代不收敛。需要使用Cesaro平均或直接解方程。

**思考2：GBVS模型中的马尔可夫链**

问题：在《人工智能注意力机制》一书的GBVS模型中，特征图被构造为马尔可夫链来计算显著性。请分析这种做法的理论依据。

**答案与解析：**

**理论依据**：

1. **节点关系归一化**：GBVS模型中，特征图的节点间有关系权重 $w((i,j)|(p,q))$。将每个节点的所有出边权重归一化为概率（和为1），就得到了状态转移概率。

2. **平稳分布的物理意义**：马尔可夫链的平稳分布描述了"随机游走长时间后的位置分布"。在GBVS模型中，这对应于"如果一个人在图像上随机跳转，最终最可能停留在哪些位置"。这些位置就是最显著的位置。

3. **与视觉注意力的联系**：平稳分布体现了一种在随机状态转移下达到的稳定状态，这与视觉系统在场景中随机搜索并最终稳定关注某些区域的过程非常相似（原文描述）。

4. **计算方法**：GBVS使用两种方法计算平稳分布：
   - 迭代法（幂迭代）
   - 直接法（特征值分解）

这种将特征图转化为马尔可夫链的思路，本质上是将空间关系（节点间的相似度/距离）转化为概率转移关系，通过马尔可夫链的理论工具来分析空间显著性。

### 13.3 开放思考（1题）

**思考3：马尔可夫链在NLP中的应用设计**

问题：设计一个基于马尔可夫链的简单文本生成器。给定一篇中文文章，如何用它训练一个Bigram马尔可夫链来生成新文本？这种方法的局限性是什么？

**答案与解析：**

**设计方案**：

1. **状态定义**：每个汉字（或词）是一个状态
2. **转移矩阵估计**：统计文本中相邻字/词的共现频率，归一化为转移概率
3. **文本生成**：从某个起始字开始，根据转移概率逐步采样下一个字

**代码框架**：
```python
# 1. 从文本估计转移矩阵
chars = list(set(text))
char_to_idx = {c: i for i, c in enumerate(chars)}
n = len(chars)
count = np.zeros((n, n))

for t in range(len(text) - 1):
    i = char_to_idx[text[t]]
    j = char_to_idx[text[t+1]]
    count[i][j] += 1

P = (count + 1) / (count + 1).sum(axis=1, keepdims=True)

# 2. 生成文本
current = start_char
result = [current]
for _ in range(100):
    probs = P[char_to_idx[current]]
    next_char = chars[np.random.choice(n, p=probs)]
    result.append(next_char)
    current = next_char
```

**局限性**：
1. **只有局部上下文**：Bigram模型只看前一个字，无法捕捉长程依赖（如"虽然...但是..."的搭配需要跨多个字）
2. **马尔可夫假设过强**：自然语言具有丰富的长程结构，远非"只依赖前一个词"
3. **状态空间爆炸**：如果以词为单位，词典大小可达数万甚至数十万，转移矩阵无法存储
4. **无法生成全新内容**：只能重新组合训练文本中已有的n-gram

**改进方向**：
- 使用Trigram或更高阶的马尔可夫链（但参数量指数增长）
- 使用隐马尔可夫模型（HMM）引入隐状态
- 使用RNN/LSTM/Transformer替代（本质上是无参数/参数化的"高阶马尔可夫链"）

### B. 常见问题FAQ

**Q1：马尔可夫链和马尔可夫决策过程（MDP）有什么区别？**

A：马尔可夫链的状态转移是完全被动的（由转移概率决定），而MDP中有一个"智能体"主动选择动作，不同的动作导致不同的转移概率。MDP可以看作是"带动作的马尔可夫链"。RL中的策略梯度、Q-learning等都是基于MDP框架的。

**Q2：平稳分布一定存在吗？**

A：对于有限状态空间的马尔可夫链，平稳分布一定存在（由Brouwer不动点定理保证）。但唯一性需要不可约性条件，收敛到平稳分布需要非周期性条件。

**Q3：连续时间有没有马尔可夫链？**

A：有，称为连续时间马尔可夫链（CTMC）。在CTMC中，状态转移可以在任意时刻发生，用转移速率矩阵（Q矩阵）代替转移概率矩阵。CTMC在排队论、生物学等领域有重要应用。
