# 卷积神经网络（Convolutional Neural Network）学习文档

## 1. 算法基础认知

### 1.1 什么是卷积神经网络

卷积神经网络（Convolutional Neural Network，CNN）是一种专门用于处理具有网格结构数据（如图像）的深度神经网络。CNN通过卷积操作实现局部连接和参数共享，大大减少了网络的参数量，使得训练更深更大的网络成为可能。

卷积神经网络的学名是"Convolutional Neural Network"，简称CNN。与全连接的前馈神经网络不同，CNN利用了数据的局部相关性——图像中相邻像素之间的关联性往往比远距离像素更强。这种局部性是CNN成功的关键之一。

CNN的发展历程展示了深度学习在计算机视觉领域的演进。1998年，LeCun等人提出了LeNet-5用于手写数字识别，这是第一个成功的CNN架构。2012年，AlexNet在ImageNet竞赛中取得突破性成绩，准确率远超传统方法，引发了深度学习的革命。此后，VGGNet、GoogLeNet、ResNet等更深的网络相继出现，推动了计算机视觉的发展。

卷积神经网络的核心优势在于：局部感受野允许网络学习局部特征（如边缘、纹理），这些局部特征可以组合成更高级的语义特征（如眼睛、鼻子）；参数共享大大减少了参数量，降低了过拟合风险；卷积操作的平移不变性使得网络对输入的平移具有鲁棒性。

### 1.2 卷积操作的核心概念

卷积操作是CNN的核心。与全连接层的矩阵乘法不同，卷积使用一个小的卷积核（kernel）在输入上滑动，在每个位置进行局部点乘然后求和。这个卷积核也称为过滤器（filter）或感受野（receptive field）。

卷积操作有三个重要参数：**卷积核大小（Kernel Size）**是卷积核的尺寸，常用的是3×3、5×5等。**步长（Stride）**是卷积核每次移动的步数，步长1表示每次移动1个像素，步长2表示每次移动2个像素。**填充（Padding）**是在输入边界周围添加的零填充，用于控制输出尺寸。

通过调整这些参数，可以控制输出特征图的尺寸。输入尺寸$W$、卷积核大小$K$、步长$S$、填充$P$下的输出尺寸为：$O = \lfloor \frac{W - K + 2P}{S} \rfloor + 1$。

### 1.3 CNN的网络结构

一个典型的CNN由三类层组成：**卷积层（Convolutional Layer）**是CNN的核心，负责提取特征。每个卷积层包含多个卷积核，每个卷积核学习提取一种特征。**池化层（Pooling Layer）**用于降低特征图的分辨率，减少计算量和参数。常用的有最大池化和平均池化。**全连接层（Fully Connected Layer）**在网络末端，将特征映射到样本标记空间。

CNN的层级组织遵循"从局部到整体"的原则。早期卷积层提取低级特征（边缘、角点、纹理），中期卷积层组合低级特征形成中级特征（部件、形状），后期卷积层和全连接层形成高级特征（完整目标、语义概念）。

## 2. 核心原理

### 2.1 局部连接

局部连接（Local Connectivity）是CNN区别于全连接网络的关键特性。在全连接网络中，每个神经元与上一层的所有神经元相连；在CNN中，每个神经元只与上一层的局部区域相连。

局部连接的理论依据来源于视觉系统的生物学研究。在人脑的视觉皮层中，视觉神经元只对视野中的局部区域敏感，这个区域称为“感受野”。CNN正是模仿了这一特性。

局部连接大大减少了参数量。假设输入是$32\times32\times3$的图像，全连接层有4096个神经元，那么参数量是$32\times32\times3\times4096 \approx 1200万$。如果使用$3\times3$的卷积核，64个卷积��，参数量只有$3\times3\times3\times64 \approx 1700$，相差数千倍。

### 2.2 参数共享

参数共享（Parameter Sharing）是CNN的另一个关键特性。在全连接网络中，每个位置的权重是不同的；在CNN中，同一个卷积核在整个输入上共享同一组权重。

参数共享的理论依据是图像特征的平移不变性。边缘纹理等特征可能出现在图像的任何位置，因此使用同一组卷积核就能检测这些特征。

参数共享进一步减少了参数量，也是CNN能够训练深层网络的关键因素之一。多个位置使用同一组参数，使得网络能够从有限的数据中学习到有效的特征表示。

### 2.3 池化操作

池化（Pooling）是对特征图进行下采样的操作。最大池化（Max Pooling）取局部区域的最大值，保留最显著的特征。平均池化（Average Pooling）取局部区域的平均值，提供平滑的特征。

池化的作用：降低特征图分辨率，减少后续层的计算量；提供一定程度的平移不变性，因为池化对位置的微小变化不敏感；减少过拟合，因为特征的精确位置变得不那么重要。

现代CNN中，池化层的使用有减少的趋势，更多使用步长卷积（strided convolution）来降低分辨率。

## 3. 数学公式与推导

### 3.1 卷积操作

考虑二维卷积（对单通道图像）。设输入为$I \in \mathbb{R}^{H \times W}$，卷积核为$K \in \mathbb{R}^{k_h \times k_w}$，输出为$O \in \mathbb{R}^{H' \times W'}$。

卷积操作可以表示为：$O(i,j) = \sum_{m=0}^{k_h-1} \sum_{n=0}^{k_w-1} I(i+m, j+n) \cdot K(m,n)$

对于多通道输入和多个卷积核：设输入有$C$个通道，输出有$F$个特征图（通道）。输入张量$I \in \mathbb{R}^{C \times H \times W}$，卷积核张量$K \in \mathbb{R}^{F \times C \times k_h \times k_w}$，输出张量$O \in \mathbb{R}^{F \times H' \times W'}$。

$O(f,i,j) = \sum_{c=0}^{C-1} \sum_{m=0}^{k_h-1} \sum_{n=0}^{k_w-1} I(c,i+m,j+n) \cdot K(f,c,m,n)$

### 3.2 卷积层的参数量

对于卷积层，输入通道数$C$，输出通道数$F$，卷积核大小$k \times k$。

参数量（权重，不含偏置）：$C \times F \times k \times k$

偏置数量：$F$

例如，输入3通道（RGB），输出64通道，$3\times3$卷积核：参数量 = $3\times64\times3\times3 + 64 = 17248$

卷积层的计算量（FLOPs，每秒浮点运算次数）：设输出特征图尺寸为$H' \times W'$，则FLOPs = $H' \times W' \times C \times F \times k \times k$

### 3.3 特征图尺寸计算公式

设输入尺寸为$H \times W$，卷积核大小为$k$，填充为$p$，步长为$s$，输出尺寸为：

$H' = \lfloor \frac{H - k + 2p}{s} \rfloor + 1$，$W' = \lfloor \frac{W - k + 2p}{s} \rfloor + 1$

当输入输出尺寸相同时（常见于保持特征图尺寸的卷积层），填充满足：$p = \lfloor k/2 \rfloor$

### 3.4 反向传播

卷积层的反向传播需要计算损失对卷积核和输入的梯度。

设前向传播：$z = I * K$（卷积），$a = f(z)$。

输出层误差项：$\delta^L = \frac{\partial L}{\partial z^L} = \frac{\partial L}{\partial a^L} \odot f'(z^L)$

对卷积核的梯度：$\frac{\partial L}{\partial K} = \text{rot180}(\delta^L) * \text{rot180}(I)$，实际上可以通过交叉相关计算。

对输入的梯度：$\frac{\partial L}{\partial I} = \delta^L * \text{rot180}(K)$

使用PyTorch时，框架会自动处理这些梯度计算，用户无需手动实现。

## 4. 训练过程讲解

### 4.1 数据准备

训练CNN需要准备图像数据。常用流程：加载图像数据集（训练集、验证集、测试集），将像素值归一化到[0,1]，计算���值和标准差进行标准化，数据增强（随机裁剪、翻转、颜色抖动等）增加数据多样性。

对于PyTorch，使用torchvision.datasets和torch.utils.data.DataLoader进行数据加载和批量迭代。

### 4.2 网络初始化

CNN的权重初始化很重要。常用方法包括：Xavier初始化，适用于ReLU/Tanh激活函数。He初始化，专门适用于ReLU激活函数。预训练模型微调，使用在大规模数据集上预训练的模型。

### 4.3 超参数选择

CNN训练涉及多个超参数：学习率（通常从0.001开始），批量大小（32、64或128），卷积层层数和每层通道数，全连接层的隐层大小，训练轮数（epoch）。

使用验证集选择最优超参数组合。观察训练损失曲线判断是否收敛或过拟合。

### 4.4 训练流程

完整训练流程：加载数据到GPU，创建网络模型到GPU，定义损失函数（CrossEntropyLoss）和优化器（Adam或SGD with Momentum），训练循环中执行前向传播、损失计算、反向传播、参数更新，验证集上评估性能，保存最优模型。

## 5. 应用场景

### 5.1 图像分类

图像分类是CNN最经典的应用。输入图像，输出类别标签。经典网络包括LeNet-5（手写数字）、AlexNet（ImageNet）、ResNet（CIFAR）等。

### 5.2 目标检测

目标检测需要定位图像中的目标并识别其类别。典型方法包括：两阶段检测器（R-CNN系列），单阶段检测器（YOLO、SSD）。CNN是这些检测器的核心特征提取器。

### 5.3 语义分割

语义分割为图像中每个像素分配类别。典型方法包括FCN、U-Net、DeepLab系列。编码器部分使用CNN提取特征，解码器部分将特征图上采样到原始分辨率。

### 5.4 人脸识别

人脸识别使用CNN提取人脸特征。常见流程：人脸检测、人脸对齐、特征提取、特征比对。ArcFace、CosFace等方法使用CNN提取具有区分性的人脸特征。

### 5.5 其他视觉任务

CNN还应用于图像生成（GAN）、图像超分辨率、姿态估计、图像风格迁移等任务。

---

## 6. 优缺点分析

### 6.1 优点

**参数效率高**：相比全连接网络，CNN参数少很多，能够训练更深的网络。

**适合处理图像**：局部连接和参数共享利用了图像的空间结构。

**平移不变性**：对输入的平移具有鲁棒性。

**可扩展性强**：可以从简单网络扩展到复杂网络（更多层、更多通道）。

### 6.2 缺点

**对旋转和尺度变换敏感**：通常需要对数据增强处理。

**需要大量数据和计算资源**：深层CNN需要大规模数据集和GPU。

**黑盒模型**：可解释性相对较差。

**可能存在梯度消失**：深层网络训练困难（但Batch Normalization和残差连接部分解决）。

## 7. 调库实现（PyTorch完整代码）

```python
"""
卷积神经网络（CNN）- MNIST手写数字分类
使用PyTorch实现完整的卷积神经网络分类器
"""

import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import matplotlib.pyplot as plt
import numpy as np


class CNN(nn.Module):
    def __init__(self, num_classes=10):
        super(CNN, self).__init__()
        
        self.conv1 = nn.Conv2d(1, 32, kernel_size=3, padding=1)
        self.bn1 = nn.BatchNorm2d(32)
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.bn2 = nn.BatchNorm2d(64)
        self.pool1 = nn.MaxPool2d(2, 2)
        
        self.conv3 = nn.Conv2d(64, 128, kernel_size=3, padding=1)
        self.bn3 = nn.BatchNorm2d(128)
        self.conv4 = nn.Conv2d(128, 128, kernel_size=3, padding=1)
        self.bn4 = nn.BatchNorm2d(128)
        self.pool2 = nn.MaxPool2d(2, 2)
        
        self.conv5 = nn.Conv2d(128, 256, kernel_size=3, padding=1)
        self.bn5 = nn.BatchNorm2d(256)
        self.conv6 = nn.Conv2d(256, 256, kernel_size=3, padding=1)
        self.bn6 = nn.BatchNorm2d(256)
        self.pool3 = nn.MaxPool2d(2, 2)
        
        self.dropout = nn.Dropout(0.5)
        self.fc1 = nn.Linear(256 * 3 * 3, 512)
        self.fc2 = nn.Linear(512, num_classes)
    
    def forward(self, x):
        x = self.conv1(x)
        x = self.bn1(x)
        x = F.relu(x)
        
        x = self.conv2(x)
        x = self.bn2(x)
        x = F.relu(x)
        x = self.pool1(x)
        
        x = self.conv3(x)
        x = self.bn3(x)
        x = F.relu(x)
        
        x = self.conv4(x)
        x = self.bn4(x)
        x = F.relu(x)
        x = self.pool2(x)
        
        x = self.conv5(x)
        x = self.bn5(x)
        x = F.relu(x)
        
        x = self.conv6(x)
        x = self.bn6(x)
        x = F.relu(x)
        x = self.pool3(x)
        
        x = x.view(x.size(0), -1)
        x = self.dropout(x)
        x = self.fc1(x)
        x = F.relu(x)
        x = self.dropout(x)
        x = self.fc2(x)
        
        return x


class LeNet5(nn.Module):
    def __init__(self, num_classes=10):
        super(LeNet5, self).__init__()
        
        self.conv1 = nn.Conv2d(1, 6, kernel_size=5)
        self.conv2 = nn.Conv2d(6, 16, kernel_size=5)
        self.pool = nn.MaxPool2d(2, 2)
        
        self.fc1 = nn.Linear(16 * 5 * 5, 120)
        self.fc2 = nn.Linear(120, 84)
        self.fc3 = nn.Linear(84, num_classes)
        
        self.relu = nn.ReLU()
    
    def forward(self, x):
        x = self.pool(self.relu(self.conv1(x)))
        x = self.pool(self.relu(self.conv2(x)))
        
        x = x.view(x.size(0), -1)
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        x = self.fc3(x)
        
        return x


def train_epoch(model, loader, criterion, optimizer, device):
    model.train()
    total_loss = 0
    correct = 0
    total = 0
    
    for images, labels in loader:
        images, labels = images.to(device), labels.to(device)
        
        optimizer.zero_grad()
        outputs = model(images)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item()
        _, predicted = torch.max(outputs.data, 1)
        total += labels.size(0)
        correct += (predicted == labels).sum().item()
    
    return total_loss / len(loader), 100 * correct / total


def evaluate(model, loader, device):
    model.eval()
    correct = 0
    total = 0
    
    with torch.no_grad():
        for images, labels in loader:
            images, labels = images.to(device), labels.to(device)
            outputs = model(images)
            _, predicted = torch.max(outputs.data, 1)
            total += labels.size(0)
            correct += (predicted == labels).sum().item()
    
    return 100 * correct / total


def visualize_predictions(images, predictions, labels, num_samples=10):
    fig, axes = plt.subplots(2, 5, figsize=(15, 6))
    for i, ax in enumerate(axes.flat):
        if i < num_samples:
            ax.imshow(images[i].squeeze(), cmap='gray')
            ax.set_title(f'True: {labels[i]}\nPred: {predictions[i]}')
            ax.axis('off')
    plt.tight_layout()
    plt.savefig('cnn_predictions.png', dpi=150)
    plt.close()
    print("预测结果可视化已保存到 cnn_predictions.png")


def main():
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    print(f"Using device: {device}")
    
    transform_train = transforms.Compose([
        transforms.RandomRotation(10),
        transforms.RandomAffine(degrees=0, translate=(0.1, 0.1)),
        transforms.ToTensor(),
        transforms.Normalize((0.1307,), (0.3081,))
    ])
    
    transform_test = transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize((0.1307,), (0.3081,))
    ])
    
    train_data = datasets.MNIST(root='./data', train=True, download=True, transform=transform_train)
    test_data = datasets.MNIST(root='./data', train=False, download=True, transform=transform_test)
    
    train_loader = DataLoader(train_data, batch_size=128, shuffle=True)
    test_loader = DataLoader(test_data, batch_size=128, shuffle=False)
    
    model = CNN(num_classes=10).to(device)
    criterion = nn.CrossEntropyLoss()
    optimizer = optim.Adam(model.parameters(), lr=0.001)
    scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=5, gamma=0.5)
    
    print(f"Model architecture:\n{model}")
    params = sum(p.numel() for p in model.parameters())
    print(f"\nTotal parameters: {params:,}")
    
    num_epochs = 15
    best_acc = 0
    
    print("\nTraining CNN...")
    for epoch in range(num_epochs):
        train_loss, train_acc = train_epoch(model, train_loader, criterion, optimizer, device)
        test_acc = evaluate(model, test_loader, device)
        
        if test_acc > best_acc:
            best_acc = test_acc
            torch.save(model.state_dict(), 'cnn_mnist.pth')
        
        print(f"Epoch [{epoch+1}/{num_epochs}] Loss: {train_loss:.4f}, Train: {train_acc:.2f}%, Test: {test_acc:.2f}%")
        scheduler.step()
    
    print(f"\nBest test accuracy: {best_acc:.2f}%")
    
    model.load_state_dict(torch.load('cnn_mnist.pth'))
    model.eval()
    
    test_samples, test_labels = next(iter(test_loader))
    test_samples = test_samples[:10].to(device)
    
    with torch.no_grad():
        outputs = model(test_samples)
        _, predictions = torch.max(outputs, 1)
    
    visualize_predictions(test_samples.cpu().numpy(), predictions.cpu().numpy(), test_labels[:10].numpy())


if __name__ == '__main__':
    main()
```

## 8. 手工代码实现（PyTorch Tensor）

```python
"""
卷积神经网络 - 手工实现版本（纯NumPy/PyTorch Tensor）
手动实现卷积操作和池化操作，深入理解CNN原理
"""

import torch
import torch.nn.functional as F
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import numpy as np


class ManualConv2d(torch.nn.Module):
    def __init__(self, in_channels, out_channels, kernel_size, stride=1, padding=0):
        super(ManualConv2d, self).__init__()
        self.in_channels = in_channels
        self.out_channels = out_channels
        self.kernel_size = kernel_size
        self.stride = stride
        self.padding = padding
        
        self.weight = torch.randn(out_channels, in_channels, kernel_size, kernel_size) * 0.1
        self.bias = torch.zeros(out_channels)
        
        self.weight.requires_grad = True
        self.bias.requires_grad = True
    
    def forward(self, x):
        return F.conv2d(x, self.weight, self.bias, self.stride, self.padding)


class ManualMaxPool2d(torch.nn.Module):
    def __init__(self, kernel_size=2, stride=2):
        super(ManualMaxPool2d, self).__init__()
        self.kernel_size = kernel_size
        self.stride = stride
    
    def forward(self, x):
        return F.max_pool2d(x, self.kernel_size, self.stride)


class ManualCNN(torch.nn.Module):
    def __init__(self, in_channels=1, num_classes=10):
        super(ManualCNN, self).__init__()
        
        self.conv1 = ManualConv2d(in_channels, 16, kernel_size=3, padding=1)
        self.conv2 = ManualConv2d(16, 32, kernel_size=3, padding=1)
        self.pool1 = ManualMaxPool2d(2, 2)
        
        self.conv3 = ManualConv2d(32, 64, kernel_size=3, padding=1)
        self.conv4 = ManualConv2d(64, 64, kernel_size=3, padding=1)
        self.pool2 = ManualMaxPool2d(2, 2)
        
        self.fc1 = torch.nn.Linear(64 * 7 * 7, 256)
        self.fc2 = torch.nn.Linear(256, num_classes)
    
    def forward(self, x):
        x = F.relu(self.conv1(x))
        x = F.relu(self.conv2(x))
        x = self.pool1(x)
        
        x = F.relu(self.conv3(x))
        x = F.relu(self.conv4(x))
        x = self.pool2(x)
        
        x = x.view(x.size(0), -1)
        x = F.relu(self.fc1(x))
        x = self.fc2(x)
        
        return x


class ManualConv2dManual:
    """
    纯手工实现卷积操作（不使用F.conv2d）
    展示卷积操作的底层实现
    """
    def __init__(self, in_channels, out_channels, kernel_size, stride=1, padding=0):
        self.in_channels = in_channels
        self.out_channels = out_channels
        self.kernel_size = kernel_size
        self.stride = stride
        self.padding = padding
        
        self.weight = torch.randn(out_channels, in_channels, kernel_size, kernel_size) * 0.1
        self.bias = torch.zeros(out_channels)
        
        self.weight.requires_grad = True
        self.bias.requires_grad = True
    
    def forward(self, x):
        if self.padding > 0:
            x = torch.nn.functional.pad(x, (self.padding,) * 4)
        
        batch, channels, height, width = x.shape
        out_channels, _, k_h, k_w = self.weight.shape
        
        out_h = (height - k_h) // self.stride + 1
        out_w = (width - k_w) // self.stride + 1
        
        output = torch.zeros(batch, out_channels, out_h, out_w)
        
        for b in range(batch):
            for oc in range(out_channels):
                for ic in range(channels):
                    for i in range(0, height - k_h + 1, self.stride):
                        for j in range(0, width - k_w + 1, self.stride):
                            patch = x[b, ic, i:i+k_h, j:j+k_w]
                            output[b, oc, i//self.stride, j//self.stride] += torch.sum(patch * self.weight[oc, ic])
                
                output[b, oc] += self.bias[oc]
        
        return output
    
    def parameters(self):
        return [self.weight, self.bias]


def manual_conv2d_demo():
    print("=" * 60)
```

## 11. 常见问题与易错点

### 11.1 维度不匹配

**问题**：卷积层、全连接层之间的维度不匹配。**解决方法**：仔细计算每层的输入输出尺寸，使用print或summary工具检查。

### 11.2 梯度消失

**问题**：深层网络训练困难，损失不下降。**解决方法**：使用Batch Normalization、残差连接、ReLU激活函数。

### 11.3 过拟合

**问题**：训练准确率高但测试准确率低。**解决方法**：使用Dropout、数据增强、Early Stopping。

### 11.4 内存不足

**问题**：GPU内存不足，batch size太小。**解决方法**：减小模型规模、使用梯度累积、混合精度训练。

### 11.5 学习率不当

**问题**：训练振荡或发散。**解决方法**：使用学习率衰减、合适的优化器。

## 12. 学习总结

卷积神经网络（CNN）是计算机视觉领域的核心算法。**核心要点**：卷积操作实现局部连接和参数共享，大大减少参数量；池化操作降低分辨率，提供平移不变性。典型CNN结构：多个卷积层+BN+激活+池化，全连接层输出分类。

**实现要点**：PyTorch的nn.Conv2d、nn.MaxPool2d等模块使实现变得简单。使用Batch Normalization和Dropout提高训练稳定性。使用GPU加速训练。

**实践要点**：选择合适的网络规模，超参数调优很重要。数据增强能显著提高泛化能力。使用预训练模型进行迁移学习。

## 13. 练习题与思考题与思考题（含答案）

### 练习题

**练习1**：计算输入$32\times32\times3$的图像，经过64个$3\times3$卷积核（步长1，填充1）后的特征图尺寸。

**解答**：$O = \lfloor \frac{32 - 3 + 2\times1}{1} \rfloor + 1 = \lfloor 32 \rfloor + 1 = 33$？实际上在PyTorch中：$O = \lfloor \frac{32 + 2\times1 - 3}{1} \rfloor + 1 = \lfloor 31 \rfloor + 1 = 32$。因为公式是：$O = \lfloor \frac{W + 2P - K}{S} \rfloor + 1$，代入：$O = \lfloor \frac{32 + 2\times1 - 3}{1} \rfloor + 1 = \lfloor \frac{31}{1} \rfloor + 1 = 31 + 1 = 32$。所以输出是$32\times32\times64$。

**练习2**：解释为什么$3\times3$卷积两次比$5\times5$卷积一次更好。

**解答**：$3\times3$卷积两次的感受野是$5\times5$，但参数量更少：$3\times3\times2 = 18$ vs $5\times5 = 25$。同时，两个$3\times3$卷积有更多的非线性操作，更容易优化。

**练习3**：实现一个简单的CNN用于CIFAR-10分类。

**解答**：见第7节的代码，只需将输入通道改为3，修改全连接层尺寸。

### 思考题

**思考1**：为什么卷积层后通常接Batch Normalization？

**解答**：Batch Normalization将每层的输入分布归一化到标准正态分布，使得：梯度传播更稳定，每层可以独立设置学习率，具有一定的正则化效果。训练时使用batch均值和方差，推理时使用滑动平均。

**思考2**：$1\times1$卷积的作用是什么？

**解答**：$1\times1$卷积实现通道间的线性变换，可以：改变通道数（升降维），融合不同通道的信息，减少参数量（在Inception和ResNet中大量使用）。

**思考3**：为什么需要数据增强？

**解答**：CNN只看到训练数据，数据增强可以：增加数据多样性，提高泛化能力，使模型对旋转、尺度、亮度等变化更鲁棒。
