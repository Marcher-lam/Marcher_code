# 文本生成策略 学习文档

> 大语言模型在生成文本时使用的解码策略，包括确定性方法和随机性采样方法

---

## 1. 算法基础认知

**一句话定义**：文本生成策略是语言模型在生成文本时选择输出token的方法，决定了生成内容的质量、多样性和创造性。

**直觉类比**：就像在选择题中答题：
- 贪婪搜索：总是选最确定的答案（可能过于保守）
- Beam Search：保留多个选项再选择（更稳健）
- 采样：按概率随机选择（更有创意但可能偏离主题）

**历史背景**：
- 2017年前主要是贪婪搜索和Beam Search
- 2018年后GPT系列引入采样方法
- 2019年Top-p (Nucleus)采样提出
- 2020年后出现Temperature、Top-k等组合策略

**算法定位**：
- 类型：NLP → 语言模型解码
- 输出：下一个token
- 模型类型：解码策略

**前置知识**：
- [必备]：语言模型基础
- [必备]：概率分布
- [扩展]：Transformer、GPT

---

## 2. 核心原理

### 2.1 核心思想

不同策略在" exploitation（利用）"和"exploration（探索）"之间权衡：
- 确定性：利用已知最优
- 随机性：探索新可能

### 2.2 关键概念

- **Temperature（T）**：控制概率分布的平滑度
  - T高：分布更均匀 → 更有创意
  - T低：分布更 sharp → 更确定

- **Top-k**：只保留概率最高的k个token

- **Top-p (Nucleus)**：保留累计概率达到p的最小token集合

### 2.3 算法对比

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 贪婪搜索 | 确定、简单 | 容易重复 | 命令式生成 |
| Beam Search | 稳健、质量高 | 计算成本高 | 翻译、摘要 |
| Top-k采样 | 多样、有创意 | 可能不连贯 | 创意写作 |
| Top-p采样 | 自适应多样 | 不够稳定 | 对话生成 |

## 3. 数学公式

### 3.1 Softmax with Temperature

$$P_T(x_i) = \frac{e^{z_i/T}}{\sum_j e^{z_j/T}}$$

当 T=1：标准softmax
当 T→0：趋近于argmax
当 T→∞：趋近于均匀分布

### 3.2 Top-k Sampling

从概率最高的k个token中按概率采样

### 3.3 Top-p Sampling

选择最小集合U，使得：
$$\sum_{x \in U} P(x) \ge p$$

## 4. 调库实现

```python
"""
文本生成策略实现
"""

import numpy as np
import torch
import torch.nn.functional as F


def greedy_search(logits):
    """贪婪搜索：总是选择概率最高的token"""
    return torch.argmax(logits, dim=-1)


def beam_search(logits, beam_width=5):
    """Beam Search：保留beam_width个最优序列"""
    # 简化实现
    topk = torch.topk(logits, beam_width, dim=-1)
    return topk.indices, topk.values


def temperature_sampling(logits, temperature=0.7):
    """Temperature采样"""
    # 应用temperature
    logits = logits / temperature
    # 转换为概率
    probs = F.softmax(logits, dim=-1)
    # 采样
    return torch.multinomial(probs, 1)


def top_k_sampling(logits, k=40, temperature=0.7):
    """Top-k采样"""
    # 应用temperature
    logits = logits / temperature
    
    # Top-k过滤
    top_k = torch.topk(logits, k, dim=-1)
    scores = F.softmax(top_k.values, dim=-1)
    indices = top_k.indices
    
    # 采样
    sampled_idx = torch.multinomial(scores, 1)
    return indices.gather(1, sampled_idx)


def top_p_sampling(logits, p=0.9, temperature=0.7):
    """Top-p (Nucleus)采样"""
    # 应用temperature
    logits = logits / temperature
    
    # 排序
    sorted_logits, sorted_indices = torch.sort(logits, descending=True)
    probs = F.softmax(sorted_logits, dim=-1)
    
    # 计算累积概率
    cumsum_probs = torch.cumsum(probs, dim=-1)
    
    # 找到满足p的最小集合
    mask = cumsum_probs <= p
    
    # 保留第一个超过p的
    first_exceed = (cumsum_probs > p).nonzero(as_tuple=True)[1][0]
    mask[first_exceed:] = True
    
    # 应用mask
    filtered_logits = torch.where(mask, sorted_logits, float('-inf'))
    
    # 重新计算概率并采样
    filtered_probs = F.softmax(filtered_logits, dim=-1)
    sampled = torch.multinomial(filtered_probs, 1)
    
    # 返回原始索引
    return sorted_indices.gather(1, sampled)


# 组合策略
def generate_with_strategy(logits, strategy='top_p', **kwargs):
    """组合生成策略"""
    
    if strategy == 'greedy':
        return greedy_search(logits)
    elif strategy == 'beam':
        return beam_search(logits, kwargs.get('beam_width', 5))
    elif strategy == 'temperature':
        return temperature_sampling(logits, kwargs.get('temperature', 1.0))
    elif strategy == 'top_k':
        return top_k_sampling(logits, kwargs.get('k', 40), kwargs.get('temperature', 0.7))
    elif strategy == 'top_p':
        return top_p_sampling(logits, kwargs.get('p', 0.9), kwargs.get('temperature', 0.7))
    else:
        raise ValueError(f"Unknown strategy: {strategy}")


# 测试
if __name__ == "__main__":
    # 模拟logits
    logits = torch.randn(1, 10000)
    
    # 测试各种策略
    strategies = ['greedy', 'temperature', 'top_k', 'top_p']
    
    for s in strategies:
        result = generate_with_strategy(logits, s, temperature=0.8, k=50, p=0.9)
        print(f"{s}: {result.item()}")
```

## 5. 应用场景

### 5.1 策略选择指南

| 场景 | 推荐策略 |
|------|----------|
| 机器翻译 | Beam Search |
| 摘要生成 | Beam Search + Temperature |
| 对话生成 | Top-p采样 |
| 代码生成 | Top-k采样 |
| 创意写作 | Top-p + Temperature |
| 问答 | Greedy |

### 5.2 超参数建议

| 参数 | 推荐值 |
|------|-------|
| Temperature | 0.7-1.0 |
| Top-k | 20-50 |
| Top-p | 0.85-0.95 |
| Beam Width | 3-5 |

---

## 6. 最佳实践

1. **组合策略**：Top-p + Temperature 通常效果最好
2. **避免重复**：可加入n-gram惩罚
3. **长度控制**：在长度适中处截断
4. **测试调优**：根据实际效果调整参数

## 7. 练习题

**问题**：为什么Top-p采样通常比Top-k更好？

答案：Top-p自适应地选择token数量，在不同位置灵活调整。
