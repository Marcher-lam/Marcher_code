# 文本生成策略 学习文档

> 大语言模型在生成文本时使用的解码策略，包括确定性方法和随机性采样方法

---

## 1. 算法基础认知

### 1.1 一句话定义

文本生成策略是语言模型在生成文本时选择输出token的方法，决定了生成内容的质量、多样性和创造性。

### 1.2 直觉类比

文本生成策略就像在一个巨大的图书馆中选择下一本书：
- **贪婪搜索**：只看最热门的那本（可能过于保守，总是选最确定的答案）
- **Beam Search**：同时借阅几本热门书，最后选择最好的（保留多个选项再选择，更稳健）
- **采样**：按热门程度随机选择一本（更有创意但可能偏离主题）
- **Top-p采样**：选择涵盖85%热度的书籍集合，从中随机选择（自适应调整，更灵活）

### 1.3 发展背景

- 2017年前：主要是贪婪搜索和Beam Search主导
- 2018年：GPT系列引入采样方法
- 2019年：Top-p (Nucleus)采样被提出
- 2020年后：组合策略成为主流（Temperature + Top-k + Top-p）

### 1.4 核心定位

| 特性 | 说明 |
|------|------|
| 类型 | NLP → 语言模型解码 |
| 输出 | 下一个token |
| 模型类型 | 解码策略 |
| 核心矛盾 | 确定性与多样性 |

### 1.5 前置知识

- [必备]：语言模型基础
- [必备]：概率分布
- [扩展]：Transformer、GPT

## 2. 核心原理

### 2.1 核心思想

文本生成策略的核心是在"exploitation（利用）"和"exploration（探索）"之间权衡：
- **确定性策略**：利用已知最优（贪婪、Beam Search）
- **随机性策略**：探索新可能性（采样类方法）

### 2.2 工作流程

```
1. 模型输出logits
2. 应用Temperature调整分布
3. 应用Top-k/Top-p过滤
4. 转换为概率分布
5. 采样选择token
6. 重复直到结束
```

### 2.3 关键概念

#### 2.3.1 Temperature（T）

控制概率分布的平滑度：
| T值 | 效果 |
|-----|------|
| T→0 | 趋近argmax，完全确定性 |
| T=1 | 标准softmax |
| T>1 | 分布更均匀，更随机 |
| T→∞ | 趋近均匀分布 |

#### 2.3.2 Top-k

只保留概率最高的k个token，其余设为0概率。

#### 2.3.3 Top-p (Nucleus)

保留累计概率达到p的最小token集合，动态调整候选数量。

## 3. 数学公式与推导

### 3.1 Softmax with Temperature

温度调整后的softmax：
$$P_T(x_i) = \frac{e^{z_i/T}}{sum_j e^{z_j/T}}$$

推导：
- 当 T=1：标准softmax，$P_1(x_i) = frac{e^{z_i}}{sum_j e^{z_j}}$
- 当 T→0：$lim_{T to 0} P_T(x_i) = 1$ if $i = argmax(z)$，否则为0（趋近于argmax）
- 当 T→∞：$lim_{T to infty} P_T(x_i) = frac{1}{n}$（趋近于均匀分布）

### 3.2 Top-k Sampling

从概率最高的k个token中按概率采样：
$$P_{top-k}(x_i) = begin{cases} frac{P(x_i)}{sum_{j in top-k} P(x_j)} & text{if } x_i in top-k  0 & text{otherwise} end{cases}$$

### 3.3 Top-p Sampling (Nucleus)

选择最小集合U，使得累积概率达到p：
$$U = argmin_{|U|} { sum_{x in U} P(x) ge p }$$

然后重新归一化：
$$P_{top-p}(x) = begin{cases} frac{P(x)}{sum_{x' in U} P(x')} & text{if } x in U  0 & text{otherwise} end{cases}$$

### 3.4 Beam Search

保留beam_width个最优序列，定义score：
$$score(y_{1:t}) = log P(y_{1:t}|x) = sum_{i=1}^{t} log P(y_i|y_{1:i-1}, x)$$

最终选择：
$$hat{y} = argmax_{y in beams} score(y)$$

### 3.5 长度归一化

为避免短序列偏好，使用长度归一化：
$$score_{norm}(y) = frac{1}{t^alpha} log P(y|x)$$

常用alpha=0.6-0.7。

## 4. 训练过程讲解

### 4.1 策略选择流程

```python
def select_strategy(logits, strategy_config):
    """策略选择主流程"""
    T = strategy_config.get('temperature', 1.0)
    k = strategy_config.get('top_k', 0)
    p = strategy_config.get('top_p', 1.0)
    
    # Step 1: Temperature调整
    if T != 1.0:
        logits = logits / T
    
    # Step 2: 过滤
    if k > 0:
        logits = top_k_filter(logits, k)
    if p < 1.0:
        logits = top_p_filter(logits, p)
    
    # Step 3: 采样
    probs = softmax(logits)
    token = sample(probs)
    
    return token
```

## 6. 优缺点分析

### 6.1 优点

| 优点 | 说明 |
|------|------|
| **多样性可控** | 通过T/k/p调整 |
| **自适应** | Top-p动态调整候选 |
| **可解释** | 参数意义明确 |
| **组合灵活** | 多种策略可组合 |

### 6.2 缺点

| 缺点 | 说明 |
|------|------|
| **重复问题** | 可能生成循环文本 |
| **计算开销** | Beam/Sampling有开销 |
| **超参敏感** | 需要调优 |
| **长度偏移** | 长文本可能偏移 |

### 6.3 注意事项

- **重复惩罚**：在logits中加入n-gram惩罚项
- **长度截断**：设置最大生成长度
- **结束符**：正确配置EOS token
- **缓存**：采样结果可缓存加速

## 7. 调库实现（Python）

### 7.1 基础实现

```python
import numpy as np
import torch
import torch.nn.functional as F
from typing import Optional


def greedy_search(logits: torch.Tensor) -> torch.Tensor:
    """贪婪搜索：总是选择概率最高的token"""
    return torch.argmax(logits, dim=-1)


def temperature_sampling(logits: torch.Tensor, temperature: float = 0.7) -> torch.Tensor:
    """Temperature采样"""
    if temperature <= 0:
        raise ValueError("Temperature must be positive")
    
    logits = logits / temperature
    probs = F.softmax(logits, dim=-1)
    return torch.multinomial(probs, 1)


def top_k_sampling(logits: torch.Tensor, k: int = 40, 
                 temperature: float = 0.7) -> torch.Tensor:
    """Top-k采样"""
    logits = logits / temperature
    
    top_k = torch.topk(logits, k, dim=-1)
    scores = F.softmax(top_k.values, dim=-1)
    indices = top_k.indices
    
    sampled_idx = torch.multinomial(scores, 1)
    return indices.gather(1, sampled_idx)


def top_p_sampling(logits: torch.Tensor, p: float = 0.9,
                  temperature: float = 0.7) -> torch.Tensor:
    """Top-p (Nucleus)采样"""
    logits = logits / temperature
    
    sorted_logits, sorted_indices = torch.sort(logits, descending=True)
    probs = F.softmax(sorted_logits, dim=-1)
    
    cumsum_probs = torch.cumsum(probs, dim=-1)
    
    mask = cumsum_probs <= p
    first_exceed = (cumsum_probs > p).nonzero(as_tuple=True)[1]
    if len(first_exceed) > 0:
        mask[first_exceed[0]:] = True
    
    filtered_logits = torch.where(mask, sorted_logits, float('-inf'))
    filtered_probs = F.softmax(filtered_logits, dim=-1)
    sampled = torch.multinomial(filtered_probs, 1)
    
    return sorted_indices.gather(1, sampled)


def beam_search(logits: torch.Tensor, beam_width: int = 5) -> tuple:
    """Beam Search"""
    topk = torch.topk(logits, beam_width, dim=-1)
    return topk.indices, topk.values
```

### 7.2 完整生成器

```python
class TextGenerator:
    """文本生成器"""
    
    def __init__(self, model, tokenizer,
                 strategy: str = 'top_p',
                 temperature: float = 0.7,
                 top_k: int = 40,
                 top_p: float = 0.9,
                 max_length: int = 100):
        self.model = model
        self.tokenizer = tokenizer
        self.strategy = strategy
        self.temperature = temperature
        self.top_k = top_k
        self.top_p = top_p
        self.max_length = max_length
    
    def generate(self, prompt: str) -> str:
        """生成文本"""
        input_ids = self.tokenizer.encode(prompt)
        input_tensor = torch.tensor([input_ids])
        
        for _ in range(self.max_length):
            logits = self.model(input_tensor)
            next_token_logits = logits[0, -1, :]
            
            if self.strategy == 'greedy':
                next_token = greedy_search(next_token_logits.unsqueeze(0))
            elif self.strategy == 'top_k':
                next_token = top_k_sampling(
                    next_token_logits.unsqueeze(0),
                    self.top_k,
                    self.temperature
                )
            elif self.strategy == 'top_p':
                next_token = top_p_sampling(
                    next_token_logits.unsqueeze(0),
                    self.top_p,
                    self.temperature
                )
            else:
                next_token = temperature_sampling(
                    next_token_logits.unsqueeze(0),
                    self.temperature
                )
            
            if next_token.item() == self.tokenizer.eos_token_id:
                break
            
            input_tensor = torch.cat([input_tensor, next_token], dim=1)
        
        return self.tokenizer.decode(input_tensor[0])
```

### 7.3 重复惩罚

```python
def apply_repetition_penalty(logits: torch.Tensor, 
                      generated_ids: torch.Tensor,
                      penalty: float = 1.2) -> torch.Tensor:
    """应用重复惩罚"""
    for token_id in generated_ids.unique():
        logits[0, token_id] = logits[0, token_id] / penalty
    return logits
```

## 8. 手工代码实现（理解原理）

### 8.1 简化版Softmax

```python
import numpy as np

def softmax_with_temperature(logits: np.ndarray, temperature: float = 1.0) -> np.ndarray:
    """带温度的softmax"""
    scaled = logits / temperature
    exp_scaled = np.exp(scaled - np.max(scaled))
    return exp_scaled / np.sum(exp_scaled)


def manual_greedy_search(logits: np.ndarray) -> int:
    """手工贪婪搜索"""
    return np.argmax(logits)


def manual_temperature_sampling(logits: np.ndarray, 
                               temperature: float = 0.7) -> int:
    """手工温度采样"""
    probs = softmax_with_temperature(logits, temperature)
    return np.random.choice(len(probs), p=probs)


def manual_top_k_sampling(logits: np.ndarray, k: int = 40,
                        temperature: float = 0.7) -> int:
    """手工Top-k采样"""
    top_k_indices = np.argsort(logits)[-k:]
    top_k_logits = logits[top_k_indices]
    probs = softmax_with_temperature(top_k_logits, temperature)
    chosen_idx = np.random.choice(k, p=probs)
    return top_k_indices[chosen_idx]


def manual_top_p_sampling(logits: np.ndarray, p: float = 0.9,
                      temperature: float = 0.7) -> int:
    """手工Top-p采样"""
    sorted_indices = np.argsort(logits)[::-1]
    sorted_logits = logits[sorted_indices]
    probs = softmax_with_temperature(sorted_logits, temperature)
    
    cumsum = np.cumsum(probs)
    cutoff = np.searchsorted(cumsum, p)
    cutoff = max(cutoff + 1, 1)
    
    filtered_probs = np.zeros_like(probs)
    filtered_probs[:cutoff] = probs[:cutoff]
    filtered_probs /= filtered_probs.sum()
    
    chosen_idx = np.random.choice(cutoff, p=filtered_probs)
    return sorted_indices[chosen_idx]
```

### 8.2 完整实现示例

```python
class SimpleTextGenerator:
    """简化版文本生成器 - 理解原理"""
    
    def __init__(self, temperature: float = 0.7,
                 top_k: int = 40,
                 top_p: float = 0.9):
        self.temperature = temperature
        self.top_k = top_k
        self.top_p = top_p
    
    def generate_step(self, logits: np.ndarray) -> int:
        """单步生成（简化版）"""
        if self.top_p < 1.0:
            return manual_top_p_sampling(logits, self.top_p, self.temperature)
        elif self.top_k > 0:
            return manual_top_k_sampling(logits, self.top_k, self.temperature)
        else:
            return manual_temperature_sampling(logits, self.temperature)
    
    def generate(self, num_steps: int, logits_fn) -> list:
        """多步生成"""
        results = []
        for _ in range(num_steps):
            logits = logits_fn()
            token = self.generate_step(logits)
            results.append(token)
        return results
```

```python
from collections import Counter

def evaluate_generation(generated_texts: list) -> dict:
    """评估生成质量"""
    all_tokens = []
    for text in generated_texts:
        all_tokens.extend(text)
    
    total = len(all_tokens)
    unique = len(set(all_tokens))
    
    # 重复检测
    repeats = 0
    for i in range(1, len(all_tokens)):
        if all_tokens[i] == all_tokens[i-1]:
            repeats += 1
    
    metrics = {
        'num_samples': len(generated_texts),
        'total_tokens': total,
        'unique_tokens': unique,
        'diversity': unique / total if total > 0 else 0,
        'repetition_rate': repeats / (total - 1) if total > 1 else 0,
    }
    
    for k, v in metrics.items():
        print(f"{k}: {v:.4f}")
    
    return metrics
```

## 11. 常见问题与易错点

### Q1: Temperature设为0会怎样？

**答案**：Temperature为0会导致除以零错误。应该用极小值如0.01代替，或直接用argmax。

### Q2: Top-k和Top-p能同时用吗？

**答案**：可以，通常先Top-k过滤再Top-p过滤，或只用一种。

### Q3: 生成重复内容怎么办？

**答案**：添加n-gram惩罚，或降低Temperature，或增加Top-k/p的值。

### Q4: Beam Search如何选beam_width？

**答案**：3-5是常见值，计算资源允许可更大，但收益递减。

### Q5: 如何避免生成长文本质量下降？

**答案**：设置最大长度，或使用长度归一化，或在中间加入refinement步骤。
