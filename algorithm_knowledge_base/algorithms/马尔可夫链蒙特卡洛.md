# 马尔可夫链蒙特卡洛 学习文档

## 1. 算法基础认知
### 1.1 一句话定义
马尔可夫链蒙特卡洛（Markov Chain Monte Carlo, MCMC）是一类从复杂概率分布中生成样本的算法，通过构建满足细致平衡的马尔可夫链来逼近目标分布。

### 1.2 直觉类比
想象黑暗中的随机行走：你被蒙上眼睛在陌生的城堡中寻找宝藏。你不知道宝藏在哪里，但每到一扇门可以问"宝藏离这里更近还是更远"。根据答案你能决定下一步往哪里走。通过足够多次的探索，你最终能绘制出宝藏的大致位置——MCMC就是这个"边探索边估计"的过程。

### 1.3 历史背景
MCMC起源可追溯到1950年代Metropolis的工作。1984年Hastings提出通用Metropolis-Hastings算法，使其成为统计物理的标准工具。1990年代在贝叶斯统计中广泛应用，至今是统计计算的核心方法。

### 1.4 算法定位
- 类型：统计计算/采样方法
- 输出：来自目标分布的样本
- 模型类别：蒙特卡洛方法

### 1.5 前置知识
- 概率论（条件概率、贝叶斯定理）
- 马尔可夫链基础
- Python 编程（NumPy）

## 2. 核心原理
### 2.1 核心思想
MCMC的核心思想是构建一个马尔可夫链，使其平稳分布等于目标分布。通过在这个链上迭代采样，得到的样本就近似来自目标分布。关键在于设计满足细致平衡条件的转移核。

### 2.2 工作流程
1. 初始化：选择初始状态$x_0$
2. 迭代采样：
   - 从当前状态$x$生成候选状态$y$
   - 计算接受概率$\alpha$
   - 以概率$\alpha$接受，否者保留$x$
3. 重复：直到收集足够样本

### 2.3 关键概念解释
- **细致平衡**：$\pi(x)P(x\to y) = \pi(y)P(y\to x)$，保证平稳分布
- **接受率**：$\alpha = \min(1, \pi(y)q(y\to x) / (\pi(x)q(x\to y)))$
- **burn-in**：burn-in期后的样本更接近目标分布
- **自相关**：相邻样本相关，需 thinning

### 2.4 几何/直观解释
MCMC可看作在概率密度曲面上随机跳跃。接受率的计算确保跳到高密度区更易，跳到低密度区更难，从而使样本按正确比例分布。

## 3. 数学公式与推导
### 3.1 符号约定
| 符号 | 含义 |
|------|------|
| $\pi(x)$ | 目标分布（未归一化也可） |
| $q(x\to y)$ | 提议分布 |
| $\alpha$ | 接受概率 |
| $x_t$ | 第t个样本 |

### 3.2 问题形式化
已知未归一化密度$\tilde{\pi}(x)$，采样$x \sim \pi$

### 3.3 目标函数/损失函数
无显式目标函数。通过接受率确保细致平衡：
$$\alpha(x\to y) = \min\left(1, \frac{\pi(y)q(y\to x)}{\pi(x)q(x\to y)}\right)$$

### 3.4 推导过程
从细致平衡条件：
$$\pi(x)P(x\to y) = pi(y)P(y\to x)$$

$$P(x\to y) = q(x\to y)\alpha(x\to y)$$

代入得：
$$q(x\to y)\alpha(x\to y) = q(y\to x)\alpha(y\to x)$$

解得上式定义的接受率满足条件。

### 3.5 最终解/算法步骤
**Metropolis-Hastings算法**：
```
输入：目标分布π，先验q，初始化x0，迭代次数T
输出：样本序列{x_t}

for t = 1 to T:
    1. 从q(xt-1 → y)采样y
    2. 计算α = min(1, π(y)q(y→xt-1) / (π(xt-1)q(xt-1→y)))
    3. u ~ Uniform(0,1)
    4. if u < α: xt = y else: xt = xt-1
```

## 5. 应用场景
### 5.1 典型应用
- **贝叶斯推断**：后验采样
- **统计物理**：系综采样
- **机器学习**：模型参数采样
- **优化**：模拟退火

### 5.2 适用数据特征
- 高维复杂分布
- 归一化常数难求
- 无法直接采样

### 5.3 不适用场景
- 低维可用其他方法
- 实时要求高

## 6. 优缺点分析
### 6.1 优点
- 理论上适用于任意分布
- 只需求未归一化密度
- 可处理高维问题

### 6.2 缺点
- 样本间相关
- 收敛诊断困难
- 可能卡在局部

### 6.3 与同类算法对比

| 算法 | 适用场景 | 方差 | 复杂度 |
|------|--------|------|-------|
| MH | 通用 | 中 | 中 |
| Gibbs | 条件易求 | 低 | 低 |
| Hamiltonian | 高维 | 低 | 高 |

### 7.2 完整代码示例
```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

class MetropolisHastings:
    """Metropolis-Hastings采样器"""
    def __init__(self, target_log_prob, proposal_std=1.0):
        self.target_log_prob = target_log_prob
        self.proposal_std = proposal_std
    
    def sample(self, x0, n_samples, burn_in=1000):
        samples = []
        x = x0
        
        for i in range(n_samples + burn_in):
            x_new = x + np.random.normal(0, self.proposal_std)
            
            log_prob_current = self.target_log_prob(x)
            log_prob_new = self.target_log_prob(x_new)
            
            log_alpha = log_prob_new - log_prob_current
            
            if np.log(np.random.random()) < log_alpha:
                x = x_new
            
            if i >= burn_in:
                samples.append(x)
        
        return np.array(samples)

class GibbsSampler:
    """Gibbs采样器示例（二维高斯）"""
    def __init__(self, mu, cov):
        self.mu = np.array(mu)
        self.cov = np.array(cov)
        self.dim = len(mu)
    
    def sample(self, x0, n_samples, burn_in=1000):
        samples = []
        x = np.array(x0)
        
        for i in range(n_samples + burn_in):
            for d in range(self.dim):
                cond_mean = self.mu[d] + self.cov[d,:d].dot(
                    np.linalg.solve(self.cov[:d,:d], x[:d] - self.mu[:d])
                ) if d > 0 else self.mu[d]
                
                cond_var = self.cov[d,d] - self.cov[d,:d].dot(
                    np.linalg.solve(self.cov[:d,:d], self.cov[:d,d])
                )
                
                x[d] = np.random.normal(cond_mean, np.sqrt(cond_var))
            
            if i >= burn_in:
                samples.append(x.copy())
        
        return np.array(samples)

def example_unimodal():
    """单峰分布示例"""
    def target_log_prob(x):
        return -0.5 * x**2
    
    mh = MetropolisHastings(target_log_prob, proposal_std=2.0)
    samples = mh.sample(x0=0, n_samples=10000, burn_in=1000)
    
    plt.figure(figsize=(10, 4))
    plt.subplot(1, 2, 1)
    plt.hist(samples, bins=50, density=True, alpha=0.7)
    x = np.linspace(-4, 4, 100)
    plt.plot(x, stats.norm.pdf(x), 'r-', label='真实分布')
    plt.xlabel('x')
    plt.ylabel('密度')
    plt.title('MCMC采样 vs 真实分布')
    plt.legend()
    
    plt.subplot(1, 2, 2)
    plt.plot(samples[:500], alpha=0.5)
    plt.xlabel('迭代')
    plt.ylabel('x')
    plt.title('采样轨迹')
    plt.tight_layout()
    plt.show()

def example_multimodal():
    """多峰分布示例（用变体处理）"""
    def target_log_prob(x):
        p1 = stats.norm.pdf(x, loc=-3, scale=0.5)
        p2 = stats.norm.pdf(x, loc=3, scale=0.5)
        return np.log(p1 + p2)
    
    mh = MetropolisHastings(target_log_prob, proposal_std=3.0)
    samples = mh.sample(x0=0, n_samples=20000, burn_in=2000)
    
    plt.figure(figsize=(10, 4))
    plt.subplot(1, 2, 1)
    plt.hist(samples, bins=50, density=True, alpha=0.7)
    x = np.linspace(-6, 6, 100)
    plt.plot(x, stats.norm.pdf(x, -3, 0.5) + stats.norm.pdf(x, 3, 0.5), 'r-')
    plt.xlabel('x')
    plt.ylabel('密度')
    plt.title('多峰分布采样')
    
    plt.subplot(1, 2, 2)
    plt.plot(samples[:1000])
    plt.xlabel('迭代')
    plt.ylabel('x')
    plt.title('采样轨迹（跳跃很慢）')
    plt.tight_layout()
    plt.show()

def example_2d_gaussian():
    """二维高斯Gibbs采样"""
    mu = [0, 0]
    cov = [[1, 0.8], [0.8, 1]]
    
    gibbs = GibbsSampler(mu, cov)
    samples = gibbs.sample([3, 3], n_samples=10000, burn_in=1000)
    
    plt.figure(figsize=(10, 4))
    plt.subplot(1, 2, 1)
    plt.scatter(samples[:,0], samples[:,1], alpha=0.1, s=1)
    plt.xlabel('x₁')
    plt.ylabel('x₂')
    plt.title('Gibbs采样散点图')
    
    plt.subplot(1, 2, 2)
    plt.plot(samples[:500,0], label='x₁')
    plt.plot(samples[:500,1], label='x₂')
    plt.xlabel('迭代')
    plt.ylabel('值')
    plt.title('采样轨迹')
    plt.legend()
    plt.tight_layout()
    plt.show()

if __name__ == "__main__":
    example_unimodal()
    example_multimodal()
    example_2d_gaussian()
```

```python
def effective_sample_size(samples):
    """计算有效样本量"""
    n = len(samples)
    acf = np.correlate(samples - samples.mean(), samples - samples.mean(), mode='full')
    acf = acf[n:] / acf[n]
    return n / (1 + 2 * np.sum(acf))
```

### 13.2 进阶思考题
1. 如何处理多峰分布的跳跃问题？
2. MCMC与变分推断的区别？

### 13.3 详细答案与解析
**答案1**：因为新样本基于旧样本生成，不是独立的i.i.d.。

**答案2**：检查轨迹是否稳定，或用Geweke检验。
