# 马尔可夫链蒙特卡洛 学习文档

> 结合马尔可夫链和蒙特卡洛方法的采样技术，用于从复杂分布中采样$

---

## 1. 算法基础认知:

### 一句话定义
马尔可夫链蒙特卡洛（MCMC）是一种从复杂概率分布中采样的计算框架，通过构建平稳分布为目标分布的马尔可夫链，利用样本进行近似推断。

### 直觉类比
想象你要调查一个复杂形状湖泊中鱼的数量分布。传统的蒙特卡洛方法需要独立采样，但湖泊形状复杂很难直接采样。MCMC就像在湖泊中放一条鱼（马尔可夫链），让它按照特定规则游动（基于当前位置和目标分布），经过一段时间后，鱼的位置分布就近似于湖泊中鱼的真实分布。

### 历史背景
MCMC的思想起源于1940年代，但现代MCMC的发展主要归功于Metropolis等人1953年的工作（Metropolis算法）。1980年代，Geman兄弟证明了Gibbs采样的收敛性，使得MCMC成为贝叶斯统计和统计物理的标准工具。

### 算法定位
- 类型：无监督学习 → 概率推断、采样$
- 输出：从目标分布中采样的样本序列$
- 模型类型：采样方法、概率计算$

### 前置知识
- 马尔可夫链：平稳分布、细致平稳条件$
- 蒙特卡洛方法：用样本近似期望、积分$
- 贝叶斯推断：后验分布、先验、似然$
- 概率论：条件概率、联合分布$
- Python基础：NumPy、随机数生成、统计绘图$

## 2. 核心原理:

### 2.1 核心思想
MCMC的核心思想是：**构建一个马尔可夫链，使其平稳分布恰好是我们要采样的目标分布 $\pi(x)$，然后运行这个链足够长时间，收集的样本就近似来自 $\pi(x)$**。

关键insight：我们不需要直接采样 $\pi(x)$，只需要能构建一个转移核 $P(x'|x)$ 满足细致平稳条件（detailed balance），这样链就会收敛到 $\pi(x)$。

### 2.2 工作流程:

1. **确定目标分布**
   - 输入：目标分布 $\pi(x)$（通常是贝叶斯后验 $P(\theta|X)$ 或Gibbs分布）
   - 选择MCMC方法：Metropolis-Hastings、Gibbs采样等

2. **初始化**
   - 选择初始状态 $x^{(0)}$（通常随机或基于先验）
   - 设置链长度 $T$、老化期（burn-in）$B$、采样间隔（thinning）$K$

3. **迭代采样（对 $t=1$ 到 $T$）**
   - a. **提议**：从提议分布 $q(x'|x^{(t-1)})$ 生成候选 $x^*$
   - b. **计算接受概率**（以Metropolis-Hastings为例）：
     $$A(x^{(t-1)}, x^*) = \min \left(1, \frac{\pi(x^*) q(x^{(t-1)}|x^*)} {\pi(x^{(t-1)}) q(x^*|x^{(t-1)})} \right)$$
   - c. **接受或拒绝**：
     - 从 $[0,1]$ 均匀采样 $u$
     - 如果 $u \leq A$，则 $x^{(t)} = x^*$（接受）
     - 否则，$x^{(t)} = x^{(t-1)}$（拒绝，保留当前状态）

4. **收集样本**
   - 丢弃前 $B$ 个样本（老化期）
   - 每隔 $K$ 个样本保存一个（减少相关性）
   - 最终得到近似独立同分布（i.i.d.）的样本

### 2.3 关键概念解释:

- **平稳分布**：马尔可夫链的极限分布，与初始状态无关$
- **细致平稳条件**：$\pi(x) P(x'|x) = \pi(x') P(x|x')$，保证 $\pi$ 是平稳分布$
- **老化期（burn-in）**：链需要时间收敛到平稳分布，前期样本丢弃$
- **采样间隔（thinning）**：MCMC样本自相关，隔一定间隔采样以减少相关性$
- **有效样本量（ESS）**：考虑相关性后的有效独立样本数，用于评估采样效率$

### 2.4 几何/直观解释
想象一个粒子在能量 landscape上移动，目标分布 $\pi(x)$ 对应低温下的Boltzmann分布 $e^{-E(x)/T}$。粒子倾向于停留在低能量区域（高概率区域），但偶尔通过热扰动跳出局部极小。MCMC就是模拟这个粒子的运动，收集的位置就是来自目标分布的样本。

高维空间中，直接采样困难，但MCMC通过局部移动（Markov链）逐步探索整个空间，最终收敛到目标分布。

## 3. 数学公式与推导:

### 3.1 符号约定:

| 符号 | 含义 | 维度/类型 |
|------|------|----------|
| $\pi(x)$ | 目标分布（通常为未归一化的） | 函数：$\mathbb{R}^d \rightarrow \mathbb{R}^+$ |
| $q(x'|x)$ | 提议分布 | 条件概率密度 |
| $A(x, x')$ | 接受概率 | 标量，$0 \leq A \leq 1$ |
| $x^{(t)}$ | 第 $t$ 个样本 | $d \times 1$ 向量 |
| $T$ | 链长度（采样总数） | 标量 |
| $B$ | 老化期长度 | 标量 |
| $K$ | 采样间隔 | 标量 |

### 3.2 问题形式化
给定目标分布 $\pi(x)$（通常仅知道未归一化的形式 $\tilde{\pi}(x)$），我们希望：
1. 从 $\pi(x)$ 中生成样本
2. 使用样本近似积分：$ \mathbb{E}_{\pi}[f(X)] \approx \frac{1}{N} \sum_{i=1}^{N} f(x^{(i)} $

MCMC通过构建马尔可夫链 $x^{(0)}, x^{(1)}, ..., x^{(T)}$ 来实现，其中平稳分布是 $\pi(x)$。

### 3.3 目标函数/损失函数
MCMC不是优化算法，没有损失函数。但有一个**收敛诊断**目标：确保链的平稳分布是 $\pi(x)$。

常用的收敛诊断：
1. **Gelman-Rubin统计量**：比较多条链的间方差和链内方差，接近1表示收敛
2. **轨迹图**：观察样本轨迹是否平稳
3. **自相关函数**：检查样本间的相关性，理想情况衰减快

### 3.4 推导过程:

**细致平稳条件（Detailed Balance）**

我们希望马尔可夫链的转移核 $P(x'|x)$ 满足：
$$\pi(x) P(x'|x) = \pi(x') P(x|x')$$

这意味着从 $x$ 到 $x'$ 的流量等于从 $x'$ 到 $x$ 的流量，系统处于细致平稳状态。

**Metropolis-Hastings算法的接受概率推导**

假设我们使用提议分布 $q(x'|x)$，并允许接受/拒绝。定义转移核 $P(x'|x) = q(x'|x) A(x, x')$，其中 $A(x, x')$ 是接受概率。

细致平稳条件要求：
$$\pi(x) q(x'|x) A(x, x') = \pi(x') q(x|x') A(x', x)$$

如果我们设：
$$A(x, x') = \min \left(1, \frac{\pi(x') q(x|x')}{\pi(x) q(x'|x)} \right)$$

那么可以验证上述细致平稳条件成立（分两种情况讨论：$A$ 取1或取比值）。

**证明思路**：
1. 如果 $\frac{\pi(x') q(x|x')}{\pi(x) q(x'|x)} \geq 1$，则 $A(x, x') = 1$，此时需要验证 $\pi(x) q(x'|x) = \pi(x') q(x|x') A(x', x)$。由于对称性，$A(x', x) = 1$，等式成立。

2. 如果比值 $< 1$，则 $A(x, x') = \frac{\pi(x') q(x|x')}{\pi(x) q(x'|x)}$，代入可验证等式。

因此，Metropolis-Hastings算法满足细致平稳条件，平稳分布是 $\pi(x)$。

### 3.5 最终解/算法步骤:

**Metropolis-Hastings算法**：

```
输入：目标分布 π(x)（未归一化），提议分布 q(x'|x)，链长度 T，老化期 B，间隔 K
输出：样本集合 {x⁽�⁾, x⁽�⁺�⁾, ..., x⁽�⁺�⁺...} （近似来自 π)

1. 初始化：x⁽⁰⁾ ~ 初始分布（如先验）
2. 对 t=1 到 T：
   a. 提议：从 q(x'|x⁽ᵗ⁻¹⁾) 采样候选 x*
   b. 计算接受概率：
        A = min(1, [π(x*) q(x⁽ᵗ⁻¹⁾|x*) / [π(x⁽ᵗ⁻¹⁾) q(x*|x⁽ᵗ⁻¹⁾)])
   c. 从 U(0,1) 采样 u：
      如果 u ≤ A：x⁽ᵗ⁾ = x* （接受）
      否则：x⁽ᵗ⁾ = x⁽ᵗ⁻¹⁾ （拒绝）
3. 老化期后收集样本：
   对于 t = B+1, B+1+K, B+1+2K, ..., T：
      保存 x⁽ᵗ⁾ 到样本集合
4. 返回样本集合
```

**Gibbs采样**（特殊情况，当条件分布易采样时）：

```
输入：目标分布 p(θ₁, θ₂, ..., θₚ) （联合分布）
输出：样本集合

1. 初始化：θ⁽⁰⁾ ~ 初始值
2. 对 t=1 到 T：
   对于每个维度 j=1 到 d：
       从满条件分布采样：θⱼ⁽ᵗ⁾ ~ p(θⱼ | θ₋⁽ᵗ⁾, ..., θⱼ₋₁⁽ᵗ⁾, θⱼ₊₁⁽ᵗ⁻¹⁾, ..., θₚ⁽ᵗ⁾)
3. 老化期后收集样本
4. 返回样本集合
```

## 4. 训练过程讲解:

### 4.1 数据预处理:

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import multivariate_normal

# ============================================
# 示例：从二元高斯混合中采样（使用MCMC）
# ============================================
# 目标分布：两个高斯分布的混合
def target_log_prob(x, means, covs, weights):
    """
    计算目标分布的对数概率密度（未归一化）
    x: 形状 (d,)
    """
    d = len(x)
    log_prob = -np.inf
    for k in range(len(weights)):
        # 多元高斯对数密度
        diff = x - means[k]
        # 简化：假设对角协方差
        exponent = -0.5 * np.sum((diff ** 2) / np.diag(covs[k])))
        log_det = -0.5 * np.sum(np.log(2 * np.pi * np.diag(covs[k])))
        log_gauss = log_det + exponent
        # 加权求和（对数空间）
        if k == 0:
            log_prob = np.log(weights[k]) + log_gauss
        else:
            # 对数空间求和：log(sum w_i * exp(log_gauss_i))
            # 这里简化：忽略，实际应使用log-sum-exp技巧
            pass
    return log_prob

# 设置混合高斯参数
means = [np.array([0, 0]), np.array([3, 3])]
covs = [np.eye(2) * 0.5, np.eye(2) * 0.5]
weights = [0.5, 0.5]

print("目标分布：二元高斯混合，两个成分均值在(0,0)和(3,3)")
print("协方差都是单位矩阵*0.5")
```

预处理要点：
1. **目标分布**：需要能计算未归一化密度（或对数密度）的函数$
2. **提议分布**：常用高斯随机游走：$q(x'|x) = \mathcal{N}(x, \Sigma_q)$
3. **初始值**：通常从先验或合理的猜测开始$
4. **参数**：链长度、老化期、间隔需要根据问题调整$

### 4.2 参数初始化:

```python
def initialize_mcmc(initial_state=None, n_dim=2):
    """
    初始化MCMC参数
    """
    if initial_state is None:
        # 随机初始化
        x_current = np.random.randn(n_dim)
    else:
        x_current = np.array(initial_state, dtype=float)
    
    # 提议分布的协方差（步长参数）
    proposal_cov = np.eye(n_dim) * 0.5  # 高斯随机游走的协方差
    
    # 链长度、老化期、间隔
    T = 10000
    burn_in = 1000
    thinning = 5
    
    # 存储接受的样本（老化期后）
    samples = []
    accepted = 0
    total_proposed = 0
    
    return {
        'x_current': x_current,
        'proposal_cov': proposal_cov,
        'T': T,
        'burn_in': burn_in,
        'thinning': thinning,
        'samples': samples,
        'accepted': accepted,
        'total_proposed': total_proposed
    }
```

初始化建议：
1. **初始状态**：可以随机、从先验采样、或使用MAP估计$
2. **提议协方差**：控制提议步长，影响接受率（理想20-50%）$
3. **链长度**：通常10,000-1,000,000，取决于问题维度$
4. **老化期**：通常前10-25%的样本丢弃$

### 4.3 迭代过程（Metropolis-Hastings）:

```python
def metropolis_hastings(params, target_log_prob_fn, *args):
    """
    Metropolis-Hastings MCMC采样
    
    参数:
        params: 初始化参数字典
        target_log_prob_fn: 目标对数概率密度函数
        *args: 传递给目标函数的额外参数
    
    返回:
        更新后的params字典，包含样本
    """
    x = params['x_current']
    proposal_cov = params['proposal_cov']
    T = params['T']
    burn_in = params['burn_in']
    thinning = params['thinning']
    
    accepted = 0
    total_proposed = 0
    
    for t in range(T):
        # a. 提议：从高斯随机游走生成候选
        x_star = x + np.random.multivariate_normal(np.zeros(len(x)), proposal_cov)
        
        # b. 计算接受概率的对数（数值稳定）
        log_p_current = target_log_prob_fn(x, *args)
        log_p_star = target_log_prob_fn(x_star, *args)
        
        log_acceptance_ratio = log_p_star - log_p_current  # 对称提议时，q比值=1
        # 数值稳定：使用最小值防止exp溢出
        acceptance_ratio = np.exp(min(0, log_acceptance_ratio))  # min(0, ...) 确保≤1
        
        # c. 接受或拒绝
        u = np.random.rand()
        if u < acceptance_ratio:
            x = x_star
            accepted += 1
        total_proposed += 1
        
        # d. 老化期后，按间隔收集样本
        if t >= burn_in and (t - burn_in) % thinning == 0:
            params['samples'].append(x.copy())
    
    params['x_current'] = x
    params['accepted'] = accepted
    params['total_proposed'] = total_proposed
    params['acceptance_rate'] = accepted / total_proposed
    
    return params

# 运行MCMC
params = initialize_mcmc(initial_state=[-2, -2], n_dim=2)
# 定义目标函数（混入高斯）
def target_gmm_log_prob(x):
    # 二元高斯混合的对数概率密度（未归一化）
    log_probs = []
    for k in range(2):
        diff = x - means[k]
        exponent = -0.5 * np.sum((diff ** 2) / np.diag(covs[k])))
        log_det = -0.5 * np.sum(np.log(2 * np.pi * np.diag(covs[k])))
        log_probs.append(np.log(weights[k]) + log_det + exponent)
    # 对数空间求和：使用log-sum-exp技巧
    max_log = max(log_probs)
    return max_log + np.log(sum(np.exp(l - max_log) for l in log_probs))

params = metropolis_hastings(params, target_gmm_log_prob)

print(f"接受率: {params['acceptance_rate']:.4f}")
print(f"收集样本数: {len(params['samples'])}")
```

### 4.4 收敛条件:

MCMC没有传统的收敛条件，但有以下诊断方法：

```python
def check_convergence_mcmc(samples, n_chains=1):
    """
    检查MCMC收敛性（简化版）
    """
    samples = np.array(samples)
    n_samples, n_dim = samples.shape
    
    # 1. 轨迹图：观察是否平稳
    fig, axes = plt.subplots(n_dim, 1, figsize=(12, 8))
    for d in range(n_dim):
        axes[d].plot(range(n_samples), samples[:, d])
        axes[d].set_ylabel(f'维度 {d}')
        axes[d].set_title(f'维度 {d} 的轨迹图')
        axes[d].grid(True, alpha=0.3)
    axes[-1].set_xlabel('样本索引（老化期后）')
    plt.tight_layout()
    plt.show()
    
    # 2. 自相关函数
    from statsmodels.graphics.tsaplots import plot_acf
    fig, axes = plt.subplots(n_dim, 1, figsize=(12, 8))
    for d in range(n_dim):
        plot_acf(samples[:, d], lags=50, ax=axes[d])
        axes[d].set_title(f'维度 {d} 的自相关函数')
    plt.tight_layout()
    plt.show()
    
    # 3. Gelman-Rubin诊断需要多条链，这里省略
    print("收敛诊断：检查轨迹是否平稳，自相关是否快速衰减")
```

收敛诊断要点：
1. **轨迹图**：看起来像平稳噪声，没有趋势或漂移$
2. **自相关**：快速衰减到零，说明样本间相关性低$
3. **Gelman-Rubin统计量**：$\hat{R} \approx 1$ 表示收敛$
4. **多条链**：从不同初始值开始，比较链间和链内方差$

### 4.5 超参数及推荐范围:

| 超参数 | 作用 | 推荐范围 | 默认值 |
|--------|------|----------|--------|
| `T` (链长度） | 总采样数 | 10,000 ~ 1,000,000 | 10,000 |
| `burn_in` (老化期） | 丢弃的样本数 | T的10-25% | T的10% |
| `thinning` (间隔） | 每隔多少样本保存一个 | 1 ~ 20 | 1 (无thinning) |
| `proposal_cov` (提议协方差） | 控制步长 | 影响接受率在20-50% | 根据预运行调整 |
| `n_chains` (链数） | 用于收敛诊断 | 2 ~ 5 | 1 |

选择建议：
1. **接受率**：Metropolis算法理想接受率约23.4%（在高维中），随机游走建议约20-50%$
2. **提议协方差**：如果接受率高，增大协方差；如果低，减小$
3. **老化期**：通常丢弃前10-25%的样本$
4. **thinning**：如果自相关高，使用thinning（但会损失样本数）$

## 5. 应用场景:

### 5.1 典型应用:

**应用1：贝叶斯统计推断**
- 场景：从后验分布 $P(\theta|X)$ 中采样，估计参数$
- 为什么适合：MCMC可以从复杂后验采样，即使归一化常数未知$
- 实现：使用Metropolis-Hastings或Gibbs采样，从后验采样$

**应用2：统计物理（模拟退火）**
- 场景：模拟系统在温度T下的平衡态$
- 为什么适合：Boltzmann分布 $e^{-E(x)/T}$ 是MCMC的目标分布$
- 实现：Metropolis算法（1953年原始论文）$

**应用3：机器学习模型平均**
- 场景：从多个模型的 posterior 采样，进行贝叶斯模型平均$
- 为什么适合：MCMC可以结合多个模型，避免选择单一模型$
- 实现：MCMC在模型空间跳转（可逆跳跃MCMC）$

### 5.2 适用数据特征:

1. **复杂分布**：目标分布复杂、高维、多峰$
2. **归一化常数未知**：MCMC只需要未归一化密度$
3. **高维参数空间**：MCMC可以探索高维空间（虽然收敛慢）$
4. **贝叶斯框架**：后验分布通常只能数值近似$
5. **需要不确定性量化**：MCMC给出完整后验，而非点估计$

### 5.3 不适用场景:

1. **需要快速采样**：MCMC收敛慢，不适合实时应用 → 使用变分推断$
2. **低维简单分布**：可以直接采样或使用拒绝采样 → MCMC overkill$
3. **极高维（如百万维）**：MCMC混合极慢 → 使用哈密顿蒙特卡洛（HMC）或变分推断$
4. **需要点估计**：MCMC给出分布，如果只需要MAP估计 → 使用优化$
5. **并行需求**：MCMC是串行的（序列），难以并行化 → 使用变分推断或分布式MCMC$

---

## 6. 优缺点分析:

### 6.1 优点:

| 优点 | 说明 | 成立条件 |
|------|------|----------|
| 从复杂分布采样 | 只要能计算密度，几乎任何分布 | 目标分布定义良好 |
| 不需要归一化 | 只需要未归一化密度 | 通用 |
| 渐近精确 | 链长度→∞时，样本分布→目标分布 | 链正常收敛 |
| 通用框架 | Metropolis-Hastings适用于任何目标 | 提议分布合理 |
| 提供完整后验 | 不仅仅是点估计，还有不确定性 | 贝叶斯推断 |

### 6.2 缺点:

| 缺点 | 说明 | 缓解方法 |
|------|------|----------|
| 收敛慢 | 需要很长时间达到平稳分布 | 使用预热（warm-up）、自适应MCMC |
| 样本自相关 | MCMC样本高度相关，有效样本少 | 使用thinning、设计更好的提议 |
| 调参困难 | 提议分布难以调整，接受率不合适 | 使用自适应MCMC、预运行 |
| 诊断困难 | 很难确定链是否收敛 | 使用多条链、Gelman-Rubin诊断 |
| 计算昂贵 | 每个样本需要计算目标密度，可能很慢 | 使用近似、变分推断 |

```python
import numpy as np
import matplotlib.pyplot as plt

class MetropolisHastingsManual:
    """
    手动实现的Metropolis-Hastings MCMC
    用于教学目的，实际应用请使用emcee等库
    """
    
    def __init__(self, target_log_prob_fn, proposal_cov, n_dim=1):
        """
        初始化Metropolis-Hastings采样器
        
        参数:
            target_log_prob_fn: 目标对数概率密度函数
            proposal_cov: 提议分布的协方差矩阵 (n_dim x n_dim)
            n_dim: 参数维度
        """
        self.target_log_prob_fn = target_log_prob_fn
        self.proposal_cov = proposal_cov
        self.n_dim = n_dim
        
        self.samples_ = None
        self.acceptance_rate_ = None
        self.trace_ = None
        
    def sample(self, n_samples=10000, burn_in=1000, thin=5, initial_state=None):
        """
        执行MCMC采样
        
        参数:
            n_samples: 要收集的样本数（老化期后）
            burn_in: 老化期长度
            thin: 采样间隔
            initial_state: 初始状态
        
        返回:
            samples: 收集的样本数组
        """
        if initial_state is None:
            current_state = np.zeros(self.n_dim)
        else:
            current_state = np.array(initial_state, dtype=float)
        
        total_iter = burn_in + n_samples * thin
        accepted = 0
        trace = []  # 保存所有迭代（包括老化期）用于诊断
        
        for t in range(total_iter):
            # a. 提议：从高斯随机游走
            proposal = current_state + np.random.multivariate_normal(
                np.zeros(self.n_dim), self.proposal_cov
            )
            
            # b. 计算接受概率的对数
            log_p_current = self.target_log_prob_fn(current_state)
            log_p_proposal = self.target_log_prob_fn(proposal)
            
            log_acceptance_ratio = log_p_proposal - log_p_current
            # 对称提议时，q比值=1
            acceptance_ratio = np.exp(min(0, log_acceptance_ratio))
            
            # c. 接受或拒绝
            u = np.random.rand()
            if u < acceptance_ratio:
                current_state = proposal.copy()
                accepted += 1
            
            trace.append(current_state.copy())
            
            # d. 老化期后收集样本
            if t >= burn_in:
                if (t - burn_in) % thin == 0:
                    if len(self.samples_) == 0:
                        self.samples_ = [current_state.copy()]
                    else:
                        self.samples_.append(current_state.copy())
        
        self.acceptance_rate_ = accepted / total_iter
        self.trace_ = np.array(trace)
        
        print(f"MCMC采样完成！")
        print(f"接受率: {self.acceptance_rate_:.4f}")
        print(f"收集样本数: {len(self.samples_)}")
        
        return np.array(self.samples_)
    
    def diagnose(self):
        """
        收敛诊断：轨迹图和自相关
        """
        if self.trace_ is None:
            print("请先运行sample()方法")
            return
        
        fig, axes = plt.subplots(self.n_dim, 2, figsize=(14, 5*self.n_dim))
        
        for d in range(self.n_dim):
            # 轨迹图
            axes[d, 0].plot(self.trace_[:, d])
            axes[d, 0].set_ylabel(f'维度 {d}')
            axes[d, 0].set_title(f'维度 {d} 的轨迹图')
            axes[d, 0].grid(True, alpha=0.3)
            
            # 自相关图（简化）
            from statsmodels.graphics.tsaplots import plot_acf
            plot_acf(self.trace_[:, d], lags=50, ax=axes[d, 1])
            axes[d, 1].set_title(f'维度 {d} 的自相关函数')
        
        axes[-1, 0].set_xlabel('迭代次数（包括老化期）')
        plt.tight_layout()
        plt.show()

# ============================================
```

```python
import numpy as np
```

```python
def evaluate_mcmc(samples, target_dist_fn, true_params=None):

        samples = samples.reshape(-1, 1)

    for d in range(n_dim):
        # 计算自相关函数直到滞后50

    # 4. Gelman-Rubin诊断需要多条链，这里省略
    print("\n注意：完整的MCMC评估需要多条链和Gelman-Rubin诊断")
    
    return mean_est, std_est, ess
```

## 11. 常见问题与易错点:

### 11.1 链不收敛，轨迹有趋势或漂移
**原因**：
- 老化期太短，链还未收敛$
- 初始值太偏，位于低概率区域$
- 目标分布多峰，链被困在一个峰内$

**解决方案**：
```python

samples = mh.sample(n_samples=5000, burn_in=5000, thin=5)  # 增加老化期

# 3. 使用多条链从不同初始值开始，检查收敛
# 4. 对于多峰分布，使用并行回火（Parallel Tempering）
```

### 11.2 接受率太高（>80%）或太低（<10%）
**原因**：
- 提议协方差不合适：太高导致拒绝多，太低导致接受多但探索慢$

**解决方案**：
```python

# 2. 使用自适应MCMC（如Haarnoja提案）
# 3. 对于高维，理想的接受率约为0.234（随机游走）

# 4. 使用emcee等先进采样器，自动调整步长
```

### 11.3 样本自相关性高，有效样本量少
**原因**：
- 提议步长太小，连续样本几乎相同$
- 没有使用thinning$

**解决方案**：

**问题**：维度增加，MCMC的混合时间指数增长。

## 12. 学习总结:

### 核心要点回顾：
1. **MCMC框架**：构建平稳分布为目标分布的马尔可夫链，采样得到近似样本$
2. **细致平稳条件**：$\pi(x) P(x'|x) = \pi(x') P(x|x')$，保证平稳分布$
3. **Metropolis-Hastings**：通用MCMC方法，使用提议分布和接受/拒绝$
4. **Gibbs采样**：当条件分布易采样时使用，不需要接受/拒绝$
5. **收敛诊断**：轨迹平稳、自相关衰减、Gelman-Rubin统计量$

### 从MCMC到其他采样方法：
```
拒绝采样 - 简单但效率可能低
    ↓
重要性采样 - 加权样本
    ↓
Metropolis-Hastings MCMC - 通用，但可能混合慢
    ↓
Gibbs采样 - 条件分布易采样时高效
    ↓
Hamiltonian Monte Carlo (HMC) - 利用梯度，高维更高效
    ↓
NUTS (No-U-Turn Sampler) - 自适应HMC，现代金标准
```

### 实践建议：
1. **默认使用**：emcee或PyMC3等库，而不是自己实现$
2. **调整接受率**：随机游走提议的目标接受率约23.4%$
3. **收敛诊断**：总是检查轨迹、自相关、Gelman-Rubin统计量$
4. **有效样本量**：关注ESS，不仅仅是样本总数$
5. **与变分推断比较**：MCMC精确但慢，VI快速但近似$

## 13. 练习题与思考题（含答案）:

### 练习题:

**习题1：基础计算**
问题：使用Metropolis算法（对称提议）从 $\mathcal{N}(3, 1)$ 中采样。当前状态 $x^{(t)} = 2.5$，提议 $x^* = 3.2$。计算接受概率。

<details>
<summary>答案</summary>

对于对称提议（如高斯随机游走 $q(x'|x) = q(x|x')$），接受概率简化为：
$$A = \min \left(1, \frac{\pi(x^*)}{\pi(x^{(t)})} \right)$$

$\pi(x) = \mathcal{N}(x; 3, 1)$，所以：
$$\frac{\pi(3.2)}{\pi(2.5)} = \frac{e^{-(3.2-3)^2/2}}{e^{-(2.5-3)^2/2}} = e^{[(-0.04/2) - (-0.25/2))} = e^{0.105} \approx 1.111$$

因此 $A = \min(1, 1.111) = 1$。总是接受这次提议（因为建议值更接近均值）。

实际中，我们通常在对数空间计算：$\log A = \log \pi(x^*) - \log \pi(x^{(t)}) = -0.02 + 0.125 = 0.105$，然后 $A = \min(1, e^{0.105}) = 1$。
</details>

**习题2：编程实践**
问题：使用手写Metropolis-Hastings实现从 $\mathcal{N}(0, 1)$ 中采样，并绘制样本直方图与真实分布比较。

<details>
<summary>答案</summary>

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

# 定义目标：标准正态 N(0,1)
def target_log_prob(x):
    return -0.5 * x[0] ** 2  # 忽略常数项

# 初始化
mh = MetropolisHastingsManual(
    target_log_prob_fn=target_log_prob,
    proposal_cov=np.eye(1) * 2.0,
    n_dim=1
)

# 采样
samples = mh.sample(n_samples=10000, burn_in=1000, thin=5, initial_state=[5.0])

# 评估
mean_est = np.mean(samples)
std_est = np.std(samples)
print(f"后验均值: {mean_est:.4f} (真实: 0.0)")
print(f"后验标准差: {std_est:.4f} (真实: 1.0)")
print(f"接受率: {mh.acceptance_rate_:.4f}")

# 绘制直方图
plt.figure(figsize=(10, 6))
plt.hist(samples, bins=50, density=True, alpha=0.7, color='skyblue', label='MCMC样本')

# 真实分布
x_grid = np.linspace(-4, 4, 1000)
plt.plot(x_grid, norm.pdf(x_grid), 'r-', linewidth=2, label='真实 N(0,1)')
plt.xlabel('x')
plt.ylabel('密度')
plt.title('Metropolis-Hastings采样：N(0,1)')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```
</details>

**习题3：理论推导**
问题：证明对于对称提议分布（$q(x'|x) = q(x|x')$），Metropolis-Hastings的接受概率简化为 $A = \min(1, \pi(x')/\pi(x))$。

<details>
<summary>答案</summary>

Metropolis-Hastings接受概率：
$$A(x, x') = \min \left(1, \frac{\pi(x') q(x|x')}{\pi(x) q(x'|x)} \right)$$

如果提议分布对称：$q(x'|x) = q(x|x')$，那么 $q$ 比值 $= 1$。

因此：
$$A(x, x') = \min \left(1, \frac{\pi(x')}{\pi(x)} \right)$$

这就是Metropolis算法（1953年）的原始形式。注意：对称提议意味着提议分布只依赖于差：$q(x'|x) = q(x' - x)$。
</details>

### 思考题:

**思考题1**：MCMC和变分推断（如变分EM）有什么区别？

<details>
<summary>答案</summary>

| 方面 | MCMC | 变分推断 |
|------|----------|----------|
| 输出 | 随机样本（近似后验） | 确定性分布 Q(Z)（近似后验） |
| 精确性 | 渐近精确（链长度→∞） | 近似，有KL散度误差 |
| 速度 | 通常慢（探索整个空间） | 通常快（优化问题） |
| 诊断 | 收敛诊断复杂 | 简单（监控ELBO） |
| 适用 | 低-中维度，需要精确后验 | 高维度，需要快速推断 |

核心区别：MCMC是采样方法，给出随机样本；变分推断是优化方法，给出近似分布。MCMC通常更精确但更慢。
</details>

**思考题2**：什么时候用Gibbs采样而不是Metropolis-Hastings？

<details>
<summary>答案</summary>

| 场景 | 推荐方法 | 原因 |
|------|----------|------|
| 条件分布易采样 | Gibbbs采样 | 不需要提议和接受/拒绝，高效 |
| 高维问题 | HMC/NUTS | Gibhs仍需遍历所有维度，可能慢 |
| 条件分布复杂 | Metropolis-Hastings | 使用合适的提议分布 |
| 混合模型 | Gibhs采样 | 每个components的条件分布通常易采样 |
| 需要快速原型 | 变分推断 | Gibhs收敛可能很慢 |

总结：如果满条件分布 $p(x_j | x_{-j})$ 容易采样，Gibbs采样通常是最好的选择，因为它不需要接受/拒绝步骤，总是接受。
</details>
