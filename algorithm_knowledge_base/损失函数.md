## 1. 算法基础认知

### 1.1 什么是损失函数

损失函数（Loss Function），也称为代价函数（Cost Function）或目标函数（Objective Function），是衡量模型预测值与真实值之间差距的函数。在机器学习中，我们的目标是最小化损失函数，使模型的预测尽可能接近真实值。

损失函数的选择直接影响：
- 模型的学习方向
- 训练的收敛速度
- 对异常值的敏感程度
- 最终模型的性能

### 1.2 直觉类比

把损失函数想象成打靶时的偏差：
- 你瞄准靶心射出一箭
- 箭没有射中靶心，而是偏离了一段距离
- 这段偏离的距离就是"损失"
- 你的目标是让这个偏离尽可能小

在机器学习中，损失函数就是这个"偏离距离"的数学表达，我们通过优化算法来最小化这个距离。

### 1.3 历史背景

损失函数的概念伴随着统计学和机器学习的发展而发展：
- 19世纪：高斯提出最小二乘法
- 1950-1960年代：统计学习中的损失函数理论
- 1980年代：神经网络中的交叉熵损失
- 2010年代：深度学习中的各种改进损失函数

近年来，针对不同的任务出现了各种专门的损失函数，如Focal Loss、Contrastive Loss、Triplet Loss等。

### 1.4 算法定位

损失函数是**监督学习**的**核心组件**，是所有参数化模型训练的优化目标：

- 回归任务：MSE、MAE、Huber
- 分类任务：Cross-Entropy、KL-Divergence
- 排序任务：Pairwise Hinge、Listwise
- 生成任务：对抗损失、内容损失

### 1.5 前置知识

- 基础微积分（导数、梯度）
- 线性代数（向量、矩阵运算）
- 基础概率论（概率分布）
- 优化理论（梯度下降）

## 2. 核心原理

### 2.1 核心思想

损失函数的核心是量化"预测"与"真实"之间的差距。形式上，对于单个样本：

$$L = f(y_{pred}, y_{true})$$

对于整个数据集：

$$L_{total} = \frac{1}{n}\sum_{i=1}^{n}L_i$$

我们的目标是：$\min L_{total}$

### 2.2 损失函数分类

```
损失函数
├── 回归损失
│   ├── L1 Loss (MAE)
│   ├── L2 Loss (MSE)
│   ├── Huber Loss
│   └── Smooth L1 Loss
├── 分类损失
│   ├── Binary Cross-Entropy
│   ├── Multi-class Cross-Entropy
│   ├── KL Divergence
│   └── Hinge Loss
├── 排序损失
│   ├── Margin Ranking Loss
│   └── ListNet Loss
└── 特殊损失
    ├── Focal Loss
    ├── Contrastive Loss
    └── Triplet Loss
```

### 2.3 工作流程

1. **计算预测**：$y_{pred} = f(x; \theta)$
2. **计算损失**：$L = loss(y_{pred}, y_{true})$
3. **计算梯度**：$\nabla L = \frac{\partial L}{\partial \theta}$
4. **更新参数**：$\theta = \theta - \alpha \nabla L$

### 2.4 关键概念

**经验风险**：训练集上的平均损失

**结构风险**：加入正则化项的损失

**代理损失**：实际优化的损失（近似真实目标）

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 |
|------|------|
| $y_{pred}$ | 预测值 |
| $y_{true}$ | 真实值 |
| $n$ | 样本数 |
| $L$ | 损失函数值 |
| $\theta$ | 模型参数 |

### 3.2 L1 Loss (MAE)

Mean Absolute Error，平均绝对误差：

$$L_{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_{pred} - y_{true}|$$

特点：
- 对异常值鲁棒
- 梯度恒定
- 可能导致梯度不稳定

### 3.3 L2 Loss (MSE)

Mean Squared Error，均方误差：

$$L_{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_{pred} - y_{true})^2$$

特点：
- 对大误差惩罚更大
- 优化稳定
- 对异常值敏感

### 3.4 Huber Loss

结合L1和L2的优点：

$$L_{Huber} = \begin{cases}
\frac{1}{2}(y_{pred} - y_{true})^2 & |y_{pred} - y_{true}| \leq \delta \\
\delta|y_{pred} - y_{true}| - \frac{1}{2}\delta^2 & |y_{pred} - y_{true}| > \delta
\end{cases}$$

### 3.5 Cross-Entropy Loss

交叉熵损失，用于分类：

$$L_{CE} = -\sum_{c=1}^{C}y_{true,c}\log(y_{pred,c})$$

对于二分类：

$$L_{BCE} = -[y\log(y_{pred}) + (1-y)\log(1-y_{pred})]$$

### 3.6 梯度推导（重要）

**MSE梯度**：

$$\frac{\partial L_{MSE}}{\partial y_{pred}} = \frac{2}{n}(y_{pred} - y_{true})$$

**Cross-Entropy梯度**：

$$\frac{\partial L_{CE}}{\partial y_{pred}} = -\frac{y_{true}}{y_{pred}}$$

### 4.3 自定义损失函数

```python
import torch
import torch.nn as nn

class CustomLoss(nn.Module):
    """自定义损失函数"""
    
    def __init__(self, alpha=0.5):
        super().__init__()
        self.alpha = alpha
    
    def forward(self, y_pred, y_true):
        mse = torch.mean((y_pred - y_true) ** 2)
        mae = torch.mean(torch.abs(y_pred - y_true))
        return self.alpha * mse + (1 - self.alpha) * mae
```

### 4.4 组合损失函数

```python
class CombinedLoss(nn.Module):
    """组合多个损失函数"""
    
    def __init__(self, tasks):
        super().__init__()
        self.tasks = tasks
    
    def forward(self, y_pred, y_true):
        total_loss = 0
        for task, weight in self.tasks:
            loss = task(y_pred, y_true)
            total_loss += weight * loss
        return total_loss
```

```python
def focal_loss_demo():
    """Focal Loss用于处理类别不平衡"""
    
    class FocalLoss(nn.Module):
        def __init__(self, alpha=0.25, gamma=2.0):
            super().__init__()
            self.alpha = alpha
            self.gamma = gamma
        
        def forward(self, y_pred, y_true):
            ce = nn.functional.binary_cross_entropy_with_logits(
                y_pred, y_true, reduction='none'
            )
            p = torch.sigmoid(y_pred)
            alpha_t = self.alpha * y_true + (1 - self.alpha) * (1 - y_true)
            focal_weight = alpha_t * (1 - p) ** self.gamma
            return (focal_weight * ce).mean()
    
    # 测试
    focal = FocalLoss()
    y_true = torch.tensor([0, 1, 0, 1, 0, 1]).float()
    y_pred = torch.tensor([0.2, 0.8, 0.3, 0.7, 0.1, 0.9])
    loss = focal(y_pred, y_true)
    print(f"Focal Loss: {loss:.4f}")
```

```python
def contrastive_loss_demo():
    """对比学习损失"""
    
    class ContrastiveLoss(nn.Module):
        def __init__(self, margin=1.0):
            super().__init__()
            self.margin = margin
        
        def forward(self, anchor, positive, negative):
            pos_dist = torch.sum((anchor - positive) ** 2)
```

## 6. 优缺点分析

### 6.1 损失函数对比

| 损失函数 | 优点 | 缺点 | 适用场景 |
|---------|------|------|----------|
| MSE | 可导、优化稳定 | 对异常值敏感 | 无异常回归 |
| MAE | 对异常值鲁棒 | 梯度不稳定 | 有异常回归 |
| Huber | 平衡 | 需要调参 | 一般回归 |
| BCE | 概率解释 | 数值不稳定 | 二分类 |
| CE | 多分类标准 | 需要One-Hot | 多分类 |

```python
import torch.nn as nn

class WeightedMSELoss(nn.Module):
    """加权MSE损失"""
    
    def __init__(self, weights):
        super().__init__()
        self.weights = weights
    
    def forward(self, y_pred, y_true):
        loss = (y_pred - y_true) ** 2
        weighted_loss = loss * self.weights
        return weighted_loss.mean()

class ClassBalancedLoss(nn.Module):
    """类别平衡损失"""
    
    def __init__(self, num_classes):
        super().__init__()
        self.num_classes = num_classes
    
    def forward(self, y_pred, y_true):
        # 计算类别权重
        class_counts = torch.bincount(y_true, minlength=self.num_classes)
        class_weights = 1.0 / (class_counts.float() + 1e-6)
        class_weights = class_weights / class_weights.sum()
        
        # 应用权重
        loss = nn.functional.cross_entropy(y_pred, y_true, reduction='none')
        weighted_loss = loss * class_weights[y_true]
        return weighted_loss.mean()
```

## 8. 手工代码实现

### 8.1 MSE实现

```python
import numpy as np

def mse_loss(y_pred, y_true):
    """
    Mean Squared Error
    
    L = (1/n) * sum((y_pred - y_true)^2)
    """
    return np.mean((y_pred - y_true) ** 2)

def mse_gradient(y_pred, y_true):
    """
    MSE的梯度
    
    dL/dy_pred = (2/n) * (y_pred - y_true)
    """
    return (2 / len(y_true)) * (y_pred - y_true)
```

### 8.2 MAE实现

```python
import numpy as np

def mae_loss(y_pred, y_true):
    """
    Mean Absolute Error
    
    L = (1/n) * sum(|y_pred - y_true|)
    """
    return np.mean(np.abs(y_pred - y_true))

def mae_gradient(y_pred, y_true):
    """
    MAE的梯度
    
    dL/dy_pred = sign(y_pred - y_true) / n
    """
    return np.sign(y_pred - y_true) / len(y_true)
```

### 8.3 Cross-Entropy实现

```python
import numpy as np

def cross_entropy_loss(y_pred, y_true, epsilon=1e-15):
    """
    Cross-Entropy Loss
    
    L = -sum(y_true * log(y_pred))
    """
    # 归一化
    y_pred = np.clip(y_pred, epsilon, 1 - epsilon)
    y_pred = y_pred / y_pred.sum(axis=-1, keepdims=True)
    
    # 计算损失
    n = len(y_true)
    ce = -np.sum(y_true * np.log(y_pred)) / n
    
    return ce

def softmax(x):
    """Softmax函数"""
    exp_x = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return exp_x / np.sum(exp_x, axis=-1, keepdims=True)
```

### 8.4 Huber Loss实现

```python
import numpy as np

def huber_loss(y_pred, y_true, delta=1.0):
    """
    Huber Loss
    
    L = 0.5 * error^2 if |error| <= delta
    L = delta * |error| - 0.5 * delta^2 otherwise
    """
    error = y_pred - y_true
    abs_error = np.abs(error)
    
    quadratic = np.minimum(abs_error, delta) ** 2 / 2
    linear = delta * abs_error - delta ** 2 / 2
    
    return np.where(abs_error <= delta, quadratic, linear).mean()

def huber_gradient(y_pred, y_true, delta=1.0):
    """Huber Loss的梯度"""
    error = y_pred - y_true
    sign = np.sign(error)
    
    return np.where(np.abs(error) <= delta, error, delta * sign) / len(y_true)
```

### 8.5 完整手动实现

```python
import numpy as np

class ManualLossFunction:
    """手动实现的损失函���"""
    
    @staticmethod
    def mse(y_pred, y_true):
        return np.mean((y_pred - y_true) ** 2)
    
    @staticmethod
    def mae(y_pred, y_true):
        return np.mean(np.abs(y_pred - y_true))
    
    @staticmethod
    def cross_entropy(y_pred, y_true):
        # Logits to probabilities
        exp_pred = np.exp(y_pred - np.max(y_pred, axis=-1, keepdims=True))
        probs = exp_pred / np.sum(exp_pred, axis=-1, keepdims=True)
        
        # Clip
        probs = np.clip(probs, 1e-15, 1 - 1e-15)
        
        # CE
        return -np.sum(y_true * np.log(probs)) / len(y_true)
    
    @staticmethod
    def binary_cross_entropy(y_pred, y_true):
        # Sigmoid
        probs = 1 / (1 + np.exp(-y_pred))
        probs = np.clip(probs, 1e-15, 1 - 1.15)
        
        # BCE
        return -np.mean(y_true * np.log(probs) + (1 - y_true) * np.log(1 - probs))

print(f"MSE: {ManualLossFunction.mse(y_pred, y_true):.4f}")
```

```python
    mae_grad = np.sign(x)
    
    # Huber梯度
    delta = 1.0
    huber_grad = np.where(np.abs(x) <= delta, x, delta * np.sign(x))
    
    plt.figure(figsize=(10, 6))
    plt.plot(x, mse_grad, label='MSE Gradient', linewidth=2)
    plt.plot(x, mae_grad, label='MAE Gradient', linewidth=2)
    plt.plot(x, huber_grad, label='Huber Gradient', linewidth=2)
    plt.xlabel('Error')
    plt.ylabel('Gradient')
    plt.title('Gradient Comparison')
    plt.legend()
    plt.grid(True, alpha=0.3)
    plt.axhline(y=0, color='k', linestyle='--', alpha=0.3)
    plt.axvline(x=0, color='k', linestyle='--', alpha=0.3)
    plt.show()
```

```python
import numpy as np
import matplotlib.pyplot as plt

def plot_outlier_effect():
    """异常值对损失函数的影响"""
    # 正常数据
    y_true = np.array([1, 2, 3, 4, 5])
    y_pred = np.array([1.1, 2.1, 3.1, 4.1, 5.1])
    
    # 加异常值
    y_true_outlier = np.append(y_true, 100)
    y_pred_outlier = np.append(y_pred, 50)
    
    # MSE变化
    mse_normal = np.mean((y_pred - y_true) ** 2)
    mse_outlier = np.mean((y_pred_outlier - y_true_outlier) ** 2)
    
    # MAE变化
    mae_normal = np.mean(np.abs(y_pred - y_true))
    mae_outlier = np.mean(np.abs(y_pred_outlier - y_true_outlier))
    
    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5))
    
    # 正常
    categories = ['MSE', 'MAE']
    values_normal = [mse_normal, mae_normal]
    ax1.bar(categories, values_normal)
    ax1.set_title('Without Outlier')
    ax1.set_ylabel('Loss')
    
    # 异常
    values_outlier = [mse_outlier, mae_outlier]
    ax2.bar(categories, values_outlier)
    ax2.set_title('With Outlier')
    ax2.set_ylabel('Loss')
    
    plt.tight_layout()
    plt.show()

plot_outlier_effect()
```

```python
def evaluate_loss(y_pred, y_true):
    """评估损失"""
    metrics = {
        'mse': np.mean((y_pred - y_true) ** 2),
        'mae': np.mean(np.abs(y_pred - y_true)),
        'rmse': np.sqrt(np.mean((y_pred - y_true) ** 2))
    }
    return metrics
```

## 12. 学习总结

### 核心思想

损失函数量化模型预测与真实值的差距，是优化的目标。选择合适的损失函数对模型性能至关重要。

### 关键公式

- MSE: $(y_{pred} - y_{true})^2$
- MAE: $|y_{pred} - y_{true}|$
- CE: $-y_{true}\log(y_{pred})$
