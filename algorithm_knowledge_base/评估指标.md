# 语言模型评估指标 学习文档

> 评估语言模型性能的指标，包括困惑度、BLEU、ROUGE等。

## 1. 评估基础

### 1.1 困惑度（Perplexity）

困惑度是最常用的语言模型评估指标，表示模型对下一个词的不确定性。

#### 数学公式

$$PPL = 2^{-\frac{1}{N}\sum_{i=1}^{N}\log_2 P(w_i|w_{1:i-1})}$$

或者

$$PPL = \exp\left(\frac{1}{N}\sum_{i=1}^{N}(-\log P(w_i))\right)$$

#### 实现代码

```python
import numpy as np

def calculate_perplexity(log_probs):
    """计算困惑度"""
    N = len(log_probs)
    loss = -np.sum(log_probs) / N
    return np.exp(loss)

# 示例
log_probs = [-0.5, -1.0, -0.8]
ppl = calculate_perplexity(log_probs)
print(f"Perplexity: {ppl:.2f}")
```

### 1.2 BLEU分数

BLEU（Bilingual Evaluation Understudy）评估机器翻译质量。

#### 实现代码

```python
from nltk.translate.bleu_score import sentence_bleu

reference = [["the", "cat", "is", "on", "the", "mat"]]
candidate = ["the", "cat", "is", "the", "mat"]

score = sentence_bleu(reference, candidate)
print(f"BLEU: {score:.4f}")
```

### 1.3 ROUGE分数

ROUGE评估文本摘要质量。

#### 实现代码

```python
from rouge import Rouge

reference = "the cat is on the mat"
candidate = "the cat is the mat"

rouge = Rouge()
scores = rouge.get_scores(candidate, reference)
print(scores)
```

## 2. 指标对比

| 指标 | 用途 | 范围 |
|------|------|------|
| Perplexity | 语言模型 | 0-∞，越低越好 |
| BLEU | 翻译/摘要 | 0-1，越高越好 |
| ROUGE | 摘要 | 0-1，越高越好 |

## 3. 学习总结

不同任务使用不同评估指标。语言模型常用Perplexity，生成任务常用BLEU/ROUGE。

## 4. 练习题

**题目**：Perplexity=10表示什么？

**答案**：模型对下一个词的预测相当于从10个词中随机选择，表示模型的预测能力。
