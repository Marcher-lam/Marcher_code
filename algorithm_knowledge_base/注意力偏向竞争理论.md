# 注意力偏向竞争理论（Biased Competition Theory）学习文档

> 从神经科学角度解释注意力如何通过"竞争"机制选择性地处理视觉信息。

## 1. 算法基础认知

### 一句话定义

注意力偏向竞争理论认为，当视觉场景中有多个对象竞争有限的神经资源时，注意力通过偏向某些对象使其在竞争中获胜，从而优先获得处理。

### 直觉类比

就像在一群人中找自己的朋友——你的注意力会自动偏向熟悉的面孔，让你在"茫茫人海"中快速找到目标。这种"偏向"让你的神经系统优先处理相关信息。

### 历史背景

- **1995年**：Desimone和Duncan提出偏向竞争理论
- **后续研究**：大量神经科学实验验证该理论

### 算法定位

偏向竞争理论是**认知神经科学理论**，为计算模型中的注意力机制提供生物学基础。

---

## 2. 核心原理

### 核心思想

1. **神经资源有限**：视觉系统无法同时处理所有输入
2. **竞争机制**：多个对象竞争注意力资源
3. **偏向机制**：自上而下的信号偏向某些对象
4. **选择处理**：获胜者获得优先处理权

### 工作流程

```
多个视觉对象同时呈现
     ↓
竞争有限的神经处理资源
     ↓
自上而下信号（记忆、任务）产生偏向
     ↓
偏向使特定对象神经活动增强
     ↓
获胜对象获得优先感知和处理
```

---

## 3. 关键机制

### 自下而上的显著性

显著特征（颜色、形状、运动）自动吸引注意力：
- 红色在绿色背景中更突出
- 运动的物体更容易被注意

### 自上而下的偏向

任务相关的对象获得优先：
- 搜索"汽车"时，所有车辆更容易被注意
- 记住要找的人的外貌特征

### 交互作用

两种机制共同决定最终的注意焦点：
$$激活强度 = 显著性 + 任务偏向$$

---

## 4. 神经网络层面的体现

### 感受野竞争

- 视野中多个对象落入同一感受野
- 注意力偏向使目标对象响应更强
- 非目标对象响应被抑制

### 皮层层次

- V1、V2处理底层特征
- V4、IT处理高层对象
- 注意力在多个层次产生偏向

## 5. 计算模型应用

```python
import numpy as np

class BiasedCompetitionModel:
    """简化的偏向竞争模型"""
    
    def __init__(self, num_objects):
        self.num_objects = num_objects
        self.activation = np.zeros(num_objects)
        
    def compute_saliency(self, features):
        """计算自下而上的显著性"""
        # 简化的显著性计算
        return np.linalg.norm(features, axis=-1)
    
    def compute_top_down_bias(self, task_features, target_features):
        """计算自上而下的任务偏向"""
        # 简化的任务匹配
        bias = np.sum(task_features * target_features, axis=-1)
        return bias
    
    def competition(self, saliency, bias, attention_limit=1):
        """竞争机制"""
        # 组合显著性+偏向
        total_activation = saliency + 0.5 * bias
        
        # 胜者通吃机制
        winner = np.argmax(total_activation)
        winners = [winner]
        
        return winners
    
    def forward(self, objects_features, task_features):
        saliency = self.compute_saliency(objects_features)
        bias = self.compute_top_down_bias(task_features, objects_features)
        winner = self.competition(saliency, bias)
        return winner

# 测试
if __name__ == "__main__":
    np.random.seed(42)
    
    # 模拟5个对象，每个有10维特征
    objects = np.random.rand(5, 10)
    task = np.random.rand(10)
    
    model = BiasedCompetitionModel(5)
    winner = model.forward(objects, task)
    print(f"获胜对象: {winner}")
```

## 6. 与深度学习的关系

### 注意力机制中的体现

- **显著性检测**：计算输入的"显著性图"
- **任务驱动注意力**：Query决定关注什么
- **竞争机制**：Softmax归一化实现soft竞争

### 应用示例

```python
import torch
import torch.nn.functional as F

def biased_attention(query, keys, task_bias=None):
    """
    带偏向的注意力计算
    """
    # 基础注意力分数
    scores = torch.matmul(query, keys.transpose(-2, -1))
    
    # 添加任务偏向
    if task_bias is not None:
        scores = scores + task_bias
    
    # Softmax归一化（实现竞争）
    attention = F.softmax(scores, dim=-1)
    
    return attention
```

## 7. 可视化

```python
import matplotlib.pyplot as plt
import numpy as np

def visualize_competition():
    """可视化偏向竞争机制"""
    fig, axes = plt.subplots(1, 3, figsize=(15, 5))
    
    # 场景1: 纯自下而上
    objects = [1, 2, 3, 4, 5]
    saliency = [0.1, 0.3, 0.8, 0.2, 0.1]
    axes[0].bar(objects, saliency, color='steelblue')
    axes[0].set_title('Bottom-up Saliency')
    axes[0].set_xlabel('Object')
    axes[0].set_ylabel('Activation')
    
    # 场景2: 纯自上而下
    task_bias = [0.1, 0.1, 0.1, 0.8, 0.2]
    axes[1].bar(objects, task_bias, color='coral')
    axes[1].set_title('Top-down Bias')
    axes[1].set_xlabel('Object')
    
    # 场景3: 竞争结果
    total = [s + 0.5*b for s, b in zip(saliency, task_bias)]
    winner = np.argmax(total) + 1
    colors = ['green' if i+1 == winner else 'gray' for i in range(5)]
    axes[2].bar(objects, total, color=colors)
    axes[2].set_title(f'Competition (Winner: {winner})')
    axes[2].set_xlabel('Object')
    
    plt.tight_layout()
    plt.savefig('biased_competition.png', dpi=150)
    plt.show()

if __name__ == "__main__":
    visualize_competition()
```
