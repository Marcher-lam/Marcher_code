# 马尔可夫链学习文档

> 用一句话说明这个算法的核心价值，不超过30字。

马尔可夫链是一种基于当前状态预测下一个状态的随机过程模型。

## 1. 算法基础认知

### 1.1 什么是马尔可夫链

马尔可夫链（Markov Chain）是一种随机过程模型，其核心特性是"无记忆性"——未来只与现在有关，与过去无关。当前状态只依赖前一个状态，而不是整个历史。

### 1.2 直觉类比

想象你早上决定穿什么衣服：你只考虑今天天气怎么样，而不管上周穿了什么。马尔可夫链做的是同样的事——只根据"现在"预测"下一步"。

### 1.3 历史背景

马尔可夫链由俄罗斯数学家Andrey Markov在1907年提出，最初用于分析普希金的诗歌中的元音分布。如今，它在NLP、语音识别、金融等领域都有广泛应用。

### 1.4 算法定位

马尔可夫链是**统计/概率模型**，属于无监督学习，但常被用作生成模型。

### 1.5 前置知识

- 基础概率论
- Python编程
- 矩阵运算

## 2. 核心原理

### 2.1 核心思想

马尔可夫性质（一阶）：
$$P(X_{t+1} = j | X_t = i, X_{t-1}, ..., X_0) = P(X_{t+1} = j | X_t = i)$$

### 2.2 工作流程

1. 定义状态空间
2. 统计状态转移概率
3. 验证马尔可夫性质
4. 迭代生成新状态

### 2.3 关键概念

- **状态空间**：所有可能状态的集合
- **转移矩阵**：描述状态间转移概率的矩阵
- **平稳分布**：长期来看的极限分布

## 3. 数学公式

### 3.1 转移概率

对于离散马尔可夫链：
$$P_{ij} = P(X_{t+1} = j | X_t = i)$$

### 3.2 转移矩阵

$$P = \begin{bmatrix} P_{11} & P_{12} & ... \\ P_{21} & P_{22} & ... \\ ... & ... & ... \end{bmatrix}$$

每行和为1。

### 3.3 n步转移

$$P^{(n)} = P^n$$

## 7. 调库实现

```python
"""
马尔可夫链文本生成器
"""

import random
from collections import defaultdict, Counter

class MarkovChain:
    """马尔可夫链文本生成器"""
    
    def __init__(self, order=1):
        self.order = order  # 阶数
        self.transitions = defaultdict(Counter)
        self.start_states = []  # 可能的起始状态
        
    def train(self, sentences):
        """训练模型"""
        for sentence in sentences:
            # 添加开始/结束标记
            padded = ['<START>'] * self.order + sentence + ['<END>']
            
            for i in range(len(padded) - self.order):
                state = tuple(padded[i:i+self.order])
                next_word = padded[i+self.order]
                
                self.transitions[state][next_word] += 1
                
                if i == 0:
                    self.start_states.append(state)
        
        return self
    
    def generate(self, max_length=20):
        """生成文本"""
        state = random.choice(self.start_states)
        result = list(state)
        
        for _ in range(max_length):
            next_candidates = self.transitions[state]
            
            if not next_candidates:
                break
            
            # 按概率选择下一个词
            total = sum(next_candidates.values())
            r = random.randint(1, total)
            
            cumulative = 0
            for word, count in next_candidates.items():
                cumulative += count
                if cumulative >= r:
                    if word == '<END>':
                        return result
                    result.append(word)
                    state = tuple(result[-self.order:])
                    break
        
        return result

# 示例使用
sentences = [
    ["I", "love", "you"],
    ["you", "love", "me"],
    ["he", "loves", "her"],
]

mc = MarkovChain(order=2)
mc.train(sentences)
print("生成的句子:", mc.generate(10))
## 8. 手工代码实现（核心算法纯代码实现）

以下是一个完整的马尔可夫链手写实现，包含转移矩阵估计和序列生成：

```python
"""
马尔可夫链 - 纯手写实现
核心：转移概率估计、状态生成、平稳分布计算
"""

import numpy as np
from collections import defaultdict
import random

class MarkovChain:
    """
    离散马尔可夫链实现
    
    核心概念：
    - 状态空间S = {s1, s2, ..., sn}
    - 转移矩阵P，p_ij = P(s_j | s_i)
    
    核心假设（一阶马尔可夫）：
    P(X_t | X_{t-1}, X_{t-2}, ...) = P(X_t | X_{t-1})
    """
    
    def __init__(self, order=1):
        """
        参数：
        - order: 马尔可夫阶数（1阶只考虑前一个状态）
        """
        self.order = order
        self.states = []  # 状态列表
        self.state_to_idx = {}  # 状态到索引
        self.idx_to_state = {}  # 索引到状态
        self.transition_counts = None  # 转移计数
        self.transition_probs = None  # 转移概率
        self.n_states = 0
        
    def fit(self, sequences):
        """
        从序列数据学习转移概率
        
        sequences: 多个序列的列表，每个序列是状态的列表
        
        步骤：
        1. 构建状态空间
        2. 统计转移次数
        3. 计算转移概率
        """
        # 1. 构建状态空间
        all_states = set()
        for seq in sequences:
            for state in seq:
                all_states.add(state)
        
        self.states = sorted(list(all_states))
        self.n_states = len(self.states)
        self.state_to_idx = {s: i for i, s in enumerate(self.states)}
        self.idx_to_state = {i: s for s, i in self.state_to_idx.items()}
        
        # 2. 统计转移计数
        # 初始化计数矩阵
        self.transition_counts = np.zeros((self.n_states, self.n_states))
        
        for seq in sequences:
            # 添加起始位置标记（用None表示）
            padded = [None] * self.order + list(seq)
            
            # 统计转移
            for i in range(len(padded) - self.order):
                state_idx = self.state_to_idx.get(padded[i])
                next_state_idx = self.state_to_idx.get(padded[i + self.order])
                
                if state_idx is not None and next_state_idx is not None:
                    self.transition_counts[state_idx, next_state_idx] += 1
        
        # 3. 归一化得到转移概率
        # 每行的和应该为1
        self.transition_probs = self.transition_counts.copy()
        row_sums = self.transition_probs.sum(axis=1, keepdims=True)
        
        # 避免除零
        row_sums[row_sums == 0] = 1.0
        self.transition_probs = self.transition_probs / row_sums
        
        return self
    
    def generate(self, length, start_state=None, random_seed=None):
        """
        根据转移概率生成新序列
        
        length: 生成序列长度
        start_state: 起始状态（默认随机选择）
        random_seed: 随机种子
        """
        if random_seed is not None:
            random.seed(random_seed)
        
        # 选择起始状态
        if start_state is None:
            # 随机选择（根据转移次数）
            start_idx = random.randint(0, self.n_states - 1)
        else:
            start_idx = self.state_to_idx.get(start_state, 0)
        
        # 生成序列
        result = [self.idx_to_state[start_idx]]
        current_idx = start_idx
        
        for _ in range(length - 1):
            # 根据转移概率选择下一个状态
            probs = self.transition_probs[current_idx]
            next_idx = np.random.choice(self.n_states, p=probs)
            
            result.append(self.idx_to_state[next_idx])
            current_idx = next_idx
        
        return result
    
    def get_transition_matrix(self):
        """获取转移矩阵"""
        return self.transition_probs
    
    def get_stationary_distribution(self, max_iter=1000):
        """
        计算平稳分布
        
        平稳分布π满足：π = πP
        
        使用幂迭代法求解
        """
        # 初始化均匀分布
        pi = np.ones(self.n_states) / self.n_states
        
        for _ in range(max_iter):
            # π = πP
            pi_new = np.matmul(pi, self.transition_probs)
            
            # 检查收敛
            if np.allclose(pi, pi_new, atol=1e-6):
                break
            
            pi = pi_new
        
        return pi
    
    def probability(self, sequence):
        """
        计算整个序列的概率
        
        P(X_1, X_2, ...) = P(X_1) * P(X_2|X_1) * ...
        """
        if len(sequence) == 0:
            return 0.0
        
        # 第一个状态的概率（简化：均匀）
        prob = 1.0 / self.n_states
        
        # 后续状态的条件概率
        padded = [None] * self.order + list(sequence)
        
        for i in range(self.order, len(padded)):
            state_idx = self.state_to_idx.get(padded[i])
            prev_state_idx = self.state_to_idx.get(padded[i - self.order])
            
            if state_idx is not None and prev_state_idx is not None:
                p = self.transition_probs[prev_state_idx, state_idx]
                prob *= p
        
        return prob

def main():
    print("=" * 60)
    print("马尔可夫链 - 手写实现")
    print("=" * 60)
    
    # 训练数据
    sentences = [
        ['I', 'love', 'you'],
        ['you', 'love', 'me'],
        ['he', 'loves', 'her'],
        ['she', 'loves', 'him'],
        ['I', 'like', 'you'],
        ['you', 'like', 'me'],
    ]
    
    print(f"\n训练数据: {len(sentences)} 个句子")
    
    # 创建模型
    mc = MarkovChain(order=1)
    mc.fit(sentences)
    
    print(f"状态空间: {mc.states}")
    print(f"状态数量: {mc.n_states}")
    
    # 转移矩阵
    print("\n转移矩阵:")
    print(mc.get_transition_matrix())
    
    # 生成序列
    print("\n生成序列:")
    for _ in range(3):
        seq = mc.generate(5, random_seed=_)
        print(f"  {' -> '.join(seq)}")
    
    # 平稳分布
    print("\n平稳分布:")
    stationary = mc.get_stationary_distribution()
    for i, p in enumerate(mc.states):
        print(f"  {p}: {stationary[i]:.4f}")

if __name__ == "__main__":
    main()
```

**代码核心要点**：

1. **转移矩阵**：统计状态i转到状态j的次数
2. **归一化**：按行归一化得到概率
3. **序列生成**：按概率采样下一个状态
4. **平稳分布**：幂迭代法求解π = πP

```python
"""
马尔可夫链可视化 - 转移矩阵热力图
"""

import numpy as np
import matplotlib.pyplot as plt

def visualize_transition_matrix(mc, save_path='markov_transition.png'):
    """可视化转移矩阵"""
    P = mc.get_transition_matrix()
    states = mc.states
    
    fig, ax = plt.subplots(figsize=(8, 6))
    
    im = ax.imshow(P, cmap='Blues', vmin=0, vmax=1)
    
    ax.set_xticks(range(mc.n_states))
    ax.set_yticks(range(mc.n_states))
    ax.set_xticklabels(states, rotation=45)
    ax.set_yticklabels(states)
    
    ax.set_xlabel('Next State')
    ax.set_ylabel('Current State')
    ax.set_title('Transition Matrix')
    
    # 添加数值标注
    for i in range(mc.n_states):
        for j in range(mc.n_states):
            text = ax.text(j, i, f'{P[i, j]:.2f}',
                        ha='center', va='center', color='black' if P[i, j] < 0.5 else 'white')
    
    plt.colorbar(im, ax=ax)
    plt.tight_layout()
    plt.savefig(save_path, dpi=150)
    print(f"转移矩阵图已保存为 {save_path}")
    plt.close()

# 测试

## 11. 常见问题与易错点

### 11.1 训练问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 稀疏矩阵 | 观测数据少 | 增加数据/高阶马尔可夫 |
| 未覆盖状态 | 测试集有新状态 | 拉普拉斯平滑 |

### 11.2 使用问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 生成重复 | 转移概率集中在某些状态 | 增加随机性 |
| 不收敛 | 转移矩阵不可约 | 检查图连通性 |

### 11.3 典型易错点

1. **行vs列**：P(i,j)是第i行第j列（i→j）
2. **阶数**：一阶只看前一个状态
3. **归一化**：每行和为1
4. **OOV**：未见过的状态

## 13. 练习题与思考题

### 13.1 基础题

**问题**：为什么马尔可夫链的转移矩阵每行和为1？

**答案**：每行表示从当前状态转移到所有可能下一个状态的概率之和，必须为1。

### 13.2 进阶题

**问题**：如果有转移矩阵P，如何求平稳分布？

**答案**：
1. 解方程π = πP
2. 幂迭代：π_{t+1} = π_t P，直到收敛

### 13.3 开放题

**问题**：马尔可夫链在文本生成中有什么局限性？如何改进？
