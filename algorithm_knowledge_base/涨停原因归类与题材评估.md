> 来源线索：本节内容根据原书中关于"涨停原因归类与题材持续性评估"（第3章3.16节）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：对涨停股票按驱动因素（政策/业绩/事件/资金/技术）进行分类，评估所属题材的持续性和扩散力，构建选股评分体系的方法。

**直觉类比**：医生问诊——不是只看"发烧"这个症状（涨停），而是查清病因（涨停原因），判断病程（是普通感冒一天就好，还是慢性病需要长期关注）。

**背景**：A股每天数十只涨停股，同样的涨停板背后可能是完全不同级别的机会。政策驱动的题材可能持续数月，资金纯炒作的"一日游"题材可能次日就反转。区分涨停的质量，是短线交易者的核心能力。

**算法定位**：量化策略 / 另类数据 / 分类评估 / 短线选股。

**前置知识**：A股涨停制度、题材炒作规律、分类算法基础。

## 2. 核心原理

**涨停原因五大分类**：

| 类型 | 典型特征 | 持续性评估 | 优先级 |
|------|----------|-----------|--------|
| 政策驱动 | 国务院/部委级别的产业政策 | 3-6个月 | 最高 |
| 业绩驱动 | 超预期的财报/业绩预告 | 1-3个月 | 高 |
| 事件驱动 | 并购、新产品、订单 | 1-4周 | 中 |
| 资金驱动 | 龙虎榜知名游资集中买入 | 1-5天 | 中低 |
| 技术反弹 | 超跌+放量突破 | 1-3天 | 低 |

**题材持续性评分（5维度各20分）**：
- 题材新颖度：全新概念 > 旧题材反复炒
- 政策支持力度：国务院级别 > 部委 > 地方
- 板块联动效应：同题材多只涨停 > 孤军奋战
- 龙头股强度：封板时间早、封单大
- 资金认可度：龙虎榜净买入大、机构参与

## 3. 数学公式

### 3.1 题材持续性得分
$$
S_{\text{continuity}} = \sum_{i=1}^{5} w_i \cdot \text{Score}_i
$$

### 3.2 板块联动强度
$$
\text{SectorStrength} = \frac{N_{\text{同题材涨停股}}}{N_{\text{全市场涨停股}}} \times 100
$$
> 5% 说明题材较强，有板块效应。

### 3.3 题材生命力阶段判断
- 涨停数递增 + 龙头连板数递增 → 发酵期
- 涨停数高位 + 龙头开始断板 → 退潮期
- 零星涨停 + 无龙头 → 萌芽/尾声

## 4. 训练过程讲解

- 每日收盘后获取涨停股列表
- 人工/NLP辅助标注涨停原因类型
- 同类涨停股归集为题材组
- 按五维度计算持续性得分
- 跟踪各题材的每日涨停数与龙头连板数
- 判断题材所处阶段
- 根据评分排序选股

**关键参数**：题材评分权重可参考历史回测中各类题材的平均持续天数来设定。

## 5. 应用场景

1. **涨停板筛选**：只参与评分>80的高确定性涨停
2. **主线识别**：持续性评分最高的题材=当前市场主线
3. **题材轮动预判**：旧主线评分下降、新题材评分上升→轮动
4. **仓位分配**：高评分题材重仓、低评分题材轻仓或不参与

**适用**：A股题材炒作活跃期
**不适用**：全面熊市(题材都不可持续)、纯粹指数投资

## 6. 优缺点分析

**优点**：逻辑清晰、可操作性强、前瞻性好(提前判断题材持续性)
**缺点**：分类主观性强（政策vs事件有时难以分清）、题材命名不统一、需要大量人工标注或高质量NLP

## 7. 调库实现

```python
"""涨停原因分类 + 题材持续性评估"""
import numpy as np
import pandas as pd

np.random.seed(42)

# ========== 1. 模拟涨停股数据 ==========
n_stocks = 40
reasons = ['政策驱动', '业绩驱动', '事件驱动', '资金驱动', '技术反弹']
topics = ['AI大模型', '低空经济', '固态电池', '房地产', '医药']

df = pd.DataFrame({
    '股票': [f'{600000+i}' for i in range(n_stocks)],
    '涨停原因': np.random.choice(reasons, n_stocks,
                             p=[0.15, 0.20, 0.30, 0.20, 0.15]),
    '题材': np.random.choice(topics, n_stocks),
})

# ========== 2. 模拟各题材的持续性指标 ==========
topic_stats = df.groupby('题材').agg(
    涨停股数=('股票', 'count'),
).reset_index()

topic_stats['政策力度'] = np.random.uniform(0, 1, len(topic_stats))
topic_stats['新颖度'] = np.random.uniform(0, 1, len(topic_stats))
topic_stats['龙头强度'] = np.random.uniform(0, 1, len(topic_stats))

# 综合评分
topic_stats['持续性得分'] = (
    0.25 * topic_stats['涨停股数'] / topic_stats['涨停股数'].max() * 100 +
    0.25 * topic_stats['政策力度'] * 100 +
    0.25 * topic_stats['新颖度'] * 100 +
    0.25 * topic_stats['龙头强度'] * 100
)
print("题材持续性评估:")
print(topic_stats.sort_values('持续性得分', ascending=False).to_string(index=False))

# ========== 3. 可视化 ==========
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['Arial Unicode MS', 'SimHei']
plt.rcParams['axes.unicode_minus'] = False

fig, axes = plt.subplots(1, 3, figsize=(15, 4.5))

# 涨停原因分布
reason_counts = df['涨停原因'].value_counts()
axes[0].pie(reason_counts, labels=reason_counts.index, autopct='%1.0f%%')
axes[0].set_title('涨停原因分布')

# 题材评分
top_sorted = topic_stats.sort_values('持续性得分')
axes[1].barh(top_sorted['题材'], top_sorted['持续性得分'], color='steelblue')
axes[1].set_title('题材持续性得分')

# 各题材涨停数(柱状) + 龙头强度(散点)
x = np.arange(len(topic_stats))
axes[2].bar(x, topic_stats['涨停股数'], alpha=0.7, label='涨停股数')
axes[2].scatter(x, topic_stats['龙头强度'] * topic_stats['涨停股数'].max(),
               c='red', s=80, zorder=5, label='龙头强度(缩放)')
axes[2].set_xticks(x)
axes[2].set_xticklabels(topic_stats['题材'], rotation=30)
axes[2].set_title('各题材涨停股数 & 龙头强度')
axes[2].legend()

plt.tight_layout()
plt.show()
```

## 8-14. 综合章节

**关键公式**：持续性得分 = 涨停密度 × 0.25 + 政策力度 × 0.25 + 新颖度 × 0.25 + 龙头强度 × 0.25

**常见问题**：分类边界模糊(一个涨停可能既有政策又有事件)→ 允许标注多标签，取最强的一个作为主因；题材命名不一致→ 建立标准题材词表；人工标注工作量大→ 用大模型(Few-Shot)自动分类，人工抽查质检

**学习路径**：A股涨停板生态→题材分类体系→NLP自动标注→题材轮动监控

**练习题**：
- 基础：某题材涨停8只、政策力度0.9、新颖度0.8、龙头强度0.7。估算得分。→ (8/假设max=10)×25 + 0.9×25 + 0.8×25 + 0.7×25 = 20+22.5+20+17.5=80。高持续性。
- 进阶：如何判断题材进入"退潮期"？→ 涨停数连续3天递减+龙头开板/炸板增加+新题材开始分流资金。三个信号同时出现时退潮概率>80%。
- 开放：用大模型做自动涨停分类的prompt如何设计？→ "你是一个A股涨停板分析专家。请阅读以下涨停股的相关新闻/公告，判断其主要涨停原因（政策/业绩/事件/资金/技术5选1），并给出0-100分的确定性评分。输出JSON格式。"
