# 值迭代 学习文档

> 动态规划中通过迭代更新值函数来求解最优策略的算法。

## 1. 算法基础认知

值迭代（Value Iteration）是动态规划中用于求解马尔可夫决策过程最优策略的经典算法之一。它通过迭代更新状态值函数来逐步逼近最优值函数，然后从最优值函数中提取最优策略。

**直觉类比**：想象你在玩一个棋类游戏，你不知道每一步的真正价值，但你可以"猜测"每步的价值。然后你通过与对手下棋来验证这些猜测，更新你的估计值。重复这个过程直到你的估计值不再变化。

**历史背景**：值迭代是动态规划的两种核心算法之一，由Bellman在1950年代提出。

**前置知识**：动态规划基础、贝尔曼方程

## 2. 核心原理

值迭代的核心是贝尔曼最优算子。每次迭代对所有状态应用贝尔曼最优更新。

**核心思想**：
- 从初始值函数开始
- 迭代应用贝尔曼最优算子
- 收敛后提取策略

**工作流程**：
```
1. 初始化 V(s) = 0
2. 循环直到收敛：
   对每个状态s:
     V(s) = max_a [R(s,a) + γ∑_s' P(s'|s,a)V(s')]
3. 提取策略 π(s) = argmax_a [R(s,a) + γ∑_s' P(s'|s,a)V(s')]
```

## 3. 数学公式与推导

**贝尔曼最优算子**：
$$T^*(V)(s) = \max_a [R(s,a) + \gamma \sum_{s'} P(s'|s,a) V(s')]$$

**值迭代更新**：
$$V_{k+1}(s) = T^*(V_k)(s) = \max_a [R(s,a) + \gamma \sum_{s'} P(s'|s,a) V_k(s')]$$

**收敛性证明**:
- T(*)是γ-收缩映射：||T(V1) - T(V2)||∞ ≤ γ||V1 - V2||∞
- 由 Banach 不动点定理，值迭代收敛到唯一不动点 V*

**提取策略**：
$$\pi^*(s) = \arg\max_a [R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s')]$$

## 4. 训练过程讲解

**参数说明**：
| 参数 | 作用 | 推荐范围 |
|------|------|----------|
| γ | 折扣因子 | 0.9-0.99 |
| θ | 收敛阈值 | 1e-6 |
| max_iter | 最大迭代次数 | 1000-10000 |

**停止条件**：
- ||V_{k+1} - V_k||_∞ < θ
- 达到最大迭代次数

## 5. 应用场景

- 网格世界导航
- 简单游戏AI
- 资源调度

## 6. 优缺点分析

**优点**：
1. 实现简单直观
2. 收敛性有保证
3. 适用于小规模问题

**缺点**：
1. 每次迭代O(|S||A|)复杂度
2. 需要知道完整模型
3. 对大规模问题不适用

## 7. 调库实现

```python
"""
值迭代算法实现
"""
import numpy as np

def value_iteration(transitions, rewards, gamma=0.9, theta=1e-6, max_iter=10000):
    """
    值迭代算法
    
    参数:
        transitions: [states, actions, next_states] 转移概率
        rewards: [states, actions] 奖励
        gamma: 折扣因子
        theta: 收敛阈值
        max_iter: 最大迭代次数
    
    返回:
        V: 最优值函数
        policy: 最优策略
    """
    n_states, n_actions, _ = transitions.shape
    V = np.zeros(n_states)
    
    for iteration in range(max_iter):
        delta = 0
        
        for s in range(n_states):
            v_old = V[s]
            
            # 计算所有动作的值，取最大
            action_values = rewards[s, :] + gamma * np.sum(
                transitions[s, :, :] * V, axis=1
            )
            V[s] = np.max(action_values)
            
            delta = max(delta, abs(v_old - V[s]))
        
        if delta < theta:
            print(f"值迭代在第{iteration+1}次迭代后收敛，delta={delta:.6f}")
            break
    
    # 提取最优策略
    policy = np.zeros(n_states, dtype=int)
    for s in range(n_states):
        action_values = rewards[s, :] + gamma * np.sum(
            transitions[s, :, :] * V, axis=1
        )
        policy[s] = np.argmax(action_values)
    
    return V, policy

# 测试：网格世界
def create_gridworld_mdp(grid_size=4):
    """创建网格世界MDP"""
    n_states = grid_size * grid_size
    n_actions = 4  # 上，下，左，右
    
    transitions = np.zeros((n_states, n_actions, n_states))
    rewards = np.zeros((n_states, n_actions))
    
    for s in range(n_states):
        row, col = s // grid_size, s % grid_size
        
        for a, (dr, dc) in enumerate([(-1,0), (1,0), (0,-1), (0,1)]):
            new_row = max(0, min(grid_size-1, row + dr))
            new_col = max(0, min(grid_size-1, col + dc))
            next_s = new_row * grid_size + new_col
            
            transitions[s, a, next_s] = 1.0
            
            # 奖励设置
            if (new_row, new_col) == (grid_size-1, grid_size-1):
                rewards[s, a] = 10.0
            elif (new_row, new_col) == (1, 1):
                rewards[s, a] = -10.0
            else:
                rewards[s, a] = -0.01
    
    return transitions, rewards

# 运行
transitions, rewards = create_gridworld_mdp(4)
V, policy = value_iteration(transitions, rewards, gamma=0.9)

print("\n值函数:")
print(V.reshape(4, 4))
print("\n最优策略 (0=上,1=下,2=左,3=右):")
print(policy.reshape(4, 4))
```

## 8. 手工代码实现

```python
"""
值迭代手工实现
"""
import numpy as np

class ValueIterationAgent:
    """值迭代智能体"""
    def __init__(self, n_states, n_actions, gamma=0.9, theta=1e-6):
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma
        self.theta = theta
        
        self.V = np.zeros(n_states)
        self.policy = np.zeros(n_states, dtype=int)
    
    def bellman_optimal_update(self, transitions, rewards):
        """贝尔曼最优更新"""
        V_new = np.zeros(self.n_states)
        
        for s in range(self.n_states):
            best_value = float('-inf')
            
            for a in range(self.n_actions):
                value = rewards[s, a]
                for next_s in range(self.n_states):
                    value += self.gamma * transitions[s, a, next_s] * self.V[next_s]
                
                if value > best_value:
                    best_value = value
            
            V_new[s] = best_value
        
        return V_new
    
    def train(self, transitions, rewards, max_iter=10000):
        """训练"""
        for iteration in range(max_iter):
            V_new = self.bellman_optimal_update(transitions, rewards)
            
            delta = np.max(np.abs(V_new - self.V))
            self.V = V_new
            
            if delta < self.theta:
                print(f"收敛于第{iteration+1}次迭代")
                break
        
        # 提取策略
        for s in range(self.n_states):
            best_action = 0
            best_value = float('-inf')
            
            for a in range(self.n_actions):
                value = rewards[s, a]
                for next_s in range(self.n_states):
                    value += self.gamma * transitions[s, a, next_s] * self.V[next_s]
                
                if value > best_value:
                    best_value = value
                    best_action = a
            
            self.policy[s] = best_action
    
    def get_action(self, state):
        """获取动作"""
        return self.policy[state]

# 测试
n_states = 16
n_actions = 4
gamma = 0.9

transitions = np.zeros((n_states, n_actions, n_states))
rewards = np.zeros((n_states, n_actions))

# 初始化转移和奖励
for s in range(n_states):
    row, col = s // 4, s % 4
    for a, (dr, dc) in enumerate([(-1,0), (1,0), (0,-1), (0,1)]):
        new_row = max(0, min(3, row + dr))
        new_col = max(0, min(3, col + dc))
        next_s = new_row * 4 + new_col
        transitions[s, a, next_s] = 1.0
        
        if (new_row, new_col) == (3, 3):
            rewards[s, a] = 1.0

agent = ValueIterationAgent(n_states, n_actions, gamma)
agent.train(transitions, rewards)

print("V =", agent.V.reshape(4, 4))
print("π =", agent.policy.reshape(4, 4))
```

## 11. 常见问题与易错点

1. **不收敛**：检查γ是否<1
2. **数值不稳定**：检查奖励和转移概率归一化
3. **策略提取错误**：确保V收敛后再提取策略

## 12. 学习总结

值迭代通过迭代应用贝尔曼最优算子来更新值函数，最终收敛到最优值函数。最优策略从最优值函数中提取。

**核心公式**：
$$V_{k+1}(s) = \max_a [R(s,a) + \gamma \sum_{s'} P(s'|s,a) V_k(s')]$$

**与策略迭代对比**：
- 值迭代：每次迭代更新所有状态的值
- 策略迭代：交替进行策略评估和策略改进
