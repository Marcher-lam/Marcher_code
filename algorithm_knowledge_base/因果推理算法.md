# 因果推理算法 学习文档

> 识别变量间的因果关系而非仅仅统计相关性，从而追溯问题的真正根因。

## 1. 算法基础认知

因果推理算法是帮助AI从"相关性"思维上升到"因果性"思维的技术，就像侦探不仅知道谁在现场，还要找出真凶。

### 历史背景

- **2000年**：Pearl提出因果推断框架
- **2019年**：Judea Pearl获图灵奖
- **2022年**：工业因果推理兴起

### 直觉类比

因果推理就像"种菜"：知道浇水多植物会长得好（相关性），但搞清楚是浇水促进了生长（因果性），就能主动优化种植。

### 前置知识

- 概率论基础
- 统计学基础
- Python数据分析

## 2. 核心原理

### 因果与相关的区别

| 相关 | 因果 |
|------|------|
| A大B也大 | A导致B |
| 统计数据 | 可干预 |
| 无法回答"如果" | 可以回答"如果" |

### 三层因果问题

1. **关联**：观察到什么？
2. **干预**：如果这样做会怎样？
3. **反事实**：如果没有做会怎样？

## 3. 数学公式与推导

### 因果效应

$$P(Y|do(X=x)) = \sum_y P(Y|X=x, Z=z) \cdot P(Z=z)$$

### 干预效应

$$\tau = E[Y|X=1, do(X=1)] - E[Y|X=0, do(X=0)]$$

辛普森悖论示例：
- 总趋势：男性治疗成功率更高
- 但分组后：女性和男性都是药物组更高
- 原因：药物组女性更多

## 6. 调库实现

```python
import numpy as np
from scipy import stats

class CausalDiscovery:
    """因果发现"""
    
    def __init__(self, method='pc', alpha=0.05):
        self.method = method
        self.alpha = alpha
        self.graph = {}
        
    def pc_algorithm(self, data):
        """PC算法简化版"""
        n_vars = data.shape[1]
        # 简化的条件独立性检验
        adjacencies = {}
        
        # 检测每对变量
        for i in range(n_vars):
            for j in range(i+1, n_vars):
                corr, p_value = stats.pearsonr(data[:, i], data[:, j])
                if p_value < self.alpha:
                    adjacencies[(i, j)] = corr
                    
        return adjacencies
        
    def fit(self, data):
        """训练"""
        self.graph = self.pc_algorithm(data)
        return self

# 测试
print("=== 因果发现示例 ===")
np.random.seed(42)
data = np.random.randn(1000, 3)
data[:, 2] = data[:, 0] * 0.5 + data[:, 1] * 0.3 + np.random.randn(1000) * 0.1

cd = CausalDiscovery(alpha=0.05)
cd.fit(data)
print("发现的因果关系:")
for k, v in cd.graph.items():
    print(f"  变量{k[0]} -> 变量{k[1]}: corr={v:.3f}")
```

## 7. 手工代码

```python
import numpy as np

class SimpleCausalAnalysis:
    """简化因果分析"""
    
    def __init__(self):
        pass
        
    def compute_partial_corr(self, X, Y, Z):
        """计算偏相关系数"""
        # 残差化
        r_XZ = np.polyfit(Z, X, 1)[0] * Z
        r_YZ = np.polyfit(Z, Y, 1)[0] * Z
        
        res_X = X - r_XZ
        res_Y = Y - r_YZ
        
        # 残差相关
        corr = np.corrcoef(res_X, res_Y)[0, 1]
        
        return corr
        
    def granger_causality(self, X, Y, max_lag=3):
        """格兰杰因果检验"""
        from scipy import stats
        
        # 创建滞后变量
        best_lag = 0
        best_p = 1.0
        
        for lag in range(1, max_lag + 1):
            X_lag = X[:-lag]
            Y_future = Y[lag:]
            
            # 回归
            slope, intercept, r_value, p_value, std_err = stats.linregress(X_lag, Y_future)
            
            if p_value < best_p:
                best_p = p_value
                best_lag = lag
                
        return best_lag, best_p < 0.05

# 测试
if __name__ == "__main__":
    np.random.seed(42)
    
    # 创建数据：X导致Y
    n = 1000
    X = np.random.randn(n)
    Y = X * 0.8 + np.random.randn(n) * 0.2
    
    analyzer = SimpleCausalAnalysis()
    lag, is_causal = analyzer.granger_causality(X, Y, max_lag=3)
    
    print(f"格兰杰因果检验:")
    print(f"  最优滞后: {lag}")
    print(f"  存在因果: {is_causal}")
```

## 9. 模型评估

```python
def evaluate_causal_discovery(pred_edges, true_edges):
    """评估因果发现"""
    true_edges = set(true_edges)
    pred_edges = set(pred_edges)
    
    # 准确率
    correct = len(true_edges & pred_edges)
    total = len(pred_edges)
    precision = correct / total if total > 0 else 0
    
    recall = correct / len(true_edges) if len(true_edges) > 0 else 0
    f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0
    
    print(f"因果发现评估:")
    print(f"  精确率: {precision:.1%}")
    print(f"  召回率: {recall:.1%}")
    print(f"  F1: {f1:.1%}")
    
    return {'precision': precision, 'recall': recall, 'f1': f1}
```
