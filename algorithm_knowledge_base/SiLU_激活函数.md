# SiLU 激活函数 学习文档

> 平滑的非线性激活函数，是现代LLM前馈网络的标准激活选择。

> 来源线索：本节内容根据原书附录C C.2节关于激活函数的讲解整理、扩展与教学化改写。

## 1. 算法基础认知

### 一句话定义
SiLU (Sigmoid Linear Unit, 又称 Swish) 是 x·σ(x) 形式的平滑激活函数，在负区间有轻微的非零输出。

### 直觉类比
ReLU 像一个"要么开门要么完全关门"的粗暴守门员，SiLU 像一个"渐进式开门"的温柔守门员——负面信息不会立刻被完全拒绝，而是被部分衰减。

### 历史背景
SiLU / Swish 于 2017 年由 Google Brain (Ramachandran et al.) 通过神经架构搜索发现。Swish 是其原名（β=1时等价SiLU）。2020年起逐渐取代GELU成为LLM的标准激活函数。

### 算法定位
- **类型**：激活函数 / 非线性函数
- **性质**：神经网络的基本组件

## 2. 核心原理

### 数学定义
$$\text{SiLU}(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}}$$

### 关键特性
- 当x → +∞: SiLU(x) ≈ x（近似线性，无上界）
- 当x → -∞: SiLU(x) ≈ 0（但非精确0，有微小的负值）
- x = 0: SiLU(0) = 0
- 最小值：SiLU(-1.278...) ≈ -0.278

### 与ReLU/GELU的对比
```
ReLU(x)  = max(0, x)           # 负区间=0，有尖角
GELU(x)  ≈ x·Φ(x)             # 基于高斯CDF，平滑但计算复杂
SiLU(x)  = x·σ(x)              # 基于sigmoid，平滑且计算简单
```

## 3. 优缺点分析

| 优点 | 说明 |
|------|------|
| 平滑可微 | 处处可导，梯度流动好 |
| 计算简单 | 比GELU（需高斯CDF）快 |
| 非单调 | 负区间有微小的负输出（有助于表达力） |
| 无上界 | 大正数不会被截断 |

| 缺点 | 说明 |
|------|------|
| 计算比ReLU稍贵 | ReLU只是一个max操作 |
| 负区间太弱 | -0.278的最小值在某些场景不够"抑制" |

## 4-14. 实现、问题、练习

### 调库实现
```python
import torch.nn.functional as F
y = F.silu(x)  # SiLU
```

### 手工实现
```python
def silu(x):
    return x * (1 / (1 + (-x).exp()))  # x * sigmoid(x)
```

### 练习题
**题1**：为什么SiLU在现代LLM中替代了GELU？

**参考答案**：(1) 计算效率——SiLU只需sigmoid和乘法，GELU需要高斯CDF或tanh近似；(2) 建模性能相当——实验表明两者在不同任务上表现相近；(3) 在GPU上SiLU更容易融合为高效kernel。在Qwen3的前馈网络中，SiLU与门控乘法结合成SwiGLU，这是性能提升的核心。
