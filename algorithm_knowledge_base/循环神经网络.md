# 循环神经网络 学习文档

## 1. 算法基础认知
处理序列数据的神经网络，包含循环结构。

## 2. 核心原理
通过隐藏状态传递信息：$h_t = \sigma(W_{xh}x_t + W_{hh}h_{t-1} + b)$

## 3. 数学推导
反向传播通过时间展开（BPTT）计算梯度。

## 4. 训练过程
按时间步展开，逐时间步更新参数。

## 5. 应用场景
- 文本生成
- 语音识别
- 时间序列预测

## 6. 优缺点
优点：处理变长序列；缺点：梯度消失/爆炸

## 7. 代码实现
```python
import torch.nn as nn

rnn = nn.RNN(input_size, hidden_size, num_layers, batch_first=True)
```

```python
import numpy as np

class RNNScratch:
    def __init__(self, input_size, hidden_size):
        self.input_size = input_size
        self.hidden_size = hidden_size
        # Xavier初始化
        self.W_xh = np.random.randn(input_size, hidden_size) * np.sqrt(1.0/input_size)
        self.W_hh = np.random.randn(hidden_size, hidden_size) * np.sqrt(1.0/hidden_size)
        self.W_hy = np.random.randn(hidden_size, output_size) * np.sqrt(1.0/hidden_size)
        self.b_h = np.zeros((1, hidden_size))
        self.b_y = np.zeros((1, output_size))
    
    def forward(self, X):
        T = X.shape[1]  # 时间步
        h = np.zeros((1, self.hidden_size))
        
        for t in range(T):
            x_t = X[:, t, :]
            h = np.tanh(x_t @ self.W_xh + h @ self.W_hh + self.b_h)
        
        y = h @ self.W_hy + self.b_y
        return y, h
```
