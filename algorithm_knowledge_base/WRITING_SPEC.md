# 文档编写规范

## 1. 面向初学者（但不降低深度）
- 使用通俗易懂的语言解释复杂概念
- 从具体例子入手，逐步抽象
- 提供直观的图解和代码示例

## 2. 解释“为什么”
- 不能只写结论，要解释推导过程
- 说明算法动机和设计思想
- 解释数学公式的直观含义

## 3. 数学推导清晰，不跳步
- 关键步骤要详细说明
- 公式推导要完整
- 变量定义要清晰

## 4. 代码要求
- 可运行，无语法错误
- 带详细注释
- 使用scikit-learn（传统算法）或PyTorch（深度学习）
- 代码结构化，模块化

## 5. 风格统一
- 像一本书的章节，不是拼凑内容
- 统一的公式格式和符号
- 统一的代码风格和注释格式
