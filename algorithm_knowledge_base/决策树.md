# 决策树 学习文档

## 1. 算法基础认知
树形结构的分类/回归模型，通过递归划分特征空间。

## 2. 核心原理
使用信息增益、基尼指数选择最优划分特征。

## 3. 数学推导
信息增益：$Gain(D,a) = Entropy(D) - \sum_{v} rac{|D^v|}{|D|}Entropy(D^v)$
基尼指数：$Gini(D) = 1 - \sum_{k=1}^K (p_k)^2$

## 4. 训练过程
递归构建树，直到达到停止条件（最大深度、最小样本数等）。

## 5. 应用场景
- 可解释性要求高的场景
- 特征选择

## 6. 优缺点
优点：可解释、可处理非线性；缺点：容易过拟合

## 8. 手工实现
```python
import numpy as np

class DecisionTreeScratch:
    def __init__(self, max_depth=5):
        self.max_depth = max_depth
    
    def fit(self, X, y):
        self.tree = self._build_tree(X, y, depth=0)
    
    def _build_tree(self, X, y, depth):
        # 简化的递归构建
        n_samples, n_features = X.shape
        if depth >= self.max_depth or n_samples < 2:
            return {'type': 'leaf', 'value': np.argmax(np.bincount(y))}
        
        # 寻找最佳划分
        best_feature, best_threshold = self._find_best_split(X, y)
        
        if best_feature is None:
            return {'type': 'leaf', 'value': np.argmax(np.bincount(y))}
        
        left_idx = X[:, best_feature] <= best_threshold
        right_idx = ~left_idx
        
        return {
            'type': 'node',
            'feature': best_feature,
            'threshold': best_threshold,
            'left': self._build_tree(X[left_idx], y[left_idx], depth+1),
            'right': self._build_tree(X[right_idx], y[right_idx], depth+1)
        }
    
    def _find_best_split(self, X, y):
        # 简化的最佳划分查找
        best_gain = -1
        best_feature, best_threshold = None, None
        
        for feature in range(X.shape[1]):
            thresholds = np.unique(X[:, feature])
            for threshold in thresholds:
                left = y[X[:, feature] <= threshold]
                right = y[X[:, feature] > threshold]
                if len(left) == 0 or len(right) == 0:
                    continue
                gain = self._information_gain(y, left, right)
                if gain > best_gain:
                    best_gain = gain
                    best_feature = feature
                    best_threshold = threshold
        return best_feature, best_threshold
    
    def _information_gain(self, parent, left, right):
        # 简化版信息增益计算
        def entropy(y):
            counts = np.bincount(y)
            probs = counts / len(y)
            return -np.sum([p * np.log2(p) for p in probs if p > 0])
        
        n = len(parent)
        n_l, n_r = len(left), len(right)
        return entropy(parent) - (n_l/n)*entropy(left) - (n_r/n)*entropy(right)
    
    def predict(self, X):
        return np.array([self._predict_sample(x, self.tree) for x in X])
    
    def _predict_sample(self, x, tree):
        if tree['type'] == 'leaf':
            return tree['value']
        if x[tree['feature']] <= tree['threshold']:
            return self._predict_sample(x, tree['left'])
        else:
            return self._predict_sample(x, tree['right'])
```
