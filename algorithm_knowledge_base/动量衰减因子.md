# 动量衰减因子 学习文档

> 捕捉动量效应的衰减信号，在趋势力竭时反向操作——高频交易的制胜法宝。
> 来源线索：本节内容根据原书中关于"高频动量衰减因子开发"（第3章3.12节）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：动量衰减因子通过测量价格动量随时间减弱的速率来预测短期价格反转，是高频反转策略的核心信号。

**直觉类比**：扔出的皮球——初速最快（强动量），但空气阻力让它越来越慢（动量衰减），最终落地甚至反弹（价格反转）。动量衰减因子就是测量"皮球减速的程度"。

**背景**：动量效应是金融市场最稳健的异象之一（2013 年尤金·法玛在诺贝尔奖演讲中承认）。但动量不会永远持续——信息被消化后，动量衰减，价格回归。捕捉这个衰减过程，就能在趋势耗尽时反向操作获利。

**算法定位**：量化因子 / 贝塔策略 / 高频交易 / 反转信号。

**前置知识**：动量因子基础、时间序列分析、高频数据结构。

## 2. 核心原理

**动量衰减的微观机制**：
1. **信息消化**：利好/利空消息推动价格运动，随着消息被市场充分消化，动量减弱
2. **流动性恢复**：大单冲击导致价格短期偏离，做市商和套利者逐步将价格推回均衡
3. **获利了结**：趋势跟随者获利平仓，反向压力增大

**动量衰减测量方法**：
- **一阶差分法**：$\Delta M_t = M_t - M_{t-1}$，连续为负说明衰减
- **半衰期法**：动量值从峰值降到一半所需的时间
- **指数衰减拟合**：$M_t = M_0 \cdot e^{-\lambda t}$，$\lambda$ 越大衰减越快

**信号生成**：
- 测量当前动量的衰减速率
- 衰减速率超过阈值 → 动量即将耗尽 → 准备反向交易
- 配合成交量萎缩确认信号

## 3. 数学公式与推导

### 3.1 动量定义
$$
M_t = \frac{P_t}{P_{t-N}} - 1
$$
N 为回溯窗口（高频中通常 10-100 个 tick/秒）。

### 3.2 衰减率（一阶差分）
$$
D_t = M_t - M_{t-1}
$$
$D_t < 0$ 且数值较大 → 动量在快速衰减。

### 3.3 指数衰减模型
$$
M_t = M_0 \cdot e^{-\lambda t}
$$
取对数：$\ln M_t = \ln M_0 - \lambda t$，用线性回归估计 $\lambda$。
半衰期：$t_{1/2} = \frac{\ln 2}{\lambda}$

### 3.4 衰减强度因子
$$
F_t^{\text{decay}} = -\frac{D_t}{\sigma_D} \quad \text{(Z-score标准化)}
$$
因子值越大，衰减越显著，反转概率越高。

## 4. 训练过程讲解

### 4.1 数据需求
- 高频 tick/秒级价格数据
- 推荐 1 秒或 10 tick 频率
- 至少 1 个月的高频数据用于参数估计

### 4.2 参数选择
| 参数 | 含义 | 推荐范围 |
|------|------|----------|
| N (动量窗口) | 往回看多少期 | 10-100 tick |
| λ 估计窗口 | 衰减率回归窗口 | 20-50 期 |
| 衰减阈值 | 触发反转信号 | 1.5-2.5 σ |
| 持仓周期 | 反转后持有多久 | 5-30 秒 |

### 4.3 信号过滤
- 低波动时不过度交易（信号噪声大）
- 结合成交量萎缩验证（无量衰减更可靠）
- 避开开盘/收盘等流动性异常时段

## 5. 应用场景

1. **高频反转交易**：动量衰减 → 反向开仓 → 价格回归后平仓
2. **做市商库存管理**：识别趋势即将反转，调整买卖报价
3. **TWAP/VWAP 执行优化**：在动量衰减期执行大单以减少冲击
4. **与趋势策略互补**：趋势+反转双策略组合降低整体回撤

**适用**：流动性好的标的（期货主力、大盘股）、高频/日内频率
**不适用**：强趋势行情（动量不衰减持续上涨/下跌）、新闻事件冲击期

## 6. 优缺点分析

### 优点
- 微结构 Alpha：捕捉传统因子看不到的超短期机会
- 与趋势策略互补：降低组合波动
- 逻辑清晰：建立在成熟的动量效应理论基础

### 缺点
- 信号噪声大：高频数据天然多噪声
- 交易成本敏感：反转交易频繁，手续费和滑点可能吃掉利润
- 参数不稳定：不同品种/时段的衰减特性不同

## 7. 调库实现

```python
"""
动量衰减因子调库实现
pandas + numpy 完整实现多衰减测量方法
"""
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['Arial Unicode MS', 'SimHei']
plt.rcParams['axes.unicode_minus'] = False

np.random.seed(42)
n_ticks = 2000

# ========== 1. 模拟高频价格序列 ==========
# 生成有动量+衰减特征的价格
returns = np.random.randn(n_ticks) * 0.0003
# 加入一些动量爆发+衰减的模式
for i in range(0, n_ticks, 200):
    burst_len = np.random.randint(15, 40)
    direction = np.random.choice([1, -1])
    burst = direction * np.linspace(0.003, 0, burst_len)  # 动量逐渐衰减
    end = min(i + burst_len, n_ticks)
    returns[i:end] += burst[:end-i]

price = 100 + np.cumsum(returns)
price = np.maximum(price, 50)

# ========== 2. 计算动量（多种窗口） ==========
for window in [20, 50, 100]:
    df = pd.DataFrame({'price': price})
    df[f'momentum_{window}'] = df['price'].pct_change(window)

# ========== 3. 计算衰减率 ==========
df = pd.DataFrame({'price': price})
df['momentum_30'] = df['price'].pct_change(30)

# 衰减率 = 动量的一阶差分
df['decay_rate'] = df['momentum_30'].diff()

# 衰减强度 = Z-score
df['decay_strength'] = (df['decay_rate'] - df['decay_rate'].rolling(200).mean()) / (
    df['decay_rate'].rolling(200).std() + 1e-8)

# ========== 4. 信号生成 ==========
# 正动量 + 衰减 → 做空（上涨趋势在衰竭）
# 负动量 + 衰减 → 做多（下跌趋势在衰竭）
df['signal'] = 0
df.loc[(df['momentum_30'] > 0.001) & (df['decay_strength'] < -1.5), 'signal'] = -1
df.loc[(df['momentum_30'] < -0.001) & (df['decay_strength'] < -1.5), 'signal'] = 1

# ========== 5. 回测 ==========
df['future_ret'] = df['price'].shift(-15) / df['price'] - 1
df['strategy_ret'] = df['signal'] * df['future_ret']
df = df.dropna()

trade_returns = df.loc[df['signal'] != 0, 'strategy_ret']
win_rate = (trade_returns > 0).mean() if len(trade_returns) > 0 else 0

print(f"信号数: {len(trade_returns)}")
print(f"胜率: {win_rate:.1%}")
print(f"总收益: {df['strategy_ret'].sum():.4f}")

# ========== 6. 可视化 ==========
fig, axes = plt.subplots(2, 1, figsize=(14, 8))

# 价格与信号
ax1 = axes[0]
ax1.plot(df['price'].values, 'gray', linewidth=0.6, alpha=0.7, label='价格')
buy_idx = df.index[df['signal'] == 1]
sell_idx = df.index[df['signal'] == -1]
ax1.scatter(buy_idx, df.loc[buy_idx, 'price'], c='red', s=20, marker='^', label='买入信号', zorder=5)
ax1.scatter(sell_idx, df.loc[sell_idx, 'price'], c='green', s=20, marker='v', label='卖出信号', zorder=5)
ax1.set_title('价格序列与动量衰减交易信号')
ax1.legend(loc='upper left')
ax1.grid(True, alpha=0.3)

# 动量与衰减强度
ax2 = axes[0].twinx()
axes[1].plot(df['momentum_30'].values, 'steelblue', linewidth=0.8, label='动量(30)', alpha=0.7)
ax2.plot(df['decay_strength'].values, 'darkorange', linewidth=0.5, alpha=0.5, label='衰减强度')
ax2.axhline(y=-1.5, color='r', linestyle='--', alpha=0.3)
axes[1].set_title('动量 vs 衰减强度')
axes[1].set_xlabel('Tick序号')
axes[1].set_ylabel('动量')
ax2.set_ylabel('衰减强度(Z-score)')
axes[1].legend(loc='upper left')
ax2.legend(loc='upper right')
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## 8. 手工代码实现

```python
"""
动量衰减因子手工实现
从零实现多种衰减测量方法
"""
import numpy as np


class MomentumDecayFactor:
    """动量衰减因子计算器"""

    def __init__(self, momentum_window=30, decay_window=5):
        self.momentum_window = momentum_window
        self.decay_window = decay_window

    def calc_momentum(self, prices):
        n = len(prices)
        momentum = np.full(n, np.nan)
        for i in range(self.momentum_window, n):
            momentum[i] = prices[i] / prices[i - self.momentum_window] - 1
        return momentum

    def decay_diff(self, momentum):
        """一阶差分衰减率"""
        return np.diff(momentum, prepend=np.nan)

    def decay_exp_lambda(self, momentum, window=20):
        """指数衰减 λ 估计"""
        n = len(momentum)
        lambdas = np.full(n, np.nan)
        for i in range(window, n):
            seg = momentum[i-window:i+1]
            valid = ~np.isnan(seg)
            if valid.sum() > 10:
                t = np.arange(len(seg))[valid]
                y = np.log(np.maximum(seg[valid], 1e-10))
                # 简单线性回归: y = a - λ*t
                a = (np.sum(t*y) - np.sum(t)*np.sum(y)/len(t)) / (np.sum(t**2) - np.sum(t)**2/len(t))
                lambdas[i] = -a
        return lambdas

    def half_life(self, lambdas):
        """半衰期 = ln(2)/λ"""
        return np.log(2) / (np.abs(lambdas) + 1e-8)

    def generate_signal(self, momentum, decay_strength, threshold=1.5):
        signal = np.zeros(len(momentum))
        sig_mask = ~np.isnan(momentum) & ~np.isnan(decay_strength)
        # 正向动量衰减 → 做空
        signal[(momentum > 0.001) & (decay_strength < -threshold)] = -1
        # 负向动量衰减 → 做多
        signal[(momentum < -0.001) & (decay_strength < -threshold)] = 1
        return signal


# ========== 测试 ==========
if __name__ == '__main__':
    np.random.seed(42)
    prices = 100 + np.cumsum(np.random.randn(500) * 0.1)

    mdf = MomentumDecayFactor(momentum_window=20)
    mom = mdf.calc_momentum(prices)
    decay = mdf.decay_diff(mom)
    sig = mdf.generate_signal(mom, decay)

    print(f"信号统计: 买入={np.sum(sig==1)}, 卖出={np.sum(sig==-1)}")
```

## 练习题

**题1**（基础）：某股票10秒内动量从+0.3%衰减到+0.05%，衰减速率约多少？
**参考答案**：$\Delta M$ = 0.0005-0.003 = -0.0025（10秒），每秒衰减约 0.025%。若这是 2σ 以上的异常，应做空。

**题2**（进阶）：为什么要确认"动量方向"后才做衰减反向？直接做多所有衰减信号不行吗？
**参考答案**：衰减只是趋势变弱，不意味着趋势反转。上涨趋势衰减后可能横盘而非下跌。只有"原本有方向+现在衰减"时，反向概率才高。"无方向+衰减"往往只是随机游走噪声。所以必须同时对动量方向施加约束。
