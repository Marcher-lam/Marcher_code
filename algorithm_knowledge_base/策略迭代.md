# 策略迭代 学习文档

> 动态规划中通过交替进行策略评估与策略改进来求解最优策略的算法。

## 1. 算法基础认知

策略迭代（Policy Iteration）是动态规划中用于求解马尔可夫决策过程最优策略的经典算法。它由Howard于1960年提出，通过交替进行策略评估和策略改进来逐步逼近最优策略。

**直觉类比**：想象你在学开车，最初你有一个粗略的驾驶策略（"慢速行驶"）。策略评估阶段，你实际开车并记录每次决策的效果（是否顺利、是否安全）。策略改进阶段，你分析这些结果，调整策略使其更好（"在高速路上应该保持中速"）。重复这个过程直到策略不再变化。

**历史背景**：策略迭代由Howard在1960年的MDP研究中提出，与值迭代并列为动态规划的两种核心算法。

**前置知识**：动态规划基础、贝尔曼方程

## 2. 核心原理

策略迭代的核心是"评估-改进"交替过程。每次迭代包括：
1. **策略评估**：给定策略π，计算值函数V_π
2. **策略改进**：根据V_π更新策略

**核心思想**：通过局部改进逐步达到全局最优。

**收敛性保证**：单调性原理保证每轮迭代策略不退化。

## 3. 数学公式与推导

**策略评估**：
$$V^{\pi}(s) = R(s, \pi(s)) + \gamma \sum_{s'} P(s'|s, \pi(s)) V^{\pi}(s')$$

写成矩阵形式：
$$V^{\pi} = R^{\pi} + \gamma P^{\pi} V^{\pi}$$
$$(I - \gamma P^{\pi})V^{\pi} = R^{\pi}$$

**策略改进**：
$$\pi'(s) = \arg\max_a [R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^{\pi}(s')]$$

**策略迭代算法**：
```
1. 初始化策略π
2. 循环直到策略稳定：
   a) 策略评估：求解V_π
   b) 策略改进：π ← π'
3. 返回最优π和V
```

## 4. 训练过程讲解

**参数含义**：
| 参数 | 作用 |
|------|------|
| γ | 折扣因子 |
| θ | 收敛阈值 |
| max_iter | 最大迭代次数 |

**迭代流程**：
1. 随机或指定初始策略π
2. 策略评估：迭代求解V_π（通常迭代100次或收敛）
3. 策略改进：对每个状态选择最优动作
4. 检查策略是否变化，无变化则停止

## 5. 应用场景

- 机器人控制
- 游戏AI
- 资源调度

## 6. 优缺点分析

**优点**：
1. 收敛效率高（通常比值迭代快）
2. 每次迭代保证策略不退化
3. 适用于中小规模问题

**缺点**：
1. 每次迭代需要遍历所有状态
2. 对大规模问题效率低

## 7. 调库实现

```python
"""
策略迭代算法实现
"""
import numpy as np

def policy_iteration(transitions, rewards, gamma=0.9, theta=1e-6, max_iter=1000):
    """
    策略迭代算法
    
    参数:
        transitions: [states, actions, next_states] 转移概率
        rewards: [states, actions] 奖励
        gamma: 折扣因子
        theta: 收敛阈值
        max_iter: 最大迭代次数
    
    返回:
        V: 值函数
        policy: 最优策略
    """
    n_states, n_actions, _ = transitions.shape
    
    # 随机初始化策略
    policy = np.random.randint(0, n_actions, n_states)
    V = np.zeros(n_states)
    
    for i in range(max_iter):
        # ===== 策略评估 =====
        for _ in range(100):  # 迭代评估
            V_new = np.zeros(n_states)
            for s in range(n_states):
                a = policy[s]
                V_new[s] = rewards[s, a] + gamma * np.sum(
                    transitions[s, a, :] * V
                )
            V = V_new
        
        # ===== 策略改进 =====
        policy_stable = True
        for s in range(n_states):
            old_action = policy[s]
            
            # 计算所有动作的值
            action_values = rewards[s, :] + gamma * np.sum(
                transitions[s, :, :] * V, axis=1
            )
            best_action = np.argmax(action_values)
            policy[s] = best_action
            
            if old_action != best_action:
                policy_stable = False
        
        if policy_stable:
            print(f"策略迭代在第{i+1}次迭代后收敛")
            break
    
    return V, policy

# 测试：网格世界
grid_size = 4
n_states = grid_size * grid_size
n_actions = 4
transitions = np.zeros((n_states, n_actions, n_states))
rewards = np.zeros((n_states, n_actions))

# 构建网格世界MDP
for s in range(n_states):
    row, col = s // grid_size, s % grid_size
    for a, (dr, dc) in enumerate([(-1,0), (1,0), (0,-1), (0,1)]):
        new_row = max(0, min(grid_size-1, row + dr))
        new_col = max(0, min(grid_size-1, col + dc))
        next_s = new_row * grid_size + new_col
        transitions[s, a, next_s] = 1.0
        
        if (new_row, new_col) == (grid_size-1, grid_size-1):
            rewards[s, a] = 1.0
        elif (new_row, new_col) == (1, 1):
            rewards[s, a] = -1.0

V, policy = policy_iteration(transitions, rewards, gamma=0.9)
print("值函数:", V.reshape(4,4))
print("策略:", policy.reshape(4,4))
```

## 8. 手工代码实现

```python
"""
策略迭代手工实现
"""
import numpy as np

class PolicyIterationAgent:
    def __init__(self, n_states, n_actions, gamma=0.9):
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma
        
        self.policy = np.random.randint(0, n_actions, n_states)
        self.V = np.zeros(n_states)
    
    def evaluate_policy(self, env, n_iter=100):
        """策略评估"""
        for _ in range(n_iter):
            V_new = np.zeros(self.n_states)
            for s in range(self.n_states):
                a = self.policy[s]
                next_s, reward, done, _ = env.step(s, a)
                V_new[s] = reward + self.gamma * self.V[next_s] if not done else reward
            self.V = V_new
    
    def improve_policy(self, env):
        """策略改进"""
        policy_stable = True
        for s in range(self.n_states):
            old_action = self.policy[s]
            
            best_action = 0
            best_value = float('-inf')
            
            for a in range(self.n_actions):
                next_s, reward, done, _ = env.step(s, a)
                value = reward + self.gamma * self.V[next_s] if not done else reward
                
                if value > best_value:
                    best_value = value
                    best_action = a
            
            self.policy[s] = best_action
            if old_action != best_action:
                policy_stable = False
        
        return policy_stable
    
    def train(self, env, max_iter=100):
        """训练"""
        for i in range(max_iter):
            self.evaluate_policy(env)
            stable = self.improve_policy(env)
            if stable:
                print(f"第{i+1}次迭代收敛")
                break
```

## 11. 常见问题与易错点

1. **策略评估不充分**：评估次数太少导致策略改进不准。
2. **学习率设置**：γ太大可能导致数值不稳定。
3. **初始化不当**：策略初始化影响收敛速度。

## 12. 学习总结

策略迭代通过交替进行策略评估和策略改进来求解最优策略。每次迭代保证策略不退化，最终收敛到最优策略。

**核心公式**：
- 评估：$V^{\pi} = R^{\pi} + \gamma P^{\pi} V^{\pi}$
- 改进：$\pi'(s) = \arg\max_a [R(s,a) + \gamma P(s,a)V^{\pi}(s)]$
