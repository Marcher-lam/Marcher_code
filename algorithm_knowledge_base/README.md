# 机器学习算法知识库

## 项目介绍
这是一个全面的机器学习算法知识库，涵盖监督学习、无监督学习、深度学习和强化学习四大类，包含40+种核心算法。

## 学习路径图

### 初级阶段（回归与分类基础）
```
线性回归 → 逻辑回归 → K近邻法 → 朴素贝叶斯 → 决策树 → 支持向量机
```

### 中级阶段（集成与优化）
```
随机森林 → 梯度提升 → 神经网络基础 → 优化算法(Adam) → 损失函数
```

### 高级阶段（深度学习）
```
卷积神经网络 → 循环神经网络 → LSTM → Transformer → 注意力机制
```

### 强化学习阶段
```
马尔可夫决策过程 → 多臂老虎机 → 价值方法 → 策略方法 → DQN → PPO
```

## 算法分类

### 监督学习（30+算法）
- **回归**：线性回归、岭回归、Lasso、多项式回归
- **分类**：逻辑回归、朴素贝叶斯、决策树、CART、随机森林、梯度提升、SVM
- **排序/结构预测**：HMM、CRF、条件随机场

### 无监督学习（10+算法）
- **聚类**：K-means、层次聚类
- **降维**：PCA、奇异值分解、LDA
- **话题模型**：LSA、LDA、PLSA
- **生成模型**：VAE、GAN、扩散模型

### 深度学习（15+算法）
- **前馈网络**：MLP、ResNet、激活函数
- **卷积网络**：CNN、AlexNet、Inception
- **循环网络**：RNN、LSTM、GRU、双向RNN
- **Transformer系列**：Transformer、GPT、BERT、Attention
- **生成模型**：VAE、GAN、扩散模型

### 强化学习（10+算法）
- **基础**：MDP、动态规划、蒙特卡罗
- **策略优化**：REINFORCE、A3C、PPO、TRPO
- **值函数方法**：Q-learning、DQN、SARSA
- **探索**：多臂老虎机、UCB、汤普森采样

### 学习建议

#### 1. 从基础开始
- 先掌握线性回归、逻辑回归、KNN等基础算法
- 理解监督学习的三要素：模型、策略、算法

#### 2. 循序渐进
- 传统机器学习 → 深度学习 → 强化学习
- 每学完一类算法，完成对应的练习题

#### 3. 理论与实践结合
- 阅读算法理论文档
- 运行配套代码示例
- 尝试手工实现核心算法

#### 4. 项目驱动
- 选择一个应用领域（如图像分类、文本生成）
- 组合使用多种算法解决实际问题

## 算法文档格式

每个算法文档包含以下14个部分：
1. 算法基础认知
2. 核心原理
3. 数学公式与推导
4. 训练过程讲解
5. 应用场景
6. 优缺点分析
7. 调库实现（Python + 完整代码）
8. 手工代码实现（核心算法手写）
9. 可视化与结果理解
10. 模型评估
11. 常见问题与易错点
12. 学习总结
13. 练习题与思考题（含答案）
14. 学习路径建议
