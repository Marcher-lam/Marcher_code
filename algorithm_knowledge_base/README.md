# 算法知识库

> 一套系统化、高质量的机器学习与深度学习算法学习文档

## 项目简介

这是一个完整的算法学习知识库，涵盖了从传统机器学习到现代深度学习的核心算法。每个算法都配有详细的数学推导、代码实现和学习指导。

### 特色

- **系统化**：从基础到高级，循序渐进
- **深入浅出**：既有理论深度，又有实践代码
- **即学即用**：所有代码可直接运行
- **结构统一**：像一本专业书籍，而非拼凑内容

## 项目结构


## 如何使用本知识库

### 1. 确定学习目标

如果你是：
- **初学者**：从 `roadmap.md` 的初级路径开始
- **有一定基础**：按需查阅特定算法文档
- **准备面试**：重点关注每个算法的"优缺点分析"和"常见问题"

### 2. 阅读建议

每个算法文档包含14个章节，建议阅读顺序：

| 优先级 | 章节 | 说明 |
|--------|------|------|

| ⭐⭐⭐ | 2. 核心原理 | 理解算法思想 |

## 算法分类概览

### 传统机器学习
- **回归算法**：线性回归、岭回归、LASSO回归、多项式回归
- **分类算法**：感知机、逻辑回归、朴素贝叶斯、支持向量机
- **树模型**：决策树、ID3、C4.5、CART、AdaBoost、GBDT
- **聚类算法**：K-Means
- **降维算法**：PCA、LDA、SVD、NMF
- **概率图模型**：HMM、CRF

### 深度学习
- **神经网络基础**：多层感知机、前馈神经网络、反向传播
- **卷积网络**：CNN、残差网络
- **循环网络**：RNN、LSTM、GRU、DRNN
- **注意力机制**：Attention、MHA、Transformer
- **生成模型**：AE、VAE、GAN、DCGAN、DDPM

### 自然语言处理
- **词表示**：One-Hot、TF-IDF、Word2Vec、GloVe
- **预训练模型**：GPT、BERT

### 强化学习
- **基础**：MDP、多臂老虎机、UCB、Thompson Sampling
- **值函数方法**：蒙特卡洛、TD、SARSA、Q-Learning、DQN
- **策略梯度**：REINFORCE、PPO、A2C、ACER
- **Actor-Critic**：DDPG、SAC、TD3

## 学习建议

1. **不要跳过数学**：理解公式推导是深入理解算法的关键
2. **动手实践**：每个算法都要亲自跑通代码
3. **对比学习**：相似算法要对比理解（如LASSO vs 岭回归）
4. **关注细节**：注意"常见问题与易错点"章节
5. **完成练习**：练习题帮助巩固理解
