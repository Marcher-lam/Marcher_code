# 供应链管理 学习文档

> 多智能体强化学习在供应链中的应用。

## 1. 算法基础认知

供应链管理（Supply Chain Management, SCM）是将多智能体强化学习应用于供应链网络优化的方法，研究如何协调供应商、制造商、分销商和客户之间的决策。

**前置知识**：多智能体强化学习

## 2. 核心原理

- 每个节点作为智能体
- 协作学习最优决策
- 适应需求变化

## 3. 数学公式

每个节点的Q值更新：
$$Q_i(s,a) \leftarrow (1-\alpha)Q_i(s,a) + \alpha[R_i + \gamma \max_{a'} Q_i(s',a')]$$

## 4. 应用场景

- 库存管理
- 订单分配
- 物流优化
