# 舆情监控与事件驱动分析 学习文档

> 用NLP和AI构建舆情雷达系统，在重大事件发生瞬间捕捉交易机会。
> 来源线索：本节内容根据原书中关于"舆情监控与事件驱动分析"（第3章3.14节）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：舆情监控与事件驱动分析是通过NLP技术对新闻、社交媒体、公告等非结构化文本进行实时情感分析和事件识别，捕捉事件驱动型交易机会的方法体系。

**直觉类比**：雷达预警系统——全天候扫描天空，一旦探测到目标（重大事件），立即评估威胁等级（影响力评分），触发响应程序（交易决策）。

**背景**：市场对重大事件的反应往往在几秒到几分钟内完成。传统人工阅读新闻的方式远远跟不上高频事件驱动交易的需求。NLP大模型的出现使实时文本理解成为可能。

**算法定位**：量化策略 / 另类数据 / NLP应用 / 事件驱动。

**前置知识**：NLP基础（分词、情感分析）、API调用、事件驱动策略概念。

## 2. 核心原理

**舆情数据源分类**：
1. **权威新闻**：财联社、华尔街见闻、Reuters、Bloomberg——速度快、可信度高
2. **公司公告**：交易所公告、年报/季报——确定性高但有延迟
3. **社交媒体**：微博、雪球、Twitter——速度快但噪声大
4. **行业论坛**：淘股吧、雪球——包含专业投资者观点

**事件驱动流程**：
文本采集→NLP处理(分词/实体识别/情感)→事件分类(利好/利空)→影响力评分→时效性权重→信号生成→执行

**信息时效性衰减**：
$$
W(t) = e^{-\lambda(t - t_0)}
$$
新闻发出后，价值随时间指数衰减。$\lambda$ 越大，衰减越快。

## 3. 数学公式

### 3.1 情感得分
每篇文本的情感极性：[-1, 1]
$$
\text{sentiment} = \frac{\text{pos\_score} - \text{neg\_score}}{\text{pos\_score} + \text{neg\_score} + 1}
$$

### 3.2 事件影响力评分
$$
\text{Impact} = \text{sentiment} \times \text{source\_weight} \times \text{freshness} \times \text{relevance}
$$

其中 source_weight(信源权重)：官媒>财经媒体>自媒体

### 3.3 综合信号强度
多个事件叠加：
$$
\text{Signal} = \sum_i \text{Impact}_i \times W(t - t_i)
$$

## 4. 训练过程讲解

**数据采集**：
- 新闻API（财联社、华尔街见闻等RSS/API）
- 爬虫（需注意合规）
- 关键词过滤（公司名、行业术语、政策关键词）

**预处理**：文本清洗(去HTML)、中文分词(jieba)、去停用词

**情感模型选择**：SnowNLP(快速轻量)、BERT微调(准确率高但需GPU)

**信号过滤**：多源交叉验证(单一来源不可信)、相关性筛选(与持仓相关的才处理)

## 5. 应用场景

1. **突发新闻套利**：政策发布/业绩预告发布→第一时间判断方向→快速下单
2. **情绪择时**：整体舆情偏向正面→看多；偏向负面→看空/减仓
3. **黑天鹅预警**：负面舆情急剧升温→紧急减仓
4. **题材热度监控**：某题材讨论量激增→可能成为主线

**适用**：对新闻敏感的股票/期货、短线/事件驱动策略
**不适用**：低频长期投资、纯技术分析策略

## 6. 优缺点分析

**优点**：信息优势(比人工快)、覆盖面广(7×24监控)、可量化(信号可回测)
**缺点**：噪声多(社交媒体假消息)、语言歧义(反讽/隐喻)、时效性要求高

## 7. 调库实现

```python
"""
舆情监控与事件驱动分析
模拟舆情数据 + 情感分析 + 事件评分 + 信号生成
"""
import numpy as np
import pandas as pd
from datetime import datetime, timedelta

np.random.seed(42)

# ========== 1. 模拟舆情数据流 ==========
n_events = 200
sources = ['财联社', '华尔街见闻', '公司公告', '微博', '雪球']
source_weights = {'财联社': 1.0, '华尔街见闻': 0.9, '公司公告': 1.2,
                  '微博': 0.3, '雪球': 0.5}
now = datetime.now()

events = pd.DataFrame({
    'time': [now - timedelta(minutes=np.random.randint(0, 480)) for _ in range(n_events)],
    'source': np.random.choice(sources, n_events),
    'sentiment_score': np.random.uniform(-1, 1, n_events),
    'stock_code': np.random.choice(['000001', '600519', '300750'], n_events),
})

# 按时间排序
events = events.sort_values('time').reset_index(drop=True)

# ========== 2. 计算事件影响力 ==========
events['source_w'] = events['source'].map(source_weights)

# 时效性衰减（最新的事件权重最高）
latest_time = events['time'].max()
events['freshness'] = np.exp(-0.01 * (latest_time - events['time']).dt.total_seconds() / 60)

# 相关性（简化为随机 0.5-1.0）
events['relevance'] = np.random.uniform(0.5, 1.0, n_events)

# 综合影响力
events['impact'] = (events['sentiment_score'] * events['source_w'] *
                    events['freshness'] * events['relevance'])

# ========== 3. 按股票聚合信号 ==========
stock_signals = events.groupby('stock_code').agg({
    'impact': 'sum',
    'sentiment_score': 'mean',
    'time': 'count'
}).rename(columns={'time': 'event_count'})

stock_signals['signal'] = np.sign(stock_signals['impact'])
stock_signals['strength'] = np.abs(stock_signals['impact'])

print("舆情信号汇总:")
print(stock_signals.round(3).to_string())

# ========== 4. 可视化 ==========
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['Arial Unicode MS', 'SimHei']
plt.rcParams['axes.unicode_minus'] = False

fig, axes = plt.subplots(1, 3, figsize=(15, 4.5))

# 时间线上的事件分布
axes[0].scatter(events['time'], events['impact'],
                c=events['sentiment_score'], cmap='RdYlGn', alpha=0.6, s=20)
axes[0].axhline(y=0, color='gray', linestyle='--', alpha=0.3)
axes[0].set_title('事件时间线（颜色=情感方向）')
axes[0].set_ylabel('影响力')

# 信源分布
src_counts = events['source'].value_counts()
axes[1].pie(src_counts, labels=src_counts.index, autopct='%1.0f%%')
axes[1].set_title('舆情信源分布')

# 股票信号强度
colors_sig = ['g' if x > 0 else 'r' for x in stock_signals['impact']]
axes[2].bar(stock_signals.index, stock_signals['impact'], color=colors_sig, alpha=0.7)
axes[2].axhline(y=0, color='k')
axes[2].set_title('各股票综合信号强度')
axes[2].set_ylabel('综合影响力')

plt.tight_layout()
plt.show()
```

## 8. 手工代码实现

```python
"""舆情分析手工实现"""
import numpy as np
import re

class SimpleSentimentAnalyzer:
    """简化的情感分析器（基于关键词词典）"""

    def __init__(self):
        # 简化情感词典
        self.pos_words = {'增长', '利好', '突破', '超预期', '涨停', '回购', '增持',
                         '利润', '收入', '政策支持', '复苏', '新高', '中标'}
        self.neg_words = {'下跌', '利空', '亏损', '减持', '跌停', '爆雷', '处罚',
                         '下滑', '退市', '风险', '诉讼', '调查'}

    def analyze(self, text):
        """简单关键词匹配情感分析"""
        pos_count = sum(1 for w in self.pos_words if w in text)
        neg_count = sum(1 for w in self.neg_words if w in text)
        total = pos_count + neg_count
        if total == 0:
            return 0.0, '中性'
        score = (pos_count - neg_count) / total
        if score > 0.2: label = '积极'
        elif score < -0.2: label = '消极'
        else: label = '中性'
        return score, label


class EventDrivenSignalGenerator:
    """事件驱动信号生成器"""

    def __init__(self, sentiment_analyzer, decay_lambda=0.05):
        self.analyzer = sentiment_analyzer
        self.decay_lambda = decay_lambda
        self.event_buffer = []

    def ingest(self, text, source_weight, timestamp):
        """摄入一条舆情"""
        sentiment, label = self.analyzer.analyze(text)
        self.event_buffer.append({
            'timestamp': timestamp,
            'sentiment': sentiment,
            'source_weight': source_weight,
        })

    def get_signal(self, current_time, lookback_minutes=30):
        """计算当前时点的综合信号"""
        total_impact = 0
        for evt in self.event_buffer:
            age_min = (current_time - evt['timestamp']).total_seconds() / 60
            if age_min < 0 or age_min > lookback_minutes:
                continue
            freshness = np.exp(-self.decay_lambda * age_min)
            total_impact += evt['sentiment'] * evt['source_weight'] * freshness
        return total_impact


# 测试
if __name__ == '__main__':
    from datetime import datetime, timedelta
    analyzer = SimpleSentimentAnalyzer()
    generator = EventDrivenSignalGenerator(analyzer)

    now = datetime.now()
    # 模拟几条新闻
    generator.ingest("公司发布业绩预告，净利润增长50%超预期", 1.0, now - timedelta(minutes=5))
    generator.ingest("股东公告减持1%股份", 1.0, now - timedelta(minutes=2))

    signal = generator.get_signal(now)
    print(f"综合信号: {signal:.3f}", "→ 看多" if signal > 0 else "→ 看空/谨慎")
```

## 9-14. 综合章节

**关键公式**：事件影响力 = 情感得分 × 信源权重 × 时效性 × 相关性

**常见问题**：假新闻/谣言 → 多源交叉验证+信源可信度权重；情感误判（"利润下滑收窄"被判断为负面）→ 需要上下文理解而非简单关键词匹配→用BERT微调；延迟导致信号过时 → 减少链路上的延迟、优先使用API直连而非爬虫

**学习路径**：基础NLP（分词/情感）→ 大模型微调→ 实时数据管道(Spark/Kafka)→ 多模态事件融合

**练习题**：
- 基础：一条新闻的情感分为0.7、信源权重1.0、5分钟后新鲜度=exp(-0.01×5)=0.95、相关性=0.9。影响力=? → 0.7×1.0×0.95×0.9=0.60
- 进阶：如何处理"利好出尽是利空"这类反直觉走势？→ 引入市场的预期差建模——市场对事件的预期 vs 实际结果，预期已经充分price in时，利好消息可能反而触发获利了结
- 开放：如何用大模型替代简单关键词匹配做情感分析？→ 提示词："分析以下财经新闻的情感倾向(积极/消极/中性)，并给出0-100的影响力度分"，利用大模型的理解能力进行few-shot prompt
