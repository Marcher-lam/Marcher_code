# 对比学习 学习文档

> 通过样本相似性对比，无监督学习特征表示

**来源线索：** 第8章 8.1节（full.md lines 5295-5580）

## 1. 算法基础认知

对比学习（Contrastive Learning）是一种自监督学习（Self-Supervised Learning）方法，其核心思想是通过构建正负样本对，让模型学会区分相似和不相似的数据，从而在不需要人工标注的情况下学习到有用的特征表示。对比学习的核心目标是：在特征空间中，让相似的样本（正样本对）彼此靠近，让不相似的样本（负样本对）彼此远离。

在传统的监督学习中，我们需要大量的标注数据（如ImageNet的1000类、130万张标注图像）来训练模型。然而，标注数据的获取成本高昂且耗时。对比学习打破了这一限制：它利用数据本身的结构（如同一张图像的不同增强视图、同一段文本的不同上下文等）自动生成监督信号，无需人工标注。

对比学习的工作流程可以概括为三个步骤：
1. **数据增强/采样：** 对原始数据施加不同的变换（如裁剪、颜色抖动、旋转等），生成多个视图（views）。同一原始数据的不同视图构成正样本对，不同原始数据的视图构成负样本对。
2. **特征提取：** 使用一个编码器网络（如CNN、Transformer）将输入数据映射到特征空间（embedding space）。
3. **对比损失：** 使用对比损失函数（如InfoNCE、Triplet Loss、Contrastive Loss等）训练编码器，使得正样本对的特征相似度最大化，负样本对的特征相似度最小化。

对比学习的优势在于：它学习到的特征表示具有很强的泛化能力，可以迁移到各种下游任务（如分类、检测、分割等）。例如，SimCLR在ImageNet上通过对比学习预训练后，在线性评估（只训练一个线性分类器）下可以达到76.5%的准确率，接近监督学习的效果。此外，对比学习的特征是"任务无关"的，同一个预训练模型可以适应多个不同的下游任务，大大降低了针对每个任务重新训练的成本。

## 2. 核心原理

对比学习的核心原理基于一个简单而深刻的直觉：**相似的样本在特征空间中应该靠近，不相似的样本应该远离**。这个想法与人类的学习方式类似：我们通过观察和比较不同的事物，逐渐学会哪些事物是相似的，哪些是不同的。

**核心组件：**

1. **编码器（Encoder）：** 一个神经网络，将输入数据 $x$ 映射到特征向量 $f(x) \in \mathbb{R}^d$。通常使用深度卷积网络（如ResNet）处理图像，或使用Transformer处理文本。

2. **投影头（Projection Head）：** 一个额外的神经网络，将编码器输出 $f(x)$ 进一步映射到对比学习空间 $g(f(x)) \in \mathbb{R}^{d'}$。投影头通常使用简单的MLP（多层感知机），它的作用是分离"表征学习"和"对比任务"：投影头后的特征用于对比损失，而编码器学到的特征用于下游任务。

3. **数据增强（Data Augmentation）：** 对原始数据 $x$ 施加随机变换 $\mathcal{T}$，生成不同的视图：
   $$x_i = \mathcal{T}(x), \quad x_j = \mathcal{T}'(x)$$
   对于同一原始数据 $x$，其不同视图 $x_i$ 和 $x_j$ 构成正样本对；对于不同的原始数据 $x$ 和 $x'$，其视图 $x_i$ 和 $x'_j$ 构成负样本对。

4. **对比损失（Contrastive Loss）：** 最常用的是InfoNCE损失（Noise Contrastive Estimation）：
   $$\mathcal{L}_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j)/\tau)}{\sum_{k=1}^{2N} \mathbb{1}_{[k \neq i]} \exp(\text{sim}(z_i, z_k)/\tau)}$$
   其中 $z_i = g(f(x_i))$, $z_j = g(f(x_j))$ 是正样本对的特征，$\tau$ 是温度参数（temperature），$\text{sim}(\cdot, \cdot)$ 是相似度度量（通常是余弦相似度）。

**训练过程：**

在每轮训练中，对于一个批次的数据 ${x_1, x_2, ..., x_N}$：
1. 对每个 $x_i$，生成两个增强视图：$x_{i,1} = \mathcal{T}(x_i)$, $x_{i,2} = \mathcal{T}'(x_i)$
2. 通过编码器获得特征：$h_{i,1} = f(x_{i,1})$, $h_{i,2} = f(x_{i,2})$
3. 通过投影头获得对比特征：$z_{i,1} = g(h_{i,1})$, $z_{i,2} = g(h_{i,2})$
4. 计算对比损失：对于正样本对 $(z_{i,1}, z_{i,2})$，将同一批次所有其他样本作为负样本
5. 反向传播，更新编码器 $f$ 和投影头 $g$ 的参数

**为什么对比学习有效？**

从信息论角度看，对比学习最大化正样本对之间的互信息（Mutual Information）：
$$\max I(v_1; v_2) = \mathbb{E}_{p(v_1, v_2)} \left[ \log \frac{p(v_1, v_2)}{p(v_1)p(v_2)} \right]$$
InfoNCE损失是互信息下界的一个估计器。通过最大化不同视图间的互信息，编码器学会了捕获数据中最本质、最不变的特征（如物体的形状、类别等），而忽略不重要的细节（如光照、姿态等）。

**负样本的重要性：**

负样本在对比学习中起着关键作用。直观理解：如果没有负样本，模型可以简单地让所有样本的特征都映射到同一个点（或非常接近的点），从而轻松"骗过"损失函数。负样本迫使模型学习到具有区分度的特征，将不同的样本推开。因此，负样本的数量和质量直接影响对比学习的效果——更多的负样本通常带来更好的特征质量。

## 3. 数学公式与推导

对比学习的数学基础主要围绕InfoNCE损失展开。我们来详细推导。

**符号定义：**

- 批次大小：$N$
- 每个样本的2个增强视图，总计 $2N$ 个视图
- 编码器：$f_\theta(\cdot)$，参数 $\theta$
- 投影头：$g_\phi(\cdot)$，参数 $\phi$
- 对于样本 $i$，两个视图的特征：$z_i = g(f(x_{i,1}))$, $z_j = g(f(x_{i,2}))$

**余弦相似度：**

使用余弦相似度计算两个特征向量的相似度：
$$\text{sim}(z_i, z_j) = \frac{z_i^T z_j}{\|z_i\| \|z_j\|}$$

**温度参数 $\tau$：**

温度参数控制相似度分布的"尖锐"程度：
- $\tau \to 0$：模型会非常关注最难区分的负样本
- $\tau \to \infty$：所有负样本的权重趋于均匀

**InfoNCE损失推导：**

对于正样本对 $(z_i, z_j)$，InfoNCE损失定义为：
$$\mathcal{L}_{i,j} = -\log \frac{\exp(z_i^T z_j / (\tau \|z_i\| \|z_j\|))}{\sum_{k=1}^{2N} \mathbb{1}_{[k \neq i]} \exp(z_i^T z_k / (\tau \|z_i\| \|z_k\|))}$$

简化表示（假设特征已L2归一化，即 $\|z\| = 1$）：
$$\mathcal{L}_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j)/\tau)}{\sum_{k \neq i} \exp(\text{sim}(z_i, z_k)/\tau)}$$

**分母的构成：**

在实际实现中，对于一个批次 ${z_1, z_2, ..., z_{2N}}$（其中 $z_{2k-1}$ 和 $z_{2k}$ 是样本 $k$ 的两个视图），对于 $z_i$（样本 $i$ 的视图1），其正样本是 $z_{i+1}$（样本 $i$ 的视图2），负样本是批次中所有其他 $2N-2$ 个视图。

因此，InfoNCE损失可以写为：
$$\mathcal{L}_{i} = -\log \frac{\exp(z_i \cdot z_{i+1} / \tau)}{\exp(z_i \cdot z_{i+1} / \tau) + \sum_{k \neq i, i+1} \exp(z_i \cdot z_k / \tau)}$$

**对称损失：**

由于每个样本有两个视图，我们通常计算对称损失：
$$\mathcal{L}_{\text{total}} = \frac{1}{2N} \sum_{i=1}^{N} \left( \mathcal{L}_{i, 2i-1 \to 2i} + \mathcal{L}_{i, 2i \to 2i-1} \right)$$

即对于样本 $i$，既考虑用视图1作为锚点、视图2作为正样本，也考虑用视图2作为锚点、视图1作为正样本。

**对比损失与互信息的关系：**

InfoNCE损失是互信息 $I(X; Y)$ 的下界估计器。具体来说：
$$I(x; y) \geq \log(N) - \mathcal{L}_{\text{InfoNCE}}$$

证明（简化版）：
考虑 $N$ 个样本，其中 $x$ 和 $y$ 是正样本对（来自同一原始数据），其余 $N-1$ 个是负样本对。根据NCE（Noise Contrastive Estimation）原理，通过训练一个二元分类器来区分正样本和负样本，可以估计密度比 $p(x|y)/p(x)$，进而估计互信息。InfoNCE损失正是这个二元分类的负对数似然：
$$\mathcal{L} = -\mathbb{E} \left[ \log \frac{p(x|y)}{p(x|y) + (N-1)p(x)} \right] \approx \log(N) - I(x; y)$$

**梯度分析：**

对InfoNCE损失求导，可以得到正样本和负样本的梯度贡献：
$$\frac{\partial \mathcal{L}}{\partial z_i} = \frac{1}{\tau} \left( - \frac{z_j}{\exp(\cdot)} - \sum_{k \neq i,j} \frac{\exp(z_i \cdot z_k / \tau)}{\sum} z_k + \frac{\sum_{k \neq i} \exp(z_i \cdot z_k / \tau)}{\sum} z_i \right)$$

直观解释：
- 第一项（正样本）：拉近正样本（梯度指向 $z_j$）
- 第二项（负样本）：推远负样本（梯度指向远离 $z_k$ 的方向）
- 第三项（正则化）：保持特征向量模长

## 4. 训练过程讲解

对比学习的训练过程与监督学习有所不同，主要在于数据准备和损失计算方式。

**完整训练流程：**

```python
# ========== 1. 数据准备 ==========
# 定义数据增强（对于对比学习至关重要）
contrastive_transform = transforms.Compose([
    transforms.RandomResizedCrop(32, scale=(0.08, 1.0)),  # 随机裁剪
    transforms.RandomHorizontalFlip(),  # 随机水平翻转
    transforms.ColorJitter(0.4, 0.4, 0.4, 0.1),  # 颜色抖动
    transforms.RandomGrayscale(p=0.2),  # 随机灰度化
    transforms.ToTensor(),
    transforms.Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))
])

# 创建对比学习数据集（每个样本生成两个增强视图）
class ContrastiveDataset(Dataset):
    def __init__(self, base_dataset, transform):
        self.base_dataset = base_dataset
        self.transform = transform
    
    def __getitem__(self, idx):
        img, _ = self.base_dataset[idx]  # 忽略标签，自监督学习
        # 生成两个不同的增强视图
        view1 = self.transform(img)
        view2 = self.transform(img)
        return view1, view2
    
    def __len__(self):
        return len(self.base_dataset)

# ========== 2. 初始化模型 ==========
# 编码器 + 投影头
encoder = ResNetEncoder()  # 输出维度如128
projection_head = ProjectionHead(input_dim=128, output_dim=64)

# ========== 3. 定义对比损失 ==========
class NTXentLoss(nn.Module):
    def __init__(self, temperature=0.5):
        super().__init__()
        self.temperature = temperature
        self.cosine_similarity = nn.CosineSimilarity(dim=-1)
    
    def forward(self, z_i, z_j):
        # z_i, z_j: [batch_size, feature_dim]
        batch_size = z_i.size(0)
        
        # L2归一化（确保余弦相似度计算正确）
        z_i = F.normalize(z_i, dim=1)
        z_j = F.normalize(z_j, dim=1)
        
        # 计算正样本相似度
        pos_sim = self.cosine_similarity(z_i, z_j) / self.temperature  # [batch_size]
        
        # 计算负样本相似度（所有样本对之间）
        # 构造矩阵：[2*batch_size, feature_dim]
        z = torch.cat([z_i, z_j], dim=0)  # [2*batch_size, feature_dim]
        sim_matrix = torch.mm(z, z.T) / self.temperature  # [2*batch_size, 2*batch_size]
        
        # 构造标签：对于每个样本，其正样本是另一个视图
        labels = torch.arange(batch_size, device=z_i.device)
        labels = torch.cat([labels + batch_size, labels], dim=0)  # [2*batch_size]
        
        # 构造logits：排除自身（对角线元素）
        mask = torch.eye(2*batch_size, device=z_i.device).bool()
        sim_matrix = sim_matrix[~mask].view(2*batch_size, -1)  # 移除对角线
        
        # 交叉熵损失
        loss = F.cross_entropy(sim_matrix, labels)
        return loss

criterion = NTXentLoss(temperature=0.5)

# ========== 4. 优化器 ==========
optimizer = optim.Adam(list(encoder.parameters()) + list(projection_head.parameters()), 
                       lr=1e-3)

# ========== 5. 训练循环 ==========
encoder.train()
projection_head.train()

for epoch in range(num_epochs):
    total_loss = 0.0
    
    for view1, view2 in dataloader:  # 每个batch包含2个视图
        view1, view2 = view1.cuda(), view2.cuda()
        
        optimizer.zero_grad()
        
        # 前向传播：通过编码器和投影头
        h_i = encoder(view1)
        z_i = projection_head(h_i)
        
        h_j = encoder(view2)
        z_j = projection_head(h_j)
        
        # 计算对比损失
        loss = criterion(z_i, z_j)
        
        # 反向传播
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item()
    
    avg_loss = total_loss / len(dataloader)
    print(f"Epoch [{epoch+1}/{num_epochs}], Loss: {avg_loss:.4f}")
```

**关键注意事项：**

1. **数据增强的选择：** 数据增强是对比学习的核心。增强应该保留语义信息（如裁剪、颜色抖动），但不能太弱（否则任务太简单）或太强（否则破坏语义）。

2. **温度参数 $\tau$：** 通常设置在0.5-1.0之间。较小的 $\tau$ 会使损失更关注困难样本（hard negatives），较大的 $\tau$ 会使分布更平滑。

3. **L2归一化：** 在计算对比损失前，通常需要对特征进行L2归一化，使得余弦相似度在[-1, 1]范围内。

4. **负样本数量：** InfoNCE损失中，负样本数量等于 `2*batch_size - 2`。更大的批次大小可以提供更多的负样本，通常带来更好的特征质量。

5. **投影头的作用：** 训练时，我们使用投影头的输出 $z = g(f(x))$ 计算对比损失；但在下游任务中，我们只使用编码器的输出 $h = f(x)$ 作为特征。这是因为投影头帮助分离了"对比任务"和"表征学习"，使得编码器学到更通用的特征。

## 5. 应用场景

对比学习适用于以下场景：

**1. 自监督预训练**
这是对比学习最典型的应用。在标注数据稀缺或昂贵的情况下，可以先在无标注数据上通过对比学习预训练模型，然后在下游任务上微调。例如，在医学影像领域，标注数据通常需要专家标注，成本高昂，对比学习可以充分利用大量无标注的医学影像。

**2. 图像分类（Image Classification）**
SimCLR、MoCo等方法在ImageNet上预训练后，通过线性评估（只训练一个线性分类器）可以达到接近监督学习的准确率。这表明对比学习学到的特征是高度可分离的。

**3. 目标检测与语义分割**
在COCO、PASCAL VOC等数据集上，使用对比学习预训练的骨干网络（如ResNet、ViT）作为特征提取器，可以显著提升检测和分割的性能，尤其是在标注数据有限的情况下。

**4. 自然语言处理（NLP）**
对比学习也被广泛应用于NLP任务。例如，SimCSE使用对比学习学习句子嵌入，通过Dropout作为数据增强；ConSERT使用多种文本增强（同义词替换、裁剪等）进行对比学习。这些模型在语义文本相似度（STS）任务上表现出色。

**5. 多模态学习（Multimodal Learning）**
CLIP（Contrastive Language-Image Pre-training）使用对比学习将图像和文本映射到同一个特征空间，通过最大化匹配的图像-文本对的相似度，最小化不匹配对的相似度。CLIP在零样本分类、图像检索、文本-图像生成等任务上展示了惊人的泛化能力。

**6. 推荐系统**
对比学习被用于学习用户和物品的特征表示。例如，对同一用户的不同行为序列进行对比学习，可以学习到更鲁棒的用户表示，提升推荐效果。

## 6. 优缺点分析

**优点：**

1. **无需标注数据：** 最核心的优势，利用数据本身的结构作为监督信号，极大地降低了数据标注成本。

2. **学习通用特征：** 对比学习学到的特征是"任务无关"的，可以迁移到多种下游任务，具有很强的泛化能力。

3. **利用数据增强：** 通过对数据施加各种增强，模型学会了不变性（invariance），即对变换（如裁剪、颜色变化等）不敏感，这通常是下游任务所需要的。

4. **性能优异：** 在ImageNet等基准上，对比学习方法的线性评估性能已经接近甚至超过监督学习，证明了其学习高质量特征的能力。

5. **灵活性高：** 可以结合各种数据增强、编码器架构、投影头设计，适应不同的数据类型和任务需求。

**缺点：**

1. **依赖大量负样本：** 对比学习的效果很大程度上依赖于负样本的数量和质量。传统的对比学习方法需要大批次或内存队列来提供大量负样本，这带来了显存和计算的开销。

2. **数据增强设计困难：** 数据增强的选择对性能影响巨大。太弱的增强导致任务太简单，模型学不到有用的特征；太强的增强破坏语义信息，导致任务无法学习。设计好的数据增强需要领域知识和大量实验。

3. **计算成本高：** 对比学习通常需要更大的模型、更大的批次、更长的训练时间。例如，SimCLR在ImageNet上需要使用batch size 4096、训练100个epoch才能达到最佳效果，这需要数十个GPU。

4. **负样本可能带来偏差：** 如果负样本中包含与正样本语义相似的样本（如同一类别的不同图像），会错误地推开它们，导致学到的特征不够区分。如何处理"伪负样本"（false negatives）是对比学习的一个开放问题。

5. **下游任务微调仍然需要标注数据：** 虽然预训练不需要标注，但在下游任务上微调时，仍然需要一定量的标注数据。纯自监督学习在完全没有标注的情况下，性能通常仍低于监督学习。

**对比表：对比学习 vs 监督学习**

| 特性 | 对比学习 | 监督学习 |
|------|----------|----------|
| 标注需求 | 不需要 | 需要大量 |
| 特征通用性 | 高（任务无关） | 低（任务相关） |
| 预训练成本 | 高（大批次、长训练） | 中等 |
| 下游任务性能 | 接近监督学习 | 基准 |
| 数据增强 | 关键（需精心设计） | 辅助（可选） |
| 负样本需求 | 大量 | 不需要 |

## 7. 调库实现

以下是使用PyTorch实现对比学习（SimCLR风格）的完整可运行代码：

```python
"""
对比学习示例：SimCLR-style Contrastive Learning
使用CIFAR-10数据集，完整可运行代码
"""
import torch
import torch.nn as nn
import torch.optim as optim
import torch.nn.functional as F
from torchvision import datasets, transforms
from torch.utils.data import DataLoader, Dataset
import torchvision.models as models

# ========== 1. 定义对比学习的数据增强 ==========
class ContrastiveLearningViewGenerator(object):
    """生成对比学习所需的多个视图"""
    def __init__(self, base_transform, n_views=2):
        self.base_transform = base_transform

        super(Encoder, self).__init__()
        # 使用预训练ResNet-18作为骨干网络
        resnet = models.resnet18(pretrained=False)

        self.encoder = resnet
    
    def forward(self, x):
        return self.encoder(x)

# ========== 4. 定义投影头 ==========
class ProjectionHead(nn.Module):
    def __init__(self, input_dim=128, hidden_dim=128, output_dim=64):
        super(ProjectionHead, self).__init__()
        self.projection = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, output_dim)
        )
    
    def forward(self, x):
        return self.projection(x)

# ========== 5. 定义NT-Xent损失（InfoNCE） ==========
class NTXentLoss(nn.Module):
    def __init__(self, temperature=0.5):
        super(NTXentLoss, self).__init__()
        self.temperature = temperature
    
    def forward(self, z_i, z_j):
        """
        z_i, z_j: [batch_size, feature_dim]
        """
        batch_size = z_i.size(0)
        
        # L2归一化
        z_i = F.normalize(z_i, dim=1)
        z_j = F.normalize(z_j, dim=1)
        
        # 拼接所有特征：[2*batch_size, feature_dim]
        z = torch.cat([z_i, z_j], dim=0)
        
        # 计算相似度矩阵
        sim_matrix = torch.mm(z, z.T) / self.temperature
        
        # 构造标签：对于每个样本，其正样本是另一个视图
        # z[0:batch_size]的锚点，正样本是z[batch_size:]
        # z[batch_size:]的锚点，正样本是z[0:batch_size]
        labels = torch.arange(batch_size, device=z_i.device)
        labels = torch.cat([labels + batch_size, labels], dim=0)
        
        # 创建mask：排除自身（对角线）
        mask = torch.eye(2*batch_size, dtype=torch.bool, device=z_i.device)
        sim_matrix = sim_matrix[~mask].view(2*batch_size, -1)
        
        # 交叉熵损失
        loss = F.cross_entropy(sim_matrix, labels)
        return loss

# ========== 6. 初始化模型、损失和优化器 ==========
encoder = Encoder(feature_dim=128).cuda()
projection_head = ProjectionHead(input_dim=128, output_dim=64).cuda()
criterion = NTXentLoss(temperature=0.5)
optimizer = optim.Adam(list(encoder.parameters()) +

        h_j = encoder(view2)
        z_j = projection_head(h_j)
        
        # 计算对比损失
        loss = criterion(z_i, z_j)
        
        # 反向传播
        loss.backward()
        optimizer.step()

          f"平均损失: {avg_loss:.4f}\n")
```

## 8. 手工代码实现

以下是从零实现对比学习的核心组件，包括编码器、投影头和NT-Xent损失：

```python
"""
手工实现对比学习核心组件
包含：编码器、投影头、NT-Xent损失函数
"""
import torch
import torch.nn as nn
import torch.optim as optim
import torch.nn.functional as F
from torchvision import datasets, transforms
from torch.utils.data import DataLoader, Dataset
import numpy as np

class SimpleEncoder(nn.Module):
    """简单的CNN编码器"""
    def __init__(self, feature_dim=128):
        super(SimpleEncoder, self).__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(3, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2, 2),
            nn.Conv2d(64, 128, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2, 2),
            nn.Conv2d(128, 256, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.AdaptiveAvgPool2d((1, 1))
        )
        self.fc = nn.Linear(256, feature_dim)
    
    def forward(self, x):
        x = self.conv(x)
        x = x.view(x.size(0), -1)
        x = self.fc(x)
        return x


class SimpleProjectionHead(nn.Module):
    """简单的投影头"""
    def __init__(self, input_dim=128, hidden_dim=128, output_dim=64):
        super(SimpleProjectionHead, self).__init__()
        self.layers = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, output_dim)
        )
    
    def forward(self, x):
        return self.layers(x)


class ManualNTXentLoss(nn.Module):
    """
    手动实现NT-Xent损失
    详细展示计算过程
    """
    def __init__(self, temperature=0.5):
        super(ManualNTXentLoss, self).__init__()
        self.temperature = temperature
    
    def forward(self, z_i, z_j):
        """
        手动实现NT-Xent损失
        z_i, z_j: [batch_size, feature_dim]
        """
        batch_size = z_i.size(0)
        
        # 步骤1：L2归一化
        z_i = F.normalize(z_i, dim=1)
        z_j = F.normalize(z_j, dim=1)
        
        # 步骤2：拼接所有特征
        # z的所有视图：[z_i[0], z_j[0], z_i[1], z_j[1], ...]
        z = torch.cat([z_i, z_j], dim=0)  # [2*batch_size, feature_dim]
        
        # 步骤3：计算相似度矩阵
        sim_matrix = torch.mm(z, z.T)  # [2*batch_size, 2*batch_size]
        sim_matrix = sim_matrix / self.temperature
        
        # 步骤4：构造正样本掩码
        # 对于z_i中的每个样本，其正样本是z_j中对应的样本
        # 对于z_j中的每个样本，其正样本是z_i中对应的样本
        pos_mask = torch.zeros(2*batch_size, 2*batch_size, dtype=torch.bool)
        for i in range(batch_size):
            pos_mask[i, i + batch_size] = True
            pos_mask[i + batch_size, i] = True
        
        # 步骤5：构造负样本掩码（排除自身和正样本）
        self_mask = torch.eye(2*batch_size, dtype=torch.bool)
        neg_mask = ~(pos_mask | self_mask)
        
        # 步骤6：计算正样本相似度（取对数）
        pos_sim = sim_matrix[pos_mask].view(2*batch_size, 1)
        
        # 步骤7：计算负样本相似度
        neg_sim = sim_matrix[neg_mask].view(2*batch_size, -1)
        
        # 步骤8：计算InfoNCE损失
        # logits = [正样本相似度, 负样本相似度]
        logits = torch.cat([pos_sim, neg_sim], dim=1)
        
        # 标签：正样本在位置0
        labels = torch.zeros(2*batch_size, dtype=torch.long)
        
        # 交叉熵损失
        loss = F.cross_entropy(logits, labels)
        
        return loss

    criterion = ManualNTXentLoss(temperature=0.5)

    print("手工对比学习训练完成！")
```

## 10. 模型评估

对比学习采用两阶段评估：首先在预训练任务上评估损失，然后在下游任务上评估特征质量。

```python
"""
对比学习模型评估
包括：预训练损失评估、线性评估（Linear Evaluation）
"""
import torch
import torch.nn as nn
import torch.nn.functional as F
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

def evaluate_pretraining_loss(encoder, projection_head, test_loader, criterion):
    """评估预训练阶段的对比损失"""
    encoder.eval()
    projection_head.eval()
    total_loss = 0.0
    total_samples = 0
    
    with torch.no_grad():
        for view1, view2 in test_loader:
            view1, view2 = view1.cuda(), view2.cuda()
            z_i = projection_head(encoder(view1))
            z_j = projection_head(encoder(view2))
            loss = criterion(z_i, z_j)
            total_loss += loss.item() * view1.size(0)
            total_samples += view1.size(0)
    
    return total_loss / total_samples


def linear_evaluation(encoder, train_loader, test_loader, num_classes=10, num_epochs=10):
    """
    线性评估（Linear Evaluation）
    冻结编码器，只训练一个线性分类器
    这是评估对比学习特征质量的常用方法
    """
    # 冻结编码器参数
    for param in encoder.parameters():
        param.requires_grad = False
    
    encoder.eval()
    
    # 创建线性分类器
    feature_dim = encoder.fc.out_features if hasattr(encoder, 'fc') else 128
    classifier = nn.Linear(feature_dim, num_classes).cuda()
    optimizer = torch.optim.Adam(classifier.parameters(), lr=1e-3)
    criterion = nn.CrossEntropyLoss()
    
    print("\n" + "="*60)
    print("线性评估（Linear Evaluation）")
    print("="*60)
    
    # 训练线性分类器
    for epoch in range(num_epochs):
        classifier.train()
        correct = 0
        total = 0
        total_loss = 0.0
        
        for images, labels in train_loader:
            images, labels = images.cuda(), labels.cuda()
            
            optimizer.zero_grad()
            
            with torch.no_grad():
                features = encoder(images)
            
            outputs = classifier(features)
            loss = criterion(outputs, labels)
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
            _, predicted = torch.max(outputs.data, 1)
            total += labels.size(0)
            correct += (predicted == labels).sum().item()
        
        train_acc = 100 * correct / total
        train_loss = total_loss / len(train_loader)
        
        # 测试
        classifier.eval()
        test_correct = 0
        test_total = 0
        test_loss = 0.0
        
        with torch.no_grad():
            for images, labels in test_loader:
                images, labels = images.cuda(), labels.cuda()
                features = encoder(images)
                outputs = classifier(features)
                loss = criterion(outputs, labels)
                test_loss += loss.item()
                _, predicted = torch.max(outputs.data, 1)
                test_total += labels.size(0)
                test_correct += (predicted == labels).sum().item()
        
        test_acc = 100 * test_correct / test_total
        test_loss = test_loss / len(test_loader)
        
        print(f"Epoch [{epoch+1}/{num_epochs}], "
              f"Train Loss: {train_loss:.4f}, Train Acc: {train_acc:.2f}%, "
              f"Test Loss: {test_loss:.4f}, Test Acc: {test_acc:.2f}%")
    
    # 解冻编码器（如果需要后续微调）
    for param in encoder.parameters():
        param.requires_grad = True
    
    return test_acc
```

## 11. 常见问题与易错点

**数据层面：**

1. **数据增强选择不当**
   - 问题：增强太弱（如只做随机裁剪）导致任务太简单，或太强（如极端颜色抖动）破坏语义信息
   - 解决：使用经过验证的增强组合，如SimCLR的增强策略（裁剪+颜色抖动+灰度化+翻转）
   ```python
   # SimCLR推荐的数据增强
   contrastive_transform = transforms.Compose([
       transforms.RandomResizedCrop(32, scale=(0.08, 1.0)),  # 不能太弱
       transforms.RandomHorizontalFlip(),
       transforms.ColorJitter(0.4, 0.4, 0.4, 0.1),  # 不能太强
       transforms.RandomGrayscale(p=0.2),
       transforms.ToTensor(),
   ])
   ```

2. **批次大小太小**
   - 问题：对比学习需要大量负样本，批次太小（如<32）导致负样本不足，特征质量差
   - 解决：使用尽可能大的批次（如128、256、512），或使用梯度累积、内存队列（如MoCo）来增加有效负样本数

3. **忘记归一化特征**
   - 问题：在计算对比损失前没有对特征进行L2归一化，导致余弦相似度计算不正确
   - 解决：在损失函数中确保特征被归一化
   ```python
   # 正确做法
   z_i = F.normalize(z_i, dim=1)
   z_j = F.normalize(z_j, dim=1)
   similarity = torch.mm(z_i, z_j.T) / temperature
   ```

**模型层面：**

1. **投影头缺失或使用不当**
   - 问题：直接使用编码器输出计算对比损失，没有投影头
   - 解决：添加投影头（通常是2-3层的MLP），但下游任务使用编码器输出（不是投影头输出）
   ```python
   # 预训练时：使用投影头的输出计算损失
   z = projection_head(encoder(x))
   loss = criterion(z_i, z_j)
   
   # 下游任务：使用编码器的输出作为特征
   features = encoder(x)  # 不是projection_head(encoder(x))
   ```

2. **温度参数设置不当**
   - 问题：温度参数 $\tau$ 设置不合适（太大或太小）
   - 建议：$\tau$ 通常设置在0.5-1.0之间。可以网格搜索找到最佳值
   ```python
   # 常用的温度参数值
   temperatures = [0.1, 0.5, 1.0]
   # 较小的tau（如0.1）关注困难负样本
   # 较大的tau（如1.0）使分布更平滑
   ```

3. **编码器架构选择**
   - 问题：编码器太简单（如只有几层）导致特征表达能力不足
   - 建议：使用经过验证的架构（如ResNet-18/50、ViT等），根据任务和数据规模选择

**调参层面：**

1. **学习率调整**
   - 问题：对比学习通常需要较大的批次和较长的训练，学习率设置不当
   - 建议：使用warmup + cosine decay学习率调度，初始学习率可以稍大（如1e-3）
   ```python
   optimizer = optim.Adam(model.parameters(), lr=1e-3)
   scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=num_epochs)
   ```

2. **训练轮数不足**
   - 问题：对比学习通常需要很长的训练（如100-1000个epoch）才能学到好的特征
   - 建议：至少训练100个epoch，如果可能尽量训练更久

## 12. 学习总结

对比学习是一种强大的自监督学习范式，通过构建正负样本对、使用对比损失训练模型，能够在无标注数据上学习到高质量的特征表示。其核心思想简单而深刻：在特征空间中拉近正样本、推远负样本。

关键要点总结：
1. **核心组件**：编码器（提取特征）、投影头（用于对比任务）、数据增强（生成正负样本对）、对比损失（如InfoNCE）。

2. **训练流程**：对每个样本生成多个增强视图 → 通过编码器提取特征 → 通过投影头映射到对比空间 → 计算对比损失（正样本相似度最大、负样本相似度最小）→ 反向传播更新参数。

3. **评估方式**：采用两阶段评估，先在预训练任务上评估损失，然后在下游任务上进行线性评估或微调。线性评估准确率反映了编码器学到的特征质量。

4. **关键技巧**：数据增强的设计至关重要、温度参数需要仔细调整、批次大小影响负样本数量、投影头分离了表征学习和对比任务。

5. **应用场景**：自监督预训练、图像分类、目标检测、NLP句子嵌入、多模态学习（如CLIP）等。对比学习正在成为深度学习预训练的新范式。

掌握对比学习不仅让你能够利用无标注数据，还为理解自监督学习、迁移学习等前沿技术打下坚实基础。

## 13. 练习题与思考题

**基础题：**

1. **简答题**：对比学习的核心思想是什么？为什么需要负样本？

   **答案**：核心思想：在特征空间中，让相似的样本（正样本对）彼此靠近，让不相似的样本（负样本对）彼此远离。负样本的作用：如果没有负样本，模型可以简单地让所有样本的特征都映射到同一个点，从而轻松"骗过"损失函数。负样本迫使模型学习到具有区分度的特征，将不同的样本推开。因此，负样本的数量和质量直接影响对比学习的效果。

2. **代码题**：下面的对比损失代码有什么错误？如何修正？
   ```python
   def ntxent_loss(z_i, z_j, temperature=0.5):
       # z_i, z_j: [batch_size, feature_dim]
       batch_size = z_i.size(0)
       z = torch.cat([z_i, z_j], dim=0)
       sim = torch.mm(z, z.T) / temperature
       # 正样本在对角线（错误！）
       pos = torch.diag(sim)
       loss = -torch.log(pos).mean()
       return loss
   ```
   
   **答案**：
   ```python
   def ntxent_loss(z_i, z_j, temperature=0.5):
       batch_size = z_i.size(0)
       # 需要L2归一化
       z_i = F.normalize(z_i, dim=1)
       z_j = F.normalize(z_j, dim=1)
       
       z = torch.cat([z_i, z_j], dim=0)
       sim = torch.mm(z, z.T) / temperature
       
       # 正样本：z_i <--> z_j，不是对角线
       # 对于z[0:batch_size]（即z_i），正样本是z[batch_size:]（即z_j）
       pos = sim[:batch_size, batch_size:].diag()  # 正确的正样本位置
       
       # 还需要负样本
       # 构造logits：[正样本相似度, 负样本相似度]
       # 简化版：使用softmax
       labels = torch.arange(batch_size, device=z_i.device)
       logits = sim[:batch_size]  # 所有相似度
       loss = F.cross_entropy(logits, labels)  # 需要构造正确的labels
       return loss
   ```

**进阶题：**

3. **分析题**：为什么对比学习中通常使用投影头（projection head）？在下游任务中应该使用编码器的输出还是投影头的输出作为特征？

   **答案**：使用投影头的原因：(1) 分离表征学习和对比任务：投影头后的特征专门用于对比损失计算，使得编码器能够学习更通用、更不依赖于对比任务的特征；(2) 非线性变换：投影头（通常是MLP）引入了非线性，可以更好地分离对比学习的特征空间；(3) 信息瓶颈：投影头可能丢弃一些与对比任务无关但与下游任务相关的信息，这些信息保留在编码器的输出中。在下游任务中：应该使用编码器的输出作为特征，而不是投影头的输出。因为投影头是为了对比任务设计的，可能丢失一些有用的信息；而编码器的输出保留了更完整、更通用的特征表示。

4. **设计题**：设计一个实验来比较不同数据增强策略对对比学习性能的影响。需要说明实验设置、评估指标、预期结果。

   **答案**：实验设计：(1) 基准：SimCLR的标准增强（裁剪+颜色抖动+灰度化+翻转）；(2) 对比组1：只使用裁剪和翻转（太弱）；(3) 对比组2：使用极端的颜色抖动和噪声（太强）；(4) 模型：相同的编码器（如ResNet-18）、投影头；(5) 训练：相同的数据集（CIFAR-10）、批次大小（128）、训练轮数（100）；(6) 评估：线性评估准确率。预期结果：基准组的准确率最高（约70-80%）；太弱的增强导致准确率较低（约50-60%），因为任务太简单；太强的增强也导致准确率较低（约40-50%），因为破坏了语义信息。

**开放题：**

5. **讨论题**：对比学习、掩码自编码器（MAE）、掩码语言模型（MLM，如BERT）都是自监督学习的方法。讨论它们的异同，以及各自的优势和适用场景。

   **答案**：相同点：都是自监督学习，不需要人工标注数据，通过设计预训练任务来学习特征表示。不同点：(1) 对比学习：通过正负样本对比，学习的是样本间的区分性特征；(2) MAE：通过掩码一部分输入（如图像块）并重建，学习的是输入的完整表示；(3) MLM：通过掩码一部分token并预测，学习的是语言的上下文理解。优势与适用场景：对比学习适用于需要学习样本区分性的任务（如检索、聚类）；MAE适用于需要学习完整输入表示的任务（如图像生成、分割）；MLM适用于需要理解上下文的任务（如问答、摘要）。实际上，这些方法可以结合使用（如CLIP结合对比学习和掩码预测），进一步提升性能。
