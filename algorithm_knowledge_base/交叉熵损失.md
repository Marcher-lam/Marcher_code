# 交叉熵损失 学习文档

## 1. 算法基础认知
分类问题中常用的损失函数，衡量预测概率分布与真实分布的差异。

## 2. 核心原理
$CE = -\sum_i y_i \log(p_i)$

## 3. 数学推导
从极大似然估计推导而来。

## 4. 训练过程
与优化算法结合最小化损失。

## 5. 应用场景
- 多分类问题
- 二分类问题（结合Sigmoid）

## 6. 优缺点
优点：梯度信息丰富；缺点：对异常值敏感

## 7. 代码实现
```python
import torch.nn as nn
loss = nn.CrossEntropyLoss()
```

## 8. 手工实现
```python
import numpy as np

def cross_entropy(predictions, targets):
    # 防止log(0)
    eps = 1e-15
    predictions = np.clip(predictions, eps, 1 - eps)
    
    n_samples = predictions.shape[0]
    log_likelihood = -np.log(predictions[range(n_samples), targets])
    loss = np.sum(log_likelihood) / n_samples
    return loss
```
