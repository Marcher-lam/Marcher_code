## 1. 算法基础认知

**一句话定义：** GMM 用 $K$ 个高斯分布的加权线性组合建模数据分布，通过 EM 算法学习各分量的均值、协方差和混合权重。

**直觉类比：** 单一高斯分布只能描述"一个团"，但现实数据常有"多个团"。GMM 就像把多个"高斯泡泡"叠加在一起——每个泡泡描述一个子群体，权重决定每个泡泡的"影响力"。

**算法定位：** 概率模型、聚类、密度估计。

**前置知识：** 高斯分布、EM 算法、最大似然估计。

## 2-3. 核心原理与数学公式

### 模型定义

$$p(x) = \sum_{k=1}^{K} \pi_k \mathcal{N}(x | \mu_k, \Sigma_k)$$

参数：$\theta = \{\pi_k, \mu_k, \Sigma_k\}_{k=1}^K$

- $\pi_k$：混合权重，$\sum_k \pi_k = 1$
- $\mu_k, \Sigma_k$：第 $k$ 个高斯分量的均值和协方差

### EM 求解

**E 步**：计算后验概率

$$\gamma_{ik} = \frac{\pi_k \mathcal{N}(x_i|\mu_k,\Sigma_k)}{\sum_j \pi_j \mathcal{N}(x_i|\mu_j,\Sigma_j)}$$

**M 步**：更新参数

$$\mu_k = \frac{\sum_i \gamma_{ik} x_i}{\sum_i \gamma_{ik}}, \quad \pi_k = \frac{\sum_i \gamma_{ik}}{n}$$

## 4-8. 代码实现

```python
import numpy as np
from sklearn.mixture import GaussianMixture

# 生成双峰数据
np.random.seed(42)
X = np.vstack([np.random.randn(200, 2) + [2, 2],
               np.random.randn(200, 2) + [-2, -2]])

gmm = GaussianMixture(n_components=2, random_state=42).fit(X)
labels = gmm.predict(X)

print(f"均值:\n{gmm.means_}")
print(f"权重: {gmm.weights_}")
print(f"对数似然: {gmm.score(X):.4f}")
```

## 9-14. 练习与路径

**题1：** GMM 与 K-Means 的关系？

**参考答案：** K-Means 是 GMM 的硬分配特例——后验概率退化为 one-hot，协方差趋于 0。GMM 提供软分配（概率），更灵活但计算更复杂。

### 学习路径
- 前置：高斯分布、EM 算法
- 进阶：变分 GMM（自动选 K）、贝叶斯非参数模型
