# 课程学习 学习文档

> 用一句话说明这个算法的核心价值：作为稀疏奖励环境的训练增强技术，课程学习通过逐步增加任务难度，引导智能体从简单到复杂逐步掌握，提升学习效率和最终性能。

## 1. 算法基础认知

课程学习（Curriculum Learning）是**强化学习中的训练策略**，通过设计由易到难的课程（Curriculum），引导智能体逐步掌握复杂任务，解决稀疏奖励和复杂任务难以直接学习的问题。

**一句话定义**：将复杂任务分解为多个子任务（Curriculum），从最简单的子任务开始训练，逐步过渡到最终复杂任务。智能体先在小任务上学习基础能力，再逐步过渡到最终任务。

**直觉类比**：就像学数学时，先学加减法（简单任务），再学乘除法（中等难度），然后学代数（较难），最后学微积分（最难），而不是一开始就直接学微积分。通过循序渐进的学习，即使微积分很难，学生也能学会。

**历史背景**：
- 2009年：Bengio等人在监督学习中提出课程学习概念
- 2015年：Schaul等人将课程学习引入强化学习
- 2017年：OpenAI将课程学习用于机器人训练
- 2019年：自动课程学习（Automatic Curriculum Learning）开始流行
- 2020年：Self-Paced Learning和Meta-Curriculum成为热点

**算法定位**：
- 属于RL训练策略，不改变核心算法框架
- 可结合任何RL算法（DQN、PPO、SAC、TD3等）
- 解决复杂任务难以直接学习的问题
- 尤其适合稀疏奖励环境、长horizon任务、多阶段任务

**前置知识**：
- 强化学习基础（MDP、奖励、策略）
- 任务分解与课程设计
- RL算法框架（PPO、SAC等）
- PyTorch深度学习框架

## 2. 核心原理

课程学习的核心思想是：**将复杂任务分解为由易到难的课程**，智能体先在小任务上学习基础能力，再逐步过渡到最终任务。

### 2.1 四种课程设计方法

#### 状态初始化（State Initialization）
简单任务从接近目标的状态开始，复杂任务从远离目标的状态开始。例如导航任务中：
- 子任务1：初始位置距离目标1米
- 子任务2：初始位置距离目标5米
- 子任务3：初始位置距离目标10米
- 最终任务：初始位置距离目标50米

#### 奖励塑造（Reward Shaping）
简单任务给予更密集的奖励，复杂任务只给最终奖励。例如：
- 子任务1：每步给距离目标减少的奖励
- 子任务2：只有到达检查点的奖励
- 最终任务：只有到达终点的奖励

#### 终止条件（Termination Conditions）
简单任务的episode更短、容错率更高：
- 子任务1：步数限制50步，只要不摔倒就成功
- 子任务2：步数限制100步，不摔倒+到达检查点
- 最终任务：步数限制200步，完整任务

#### 环境参数（Environment Parameters）
逐步改变环境参数增加难度：
- 子任务1：低速、摩擦小、障碍物少
- 子任务2：中速、普通摩擦、障碍物中等
- 最终任务：高速、高摩擦、障碍物密集

### 2.2 课程转移条件

1. **固定步数**：训练N步后自动转移到下一课程
2. **性能阈值**：平均回报达到阈值 $\eta_i$ 后转移
3. **自适应**：根据智能体能力动态调整课程

### 2.3 课程设计原则

- **可行性**：每个子任务应该是智能体能够学会的
- **递进性**：子任务之间应该有明确递进
- **覆盖性**：子任务集合应该覆盖最终任务的能力空间

## 3. 数学公式与推导

### 3.1 课程策略形式化

整个课程学习过程可以表示为时变策略：
$$\pi_{\text{curr}}(s, t) = \begin{cases}
\pi_1(s), & \text{if } t \leq \alpha_1 \\
\pi_2(s), & \text{if } \alpha_1 < t \leq \alpha_1+\alpha_2 \\
\vdots & \vdots \\
\pi_N(s), & \text{if } t > \alpha_1+\cdots+\alpha_{N-1}
\end{cases}$$

其中 $\alpha_i$ 是第 $i$ 个子任务的训练步数，$\pi_i$ 是子任务 $i$ 学习到的策略。

### 3.2 难度度量

子任务难度可以用以下方式量化：
- 初始状态分布与目标的距离
- 稀疏奖励的比例
- 达到目标的平均步数
- 策略梯度方差

难度递增函数：$d_1 < d_2 < \cdots < d_N$

### 3.3 性能分析

课程学习的优势可以用样本效率和最终性能来衡量：
- **样本效率**：$E[\text{steps} | \text{curriculum}] < E[\text{steps} | \text{no curriculum}]$
- **最终性能**：$J(\pi_N^{\text{curriculum}}) \geq J(\pi_N^{\text{random}})$

## 4. 训练过程讲解

课程学习的训练过程包括：

1. **任务分解**：将最终任务分解为N个子任务
2. **课程设计**：为每个子任务设计初始状态、奖励函数、终止条件
3. **阶段训练**：
   - 从最简单子任务开始训练
   - 当满足转移条件时，进入下一子任务
   - 在最终任务上微调
4. **自适应调整**：根据训练进度动态调整课程

## 5. 应用场景

- 机器人技能学习（行走、抓取、导航）
- 游戏AI训练（从简单关卡到复杂关卡）
- 自动驾驶（从简单道路到复杂交通）
- 多阶段任务（如对话系统）
- 稀疏奖励环境（如Montezuma's Revenge）

## 6. 优缺点分析

**优点**：
- 显著提升样本效率
- 解决稀疏奖励问题
- 加速收敛速度
- 提高最终性能
- 符合人类学习规律

**缺点**
- 需要任务分解能力
- 课程设计需要专业知识
- 不当课程可能导致学习失败
- 增加训练复杂度

        return True

import numpy as np

class SimpleCurriculumLearning:
    def __init__(self, env, curriculum):
        """

        self.env = env
        self.curriculum = curriculum
        self.current_stage = 0
        self.stage_steps = 0
        self.total_steps = 0
    
    def train(self, total_timesteps):
        """按课程训练智能体"""
        results = []
        
        for stage_idx, stage in enumerate(self.curriculum):
            if stage_idx > 0:
                print(f"Transitioning to stage {stage_idx}: {stage['task_name']}")
                self.env = stage['env_fn']()
            
            stage_rewards = self._train_stage(
                stage['max_steps'],
                stage.get('reward_threshold', stage['transition_reward'])
            )
            results.extend(stage_rewards)
        
        return results

        """训练单个课程阶段"""

## 10. 模型评估

评估课程学习的指标：
- **样本效率**：达到目标性能所需的训练步数
- **最终性能**：在最终任务上的表现
- **稳定性**：学习曲线的平滑度
- **转移成功率**：各阶段过渡的成功率

## 11. 常见问题与易错点

- **课程设计不当**：阶段间差距过大导致学习失败
  - 解决方法：使用自动课程学习或先验知识设计
- **过早转移**：在阶段尚未掌握时就转移
  - 解决方法：设置更严格的转移条件
- **奖励稀疏性**：子任务奖励仍然稀疏
  - 解决方法：引入中间奖励或潜在空间距离奖励
- **负迁移**：前一阶段知识对后续阶段有害
  - 解决方法：课程设计时确保任务相关性

## 12. 学习总结

课程学习通过有策略地设计学习路径，显著提升了强化学习的训练效率和最终性能。它体现了"由浅入深"的教育理念，是解决复杂RL任务的有效方法。
