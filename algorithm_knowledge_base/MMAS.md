# MMAS 最大最小蚂蚁系统 学习文档

>ACO的改进版本，限制信息素范围。

## 1. 算法基础认知

MMAS（Max-Min Ant System）是ACO的重要改进，由Stützle和Hoos提出，限制每条边的信息素在[τ_min, τ_max]范围内。

## 2. 核心原理

- 信息素上下界限制
- 只更新最优蚂蚁的信息素
- 信息素平滑机制

## 3. 数学公式

$$\tau_{ij} \in [\tau_{min}, \tau_{max}]$$
