# 多查询注意力学习文档

> 多查询注意力（Multi-Query Attention，MQA）是Transformer模型中一种重要的推理优化技术，通过让多个Query头共享同一套Key和Value，显著降低自回归推理时的KV Cache内存占用

---

## 1. 算法基础认知

### 1.1 一句话定义

**多查询注意力（Multi-Query Attention，MQA）** 是对标准多头注意力（MHA）的一种优化变体，其核心思想是让所有Query头共享同一套Key和Value向量，通过牺牲部分建模能力换取推理时KV Cache的大幅降低。

### 1.2 经典类比

| 机制 | 比喻 | 内存占用 |
|------|------|----------|
| MHA | 每人一本独立字典 | 大 |
| MQA | 所有人共用一本字典 | 小 |
| GQA | 小组共用一本字典 | 中 |

MQA就像一个团队工作：MHA是每个人有自己的参考资料，MQA是大家共用一份参考资料——查找快但可能信息不够个性化。

### 1.3 历史背景

| 年份 | 里程碑 |
|------|--------|
| 2019 | 《Fast Transformer》首次提出MQA |
| 2021 | 《Training, Evaluating, and Distilling Multi-Query Attention》 |
| 2022 | LLaMA等大模型采用 |
| 2023 | MQA成为LLM标配 |

### 1.4 核心定位

| 维度 | 描述 |
|------|------|
| 类型 | 注意力机制变体 |
| 优化目标 | 推理KV Cache |
| 核心思想 | Key-Value共享 |
| 应用 | 自回归LLM |

### 1.5 前置知识

- Transformer架构
- Multi-Head Attention
- KV Cache机制
- 推理优化基础

## 2. 核心原理

### 2.1 MHA vs MQA

**标准MHA**：
- $Q_i = XW_i^Q$ （$n_h$个头）
- $K_i = XW_i^K$ （$n_h$个头）
- $V_i = XW_i^V$ （$n_h$个头）

**MQA**：
- $Q_i = XW_i^Q$ （$n_h$个头）
- $K = XW^K$ （1个头）
- $V = XW^V$ （1个头）

### 2.2 计算流程

```python
# MQA前向计算
class MultiQueryAttention(nn.Module):
    def __init__(self, hidden_size, num_heads):
        self.num_heads = num_heads
        self.head_dim = hidden_size // num_heads
        
        # Query: 每个头独立
        self.q_proj = nn.Linear(hidden_size, hidden_size)
        
        # Key和Value: 所有头共享
        self.k_proj = nn.Linear(hidden_size, self.head_dim)
        self.v_proj = nn.Linear(hidden_size, self.head_dim)
        
        self.o_proj = nn.Linear(hidden_size, hidden_size)
    
    def forward(self, x, mask=None):
        batch_size, seq_len, _ = x.shape
        
        # 投影到Q（保持多头）
        Q = self.q_proj(x).view(
            batch_size, seq_len, self.num_heads, self.head_dim
        ).transpose(1, 2)
        
        # 投影到K和V（压缩为单头）
        K = self.k_proj(x).unsqueeze(1)  # (batch, 1, seq, head_dim)
        V = self.v_proj(x).unsqueeze(1)  # (batch, 1, seq, head_dim)
        
        # 注意力计算
        scores = torch.matmul(Q, K.transpose(-2, -1)) / sqrt(self.head_dim)
        
        if mask is not None:
            scores = scores.masked_fill(mask, float('-inf'))
        
        attn_weights = F.softmax(scores, dim=-1)
        context = torch.matmul(attn_weights, V)
        
        # 输出
        context = context.transpose(1, 2).contiguous().view(
            batch_size, seq_len, -1
        )
        
        return self.o_proj(context)
```

### 2.3 推理时的KV Cache

**MHA推理**：
```python
# MHA: 每个头独立缓存
k_cache = torch.zeros(batch, num_heads, max_seq, head_dim)
v_cache = torch.zeros(batch, num_heads, max_seq, head_dim)

# 生成新token时需要更新所有头
for h in range(num_heads):
    k_cache[:, h, pos] = k_h
    v_cache[:, h, pos] = v_h
```

**MQA推理**：
```python
# MQA: 只需缓存一套
k_cache = torch.zeros(batch, 1, max_seq, head_dim)
v_cache = torch.zeros(batch, 1, max_seq, head_dim)

# 生成新token时只需更新一套
k_cache[:, 0, pos] = k
v_cache[:, 0, pos] = v
```

## 3. 数学公式与推导

### 3.1 形式化定义

设模型参数：
- $d_{model}$：模型隐藏维度
- $n_h$：Query头数
- $d_k$：每个头的Key维度

**Query投影**：
$$Q = XW^Q, \quad Q \in \mathbb{R}^{b \times s \times (n_h d_k)}$$

**Key和Value投影**（压缩）：
$$K = XW^K, \quad K \in \mathbb{R}^{b \times s \times d_k}$$
$$V = XW^V, \quad V \in \mathbb{R}^{b \times s \times d_k}$$

**注意力分数**：
$$\text{scores}_{i,j} = \frac{Q_{:,i,:} \cdot K_{:,j,:}}{\sqrt{d_k}}$$

形状：$(b, n_h, s, s)$

### 3.2 内存节省分析

| 机制 | KV Cache大小 | 公式 |
|------|------------|------|
| MHA | $2 \times n_h \times S \times d_k$ | 标准 |
| MQA | $2 \times 1 \times S \times d_k$ | $\frac{1}{n_h}$ |
| GQA(g组) | $2 \times g \times S \times d_k$ | $\frac{g}{n_h}$ |

**节省比例**：
$$\text{Saving} = \frac{n_h - 1}{n_h} \approx 100\%$$

### 3.3 例子：LLaMA-7B

设$L=32, d_k=128$：

- MHA: $32 \times 128 \times 2 = 8192$ tokens
- MQA: $1 \times 128 \times 2 = 256$ tokens
- **节省**: 96.9%

### 3.4 训练vs推理权衡

| 阶段 | MHA | MQA | 选择 |
|------|-----|-----|------|
| 训练 | $O(n_h)$ FLOPs | $O(n_h)$ FLOPs | 相同 |
| 推理 | large KV | small KV | MQA更好 |

MQA的核心优化在于**推理阶段的内存**，训练阶段计算量相同。

## 4. Python实现

### 4.1 完整MQA实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class MultiQueryAttention(nn.Module):
    """多查询注意力（MQA）完整实现"""
    
    def __init__(self, hidden_size, num_heads, dropout=0.0):
        super().__init__()
        
        assert hidden_size % num_heads == 0
        
        self.hidden_size = hidden_size
        self.num_heads = num_heads
        self.head_dim = hidden_size // num_heads
        
        # Query: 保持多头结构
        self.q_proj = nn.Linear(hidden_size, hidden_size)
        
        # Key和Value: 压缩为单头
        self.k_proj = nn.Linear(hidden_size, self.head_dim)
        self.v_proj = nn.Linear(hidden_size, self.head_dim)
        
        self.o_proj = nn.Linear(hidden_size, hidden_size)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, mask=None, use_cache=False, past_kv=None):
        """
        Args:
            x: (batch, seq_len, hidden_size)
            mask: attention mask
            use_cache: 是否使用KV Cache
            past_kv: 过去的 KV Cache
        Returns:
            output: (batch, seq_len, hidden_size)
            present: 当前的 KV Cache
        """
        batch_size, seq_len, _ = x.shape
        
        # Query: 多头
        Q = self.q_proj(x).view(
            batch_size, seq_len, self.num_heads, self.head_dim
        ).transpose(1, 2)
        
        # Key和Value: 单头
        K = self.k_proj(x).unsqueeze(2)  # (batch, 1, seq, head_dim)
        V = self.v_proj(x).unsqueeze(2)
        
        if past_kv is not None:
            past_k, past_v = past_kv
            K = torch.cat([past_k.expand(-1, -1, self.head_dim), K], dim=2)
            V = torch.cat([past_v.expand(-1, -1, self.head_dim), V], dim=2)
        
        if use_cache:
            present = (K, V)
        else:
            present = None
        
        # 注意力计算
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.head_dim)
        
        if mask is not None:
            scores = scores.masked_fill(mask, float('-inf'))
        
        attn_weights = F.softmax(scores, dim=-1)
        attn_weights = self.dropout(attn_weights)
        
        # 输出
        context = torch.matmul(attn_weights, V)
        
        context = context.transpose(1, 2).contiguous().view(
            batch_size, seq_len, self.hidden_size
        )
        
        output = self.o_proj(context)
        
        return output, present


class TransformerBlockWithMQA(nn.Module):
    """带MQA的Transformer块"""
    
    def __init__(self, hidden_size, num_heads, ff_dim, dropout=0.1):
        super().__init__()
        
        self.attention = MultiQueryAttention(hidden_size, num_heads, dropout)
        self.norm1 = nn.LayerNorm(hidden_size)
        
        self.feed_forward = nn.Sequential(
            nn.Linear(hidden_size, ff_dim),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(ff_dim, hidden_size),
            nn.Dropout(dropout)
        )
        self.norm2 = nn.LayerNorm(hidden_size)
    
    def forward(self, x, mask=None, use_cache=False, past_kv=None):
        attn_output, present = self.attention(
            self.norm1(x), mask, use_cache, past_kv
        )
        x = x + attn_output
        
        ff_output = self.feed_forward(self.norm2(x))
        x = x + ff_output
        
        return x, present
```

### 4.2 推理优化实现

```python
class MQAInference:
    """MQA推理优化"""
    
    def __init__(self, model, max_seq_len=2048):
        self.model = model
        self.max_seq_len = max_seq_len
        
        # KV Cache缓存
        self.k_cache = None
        self.v_cache = None
    
    def prefill(self, prompt_ids):
        """预填充阶段：处理完整prompt"""
        self.model.eval()
        
        with torch.no_grad():
            outputs = self.model(
                prompt_ids,
                use_cache=True
            )
        
        # 缓存KV
        for layer_idx, layer in enumerate(self.model.layers):
            self.k_cache[layer_idx] = layer.attention.k_cache
            self.v_cache[layer_idx] = layer.attention.v_cache
        
        return outputs
    
    def decode(self, next_token):
        """解码阶段：逐token生成"""
        self.model.eval()
        
        # 拼接历史
        input_ids = torch.cat([self.past_ids, next_token], dim=1)
        
        with torch.no_grad():
            for layer_idx, layer in enumerate(self.model.layers):
                # 使用缓存的KV
                past_kv = (
                    self.k_cache[layer_idx],
                    self.v_cache[layer_idx]
                )
                
                # 计算新token
                outputs = layer(
                    input_ids[:, -1:],
                    past_kv=past_kv,
                    use_cache=True
                )
                
                # 更新缓存
                self.k_cache[layer_idx] = outputs[1][0]
                self.v_cache[layer_idx] = outputs[1][1]
        
        return self.model.lm_head(self.past_ids)
    
    def autoregressive_generate(self, prompt, max_new_tokens=50):
        """自回归生成"""
        prompt_ids = self.tokenizer(prompt, return_tensors="pt")
        
        # 预填充
        self.prefill(prompt_ids)
        
        generated = []
        
        for _ in range(max_new_tokens):
            logits = self.decode(last_token)
            next_token = logits.argmax(-1)
            generated.append(next_token)
            
            if next_token == self.tokenizer.eos_token_id:
                break
        
        return self.tokenizer.decode(generated)
```

```python
def compare_mha_mqa():
    """对比MHA和MQA"""
    
    class StandardMHA(nn.Module):
        """标准MHA"""
        def __init__(self, hidden_size, num_heads):
            super().__init__()
            self.num_heads = num_heads
            self.head_dim = hidden_size // num_heads
            
            self.q_proj = nn.Linear(hidden_size, hidden_size)
            self.k_proj = nn.Linear(hidden_size, hidden_size)
            self.v_proj = nn.Linear(hidden_size, hidden_size)
            self.o_proj = nn.Linear(hidden_size, hidden_size)
        
        def forward(self, x):
            Q = self.q_proj(x).view(-1, self.num_heads, self.head_dim).transpose(1, 2)
            K = self.k_proj(x).view(-1, self.num_heads, self.head_dim).transpose(1, 2)
            V = self.v_proj(x).view(-1, self.num_heads, self.head_dim).transpose(1, 2)

            return self.o_proj(out)
    
    # 参数统计
    mha = StandardMHA(512, 8)
    mqa = MultiQueryAttention(512, 8)
    
    def count_params(model):
        return sum(p.numel() for p in model.parameters())
    
    print(f"MHA参数: {count_params(mha):,}")
    print(f"MQA参数: {count_params(mqa):,}")
    
    # 推理内存
    batch, seq, heads, dim = 1, 512, 8, 64
    
    mha_cache = 2 * batch * heads * seq * dim
    mqa_cache = 2 * batch * 1 * seq * dim
    
    print(f"MHA KV Cache: {mha_cache:,}")
```

```python
def convert_to_mqa(model, num_kv_heads=1):
    """将模型转换为MQA"""
    
    for name, module in model.named_modules():
        if 'attention' in name.lower():
            if hasattr(module, 'k_proj'):
                # 压缩K和V的维度
                old_k_proj = module.k_proj
                old_v_proj = module.v_proj
                
                new_k_proj = nn.Linear(
                    old_k_proj.in_features,
                    num_kv_heads * module.head_dim
                )
                new_v_proj = nn.Linear(
                    old_v_proj.in_features,
                    num_kv_heads * module.head_dim
                )
                
                # 复制权重
                with torch.no_grad():
                    new_k_proj.weight[:] = old_k_proj.weight[:num_kv_heads]
                    new_v_proj.weight[:] = old_v_proj.weight[:num_kv_heads]
                
                module.k_proj = new_k_proj
                module.v_proj = new_v_proj
    
    return model
```

## 8. 手工代码实现

### 8.1 完整的MQA模型

```python
class SimpleMQA(nn.Module):
    """简化版MQA实现"""
    
    def __init__(self, vocab_size, d_model, num_heads, num_layers):
        super().__init__()
        
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads
        
        self.token_embedding = nn.Embedding(vocab_size, d_model)
        self.position_embedding = nn.Embedding(2048, d_model)
        
        self.layers = nn.ModuleList([
            MQAEncoderLayer(d_model, num_heads)
            for _ in range(num_layers)
        ])
        
        self.lm_head = nn.Linear(d_model, vocab_size, bias=False)
    
    def forward(self, input_ids, position_ids=None, past_kv=None):
        h = self.token_embedding(input_ids)
        
        if position_ids is None:
            position_ids = torch.arange(
                input_ids.size(1), device=input_ids.device
            ).unsqueeze(0)
        
        h = h + self.position_embedding(position_ids)
        
        presents = []
        
        for i, layer in enumerate(self.layers):
            past = past_kv[i] if past_kv is not None else None
            h, present = layer(h, past_key_value=past)
            presents.append(present)
        
        logits = self.lm_head(h)
        
        return logits, presents


class MQAEncoderLayer(nn.Module):
    """MQA Encoder层"""
    
    def __init__(self, d_model, num_heads, dropout=0.1):
        super().__init__()
        
        self.self_attn = MQAInferenceAttention(d_model, num_heads)
        self.feed_forward = nn.Sequential(
            nn.Linear(d_model, 4 * d_model),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(4 * d_model, d_model),
            nn.Dropout(dropout)
        )
        
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
    
    def forward(self, x, past_key_value=None):
        attn_output, present = self.self_attn(
            self.norm1(x), past_key_value=past_key_value
        )
        x = x + attn_output
        
        ff_output = self.feed_forward(self.norm2(x))
        x = x + ff_output
        
        return x, present


class MQAInferenceAttention(nn.Module):
    """推理优化的MQA"""
    
    def __init__(self, d_model, num_heads):
        super().__init__()
        
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads
        
        self.q_proj = nn.Linear(d_model, d_model)
        self.k_proj = nn.Linear(d_model, self.head_dim)
        self.v_proj = nn.Linear(d_model, self.head_dim)
        self.out_proj = nn.Linear(d_model, d_model)
    
    def forward(self, x, past_key_value=None):
        batch_size, seq_len, _ = x.shape
        
        q = self.q_proj(x).view(
            batch_size, seq_len, self.num_heads, self.head_dim
        ).transpose(1, 2)
        
        k = self.k_proj(x).unsqueeze(2)
        v = self.v_proj(x).unsqueeze(2)
        
        if past_key_value is not None:
            past_k, past_v = past_key_value
            k = torch.cat([past_k.expand(-1, -1, self.head_dim), k], dim=2)
            v = torch.cat([past_v.expand(-1, -1, self.head_dim), v], dim=2)
        
        present = (k, v)
        
        scores = torch.matmul(q, k.transpose(-2, -1)) / (self.head_dim ** 0.5)
        
        attn = F.softmax(scores, dim=-1)
        context = torch.matmul(attn, v)
        
        context = context.transpose(1, 2).contiguous().view(
            batch_size, seq_len, -1
        )
        
        return self.out_proj(context), present
```

## 12. 学习总结

### 12.1 核心要点

1. **核心优化**：KV Cache减少90%+
2. **关键改变**：所有Query头共享一套K/V
3. **权衡**：推理快 vs 表达能力
4. **变体**：GQA是MHA和MQA的折中

### 12.2 关键公式

- KV Cache节省：$1 - 1/n_h$
- GQA节省：$1 - g/n_h$

### 12.3 学习路径

```
Multi-Head Attention
   ↓
Multi-Query Attention
   ↓
Grouped Query Attention
   ↓
MLA (潜在注意力)
```

```python
class GroupedQueryAttention(nn.Module):
    def __init__(self, num_q_heads, num_kv_groups):
        self.num_q_heads = num_q_heads
        self.num_kv_groups = num_kv_groups
        
        # KV的头数是 gruppo数
        self.k_proj = nn.Linear(d_model, num_kv_groups * head_dim)
        self.v_proj = nn.Linear(d_model, num_kv_groups * head_dim)
    
    def forward(self, Q):
        K = self.k_proj(x).view(batch, self.num_kv_groups, 1, head_dim)
        V = self.v_proj(x).view(batch, self.num_kv_groups, 1, head_dim)
        # 复制K/V到每个Query head
        K = K.expand(-1, -1, self.num_q_heads // self.num_kv_groups, -1).flatten(1, 2)
```
