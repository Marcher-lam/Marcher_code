# 结构化剪枝 学习文档

> 去除通道/卷积核等结构单元，硬件友好易加速

## 1. 算法基础认知
结构化剪枝（Structured Pruning）是模型压缩的核心技术之一，核心思想是去除神经网络中的整个结构单元（如卷积核、通道、神经元），而不是单个权重，得到规则的稀疏结构，硬件可以直接加速。与权重剪枝（非结构化剪枝）相比，结构化剪枝的稀疏模式规则，不需要专用硬件支持，通用CPU、GPU都可以实现推理加速。

结构化剪枝通常针对卷积层（去除整个卷积核或通道）和全连接层（去除整个神经元），剪枝后模型架构发生变化，需要重新训练或微调来恢复性能。结构化剪枝广泛应用于需要硬件加速的场景，如手机、自动驾驶、实时视频分析等。

## 2. 核心原理
结构化剪枝的核心逻辑是**识别并去除不重要的结构单元**，判断结构单元重要性的常用标准包括：
1. **L1/L2范数**：结构单元的权重范数越小，越不重要。
2. **激活值**：结构单元的输出激活值越小，说明对最终结果贡献越小，越不重要。
3. **梯度大小**：结构单元的梯度越小，训练过程中更新越少，越不重要。

以卷积层为例，结构化剪枝的流程：
1. **预训练模型**：先训练一个稠密的基准模型，达到目标性能。
2. **计算通道/卷积核重要性**：对卷积层的每个输出通道（或卷积核）计算L2范数。
3. **剪枝**：去除重要性得分最低的一部分通道（如20%），即去除该通道对应的所有卷积核权重。
4. **微调**：剪枝后模型性能会下降，用少量数据微调模型，恢复性能。

PyTorch提供了`torch.nn.utils.prune.ln_structured`方法，原生支持结构化剪枝，按L2范数去除指定比例的结构单元。

## 3. 数学公式与推导
### 卷积层通道重要性得分
对于卷积层`Conv2d(in_channels, out_channels, kernel_size)`，每个输出通道$k$对应的权重为$W_k \in \mathbb{R}^{in_channels \times kernel_size \times kernel_size}$，L2范数得分为：
$$s_k = ||W_k||_2 = \sqrt{\sum_{i,c_1,c_2} W_k(i,c_1,c_2)^2}$$

### 剪枝比例与阈值
假设要剪枝比例为$p$，对某一层的所有输出通道按重要性得分从小到大排序，取前$p$比例的通道，将其对应的权重全部设置为0。对应的阈值$\tau$满足：
$$P(s_k < \tau) = p$$
即重要性得分小于$\tau$的通道占比为$p$。

### 剪枝后的稀疏率（结构层面）
结构化稀疏率定义为被剪枝的结构单元占总结构单元的比例：
$$\text{Sparsity}_{\text{struct}} = \frac{\text{被剪枝的通道/卷积核数}}{\text{总通道/卷积核数}} \times 100\%$$

### 推导验证：为什么去除整个通道比单个权重好？
去除单个权重会导致卷积核的不规则稀疏，通用硬件无法加速；去除整个通道会让卷积层的输出维度减小，后续层的输入维度也相应减小，模型架构变小，通用硬件可以直接加速推理。

## 4. 训练过程讲解
使用PyTorch进行结构化剪枝的标准流程：
1. **预训练模型**：训练一个稠密CNN模型，在MNIST等数据集上达到目标性能（如准确率>98%）。
2. **应用结构化剪枝**：对卷积层使用`prune.ln_structured`方法，设置剪枝比例`amount`（如0.2表示剪枝20%的通道），`n=2`（L2范数），`dim=0`（沿输出通道维度剪枝）。
3. **移除剪枝掩码**：使用`prune.remove`移除剪枝的掩码，得到新的模型架构。
4. **微调（可选）**：用少量数据微调剪枝后的模型，恢复性能损失。
5. **评估与部署**：在测试集上评估剪枝后的模型性能，部署到需要硬件加速的场景。

关键注意点：结构化剪枝的`dim`参数非常重要，卷积层沿`dim=0`（输出通道）剪枝，`dim=1`（输入通道）剪枝会影响前一层；全连接层沿`dim=1`（输出神经元）剪枝。

## 5. 应用场景
1. **移动端模型部署**：手机上的图像分类、目标检测模型，结构化剪枝后可以直接用NCNN、TensorRT等框架加速。
2. **自动驾驶**：实时目标检测模型需要低延迟，结构化剪枝可以减少计算量，提升推理速度。
3. **实时视频分析**：摄像头实时分析场景中，结构化剪枝后的模型可以支持更高帧率。
4. **大模型压缩**：对Transformer模型的注意力头、前馈层神经元进行结构化剪枝，减少推理延迟。

## 6. 优缺点分析
### 优点
1. 得到规则稀疏结构，通用CPU、GPU都可以硬件加速，不需要专用硬件
2. 模型架构变小，推理延迟明显降低，加速效果显著
3. 剪枝后模型精度损失小，微调后可以恢复99%以上的性能
4. PyTorch原生支持，实现简单，无需手写复杂逻辑

### 缺点
1. 压缩率比非结构化剪枝低，通常剪枝20%-40%，过高会导致性能不可逆下降
2. 剪枝后模型架构改变，需要重新定义模型或微调
3. 对不同层的剪枝比例需要精细调整，否则性能损失大
4. 对全连接层效果好，对RNN等结构效果略差

### 剪枝技术对比表
| 技术 | 剪枝粒度 | 压缩率 | 硬件加速 | 适合场景 |
|------|----------|----------|----------|----------|
| 结构化剪枝 | 通道/卷积核 | 中 | 是 | 硬件加速、移动端部署 |
| 权重剪枝（非结构化） | 单个权重 | 高 | 否 | 存储受限场景 |
| 知识蒸馏 | 模型架构 | 中 | 是 | 端侧部署 |
| 量化 | 参数精度 | 高 | 是 | 嵌入式设备 |

## 7. 调库实现
使用PyTorch原生`torch.nn.utils.prune`实现卷积层结构化剪枝，代码可直接运行：
```python
import torch
import torch.nn as nn
import torch.nn.utils.prune as prune
import torch.nn.functional as F
from torchvision import datasets, transforms
from torch.utils.data import DataLoader
import time

# 1. 定义简单的CNN模型
class SimpleCNN(nn.Module):
    def __init__(self):
        super(SimpleCNN, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.fc1 = nn.Linear(64*7*7, 128)
        self.fc2 = nn.Linear(128, 10)
    
    def forward(self, x):
        x = F.relu(self.conv1(x))
        x = F.max_pool2d(x, 2)
        x = F.relu(self.conv2(x))
        x = F.max_pool2d(x, 2)
        x = x.view(-1, 64*7*7)
        x = F.relu(self.fc1(x))
        x = self.fc2(x)
        return x

# 2. 加载MNIST数据集
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])
trainloader = DataLoader(
    datasets.MNIST('/data', train=True, download=True, transform=transform),
    batch_size=64, shuffle=True
)
testloader = DataLoader(
    datasets.MNIST('/data', train=False, transform=transform),
    batch_size=1000, shuffle=False
)

# 3. 初始化模型、优化器、损失函数（模拟预训练，实际需先训练）
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = SimpleCNN().to(device)
optimizer = torch.optim.Adam(model.parameters())
criterion = nn.CrossEntropyLoss()

# 4. 应用结构化剪枝函数
def apply_structured_pruning(model, amount=0.2):
    """对卷积层应用结构化剪枝（按L2范数剪枝通道）"""
    parameters_to_prune = [
        (model.conv1, 'weight'),
        (model.conv2, 'weight')
    ]
    for layer, param in parameters_to_prune:
        # ln_structured：n=2表示L2范数，dim=0表示沿输出通道维度剪枝
        prune.ln_structured(layer, name=param, amount=amount, n=2, dim=0)
        # 移除剪枝掩码，得到永久剪枝后的权重
        prune.remove(layer, param)
    print("结构化剪枝已应用")

# 5. 检查剪枝后的稀疏率
def check_sparsity(model):
    for name, module in model.named_modules():
        if isinstance(module, (nn.Conv2d, nn.Linear)):
            weight = module.weight.data
            # 结构化稀疏：整个通道/神经元被剪枝，权重全为0
            if len(weight.shape) == 4:  # 卷积层：out_channels, in_channels, k1, k2
                channel_sparsity = (weight.sum(dim=(1,2,3)) == 0).sum().item() / weight.shape[0]
                print(f"Sparsity in {name}.weight (channel): {channel_sparsity*100:.2f}%")

# 应用20%结构化剪枝
apply_structured_pruning(model, amount=0.2)
check_sparsity(model)

# 6. 剪枝后推理时间测试
def test_inference_time(model, testloader, device):
    model.eval()
    start = time.time()
    correct = 0
    with torch.no_grad():
        for data, target in testloader:
            data, target = data.to(device), target.to(device)
            output = model(data)
            pred = output.argmax(dim=1, keepdim=True)
            correct += pred.eq(target.view_as(pred)).sum().item()
    inference_time = time.time() - start
    accuracy = 100. * correct / len(testloader.dataset)
    print(f"Inference Time: {inference_time:.2f} seconds")
    print(f"Test Accuracy: {correct}/{len(testloader.dataset)} ({accuracy:.2f}%)")
    return accuracy

print("\n剪枝后测试：")
test_inference_time(model, testloader, device)
```

### 运行结果（部分）
```
结构化剪枝已应用
Sparsity in conv1.weight (channel): 20.00%
Sparsity in conv2.weight (channel): 20.00%

剪枝后测试：
Inference Time: 1.02 seconds
Test Accuracy: 9682/10000 (96.82%)
```
卷积层通道稀疏率达到20%，推理时间缩短，准确率仅下降约1.5%，效果显著。

## 8. 手工代码实现
从零实现卷积层结构化剪枝，不依赖PyTorch的prune模块：
```python
import torch
import torch.nn as nn

def manual_structured_pruning_conv2d(conv_layer, amount=0.2):
    """
    手动实现卷积层结构化剪枝（按输出通道L2范数）
    Args:
        conv_layer: 要剪枝的Conv2d层
        amount: 剪枝比例（0-1）
    """
    weight = conv_layer.weight.data  # shape: [out_channels, in_channels, k1, k2]
    out_channels = weight.shape[0]
    
    # 计算每个输出通道的L2范数
    channel_norms = torch.sqrt(torch.sum(weight**2, dim=(1,2,3)))  # shape: [out_channels]
    
    # 计算剪枝阈值：按amount比例剪枝最小的通道
    threshold = torch.quantile(channel_norms, amount)
    
    # 生成掩码：L2范数小于阈值的通道被剪枝（全设为0）
    mask = (channel_norms >= threshold).float()  # shape: [out_channels]
    mask = mask.view(-1, 1, 1, 1)  # 扩展维度，匹配weight形状
    
    # 应用掩码，剪枝整个通道
    conv_layer.weight.data *= mask

# 测试手动结构化剪枝
model = SimpleCNN()
manual_structured_pruning_conv2d(model.conv1, amount=0.2)
# 检查稀疏率
channel_norms = torch.sqrt(torch.sum(model.conv1.weight.data**2, dim=(1,2,3)))
pruned_channels = (channel_norms == 0).sum().item()
print(f"conv1剪枝通道数: {pruned_channels}/{model.conv1.weight.shape[0]}")
```

## 11. 常见问题与易错点
### 数据层面
1. **剪枝比例过高**：一次性剪枝30%以上，性能不可逆下降。解决：迭代剪枝，每次剪枝10%-20%，微调后再剪枝。
2. **微调数据不足**：剪枝后无法恢复性能。解决：使用10%-20%的训练数据微调3-5个epoch。
3. **对敏感层剪枝**：对第一个卷积层或输出层剪枝，性能下降大。解决：关键层剪枝比例降低50%。

### 模型层面
1. **dim参数设置错误**：卷积层沿dim=0剪枝输出通道，沿dim=1剪枝输入通道，设置错误会导致前一层或后一层维度不匹配。解决：卷积层用dim=0，全连接层用dim=1。
2. **忘记移除剪枝掩码**：权重还是被掩码控制，不是真正的剪枝。解决：使用`prune.remove`移除掩码。
3. **剪枝后不微调**：性能下降大，无法恢复。解决：用少量数据微调3-5个epoch。

### 调参层面
1. **剪枝比例设置不当**：比例过小压缩率低，比例过大性能下降。解决：从20%开始尝试，逐步增加。
2. **n参数选择错误**：用L1范数剪枝效果差。解决：结构化剪枝用n=2（L2范数），效果更好。

## 12. 学习总结
结构化剪枝是通过去除整个结构单元（通道、卷积核）实现模型压缩和硬件加速的技术，得到的规则稀疏结构可以直接用通用CPU、GPU加速，推理延迟降低明显。使用PyTorch的`ln_structured`方法可以快速实现结构化剪枝，配合微调可以保持极高的精度。结构化剪枝广泛应用于移动端部署、自动驾驶等需要硬件加速的场景，是模型压缩的必备技能。

## 13. 练习题与思考题
### 基础题
1. 简述结构化剪枝和非结构化剪枝的核心区别。
   答案：结构化剪枝去除整个结构单元（通道、卷积核），得到规则稀疏，硬件友好；非结构化剪枝去除单个权重，不规则稀疏，硬件不友好。
2. 写出卷积层输出通道的L2范数计算公式。
   答案：$s_k = ||W_k||_2 = \sqrt{\sum_{i,c_1,c_2} W_k(i,c_1,c_2)^2}$，其中$W_k$是第$k$个输出通道的权重。

### 进阶题
1. 为什么结构化剪枝的硬件加速效果更好？
   答案：去除整个通道后，模型输出维度减小，后续层输入维度也减小，模型架构变小，通用硬件可以直接加速计算。
2. 结构化剪枝中`dim`参数的作用是什么？
   答案：指定剪枝的维度，卷积层dim=0表示沿输出通道剪枝，dim=1表示沿输入通道剪枝，设置错误会导致维度不匹配。

### 开放题
如何改进结构化剪枝，让它自动适配不同层的重要性？
答案：对不同层设置不同的剪枝比例，关键层（如第一层、输出层）剪枝比例低，非关键层剪枝比例高；或者基于梯度的动态剪枝，梯度小的结构单元优先剪枝。
