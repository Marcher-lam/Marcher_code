# 贝叶斯意外模型 学习文档

> 用概率论量化"意外"——视觉显著性由意外程度决定。

## 1. 算法基础认知

**一句话定义：** 贝叶斯意外模型（Bayesian Surprise, BS）由Baldi和Itti于2005年提出，使用贝叶斯推理量化视觉刺激的"意外"程度，认为视觉注意力被高意外性的区域吸引。

**直觉类比：** 想象你每天都走同一条路，路边的景色你已经熟悉（先验信念）。突然有一天，路边出现了一栋新建筑（新观测数据）。这个新建筑会让你感到"意外"——你的信念被显著改变了。贝叶斯意外模型量化了这种"信念改变的程度"作为显著性。

**核心思想：** 视觉显著性 = 后验分布与先验分布的差异。当新观测数据显著地改变了对场景的信念时，该位置被认为"意外"且吸引注意。

**数学基础：** 
$$S(D) = \int P(M) \log\frac{P(M|D)}{P(M)} dM$$

其中 $S(D)$ 是数据 $D$ 带来的意外度，$P(M)$ 是先验分布，$P(M|D)$ 是后验分布。

**算法定位：** 基于概率推理的传统视觉显著性模型。

## 2. 核心原理

### 2.1 工作流程

```
先验信念 P(M) → 新观测数据 D → 贝叶斯更新 P(M|D)
→ 计算意外度 S(D) = KL(P(M|D) || P(M)) → 显著性图
```

### 2.2 关键概念

**KL散度：** 意外度的数学基础：$S(D) = KL(P(M|D) || P(M))$

**贝叶斯更新：** $P(M|D) = \frac{P(D|M)P(M)}{P(D)}$

**先验分布：** 对场景特征的先验知识（如颜色分布、纹理分布）

**似然函数：** $P(D|M)$ 给定模型（特征分布）下观测到数据D的概率

### 2.3 为什么是KL散度？

KL散度满足意外度的合理性质：
- 当后验=先验时（没有新信息），KL=0 → 不意外
- 当后验先验差异大时，KL大 → 很意外
- KL散度非负且不对称，符合"意外"的直觉

## 3. 数学公式与推导

### 3.1 高斯分布假设下的闭式解

假设先验 $P(\mu) = \mathcal{N}(\mu_0, \sigma_0^2)$，似然 $P(D|\mu) = \mathcal{N}(\mu, \sigma^2)$。

**后验更新：**

后验均值：
$$\mu_{\text{post}} = \frac{\sigma_0^{-2}\mu_0 + \sigma^{-2}D}{\sigma_0^{-2} + \sigma^{-2}}$$

后验方差：
$$\sigma_{\text{post}}^2 = \frac{1}{\sigma_0^{-2} + \sigma^{-2}}$$

**KL散度（两个高斯分布之间）：**

$$KL(\mathcal{N}(\mu_1, \sigma_1^2) || \mathcal{N}(\mu_2, \sigma_2^2)) = \log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2} - \frac{1}{2}$$

代入后验 $\mathcal{N}(\mu_{\text{post}}, \sigma_{\text{post}}^2)$ 和先验 $\mathcal{N}(\mu_0, \sigma_0^2)$：

$$S(D) = \log\frac{\sigma_0}{\sigma_{\text{post}}} + \frac{\sigma_{\text{post}}^2 + (\mu_{\text{post}} - \mu_0)^2}{2\sigma_0^2} - \frac{1}{2}$$

### 3.2 推导过程

从KL散度定义出发：

$$KL(Q||P) = \int Q(x) \log\frac{Q(x)}{P(x)} dx$$

对高斯分布 $Q = \mathcal{N}(\mu_1, \sigma_1^2)$，$P = \mathcal{N}(\mu_2, \sigma_2^2)$：

$$\log\frac{Q(x)}{P(x)} = \frac{1}{2}\log\frac{\sigma_2^2}{\sigma_1^2} + \frac{(x-\mu_2)^2}{2\sigma_2^2} - \frac{(x-\mu_1)^2}{2\sigma_1^2}$$

在 $Q$ 下求期望：

$$\mathbb{E}_Q[\log\frac{Q}{P}] = \frac{1}{2}\log\frac{\sigma_2^2}{\sigma_1^2} + \frac{\sigma_1^2 + (\mu_1-\mu_2)^2}{2\sigma_2^2} - \frac{1}{2}$$

## 4. 训练过程讲解

贝叶斯意外模型**不需要训练**。它直接使用贝叶斯推理计算每一点的意外度。

对于图像显著性检测：
1. 将图像划分为局部区域（块或像素）
2. 对每个区域，维护一个先验分布（通常为高斯分布）
3. 该区域的观测值为特征（如像素值、颜色）
4. 计算贝叶斯更新
5. 计算KL散度作为意外度

## 5. 应用场景

1. **眼动预测**：比较意外度图与真实眼动数据
2. **事件检测**：检测视频中的意外事件（如突然出现的物体）
3. **异常检测**：在监控视频中检测异常行为
4. **主动学习**：选择最"意外"的样本进行标注

## 6. 优缺点分析

### 优点
1. **理论基础坚实**：基于贝叶斯概率框架
2. **可解释性强**：意外度的物理含义明确
3. **动态更新**：可处理时间序列中的显著性变化

### 缺点
1. **计算复杂**：每个位置需要独立的贝叶斯更新
2. **先验选择敏感**：先验分布的参数对结果影响大
3. **特征表达有限**：低层特征限制了效果

## 7. 调库实现

```python
"""
贝叶斯意外模型完整实现
"""

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm


class BayesianSurprise:
    """贝叶斯意外模型

    使用高斯分布建模先验和后验，
    用KL散度量化意外度。

    参数:
        prior_mean: 先验均值
        prior_var: 先验方差
        obs_var: 观测噪声方差
    """

    def __init__(self, prior_mean=0.5, prior_var=0.25, obs_var=0.1):
        self.prior_mean = prior_mean
        self.prior_var = prior_var
        self.obs_var = obs_var

    def compute_surprise(self, observation):
        """计算单个观测值的意外度

        参数:
            observation: 观测值（标量）

        返回:
            surprise: KL散度值
        """
        # 后验更新
        posterior_var = 1 / (1/self.prior_var + 1/self.obs_var)
        posterior_mean = posterior_var * (
            self.prior_mean/self.prior_var + observation/self.obs_var
        )

        # KL散度: KL(N(mu_post, var_post) || N(mu_prior, var_prior))
        kl = (0.5 * (np.log(self.prior_var / posterior_var)
              + (posterior_var + (posterior_mean - self.prior_mean)**2)
              / self.prior_var - 1))

        # 更新先验（序列贝叶斯）
        self.prior_mean = posterior_mean
        self.prior_var = posterior_var

        return kl

    def compute_image_surprise(self, image, window_size=8):
        """计算图像的意外度图

        参数:
            image: HxW 灰度图像
            window_size: 局部窗口大小

        返回:
            surprise_map: HxW 意外度图
        """
        h, w = image.shape
        surprise_map = np.zeros_like(image, dtype=np.float32)

        for i in range(0, h - window_size, window_size // 2):
            for j in range(0, w - window_size, window_size // 2):
                patch = image[i:i+window_size, j:j+window_size]
                obs = np.mean(patch)
                surprise = self.compute_surprise(obs)
                surprise_map[i:i+window_size, j:j+window_size] = surprise

        return surprise_map

    def compute_surprise_sequence(self, observations):
        """计算时间序列的意外度

        参数:
            observations: (T,) 观测序列

        返回:
            surprises: (T,) 意外度序列
        """
        # 重置先验
        self.prior_mean = self.prior_mean_orig if hasattr(self, 'prior_mean_orig') else self.prior_mean
        self.prior_var = self.prior_var_orig if hasattr(self, 'prior_var_orig') else self.prior_var

        surprises = []
        for obs in observations:
            s = self.compute_surprise(obs)
            surprises.append(s)
        return np.array(surprises)


def demo():
    np.random.seed(42)

    # 测试图像
    image = np.random.rand(64, 64)
    image[20:40, 20:40] = 0.9  # 显著物体

    model = BayesianSurprise(prior_mean=0.5, prior_var=0.25, obs_var=0.1)
    surprise_map = model.compute_image_surprise(image)

    print("=== 贝叶斯意外模型 ===")
    print(f"意外度范围: [{surprise_map.min():.4f}, {surprise_map.max():.4f}]")
    print(f"目标区域意外度: {surprise_map[20:40, 20:40].mean():.4f}")
    print(f"背景意外度: {surprise_map[:20, :20].mean():.4f}")

    # 时间序列演示
    print("\n=== 时间序列意外度 ===")
    model2 = BayesianSurprise(prior_mean=0, prior_var=1, obs_var=0.5)
    # 正常序列
    normal = np.random.randn(20) * 0.5
    # 突然的异常
    abnormal = np.array([0.5] * 10 + [5.0] + [0.5] * 9)
    surprises_normal = model2.compute_surprise_sequence(normal)
    model2 = BayesianSurprise(prior_mean=0, prior_var=1, obs_var=0.5)
    surprises_abnormal = model2.compute_surprise_sequence(abnormal)
    print(f"正常序列平均意外度: {np.mean(surprises_normal):.4f}")
    print(f"异常序列平均意外度: {np.mean(surprises_abnormal):.4f}")
    print(f"异常时刻意外度: {surprises_abnormal[10]:.4f} (远大于正常值)")


if __name__ == "__main__":
    demo()
```

## 8. 手工实现

```python
"""贝叶斯意外核心手工实现"""
import numpy as np

def bayesian_surprise_gaussian(prior_mean, prior_var, obs, obs_var=0.1):
    """手工贝叶斯意外度计算"""
    post_var = 1 / (1/prior_var + 1/obs_var)
    post_mean = post_var * (prior_mean/prior_var + obs/obs_var)
    kl = 0.5 * (np.log(prior_var / post_var)
                + (post_var + (post_mean - prior_mean)**2) / prior_var
                - 1)
    return kl, post_mean, post_var

def test():
    prior_m, prior_v = 0.5, 0.25
    obs = 0.9
    kl, post_m, post_v = bayesian_surprise_gaussian(prior_m, prior_v, obs)
    print(f"观测值={obs:.2f}")
    print(f"先验: N({prior_m:.2f}, {prior_v:.4f})")
    print(f"后验: N({post_m:.2f}, {post_v:.4f})")
    print(f"意外度(KL): {kl:.4f}")
    # 预期：观测值远离先验 → KL大

if __name__ == "__main__":
    test()
```

```python
import matplotlib.pyplot as plt
import numpy as np
from scipy.stats import norm

def visualize_bayesian_update(save_path='bayesian_surprise.png'):
    """可视化贝叶斯更新过程"""
    prior = norm(0.5, 0.5)
    obs = 0.9
    post_var = 1 / (1/0.25 + 1/0.1)
    post_mean = post_var * (0.5/0.25 + 0.9/0.1)
    posterior = norm(post_mean, np.sqrt(post_var))

    x = np.linspace(-1, 2, 200)
    fig, axes = plt.subplots(1, 2, figsize=(12, 4))

    axes[0].plot(x, prior.pdf(x), 'b-', linewidth=2, label='先验')
    axes[0].plot(x, posterior.pdf(x), 'r-', linewidth=2, label='后验')
    axes[0].axvline(obs, color='g', linestyle='--', label=f'观测值={obs}')
    axes[0].fill_between(x, prior.pdf(x), alpha=0.1, color='blue')
    axes[0].fill_between(x, posterior.pdf(x), alpha=0.1, color='red')
    axes[0].set_xlabel('μ'); axes[0].set_ylabel('概率密度')
    axes[0].set_title('贝叶斯更新: 先验→后验')
    axes[0].legend(); axes[0].grid(True, alpha=0.3)

    # 意外度 vs 观测值
    obs_range = np.linspace(0, 1, 50)
    kl_vals = []
    prior_m, prior_v = 0.5, 0.25
    for o in obs_range:
        kl, _, _ = bayesian_surprise_gaussian(prior_m, prior_v, o)
        kl_vals.append(kl)

    axes[1].plot(obs_range, kl_vals, 'b-', linewidth=2)
    axes[1].axvline(prior_m, color='r', linestyle='--', label=f'先验均值={prior_m}')
    axes[1].set_xlabel('观测值'); axes[1].set_ylabel('意外度 (KL)')
    axes[1].set_title('意外度 vs 观测值')
    axes[1].legend(); axes[1].grid(True, alpha=0.3)

    plt.tight_layout()
    plt.savefig(save_path, dpi=150)
    print(f"已保存到 {save_path}")
```

```python
"""贝叶斯意外模型评估"""
def evaluate_bayesian_surprise(pred_surprise, gt_fixation):
    from sklearn.metrics import roc_auc_score
    import numpy as np
    p = pred_surprise.flatten()
    g = gt_fixation.flatten()
    auc = roc_auc_score((g > g.mean()).astype(int), p)
    cc = np.corrcoef(p, g)[0, 1]
    return {'AUC': auc, 'CC': cc}
```

## 11. 常见问题与易错点

**Q1: 贝叶斯意外模型和ITTI模型的主要区别？**
ITTI基于特征对比度（中心-周围差），关注局部差异。贝叶斯意外模型基于信息论（KL散度），关注信念更新的程度。

**Q2: 先验分布如何选择？**
通常使用高斯分布。先验均值可以是图像的平均强度，先验方差控制对"意外"的敏感度。方差越小，对微小变化的敏感性越高。

**Q3: 为什么KL散度不是对称的？**
KL散度度量的是"从先验更新到后验所需的信息量"。这个信息量天然不对称——从A到B和从B到A的信息量不同。

## 12. 学习总结

- 贝叶斯意外模型用概率论量化"意外"
- 核心公式：KL散度度量先验和后验的差异
- 高斯分布假设下可得到闭式解
- 适用于空间和时间序列的显著性检测
- 理论基础坚实但实际效果受限于低层特征

## 13. 练习题

**基础题：**

1. 贝叶斯意外模型的数学基础是什么？意外度如何计算？
> **答案：** KL散度。$S(D) = KL(P(M|D) || P(M))$，即后验分布与先验分布的KL散度。

2. 在高斯分布假设下，后验均值和方差的更新公式是什么？
> **答案：** $\mu_{\text{post}} = \frac{\sigma_0^{-2}\mu_0 + \sigma^{-2}D}{\sigma_0^{-2} + \sigma^{-2}}$，$\sigma_{\text{post}}^2 = \frac{1}{\sigma_0^{-2} + \sigma^{-2}}$。

**进阶题：**

3. 如果观测值等于先验均值，意外度是多少？为什么？
> **答案：** 接近0。因为观测值没有提供新信息，后验=先验，KL散度=0。

4. 贝叶斯意外模型如何扩展到多模态特征？
> **答案：** 使用多维高斯分布或多变量KL散度。每个特征维度对应一个高斯分量，计算多维KL散度作为总意外度。

5. 在贝叶斯意外模型中，观测方差 $obs\\_var$ 的大小如何影响结果？
> **答案：** obs_var越小（观测越可靠），后验更新幅度越大，意外度越高。obs_var越大（观测不可靠），后验几乎不变，意外度很低。这符合直觉：可靠的意外事件比不可靠的信息更引人注意。

6. 序列贝叶斯更新中，先验更新后对后续意外度有什么影响？
> **答案：** 每次更新后，先验变得更"适应"当前环境。如果环境稳定，后续观测的意外度会逐渐降低（习惯化）。如果环境突变，意外度会再次升高。
