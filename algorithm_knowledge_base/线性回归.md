# 线性回归 学习文档

## 1. 算法基础认知
线性回归是监督学习中最基础的回归算法，用于预测连续数值型目标变量。它假设目标变量与输入特征之间存在线性关系。

## 2. 核心原理
线性回归通过构建一个线性模型来描述输入特征与输出值之间的关系。模型试图找到一条直线（在二维空间）或超平面（在多维空间），使得所有数据点到该超平面的距离平方和最小。

## 3. 数学公式与推导
给定训练集 $D = \{(\boldsymbol{x}_1, y_1), (\boldsymbol{x}_2, y_2), \dots, (\boldsymbol{x}_n, y_n)\}$，其中 $\boldsymbol{x}_i \in \mathbb{R}^d$，$y_i \in \mathbb{R}$。

线性回归模型假设：
$$
y = \boldsymbol{w}^T \boldsymbol{x} + b
$$

其中 $\boldsymbol{w}$ 是权重向量，$b$ 是偏置。

**正规方程解**：
$$\boldsymbol{w} = (\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{y}$$

**梯度下降更新规则**：
$$\boldsymbol{w} := \boldsymbol{w} - \alpha \nabla_{\boldsymbol{w}} J(\boldsymbol{w})$$
其中代价函数 $J(\boldsymbol{w}) = \frac{1}{2n}\sum_{i=1}^{n}(\boldsymbol{w}^T\boldsymbol{x}_i + b - y_i)^2$

## 4. 训练过程讲解
1. 初始化权重 $\boldsymbol{w}$ 和偏置 $b$（通常为0或小随机数）
2. 计算预测值 $\hat{y} = \boldsymbol{w}^T\boldsymbol{x} + b$
3. 计算损失（误差）
4. 使用梯度下降更新参数
5. 重复直到收敛

## 5. 应用场景
- 房价预测
- 股票价格预测
- 销售预测
- 任何连续值预测问题

## 6. 优缺点分析
**优点**：
- 模型简单，易于理解和实现
- 训练速度快
- 可解释性强
- 作为其他复杂模型的基础

**缺点**：
- 假设线性关系，无法捕捉非线性模式
- 对异常值敏感
- 容易欠拟合复杂数据

## 7. 调库实现（Python + 完整代码 + 注释）
```python
import numpy as np
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score
from sklearn.preprocessing import StandardScaler

# 生成示例数据
np.random.seed(42)
X = 2 * np.random.rand(100, 1)
y = 4 + 3 * X + np.random.randn(100, 1)

# 特征标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 使用sklearn线性回归
model = LinearRegression()
model.fit(X_scaled, y)

# 预测
y_pred = model.predict(X_scaled)

# 评估
mse = mean_squared_error(y, y_pred)
r2 = r2_score(y, y_pred)
print(f"MSE: {mse:.4f}, R2: {r2:.4f}")
print(f"权重: {model.coef_[0][0]:.4f}, 偏置: {model.intercept_[0]:.4f}")

# 使用Ridge回归（带L2正则化）
ridge = Ridge(alpha=1.0)
ridge.fit(X_scaled, y)
print(f"Ridge权重: {ridge.coef_[0][0]:.4f}")

# 使用Lasso回归（带L1正则化）
lasso = Lasso(alpha=0.1)
lasso.fit(X_scaled, y)
print(f"Lasso权重: {lasso.coef_[0][0]:.4f}")
```

## 8. 手工代码实现（核心算法手写 + 注释）
```python
import numpy as np

class LinearRegressionScratch:
    def __init__(self, lr=0.01, n_iters=1000):
        self.lr = lr
        self.n_iters = n_iters
        self.weights = None
        self.bias = None
        self.cost_history = []
    
    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.weights = np.zeros(n_features)
        self.bias = 0
        
        # 梯度下降
        for i in range(self.n_iters):
            y_pred = np.dot(X, self.weights) + self.bias
            
            # 计算代价
            cost = (1 / (2 * n_samples)) * np.sum((y_pred - y) ** 2)
            self.cost_history.append(cost)
            
            # 计算梯度
            dw = (1 / n_samples) * np.dot(X.T, (y_pred - y))
            db = (1 / n_samples) * np.sum(y_pred - y)
            
            # 更新参数
            self.weights -= self.lr * dw
            self.bias -= self.lr * db
    
    def predict(self, X):
        return np.dot(X, self.weights) + self.bias

# 使用示例
if __name__ == "__main__":
    # 生成数据
    X = 2 * np.random.rand(100, 1)
    y = 4 + 3 * X + np.random.randn(100, 1)
    
    # 训练
    model = LinearRegressionScratch(lr=0.01, n_iters=1000)
    model.fit(X, y)
    
    # 预测
    predictions = model.predict(X)
    print(f"手工实现权重: {model.weights[0]:.4f}, 偏置: {model.bias:.4f}")
```

## 13. 练习题与思考题（含答案）
1. 为什么需要计算代价函数的梯度？
   答：梯度指示了代价函数增长最快的方向，反向梯度下降可以使代价函数最小化。
2. 正规方程和梯度下降各有什么优缺点？
   答：正规方程精确求解但计算复杂度高（O(n³)）；梯度下降可处理大数据但需要调参。
3. 如何处理特征数量远大于样本数量的情况？
   答：可以使用正则化（Ridge/Lasso）或降维技术（PCA）。
