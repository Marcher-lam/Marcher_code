## 1. 算法基础认知

### 1.1 一句话定义
T5（Text-to-Text Transfer Transformer）是Google于2019年提出的统一文本到文本框架，将所有NLP任务统一转换为"输入文本→输出文本"的Seq2Seq格式，用单一模型和单一训练目标处理翻译、分类、摘要、问答等所有任务。

### 1.2 直觉类比
T5就像一个"万能翻译器"——不管你给它什么任务，它都当"翻译"来做。分类？翻译成类别名。摘要？翻译成短文本。翻译？从一种语言翻译成另一种。所有任务都变成"你给我一段文本，我给你一段文本"。

### 1.3 历史背景
- **2019年10月**：Google发布T5（Text-to-Text Transfer Transformer）
- **参数量**：Base 220M，Large 770M，3B，11B（最大版本）
- **数据集**：C4（Colossal Clean Crawled Corpus），750GB清洗后的网页文本
- **意义**："统一框架"思想的代表作，系统性研究了预训练的各种设计选择

### 1.4 算法定位
T5是**编码器-解码器Transformer**，采用Span Corruption预训练目标，所有任务统一为Text-to-Text格式。

## 2. 核心原理

### 2.1 Text-to-Text框架
所有任务都表示为：

```
输入:  "task_prefix: task_specific_input"
输出:  "target_text"
```

| 任务 | 输入格式 | 输出 |
|------|----------|------|
| 翻译 | "translate English to German: Hello" | "Hallo" |
| 分类 | "cola: The boy walks." | "acceptable" |
| 摘要 | "summarize: ..." | "摘要文本" |
| 问答 | "question: What is the capital? context: ..." | "Paris" |
| 相似度 | "stsb: sentence1 sentence2" | "3.8" |

### 2.2 Span Corruption预训练
T5不像BERT那样mask单个token，而是mask连续的span（文本片段）：

**输入**: "Thank you [X] me to your [Y]."
**输出**: "[X] for inviting [Y] party."

其中 [X], [Y] 是sentinel token（哨兵标记），解码器预测被mask的span内容。

### 2.3 编码器-解码器架构
- **编码器**：双向注意力（类似BERT）
- **解码器**：因果注意力（类似GPT），可交叉注意编码器输出
- 编码器和解码器各12层（Base版本）

## 3. 数学公式与推导

### 3.1 Span Corruption目标
原始序列 $x$，随机采样 $k$ 个span（长度服从 $\lambda=3$ 的泊松分布）：

对于每个span $s_i$（位置 $[a_i, b_i]$）：
- 编码器输入 $x_{\text{noisy}}$：用 sentinel token `<extra_id_i>` 替换 $x_{a_i:b_i}$
- 解码器目标：`<extra_id_i> x_{a_i:b_i} <extra_id_{i+1}> ...`

损失函数（解码器上的交叉熵）：

$$L = -\sum_{t=1}^{T_{\text{dec}}} \log P(y_t | y_{<t}, x_{\text{noisy}})$$

其中 $y$ 是解码器目标序列。

### 3.2 Text-to-Text的数学统一性
对于任意任务 $k$，数据集 $D_k$ 包含输入 $I$ 和输出 $O$：

$$L_k = -\mathbb{E}_{(I,O)\sim D_k} \log P(O | \text{prefix}_k: I)$$

所有任务的最小化同一目标函数，只是前缀不同。

### 3.3 相对位置偏置
T5使用简化的相对位置编码：每个注意力头维护一个标量偏置 $b_{i-j}$，截断到 $[-8, 8]$ 范围共16个bucket：

$$b_{i-j} = \text{learned\_bias}[\text{clip}(i-j, -8, 8) + 8]$$

### 3.4 模型缩放
T5的模型配置：

| 模型 | 层数 | d_model | d_ff | 头数 | 参数量 |
|------|------|---------|------|------|--------|
| T5-Small | 6 | 512 | 2048 | 8 | 60M |
| T5-Base | 12 | 768 | 3072 | 12 | 220M |
| T5-Large | 24 | 1024 | 4096 | 16 | 770M |
| T5-3B | 24 | 1024 | 16384 | 32 | 2.8B |
| T5-11B | 24 | 1024 | 65536 | 128 | 11B |

## 4. 训练过程讲解

### 4.1 预训练：Span Corruption
1. 从C4数据集中采样文本
2. 随机mask 15%的token为连续span
3. 构造编码器输入（带sentinel token的损坏文本）
4. 构造解码器目标（sentinel + 原始span内容）
5. 计算解码器上的交叉熵损失
6. 更新编码器和解码器参数

### 4.2 微调：Text-to-Text
1. 加载预训练权重
2. 为每个任务添加任务前缀
3. 在任务数据上计算标准交叉熵损失
4. 可选：多任务联合训练

### 4.3 推理
编码器处理输入文本，解码器自回归生成输出文本。

## 6. 优缺点分析

### 优点
1. **统一框架**：所有任务同一格式，无需任务特定架构
2. **系统研究**：T5论文系统比较了各种设计选择（架构、目标、数据集）
3. **强大性能**：在多项基准上达到SOTA
4. **灵活性强**：新任务只需定义输入输出格式

### 缺点
1. **推理慢**：编码器-解码器架构，自回归生成
2. **参数量大**：11B版本需要大量计算资源
3. **任务前缀需要设计**：不同前缀可能影响效果
4. **C4数据质量问题**：虽然清洗过，仍有噪声

## 7. 调库实现（Python + 完整代码 + 注释）

```python
import torch
import torch.nn as nn
from transformers import T5ForConditionalGeneration, T5Tokenizer, T5Config

class T5UnifiedModel:
    """T5统一文本到文本模型"""
    def __init__(self, model_name="t5-base"):
        self.tokenizer = T5Tokenizer.from_pretrained(model_name)
        self.model = T5ForConditionalGeneration.from_pretrained(model_name)
        self.device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
        self.model.to(self.device)
        self.model.eval()
        
    def run_task(self, input_text, task_type, max_length=50):
        """统一任务接口"""
        # 构建任务前缀
        prefix_map = {
            'translate_en2zh': 'translate English to Chinese: ',
            'translate_en2de': 'translate English to German: ',
            'translate_en2fr': 'translate English to French: ',
            'summarize': 'summarize: ',
            'cola': 'cola sentence: ',
            'sst2': 'sst2 sentence: ',
            'imdb': 'imdb: ',
            'qnli': 'qnli: ',
            'stsb': 'stsb: ',
        }
        
        prefix = prefix_map.get(task_type, '')
        full_input = prefix + input_text
        
        inputs = self.tokenizer(
            full_input,
            return_tensors='pt',
            max_length=512,
            truncation=True
        ).to(self.device)
        
        with torch.no_grad():
            outputs = self.model.generate(
                **inputs,
                max_length=max_length,
                num_beams=4,
                early_stopping=True,
                no_repeat_ngram_size=3 if task_type == 'summarize' else 0
            )
            
        return self.tokenizer.decode(outputs[0], skip_special_tokens=True)


class T5FineTuner:
    """T5微调器"""
    def __init__(self, model_name="t5-base"):
        self.tokenizer = T5Tokenizer.from_pretrained(model_name)
        self.model = T5ForConditionalGeneration.from_pretrained(model_name)
        self.device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
        self.model.to(self.device)
        
    def prepare_inputs(self, input_texts, target_texts, task_prefix=""):
        """准备训练数据"""
        full_inputs = [task_prefix + text for text in input_texts]
        
        model_inputs = self.tokenizer(
            full_inputs,
            max_length=512,
            truncation=True,
            padding=True,
            return_tensors='pt'
        ).to(self.device)
        
        with self.tokenizer.as_target_tokenizer():
            labels = self.tokenizer(
                target_texts,
                max_length=128,
                truncation=True,
                padding=True,
                return_tensors='pt'
            ).to(self.device)
            
        model_inputs['labels'] = labels.input_ids
        return model_inputs
    
    def train_step(self, input_texts, target_texts, task_prefix="", lr=3e-5):
        """单步训练"""
        self.model.train()
        optimizer = torch.optim.AdamW(self.model.parameters(), lr=lr)
        
        inputs = self.prepare_inputs(input_texts, target_texts, task_prefix)
        
        outputs = self.model(**inputs)
        loss = outputs.loss
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        return loss.item()


class T5SpanCorruption(nn.Module):
    """T5 Span Corruption预训练目标实现"""
    def __init__(self, model_name="t5-base"):
        super().__init__()
        self.model = T5ForConditionalGeneration.from_pretrained(model_name)
        self.tokenizer = T5Tokenizer.from_pretrained(model_name)
        
    def corrupt_spans(self, input_ids, corruption_rate=0.15, span_length=3):
        """
        应用Span Corruption
        Args:
            input_ids: 原始token序列 [B, L]
        Returns:
            noisy_input_ids: 带sentinel的输入
            decoder_input_ids: 解码器输入
            labels: 解码器标签
        """
        # 简化实现：随机选择corruption_rate的token
        # 实际T5使用泊松分布采样span长度
        B, L = input_ids.shape
        device = input_ids.device
        
        sentinel_ids = torch.arange(32000, 32100, device=device)  # sentinel token
        
        noisy_inputs = []
        decoder_inputs = []
        all_labels = []
        
        for b in range(B):
            tokens = input_ids[b].tolist()
            
            # 随机选择span
            num_noisy = int(L * corruption_rate)
            noisy_positions = sorted(torch.randperm(L)[:num_noisy].tolist())
            
            # 构建noisy输入和decoder目标
            noisy = []
            decoder = []
            sentinel_idx = 0
            
            i = 0
            while i < L:
                if i in noisy_positions:
                    # 开始一个span
                    sid = sentinel_ids[sentinel_idx].item()
                    noisy.append(sid)
                    decoder.append(sid)
                    sentinel_idx += 1
                    
                    # 添加span内容到decoder
                    span_end = i
                    while span_end < L and span_end - i < span_length and span_end in noisy_positions:
                        decoder.append(tokens[span_end])
                        span_end += 1
                    
                    i = span_end
                else:
                    noisy.append(tokens[i])
                    i += 1
            
            noisy_inputs.append(noisy[:L])  # 保持长度
            decoder_inputs.append(decoder)
            all_labels.append(decoder)
        
        return (torch.tensor(noisy_inputs, device=device),
                torch.tensor(decoder_inputs, device=device),
                torch.tensor(all_labels, device=device))


def test_t5():
    """测试T5基本功能"""
    t5 = T5UnifiedModel("t5-small")
    
    # 翻译
    result = t5.run_task("Hello, how are you?", "translate_en2de")
    print(f"翻译 (en→de): {result}")
    
    # 摘要
    text = "The Transformer architecture is a deep learning model introduced in 2017. It relies on self-attention mechanisms to process sequential data. Since its introduction, it has become the dominant architecture in NLP."
    summary = t5.run_task(text, "summarize", max_length=30)
    print(f"摘要: {summary}")
    
    print("T5测试通过！")

if __name__ == "__main__":
    test_t5()
```

## 8. 手工代码实现（核心算法手写 + 注释）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math
import copy

class HandwrittenT5(nn.Module):
    """T5核心逻辑手工实现"""
    def __init__(self, vocab_size=32128, d_model=768, nhead=12,
                 num_encoder_layers=12, num_decoder_layers=12):
        super().__init__()
        self.d_model = d_model
        
        # 共享嵌入
        self.shared = nn.Embedding(vocab_size, d_model)
        
        # 相对位置偏置（16个bucket）
        self.rel_pos_bias = nn.Embedding(32, nhead)  # -8~8 + padding
        
        # 编码器
        self.encoder_layers = nn.ModuleList([
            T5Layer(d_model, nhead) for _ in range(num_encoder_layers)
        ])
        self.encoder_norm = nn.LayerNorm(d_model)
        
        # 解码器
        self.decoder_layers = nn.ModuleList([
            T5DecoderLayer(d_model, nhead) for _ in range(num_decoder_layers)
        ])
        self.decoder_norm = nn.LayerNorm(d_model)
        
        # 输出头
        self.lm_head = nn.Linear(d_model, vocab_size, bias=False)
        
    def forward(self, encoder_ids, decoder_ids):
        memory = self.encode(encoder_ids)
        logits = self.decode(decoder_ids, memory, encoder_ids.size(1))
        return logits
    
    def encode(self, input_ids):
        x = self.shared(input_ids)
        x = self._add_rel_pos(x)
        
        for layer in self.encoder_layers:
            x = layer(x)
        return self.encoder_norm(x)
    
    def decode(self, input_ids, memory, enc_len):
        x = self.shared(input_ids)
        x = self._add_rel_pos(x)
        
        L = input_ids.size(1)
        causal_mask = torch.triu(torch.full((L, L), float('-inf')), diagonal=1)
        
        for layer in self.decoder_layers:
            x = layer(x, memory, causal_mask, enc_len)
        x = self.decoder_norm(x)
        
        return self.lm_head(x)
    
    def _add_rel_pos(self, x):
        """简化相对位置编码"""
        return x


def test_handwritten():
    model = HandwrittenT5(vocab_size=10000, d_model=256, nhead=4)
    B, S, T = 2, 20, 10
    enc_ids = torch.randint(0, 10000, (B, S))
    dec_ids = torch.randint(0, 10000, (B, T))
    logits = model(enc_ids, dec_ids)
    print(f"手工T5输出: {logits.shape}")

if __name__ == "__main__":
    test_handwritten()
```

## 9. 可视化与结果理解

### 9.1 Text-to-Text统一性
所有NLP任务共享同一界面，极大简化了模型部署和任务切换。

### 9.2 Span Corruption vs MLM
T5的Span Corruption需要解码器生成多个token，比BERT的MLM（只预测单个token）更具挑战性，迫使模型学习更丰富的语言知识。

## 11. 常见问题

### Q1: T5和BART的区别？
A: BART使用多种噪声策略，T5使用Span Corruption。T5将所有任务统一为Text-to-Text，BART则保持传统预训练-微调范式。

### Q2: C4数据集是什么？
A: Colossal Clean Crawled Corpus，从Common Crawl中提取并清洗的750GB英文文本。使用启发式规则（去重、去脏话、去代码等）过滤。

### Q3: T5为什么不用绝对位置编码？
A: T5使用简化相对位置编码（16个bucket），更轻量且能处理任意长度序列。

## 13. 练习题

### 习题1：T5的Text-to-Text框架如何统一分类任务？
**答案**：将分类标签映射为文本，如情感分析输出"positive"或"negative"。这也意味着模型需要"写"出类别名。

### 习题2：Span Corruption和MLM的训练目标有什么本质区别？
**答案**：MLM只预测单个mask token（分类），Span Corruption需要解码器生成一段文本（序列生成）。前者用编码器输出做分类，后者用解码器逐token生成。

### 习题3：T5为什么需要sentinel token？
**答案**：sentinel token标记了被mask span的位置和顺序，解码器需要按sentinel顺序输出对应的span内容。

### 习题4：T5-11B的d_ff为什么不是4×d_model（标准做法）？
**答案**：T5-11B使用d_ff=65536（d_model=1024，64倍），因为更多的FFN参数能提供更大的模型容量，是T5缩放策略的核心。
