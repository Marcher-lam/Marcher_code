# 蒙特卡洛预测（Monte Carlo Prediction）学习文档

## 1. 算法基础认知

### 1.1 一句话定义

蒙特卡洛预测是强化学习中的一种无模型（model-free）方法，通过对环境进行随机采样来估计状态价值函数，是理解强化学习估值问题的入门算法。

### 1.2 直觉类比

想象蒙特卡洛预测的工作方式就像评估一个陌生赌场的老虎机：你不知道它的内部机制（转移概率和奖励），于是你反复玩很多次，记录每次的收益，然后用平均收益来估计这台机器的价值。玩得越多，估计越准确。

### 1.3 历史背景

蒙特卡洛方法起源于1940年代的曼哈顿计划：
- 1940年代：von Neumann和Ulam提出蒙特卡洛方法
- 1950年代：用于物理模拟
- 1990年代：Sutton将MC方法引入强化学习
- 2000年代：TD学习发展
- 2010年代：深度强化学习中的MC方法

### 1.4 算法定位

| 特性 | 说明 |
|------|------|
| 算法类型 | 无模型预测 |
| 用途 | 估计V(s)或Q(s,a) |
| 需要 | 完整episode采样 |
| 收敛 | 近似最优 |
| 方差 | 高 |

### 1.5 前置知识

1. 马尔可夫决策过程（MDP）
2. 价值函数定义
3. 采样方法
4. 折扣因子

## 2. 核心原理

### 2.1 核心思想

蒙特卡洛预测的核心思想是"用经验平均估计期望"：通过采样多个完整episode，计算每个状态的累积奖励，然后用平均来估计价值函数。

**为什么可行？**
- 根据大数定律
- 样本均值收敛到真实期望

### 2.2 工作流程

1. 从状态s开始，按照策略π与环境交互
2. 记录完整的episode轨迹
3. 计算每个状态的回报G
4. 用平均回报估计V(s)

### 2.3 First-visit vs Every-visit

**First-visit MC**：只使用每个episode中第一次访问状态s时的回报来估计V(s)

**Every-visit MC**：使用每次访问状态s时的回报来估计V(s)

数学表示：
- First-visit: $V(s) = \frac{1}{N_{first}(s)} \sum_{i \in First(s)} G_i$
- Every-visit: $V(s) = \frac{1}{N(s)} \sum_{i=1}^{N(s)} G_i$

### 2.4 增量平均值

为了高效更新，使用增量平均值公式：
$$V(s) \leftarrow V(s) + \frac{1}{N(s)}(G - V(s))$$

或者用学习率形式：
$$V(s) \leftarrow V(s) + \alpha(G - V(s))$$

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 |
|------|------|
| $\pi$ | 策略 |
| $s$ | 状态 |
| $a$ | 动作 |
| $r$ | 奖励 |
| $\gamma$ | 折扣因子 |
| $G_t$ | 回报 |
| $V(s)$ | 状态价值函数 |
| $Q(s,a)$ | 动作价值函数 |
| $N(s)$ | 状态访问次数 |

### 3.2 回报定义

$$G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + ... = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}$$

递推形式：
$$G_t = r_{t+1} + \gamma G_{t+1}$$

### 3.3 价值函数

状态价值函数：
$$V^\pi(s) = \mathbb{E}_\pi[G_t | S_t = s]$$

动作价值函数：
$$Q^\pi(s, a) = \mathbb{E}_\pi[G_t | S_t = s, A_t = a]$$

### 3.4 MC估计

$$\hat{V}(s) = \frac{1}{N(s)} \sum_{i=1}^{N(s)} G_i(s)$$

其中 $N(s)$ 是状态 $s$ 被访问的次数。

### 3.5 期望收敛

根据大数定律：
$$\hat{V}(s) \rightarrow V^\pi(s) \quad \text{当} \quad N(s) \rightarrow \infty$$

更精确地：
$$E[\hat{V}(s)] = V^\pi(s)$$
$$\text{Var}[\hat{V}(s)] = \frac{\sigma^2}{N(s)}$$

### 3.6 方差分析

MC方法的方差来源：
$$\text{Var}[G_t] = \text{Var}[r_{t+1}] + \gamma^2 \text{Var}[r_{t+2}] + ...$$

通常较高，需要与其他方法（TD）结合使用。

## 4. 训练过程讲解

### 4.1 完整流程

```
输入: 训练集episodes, 策略π
输出: 价值函数V

步骤1: 初始化V(s)=0, Returns(s)=空列表
步骤2: 对每个episode:
    生成一个完整轨迹
    对每个状态s_t:
        计算回报G_t
        将G_t加入Returns(s_t)
        更新V(s_t) = mean(Returns(s_t))
步骤3: 返回V
```

```python
import numpy as np
from collections import defaultdict

class MCEnvironment:
    """简化环境"""
    
    def __init__(self, n_states=5):
        self.n_states = n_states
        self.current_state = 0
        self.done = False
    
    def reset(self):
        self.current_state = 0
        self.done = False
        return self.current_state
    
    def step(self, action):
        if action == 1:
            self.current_state = min(self.current_state + 1, self.n_states - 1)
        else:
            self.current_state = max(self.current_state - 1, 0)
        
        reward = 1.0 if self.current_state == self.n_states - 1 else 0.0
        self.done = self.current_state == self.n_states - 1
        
        return self.current_state, reward, self.done
    
    @property
    def states(self):
        return list(range(self.n_states))


class SimplePolicy:
    """随机策略"""
    
    def __init__(self, n_actions=2):
        self.n_actions = n_actions
    
    def __call__(self, state):
        return np.random.randint(0, self.n_actions)


def generate_episode(env, policy):
    """生成一个episode"""
    episode = []
    state = env.reset()
    
    while True:
        action = policy(state)
        next_state, reward, done = env.step(action)
        episode.append((state, action, reward))
        state = next_state
        
        if done:
            break
    
    return episode


def mc_prediction_first_visit(env, policy, n_episodes=10000, gamma=0.9):
    """MC预测 - First-visit"""
    
    V = {s: 0.0 for s in env.states}
    returns = {s: [] for s in env.states}
    first_visit_count = {s: 0 for s in env.states}
    
    for episode_idx in range(n_episodes):
        episode = generate_episode(env, policy)
        
        G = 0
        visited = set()
        
        for t, (state, action, reward) in enumerate(reversed(episode)):
            G = reward + gamma * G
            
            if state not in visited:
                first_visit_count[state] += 1
                returns[state].append(G)
                V[state] = np.mean(returns[state])
                visited.add(state)
        
        if (episode_idx + 1) % 1000 == 0:
            print(f"Episode {episode_idx + 1}: V = {V}")
    
    return V


def mc_prediction_every_visit(env, policy, n_episodes=10000, gamma=0.9):
    """MC预测 - Every-visit"""
    
    V = {s: 0.0 for s in env.states}
    returns = {s: [] for s in env.states}
    visit_count = {s: 0 for s in env.states}
    
    for episode_idx in range(n_episodes):
        episode = generate_episode(env, policy)
        
        G = 0
        for t, (state, action, reward) in enumerate(reversed(episode)):
            G = reward + gamma * G
            
            visit_count[state] += 1
            returns[state].append(G)
            
            alpha = 1.0 / visit_count[state]
            V[state] = V[state] + alpha * (G - V[state])
    
    return V


def mc_prediction_incremental(env, policy, n_episodes=10000, gamma=0.9, alpha=0.1):
    """MC预测 - 增量更新"""
    
    V = {s: 0.0 for s in env.states}
    N = {s: 0 for s in env.states}
    
    for episode_idx in range(n_episodes):
        episode = generate_episode(env, policy)
        
        G = 0
        for t, (state, action, reward) in enumerate(reversed(episode)):
            G = reward + gamma * G
            
            N[state] += 1
            V[state] = V[state] + alpha * (G - V[state])
    
    return V


def demo_basic_mc():
    """演示基本MC预测"""
    print("=== MC预测基本演示 ===\n")
    
    env = MCEnvironment(n_states=5)
    policy = SimplePolicy()
    
    print("First-visit MC:")
    V_fv = mc_prediction_first_visit(env, policy, n_episodes=1000)
    print(f"V = {V_fv}\n")
    
    print("Every-visit MC:")
    V_ev = mc_prediction_every_visit(env, policy, n_episodes=1000)
    print(f"V = {V_ev}\n")
    
    print("增量更新 MC:")
    V_inc = mc_prediction_incremental(env, policy, n_episodes=1000)
    print(f"V = {V_inc}")


if __name__ == "__main__":
    demo_basic_mc()
```

```python
class MCPrediction:
    """MC预测完整类"""
    
    def __init__(self, n_states, n_actions=2, gamma=0.99, 
                 n_episodes=10000, alpha=0.1, visit_type='every'):
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma
        self.n_episodes = n_episodes
        self.alpha = alpha
        self.visit_type = visit_type
        
        self.V = np.zeros(n_states)
        self.returns = [[] for _ in range(n_states)]
        self.visit_count = np.zeros(n_states)
    
    def _generate_episode(self, env, policy):
        """生成episode"""
        episode = []
        state = env.reset()
        
        while True:
            action = policy(state)
            next_state, reward, done = env.step(action)
            episode.append((state, action, reward))
            state = next_state
            
            if done:
                break
        
        return episode
    
    def _compute_returns(self, episode):
        """计算回报"""
        G = 0
        returns = []
        
        for state, action, reward in reversed(episode):
            G = reward + self.gamma * G
            returns.insert(0, G)
        
        return returns
    
    def fit(self, env, policy):
        """训练"""
        for episode_idx in range(self.n_episodes):
            episode = self._generate_episode(env, policy)
            returns = self._compute_returns(episode)
            
            for t, (state, action, reward) in enumerate(episode):
                G = returns[t]
                
                if self.visit_type == 'first':
                    if state not in self.first_visited:
                        self.first_visited.add(state)
                        self.returns[state].append(G)
                        self.visit_count[state] += 1
                else:
                    self.returns[state].append(G)
                    self.visit_count[state] += 1
                
                if self.visit_count[state] > 0:
                    self.V[state] = np.mean(self.returns[state])
            
            if episode_idx % 1000 == 0:
                print(f"Episode {episode_idx}: V = {self.V}")
        
        return self.V
    
    def predict(self, state):
        """预测单个状态"""
        return self.V[state]
    
    def predict_all(self):
        """预测所有状态"""
        return self.V.copy()


class OffPolicyMC:
    """离线MC预测 - 重要采样"""
    
    def __init__(self, n_states, gamma=0.99, n_episodes=10000):
        self.n_states = n_states
        self.gamma = gamma
        self.n_episodes = n_episodes
        
        self.V = np.zeros(n_states)
        self.C = np.zeros(n_states)
    
    def fit(self, env, behavior_policy, target_policy):
        """训练"""
        for episode_idx in range(self.n_episodes):
            episode = generate_episode(env, behavior_policy)
            
            G = 0
            W = 1.0
            
            for t, (state, action, reward) in enumerate(reversed(episode)):
                G = reward + self.gamma * G
                
                b_prob = behavior_policy(state) if callable(behavior_policy) else 0.5
                p_prob = target_policy(state, action) if callable(target_policy) else 1.0
                
                if b_prob > 0:
                    W = W * (p_prob / b_prob)
                
                self.C[state] += W
                if self.C[state] != 0:
                    self.V[state] += (W / self.C[state]) * (G - self.V[state])
        
        return self.V


def demo_complete_mc():
    """演示完整MC预测"""
    print("=== MC预测完整演示 ===\n")
    
    env = MCEnvironment(n_states=5)
    behavior_policy = SimplePolicy()
    
    mc = MCPrediction(n_states=5, gamma=0.9, n_episodes=1000)
    V = mc.fit(env, behavior_policy)
    
    print(f"\n最终价值函数: V = {V}")


if __name__ == "__main__":
    demo_complete_mc()
```

```python
def train_with_monitoring(env, policy, n_episodes=10000, 
                            eval_interval=1000):
    """带监控的训练"""
    
    V = {s: 0.0 for s in env.states}
    returns = {s: [] for s in env.states}
    history = {'episodes': [], 'V_norm': [], 'V_error': []}
    
    for episode_idx in range(n_episodes):
        episode = generate_episode(env, policy)
        
        G = 0
        for t, (state, action, reward) in enumerate(reversed(episode)):
            G = reward + gamma * G
            returns[state].append(G)
            if len(returns[state]) > 0:
                V[state] = np.mean(returns[state])
        
        if (episode_idx + 1) % eval_interval == 0:
            V_norm = np.linalg.norm(list(V.values()))
            history['episodes'].append(episode_idx + 1)
            history['V_norm'].append(V_norm)
            
            print(f"Episode {episode_idx + 1}: ||V|| = {V_norm:.4f}")
    
    return V, history
```

### 6.1 优点

1. **无需环境模型**
   - 不需要知道转移概率
   - 适用于黑盒环境

2. **无偏估计**
   - 渐近无偏
   - 收敛到真实值

   - 可以处理非线性
   - 不依赖函数近似

1. **需要完整episode**
   - 必须等待episode结束

```python
class MCPredictionGym:
    """使用Gym的MC预测"""
    
    def __init__(self, env_name='CartPole-v1', gamma=0.99, n_episodes=5000):
        self.env_name = env_name
        self.gamma = gamma
        self.n_episodes = n_episodes
        
        self.env = None
        self.V = None
    
    def _discretize_state(self, state, n_bins=10):
        """离散化状态"""
        env = self.env
        low = env.observation_space.low
        high = env.observation_space.high
        
        bins = []
        for i, (lo, hi) in enumerate(zip(low, high)):
            bins.append(np.linspace(lo, hi, n_bins))
        
        indices = []
        for i, s in enumerate(state):
            idx = np.searchsorted(bins[i], s)
            idx = min(idx, n_bins - 1)
            indices.append(idx)
        
        return tuple(indices)
    
    def _state_to_index(self, state):
        """状态转索引"""
        return state if isinstance(state, int) else hash(state)
    
    def fit(self):
        """训练"""
        self.env = gym.make(self.env_name)
        
        states = []
        for _ in range(self.n_episodes):
            state, _ = self.env.reset()
            done = False
            episode = []
            
            while not done:
                action = self.env.action_space.sample()
                next_state, reward, terminated, truncated, _ = self.env.step(action)
                done = terminated or truncated
                
                episode.append((state, action, reward))
                state = next_state
            
            G = 0
            for s, a, r in reversed(episode):
                G = r + self.gamma * G
                states.append((s, G))
        
        state_returns = {}
        for state, G in states:
            if state not in state_returns:
                state_returns[state] = []
            state_returns[state].append(G)
        
        self.V = {s: np.mean(returns) for s, returns in state_returns.items()}
        
        self.env.close()
        return self.V
    
    def predict(self, state):
        """预测"""
        if self.V is None:
            return 0.0
        return self.V.get(state, 0.0)
```

```python
class GridWorldEnv:
    """网格世界环境"""
    
    def __init__(self, grid_size=4):
        self.grid_size = grid_size
        self.state = (0, 0)
        
        self.actions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        self.goal = (grid_size - 1, grid_size - 1)
        
        self.rewards = {
            self.goal: 1.0,
            (-1, -1): -0.1
        }
    
    def reset(self):
        self.state = (0, 0)
        return self.state
    
    def step(self, action):
        dr, dc = self.actions[action]
        
        nr = max(0, min(self.grid_size - 1, self.state[0] + dr))
        nc = max(0, min(self.grid_size - 1, self.state[1] + dc))
        
        self.state = (nr, nc)
        
        reward = 0.0
        done = self.state == self.goal
        
        return self.state, reward, done
    
    @property
    def states(self):
        return [(i, j) for i in range(self.grid_size) 
                         for j in range(self.grid_size)]
    
    @property
    def n_actions(self):
        return len(self.actions)


class MCGridWorld:
    """网格世界MC预测"""
    
    def __init__(self, gamma=0.9, n_episodes=5000):
        self.gamma = gamma
        self.n_episodes = n_episodes
        
        self.env = GridWorldEnv(grid_size=4)
        self.V = {s: 0.0 for s in self.env.states}
        self.returns = {s: [] for s in self.env.states}
    
    def _random_policy(self, state):
        """随机策略"""
        return np.random.randint(0, self.env.n_actions)
    
    def fit(self):
        """训练"""
        for _ in range(self.n_episodes):
            state = self.env.reset()
            episode = []
            done = False
            
            while not done:
                action = self._random_policy(state)
                next_state, reward, done = self.env.step(action)
                episode.append((state, reward))
                state = next_state
            
            G = 0
            for s, r in reversed(episode):
                G = r + self.gamma * G
                self.returns[s].append(G)
                self.V[s] = np.mean(self.returns[s])
        
        return self.V
    
    def visualize(self):
        """可视化"""
        grid = []
        for i in range(self.env.grid_size):
            row = []
            for j in range(self.env.grid_size):
                v = self.V.get((i, j), 0.0)
                row.append(f"{v:.2f}")
            grid.append(row)
        
        for row in grid:
            print(" ".join(row))


def demo_grid_world():
    """演示网格世界"""
    print("=== 网格世界MC预测 ===\n")
    
    mc = MCGridWorld(gamma=0.9, n_episodes=1000)
    V = mc.fit()
    
    mc.visualize()
```

```python
class MCSolverManual:

    def __init__(self, n_states, n_actions=2, gamma=0.9, n_episodes=1000):
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma
        self.n_episodes = n_episodes
        
        self.V = np.zeros(n_states)
        self.returns = [[] for _ in range(n_states)]
        self.visit_count = np.zeros(n_states)
    
    def simple_env(self, state, action):
        """简化环境"""
        if action == 1:
            next_state = min(state + 1, self.n_states - 1)
        else:
            next_state = max(state - 1, 0)
        
        reward = 1.0 if next_state == self.n_states - 1 else 0.0
        done = next_state == self.n_states - 1
        
        return next_state, reward, done
    
    def random_policy(self, state):
        """随机策略"""
        return random.randint(0, self.n_actions - 1)
    
    def generate_episode(self, start_state=None):
        """生成episode"""
        if start_state is None:
            state = random.randint(0, self.n_states - 1)
        else:
            state = start_state
        
        episode = []
        done = False
        max_steps = 100
        
        for _ in range(max_steps):
            action = self.random_policy(state)
            next_state, reward, done = self.simple_env(state, action)
            episode.append((state, action, reward))
            state = next_state
            
            if done:
                break
        
        return episode
    
    def solve(self, use_incremental=True, alpha=None):
        """求解"""
        
        for episode_idx in range(self.n_episodes):
            episode = self.generate_episode()
            
            G = 0
            for t, (state, action, reward) in enumerate(reversed(episode)):
                G = reward + self.gamma * G
                
                if use_incremental:
                    self.visit_count[state] += 1
                    
                    if alpha is None:
                        alpha = 1.0 / self.visit_count[state]
                    
                    self.V[state] += alpha * (G - self.V[state])
                else:
                    self.returns[state].append(G)
                    self.V[state] = np.mean(self.returns[state])
            
            if (episode_idx + 1) % 200 == 0:
                print(f"Episode {episode_idx + 1}: V = {self.V}")
        
        return self.V
    
    def get_state_value(self, state):
        """获取状态价值"""
        return self.V[state]


class MCPredictionManual:
    """完整MC预测手工实现"""
    
    def __init__(self, n_states, gamma=0.99, alpha=0.1, 
                 n_episodes=5000, visit_type='every'):
        self.n_states = n_states
        self.gamma = gamma
        self.alpha = alpha
        self.n_episodes = n_episodes
        self.visit_type = visit_type
        
        self.V = np.zeros(n_states)
        self.returns_sum = np.zeros(n_states)
        self.visit_count = np.zeros(n_states)
        self.first_visited = [set() for _ in range(n_states)]
    
    def _initial_policy(self, state, n_actions):
        """初始策略"""
        return np.random.randint(0, n_actions)
    
    def fit(self, env, n_actions=2, policy=None):
        """训练"""
        if policy is None:
            policy = lambda s: self._initial_policy(s, n_actions)
        
        for _ in range(self.n_episodes):
            episode = []
            state = env.reset()
            done = False
            
            while not done:
                action = policy(state)
                next_state, reward, done = env.step(action)
                episode.append((state, reward))
                state = next_state
            
            G = 0
            for t, (state, reward) in enumerate(reversed(episode)):
                G = reward + self.gamma * G
                
                if self.visit_type == 'first':
                    if state not in self.first_visited[state]:
                        self.first_visited[state].add(state)
                        self.returns_sum[state] += G
                        self.visit_count[state] += 1
                else:
                    self.returns_sum[state] += G
                    self.visit_count[state] += 1
                
                if self.visit_count[state] > 0:
                    self.V[state] = self.returns_sum[state] / self.visit_count[state]
        
        return self.V
```

```python
class IncrementalMC:
    """增量更新MC"""
    
    def __init__(self, gamma=0.9, alpha=0.1):
        self.gamma = gamma
        self.alpha = alpha
        
        self.V = {}
        self.counts = {}
        self.returns = {}
    
    def update_gaussian(self, state, G):
        """高斯更新"""
        if state not in self.V:
            self.V[state] = 0.0
            self.counts[state] = 0
            self.returns[state] = []
        
        self.counts[state] += 1
        self.returns[state].append(G)
        
        self.V[state] = np.mean(self.returns[state])
    
    def update_incremental(self, state, G):
        """增量更新"""
        if state not in self.V:
            self.V[state] = 0.0
            self.counts[state] = 0
        
        self.counts[state] += 1
        
        step_size = self.alpha
        self.V[state] += step_size * (G - self.V[state])
    
    def update_poly(self, state, G):
        """多项式衰减更新"""
        if state not in self.V:
            self.V[state] = 0.0
            self.counts[state] = 0
        
        self.counts[state] += 1
        
        step_size = 1.0 / (self.counts[state] ** 0.5)
        self.V[state] += step_size * (G - self.V[state])


def compare_update_methods():
    """比较不同更新方法"""
    methods = {
        'sample_mean': lambda state, G, mc: mc.update_gaussian(state, G),
        'incremental': lambda state, G, mc: mc.update_incremental(state, G),
        'poly_decay': lambda state, G, mc: mc.update_poly(state, G),
    }
    
    results = {}
    
    for method_name, update_fn in methods.items():
        mc = IncrementalMC(gamma=0.9, alpha=0.1)
        
        for _ in range(1000):
            episode = [(0, 1.0)] * 10
            G = 0
            for s, r in reversed(episode):
                G = r + 0.9 * G
                update_fn(s, G, mc)
        
        results[method_name] = mc.V.get(0, 0.0)
    
    for method, v in results.items():
        print(f"{method}: V = {v:.4f}")


if __name__ == "__main__":
    compare_update_methods()
```

## 11. 常见问题与易错点

### 11.1 算法问题

1. **需要完整episode**
   - MC必须等待episode结束
   - 解决：从开始状态采样

2. **高方差**
   - 回报是高方差随机变量
   - 解决：增大样本数

3. **仅适用于Episdic**
   - 不适合���续���务
   - 解决：使用TD方法

### 11.2 实现问题

1. **状态访问次数为0**
   - 某些状态从未访问
   - 解决：探索起始

2. **回报计算错误**
   - 时序倒序计算
   - 解决：逐层递推

3. **增量更新学习率**
   - 固定学习率可能导致不收敛
   - 解决：使用1/N

### 11.3 概念混淆

1. **First-visit vs Every-visit**
   - First-visit更常用
   - Every-visit更简单

2. **MC vs TD**
   - MC无偏，高方差
   - TD有偏，低方差

3. **on-policy vs off-policy**
   - on-policy：采样和评估同一策略
   - off-policy：使用重要采样

## 13. 练习题与思考题

### 13.1 练习题

**题目1**：简述MC预测的原理

**答案**：
MC预测通过采样多个完整episode，计算每个状态的累积奖励，然后用平均回报来估计价值函数。核心思想是"用经验平均估计期望"。

**题目2**：比较First-visit和Every-visit

**答案**：
- First-visit：只使用第一次访问的回报，收敛更快，方差更低
- Every-visit：使用所有访问的回报，实现更简单，但方差更高

**题目3**：MC vs TD的区别

**答案**：
- MC：需要完整episode，无偏但方差高
- TD：单步更新，有偏但方差低
