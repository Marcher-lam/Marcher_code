# CVRP 电容车辆路径问题 学习文档

> 带车辆容量约束的车辆路径问题。

## 1. 算法基础认知

CVRP（Capacitated Vehicle Routing Problem）是VRP的一种变体，为每辆配送车设置容量限制，顾客需求量不能超过车辆容量。

**直觉类比**：快递公司用大货车送货，每辆车有最大载重量，不能一次送完所有快递。

## 2. 核心原理

- 每辆车有最大容量C
- 每个客户有需求量d_i
- 总需求量不超过车辆容量
- 最小化总行驶距离

## 3. 数学公式

$$\min \sum_k \sum_{i,j} d_{ij} x_{ijk}$$

$$s.t. \sum_{i} d_i y_{ik} \leq C$$
