# 市场情绪量化评分系统 学习文档

> 将市场情绪量化为0-100分，像体温计一样准确测量市场的冷热程度。
> 来源线索：本节内容根据原书中关于"市场情绪量化评分系统"（第3章3.8节）的相关内容整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：市场情绪量化评分系统是通过统计涨停比、连板涨幅、炸板率等多项指标，综合计算0-100分情绪指数来指导仓位管理的量化工具。

**直觉类比**：体温计——38度以上发烧（市场过热，该减仓），35度以下低体温（市场过冷，可抄底），36-37度正常（正常持仓）。

**背景**：市场情绪反映了参与者的群体心理和风险偏好。行为金融学证明，极端情绪往往是市场反转的领先指标。AI和大数据时代，情绪可以被量化、建模，转化为可操作的仓位信号。

**算法定位**：量化策略 / 情绪因子 / 风险管理 / 择时信号。

**前置知识**：A股涨停跌停制度、基本市场指标（成交量、换手率、涨跌幅）、归一化/标准化概念。

## 2. 核心原理

**五大核心情绪指标**：

1. **涨停数与跌停数比值**：反映多空力量对比。涨停数 ≫ 跌停数 = 多头主导。
2. **连板股平均涨幅**：连板股是市场最强势板块，其涨幅反映高风险偏好强度。
3. **炸板率**：炸板数 / (涨停数 + 炸板数)。炸板率高说明资金追高意愿减弱、情绪分歧。
4. **高标股次日开盘溢价率**：取连板最多的前5只股，统计次日开盘相对今日收盘的溢价。正溢价 = 情绪持续。
5. **昨日涨停今日溢价**：昨日涨停股今日开盘相对昨日收盘的均值收益，反映短线情绪反馈。

**情绪周期四阶段**：
- 0-30分：**冰点**——极度悲观，卖盘枯竭，关注反转
- 30-50分：**复苏**——情绪回暖，可逐步加仓
- 50-80分：**高潮**——情绪亢奋，持股待涨但控制仓位
- 80-100分：**退潮预警**——过度乐观，减仓避险

**情绪与指数背离预警**：
- 情绪高涨(>70) + 指数下跌 → 警惕系统性风险
- 情绪低迷(<30) + 指数上涨 → 注意反转机会

## 3. 数学公式与推导

### 3.1 涨跌比
$$
\text{Ratio} = \frac{N_{\text{up\_limit}}}{N_{\text{down\_limit}} + 1}
$$
加1防止除零。

### 3.2 炸板率
$$
\text{ZhaBanRate} = \frac{N_{\text{zha\_ban}}}{N_{\text{up\_limit}} + N_{\text{zha\_ban}} + 1}
$$

### 3.3 情绪得分合成
对每项指标 Min-Max 归一化后加权：
$$
S = \sum_{i=1}^{5} w_i \cdot \text{norm}(\text{indicator}_i) \times 100
$$

权重建议：涨跌比 0.25、连板涨幅 0.20、炸板率(-)0.20、高标溢价 0.20、昨涨溢价 0.15。炸板率取反（越低越好）。

### 3.4 历史分位数
$$
\text{Percentile} = \frac{\sum \mathbb{1}[s_{\text{hist}} < s_{\text{today}}]}{N_{\text{hist}}}
$$

## 4. 训练过程讲解

### 4.1 数据采集
- 全市场每日行情：涨幅、开盘价、收盘价、涨停/跌停状态
- 涨停/跌停/炸板股票列表
- 连板数据
- 来源：Tushare、聚宽、同花顺

### 4.2 计算流程
1. 采集当日全市场股票行情
2. 统计涨停数、跌停数、炸板数
3. 计算 5 项指标
4. 用历史窗口（60日）归一化各指标
5. 加权合成 0-100 分
6. 判断情绪周期和背离

### 4.3 关键参数
- 历史窗口：推荐 60 个交易日（约一季度）
- 高标股数量：前 5 只
- 涨停阈值：涨幅 >= 9.8%

## 5. 应用场景

1. **仓位管理**：情绪 > 80 分 → 减仓至 30%；30-50 分 → 加仓至 80%
2. **风控预警**：情绪-指数背离时暂停新开仓
3. **选股增强**：只在高情绪期追涨停板策略，低情绪期做低吸
4. **股指期货择时**：高情绪+指数滞涨 → 做空 IF/IC

**适用市场**：A股（有涨跌停制度）、期货市场；**不适用**：无涨跌停的成熟市场（需调整指标定义）

## 6. 优缺点分析

### 优点
- 直观易懂：0-100 分任何人都能理解
- 实时性：每日收盘后可即时计算
- 可操作：直接映射到仓位建议
- 多维验证：多个指标交叉确认减少误判

### 缺点
- 权重主观：需根据历史回测确定最优权重
- 极端行情失真：千股跌停/涨停时日指标失效
- 市场结构依赖：注册制推行后涨停生态可能改变

## 7. 调库实现

```python
"""
市场情绪量化评分系统
pandas + numpy 实现完整 5 指标情绪评分
"""
import numpy as np
import pandas as pd

np.random.seed(42)
n_days = 200

# ========== 1. 模拟 A 股市场情绪指标数据 ==========
dates = pd.date_range('2024-01-01', periods=n_days, freq='B')

# 生成有周期性特征的模拟情绪数据
base_cycle = np.sin(np.linspace(0, 4*np.pi, n_days))
noise = np.random.randn(n_days) * 0.3

up_count = (300 + base_cycle * 100 + noise * 50).astype(int)
up_count = np.maximum(up_count, 10)
down_count = (50 - base_cycle * 30 + noise * 20).astype(int)
down_count = np.maximum(down_count, 1)
zha_ban_count = (80 - base_cycle * 30 + np.random.randn(n_days) * 20).astype(int)
zha_ban_count = np.maximum(zha_ban_count, 5)
lianban_avg_pct = 2.0 + base_cycle * 1.5 + noise
lianban_avg_pct = np.maximum(lianban_avg_pct, 0.1)
high_mark_yield = base_cycle * 1.0 + noise * 0.5
prev_up_yield = base_cycle * 0.8 + noise * 0.4
idx_chg = base_cycle * 1.2 + noise * 0.8

df = pd.DataFrame({
    'date': dates,
    'up_limit_count': up_count, 'down_limit_count': down_count,
    'zha_ban_count': zha_ban_count, 'lianban_avg_pct': lianban_avg_pct,
    'high_mark_yield': high_mark_yield, 'prev_up_yield': prev_up_yield,
    'index_chg': idx_chg,
})

# ========== 2. 计算各指标 ==========
df['up_down_ratio'] = df['up_limit_count'] / (df['down_limit_count'] + 1)
df['zha_ban_rate'] = df['zha_ban_count'] / (df['up_limit_count'] + df['zha_ban_count'] + 1)

# ========== 3. 滚动归一化（60日窗口） ==========
window = 60

def rolling_norm(series, window):
    """对序列做滚动 Min-Max 归一化"""
    roll_min = series.rolling(window, min_periods=20).min()
    roll_max = series.rolling(window, min_periods=20).max()
    return (series - roll_min) / (roll_max - roll_min + 1e-8)

df['up_down_score'] = rolling_norm(df['up_down_ratio'], window)
df['lianban_score'] = rolling_norm(df['lianban_avg_pct'], window)
# 炸板率越低越好，取反
df['zha_ban_score'] = 1 - rolling_norm(df['zha_ban_rate'], window)
df['high_mark_score'] = rolling_norm(df['high_mark_yield'], window)
df['prev_up_score'] = rolling_norm(df['prev_up_yield'], window)

# ========== 4. 加权合成 ==========
weights = {'up_down': 0.25, 'lianban': 0.20, 'zha_ban': 0.20,
           'high_mark': 0.20, 'prev_up': 0.15}

df['sentiment_score'] = (
    weights['up_down'] * df['up_down_score'] +
    weights['lianban'] * df['lianban_score'] +
    weights['zha_ban'] * df['zha_ban_score'] +
    weights['high_mark'] * df['high_mark_score'] +
    weights['prev_up'] * df['prev_up_score']
) * 100

# ========== 5. 历史分位数 ==========
df['percentile'] = df['sentiment_score'].rolling(window, min_periods=20).apply(
    lambda x: (x.iloc[:-1] < x.iloc[-1]).mean() if len(x) > 1 else 0.5
)

# ========== 6. 情绪周期判断 ==========
def classify_phase(score):
    if score < 30: return '冰点'
    elif score < 50: return '复苏'
    elif score < 80: return '高潮'
    else: return '退潮预警'

df['phase'] = df['sentiment_score'].apply(classify_phase)

# ========== 7. 背离检测 ==========
df['divergence'] = ''
df.loc[(df['sentiment_score'] > 70) & (df['index_chg'] < 0), 'divergence'] = '情绪-指数顶背离'
df.loc[(df['sentiment_score'] < 30) & (df['index_chg'] > 0), 'divergence'] = '情绪-指数底背离'

# ========== 8. 仓位建议 ==========
def position_advice(score):
    if score < 30: return '重仓(80%)'
    elif score < 50: return '中等(60%)'
    elif score < 70: return '轻仓(40%)'
    else: return '极轻仓(20%)'

df['position'] = df['sentiment_score'].apply(position_advice)

print("最近 5 日情绪评分:")
print(df[['date', 'sentiment_score', 'percentile', 'phase', 'position']].tail(5).to_string(index=False))

# ========== 9. 可视化 ==========
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['Arial Unicode MS', 'SimHei']
plt.rcParams['axes.unicode_minus'] = False

fig, axes = plt.subplots(2, 1, figsize=(14, 8))

# 情绪指数时序
ax1 = axes[0]
colors = {'冰点': 'blue', '复苏': 'green', '高潮': 'orange', '退潮预警': 'red'}
for phase_name, color in colors.items():
    mask = df['phase'] == phase_name
    ax1.scatter(df.loc[mask, 'date'], df.loc[mask, 'sentiment_score'],
                c=color, label=phase_name, s=20, alpha=0.7)
ax1.plot(df['date'], df['sentiment_score'], 'gray', linewidth=0.5, alpha=0.5)
ax1.axhline(y=30, color='blue', linestyle='--', alpha=0.3)
ax1.axhline(y=50, color='green', linestyle='--', alpha=0.3)
ax1.axhline(y=80, color='red', linestyle='--', alpha=0.3)
ax1.set_title('市场情绪指数 (0-100)')
ax1.set_ylabel('情绪得分')
ax1.legend(loc='upper right')
ax1.grid(True, alpha=0.3)

# 情绪 vs 指数走势
ax2 = axes[1].twinx()
axes[1].plot(df['date'], df['index_chg'], 'gray', linewidth=1, label='指数涨跌%', alpha=0.7)
ax2.plot(df['date'], df['sentiment_score'], 'red', linewidth=1.5, alpha=0.7, label='情绪得分')
# 标记背离点
div_top = df[df['divergence'] == '情绪-指数顶背离']
div_bot = df[df['divergence'] == '情绪-指数底背离']
axes[1].scatter(div_top['date'], div_top['index_chg'], c='red', s=50, marker='v', zorder=5)
axes[1].scatter(div_bot['date'], div_bot['index_chg'], c='green', s=50, marker='^', zorder=5)
axes[1].set_ylabel('指数涨跌%')
ax2.set_ylabel('情绪得分')
axes[1].set_title('情绪指数 vs 市场指数（标注背离点）')
axes[1].legend(loc='upper left')
ax2.legend(loc='upper right')
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## 8. 手工代码实现

```python
"""
市场情绪评分系统手工实现
"""
import numpy as np


class MarketSentimentScorer:
    """从零实现市场情绪量化评分"""

    def __init__(self, hist_window=60):
        self.hist_window = hist_window
        self.history = []

    def _minmax_norm(self, value, history_values):
        """Min-Max 归一化"""
        arr = np.array(history_values + [value])
        return (value - arr.min()) / (arr.max() - arr.min() + 1e-8)

    def score(self, up_count, down_count, zha_ban_count, lianban_avg,
              high_mark_ret, prev_up_ret):
        """计算单日情绪得分"""
        # 计算指标
        up_down_ratio = up_count / (down_count + 1)
        zha_ban_rate = zha_ban_count / (up_count + zha_ban_count + 1)

        # 归一化（基于历史）
        if len(self.history) >= self.hist_window // 2:
            hist_ratios = [h['up_down_ratio'] for h in self.history[-self.hist_window:]]
            hist_lianban = [h['lianban_avg'] for h in self.history[-self.hist_window:]]
            hist_zha = [h['zha_ban_rate'] for h in self.history[-self.hist_window:]]
            hist_high = [h['high_mark_ret'] for h in self.history[-self.hist_window:]]
            hist_prev = [h['prev_up_ret'] for h in self.history[-self.hist_window:]]

            up_score = self._minmax_norm(up_down_ratio, hist_ratios)
            lian_score = self._minmax_norm(lianban_avg, hist_lianban)
            zha_score = 1 - self._minmax_norm(zha_ban_rate, hist_zha)
            high_score = self._minmax_norm(high_mark_ret, hist_high)
            prev_score = self._minmax_norm(prev_up_ret, hist_prev)

            # 加权
            sentiment = (0.25 * up_score + 0.20 * lian_score +
                         0.20 * zha_score + 0.20 * high_score +
                         0.15 * prev_score) * 100
        else:
            sentiment = 50  # 数据不足时默认中性

        # 记录历史
        self.history.append({
            'up_down_ratio': up_down_ratio,
            'lianban_avg': lianban_avg,
            'zha_ban_rate': zha_ban_rate,
            'high_mark_ret': high_mark_ret,
            'prev_up_ret': prev_up_ret,
            'sentiment': sentiment,
        })
        return sentiment

    def get_phase(self, score):
        if score < 30: return '冰点'
        elif score < 50: return '复苏'
        elif score < 80: return '高潮'
        return '退潮预警'

    def get_position(self, score):
        if score < 30: return 0.8
        elif score < 50: return 0.6
        elif score < 70: return 0.4
        return 0.2


# ========== 测试 ==========
if __name__ == '__main__':
    np.random.seed(42)
    scorer = MarketSentimentScorer(hist_window=60)

    # 模拟 100 天情绪评分
    positions = []
    for day in range(100):
        up = np.random.poisson(200 + 30 * np.sin(day/15))
        down = np.random.poisson(30)
        zha = np.random.poisson(40)
        lianban = np.random.uniform(1, 5)
        high_mk = np.random.uniform(-1, 3)
        prev_up = np.random.uniform(-0.5, 2)

        s = scorer.score(up, down, zha, lianban, high_mk, prev_up)
        pos = scorer.get_position(s)
        positions.append(pos)

    print(f"情绪评分统计: 最高={max(scorer.history[-1].values())}")
    print(f"平均仓位: {np.mean(positions):.1%}")
```

## 9. 可视化与结果理解

第7节代码已生成完整的三面板可视化。解读要点：
- 情绪指数用颜色区分四阶段，一目了然
- 背离信号（三角标记）往往是重要的交易机会点
- 仓位建议跟随情绪变化，高情绪低仓位原则在A股回测中通常有正超额

## 10. 模型评估

| 评估维度 | 方法 |
|----------|------|
| 情绪有效性 | 情绪指数与未来5/10/20日收益的相关性 |
| 仓位策略 | 情绪驱动仓位 vs 满仓基准的年化收益和最大回撤对比 |
| 背离准确性 | 背离信号出现后20日内发生反转的比例 |
| 稳定性 | 不同历史窗口（30/60/90日）下情绪得分的相关性 |

## 11. 常见问题与易错点

- **停牌/ST 股未剔除**：这些股票的涨停跌停含义不同→计算前先剔除
- **归一化窗口过短**：如 10 日窗口，极端行情会让分数"失灵"→60日以上
- **权重拍脑袋**：初始权重来自经验，应通过回测网格搜索最优值
- **不同市场涨停定义不同**：科创板/创业板20%，主板10%→需区分板块计算

## 12. 学习总结

**核心回顾**：情绪评分系统将主观的市场感受量化为客观的0-100分数，通过多指标交叉验证减少单一指标误判，最终映射到可执行的仓位决策。

**关键公式**：情绪得分 = Σ(归一化指标 × 权重) × 100

**后续方向**：纳入龙虎榜资金、两融余额、新闻NLP情感等更多维度，构建更全面的情绪指标体系。

## 13. 练习题与思考题

**题1**（基础）：某日市场：涨停80家、跌停10家、炸板25家、连板股平均涨幅3.5%、高标溢价1.2%、昨涨溢价0.8%。请估算情绪周期。
**参考答案**：涨跌比=80/11=7.27(偏高)，炸板率=25/105=0.24(中等)，连板涨3.5%(偏强)，溢价均为正。综合判断：高潮期（50-80分区间偏上）。

**题2**（进阶）：假如情绪评分连续3天>85，但指数连续3天微跌，应该如何操作？
**参考答案**：这是典型的顶背离信号——情绪极度亢奋但指数已无力上攻，说明聪明钱在出货、散户在追高。应大幅减仓、不做多单。历史上类似模式常出现在阶段性顶部。

**题3**（开放）：美股的VIX恐慌指数可作为情绪指标。A股如何设计"本土版VIX"？
**参考答案**：可选用：1)50ETF期权隐含波动率；2)涨停家数与跌停家数的波动率；3)市场宽度指标（站上20日均线的股票占比的波动）；4)融资买入额的变化率等构建综合恐慌指数。
