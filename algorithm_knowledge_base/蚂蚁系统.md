# 蚂蚁系统 学习文档

> 蚂蚁群体的智能优化算法。

## 1. 算法基础认知

蚂蚁系统（Ant System, AS）是蚁群优化的第一个算法，由Dorigo等人提出。多个"蚂蚁"通过信息素通信来寻找最优解。

**前置知识**：蚁群优化基础

## 2. 核心原理

- 多个蚂蚁并行搜索
- 信息素正反馈
- 信息素挥发

## 3. 数学公式

**状态转移**：
$$P_{ij} = \frac{\tau_{ij}^\alpha \eta_{ij}^\beta}{\sum \tau_{il}^\alpha \eta_{il}^\beta}$$
