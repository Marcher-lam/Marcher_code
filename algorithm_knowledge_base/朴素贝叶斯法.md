# 朴素贝叶斯法 (Naive Bayes)

> 基于贝叶斯定理的概率分类器，"朴素"假设下的高效算法

---

## 1. 算法基础认知

### 1.1 一句话定义

朴素贝叶斯法是基于贝叶斯定理和特征条件独立假设的概率分类器。虽然"朴素"假设在现实中很少成立，但该算法在许多文本分类任务中表现优异，以简单高效著称。

### 1.2 直觉类比

朴素贝叶斯就像"垃圾邮件过滤器"：
- 假设邮件中出现"免费"、"赢大奖"等词
- 统计历史数据中包含这些词的邮件
- "免费"在垃圾邮件中出现的概率 vs 正常邮件中的概率
- 计算：$P(垃圾邮件|免费) = \frac{P(免费|垃圾邮件) \times P(垃圾邮件)}{P(免费)}$

### 1.3 发展历程

- **1763**: Thomas Bayes提出贝叶斯定理
- **1960s**: 朴素贝叶斯在文本分类中应用
- **1990s**: 成为文本分类标准方法
- **现在**: NLP、推荐系统中广泛使用

---

## 2. 核心原理

### 2.1 贝叶斯定理

贝叶斯定理是概率论中最核心的公式之一：

$$P(y|\mathbf{x}) = \frac{P(\mathbf{x}|y)P(y)}{P(\mathbf{x})}$$

其中：
- $P(y)$：先验概率（prior），类别y的先验概率
- $P(\mathbf{x}|y)$：似然（likelihood），给定类别y下特征x的概率
- $P(y|\mathbf{x})$：后验概率（posterior），给定特征x下类别y的概率
- $P(\mathbf{x})$：证据（evidence），特征的边缘概率

**分类决策**：
$$\hat{y} = \arg\max_y P(y|\mathbf{x}) = \arg\max_y \frac{P(\mathbf{x}|y)P(y)}{P(\mathbf{x})}$$

由于$P(\mathbf{x})$与y无关，可以忽略：
$$\hat{y} = \arg\max_y P(\mathbf{x}|y)P(y)$$

### 2.2 条件独立假设

"朴素"假设：给定类别y，特征之间相互独立：

$$P(\mathbf{x}|y) = P(x_1, x_2, ..., x_n|y) = \prod_{i=1}^{n} P(x_i|y)$$

**为什么"朴素"**：
- 现实中特征往往不独立（词与词有语义关联）
- 但即使假设不成立，朴素贝叶斯仍常常有效
- 原因：分类决策只需要正确的类别，概率值本身不必精确

### 2.3 对数概率计算

连乘概率会导致数值下溢，使用对数：

$$\log P(\mathbf{x}|y) + \log P(y) = \sum_{i=1}^{n} \log P(x_i|y) + \log P(y)$$

## 3. 数学公式与推导

### 3.1 高斯朴素贝叶斯

适用于连续值特征，假设每个类的特征服从高斯分布：

$$P(x_i|y=k) = \frac{1}{\sqrt{2\pi\sigma_k^2}} \exp\left(-\frac{(x_i - \mu_k)^2}{2\sigma_k^2}\right)$$

其中 $\mu_k, \sigma_k^2$ 是类别k下特征i的均值和方差。

**参数估计**（最大似然估计）：
$$\hat{\mu}_k = \frac{1}{N_k} \sum_{i: y_i=k} x_i$$

$$\hat{\sigma}_k^2 = \frac{1}{N_k} \sum_{i: y_i=k} (x_i - \hat{\mu}_k)^2$$

### 3.2 多项式朴素贝叶斯

适用于离散计数数据（如文本中词的出现次数）：

$$P(x_i|y=k) = \frac{N_{ki} + \alpha}{N_k + \alpha V}$$

其中：
- $N_{ki}$：类别k中特征i的总计数
- $N_k$：类别k中所有特征的总计数
- $V$：特征数量
- $\alpha$：平滑参数（拉普拉斯平滑 $\alpha=1$）

### 3.3 伯努利朴素贝叶斯

适用于二元特征（特征出现或不出现）：

$$P(x_i|y=k) = P(x_i=1|y=k)^{x_i} (1 - P(x_i=1|y=k))^{1-x_i}$$

**文本应用**：
- $x_i=1$: 词i出现在文档中
- $x_i=0$: 词i未出现在文档中

### 3.4 补充朴素贝叶斯

适用于连续数据，假设特征服从指数分布：

$$P(x_i|y=k) = \lambda_k \exp(-\lambda_k x_i)$$

### 4.1 高斯朴���贝叶斯训练

```python
import numpy as np
from collections import defaultdict

class GaussianNB:
    def __init__(self):
        self.classes = None
        self.class_prior = {}  # P(y)
        self.theta = {}       # 均值
        self.var = {}         # 方差
    
    def fit(self, X, y):
        """训练：计算每个类的先验和高斯参数"""
        n_samples, n_features = X.shape
        self.classes = np.unique(y)
        
        for c in self.classes:
            X_c = X[y == c]
            N_c = len(X_c)
            
            # 先验概率 P(y=c)
            self.class_prior[c] = N_c / n_samples
            
            # 高斯参数
            self.theta[c] = np.mean(X_c, axis=0)
            self.var[c] = np.var(X_c, axis=0) + 1e-9  # 避免除零
    
    def _pdf(self, X, c):
        """计算高斯概率密度"""
        eps = 1e-9
        mean = self.theta[c]
        var = self.var[c]
        
        coeff = 1.0 / np.sqrt(2 * np.pi * var + eps)
        exponent = -((X - mean) ** 2) / (2 * var + eps)
        
        return coeff * np.exp(exponent)
    
    def predict(self, X):
        """预测：计算后验概率"""
        predictions = []
        
        for x in X:
            posteriors = {}
            
            for c in self.classes:
                # log(P(y)) + log(P(x|y))
                log_prior = np.log(self.class_prior[c])
                
                # log(P(x|y)) = sum(log(P(x_i|y)))
                log_likelihood = np.sum(np.log(self._pdf(x, c) + 1e-9))
                
                posteriors[c] = log_prior + log_likelihood
            
            # 选择后验概率最大的类
            predictions.append(max(posteriors, key=posteriors.get))
        
        return np.array(predictions)
```

```python
class MultinomialNB:
    def __init__(self, alpha=1.0):
        self.alpha = alpha  # 平滑参数
        self.classes = None
        self.class_prior = {}
        self.feature_prob = {}
    
    def fit(self, X, y):
        """训练：计算词频"""
        n_samples, n_features = X.shape
        self.classes = np.unique(y)
        
        for c in self.classes:
            X_c = X[y == c]
            N_c = X_c.sum()  # 总词数
            self.class_prior[c] = len(X_c) / n_samples
            
            # 每个词的条件概率
            feature_count = X_c.sum(axis=0)
            self.feature_prob[c] = (feature_count + self.alpha) / (N_c + self.alpha * n_features)
    
    def predict(self, X):
        """预测"""
        predictions = []
        
        for x in X:
            posteriors = {}
            
            for c in self.classes:
                log_prior = np.log(self.class_prior[c])
                # 对数似然：乘积变求和
                log_likelihood = np.sum(x * np.log(self.feature_prob[c] + 1e-9))
                
                posteriors[c] = log_prior + log_likelihood
            
            predictions.append(max(posteriors, key=posteriors.get))
        
        return np.array(predictions)
```

## 6. 优缺点分析

### 6.1 优点

| 优点 | 说明 |
|------|------|
| 训练速度快 | 只需统计频率，无需迭代优化 |
| 预测速度快 | 条件概率计算简单 |
| 对高维数据友好 | 文本分类中效果好 |
| 可解释性强 | 概率形式，易于理解 |
| 对小规模数据有效 | 参数少，不易过拟合 |
| 可处理多分类 | 自然扩展到多类 |

### 6.2 缺点

| 缺点 | 说明 |
|------|------|
| 条件独立假设强 | 现实中特征往往相关 |
| 零概率问题 | 未见过的特征组合概率为0 |
| 特征条件概率 | 需离散化或假设分布 |
| 连续特征处理 | 高斯假设可能不成立 |

### 6.3 改进方法

1. **拉普拉斯平滑**：避免零概率
2. **特征选择**：去除相关特征
3. **特征合并**：组合相关特征
4. **混合模型**：结合其他分类器

## 8. 手工代码实现

### 8.1 完整高斯朴素贝叶斯

```python
import numpy as np
from collections import Counter

class NaiveBayesClassifier:
    """朴素贝叶斯分类器（高斯模型）"""
    
    def __init__(self):
        self.classes = None
        self.class_prior = {}  # P(y)
        self.theta = {}         # 均值
        self.var = {}          # 方差
        self.epis = 1e-9      # 防止除零
    
    def fit(self, X, y):
        """训练"""
        n_samples, n_features = X.shape
        self.classes = np.unique(y)
        
        for c in self.classes:
            X_c = X[y == c]
            N_c = X_c.shape[0]
            
            # 先验概率：P(y=c) = N_c / N
            self.class_prior[c] = N_c / n_samples
            
            # 似然参数：均值和方差
            self.theta[c] = X_c.mean(axis=0)
            self.var[c] = X_c.var(axis=0) + self.epis
    
    def _gaussian_pdf(self, x, mean, var):
        """高斯概率密度函数"""
        coef = 1.0 / np.sqrt(2 * np.pi * var)
        exp = np.exp(-((x - mean) ** 2) / (2 * var))
        return coef * exp
    
    def _predict_single(self, x):
        """预测单个��本"""
        posteriors = {}
        
        for c in self.classes:
            #log P(y) + log P(x|y)
            log_prior = np.log(self.class_prior[c])
            
            # log P(x_i|y) = sum(log P(x_i|y))
            log_likelihood = np.sum(
                np.log(self._gaussian_pdf(x, self.theta[c], self.var[c]) + self.epis)
            )
            
            posteriors[c] = log_prior + log_likelihood
        
        return max(posteriors, key=posteriors.get)
    
    def predict(self, X):
        """预测"""
        return np.array([self._predict_single(x) for x in X])
    
    def score(self, X, y):
        """评估准确率"""
        return np.mean(self.predict(X) == y)
```

### 8.2 多项式朴素贝叶斯

```python
class MultinomialNB:
    """多项式朴素贝叶斯（文本分类）"""
    
    def __init__(self, alpha=1.0):
        self.alpha = alpha
        self.classes = None
        self.class_prior = {}
        self.feature_log_prob = {}
    
    def fit(self, X, y):
        """训练"""
        n_samples = X.shape[0]
        self.classes = np.unique(y)
        n_features = X.shape[1]
        
        for c in self.classes:
            X_c = X[y == c]
            N_c = X_c.sum()
            
            # 先验
            self.class_prior[c] = X_c.shape[0] / n_samples
            
            # 词频：P(word_i|class_c)
            feature_count = X_c.sum(axis=0)
            self.feature_log_prob[c] = np.log(
                (feature_count + self.alpha) / (N_c + self.alpha * n_features)
            )
    
    def predict(self, X):
        """预测"""
        predictions = []
        
        for x in X:
            posteriors = {}
            
            for c in self.classes:
                log_prior = np.log(self.class_prior[c])
                log_likelihood = np.dot(x, self.feature_log_prob[c])
                
                posteriors[c] = log_prior + log_likelihood
            
            predictions.append(max(posteriors, key=posteriors.get))
        
        return np.array(predictions)
```

## 11. 常见问题与易错点

### 11.1 零概率问题

**问题**：新特征组合导致概率为0

**原因**：训练数据中未出现过该特征组合

**解决方案**：拉普拉斯平滑
```python
# sklearn自动处理
clf = MultinomialNB(alpha=1.0)  # alpha>0启用平滑

# 手动实现
p(x_i|y) = (N_{yi} + alpha) / (N_y + alpha * V)
```

### 11.2 下溢问题

**问题**：概率连乘导致数值下溢

**解决方案**：使用对数概率
```python
# 原来
posterior = P(y) * P(x_1|y) * P(x_2|y) * ...

# 修改为
log_posterior = log(P(y)) + log(P(x_1|y)) + log(P(x_2|y)) + ...
```

### 11.3 连续特征处理

**问题**：高斯假设不成立

**解决方案**：
1. 离散化（分箱）
2. 使用高斯朴素贝叶斯
3. 特征标准化

### 11.4 特征相关

**问题**：条件独立假设不成立

**说明**：实际中效果通常仍可接受，若效果差可：
1. 特征选择
2. 使用PCA降维
3. 换用其他分类器

### 11.5 类别不平衡

**问题**：少数类被忽略

**解决方案**：
```python
# 1. 调整先验
clf = MultinomialNB(alpha=0.1, class_prior=[0.3, 0.7])

# 2. 使用补充朴素贝叶斯
from sklearn.naive_bayes import ComplementNB
clf = ComplementNB()

# 3. 调整权重
clf = MultinomialNB(alpha=0.1, fit_prior=False)
```

## 12. 学习总结

### 12.1 核心要点

1. **贝叶斯定理**：$P(y|x) = \frac{P(x|y)P(y)}{P(x)}$
2. **条件独立假设**：$P(x|y) = \prod P(x_i|y)$
3. **三种变体**：
   - 高斯：连续特征
   - 多项式：计数数据
   - 伯努利：二元特征
4. **对数计算**：避免下溢

### 12.2 实用技巧

- 文本分类首选多项式朴素贝叶斯
- 使用TF-IDF而非简单计数
- alpha调参（0.01-0.5）
- 预处理：去除停用词

### 12.3 适用场景

- 文本分类（垃圾邮件、主题）
- 快速原型开发
- 特征维度高的数据
- 多分类问题

## 13. 练习题与思考题

### 13.1 基础题

**练习1**：贝叶斯定理计算
```
已知：
- P(垃圾邮件) = 0.3
- P(免费|垃圾邮件) = 0.8
- P(免费) = 0.35

求：P(垃圾邮件|免费)
```

**答案**：
$$P(垃圾邮件|免费) = \frac{P(免费|垃圾邮件) \times P(垃圾邮件)}{P(免费)}$$
$$= \frac{0.8 \times 0.3}{0.35} = \frac{0.24}{0.35} = 0.686$$

**练习2**：高斯概率密度
```
已知：mu=0, sigma=1, x=0
计算：P(x|mu,sigma)
```

**答案**：
$$P(x) = \frac{1}{\sqrt{2\pi}} e^{-0} = \frac{1}{\sqrt{2\pi}} \approx 0.399$$

### 13.3 思考题

**问题1**：为什么朴素假设有效？

**答案**：
1. 分类只需正确类别，不需精确概率
2. 错误的部分可能相互抵消
3. 参数少，不易过拟合

**问题2**：何时不使用朴素贝叶斯？

**答案**：
1. 特征强相关（可用特征选择或PCA）
2. 精确概率需求（可用概率校准）
3. 复杂决策边界

**问题3**：多分类怎么做？

**答案**：选择后验概率最大的类
$$\hat{y} = \arg\max_y P(y|x)$$
