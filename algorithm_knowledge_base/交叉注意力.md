# 交叉注意力学习文档

## 1. 算法基础认知

交叉注意力（Cross Attention）是Encoder-Decoder架构中的一种关键机制，它允许解码器（Decoder）在生成输出时关注编码器（Encoder）的表示。在传统的序列到序列（Seq2Seq）模型中，解码器只能看到自己的隐藏状态，而交叉注意力机制使解码器能够直接访问编码器的完整上下文信息，这对于机器翻译、文本摘要、问答系统等任务至关重要。

交叉注意力与自注意力（Self-Attention）不同：自注意力在同一个序列内部建立依赖关系，而交叉注意力在两个不同序列之间建立关系。假设我们有源序列$s$（编码器的输出）和目标序列$t$（解码器的输入），交叉注意力计算$t$中每个位置对$s$中每个位置的注意力分数。

交叉注意力最早在注意力机制论文（Bahdanau et al., 2014）中被提出，最初形式是加性注意力（Additive Attention）或拼接注意力。后续研究者提出了更高效的计算形式，包括点积注意力（Dot-Product Attention）。目前，交叉注意力已成为Transformer架构的核心组件之一。

理解交叉注意力对于掌握Seq2Seq模型和Transformer非常重要。许多实际应用，如机器翻译、对话系统、文本摘要，都依赖于交叉注意力机制来整合源序列和目标序列的信息。

## 2. 核心原理

交叉注意力的核心原理是通过计算目标序列（Query）对源序列（Key-Value）的注意力分数，来选择性地从源序列中获取信息。形式化地，设：

- 编码器输出（源序列）: $S = [s_1, s_2, ..., s_n]$，每个$s_i \in \mathbb{R}^d$
- 解码器隐藏状态（目标序列）: $T = [t_1, t_2, ..., t_m]$，每个$t_j \in \mathbb{R}^d$

交叉注意力计算：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

其中：
- $Q$（Query）来自解码器：$Q = T \cdot W^Q$
- $K$（Key）来自编码器：$K = S \cdot W^K$
- $V$（Value）来自编码器：$V = S \cdot W^V$

$W^Q, W^K, W^V$是可学习的投影矩阵。

输出是加权求和的源序列信息：
$$c_j = \sum_{i=1}^{n} \alpha_{j,i} \cdot v_i$$

其中$\alpha_{j,i}$是注意力权重：
$$\alpha_{j,i} = \frac{\exp(e_{j,i})}{\sum_{k=1}^{n} \exp(e_{j,k})}$$

而$e_{j,i} = \frac{q_j^T k_i}{\sqrt{d_k}}$是注意力分数。

## 3. 数学公式与推导

### 3.1 加性注意力（Bahdanau Attention）

最早的交叉注意力形式，由Bahdanau等人提出：

$$e_{ij} = v^T \tanh(W_q h_i + W_k s_j)$$

$$\alpha_{ij} = \frac{\exp(e_{ij})}{\sum_k \exp(e_{ik})}$$

$$c_i = \sum_j \alpha_{ij} s_j$$

其中$W_q, W_k, v$是可学习参数。

### 3.2 点积注意力（Scaled Dot-Product Attention）

Transformer中使用的形式，计算更高效：

$$e_{ij} = \frac{q_i^T k_j}{\sqrt{d_k}}$$

$$\alpha_{ij} = \text{softmax}(e_{ij})$$

优点：可以使用矩阵乘法并行计算，速度快。

### 3.3 推导：为什么需要缩放

点积注意力的方差会随维度增长：

$$\text{Var}(q_i^T k_j) = d_k \cdot \text{Var}(q) \cdot \text{Var}(k)$$

当$d_k$很大时，方差很大，softmax会进入饱和区域，梯度变小。

除以$\sqrt{d_k}$可以归一化方差：
$$\text{Var}\left(\frac{q^T k}{\sqrt{d_k}}\right) = \text{Var}(q^T k)$$

### 3.4 多头交叉注意力

$$ \text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O $$

其中：
$$\text{head}_i = \text{Attention}(QW_i^Q, KW_i^KV, VW_i^V)$$

## 4. 训练过程讲解

### 4.1 Encoder-Decoder架构

完��的Seq2Seq模型训练流程：

```
编码器:
  输入: x_1, x_2, ..., x_n
  编码: h_i = encoder(x_i)
  输出: enc_output = [h_1, h_2, ..., h_n]

解码器（自回归）:
  for t in 1..m:
    dec_input = y_{t-1}
    dec_output = decoder(dec_input, enc_output)
    y_pred = output_layer(dec_output)
```

以下是PyTorch实现的交叉注意力模块：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class CrossAttention(nn.Module):
    """交叉注意力层"""
    
    def __init__(self, d_model, n_heads, dropout=0.1):
        super(CrossAttention, self).__init__()
        
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        
        assert d_model % n_heads == 0, "d_model must be divisible by n_heads"
        
        self.W_Q = nn.Linear(d_model, d_model)
        self.W_K = nn.Linear(d_model, d_model)
        self.W_V = nn.Linear(d_model, d_model)
        
        self.W_O = nn.Linear(d_model, d_model)
        
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, query, key_value, mask=None):
        """
        前向传播
        
        Args:
            query: (batch, query_len, d_model)
            key_value: (batch, kv_len, d_model)
            mask: (batch, query_len, kv_len) or (batch, kv_len)
        
        Returns:
            output: (batch, query_len, d_model)
        """
        batch_size = query.size(0)
        query_len = query.size(1)
        kv_len = key_value.size(1)
        
        Q = self.W_Q(query)
        K = self.W_K(key_value)
        V = self.W_V(key_value)
        
        Q = Q.view(batch_size, query_len, self.n_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, kv_len, self.n_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, kv_len, self.n_heads, self.d_k).transpose(1, 2)
        
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        if mask is not None:
            if mask.dim() == 2:
                mask = mask.unsqueeze(1).unsqueeze(2)
            elif mask.dim() == 3:
                mask = mask.unsqueeze(1)
            scores = scores.masked_fill(mask == 0, -1e9)
        
        attn_weights = F.softmax(scores, dim=-1)
        attn_weights = self.dropout(attn_weights)
        
        context = torch.matmul(attn_weights, V)
        
        context = context.transpose(1, 2).contiguous().view(
            batch_size, query_len, self.d_model)
        
        output = self.W_O(context)
        
        return output, attn_weights


class EncoderLayerWithCrossAttention(nn.Module):
    """带交叉注意力的编码器层"""
    
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super(EncoderLayerWithCrossAttention, self).__init__()
        
        self.self_attn = nn.MultiheadAttention(d_model, n_heads, dropout)
        self.cross_attn = CrossAttention(d_model, n_heads, dropout)
        
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model)
        )
        
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, encoder_kv=None, src_mask=None, cross_mask=None):
        """前向传播"""
        q = x
        
        if encoder_kv is None:
            encoder_kv = x
        
        attn_out, _ = self.self_attn(x, x, x, attn_mask=src_mask)
        x = self.norm1(x + self.dropout(attn_out))
        
        attn_out, _ = self.cross_attn(x, encoder_kv, cross_mask)
        x = self.norm2(x + self.dropout(attn_out))
        
        ffn_out = self.ffn(x)
        x = self.norm3(x + self.dropout(ffn_out))
        
        return x


class DecoderLayerWithCrossAttention(nn.Module):
    """带交叉注意力的解码器层"""
    
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super(DecoderLayerWithCrossAttention, self).__init__()
        
        self.self_attn = nn.MultiheadAttention(d_model, n_heads, dropout)
        self.cross_attn = CrossAttention(d_model, n_heads, dropout)
        
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model)
        )
        
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, encoder_output, tgt_mask=None, src_mask=None):
        """前向传播"""
        q = x
        
        attn_out, _ = self.self_attn(x, x, x, attn_mask=tgt_mask)
        x = self.norm1(x + self.dropout(attn_out))
        
        attn_out, cross_attn_weights = self.cross_attn(
            x, encoder_output, src_mask)
        x = self.norm2(x + self.dropout(attn_out))
        
        ffn_out = self.ffn(x)
        x = self.norm3(x + self.dropout(ffn_out))
        
        return x, cross_attn_weights
```

```python
class Seq2SeqModel(nn.Module):
    """序列到序列模型"""
    
    def __init__(self, vocab_size, d_model=512, n_heads=8, n_layers=6, 
                 d_ff=2048, dropout=0.1, max_len=5000):
        super(Seq2SeqModel, self).__init__()
        
        self.d_model = d_model
        
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.pos_encoding = PositionalEncoding(d_model, max_len, dropout)
        
        self.encoder_layers = nn.ModuleList([
            EncoderLayerWithCrossAttention(d_model, n_heads, d_ff, dropout)
            for _ in range(n_layers)
        ])
        
        self.decoder_layers = nn.ModuleList([
            DecoderLayerWithCrossAttention(d_model, n_heads, d_ff, dropout)
            for _ in range(n_layers)
        ])
        
        self.output_layer = nn.Linear(d_model, vocab_size)
        
        self._init_weights()
    
    def _init_weights(self):
        for p in self.parameters():
            if p.dim() > 1:
                nn.init.xavier_uniform_(p)
    
    def encode(self, src, src_mask=None):
        """编码"""
        x = self.embedding(src) * math.sqrt(self.d_model)
        x = self.pos_encoding(x)
        
        for layer in self.encoder_layers:
            x = layer(x, None, src_mask)
        
        return x
    
    def decode(self, tgt, encoder_output, tgt_mask=None, src_mask=None):
        """解码"""
        x = self.embedding(tgt) * math.sqrt(self.d_model)
        x = self.pos_encoding(x)
        
        for layer in self.decoder_layers:
            x, attn_weights = layer(x, encoder_output, tgt_mask, src_mask)
        
        return self.output_layer(x)
    
    def forward(self, src, tgt, src_mask=None, tgt_mask=None):
        """前向传播"""
        encoder_output = self.encode(src, src_mask)
        output = self.decode(tgt, encoder_output, tgt_mask, src_mask)
        
        return output


def create_padding_mask(seq, pad_idx=0):
    """创建padding mask"""
    return (seq == pad_idx)


def create_causal_mask(seq_len):
    """创建因果 mask（上三角 mask）"""
    mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1).T == 1
    return mask


class PositionalEncoding(nn.Module):
    """位置编码"""
    
    def __init__(self, d_model, max_len=5000, dropout=0.1):
        super(PositionalEncoding, self).__init__()
        
        self.dropout = nn.Dropout(dropout)
        
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * 
                         (-math.log(10000.0) / d_model))
        
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        
        pe = pe.unsqueeze(0)
        self.register_buffer('pe', pe)
    
    def forward(self, x):
        x = x + self.pe[:, :x.size(1)]
        return self.dropout(x)


# 训练数据示例
def prepare_training_data():
    """准备训练数据"""
    source_texts = [
        "Hello, how are you?",
        "I love machine learning",
        "Transformer models are powerful"
    ]
    
    target_texts = [
        "Bonjour, comment allez-vous?",
        "J'adore l'apprentissage automatique",
        "Les modèles Transformer sont puissants"
    ]
    
    return source_texts, target_texts


def train_step(model, optimizer, src, tgt, src_mask, tgt_mask):
    """单步训练"""
    optimizer.zero_grad()
    
    output = model(src, tgt[:, :-1], src_mask, tgt_mask[:, :-1])
    
    loss = F.cross_entropy(
        output.view(-1, output.size(-1)),
        tgt[:, 1:].view(-1),
        ignore_index=0
    )
    
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    optimizer.step()
    
    return loss.item()
```
