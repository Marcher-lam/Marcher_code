# 余弦退火 学习文档

> 余弦曲线动态调整学习率，支持周期性重启提升泛化

## 1. 算法基础认知
余弦退火（Cosine Annealing）是一种动态学习率调度策略，核心思想是让学习率按照余弦函数的曲线从初始值逐步下降到0，每个周期结束后可以选择重启（Warm Restarts），重新开始新的余弦下降周期。该策略模拟了金属退火的过程：高温下分子运动剧烈（对应大学习率，参数大范围探索），温度逐步降低（对应学习率下降，参数精细调整），最终达到稳定状态（收敛到最优解）。

余弦退火由Loshchilov等人在2016年提出的论文《SGDR: Stochastic Gradient Descent with Warm Restarts》中正式引入深度学习领域，现已成为大模型预训练的标准学习率调度策略之一。与线性衰减相比，余弦退火的学习率下降速度先快后慢，更符合训练过程中损失下降的规律，同时周期性重启可以帮助模型逃离局部最优解，提升泛化性能。

## 2. 核心原理
余弦退火的核心逻辑是**让学习率随训练进度按余弦曲线下降**，假设当前周期长度为$T$，初始学习率为$\eta_{\text{max}}$，最小学习率为$\eta_{\text{min}}$，则第$t$步（在一个周期内）的学习率为：
$$\eta_t = \eta_{\text{min}} + \frac{1}{2}(\eta_{\text{max}} - \eta_{\text{min}}) \left(1 + \cos\left(\frac{t}{T} \pi\right)\right)$$
其中$t \in [0, T]$。当$t=0$时，$\cos(0)=1$，$\eta_0 = \eta_{\text{max}}$；当$t=T$时，$\cos(\pi)=-1$，$\eta_T = \eta_{\text{min}}$，符合余弦曲线的变化规律。

如果启用Warm Restarts（周期性重启），当当前周期结束后，$t$重置为0，开始新的周期，周期长度可以按$T_{\text{mult}}$倍数增长（例如$T_{\text{mult}}=2$，下一个周期长度是当前周期的2倍）。这种设计让模型在训练后期仍然有机会跳出局部最优，探索更优的参数空间。

## 3. 数学公式与推导
### 基础余弦退火公式推导
余弦函数的标准形式为$\cos(x)$，值域为$[-1, 1]$。我们需要将其映射到学习率区间$[\eta_{\text{min}}, \eta_{\text{max}}]$：
1. 当$x=0$时，$\cos(0)=1$，对应学习率$\eta_{\text{max}}$
2. 当$x=\pi$时，$\cos(\pi)=-1$，对应学习率$\eta_{\text{min}}$

首先将$\cos(x)$从$[-1,1]$映射到$[0,1]$：$\frac{1 + \cos(x)}{2}$，当$x=0$时为1，$x=\pi$时为0。
然后将其映射到$[\eta_{\text{min}}, \eta_{\text{max}}]$：
$$\eta_x = \eta_{\text{min}} + (\eta_{\text{max}} - \eta_{\text{min}}) \cdot \frac{1 + \cos(x)}{2}$$
将$x = \frac{t}{T} \pi$代入，得到：
$$\eta_t = \eta_{\text{min}} + \frac{1}{2}(\eta_{\text{max}} - \eta_{\text{min}}) \left(1 + \cos\left(\frac{t}{T} \pi\right)\right)$$

### 带Warm Restarts的余弦退火
假设第$i$个周期的长度为$T_i$，则当前步数$t$对应的周期内步数为$t - \sum_{j=0}^{i-1} T_j$，周期长度更新规则为$T_{i+1} = T_i \cdot T_{\text{mult}}$。

### 推导验证：为什么余弦退火比线性衰减好？
训练初期，损失下降快，需要较大的学习率，余弦退火初期下降速度快，匹配损失下降节奏；训练后期，损失下降慢，需要较小的学习率，余弦退火后期下降速度慢，避免参数震荡。而线性衰减的下降速度是固定的，无法适配这种节奏变化。

## 4. 训练过程讲解
使用PyTorch原生余弦退火调度器的标准流程：
1. **初始化模型与优化器**：定义模型，使用任意优化器（如SGD、AdamW），设置初始学习率$\eta_{\text{max}}$。
2. **定义余弦退火调度器**：使用`torch.optim.lr_scheduler.CosineAnnealingLR`（无重启）或`CosineAnnealingWarmRestarts`（带重启），设置$T_{\text{max}}$（周期长度）、$\eta_{\text{min}}$（最小学习率）。
3. **训练循环**：
   a. 执行前向传播、损失计算、反向传播、参数更新
   b. 每个epoch或step后调用`scheduler.step()`更新学习率
4. **可选：调整周期长度**：带重启的调度器可以设置$T_{\text{mult}}$，让周期长度逐步增长。

关键注意点：$T_{\text{max}}$的设置要和训练总轮数匹配，如果是带重启的调度器，第一个周期长度通常设置为总轮数的1/4到1/2，保证有足够的重启次数。

## 5. 应用场景
1. **大模型预训练**：BERT、GPT等模型预训练时使用余弦退火配合Warmup，是行业标准配置，能提升收敛速度和泛化性能。
2. **图像分类任务**：ResNet、ViT等在ImageNet上训练时，余弦退火比线性衰减的最终精度高1%-2%。
3. **长时间训练任务**：训练轮数>100的任务，余弦退火的周期性重启可以帮助模型逃离局部最优。
4. **生成模型训练**：GAN、扩散模型等训练不稳定的任务，余弦退火可以稳定训练过程。

## 6. 优缺点分析
### 优点
1. 学习率下降节奏符合训练规律，收敛速度和精度优于线性衰减
2. 支持周期性重启，帮助模型逃离局部最优，提升泛化性能
3. 实现简单，PyTorch原生支持，无需手写复杂逻辑
4. 适配各类优化器，和AdamW、LAMB等都能配合

### 缺点
1. 超参数较多（$T_{\text{max}}$、$\eta_{\text{min}}$、$T_{\text{mult}}$），需要精细调参
2. 对周期长度敏感，设置不当会导致训练不稳定
3. 无重启的余弦退火在训练后期学习率接近0，更新停滞
4. 小任务上提升有限，甚至不如简单的线性衰减

### 调度器对比表
| 调度器 | 衰减方式 | 支持重启 | 实现复杂度 | 适合场景 |
|--------|----------|------------|------------|----------|
| 线性衰减 | 线性下降 | 否 | 低 | 小任务、少轮次 |
| 余弦退火 | 余弦曲线下降 | 可选 | 中 | 大模型预训练、长时间训练 |
| Warmup | 线性上升 | 否 | 低 | 训练初期稳定 |
| 循环学习率 | 周期性波动 | 是 | 高 | 探索参数空间 |

## 7. 调库实现
使用PyTorch原生`CosineAnnealingLR`实现，代码可直接运行：
```python
import torch
import torch.nn as nn
import torch.optim as optim
import matplotlib.pyplot as plt

# 1. 创建简单模型
model = nn.Linear(10, 2)

# 2. 设置优化器和余弦退火调度器
optimizer = optim.SGD(model.parameters(), lr=0.1)
# T_max=50：50个epoch为一个完整周期，eta_min=0：最小学习率为0
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=50, eta_min=0)

# 3. 模拟训练过程，记录学习率变化
lr_history = []
for epoch in range(100):
    # 模拟训练步骤
    optimizer.zero_grad()
    output = model(torch.randn(32, 10))
    loss = output.sum()
    loss.backward()
    optimizer.step()
    
    # 更新学习率
    scheduler.step()
    current_lr = scheduler.get_last_lr()[0]
    lr_history.append(current_lr)
    print(f"Epoch {epoch+1}: Learning Rate={current_lr:.5f}")

# 4. 绘制学习率变化曲线
plt.plot(range(1, 101), lr_history)
plt.xlabel('训练轮次 (Epoch)')
plt.ylabel('学习率 (Learning Rate)')
plt.title('余弦退火学习率变化曲线 (T_max=50)')
plt.grid(True)
plt.show()
```

### 运行结果
```
Epoch 1: Learning Rate=0.10000
Epoch 2: Learning Rate=0.09901
Epoch 3: Learning Rate=0.09605
...
Epoch 50: Learning Rate=0.00000
Epoch 51: Learning Rate=0.09901  # 进入下一个周期
Epoch 52: Learning Rate=0.09605
...
Epoch 100: Learning Rate=0.09901
```
学习率按余弦曲线下降，50个epoch后回到接近初始值，开始新的周期。

## 8. 手工代码实现
从零实现余弦退火调度器，支持Warm Restarts：
```python
import math
from torch.optim.lr_scheduler import _LRScheduler

class CosineAnnealingWarmRestarts(_LRScheduler):
    def __init__(self, optimizer, T_0, T_mult=1, eta_min=0, last_epoch=-1):
        """
        带Warm Restarts的余弦退火调度器
        Args:
            optimizer: 关联的优化器
            T_0: 初始周期长度
            T_mult: 周期长度倍增因子，默认1（不倍增）
            eta_min: 最小学习率
            last_epoch: 最后一个epoch索引
        """
        self.T_0 = T_0
        self.T_mult = T_mult
        self.eta_min = eta_min
        self.T_cur = 0  # 当前周期内的步数
        self.T_i = T_0  # 当前周期长度
        super(CosineAnnealingWarmRestarts, self).__init__(optimizer, last_epoch)
    
    def get_lr(self):
        """计算当前学习率"""
        # 余弦退火公式
        lr = self.eta_min + (self.base_lrs[0] - self.eta_min) * (1 + math.cos(math.pi * self.T_cur / self.T_i)) / 2
        return [lr for _ in self.base_lrs]
    
    def step(self, epoch=None):
        """更新学习率，检查是否需要重启"""
        if epoch is None:
            epoch = self.last_epoch + 1
        self.last_epoch = epoch
        
        # 更新当前周期内的步数
        self.T_cur += 1
        # 如果达到当前周期长度，重启
        if self.T_cur >= self.T_i:
            self.T_cur = 0
            self.T_i *= self.T_mult
        
        # 更新学习率
        for param_group, lr in zip(self.optimizer.param_groups, self.get_lr()):
            param_group['lr'] = lr
```

## 11. 常见问题与易错点
### 数据层面
1. **T_max设置过大**：周期太长，学习率下降过慢，训练后期学习率仍较大导致震荡。解决：T_max设置为总轮数的1/4到1/2。
2. **eta_min设置过低**：学习率接近0，参数更新停滞，收敛变慢。解决：eta_min设置为初始学习率的1/100左右。
3. **数据量小**：余弦退火的提升有限，甚至不如线性衰减。解决：小任务使用简单调度器。

### 模型层面
1. **忘记调用scheduler.step()**：学习率不会更新，调度无效。解决：每个epoch后调用step()。
2. **T_mult设置过大**：周期长度增长过快，后期周期太长，重启次数太少。解决：T_mult设置为1或2。
3. **和Warmup的顺序错误**：应该先Warmup再余弦退火，顺序反了导致训练不稳定。

### 调参层面
1. **初始学习率设置过大**：余弦退火初期学习率大，导致训练震荡。解决：初始学习率设置为1e-3到1e-1。
2. **T_max和总轮数不匹配**：总轮数不是T_max的整数倍，最后一个周期不完整。解决：调整T_max或总轮数。

## 12. 学习总结
余弦退火是一种高效的动态学习率调度策略，通过余弦曲线下降学习率，匹配训练过程中损失下降的规律，同时支持周期性重启帮助模型逃离局部最优。它已成为大模型预训练的标准配置，比线性衰减有更高的收敛精度和泛化性能。使用时需要合理设置周期长度、最小学习率等超参数，通常配合Warmup策略使用，进一步提升训练稳定性。掌握余弦退火的原理和使用，是进入大模型训练领域的必备技能。

## 13. 练习题与思考题
### 基础题
1. 写出余弦退火的核心公式。
   答案：$\eta_t = \eta_{\text{min}} + \frac{1}{2}(\eta_{\text{max}} - \eta_{\text{min}}) \left(1 + \cos\left(\frac{t}{T} \pi\right)\right)$
2. 余弦退火中，当t=T时，学习率是多少？
   答案：$\eta_T = \eta_{\text{min}}$，因为$\cos(\pi) = -1$，代入公式得到$\eta_{\text{min}} + 0 = \eta_{\text{min}}$。

### 进阶题
1. 为什么余弦退火比线性衰减的收敛精度高？
   答案：余弦退火的学习率下降节奏先快后慢，匹配损失下降的规律，后期小学习率精细调整，避免震荡。
2. Warm Restarts的作用是什么？
   答案：让学习率回到较大的值，帮助模型跳出局部最优解，探索更优的参数空间，提升泛化性能。

### 开放题
在大模型预训练中，如何选择余弦退火的T_max和Warmup步数？
答案：通常Warmup步数设置为总步数的1/10到1/20，T_max设置为总步数减去Warmup步数，或者设置为Warmup步数的5-10倍，保证有足够的余弦下降周期。
