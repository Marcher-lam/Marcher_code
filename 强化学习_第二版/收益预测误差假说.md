## 11. 常见问题与易错点

### 11.1 数据层面常见错误

**错误1：奖励设计不合理**

**现象：**
- 智能体学不到有效策略
- 训练不收敛
- 学到意外行为

**原因：**
- 奖励稀疏或过于密集
- 奖励尺度不合适
- 未考虑奖励塑形

**解决方案：**
```python
# 1. 合理设计奖励函数
def reward_function(state, action, next_state):
    # 基础奖励
    reward = 0
    
    # 根据任务设计
    # 例如：到达目标给正奖励，失败给负奖励
    if goal_reached(next_state):
        reward += 10
    elif failed(next_state):
        reward -= 10
    
    return reward
```

**错误2：状态表示不当**

**现象：**
- 学习效率低
- 无法收敛

**原因：**
- 状态空间太大未离散化
- 重要特征未提取
- 状态未归一化

### 11.2 模型层面常见错误

**错误1：探索不足**

**现象：**
- 陷入局部最优
- 策略不更新

**原因：**
- ε太小或衰减太快
- 未使用合适的探索策略

**解决方案：**
```python
# 使用衰减的ε-贪心
def epsilon_decay(episode, epsilon_start=1.0, epsilon_end=0.01, decay_rate=0.995):
    return epsilon_end + (epsilon_start - epsilon_end) * np.exp(-decay_rate * episode)

# 或使用UCB等探索策略
```

**错误2：学习率设置不当**

**现象：**
- 学习率过大：震荡不收敛
- 学习率过小：学习太慢

**解决方案：**
```python
# 使用自适应学习率
def adaptive_lr(initial_lr=0.1, min_lr=0.001, decay_steps=1000):
    # 随时间衰减
    return max(min_lr, initial_lr * (0.9 ** (step // decay_steps)))
```

### 11.3 调参层面常见误区

**误区1：折扣因子γ设置不当**

**过大（接近1）：**
- 过于关注长期奖励
- 可能忽略短期重要奖励

**过小（接近0）：**
- 过于短视
- 无法学习长期策略

**正确做法：**
```python
# 根据任务时长选择
if task_horizon_short:
    gamma = 0.9
elif task_horizon_long:
    gamma = 0.99
```
