## 1. 算法基础认知

**一句话定义**：策略迭代（Policy Iteration）通过交替执行**策略评估**（计算当前策略的价值函数V^π）和**策略改进**（根据V^π更新为贪心策略），直到策略稳定，收敛到最优策略π*。

**直觉类比**：想象调音师调钢琴，第一次先听每个键的音高（策略评估：用当前策略弹一遍，记录每个状态的价值），然后调紧/松对应的弦（策略改进：根据音高偏差调整策略）。重复这两步直到钢琴音准（策略稳定）。策略迭代就是这种“评估→改进→再评估→再改进”的循环，直到找到最优策略。

**历史背景**：策略迭代由理查德·贝尔曼（Richard Bellman）于1950年代提出，作为动态规划在马尔可夫决策过程（MDP）中的核心应用。它是第一个被证明收敛到最优策略的规划算法，奠定了后续广义策略迭代（GPI）的理论基础，是理解DP、MC、TD统一框架的关键。

**算法定位**：
- 类型：强化学习 → 基于模型的规划（Model-Based Planning）
- 输出：最优状态价值函数V*(s)、最优策略π*(a|s)
- 模型类型：基于模型（需要完整MDP模型P(s'|s,a)、R(s,a,s')）
- 与GPI的关系：策略迭代是GPI的一个具体实现（严格的评估+改进交替）

**前置知识**：
- 马尔可夫决策过程（MDP）：状态、动作、转移概率P、奖励R、折扣因子γ
- 贝尔曼方程：V^π(s) = E[r + γV^π(s') | s, π]
- 贝尔曼最优方程：V*(s) = max_a E[r + γV*(s') | s, a]
- 策略评估与策略改进的概念
- 线性代数：不动点迭代、压缩映射（理解收敛性）
- Python编程：实现迭代算法、字典/列表操作

## 2. 核心原理

### 2.1 核心思想

策略迭代的核心思想是：通过**策略评估**和**策略改进**的交替迭代，逐步将任意初始策略优化到最优策略π*。它基于两个关键定理：
1. **策略改进定理**：如果π'在每一个状态s上都满足Q^π(s, π'(s)) ≥ V^π(s)，则π'的价值函数V^{π'} ≥ V^π。
2. **收敛性定理**：有限MDP中策略数量有限，且每次改进严格提升（或不变），因此策略迭代保证在有限步内收敛到最优策略π*。

核心思想可以概括为：通过“评估当前策略→改进策略→再评估→再改进”的循环，逐步收敛到全局最优策略。

### 2.2 工作流程

1. **初始化**：初始化策略π（随机或均匀策略）、价值函数V(s)（通常初始化为0）
   - 输入：MDP模型（S, A, P, R, γ）
   - 输出：初始π和V

2. **策略评估（Policy Evaluation）**：
   - 目标：计算当前策略π的价值函数V^π，直到收敛（Δ < θ）
   - 更新规则（同步迭代）：V_{k+1}(s) = Σ_a π(a|s) Σ_{s',r} P(s',r|s,a)[r + γV_k(s')]
   - 终止条件：max_s |V_{k+1}(s) - V_k(s)| < θ（收敛阈值）

3. **策略改进（Policy Improvement）**：
   - 根据V^π，更新策略为贪心策略：π'(s) = argmax_a Σ_{s',r} P(s',r|s,a)[r + γV^π(s')]
   - 检查策略稳定性：如果π' = π（所有状态最优动作不变），则已收敛到π*，停止；否则令π ← π'，继续。

4. **终止条件**：策略稳定（π' = π）或达到最大迭代次数。

### 2.3 关键概念解释

- **策略评估（Policy Evaluation）**：给定策略π，通过贝尔曼方程的迭代求解V^π的过程，本质是线性方程的迭代解法。
- **策略改进（Policy Improvement）**：根据当前价值函数V^π，将策略更新为贪心策略（每个状态选Q值最大的动作）。
- **策略改进定理（Policy Improvement Theorem）**：如果π'在每个状态s的Q值都不低于V^π(s)，则π'是比π更优或相等的策略。
- **广义策略迭代（GPI）**：任何让策略评估和策略改进交互的通用框架，策略迭代是GPI的一个特例（评估直到收敛，再改进）。
- **同步迭代（Synchronous Iteration）**：每次更新所有状态的价值，用上一次的全部V_k计算V_{k+1}，保证收敛。
- **in-place迭代（Asynchronous Iteration）**：更新时直接使用最新价值（V_{k+1}(s)可能在同一次迭代中被更新多次），加速收敛。

### 2.4 几何/直观解释

策略迭代可以看作是在策略空间中“爬坡”：策略评估是计算当前策略的高度（V^π），策略改进是往更高的地方迈一步（更新为贪心策略）。由于有限MDP的策略数量有限，且每一步都不下降，因此最多经过|Π|步（Π是所有可能策略的集合）就会收敛到最高点的π*。

与价值迭代相比，策略迭代的每一步更接近最优策略：评估是完整收敛的，而价值迭代是压缩迭代，每一步都不完全收敛。因此策略迭代通常收敛更快（更少的外层循环）。

## 3. 数学公式与推导

### 3.1 符号约定

| 符号 | 含义 | 维度/范围 |
|------|------|----------|
| $S$ | 状态集合 | 有限集，size S |
| $A$ | 动作集合 | 有限集，size A |
| $P(s',r\|s,a)$ | 状态转移概率和奖励 | $[0,1]$ |
| $\gamma$ | 折扣因子 | $[0,1)$ |
| $V^\pi(s)$ | 策略π的状态价值函数 | $\mathbb{R}$ |
| $Q^\pi(s,a)$ | 策略π的动作价值函数 | $\mathbb{R}$ |
| $\pi(a\|s)$ | 策略（动作概率分布） | $[0,1]$ |
| $\pi^*$ | 最优策略 | - |
| $V^*(s)$ | 最优状态价值函数 | $\mathbb{R}$ |
| $\theta$ | 收敛阈值 | 小正数（如1e-4） |

### 3.2 问题形式化

给定马尔可夫决策过程 $M = \langle S, A, P, R, \gamma \rangle$，策略迭代的目标是找到最优策略 $\pi^*$ 使得期望回报最大：
$$ \pi^* = \arg\max_\pi V^\pi(s), \quad \forall s \in S $$

等价于求解贝尔曼最优方程的不动点：
$$ V^*(s) = \max_a \sum_{s',r} P(s',r|s,a) \left[ r + \gamma V^*(s') \right] $$

### 3.3 目标函数/损失函数

**策略评估的目标**：求解线性方程 $V^\pi = f(V^\pi)$，其中 $f$ 是贝尔曼方程的映射：
$$ f(V)(s) = \sum_a \pi(a|s) \sum_{s',r} P(s',r|s,a) \left[ r + \gamma V(s') \right] $$

**策略改进的目标**：最大化每个状态的Q值：
$$ \pi'(s) = \arg\max_a Q^\pi(s,a) = \arg\max_a \sum_{s',r} P(s',r|s,a) \left[ r + \gamma V^\pi(s') \right] $$

### 3.4 推导过程

**Step 1：策略评估的迭代形式**

根据贝尔曼方程，策略π的价值函数满足：
$$ V^\pi(s) = \sum_a \pi(a|s) \sum_{s',r} P(s',r|s,a) \left[ r + \gamma V^\pi(s') \right] $$

这是一个线性方程组，变量是V(s)（共S个）。我们将其转化为迭代形式（同步迭代）：
$$ V_{k+1}(s) = \sum_a \pi(a|s) \sum_{s',r} P(s',r|s,a) \left[ r + \gamma V_k(s') \right] $$

当 $k \rightarrow \infty$ 时，$V_k \rightarrow V^\pi$。

**Step 2：策略改进定理的证明**

假设策略π和π'满足：对所有s∈S，$Q^\pi(s, \pi'(s)) \geq V^\pi(s)$。

根据Q值定义：
$$ Q^\pi(s, \pi'(s)) = \sum_{s',r} P(s',r|s,\pi'(s)) \left[ r + \gamma V^\pi(s') \right] $$

由条件得：
$$ \sum_{s',r} P(s',r|s,\pi'(s)) \left[ r + \gamma V^\pi(s') \right] \geq V^\pi(s) $$

对两边取V^{π'}的期望（因为π'选择动作π'(s)）：
$$ V^{\pi'}(s) = \sum_{s_1,r_1} P(s_1,r_1|s,\pi'(s)) \left[ r_1 + \gamma V^{\pi'}(s_1) \right] $$

将$s_1$展开为递归形式，结合不等式可证得 $V^{\pi'}(s) \geq V^\pi(s)$ 对所有s成立。

**Step 3：策略迭代的收敛性**

有限MDP的策略总数是有限的（|A|^|S| 种确定性策略）。每次策略改进要么严格提升（存在s使得Q^π(s,π'(s)) > V^π(s)），要么不变（已收敛到π*）。因此最多经过|Π|次迭代，策略必然稳定。

### 3.5 最终解/算法步骤

**算法：策略迭代（Policy Iteration）**
```
初始化：任意策略π（如均匀随机策略）
重复：
    1. 策略评估：
        初始化V(s) = 0（或任意值）
        重复：
            Δ ← 0
            对每个状态s：
                v ← V(s)
                V(s) ← Σ_a π(a|s) Σ_{s',r} P(s',r|s,a)[r + γV(s')]
                Δ ← max(Δ, |v - V(s)|)
        直到 Δ < θ（收敛阈值）
    
    2. 策略改进：
        策略稳定 ← True
        对每个状态s：
            旧动作 ← π(s) （确定性策略的选中的动作）
            π'(s) ← argmax_a Σ_{s',r} P(s',r|s,a)[r + γV(s')]
            如果 旧动作 ≠ π'(s)：
                策略稳定 ← False
        
        如果 策略稳定：
            返回 V, π （已收敛到V*和π*）
        否则：
            π ← π' （继续下一次迭代）
```

## 4. 训练过程讲解

### 4.1 数据预处理

**必要预处理**：
1. **环境模型获取**：策略迭代必须已知MDP模型P和R。
   - 已知模型：如棋盘游戏、简单网格世界，直接定义P和R。
   - 未知模型：需先通过大量交互采样估计P和R（转化为已知模型问题）。
   - 代码示例（采样估计模型）：
     ```python
     def estimate_mdp_model(env, num_samples=10000):
         """
         通过采样估计MDP模型
         env: 环境，需支持reset/step
         返回: P[s][a][s_next] = (prob, reward, count)
         """
         P = {s: {a: {} for a in range(env.n_actions)} 
              for s in range(env.n_states)}
         R = {s: {a: {} for a in range(env.n_actions)} 
              for s in range(env.n_states)}
         
         for _ in range(num_samples):
             s = env.reset()
             a = np.random.randint(env.n_actions)
             s_next, r, done, _ = env.step(a)
             
             # 统计转移次数和平均奖励
             if s_next in P[s][a]:
                 cnt, old_r, _ = P[s][a][s_next]
                 P[s][a][s_next] = (cnt+1, (old_r*cnt + r)/(cnt+1), cnt+1)
             else:
                 P[s][a][s_next] = (1, r, 1)
             
             if done:
                 continue
         
         # 转换为概率
         for s in P:
             for a in P[s]:
                 total = sum(cnt for _, _, cnt in P[s][a].values())
                 for s_next in P[s][a]:
                     cnt, r, _ = P[s][a][s_next]
                     P[s][a][s_next] = (cnt/total, r, cnt)
         
         return P
     ```

2. **状态/动作空间离散化**：连续状态需先离散化，因为DP要求有限状态空间。

### 4.2 参数初始化

- **策略π**：初始化为均匀随机策略（每个状态等概率选所有动作）或贪心策略（随机初始动作）。
- **价值函数V(s)**：通常初始化为0或小的随机值，不影响收敛（只影响收敛速度）。
- **收敛阈值θ**：推荐1e-4（平衡精度和速度），更小的θ（如1e-6）更精确但更慢。

### 4.3 迭代过程（Python实现）

```python
import numpy as np
from collections import defaultdict

class PolicyIterationAgent:
    """策略迭代智能体（表格型，确定性策略）"""
    
    def __init__(self, n_states, n_actions, gamma=0.99, theta=1e-4):
        """
        初始化智能体
        
        Args:
            n_states: 状态数量（有限）
            n_actions: 动作数量（有限）
            gamma: 折扣因子
            theta: 策略评估的收敛阈值
        """
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma
        self.theta = theta
        
        # MDP模型：P[s][a] = [(prob, s_next, reward), ...]
        self.P = None
        self.R = None  # R[s][a] = reward（简化：假设确定奖励）
        
        # 策略：确定性策略，policy[s] = 选中的动作
        self.policy = np.random.randint(0, n_actions, size=n_states)
        # 价值函数
        self.V = np.zeros(n_states)
    
    def set_model(self, P, R=None):
        """设置MDP模型"""
        self.P = P
        if R is not None:
            self.R = R
        else:
            # 从P中提取奖励（假设确定环境）
            self.R = {}
            for s in P:
                self.R[s] = {}
                for a in P[s]:
                    for s_next in P[s][a]:
                        prob, reward, _ = P[s][a][s_next]
                        if s not in self.R:
                            self.R[s][a] = {}
                        self.R[s][a][s_next] = reward
    
    def policy_evaluation(self, policy=None, max_iter=1000):
        """
        策略评估：计算给定策略的价值函数V^π
        
        Args:
            policy: 要评估的策略，None表示使用self.policy
            max_iter: 最大迭代次数
            
        Returns:
            V: 收敛的价值函数
        """
        if policy is None:
            policy = self.policy
        
        V = np.zeros(self.n_states)
        
        for i in range(max_iter):
            V_old = V.copy()
            delta = 0.0
            
            for s in range(self.n_states):
                a = policy[s]  # 确定性策略的动作
                # 计算贝尔曼方程的期望
                v = 0.0
                for s_next in self.P[s][a]:
                    prob, reward, _ = self.P[s][a][s_next]
                    v += prob * (reward + self.gamma * V_old[s_next])
                
                V[s] = v
                delta = max(delta, abs(V_old[s] - V[s]))
            
            if delta < self.theta:
                print(f"策略评估收敛于第{i+1}次迭代，Δ={delta:.6f}")
                return V
        
        print(f"策略评估达到最大迭代次数 {max_iter}")
        return V
    
    def policy_improvement(self, V, policy=None):
        """
        策略改进：根据价值函数更新策略
        
        Args:
            V: 当前价值函数
            policy: 当前策略（用于检查稳定性）
            
        Returns:
            new_policy: 改进后的策略（确定性）
            stable: 策略是否稳定
        """
        if policy is None:
            policy = self.policy
        
        new_policy = np.zeros(self.n_states, dtype=int)
        stable = True
        
        for s in range(self.n_states):
            # 计算所有动作的Q值
            q_values = np.zeros(self.n_actions)
            for a in range(self.n_actions):
                for s_next in self.P[s][a]:
                    prob, reward, _ = self.P[s][a][s_next]
                    q_values[a] += prob * (reward + self.gamma * V[s_next])
            
            # 选择最优动作
            best_a = np.argmax(q_values)
            new_policy[s] = best_a
            
            # 检查策略是否改变
            if policy[s] != best_a:
                stable = False
        
        return new_policy, stable
    
    def policy_iteration(self, max_outer_iter=100):
        """
        策略迭代主算法
        
        Args:
            max_outer_iter: 最大外层迭代次数（策略评估+改进的次数）
            
        Returns:
            V: 最优价值函数V*
            policy: 最优策略π*
        """
        print("开始策略迭代...")
        
        for i in range(max_outer_iter):
            # 1. 策略评估
            self.V = self.policy_evaluation(self.policy)
            
            # 2. 策略改进
            new_policy, stable = self.policy_improvement(self.V, self.policy)
            
            # 检查是否收敛
            if stable:
                print(f"策略迭代收敛于第{i+1}轮，已找到最优策略π*")
                self.policy = new_policy
                return self.V, self.policy
            
            self.policy = new_policy
        
        print(f"达到最大外层迭代次数 {max_outer_iter}")
        return self.V, self.policy
    
    def value_iteration(self, max_iter=1000):
        """
        价值迭代（对比用）
        
        Returns:
            V: 最优价值函数V*
            policy: 最优策略π*
        """
        print("开始价值迭代（对比）...")
        
        V = np.zeros(self.n_states)
        
        for i in range(max_iter):
            V_old = V.copy()
            delta = 0.0
            
            for s in range(self.n_states):
                # 计算max_a的贝尔曼最优方程
                q_values = np.zeros(self.n_actions)
                for a in range(self.n_actions):
                    for s_next in self.P[s][a]:
                        prob, reward, _ = self.P[s][a][s_next]
                        q_values[a] += prob * (reward + self.gamma * V_old[s_next])
                
                V[s] = np.max(q_values)
                delta = max(delta, abs(V_old[s] - V[s]))
            
            if delta < self.theta:
                print(f"价值迭代收敛于第{i+1}次迭代，Δ={delta:.6f}")
                break
        
        # 从V*提取最优策略
        policy = np.zeros(self.n_states, dtype=int)
        for s in range(self.n_states):
            q_values = np.zeros(self.n_actions)
            for a in range(self.n_actions):
                for s_next in self.P[s][a]:
                    prob, reward, _ = self.P[s][a][s_next]
                    q_values[a] += prob * (reward + self.gamma * V[s_next])
            policy[s] = np.argmax(q_values)
        
        return V, policy
```

### 4.4 收敛条件

- **策略评估收敛**：max_s |V_{k+1}(s) - V_k(s)| < θ（如1e-4）
- **策略迭代收敛**：策略稳定（π' = π），或达到最大外层迭代次数（如100次）
- **价值迭代收敛**：max_s |V_{k+1}(s) - V_k(s)| < θ，或达到最大迭代次数

### 4.5 超参数及推荐范围

| 超参数 | 作用 | 推荐范围 | 默认值 |
|--------|------|----------|--------|
| $\gamma$ (折扣因子) | 未来奖励的权重 | 0.9-0.999 | 0.99 |
| $\theta$ (收敛阈值) | 控制策略评估的停止 | 1e-6 ~ 1e-4 | 1e-4 |
| 最大外层迭代 | 防止无限循环 | 50-100 | 100 |
| 最大策略评估迭代 | 防止评估不收敛 | 100-1000 | 1000 |

**调参建议**：
- 收敛阈值θ：越小越精确，但策略评估更慢；通常1e-4足够。
- 折扣因子γ：任务horizon短选0.9，长选0.99+。
- 如果状态空间大，可使用in-place迭代加速策略评估。

## 5. 应用场景

### 5.1 典型应用

**应用1：棋盘游戏AI（国际象棋、围棋简化版）**
- 问题类型：完全信息博弈，状态转移确定或概率已知
- 为什么适合策略迭代：规则明确（模型已知），状态空间有限（简化版），需要全局最优策略
- 实际案例：早期国际象棋程序、简化版围棋AI

**应用2：机器人路径规划（已知地图）**
- 问题类型：已知环境地图，规划最优路径
- 为什么适合策略迭代：转移概率已知（移动成功率），奖励明确（到达目标+10，碰撞-10）
- 实际案例：扫地机器人路径规划、自动驾驶路线规划（已知高精地图）

**应用3：资源分配优化**
- 问题类型：多阶段决策，状态转移已知
- 为什么适合策略迭代：模型明确，需要全局最优解
- 实际案例：投资组合优化、生产计划调度、库存管理

### 5.2 适用数据特征

该算法适合的数据特征：
- **环境模型**：必须已知P(s'|s,a)和R(s,a,s')，否则无法使用
- **状态/动作空间**：必须有限，否则无法枚举计算
- **任务类型**：episodic和continuing均可，DP通用
- **计算资源**：需要内存存储P和R，状态空间大时内存爆炸

### 5.3 不适用场景

**不适合的情况**：
1. **未知环境模型**：无法获取P和R，或获取成本极高
   - 解决思路：改用无模型方法（MC、TD、Q-learning）
2. **状态/动作空间极大**：如围棋（10^170状态）、Atari游戏（像素状态）
   - 解决思路：使用函数逼近（DQN、Actor-Critic）
3. **连续状态/动作空间**：策略迭代要求离散有限空间
   - 解决思路：离散化后DP，或直接用连续控制算法（DDPG）
4. **实时决策需求**：策略迭代需要离线计算模型，无法在线学习
   - 解决思路：使用在线学习算法（Q-learning、Sarsa）

## 6. 优缺点分析

### 6.1 优点

1. **保证收敛到全局最优**：有限MDP中，策略迭代保证在有限步内收敛到π*
   - 成立条件：模型准确，γ < 1，状态/动作空间有限
   - 技术细节：基于策略改进定理和有限策略数量，严格收敛性证明

2. **样本效率最高**：无需与环境交互采样，利用完整模型直接计算
   - 成立条件：环境模型已知且准确
   - 技术细节：DP是规划方法，不是学习方法，零样本效率问题

3. **收敛速度快（相比价值迭代）**：通常只需要2-10次外层迭代即可收敛
   - 成立条件：策略评估收敛到V^π，而不是压缩迭代
   - 技术细节：每次外层迭代都显著改进策略，价值迭代需要更多次迭代

4. **理论清晰**：策略评估+改进的交替逻辑直观，易于理解和证明
   - 适用场景：教学、理解GPI框架
   - 技术细节：是理解广义策略迭代（GPI）的基础

### 6.2 缺点

1. **需要完整环境模型**：必须知道P(s'|s,a)和R(s,a,s')，现实中很难获取
   - 问题场景：复杂真实环境（如自动驾驶、机器人），模型无法精确建模
   - 解决思路：
     - 先通过交互采样估计模型（转为已知模型问题）
     - 改用无模型方法（MC、TD、Q-learning）

2. **维数灾难**：状态/动作空间大时无法计算（存储P需要S²A内存）
   - 问题场景：状态数S=10^6，动作数A=10，需要10^12内存
   - 解决思路：
     - 使用函数逼近（DQN、Actor-Critic）
     - 使用近似DP（如Dyna架构，结合模型学习和规划）

3. **策略评估可能很慢**：每次评估需要迭代到收敛（尤其γ接近1时）
   - 问题场景：大规模MDP，策略评估收敛慢
   - 解决思路：
     - 使用截断策略评估（如只迭代K次，不完收敛）
     - 使用in-place迭代加速收敛

4. **无法处理连续空间**：要求状态/动作空间离散有限
   - 问题场景：连续控制任务（如机器人关节角度）
   - 解决思路：
     - 离散化（但维度灾难）
     - 使用连续空间算法（DDPG、PPO）

### 6.3 与同类算法对比

| 维度 | 策略迭代 | 价值迭代 | 广义策略迭代（GPI） |
|------|-----------|--------------|------------------------|
| 策略评估深度 | 完全收敛到V^π | 不完全（单次更新） | 任意深度（可截断） |
| 外层迭代次数 | 少（2-10次） | 多（100+次） | 取决于评估深度 |
| 收敛速度 | 快（外层少） | 慢（外层多） | 可调 |
| 理论保证 | 有限步收敛到π* | 渐进收敛到V* | 收敛到π*（评估足够） |
| 计算量 | 每次评估迭代全状态 | 每次迭代全状态 | 灵活 |

**选择建议**：
- 选择策略迭代：模型已知、状态空间小、需要最快收敛到π*
- 选择价值迭代：模型已知、状态空间中等、实现更简单
- 选择GPI：需要灵活的评估/改进平衡，理解统一框架

```python
        self.P, self.R = self.build_model()
    
    def build_model(self):
        """构建精确的环境模型（确定环境）"""
        P = {s: {a: {} for a in range(self.n_actions)} 
             for s in range(self.n_states)}
        R = {s: {a: {} for a in range(self.n_actions)} 
             for s in range(self.n_states)}
        
        for s in range(self.n_states):
            x, y = s // 4, s % 4
            
            for a in range(self.n_actions):
                # 计算下一个状态
                next_x, next_y = x, y
                if a == 0:  # 上
                    next_y = max(0, y - 1)
                elif a == 1:  # 下
                    next_y = min(3, y + 1)
                elif a == 2:  # 左
                    next_x = max(0, x - 1)
                elif a == 3:  # 右
                    next_x = min(3, x + 1)
                
                s_next = next_x * 4 + next_y
                
                # 转移概率（确定环境，概率1.0）
                P[s][a][s_next] = (1.0, 0, 1)  # (prob, reward, count)
                
                # 奖励：到达目标+1，否则-0.01
                reward = 1.0 if s_next == self.goal else -0.01
                R[s][a][s_next] = reward
        
        return P, R
    
    def reset(self):
        return 0  # 从左上角开始
    
    def step(self, s, a):
        """模拟执行动作（用于验证）"""
        x, y = s // 4, s % 4

        elif a == 1: y = min(3, y+1)
        elif a == 2: x = max(0, x-1)
        elif a == 3: x = min(3, x+1)
        
        s_next = x * 4 + y
        reward = 1.0 if s_next == self.goal else -0.01
        done = (s_next == self.goal)
        
        return s_next, reward, done
```

```python
"""
策略迭代 手工实现
仅依赖Python基础库，从零实现核心逻辑
支持自定义环境和超参数
"""

import random

class PolicyIterationFromScratch:
    """策略迭代从零实现（简化版）"""
    
    def __init__(self, n_states, n_actions, gamma=0.99, theta=1e-4):
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma
        self.theta = theta
        
        # 模型：P[s][a] = [(prob, s_next, reward), ...]
        self.P = {}
        self.policy = [random.randint(0, n_actions-1) for _ in range(n_states)]
        self.V = [0.0] * n_states
    
    def set_model_from_grid(self, goal_state=15):
        """从网格世界构建模型"""
        for s in range(self.n_states):
            self.P[s] = {}
            for a in range(self.n_actions):
                self.P[s][a] = []
                
                x, y = s // 4, s % 4
                next_x, next_y = x, y
                
                if a == 0: next_y = max(0, y-1)
                elif a == 1: next_y = min(3, y+1)
                elif a == 2: next_x = max(0, x-1)
                elif a == 3: next_x = min(3, x+1)
                
                s_next = next_x * 4 + next_y
                reward = 1.0 if s_next == goal_state else -0.01
                prob = 1.0
                
                self.P[s][a].append((prob, s_next, reward))
    
    def policy_evaluation(self, policy, max_iter=1000):
        """策略评估"""
        V = [0.0] * self.n_states
        
        for _ in range(max_iter):
            V_old = V.copy()
            delta = 0.0
            
            for s in range(self.n_states):
                a = policy[s]
                v = 0.0
                for prob, s_next, reward in self.P[s][a]:
                    v += prob * (reward + self.gamma * V_old[s_next])
                
                V[s] = v
                delta = max(delta, abs(V_old[s] - V[s]))
            
            if delta < self.theta:
                return V
        
        return V
    
    def policy_improvement(self, V, policy):
        """策略改进"""
        new_policy = policy.copy()
        stable = True
        
        for s in range(self.n_states):
            # 计算所有动作的Q值
            q_values = [0.0] * self.n_actions
            for a in range(self.n_actions):
                for prob, s_next, reward in self.P[s][a]:
                    q_values[a] += prob * (reward + self.gamma * V[s_next])
            
            best_a = max(range(self.n_actions), key=lambda a: q_values[a])
            
            if policy[s] != best_a:
                stable = False
            new_policy[s] = best_a
        
        return new_policy, stable
    
    def policy_iteration(self):
        """策略迭代主函数"""
        policy = self.policy.copy()
        
        for i in range(100):
            # 策略评估
            V = self.policy_evaluation(policy)
            
            # 策略改进
            new_policy, stable = self.policy_improvement(V, policy)
            
            if stable:
                print(f"策略迭代收敛于第{i+1}轮")
                return V, new_policy
            
            policy = new_policy
        
        print("达到最大迭代次数")
        return V, policy

# ==============================

# ==============================
if __name__ == "__main__":

    agent = PolicyIterationFromScratch(n_states=16, n_actions=4, gamma=0.99, theta=1e-4)
    agent.set_model_from_grid(goal_state=15)
    
    # 运行策略迭代

    V, policy = agent.policy_iteration()
    
    # 打印结果
    print("\n最优价值函数:")
    for i in range(4):
        row = [f"{V[i*4+j]:6.2f}" for j in range(4)]
        print(f"Row {i}: {''.join(row)}")
    
    print("\n最优策略:")
    for i in range(4):
        row = [str(policy[i*4+j]) for j in range(4)]
        print(f"Row {i}: {' '.join(row)}")
    
    # 测试路径
    print("\n测试最优路径（从0到15）:")
    state = 0
    path = [state]
    goal = 15
    
    while state != goal:
        action = policy[state]
        x, y = state // 4, state % 4
        
        if action == 0: y = max(0, y-1)
        elif action == 1: y = min(3, y+1)
        elif action == 2: x = max(0, x-1)
        elif action == 3: x = min(3, x+1)
        
        state = x * 4 + y
        path.append(state)
    
    print(f"路径: {path}")
    print(f"长度: {len(path)-1} 步")
```

| 价值函数误差 | 策略评估问题 | 衡量V^π与真实V^π的差距 |
| 策略最优性 | 策略迭代问题 | 检查π是否等于π* |
| 收敛速度 | 算法比较 | 衡量迭代效率 |
| 路径长度 | 路径规划任务 | 直观反映策略质量 |

### 10.2 评估代码

```python
def evaluate_policy(policy, start_state=0, goal_state=15):
    """评估策略迭代学到的策略"""
    state = start_state
    path = [state]
    total_reward = 0
    
    while state != goal_state:
        action = policy[state]
        # 模拟执行（使用模型）
        x, y = state // 4, state % 4
        if action == 0: y = max(0, y-1)
        elif action == 1: y = min(3, y+1)
        elif action == 2: x = max(0, x-1)
        elif action == 3: x = min(3, x+1)
        
        state = x * 4 + y
        reward = 1.0 if state == goal_state else -0.01
        total_reward += reward
        path.append(state)
        
        if len(path) > 100:  # 防止无限循环
            break
    
    print(f"路径: {path}")
    print(f"路径长度: {len(path)-1} 步")
    print(f"总奖励: {total_reward:.2f}")
    
    return path, total_reward
```

## 11. 常见问题与易错点

### 11.1 数据层面常见错误

**错误1：环境模型不准确**
- 现象：策略迭代学到次优策略，与真实最优策略不符
- 原因：P或R估计错误，或环境是随机的但模型用了期望值
- 解决方案：
  - 多次采样估计P和R，提高模型精度
  - 对随机环境，使用期望转移概率

**错误2：状态空间太大导致内存爆炸**
- 现象：无法存储P（需要S²A内存）
- 原因：状态数S过大（如S=10^6）
- 解决方案：
  - 使用函数逼近代替表格型DP
  - 使用近似DP（如Dyna架构，结合模型学习和规划）

### 11.2 模型层面常见错误

**错误1：策略评估不收敛就进行策略改进**
- 现象：算法不收敛，策略震荡
- 原因：策略评估的θ设置过大，V^π未收敛
- 解决方案：减小θ，或增加策略评估的最大迭代次数

**错误2：混淆策略迭代和价值迭代**
- 现象：实现错误，结果不符合预期
- 原因：不清楚两者的区别（策略迭代评估直到收敛，价值迭代不完全更新）
- 解决方案：严格按算法步骤实现，区分两种算法

**错误3：使用随机策略时策略改进错误**
- 现象：策略改进后反而变差
- 原因：随机策略的改进需要计算期望Q值，而不是单个动作
- 解决方案：对随机策略，π(a|s) > 0的动作都要考虑，取期望最大的动作

## 12. 学习总结

### 12.1 核心要点回顾

✓ **核心思想**：通过“策略评估→策略改进→再评估→再改进”的循环，逐步收敛到全局最优策略π*
✓ **数学本质**：基于策略改进定理和有限MDP的策略数量有限，保证有限步收敛
✓ **优化目标**：找到最优策略π*，最大化期望累计折扣回报
✓ **适用场景**：模型已知、状态空间有限、需要全局最优解
✓ **局限性**：需要完整模型、维数灾难、无法处理连续空间

### 12.2 关键公式汇总

1. 策略评估更新：$$ V_{k+1}(s) = \sum_a \pi(a|s) \sum_{s',r} P(s',r|s,a)[r + \gamma V_k(s')] $$
2. 策略改进：$$ \pi'(s) = \arg\max_a \sum_{s',r} P(s',r|s,a)[r + \gamma V^\pi(s')] $$
3. 贝尔曼最优方程：$$ V^*(s) = \max_a \sum_{s',r} P(s',r|s,a)[r + \gamma V^*(s')] $$

### 12.3 最佳实践

- ✓ 确保环境模型准确（P和R）
- ✓ 合理设置收敛阈值θ，平衡精度和速度
- ✓ 优先使用策略迭代（收敛更快）
- ✓ 状态空间大时考虑近似DP或函数逼近
- ✓ 验证模型时用小网格世界测试

### 12.4 与其他算法的联系

- **前置算法**：动态规划（DP）、贝尔曼方程、MDP基础
- **后续算法**：广义策略迭代（GPI）、Dyna架构（结合模型学习和规划）
- **相关算法**：价值迭代（DP的另一个核心算法）、蒙特卡洛、时序差分（无模型方法）

**练习2：手动计算**

问题：假设一个2状态MDP：S={s0, s1}，A={a0, a1}，γ=0.9。
- P(s1|s0,a0)=1，奖励r=0；P(s0|s0,a1)=1，奖励r=1；
- P(s1|s1,任意a)=1，奖励r=10（终止状态）。
初始策略π：s0→a0，s1→任意。
请手动计算1次策略评估（迭代2次）后的V(s0)、V(s1)。

**答案与解析：**

**初始化**：V0(s0)=0，V0(s1)=0

**第1次迭代（k=0→k=1）**：
- V1(s0) = Σ_a π(a|s0) Σ_{s'} P(s'|s0,a)[r + γV0(s')]
  = 1 * [P(s1|s0,a0)*(0 + 0.9*V0(s1))] = 1*(0 + 0.9*0) = 0
- V1(s1) = 10 + 0.9*V0(s1) = 10 + 0 = 10

**第2次迭代（k=1→k=2）**：
- V2(s0) = 1 * [P(s1|s0,a0)*(0 + 0.9*V1(s1))] = 0 + 0.9*10 = 9
- V2(s1) = 10 + 0.9*V1(s1) = 10 + 9 = 19

因此，2次迭代后V(s0)=9，V(s1)=19。
（真实V^π(s0)=0+0.9*(10+0.9*0+0.9²*10+...) = 90，需要更多次迭代收敛）

### 13.2 进阶思考（2题）

**思考1：改进分析**

问题：策略评估需要迭代到收敛，速度慢，如何改进？
**答案与解析：**

**改进方法1：截断策略评估**
- 原理：不要求评估完全收敛，只迭代K次（如K=10）就进行策略改进
- 效果：策略迭代退化为广义策略迭代（GPI），评估深度可调
- 优势：加快单次外层迭代速度，整体收敛可能更快

**改进方法2：in-place迭代**
- 原理：策略评估时使用最新价值（V_{k+1}(s)可能在同一次迭代中被更新多次）
- 效果：加速策略评估的收敛速度
- 优势：通常比同步迭代快2-3倍

**改进方法3：直接求解线性方程组**
- 原理：策略评估是线性方程组，可用高斯消元法等直接求解
- 效果：一次求解V^π，无需迭代
- 劣势：状态空间大时（S>1000）计算量爆炸

---

**思考2：对比分析**

问题：策略迭代和价值迭代哪个更好？如何选择？
**答案与解析：**

**策略迭代的优势**：
1. 外层迭代次数少（通常2-10次），因为每次评估都收敛到V^π
2. 理论清晰，容易理解“评估→改进”的逻辑
3. 适合教学和理解GPI框架

**价值迭代的优势**：
1. 实现更简单（不需要单独的策略评估循环）
2. 单次迭代计算量小（只做一次max_a更新）
3. 适合状态空间中等的问题

**选择建议**：
- 模型已知、状态空间小、需要最快收敛：选策略迭代
- 实现简单优先、状态空间中等：选价值迭代
- 研究GPI框架：两种都实现，对比理解

### 13.3 开放思考（1题）

**思考3：创新扩展**

问题：如何将策略迭代应用到未知模型的问题？
**答案与解析：**

**方案1：先估计模型，再策略迭代**
1. 通过大量交互采样估计P(s'|s,a)和R(s,a,s')
2. 用估计的模型运行策略迭代
3. 随着采样增加，模型越来越准，策略越来越优
4. 这是Dyna架构的核心思想：模型学习+规划

**方案2：近似策略迭代（API）**
1. 用函数逼近代替表格存储V和π
2. 用采样估计的贝尔曼误差来更新价值函数
3. 策略改进用贪心策略，但用函数逼近的Q值
4. 适合大规模状态空间

**方案3：结合无模型方法**
1. 用MC或TD学习价值函数V^π（代替策略评估）
2. 改进策略为贪心策略（同策略迭代）
3. 交替进行：采样学V^π → 改进策略 → 再采样学V^π
4. 这是GPI在无模型领域的应用

## 超深度补充
## 深度补充：动态规划高级主题

### 策略迭代的收敛性证明

**定理**：策略迭代在有限MDP中保证收敛到最优策略。

**证明**：
1. **策略评估**：给定策略π，计算 $V^\pi$ 使用贝尔曼方程：
   $$ V^\pi(s) = \sum_a \pi(a|s) \sum_{s',r} p(s',r|s,a)[r + \gamma V^\pi(s')] $$
   这是一个线性系统，有唯一解。

2. **策略改进**：贪心更新保证单调改进：
   $$ \pi'(s) = \arg\max_a Q^\pi(s,a) $$
   根据贝尔曼最优方程，如果 $Q^\pi(s, \pi'(s)) = V^\pi(s)$ 对所有s成立，则π已是最优。

3. **有限性**：有限MDP中策略数量有限（$|A|^{|S|}$），每次改进严格提升（或不变），故必在有限步内收敛。

### 值迭代的误差界

**定理**：值迭代第k次迭代的误差界为：
$$ \| V_k - V^* \|_\infty \leq \frac{\gamma^k}{1-\gamma} \| V_1 - V_0 \|_\infty $$

**推导**：
值迭代：$V_{k+1} = \mathcal{B} V_k$，其中$\mathcal{B}$是最优贝尔曼算子。
由于$\mathcal{B}$是$\gamma$-压缩映射：
$$ \| \mathcal{B} V - \mathcal{B} V' \|_\infty \leq \gamma \| V - V' \|_\infty $$
迭代k次后：
$$ \| V_k - V^* \|_\infty \leq \gamma^k \| V_0 - V^* \|_\infty $$
利用几何级数求和得到上述界。

### 广义策略迭代（GPI）框架

策略迭代和值迭代都是GPI的特例：

**GPI的两个同步过程**：
1. **策略评估**：给定策略π，计算 $V^\pi$ 或 $Q^\pi$
2. **策略改进**：给定价值函数V，改进策略π

**不同算法的GPI实现**：
| 算法 | 策略评估 | 策略改进 |
|------|----------|----------|
| 策略迭代 | 精确求解（迭代评估至收敛） | 完全贪心更新 |
| 值迭代 | 单次更新（不等待收敛） | 隐式改进（在值更新中） |
| 截断策略迭代 | 有限次评估迭代 | 完全贪心更新 |

```python
import numpy as np

class RTDP:
    """实时动态规划（Real-Time Dynamic Programming）"""
    
    def __init__(self, n_states, n_actions, gamma=0.99, lr=0.1):
        self.V = np.zeros(n_states)
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma
        self.lr = lr
    
    def set_model(self, transitions):
        """设置环境模型"""
        self.transitions = transitions
    
    def rtdp_update(self, s, a, r, s_next):
        """RTDP更新：只更新访问过的状态"""
        # 计算TD目标
        if s_next is None:  # 终止状态
            td_target = r
        else:
            # 使用贪心动作选择
            next_values = []
            for a_next in range(self.n_actions):
                v = 0.0
                for prob, next_s, reward, done in self.transitions[s_next][a_next]:
                    if done:
                        v += prob * reward
                    else:
                        v += prob * (reward + self.gamma * self.V[next_s])
                next_values.append(v)
            td_target = r + self.gamma * max(next_values)
        
        # TD更新
        td_error = td_target - self.V[s]
        self.V[s] += self.lr * td_error
        
        return td_error
    
    def plan_episode(self, start_state, max_steps=100):
        """规划一个episode（使用当前模型）"""
        s = start_state
        trajectory = []
        
        for step in range(max_steps):
            # 贪心动作选择
            best_a = 0
            best_v = float('-inf')
            for a in range(self.n_actions):
                v = 0.0
                for prob, next_s, reward, done in self.transitions[s][a]:
                    if done:
                        v += prob * reward
                    else:
                        v += prob * (reward + self.gamma * self.V[next_s])
                if v > best_v:
                    best_v = v
                    best_a = a
            
            # 执行动作（模拟）
            prob, next_s, reward, done = random.choice(self.transitions[s][best_a])
            trajectory.append((s, best_a, reward, next_s))
            
            # RTDP更新
            self.rtdp_update(s, best_a, reward, next_s if not done else None)
            
            if done:
                break
            s = next_s
        
        return trajectory
    
    def solve(self, start_states, num_episodes=1000):
        """求解MDP"""
        for episode in range(num_episodes):
            start = random.choice(start_states)
            self.plan_episode(start)
            
            if (episode + 1) % 100 == 0:
                print(f"Episode {episode+1}/{num_episodes}")
```

### 理论扩展：压缩映射定理

**定义**：算子 $\mathcal{T}$ 是 $\gamma$-压缩映射，如果：
$$ \| \mathcal{T} V - \mathcal{T} V' \|_\infty \leq \gamma \| V - V' \|_\infty, \quad 0 \leq \gamma < 1 $$

**贝尔曼最优算子**：$\mathcal{B} V(s) = \max_a \sum_{s',r} p(s',r|s,a)[r + \gamma V(s')]$
是$\gamma$-压缩映射。

**证明**：
$$ |\mathcal{B} V(s) - \mathcal{B} V'(s)| = |\max_a Q(s,a) - \max_a Q'(s,a)| \leq \max_a |Q(s,a) - Q'(s,a)| $$
$$ \leq \gamma \max_{s'} |V(s') - V'(s')| = \gamma \| V - V' \|_\infty $$

**推论**：根据压缩映射不动点定理，$\mathcal{B}$ 有唯一不动点 $V^*$，且值迭代收敛到 $V^*$。

### 策略迭代的收敛性证明

**定理**：策略迭代在有限MDP中保证收敛到最优策略。

**证明**：
1. **策略评估**：给定策略π，计算 $V^\pi$ 使用贝尔曼方程：
   $$ V^\pi(s) = \sum_a \pi(a|s) \sum_{s',r} p(s',r|s,a)[r + \gamma V^\pi(s')] $$
   这是一个线性系统，有唯一解。

2. **策略改进**：贪心更新保证单调改进：
   $$ \pi'(s) = \arg\max_a Q^\pi(s,a) $$
   根据贝尔曼最优方程，如果 $Q^\pi(s, \pi'(s)) = V^\pi(s)$ 对所有s成立，则π已是最优。

3. **有限性**：有限MDP中策略数量有限（$|A|^{|S|}$），每次改进严格提升（或不变），故必在有限步内收敛。

### 值迭代的误差界

**定理**：值迭代第k次迭代的误差界为：
$$ \| V_k - V^* \|_\infty \leq \frac{\gamma^k}{1-\gamma} \| V_1 - V_0 \|_\infty $$

**推导**：
值迭代：$V_{k+1} = \mathcal{B} V_k$，其中$\mathcal{B}$是最优贝尔曼算子。
由于$\mathcal{B}$是$\gamma$-压缩映射：
$$ \| \mathcal{B} V - \mathcal{B} V' \|_\infty \leq \gamma \| V - V' \|_\infty $$
迭代k次后：
$$ \| V_k - V^* \|_\infty \leq \gamma^k \| V_0 - V^* \|_\infty $$
利用几何级数求和得到上述界。

### 广义策略迭代（GPI）框架

策略迭代和值迭代都是GPI的特例：

**GPI的两个同步过程**：
1. **策略评估**：给定策略π，计算 $V^\pi$ 或 $Q^\pi$
2. **策略改进**：给定价值函数V，改进策略π

**不同算法的GPI实现**：
| 算法 | 策略评估 | 策略改进 |

### 策略迭代的收敛性证明

**定理**：策略迭代在有限MDP中保证收敛到最优策略。

**证明**：
1. **策略评估**：给定策略π，计算 $V^\pi$ 使用贝尔曼方程：
   $$ V^\pi(s) = \sum_a \pi(a|s) \sum_{s',r} p(s',r|s,a)[r + \gamma V^\pi(s')] $$
   这是一个线性系统，有唯一解。

2. **策略改进**：贪心更新保证单调改进：
   $$ \pi'(s) = \arg\max_a Q^\pi(s,a) $$
   根据贝尔曼最优方程，如果 $Q^\pi(s, \pi'(s)) = V^\pi(s)$ 对所有s成立，则π已是最优。

3. **有限性**：有限MDP中策略数量有限（$|A|^{|S|}$），每次改进严格提升（或不变），故必在有限步内收敛。

### 值迭代的误差界

**定理**：值迭代第k次迭代的误差界为：
$$ \| V_k - V^* \|_\infty \leq \frac{\gamma^k}{1-\gamma} \| V_1 - V_0 \|_\infty $$

**推导**：
值迭代：$V_{k+1} = \mathcal{B} V_k$，其中$\mathcal{B}$是最优贝尔曼算子。
由于$\mathcal{B}$是$\gamma$-压缩映射：
$$ \| \mathcal{B} V - \mathcal{B} V' \|_\infty \leq \gamma \| V - V' \|_\infty $$
迭代k次后：
$$ \| V_k - V^* \|_\infty \leq \gamma^k \| V_0 - V^* \|_\infty $$
利用几何级数求和得到上述界。

```python
import numpy as np

class RTDP:
    """实时动态规划（Real-Time Dynamic Programming）"""
    
    def __init__(self, n_states, n_actions, gamma=0.99, lr=0.1):
        self.V = np.zeros(n_states)
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma
        self.lr = lr
    
    def set_model(self, transitions):
        """设置环境模型"""
        self.transitions = transitions
    
    def rtdp_update(self, s, a, r, s_next):
        """RTDP更新：只更新访问过的状态"""
        # 计算TD目标
        if s_next is None:  # 终止状态
            td_target = r
        else:
            # 使用贪心动作选择
            next_values = []
            for a_next in range(self.n_actions):
                v = 0.0
                for prob, next_s, reward, done in self.transitions[s_next][a_next]:
                    if done:
                        v += prob * reward
                    else:
                        v += prob * (reward + self.gamma * self.V[next_s])
                next_values.append(v)
            td_target = r + self.gamma * max(next_values)
        
        # TD更新
        td_error = td_target - self.V[s]
        self.V[s] += self.lr * td_error
        
        return td_error
    
    def plan_episode(self, start_state, max_steps=100):
        """规划一个episode（使用当前模型）"""
        s = start_state
        trajectory = []
        
        for step in range(max_steps):
            # 贪心动作选择
            best_a = 0
            best_v = float('-inf')
            for a in range(self.n_actions):
                v = 0.0
                for prob, next_s, reward, done in self.transitions[s][a]:
                    if done:
                        v += prob * reward
                    else:
                        v += prob * (reward + self.gamma * self.V[next_s])
                if v > best_v:
                    best_v = v
                    best_a = a
            
            # 执行动作（模拟）
            prob, next_s, reward, done = random.choice(self.transitions[s][best_a])
            trajectory.append((s, best_a, reward, next_s))
            
            # RTDP更新
            self.rtdp_update(s, best_a, reward, next_s if not done else None)
            
            if done:
                break
            s = next_s
        
        return trajectory
    
    def solve(self, start_states, num_episodes=1000):
        """求解MDP"""
        for episode in range(num_episodes):
            start = random.choice(start_states)
            self.plan_episode(start)
            
            if (episode + 1) % 100 == 0:
                print(f"Episode {episode+1}/{num_episodes}")
```

### 理论扩展：压缩映射定理

**定义**：算子 $\mathcal{T}$ 是 $\gamma$-压缩映射，如果：
$$ \| \mathcal{T} V - \mathcal{T} V' \|_\infty \leq \gamma \| V - V' \|_\infty, \quad 0 \leq \gamma < 1 $$

**贝尔曼最优算子**：$\mathcal{B} V(s) = \max_a \sum_{s',r} p(s',r|s,a)[r + \gamma V(s')]$
是$\gamma$-压缩映射。

**证明**：
$$ |\mathcal{B} V(s) - \mathcal{B} V'(s)| = |\max_a Q(s,a) - \max_a Q'(s,a)| \leq \max_a |Q(s,a) - Q'(s,a)| $$
$$ \leq \gamma \max_{s'} |V(s') - V'(s')| = \gamma \| V - V' \|_\infty $$

**推论**：根据压缩映射不动点定理，$\mathcal{B}$ 有唯一不动点 $V^*$，且值迭代收敛到 $V^*$。

3. **奖励**：每步-1（鼓励最短路径），到达目标+10
4. **转移模型**：如果撞墙则留在原地

**为什么使用DP**：
- 环境模型已知（网格世界规则明确）
- 状态空间有限（可以穷举）
- 需要精确的最优解

**值迭代实现要点**：
```python
# 伪代码
for iteration in range(max_iterations):
    delta = 0
    for s in all_states:
        v = V[s]
        # 计算最大值更新
        max_value = float('-inf')
        for a in actions:
            # 模型预测下一个状态和奖励
            next_s, reward = model(s, a)
            value = reward + gamma * V[next_s]
            max_value = max(max_value, value)
        V[s] = max_value
        delta = max(delta, abs(v - V[s]))
    if delta < theta:
        break
```

### 理论扩展：压缩映射定理

**定义**：算子 $\mathcal{T}$ 是 $\gamma$-压缩映射，如果：
$$ \| \mathcal{T} V - \mathcal{T} V' \|_\infty \leq \gamma \| V - V' \|_\infty, \quad 0 \leq \gamma < 1 $$

**贝尔曼最优算子**：$\mathcal{B} V(s) = \max_a \sum_{s',r} p(s',r|s,a)[r + \gamma V(s')]$
是$\gamma$-压缩映射。

**证明**：
$$ |\mathcal{B} V(s) - \mathcal{B} V'(s)| = |\max_a Q(s,a) - \max_a Q'(s,a)| \leq \max_a |Q(s,a) - Q'(s,a)| $$
$$ \leq \gamma \max_{s'} |V(s') - V'(s')| = \gamma \| V - V' \|_\infty $$

**推论**：根据压缩映射不动点定理，$\mathcal{B}$ 有唯一不动点 $V^*$，且值迭代收敛到 $V^*$。

**练习12：截断策略迭代**

**练习13：异步DP的收敛性**
问题：证明异步DP（Gauss-Seidel值迭代）比同步DP收敛更快。

答案要点：
1. 异步DP使用最新的值更新，信息传播更快
2. 同步DP使用旧的一轮值，需要等待所有状态更新完
3. 实验：在网格世界上比较两者达到收敛的迭代次数
4. 结论：异步DP通常快1.5-2倍

**练习14：RTDP的样本效率**
问题：为什么RTDP比值迭代更高效？在什么情况下RTDP可能失败？

答案要点：
1. RTDP只更新访问过的状态，避免无用计算
2. 适合大规模MDP，其中很多状态不可达
3. 失败情况：如果起始状态分布不均匀，可能错过重要状态
4. 解决方案：使用探索策略或重要性采样
