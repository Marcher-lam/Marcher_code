## 1. 总体原则

### 1.1 核心目标
每篇文档必须做到：**读完一篇，真正学会一个算法**。不是"知道名字"，而是能推导、能实现、能用起来。

### 1.2 写作基调
- **面向初学者但绝不降低深度**：假设读者有线性代数、概率论和 Python 基础，但不假设任何机器学习先验知识
- **解释"为什么"而非只写"是什么"**：每个公式、每个设计选择都必须给出动机（motivation）
- **循序渐进**：从直觉 → 原理 → 数学 → 代码，层层递进

### 1.3 禁止事项
- ❌ 占位符文本（如"请根据实际算法补充"）
- ❌ 通用模板套话（如"该章节介绍XX的基本概念"）
- ❌ 不解释的公式堆砌
- ❌ 不可运行的代码
- ❌ 跨算法完全复制粘贴的内容（优缺点、练习题、学习路径必须针对具体算法定制）
- ❌ 缩进错误的代码块

**示例**:
```markdown
## 1. 算法基础认知

**一句话定义**：线性回归用一条直线（或超平面）去拟合数据，预测连续值。

**直觉类比**：想象你在看一张散点图，上面画满了"面积-房价"的数据点。线性回归

**算法定位**：
- 类型：监督学习 → 回归
- 输出：连续值预测
- 参数模型

**前置知识**：
- 线性代数：矩阵运算、向量内积
- 微积分：偏导数、梯度
- 概率论：正态分布（理解概率解释时需要）
```

### 第 3 章：数学公式与推导

**目标**: 给出严谨但可读的数学推导，不跳步。

**必须包含**:
1. **符号约定**：列出所有用到的数学符号及其含义
2. **问题形式化**：将算法问题用数学语言表述
3. **目标函数/损失函数**：明确定义优化目标
4. **推导过程**：逐步推导，每一步都要解释"为什么这么变换"
5. **最终解/算法**：推导得到的最终公式或算法步骤

**格式要求**:
- 使用 LaTeX 数学公式语法（`$...$` 行内，`$$...$$` 独立行）
- 每个公式后紧跟文字解释
- 推导链中标注"由 XX 可得"、"对 XX 求导"等过渡语

**字数要求**: 500-1500 字（取决于算法复杂度）

**示例**:
```markdown
### 符号约定

| 符号 | 含义 |
|------|------|
| $X \in \mathbb{R}^{n \times d}$ | 特征矩阵，$n$ 个样本，$d$ 个特征 |
| $y \in \mathbb{R}^n$ | 标签向量 |
| $\theta \in \mathbb{R}^d$ | 参数向量 |

### 目标函数

线性回归的目标是最小化残差平方和：

$$J(\theta) = \frac{1}{2n} \sum_{i=1}^{n} (y_i - \theta^T x_i)^2$$

为什么用平方而非绝对值？因为平方损失对应高斯噪声假设下的最大似然估计
（见下方推导）。

### 推导：解析解

将 $J(\theta)$ 写成矩阵形式：

$$J(\theta) = \frac{1}{2n} (y - X\theta)^T(y - X\theta)$$

对 $\theta$ 求导并令其为零：

$$\nabla_\theta J = -\frac{1}{n}X^T(y - X\theta) = 0$$

展开得：

$$X^T X \theta = X^T y$$

当 $X^T X$ 可逆时，解析解为：

$$\theta^* = (X^T X)^{-1} X^T y$$
```

### 第 6 章：优缺点分析

**目标**: 帮助读者在算法选型时做决策。

**必须包含**:
1. **优点**（3-5 个）：每个优点说明在什么条件下成立
2. **缺点**（3-5 个）：每个缺点说明在什么情况下会成为问题
3. **与同类算法对比**：列出 2-3 个功能相似的算法，简要对比

**禁止**: 使用通用套话如"实现简单、解释性强"。必须针对具体算法。

**字数要求**: 300-500 字

**示例**:
```markdown
### 优点
1. **解析解存在**：线性回归有封闭解 $\theta^* = (X^TX)^{-1}X^Ty$，
   无需迭代优化，计算效率高
2. **可解释性强**：每个特征的系数直接反映其对预测的贡献方向和大小
3. **概率解释清晰**：在误差服从高斯分布假设下，最小二乘等价于最大似然估计

### 缺点
1. **线性假设**：只能建模线性关系，对非线性数据拟合效果差
   → 解决：多项式回归、特征变换
2. **对异常值敏感**：平方损失放大异常值影响
   → 解决：Huber 损失、RANSAC
3. **多重共线性**：特征高度相关时，$(X^TX)$ 近似奇异，解不稳定
   → 解决：岭回归（L2 正则化）

### 与同类算法对比

| 维度 | 线性回归 | 岭回归 | LASSO |
|------|---------|--------|-------|
| 正则化 | 无 | L2 | L1 |
| 特征选择 | 不支持 | 不支持 | 支持 |
| 共线性处理 | 差 | 好 | 中等 |
```

### 第 8 章：手工代码实现

**目标**: 从零实现算法核心逻辑，让读者理解内部机制。

**必须满足**:
1. ✅ **使用 NumPy**（传统 ML）或 **纯 PyTorch tensor 操作**（深度学习）
2. ✅ **实现核心算法**：不是简单调用库，而是真正实现算法逻辑
3. ✅ **类结构**：使用 `class` 封装，有 `fit`、`predict` 等方法
4. ✅ **详细注释**：关键步骤注释解释数学原理
5. ✅ **可运行**：附带测试代码

**代码结构**:
```python
"""
[算法名] 手工实现
仅依赖 NumPy，从零实现算法核心逻辑
"""
import numpy as np

class LinearRegressionManual:
    """手工实现的线性回归
    
    使用正规方程求解: θ = (X^T X)^{-1} X^T y
    """
    
    def __init__(self):
        self.weights = None
        self.bias = None
    
    def fit(self, X, y):
        """训练模型
        
        参数:
            X: np.ndarray, shape (n_samples, n_features)
            y: np.ndarray, shape (n_samples,)
        """
        # 添加偏置列 [1, x1, x2, ...]
        X_b = np.c_[np.ones(len(X)), X]
        # 正规方程求解
        theta = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y
        self.bias = theta[0]
        self.weights = theta[1:]
        return self
    
    def predict(self, X):
        """预测"""
        return X @ self.weights + self.bias

# === 测试代码 ===
if __name__ == "__main__":
    # 生成测试数据
    np.random.seed(42)
    X = 2 * np.random.rand(100, 1)
    y = 4 + 3 * X.ravel() + np.random.randn(100) * 0.5
    
    model = LinearRegressionManual()
    model.fit(X, y)
    print(f"权重: {model.weights}, 偏置: {model.bias}")
    # 预期输出: 权重接近 [3.0], 偏置接近 4.0
```

## 3. 格式规范

### 3.1 文件命名
- 中文算法名直接用中文：`线性回归.md`
- 英文算法名用原名：`Transformer.md`
- 驼峰命名用下划线：`k-D_tree.md` → `k-D_tree.md`

### 3.2 Markdown 格式
- 标题层级：`#` 算法名，`##` 章节号，`###` 子章节
- 公式：LaTeX 语法
- 代码块：标注语言 ` ```python `
- 表格：用于对比和符号说明
- 加粗：用于强调关键概念

### 3.3 代码规范
- Python 3.9+ 兼容
- 遵循 PEP 8
- 变量名有意义
- 导入放在文件顶部
