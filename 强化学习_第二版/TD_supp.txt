## 补充内容：TD学习深入解析

### TD(λ)的资格迹机制

资格迹记录了每个状态-动作对在过去被访问的"痕迹"。痕迹的衰减由λ参数控制：

更新规则：E_t(s,a) = γλ E_{t-1}(s,a) + 1(s_t=s, a_t=a)

TD(λ)更新公式：
Q(s,a) ← Q(s,a) + α δ_t E_t(s,a)

其中δ_t是TD误差。

### n-step TD详解

| 算法 | 更新公式 | 特点 |
|------|----------|------|
| TD(0) | Q(s_t,a_t) ← Q(s_t,a_t) + α[r_{t+1} + γQ(s_{t+1}) - Q(s_t,a_t)] | 单步，高偏差低方差 |
| n-step TD | Q(s_t,a_t) ← Q(s_t,a_t) + α[G_t^{(n)} - Q(s_t,a_t)] | n步回报，平衡偏差方差 |
| TD(λ) | Q(s_t,a_t) ← Q(s_t,a_t) + αδ_t E_t(s,a) | 资格迹，理论最优λ exists |

### 代码示例：TD(λ)实现

```python
class TDLambdaAgent:
    def __init__(self, n_states, n_actions, lamda=0.9, gamma=0.99, lr=0.01):
        self.Q = np.zeros((n_states, n_actions))
        self.lamda = lamda
        self.gamma = gamma
        self.lr = lr
    
    def update(self, trajectory, rewards):
        E = np.zeros_like(self.Q)  # 资格迹
        
        for t, ((s, a), r) in enumerate(zip(trajectory, rewards)):
            s_next, a_next = trajectory[t+1] if t < len(trajectory)-1 else (None, None)
            
            if s_next is not None:
                td_target = r + gamma * self.Q[s_next, a_next]
            else:
                td_target = r
            
            td_error = td_target - self.Q[s, a]
            
            # 更新资格迹
            E *= self.lamda * self.gamma
            E[s, a] += 1.0
            
            # 更新所有状态-动作对
            self.Q += self.lr * td_error * E
```
