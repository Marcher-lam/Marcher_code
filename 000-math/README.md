# AI 数学基础

本模块涵盖人工智能所需的数学基础知识，包括线性代数、概率论、微积分和最优化理论。

## 📚 目录结构

```
000-math/
├── 01-linear-algebra.ipynb    # 线性代数
├── 02-probability.ipynb        # 概率论与数理统计
├── 03-calculus.ipynb          # 微积分
├── 04-optimization.ipynb      # 最优化理论
└── README.md
```

## 🎯 学习目标

### 1. 线性代数
- 向量和矩阵运算
- 特征值和特征向量
- 矩阵分解（SVD、QR、LU）
- 张量运算

### 2. 概率论与数理统计
- 随机变量和概率分布
- 贝叶斯定理
- 期望、方差和协方差
- 最大似然估计

### 3. 微积分
- 导数和偏导数
- 梯度和方向导数
- 链式法则（反向传播基础）
- 雅可比矩阵和海森矩阵

### 4. 最优化理论
- 梯度下降法
- 凸优化
- 拉格朗日乘数法
- 约束优化
