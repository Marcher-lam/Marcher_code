# 最优停止(Optimal Stopping) 学习文档

> 决定何时停止观察并采取行动，是序列决策的经典问题。

> 来源线索：本节内容根据原书中关于"Optimal Stopping"的相关章节(Ch 2.1.7)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：最优停止问题决定何时停止序列观察并接受当前选项，目标是最大化期望奖励。

**模型**：观测$W^1, W^2, \ldots$，停止时获得当前观测的奖励：

$$\max_\tau \mathbb{E}[W^\tau]$$

**经典问题——秘书问题**：面试N个候选人，按随机顺序逐个面试。每面试一个必须立即决定接受或拒绝。最优策略：先观察$\approx N/e$个（了解市场），然后接受第一个比前面都好的。

**最优停止规则**：

$$\text{停止当} W^n \geq v^n$$

其中$v^n$是"保留价值"（继续观察的期望价值）。

## 4-8. 核心实现

```python
"""最优停止：秘书问题"""
import numpy as np

def secretary_problem(N=100, n_sims=10000):
    """秘书问题模拟"""
    wins = 0
    for _ in range(n_sims):
        candidates = np.random.permutation(N)
        threshold = int(N / np.e)  # 观察前1/e
        best_so_far = candidates[:threshold].max()
        chosen = N  # 默认最后一个
        for i in range(threshold, N):
            if candidates[i] > best_so_far:
                chosen = i
                break
        if candidates[chosen] == N - 1:  # 选到最优
            wins += 1
    return wins / n_sims

if __name__ == "__main__":
    np.random.seed(42)
    prob = secretary_problem(N=100, n_sims=10000)
    print(f"秘书问题选到最优的概率: {prob:.3f} (理论≈1/e≈{1/np.e:.3f})")
```

## 9-14. 简要

### 12. 学习总结
最优停止：$\max_\tau E[W^\tau]$。停止规则$W^n \geq v^n$，保留价值=继续期望。秘书问题最优概率≈1/e。

### 13. 练习题
**Q1**：股票卖出是最优停止问题吗？
**A1**：是的。决定何时卖出股票（停止持有）以最大化期望收益。但比标准停止问题复杂——可以设定止损/止盈、价格过程非平稳。
