# 前瞻中的修正目标(Modified Objectives in Lookahead) 学习文档

> 前瞻模型的目标函数可以不同于基模型——风险调整、机会约束、多目标效用函数。

> 来源线索：本节内容根据原书中关于"Modified Objectives in Lookahead Models"的相关章节(Ch 19.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：在前瞻模型中使用修改后的目标函数——如风险度量替代期望值——以获得更鲁棒的决策。

## 2. 核心原理

**常见修正方式**：

1. **风险调整策略**：
   - 用CVaR替代期望：$\min_x CVaR_\alpha[C(x, \omega)]$
   - 更关注尾部风险

2. **机会约束策略**：
   - $P(C(x, \omega) \leq threshold) \geq 1-\alpha$
   - 将约束变为概率性的

3. **多目标效用函数**：
   - $U(cost, risk, service\_level) = w_1 \cdot cost + w_2 \cdot risk$
   - 权重可调

4. **模型折扣**：
   - 前瞻模型中使用与基模型不同的折扣因子
   - 前瞻折扣因子作为可调参数

**为什么修改目标**：
- 基模型的目标可能不适合前瞻模型的简化设定
- 修改目标可以补偿前瞻模型的近似误差
- 风险偏好可能不同于期望最优

## 3. Python 实现

```python
import numpy as np

def risk_adjusted_lookahead(inventory, n_scenarios=100, alpha=0.1):
    """CVaR前瞻策略"""
    best_order = 0
    best_cvar = np.inf

    for order in range(0, 25):
        costs = []
        for _ in range(n_scenarios):
            demand = np.random.poisson(8)
            held = max(0, inventory + order - demand)
            stockout = max(0, demand - inventory - order)
            cost = held * 1.0 + stockout * 5.0
            costs.append(cost)

        costs = np.sort(costs)
        cutoff = int(np.ceil(n_scenarios * (1 - alpha)))
        cvar = np.mean(costs[cutoff:])
        if cvar < best_cvar:
            best_cvar = cvar
            best_order = order

    return best_order, best_cvar

np.random.seed(42)
order, cvar = risk_adjusted_lookahead(inventory=5)
print(f"CVaR前瞻最优订货量: {order}, CVaR值: {cvar:.2f}")
```

## 4. 与其他方法的关系

- **鲁棒优化**：最坏情况优化的极端形式
- **VaR/CVaR**：风险度量的选择
- **模型预测控制**：可以在目标中加入风险项
