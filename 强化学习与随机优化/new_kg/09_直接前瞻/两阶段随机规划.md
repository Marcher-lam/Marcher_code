# 两阶段随机规划(Two-Stage Stochastic Programming) 学习文档

> 第一阶段决策+第二阶段补偿，是随机规划的典型结构。

> 来源线索：本节内容根据原书中关于"Two-Stage Stochastic Programming"的相关章节(Ch 19.9)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：两阶段随机规划在观测随机参数之前做第一阶段决策$x$，观测后做第二阶段补偿$y(\omega)$。

**模型**：

$$\min_x \left\{c^Tx + \mathbb{E}_\omega[\min_y q(\omega)^Ty(\omega)]\right\}$$
$$\text{s.t. } Ax = b, \quad T(\omega)x + Wy(\omega) = h(\omega), \quad y \geq 0$$

**求解方法**：
1. **Benders分解/L形法**：将第二阶段切割平面加到第一阶段
2. **SAA**：蒙特卡洛采样后求解确定性等价

## 4-8. 核心实现

```python
"""两阶段随机规划：简化的投资组合问题"""
import numpy as np
from scipy.optimize import linprog

def two_stage_sp(scenarios, probs):
    """两阶段SP：投资决策+市场观测后调整"""
    K = len(scenarios)
    # 简化：第一阶段投多少，第二阶段根据场景调整
    best_x, best_cost = 0, np.inf
    for x in np.arange(0, 100, 5):
        expected_cost = 0
        for k in range(K):
            # 第二阶段：最优补偿
            demand = scenarios[k]
            sold = min(x, demand)
            shortfall = max(0, demand - x)
            excess = max(0, x - demand)
            stage2_cost = -10*sold + 3*shortfall + 2*excess
            expected_cost += probs[k] * stage2_cost
        total = 6*x + expected_cost
        if total < best_cost:
            best_cost = total
            best_x = x
    return best_x, best_cost

if __name__ == "__main__":
    np.random.seed(42)
    scenarios = np.random.poisson(50, 20)
    probs = np.ones(20) / 20
    x, cost = two_stage_sp(scenarios, probs)
    print(f"最优第一阶段决策: x={x}, 总期望成本={cost:.1f}")
```

## 9-14. 简要

### 12. 学习总结
两阶段SP：$\min_x c^Tx + E[\min_y q^Ty]$。Benders分解用切平面迭代，SAA用蒙特卡洛近似。

### 13. 练习题
**Q1**：两阶段和多阶段随机规划的区别？
**A1**：两阶段只有一个"此时"决策和一个补偿。多阶段有多个决策时刻，每步观测后调整，是更一般的序列决策问题。
