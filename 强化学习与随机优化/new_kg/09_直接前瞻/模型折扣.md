# 模型折扣(Model Discounting in Lookahead) 学习文档

> 前瞻模型中的折扣因子作为可调参数——不同于基模型的折扣。

> 来源线索：Ch 19.3.3 "Model Discounting"

## 1. 基础认知

**一句话定义**：前瞻模型中使用独立的折扣因子 $\gamma_{la}$，与基模型的 $\gamma$ 不同，用于控制前瞻的"近视程度"。

## 2. 核心原理

**核心思想**：前瞻模型的目标函数使用 $\gamma_{la}$ 而非 $\gamma$：
$$V^{la}(s) = \max_a [r(s,a) + \gamma_{la} \sum_{s'} P(s'|s,a) V^{la}(s')]$$

- $\gamma_{la} < \gamma$：更短视的前瞻（更快响应近端信息）
- $\gamma_{la} > \gamma$：更远视的前瞻（更多考虑长期）
- $\gamma_{la}$ 是可调参数

## 3. Python 实现

```python
import numpy as np

def lookahead_with_discount(state, V_approx, gamma_la=0.8, gamma_base=0.95, H=5):
    for gamma in [gamma_la, gamma_base]:
        value = sum(gamma**t * np.random.rand() for t in range(H))
        print(f"  γ={gamma}: 前瞻值={value:.2f}")

lookahead_with_discount(0, None)
```
