# 前瞻混合策略(Lookahead PFAs/CFAs/VFAs/DLAs) 学习文档

> 前瞻策略可以与PFA/CFA/VFA组合——用简单策略辅助前瞻搜索。

> 来源线索：本节内容根据原书中关于"Lookahead Policies with Value Function Approximations"等的相关章节(Ch 19.7)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：在前瞻模型中嵌入PFA/CFA/VFA/DLA作为子策略，用简单方法处理前瞻树的一部分。

## 2. 核心原理

**四种前瞻混合模式**：

1. **前瞻VFA**：搜索H步后用VFA截断
   $$V_{t+H}(s_{t+H}) \approx \bar{V}(s_{t+H}|\theta)$$

2. **前瞻CFA**：在前瞻模型中用参数化修正
   $$\min_{x_t,...,x_{t+H}} \sum_{\tau} \bar{C}(S_\tau, x_\tau|\theta)$$

3. **前瞻PFA**：在rollout中用简单规则代替完整前瞻
   - MCTS的rollout策略就是前瞻PFA

4. **前瞻DLA**：嵌套前瞻（前瞻中的前瞻）
   - 计算量极大，通常不实际

**设计原则**：
- 前瞻处理近期的精确规划
- 子策略处理远期的粗略估计
- 用参数调优补偿近似误差

## 3. Python 实现

```python
import numpy as np

def lookahead_vfa(inventory, V_approx, T=3, n_actions=20, gamma=0.9):
    """前瞻VFA：搜索T步后用VFA截断"""
    best_order = 0
    best_value = -np.inf

    for order in range(n_actions):
        value = 0
        inv = inventory + order
        for t in range(T):
            demand = 8  # 期望需求
            held = max(0, inv - demand)
            stockout = max(0, demand - inv)
            cost = held * 1.0 + stockout * 5.0
            value -= gamma**t * cost
            inv = held
        # VFA截断
        value += gamma**T * V_approx(inv)
        if value > best_value:
            best_value = value
            best_order = order

    return best_order

# 简单VFA：库存越多越好（递减）
V_approx = lambda inv: 10 * np.sqrt(inv + 1)

order = lookahead_vfa(inventory=5, V_approx=V_approx)
print(f"前瞻VFA最优订货量: {order}")
```

## 4. 与其他方法的关系

- **MCTS**：前瞻DLA + rollout PFA + VFA
- **AlphaGo**：前瞻DLA + PFA策略网络 + VFA值网络
- **模型预测控制**：前瞻CFA的实现
