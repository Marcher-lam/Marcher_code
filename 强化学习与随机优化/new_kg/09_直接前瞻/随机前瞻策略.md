# 随机前瞻策略(Stochastic Lookahead Policies) 学习文档

> 显式建模未来不确定性——通过场景采样或场景树表示可能的未来。

> 来源线索：本节内容根据原书中关于"Stochastic Lookahead Policies"的相关章节(Ch 19.5-19.6)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：随机前瞻策略在前瞻模型中保留随机性，通过采样多条可能的未来路径来做出更鲁棒的决策。

## 2. 核心原理

**方法**：
1. 采样 $N$ 条场景路径 $\omega^1, ..., \omega^N$
2. 对每条路径做前瞻优化
3. 选择在所有（或大多数）场景下表现最好的决策

**两阶段随机规划**是最简单的随机前瞻：
$$\min_x c^T x + E_\omega[Q(x, \omega)]$$

**多阶段随机前瞻**的计算挑战：
- 场景树指数增长
- 需要场景缩减或采样
- 可用SAA（Sample Average Approximation）

**与确定性前瞻的对比**：
- 确定性前瞻忽略不确定性→可能次优
- 随机前瞻显式处理不确定性→更鲁棒但计算昂贵

## 3. Python 实现

```python
import numpy as np

def stochastic_lookahead(inventory, demand_dist, n_scenarios=50, T=3, gamma=0.9):
    """随机前瞻：多场景平均"""
    best_order = 0
    best_expected_cost = np.inf

    for order in range(0, 25):
        costs = []
        for _ in range(n_scenarios):
            total_cost = 0
            inv = inventory + order
            for t in range(T):
                demand = np.random.choice(demand_dist)
                held = max(0, inv - demand)
                stockout = max(0, demand - inv)
                cost = held * 1.0 + stockout * 5.0
                total_cost += gamma**t * cost
                inv = held
            costs.append(total_cost)
        expected_cost = np.mean(costs)
        if expected_cost < best_expected_cost:
            best_expected_cost = expected_cost
            best_order = order

    return best_order

np.random.seed(42)
demand_dist = np.array([3, 5, 7, 9, 11])
order = stochastic_lookahead(inventory=5, demand_dist=demand_dist)
print(f"当前库存5, 随机前瞻最优订货量: {order}")
```

## 4. 与其他方法的关系

- **两阶段随机规划**：最简单的随机前瞻
- **SAA**：用采样平均值近似期望
- **MCTS**：通过随机rollout做随机前瞻
