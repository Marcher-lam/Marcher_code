# 确定性前瞻策略(Deterministic Lookahead Policies) 学习文档

> 用期望值替代随机变量，将随机前瞻简化为确定性优化——计算简单但忽略不确定性。

> 来源线索：本节内容根据原书中关于"Deterministic Lookahead"的相关章节(Ch 19.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：确定性前瞻策略假设未来不确定性取期望值，将随机前瞻问题转化为确定性优化问题求解。

## 2. 核心原理

**方法**：将随机变量 $W_{t+1}, ..., W_{t+H}$ 替换为其期望值 $\bar{W}$：
$$\min_{x_t,...,x_{t+H}} \sum_{\tau=t}^{t+H} C(S_\tau, x_\tau)$$
$$\text{s.t. } S_{\tau+1} = S^M(S_\tau, x_\tau, \bar{W}_{\tau+1})$$

**优点**：可用标准确定性优化器（LP、MILP、NLP）
**缺点**：忽略不确定性→可能做出风险过高的决策

**参数化确定性前瞻**：加入可调参数 $\theta$ 补偿近似误差：
$$\min_{x_t,...,x_{t+H}} \sum_{\tau=t}^{t+H} \bar{C}(S_\tau, x_\tau|\theta)$$

## 3. Python 实现

```python
import numpy as np

def deterministic_lookahead(inventory, demand_mean, T=5, gamma=0.9):
    """确定性前瞻：库存控制"""
    best_order = 0
    best_cost = np.inf

    for order in range(0, 30):
        total_cost = 0
        inv = inventory + order
        for t in range(T):
            demand = demand_mean  # 用期望值代替随机需求
            held = max(0, inv - demand)
            stockout = max(0, demand - inv)
            cost = held * 1.0 + stockout * 5.0
            total_cost += gamma**t * cost
            inv = held
        if total_cost < best_cost:
            best_cost = total_cost
            best_order = order

    return best_order

order = deterministic_lookahead(inventory=5, demand_mean=8)
print(f"当前库存5, 确定性前瞻最优订货量: {order}")
```

## 4. 与其他方法的关系

- **随机前瞻**：显式建模不确定性的版本
- **模型预测控制(MPC)**：滚动horizon的确定性前瞻
- **CFA修正**：在确定性前瞻上加参数修正
