# 采样信念模型(Sampled Belief Models) 学习文档

> 用离散参数样本加概率分布表示非线性模型的参数不确定性。

> 来源线索：本节内容根据原书中关于"Sampled Belief Models"的相关章节(Ch 3.9.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：采样信念模型将连续参数空间离散化为有限个候选值，用概率分布表示参数不确定性，通过贝叶斯更新维护信念。

**直觉类比**：你不确定明天的天气模型参数。你准备5套候选参数（晴天型、多云型、雨天型等），每套有一个可信度（概率）。每次观测天气后，用贝叶斯定理更新每套参数的可信度。

**历史背景**：采样信念模型是贝叶斯非参数方法的简化版本。原书Ch 3.9.2中作为处理非线性模型参数不确定性的实用方法引入，避免了连续参数空间的积分困难。

**算法定位**：在线学习/贝叶斯参数估计。是MLE的贝叶斯替代方案。

**前置知识**：贝叶斯定理、最大似然估计、概率分布。

## 2. 核心原理

**核心思想**：假设参数$\theta$只能取有限值$\theta_1, \ldots, \theta_K$，用概率$p_k^n = \mathbb{P}[\theta = \theta_k | H^n]$表示对每个候选的信念。新观测到来时用贝叶斯更新概率。

**工作流程**：
1. 生成候选参数集$\Theta = \{\theta_1, \ldots, \theta_K\}$
2. 初始化先验概率$p_k^0$（均匀或其他）
3. 每次观测后用贝叶斯更新$p_k^{n+1}$
4. 用期望预测：$\hat{y} = \sum_k p_k^n f(x|\theta_k)$

## 3. 数学公式与推导

### 贝叶斯更新

观测$Y=y^{n+1}$后更新概率：

$$p_k^{n+1} = \frac{\mathbb{P}[Y=y^{n+1}|x^n, \theta_k, H^n] \cdot p_k^n}{\sum_{j=1}^K \mathbb{P}[Y=y^{n+1}|x^n, \theta_j, H^n] \cdot p_j^n}$$

### 逻辑回归似然

对二分类$Y \in \{0, 1\}$：

$$\mathbb{P}[Y=1|x, \theta_k] = \frac{\exp(U(x|\theta_k))}{1 + \exp(U(x|\theta_k))}$$

似然：

$$\mathbb{P}[Y=y|x, \theta_k] = \begin{cases} f(x|\theta_k) & \text{if } y=1 \\ 1-f(x|\theta_k) & \text{if } y=0 \end{cases}$$

### 信念状态

$$B^n = (p^n, \Theta)$$

可定期用新候选替换低概率的$\theta_k$，保持集合质量。

## 4-6. 简要

### 应用
1. 医疗决策中的个性化治疗参数估计
2. 强化学习中的转移模型参数学习
3. 在线广告点击率模型的不确定性量化

### 优缺点
**优点**：处理非线性模型简单直观、天然表达不确定性
**缺点**：参数空间大时$K$需要很大、离散化可能遗漏最优参数

## 7-8. 核心实现

```python
"""采样信念模型：离散参数空间的贝叶斯更新"""
import numpy as np

class SampledBeliefModel:
    """采样信念模型"""
    def __init__(self, theta_candidates, prior=None):
        self.thetas = np.array(theta_candidates)  # K个候选参数向量
        self.K = len(theta_candidates)
        self.probs = np.ones(self.K) / self.K if prior is None else np.array(prior)

    def predict_proba(self, x):
        """加权预测 P(Y=1|x)"""
        probs_per_theta = np.array([self._likelihood_1(x, t) for t in self.thetas])
        return np.sum(self.probs * probs_per_theta)

    def update(self, x, y):
        """贝叶斯更新：观测(x, y)后更新信念"""
        likelihoods = np.array([
            self._likelihood_1(x, t) if y == 1 else 1 - self._likelihood_1(x, t)
            for t in self.thetas
        ])
        # 后验 ∝ 似然 × 先验
        unnormalized = likelihoods * self.probs
        self.probs = unnormalized / (unnormalized.sum() + 1e-15)
        return self.probs

    @staticmethod
    def _likelihood_1(x, theta):
        """逻辑模型 P(Y=1|x, theta)"""
        u = theta[0] + np.dot(theta[1:], x) if len(theta) > 1 else theta[0]
        return 1 / (1 + np.exp(-np.clip(u, -500, 500)))

if __name__ == "__main__":
    np.random.seed(42)

    # 生成候选参数
    candidates = [
        [-1.0, 0.5, -0.3],
        [0.0, 1.0, 0.0],
        [1.0, 0.3, 0.5],
        [0.5, -1.0, 0.3],
        [-0.5, 0.8, -0.5],
    ]
    true_theta = [0.5, -1.0, 0.3]

    sbm = SampledBeliefModel(candidates)

    # 在线学习
    for i in range(200):
        x = np.random.randn(2)
        u = true_theta[0] + true_theta[1]*x[0] + true_theta[2]*x[1]
        p = 1 / (1 + np.exp(-u))
        y = 1 if np.random.random() < p else 0
        sbm.update(x, y)

    print("参数后验概率:")
    for k in range(sbm.K):
        print(f"  θ_{k}={candidates[k]}, P={sbm.probs[k]:.3f}")
    print(f"最可能的参数: θ_{np.argmax(sbm.probs)}")
```

## 9-14. 简要

### 12. 学习总结
采样信念模型：$B^n=(p^n, \Theta)$，贝叶斯更新$p_k^{n+1} \propto L(y|x,\theta_k)p_k^n$。用离散样本近似连续参数后验。

### 13. 练习题
**Q1**：如何处理候选集$\Theta$不包含真实参数的情况？
**A1**：定期生成新候选（从高概率参数附近采样），删除低概率参数。保持$K$固定但更新候选集。
