## 1-3. 核心认知与公式

**一句话定义**：体制转换模型假设系统在有限个离散状态（体制）间切换，每个体制有不同的参数。

**模型**：用隐马尔可夫模型(HMM)描述体制切换：

$$p_{t+1} = p_t + \kappa(S_t)(\bar{\mu}_{S_t} - p_t) + \sigma_{S_t}\varepsilon_{t+1}$$

其中$S_t \in \{1, \ldots, K\}$是隐体制状态，转移矩阵$P_{ij} = \mathbb{P}(S_{t+1}=j|S_t=i)$。

**典型应用**：
- 高/低波动体制（金融市场）
- 正常/高峰价格体制（电力市场）
- 经济扩张/衰退（宏观经济）

## 4-8. 核心实现

```python
"""体制转换模型：简化HMM"""
import numpy as np

class RegimeSwitching:
    def __init__(self, n_regimes=2):
        self.K = n_regimes
        self.params = [{'mu': 50, 'sigma': 2}, {'mu': 50, 'sigma': 10}]
        self.trans_mat = np.array([[0.95, 0.05], [0.1, 0.9]])

    def simulate(self, p0, T):
        prices = [p0]
        regimes = []
        s = 0
        for t in range(T):
            regimes.append(s)
            noise = self.params[s]['sigma'] * np.random.randn()
            p = 0.9*prices[-1] + 0.1*self.params[s]['mu'] + noise
            prices.append(p)
            s = np.random.choice(self.K, p=self.trans_mat[s])
        return np.array(prices), np.array(regimes)

if __name__ == "__main__":
    np.random.seed(42)
    rs = RegimeSwitching()
    prices, regimes = rs.simulate(50.0, 500)
    regime1 = prices[1:][regimes == 0]
    regime2 = prices[1:][regimes == 1]
    print(f"体制0(低波动): {len(regime1)}步, σ≈{regime1.std():.1f}")
    print(f"体制1(高波动): {len(regime2)}步, σ≈{regime2.std():.1f}")
```

### 12. 学习总结
体制转换：隐状态$S_t$切换参数$(\mu_{S},\sigma_{S})$。HMM框架，EM算法估计参数。

### 13. 练习题
**Q1**：体制转换和跳跃扩散捕捉的不同现象？
**A1**：跳跃扩散捕捉瞬时跳变后快速回归；体制转换捕捉持续性的参数变化（高波动期持续一段时间）。
