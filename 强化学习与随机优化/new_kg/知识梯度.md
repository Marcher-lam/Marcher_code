# 知识梯度(Knowledge Gradient) 学习文档

> Knowledge Gradient显式计算"学到的信息有多值钱"，是信息量最优的探索策略，由本书作者Powell教授提出。

> 来源线索：本节内容根据原书中关于"The Knowledge Gradient"的相关章节(Ch 7.8)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：Knowledge Gradient（KG）策略选择使"后验期望最优值-当前最优值"最大化的动作，即选择能带来最多有价值信息的选项。

**直觉类比**：你在面试两个候选人。候选人A简历很好但你对他的编程能力很确定（90%概率合格）。候选人B简历一般但不确定（可能0%也可能100%合格）。如果你只面一个人就做决定，面A能确认已知的好选择；面B虽然风险大，但"可能学到改变决定的关键信息"。KG策略会计算：面B能带来多少"改变当前最优选择的可能性"，如果足够大就选B。

**历史背景**：Knowledge Gradient由Warren B. Powell和Ilya O. Ryzhov在2012年系统提出，是本书作者的代表性贡献之一。KG的核心思想是显式计算学习的价值（information value），在贝叶斯框架下给出理论最优的探索策略。

**算法定位**：无导数随机搜索/贝叶斯探索策略。在原书Ch 7中，KG是与UCB、Thompson采样、Gittins指数并列的核心探索策略。

**前置知识**：贝叶斯统计、多臂赌博机、正态分布、期望计算。

## 2. 核心原理

**核心思想**：KG不只看"当前哪个臂最好"，而是计算"如果拉某个臂，我能获得多少改变未来决策的信息价值"。具体来说，KG计算：在拉完臂$a$后，后验分布下的期望最优值，减去当前已知的最优值。差值就是"知识梯度"——拉这个臂能带来多少"知识的增值"。

**工作流程**：

1. 维护每个臂的信念分布（如$\mu_k \sim \mathcal{N}(\bar{\mu}_k^n, \sigma_k^{2,n})$）
2. 对每个候选臂$a$，计算KG值：$v_a^{KG,n} = \mathbb{E}[\max_k \bar{\mu}_k^{n+1} | a^n = a] - \max_k \bar{\mu}_k^n$
3. 选择KG值最大的臂：$a^* = \arg\max_a v_a^{KG,n}$
4. 拉动该臂，观察奖励
5. 贝叶斯更新信念

**关键概念**：

- **知识梯度**$v^{KG}$：拉某臂后期望最优值的增量
- **信念模型**：对每个臂奖励分布的当前估计
- **贝叶斯更新**：观察新数据后更新信念
- **信息价值**：KG本质上是在计算"信息价值"

```
臂的信念分布：    臂1: N(0.8, 0.1²)  ← 很确定，接近最优
                  臂2: N(0.5, 0.3²)  ← 不确定，可能更好也可能更差
                  臂3: N(0.6, 0.05²) ← 比较确定

KG计算：面臂2的"知识梯度"最大，因为其不确定性最高，
       拉完后可能改变当前选择臂1的决定

选择：argmax KG值 → 臂2（虽然不是当前最优，但最有学习价值）
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $\bar{\mu}_k^n$ | $n$步后臂$k$的均值估计 |
| $\sigma_k^{2,n}$ | $n$步后臂$k$的方差估计 |
| $v_a^{KG,n}$ | 臂$a$的知识梯度值 |
| $\zeta$ | 标准化信号噪声比 |

### 正态信念模型下的KG

假设每个臂的奖励服从$\mathcal{N}(\mu_k, \beta_k)$，其中$\mu_k$未知，先验为$\mathcal{N}(\bar{\mu}_k^n, \sigma_k^{2,n})$。

**KG值计算**：

$$v_a^{KG,n} = \mathbb{E}\left[\max_k \bar{\mu}_k^{n+1} \mid a^n = a\right] - \max_k \bar{\mu}_k^n$$

对于正态分布，可以推导出：

$$v_a^{KG,n} = h\left(\bar{\mu}^n, \tilde{\sigma}^{n+1}\right)$$

其中$\tilde{\sigma}^{n+1}$是拉臂$a$后该臂后验方差的减少量，$h$是一个与排序和正态CDF相关的函数。

### 单步KG公式

对于独立正态信念，臂$a$的KG值为：

$$v_a^{KG,n} = \sum_{k} \left[\tilde{\sigma}_k^{n+1}(a) \cdot \phi\left(\frac{\bar{\mu}_k^n - \max_{j\neq k}\bar{\mu}_j^n}{\tilde{\sigma}_k^{n+1}(a)}\right) + \left(\bar{\mu}_k^n - \max_{j\neq k}\bar{\mu}_j^n\right) \cdot \Phi\left(\frac{\bar{\mu}_k^n - \max_{j\neq k}\bar{\mu}_j^n}{\tilde{\sigma}_k^{n+1}(a)}\right)\right]$$

其中$\phi$和$\Phi$分别是标准正态的PDF和CDF，$\tilde{\sigma}_k^{n+1}(a)$是拉臂$a$后臂$k$后验标准差的变化量。

对于被拉的臂$a$本身：$\tilde{\sigma}_a^{n+1} = \sqrt{(\sigma_a^n)^2 - (\sigma_a^{n+1})^2}$

### 贝叶斯更新（正态）

拉臂$a$观察奖励$W$后（精度$\beta$已知）：

$$\sigma_a^{2,n+1} = \left(\frac{1}{\sigma_a^{2,n}} + \frac{1}{\beta}\right)^{-1}$$

$$\bar{\mu}_a^{n+1} = \sigma_a^{2,n+1}\left(\frac{\bar{\mu}_a^n}{\sigma_a^{2,n}} + \frac{W}{\beta}\right)$$

### KG vs UCB vs Thompson

- **UCB**：基于置信上界，$\bar{\mu} + c\sqrt{\ln n/N}$
- **Thompson**：从后验采样，选最大
- **KG**：显式计算"学习带来的期望价值提升"

KG的理论优势：在特定条件下，KG是贝叶斯最优的1步前瞻策略。

## 4. 训练过程讲解

### 超参数表

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| 先验均值$\bar{\mu}_k^0$ | 初始估计 | 0 |
| 先验方差$\sigma_k^{2,0}$ | 初始不确定性 | 1（或较大值鼓励探索） |
| 观测精度$\beta$ | 奖励噪声的倒数 | 根据问题设定 |

### 迭代过程
1. 计算每个臂的KG值
2. 选择KG值最大的臂
3. 拉动该臂，获得奖励$W$
4. 贝叶斯更新该臂的信念
5. 重复

## 5. 应用场景

1. **实验设计**：多项治疗方案/营销策略中，KG能高效找到最优方案
2. **A/B测试优化**：比传统UCB更考虑"信息价值"
3. **仿真优化**：选择下一个仿真点使获得的信息最多
4. **药物发现**：选择下一个实验使发现最优药物的概率最大

## 6. 优缺点分析

### 优点
1. **理论最优性**：在1步前瞻贝叶斯框架下最优
2. **显式信息价值**：清楚知道"为什么探索这个选项"
3. **处理相关信念**：可以扩展到臂之间有相关性的场景

### 缺点
1. **计算复杂**：每次选择需要计算所有臂的KG值
2. **需要指定先验**：贝叶斯框架需要合理的先验
3. **1步前瞻局限**：只看1步后的信息价值，不考虑多步

### 算法对比

| 策略 | 计算复杂度 | 信息量最优 | 处理相关性 |
|------|-----------|-----------|-----------|
| ε-greedy | $O(K)$ | 否 | 否 |
| UCB | $O(K)$ | 渐近 | 否 |
| Thompson | $O(K)$ | 渐近 | 可 |
| KG | $O(K^2)$ | 1步最优 | 可 |

## 7. 调库实现

```python
"""
Knowledge Gradient策略实现
正态信念模型
"""
import numpy as np
from scipy.stats import norm

class KnowledgeGradient:
    """Knowledge Gradient策略"""

    def __init__(self, n_arms, prior_mu=0.0, prior_sigma=1.0, obs_var=1.0):
        self.n_arms = n_arms
        self.mu = np.full(n_arms, prior_mu)       # 均值估计
        self.sigma2 = np.full(n_arms, prior_sigma**2)  # 方差估计
        self.obs_var = obs_var  # 观测噪声方差

    def compute_kg(self):
        """计算每个臂的KG值"""
        kg = np.zeros(self.n_arms)
        beta = 1.0 / self.obs_var

        for a in range(self.n_arms):
            # 拉臂a后，臂a的后验方差变化量
            sigma2_new = 1.0 / (1.0/self.sigma2[a] + beta)
            sigma_tilde = np.sqrt(self.sigma2[a] - sigma2_new)

            if sigma_tilde < 1e-10:
                continue

            # KG值：期望后验最大值 - 当前最大值
            current_max = np.max(self.mu)
            for k in range(self.n_arms):
                diff = self.mu[k] - current_max
                z = diff / sigma_tilde if sigma_tilde > 0 else 0
                kg[a] += sigma_tilde * norm.pdf(z) + diff * norm.cdf(z)

        return kg

    def choose_arm(self):
        """选择KG值最大的臂"""
        kg = self.compute_kg()
        return np.argmax(kg)

    def update(self, arm, reward):
        """贝叶斯更新"""
        beta = 1.0 / self.obs_var
        precision_old = 1.0 / self.sigma2[arm]
        precision_new = precision_old + beta
        self.sigma2[arm] = 1.0 / precision_new
        self.mu[arm] = self.sigma2[arm] * (self.mu[arm] * precision_old + reward * beta)

# 测试
if __name__ == "__main__":
    np.random.seed(42)
    K = 5
    true_means = np.array([0.3, 0.5, 0.7, 0.4, 0.6])
    print(f"真实均值: {true_means}")
    print(f"最优臂: {np.argmax(true_means)} (均值={np.max(true_means)})")

    kg = KnowledgeGradient(K, prior_mu=0.5, prior_sigma=0.5, obs_var=0.25)
    counts = np.zeros(K)

    for t in range(200):
        arm = kg.choose_arm()
        reward = np.random.normal(true_means[arm], np.sqrt(0.25))
        kg.update(arm, reward)
        counts[arm] += 1

    print(f"\n最终估计: {kg.mu.round(3)}")
    print(f"选择次数: {counts}")
    print(f"识别最优臂: {np.argmax(kg.mu)}")
```

## 8. 手工代码实现

```python
"""
从零实现KG策略（纯NumPy，不依赖scipy）
"""
import numpy as np

def norm_pdf(x):
    return np.exp(-0.5 * x**2) / np.sqrt(2 * np.pi)

def norm_cdf(x):
    return 0.5 * (1 + np.vectorize(np.math.erf)(x / np.sqrt(2)))

class KGAgent:
    """Knowledge Gradient智能体"""
    def __init__(self, n_arms, prior_mu=0.0, prior_var=1.0, obs_var=1.0):
        self.K = n_arms
        self.mu = np.full(n_arms, prior_mu, dtype=float)
        self.var = np.full(n_arms, prior_var, dtype=float)
        self.obs_var = obs_var

    def kg_value(self, arm):
        """计算拉arm后的KG值"""
        beta = 1.0 / self.obs_var
        new_var = 1.0 / (1.0/self.var[arm] + beta)
        sigma_tilde = np.sqrt(self.var[arm] - new_var)

        if sigma_tilde < 1e-12:
            return 0.0

        current_max = np.max(self.mu)
        kg = 0.0
        for k in range(self.K):
            z = (self.mu[k] - current_max) / sigma_tilde
            kg += sigma_tilde * norm_pdf(z) + (self.mu[k] - current_max) * norm_cdf(z)
        return kg

    def act(self):
        return np.argmax([self.kg_value(a) for a in range(self.K)])

    def update(self, arm, reward):
        beta = 1.0 / self.obs_var
        old_prec = 1.0 / self.var[arm]
        new_prec = old_prec + beta
        self.var[arm] = 1.0 / new_prec
        self.mu[arm] = self.var[arm] * (self.mu[arm] * old_prec + reward * beta)

# 测试
if __name__ == "__main__":
    np.random.seed(42)
    K, n_steps = 5, 300
    true_mu = np.array([0.2, 0.4, 0.8, 0.3, 0.5])
    agent = KGAgent(K, prior_mu=0.5, prior_var=0.3, obs_var=0.2)
    total_reward = 0
    for t in range(n_steps):
        a = agent.act()
        r = np.random.normal(true_mu[a], np.sqrt(0.2))
        agent.update(a, r)
        total_reward += r
    print(f"KG总奖励: {total_reward:.1f}, 最优臂估计: {np.argmax(agent.mu)}")
    print(f"估计均值: {agent.mu.round(3)}")
```

import matplotlib.pyplot as plt

def visualize_kg_beliefs(mu, var, true_mu):
    """可视化KG的信念分布"""
    x = np.linspace(-1, 2, 200)

## 11. 常见问题与易错点

1. **先验方差过大**：导致初期过度探索 → 设为合理值或衰减
2. **观测噪声估计错误**：影响更新精度 → 从数据估计或设保守值
3. **KG计算中忽略排序**：KG公式依赖$\max_{j\neq k}$的正确计算

## 12. 学习总结

KG策略的核心创新是显式计算"信息价值"：$v^{KG} = \mathbb{E}[\text{后验最优}] - \text{当前最优}$。不同于UCB基于置信上界或Thompson基于随机采样，KG直接回答"学什么最有价值"。

**关键公式**：
1. KG值：$v_a^{KG} = \mathbb{E}[\max_k \bar{\mu}_k^{n+1}|a] - \max_k \bar{\mu}_k^n$
2. 贝叶斯更新：$\sigma^{2,n+1} = (1/\sigma^{2,n} + 1/\beta)^{-1}$

## 13. 练习题与思考题

**题目1**：两个臂，信念$\mu_1=0.8,\sigma_1=0.1$和$\mu_2=0.5,\sigma_2=0.5$。KG策略会选择哪个臂？

**参考答案**：臂1当前最优(0.8)。臂2不确定性高(σ=0.5)，拉完后可能发现它更好。KG计算：臂1的KG值较小（已经很确定），臂2的KG值较大（不确定性高，可能改变选择）。所以KG选择臂2。

**题目2（开放）**：KG是1步前瞻策略。如果做2步前瞻（考虑未来两步的最优选择），理论上更好但计算量如何变化？

**参考答案方向**：2步前瞻需要考虑所有$(a^n, a^{n+1})$组合，计算量从$O(K)$增到$O(K^2)$，且需要更复杂的期望计算。多步KG理论上更优但实践中1步KG已足够有效。
