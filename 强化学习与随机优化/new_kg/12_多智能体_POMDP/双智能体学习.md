# 双智能体学习(Two-Agent Learning) 学习文档

> 两个智能体互相学习——一个学习环境，一个学习对手的策略。

> 来源线索：本节内容根据原书中关于"Two-Agent Learning Models"的相关章节(Ch 20.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：双智能体学习模型中，两个智能体同时在与环境交互并互相影响，需要同时学习环境动态和对方行为。

## 2. 核心原理

**模型设定**：
- 智能体A（如"中央指挥部"）和智能体B（如"现场人员"）
- A需要学习B的行为模式
- B需要学习A的指令模式
- 两者都受环境影响

**过渡函数**：
$$S_{t+1} = S^M(S_t, x_t^A, x_t^B, W_{t+1})$$

需要同时描述两个智能体的决策如何影响系统。

**与博弈论的关系**：
- 零和博弈：一方收益=另一方损失
- 合作博弈：共同最大化目标
- 混合动机：部分合作部分竞争

**学习挑战**：
- 非平稳性：对方策略在变化
- 信用分配：哪个智能体的贡献更大
- 探索vs利用：在对方也在学习的设定下

## 3. Python 实现

```python
import numpy as np

class TwoAgentLearning:
    """双智能体学习示例"""
    def __init__(self):
        self.agent_a_policy = {'threshold': 0.5}
        self.agent_b_policy = {'bias': 0.0}

    def agent_a_decide(self, state):
        """A的决策：基于阈值"""
        return 1 if state > self.agent_a_policy['threshold'] else 0

    def agent_b_decide(self, state):
        """B的决策：基于偏好"""
        return 1 if state + self.agent_b_policy['bias'] > 0.5 else 0

    def simulate(self, T=100, lr=0.05):
        for t in range(T):
            state = np.random.rand()
            action_a = self.agent_a_decide(state)
            action_b = self.agent_b_decide(state)

            # 共同奖励
            reward = 1.0 if action_a == action_b else -0.5

            # 简单梯度更新
            self.agent_a_policy['threshold'] += lr * reward * (0.5 - state)
            self.agent_b_policy['bias'] += lr * reward * (0.5 - state)

        print(f"A的阈值: {self.agent_a_policy['threshold']:.3f}")
        print(f"B的偏好: {self.agent_b_policy['bias']:.3f}")

agents = TwoAgentLearning()
agents.simulate()
```
