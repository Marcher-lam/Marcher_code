# 合作智能体(Cooperative Agents) 学习文档

> 来源线索：本节内容根据原书中关于"Cooperative Agents – A Spatially Distributed Blood Management Problem"的相关章节(Ch 20.6)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：合作智能体系统中，多个agent共享共同目标，通过协调各自决策来最大化全局收益。

## 2. 核心原理

**与独立智能体的区别**：
- 独立智能体：各agent只关心自己的局部目标
- 合作智能体：所有agent共享全局目标
- 需要某种形式的协调机制

**血液管理问题**：
- 多个医院/血站各自管理血液库存
- 目标：最小化总浪费（过期）+ 总短缺
- 血液可以在站点间转移
- 每个站点面临随机需求

**协调机制**：
1. **集中控制**：一个中心决策器分配所有资源
2. **分布式协调**：agent之间通信协商
3. **隐式协调**：通过共享值函数或奖励实现

**空间分布**：
- 不同地理位置的agent面临不同需求
- 运输成本影响协调效率
- 可以用空间模型建模

## 3. Python 实现

```python
import numpy as np

class BloodBank:
    """单个血站"""
    def __init__(self, location, capacity=100):
        self.location = location
        self.capacity = capacity
        self.inventory = np.random.randint(20, 60)

    def step(self, supply, demand, transfer_out=0, transfer_in=0):
        self.inventory += supply - demand - transfer_out + transfer_in
        shortage = max(0, demand - self.inventory - supply)
        waste = max(0, self.inventory - self.capacity)
        self.inventory = np.clip(self.inventory, 0, self.capacity)
        return shortage, waste

class CooperativeBloodSystem:
    """合作血液管理系统"""
    def __init__(self, n_banks=4):
        self.banks = [BloodBank(location=i) for i in range(n_banks)]

    def coordinate(self):
        """简单协调策略：从富余站向短缺站转移"""
        inventories = [b.inventory for b in self.banks]
        mean_inv = np.mean(inventories)

        transfers = []
        for i, bank in enumerate(self.banks):
            surplus = bank.inventory - mean_inv
            if surplus > 0:
                transfers.append((i, surplus * 0.3))  # 转移30%富余
            else:
                transfers.append((i, 0))
        return transfers

    def simulate(self, T=50):
        total_shortage = 0
        total_waste = 0
        for t in range(T):
            transfers = self.coordinate()
            for i, bank in enumerate(self.banks):
                supply = np.random.poisson(10)
                demand = np.random.poisson(8)
                t_out = transfers[i][1]
                shortage, waste = bank.step(supply, demand, t_out)
                total_shortage += shortage
                total_waste += waste
        return total_shortage, total_waste

system = CooperativeBloodSystem()
s, w = system.simulate()
print(f"总短缺: {s}, 总浪费: {w}")
for i, b in enumerate(system.banks):
    print(f"血站{i}: 库存={b.inventory}")
```
