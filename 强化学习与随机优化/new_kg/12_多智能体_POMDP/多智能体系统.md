# 多智能体系统(Multi-Agent Systems) 学习文档

> 多个决策者同时行动，需要协调或竞争，是RL的前沿方向。

> 来源线索：本节内容根据原书中关于"Multi-Agent Systems"的相关章节(Ch 20)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：多智能体系统(MAS)中多个agent同时做出决策，每个agent的奖励依赖于所有agent的联合动作，需要在非平稳环境中学习最优策略。

**直觉类比**：想象一场足球赛。每个球员（agent）根据自己的位置（状态）选择传球、射门或跑位（动作）。但一次进攻的成功不仅取决于你的选择，还取决于队友和对手的行动（联合动作）。你需要学习与其他球员协作（合作型）或击败对手（竞争型）。

**历史背景**：多智能体强化学习(MARL)的研究起源于博弈论（Nash均衡, 1950）和分布式人工智能。2000年代Busoniu等人系统化了MARL方法，2018年后QMIX、MAPPO等深度MARL算法推动了实用化。原书(Ch 20)从统一框架角度将多智能体建模为POMDP变体。

**算法定位**：多智能体强化学习/分布式决策。是单agent RL向多agent的推广。

**前置知识**：Q-Learning、博弈论基础、POMDP、策略梯度。

## 2. 核心原理

**核心思想**：每个agent独立学习时，面对的是非平稳环境——因为其他agent的策略也在变化。这违反了单agent RL的马尔可夫假设。核心挑战是如何在"别人也在学习"的环境中有效学习。

**MAS五要素**：

1. **agent集合**$\{1, 2, \ldots, N\}$：决策者数量
2. **联合状态**$S_t = (S_t^1, \ldots, S_t^N)$：所有agent的状态组合
3. **联合动作**$\mathbf{a}_t = (a_t^1, \ldots, a_t^N)$：所有agent的动作组合
4. **转移函数**$P(S_{t+1}|S_t, \mathbf{a}_t)$：联合动作驱动状态转移
5. **个体奖励**$r_t^i = R^i(S_t, \mathbf{a}_t, W_{t+1})$：每个agent获得的奖励

**三种交互模式**：
- **合作型**：所有agent共享相同目标$r^i = r^{team}$，最大化团队收益
- **竞争型**：零和博弈$\sum_i r^i = 0$，一方的收益等于他方的损失
- **混合型**：部分合作部分竞争（如市场中的企业）

**工作流程**：

1. 每个agent $i$ 观察自己的局部状态$S_t^i$
2. 每个agent独立选择动作$a_t^i = \pi^i(S_t^i)$
3. 环境执行联合动作$\mathbf{a}_t$，产生新状态$S_{t+1}$
4. 每个agent获得个体奖励$r_t^i$
5. 各agent更新策略，重复

**关键概念**：

- **非平稳性(Non-stationarity)**：agent $i$面对的转移函数因其他agent策略变化而改变
- **信用分配(Credit Assignment)**：如何将团队奖励$r^{team}$归因到个体贡献
- **CTDE(中心化训练去中心化执行)**：训练时用全局信息，执行时只用局部信息

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $N$ | agent数量 |
| $S^i$ | agent $i$的局部状态空间 |
| $a^i$ | agent $i$的动作 |
| $\mathbf{a}$ | 联合动作$(a^1, \ldots, a^N)$ |
| $r^i$ | agent $i$的奖励 |
| $\pi^i$ | agent $i$的策略 |
| $Q^i(s, a^i)$ | agent $i$的Q函数 |

### 独立Q学习的更新

每个agent忽略其他agent，独立执行Q-learning：

$$Q^i(s^i, a^i) \leftarrow Q^i(s^i, a^i) + \alpha[r^i + \gamma \max_{a'} Q^i(s'^i, a') - Q^i(s^i, a^i)]$$

### 合作型团队的联合Q函数

最优联合策略使团队总奖励最大：

$$\max_{\pi^1, \ldots, \pi^N} \mathbb{E}\left[\sum_{t=0}^T \gamma^t \sum_{i=1}^N r_t^i\right]$$

### 信用分配：反事实基线

QMIX使用混合网络$Q_{tot} = f(Q^1, \ldots, Q^N, s)$，保证单调性$\frac{\partial Q_{tot}}{\partial Q^i} \geq 0$。反事实基线：

$$A^i(s, \mathbf{a}) = Q_{tot}(s, \mathbf{a}) - Q_{tot}(s, (a^{-i}, \bar{a}^i))$$

其中$\bar{a}^i$是agent $i$的默认动作，衡量"agent $i$的贡献超出默认多少"。

### 纳什均衡

在竞争型设定中，纳什均衡$\pi^*$满足：

$$V^i(\pi^{*,i}, \pi^{*,-i}) \geq V^i(\pi^i, \pi^{*,-i}), \quad \forall \pi^i$$

即没有任何agent能通过单方面偏离获得更高收益。

## 4. 训练过程讲解

### 参数初始化

- **独立Q学习**：每个agent初始化$Q^i = 0$
- **CTDE方法**：每个agent有本地Q网络 + 中央混合网络
- **策略梯度方法**：每个agent有策略网络$\pi_\theta^i$

### 迭代过程（独立Q学习）

1. 初始化$N$个Q表
2. 每回合：各agent同时选择动作（$\epsilon$-greedy）
3. 环境返回个体奖励和下一状态
4. 各agent独立更新Q表
5. 重复直到收敛（或最大回合数）

### 收敛条件

- 独立Q学习：通常**不保证收敛**（非平稳环境）
- CTDE方法：中心化训练可收敛，但执行策略质量依赖泛化
- 策略梯度方法：收敛到局部纳什均衡（不一定全局最优）

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $N$ | agent数量 | 2-10 | 3 |
| $\alpha$ | 学习率 | [0.001, 0.1] | 0.01 |
| $\gamma$ | 折扣因子 | [0.9, 0.99] | 0.95 |
| $\epsilon$ | 探索率 | [0.01, 0.3] | 0.1 |

## 5. 应用场景

1. **多机器人协调**：仓库中多机器人路径规划和任务分配。为什么适合：每个机器人只知道局部环境，需要协调避免碰撞和冲突。
2. **自动驾驶车队**：多辆车在路口协调通行。为什么适合：每辆车独立决策但安全依赖于其他车辆行为。
3. **金融市场**：多个交易agent模拟市场动态。为什么适合：每个agent的策略影响价格（非平稳环境）。
4. **电网调度**：多个分布式能源协调出力。为什么适合：每个能源节点独立控制但系统稳定性是共同目标。

### 不适用场景
- agent数量极大（>100）时独立Q学习维度爆炸
- 需要严格实时决策的场景（CTDE训练开销大）

## 6. 优缺点分析

### 优点
1. **分布式决策**：每个agent只需局部信息，不依赖中央控制器（成立条件：局部信息足够）
2. **可扩展性**：独立学习可并行训练多个agent
3. **鲁棒性**：单个agent失效不影响整体系统（合作型）

### 缺点
1. **非平稳性**：每个agent面对的环境因其他agent变化而非平稳（当N>2时尤为严重）
2. **信用分配难**：团队奖励难以归因到个体贡献（合作型核心问题）
3. **维度爆炸**：联合状态-动作空间$|\mathcal{S}|^N \times |\mathcal{A}|^N$指数增长
4. **多均衡问题**：可能存在多个纳什均衡，收敛到哪个不确定

### 算法对比

| 特性 | 独立Q学习 | CTDE (QMIX) | 通信MARL |
|------|----------|------------|----------|
| 信息需求 | 局部 | 训练时全局 | 显式通信 |
| 收敛保证 | 无 | 有（训练阶段） | 弱 |
| 可扩展性 | 好 | 中 | 差 |
| 执行开销 | 低 | 低 | 中 |

## 7. 调库实现

```python
"""多智能体独立Q学习：合作型匹配任务"""
import numpy as np

class IndependentQLearner:
    """独立Q学习agent"""
    def __init__(self, n_states, n_actions, lr=0.1, gamma=0.95, epsilon=0.1):
        self.Q = np.zeros((n_states, n_actions))
        self.lr, self.gamma, self.epsilon = lr, gamma, epsilon
        self.nA = n_actions

    def select(self, s):
        if np.random.random() < self.epsilon:
            return np.random.randint(self.nA)
        return np.argmax(self.Q[s])

    def update(self, s, a, r, s_next):
        td = r + self.gamma * self.Q[s_next].max() - self.Q[s, a]
        self.Q[s, a] += self.lr * td

def run_multi_agent(n_agents=3, n_states=10, n_actions=3, n_episodes=1000):
    """运行多agent协作任务"""
    np.random.seed(42)
    agents = [IndependentQLearner(n_states, n_actions) for _ in range(n_agents)]
    target = n_actions  # 联合动作的目标和
    rewards_history = []

    for ep in range(n_episodes):
        states = [np.random.randint(n_states) for _ in range(n_agents)]
        actions = [ag.select(s) for ag, s in zip(agents, states)]

        # 合作型奖励：联合动作和接近目标值
        team_reward = -abs(sum(actions) - target) + 2.0
        rewards_history.append(team_reward)

        for i, ag in enumerate(agents):
            s_next = np.random.randint(n_states)
            ag.update(states[i], actions[i], team_reward, s_next)

    # 输出结果
    print(f"多智能体训练完成 ({n_agents}个agent, {n_episodes}回合):")
    print(f"  前100回合平均奖励: {np.mean(rewards_history[:100]):.2f}")
    print(f"  后100回合平均奖励: {np.mean(rewards_history[-100:]):.2f}")
    for i, ag in enumerate(agents):
        print(f"  Agent {i} Q表均值: {ag.Q.mean():.3f}, 最优动作分布: {np.argmax(ag.Q, axis=1)}")
    return agents, rewards_history

if __name__ == "__main__":
    agents, rewards = run_multi_agent()
```

## 8. 手工代码实现

```python
"""从零实现CTDE架构（中心化训练去中心化执行）"""
import numpy as np

class CTDEAgent:
    """CTDE：中心化训练去中心化执行"""
    def __init__(self, n_agents, n_states, n_actions, lr=0.01, gamma=0.95):
        self.N = n_agents
        self.ns, self.na = n_states, n_actions
        self.gamma = gamma
        self.lr = lr
        # 每个agent的本地Q表
        self.local_Q = [np.zeros((n_states, n_actions)) for _ in range(n_agents)]
        # 中央混合网络权重（简化线性混合）
        self.mix_weights = np.ones(n_agents) / n_agents

    def select_actions(self, states, epsilon=0.1):
        """去中心化执行：每个agent只看自己的状态"""
        actions = []
        for i in range(self.N):
            if np.random.random() < epsilon:
                actions.append(np.random.randint(self.na))
            else:
                actions.append(np.argmax(self.local_Q[i][states[i]]))
        return actions

    def compute_team_q(self, states, actions):
        """中心化混合：用局部Q值计算团队Q"""
        local_qs = [self.local_Q[i][states[i]][actions[i]] for i in range(self.N)]
        return sum(w * q for w, q in zip(self.mix_weights, local_qs))

    def update(self, states, actions, team_reward, next_states):
        """中心化训练更新"""
        # 计算目标团队Q值
        next_actions = [np.argmax(self.local_Q[i][next_states[i]])
                        for i in range(self.N)]
        target_team_q = team_reward + self.gamma * self.compute_team_q(next_states, next_actions)
        current_team_q = self.compute_team_q(states, actions)
        td_error = target_team_q - current_team_q

        # 更新每个agent的本地Q（按混合权重分配信用）
        for i in range(self.N):
            local_td = td_error * self.mix_weights[i]
            self.local_Q[i][states[i]][actions[i]] += self.lr * local_td

if __name__ == "__main__":
    np.random.seed(42)
    n_agents, ns, na = 3, 10, 3
    ctde = CTDEAgent(n_agents, ns, na, lr=0.05)
    target = 4

    for ep in range(2000):
        states = [np.random.randint(ns) for _ in range(n_agents)]
        eps = max(0.01, 0.3 * (1 - ep / 2000))  # 衰减探索
        actions = ctde.select_actions(states, epsilon=eps)
        team_reward = -abs(sum(actions) - target) + 2.0
        next_states = [np.random.randint(ns) for _ in range(n_agents)]
        ctde.update(states, actions, team_reward, next_states)

    # 验证
    print("CTDE训练完成:")
    test_states = [1, 3, 5]
    test_actions = ctde.select_actions(test_states, epsilon=0.0)
    print(f"  测试状态={test_states} → 联合动作={test_actions}, 动作和={sum(test_actions)}")
    print(f"  目标和={target}, 偏差={abs(sum(test_actions)-target)}")
```

"""多智能体训练过程可视化"""
import matplotlib.pyplot as plt
import numpy as np

def visualize_marl_training(rewards_history, window=50):
    """绘制训练奖励曲线"""

    axes[0].set_ylabel('团队奖励')

## 10. 模型评估

```python
"""多智能体策略评估"""
import numpy as np

def evaluate_marl(agents, env_fn, n_episodes=200, max_steps=50):
    """
    评估多agent策略
    指标：平均团队奖励、协调成功率、策略一致性
    """
    team_rewards = []
    coordination_success = 0

    for ep in range(n_episodes):
        states = [np.random.randint(10) for _ in range(len(agents))]
        ep_reward = 0
        for t in range(max_steps):
            actions = [ag.select(s) for ag, s in zip(agents, states)]
            team_reward = -abs(sum(actions) - 4) + 2.0
            ep_reward += team_reward
            states = [np.random.randint(10) for _ in range(len(agents))]

        team_rewards.append(ep_reward)
        if ep_reward / max_steps > 1.5:  # 协调成功阈值
            coordination_success += 1

    mean_r = np.mean(team_rewards)
    std_r = np.std(team_rewards)
    coord_rate = coordination_success / n_episodes

    print(f"多智能体策略评估 ({n_episodes}回合):")
    print(f"  平均回合奖励: {mean_r:.2f} ± {std_r:.2f}")
    print(f"  协调成功率: {coord_rate:.2%}")
    print(f"  最优可能奖励: {2.0 * max_steps:.0f}")
    print(f"  效率比: {mean_r / (2.0 * max_steps):.2%}")
```

**评估指标说明**：
- **平均回合奖励**：团队协作的直接度量，越高越好
- **协调成功率**：回合平均奖励超过阈值的比例，衡量稳定性
- **效率比**：实际奖励与理论最优的比值

## 11. 常见问题与易错点

### 数据层面

1. **奖励设计不当**
   - 现象：agent学会了次优协调策略（如全部选动作0）
   - 原因：团队奖励没有充分惩罚不良协调
   - 解决方案：设计更精细的奖励，加入个体贡献惩罚/奖励

2. **经验回放不兼容**
   - 现象：使用经验回放后性能下降
   - 原因：旧经验中其他agent的策略与当前不同（策略非平稳）
   - 解决方案：使用多agent经验回放（记录所有agent的联合动作），或限制回放缓冲区大小

### 模型层面

3. **独立Q学习不收敛**
   - 现象：训练曲线持续振荡，不收敛
   - 原因：非平稳环境——每个agent面对的MDP因其他agent策略变化而改变
   - 解决方案：使用CTDE架构、或添加通信机制、或使用策略梯度方法（更稳定）

4. **信用分配偏差**
   - 现象：贡献大的agent和搭便车的agent获得相同更新
   - 原因：直接用团队奖励更新所有agent
   - 解决方案：使用反事实基线（COMA）、或QMIX的混合网络

### 调参层面

5. **探索率衰减过快**
   - 现象：agent过早锁定次优策略
   - 原因：多agent需要更多探索才能发现好的协调策略
   - 解决方案：使用更慢的$\epsilon$衰减，或增加初始探索回合数

## 12. 学习总结

多智能体系统中$N$个agent联合决策，奖励$R^i(S, \mathbf{a})$依赖于所有agent的动作。核心挑战是非平稳性（其他agent也在学习）和信用分配（如何将团队奖励归因到个体）。

**关键公式**：
1. 独立Q更新：$Q^i(s, a) \leftarrow Q^i(s, a) + \alpha[r^i + \gamma\max_{a'}Q^i(s', a') - Q^i(s, a)]$
2. 团队目标：$\max_{\pi^1,\ldots,\pi^N}\mathbb{E}[\sum_t\gamma^t\sum_i r_t^i]$
3. 信用分配：$A^i = Q_{tot}(\mathbf{a}) - Q_{tot}(a^{-i}, \bar{a}^i)$

MAS与单agent RL的区别在于环境非平稳性，与博弈论的联系在于纳什均衡概念，与POMDP的联系在于每个agent只能看到局部信息。

## 13. 练习题与思考题

### 基础题

**题目1**：为什么独立Q学习在多智能体环境中通常不保证收敛？

**参考答案**：
Q学习的收敛性要求环境（转移函数和奖励函数）是平稳的。但在多agent环境中，agent $i$面对的"环境"包含其他agent的策略。当其他agent的策略随训练变化时，转移函数$P(s'|s,a^i)$也在变化（因为$s'$还依赖于其他agent的动作$a^{-i}$）。这违反了马尔可夫假设，导致Q学习的收敛性理论不再适用。

**题目2**：在合作型多agent系统中，什么是信用分配问题？举例说明。

**参考答案**：
信用分配问题：当团队获得一个共享奖励时，如何将这个奖励归因到每个agent的个体贡献。例如，3个robot协作搬运物体成功获得+10奖励。如果robot A做了大部分工作而robot C几乎没贡献，直接给三者都更新+10会误导robot C认为自己的"偷懒"策略也是好的。解决方案包括：反事实基线（假设没有agent $i$时代替默认动作，看奖励变化多少）、差异化奖励（根据个体贡献给不同奖励）。

### 进阶题

**题目3**：CTDE（中心化训练去中心化执行）如何缓解多agent学习的非平稳性问题？

**参考答案**：
CTDE在训练阶段使用全局信息（所有agent的状态和动作），由中央混合网络计算团队Q值$Q_{tot}$，然后通过混合网络的结构约束（如QMIX的单调性）将全局信号分解为个体梯度。这样，每个agent的本地Q更新考虑了其他agent的影响，等效于在一个"稳定化的"联合MDP上训练。执行阶段，每个agent只需自己的局部Q表/网络做决策，无需通信。

### 开放思考题

**题目4**：原书(Ch 20)讨论了多智能体的"控制架构"——集中式、分布式和分层式。请思考：在什么场景下分布式架构优于集中式？什么场景下集中式更好？

**参考答案方向**：
- 分布式更好的场景：(1) 通信受限（如无人机集群通信带宽有限）；(2) agent数量大（集中式计算量指数增长）；(3) 需要鲁棒性（单点故障不影响整体）
- 集中式更好的场景：(1) 安全关键（自动驾驶需要全局协调）；(2) agent数量少且通信良好；(3) 需要全局最优保证
- 分层式是折中：高层中央控制器做战略决策，低层agent自主执行战术动作
