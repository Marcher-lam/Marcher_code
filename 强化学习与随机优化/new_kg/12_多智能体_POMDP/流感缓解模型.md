# 流感缓解模型(Flu Mitigation Model) 学习文档

> 序贯决策在公共卫生中的典型应用——SIR模型+资源分配+多种模型变体。

> 来源线索：本节内容根据原书中关于"A Learning Problem – Flu Mitigation"的相关章节(Ch 20.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：流感缓解模型将传染病控制建模为序贯决策问题——每期决定如何分配有限资源（疫苗、隔离措施）以最小化感染人数。

## 2. 核心原理

**SIR模型**：
$$\frac{dS}{dt} = -\beta S I, \quad \frac{dI}{dt} = \beta S I - \gamma I, \quad \frac{dR}{dt} = \gamma I$$

**作为序贯决策问题**：
- **状态** $S_t$：$(S_t, I_t, R_t, \text{资源})$
- **决策** $x_t$：疫苗分配、隔离区域选择
- **外生信息**：新感染、传播率变化
- **目标**：最小化总感染人数

**六种模型变体**：
1. 静态模型：参数固定
2. 时变模型：参数随时间变化
3. 有漂移模型：参数有趋势
4. 可控真值模型：干预可改变传播率
5. 资源约束模型：有限疫苗/预算
6. 空间模型：多区域传播

**策略设计**：
- PFA：固定分配规则
- CFA：参数化优化模型
- VFA：学习各状态的价值
- DLA：前瞻规划（疫情模拟）

## 3. Python 实现

```python
import numpy as np

class FluMitigation:
    """简单流感缓解模型"""
    def __init__(self, population=10000, beta=0.3, gamma=0.1):
        self.N = population
        self.beta = beta
        self.gamma = gamma
        self.S = population * 0.99
        self.I = population * 0.01
        self.R = 0

    def step(self, vaccination_rate=0.0):
        """一步模拟"""
        # 接种减少易感者
        vaccinated = self.S * vaccination_rate
        self.S -= vaccinated
        self.R += vaccinated

        # SIR传播
        new_infected = self.beta * self.S * self.I / self.N
        new_recovered = self.gamma * self.I

        self.S -= new_infected
        self.I += new_infected - new_recovered
        self.R += new_recovered

        return new_infected

    def simulate_policy(self, T=100, daily_vax_rate=0.01):
        """模拟策略效果"""
        total_infected = 0
        peak_infected = 0
        for t in range(T):
            new_inf = self.step(vaccination_rate=daily_vax_rate)
            total_infected += new_inf
            peak_infected = max(peak_infected, self.I)
        return total_infected, peak_infected

# 对比不同策略
for vax_rate in [0.0, 0.005, 0.01, 0.02]:
    flu = FluMitigation()

    print(f"接种率{vax_rate:.3f}: 总感染{total:.0f}, 峰值感染{peak:.0f}")
```
