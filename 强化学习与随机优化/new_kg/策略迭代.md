# 策略迭代(Policy Iteration) 学习文档

> 策略迭代交替执行策略评估和策略改进，通常比值迭代更快收敛到最优策略。

> 来源线索：本节内容根据原书中关于"Policy Iteration for Infinite Horizon Problems"的相关章节(Ch 14.7)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：策略迭代通过交替计算当前策略的精确值函数（策略评估）和基于值函数改进策略（策略改进），直到策略不再变化。

**直觉类比**：你有一套行车路线（策略）。第一步，精确计算按这套路线到每个目的地的期望时间（策略评估）。第二步，在每个路口看看有没有更快的转弯选择（策略改进）。如果任何路口的转弯变了，说明策略还能改进，重复上述过程。直到所有路口的最优选择都不变了，就找到了全局最优路线。

**历史背景**：策略迭代由Ronald Howard在1960年提出，是动态规划中与值迭代并列的两大经典算法。策略迭代的优势在于通常在很少的迭代次数内收敛（实践中往往不到$|\mathcal{S}|$次）。

**算法定位**：动态规划/精确求解方法。

**前置知识**：MDP、Bellman方程、值迭代、线性方程组求解。

## 2. 核心原理

**核心思想**：策略迭代分两步：(1)给定策略$\pi$，精确计算其值函数$V^\pi$（策略评估，解线性方程组）；(2)用$V^\pi$贪心地改进策略（策略改进）。策略改进定理保证：每步改进后策略不会变差。当策略稳定不变时，它就是最优策略。

**工作流程**：

1. 初始化任意策略$\pi^{(0)}$
2. **策略评估**：求解$V^\pi(s) = r(s,\pi(s)) + \gamma\sum_{s'}P(s'|s,\pi(s))V^\pi(s')$，这是关于$V$的线性方程组
3. **策略改进**：$\pi'(s) = \arg\max_a(r(s,a) + \gamma\sum_{s'}P(s'|s,a)V^\pi(s'))$
4. 若$\pi' = \pi$，停止；否则$\pi \leftarrow \pi'$，回到步骤2

```
策略π → 策略评估(解方程组) → V^π → 策略改进(argmax) → π'
  ↑                                                        │
  └──────────── 若π'≠π，重复 ────────────────────────────┘
                          若π'=π，π就是最优策略
```

## 3. 数学公式与推导

### 策略评估

给定策略$\pi$，值函数$V^\pi$满足线性方程组：

$$V^\pi(s) = r(s,\pi(s)) + \gamma \sum_{s'} P(s'|s,\pi(s)) V^\pi(s')$$

矩阵形式：$(I - \gamma P^\pi)V^\pi = r^\pi$

求解：$V^\pi = (I - \gamma P^\pi)^{-1} r^\pi$

### 策略改进

$$\pi'(s) = \arg\max_a \left[r(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s')\right]$$

### 策略改进定理

**定理**：$V^{\pi'}(s) \geq V^\pi(s)$对所有$s$成立。如果$\pi' \neq \pi$，则至少一个状态严格不等。

这保证了策略迭代单调改进，且有限状态空间下必在有限步内终止。

### 收敛性

有限状态MDP中，策略迭代至多$|\mathcal{S}| \times (|\mathcal{A}|-1)$步收敛（因为策略数量有限且每步严格改进）。

## 4. 训练过程讲解

### 超参数表

| 参数 | 含义 | 默认值 |
|------|------|--------|
| $\gamma$ | 折扣因子 | 0.95 |
| max_iter | 最大迭代 | 100 |

### 收敛条件
策略不再变化：$\pi^{(k+1)} = \pi^{(k)}$

## 5-6. 应用场景与优缺点

### 优点
1. **收敛快**：实践中通常$O(|\mathcal{S}|)$步内收敛
2. **精确**：每步策略评估是精确的

### 缺点
1. **每轮代价高**：策略评估需要解$O(|\mathcal{S}|^3)$线性方程组
2. **维度灾难**：大状态空间不可行

### 对比

| 特性 | 值迭代 | 策略迭代 |
|------|--------|---------|
| 每轮复杂度 | $O(S^2A)$ | $O(S^3+S^2A)$ |
| 收敛轮数 | 多 | 少 |
| 总复杂度 | 视$\gamma$ | 通常更低 |

## 7. 调库实现

```python
"""策略迭代求解MDP"""
import numpy as np

def policy_iteration(P, R, gamma=0.95, max_iter=100):
    n_states, n_actions = P.shape[0], P.shape[1]
    policy = np.zeros(n_states, dtype=int)

    for iteration in range(max_iter):
        # 策略评估：解 (I - γP^π)V = r^π
        P_pi = P[np.arange(n_states), policy, :]
        R_pi = R[np.arange(n_states), policy]
        A = np.eye(n_states) - gamma * P_pi
        V = np.linalg.solve(A, R_pi)

        # 策略改进
        Q = R + gamma * np.einsum('ijk,k->ij', P, V)
        new_policy = np.argmax(Q, axis=1)

        if np.array_equal(new_policy, policy):
            print(f"策略迭代在第{iteration+1}轮收敛")
            return V, new_policy
        policy = new_policy

    return V, policy

# 测试
n, na = 16, 4
P = np.zeros((n, na, n)); R = np.full((n, na), -0.01); R[15,:] = 1.0
for s in range(n):
    r, c = s//4, s%4
    for a in range(na):
        if a==0: nr,nc=max(r-1,0),c
        elif a==1: nr,nc=r,min(c+1,3)
        elif a==2: nr,nc=min(r+1,3),c
        else: nr,nc=r,max(c-1,0)
        P[s,a,nr*4+nc] = 1.0

V, pi = policy_iteration(P, R, gamma=0.95)
print(f"最优值函数:\n{V.reshape(4,4).round(3)}")
print(f"最优策略:\n{pi.reshape(4,4)}")
```

## 8. 手工代码实现

```python
"""从零实现策略迭代"""
import numpy as np

class PolicyIteration:
    def __init__(self, P, R, gamma=0.95):
        self.P, self.R, self.gamma = P, R, gamma
        self.ns, self.na = P.shape[0], P.shape[1]

    def solve(self, max_iter=100):
        policy = np.zeros(self.ns, dtype=int)
        for i in range(max_iter):
            V = self._evaluate(policy)
            Q = self.R + self.gamma * np.einsum('ijk,k->ij', self.P, V)
            new_policy = np.argmax(Q, axis=1)
            if np.array_equal(new_policy, policy):
                print(f"策略迭代收敛于第{i+1}轮")
                return V, new_policy
            policy = new_policy
        return V, policy

    def _evaluate(self, policy):
        P_pi = self.P[np.arange(self.ns), policy, :]
        R_pi = self.R[np.arange(self.ns), policy]
        return np.linalg.solve(np.eye(self.ns) - self.gamma * P_pi, R_pi)

if __name__ == "__main__":
    np.random.seed(42)
    n, na = 16, 4
    P = np.zeros((n, na, n)); R = np.full((n, na), -0.01); R[15,:] = 1.0
    for s in range(n):
        r, c = s//4, s%4
        for a in range(na):
            if a==0: nr,nc=max(r-1,0),c
            elif a==1: nr,nc=r,min(c+1,3)
            elif a==2: nr,nc=min(r+1,3),c
            else: nr,nc=r,max(c-1,0)
            P[s,a,nr*4+nc] = 1.0

    pi_solver = PolicyIteration(P, R, gamma=0.95)
    V, policy = pi_solver.solve()
    print(f"最优策略:\n{policy.reshape(4,4)}")
```

### 9. 可视化

### 10. 评估
策略迭代给出的策略是精确最优的（给定模型），通过仿真验证。

### 11. 常见问题
1. **线性方程组求解代价高**：状态空间大时用迭代法（如Jacobi）替代直接求解
2. **混合值-策略迭代**：策略评估不需要完全收敛，几步就足够

### 12. 学习总结
策略迭代通过"评估-改进"循环，利用策略改进定理保证单调提升。公式：$V^\pi = (I-\gamma P^\pi)^{-1}r^\pi$（评估），$\pi' = \arg\max_a Q^\pi$（改进）。

### 13. 练习题
**Q1**：在3状态MDP中，策略迭代最多需要几步收敛？
**A1**：最多$3 \times (|\mathcal{A}|-1)$步（每个状态最多改进$|\mathcal{A}|-1$次），但实际通常远少于这个上界。
