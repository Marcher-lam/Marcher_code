## 1. 算法基础认知

**一句话定义**：随机规划在数学规划框架中直接处理随机参数，通过优化期望目标或概率约束来做出鲁棒决策。

**直觉类比**：规划旅行路线。确定性规划假设天气确定，选出最短路线。随机规划考虑天气可能变化，选一个在各种天气下期望表现最好的路线。

**历史背景**：随机规划由Dantzig (1955)和Beale (1955)创立。两阶段随机规划(Benders分解)是经典方法。原书Ch 2.1.8中分类为CFA（成本函数近似）策略的一种。

**算法定位**：随机优化/数学规划。与鲁棒优化和机会约束规划并列。

**前置知识**：线性规划、概率论、期望值。

## 2. 核心原理

**核心思想**：将随机参数$\omega$的分布纳入优化模型。常见形式：

1. **期望值模型**：$\min_x \mathbb{E}_\omega[f(x, \omega)]$
2. **两阶段模型**：第一阶段决策$x$，观测$\omega$后做第二阶段决策$y(x,\omega)$
3. **机会约束**：$\mathbb{P}[g(x,\omega) \leq 0] \geq 1-\alpha$

**工作流程（两阶段）**：
1. 第一阶段：做决策$x$（在观测$\omega$之前）
2. 观测随机参数$\omega$
3. 第二阶段：做补偿决策$y(x,\omega)$
4. 目标：$\min_x \{c^Tx + \mathbb{E}_\omega[Q(x,\omega)]\}$

## 3. 数学公式与推导

### 两阶段随机线性规划

$$\min_x c^Tx + \mathbb{E}_\omega[\min_y q(\omega)^Ty]$$
$$\text{s.t. } Ax = b, \quad T(\omega)x + W(\omega)y = h(\omega), \quad y \geq 0$$

用蒙特卡洛采样近似期望：

$$\mathbb{E}_\omega[Q(x,\omega)] \approx \frac{1}{N}\sum_{n=1}^N Q(x,\omega^n)$$

### 样本平均近似(SAA)

$$\min_x \frac{1}{N}\sum_{n=1}^N f(x, \omega^n)$$

当$N \to \infty$时SAA解收敛到真实最优解。

## 4-8. 核心实现

```python
"""两阶段随机规划：报童问题的LP形式"""
import numpy as np
from scipy.optimize import linprog

def two_stage_newsvendor(price, cost, salvage, demands):
    """两阶段随机规划求解报童问题"""
    n_scenarios = len(demands)
    prob = 1.0 / n_scenarios

    # 决策变量：[x, y_1,...,y_S, z_1,...,z_S]
    # x=订货量, y_s=销售量, z_s=剩余量
    n_var = 1 + 2 * n_scenarios
    c = np.zeros(n_var)
    c[0] = cost  # 订货成本
    for s in range(n_scenarios):
        c[1 + s] = -price * prob  # 销售收入（负=最大化）
        c[1 + n_scenarios + s] = -salvage * prob  # 残值

    # 约束：y_s + z_s = x, y_s <= d_s
    A_eq, b_eq, A_ub, b_ub = [], [], [], []
    for s in range(n_scenarios):
        row = np.zeros(n_var)
        row[0] = -1; row[1+s] = 1; row[1+n_scenarios+s] = 1
        A_eq.append(row); b_eq.append(0)

        row2 = np.zeros(n_var)
        row2[1+s] = 1
        A_ub.append(row2); b_ub.append(demands[s])

    bounds = [(0, None)] * n_var
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, bounds=bounds)
    return result.x[0], -result.fun

if __name__ == "__main__":
    np.random.seed(42)
    demands = np.random.poisson(100, 50)
    x_opt, profit = two_stage_newsvendor(10, 6, 2, demands)
    print(f"最优订货量: {x_opt:.1f}")
    print(f"期望利润: {profit:.1f}")
```

## 9-14. 简要

### 12. 学习总结
随机规划：$\min_x c^Tx + \mathbb{E}_\omega Q(x,\omega)$。SAA方法用蒙特卡洛近似期望，是处理大规模随机问题的实用工具。

### 13. 练习题
**Q1**：SAA方法中，样本数N如何影响解的质量？
**A1**：解的误差$O(1/\sqrt{N})$（CLT）。但每次求解的计算量正比于$N$。需要在精度和效率间权衡。
