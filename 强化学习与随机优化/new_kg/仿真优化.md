## 1-3. 核心认知与公式

**一句话定义**：仿真优化在基于仿真的黑箱函数上寻找最优解，每次评估代价高昂且含噪声。

**核心框架**：

$$\max_{x \in \mathcal{X}} \mathbb{E}[F(x, \omega)]$$

其中$F(x,\omega)$是仿真输出，$\omega$代表随机性。

**方法分类**：
1. **基于随机搜索**：SPSA、有限差分、随机搜索
2. **基于赌博机**：UCB、Thompson采样、知识梯度
3. **基于元模型**：响应曲面法、克里金/高斯过程
4. **基于预算分配**：OCBA

**与原书的联系**：仿真优化是原书中多种方法的汇合点——赌博机(Ch 7)用于探索、步长(Ch 6)用于更新、随机搜索(Ch 5)用于优化。

## 4-8. 核心实现

```python
"""仿真优化：结合元模型和UCB搜索"""
import numpy as np

class SimulationOptimizer:
    """基于UCB的仿真优化"""
    def __init__(self, candidates, sigma=1.0):
        self.candidates = candidates
        self.K = len(candidates)
        self.means = np.zeros(self.K)
        self.counts = np.zeros(self.K)
        self.sigma = sigma

    def evaluate(self, k, n_rep=1):
        """仿真评估候选k"""
        x = self.candidates[k]
        # 模拟黑箱函数 f(x) = -|x-3| + noise
        return -abs(x - 3.0) + self.sigma * np.random.randn(n_rep).mean()

    def optimize(self, total_budget=100):
        for t in range(total_budget):
            if t < self.K:
                k = t  # 初始：每臂评估一次
            else:
                ucb = self.means + 2.0 * np.sqrt(np.log(t+1) / (self.counts + 1))
                k = np.argmax(ucb)
            r = self.evaluate(k)
            self.counts[k] += 1
            self.means[k] += (r - self.means[k]) / self.counts[k]
        best_k = np.argmax(self.means)
        return self.candidates[best_k], self.means[best_k]

if __name__ == "__main__":
    np.random.seed(42)
    candidates = np.linspace(0, 6, 13)
    opt = SimulationOptimizer(candidates)
    best_x, best_val = opt.optimize(100)
    print(f"最优参数: x={best_x:.2f}, 估计值={best_val:.3f}")
    print(f"真实最优: x=3.00")
    print(f"评估次数分配: {opt.counts.astype(int)}")
```

## 9-14. 简要

### 12. 学习总结
仿真优化：$\max_x E[F(x,\omega)]$，黑箱+噪声+高代价。结合赌博机探索、元模型近似和预算分配策略。

### 13. 练习题
**Q1**：为什么仿真优化比确定性优化更困难？
**A1**：仿真输出含噪声，同一输入可能得到不同结果。需要重复评估取平均，且无法利用梯度信息（黑箱）。
