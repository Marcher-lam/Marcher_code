# 报童问题(Newsvendor Problem) 学习文档

> 在需求不确定下确定最优订货量，是随机优化的入门经典问题。

> 来源线索：本节内容根据原书中关于"The Newsvendor Problems"的相关章节(Ch 2.3.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：报童问题在需求随机的情况下，决定最优订货量以最大化期望利润——订多了亏损成本，订少了损失收入。

**直觉类比**：你是一个报童，每天早上要决定批发多少份报纸。批发价c元，零售价p元。如果需求大于订量，少卖的钱就是损失；如果订量大于需求，剩下的报纸只能当废纸。你需要找到一个"刚好够"的数量。

**历史背景**：报童问题是运筹学中最经典的随机优化问题之一，最初由Edgeworth (1888)在银行储备问题中研究。名称来自"报纸零售商"的比喻。在现代供应链管理、库存控制、容量规划中广泛应用。

**算法定位**：随机优化/单阶段决策。是理解更复杂库存问题和多阶段随机规划的起点。

**前置知识**：概率分布、期望值、微积分。

## 2. 核心原理

**核心思想**：寻找订货量$x^*$使得边际利润等于边际成本的期望。最优解满足：

$$\mathbb{P}(W \leq x^*) = \frac{p - c}{p} = \frac{\text{单位缺货损失}}{\text{单位缺货损失} + \text{单位过剩损失}}$$

这个比率称为**临界比率(critical ratio)**。

**工作流程**：
1. 确定售价$p$、成本$c$和需求的分布$F_W(w)$
2. 计算临界比率$CR = (p-c)/p$
3. 求解$x^* = F_W^{-1}(CR)$
4. 当分布未知时，通过在线学习逐步估计最优订货量

**关键概念**：
- **最终奖励 vs 累积奖励**：原书区分了静态（只看最终决策质量）和动态（累积学习过程中的利润）两种形式
- **审查观测(censored observations)**：通常只能观测到$\min(x^n, W^{n+1})$而非真实需求$W^{n+1}$

## 3. 数学公式与推导

### 利润函数

$$F(x, W) = p \min\{x, W\} - cx$$

- $x$：订货量（决策变量）
- $W$：随机需求
- $p$：单位售价，$c$：单位成本

### 最优解推导

期望利润：$\mathbb{E}_W[F(x,W)] = p\mathbb{E}[\min(x,W)] - cx$

当需求$W$有连续CDF $F_W(w)$时：

$$\mathbb{E}[\min(x,W)] = \int_0^x wf(w)dw + x(1-F_W(x))$$

对$x$求导并令其等于0：

$$\frac{d}{dx}\mathbb{E}[F(x,W)] = p(1 - F_W(x^*)) - c = 0$$

$$F_W(x^*) = \frac{p-c}{p}$$

$$x^* = F_W^{-1}\left(\frac{p-c}{p}\right)$$

### 多维报童问题

$K$个产品共享产能约束$\sum_{k=1}^K x_k \leq U$：

$$\max_{x_1,...,x_K} \mathbb{E}\sum_{k=1}^K [p_k\min(x_k, W_k) - c_kx_k]$$

### 上下文报童

价格$p_t$随时间变化时，状态$S_t = (p_t, B_t)$，决策变为$x^*(S_t)$。

## 4-6. 简要

### 超参数/参数

| 参数 | 含义 | 选择方式 |
|------|------|---------|
| $p$ | 单位售价 | 已知 |
| $c$ | 单位成本 | 已知 |
| 需求分布 | $F_W(w)$ | 已知或从数据估计 |

### 应用
1. 供应链库存管理（季节性商品）
2. 航空座位超售（座位=报纸，乘客=需求）
3. 容量规划（服务器、带宽）
4. 广告竞价（预算=订量，点击=需求）

### 优缺点
**优点**：解析解简洁、直觉清晰、是复杂模型的基石
**缺点**：单阶段模型、假设分布已知、忽略订货提前期

## 7-8. 核心实现

```python
"""报童问题：解析解与在线学习"""
import numpy as np
from scipy import stats

class NewsvendorProblem:
    """报童问题求解器"""
    def __init__(self, price, cost, demand_dist=None):
        self.p = price
        self.c = cost
        self.dist = demand_dist  # scipy分布对象
        self.cr = (price - cost) / price  # 临界比率

    def optimal_order(self):
        """已知分布时的解析最优解"""
        if self.dist is None:
            raise ValueError("需求分布未知")
        return self.dist.ppf(self.cr)

    def profit(self, x, demand):
        """计算利润"""
        return self.p * min(x, demand) - self.c * x

    def expected_profit(self, x, n_samples=100000):
        """蒙特卡洛估计期望利润"""
        demands = self.dist.rvs(n_samples)
        profits = [self.profit(x, d) for d in demands]
        return np.mean(profits)

class OnlineNewsvendor:
    """分布未知时的在线学习"""
    def __init__(self, price, cost, x_range):
        self.p = price
        self.c = cost
        self.x_range = x_range  # 订货量候选值
        self.n_tries = np.zeros(len(x_range))  # 每个x的尝试次数
        self.total_profit = np.zeros(len(x_range))  # 累积利润

    def choose_order(self, epsilon=0.1):
        """ε-greedy策略选择订货量"""
        if np.random.random() < epsilon:
            idx = np.random.randint(len(self.x_range))
        else:
            avg = np.where(self.n_tries > 0,
                          self.total_profit / np.maximum(self.n_tries, 1), -np.inf)
            idx = np.argmax(avg)
        return idx, self.x_range[idx]

    def update(self, idx, demand):
        """更新利润统计"""
        x = self.x_range[idx]
        profit = self.p * min(x, demand) - self.c * x
        self.n_tries[idx] += 1
        self.total_profit[idx] += profit
        return profit

if __name__ == "__main__":
    np.random.seed(42)
    p, c = 10.0, 6.0
    dist = stats.norm(loc=100, scale=20)

    # 解析解
    nv = NewsvendorProblem(p, c, dist)
    x_opt = nv.optimal_order()
    print(f"临界比率: {nv.cr:.2f}")
    print(f"最优订货量: {x_opt:.1f}")
    print(f"最优期望利润: {nv.expected_profit(x_opt):.2f}")

    # 在线学习
    online = OnlineNewsvendor(p, c, list(range(50, 151, 5)))
    total_profit = 0
    for day in range(1000):
        idx, x = online.choose_order(epsilon=max(0.05, 0.3 - day*0.0003))
        demand = dist.rvs()
        total_profit += online.update(idx, demand)
    best_x = online.x_range[np.argmax(
        np.where(online.n_tries > 0, online.total_profit / online.n_tries, -np.inf))]
    print(f"\n在线学习1000天后:")
    print(f"学到的最优订货量: {best_x}")
    print(f"累计利润: {total_profit:.1f}")
```

### 12. 学习总结
报童问题：$x^* = F_W^{-1}(\frac{p-c}{p})$。临界比率平衡缺货与过剩成本。是原书中展示随机优化、在线学习、策略设计的核心案例。

### 13. 练习题
**Q1**：$p=10, c=6$，需求$\sim N(100, 20^2)$，最优订货量是多少？
**A1**：$CR = 0.4$，$x^* = \mu + \sigma \cdot \Phi^{-1}(0.4) = 100 + 20 \times (-0.253) = 94.94$。
