# 梯度平滑(Gradient Smoothing) 学习文档

> 通过对参数的随机扰动平均化来估计平滑梯度，连接有限差分和SPSA。

## 1. 算法基础认知

**一句话定义**：梯度平滑用随机扰动方向上的方向导数来构建梯度估计，扰动越小平滑梯度越接近真实梯度。

**直觉类比**：盲人摸象的一种改进。不是只摸一个点（有限差分），而是在随机方向上摸多个点取平均，得到一个"平滑化"的梯度。

**算法定位**：优化/无导数方法。是SPSA和随机搜索的理论基础。

**前置知识**：梯度、有限差分、概率。

## 2-3. 核心原理与公式

### 平滑梯度

对随机扰动$\Delta \in \mathbb{R}^p$，平滑函数定义为：

$$f_\delta(\theta) = \mathbb{E}_\Delta[f(\theta + \delta\Delta)]$$

平滑梯度：

$$\nabla f_\delta(\theta) = \frac{1}{\delta}\mathbb{E}_\Delta[f(\theta + \delta\Delta)\Delta]$$

### 高斯平滑

当$\Delta \sim N(0, I)$时：

$$\nabla f_\delta(\theta) \approx \frac{1}{N_s}\sum_{i=1}^{N_s} \frac{f(\theta + \delta\Delta^i) - f(\theta)}{\delta}\Delta^i$$

### 与有限差分的关系

有限差分是梯度平滑在$\Delta = e_j$（标准基向量）时的特例。SPSA是$\Delta = (\pm1, \pm1, \ldots)$（Bernoulli）时的特例。

## 4-8. 核心实现

```python
"""梯度平滑：随机方向梯度估计"""
import numpy as np

def smoothed_gradient(f, theta, delta=0.01, n_samples=10):
    """梯度平滑估计"""
    p = len(theta)
    f0 = f(theta)
    grad = np.zeros(p)
    for _ in range(n_samples):
        delta_vec = np.random.randn(p)
        f_new = f(theta + delta * delta_vec)
        grad += (f_new - f0) / delta * delta_vec
    return grad / n_samples

if __name__ == "__main__":
    np.random.seed(42)
    f = lambda t: np.sum(t**2) + np.sin(t[0])
    theta = np.array([1.0, 2.0])
    true_grad = np.array([2*theta[0] + np.cos(theta[0]), 2*theta[1]])

    for ns in [1, 5, 20, 100]:
        est = smoothed_gradient(f, theta, n_samples=ns)
        err = np.linalg.norm(est - true_grad)
        print(f"N_samples={ns:3d}: 估计={est.round(3)}, 误差={err:.4f}")
```

## 9-14. 简要

### 12. 学习总结
梯度平滑：$\nabla f_\delta \approx \frac{1}{\delta}\mathbb{E}[f(\theta+\delta\Delta)\Delta]$。是有限差分和SPSA的统一框架。

### 13. 练习题
**Q1**：为什么多方向平均比单方向（有限差分）更鲁棒？
**A1**：随机方向平均减少噪声影响。单个方向可能恰好沿函数的平坦方向（梯度小），多方向平均更稳定。
