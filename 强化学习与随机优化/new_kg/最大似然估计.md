# 最大似然估计(MLE) 学习文档

> 找到使观测数据出现概率最大的参数值，是统计推断的通用方法。

> 来源线索：本节内容根据原书中关于"Maximum Likelihood Estimation"的相关章节(Ch 3.9.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：MLE通过最大化似然函数$L(\theta|data)$来估计模型参数，选择"最可能产生观测数据"的参数值。

**直觉类比**：你看到一个人穿红色球衣。支持曼联还是利物浦？如果曼联球迷穿红的概率是80%，利物浦是30%，MLE会说"这个人更可能是曼联球迷"——选择使观测（穿红色）概率最大的假设。

**历史背景**：MLE由R.A. Fisher在1912-1922年间系统发展。它是频率学派参数估计的核心方法，在几乎所有统计模型中使用。

**算法定位**：统计学习/参数估计。原书Ch 3.9.1中作为非线性模型参数估计的标准方法引入。

**前置知识**：概率密度函数、优化、对数。

## 2. 核心原理

**核心思想**：给定观测数据$y^1, \ldots, y^N$和模型$f(x|\theta)$，找到使似然函数最大的$\theta$：

$$\hat{\theta}^{MLE} = \arg\max_\theta L(\theta | y, x) = \arg\max_\theta \prod_{n=1}^N f(y^n | x^n, \theta)$$

**工作流程**：
1. 设定参数化模型$f(x|\theta)$
2. 写出似然函数$L(\theta)$
3. 取对数得$\mathcal{L}(\theta) = \log L(\theta)$
4. 求导令其为0或用数值优化求解

**与最小二乘的关系**：当误差$\epsilon \sim N(0, \sigma^2)$时，MLE等价于最小二乘。

## 3. 数学公式与推导

### 似然函数

观测模型：$y = f(x|\theta) + \epsilon$，$\epsilon \sim N(0, \sigma^2)$

$$L(\theta|y, x) = \prod_{n=1}^N \frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(y^n - f(x^n|\theta))^2}{2\sigma^2}\right)$$

### 对数似然

$$\mathcal{L}(\theta) = \sum_{n=1}^N -\frac{(y^n - f(x^n|\theta))^2}{2\sigma^2} + \text{const}$$

最大化$\mathcal{L}$等价于最小化$\sum(y^n - f(x^n|\theta))^2$（MSE）。

### MLE的性质

- **一致性**：$N \to \infty$时$\hat{\theta}^{MLE} \to \theta_{true}$
- **渐近正态**：$\hat{\theta}^{MLE} \sim N(\theta, I^{-1}(\theta)/N)$
- **渐近有效**：达到Cramér-Rao下界

## 4-6. 简要

### 应用
1. 逻辑回归参数估计（最大化对数似然）
2. 随机过程中的参数校准（原书Ch 10.5中电力价格模型）
3. 强化学习中的转移概率估计

### 优缺点
**优点**：渐近最优、通用性强、有良好理论性质
**缺点**：需要假设模型形式、可能过拟合、非线性模型优化困难

## 7-8. 核心实现

```python
"""最大似然估计：正态分布和逻辑回归"""
import numpy as np
from scipy.optimize import minimize

class NormalMLE:
    """正态分布参数的MLE"""
    def __init__(self):
        self.mu = None
        self.sigma = None

    def fit(self, data):
        """解析解"""
        self.mu = np.mean(data)
        self.sigma = np.std(data, ddof=0)  # MLE用N，非N-1
        return self

    def log_likelihood(self, data):
        """计算对数似然"""
        n = len(data)
        ll = -n/2 * np.log(2*np.pi*self.sigma**2) \
             - np.sum((data - self.mu)**2) / (2*self.sigma**2)
        return ll

class LogisticRegressionMLE:
    """逻辑回归MLE（数值优化）"""
    def __init__(self):
        self.theta = None

    @staticmethod
    def _sigmoid(z):
        return 1 / (1 + np.exp(-np.clip(z, -500, 500)))

    def _neg_log_likelihood(self, theta, X, y):
        """负对数似然（待最小化）"""
        z = X @ theta
        h = self._sigmoid(z)
        # 数值稳定的对数似然
        nll = -np.sum(y * np.log(h + 1e-10) + (1-y) * np.log(1-h + 1e-10))
        return nll

    def fit(self, X, y):
        X_b = np.c_[np.ones(len(X)), X]
        theta0 = np.zeros(X_b.shape[1])
        result = minimize(self._neg_log_likelihood, theta0,
                         args=(X_b, y), method='L-BFGS-B')
        self.theta = result.x
        return self

    def predict_proba(self, X):
        X_b = np.c_[np.ones(len(X)), X]
        return self._sigmoid(X_b @ self.theta)

    def predict(self, X):
        return (self.predict_proba(X) >= 0.5).astype(int)

if __name__ == "__main__":
    np.random.seed(42)

    # 1. 正态分布MLE
    data = np.random.normal(5.0, 2.0, 1000)
    mle = NormalMLE().fit(data)
    print(f"正态MLE: μ={mle.mu:.3f} (真值5.0), σ={mle.sigma:.3f} (真值2.0)")
    print(f"对数似然: {mle.log_likelihood(data):.1f}")

    # 2. 逻辑回归MLE
    n = 200
    X = np.random.randn(n, 2)
    true_theta = np.array([0.5, -1.0, 0.3])
    X_b = np.c_[np.ones(n), X]
    prob = 1 / (1 + np.exp(-X_b @ true_theta))
    y = (np.random.random(n) < prob).astype(int)

    lr = LogisticRegressionMLE().fit(X, y)
    pred = lr.predict(X)
    acc = np.mean(pred == y)
    print(f"\n逻辑回归MLE: 准确率={acc:.3f}")
    print(f"估计参数: {lr.theta.round(3)}")
    print(f"真实参数: {true_theta}")
```

## 9-14. 简要

### 12. 学习总结
MLE：$\hat{\theta} = \arg\max_\theta \prod f(y^n|x^n,\theta)$，取对数后$\Leftrightarrow$最小化MSE（正态误差时）。渐近最优的通用参数估计方法。

### 13. 练习题
**Q1**：正态分布下MLE和最小二乘为什么等价？
**A1**：正态似然$L \propto \exp(-\sum(y-f)^2/2\sigma^2)$，最大化$L$等价于最小化$\sum(y-f)^2$（MSE）。
