# 层次聚合(Hierarchical Aggregation) 学习文档

> 在多粒度聚合层级上同时估计函数值，用方差加权组合克服维度灾难。

> 来源线索：本节内容根据原书中关于"Hierarchical Aggregation"的相关章节(Ch 3.6.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：层次聚合在不同粒度层级上估计函数值，然后根据每个层级的统计精度加权组合，在数据稀疏时借助粗粒度估计弥补。

**直觉类比**：预测中国每个县的降雨量。某些县有100年数据（精确），有些只有5年（不精确）。你可以参考省级平均值（粗但稳定），将县级和省级估计加权组合——数据少时偏向省级，数据多时偏向县级。

**历史背景**：层次聚合是处理维度灾难的经典策略。原书Ch 3.6.1中以"游牧卡车司机"问题为例，展示如何在位置、车型、归属地等多维属性上进行分层估计。

**算法定位**：在线学习/查表模型。是值函数近似的重要工具。

**前置知识**：偏差-方差权衡、频率学派更新。

## 2. 核心原理

**核心思想**：细粒度估计方差大（数据少）但偏差小；粗粒度估计方差小但偏差大。层次聚合按各方差倒数加权组合，自动在偏差和方差间取得最优平衡。

**工作流程**：
1. 定义一族聚合函数$G^g: \mathcal{X} \to \mathcal{X}^{(g)}$，$g=0$最细，$g$越大越粗
2. 在每个层级独立维护估计$\bar{f}_x^{(g,n)}$
3. 新观测到来时，更新所有相关层级的估计
4. 加权组合：$\bar{f}_x^{(n)} = \sum_g w_x^{(g,n)} \bar{f}_x^{(g,n)}$

**关键概念**：
- **聚合函数$G^g$**：将细粒度状态映射到粗粒度（如5位邮编→3位→州）
- **偏差来自聚合**：粗粒度将不同状态混为一体
- **方差来自采样不足**：细粒度每个状态数据少

## 3. 数学公式与推导

### 多层级估计组合

设$\bar{f}_x^{(g,n)}$为第$g$层对$x$的估计，$\bar{\sigma}^{2,(g,n)}_x$为其方差。最优权重为方差倒数：

$$w_x^{(g,n)} = \frac{1/\bar{\sigma}^{2,(g,n)}_x}{\sum_{g'} 1/\bar{\sigma}^{2,(g',n)}_x}$$

组合估计：

$$\bar{f}_x^{(n)} = \sum_g w_x^{(g,n)} \bar{f}_x^{(g,n)}$$

### 聚合偏置

第$g$层偏置：$\delta_x^{(g)} = f_x^{(g)} - f_x$

$g=0$时偏置为0（最细），$g$越大偏置越大。

### 原书例子：游牧卡车

| 层级 | 位置 | 车型 | 归属地 | 状态空间大小 |
|------|------|------|--------|------------|
| 0 | 子区域 | 车队 | 区域 | 200,000 |
| 1 | 区域 | 车队 | 区域 | 50,000 |
| 2 | 区域 | 车队 | 地带 | 5,000 |
| 3 | 区域 | 车队 | - | 500 |
| 4 | 地带 | - | - | 10 |

## 4-6. 简要

### 应用
1. 运输网络中的值函数估计（卡车/飞机定位）
2. 血液库存管理的多层级状态估计
3. 资产定价中的多粒度价格估计

### 优缺点
**优点**：克服维度灾难、数据稀疏时自动借用粗粒度信息
**缺点**：需要设计合理的聚合层级、粗粒度偏置可能引入误差

## 7-8. 核心实现

```python
"""层次聚合：多粒度函数估计"""
import numpy as np

class HierarchicalAggregation:
    """多层级聚合估计器"""
    def __init__(self, levels):
        # levels: list of dicts mapping fine_state -> aggregate_state
        self.levels = levels  # levels[g][fine] = aggregate_state
        self.n_levels = len(levels)
        # 每个层级的估计和计数
        self.estimates = [{} for _ in range(self.n_levels)]
        self.counts = [{} for _ in range(self.n_levels)]
        self.sum_sq = [{} for _ in range(self.n_levels)]

    def update(self, fine_state, observation):
        """更新所有层级的估计"""
        for g in range(self.n_levels):
            agg_state = self.levels[g].get(fine_state, 'default')
            if agg_state not in self.estimates[g]:
                self.estimates[g][agg_state] = 0.0
                self.counts[g][agg_state] = 0
                self.sum_sq[g][agg_state] = 0.0

            n = self.counts[g][agg_state]
            old_mean = self.estimates[g][agg_state]
            n += 1
            new_mean = old_mean + (observation - old_mean) / n
            self.estimates[g][agg_state] = new_mean
            self.counts[g][agg_state] = n

    def estimate(self, fine_state):
        """加权组合所有层级的估计"""
        values = []
        weights = []
        for g in range(self.n_levels):
            agg_state = self.levels[g].get(fine_state, 'default')
            if agg_state in self.estimates[g] and self.counts[g][agg_state] > 0:
                val = self.estimates[g][agg_state]
                n = self.counts[g][agg_state]
                # 权重正比于样本数（方差越大的权重越小）
                # 加入偏置惩罚：层级越深偏置越大
                w = n / (1 + g * 10)  # g越大偏置越大，权重越低
                values.append(val)
                weights.append(w)

        if not values:
            return 0.0
        weights = np.array(weights)
        weights /= weights.sum()
        return sum(v * w for v, w in zip(values, weights))

if __name__ == "__main__":
    np.random.seed(42)
    # 3层聚合：细(100个) → 中(10个) → 粗(1个)
    level0 = {i: i for i in range(100)}       # 无聚合
    level1 = {i: i // 10 for i in range(100)}  # 10个一组
    level2 = {i: 0 for i in range(100)}         # 全部聚合为1

    ha = HierarchicalAggregation([level0, level1, level2])
    # 模拟观测：真实值f(i) = sin(i/10)
    for _ in range(500):
        fine = np.random.randint(100)
        true_val = np.sin(fine / 10) + 5
        obs = true_val + 0.3 * np.random.randn()
        ha.update(fine, obs)

    # 估计对比
    test_states = [5, 50, 95]
    for s in test_states:
        est = ha.estimate(s)
        true = np.sin(s / 10) + 5
        print(f"状态{s}: 估计={est:.3f}, 真值={true:.3f}, 误差={abs(est-true):.3f}")
```

## 9-14. 简要

### 12. 学习总结
层次聚合：在$G$个聚合层级上独立估计，按$w \propto 1/\sigma^2$加权组合。数据少时自动借用粗粒度信息，是克服查表模型维度灾难的关键工具。

### 13. 练习题
**Q1**：为什么不能只用最细粒度的估计？
**A1**：最细粒度每个状态数据少，方差大。层次聚合在数据稀疏时自动退化为粗粒度估计（低方差但有偏），数据充足时偏向细粒度（无偏且低方差）。
