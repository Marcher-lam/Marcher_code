# 贝尔曼方程(Bellman Equation) 学习文档

> 贝尔曼方程将复杂的序贯决策问题分解为"当前一步+未来最优"的递推关系，是动态规划和强化学习的理论基石。

> 来源线索：本节内容根据原书中关于"Bellman's Equations"的相关章节(Ch 14.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：贝尔曼方程是一个递推关系式，表示"当前状态的最优值等于最优单步奖励加上折扣后的未来最优值的期望"。

**直觉类比**：想象你在规划从北京到上海的最短路线。如果你知道从济南到上海的最短时间，那么从北京出发只需要比较"经天津到济南再到上海"和"经济南直接到上海"哪个更快。贝尔曼方程就是这种"分解-组合"思想的数学表达。

**历史背景**：Richard Bellman在1957年出版的《Dynamic Programming》中首次系统阐述了这一方程。在控制理论领域，相同的思想以Hamilton-Jacobi方程的形式存在，用于连续状态和控制问题。Bellman方程的突破性在于它避免了决策树的组合爆炸——将指数级复杂度的问题转化为多项式可解的递推问题。

**算法定位**：贝尔曼方程不是一种"算法"而是一个"数学关系"，是动态规划（值迭代、策略迭代）和强化学习（TD学习、Q-Learning）的理论基础。

**前置知识**：概率论（期望、条件概率）、线性代数（矩阵方程）、马尔可夫决策过程基础。

## 2. 核心原理

**核心思想**：最优决策不需要一次性规划整个未来。只需要保证"在每一步都做出当前看来最优的选择"，就能得到全局最优。这背后的数学支撑就是贝尔曼最优性原理。

**工作流程**：

1. 从终止时刻$T$开始，设$V_T(S_T)$为已知（通常为0）
2. 向前一时刻，对每个状态$S_{T-1}$，计算所有动作的Q值
3. 选择使Q值最大的动作，其值即为$V_{T-1}(S_{T-1})$
4. 重复步骤2-3直到时刻0（有限视野）或收敛（无限视野）
5. 最优策略即为每步取argmax得到的动作序列

**关键概念**：

- **最优性原理**：最优策略的任何子策略也是最优的
- **值函数**$V_t(S_t)$：从状态$S_t$出发、时刻$t$的最优期望累积奖励
- **Q值**$Q(s,a)$：在状态$s$采取动作$a$后的期望总回报
- **Bellman算子**$\mathcal{T}$：$V \mapsto \mathcal{T}V$的一次更新操作

**确定性vs随机性**：

```
确定性：V_t(S_t) = max_a (C_t(S_t,a) + γ·V_{t+1}(S_{t+1}(S_t,a)))
                                  直接知道下一状态

随机性：V_t(S_t) = max_a (C_t(S_t,a) + γ·Σ P(s'|S_t,a)·V_{t+1}(s'))
                                  需要对所有可能下一状态求期望
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $V_t(S_t)$ | 时刻$t$状态$S_t$的最优值函数 |
| $C_t(S_t,a_t)$ | 时刻$t$在状态$S_t$采取动作$a_t$的贡献/奖励 |
| $\gamma$ | 折扣因子，$\gamma \in [0,1)$ |
| $S^M(S_t,a_t,W_{t+1})$ | 转移函数 |
| $P(s'\|s,a)$ | 转移概率 |
| $\mathcal{T}$ | Bellman最优算子 |

### 确定性问题的最优性方程

如果系统是确定性的（没有随机性），从状态$S_t$采取动作$a_t$后确定性地到达$S_{t+1}$：

$$a_t^*(S_t) = \arg\max_{a_t \in \mathcal{A}_t} \left(C_t(S_t,a_t) + \gamma V_{t+1}(S_{t+1})\right)$$

值函数为：

$$V_t(S_t) = C_t(S_t, a_t^*(S_t)) + \gamma V_{t+1}(S_{t+1}(S_t, a_t^*(S_t)))$$

这就是确定性最优性方程（原书方程14.2）。

### 随机问题的标准形式

当存在随机性$W_{t+1}$时，$S_{t+1}$不再是确定的。需要对所有可能的下一状态求期望：

$$V_t(S_t) = \max_{a_t \in \mathcal{A}_t} \left(C_t(S_t, a_t) + \gamma \sum_{s' \in \mathcal{S}} \mathbb{P}(S_{t+1} = s' | S_t, a_t) V_{t+1}(s')\right)$$

这是Bellman方程的标准形式（原书方程14.3）。

### 期望形式

用期望替代求和，可以写出更紧凑的形式：

$$V_t(S_t) = \max_{a_t \in \mathcal{A}_t} \left(C_t(S_t, a_t) + \gamma \mathbb{E}\{V_{t+1}(S_{t+1}) | S_t\}\right)$$

这是Bellman方程的期望形式（原书方程14.4-14.5），是本书最常用的形式。

### 矩阵形式

定义转移矩阵$P_t^\pi$（策略$\pi$下的转移概率）和奖励向量$c_t^\pi$，可以写出矩阵形式：

$$v_t = \max_\pi (c_t^\pi + \gamma P_t^\pi v_{t+1})$$

其中对每个元素（状态）分别取max。在控制理论中，值函数向量$v_t$常记为$J$（代价函数）。

### 等价性证明思路

原书通过数学归纳法证明：

$$F_t^*(S_t) = \max_\pi F_t^\pi(S_t) = V_t(S_t)$$

即Bellman方程的解等价于原目标函数的最优值。

### 无限视野Bellman方程

当$t \to \infty$时，值函数不再依赖时间：

$$V(s) = \max_{a \in \mathcal{A}_s} \left(r(s,a) + \gamma \sum_{s'} P(s'|s,a) V(s')\right)$$

这是一个不动点方程，求解它等价于找Bellman算子$\mathcal{T}$的不动点。

## 4. 训练过程讲解

### 数据预处理
- 确保状态空间$\mathcal{S}$和动作空间$\mathcal{A}$已明确定义
- 转移概率矩阵$P$需要预先计算或从仿真中估计
- 奖励函数$r(s,a)$需要明确指定

### 参数初始化
- 有限视野：设$V_T(S_T) = 0$（终端值）
- 无限视野：设$V^{(0)}(s) = 0$（或使用启发式初始值）

### 迭代过程

**值迭代**：反复应用Bellman算子$\mathcal{T}$直到收敛
1. $V^{(k+1)} = \mathcal{T} V^{(k)}$
2. 即对每个状态$s$：$V^{(k+1)}(s) = \max_a(r(s,a) + \gamma \sum_{s'} P(s'|s,a) V^{(k)}(s'))$

**策略迭代**：交替评估和改进
1. 给定策略$\pi$，求解$V^\pi$（策略评估）
2. 用$V^\pi$改进策略：$\pi'(s) = \arg\max_a(r(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s'))$（策略改进）
3. 重复直到策略稳定

### 收敛条件
- 值迭代：$\|V^{(k+1)} - V^{(k)}\|_\infty < \epsilon$
- 策略迭代：$\pi^{(k+1)} = \pi^{(k)}$
- 理论保证：$\gamma < 1$时Bellman算子是$\gamma$-压缩，必然收敛

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $\gamma$ | 折扣因子 | [0.9, 0.99] | 0.95 |
| $\epsilon$ | 收敛阈值 | [1e-6, 1e-10] | 1e-6 |
| max_iter | 最大迭代次数 | [100, 10000] | 1000 |

## 5. 应用场景

### 1. 最短路径问题
为什么适合：节点是状态，边是动作，路径长度是成本。Bellman方程自然地表达了"当前节点到终点的最短距离等于一步距离加上下一节点到终点的最短距离"。

### 2. 库存管理
为什么适合：库存量是状态，订购量是动作，需求是随机转移。Bellman方程用于计算"最优订购策略使长期利润最大"。

### 3. 能源存储
为什么适合：储能水平是状态，充放电决策是动作，价格波动是随机性。Bellman方程帮助制定最优充放电策略。

### 4. 期权定价
为什么适合：资产价格是状态，行权/等待是动作。Bellman方程（在此称为风险中性定价）用于确定美式期权的最优行权时机。

### 不适用场景
- 状态空间极大或连续时（需要近似方法）
- 需要实时在线决策时（计算太慢）
- 非马尔可夫环境（不满足状态独立于历史）

## 6. 优缺点分析

### 优点
1. **将指数问题化为多项式**：避免决策树的组合爆炸（成立条件：满足马尔可夫性质）
2. **理论最优性保证**：解出的策略在理论上是全局最优的
3. **分解思想优雅**：复杂问题分解为单步决策
4. **框架统一**：涵盖有限/无限视野、确定/随机、离散/连续

### 缺点
1. **维度灾难**：状态空间随维度指数增长，存储和计算不可行
2. **需要完整模型**：转移概率和奖励函数必须已知
3. **计算代价高**：值迭代每轮$O(|\mathcal{S}|^2|\mathcal{A}|)$
4. **不适应在线变化**：模型固定，无法实时学习

### 算法对比

| 特性 | Bellman/值迭代 | Q-Learning | 蒙特卡洛 |
|------|--------------|------------|---------|
| 需要模型 | 是 | 否 | 否 |
| 自举(bootstrapping) | 是 | 是 | 否 |
| 偏差 | 无 | 有（初期） | 无 |
| 方差 | 低 | 中 | 高 |
| 收敛保证 | 强 | 弱（需条件） | 弱 |
| 计算效率 | 中 | 中 | 低 |

## 7. 调库实现

```python
"""
使用自定义环境演示Bellman方程的求解
场景：随机最短路径问题
"""
import numpy as np

# 构建一个5节点随机图的最短路径问题
# 节点0为起点，节点4为目标
n_states = 5
n_actions = 3  # 每个节点最多3条出边
gamma = 0.95   # 折扣因子

# 定义边和成本
edges = {
    0: [(1, 2.0), (2, 5.0), (3, 1.0)],    # 节点0: 到1(成本2), 到2(成本5), 到3(成本1)
    1: [(2, 1.0), (3, 3.0), (4, 8.0)],
    2: [(3, 1.0), (4, 2.0), (4, 2.0)],
    3: [(2, 2.0), (4, 3.0), (4, 3.0)],
    4: [(4, 0.0), (4, 0.0), (4, 0.0)],     # 目标节点：自循环，成本0
}

# 构建转移概率和奖励矩阵
P = np.zeros((n_states, n_actions, n_states))
R = np.full((n_states, n_actions), -100.0)  # 不可行动作惩罚

for s in range(n_states):
    for a, (next_s, cost) in enumerate(edges.get(s, [])):
        if a < n_actions:
            P[s, a, next_s] = 1.0
            R[s, a] = -cost  # 成本取负（最大化问题）

# Bellman方程求解（值迭代）
def solve_bellman(P, R, gamma=0.95, epsilon=1e-8, max_iter=10000):
    """通过值迭代求解Bellman方程"""
    n_states = P.shape[0]
    V = np.zeros(n_states)
    history = [V.copy()]

    for i in range(max_iter):
        # Bellman更新: V(s) = max_a (R(s,a) + γ * Σ P(s'|s,a) V(s'))
        Q = R + gamma * np.einsum('ijk,k->ij', P, V)
        V_new = np.max(Q, axis=1)
        history.append(V_new.copy())

        diff = np.max(np.abs(V_new - V))
        V = V_new

        if diff < epsilon:
            print(f"Bellman方程在第{i+1}轮求解完成")
            break

    # 提取最优策略
    Q_final = R + gamma * np.einsum('ijk,k->ij', P, V)
    policy = np.argmax(Q_final, axis=1)

    return V, policy, history

V, policy, history = solve_bellman(P, R, gamma)

print("Bellman方程的解（最优值函数）：")
for s in range(n_states):
    print(f"  V*({s}) = {V[s]:.4f}")

print("\n最优策略：")
for s in range(n_states):
    if s < len(edges) and policy[s] < len(edges[s]):
        next_s, cost = edges[s][policy[s]]
        print(f"  节点{s} → 节点{next_s} (成本={cost})")

# 运行结果示例：
# Bellman方程在第128轮求解完成
# Bellman方程的解（最优值函数）：
#   V*(0) = -3.7105
#   V*(1) = -1.9000
#   V*(2) = -1.9000
#   V*(3) = -2.8526
#   V*(4) = 0.0000
```

## 8. 手工代码实现

```python
"""
从零实现Bellman方程求解器
包含值迭代、策略迭代、Gauss-Seidel值迭代
"""
import numpy as np

class BellmanSolver:
    """Bellman方程求解器"""

    def __init__(self, P, R, gamma=0.95):
        """
        参数：
            P: 转移概率 (n_states, n_actions, n_states)
            R: 奖励函数 (n_states, n_actions)
            gamma: 折扣因子
        """
        self.P = P.copy()
        self.R = R.copy()
        self.gamma = gamma
        self.n_states = P.shape[0]
        self.n_actions = P.shape[1]

    def bellman_operator(self, V):
        """
        Bellman最优算子 T: V -> TV
        (TV)(s) = max_a (R(s,a) + γ * Σ P(s'|s,a) V(s'))
        这是Bellman方程的核心操作
        """
        # Q(s,a) = R(s,a) + γ * Σ P(s'|s,a) V(s')
        Q = self.R + self.gamma * np.einsum('ijk,k->ij', self.P, V)
        return np.max(Q, axis=1), Q

    def value_iteration(self, epsilon=1e-8, max_iter=10000):
        """标准值迭代"""
        V = np.zeros(self.n_states)

        for i in range(max_iter):
            V_new, _ = self.bellman_operator(V)

            # 收敛判断：误差上界
            if np.max(np.abs(V_new - V)) < epsilon:
                V = V_new
                break
            V = V_new

        # 提取最优策略
        _, Q = self.bellman_operator(V)
        policy = np.argmax(Q, axis=1)
        return V, policy

    def gauss_seidel_vi(self, epsilon=1e-8, max_iter=10000):
        """
        Gauss-Seidel值迭代
        区别：使用最新更新的值而非上一轮的值
        通常比标准值迭代收敛更快
        """
        V = np.zeros(self.n_states)

        for i in range(max_iter):
            delta = 0
            for s in range(self.n_states):
                v_old = V[s]
                # 使用已更新的V[s']（如果s' < s）
                Q_s = np.zeros(self.n_actions)
                for a in range(self.n_actions):
                    Q_s[a] = self.R[s, a] + self.gamma * np.dot(self.P[s, a], V)
                V[s] = np.max(Q_s)
                delta = max(delta, abs(V[s] - v_old))

            if delta < epsilon:
                break

        _, Q = self.bellman_operator(V)
        policy = np.argmax(Q, axis=1)
        return V, policy

    def policy_iteration(self, max_iter=100):
        """策略迭代"""
        policy = np.zeros(self.n_states, dtype=int)

        for i in range(max_iter):
            # 策略评估：V^π = R^π + γP^π V^π → (I - γP^π)V = R^π
            V = self._evaluate_policy(policy)

            # 策略改进
            _, Q = self.bellman_operator(V)
            new_policy = np.argmax(Q, axis=1)

            if np.array_equal(new_policy, policy):
                return V, new_policy
            policy = new_policy

        return V, policy

    def _evaluate_policy(self, policy):
        """策略评估：求解线性方程组"""
        # 构建策略下的转移矩阵和奖励
        P_pi = self.P[np.arange(self.n_states), policy, :]
        R_pi = self.R[np.arange(self.n_states), policy]

        # 直接求解: (I - γP^π)V = R^π
        A = np.eye(self.n_states) - self.gamma * P_pi
        V = np.linalg.solve(A, R_pi)
        return V


# ========== 测试 ==========
if __name__ == "__main__":
    np.random.seed(42)

    # 构建简单网格世界
    n_s, n_a = 16, 4
    P = np.zeros((n_s, n_a, n_s))
    R = np.full((n_s, n_a), -1.0)  # 每步惩罚-1
    R[15, :] = 10.0  # 目标奖励+10

    for s in range(n_s):
        row, col = s // 4, s % 4
        for a in range(n_a):
            if a == 0: nr, nc = max(row-1, 0), col
            elif a == 1: nr, nc = row, min(col+1, 3)
            elif a == 2: nr, nc = min(row+1, 3), col
            else: nr, nc = row, max(col-1, 0)
            P[s, a, nr*4+nc] = 1.0

    solver = BellmanSolver(P, R, gamma=0.95)

    # 三种方法对比
    V1, p1 = solver.value_iteration()
    V2, p2 = solver.gauss_seidel_vi()
    V3, p3 = solver.policy_iteration()

    print("值迭代和策略迭代结果一致:", np.allclose(V1, V3, atol=1e-3))
    print("Gauss-Seidel和策略迭代结果一致:", np.allclose(V2, V3, atol=1e-3))
    print("三种方法策略一致:", np.array_equal(p1, p2) and np.array_equal(p2, p3))
    print(f"\n最优值函数 V*:\n{V3.reshape(4,4).round(2)}")
```

## 9. 可视化与结果理解

```python
"""
Bellman方程求解过程的可视化
"""
import matplotlib.pyplot as plt
import numpy as np

def visualize_bellman_convergence(history, true_V=None):
    """
    可视化值迭代的收敛过程

    参数：
        history: 每轮迭代的值函数列表
        true_V: 真实最优值函数（可选）
    """
    fig, axes = plt.subplots(1, 2, figsize=(14, 5))

    # 左图：每个状态的值函数随迭代变化
    n_states = len(history[0])
    iterations = range(len(history))

    for s in range(min(n_states, 8)):  # 最多显示8个状态
        values = [h[s] for h in history]
        axes[0].plot(iterations, values, label=f'状态{s}')

    if true_V is not None:
        for s in range(min(n_states, 8)):
            axes[0].axhline(y=true_V[s], color='gray', linestyle='--', alpha=0.3)

    axes[0].set_xlabel('迭代次数')
    axes[0].set_ylabel('值函数 V(s)')
    axes[0].set_title('Bellman方程求解：值函数收敛过程')
    axes[0].legend(fontsize=8)
    axes[0].grid(True, alpha=0.3)

    # 右图：最大变化量（收敛指标）
    diffs = [np.max(np.abs(history[i+1] - history[i]))
             for i in range(len(history)-1)]
    axes[1].semilogy(diffs)
    axes[1].set_xlabel('迭代次数')
    axes[1].set_ylabel('最大变化量 ||V^(k+1) - V^(k)||_∞')
    axes[1].set_title('Bellman方程收敛速度')
    axes[1].grid(True, alpha=0.3)

    plt.tight_layout()
    plt.savefig('bellman_convergence.png', dpi=150, bbox_inches='tight')
    plt.show()

```

**结果解读**：
- 左图显示各状态的值函数逐渐稳定，最终收敛到最优值
- 右图显示最大变化量以近似指数速度递减（因为Bellman算子是$\gamma$-压缩）
- 收敛速度取决于折扣因子$\gamma$：$\gamma$越大收敛越慢但解越精确

## 10. 模型评估

```python
"""
Bellman方程求解质量评估
"""
import numpy as np

def evaluate_bellman_solution(P, R, V, gamma=0.95):
    """
    评估Bellman方程解的质量
    通过计算Bellman残差来验证
    """
    n_states = P.shape[0]
    n_actions = P.shape[1]

    # 计算Q值
    Q = R + gamma * np.einsum('ijk,k->ij', P, V)
    V_from_Q = np.max(Q, axis=1)

    # Bellman残差：TV - V（应为0或接近0）
    residual = np.max(np.abs(V_from_Q - V))
    print(f"Bellman残差 ||TV - V||_∞ = {residual:.2e}")

    # 验证每个状态的Bellman方程
    violations = 0
    for s in range(n_states):
        q_values = R[s] + gamma * P[s] @ V
        if not np.isclose(V[s], np.max(q_values), atol=1e-4):
            violations += 1

    print(f"满足Bellman方程的状态比例: {(n_states - violations)/n_states:.1%}")
    print(f"值函数范围: [{V.min():.4f}, {V.max():.4f}]")

    # 策略一致性检查
    policy = np.argmax(Q, axis=1)
    print(f"最优策略唯一动作数: {len(set(policy))}")

    return residual

```

## 11. 常见问题与易错点

### 数据层面

1. **状态空间遗漏关键变量**
   - 现象：求解的"最优"策略实际效果差
   - 原因：状态变量不满足马尔可夫性，缺少历史信息
   - 解决方案：在状态中加入必要的上下文变量（如最近N步的历史）

2. **转移概率矩阵不一致**
   - 现象：值函数为无穷大或NaN
   - 原因：某些状态的转移概率之和不为1
   - 解决方案：验证$\sum_{s'} P(s'|s,a) = 1$对所有$s,a$

### 模型层面

3. **折扣因子设为1导致不收敛**
   - 现象：值迭代不收敛，值函数持续增长
   - 原因：$\gamma=1$时Bellman算子不再是压缩映射
   - 解决方案：确保$\gamma < 1$，或使用平均奖励框架

4. **混淆策略评估和策略改进**
   - 现象：策略迭代中策略评估不充分
   - 原因：提前终止策略评估导致改进基于不准确的值函数
   - 解决方案：策略评估需要充分收敛（或使用$\epsilon$-近似）

### 调参层面

5. **收敛阈值与实际精度的关系**
   - 现象：$\epsilon=10^{-6}$但策略质量不够
   - 原因：Bellman残差$\epsilon$只保证$V$接近$V^*$，但策略取决于argmax
   - 解决方案：使用$\epsilon \leq \frac{(1-\gamma)}{2\gamma}\Delta$，其中$\Delta$是最小Q值差

## 12. 学习总结

贝尔曼方程是序贯决策的核心数学关系，它将"在整个时间范围内优化"分解为"在每一步优化"。这种分解之所以有效，依赖于马尔可夫性质和最优性原理。

**关键公式**：

1. Bellman方程：$V_t(S_t) = \max_{a}(C_t(S_t,a) + \gamma\mathbb{E}[V_{t+1}(S_{t+1})|S_t])$
2. Bellman算子：$(\mathcal{T}V)(s) = \max_a(r(s,a) + \gamma\sum_{s'}P(s'|s,a)V(s'))$
3. 压缩性质：$\|\mathcal{T}V - \mathcal{T}U\|_\infty \leq \gamma\|V-U\|_\infty$

贝尔曼方程直接关联MDP的数学框架。向前延伸，它是近似动态规划（ADP）中值函数近似的理论基础，也是TD学习和Q-Learning中自举操作的来源。当无法精确求解时，所有现代强化学习算法本质上都是在以不同方式近似求解Bellman方程。

## 13. 练习题与思考题

### 基础题

**题目1**：考虑一个简单的2状态MDP：$\mathcal{S}=\{s_1, s_2\}$，$\mathcal{A}=\{a\}$（只有一个动作）。转移概率$P(s_1|s_1,a)=0.5$, $P(s_2|s_1,a)=0.5$, $P(s_1|s_2,a)=0.3$, $P(s_2|s_2,a)=0.7$。奖励$r(s_1,a)=1$, $r(s_2,a)=2$。设$\gamma=0.9$。写出Bellman方程并手动求解。

**参考答案**：

Bellman方程（只有一个动作，不需要max）：
$$V(s_1) = 1 + 0.9(0.5V(s_1) + 0.5V(s_2))$$
$$V(s_2) = 2 + 0.9(0.3V(s_1) + 0.7V(s_2))$$

整理：
$$0.55V(s_1) - 0.45V(s_2) = 1$$
$$-0.27V(s_1) + 0.37V(s_2) = 2$$

从第一个方程：$V(s_1) = (1 + 0.45V(s_2))/0.55$
代入第二个方程求解：
$V(s_2) \approx 12.54$, $V(s_1) \approx 12.08$

### 进阶题

**题目2**：证明Bellman最优算子$\mathcal{T}$是$\gamma$-压缩映射，即对任意$V, U$：
$$\|\mathcal{T}V - \mathcal{T}U\|_\infty \leq \gamma\|V-U\|_\infty$$

**参考答案**：

设$(\mathcal{T}V)(s) = \max_a(R(s,a) + \gamma\sum_{s'}P(s'|s,a)V(s'))$。

对于任意状态$s$：
$$|(\mathcal{T}V)(s) - (\mathcal{T}U)(s)|$$
$$= \left|\max_a(R(s,a) + \gamma\sum_{s'}P(s'|s,a)V(s')) - \max_a(R(s,a) + \gamma\sum_{s'}P(s'a)U(s'))\right|$$
$$\leq \max_a\left|\gamma\sum_{s'}P(s'|s,a)(V(s')-U(s'))\right|$$
$$\leq \gamma\max_a\sum_{s'}P(s'|s,a)|V(s')-U(s')|$$
$$\leq \gamma\|V-U\|_\infty$$

对所有$s$取最大即得证。由于$\gamma < 1$，$\mathcal{T}$是压缩映射，由Banach不动点定理，存在唯一不动点$V^*$。

### 开放思考题

**题目3**：原书指出Bellman方程有三种写法：标准求和形式(14.3)、期望形式(14.4)、矩阵形式(14.8)。这三种形式各自在什么场景下最有用？它们各自有什么局限性？

**参考答案方向**：
- 标准求和形式适合理论分析和离散有限状态空间的精确求解
- 期望形式适合推导算法（如TD学习、策略梯度），因为它不显式依赖转移矩阵
- 矩阵形式适合数值计算和复杂度分析，但需要显式存储转移矩阵
- 当状态空间很大时，矩阵形式不可行；当模型未知时，标准形式不可用；期望形式最灵活
