# 线性回归(Linear Regression) 学习文档

> 线性回归是最基本的统计学习方法，也是理解所有机器学习模型的起点。

> 来源线索：本节内容根据原书中关于"Linear Regression Review"的相关章节(Ch 3.7.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：线性回归用特征的线性组合建模目标变量，通过最小化均方误差求解最优参数。

**直觉类比**：预测房价。你发现面积、房间数、楼层都影响价格。线性回归假设每个因素有一个固定"单价"，总价格=面积×单价₁+房间×单价₂+...+常数。通过已有数据反推这些"单价"（系数），就能预测新房子。

**历史背景**：最小二乘法由Legendre(1805)和Gauss(1809)独立提出。线性回归是统计学和机器学习最古老也最常用的方法。

**算法定位**：监督学习/回归方法。在原书Ch 3.7.1中作为参数化模型的基础引入。

**前置知识**：线性代数、概率统计、Python。

## 2. 核心原理

线性回归模型：

$$y = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_p x_p + \epsilon$$

矩阵形式：$y = X\theta + \epsilon$

目标：$\min_\theta \frac{1}{N}\sum_{i=1}^N (y_i - X_i\theta)^2$

解析解（正规方程）：$\hat{\theta} = (X^TX)^{-1}X^Ty$

## 3. 数学公式

### 损失函数（MSE）

$$L(\theta) = \frac{1}{2N}\sum_{i=1}^N(y_i - x_i^T\theta)^2 = \frac{1}{2N}\|y - X\theta\|^2$$

### 梯度

$$\nabla_\theta L = -\frac{1}{N}X^T(y - X\theta)$$

### 正规方程

令梯度=0：$X^TX\theta = X^Ty \Rightarrow \hat{\theta} = (X^TX)^{-1}X^Ty$

### 带L2正则化（Ridge）

$$\hat{\theta} = (X^TX + \lambda I)^{-1}X^Ty$$

## 4-6. 简要

### 超参数

| 参数 | 含义 | 推荐 |
|------|------|------|
| λ(Ridge) | 正则化强度 | 交叉验证 |

### 应用
1. 房价预测、销售预测
2. 作为更复杂模型的基线
3. 特征重要性分析

### 优缺点
**优点**：简单、可解释、解析解、计算快
**缺点**：只能建模线性关系、对异常值敏感、假设误差正态

## 7-8. 实现

```python
"""线性回归：sklearn和手工实现"""
import numpy as np

# 手工实现
class LinearRegression:
    def __init__(self):
        self.theta = None

    def fit(self, X, y):
        X_b = np.c_[np.ones(len(X)), X]  # 添加偏置项
        self.theta = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y

    def predict(self, X):
        X_b = np.c_[np.ones(len(X)), X]
        return X_b @ self.theta

if __name__ == "__main__":
    np.random.seed(42)
    n, p = 200, 3
    X = np.random.randn(n, p)
    true_theta = np.array([2.0, -1.0, 0.5])
    y = X @ true_theta + 1.0 + 0.1 * np.random.randn(n)

    model = LinearRegression()
    model.fit(X, y)
    y_pred = model.predict(X)

    print(f"真实系数: [1.0, {true_theta}]")
    print(f"估计系数: {model.theta.round(4)}")
    print(f"MSE: {np.mean((y - y_pred)**2):.4f}")
    print(f"R²: {1 - np.sum((y-y_pred)**2)/np.sum((y-y.mean())**2):.4f}")
```

### 12. 学习总结
线性回归：$\hat{y}=X\theta$，解析解$\hat{\theta}=(X^TX)^{-1}X^Ty$。所有机器学习的起点。

### 13. 练习题
**Q1**：为什么$X^TX$可能不可逆？怎么处理？
**A1**：特征多于样本数或特征线性相关时不可逆。用Ridge正则化：$(X^TX+\lambda I)$保证正定可逆。
