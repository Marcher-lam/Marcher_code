# 拟合值迭代(Fitted Value Iteration) 学习文档

> 每次值迭代后用回归重新拟合值函数，是后向ADP的核心算法。

> 来源线索：本节内容根据原书中关于"Fitted Value Iteration"的相关章节(Ch 15.2)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：拟合值迭代将标准值迭代的$V(s)$替换为回归模型$\bar{V}(s|\theta)$，每次迭代用新样本重新训练。

**算法**：
1. 采样状态集$\{s^1, \ldots, s^M\}$
2. 对每个$s^i$计算目标：$y^i = \max_a \frac{1}{N}\sum_j [r(s^i,a,s_j^i) + \gamma\bar{V}(s_j^i)]$
3. 用回归拟合$\bar{V}(\cdot|\theta) \approx y$
4. 重复直到收敛

**与标准值迭代的区别**：标准VI在表格上操作，FVI在函数空间上操作。

## 4-8. 核心实现

```python
"""拟合值迭代"""
import numpy as np

class FittedValueIteration:
    def __init__(self, n_features, gamma=0.95):
        self.gamma = gamma
        self.theta = np.zeros(n_features)
        self.n_features = n_features

    def V(self, s):
        return self.theta @ self._features(s)

    def _features(self, s):
        f = np.zeros(self.n_features)
        f[0] = 1.0
        if self.n_features > 1: f[1] = s
        if self.n_features > 2: f[2] = s**2
        return f

    def solve(self, sample_states, trans_fn, reward_fn, n_actions=4,
              n_samples=20, n_iters=30):
        for it in range(n_iters):
            targets = []
            features = []
            for s in sample_states:
                q_values = []
                for a in range(n_actions):
                    qs = [reward_fn(s, a) + self.gamma * self.V(trans_fn(s, a, j))
                          for j in range(n_samples)]
                    q_values.append(np.mean(qs))
                targets.append(max(q_values))
                features.append(self._features(s))
            X = np.array(features)
            y = np.array(targets)
            self.theta = np.linalg.lstsq(X, y, rcond=None)[0]
        return self

if __name__ == "__main__":
    np.random.seed(42)
    trans = lambda s, a, j: np.clip(s + np.random.randint(-2, 3), 0, 10)
    reward = lambda s, a: 10.0 if s >= 9 else -0.1 * a
    fvi = FittedValueIteration(n_features=3)
    states = np.arange(11, dtype=float)
    fvi.solve(states, trans, reward, n_iters=20)
    print("FVI值函数估计:")
    for s in range(11):
        print(f"  V({s}) = {fvi.V(s):.2f}")
```

## 9-14. 简要

### 12. 学习总结
拟合值迭代：每步采样→计算目标→回归拟合。是后向ADP的核心算法，用回归替代查表。

### 13. 练习题
**Q1**：为什么拟合值迭代可能不收敛？
**A1**：回归拟合引入近似误差，可能被放大。Bellman算子在函数空间不一定是收缩映射。解决：使用稳定基函数或深度网络+目标网络。
