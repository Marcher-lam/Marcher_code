# 策略搜索方法(Policy Search Methods) 学习文档

> 搜索最优策略参数而非推导最优策略——策略搜索是PFA和CFA的核心优化范式。

> 来源线索：本节内容根据原书中关于"Policy Search"的相关章节(Ch 12.1, 12.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：策略搜索在参数化的策略族 $\{X^\pi(\cdot|\theta)\}$ 中搜索使目标函数 $F^\pi(\theta)$ 最优的参数 $\theta^*$。

**直觉类比**：策略评估像"考试判卷"——给定一份答卷（策略），算分数。策略搜索像"反复修改答卷"——不断调整答案直到得分最高。

**历史背景**：策略搜索在控制论中有悠久历史。策略梯度定理(Sutton et al., 1999)和REINFORCE(Williams, 1992)是其理论基础。现代深度RL中策略搜索是核心范式（PPO、TRPO等）。

**算法定位**：PFA和CFA的参数优化方法。与VFA（学习值函数）和DLA（在线规划）形成对比。

## 2. 核心原理

**策略搜索的变体**：

| 方法 | 梯度类型 | 适用场景 |
|---|---|---|
| 数值梯度 | 有限差分 | 参数少、易评估 |
| SPSA | 随机扰动 | 参数中等、噪声大 |
| 策略梯度(REINFORCE) | 解析梯度 | 连续动作、可微策略 |
| 无导数(进化策略) | 无梯度 | 高维、非凸 |

**策略梯度定理**：
$$\nabla_\theta J(\theta) = E_\pi\left[\sum_t \nabla_\theta \log \pi(a_t|s_t;\theta) \cdot G_t\right]$$

其中 $G_t$ 是从时刻 $t$ 开始的累计奖励。

**策略搜索作为序贯决策问题**：
- 状态：当前参数 $\theta^n$ 和搜索历史
- 决策：搜索方向和步长
- 目标：最小化 $F^\pi(\theta)$
- 不确定性：目标函数的噪声评估

## 3. Python 实现

```python
import numpy as np

def policy_search_reinforce(env_fn, policy_fn, n_episodes=200, lr=0.01):
    """REINFORCE策略搜索"""
    theta = np.random.randn(3) * 0.1  # 初始参数

    for ep in range(n_episodes):
        states, actions, rewards = [], [], []
        state = env_fn()
        done = False

        while not done:
            phi = np.array([state, state**2, 1.0])
            mu = theta @ phi
            std = 0.5
            action = np.random.normal(mu, std)
            action = np.clip(action, -2, 2)

            # 简单环境反馈
            reward = -abs(action - np.sin(state))
            next_state = state + 0.1 * action
            done = abs(next_state) > 5

            states.append(state)
            actions.append(action)
            rewards.append(reward)
            state = next_state

        # 计算策略梯度
        G = np.cumsum(rewards[::-1])[::-1]
        for s, a, g in zip(states, actions, G):
            phi = np.array([s, s**2, 1.0])
            mu = theta @ phi
            grad_logp = (a - mu) / 0.25 * phi
            theta += lr * grad_logp * g

    return theta

theta = policy_search_reinforce(lambda: 0.0, None)
print(f"学到的参数: {np.round(theta, 3)}")
```

## 4. 与其他方法的关系

- **REINFORCE**：最基本的策略梯度
- **Actor-Critic**：策略搜索+值函数辅助
- **SPSA**：无导数的策略搜索
