# 非线性策略(Nonlinear Policies) 学习文档

> 用非线性参数模型表示策略，比线性策略更灵活，适用于复杂的决策边界。

> 来源线索：本节内容根据原书中关于"Nonlinear Policies"的相关章节(Ch 12.2.5)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：非线性策略使用非线性参数模型 $X^\pi(s|\theta) = f(s; \theta)$ 将状态映射到动作，能表达更复杂的决策规则。

**直觉类比**：线性策略像用直尺做决策（"温度>30度就开空调"），非线性策略像用曲线做决策（"温度接近30度时逐渐增加空调功率"），更细腻地适应环境。

**算法定位**：PFA（策略函数近似）的进阶形式，在线性策略和神经网络策略之间。

**前置知识**：
- 线性决策规则
- 非线性参数模型
- 策略梯度

## 2. 核心原理

**常见非线性策略形式**：

1. **Sigmoid/Logistic策略**：
   $$X^\pi(s) = \frac{L}{1 + e^{-\theta^T s}}$$

2. **多项式策略**：
   $$X^\pi(s) = \sum_{k=0}^{K} \theta_k \phi_k(s)$$

3. **神经网络策略**：
   $$X^\pi(s) = \text{NN}_\theta(s)$$

4. **分段策略**：
   $$X^\pi(s) = \begin{cases} f_1(s;\theta_1) & s \in R_1 \\ f_2(s;\theta_2) & s \in R_2 \end{cases}$$

**参数优化**：
- 非线性策略的参数通常通过策略梯度法优化
- $\nabla_\theta J(\theta) = E[\nabla_\theta \log \pi(a|s;\theta) \cdot R]$
- 需要处理多个局部最优

**与线性策略的对比**：

| 特性 | 线性策略 | 非线性策略 |
|---|---|---|
| 表达能力 | 有限 | 强 |
| 参数数量 | 少 | 多 |
| 优化难度 | 凸（通常） | 非凸 |
| 泛化能力 | 取决于特征 | 取决于模型和数据 |
| 可解释性 | 高 | 中等 |

## 3. Python 实现

```python
import numpy as np

class NonlinearPolicy:
    """Sigmoid策略用于库存控制"""
    def __init__(self, theta):
        self.theta = theta  # [偏置, 特征权重...]

    def act(self, state):
        """Sigmoid策略：输出连续动作"""
        z = self.theta @ state
        # 输出0到max_order之间的订货量
        order = 20.0 / (1 + np.exp(-z))
        return int(np.clip(order, 0, 20))

    def gradient(self, state, action, advantage):
        """策略梯度"""
        z = self.theta @ state
        sigmoid = 1 / (1 + np.exp(-z))
        grad_logp = state * (action/20.0 - sigmoid)
        return grad_logp * advantage

# 简单的策略梯度训练
np.random.seed(42)
policy = NonlinearPolicy(np.array([0.0, 0.5, -0.3]))

for ep in range(100):
    state = np.array([1.0, np.random.randn(), np.random.randn()])
    action = policy.act(state)
    reward = -abs(action - 10)  # 目标：订货量接近10
    advantage = reward + 10  # baseline
    grad = policy.gradient(state, action, advantage)
    policy.theta += 0.01 * grad

print(f"训练后参数: {np.round(policy.theta, 3)}")
test_state = np.array([1.0, 0.0, 0.0])
print(f"测试输出: {policy.act(test_state)}")
```

## 4. 与其他方法的关系

- **线性决策规则**：非线性策略的特例
- **策略梯度**：非线性策略的主要优化方法
- **REINFORCE**：最基本的策略梯度算法
- **神经网络策略**：最复杂的非线性策略
