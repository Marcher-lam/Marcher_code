# 动态交易策略(Dynamic Trading Policy) 学习文档

> CFA在交易和路径规划中的典型应用——用参数化修正项调整优化模型。

> 来源线索：本节内容根据原书中关于"Dynamic Trading Policy"和"CFAs for Dynamic Assignment"的相关章节(Ch 13.2-13.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：动态交易策略通过在简单优化模型上添加可调参数化修正项（CFA），实现动态环境中的序贯交易决策。

**直觉类比**：基本交易策略是"低买高卖"，CFA修正策略在此基础上加上"涨了X%后减仓Y"、"跌了Z%后加仓W"等可调规则，通过历史数据调优这些参数。

**算法定位**：CFA（成本函数近似）的典型应用案例。

## 2. 核心原理

**CFA的一般形式**：
$$X^{CFA}(S_t|\theta) = \arg\min_{x_t} \bar{C}(S_t, x_t|\theta)$$

其中 $\bar{C}$ 是修正后的成本函数：
$$\bar{C}(S_t, x_t|\theta) = C(S_t, x_t) + \theta^T \phi(S_t, x_t)$$

**动态交易策略**：
- 基础策略：贪心（myopic）优化
- CFA修正：添加风险惩罚、时间衰减等项
- 参数 $\theta$ 在模拟器中调优

**约束修正CFA**：
$$\bar{C}(S_t, x_t|\theta) = C(S_t, x_t), \quad \text{s.t. } g(S_t, x_t) \leq \theta$$

将硬约束放松为可调参数化的软约束。

## 3. Python 实现

```python
import numpy as np

class DynamicTradingCFA:
    """CFA动态交易策略"""
    def __init__(self):
        self.theta = np.array([0.1, -0.05])  # 风险惩罚, 时间衰减

    def trade(self, price, holding, cash, time_left, prices_history):
        """CFA交易决策"""
        # 基础策略：基于预期收益
        expected_return = np.mean(np.diff(prices_history[-10:]))

        # CFA修正项
        risk_penalty = self.theta[0] * np.std(prices_history[-10:])
        time_decay = self.theta[1] * (1.0 / max(time_left, 1))

        # 修正后的评分
        score = expected_return - risk_penalty + time_decay

        if score > 0 and cash > 0:
            trade = min(10, int(cash / price))
            return trade  # 买入
        elif score < 0 and holding > 0:
            return -min(10, holding)  # 卖出
        return 0  # 持有

# 模拟
np.random.seed(42)
prices = [100.0]
for _ in range(100):
    prices.append(prices[-1] * (1 + 0.001 * np.random.randn()))

trader = DynamicTradingCFA()
holding, cash = 0, 10000.0

for t in range(10, len(prices)):
    action = trader.trade(prices[t], holding, cash, len(prices)-t, prices[:t+1])
    if action > 0:
        cost = action * prices[t]
        if cost <= cash:
            holding += action
            cash -= cost
    elif action < 0:
        sell = -action
        holding -= sell
        cash += sell * prices[t]

total = cash + holding * prices[-1]
print(f"最终资产: ${total:.2f} (现金: ${cash:.2f}, 持仓: {holding})")
```

## 4. 与其他方法的关系

- **CFA**：本策略的实现框架
- **模型预测控制(MPC)**：类似的前瞻+参数化方法
- **动量交易**：CFA修正项可以捕捉动量效应
