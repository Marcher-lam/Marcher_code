# 单调策略(Monotone Policies) 学习文档

> 利用问题的结构性质（保序性）证明最优策略的单调性，大幅缩小搜索空间。

> 来源线索：本节内容根据原书中关于"Monotone Policies"的相关章节(Ch 12, Policy Search章节)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：单调策略是指决策$x^*(s)$关于状态$s$单调递增（或递减）的最优策略，可通过结构分析证明其存在性，从而将策略搜索从整个策略空间缩小到单调策略子集。

**算法定位**：策略设计 / PFA策略子类。属于策略函数近似中的结构化策略。

**前置知识**：MDP、值迭代、凸优化、策略搜索。

## 2. 核心原理

**核心思想**：许多实际问题具有"状态越好→决策越大"（或越小）的直觉性质。如果能从数学上证明最优策略满足单调性，就可以：
1. 将策略参数化为单调函数，大幅降低搜索维度
2. 加速DP算法（利用单调性剪枝）
3. 提高样本效率（只探索单调策略区域）

**单调性的数学定义**：策略$\pi$是单调的，若$s_1 \leq s_2 \Rightarrow \pi(s_1) \leq \pi(s_2)$。

**关键定理**（单调策略存在性条件）：若以下条件满足，则最优策略单调：
1. 转移概率$P(s'|s,a)$对$(s,a)$单调（超模/次模性）
2. 奖励$r(s,a)$对$s$和$a$满足超模性
3. 值函数$V^*(s)$关于$s$单调递增

## 3. 数学公式

### 超模性条件

函数$f(x,y)$是超模的(supermodular)：

$$f(x', y') + f(x, y) \geq f(x', y) + f(x, y'), \quad \forall x' > x, y' > y$$

### 单调策略定理

若$r(s,a)$是$(s,a)$上的超模函数，且$P(\cdot|s,a)$满足随机单调性，则：
1. $V^*(s)$关于$s$单调递增
2. 存在最优策略$\pi^*(s)$关于$s$单调递增

### 参数化单调策略

$$\pi_\theta(s) = g(\theta_0 + \theta_1 s)$$

其中$g$是单调递增函数（如sigmoid、ReLU、恒等映射），$\theta_1 \geq 0$保证单调性。

### 单调性约束的策略搜索

$$\max_\theta \hat{J}(\theta) \quad \text{s.t.} \quad \theta_1 \geq 0$$

## 4. 训练/迭代过程

1. **验证单调性条件**：检查问题是否满足超模性
2. **参数化策略**：选择单调参数化形式$\pi_\theta(s) = g(\theta_0 + \theta_1 s)$
3. **策略搜索**：在单调约束下优化$\theta$（投影梯度、约束优化）
4. **验证**：检查学到的策略是否确实单调

## 5. 应用场景

- **库存管理**：最优订货量随库存水平单调变化
- **资源分配**：最优分配量随需求单调递增
- **定价问题**：最优价格随需求曲线单调变化
- **医疗决策**：治疗强度随病情严重程度单调变化
- **能源管理**：储能充放电策略随电价水平单调变化

## 6. 优缺点

**优点**：
- 大幅降低策略搜索空间
- 提高样本效率（正则化效果）
- 策略可解释性强（单调关系直观）
- 收敛更快更稳定

**缺点**：
- 需要预先验证单调性条件
- 非单调问题不能强行使用
- 单调假设可能过于简化实际问题

## 7. 库实现

Python中可用 `scipy.optimize.minimize` 加约束实现单调策略搜索，或在PyTorch中用投影梯度法。

## 8. 从零实现

```python
"""单调策略：结构化策略搜索"""
import numpy as np

class MonotonePolicy:
    """参数化单调策略：pi(s) = clip(theta0 + theta1 * s, a_min, a_max)"""
    def __init__(self, theta0=0.0, theta1=1.0, a_min=0, a_max=10):
        self.theta0 = theta0
        self.theta1 = theta1  # >= 0 保证单调递增
        self.a_min = a_min
        self.a_max = a_max

    def act(self, s):
        return np.clip(self.theta0 + self.theta1 * s, self.a_min, self.a_max)

    def params(self):
        return np.array([self.theta0, self.theta1])

    def set_params(self, theta):
        self.theta0 = theta[0]
        self.theta1 = max(theta[1], 0)  # 保证非负（单调性约束）

def evaluate_policy(policy, env_fn, n_episodes=100):
    """蒙特卡洛评估策略"""
    total_reward = 0
    for _ in range(n_episodes):
        s, done = env_fn(), False
        while not done:
            a = policy.act(s)
            s, r, done = step_fn(s, a)
            total_reward += r
    return total_reward / n_episodes

def step_fn(s, a):
    """简化的库存环境step"""
    demand = np.random.exponential(3.0)
    sales = min(a + s, demand)
    holding_cost = 0.5 * max(a + s - demand, 0)
    shortage_cost = 2.0 * max(demand - a - s, 0)
    r = sales * 2.0 - a * 1.0 - holding_cost - shortage_cost
    s_next = max(a + s - demand, 0)
    s_next = min(s_next, 20)
    done = False
    return s_next, r, done

def env_fn():
    return np.random.uniform(0, 10)

def search_monotone_policy(n_iter=200, lr=0.1):
    """梯度上升搜索单调策略参数"""
    policy = MonotonePolicy(theta0=2.0, theta1=0.5)
    best_reward = -float('inf')
    best_params = policy.params().copy()

    for it in range(n_iter):
        # 数值梯度
        theta = policy.params()
        grads = np.zeros(2)
        for j in range(2):
            theta_plus = theta.copy()
            theta_plus[j] += 0.01
            policy.set_params(theta_plus)
            r_plus = evaluate_policy(policy, env_fn, n_episodes=50)

            theta_minus = theta.copy()
            theta_minus[j] -= 0.01
            policy.set_params(theta_minus)
            r_minus = evaluate_policy(policy, env_fn, n_episodes=50)

            grads[j] = (r_plus - r_minus) / 0.02

        # 梯度上升 + 投影（theta1 >= 0）
        theta_new = theta + lr * grads
        policy.set_params(theta_new)

        reward = evaluate_policy(policy, env_fn, n_episodes=100)
        if reward > best_reward:
            best_reward = reward
            best_params = theta_new.copy()

        if (it + 1) % 50 == 0:
            print(f"Iter {it+1}: reward={reward:.2f}, theta={policy.params().round(3)}")

    policy.set_params(best_params)
    return policy, best_reward

if __name__ == "__main__":
    np.random.seed(42)
    policy, best_r = search_monotone_policy()
    print(f"\n最优单调策略: theta0={policy.theta0:.3f}, theta1={policy.theta1:.3f}")
    print(f"最优奖励: {best_r:.2f}")
    print("策略验证（单调性检查）:")
    for s in [0, 2, 5, 8, 10]:
        print(f"  s={s} -> a={policy.act(s):.2f}")
```

## 10. 评估方法

- 策略单调性验证：检查$s_1 < s_2 \Rightarrow \pi(s_1) \leq \pi(s_2)$
- 与无约束策略搜索对比：收敛速度和最终性能
- 结构验证：最优DP解是否确实单调

## 11. 常见错误

- 未验证超模性就假设单调性
- 单调约束过强导致策略表达力不足
- 用离散化DP验证时分辨率不够

## 12. 学习总结

单调策略：利用超模性证明最优策略关于状态单调，参数化为$\pi_\theta(s) = g(\theta_0 + \theta_1 s), \theta_1 \geq 0$。大幅缩小搜索空间，提高样本效率和可解释性。

## 13. 练习题

**Q1**：如何判断一个问题是否满足单调策略条件？
**A1**：检查三个条件：(1) 奖励$r(s,a)$是否关于$(s,a)$超模；(2) 转移概率是否随机单调；(3) 值函数是否关于状态单调。实践中可先离散化求解精确DP，观察最优策略是否单调。

**Q2**：单调策略约束是否会损失最优性？
**A2**：如果问题确实满足单调性条件，则不会损失——最优策略就在单调策略集中。如果不满足，强行施加单调约束可能得到次优解。
