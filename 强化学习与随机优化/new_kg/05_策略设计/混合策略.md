# 混合策略(Hybrid Strategies) 学习文档

> 四大策略类别(PFA/CFA/VFA/DLA)可以组合使用——混合策略利用不同策略的优势互补。

> 来源线索：本节内容根据原书中关于"Hybrid Strategies"的相关章节(Ch 11.7)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：混合策略将两种或多种策略类别（PFA、CFA、VFA、DLA）组合使用，利用各自的优势处理复杂决策问题。

**直觉类比**：国际象棋大师不是只用一种思考方式——他们会结合模式识别（PFA）、评估局面（VFA）、向前推演几步（DLA）和规则修正（CFA）。AI下棋也是这种混合方式。

**历史背景**：AlphaGo就是混合策略的经典案例：CNN策略网络（PFA）+ 值网络（VFA）+ MCTS（DLA）。本书将这种实践提升为理论框架。

**算法定位**：策略设计的最高层次——将四大类别视为积木，灵活组合。

**前置知识**：
- 四大策略类别（PFA/CFA/VFA/DLA）
- 基本的策略设计概念

## 2. 核心原理

**核心思想**：不同策略类别有各自的优势和局限：

| 策略 | 优势 | 局限 |
|---|---|---|
| PFA | 简单、快速 | 缺乏预见性 |
| CFA | 结构化、可解释 | 需要参数调节 |
| VFA | 长期规划 | 高维困难 |
| DLA | 不需要训练 | 计算昂贵 |

**常见混合模式**：

1. **DLA + VFA**：前瞻搜索+值函数截断
   - 用DLA搜索H步，然后用VFA估计剩余价值
   - MCTS + 神经网络值函数（AlphaGo）

2. **CFA + PFA**：参数化优化+简单规则
   - UCB策略：排序规则（CFA）+ 探索参数（PFA）

3. **VFA + PFA**：值函数+策略函数
   - Actor-Critic：Critic学值函数(VFA)，Actor学策略(PFA)

4. **Policy-within-a-Policy**：前瞻模型内部嵌套子策略
   - 外层是DLA，内层用PFA/CFA做快速决策

**设计原则**：
- 让每种策略处理它最擅长的部分
- 用参数调节补偿近似误差
- 从简单组合开始，逐步增加复杂度

## 3. Python 实现

```python
import numpy as np

class HybridPolicy:
    """DLA + VFA混合策略示例：简单库存控制"""
    def __init__(self, holding_cost=1.0, stockout_cost=5.0):
        self.holding_cost = holding_cost
        self.stockout_cost = stockout_cost
        self.V = {}  # 简单值函数（查找表）

    def vfa(self, state):
        """值函数近似"""
        return self.V.get(state, 0.0)

    def lookahead(self, state, depth=3):
        """有限深度前瞻 + VFA截断"""
        best_action = None
        best_value = -np.inf

        for action in range(0, 20):  # 订货量0-19
            value = self._evaluate(state, action, depth)
            if value > best_value:
                best_value = value
                best_action = action
        return best_action

    def _evaluate(self, state, action, depth):
        """递归评估"""
        if depth == 0:
            return self.vfa(state)

        cost = self._immediate_cost(state, action)
        future_value = 0
        for demand in [1, 2, 3, 4, 5]:  # 离散需求
            p = 0.2
            new_state = max(0, state + action - demand)
            future_value += p * self._evaluate(new_state, 0, depth - 1)
        return -cost + 0.9 * future_value

    def _immediate_cost(self, inventory, order):
        total = inventory + order
        expected_demand = 3.0
        expected_holding = max(0, total - expected_demand) * self.holding_cost
        expected_stockout = max(0, expected_demand - total) * self.stockout_cost
        return expected_holding + expected_stockout

policy = HybridPolicy()
action = policy.lookahead(inventory=5, depth=2)
print(f"当前库存5, 最优订货量: {action}")
```

## 4. 与其他方法的关系

- **AlphaGo**：PFA(CNN策略网络) + VFA(值网络) + DLA(MCTS)
- **Actor-Critic**：PFA(Actor) + VFA(Critic)
- **MCTS**：DLA + 内部PFA/CFA
