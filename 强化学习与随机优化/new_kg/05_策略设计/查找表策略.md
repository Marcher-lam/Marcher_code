# 查找表策略(Lookup Table Policies) 学习文档

> 最简单的策略形式——为每个离散状态直接映射一个动作，是理解复杂策略的起点。

> 来源线索：本节内容根据原书中关于"Lookup Table Policies"的相关章节(Ch 12.2.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：查找表策略为每个离散状态s存储一个离散动作a，通过直接查表 $X^\pi(s) = a(s)$ 做出决策。

**直觉类比**：像一本"如果...那么..."手册——"如果状态是A，做动作1；如果状态是B，做动作2"。没有计算，直接查表。

**历史背景**：查找表是RL和DP中最基本的数据结构。Q-learning的原始形式就是用查找表存储Q(s,a)。

**算法定位**：最简单的PFA（策略函数近似）。在状态空间小且离散时精确，在大状态空间时不可用。

**前置知识**：
- MDP基础
- 离散状态/动作空间

## 2. 核心原理

**核心思想**：维护一个表格 $A[s]$，对于每个状态 $s$，$A[s]$ 存储最优动作。

**更新方式**：
1. **贪心更新**：基于当前值函数 $V(s)$ 或 $Q(s,a)$ 选择最优动作
2. **epsilon-greedy更新**：以概率 $\varepsilon$ 随机选择
3. **Boltzmann更新**：按softmax概率选择

**优势**：
- 无近似误差（精确表示）
- 实现简单
- 理论分析方便

**局限**：
- 维度灾难：状态数随变量数指数增长
- 无法泛化：访问状态s不帮助估计s'
- 不适用于连续状态空间

**与其他查找表的关系**：
- 值函数查找表：$V(s)$ 或 $Q(s,a)$
- 策略查找表：$A[s]$（本文件主题）
- 信念查找表：$\mu_x^n, \sigma_x^n$（Bandit中）

## 3. Python 实现

```python
import numpy as np

class LookupTablePolicy:
    """查找表策略"""
    def __init__(self, n_states, n_actions):
        self.n_states = n_states
        self.n_actions = n_actions
        self.Q = np.zeros((n_states, n_actions))  # Q表
        self.counts = np.zeros((n_states, n_actions))

    def select(self, state, epsilon=0.1):
        """epsilon-greedy选择"""
        if np.random.rand() < epsilon:
            return np.random.randint(self.n_actions)
        return np.argmax(self.Q[state])

    def update(self, state, action, reward, next_state, alpha=0.1, gamma=0.9):
        """Q-learning更新"""
        best_next = np.max(self.Q[next_state])
        td_target = reward + gamma * best_next
        self.Q[state, action] += alpha * (td_target - self.Q[state, action])
        self.counts[state, action] += 1

    def get_policy(self):
        """获取确定性策略表"""
        return np.argmax(self.Q, axis=1)

# 示例：4x4 GridWorld
n_states = 16
n_actions = 4  # 上下左右
policy = LookupTablePolicy(n_states, n_actions)

# 简单训练
for ep in range(500):
    state = np.random.randint(n_states)
    for step in range(20):
        action = policy.select(state, epsilon=0.2)
        next_state = np.random.randint(n_states)
        reward = 1.0 if next_state == 15 else -0.1
        policy.update(state, action, reward, next_state)
        state = next_state
        if state == 15:
            break

print("学习到的策略:", policy.get_policy())
```

## 4. 与其他方法的关系

- **值迭代/策略迭代**：查找表策略的精确求解方法
- **Q-learning**：用查找表存储Q函数
- **函数近似**：查找表的推广（处理大/连续空间）
