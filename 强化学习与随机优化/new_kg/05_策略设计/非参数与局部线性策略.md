# 非参数与局部线性策略(Nonparametric/Locally Linear Policies) 学习文档

> 不假设固定函数形式，用局部数据构建策略——灵活但数据饥渴的方法。

> 来源线索：本节内容根据原书中关于"Nonparametric/Locally Linear Policies"的相关章节(Ch 12.2.6)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：非参数策略不假设策略函数的形式，而是在每个局部区域用数据直接构建近似；局部线性策略在每个局部区域拟合一个线性模型。

**直觉类比**：全局线性策略像"用一个平面拟合地形"，局部线性策略像"在每个小区域放一块小平板"，随着数据增多，平板越来越小，近似越来越精确。

**历史背景**：非参数统计由Friedman, Hastie, Tibshirani等发展。局部线性方法由Cleveland (1979)提出LOESS。在RL中，非参数方法用于策略和值函数近似。

**算法定位**：PFA的高级形式，在参数模型不够灵活时使用。

**前置知识**：
- K近邻
- 核回归
- 线性回归

## 2. 核心原理

**非参数策略的核心思想**：用已有数据 $(s^n, a^n, r^n)$ 在查询点 $s$ 附近构建局部策略。

**K近邻策略**：
$$X^\pi(s) = \text{majority vote}\{a^{n_1}, ..., a^{n_K}\}$$
其中 $n_1, ..., n_K$ 是距 $s$ 最近的 $K$ 个数据点的索引。

**局部线性策略**：
在每个查询点 $s_0$ 附近求解加权最小二乘：
$$\min_\theta \sum_{n=1}^{N} K_h(s^n - s_0) \cdot (a^n - \theta^T \phi(s^n))^2$$

其中 $K_h$ 是核函数（如高斯核）。

**特性**：
- 随数据增多可逼近任意函数（一致性）
- 需要大量数据
- 预测时计算成本高（需要搜索近邻）
- 在高维时效果下降（维度灾难）

## 3. Python 实现

```python
import numpy as np

class LocallyLinearPolicy:
    """局部线性策略"""
    def __init__(self, bandwidth=1.0):
        self.bandwidth = bandwidth
        self.states = []
        self.actions = []
        self.rewards = []

    def store(self, state, action, reward):
        self.states.append(state)
        self.actions.append(action)
        self.rewards.append(reward)

    def act(self, state):
        if len(self.states) < 3:
            return np.random.choice([0, 1])  # 随机

        states = np.array(self.states)
        actions = np.array(self.actions)
        rewards = np.array(self.rewards)

        # 计算权重
        dists = np.linalg.norm(states - state, axis=1)
        weights = np.exp(-0.5 * (dists / self.bandwidth) ** 2)

        # 加权平均：选择期望奖励最高的动作
        action_values = {}
        for a in set(actions):
            mask = actions == a
            if weights[mask].sum() > 0:
                action_values[a] = np.average(rewards[mask], weights=weights[mask])

        return max(action_values, key=action_values.get)

# 示例
policy = LocallyLinearPolicy(bandwidth=0.5)
np.random.seed(42)
for _ in range(100):
    s = np.random.randn(2)
    a = np.random.choice([0, 1])
    r = 1.0 if (a == 1 and s[0] > 0) or (a == 0 and s[0] <= 0) else 0.0
    policy.store(s, a, r)

test_state = np.array([0.5, 0.0])
print(f"状态{test_state} → 动作{policy.act(test_state)}")
```

## 4. 与其他方法的关系

- **KNN**：最简单的非参数方法
- **核回归**：平滑的非参数方法
- **神经网络**：可视为参数化的非参数方法
- **高斯过程**：带不确定性量化的非参数方法
