# 监督学习用于策略(Supervised Learning for Policies) 学习文档

> 从专家演示中学习策略——模仿学习将RL问题转化为监督学习问题。

> 来源线索：本节内容根据原书中关于策略设计中监督学习应用的相关章节整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：监督学习用于策略是指从专家演示数据 $(s, a^*)$ 中学习策略 $X^\pi(s|\theta) \approx a^*$，将策略学习问题转化为监督学习问题。

**直觉类比**：学徒观察师傅做决策（什么情况做什么动作），然后通过模仿学会类似场景下的决策——这就是"行为克隆"。

**算法定位**：策略学习的简单方法。不需要奖励信号，只需要专家演示数据。

## 2. 核心原理

**行为克隆(Behavioral Cloning)**：
给定专家数据 $\mathcal{D} = \{(s^n, a^{*,n})\}_{n=1}^{N}$，最小化：
$$\min_\theta \sum_{n=1}^{N} L(a^{*,n}, X^\pi(s^n|\theta))$$

**DAgger算法**（Dataset Aggregation）：
1. 从专家数据训练初始策略 $\pi_1$
2. 用 $\pi_1$ 收集新轨迹，请专家标注动作
3. 合并数据集，重新训练 $\pi_2$
4. 重复

**局限性**：
- 分布偏移：训练时看到的状态分布与执行时不同
- 需要（昂贵的）专家标注
- 无法超越专家水平

## 3. Python 实现

```python
import numpy as np

class BehavioralCloning:
    """行为克隆：从专家数据学习策略"""
    def __init__(self, n_features, n_actions):
        self.W = np.random.randn(n_actions, n_features) * 0.01

    def train(self, states, expert_actions, lr=0.01, epochs=100):
        """训练策略网络"""
        N = len(states)
        for _ in range(epochs):
            logits = self.W @ states.T  # (n_actions, N)
            # softmax
            exp_logits = np.exp(logits - logits.max(axis=0))
            probs = exp_logits / exp_logits.sum(axis=0)
            # 交叉熵梯度
            one_hot = np.eye(self.W.shape[0])[:, expert_actions]
            grad = (probs - one_hot) @ states / N
            self.W -= lr * grad

    def act(self, state):
        logits = self.W @ state
        return np.argmax(logits)

# 生成专家数据
np.random.seed(42)
N = 500
states = np.random.randn(N, 3)
expert_actions = np.array([1 if s[0] > 0 else (2 if s[1] > 0 else 0) for s in states])

bc = BehavioralCloning(n_features=3, n_actions=3)
bc.train(states.T, expert_actions)

# 测试
test_s = np.array([1.0, -0.5, 0.3])
print(f"状态 {test_s} → 动作 {bc.act(test_s)}")
print("专家规则: s[0]>0 → 动作1 ✓" if test_s[0] > 0 else "")
```

## 4. 与其他方法的关系

- **策略梯度**：从奖励学习vs从专家学习
- **逆强化学习(IRL)**：先学奖励函数再学策略
- **DAgger**：解决分布偏移的迭代方法
