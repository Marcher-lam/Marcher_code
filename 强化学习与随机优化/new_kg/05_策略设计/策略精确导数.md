# 策略精确导数(Exact Derivatives for DP) 学习文档

> 通过链式法则或策略梯度定理计算目标函数对策略参数的精确梯度。

> 来源线索：本节内容根据原书中关于"Exact Derivatives for Continuous Sequential Problems"和"Exact Derivatives for Discrete Dynamic Programs"的相关章节(Ch 12.7, 12.8)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：精确导数方法通过解析计算（而非有限差分）获得目标函数关于策略参数的梯度，效率更高且无偏差。

**直觉类比**：有限差分像"蒙眼摸两个点猜斜率"，精确导数像"直接用公式算斜率"——更快更准。

**历史背景**：策略梯度定理由Sutton et al. (1999)证明，将REINFORCE放在了严格的理论基础上。

## 2. 核心原理

**连续问题的精确导数**：
通过链式法则 $\frac{dF}{d\theta} = \frac{\partial F}{\partial x} \cdot \frac{\partial x}{\partial \theta}$

**离散DP的策略梯度定理**：
$$\nabla_\theta V^\pi(s) = \sum_s d^\pi(s) \sum_a \nabla_\theta \pi(a|s;\theta) Q^\pi(s,a)$$

**随机策略**：$\pi(a|s;\theta)$ 是概率分布，使得梯度有定义。
$$\nabla_\theta J \approx \frac{1}{N}\sum_{n=1}^{N} \sum_t \nabla_\theta \log \pi(a_t^n|s_t^n;\theta) \cdot G_t^n$$

## 3. Python 实现

```python
import numpy as np

def exact_policy_gradient(theta, states, actions, rewards, gamma=0.99):
    """精确策略梯度计算"""
    T = len(states)
    # 计算折扣累计奖励
    G = np.zeros(T)
    G[-1] = rewards[-1]
    for t in range(T-2, -1, -1):
        G[t] = rewards[t] + gamma * G[t+1]

    # 计算策略梯度
    grad = np.zeros_like(theta)
    for t in range(T):
        s, a, g = states[t], actions[t], G[t]
        phi = np.array([s, 1.0])
        mu = theta @ phi
        # 高斯策略的梯度
        grad += (a - mu) / 1.0 * phi * g

    return grad / T

# 示例
theta = np.array([0.5, 0.0])
states = [0.1, 0.3, 0.5, 0.7]
actions = [0.2, 0.4, 0.6, 0.8]
rewards = [1.0, 0.8, 0.5, 0.2]

grad = exact_policy_gradient(theta, states, actions, rewards)
print(f"参数: {theta}")
print(f"精确梯度: {np.round(grad, 4)}")
```

## 4. 与其他方法的关系

- **有限差分法**：近似梯度，效率低
- **SPSA**：随机扰动的梯度估计
- **REINFORCE**：基于策略梯度定理的算法
