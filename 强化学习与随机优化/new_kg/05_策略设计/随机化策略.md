# 随机化策略(Randomized Policies) 学习文档

> 通过引入随机性来平衡探索与利用——随机化不是缺陷，而是策略设计的核心工具。

> 来源线索：本节内容根据原书中关于"Randomized Policies"的相关章节(Ch 11.8)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：随机化策略以概率分布选择动作，而非确定性选择——主要用于探索-利用平衡，是最简单也最常用的探索机制。

**直觉类比**：即使你知道餐厅A大概率比B好，偶尔还是应该试试B——也许B最近换了厨师变好了。这种"偶尔试试别的"就是随机化策略。

**历史背景**：epsilon-greedy是最古老的探索策略之一。Boltzmann/softmax策略来自统计物理。Thompson采样由Thompson (1933)提出但在2010年后才被重新重视。

**算法定位**：策略设计的基本工具。既可独立使用（作为PFA），也可嵌入其他策略中。

**前置知识**：
- 探索-利用困境
- 概率分布基础

## 2. 核心原理

**三种主要随机化策略**：

### 1. Epsilon-Greedy
$$X^n = \begin{cases} \arg\max_x \bar{\mu}_x^n & \text{以概率 } 1-\varepsilon \\ \text{随机选择} & \text{以概率 } \varepsilon \end{cases}$$

- $\varepsilon=0$：纯利用，$\varepsilon=1$：纯探索
- 简单但有效，$\varepsilon$ 可以随时间衰减

### 2. Boltzmann/Softmax
$$P(X^n = x | S^n) = \frac{e^{\bar{\mu}_x^n / \tau}}{\sum_{x'} e^{\bar{\mu}_{x'}^n / \tau}}$$

- $\tau$ 是"温度"参数
- $\tau \to 0$：趋向greedy，$\tau \to \infty$：趋向均匀随机
- 比epsilon-greedy更平滑

### 3. Thompson采样
$$X^n \sim P(\theta = \theta^* | S^n)$$

- 从后验分布中采样参数，然后选最优动作
- 天然平衡探索与利用
- 在贝叶斯框架下有理论保证

**随机化的理论角色**：
- 在有限MDP中，存在确定性最优策略
- 但在部分可观测或需要探索的设定中，随机化是必要的
- 随机化策略的搜索空间包含确定性策略

## 3. Python 实现

```python
import numpy as np

class RandomizedPolicies:
    """三种随机化策略对比"""
    def __init__(self, n_arms):
        self.n_arms = n_arms
        self.counts = np.zeros(n_arms)
        self.rewards = np.zeros(n_arms)

    def get_means(self):
        mask = self.counts > 0
        means = np.zeros(self.n_arms)
        means[mask] = self.rewards[mask] / self.counts[mask]
        return means

    def epsilon_greedy(self, epsilon=0.1):
        means = self.get_means()
        if np.random.rand() < epsilon:
            return np.random.randint(self.n_arms)
        return np.argmax(means)

    def boltzmann(self, tau=1.0):
        means = self.get_means()
        exp_means = np.exp(means / max(tau, 0.01))
        probs = exp_means / exp_means.sum()
        return np.random.choice(self.n_arms, p=probs)

    def thompson_sampling(self):
        """假设Beta先验"""
        successes = self.rewards
        failures = self.counts - self.rewards
        samples = np.array([np.random.beta(max(s+1, 1), max(f+1, 1))
                           for s, f in zip(successes, failures)])
        return np.argmax(samples)

    def update(self, arm, reward):
        self.counts[arm] += 1
        self.rewards[arm] += reward

# 演示
rp = RandomizedPolicies(5)
print("Epsilon-Greedy选择:", rp.epsilon_greedy(0.1))
print("Boltzmann选择:", rp.boltzmann(0.5))
print("Thompson采样选择:", rp.thompson_sampling())
```

## 4. 与其他方法的关系

| 方法 | 关系 |
|---|---|
| Boltzmann策略 | 温度控制的随机化 |
| PFA | 随机化策略是PFA的一种 |
| 知识梯度 | 更智能的探索策略 |
| 双Q学习 | 解决随机化中的偏差问题 |
