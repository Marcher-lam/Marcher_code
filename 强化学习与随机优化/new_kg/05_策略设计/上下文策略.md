# 上下文策略(Contextual Policies) 学习文档

> 策略依赖于上下文信息（外生状态）——在推荐系统和个性化决策中至关重要。

> 来源线索：本节内容根据原书中关于"Contextual Policies"的相关章节(Ch 12.2.7)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：上下文策略在决策时不仅考虑系统物理状态，还利用外生上下文信息（如时间、天气、用户特征）来做出更精准的决策。

**直觉类比**：普通策略只看"还剩多少库存"来决定订货量。上下文策略还会看"今天是节假日吗？""天气预报说会下雨吗？"——这些上下文信息帮助做出更好的决策。

**历史背景**：上下文赌博机(Contextual Bandit)是上下文策略最经典的应用。在推荐系统、在线广告、个性化医疗中被广泛使用。

**算法定位**：PFA的高级形式，将策略输入从纯物理状态扩展到包含上下文信息。

**前置知识**：
- 策略函数近似(PFA)
- 上下文赌博机
- 特征工程

## 2. 核心原理

**核心思想**：策略 $X^\pi(s, c|\theta)$ 依赖于：
- $s$：物理状态（受决策影响）
- $c$：上下文信息（外生的，不受决策影响）

**与上下文赌博机的关系**：
- 上下文赌博机 = 无物理状态 + 有上下文信息
- 上下文策略 = 有物理状态 + 有上下文信息
- 后者是前者的推广

**上下文特征的类型**：
1. **时间特征**：小时、星期几、季节
2. **环境特征**：天气、温度、经济指标
3. **用户特征**：年龄、偏好、历史行为
4. **系统特征**：负载水平、资源可用性

**策略设计**：
$$X^\pi(s, c|\theta) = f(\phi(s, c); \theta)$$

其中 $\phi(s, c)$ 是状态和上下文的特征向量。

## 3. Python 实现

```python
import numpy as np

class ContextualPolicy:
    """上下文线性策略"""
    def __init__(self, n_features, n_actions):
        self.n_actions = n_actions
        self.theta = np.zeros((n_actions, n_features))
        self.beta = 0.1  # 学习率

    def features(self, state, context):
        """构造特征向量"""
        return np.concatenate([state, context, [1.0]])  # 加偏置

    def act(self, state, context, epsilon=0.1):
        """epsilon-greedy上下文策略"""
        phi = self.features(state, context)
        scores = self.theta @ phi

        if np.random.rand() < epsilon:
            return np.random.randint(self.n_actions)
        return np.argmax(scores)

    def update(self, state, context, action, reward):
        """简单梯度更新"""
        phi = self.features(state, context)
        pred = self.theta[action] @ phi
        error = reward - pred
        self.theta[action] += self.beta * error * phi

# 示例：推荐系统
np.random.seed(42)
policy = ContextualPolicy(n_features=5, n_actions=3)

for _ in range(500):
    state = np.array([np.random.rand()])   # 用户活跃度
    context = np.array([np.random.rand(), np.random.randint(0, 2)])  # 时间段+设备
    action = policy.act(state, context, epsilon=0.2)
    # 模拟奖励
    true_pref = 0 if state[0] > 0.5 else (1 if context[0] > 0.5 else 2)
    reward = 1.0 if action == true_pref else 0.0
    policy.update(state, context, action, reward)

print("策略参数:")
print(np.round(policy.theta, 3))
```
