## 1-3. 核心认知与公式

**一句话定义**：线性决策规则$x = \theta_0 + \theta^T S$用状态的线性组合直接计算决策量，是最简洁的参数化策略。

**公式**：

$$X^{LDR}(S_t|\theta) = \theta_0 + \theta_1 S_{t,1} + \theta_2 S_{t,2} + \cdots + \theta_p S_{t,p}$$

矩阵形式：$x = \theta_0 + \Theta^T S_t$

**典型应用**：
- 库存控制：$x_t = \theta_0 + \theta_1 R_t$（订货量=基础量+库存敏感系数×当前库存）
- 能源管理：$x_t = \theta_0 + \theta_1 p_t + \theta_2 E_t$（发电量=基础+价格响应+储能水平）

**优化**：用SGD/SPSA/策略梯度优化$\theta$，目标$\max_\theta \mathbb{E}\sum_t C(S_t, X^{LDR}(S_t|\theta))$。

## 4-8. 核心实现

```python
"""线性决策规则"""
import numpy as np

class LinearDecisionRule:
    def __init__(self, n_features, lr=0.01):
        self.theta = np.random.randn(n_features + 1) * 0.1
        self.lr = lr

    def decide(self, state):
        s = np.append(1.0, state)  # 添加偏置
        return np.clip(self.theta @ s, 0, 50)  # 约束到合理范围

    def update(self, state, reward):
        """策略梯度更新"""
        s = np.append(1.0, state)
        self.theta += self.lr * reward * s / (np.linalg.norm(s) + 1e-8)

if __name__ == "__main__":
    np.random.seed(42)
    ldr = LinearDecisionRule(n_features=2)
    total_r = 0
    for t in range(500):
        state = np.array([np.random.uniform(0, 30), np.random.uniform(5, 15)])
        x = ldr.decide(state)
        demand = np.random.poisson(10)
        sold = min(x, demand)
        r = 10*sold - 6*x - max(0, x-sold)
        ldr.update(state, r)
        total_r += r
    print(f"线性决策规则参数: {ldr.theta.round(3)}")
    print(f"500步累积奖励: {total_r:.1f}")
```

## 9-14. 简要

### 12. 学习总结
LDR：$x = \theta_0 + \Theta^TS$。PFA最简洁形式，参数少、可解释、易优化。适合线性结构的问题。

### 13. 练习题
**Q1**：线性决策规则和仿射策略的区别？
**A1**：完全相同——线性决策规则包含偏置项$\theta_0$，数学上就是仿射变换。"线性决策规则"是工程术语，"仿射策略"是数学术语。
