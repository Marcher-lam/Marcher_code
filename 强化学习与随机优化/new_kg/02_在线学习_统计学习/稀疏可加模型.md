# 稀疏可加模型(Sparse Additive Models) 学习文档

> 通过稀疏约束实现特征选择，LASSO是最典型的稀疏学习方法——用L1正则化自动选出最重要的特征。

> 来源线索：本节内容根据原书中关于"Sparse Additive Models and Lasso"的相关章节(Ch 3.7.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：稀疏可加模型在回归问题中通过L1正则化（或类似稀疏约束）使大部分系数为零，自动实现特征选择和模型简化。

**直觉类比**：想象你要预测房价，手头有50个特征（面积、楼层、朝向、附近学校数……），但只有5-6个真正有用。稀疏方法像一把筛子——自动把不重要的特征权重压到零，只留下真正有影响力的。

**历史背景**：Tibshirani (1996)提出LASSO（Least Absolute Shrinkage and Selection Operator）。Efron et al. (2004)发展了LARS算法。稀疏学习已成为高维统计和机器学习的核心工具。

**算法定位**：线性模型的正则化扩展。在函数近似和策略参数化中，稀疏约束可以防止过拟合并提高可解释性。

**前置知识**：
- 线性回归
- 正则化概念（L1/L2）
- 优化基础

## 2. 核心原理

**核心思想**：在标准线性回归目标上加入L1惩罚项：

$$\min_\theta \sum_{n=1}^{N} (y^n - \theta^T x^n)^2 + \lambda \sum_{j=1}^{p} |\theta_j|$$

L1惩罚 $\lambda \|\theta\|_1$ 使得许多 $\theta_j$ 精确为零。

**为什么L1产生稀疏解**：
- L1约束的区域是菱形（有棱角），目标函数等高线更容易在棱角处相交
- L2约束的区域是圆形（光滑），交点通常不在坐标轴上

**坐标下降法求解**：
对每个 $\theta_j$，固定其他参数，求解一维优化：
$$\theta_j \leftarrow S\left(\sum_{n} x_j^n(y^n - \sum_{k \neq j} \theta_k x_k^n), \lambda\right) / \sum_n (x_j^n)^2$$

其中 $S(z, \lambda) = \text{sign}(z) \max(|z| - \lambda, 0)$ 是软阈值算子。

**关键概念**：

- **L1正则化**：$|\theta_j|$ 惩罚使系数稀疏
- **正则化参数 $\lambda$**：控制稀疏程度，越大越稀疏
- **软阈值**：将小于阈值的系数收缩为零
- **弹性网络**：L1+L2组合，兼顾稀疏性和分组效应

## 3. Python 实现

```python
import numpy as np

def soft_threshold(z, lam):
    """软阈值算子"""
    return np.sign(z) * np.maximum(np.abs(z) - lam, 0)

def lasso_coordinate_descent(X, y, lam, max_iter=1000):
    """LASSO坐标下降法"""
    n, p = X.shape
    theta = np.zeros(p)

    for _ in range(max_iter):
        theta_old = theta.copy()
        for j in range(p):
            # 计算残差（排除第j个特征）
            r_j = y - X @ theta + X[:, j] * theta[j]
            # 更新第j个系数
            z_j = X[:, j] @ r_j / n
            theta[j] = soft_threshold(z_j, lam) / (np.sum(X[:, j]**2) / n)
        if np.max(np.abs(theta - theta_old)) < 1e-6:
            break
    return theta

# 示例
np.random.seed(42)
n, p = 100, 20
X = np.random.randn(n, p)
true_theta = np.zeros(p)
true_theta[:3] = [2.0, -1.5, 0.8]  # 只有3个非零
y = X @ true_theta + 0.5 * np.random.randn(n)

theta_hat = lasso_coordinate_descent(X, y, lam=0.1)
print(f"真实参数: {true_theta}")
print(f"估计参数: {np.round(theta_hat, 3)}")
print(f"非零个数: {np.sum(np.abs(theta_hat) > 0.01)}")
```

## 4. 与其他方法的关系

- **岭回归(Ridge)**：L2正则化，不产生稀疏但更稳定
- **弹性网络(Elastic Net)**：L1+L2，兼顾稀疏性和分组效应
- **OMP（正交匹配追踪）**：另一种稀疏方法
- **在RL中**：用于选择值函数的特征
