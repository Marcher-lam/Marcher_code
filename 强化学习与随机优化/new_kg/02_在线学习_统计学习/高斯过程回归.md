# 高斯过程回归(Gaussian Process Regression) 学习文档

> 高斯过程回归用概率分布建模函数，天然给出预测不确定性，是贝叶斯优化的核心工具。

> 来源线索：本节内容根据原书中关于"Gaussian Process Regression"的相关章节(Ch 3.4.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：高斯过程回归（GPR）是一种非参数贝叶斯方法，用高斯过程先验定义函数分布，在观测数据上进行贝叶斯推断，得到函数的后验分布（均值+不确定性）。

**直觉类比**：你手头有几个房价数据点（面积→价格）。GPR不只是画一条拟合线，而是对每个面积给出一整个价格分布："均值100万，95%置信区间在80-120万"。在数据稀疏的区域，不确定性自然增大；数据密集处，不确定性很小。

**历史背景**：GP回归的理论基础由Krige（1951，地质统计）和Wiener（时间序列）奠定。现代机器学习中的GP由Williams & Rasmussen在1996年系统推广。GP是贝叶斯优化的核心模型。

**算法定位**：非参数/贝叶斯回归方法。在原书Ch 3.4.3中，GP用于构建非参数信念模型。

**前置知识**：多元正态分布、线性代数（矩阵求逆）、贝叶斯统计。

## 2. 核心原理

**核心思想**：GP将函数$f(x)$建模为一个随机过程，任意有限点集$(f(x_1),...,f(x_n))$服从联合正态分布。通过选择核函数$k(x,x')$定义函数的平滑性和相关性，然后在观测数据上做贝叶斯推断。

**预测公式**（给定训练数据$(X,y)$和新输入$x_*$）：

$$f(x_*) | X, y, x_* \sim \mathcal{N}(\mu(x_*), \sigma^2(x_*))$$

其中：
$$\mu(x_*) = k_*^T(K + \sigma_n^2 I)^{-1}y$$
$$\sigma^2(x_*) = k(x_*, x_*) - k_*^T(K + \sigma_n^2 I)^{-1}k_*$$

- $K$：训练数据的核矩阵，$K_{ij} = k(x_i, x_j)$
- $k_*$：新点与训练数据的核向量，$k_{*i} = k(x_*, x_i)$
- $\sigma_n^2$：观测噪声方差

**关键概念**：
- **核函数**$k(x,x')$：定义函数的平滑性、周期性等
- **RBF核**：$k(x,x') = \sigma_f^2 \exp(-\frac{\|x-x'\|^2}{2l^2})$
- **预测不确定性**：GP天然给出$\sigma^2(x_*)$，离训练数据越远不确定性越大

## 3. 数学公式与推导

### GP定义

高斯过程是函数空间上的概率分布：$f \sim \mathcal{GP}(m(x), k(x,x'))$

其中$m(x)$是均值函数（通常设为0），$k(x,x')$是协方差函数（核函数）。

### 联合分布

训练输出$y$和测试输出$f_*$的联合分布：

$$\begin{pmatrix} y \\ f_* \end{pmatrix} \sim \mathcal{N}\left(0, \begin{pmatrix} K + \sigma_n^2I & k_* \\ k_*^T & k_{**} \end{pmatrix}\right)$$

### 条件分布（预测）

由多元正态分布的条件分布公式直接得到：

$$f_* | y \sim \mathcal{N}(k_*^T(K+\sigma_n^2I)^{-1}y, \ k_{**} - k_*^T(K+\sigma_n^2I)^{-1}k_*)$$

### 边际似然

用于选择核超参数（如长度尺度$l$）：

$$\log p(y|X) = -\frac{1}{2}y^T(K+\sigma_n^2I)^{-1}y - \frac{1}{2}\log|K+\sigma_n^2I| - \frac{n}{2}\log 2\pi$$

## 4-6. 简要

### 超参数

| 参数 | 含义 | 选择方式 |
|------|------|---------|
| $l$ | 长度尺度 | 最大化边际似然 |
| $\sigma_f$ | 信号标准差 | 最大化边际似然 |
| $\sigma_n$ | 噪声标准差 | 最大化边际似然 |

### 应用
1. 贝叶斯优化（代理模型）
2. 时空建模
3. 主动学习

### 优缺点
**优点**：天然不确定性、非参数灵活、小数据表现好
**缺点**：$O(n^3)$计算复杂度、大数据不可行、核选择影响大

## 7-8. 实现

```python
"""高斯过程回归"""
import numpy as np

class GaussianProcessRegressor:
    def __init__(self, sigma_f=1.0, length_scale=1.0, sigma_n=0.1):
        self.sigma_f = sigma_f
        self.l = length_scale
        self.sigma_n = sigma_n

    def rbf_kernel(self, X1, X2):
        sq_dist = np.sum(X1**2, axis=1, keepdims=True) + np.sum(X2**2, axis=1) - 2 * X1 @ X2.T
        return self.sigma_f**2 * np.exp(-0.5 * sq_dist / self.l**2)

    def fit(self, X, y):
        self.X_train = X
        self.y_train = y
        K = self.rbf_kernel(X, X) + self.sigma_n**2 * np.eye(len(X))
        self.L = np.linalg.cholesky(K)
        self.alpha = np.linalg.solve(self.L.T, np.linalg.solve(self.L, y))

    def predict(self, X_test):
        K_s = self.rbf_kernel(self.X_train, X_test)
        K_ss = self.rbf_kernel(X_test, X_test)
        mu = K_s.T @ self.alpha
        v = np.linalg.solve(self.L, K_s)
        sigma2 = np.diag(K_ss) - np.sum(v**2, axis=0)
        return mu, np.sqrt(np.maximum(sigma2, 0))

if __name__ == "__main__":
    np.random.seed(42)
    X_train = np.random.uniform(-5, 5, (20, 1))
    y_train = np.sin(X_train).flatten() + 0.1 * np.random.randn(20)
    X_test = np.linspace(-5, 5, 100).reshape(-1, 1)

    gp = GaussianProcessRegressor(sigma_f=1.0, length_scale=1.0, sigma_n=0.1)
    gp.fit(X_train, y_train)
    mu, std = gp.predict(X_test)

    print(f"训练点数: {len(X_train)}")
    print(f"预测范围: [{mu.min():.2f}, {mu.max():.2f}]")
    print(f"平均不确定性: {std.mean():.3f}")
```

### 11. 常见问题
1. **核矩阵不正定**：加jitter（$+\epsilon I$）
2. **$O(n^3)$太慢**：用稀疏近似（inducing points）

### 12. 学习总结
GPR用GP先验建模函数：$f_*|y \sim \mathcal{N}(k_*^T(K+\sigma_n^2I)^{-1}y, k_{**}-k_*^T(K+\sigma_n^2I)^{-1}k_*)$。天然给不确定性。

### 13. 练习题
**Q1**：当训练数据无限多时，GP预测的不确定性会怎样？
**A1**：在训练数据覆盖的区域趋近0（精确预测），在未覆盖区域仍有高不确定性。但计算代价$O(n^3)$会变得不可行。
