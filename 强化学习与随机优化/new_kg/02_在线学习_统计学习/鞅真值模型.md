# 鞅真值模型(Martingale Truth Model) 学习文档

> 非平稳学习的第一种类型——真值随时间变化但期望保持不变，是理解"变化中的学习"的起点。

> 来源线索：本节内容根据原书中关于"Nonstationary Learning I – Martingale Truth"的相关章节(Ch 3.11.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：鞅真值模型假设被学习的参数θ_t是一个鞅过程——即E[θ_{t+1}|θ_t] = θ_t，真值在波动但期望不变。

**直觉类比**：想象你每天测量某只股票的"真实价值"——它每天都在波动，但假设没有趋势（有效市场），那么今天对未来最好的预测就是今天的观测值。这就是鞅性质。

**历史背景**：鞅论由Doob (1953)系统化。在非平稳学习中，鞅真值模型是最基本的设定——参数可变但无漂移，适应这种变化需要特殊的步长策略。

**算法定位**：非平稳学习的两种基本模型之一（另一种是瞬态真值模型）。

**前置知识**：
- 鞅过程概念
- 指数平滑
- 贝叶斯更新

## 2. 核心原理

**核心思想**：真值 $\theta_t$ 满足鞅性质：
$$\mathbb{E}[\theta_{t+1} | \theta_t] = \theta_t$$

真值在变化，但变化是无趋势的。每一步的观测：
$$y^{t+1} = \theta_t + \epsilon^{t+1}$$

**最优步长**：在鞅真值设定下，最优步长是一个常数（不是衰减到零的序列）。这是因为：
- 参数在不断变化，需要持续追踪
- 常数步长 α 实现了"遗忘因子"——旧数据权重指数衰减

**BAKF步长**（本书提出的最优步长）：
$$\alpha^* = \frac{-\sigma_\epsilon^2 + \sqrt{\sigma_\epsilon^4 + 4\sigma_\theta^2 \sigma_\epsilon^2}}{2\sigma_\theta^2}$$

其中 $\sigma_\theta^2$ 是参数变化方差，$\sigma_\epsilon^2$ 是观测噪声方差。

**与平稳学习的对比**：
- 平稳学习：$\theta_t = \theta^*$（常数），步长应衰减到零
- 鞅真值：$\theta_t$ 可变但无漂移，步长应为正的常数

**关键概念**：
- **鞅性质**：条件期望等于当前值
- **遗忘因子**：常数步长使旧数据权重指数衰减
- **追踪能力**：步长越大追踪越快但噪声越大

## 3. Python 实现

```python
import numpy as np

def martingale_truth_simulation(T=1000, sigma_theta=0.1, sigma_eps=0.5):
    """模拟鞅真值学习过程"""
    # 鞅过程：theta_{t+1} = theta_t + N(0, sigma_theta^2)
    theta_true = np.zeros(T)
    theta_true[0] = 5.0
    for t in range(1, T):
        theta_true[t] = theta_true[t-1] + np.random.randn() * sigma_theta

    # 观测
    y = theta_true + np.random.randn(T) * sigma_eps

    # 常数步长追踪
    alpha_opt = (-sigma_eps**2 + np.sqrt(sigma_eps**4 + 4*sigma_theta**2*sigma_eps**2)) / (2*sigma_theta**2)
    alpha = min(alpha_opt, 0.5)

    theta_est = np.zeros(T)
    theta_est[0] = y[0]
    for t in range(1, T):
        theta_est[t] = theta_est[t-1] + alpha * (y[t] - theta_est[t-1])

    mse = np.mean((theta_est - theta_true)**2)
    print(f"最优步长: {alpha:.4f}")
    print(f"追踪MSE: {mse:.4f}")
    return theta_true, y, theta_est

theta_true, y, theta_est = martingure_truth_simulation()
```

## 4. 与其他方法的关系

- **指数平滑**：鞅真值的最优在线学习方法
- **瞬态真值模型**：有漂移的非平稳模型
- **BAKF步长**：本书推导的最优步长公式
- **Kalman滤波**：更一般的线性动态系统
