# 瞬态真值模型(Transient Truth Model) 学习文档

> 真值随时间漂移的非平稳学习模型——参数不仅在波动，还有系统性的趋势。

> 来源线索：本节内容根据原书中关于"Nonstationary Learning II – Transient Truth"的相关章节(Ch 3.11.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：瞬态真值模型假设被学习的参数θ_t具有系统性的漂移趋势，即E[θ_{t+1}|θ_t] ≠ θ_t，需要更强的遗忘和追踪能力。

**直觉类比**：假设你在跟踪一个移动的目标。鞅真值是目标在随机游走（没有方向偏好），瞬态真值则是目标有明确的移动方向（如从左向右飞）。你需要更快地遗忘旧位置信息，才能跟上目标。

**历史背景**：瞬态学习模型是对鞅真值模型的推广，适用于参数有明显漂移的场景（如市场价格趋势、用户偏好变化）。知识梯度方法可以推广到这种设定。

**算法定位**：非平稳学习的第二种基本类型，比鞅真值更具挑战性。

**前置知识**：
- 鞅真值模型
- 步长策略
- Kalman滤波

## 2. 核心原理

**核心思想**：真值 $\theta_t$ 按下式演化：
$$\theta_{t+1} = M_t \theta_t + \varepsilon_t$$

当 $M_t \neq I$（单位矩阵）时，参数有漂移：
- $M_t = I$：退化为鞅真值模型
- $M_t > I$（标量情况）：参数有增长趋势
- $M_t < I$：参数有收缩趋势

**与鞅真值的区别**：
- 鞅真值：$E[\theta_{t+1}|\theta_t] = \theta_t$，无漂移
- 瞬态真值：$E[\theta_{t+1}|\theta_t] = M_t \theta_t$，有漂移

**步长策略的影响**：
- 需要更大的步长来追踪漂移
- 但更大的步长也意味着更多的估计噪声
- 最优步长取决于漂移速度和观测噪声的比值

**知识梯度在瞬态设定下**：
- 知识梯度的计算需要考虑参数的未来漂移
- 静态知识梯度在瞬态设定下是次优的
- 需要推广为瞬态知识梯度

**关键概念**：
- **漂移矩阵 $M_t$**：控制参数变化方向
- **遗忘因子**：需要更强的遗忘来追踪漂移
- **瞬态知识梯度**：考虑漂移的探索策略

## 3. Python 实现

```python
import numpy as np

def transient_truth_simulation(T=500, M=1.002, sigma_theta=0.05, sigma_eps=0.3):
    """瞬态真值学习模拟"""
    # 瞬态过程：theta_{t+1} = M * theta_t + epsilon
    theta_true = np.zeros(T)
    theta_true[0] = 10.0
    for t in range(1, T):
        theta_true[t] = M * theta_true[t-1] + np.random.randn() * sigma_theta

    # 观测
    y = theta_true + np.random.randn(T) * sigma_eps

    # 对比不同步长
    for alpha in [0.05, 0.15, 0.30]:
        theta_est = np.zeros(T)
        theta_est[0] = y[0]
        for t in range(1, T):
            theta_est[t] = theta_est[t-1] + alpha * (y[t] - theta_est[t-1])
        mse = np.mean((theta_est - theta_true)**2)
        print(f"步长α={alpha:.2f}, 追踪MSE={mse:.4f}")

    print(f"\n真值范围: [{theta_true.min():.1f}, {theta_true.max():.1f}]")

transient_truth_simulation()
```

| 方法 | 关系 |
|---|---|

| Kalman滤波 | 处理线性动态系统的最优方法 |
| 知识梯度 | 可推广到瞬态设定 |
| ADP | 非平稳值函数的学习 |
