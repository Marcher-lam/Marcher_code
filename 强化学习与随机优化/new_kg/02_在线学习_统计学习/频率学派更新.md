# 频率学派更新(Frequentist Updating) 学习文档

> 用样本均值和方差递归更新参数估计，是统计学习最基础的在线方法。

> 来源线索：本节内容根据原书中关于"Lookup Tables with Frequentist Updating"的相关章节(Ch 3.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：频率学派更新通过递归公式在线维护样本均值和方差，无需存储历史数据。

**直觉类比**：你记录每天体重的平均值。每称一次，不需要重新计算所有历史数据的平均——只需用旧平均值和新测量值更新即可。这就是频率学派更新的核心。

**历史背景**：频率学派统计是经典统计学的核心范式。递归更新公式（Welford 1962）使得在线计算统计量成为可能。原书Ch 3.3中作为查表模型的标准参数估计方法引入。

**算法定位**：在线学习/参数估计。是贝叶斯更新的对比基准。

**前置知识**：均值、方差、递推公式。

## 2. 核心原理

**核心思想**：频率学派将未知参数$\mu$视为固定值，估计量$\bar{\mu}^n$是随机变量（因为由随机样本计算）。通过递归公式增量更新。

**关键公式**：

均值递归更新：$\bar{\mu}^n = (1 - \frac{1}{n})\bar{\mu}^{n-1} + \frac{1}{n}W^n$

方差递归更新：$\hat{\sigma}^{2,n} = \frac{n-2}{n-1}\hat{\sigma}^{2,n-1} + \frac{1}{n}(W^n - \bar{\mu}^{n-1})^2$

信念状态：$B^n = (\bar{\mu}^n, \hat{\sigma}^{2,n})$

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $\bar{\mu}^n$ | $n$次观测后的样本均值 |
| $\hat{\sigma}^{2,n}$ | $n$次观测后的样本方差 |
| $\bar{\sigma}^{2,n}$ | 均值估计量的方差 |
| $W^n$ | 第$n$次观测 |

### 均值递归推导

由$\bar{\mu}^n = \frac{1}{n}\sum_{m=1}^n W^m$，分离最后一项：

$$\bar{\mu}^n = \frac{1}{n}\left(\sum_{m=1}^{n-1}W^m + W^n\right) = \frac{n-1}{n}\bar{\mu}^{n-1} + \frac{1}{n}W^n$$

这等价于步长$\alpha_n = 1/n$的SGD更新。

### 方差递归

Welford在线方差：

$$\hat{\sigma}^{2,n} = \frac{n-2}{n-1}\hat{\sigma}^{2,n-1} + \frac{1}{n}(W^n - \bar{\mu}^{n-1})^2, \quad n \geq 2$$

### 与指数平滑的关系

频率学派用步长$\alpha_n = 1/n$（调和步长），旧数据权重趋于0。指数平滑用固定$\alpha$，赋予近期数据更高权重。

## 4-6. 简要

### 应用
1. 赌博机算法中的动作价值估计
2. 强化学习中的Q值初始化估计
3. 在线A/B测试的统计量维护

### 优缺点
**优点**：无需先验、计算简单、无偏估计
**缺点**：没有先验信息（冷启动差）、步长$1/n$对非平稳数据不适用

## 7-8. 核心实现

```python
"""频率学派更新：在线均值和方差估计"""
import numpy as np

class FrequentistUpdater:
    """频率学派在线参数估计"""
    def __init__(self):
        self.n = 0
        self.mu = 0.0
        self.var = 0.0

    def update(self, w):
        """递归更新均值和方差"""
        self.n += 1
        old_mu = self.mu
        # Welford递归
        self.mu = (1 - 1/self.n) * old_mu + w / self.n
        if self.n >= 2:
            self.var = (self.n - 2) / (self.n - 1) * self.var + \
                       (w - old_mu)**2 / self.n

    @property
    def std(self):
        return np.sqrt(self.var) if self.n > 1 else 0.0

    @property
    def se(self):
        """均值的标准误差"""
        return self.std / np.sqrt(self.n) if self.n > 1 else float('inf')

if __name__ == "__main__":
    np.random.seed(42)
    true_mu, true_sigma = 5.0, 2.0
    fu = FrequentistUpdater()

    # 逐步更新
    for i in range(100):
        w = np.random.normal(true_mu, true_sigma)
        fu.update(w)
        if (i+1) % 20 == 0:
            print(f"n={i+1}: 均值={fu.mu:.3f}, 方差={fu.var:.3f}, SE={fu.se:.3f}")

    print(f"\n真实值: μ={true_mu}, σ²={true_sigma**2}")
    print(f"最终估计: μ={fu.mu:.3f}, σ²={fu.var:.3f}")

    # 验证与批量计算一致
    samples = np.random.normal(true_mu, true_sigma, 100)
    print(f"批量均值: {samples.mean():.3f}, 批量方差: {samples.var(ddof=1):.3f}")
```

## 9-14. 简要

### 12. 学习总结
频率学派更新：$\bar{\mu}^n = (1-1/n)\bar{\mu}^{n-1} + W^n/n$，等价于步长$1/n$的SGD。信念状态$B^n=(\bar{\mu}^n, \hat{\sigma}^{2,n})$。

### 13. 练习题
**Q1**：频率学派更新和贝叶斯更新的核心区别是什么？
**A1**：频率学派无先验（冷启动从0开始），步长固定为$1/n$。贝叶斯允许先验$B^0=(\mu^0, \beta^0)$，步长由精度比$\beta^W/(\beta^n+\beta^W)$决定，可利用领域知识。
