# 贝叶斯更新(Bayesian Updating) 学习文档

> 贝叶斯更新将新观测与先验信念结合得到后验分布，是序贯学习的理论基石。

> 来源线索：本节内容根据原书中关于"Lookup Tables with Bayesian Updating"的相关章节(Ch 3.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：贝叶斯更新利用贝叶斯定理，将先验信念与新观测数据结合，得到更新后的后验信念，实现在线学习。

**直觉类比**：你是医生，对某药物的有效率有一个初始估计（先验，比如50%）。每治一个病人，观察结果后更新你的估计：治好了让你更相信有效，没治好让你更怀疑。贝叶斯更新精确告诉你：在当前证据下，药物有效率的最可能值是多少。

**历史背景**：贝叶斯定理由Thomas Bayes在18世纪提出（死后1763年发表）。Laplace独立发展了类似理论。现代贝叶斯统计由Jeffreys, Savage, de Finetti等人系统化。在机器学习和决策理论中，贝叶斯更新是在线学习的标准框架。

**算法定位**：在线学习/统计推断方法。在原书Ch 3.4中，贝叶斯更新是构建信念模型的核心工具，也是Thompson采样、Knowledge Gradient等策略的基础。

**前置知识**：概率论（条件概率、先验/后验）、正态分布、Beta分布。

## 2. 核心原理

**贝叶斯定理**：

$$P(\theta|D) = \frac{P(D|\theta)P(\theta)}{P(D)}$$

- $P(\theta)$：先验（prior）——看到数据前的信念
- $P(D|\theta)$：似然（likelihood）——参数为$\theta$时观测到数据$D$的概率
- $P(\theta|D)$：后验（posterior）——看到数据后的更新信念
- $P(D)$：证据（evidence）——归一化常数

**核心思想**：后验 ∝ 先验 × 似然。每次新观测到来，当前后验变成新的先验，逐步精炼估计。

## 3. 数学公式与推导

### Beta-Bernoulli模型（离散奖励）

**设定**：臂的奖励为0/1（伯努利），成功概率$\mu$未知。

**先验**：$\mu \sim \text{Beta}(\alpha, \beta)$

$$P(\mu) = \frac{\mu^{\alpha-1}(1-\mu)^{\beta-1}}{B(\alpha,\beta)}$$

**似然**：观测$W=1$（成功）或$W=0$（失败）

**后验更新**：
- $W=1$：$\alpha \leftarrow \alpha + 1$
- $W=0$：$\beta \leftarrow \beta + 1$

后验均值：$\mathbb{E}[\mu] = \frac{\alpha}{\alpha+\beta}$

### 正态-正态模型（连续奖励）

**设定**：观测$W \sim \mathcal{N}(\mu, \sigma^2_w)$，$\mu$未知。

**先验**：$\mu \sim \mathcal{N}(\mu^0, \sigma^{2,0})$

**后验**：$\mu|W \sim \mathcal{N}(\mu^1, \sigma^{2,1})$

$$\sigma^{2,1} = \left(\frac{1}{\sigma^{2,0}} + \frac{1}{\sigma^2_w}\right)^{-1}$$

$$\mu^1 = \sigma^{2,1}\left(\frac{\mu^0}{\sigma^{2,0}} + \frac{W}{\sigma^2_w}\right)$$

**直觉**：后验是先验和观测的精度加权平均。数据越多，后验越集中（不确定性降低）。

### 相关信念更新

当臂之间有相关性时（原书Ch 3.4.2），需要使用协方差矩阵更新。观测臂$a$不仅更新臂$a$的信念，也影响相关臂的信念。

## 4-6. 简要

### 超参数

| 先验 | 参数 | 含义 |
|------|------|------|
| Beta | $\alpha,\beta$ | 先验成功/失败次数 |
| Normal | $\mu^0, \sigma^0$ | 先验均值和不确定性 |

### 应用
1. 多臂赌博机（Thompson采样）
2. 在线A/B测试
3. 医疗诊断
4. 推荐系统

### 优缺点
**优点**：理论最优（利用所有信息）、自然处理不确定性
**缺点**：需要指定先验、计算可能复杂（非共轭时）

## 7-8. 实现

```python
"""贝叶斯更新：Beta-Bernoulli和Normal-Normal"""
import numpy as np

class BetaBernoulli:
    """Beta-Bernoulli贝叶斯更新"""
    def __init__(self, alpha=1.0, beta=1.0):
        self.alpha = alpha
        self.beta = beta

    def update(self, success):
        if success:
            self.alpha += 1
        else:
            self.beta += 1

    def mean(self):
        return self.alpha / (self.alpha + self.beta)

    def sample(self):
        return np.random.beta(self.alpha, self.beta)

class NormalNormal:
    """正态-正态贝叶斯更新"""
    def __init__(self, mu0=0.0, sigma2_0=1.0, sigma2_w=1.0):
        self.mu = mu0
        self.sigma2 = sigma2_0
        self.sigma2_w = sigma2_w

    def update(self, observation):
        prec_prior = 1.0 / self.sigma2
        prec_obs = 1.0 / self.sigma2_w
        self.sigma2 = 1.0 / (prec_prior + prec_obs)
        self.mu = self.sigma2 * (self.mu * prec_prior + observation * prec_obs)

# 测试
if __name__ == "__main__":
    np.random.seed(42)
    true_prob = 0.7

    # Beta-Bernoulli
    bb = BetaBernoulli(alpha=1, beta=1)
    for _ in range(100):
        w = 1.0 if np.random.random() < true_prob else 0.0
        bb.update(w)
    print(f"Beta-Bernoulli: 真实={true_prob}, 估计={bb.mean():.3f}")

    # Normal-Normal
    nn = NormalNormal(mu0=0.0, sigma2_0=10.0, sigma2_w=1.0)
    for _ in range(50):
        w = np.random.normal(5.0, 1.0)
        nn.update(w)
    print(f"Normal-Normal: 真实=5.0, 估计={nn.mu:.3f}, 不确定性={nn.sigma2:.4f}")
```

### 11. 常见问题
1. **先验选择不当**：用无信息先验（$\alpha=\beta=1$或$\sigma^2_0$很大）
2. **非共轭模型**：用MCMC或变分推断近似

### 12. 学习总结
贝叶斯更新：$P(\theta|D) \propto P(D|\theta)P(\theta)$。Beta-Bernoulli：$\alpha+=W, \beta+=(1-W)$。Normal-Normal：$\mu^1 = \sigma^{2,1}(\mu^0/\sigma^{2,0} + W/\sigma^2_w)$。

### 13. 练习题
**Q1**：先验$\text{Beta}(2,2)$，观测到3次成功1次失败。后验是什么？
**A1**：$\text{Beta}(2+3, 2+1) = \text{Beta}(5,3)$。后验均值$=5/8=0.625$。
