# 近似架构设计(Approximation Architectures) 学习文档

> 函数近似架构的选择直接影响学习效果——从查找表到深度网络，复杂度递增但数据需求也递增。

> 来源线索：本节内容根据原书中关于"Designing Approximation Architectures in Adaptive Learning"的相关章节(Ch 3.12)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：近似架构是指用来近似目标函数（值函数、策略等）的函数族，从简单的查找表到复杂的深度神经网络，选择合适的架构是学习成功的关键。

**直觉类比**：想象你要画一条通过散点的曲线。你可以：(1)用尺子画直线（线性模型）；(2)用曲线尺画（非线性参数模型）；(3)用很多短线段连接（分段线性）；(4)用任意自由曲线（非参数模型）。每种选择都有精度和稳定性的权衡。

**历史背景**：函数近似在统计学和机器学习中有长期研究。在强化学习中，函数近似的选择直接影响收敛性和性能（Boyan & Moore, 1995的" Deadly Triad "问题）。

**算法定位**：学习系统的"基础设施"——决定了能学什么、学多快、学多好。

**前置知识**：
- 线性回归和非线性模型
- 查找表、参数模型、非参数模型
- 过拟合与欠拟合

## 2. 核心原理

**近似架构的谱系**：

| 架构类型 | 表达能力 | 数据需求 | 计算成本 | 泛化能力 |
|---|---|---|---|---|
| 查找表 | 精确（离散空间） | 每个状态需数据 | 高（状态空间大时） | 无 |
| 线性模型 | 有限 | 中等 | 低 | 强（特征好时） |
| 非线性参数 | 中等 | 中等 | 中等 | 中等 |
| 非参数模型 | 任意 | 大 | 高 | 依赖数据密度 |
| 深度神经网络 | 任意 | 很大 | 高 | 强（数据充足时） |

**设计原则**：

1. **先简单后复杂**：从线性模型开始，不够再加复杂度
2. **利用领域知识**：选择有物理意义的特征
3. **匹配问题结构**：凸问题用线性/分段线性，非凸用神经网络
4. **考虑在线需求**：在线学习需要快速更新的架构

**在RL中的特殊考虑**：

- **Deadly Triad**：函数近似 + 自举(bootstrapping) + 离策略学习 → 可能发散
- **特征工程**：好的特征可以大幅降低架构需求
- **后决策状态**：可以简化函数近似的复杂度

**关键概念**：
- **偏差-方差权衡**：简单模型偏差大、方差小；复杂模型反之
- **特征选择**：选择有信息量的输入特征
- **正则化**：控制模型复杂度防止过拟合

## 3. Python 实现

```python
import numpy as np

def compare_architectures():
    """对比不同近似架构在函数近似中的效果"""
    np.random.seed(42)
    n = 200
    X = np.linspace(-3, 3, n).reshape(-1, 1)
    y_true = np.sin(X).flatten() + 0.3 * X.flatten()
    y = y_true + 0.2 * np.random.randn(n)

    # 1. 线性模型
    X_lin = np.column_stack([np.ones(n), X])
    theta_lin = np.linalg.lstsq(X_lin, y, rcond=None)[0]
    y_lin = X_lin @ theta_lin

    # 2. 多项式模型（3次）
    X_poly = np.column_stack([np.ones(n), X, X**2, X**3])
    theta_poly = np.linalg.lstsq(X_poly, y, rcond=None)[0]
    y_poly = X_poly @ theta_poly

    # 3. 局部线性（简单实现）
    def local_linear(x0, X, y, bandwidth=0.5):
        w = np.exp(-0.5 * ((X - x0) / bandwidth)**2)
        W = np.diag(w.flatten())
        Xw = np.column_stack([np.ones(n), X])
        theta = np.linalg.lstsq(W @ Xw, W @ y, rcond=None)[0]
        return np.array([1, x0]) @ theta

    y_local = np.array([local_linear(x, X, y) for x in X.flatten()])

    for name, y_pred in [("线性", y_lin), ("多项式", y_poly), ("局部线性", y_local)]:
        mse = np.mean((y_pred - y_true)**2)
        print(f"{name}模型 MSE: {mse:.4f}")

compare_architectures()
```

## 4. 与其他方法的关系

- **值函数近似(VFA)**：在RL中选择合适的近似架构
- **策略函数近似(PFA)**：策略的参数化就是选择近似架构
- **特征工程**：近似架构设计的核心环节
