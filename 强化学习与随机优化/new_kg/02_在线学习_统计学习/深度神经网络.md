# 深度神经网络(Deep Neural Networks) 学习文档

> 多层神经网络通过层次化特征学习实现端到端的复杂函数近似。

> 来源线索：本节内容根据原书中关于"Deep Neural Networks"的相关章节(Ch 3.10.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：深度神经网络通过多个隐层构建层次化的特征表示，自动从数据中学习高级抽象。

**直觉类比**：识别人脸。第一层检测边缘，第二层组合边缘为轮廓，第三层组合轮廓为五官，最后一层组合五官为人脸。每层在前一层基础上构建更高级的特征。

**历史背景**：深度学习的突破始于Hinton et al. (2006)的深度信念网络。2012年AlexNet在ImageNet竞赛中大幅领先，标志深度学习时代到来。原书Ch 3.10.4中讨论深度网络在强化学习中的应用。

**算法定位**：深度学习/函数近似。原书中作为值函数和策略函数的高容量近似器。

**前置知识**：神经网络基础、反向传播、正则化。

## 2. 核心原理

**核心思想**：深度（多层）比宽度（更多神经元）更有效地表示复杂函数。每层学习一级抽象特征。

**关键技术**：
- **Batch Normalization**：标准化每层输入，加速训练
- **Dropout**：训练时随机丢弃神经元，防止过拟合
- **残差连接(ResNet)**：$a^{(l+1)} = a^{(l)} + F(a^{(l)})$，缓解梯度消失
- **Adam优化器**：自适应学习率

**正则化方法**：
- L2正则化（权重衰减）：$\lambda\|W\|^2$
- Dropout：$p$概率丢弃
- 早停(Early Stopping)：验证集性能开始下降时停止

## 3. 数学公式与推导

### 深层前向传播

$$a^{(0)} = x$$
$$z^{(l)} = W^{(l)}a^{(l-1)} + b^{(l)}, \quad l=1,\ldots,L$$
$$a^{(l)} = \sigma_l(z^{(l)})$$
$$\hat{y} = a^{(L)}$$

### 残差连接

$$a^{(l+1)} = \sigma(z^{(l+1)} + a^{(l)})$$

使梯度可以直接回传到浅层。

### Dropout

训练时：$\tilde{a}^{(l)} = m^{(l)} \odot a^{(l)}$，$m^{(l)} \sim \text{Bernoulli}(1-p)$

测试时：$\tilde{a}^{(l)} = (1-p) \cdot a^{(l)}$

## 4-6. 简要

### 超参数

| 参数 | 含义 | 推荐 |
|------|------|------|
| 层数L | 网络深度 | 3-50 |
| 宽度 | 每层神经元 | 64-1024 |
| Dropout率p | 正则化强度 | 0.1-0.5 |
| Batch size | 批量大小 | 32-256 |

### 应用
1. 深度强化学习（DQN、PPO）
2. 图像识别、自然语言处理
3. 原书中的深度值函数近似

## 7-8. 核心实现

```python
"""深度神经网络：PyTorch实现"""
import numpy as np

class DeepNeuralNetwork:
    """用NumPy实现的深度网络（带Dropout和BatchNorm）"""
    def __init__(self, layer_dims, lr=0.001, dropout_rate=0.2):
        self.lr = lr
        self.dropout_rate = dropout_rate
        self.L = len(layer_dims) - 1
        self.params = {}
        for l in range(1, self.L + 1):
            self.params[f'W{l}'] = np.random.randn(layer_dims[l-1], layer_dims[l]) * \
                                    np.sqrt(2.0 / layer_dims[l-1])
            self.params[f'b{l}'] = np.zeros(layer_dims[l])

    def _relu(self, z):
        return np.maximum(0, z)

    def forward(self, X, training=True):
        self.cache = {'A0': X}
        A = X
        for l in range(1, self.L + 1):
            Z = A @ self.params[f'W{l}'] + self.params[f'b{l}']
            if l < self.L:
                A = self._relu(Z)
                if training:
                    mask = (np.random.random(A.shape) > self.dropout_rate).astype(float)
                    A = A * mask / (1 - self.dropout_rate)
            else:
                A = Z  # 输出层无激活
            self.cache[f'Z{l}'] = Z
            self.cache[f'A{l}'] = A
        return A

    def backward(self, y):
        m = y.shape[0]
        y_pred = self.cache[f'A{self.L}']
        dA = (y_pred - y) / m
        grads = {}
        for l in range(self.L, 0, -1):
            grads[f'W{l}'] = self.cache[f'A{l-1}'].T @ dA
            grads[f'b{l}'] = dA.sum(axis=0)
            if l > 1:
                dA = (dA @ self.params[f'W{l}'].T) * (self.cache[f'Z{l-1}'] > 0)

        for l in range(1, self.L + 1):
            self.params[f'W{l}'] -= self.lr * grads[f'W{l}']
            self.params[f'b{l}'] -= self.lr * grads[f'b{l}']

        return np.mean((y_pred - y)**2)

if __name__ == "__main__":
    np.random.seed(42)
    n = 1000
    X = np.random.randn(n, 3)
    y = (X[:, 0]**2 + np.sin(X[:, 1]) - X[:, 2]).reshape(-1, 1)

    dnn = DeepNeuralNetwork([3, 64, 32, 1], lr=0.005, dropout_rate=0.1)
    for epoch in range(2000):
        loss = dnn.backward(y)
        if (epoch+1) % 400 == 0:
            y_pred = dnn.forward(X, training=False)
            loss = np.mean((y - y_pred)**2)
            print(f"Epoch {epoch+1}: MSE = {loss:.4f}")
```

### 12. 学习总结
深度网络：多层$a^{(l)} = \sigma(W^{(l)}a^{(l-1)}+b^{(l)})$，关键技术包括Dropout、BatchNorm、残差连接。在原书中用于高维值函数近似。

### 13. 练习题
**Q1**：为什么深度网络比浅层宽网络更有效？
**A1**：深度网络可以用指数级更少的参数表示某些函数类。例如$n$个变量的奇偶函数需要$O(2^n)$个隐单元（浅层），但只需$O(n)$层每层$O(n)$个单元（深层）。
