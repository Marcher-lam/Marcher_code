# 批量学习与在线学习(Batch vs Online Learning) 学习文档

> 批量学习用固定数据集一次性训练，在线学习随数据到达逐个更新——理解两种范式的区别是序贯决策的基石。

> 来源线索：本节内容根据原书中关于"Batch vs. Online Learning"的相关章节(Ch 3.1.7)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：批量学习使用固定的训练数据集一次性拟合模型；在线学习则在新数据逐个到达时实时更新模型参数。

**直觉类比**：批量学习像期末考试前集中复习所有笔记——你有所有资料，可以反复研读。在线学习像在工作中学手艺——每天遇到新情况就调整自己的技能，日积月累越来越熟练。

**历史背景**：批量学习是传统机器学习的标准范式（线性回归、SVM等），以经验风险最小化为基础。在线学习起源于Robbins & Monro (1951)的随机逼近，在控制理论和强化学习中被广泛使用。

**算法定位**：学习范式的选择。在序贯决策问题中，在线学习是天然的选择——因为数据是随时间逐个产生的。

**前置知识**：
- 线性回归基础
- 梯度下降
- 概率论基础

## 2. 核心原理

**批量学习**：
给定固定数据集 $\mathcal{D} = \{(x^n, y^n)\}_{n=1}^{N}$，最小化经验风险：
$$\min_\theta \frac{1}{N} \sum_{n=1}^{N} L(y^n, f(x^n; \theta))$$

- 可以多次遍历数据
- 每次更新使用全部（或mini-batch）数据
- 参数更新可以精确计算梯度

**在线学习**：
数据逐个到达，每次只用新数据更新参数：
$$\theta^{n+1} = \theta^n - \alpha_n \nabla_\theta L(y^{n+1}, f(x^{n+1}; \theta^n))$$

- 每个数据只用一次
- 步长序列 $\alpha_n$ 的选择至关重要
- 适用于数据流、实时决策场景

**关键区别**：

| 特性 | 批量学习 | 在线学习 |
|---|---|---|
| 数据 | 固定数据集 | 数据流 |
| 遍历 | 可多次 | 每个一次 |
| 更新 | 全梯度/mini-batch | 随机梯度 |
| 步长 | 学习率（通常固定） | 衰减步长序列 |
| 内存 | 需存储全部数据 | 只需当前数据 |
| 适应性 | 不适应新分布 | 自然适应变化 |

**在序贯决策中的角色**：序贯决策问题中，数据按时间顺序产生，决策影响后续数据分布——因此在线学习是更自然的范式。

## 3. Python 实现

```python
import numpy as np

# 生成数据
np.random.seed(42)
N = 1000
X = np.random.randn(N, 3)
true_theta = np.array([1.5, -0.8, 0.3])
y = X @ true_theta + 0.1 * np.random.randn(N)

# 批量学习：普通最小二乘
theta_batch = np.linalg.lstsq(X, y, rcond=None)[0]
print(f"批量学习: {theta_batch}")

# 在线学习：随机梯度下降
theta_online = np.zeros(3)
alpha = 0.01
for n in range(N):
    pred = X[n] @ theta_online
    error = pred - y[n]
    theta_online -= alpha * error * X[n]
print(f"在线学习: {np.round(theta_online, 3)}")
print(f"真实参数:  {true_theta}")
```

## 4. 与其他方法的关系

- **随机梯度下降(SGD)**：在线学习的优化方法，也是深度学习的核心
- **递归最小二乘(RLS)**：线性模型的在线学习算法
- **指数平滑**：最简单的在线学习方法
- **TD学习**：强化学习中的在线值函数更新
