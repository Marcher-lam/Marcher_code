# 相关信念更新(Correlated Belief Updating) 学习文档

> 观测一个臂的结果更新其他相关臂的信念，利用协方差结构加速学习。

> 来源线索：本节内容根据原书中关于"Updating for Correlated Beliefs"的相关章节(Ch 3.4.2)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：相关信念更新利用臂间的协方差矩阵，使一个臂的观测同时更新所有相关臂的后验分布。

**与独立信念更新的区别**：
- 独立：观测臂$k$只更新臂$k$的后验
- 相关：观测臂$k$通过协方差$\Sigma$同时更新臂$j\neq k$的后验

**公式**（正态信念）：

先验：$\mu \sim N(\bar{\mu}^0, \Sigma^0)$，观测$W^{n+1} = \mu_{k} + \epsilon$

后验均值：$\bar{\mu}^{n+1} = \bar{\mu}^n + \frac{\Sigma^n e_k}{e_k^T\Sigma^ne_k + \sigma_W^2}(W^{n+1} - \bar{\mu}_k^n)$

后验协方差：$\Sigma^{n+1} = \Sigma^n - \frac{\Sigma^n e_k e_k^T \Sigma^n}{e_k^T\Sigma^ne_k + \sigma_W^2}$

其中$e_k$是第$k$个标准基向量。注意：即使只观测臂$k$，**所有臂**的均值和协方差都会更新。

## 4-8. 核心实现

```python
"""相关信念更新"""
import numpy as np

class CorrelatedBeliefUpdater:
    def __init__(self, K, mu0, Sigma0, sigma_w):
        self.K = K
        self.mu = mu0.copy()
        self.Sigma = Sigma0.copy()
        self.sigma_w = sigma_w

    def update(self, k, observation):
        """观测臂k的结果，更新所有臂的信念"""
        e_k = np.zeros(self.K)
        e_k[k] = 1.0
        Sigma_ek = self.Sigma @ e_k
        denom = e_k @ Sigma_ek + self.sigma_w**2
        # 均值更新（所有臂）
        self.mu += (Sigma_ek / denom) * (observation - self.mu[k])
        # 协方差更新
        self.Sigma -= np.outer(Sigma_ek, Sigma_ek) / denom

    def uncertainty(self):
        return np.sqrt(self.Sigma.diagonal())

if __name__ == "__main__":
    np.random.seed(42)
    K = 5
    true_means = np.array([3.0, 2.8, 1.0, 0.5, 0.3])
    # 构造相关协方差（相邻臂相关）
    Sigma0 = np.eye(K) + 0.5 * np.eye(K, k=1) + 0.5 * np.eye(K, k=-1)
    cbu = CorrelatedBeliefUpdater(K, np.zeros(K), Sigma0*10, sigma_w=1.0)

    print("初始均值:", cbu.mu.round(2))
    for n in range(100):
        k = np.random.randint(K)
        obs = true_means[k] + np.random.randn()
        cbu.update(k, obs)
    print("真实均值:", true_means)
    print("估计均值:", cbu.mu.round(2))
    print("不确定性:", cbu.uncertainty().round(2))
    print("臂0从未被直接观测，但因相关性也被更新")
```

## 9-14. 简要

### 12. 学习总结
相关信念更新：$\bar{\mu}^{n+1} = \bar{\mu}^n + \frac{\Sigma^n e_k}{e_k^T\Sigma^ne_k+\sigma^2}(W-\bar{\mu}_k^n)$。利用协方差传播信息，一次观测更新所有臂。

### 13. 练习题
**Q1**：相关信念更新的核心优势？
**A1**：信息效率——一个臂的观测可以推断相关臂的价值。在臂很多但观测昂贵时（如药物试验），大幅减少所需实验次数。
