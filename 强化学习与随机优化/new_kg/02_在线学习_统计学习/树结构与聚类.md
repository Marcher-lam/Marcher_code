# 树结构与聚类(Tree Structures and Clustering) 学习文档

> 决策树和聚类是两种重要的非参数方法，前者用于预测和决策，后者用于发现数据中的自然分组。

> 来源线索：本节内容根据原书中关于"Indexed Functions, Tree Structures, and Clustering"的相关章节(Ch 3.10.5-3.10.6)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：树结构通过递归分裂特征空间构建预测模型；聚类通过相似性将数据分成若干组——两者都是不假设函数形式的灵活方法。

**直觉类比**：
- **决策树**：像20个问题游戏——"面积大于100吗？""楼层高于10吗？"每个问题把可能性减半，最后给出答案。
- **聚类**：像给一群人分组——不告诉算法应该分几组，而是根据特征相似性自动形成群组。

**历史背景**：决策树由Breiman et al. (1984)在CART中系统化。K-means聚类是最古老的聚类方法之一(Lloyd, 1982)。两者在机器学习和数据挖掘中广泛应用。

**算法定位**：非参数/半参数方法。在函数近似中，树结构可作为值函数或策略的近似器。

**前置知识**：
- 基本统计学
- 距离度量（欧氏距离等）
- 信息熵概念

## 2. 核心原理

### 决策树（CART）

**核心思想**：递归地选择最佳特征和分裂点，将特征空间划分为矩形区域，每个区域用一个常数（回归）或众数（分类）预测。

**分裂准则**：
- **回归树**：最小化平方误差 $\sum_{R} \sum_{x_i \in R} (y_i - \bar{y}_R)^2$
- **分类树**：最大化信息增益或最小化Gini系数

**算法流程**：
1. 在所有特征和分裂点上寻找最佳分裂
2. 将数据分成左右子集
3. 递归分裂直到满足停止条件
4. （可选）剪枝防止过拟合

### 聚类（K-means）

**核心思想**：将 $N$ 个数据点分成 $K$ 个簇，使簇内平方和最小：
$$\min_{C_1,...,C_K} \sum_{k=1}^{K} \sum_{x_i \in C_k} \|x_i - \mu_k\|^2$$

**算法流程**：
1. 随机初始化 $K$ 个中心 $\mu_1, ..., \mu_K$
2. 分配：每个点归入最近的中心
3. 更新：重新计算每个簇的中心
4. 重复2-3直到收敛

**在函数近似中的应用**：
- 树结构可以直接作为值函数近似器
- 聚类可以将连续状态空间离散化
- 层次聚类与层次聚合有天然联系

import numpy as np

class DecisionStump:
    """简单的决策树桩（单层决策树）"""
    def fit(self, X, y):
        best_feat, best_thr, best_loss = 0, 0, np.inf
        for j in range(X.shape[1]):
            for thr in np.unique(X[:, j]):
                left = y[X[:, j] <= thr]

def kmeans(X, K, max_iter=100):
    """K-means聚类"""
    n = X.shape[0]
    idx = np.random.choice(n, K, replace=False)
    centers = X[idx].copy()

    for _ in range(max_iter):
        # 分配
        dists = np.array([[np.linalg.norm(x - c) for c in centers] for x in X])
        labels = np.argmin(dists, axis=1)
        # 更新
        new_centers = np.array([X[labels == k].mean(axis=0) for k in range(K)])
        if np.allclose(centers, new_centers):
            break
        centers = new_centers
    return labels, centers
