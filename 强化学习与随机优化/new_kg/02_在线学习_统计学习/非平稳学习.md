# 非平稳学习(Nonstationary Learning) 学习文档

> 在数据分布随时间变化的环境中进行在线学习，核心是遗忘旧数据。

> 来源线索：本节内容根据原书中关于"Nonstationary Learning"的相关章节(Ch 3.11)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：非平稳学习处理数据分布随时间变化（概念漂移）的情况，通过遗忘因子或滑动窗口使模型跟踪最新趋势。

**直觉类比**：预测明天的天气。10年前的数据对今天的预测帮助不大，因为气候模式在变化。非平稳学习给近期数据更高权重，逐渐遗忘旧数据。

**历史背景**：非平稳学习在信号处理（自适应滤波）和在线学习中广泛研究。原书Ch 3.11中作为在线学习方法的扩展引入，与遗忘因子RLS直接关联。

**算法定位**：在线学习/自适应方法。是固定步长SGD的理论延伸。

**前置知识**：指数平滑、递归最小二乘。

## 2. 核心原理

**核心思想**：标准在线学习假设数据平稳（分布不变），步长$\alpha_n = 1/n$逐渐衰减。非平稳学习需要固定步长$\alpha$或遗忘因子$\lambda$来持续跟踪变化。

**方法分类**：
1. **固定步长SGD**：$\bar{\mu}^n = (1-\alpha)\bar{\mu}^{n-1} + \alpha W^n$，等价于指数平滑
2. **遗忘因子RLS**：$M^{n+1} = \frac{1}{\lambda}(M^n - \ldots)$，$\lambda < 1$使旧数据指数衰减
3. **滑动窗口**：只使用最近$W$个数据点

**概念漂移类型**：
- 渐变漂移：参数缓慢变化（如季节性）
- 突变漂移：参数突然跳变（如政策变化）
- 增量漂移：新概念逐步出现

## 3. 数学公式与推导

### 固定步长更新

$$\bar{\mu}^n = (1-\alpha)\bar{\mu}^{n-1} + \alpha W^n$$

有效记忆长度约$1/\alpha$个样本。

### 遗忘因子RLS

$$M^{n+1} = \frac{1}{\lambda}\left(M^n - \frac{M^n x^{n+1}(x^{n+1})^T M^n}{\lambda + (x^{n+1})^T M^n x^{n+1}}\right)$$

$\lambda \in (0.95, 1.0)$使旧数据权重按$\lambda^k$衰减。

### 偏差-方差权衡

- $\alpha$大（$\lambda$小）：跟踪快但估计方差大
- $\alpha$小（$\lambda$接近1）：估计平滑但跟踪慢

## 4-8. 核心实现

```python
"""非平稳学习：固定步长 vs 1/n步长 对比"""
import numpy as np

class NonstationaryLearner:
    """非平稳环境在线学习"""
    def __init__(self, alpha=0.1):
        self.alpha = alpha
        self.mu = 0.0
        self.mu_harmonic = 0.0
        self.n = 0

    def update(self, w):
        self.n += 1
        # 固定步长（适合非平稳）
        self.mu = (1 - self.alpha) * self.mu + self.alpha * w
        # 调和步长1/n（适合平稳）
        self.mu_harmonic = (1 - 1/self.n) * self.mu_harmonic + w / self.n

if __name__ == "__main__":
    np.random.seed(42)
    learner = NonstationaryLearner(alpha=0.05)
    T = 500

    # 模拟非平稳过程：均值在t=250时从5跳到8
    means_fixed, means_harmonic = [], []
    for t in range(T):
        true_mu = 5.0 if t < 250 else 8.0
        w = true_mu + np.random.randn()
        learner.update(w)
        means_fixed.append(learner.mu)
        means_harmonic.append(learner.mu_harmonic)

    print(f"真实均值跳变: 5.0 → 8.0 (t=250)")
    print(f"固定步长(α=0.05)在t=500时: {means_fixed[-1]:.2f}")
    print(f"调和步长(1/n)在t=500时: {means_harmonic[-1]:.2f}")
    print(f"固定步长跟踪更快，调和步长受旧数据拖累")
```

## 9-14. 简要

### 12. 学习总结
非平稳学习：固定$\alpha$替代$1/n$步长，遗忘因子$\lambda<1$替代$\lambda=1$。核心是跟踪精度和估计精度的权衡。

### 13. 练习题
**Q1**：遗忘因子$\lambda=0.99$和$\lambda=0.95$哪个跟踪突变更快？
**A1**：$\lambda=0.95$跟踪更快。有效记忆约$1/(1-\lambda)$：$\lambda=0.95$约20个样本，$\lambda=0.99$约100个样本。记忆越短跟踪越快但方差越大。
