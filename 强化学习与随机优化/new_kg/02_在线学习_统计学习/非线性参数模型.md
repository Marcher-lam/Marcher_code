# 非线性参数模型(Nonlinear Parametric Models) 学习文档

> 函数形式已知但参数需要学习的模型，介于线性模型和非参数模型之间，MLE是核心拟合工具。

> 来源线索：本节内容根据原书中关于"Nonlinear Parametric Models"的相关章节(Ch 3.8)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：非线性参数模型假设函数形式 $f(x; \theta)$ 已知，但参数 $\theta$ 需要从数据中学习，且 $f$ 关于 $\theta$ 是非线性的。

**直觉类比**：线性模型是"用直线拟合数据"，非线性参数模型则是"用已知形状的曲线拟合数据"——你知道它是指数增长、S形曲线还是多项式，但不知道具体参数。

**历史背景**：非线性回归在统计学中有悠久历史。最大似然估计(MLE)由Fisher (1922)系统化。Logistic回归是最常见的非线性参数模型。现代深度学习中的神经网络也是参数模型，但参数量巨大。

**算法定位**：在线性模型（简单但不灵活）和非参数模型（灵活但数据饥渴）之间的折中。

**前置知识**：
- 线性回归
- 最大似然估计(MLE)
- 梯度优化

## 2. 核心原理

**核心思想**：假设 $y = f(x; \theta) + \epsilon$，其中 $f$ 是已知的非线性函数族，$\theta$ 是需要学习的参数。

**常见非线性参数模型**：

1. **Logistic回归**：$P(y=1|x) = \sigma(\theta^T x) = 1/(1+e^{-\theta^T x})$
2. **多项式回归**：$y = \sum_{k=0}^{K} \theta_k x^k + \epsilon$
3. **指数模型**：$y = \theta_0 e^{\theta_1 x} + \epsilon$
4. **幂律模型**：$y = \theta_0 x^{\theta_1} + \epsilon$
5. **Sigmoid/Boltzmann**：$y = L / (1 + e^{-k(x-x_0)})$

**参数估计方法**：

- **最大似然估计(MLE)**：$\hat{\theta} = \arg\max_\theta \prod_{n=1}^{N} p(y^n | x^n; \theta)$
- **非线性最小二乘**：$\hat{\theta} = \arg\min_\theta \sum_{n=1}^{N} (y^n - f(x^n; \theta))^2$
- **迭代方法**：梯度下降、Newton-Raphson、Levenberg-Marquardt

**与线性模型的关键区别**：
- 非线性模型可能有多个局部最优
- 参数初始化更重要
- 梯度计算需要链式法则

**在策略设计中的应用**：
- 策略函数近似(PFA)：$X^\pi(s) = f(s; \theta)$
- 非线性决策规则：比线性规则更灵活，但参数更难优化

## 3. Python 实现

```python
import numpy as np
from scipy.optimize import minimize

def logistic_model(theta, X):
    """Logistic回归模型"""
    z = X @ theta
    return 1 / (1 + np.exp(-z))

def negative_log_likelihood(theta, X, y):
    """负对数似然"""
    p = logistic_model(theta, X)
    p = np.clip(p, 1e-10, 1 - 1e-10)
    return -np.sum(y * np.log(p) + (1 - y) * np.log(1 - p))

# 示例：Logistic回归
np.random.seed(42)
n = 200
X = np.random.randn(n, 2)
true_theta = np.array([1.0, -0.5])
prob = 1 / (1 + np.exp(-(X @ true_theta)))
y = (np.random.rand(n) < prob).astype(float)

X_with_intercept = np.column_stack([np.ones(n), X])
result = minimize(negative_log_likelihood, np.zeros(3),
                  args=(X_with_intercept, y), method='L-BFGS-B')
print(f"真实参数: [0, {true_theta}]")
print(f"估计参数: {np.round(result.x, 3)}")
```

## 4. 与其他方法的关系

| 方法 | 关系 |
|---|---|
| 线性模型 | 非线性模型的特例 |
| 神经网络 | 多层复合的非线性参数模型 |
| 非参数模型 | 不假设函数形式，更灵活 |
| 策略梯度 | 用非线性参数模型表示策略 |
