# 局部多项式回归(Local Polynomial Regression) 学习文档

> 在每个预测点局部拟合多项式，是核回归的改进版，修正边界偏倚。

> 来源线索：本节内容根据原书中关于"Local Polynomial Regression"的相关章节(Ch 3.10.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：局部多项式回归在每个查询点附近用加权最小二乘拟合一个低阶多项式，解决了核回归的边界偏差问题。

**直觉类比**：核回归在每个点做加权平均（局部常数），而局部多项式回归做加权线性/二次拟合（局部趋势）。就像看股票图——核回归只看最近几天的均价，局部多项式还考虑趋势方向。

**历史背景**：局部多项式回归由Cleveland (1979)的LOWESS/LOESS方法推广。它自动修正核回归的边界偏差。

**算法定位**：非参数学习/回归。是核回归的改进版。

**前置知识**：核回归、线性回归、加权最小二乘。

## 2-3. 核心原理与公式

### 局部线性回归

在查询点$x$处，求解加权最小二乘：

$$\min_{\beta_0, \beta_1} \sum_{i=1}^N K_h(x-x_i)(y_i - \beta_0 - \beta_1(x_i-x))^2$$

矩阵形式：$\hat{\beta} = (X^TWX)^{-1}X^TWy$

其中$W = \text{diag}(K_h(x-x_i))$，$X = [1, x_i-x]$。

### 预测

$\hat{f}(x) = \hat{\beta}_0$（即局部截距）

### 边界修正

核回归在边界处偏倚大（只有一侧数据），局部线性回归通过拟合局部斜率自动修正。

### 带宽选择

与核回归相同，用交叉验证选择$h$。LOO-CV有快速算法（不影响矩阵求逆的leave-one-out）。

## 4-8. 核心实现

```python
"""局部多项式回归：局部线性和局部二次"""
import numpy as np

class LocalPolynomialRegression:
    """局部多项式回归"""
    def __init__(self, bandwidth=1.0, degree=1):
        self.h = bandwidth
        self.degree = degree  # 1=线性, 2=二次

    def fit_predict(self, X_train, y_train, X_query):
        """拟合并预测（无状态——每次查询重新拟合）"""
        X_train, y_train = np.array(X_train), np.array(y_train)
        X_query = np.array(X_query)
        preds = []
        for x in X_query:
            # 计算权重
            u = (X_train - x) / self.h
            weights = np.exp(-0.5 * u**2)  # 高斯核
            # 构建设计矩阵
            if self.degree == 1:
                X_design = np.column_stack([np.ones(len(X_train)), X_train - x])
            else:
                X_design = np.column_stack([np.ones(len(X_train)),
                                           X_train - x,
                                           (X_train - x)**2])
            W = np.diag(weights)
            XtWX = X_design.T @ W @ X_design
            try:
                beta = np.linalg.solve(XtWX, X_design.T @ W @ y_train)
            except np.linalg.LinAlgError:
                beta = np.linalg.lstsq(XtWX, X_design.T @ W @ y_train, rcond=None)[0]
            preds.append(beta[0])  # 截距即为预测值
        return np.array(preds)

if __name__ == "__main__":
    np.random.seed(42)
    n = 200
    X = np.sort(np.random.uniform(0, 2*np.pi, n))
    y = np.sin(X) + 0.2 * np.random.randn(n)

    lpr = LocalPolynomialRegression(bandwidth=0.5, degree=1)
    y_pred = lpr.fit_predict(X, y, X)
    mse = np.mean((y - y_pred)**2)
    print(f"局部线性回归 MSE: {mse:.4f}")

    # 边界处表现更好
    boundary_idx = (X < 0.5) | (X > 5.5)
    print(f"边界区域MSE: {np.mean((y[boundary_idx]-y_pred[boundary_idx])**2):.4f}")
```

## 9-14. 简要

### 12. 学习总结
局部多项式回归：$\min_\beta \sum K_h(x-x_i)(y_i - \beta^T(x_i-x))^2$。自动修正边界偏差，是核回归的升级版。

### 13. 练习题
**Q1**：degree=0的局部多项式回归退化为？
**A1**：Nadaraya-Watson核回归（局部常数拟合）。
