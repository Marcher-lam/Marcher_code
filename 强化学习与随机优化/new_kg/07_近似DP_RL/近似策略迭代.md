## 1-3. 核心认知与公式

**一句话定义**：近似策略迭代(API)用近似方法替代精确PE和PI，交替执行近似评估和近似改进。

**算法**：
1. **近似策略评估**：用TD/VFA/LSTD估计$Q^{\pi_k}$
2. **近似策略改进**：$\pi_{k+1}(s) = \arg\max_a \bar{Q}(s,a|\theta)$
3. 重复直到策略收敛

**误差界**：即使每步有$\epsilon$的近似误差，API的最终策略值与最优值的差距为$O(\epsilon/(1-\gamma)^2)$。

## 4-8. 核心实现

```python
"""近似策略迭代"""
import numpy as np

class ApproxPI:
    def __init__(self, n_states, n_actions, gamma=0.95):
        self.nS, self.nA = n_states, n_actions
        self.gamma = gamma
        self.Q = np.zeros((n_states, n_actions))
        self.pi = np.zeros(n_states, dtype=int)

    def evaluate(self, trans_fn, reward_fn, n_episodes=200):
        """近似策略评估：蒙特卡洛"""
        returns = [[[] for _ in range(self.nA)] for _ in range(self.nS)]
        for _ in range(n_episodes):
            s = np.random.randint(self.nS)
            for step in range(50):
                a = self.pi[s]
                s_next = trans_fn(s, a)
                r = reward_fn(s, a, s_next)
                returns[s][a].append(r + self.gamma * self.Q[s_next, self.pi[s_next]])
                s = s_next
                if s == self.nS - 1: break
        for s in range(self.nS):
            for a in range(self.nA):
                if returns[s][a]:
                    self.Q[s, a] = np.mean(returns[s][a])

    def improve(self):
        """策略改进"""
        self.pi = np.argmax(self.Q, axis=1)

    def solve(self, trans_fn, reward_fn, n_iters=10):
        for it in range(n_iters):
            self.evaluate(trans_fn, reward_fn)
            old_pi = self.pi.copy()
            self.improve()
            if np.array_equal(old_pi, self.pi):
                print(f"API收敛于迭代{it+1}")
                break
        return self.pi

if __name__ == "__main__":
    np.random.seed(42)
    trans = lambda s, a: np.random.randint(16)
    reward = lambda s, a, s2: 1.0 if s2 == 15 else -0.01
    api = ApproxPI(16, 4)
    pi = api.solve(trans, reward, n_iters=10)
    print(f"API策略: {pi}")
```

## 9-14. 简要

### 12. 学习总结
近似PI：交替执行近似PE（TD/MC/VFA）和近似PI（$\arg\max Q$）。误差界$O(\epsilon/(1-\gamma)^2)$保证近似质量。

### 13. 练习题
**Q1**：API可能收敛到次优策略吗？
**A1**：是的。近似误差可能导致策略改进不单调（LIPO条件不满足）。实践中通常仍能找到好策略。
