# 直接策略评估(Direct Policy Evaluation) 学习文档

> 给定一个策略，直接计算其值函数——是策略迭代和策略改进的基础。

> 来源线索：本节内容根据原书中关于"Direct Policy Evaluation"的相关章节(Ch 16.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：直接策略评估计算给定策略π下每个状态的期望累计奖励 $V^\pi(s)$，是"给定策略，评估它有多好"的过程。

## 2. 核心原理

**有限Horizon**：通过模拟直接计算
$$V^\pi(s_0) = E\left[\sum_{t=0}^{T} \gamma^t r(s_t, \pi(s_t)) | s_0\right]$$

**无限Horizon**：求解Bellman方程（线性方程组）
$$V^\pi(s) = r(s, \pi(s)) + \gamma \sum_{s'} P(s'|s,\pi(s)) V^\pi(s')$$

**蒙特卡洛策略评估**：通过多次模拟取平均
$$V^\pi(s) \approx \frac{1}{N} \sum_{n=1}^{N} G^n(s)$$

**时序差分(TD)评估**：用自举(bootstrap)更新
$$V(s_t) \leftarrow V(s_t) + \alpha [r_{t+1} + \gamma V(s_{t+1}) - V(s_t)]$$

**部分模拟**：不模拟完整轨迹，截断后用近似值替代。

## 3. Python 实现

```python
import numpy as np

def monte_carlo_evaluation(env, policy, n_episodes=1000, gamma=0.9):
    """蒙特卡洛策略评估"""
    returns = {}

    for _ in range(n_episodes):
        state = env.reset()
        episode = []
        done = False
        while not done:
            action = policy[state]
            next_state, reward, done = env.step(action)
            episode.append((state, reward))
            state = next_state

        G = 0
        for t in range(len(episode)-1, -1, -1):
            s, r = episode[t]
            G = r + gamma * G
            if s not in returns:
                returns[s] = []
            returns[s].append(G)

    V = {s: np.mean(r) for s, r in returns.items()}
    return V

def td_evaluation(env, policy, n_steps=10000, alpha=0.1, gamma=0.9):
    """TD(0)策略评估"""
    V = {}
    state = env.reset()
    for _ in range(n_steps):
        action = policy[state]
        next_state, reward, done = env.step(action)
        if state not in V: V[state] = 0
        if next_state not in V: V[next_state] = 0
        V[state] += alpha * (reward + gamma * V[next_state] - V[state])
        state = next_state if not done else env.reset()
    return V
```

## 4. 与其他方法的关系

- **蒙特卡洛**：无偏但方差大
- **TD学习**：有偏但方差小
- **策略迭代**：评估+改进循环
