# 线性模型近似值迭代(Approximate VI with Linear Models) 学习文档

> 用线性函数近似值函数，使值迭代适用于大状态空间——收敛性需要特殊条件。

> 来源线索：本节内容根据原书中关于"Approximate Value Iteration Using Linear Models"的相关章节(Ch 16.5, 17.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：用线性模型 $\bar{V}(s|\theta) = \phi(s)^T\theta$ 近似值函数，将Bellman递推转化为参数更新。

## 2. 核心原理

**线性值函数近似**：
$$\bar{V}(s|\theta) = \sum_{k=1}^{K} \theta_k \phi_k(s)$$

**近似Bellman更新**：
1. 计算目标值：$\hat{v}^n = \max_a [r(s^n, a) + \gamma \bar{V}(s'^n|\theta^n)]$
2. 更新参数：$\theta^{n+1} = \theta^n + \alpha_n (\hat{v}^n - \phi(s^n)^T\theta^n) \phi(s^n)$

**几何视角**：线性近似在高维特征空间中投影Bellman备份的结果。

**收敛性**：
- 带线性近似的值迭代**不一定收敛**
- 需要特殊的步长条件和特征选择
- $1/n$ 步长保证收敛到误差 $O(1/\sqrt{n})$

**与查找表方法的对比**：
- 查找表：每个状态独立，精确
- 线性模型：跨状态泛化，近似但高效

## 3. Python 实现

```python
import numpy as np

def approximate_vi_linear(transitions, features, R, gamma=0.9, n_iter=1000, alpha=0.01):
    """线性模型近似值迭代"""
    n_states, n_features = features.shape
    n_actions = R.shape[1]
    theta = np.zeros(n_features)

    for iteration in range(n_iter):
        theta_new = theta.copy()
        for s in range(n_states):
            # 对每个动作计算Q值
            Q = np.zeros(n_actions)
            for a in range(n_actions):
                next_vals = np.array([features[s2] @ theta for s2 in range(n_states)])
                Q[a] = R[s, a] + gamma * transitions[a][s] @ next_vals
            target = Q.max()
            pred = features[s] @ theta
            theta_new += alpha * (target - pred) * features[s]

        if np.linalg.norm(theta_new - theta) < 1e-6:
            break
        theta = theta_new

    return theta, features @ theta

# 示例
n_states, n_actions, n_features = 10, 2, 3
features = np.random.randn(n_states, n_features)
R = np.random.rand(n_states, n_actions)
P = [np.random.dirichlet(np.ones(n_states)) for _ in range(n_actions)]
P = [np.tile(p, (n_states, 1)) for p in P]

theta, V = approximate_vi_linear(P, features, R)
print(f"值函数: {np.round(V, 3)}")
```

## 4. 与其他方法的关系

- **LSTD/LSPE**：用最小二乘法拟合线性值函数
- **TD(0)**：随机版本的线性近似值迭代
- **深度Q网络(DQN)**：用神经网络替代线性模型
