# 蒙特卡洛策略评估(Monte Carlo Policy Evaluation) 学习文档

> 用完整轨迹的回报平均值估计策略价值，是最直观的策略评估方法。

> 来源线索：本节内容根据原书中关于"Monte Carlo Policy Evaluation"的相关章节(Ch 16.1)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：MC策略评估运行策略多次，收集完整轨迹的回报$G_t$，取平均作为值函数估计。

**公式**：

$$V^\pi(s) = \mathbb{E}_\pi[G_t | S_t = s] \approx \frac{1}{N(s)}\sum_{i=1}^{N(s)} G_t^{(i)}(s)$$

其中$G_t = \sum_{k=0}^{T-t}\gamma^k R_{t+k+1}$。

**两种变体**：
- **首次访问MC**：只在状态$s$第一次出现时记录$G_t$
- **每次访问MC**：每次出现都记录

**增量更新**：

$$V(s) \leftarrow V(s) + \frac{1}{N(s)}[G - V(s)]$$

**与TD的区别**：MC等轨迹结束才更新（需要完整回报），TD每步更新（bootstrap）。

## 4-8. 核心实现

```python
"""蒙特卡洛策略评估"""
import numpy as np

class MCPolicyEvaluation:
    def __init__(self, n_states, gamma=0.95):
        self.nS = n_states
        self.gamma = gamma
        self.returns = {s: [] for s in range(n_states)}
        self.V = np.zeros(n_states)

    def evaluate(self, policy, trans_fn, reward_fn, n_episodes=500, max_steps=50):
        for ep in range(n_episodes):
            trajectory = []
            s = np.random.randint(self.nS)
            for step in range(max_steps):
                a = policy(s)
                s_next = trans_fn(s, a)
                r = reward_fn(s, a, s_next)
                trajectory.append((s, a, r))
                s = s_next
                if s == self.nS - 1: break

            # 计算回报并更新
            G = 0
            visited = set()
            for t in reversed(range(len(trajectory))):
                s_t = trajectory[t][0]
                G = self.gamma * G + trajectory[t][2]
                if s_t not in visited:  # 首次访问
                    self.returns[s_t].append(G)
                    self.V[s_t] = np.mean(self.returns[s_t])
                    visited.add(s_t)
        return self.V

if __name__ == "__main__":
    np.random.seed(42)
    policy = lambda s: np.random.randint(4)
    trans = lambda s, a: np.random.randint(16)
    reward = lambda s, a, s2: 1.0 if s2 == 15 else -0.01
    mcpe = MCPolicyEvaluation(16)
    V = mcpe.evaluate(policy, trans, reward, n_episodes=1000)
    print(f"MC策略评估 V(0)={V[0]:.3f}, V(15)={V[15]:.3f}")
    print(f"访问最多的状态: {np.argmax([len(v) for v in mcpe.returns.values()])}")
```

## 9-14. 简要

### 12. 学习总结
MC策略评估：$V(s) = E[G_t|S_t=s] \approx \text{avg}(G^{(i)})$。无偏但方差大，需要完整轨迹。与TD互补。

### 13. 练习题
**Q1**：MC和TD(0)各自的优缺点？
**A1**：MC无偏（用真实回报）、方差大、需要完整轨迹。TD有偏（bootstrapping）、方差小、可在线更新。MC更适合非马尔可夫环境。
