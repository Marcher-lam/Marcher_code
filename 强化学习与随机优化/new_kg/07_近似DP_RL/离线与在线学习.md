# 离线与在线学习(Offline vs Online Learning in RL) 学习文档

> 先训练后部署 vs 边用边学——两种学习范式的权衡。

> 来源线索：本节内容根据原书中关于"Offline/Online Learning"和"On-policy vs Off-policy"的相关章节(Ch 17.5)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：离线学习在部署前充分训练策略；在线学习在实际使用中持续改进策略。

## 2. 核心原理

**四种学习模式**：

| 模式 | 数据来源 | 更新时机 | 典型方法 |
|---|---|---|---|
| 离线/离策略 | 历史数据 | 部署前 | Q-learning, LSTD |
| 离线/在策略 | 模拟器 | 部署前 | REINFORCE, PPO |
| 在线/离策略 | 实际+历史 | 运行中 | Q-learning+replay |
| 在线/在策略 | 实际 | 运行中 | SARSA, TD |

**离策略学习**：可以从任何策略产生的数据中学习最优策略
- 优势：数据效率高（可重用历史数据）
- 代价：可能不稳定（ Deadly Triad ）

**在策略学习**：只能从当前策略产生的数据中学习
- 优势：理论保证更好
- 代价：数据效率低

## 3. Python 实现

```python
import numpy as np

class OfflineRL:
    """离线RL：从历史数据学习"""
    def __init__(self, n_states, n_actions):
        self.Q = np.zeros((n_states, n_actions))
        self.n_s_a = np.zeros((n_states, n_actions))

    def train_from_buffer(self, buffer, gamma=0.9, alpha=0.1):
        """从经验回放池学习"""
        for s, a, r, s2 in buffer:
            best_next = np.max(self.Q[s2])
            self.Q[s, a] += alpha * (r + gamma * best_next - self.Q[s, a])

class OnlineRL:
    """在线RL：边用边学"""
    def __init__(self, n_states, n_actions):
        self.Q = np.zeros((n_states, n_actions))
        self.eps = 0.3

    def act_and_learn(self, env, n_steps=1000, gamma=0.9, alpha=0.1):
        s = env.reset()
        for _ in range(n_steps):
            a = np.argmax(self.Q[s]) if np.random.rand() > self.eps else np.random.randint(self.Q.shape[1])
            s2, r, done = env.step(a)
            # SARSA更新（在策略）
            a2 = np.argmax(self.Q[s2]) if np.random.rand() > self.eps else np.random.randint(self.Q.shape[1])
            self.Q[s, a] += alpha * (r + gamma * self.Q[s2, a2] - self.Q[s, a])
            s, a = s2, a2
            if done: s = env.reset()
```

## 4. 与其他方法的关系

- **经验回放**：使离策略学习更高效
- **SARSA vs Q-learning**：在策略vs离策略的对比
- **模拟器训练**：最安全的离线学习方式
