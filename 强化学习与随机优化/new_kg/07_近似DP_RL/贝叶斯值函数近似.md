## 1-3. 核心认知与公式

**一句话定义**：贝叶斯VFA对值函数参数$\theta$维护后验分布$p(\theta|D)$而非点估计，提供不确定性量化和原则性探索。

**与频率学派VFA的区别**：
- 频率学派：$\hat{\theta}$是点估计，无不确定性信息
- 贝叶斯：$\theta \sim N(\bar{\theta}, \Sigma)$，有均值和协方差

**线性模型贝叶斯VFA**：

$$V(s|\theta) = \theta^T\phi(s), \quad \theta \sim N(\bar{\theta}, \Sigma)$$

更新（线性高斯模型）：

$$\Sigma^{n+1} = \left[(\Sigma^n)^{-1} + \frac{\phi(s^n)\phi(s^n)^T}{\sigma_\epsilon^2}\right]^{-1}$$
$$\bar{\theta}^{n+1} = \Sigma^{n+1}\left[(\Sigma^n)^{-1}\bar{\theta}^n + \frac{\phi(s^n)}{\sigma_\epsilon^2}(r^n + \gamma V(s^{n+1}|\bar{\theta}^n))\right]$$

**应用**：贝叶斯探索（UCB用后验标准差）、贝叶斯优化、主动学习。

## 4-8. 核心实现

```python
"""贝叶斯值函数近似"""
import numpy as np

class BayesianVFA:
    def __init__(self, n_features, sigma_eps=1.0, prior_std=10.0):
        self.n_f = n_features
        self.theta = np.zeros(n_features)
        self.Sigma = np.eye(n_features) * prior_std**2
        self.sigma_eps = sigma_eps

    def features(self, s):
        return np.array([1.0, s/16, (s/16)**2])

    def predict(self, s):
        phi = self.features(s)
        mean = phi @ self.theta
        std = np.sqrt(phi @ self.Sigma @ phi)
        return mean, std

    def update(self, s, r, s_next, gamma=0.95):
        phi = self.features(s)
        phi_next = self.features(s_next)
        target = r + gamma * (phi_next @ self.theta)
        # Bayesian linear regression update
        Sigma_inv_old = np.linalg.inv(self.Sigma)
        Sigma_new_inv = Sigma_inv_old + np.outer(phi, phi) / self.sigma_eps**2
        self.Sigma = np.linalg.inv(Sigma_new_inv)
        self.theta = self.Sigma @ (Sigma_inv_old @ self.theta + phi * target / self.sigma_eps**2)

if __name__ == "__main__":
    np.random.seed(42)
    bvfa = BayesianVFA(n_features=3)
    for ep in range(500):
        s = np.random.randint(16)
        s_next = np.random.randint(16)
        r = 1.0 if s_next == 15 else -0.01
        bvfa.update(s, r, s_next)
    print("贝叶斯VFA估计:")
    for s in [0, 5, 10, 15]:
        mean, std = bvfa.predict(s)
        print(f"  V({s}) = {mean:.3f} ± {std:.3f}")
```

## 9-14. 简要

### 12. 学习总结
贝叶斯VFA：$\theta \sim N(\bar{\theta}, \Sigma)$。提供值函数的后验分布，量化估计不确定性，支持贝叶斯探索策略。

### 13. 练习题
**Q1**：贝叶斯VFA如何指导探索？
**A1**：后验标准差大的状态说明估计不确定，值得多访问。UCB策略用$\bar{V}(s) + c\cdot\sigma(s)$选择动作——不确定性大的状态获得探索奖励。
