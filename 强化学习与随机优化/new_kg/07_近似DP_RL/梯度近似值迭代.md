# 梯度近似值迭代(Gradient-based Approximate VI) 学习文档

> 用梯度下降最小化Bellman误差来更新VFA参数，是TD/LSTD之外的第三条VFA训练路径。

> 来源线索：本节内容根据原书中关于"Gradient-based Methods for Approximate Value Iteration"的相关章节(Ch 16.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：梯度近似值迭代将Bellman误差$\delta = r + \gamma V(s') - V(s)$视为损失函数，用随机梯度下降更新值函数参数$\theta$，区别于TD的固定步长和LSTD的直接求解。

**算法定位**：近似DP/值函数近似。是TD(0)、LSTD、LSPE之外的第三种VFA训练方法。

**前置知识**：值函数近似、TD学习、SGD。

## 2. 核心原理

**核心思想**：定义Bellman误差的均方值作为损失函数，对其求梯度并做SGD更新。

$$J(\theta) = \mathbb{E}_\pi\left[\left(r + \gamma V(s'|\theta) - V(s|\theta)\right)^2\right]$$

梯度更新：

$$\theta \leftarrow \theta - \alpha \nabla_\theta J(\theta)$$

**与TD(0)的关键区别**：TD(0)更新方向是$\delta \nabla V(s)$，梯度方法考虑了目标$V(s')$对$\theta$的依赖（full gradient），而TD(0)忽略了这一点（semi-gradient）。

**与LSTD的区别**：LSTD直接求解$\theta = A^{-1}b$（一步到位），梯度方法迭代逼近（但更灵活，可用各种优化器）。

## 3. 数学公式

### 半梯度TD(0)（标准TD）

$$\theta \leftarrow \theta + \alpha \left[r + \gamma \theta^T\phi(s') - \theta^T\phi(s)\right]\phi(s)$$

注意：只对$V(s)$求梯度，忽略$V(s')$对$\theta$的依赖。

### 全梯度方法

$$\theta \leftarrow \theta + \alpha \delta \left[\phi(s) - \gamma \phi(s')\right]$$

考虑了$\nabla_\theta V(s') = \gamma \phi(s')$的影响。收敛更稳定，但方差略大。

### 残差梯度方法（Residual Gradient）

$$\theta \leftarrow \theta - \alpha \delta^2 / 2$$

最小化Bellman误差的平方，保证收敛但可能有偏。

## 4-8. 核心实现

```python
"""梯度近似值迭代：半梯度 vs 全梯度 vs 残差梯度"""
import numpy as np

class GradientApproxVI:
    def __init__(self, n_features, lr=0.01, gamma=0.95, method='full'):
        self.theta = np.random.randn(n_features) * 0.01
        self.lr = lr
        self.gamma = gamma
        self.method = method

    def V(self, phi):
        return self.theta @ phi

    def update(self, phi_s, r, phi_s_next):
        delta = r + self.gamma * self.V(phi_s_next) - self.V(phi_s)

        if self.method == 'semi':  # TD(0)风格
            grad = delta * phi_s
        elif self.method == 'full':  # 全梯度
            grad = delta * (phi_s - self.gamma * phi_s_next)
        elif self.method == 'residual':  # 残差梯度
            grad = delta * (phi_s - self.gamma * phi_s_next)

        self.theta += self.lr * grad
        return abs(delta)

if __name__ == "__main__":
    np.random.seed(42)
    def phi(s):
        return np.array([1.0, s/16, (s/16)**2])

    results = {}
    for method in ['semi', 'full', 'residual']:
        agent = GradientApproxVI(n_features=3, lr=0.005, method=method)
        total_err = 0
        for ep in range(1000):
            s = np.random.randint(16)
            s_next = np.random.randint(16)
            r = 1.0 if s_next == 15 else -0.01
            total_err += agent.update(phi(s), r, phi(s_next))
        results[method] = total_err / 1000
        print(f"{method:10s}: 平均TD误差={results[method]:.4f}, θ={agent.theta.round(3)}")
```

## 9-14. 简要

### 12. 学习总结
梯度近似VI：$\theta \leftarrow \theta + \alpha\delta[\phi(s) - \gamma\phi(s')]$。全梯度考虑目标对$\theta$的依赖，比半梯度(TD)更稳定，比LSTD更灵活。

### 13. 练习题
**Q1**：为什么半梯度(TD)在实践中比全梯度更常用？
**A1**：半梯度更新简单$\delta\phi(s)$，计算量小。全梯度需要额外计算$\gamma\phi(s')$，方差更大。尽管半梯度理论上收敛性稍弱，但在实践中配合合适步长效果很好。
