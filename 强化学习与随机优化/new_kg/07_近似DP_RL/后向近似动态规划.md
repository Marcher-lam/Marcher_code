## 1-3. 核心认知与公式

**一句话定义**：后向ADP用采样路径替代精确期望计算，用VFA替代查表值函数，实现可扩展的后向DP。

**与精确DP的区别**：
- 精确DP：$V_t(s) = \mathbb{E}[\max_a C(s,a) + V_{t+1}(S')|s]$，遍历所有状态
- 后向ADP：用$N$条采样路径近似期望，用$\bar{V}_t(s|\theta)$替代$V_t(s)$

**算法流程**：
1. 从终止时刻$T$开始后向
2. 生成$N$条采样路径
3. 对每个时间步$t$，用样本估计值函数
4. 用回归/神经网络拟合$\bar{V}_t(s|\theta)$
5. 用拟合的值函数指导前一步的决策

**核心优势**：避免状态枚举（精确DP的维度灾难），用采样+近似处理大规模问题。

## 4-8. 核心实现

```python
"""后向近似动态规划"""
import numpy as np

class BackwardADP:
    def __init__(self, n_states, T, gamma=0.95, n_samples=100):
        self.nS = n_states
        self.T = T
        self.gamma = gamma
        self.N = n_samples
        self.V_hat = np.zeros((T+1, n_states))

    def solve(self, transition_fn, reward_fn):
        # 终止条件：V_T = 0
        for t in range(self.T-1, -1, -1):
            for s in range(self.nS):
                values = []
                for a in range(4):  # 4个动作
                    # 蒙特卡洛采样估计 Q(s,a)
                    q_samples = []
                    for _ in range(self.N):
                        s_next = transition_fn(s, a)
                        r = reward_fn(s, a, s_next)
                        q_samples.append(r + self.gamma * self.V_hat[t+1, s_next])
                    values.append(np.mean(q_samples))
                self.V_hat[t, s] = max(values)
        return self.V_hat

if __name__ == "__main__":
    np.random.seed(42)
    trans = lambda s, a: np.random.randint(16)
    reward = lambda s, a, s2: 1.0 if s2 == 15 else -0.01
    adp = BackwardADP(n_states=16, T=10, n_samples=50)
    V = adp.solve(trans, reward)
    print(f"V_0(0)={V[0,0]:.3f}, V_0(15)={V[0,15]:.3f}")
```
