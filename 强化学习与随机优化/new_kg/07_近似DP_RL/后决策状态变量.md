> 在决策后、观测前捕获系统状态，是ADP降低计算维度的关键技术。

> 来源线索：本节内容根据原书中关于"Post-decision State Variable"的相关章节(Ch 9.5)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：后决策状态$S_t^{x,a}$是在时刻$t$做决策$x_t$后、观测新信息$W_{t+1}$前的系统状态，它将期望计算从决策空间转移到状态空间。

**定义**：

$$S_t^{x,a} = S^x(S_t, x_t)$$

是$S_t$和$x_t$的确定性函数。完整状态转移为：

$$S_t \xrightarrow{x_t} S_t^{x,a} \xrightarrow{W_{t+1}} S_{t+1}$$

**核心价值**：

标准Bellman方程：$V(S_t) = \max_{x_t}\{C(S_t,x_t) + \mathbb{E}[V(S_{t+1})|S_t]\}$

后决策版本：$V(S_t) = \max_{x_t}\{C(S_t,x_t) + V^{x,a}(S_t^{x,a})\}$

关键区别：$\mathbb{E}[V(S_{t+1})]$需要对所有可能的$W_{t+1}$求期望，而$V^{x,a}(S_t^{x,a})$是确定性函数——**不需要期望计算**。

**应用**：
- Q-learning中的$Q(s,a)$就是后决策状态的值函数
- 资源分配中，后决策状态简化了值函数的维度

## 4-8. 核心实现

```python
"""后决策状态变量：在ADP中的应用"""
import numpy as np

class PostDecisionADP:
    def __init__(self, max_resource=50, gamma=0.95):
        self.max_R = max_resource
        self.gamma = gamma
        self.V_pre = np.zeros(max_resource + 1)    # 前决策值函数
        self.V_post = np.zeros(max_resource + 1)    # 后决策值函数

    def post_decision_state(self, R, x):
        """后决策状态：决策后的资源水平"""
        return min(max(R - x, 0), self.max_R)

    def update(self, R, x, demand, lr=0.1):
        """用后决策状态更新值函数"""
        sold = min(R, demand)
        reward = 10 * sold - 6 * x
        R_post = self.post_decision_state(R, x)
        R_next = min(R_post + x, self.max_R)  # 简化转移
        # 后决策更新：不需要期望！
        td_target = reward + self.gamma * self.V_pre[R_next]
        self.V_post[R_post] += lr * (td_target - self.V_post[R_post])

if __name__ == "__main__":
    np.random.seed(42)
    adp = PostDecisionADP(max_resource=30)
    for ep in range(2000):
        R = np.random.randint(0, 30)
        x = np.random.randint(0, max(1, 30-R))
        demand = np.random.poisson(10)
        adp.update(R, x, demand)
    print("后决策值函数 V^post (部分):")
    for r in [0, 5, 10, 20, 30]:
        print(f"  R_post={r}: V={adp.V_post[r]:.2f}")
```

## 9-14. 简要

### 12. 学习总结
后决策状态$S_t^{x,a}$：决策后、观测前的确定性状态。将$\mathbb{E}[V(S')]$转化为$V^{x,a}(S^{x,a})$，消除期望计算。

### 13. 练习题
**Q1**：为什么后决策状态能降低计算量？
**A1**：标准方法需要对随机变量$W$的所有可能取值求期望。后决策状态将期望推迟到下一步——当前步只需查询确定性值函数$V^{x,a}$，避免了即时期望计算。
