# 核回归(Kernel Regression) 学习文档

> 用距离加权的邻居值进行预测，是KNN的光滑化版本。

> 来源线索：本节内容根据原书中关于"Kernel Regression"的相关章节(Ch 3.10.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：核回归用核函数对训练样本加权平均，距离越近的样本权重越大，实现非参数的平滑回归。

**直觉类比**：预测明天的气温。你收集了过去每天的气温数据。核回归的做法是：离明天越近的历史数据权重越大（最近几天的权重高，上个月的数据权重低），用加权平均来预测。核函数决定了权重随距离衰减的速率。

**历史背景**：Nadaraya (1964)和Watson (1964)独立提出核回归估计量。它是非参数统计的基石方法。

**算法定位**：非参数学习/回归。在原书Ch 3.10.2中作为查表模型的平滑化替代引入。

**前置知识**：KNN、距离度量、核函数。

## 2. 核心原理

**核心思想**：KNN用"是否在K个最近邻中"做硬划分，核回归用核函数做软加权——每个训练样本都有贡献，但距离越远贡献越小。

Nadaraya-Watson估计量：

$$\hat{f}(x) = \frac{\sum_{i=1}^N K_h(x - x_i) y_i}{\sum_{i=1}^N K_h(x - x_i)}$$

其中$K_h(u) = K(u/h)/h$是带宽为$h$的核函数。

**常用核函数**：
- 高斯核：$K(u) = \frac{1}{\sqrt{2\pi}}e^{-u^2/2}$
- Epanechnikov核：$K(u) = \frac{3}{4}(1-u^2)\mathbb{I}(|u| \leq 1)$

## 3. 数学公式与推导

### Nadaraya-Watson估计量

$$\hat{f}(x) = \sum_{i=1}^N w_i(x) y_i, \quad w_i(x) = \frac{K_h(x-x_i)}{\sum_j K_h(x-x_j)}$$

### 带宽选择

带宽$h$是最关键的参数：
- $h$太小：过拟合（每个点几乎是它自己）
- $h$太大：欠拟合（退化为全局均值）
- 通常用交叉验证选择最优$h$

### 偏差-方差

MSE = 偏差² + 方差。当$h$增大，偏差增大但方差减小。

## 4-8. 核心实现

```python
"""核回归：Nadaraya-Watson估计"""
import numpy as np

class KernelRegression:
    """Nadaraya-Watson核回归"""
    def __init__(self, bandwidth=1.0, kernel='gaussian'):
        self.h = bandwidth
        self.kernel = kernel

    def _K(self, u):
        """核函数"""
        if self.kernel == 'gaussian':
            return np.exp(-0.5 * u**2) / np.sqrt(2*np.pi)
        elif self.kernel == 'epanechnikov':
            return np.where(np.abs(u) <= 1, 0.75*(1-u**2), 0.0)

    def fit(self, X, y):
        self.X_train = np.array(X)
        self.y_train = np.array(y)
        return self

    def predict(self, X):
        X = np.array(X)
        preds = []
        for x in X:
            u = np.abs(self.X_train - x) / self.h
            if self.X_train.ndim > 1:
                u = np.linalg.norm(self.X_train - x, axis=1) / self.h
            weights = self._K(u)
            w_sum = weights.sum()
            if w_sum < 1e-10:
                preds.append(self.y_train.mean())
            else:
                preds.append((weights @ self.y_train) / w_sum)
        return np.array(preds)

    def cross_validate(self, X, y, h_range, k_folds=5):
        """K折交叉验证选择带宽"""
        best_h, best_mse = h_range[0], np.inf
        n = len(X)
        indices = np.arange(n)
        np.random.shuffle(indices)
        fold_size = n // k_folds

        for h in h_range:
            self.h = h
            mses = []
            for fold in range(k_folds):
                val_idx = indices[fold*fold_size:(fold+1)*fold_size]
                train_idx = np.setdiff1d(indices, val_idx)
                self.fit(X[train_idx], y[train_idx])
                y_pred = self.predict(X[val_idx])
                mses.append(np.mean((y[val_idx] - y_pred)**2))
            avg_mse = np.mean(mses)
            if avg_mse < best_mse:
                best_mse = avg_mse
                best_h = h
        self.h = best_h
        return best_h

if __name__ == "__main__":
    np.random.seed(42)
    n = 200
    X = np.sort(np.random.uniform(0, 10, n))
    y = np.sin(X) + 0.3 * np.random.randn(n)

    kr = KernelRegression()
    best_h = kr.cross_validate(X, y, h_range=[0.1, 0.3, 0.5, 0.8, 1.0, 2.0])
    kr.fit(X, y)
    y_pred = kr.predict(X)
    mse = np.mean((y - y_pred)**2)
    print(f"最优带宽 h={best_h}, MSE={mse:.4f}")
```

## 9-14. 简要

### 12. 学习总结
核回归：$\hat{f}(x) = \sum w_i y_i$，$w_i = K_h(x-x_i)/\sum K_h$。带宽$h$控制平滑度，CV选择最优$h$。

### 13. 练习题
**Q1**：核回归和KNN的主要区别是什么？
**A1**：KNN用固定K个邻居等权平均（硬边界），核回归用所有样本的核函数加权平均（软边界）。核回归的带宽$h$类似于KNN的$K$，但核回归更光滑。
