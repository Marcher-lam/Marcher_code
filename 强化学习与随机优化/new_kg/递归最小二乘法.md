# 递归最小二乘法(Recursive Least Squares) 学习文档

> 递归最小二乘法在线更新参数估计，不需要存储历史数据，是自适应滤波和在线学习的核心算法。

> 来源线索：本节内容根据原书中关于"Recursive Least Squares for Linear Models"的相关章节(Ch 3.8)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：递归最小二乘法（RLS）在新数据到来时增量更新参数估计，利用Sherman-Morrison公式避免重复计算矩阵逆，实现$O(p^2)$的在线更新。

**直觉类比**：你用一个公式预测房价，已有1000条数据。普通最小二乘需要重新计算整个矩阵求逆。RLS则像"追加更新"——只需用新数据和之前的中间结果，几步运算就能得到和重新计算完全相同的结果。

**历史背景**：RLS由Plackett (1950)系统发展，是Kalman滤波（1960）的静态参数特例。在信号处理、自适应控制和在线学习中广泛应用。

**算法定位**：在线学习/参数估计方法。在原书Ch 3.8中，RLS是在线线性模型参数估计的标准工具。

**前置知识**：线性回归、矩阵运算、指数平滑。

## 2. 核心原理

**核心思想**：批量最小二乘$\hat{\theta} = (X^TX)^{-1}X^Ty$需要所有数据。RLS利用Sherman-Morrison公式将矩阵逆的更新变为增量操作：$M^{n+1} = M^n - \frac{M^n x^{n+1}(x^{n+1})^T M^n}{1+(x^{n+1})^T M^n x^{n+1}}$。

**更新公式**：

$$\hat{\theta}^{n+1} = \hat{\theta}^n + \frac{M^n x^{n+1}}{1 + (x^{n+1})^T M^n x^{n+1}}(y^{n+1} - (x^{n+1})^T \hat{\theta}^n)$$

其中$M^n = (X^TX)^{-1}$是精度矩阵的估计。

## 3. 数学公式与推导

### 静态数据RLS

精度矩阵更新（Sherman-Morrison）：

$$M^{n+1} = M^n - \frac{M^n x^{n+1}(x^{n+1})^T M^n}{1 + (x^{n+1})^T M^n x^{n+1}}$$

参数更新：

$$\hat{\theta}^{n+1} = \hat{\theta}^n + M^{n+1} x^{n+1}(y^{n+1} - (x^{n+1})^T \hat{\theta}^n)$$

### 非平稳数据RLS

引入遗忘因子$\lambda \in (0,1]$：

$$M^{n+1} = \frac{1}{\lambda}\left(M^n - \frac{M^n x^{n+1}(x^{n+1})^T M^n}{\lambda + (x^{n+1})^T M^n x^{n+1}}\right)$$

$\lambda<1$使旧数据权重衰减，适合跟踪时变参数。

### 与指数平滑的关系

当$p=1$时，RLS退化为指数平滑。

### 超参数

### 应用

2. 在线系统辨识

## 7-8. 实现

```python
"""递归最小二乘法"""
import numpy as np

class RecursiveLeastSquares:
    def __init__(self, n_features, forgetting_factor=1.0, delta=100.0):
        self.theta = np.zeros(n_features)
        self.M = np.eye(n_features) * delta  # 精度矩阵初始值
        self.lam = forgetting_factor

    def update(self, x, y):
        x = np.asarray(x)
        Mx = self.M @ x
        denom = self.lam + x @ Mx
        k = Mx / denom  # 增益向量
        error = y - x @ self.theta
        self.theta = self.theta + k * error
        self.M = (self.M - np.outer(k, x @ self.M)) / self.lam
        return self.theta.copy(), error

if __name__ == "__main__":
    np.random.seed(42)
    n, p = 500, 3
    X = np.random.randn(n, p)
    true_theta = np.array([2.0, -1.0, 0.5])
    y = X @ true_theta + 0.1 * np.random.randn(n)

    rls = RecursiveLeastSquares(p, forgetting_factor=0.99)
    for i in range(n):
        theta, err = rls.update(X[i], y[i])

    print(f"真实系数: {true_theta}")
    print(f"RLS估计: {rls.theta.round(3)}")
    print(f"误差范数: {np.linalg.norm(rls.theta - true_theta):.4f}")

    # 与批量解比较
    theta_batch = np.linalg.lstsq(X, y, rcond=None)[0]
    print(f"批量解:   {theta_batch.round(3)}")
```

## 9-14. 简要

### 12. 学习总结
RLS：$\theta^{n+1} = \theta^n + M^{n+1}x^{n+1}(y^{n+1}-x^{n+1}\theta^n)$，$M$用Sherman-Morrison增量更新。在线等价于批量最小二乘。

### 13. 练习题
**Q1**：RLS与SGD的核心区别是什么？
**A1**：SGD用固定步长，RLS用自适应增益$M^{n+1}x^{n+1}$（近似二阶信息）。RLS收敛更快但$O(p^2)$（SGD是$O(p)$）。
