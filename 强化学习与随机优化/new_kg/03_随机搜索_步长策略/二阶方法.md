# 二阶方法(Second-Order Methods) 学习文档

> 利用二阶导数（Hessian）信息加速收敛，是牛顿法的随机优化扩展。

> 来源线索：本节内容根据原书中关于"Second-Order Methods"的相关章节(Ch 5.4.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：二阶方法利用Hessian矩阵（或其近似）的曲率信息调整步长和方向，比SGD收敛更快。

**直觉类比**：SGD像一个只看脚下坡度的行者，步长固定。二阶方法像一个拿着地形图的行者，知道坡度的变化率（曲率），在陡的地方走大步，平的地方走小步。

**算法定位**：优化/二阶方法。包含牛顿法、BFGS、自然梯度等。

**前置知识**：SGD、Hessian矩阵、泰勒展开。

## 2-3. 核心原理与公式

### 牛顿法

二阶泰勒展开：$f(\theta + d) \approx f(\theta) + \nabla f^T d + \frac{1}{2}d^T H d$

最小化得：$d^* = -H^{-1}\nabla f$

更新：$\theta^{n+1} = \theta^n - \alpha_n (H^n)^{-1} \nabla f(\theta^n)$

### 随机牛顿法

用采样估计梯度和Hessian：
- $\nabla f \approx \frac{1}{B}\sum \nabla f(x^i; \theta)$
- $H \approx \frac{1}{B}\sum \nabla^2 f(x^i; \theta)$

### BFGS（拟牛顿）

不直接计算Hessian，用梯度差分近似：$H^{n+1} \approx H^n + \text{rank-2 correction}$

### AdaGrad/RMSProp/Adam

对角近似Hessian：用历史梯度平方的累积作为自适应步长。Adam是实际中最常用的二阶近似方法。

## 4-8. 核心实现

```python
"""二阶方法：牛顿法和BFGS"""
import numpy as np
from scipy.optimize import minimize

class NewtonMethod:
    """牛顿法（带阻尼）"""
    def __init__(self, lr=1.0, max_iter=100, tol=1e-6):
        self.lr = lr
        self.max_iter = max_iter
        self.tol = tol

    def minimize(self, f, grad_f, hess_f, x0):
        x = x0.copy()
        for i in range(self.max_iter):
            g = grad_f(x)
            H = hess_f(x)
            # 阻尼牛顿：确保正定
            H_reg = H + 1e-6 * np.eye(len(x))
            d = np.linalg.solve(H_reg, g)
            x -= self.lr * d
            if np.linalg.norm(g) < self.tol:
                break
        return x

if __name__ == "__main__":
    np.random.seed(42)
    # Rosenbrock函数
    def f(x): return (1-x[0])**2 + 100*(x[1]-x[0]**2)**2
    def grad(x): return np.array([-2*(1-x[0])-400*x[0]*(x[1]-x[0]**2),
                                   200*(x[1]-x[0]**2)])
    def hess(x): return np.array([[2-400*x[1]+1200*x[0]**2, -400*x[0]],
                                   [-400*x[0], 200]])

    x0 = np.array([-1.0, 1.0])
    nm = NewtonMethod(lr=0.5)
    x_opt = nm.minimize(f, grad, hess, x0)
    print(f"牛顿法最优解: {x_opt.round(6)}")
    print(f"函数值: {f(x_opt):.2e}")
```

## 9-14. 简要

### 12. 学习总结
二阶方法：$\theta \leftarrow \theta - \alpha H^{-1}\nabla f$。利用曲率信息，收敛速度$O(1/n^2)$（SGD是$O(1/\sqrt{n})$）。计算代价$O(p^2)$- $O(p^3)$。

### 13. 练习题
**Q1**：牛顿法在什么情况下可能失败？
**A1**：Hessian不正定时（函数非凸），牛顿方向可能不是下降方向。解决方案：加正则化（$H + \lambda I$）或用拟牛顿法。
