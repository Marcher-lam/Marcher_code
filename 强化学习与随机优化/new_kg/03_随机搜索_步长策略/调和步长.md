# 调和步长(Harmonic Stepsize) 学习文档

> 步长$\alpha_n = a/(b+n)$随迭代递减，满足Robbins-Monro收敛条件。

> 来源线索：本节内容根据原书中关于"Harmonic Stepsize"的相关章节(Ch 6.1.2.2)整理、扩展与教学化改写。

## 1-3. 算法认知与公式

**一句话定义**：调和步长$\alpha_n = \frac{a}{b+n}$是最经典的递减步长策略，保证SGD在平稳环境中收敛。

**核心性质**（Robbins-Monro条件）：
- $\sum_{n=1}^\infty \alpha_n = \infty$（步长总和无穷大，保证能到达任意点）
- $\sum_{n=1}^\infty \alpha_n^2 < \infty$（步长平方和有限，保证方差收敛）

调和步长$\alpha_n = a/(b+n)$自然满足这两个条件。

特例：$\alpha_n = 1/n$是最简单的调和步长（频率学派更新的步长）。

## 4-8. 核心实现

```python
"""调和步长 vs 固定步长 对比"""
import numpy as np

class HarmonicStepsize:
    def __init__(self, a=1.0, b=0):
        self.a, self.b = a, b
    def __call__(self, n):
        return self.a / (self.b + n)

if __name__ == "__main__":
    np.random.seed(42)
    true_mu = 5.0
    # 对比不同步长
    for policy_name, alpha_fn in [
        ("调和(a=1)", lambda n: 1.0/(1+n)),
        ("调和(a=5)", lambda n: 5.0/(5+n)),
        ("固定(0.01)", lambda n: 0.01),
        ("固定(0.1)", lambda n: 0.1),
    ]:
        estimate = 0.0
        for n in range(1, 1001):
            w = true_mu + np.random.randn()
            estimate = (1-alpha_fn(n))*estimate + alpha_fn(n)*w
        print(f"{policy_name}: 最终估计={estimate:.3f}, 误差={abs(estimate-true_mu):.3f}")
```

## 9-14. 简要

### 12. 学习总结
调和步长：$\alpha_n = a/(b+n)$。满足RM条件$\sum\alpha_n=\infty, \sum\alpha_n^2<\infty$。平稳环境的最佳步长，但不适合非平稳数据。

### 13. 练习题
**Q1**：为什么固定步长不满足RM条件？
**A1**：固定$\alpha$时$\sum\alpha^2 = \infty$，估计方差不会收敛到0——永远有噪声。
