# 随机梯度自适应步长规则(SGA Adaptive Stepsize) 学习文档

> 用梯度滑动平均动态调整步长，梯度大时减小步长防止发散。

> 来源线索：本节内容根据原书中关于"Stochastic Gradient Adaptive Stepsize Rule"的相关章节(Ch 6.2.3.3)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：SGA步长规则根据梯度的二阶矩估计自适应调整步长——梯度变化剧烈时减小步长，稳定时增大。

**公式**：

$$\bar{g}^n = (1-\beta_1)\bar{g}^{n-1} + \beta_1 g^n$$（一阶矩：梯度的指数移动平均）

$$\bar{v}^n = (1-\beta_2)\bar{v}^{n-1} + \beta_2 (g^n)^2$$（二阶矩：梯度平方的指数移动平均）

$$\alpha_n = \frac{\alpha_0}{\sqrt{\bar{v}^n + \epsilon}}$$

**与Adam的区别**：SGA只自适应步长（不改梯度方向），Adam同时调整方向和步长。

## 4-8. 核心实现

```python
"""SGA自适应步长规则"""
import numpy as np

class SGAStepsize:
    def __init__(self, alpha0=0.01, beta1=0.9, beta2=0.999, eps=1e-8):
        self.alpha0 = alpha0
        self.beta1 = beta1
        self.beta2 = beta2
        self.eps = eps
        self.g_bar = None
        self.v_bar = None

    def get_alpha(self, grad):
        if self.g_bar is None:
            self.g_bar = np.zeros_like(grad)
            self.v_bar = np.zeros_like(grad)
        self.g_bar = self.beta1 * self.g_bar + (1-self.beta1) * grad
        self.v_bar = self.beta2 * self.v_bar + (1-self.beta2) * grad**2
        return self.alpha0 / (np.sqrt(self.v_bar) + self.eps)

if __name__ == "__main__":
    np.random.seed(42)
    sga = SGAStepsize(alpha0=0.01)
    for n in range(10):
        grad = np.random.randn(3) * (10 if n < 5 else 1)  # 前5步梯度大
        alpha = sga.get_alpha(grad)
        print(f"Step {n}: grad_norm={np.linalg.norm(grad):.2f}, alpha_mean={alpha.mean():.6f}")
```

## 9-14. 简要

### 12. 学习总结
SGA：$\alpha_n = \alpha_0/\sqrt{\bar{v}+\epsilon}$，$\bar{v}$是梯度平方的EMA。梯度大→步长小，梯度小→步长大。

### 13. 练习题
**Q1**：SGA和Adam的核心区别？
**A1**：Adam用$\bar{g}/\sqrt{\bar{v}}$同时调整方向和步长（类似归一化梯度）。SGA只调整步长$\alpha_0/\sqrt{\bar{v}}$，保留原始梯度方向。SGA更简单，Adam更强大。
