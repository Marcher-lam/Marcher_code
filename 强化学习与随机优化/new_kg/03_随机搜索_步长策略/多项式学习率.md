# 多项式学习率(Polynomial Learning Rates) 学习文档

> 满足Robbins-Monro条件的经典步长族——步长以多项式速度衰减，兼顾收敛性和追踪能力。

> 来源线索：本节内容根据原书中关于"Polynomial Learning Rates"的相关章节(Ch 6.1.2.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：多项式学习率的步长形式为α_n = a/(a+n)^β，其中β∈(0.5,1]，是满足Robbins-Monro收敛条件的一类经典步长。

**直觉类比**：调和步长(β=1)像"每隔一段时间回头检查一次"——检查频率越来越低。多项式学习率中β<1则"检查频率下降得更慢"，在某些问题上更有效。

**历史背景**：Robbins & Monro (1951)提出随机逼近方法并给出收敛条件。多项式学习率是最经典的满足RM条件的步长族。

**算法定位**：确定性步长策略的核心成员。与调和步长、McClain公式、Search-then-Converge并列。

**前置知识**：
- 随机逼近方法
- 收敛条件

## 2. 核心原理

**核心思想**：步长序列 $\alpha_n = \frac{a}{(a+n)^\beta}$

**Robbins-Monro收敛条件**：
1. $\sum_{n=0}^{\infty} \alpha_n = \infty$（步长之和发散→能到达任意远处）
2. $\sum_{n=0}^{\infty} \alpha_n^2 < \infty$（步长平方之和收敛→噪声被平均掉）

**多项式学习率何时满足RM条件**：
- $\beta > 1$：条件1不满足（步长衰减太快，走不到终点）
- $\beta \leq 0.5$：条件2不满足（步长衰减太慢，噪声不收敛）
- $\beta \in (0.5, 1]$：两个条件都满足

**不同β值的行为**：
- **β=1**：调和步长 $\alpha_n = a/(a+n)$，收敛最慢但最稳定
- **β=0.75**：收敛速度居中
- **β=0.5**：RM条件的边界，收敛速度最快但不够稳定

**参数a的作用**：控制初始步长大小，影响早期学习的激进程度。

**与收敛速率的关系**：
- 几乎必然收敛速率约为 $O(n^{-(1-\beta)/2})$（β<1时）
- β=1时收敛速率约为 $O(1/\log n)$（非常慢）

## 3. Python 实现

```python
import numpy as np

def polynomial_learning_rate(a, beta, n):
    """计算第n步的多项式学习率"""
    return a / (a + n) ** beta

def demo_polynomial_rates():
    """对比不同β的学习率衰减"""
    N = 1000
    for beta in [0.5, 0.75, 1.0]:
        rates = [polynomial_learning_rate(1.0, beta, n) for n in range(1, N+1)]
        sum_rates = sum(rates)
        sum_sq_rates = sum(r**2 for r in rates)
        print(f"β={beta}: Σα={sum_rates:.2f}, Σα²={sum_sq_rates:.4f}, "
              f"α_100={rates[99]:.4f}, α_1000={rates[999]:.4f}")

demo_polynomial_rates()
```

## 4. 与其他方法的关系

- **调和步长**：β=1的多项式学习率
- **常数步长**：β=0，不满足RM条件但在非平稳问题中有用
- **McClain公式**：调和步长的推广，有更好的短期性能
