# 常数步长(Constant Stepsizes) 学习文档

> 最简单也最容易被忽视的步长策略——在非平稳环境中，常数步长的"遗忘效应"反而是优势。

> 来源线索：本节内容根据原书中关于"Constant Stepsizes"的相关章节(Ch 6.1.2.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：常数步长策略令α_n = α（常数），是最简单的步长选择——但在非平稳问题中，它通过指数衰减旧数据权重实现追踪能力。

**直觉类比**：想象你在追踪一个移动目标。如果回头看所有历史观测（衰减步长），你会被旧数据拖累。常数步长就像一个"滑动窗口"——永远只关注最近的观测，自动遗忘过时的信息。

**历史背景**：常数步长虽然简单，但在非平稳优化中是实用且有效的方法。Robbins & Monro (1951)的收敛条件要求步长衰减到零，但实际应用中常数步长常被使用。

**算法定位**：最基础的步长策略。在平稳问题上不如衰减步长精确，但在非平稳问题上是最实用的选择之一。

**前置知识**：
- 随机梯度下降
- 步长的概念和作用

## 2. 核心原理

**核心思想**：参数更新规则为：
$$\theta^{n+1} = \theta^n + \alpha (y^{n+1} - \theta^n)$$

展开后可以看到：
$$\theta^n = \alpha \sum_{k=0}^{n-1} (1-\alpha)^k y^{n-k} + (1-\alpha)^n \theta^0$$

**遗忘效应**：旧数据的权重为 $(1-\alpha)^k$，随距离指数衰减：
- α=0.1：10步前的数据权重仅为 0.9^10 ≈ 0.35
- α=0.01：10步前的数据权重为 0.99^10 ≈ 0.90

**α的选择权衡**：
- **α太大**：追踪快但估计噪声大（震荡）
- **α太小**：估计平滑但追踪慢（滞后）
- **最优α**取决于信噪比和参数变化速度

**收敛性**：常数步长在平稳问题上**不收敛**到真值（有渐进偏差），但偏差为 $O(\alpha)$。在非平稳问题上，这是必要的代价。

## 3. Python 实现

```python
import numpy as np

def constant_stepsize_demo():
    """对比不同常数步长的追踪效果"""
    np.random.seed(42)
    T = 500
    # 非平稳真值：在第200步发生跳变
    theta_true = np.ones(T) * 5.0
    theta_true[200:] = 8.0
    y = theta_true + np.random.randn(T) * 1.0

    for alpha in [0.01, 0.05, 0.1, 0.3]:
        theta_est = np.zeros(T)
        theta_est[0] = y[0]
        for t in range(1, T):
            theta_est[t] = theta_est[t-1] + alpha * (y[t] - theta_est[t-1])
        # 稳态后MSE（跳变后100步）
        mse = np.mean((theta_est[300:] - theta_true[300:])**2)
        print(f"α={alpha:.2f}: 跳变后MSE={mse:.4f}")

constant_stepsize_demo()
```

## 4. 与其他方法的关系

- **调和步长**：衰减到零，在平稳问题中收敛
- **BAKF步长**：非平稳问题的最优常数步长
- **指数平滑**：等价于常数步长更新
