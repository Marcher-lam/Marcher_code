# 有限差分法(Finite Differences) 学习文档

> 通过微小扰动估计梯度，是无导数优化的最基本方法。

> 来源线索：本节内容根据原书中关于"Finite Differences"的相关章节(Ch 5.4.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：有限差分法通过在每维加减微小扰动来数值估计梯度，是梯度无法解析计算时的通用方法。

**直觉类比**：你站在山坡上闭着眼想知道哪个方向是上坡。你向东迈一小步（看升高多少），再向北迈一小步（看升高多少），就能推断出坡度方向。

**历史背景**：有限差分是数值分析的基础工具。在优化中作为"无导数优化"的入门方法。原书Ch 5.4.3中作为SPSA的对比基准。

**算法定位**：优化/梯度估计。需要$p$次函数评估（$p$为参数维度）。

**前置知识**：梯度、微积分基础。

## 2-3. 核心原理与公式

### 前向差分

$$\frac{\partial f}{\partial \theta_j} \approx \frac{f(\theta + \delta e_j) - f(\theta)}{\delta}$$

需要$p+1$次函数评估。

### 中心差分

$$\frac{\partial f}{\partial \theta_j} \approx \frac{f(\theta + \delta e_j) - f(\theta - \delta e_j)}{2\delta}$$

需要$2p$次评估，但精度更高（$O(\delta^2)$ vs $O(\delta)$）。

### 与SPSA对比

| 方法 | 函数评估次数 | 精度 |
|------|------------|------|
| 前向差分 | $p+1$ | $O(\delta)$ |
| 中心差分 | $2p$ | $O(\delta^2)$ |
| SPSA | 2（与$p$无关） | $O(\delta)$ |

有限差分的评估次数随维度$p$线性增长，SPSA与维度无关。

## 4-8. 核心实现

```python
"""有限差分法：梯度估计"""
import numpy as np

def finite_diff_gradient(f, theta, delta=1e-5, method='central'):
    """有限差分梯度估计"""
    p = len(theta)
    grad = np.zeros(p)
    if method == 'forward':
        f0 = f(theta)
        for j in range(p):
            theta_plus = theta.copy()
            theta_plus[j] += delta
            grad[j] = (f(theta_plus) - f0) / delta
    elif method == 'central':
        for j in range(p):
            theta_plus = theta.copy(); theta_plus[j] += delta
            theta_minus = theta.copy(); theta_minus[j] -= delta
            grad[j] = (f(theta_plus) - f(theta_minus)) / (2 * delta)
    return grad

if __name__ == "__main__":
    np.random.seed(42)
    # 测试：f(θ) = θ₁² + sin(θ₂), ∇f = [2θ₁, cos(θ₂)]
    f = lambda t: t[0]**2 + np.sin(t[1])
    theta = np.array([1.0, np.pi/4])
    true_grad = np.array([2*theta[0], np.cos(theta[1])])

    grad_forward = finite_diff_gradient(f, theta, method='forward')
    grad_central = finite_diff_gradient(f, theta, method='central')

    print(f"真实梯度: {true_grad.round(6)}")
    print(f"前向差分: {grad_forward.round(6)}, 误差: {np.abs(grad_forward-true_grad).max():.2e}")
    print(f"中心差分: {grad_central.round(6)}, 误差: {np.abs(grad_central-true_grad).max():.2e}")
```

## 9-14. 简要

### 12. 学习总结
有限差分：$\nabla_j f \approx [f(\theta+\delta e_j)-f(\theta-\delta e_j)]/(2\delta)$。简单但评估次数$O(p)$，高维时不如SPSA。

### 13. 练习题
**Q1**：为什么$\delta$不能太大也不能太小？
**A1**：太大→截断误差大（近似不准）；太小→舍入误差大（浮点精度限制）。最优$\delta \approx \sqrt{\epsilon_{machine}}$（前向）或$\epsilon_{machine}^{1/3}$（中心）。
