# 鲁棒优化(Robust Optimization) 学习文档

> 在最坏情况下优化，保证解对所有不确定性实现都可行。

> 来源线索：本节内容根据原书中关于"Robust Optimization"的相关章节(Ch 2.1.14, Ch 19.3)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：鲁棒优化在最坏不确定性情景下优化目标，而非在期望上优化。

**模型**：

$$\min_x \max_{\omega \in \Omega} f(x, \omega) \quad \text{s.t. } g(x, \omega) \leq 0, \forall \omega \in \Omega$$

- $\Omega$：不确定性集合（如箱约束$\omega \in [\underline{\omega}, \bar{\omega}]$）
- 目标：对$\Omega$内所有可能的情况保证可行且最优

**与随机规划的区别**：
- 随机规划：优化$\mathbb{E}[f(x,\omega)]$（平均表现）
- 鲁棒优化：优化$\max_\omega f(x,\omega)$（最坏表现）

**不确定性集选择**：箱集$\|\omega\|_\infty \leq \Gamma$、椭球集$\omega^T\Sigma^{-1}\omega \leq \Gamma^2$等。$\Gamma$控制保守程度。

## 4-8. 核心实现

```python
"""鲁棒优化：最短路径的鲁棒版本"""
import numpy as np

def robust_shortest_path(costs_nominal, delta, gamma=1.0):
    """鲁棒最短路径：用γ-百分位成本"""
    # costs_nominal: nominal edge costs
    # delta: uncertainty range per edge
    # gamma: robustness level (0=nominal, 1=worst case)
    costs_robust = costs_nominal + gamma * delta
    return costs_robust

if __name__ == "__main__":
    np.random.seed(42)
    n_edges = 10
    nominal = np.random.uniform(1, 10, n_edges)
    delta = np.random.uniform(0.5, 3, n_edges)
    for gamma in [0, 0.3, 0.5, 1.0]:
        cr = robust_shortest_path(nominal, delta, gamma)
        print(f"γ={gamma:.1f}: 总成本={cr.sum():.1f} (越保守越高)")
```

## 9-14. 简要

### 12. 学习总结
鲁棒优化：$\min_x \max_\omega f(x,\omega)$。最坏情况下保证可行。$\Gamma$控制保守程度。

### 13. 练习题
**Q1**：鲁棒优化和机会约束规划的对比？
**A1**：机会约束允许$\alpha$概率违反（概率保证），鲁棒优化要求100%满足（确定性保证），但更保守。鲁棒优化不需要分布假设。
