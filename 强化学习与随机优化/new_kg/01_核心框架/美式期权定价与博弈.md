# 美式期权定价与博弈(American Option / Tic-Tac-Toe) 学习文档

> RL在金融和博弈中的两个经典应用——最优停止和完全信息博弈。

> 来源线索：Ch 17.6.1-17.6.2

## 1. 基础认知

**一句话定义**：美式期权定价用RL学习最优行权时机；Tic-Tac-Toe用RL学习完全信息博弈策略。

## 2. 核心原理

### 美式期权定价
- **状态**：当前股价 $S_t$、距到期时间
- **决策**：行权 or 等待
- **最优停止问题**：最大化行权收益的期望
- 用VFA近似"等待的价值"，与"立即行权收益"比较

### Lose Tic-Tac-Toe
- 目标是**输掉**游戏（反向RL）
- 完全信息博弈：双方都能看到全部状态
- 用ADP学习各局面的值函数

## 3. Python 实现

```python
import numpy as np

def american_option_pricing(S0=100, K=100, T=30, r=0.05, sigma=0.3, n_paths=5000):
    """美式期权定价（LSM方法简化版）"""
    dt = T / 252
    payoffs = []

    for _ in range(n_paths):
        S = S0; exercised = False
        for t in range(T):
            S *= np.exp((r - 0.5*sigma**2)*dt + sigma*np.sqrt(dt)*np.random.randn())
            payoff = max(K - S, 0)
            if payoff > 0 and not exercised:
                # 简单策略：深度实值就行权
                if payoff > K * 0.15:
                    payoffs.append(payoff * np.exp(-r*t*dt))
                    exercised = True
        if not exercised:
            payoffs.append(max(K - S, 0) * np.exp(-r*T*dt))

    return np.mean(payoffs)

price = american_option_pricing()
print(f"美式看跌期权估计价格: ${price:.2f}")
```
