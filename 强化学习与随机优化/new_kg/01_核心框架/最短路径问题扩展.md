# 最短路径问题扩展(Shortest Path Extensions) 学习文档

> 从确定性最短路径到随机、动态、鲁棒和信息收集版本的扩展。

> 来源线索：Ch 2.3.2-2.3.5, 8.4.4

## 1. 基础认知

**一句话定义**：在确定性最短路径基础上引入随机性（边权不确定）、动态性（权值变化）、鲁棒性（最坏情况）和信息收集（沿途学习）。

## 2. 核心原理与Python

```python
import numpy as np
import heapq

def deterministic_sp(graph, start, end):
    """确定性最短路径(Dijkstra)"""
    dist = {n: float('inf') for n in graph}
    dist[start] = 0; prev = {}; pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue
        for v, w in graph[u].items():
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w; prev[v] = u
                heapq.heappush(pq, (dist[v], v))
    return dist[end]

def stochastic_sp(graph, start, end, n_sim=1000):
    """随机最短路径：边权有噪声"""
    costs = []
    for _ in range(n_sim):
        noisy = {u: {v: w + abs(np.random.randn()*w*0.2)
                      for v, w in vs.items()} for u, vs in graph.items()}
        costs.append(deterministic_sp(noisy, start, end))
    return np.mean(costs), np.std(costs)

# 示例图
G = {0:{1:2,2:5}, 1:{3:3}, 2:{3:1}, 3:{}}
print(f"确定性最短路径: {deterministic_sp(G, 0, 3)}")
mean, std = stochastic_sp(G, 0, 3)
print(f"随机最短路径: 均值={mean:.2f}, 标准差={std:.2f}")
```

**信息收集最短路径**：在行进过程中学习边权，权衡探索（走新路学习）和利用（走已知好路）。
