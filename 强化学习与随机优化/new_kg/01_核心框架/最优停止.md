# 最优停止(Optimal Stopping) 学习文档

> 决定何时停止观察并采取行动，是序列决策的经典问题。

> 来源线索：本节内容根据原书中关于"Optimal Stopping"的相关章节(Ch 2.1.7)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：最优停止问题决定何时停止序列观察并接受当前选项，目标是最大化期望奖励。

**直觉类比**：你在看房买房。每看一套房子，必须决定"买"或"继续看"。买了之后不能再看后面的，不买的话这套就被别人买走了。问题是：应该看多少套才开始认真考虑？最优停止理论告诉你：先看约37%（$1/e$）了解行情，然后选第一套比之前都好的。

**历史背景**：最优停止问题最早可追溯到Cayley (1875)对彩票问题的研究。秘书问题的最优策略由Lindley (1961)和Dynkin (1963)独立发现。Chow, Robbins & Siegmund (1971)的经典著作《Great Expectations》系统建立了最优停止的数学理论。原书(Ch 2.1.7)将其作为序贯决策问题的基本类型之一。

**算法定位**：序贯决策/停止规则。最优停止是MDP的特殊情形——决策只有"继续"和"停止"两个选项。

**前置知识**：
- 概率论（期望、条件期望、鞅）
- 马尔可夫决策过程（MDP）
- Bellman方程

## 2. 核心原理

**核心思想**：最优停止的核心是计算"保留价值"(Reservation Value)——继续观察的期望价值。当当前观测值超过保留价值时停止。

**工作流程**：

1. 在每一步$n$，观察$W^n$
2. 计算"继续"的期望价值$v^n$（保留价值）
3. 如果$W^n \geq v^n$，停止并获得$W^n$
4. 否则继续到下一步
5. 如果到达最后一步，必须接受最后一个

**关键概念**：

- **停止时间$\tau$**：一个取值为正整数的随机变量，表示停止的步数
- **保留价值$v^n$**：从第$n$步开始继续观察的期望最优收益
- **最优停止规则**：$\tau^* = \min\{n : W^n \geq v^n\}$
- **秘书问题**：最经典的最优停止问题，面试$N$个候选人，必须即时决定

**策略分类图**：

```
最优停止策略
├── 秘书问题策略：观察1/e → 选第一个超过的
├── 保留价值策略：计算vⁿ → Wⁿ ≥ vⁿ时停止
├── 阈值策略：设定固定阈值 → 超过即停
└── 动态规划策略：后向递推计算精确保留价值
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $W^n$ | 第$n$次观测值 |
| $\tau$ | 停止时间 |
| $v^n$ | 第$n$步的保留价值 |
| $N$ | 总观测次数 |
| $V^*$ | 最优期望收益 |

### 一般形式

$$\max_\tau \mathbb{E}[W^\tau], \quad \tau \in \{1, 2, \ldots, N\}$$

### Bellman方程（后向递推）

$$V^n = \max\{W^n, \mathbb{E}[V^{n+1} | W^n]\}$$

保留价值的后向递推：
$$v^{N} = -\infty \text{（最后一步必须接受）}$$
$$v^{n} = \mathbb{E}[\max(W^{n+1}, v^{n+1})]$$

### 秘书问题的解

$N$个候选人，最优策略：先观察前$k^*$个，然后选第一个比前面都好的。

$$k^* = \arg\max_k \frac{k}{N}\sum_{i=k+1}^{N}\frac{1}{i-1} \approx \frac{N}{e}$$

选到最优候选人的概率：$\approx 1/e \approx 0.368$

### 带折扣的停止问题

$$\max_\tau \mathbb{E}[\beta^\tau W^\tau]$$

其中$\beta \in (0,1)$是折扣因子。折扣使得等待有成本，加速停止决策。

## 4. 训练过程讲解

### 参数初始化
- 总步数$N$：设定最大观察次数
- 分布信息：观测值的分布（已知或未知）

### 后向递推过程
1. 终止条件：$v^{N} = -\infty$（最后一步必须接受）
2. 后向递推：$v^{n} = \mathbb{E}[\max(W, v^{n+1})]$，$n = N-1, \ldots, 1$
3. 每步检查：若$W^n \geq v^n$则停止

### 收敛条件
- 有限视野：递推到第1步即完成
- 无限视野：$v^n$收敛到固定点

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $N$ | 最大观察次数 | [10, 1000] | 100 |
| $\beta$ | 折扣因子 | [0.9, 1.0] | 1.0 |
| 观测分布 | $W$的分布 | 已知/未知 | $U(0,1)$ |

## 5. 应用场景

### 1. 秘书/招聘问题
为什么适合：面试候选人必须即时决定接受或拒绝，不能回头。最优停止规则直接适用。

### 2. 房屋买卖
为什么适合：看房是序贯过程，每套房需要即时决定。价格谈判的时机选择也是停止问题。

### 3. 股票卖出/期权行权
为什么适合：决定何时卖出股票（停止持有）以最大化期望收益。美式期权定价本质上是最优停止问题。

### 4. 医学临床试验
为什么适合：决定何时停止试验（已经收集到足够证据）vs 继续收集数据。过早停止浪费信息，过晚停止浪费资源。

### 不适用场景
- 可以回头选择之前的选项（有记忆选择问题）
- 观测之间有复杂的时间依赖性
- 停止后的奖励不是即时观测值

## 6. 优缺点分析

### 优点
1. **理论优雅**：保留价值方法给出简洁的停止规则（成立条件：观测独立同分布）
2. **解的普适性**：秘书问题的$1/e$法则适用于很多序贯选择场景
3. **计算高效**：后向递推时间复杂度$O(N)$
4. **直觉清晰**：保留价值提供了可解释的决策标准

### 缺点
1. **分布假设**：标准理论假设观测值独立同分布，实际中往往不满足
2. **无法回头**：标准设定下一旦拒绝就不能再选择
3. **信息假设**：秘书问题假设候选人之间不可比较质量只有相对排名
4. **有限视野要求**：无限视野问题需要额外的收敛性分析

### 算法对比

| 特性 | 保留价值法 | 秘书1/e法则 | 动态规划 | 强化学习 |
|------|-----------|------------|----------|----------|
| 需要分布信息 | 是 | 否 | 是 | 否 |
| 最优性保证 | 是 | 是 | 是 | 渐近 |
| 计算复杂度 | $O(N)$ | $O(1)$ | $O(N^2)$ | 高 |
| 可扩展性 | 中 | 低 | 低 | 高 |

## 7. 调库实现

```python
"""
最优停止问题：使用NumPy模拟秘书问题
"""
import numpy as np

def secretary_problem(N=100, n_sims=10000):
    """秘书问题：1/e策略的模拟验证"""
    wins = 0
    for _ in range(n_sims):
        candidates = np.random.permutation(N)
        threshold = int(N / np.e)  # 观察前1/e个
        best_so_far = candidates[:threshold].max()
        chosen = N - 1  # 默认最后一个
        for i in range(threshold, N):
            if candidates[i] > best_so_far:
                chosen = i
                break
        if candidates[chosen] == N - 1:
            wins += 1
    return wins / n_sims

def stopping_with_distribution(dist_fn, N, n_sims=10000):
    """一般最优停止：后向递推计算保留价值"""
    # 后向递推计算保留价值
    v = np.zeros(N + 1)
    v[N] = -np.inf  # 最后一步必须接受
    for n in range(N - 1, 0, -1):
        samples = dist_fn(100000)
        v[n] = np.mean(np.maximum(samples, v[n + 1]))

    # 模拟验证
    total_reward = 0
    for _ in range(n_sims):
        for n in range(1, N + 1):
            w = dist_fn(1)[0]
            if w >= v[n] or n == N:
                total_reward += w
                break
    return v, total_reward / n_sims

if __name__ == "__main__":
    np.random.seed(42)
    # 秘书问题
    prob = secretary_problem(N=100, n_sims=10000)
    print(f"秘书问题选到最优的概率: {prob:.3f} (理论≈1/e≈{1/np.e:.3f})")

    # 均匀分布停止问题
    v, avg = stopping_with_distribution(
        lambda n: np.random.uniform(0, 1, n), N=20)
    print(f"\n均匀分布停止问题 (N=20):")
    print(f"保留价值序列: {v[1:6].round(3)} ...")
    print(f"平均收益: {avg:.3f}")
```

## 8. 手工代码实现

```python
"""
从零实现最优停止问题的完整求解
纯NumPy，包含后向递推和前向模拟
"""
import numpy as np

class OptimalStopping:
    """最优停止问题求解器"""

    def __init__(self, N, dist_type='uniform'):
        self.N = N
        self.dist_type = dist_type
        self.reservation_values = None

    def sample(self, size=1):
        """从观测分布采样"""
        if self.dist_type == 'uniform':
            return np.random.uniform(0, 1, size)
        elif self.dist_type == 'normal':
            return np.random.normal(0, 1, size)
        elif self.dist_type == 'exponential':
            return np.random.exponential(1, size)

    def solve(self, n_mc=100000):
        """后向递推计算保留价值"""
        self.reservation_values = np.zeros(self.N + 1)
        self.reservation_values[self.N] = -np.inf  # 最后一步必须接受

        for n in range(self.N - 1, 0, -1):
            samples = self.sample(n_mc)
            self.reservation_values[n] = np.mean(
                np.maximum(samples, self.reservation_values[n + 1]))
        return self.reservation_values

    def simulate(self, n_episodes=10000):
        """模拟最优停止策略"""
        if self.reservation_values is None:
            self.solve()

        rewards = []
        stop_times = []
        for _ in range(n_episodes):
            for n in range(1, self.N + 1):
                w = self.sample(1)[0]
                if w >= self.reservation_values[n] or n == self.N:
                    rewards.append(w)
                    stop_times.append(n)
                    break
        return np.mean(rewards), np.mean(stop_times)

    def benchmark(self, n_episodes=10000):
        """对比不同策略"""
        # 固定阈值策略
        thresholds = [0.3, 0.4, 0.5, 0.6, 0.7]
        results = {}

        # 最优策略
        self.solve()
        opt_reward, opt_stop = self.simulate(n_episodes)
        results['最优停止'] = (opt_reward, opt_stop)

        # 固定阈值
        for t in thresholds:
            rewards = []
            for _ in range(n_episodes // 2):
                for n in range(1, self.N + 1):
                    w = self.sample(1)[0]
                    if w >= t or n == self.N:
                        rewards.append(w)
                        break
            results[f'阈值={t}'] = (np.mean(rewards), np.mean(
                [np.random.randint(1, self.N) for _ in range(len(rewards))]))

        print(f"{'策略':<12} {'平均收益':>8} {'平均停止步':>8}")
        print("-" * 32)
        for name, (r, s) in results.items():
            print(f"{name:<12} {r:>8.3f} {s:>8.1f}")
        return results


# ========== 测试 ==========
if __name__ == "__main__":
    np.random.seed(42)

    # 均匀分布
    print("=== 均匀分布 U(0,1), N=20 ===")
    os_problem = OptimalStopping(N=20, dist_type='uniform')
    os_problem.solve()
    reward, stop = os_problem.simulate()
    print(f"最优停止: 平均收益={reward:.3f}, 平均停止步={stop:.1f}")
    print(f"前5步保留价值: {os_problem.reservation_values[1:6].round(3)}")

    print("\n=== 策略对比 ===")
    os_problem.benchmark()
```

## 10. 模型评估

```python
"""
最优停止策略评估
"""
import numpy as np

def evaluate_stopping_strategy(strategy_fn, dist_fn, N, n_episodes=10000, label="策略"):
    """评估停止策略的表现"""
    rewards = []
    stop_times = []
    for _ in range(n_episodes):
        obs = []
        for n in range(1, N + 1):
            w = dist_fn()[0]
            obs.append(w)
            if strategy_fn(n, w, obs) or n == N:
                rewards.append(w)
                stop_times.append(n)
                break
    print(f"{label}评估（{n_episodes}回合）：")
    print(f"  平均收益: {np.mean(rewards):.3f} +/- {np.std(rewards):.3f}")
    print(f"  平均停止步: {np.mean(stop_times):.1f}/{N}")
    print(f"  最优观测被选中的比例: {sum(1 for r in rewards if r > 0.9)/n_episodes:.1%}")
    return np.mean(rewards)
```

**评估指标说明**：
- **平均收益**：策略的核心度量，越接近理论上界越好
- **平均停止步**：策略的效率，过快停止可能错过好选项
- **最优被选比例**：是否经常选到高质量选项

## 11. 常见问题与易错点

### 数据层面

1. **观测分布假设错误**
   - 现象：保留价值计算偏差，实际收益低于预期
   - 原因：假设均匀分布但实际有偏斜或重尾
   - 解决方案：使用非参数方法估计分布，或用鲁棒停止规则

2. **观测之间存在相关性**
   - 现象：策略表现不稳定
   - 原因：标准理论假设独立观测，但实际有时间依赖
   - 解决方案：使用条件分布更新保留价值

### 模型层面

3. **无限视野问题不收敛**
   - 现象：保留价值计算不收敛
   - 原因：无折扣时继续观察永远比停止好
   - 解决方案：加入折扣因子$\beta < 1$或设置有限截止

4. **多目标停止被忽略**
   - 现象：只优化收益而忽略风险
   - 原因：标准模型只考虑期望收益最大化
   - 解决方案：使用风险敏感目标（如CVaR条件下的停止规则）

### 调参层面

5. **截止时间设定不当**
   - 现象：过早停止或浪费太多观察机会
   - 原因：$N$设定过大或过小
   - 解决方案：根据问题规模和观测成本合理设定$N$

## 12. 学习总结

最优停止问题是"何时行动"的数学理论。核心思想是计算保留价值——继续观察的期望最优收益。当当前观测超过保留价值时停止。

**关键公式**：
1. 停止规则：$\tau^* = \min\{n : W^n \geq v^n\}$
2. 保留价值递推：$v^n = \mathbb{E}[\max(W, v^{n+1})]$
3. 秘书问题：观察$N/e$个，选第一个比之前都好的，成功概率$\approx 1/e$

最优停止是MDP的特殊情形（决策空间只有"继续/停止"），也是美式期权定价、临床试验设计、房屋买卖决策的理论基础。

## 13. 练习题与思考题

### 基础题

**题目1**：股票卖出是最优停止问题吗？与标准设定有什么不同？

**参考答案**：是的。决定何时卖出股票以最大化期望收益就是最优停止。但与标准设定不同：(1)价格过程非平稳（有时间趋势和波动率聚集）；(2)可以设定止损/止盈（多阈值）；(3)有交易成本。美式期权定价是最优停止在金融中的经典应用。

**题目2**：均匀分布$U(0,1)$，$N=3$，保留价值$v^3 = -\infty$，$v^2$是多少？

**参考答案**：
$v^3 = -\infty$（最后一步必须接受）
$v^2 = \mathbb{E}[\max(W, v^3)] = \mathbb{E}[W] = 0.5$
$v^1 = \mathbb{E}[\max(W, v^2)] = \mathbb{E}[\max(W, 0.5)] = \int_0^1 \max(w, 0.5)dw = 0.5 \times 0.5 + \int_{0.5}^1 w \, dw = 0.25 + 0.375 = 0.625$

### 进阶题

**题目3**：原书(Ch 2.1.7)讨论了"搜索问题"——决定花多少时间搜索最低价格。与秘书问题相比，搜索问题有什么本质区别？

**参考答案**：
- 秘书问题：每步看到一个新的"质量"，必须与之前最好的比较，不可回头
- 搜索问题：可以记住所有已观测的价格，目标是找到最低价
- 本质区别：搜索问题的保留价值是"已知最低价"的函数，而秘书问题是"已观测最大值"的函数
- 搜索问题的停止规则：当搜索成本超过期望改进时停止

### 开放思考题

**题目4**：在互联网时代（电商、约会App、求职），"选择过多"使得最优停止问题更加突出。你认为$1/e$法则在现实中有效吗？有哪些因素会使它失效？

**参考答案方向**：
- $1/e$法则的有效性依赖于：候选人完全随机排序、不可回头、只能选一个
- 现实中失效的原因：(1)可以"回头"（很多App允许重新联系）；(2)有额外信息（简历、评分）；(3)选择空间动态变化（新候选人不断出现）
- 更现实的模型：有部分信息的最优停止、允许回头的停止问题、无限候选人流的停止
