# 能量存储模型(Energy Storage Model) 学习文档

> 序贯决策在能源系统中的典型应用——买低卖高的储能调度问题。

> 来源线索：Ch 9.8 "Illustration: An Energy Storage Model"

## 1. 基础认知

**一句话定义**：能量存储模型决定何时充电（低价买入）和放电（高价卖出），以最大化利润。

## 2. 核心原理

**模型要素**：
- **状态** $(R_t, p_t)$：储能水平和电价
- **决策** $x_t \in [-x^{max}, x^{max}]$：正值充电、负值放电
- **转移**：$R_{t+1} = R_t + \eta_c x_t^+ - x_t^-/\eta_d$（充放电效率）
- **外生信息** $p_{t+1}$：电价演化

**策略类型**：
- PFA：固定阈值规则（价格低于θ₁充电，高于θ₂放电）
- CFA：参数化优化模型
- VFA：学习储能水平的价值函数
- DLA：前瞻价格预测

**扩展**：加入被动学习（价格分布未知）或主动学习（探索价格模式）。

## 3. Python 实现

```python
import numpy as np

class EnergyStorage:
    def __init__(self, capacity=100, eta_c=0.95, eta_d=0.95):
        self.capacity = capacity
        self.eta_c, self.eta_d = eta_c, eta_d
        self.R = 50  # 初始储能

    def step(self, action, price):
        charge = max(0, action)
        discharge = max(0, -action)
        self.R += self.eta_c * charge - discharge / self.eta_d
        self.R = np.clip(self.R, 0, self.capacity)
        profit = discharge * price - charge * price
        return profit

def pfa_policy(R, price, theta_low=30, theta_high=60):
    if price < theta_low: return min(10, 100 - R)
    elif price > theta_high: return -min(10, R)
    return 0

np.random.seed(42)
es = EnergyStorage()
prices = [50 + 20*np.sin(t*0.1) + np.random.randn()*5 for t in range(200)]
total = sum(es.step(pfa_policy(es.R, p), p) for p in prices)
print(f"总利润: ${total:.0f}, 最终储能: {es.R:.1f}")
```
