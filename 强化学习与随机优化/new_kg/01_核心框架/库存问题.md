# 库存问题(Inventory Problem) 学习文档

> 在需求不确定下管理库存的订货与销售，是动态规划最经典的连续决策应用。

> 来源线索：本节内容根据原书中关于"Inventory/Storage Problems"的相关章节(Ch 2.3.2, Ch 8.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：库存问题在随机需求下决定何时订多少货，在缺货成本和库存持有成本之间取得最优平衡，是多阶段随机优化的经典应用。

**直觉类比**：你经营一家面包店，每天有随机数量的顾客来买面包。你可以在每天开始时烤新面包，但烤多了卖不完就是浪费（持有成本），烤少了顾客空手而归（缺货成本）。你的目标是在整个运营周期内最大化总利润。每天结束后的剩余面包就是明天的"状态"。

**历史背景**：库存问题是动态规划最早的应用之一。Arrow et al. (1958) 系统研究了随机需求下的最优库存策略。Clark & Scarf (1960) 证明了多级库存系统的最优策略具有 Base-Stock 结构。原书(Powell, 2022)用库存问题贯穿全书，从第2章的建模到第11-19章的四种策略类（PFA/CFA/VFA/DLA），展示每种方法的适用场景。

**算法定位**：随机优化/多阶段序贯决策。与报童问题（单阶段）对应，是动态规划的核心应用场景。库存问题是理解"状态-决策-转移-奖励"闭环的最佳案例。

**前置知识**：
- 报童问题（单阶段版本）
- 马尔可夫决策过程（MDP）
- Bellman方程
- Python编程基础

## 2. 核心原理

**核心思想**：库存问题将报童问题扩展到多阶段。关键增加是**状态变量**：当前库存水平$R_t$，价格$p_t$，以及可能的需求信念$B_t$。每个阶段的决策影响未来状态，形成序贯决策链。

**五要素模型**：
1. **状态空间** $S_t = (R_t, p_t, B_t)$：库存水平、价格、需求信念
2. **决策** $x_t$：订货量（连续或离散）
3. **外生信息** $W_{t+1} = \hat{D}_{t+1}$：随机需求实现
4. **转移函数**：$R_{t+1} = \max(0, R_t + x_t - \hat{D}_{t+1})$
5. **目标函数**：$\max_\pi \mathbb{E}\sum_{t=0}^{T}\gamma^t C_t(S_t, x_t)$

**工作流程**：

1. 观察当前状态$S_t = (R_t, p_t, B_t)$
2. 根据策略$\pi$决定订货量$x_t$
3. 观察需求$\hat{D}_{t+1}$，计算销售$y_t = \min(R_t + x_t, \hat{D}_{t+1})$
4. 获得奖励$C_t = p_ty_t - c_tx_t - h\max(0, R_t+x_t-y_t) - b\max(0, \hat{D}_{t+1}-R_t-x_t)$
5. 更新状态$S_{t+1}$

**关键概念**：

- **信念状态$B_t$**：对需求分布的当前认知（贝叶斯更新或频率估计）
- **Base-Stock策略**：每期将库存补充到固定水平$S^*$，即$x_t = \max(0, S^* - R_t)$
- **$(s, S)$策略**：库存低于$s$时订到$S$，否则不订货
- **延迟决策(lagged decisions)**：$x_{tt'}$表示$t$时刻订购、$t'$时刻到达的货物
- **审查观测(censored observations)**：只能观测到销售量$\min(x, D)$而非真实需求$D$

**几何直观**：

```
库存水平 R_t
    │
    ├── 订货 x_t ──→ 库存升至 R_t + x_t
    │                      │
    │                 需求 D_{t+1} 发生
    │                      │
    │              ┌───────┴───────┐
    │         D ≤ R+x         D > R+x
    │         正常销售         缺货
    │     R_{t+1}=R+x-D    R_{t+1}=0
    │     利润=pD-cx-h(R+x-D)  利润=p(R+x)-cx-b(D-R-x)
    │
    ↓ 时间推进到 t+1
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $R_t$ | $t$时刻的库存水平（状态） |
| $x_t$ | $t$时刻的订货量（决策） |
| $\hat{D}_t$ | $t$时刻的随机需求 |
| $p_t$ | 单位售价 |
| $c_t$ | 单位订货成本 |
| $h$ | 单位库存持有成本 |
| $b$ | 单位缺货惩罚 |
| $T$ | 总决策阶段数 |
| $\gamma$ | 折扣因子 |

### 单步利润函数

$$C_t(R_t, x_t, \hat{D}_{t+1}) = p_t\min(R_t+x_t, \hat{D}_{t+1}) - c_tx_t - h\max(0, R_t+x_t-\hat{D}_{t+1}) - b\max(0, \hat{D}_{t+1}-R_t-x_t)$$

### 目标函数

$$\max_\pi \mathbb{E}\left[\sum_{t=0}^{T-1}\gamma^t C_t(S_t, X^\pi(S_t))\right]$$

### Bellman方程

$$V_t(S_t) = \max_{x_t}\left\{\mathbb{E}[C_t(S_t, x_t, \hat{D}_{t+1})] + \gamma\mathbb{E}[V_{t+1}(S_{t+1})|S_t, x_t]\right\}$$

### 状态转移

$$R_{t+1} = \max\{0, R_t + x_t - \hat{D}_{t+1}\}$$

**静态需求**：$S_t = R_t$

**动态价格**：$S_t = (R_t, p_t)$

**学习问题**：$S_t = (R_t, p_t, B_t)$，其中$B_t$是需求分布的信念

### Base-Stock策略的最优性

对于单产品、无固定订货成本、凸成本的库存问题，Base-Stock策略是最优的：

$$x_t^* = \max(0, S_t^* - R_t)$$

其中$S_t^*$是$t$时刻的最优Base-Stock水平，可通过后向递推求解。

### 与四种策略类的对应

| 策略类 | 库存问题中的形式 | 参数/决策变量 |
|--------|-----------------|--------------|
| PFA | $(s, S)$策略或Base-Stock策略 | 参数$s, S$或$S^*$ |
| CFA | 修正确定性规划的参数化模型 | 鲁棒参数$\alpha$ |
| VFA | 用值函数近似指导订货决策 | 近似参数$\theta$ |
| DLA | 前瞻模拟未来需求场景 | 场景数、规划窗口 |

## 4. 训练过程讲解

### 参数初始化
- 库存水平：通常$R_0 = 0$或某个初始值
- 需求分布：已知或设定先验$B_0$
- 策略参数：$(s, S)$或Base-Stock水平通过优化确定

### 后向动态规划过程
1. 终止条件：$V_T(S_T) = 0$
2. 后向递推：$t = T-1, T-2, ..., 0$
3. 对每个状态$s$，枚举所有可行决策$x$
4. 计算期望值并选择最优决策
5. 记录最优策略$\pi^*(s)$

### 收敛条件
- 有限视野问题：后向递推到$t=0$即完成
- 无限视野问题：$\|V^{(k+1)} - V^{(k)}\|_\infty < \epsilon$

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $h$ | 单位持有成本 | [0.5, 5] | 1.0 |
| $b$ | 单位缺货惩罚 | [2, 20] | 5.0 |
| $p$ | 单位售价 | [5, 50] | 10.0 |
| $c$ | 单位订货成本 | [3, 30] | 6.0 |
| $T$ | 决策阶段数 | [10, 100] | 20 |
| $\gamma$ | 折扣因子 | [0.9, 0.99] | 0.95 |
| max_inv | 最大库存容量 | [50, 500] | 100 |

## 5. 应用场景

### 1. 零售库存管理
为什么适合：超市和电商每天面临随机需求，库存水平是自然的状态变量，订货量是决策。MDP框架可以直接建模"何时订多少"的决策问题。

### 2. 能源存储调度
为什么适合：电池储能的充放电决策本质上是库存问题——电能在电池中的存储量是"库存"，电价是"价格"，用电需求是"需求"。（原书Ch 11.9详细讨论）

### 3. 血液库存管理
为什么适合：血液制品有保质期，需求随机（手术用血），供应也不确定（献血者数量）。库存问题框架可以建模血液的采集-存储-分配决策。

### 4. 备件库存
为什么适合：飞机、设备维护中备件需求稀疏但缺货代价极高。库存问题可以在备件持有成本和缺货风险之间取得平衡。

### 不适用场景
- 需求完全可预测（退化为确定性优化）
- 多产品之间有复杂耦合约束（需要更高级的分解方法）
- 实时性要求极高（DP计算时间可能不够）

## 6. 优缺点分析

### 优点
1. **模型简洁内涵丰富**：简单到可以手算，复杂到可以展示所有策略类（成立条件：合理的成本参数设定）
2. **结构化策略**：最优策略往往有简洁形式（Base-Stock或$(s,S)$），易于实施
3. **直觉清晰**：库存水平作为状态变量直观易懂
4. **教学价值高**：从报童到库存，从单阶段到多阶段，理解序贯决策的本质

### 缺点
1. **维度灾难**：多产品+预测+信念使状态空间指数增长（当产品数>3时精确DP几乎不可行）
2. **假设限制**：标准模型假设独立同分布需求和线性成本
3. **提前期建模复杂**：有订货提前期时状态空间扩大
4. **计算代价高**：精确DP的时间复杂度为$O(T \cdot |\mathcal{R}|^2 \cdot |\mathcal{X}|)$

### 算法对比

| 特性 | 精确DP | $(s,S)$策略 | 在线学习 | 仿真优化 |
|------|--------|-------------|----------|----------|
| 需求模型 | 已知 | 已知 | 未知 | 仿真 |
| 最优性 | 最优 | 次优 | 渐近最优 | 近似 |
| 计算复杂度 | 高 | 低 | 中 | 中 |
| 适应能力 | 无 | 无 | 强 | 中 |
| 可扩展性 | 差 | 好 | 好 | 中 |

## 7. 调库实现

```python
"""
库存问题：使用自定义MDP环境求解
基于后向动态规划的精确求解
"""
import numpy as np

class InventoryProblem:
    """有限阶段库存问题求解器"""

    def __init__(self, max_inv=50, T=20, p=10, c=6, h=1, b=5):
        self.max_inv = max_inv
        self.T = T
        self.p = p       # 售价
        self.c = c       # 成本
        self.h = h       # 库存持有成本
        self.b = b       # 缺货惩罚
        # 离散化需求分布
        self.demand_vals = np.arange(0, 20)
        self.demand_probs = np.array([0.05]*5 + [0.08]*5 + [0.06]*5 + [0.03]*5)
        self.demand_probs /= self.demand_probs.sum()

    def expected_reward(self, inv, order):
        """计算给定库存和订货量的期望单步利润"""
        total = inv + order
        cost = self.c * order
        expected_rev = 0
        expected_hold = 0
        expected_back = 0
        for d, prob in zip(self.demand_vals, self.demand_probs):
            sold = min(total, d)
            expected_rev += prob * self.p * sold
            leftover = max(0, total - d)
            expected_hold += prob * self.h * leftover
            shortage = max(0, d - total)
            expected_back += prob * self.b * shortage
        return expected_rev - cost - expected_hold - expected_back

    def solve_dp(self):
        """后向动态规划求解"""
        V = np.zeros((self.T + 1, self.max_inv + 1))
        policy = np.zeros((self.T, self.max_inv + 1), dtype=int)

        for t in range(self.T - 1, -1, -1):
            for inv in range(self.max_inv + 1):
                best_val = -np.inf
                best_order = 0
                for order in range(self.max_inv - inv + 1):
                    reward = self.expected_reward(inv, order)
                    future = 0
                    for d, prob in zip(self.demand_vals, self.demand_probs):
                        next_inv = min(max(0, inv + order - d), self.max_inv)
                        future += prob * V[t + 1, next_inv]
                    total_val = reward + future
                    if total_val > best_val:
                        best_val = total_val
                        best_order = order
                V[t, inv] = best_val
                policy[t, inv] = best_order
        return V, policy

    def simulate(self, policy, n_episodes=1000):
        """蒙特卡洛仿真评估策略"""
        total_rewards = []
        for _ in range(n_episodes):
            inv = 20
            ep_reward = 0
            for t in range(self.T):
                order = min(policy[t, inv], self.max_inv - inv)
                demand = np.random.choice(self.demand_vals, p=self.demand_probs)
                sold = min(inv + order, demand)
                reward = self.p * sold - self.c * order
                reward -= self.h * max(0, inv + order - demand)
                reward -= self.b * max(0, demand - inv - order)
                inv = min(max(0, inv + order - demand), self.max_inv)
                ep_reward += reward
            total_rewards.append(ep_reward)
        return np.mean(total_rewards), np.std(total_rewards)


if __name__ == "__main__":
    np.random.seed(42)
    inv = InventoryProblem(max_inv=30, T=10)
    V, policy = inv.solve_dp()
    mean_r, std_r = inv.simulate(policy)
    print(f"最优策略下期望总利润: {V[0, 20]:.1f}")
    print(f"模拟平均利润: {mean_r:.1f} +/- {std_r:.1f}")
    print(f"初始库存20时的最优订货量(前5期): {policy[:5, 20]}")
```

## 8. 手工代码实现

```python
"""
从零实现库存问题的(s,S)策略搜索
纯NumPy，无任何高级封装
"""
import numpy as np

class InventoryEnv:
    """简化的库存环境"""

    def __init__(self, max_inv=50, T=20, p=10, c=6, h=1, b=5):
        self.max_inv = max_inv
        self.T = T
        self.p, self.c, self.h, self.b = p, c, h, b
        self.demand_mean = 10
        self.demand_std = 3

    def reset(self):
        self.t = 0
        self.inv = np.random.randint(10, 30)
        return self.inv

    def step(self, order):
        order = max(0, min(order, self.max_inv - self.inv))
        demand = max(0, np.random.normal(self.demand_mean, self.demand_std))
        total = self.inv + order
        sold = min(total, demand)
        reward = (self.p * sold - self.c * order
                  - self.h * max(0, total - demand)
                  - self.b * max(0, demand - total))
        self.inv = min(max(0, total - demand), self.max_inv)
        self.t += 1
        done = (self.t >= self.T)
        return self.inv, reward, done


class SSPolicy:
    """(s, S)策略：库存低于s时订到S"""

    def __init__(self, s=10, S=25):
        self.s = s
        self.S = S

    def act(self, inv):
        if inv < self.s:
            return max(0, self.S - inv)
        return 0


def evaluate_policy(policy, env, n_episodes=500):
    """评估策略的平均总利润"""
    rewards = []
    for _ in range(n_episodes):
        inv = env.reset()
        total_r = 0
        done = False
        while not done:
            order = policy.act(inv)
            inv, r, done = env.step(order)
            total_r += r
        rewards.append(total_r)
    return np.mean(rewards), np.std(rewards)


def grid_search_ss(env, s_range=range(5, 25), S_range=range(15, 45)):
    """网格搜索最优(s,S)参数"""
    best_mean = -np.inf
    best_params = (10, 25)

    for s in s_range:
        for S in S_range:
            if S <= s:
                continue
            policy = SSPolicy(s, S)
            mean_r, _ = evaluate_policy(policy, env, n_episodes=200)
            if mean_r > best_mean:
                best_mean = mean_r
                best_params = (s, S)

    return best_params, best_mean


# ========== 测试 ==========
if __name__ == "__main__":
    np.random.seed(42)
    env = InventoryEnv(max_inv=50, T=20, p=10, c=6, h=1, b=5)

    # 网格搜索最优(s,S)
    print("搜索最优(s,S)参数...")
    (best_s, best_S), best_r = grid_search_ss(env)
    print(f"最优参数: s={best_s}, S={best_S}")
    print(f"平均总利润: {best_r:.1f}")

    # 用最优参数做详细评估
    policy = SSPolicy(best_s, best_S)
    mean_r, std_r = evaluate_policy(policy, env, n_episodes=2000)
    print(f"详细评估: {mean_r:.1f} +/- {std_r:.1f}")

    # 策略行为示例
    print("\n策略行为示例:")
    for inv in [0, 5, 10, 15, 20, 25, 30]:
        order = policy.act(inv)
        print(f"  库存={inv:2d} -> 订货={order:2d} -> 总量={inv+order:2d}")
```


**评估指标说明**：
- **平均总利润**：最直接的策略质量度量，越高越好
- **利润标准差**：衡量策略的稳定性
- **利润为正的比例**：衡量策略的可靠性

## 11. 常见问题与易错点

### 数据层面

1. **需求分布假设错误**
   - 现象：策略在实际中表现差
   - 原因：训练用正态需求，实际需求有长尾或季节性
   - 解决方案：使用非参数需求估计或鲁棒优化

2. **审查观测忽略**
   - 现象：需求估计偏差
   - 原因：只能观测到销售=min(库存, 需求)，缺货时低估真实需求
   - 解决方案：使用贝叶斯方法处理审查数据（原书Ch 3.9.2）

### 模型层面

3. **维度灾难**
   - 现象：状态空间稍大就内存溢出
   - 原因：库存水平×需求信念的联合空间指数增长
   - 解决方案：使用VFA或PFA替代精确DP

4. **忽略提前期**
   - 现象：策略频繁缺货
   - 原因：模型假设即时到货，但实际有1-3天提前期
   - 解决方案：将提前期内的在途订单纳入状态变量

### 调参层面

5. **成本参数设定不合理**
   - 现象：策略要么过度囤货要么频繁缺货
   - 原因：持有成本$h$和缺货成本$b$的比例失调
   - 解决方案：根据实际业务数据校准成本参数，通常$b/h \in [3, 10]$

## 12. 学习总结

库存问题是报童问题的多阶段扩展，是序贯决策建模的核心案例。其五要素模型（状态-决策-外生信息-转移函数-目标函数）为所有随机优化问题提供了统一的建模框架。

**关键公式**：
1. 状态转移：$R_{t+1} = \max(0, R_t + x_t - \hat{D}_{t+1})$
2. 单步利润：$C_t = p\min(R+x, D) - cx - h\max(0, R+x-D) - b\max(0, D-R-x)$
3. Bellman方程：$V_t(S_t) = \max_{x_t}\{\mathbb{E}[C_t] + \gamma\mathbb{E}[V_{t+1}(S_{t+1})]\}$

库存问题是原书中展示四种策略类（PFA/CFA/VFA/DLA）的核心案例。$(s,S)$策略属于PFA，参数化的鲁棒模型属于CFA，值函数近似属于VFA，前瞻模拟属于DLA。

## 13. 练习题与思考题

### 基础题

**题目1**：库存问题中，$(s, S)$策略属于原书四种策略类中的哪一种？给出理由。

**参考答案**：$(s, S)$策略属于PFA（策略函数近似）。它是一个参数化策略，参数$s$（再订货点）和$S$（订到水平）通过优化确定。决策规则$x_t = \max(0, S - R_t) \cdot \mathbb{1}(R_t < s)$是状态到动作的直接映射。

**题目2**：设$p=10, c=6, h=1, b=5$，需求服从$N(10, 3^2)$。如果不考虑未来（单阶段），最优订货量是多少？

**参考答案**：单阶段问题退化为报童问题。Base-Stock水平应满足$P(D \leq S^*) = (p-c+b)/(p+b) = (4+5)/(10+5) = 0.6$，所以$S^* = 10 + 3 \times \Phi^{-1}(0.6) \approx 10 + 3 \times 0.253 = 10.76$。

### 进阶题

**题目3**：原书（Ch 8.2）提到库存问题可以包含"预测信息"$f_{tt'}^D$（在$t$时刻对$t'$时刻需求的预测）。加入预测信息后，状态变量如何变化？这对DP求解有什么影响？

**参考答案**：
- 状态变为$S_t = (R_t, f_{t,t+1}^D, f_{t,t+2}^D, ..., f_{t,t+L}^D)$，其中$L$是预测窗口长度
- 状态空间从$|\mathcal{R}|$增长到$|\mathcal{R}| \times |\mathcal{F}|^L$，维度灾难加剧
- 但预测信息可以显著改善决策质量（更精确的需求估计）
- 实践中通常用PFA或VFA来近似处理高维状态

### 开放思考题

**题目4**：原书用库存问题展示四种策略类。请思考：对于一个大型的多产品、多仓库库存系统（如京东、亚马逊），你会选择哪种策略类？为什么？

**参考答案方向**：
- 大规模系统精确DP不可行，必须在四种策略类中选择
- PFA($(s,S)$策略)最简单，适合产品数很多但单产品不复杂的场景
- VFA（值函数近似）适合产品间有相关性的场景，但训练复杂
- CFA（成本函数近似）适合有约束（总预算、仓储容量）的场景
- DLA（直接前瞻）适合关键产品（高价值、需求波动大）
- 实际系统通常组合使用：普通产品用PFA，核心产品用DLA
