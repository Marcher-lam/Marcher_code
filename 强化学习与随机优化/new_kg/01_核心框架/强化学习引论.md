> Agent通过与环境交互的试错过程学习最优策略，是序贯决策问题的核心方法论之一。

> 来源线索：本节内容根据原书中关于"Reinforcement Learning"的相关章节(Ch 2.1.5)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：强化学习是智能体(agent)在与环境(environment)交互的过程中，通过试错和奖励信号学习最优行为策略的方法。

**直觉类比**：想象你第一次玩一个新游戏——没有人告诉你规则，但每做一步操作，游戏会给你一个分数（奖励）。通过反复尝试不同的操作并观察结果，你逐渐学会哪些操作在什么情况下是好选择。这就是强化学习。

**历史背景**：强化学习的理论基础来自Bellman(1957)的动态规划和Watkins(1989)的Q-learning。Sutton & Barto的经典教材(1998, 2018)系统化了RL领域。深度学习的突破使RL在2013年后迅速发展（DQN、AlphaGo等）。本书(Powell 2022)的独特视角是将RL置于"四大策略类别"的统一框架中。

**算法定位**：RL ≈ 动态规划 + 函数近似 + 试错学习。在本书框架中，RL不是单一方法，而是PFA/CFA/VFA/DLA四大策略类别的综合应用。

**前置知识**：
- 马尔可夫决策过程(MDP)
- Bellman方程
- 概率论与期望
- 基本优化方法

## 2. 核心原理

**核心思想**：RL的核心循环是 **状态-动作-奖励-新状态(SARS)**：

1. 智能体在状态 $s_t$ 选择动作 $a_t$
2. 环境返回奖励 $r_{t+1}$ 和新状态 $s_{t+1}$
3. 智能体根据经验更新策略或值函数

**RL的核心要素**：

- **策略(Policy)** $\pi$：从状态到动作的映射，即决策规则
- **值函数(Value Function)** $V^\pi(s)$：在状态 $s$ 下遵循策略 $\pi$ 的期望累计奖励
- **模型(Model)**：环境的转移概率 $P(s'|s,a)$ 和奖励函数 $R(s,a)$
- **Q函数** $Q^\pi(s,a)$：在状态 $s$ 执行动作 $a$ 后遵循策略 $\pi$ 的期望值

**RL与本书四大策略类别的关系**：

| 策略类别 | RL中的对应 |
|---|---|
| PFA（策略函数近似） | 直接参数化策略（策略梯度、REINFORCE） |
| CFA（成本函数近似） | 参数化目标函数中的修正项 |
| VFA（值函数近似） | Q-learning、SARSA、TD学习 |
| DLA（直接前瞻近似） | MCTS、规划方法 |

**Model-free vs Model-based**：

- **Model-free**：不学习环境模型，直接从经验学习值函数或策略（如Q-learning）
- **Model-based**：先学习环境模型，再用模型规划（如Dyna-Q）

**关键概念**：

- **探索vs利用**：尝试新动作 vs 选择已知好动作
- **时序差分(TD)学习**：自举(bootstrap)更新值函数
- **广义策略迭代**：策略评估 + 策略改进交替进行

## 3. Python 实现

```python
import numpy as np

class SimpleRL:
    """简单的GridWorld RL示例"""

    def __init__(self, size=4):
        self.size = size
        self.actions = [(0,1),(0,-1),(1,0),(-1,0)]  # 右左下上
        self.V = np.zeros((size, size))
        self.gamma = 0.9
        self.goal = (size-1, size-1)

    def is_valid(self, s):
        return 0 <= s[0] < self.size and 0 <= s[1] < self.size

    def value_iteration(self, n_iter=100):
        """值迭代——最基本的RL/DP方法"""
        for _ in range(n_iter):
            V_new = np.zeros_like(self.V)
            for i in range(self.size):
                for j in range(self.size):
                    if (i, j) == self.goal:
                        V_new[i, j] = 0
                        continue
                    values = []
                    for di, dj in self.actions:
                        ni, nj = i+di, j+dj
                        if self.is_valid((ni, nj)):
                            values.append(-1 + self.gamma * self.V[ni, nj])
                        else:
                            values.append(-1 + self.gamma * self.V[i, j])
                    V_new[i, j] = max(values)
            self.V = V_new
        return self.V

rl = SimpleRL()
V = rl.value_iteration()
print("最优值函数:")
print(np.round(V, 1))
```

## 4. 与其他方法的关系

| 领域 | 与RL的关系 |
|---|---|
| 动态规划 | DP是RL的理论基础，但DP需要完整模型 |
| 最优控制 | 最优控制是RL的连续版本 |
| 监督学习 | SL从标签学习，RL从奖励信号学习 |
| 赌博机理论 | 单状态RL问题 |
| 仿真优化 | 可视为无状态转移的RL |

**本书的独特贡献**：将RL从"方法集合"提升为"策略类别"的统一框架——PFA、CFA、VFA、DLA不只是RL的子方法，而是所有序贯决策问题的四种根本策略设计思路。
