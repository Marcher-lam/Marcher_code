# 决策树(Decision Trees) 学习文档

> 用树形结构表示决策序列，通过逆向归纳求解最优决策路径，是序贯决策问题最直观的入门工具。

> 来源线索：本节内容根据原书中关于"Decision Trees"的相关章节(Ch 2.1.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：决策树是一种用树形图表示序贯决策过程的分析工具，节点分为决策节点（决策者选择）和机会节点（随机事件），通过逆向归纳从叶子节点回推最优决策。

**直觉类比**：想象你在做人生决策——读研还是工作？每一步选择后又有新的分支（选什么专业、去哪家公司），每条路径有不同的收益。决策树把所有可能的选择和结果画成"树枝"，然后从终点往回算，找到期望收益最高的路径。

**历史背景**：决策树分析起源于决策论和运筹学，是决策分析(Decision Analysis)领域的核心工具。Raiffa & Schlaifer (1961)系统化了决策树方法。在机器学习中，决策树也被用作分类/回归模型（CART、ID3等），但本书中的决策树特指序贯决策分析工具。

**算法定位**：序贯决策问题的最简表示形式。决策树是理解MDP、动态规划和随机规划的起点。

**前置知识**：
- 概率论（期望值、条件概率）
- 逆向归纳思想
- 基本图论（树结构）

## 2. 核心原理

**核心思想**：决策树将序贯决策问题建模为一棵有向树：
- **决策节点**（方框）：决策者在此选择一个动作
- **机会节点**（圆圈）：随机事件按概率分布产生不同结果
- **叶子节点**（终端）：最终收益/成本

通过逆向归纳（从叶子向根回推），在每个机会节点计算期望值，在每个决策节点选择最优动作。

**工作流程**：

1. 从根节点出发，画出所有可能的决策-事件序列
2. 在叶子节点标注收益值
3. 逆向遍历：
   - 遇到机会节点：计算所有分支的期望值
   - 遇到决策节点：选择使期望值最大（或最小）的动作
4. 标记最优路径

**关键概念**：

- **期望值准则**：在机会节点用概率加权计算期望收益
- **逆向归纳**：从终端向起点回推求解
- **信息集**：决策者在某节点所知的信息
- **完全信息价值(EVPI)**：知道未来随机事件确切值后的期望收益提升

**数学表述**：

对机会节点 $n$，期望值为：
$$EV(n) = \sum_{s \in \text{successors}(n)} P(s) \cdot V(s)$$

对决策节点 $n$，最优值为：
$$V(n) = \max_{a \in A(n)} EV(\text{child}(n, a))$$

## 3. Python 实现

```python
import numpy as np

def decision_tree_example():
    """
    示例：石油钻探决策
    - 钻探成本：$70K
    - 有油概率：0.3，收益$200K
    - 无油概率：0.7，收益$0
    - 不钻探：收益$0
    """
    drill_cost = 70
    oil_value = 200
    p_oil = 0.3

    # 机会节点：钻探后的期望收益
    ev_drill = p_oil * oil_value + (1 - p_oil) * 0 - drill_cost

    # 决策节点：max(钻探, 不钻探)
    ev_no_drill = 0
    best = max(ev_drill, ev_no_drill)
    action = "钻探" if ev_drill > ev_no_drill else "不钻探"

    print(f"钻探期望收益: ${ev_drill:.0f}K")
    print(f"不钻探期望收益: ${ev_no_drill:.0f}K")
    print(f"最优决策: {action}")

decision_tree_example()
```

## 4. 与其他方法的关系

| 方法 | 与决策树的关系 |
|---|---|
| MDP | MDP是决策树的一般化：状态空间+转移概率 |
| 动态规划 | 逆向归纳就是有限horizon DP |
| 贝叶斯决策 | 决策树+先验/后验更新=贝叶斯决策分析 |
| 影响图 | 影响图是决策树的压缩表示 |
| 蒙特卡洛方法 | 当树太大时，用采样代替完全展开 |
