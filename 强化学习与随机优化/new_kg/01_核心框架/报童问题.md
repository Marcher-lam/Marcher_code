# 报童问题(Newsvendor Problem) 学习文档

> 在需求不确定下确定最优订货量，是随机优化的入门经典问题。

> 来源线索：本节内容根据原书中关于"The Newsvendor Problems"的相关章节(Ch 2.3.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：报童问题在需求随机的情况下，决定最优订货量以最大化期望利润——订多了亏损成本，订少了损失收入。

**直觉类比**：你是一个报童，每天早上要决定批发多少份报纸。批发价$c$元，零售价$p$元。如果需求大于订量，少卖的钱就是损失；如果订量大于需求，剩下的报纸只能当废纸。你需要找到一个"刚好够"的数量，使得边际收益恰好等于边际期望损失。

**历史背景**：报童问题是运筹学中最经典的随机优化问题之一，最初由Edgeworth (1888)在银行储备问题中研究。名称来自"报纸零售商"的比喻。现代应用涵盖供应链管理、容量规划、广告竞价等领域。它是理解库存问题和多阶段随机规划的起点。

**算法定位**：随机优化/单阶段决策。报童问题是理解更复杂序贯决策问题的基础——库存问题是它的多阶段扩展。

**前置知识**：
- 概率分布（CDF、PDF、分位数）
- 期望值与积分
- 微积分（求导求极值）
- Python编程基础

## 2. 核心原理

**核心思想**：寻找订货量$x^*$使得边际利润等于边际成本的期望。最优解满足临界比率条件：

$$\mathbb{P}(W \leq x^*) = \frac{p - c}{p} = \frac{\text{单位缺货损失}}{\text{单位缺货损失} + \text{单位过剩损失}}$$

当需求分布已知时，最优订货量就是需求分布的对应分位数。当分布未知时，可以通过在线学习逐步逼近最优解。

**工作流程**：

1. 确定售价$p$、成本$c$和需求的分布$F_W(w)$
2. 计算临界比率$CR = (p-c)/p$
3. 求解$x^* = F_W^{-1}(CR)$
4. 当分布未知时，通过在线学习逐步估计最优订货量

**关键概念**：

- **临界比率(Critical Ratio)**：$CR = (p-c)/p$，决定最优解在需求分布中的位置
- **边际分析**：多订一份的期望收益 vs 期望损失
- **审查观测(Censored Observations)**：通常只能观测到$\min(x, W)$而非真实需求$W$
- **最终奖励 vs 累积奖励**：原书区分了静态（只看最终决策质量）和动态（累积学习过程中的利润）两种形式

**几何直观**：

```
期望利润 E[F(x)]
    │        ╱‾‾‾‾‾╲
    │      ╱         ╲
    │    ╱              ╲
    │  ╱                   ╲
    │╱────────────────────────╲
    └────────────────────────── 订货量 x
                ↑
              x* = F⁻¹(CR)
         (期望利润最大点)
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $x$ | 订货量（决策变量） |
| $W$ | 随机需求 |
| $p$ | 单位售价 |
| $c$ | 单位成本 |
| $F_W(w)$ | 需求的累积分布函数(CDF) |
| $f_W(w)$ | 需求的概率密度函数(PDF) |
| $CR$ | 临界比率 $(p-c)/p$ |

### 利润函数

$$F(x, W) = p\min\{x, W\} - cx$$

- $x$：订货量（决策变量）
- $W$：随机需求
- 过剩损失：$c \cdot \max(0, x - W)$（订多了的成本浪费）
- 缺货损失：$(p-c) \cdot \max(0, W - x)$（订少了的利润损失）

### 最优解推导

期望利润：$\mathbb{E}_W[F(x,W)] = p\mathbb{E}[\min(x,W)] - cx$

当需求$W$有连续CDF $F_W(w)$时：

$$\mathbb{E}[\min(x,W)] = \int_0^x wf(w)dw + x(1-F_W(x))$$

对$x$求导：

$$\frac{d}{dx}\mathbb{E}[\min(x,W)] = 1 - F_W(x)$$

令导数为0：

$$p(1 - F_W(x^*)) - c = 0 \implies F_W(x^*) = \frac{p-c}{p}$$

因此：

$$x^* = F_W^{-1}\left(\frac{p-c}{p}\right)$$

**直觉解读**：临界比率$CR = (p-c)/p$等于"卖掉一份赚的"占"相关总收益"的比例。$CR$越高，说明缺货代价越大，应该多订。

### 利润的二阶分析

$$\frac{d^2}{dx^2}\mathbb{E}[F(x,W)] = -pf_W(x) < 0$$

因此期望利润关于$x$是凹函数，存在唯一最大值。

### 多维报童问题

$K$个产品共享产能约束$\sum_{k=1}^K x_k \leq U$：

$$\max_{x_1,...,x_K} \mathbb{E}\sum_{k=1}^K [p_k\min(x_k, W_k) - c_kx_k]$$

通过Lagrangian松弛可以分解为$K$个独立的单产品问题。

### 在线学习版本

当需求分布未知时，使用Bandit策略（如$\varepsilon$-greedy、Thompson采样）在线学习最优订货量。每步选择$x^n$，观察$\min(x^n, W^{n+1})$，更新对需求分布的信念。

## 4. 训练过程讲解

### 参数初始化
- 已知分布时：直接计算$x^* = F_W^{-1}(CR)$
- 未知分布时：初始化候选订货量集合和利润统计

### 离线求解过程
1. 确定价格参数$p, c$
2. 计算临界比率$CR = (p-c)/p$
3. 利用需求分布的分位数函数求解$x^*$

### 在线学习过程
1. 设定候选订货量集合$\mathcal{X} = \{x_1, ..., x_K\}$
2. 每轮用$\varepsilon$-greedy选择$x^n$
3. 观察需求$W^{n+1}$，计算利润$F(x^n, W^{n+1})$
4. 更新该订货量的平均利润
5. 逐步降低$\varepsilon$

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $p$ | 单位售价 | 已知参数 | 10 |
| $c$ | 单位成本 | 已知参数 | 6 |
| 需求分布 | $F_W(w)$ | 已知或估计 | $N(100, 20^2)$ |
| $\varepsilon$ | 探索率（在线） | [0.05, 0.3] | 0.1 |
| 候选数量 | 订货量候选数 | [10, 50] | 20 |

## 5. 应用场景

### 1. 供应链库存管理
为什么适合：季节性商品（如圣诞礼物、时装）需要在季节开始前决定订货量，需求随机且过季清仓损失大。报童模型直接适用。

### 2. 航空座位超售
为什么适合：座位=报纸，乘客=需求。航空公司决定超售多少座位，多了要赔偿（过剩成本），少了浪费座位（缺货成本）。

### 3. 容量规划
为什么适合：服务器容量=订货量，用户请求=需求。容量过剩浪费资源，容量不足损失用户。

### 4. 广告竞价
为什么适合：预算=订量，用户点击=需求。预算用不完=浪费曝光机会，预算超支=错过高价值用户。

### 不适用场景
- 多阶段决策（应使用库存问题/MDP框架）
- 需求可通过信息更新预测（应使用贝叶斯更新）
- 有订货提前期（应使用多阶段模型）

## 6. 优缺点分析

### 优点
1. **解析解简洁**：$x^* = F_W^{-1}(CR)$，一行公式即可求解（成立条件：需求分布已知且连续）
2. **直觉清晰**：临界比率平衡缺货与过剩成本
3. **扩展性强**：可推广到多维、在线学习、鲁棒优化等
4. **教学价值高**：是理解随机优化的最佳入门问题

### 缺点
1. **单阶段模型**：忽略时序关系，无法处理多阶段库存问题
2. **假设分布已知**：实际中需求分布往往未知或非平稳
3. **忽略订货提前期**：实际供应链有交货延迟
4. **线性成本假设**：实际可能有固定订货成本（setup cost）

### 算法对比

| 特性 | 解析解 | 在线学习 | 鲁棒优化 | 采样方法 |
|------|--------|----------|----------|----------|
| 需求模型 | 已知 | 未知 | 不确定性集 | 仿真 |
| 最优性 | 精确最优 | 渐近最优 | 最坏情况最优 | 近似 |
| 计算复杂度 | $O(1)$ | $O(nK)$ | $O(K)$ | $O(nK)$ |
| 数据需求 | 无 | 历史数据 | 不确定性集 | 仿真样本 |

## 7. 调库实现

```python
"""
报童问题：解析解与在线学习
使用scipy.stats处理需求分布
"""
import numpy as np
from scipy import stats

class NewsvendorProblem:
    """报童问题求解器"""

    def __init__(self, price, cost, demand_dist=None):
        self.p = price
        self.c = cost
        self.dist = demand_dist  # scipy分布对象
        self.cr = (price - cost) / price  # 临界比率

    def optimal_order(self):
        """已知分布时的解析最优解"""
        if self.dist is None:
            raise ValueError("需求分布未知")
        return self.dist.ppf(self.cr)

    def profit(self, x, demand):
        """计算单次利润"""
        return self.p * min(x, demand) - self.c * x

    def expected_profit(self, x, n_samples=100000):
        """蒙特卡洛估计期望利润"""
        demands = self.dist.rvs(n_samples)
        profits = self.p * np.minimum(x, demands) - self.c * x
        return np.mean(profits)

    def profit_curve(self, x_range, n_samples=100000):
        """计算不同订货量的期望利润"""
        demands = self.dist.rvs(n_samples)
        profits = []
        for x in x_range:
            p = np.mean(self.p * np.minimum(x, demands) - self.c * x)
            profits.append(p)
        return np.array(profits)


class OnlineNewsvendor:
    """分布未知时的在线学习"""

    def __init__(self, price, cost, x_range):
        self.p = price
        self.c = cost
        self.x_range = x_range
        self.n_tries = np.zeros(len(x_range))
        self.total_profit = np.zeros(len(x_range))

    def choose_order(self, epsilon=0.1):
        """ε-greedy策略选择订货量"""
        if np.random.random() < epsilon:
            idx = np.random.randint(len(self.x_range))
        else:
            avg = np.where(self.n_tries > 0,
                          self.total_profit / np.maximum(self.n_tries, 1), -np.inf)
            idx = np.argmax(avg)
        return idx, self.x_range[idx]

    def update(self, idx, demand):
        """更新利润统计"""
        x = self.x_range[idx]
        profit = self.p * min(x, demand) - self.c * x
        self.n_tries[idx] += 1
        self.total_profit[idx] += profit
        return profit


if __name__ == "__main__":
    np.random.seed(42)
    p, c = 10.0, 6.0
    dist = stats.norm(loc=100, scale=20)

    # 解析解
    nv = NewsvendorProblem(p, c, dist)
    x_opt = nv.optimal_order()
    print(f"临界比率: {nv.cr:.2f}")
    print(f"最优订货量: {x_opt:.1f}")
    print(f"最优期望利润: {nv.expected_profit(x_opt):.2f}")

    # 在线学习
    online = OnlineNewsvendor(p, c, list(range(50, 151, 5)))
    total_profit = 0
    for day in range(1000):
        idx, x = online.choose_order(epsilon=max(0.05, 0.3 - day*0.0003))
        demand = dist.rvs()
        total_profit += online.update(idx, demand)

    best_x = online.x_range[np.argmax(
        np.where(online.n_tries > 0, online.total_profit / online.n_tries, -np.inf))]
    print(f"\n在线学习1000天后:")
    print(f"学到的最优订货量: {best_x}")
    print(f"累计利润: {total_profit:.1f}")
```

## 8. 手工代码实现

```python
"""
从零实现报童问题求解器
纯NumPy，无scipy依赖
"""
import numpy as np

class Newsvendor:
    """报童问题完整实现"""

    def __init__(self, price=10, cost=6, demand_mean=100, demand_std=20):
        self.p = price
        self.c = cost
        self.cr = (price - cost) / price
        self.demand_mean = demand_mean
        self.demand_std = demand_std

    def profit(self, x, demand):
        """单次利润"""
        return self.p * min(x, demand) - self.c * x

    def expected_profit_mc(self, x, n_samples=50000):
        """蒙特卡洛估计期望利润"""
        demands = np.random.normal(self.demand_mean, self.demand_std, n_samples)
        return np.mean(self.p * np.minimum(x, demands) - self.c * x)

    def optimal_order_numerical(self, x_range=None):
        """数值搜索最优订货量"""
        if x_range is None:
            x_range = np.arange(
                max(0, self.demand_mean - 3*self.demand_std),
                self.demand_mean + 3*self.demand_std, 0.5)
        profits = np.array([self.expected_profit_mc(x) for x in x_range])
        best_idx = np.argmax(profits)
        return x_range[best_idx], profits[best_idx]

    def grid_search(self, x_candidates, n_samples=50000):
        """网格搜索：评估每个候选订货量"""
        demands = np.random.normal(self.demand_mean, self.demand_std, n_samples)
        results = {}
        for x in x_candidates:
            profits = self.p * np.minimum(x, demands) - self.c * x
            results[x] = (np.mean(profits), np.std(profits))
        return results


class BayesianNewsvendor:
    """贝叶斯报童：在线学习需求分布"""

    def __init__(self, price=10, cost=6, mu_0=100, sigma_0=50, sigma_w=20):
        self.p = price
        self.c = cost
        self.mu = mu_0        # 需求均值的先验均值
        self.sigma = sigma_0  # 需求均值的不确定性
        self.sigma_w = sigma_w  # 需求噪声标准差
        self.n_obs = 0

    def optimal_order(self):
        """基于当前信念计算最优订货量"""
        # CR = (p-c)/p, 需要的z值 = Φ⁻¹(CR)
        # 简化：用标准正态近似
        cr = (self.p - self.c) / self.p
        z = self._normal_ppf_approx(cr)
        return max(0, self.mu + self.sigma_w * z)

    def update(self, observed_demand):
        """贝叶斯更新需求分布的信念"""
        self.n_obs += 1
        # 后验均值：加权平均
        w = self.sigma_w**2 / (self.sigma_w**2 + self.sigma**2)
        self.mu = w * observed_demand + (1 - w) * self.mu
        # 后验标准差：缩小
        self.sigma = np.sqrt(1.0 / (1.0/self.sigma**2 + 1.0/self.sigma_w**2))

    def _normal_ppf_approx(self, p):
        """标准正态分位数的简单近似"""
        # Rational approximation (Abramowitz & Stegun)
        if p <= 0.5:
            t = np.sqrt(-2 * np.log(p))
            return -(2.515517 + 0.802853*t + 0.010328*t*t) / (1 + 1.432788*t + 0.189269*t*t + 0.001308*t*t*t)
        else:
            return -self._normal_ppf_approx(1 - p)


# ========== 测试 ==========
if __name__ == "__main__":
    np.random.seed(42)

    # 1. 数值求解
    nv = Newsvendor(price=10, cost=6, demand_mean=100, demand_std=20)
    x_opt, profit_opt = nv.optimal_order_numerical()
    print(f"数值最优订货量: {x_opt:.1f}, 期望利润: {profit_opt:.2f}")

    # 2. 网格搜索
    results = nv.grid_search(range(50, 151, 5))
    best_x = max(results, key=lambda x: results[x][0])
    print(f"网格搜索最优: x={best_x}, 利润={results[best_x][0]:.2f}")

    # 3. 贝叶斯在线学习
    bnv = BayesianNewsvendor(price=10, cost=6, mu_0=80, sigma_0=50, sigma_w=20)
    print(f"\n贝叶斯报童初始最优订货量: {bnv.optimal_order():.1f}")
    for day in range(200):
        true_demand = np.random.normal(100, 20)
        bnv.update(true_demand)
        if (day + 1) % 50 == 0:
            print(f"  第{day+1}天: 信念均值={bnv.mu:.1f}, 最优订货量={bnv.optimal_order():.1f}")
```

## 9. 可视化与结果理解

```python
"""
报童问题可视化：利润曲线和在线学习过程
"""
import matplotlib.pyplot as plt
import numpy as np

def visualize_newsvendor(nv, x_range=None):
    """可视化报童问题的利润曲线"""
    if x_range is None:
        x_range = np.linspace(20, 180, 200)

    profits = np.array([nv.expected_profit_mc(x, n_samples=100000) for x in x_range])

    fig, axes = plt.subplots(1, 2, figsize=(14, 5))

    # 1. 期望利润曲线
    axes[0].plot(x_range, profits, 'b-', linewidth=2)
    x_opt = x_range[np.argmax(profits)]
    axes[0].axvline(x_opt, color='r', linestyle='--', label=f'$x^*={x_opt:.0f}$')
    axes[0].set_xlabel('订货量 $x$')
    axes[0].set_ylabel('期望利润 $\\mathbb{E}[F(x,W)]$')
    axes[0].set_title('报童问题：期望利润曲线')
    axes[0].legend()
    axes[0].grid(True, alpha=0.3)

    # 2. 利润分布（在x*处）
    np.random.seed(42)
    demands = np.random.normal(100, 20, 10000)
    profits_at_opt = nv.p * np.minimum(x_opt, demands) - nv.c * x_opt
    axes[1].hist(profits_at_opt, bins=50, alpha=0.7, edgecolor='black')
    axes[1].axvline(np.mean(profits_at_opt), color='r', linestyle='--',
                    label=f'均值={np.mean(profits_at_opt):.0f}')
    axes[1].set_xlabel('利润')
    axes[1].set_ylabel('频数')
    axes[1].set_title(f'在$x^*={x_opt:.0f}$处的利润分布')
    axes[1].legend()
    axes[1].grid(True, alpha=0.3)

    plt.tight_layout()
    plt.savefig('newsvendor_visualization.png', dpi=150, bbox_inches='tight')
    plt.show()
```

**结果解读**：
- 期望利润曲线呈倒U形：订太少（缺货）或订太多（过剩）都会降低利润
- 最优点$x^*$处，边际过剩损失等于边际缺货损失
- 利润分布通常右偏：大部分时候利润集中，偶尔因为需求极端而利润大幅下降

## 10. 模型评估

```python
"""
报童策略评估
"""
import numpy as np

def evaluate_newsvendor(policy_fn, demand_dist, price, cost, n_days=1000, label="策略"):
    """评估订货策略的长期表现"""
    daily_profits = []
    daily_demands = []
    stockouts = 0
    leftovers = 0

    for _ in range(n_days):
        x = policy_fn()
        d = demand_dist()
        profit = price * min(x, d) - cost * x
        daily_profits.append(profit)
        daily_demands.append(d)
        if d > x:
            stockouts += 1
        if x > d:
            leftovers += 1

    print(f"{label}评估（{n_days}天）：")
    print(f"  平均利润: {np.mean(daily_profits):.2f} +/- {np.std(daily_profits):.2f}")
    print(f"  缺货天数: {stockouts} ({stockouts/n_days:.1%})")
    print(f"  过剩天数: {leftovers} ({leftovers/n_days:.1%})")
    print(f"  最小利润: {np.min(daily_profits):.1f}")
    return np.mean(daily_profits)
```

**评估指标说明**：
- **平均利润**：策略的核心度量
- **缺货率**：需求超过订量的比例，过高说明订货不足
- **过剩率**：订量超过需求的比例，过高说明订货过多
- **利润标准差**：策略的风险度量

## 11. 常见问题与易错点

### 数据层面

1. **审查观测忽略**
   - 现象：需求估计持续偏低
   - 原因：只能观测到$\min(x, D)$而非真实需求$D$，缺货时低估需求
   - 解决方案：使用贝叶斯方法处理审查数据，或用Upper Confidence Bound修正

2. **需求分布假设错误**
   - 现象：实际利润显著低于理论最优
   - 原因：假设正态分布但实际有偏斜或重尾
   - 解决方案：使用非参数估计或鲁棒优化

### 模型层面

3. **忽略固定订货成本**
   - 现象：频繁小批量订货，总订货次数过多
   - 原因：标准报童模型假设线性成本，实际有固定setup cost
   - 解决方案：使用$(s, S)$策略或加入固定成本项

4. **单阶段假设过强**
   - 现象：剩余库存被浪费
   - 原因：标准模型假设未售出产品无残值
   - 解决方案：加入残值参数$v$，利润函数变为$F(x,W) = p\min(x,W) + v\max(0,x-W) - cx$

### 调参层面

5. **在线学习的探索不足**
   - 现象：收敛到次优订货量
   - 原因：$\varepsilon$衰减太快
   - 解决方案：使用Thompson采样代替$\varepsilon$-greedy

## 12. 学习总结

报童问题是随机优化的"Hello World"——结构简单但包含随机决策的核心要素：不确定需求、成本权衡、最优决策。其解析解$x^* = F_W^{-1}(\frac{p-c}{p})$体现了边际分析的思想。

**关键公式**：
1. 临界比率：$CR = (p-c)/p$
2. 最优订货量：$x^* = F_W^{-1}(CR)$
3. 期望利润：$\mathbb{E}[F(x,W)] = p\mathbb{E}[\min(x,W)] - cx$

报童问题是库存问题（多阶段扩展）的前置知识，也是原书贯穿全书的案例——从第2章的建模到在线学习（Ch 3）、策略设计（Ch 12）、鲁棒优化（Ch 19）都能看到报童问题的身影。

## 13. 练习题与思考题

### 基础题

**题目1**：$p=10, c=6$，需求服从$N(100, 20^2)$，最优订货量是多少？

**参考答案**：
$CR = (10-6)/10 = 0.4$
$x^* = \mu + \sigma \cdot \Phi^{-1}(0.4) = 100 + 20 \times (-0.253) = 94.94 \approx 95$

**题目2**：如果成本$c$上升到8（售价$p=10$不变），最优订货量应该增加还是减少？直觉解释。

**参考答案**：
$CR = (10-8)/10 = 0.2$，比之前的0.4更小。$x^* = 100 + 20 \times \Phi^{-1}(0.2) = 100 + 20 \times (-0.842) = 83.16$。订货量减少，因为单位利润空间缩小，缺货损失相对变小，不值得冒过多过剩的风险。

### 进阶题

**题目3**：考虑有残值$v=2$的报童问题。利润函数变为$F(x,W) = p\min(x,W) + v\max(0, x-W) - cx$。求新的最优解条件。

**参考答案**：
过剩损失变为$c-v$（而非$c$），缺货损失仍为$p-c$。
新的临界比率：$CR = (p-c)/(p-c + c-v) = (p-c)/(p-v)$
$F_W(x^*) = (p-c)/(p-v) = (10-6)/(10-2) = 0.5$
$x^* = 100$（恰好是需求均值）

### 开放思考题

**题目4**：原书（Ch 2.3.1, Ch 4.2.2）区分了"最终奖励"（final reward）和"累积奖励"（cumulative reward）两种报童问题设定。这两种设定有什么本质区别？在实际中，哪种更常见？

**参考答案方向**：
- 最终奖励：只关心最终学到的策略有多好（不考虑学习过程中的损失）
- 累积奖励：关心整个学习过程中的总利润（包括探索的代价）
- 本质区别：最终奖励允许大量探索（因为过程不扣分），累积奖励要求高效探索
- 实际应用中通常是累积奖励——企业不能为了"学习"而牺牲当期利润
- 这引出了探索-利用困境，是后续多臂赌博机（Ch 7）和在线学习（Ch 3）的核心主题
