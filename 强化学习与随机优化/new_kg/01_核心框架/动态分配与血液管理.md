# 动态分配与血液管理(Dynamic Assignment / Blood Management) 学习文档

> 资源匹配问题的序贯决策版本——将有限资源（如血液）动态分配到需求点。

> 来源线索：Ch 8.3, 13.2.2, 20.6

## 1. 基础认知

**一句话定义**：动态分配问题在时间维度上将有限资源分配给需求，如将不同血型的血液分配到各医院。

## 2. 核心原理

**动态分配模型**：
- **资源** $R_t$：各类型资源的可用量
- **需求** $\hat{D}_t$：随机到达的需求
- **决策** $x_t$：分配方案
- **目标**：最小化未满足需求 + 库存过期

**血液管理**：
- 血型匹配约束（O型可给任何型，AB型只能给AB型）
- 血液有保质期
- 需求随机且可能紧急
- 空间分布：多个医院/血站

**策略方法**：
- CFA：参数化的分配优化模型
- VFA：学习资源水平的边际价值
- DLA：前瞻需求预测

## 3. Python 实现

```python
import numpy as np

def blood_allocation_sim(n_hospitals=4, blood_types=['O','A','B','AB']):
    supply = {bt: np.random.randint(5, 20) for bt in blood_types}
    total_shortage = 0

    for day in range(50):
        demands = {bt: np.random.poisson(3, n_hospitals) for bt in blood_types}
        for bt in blood_types:
            total = sum(demands[bt])
            if supply[bt] >= total:
                supply[bt] -= total
            else:
                total_shortage += total - supply[bt]
                supply[bt] = 0
        supply = {bt: supply[bt] + np.random.poisson(4) for bt in blood_types}

    print(f"总短缺: {total_shortage}")
    print(f"最终库存: {supply}")

blood_allocation_sim()
```
