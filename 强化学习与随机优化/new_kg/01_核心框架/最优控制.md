# 最优控制(Optimal Control) 学习文档

> 起源于工程领域的控制理论，处理连续状态/连续时间的系统优化，是MDP在连续域的对应。

> 来源线索：本节内容根据原书中关于"Optimal Control"的相关章节(Ch 2.1.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：最优控制理论在给定系统动态方程的约束下，寻找使目标函数（如能量消耗最小、收益最大）最优的控制输入序列。

**直觉类比**：想象你在驾驶一艘飞船从地球飞往火星。你需要不断调整推力方向和大小（控制输入），同时考虑燃料消耗和飞行时间。最优控制告诉你如何在所有可能的控制方案中找到最优的一个。

**历史背景**：最优控制理论在1950-60年代由Pontryagin（最大值原理）和Bellman（动态规划）分别发展。Pontryagin的最大值原理是变分法的推广，Bellman的HJB方程将最优控制与动态规划联系起来。广泛应用于航空航天（Apollo计划）、机器人、过程控制和经济学。

**算法定位**：连续状态/连续时间版本的序贯决策问题。与MDP互为对偶——MDP用离散状态/时间，最优控制用连续状态/时间。

**前置知识**：
- 微分方程（ODE）
- 变分法基础
- 线性代数
- Bellman方程

## 2. 核心原理

**核心思想**：确定性最优控制问题的标准形式：

$$\min_{u_0,...,u_T} \sum_{t=0}^{T} C(s_t, u_t)$$

受约束于系统动态（转移函数）：
$$s_{t+1} = f(s_t, u_t)$$

随机最优控制引入随机噪声：
$$s_{t+1} = f(s_t, u_t) + w_t$$

**确定性最优控制**：
- 系统模型（状态方程）：$\dot{x} = f(x, u, t)$
- 控制输入 $u(t) \in \mathcal{U}$
- 目标：$\min J = \phi(x(t_f)) + \int_0^{t_f} L(x, u, t) dt$

**Hamilton-Jacobi-Bellman方程**：
$$-\frac{\partial V}{\partial t} = \min_{u} \left[ C(s, u) + \nabla_s V \cdot f(s, u) \right]$$

**LQR（线性二次调节）**是最经典的确定性最优控制问题：
- 状态方程：$s_{t+1} = As_t + Bu_t$
- 目标：$\min \sum_{t=0}^{T} (s_t^T Q s_t + u_t^T R u_t)$
- 最优控制：$u_t^* = -K_t s_t$（线性反馈律）

**关键概念**：

- **状态方程**：描述系统如何演化的微分/差分方程
- **控制输入**：决策者可以操纵的变量
- **HJB方程**：连续版Bellman方程
- **Pontryagin最大值原理**：最优控制的必要条件
- **LQR**：线性系统+二次目标的最优控制解析解

## 3. Python 实现

```python
import numpy as np
from scipy.linalg import solve_discrete_are

def lqr_control(A, B, Q, R, T=50):
    """
    离散时间LQR控制器
    A, B: 系统矩阵
    Q: 状态惩罚矩阵
    R: 控制惩罚矩阵
    """
    n = A.shape[0]
    # 求解代数Riccati方程
    P = solve_discrete_are(A, B, Q, R)

    # 最优反馈增益
    K = np.linalg.inv(R + B.T @ P @ B) @ B.T @ P @ A

    return K, P

# 示例：一维质量-弹簧系统
A = np.array([[1.0, 0.1], [-0.5, 0.9]])  # 位置+速度
B = np.array([[0.0], [0.1]])              # 控制力
Q = np.eye(2) * 10                        # 状态惩罚
R = np.eye(1)                             # 控制惩罚

K, P = lqr_control(A, B, Q, R)
print(f"最优反馈增益 K = {K}")
print(f"最优控制律: u_t = -K @ s_t")
```

## 4. 与其他方法的关系

| 方法 | 与最优控制的关系 |
|---|---|
| MDP | 最优控制是MDP的连续版本 |
| 动态规划 | HJB方程是Bellman方程的连续极限 |
| LQR | 最简单的最优控制问题，有解析解 |
| MPC | 用滚动horizon近似最优控制 |
| 强化学习 | RL = 最优控制 + 函数近似 + 试错学习 |

**MDP vs 最优控制记号对比**：

| MDP | 最优控制 |
|---|---|
| 状态 $s$ | 状态 $x$ |
| 动作 $a$ | 控制 $u$ |
| 转移概率 $P(s'|s,a)$ | 系统方程 $\dot{x}=f(x,u)$ |
| 奖励 $r(s,a)$ | 代价 $L(x,u)$ |
| 策略 $\pi$ | 控制律 $\mu(x)$ |
