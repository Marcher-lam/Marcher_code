# 车队管理与游牧卡车(Fleet Management / Nomadic Trucker) 学习文档

> 大规模资源分配的典型应用——管理车队在全国范围内的调度优化。

> 来源线索：Ch 8.1.2-8.1.3, 2.3.4

## 1. 基础认知

**一句话定义**：车队管理问题决定每辆车应该移动到哪里载货，以最小化空驶成本并最大化运输收益。

## 2. 核心原理

**游牧卡车问题**：单辆卡车在全国各地移动，每个城市有到其他城市的货物需求。决策者需要决定空车移动到哪里寻找下一单生意。

**模型要素**：
- **状态**：卡车当前位置 + 各城市货物需求
- **决策**：空车移动到哪个城市
- **目标**：最大化利润（运费 - 空驶成本）

**多车队扩展**：
- 多辆车可以形成网络流
- 可用资源分配的VFA方法（CAVE、分段线性）
- Benders分解处理大规模问题

## 3. Python 实现

```python
import numpy as np

def nomadic_trucker_sim(n_cities=10, n_steps=100):
    cities = list(range(n_cities))
    # 随机需求矩阵
    demand = np.random.poisson(2, (n_cities, n_cities))
    np.fill_diagonal(demand, 0)
    # 距离矩阵
    dist = np.random.randint(10, 100, (n_cities, n_cities))
    dist = (dist + dist.T) // 2

    pos = 0; profit = 0
    for _ in range(n_steps):
        # 找最有价值的下一个城市
        best_city, best_val = pos, 0
        for c in cities:
            if c == pos: continue
            expected_load = min(demand[pos, c], 1)
            val = expected_load * dist[pos, c] * 0.5 - dist[pos, c] * 0.1
            if val > best_val:
                best_city, best_val = c, val
        if best_city != pos:
            load = min(demand[pos, best_city], 1)
            profit += load * dist[pos, best_city] * 0.5 - dist[pos, best_city] * 0.1
            demand[pos, best_city] -= load
            pos = best_city
        demand += np.random.poisson(0.3, (n_cities, n_cities))
    return profit

print(f"游牧卡车总利润: ${nomadic_trucker_sim():.0f}")
```
