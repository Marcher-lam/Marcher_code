# 随机规划(Stochastic Programming) 学习文档

> 在约束条件下优化随机目标函数的期望值，是运筹学处理不确定性的核心框架。

> 来源线索：本节内容根据原书中关于"Stochastic Programming"的相关章节(Ch 2.1.8, Ch 19.9)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：随机规划在数学规划框架中直接处理随机参数，通过优化期望目标或概率约束来做出最优决策。

**直觉类比**：规划旅行路线。确定性规划假设天气确定，选出最短路线。随机规划考虑天气可能变化，选一个在各种天气下期望表现最好的路线。和鲁棒优化不同——鲁棒优化选"即使暴雨也安全"的路线，随机规划选"平均最快"的路线。

**历史背景**：随机规划由Dantzig (1955)和Beale (1955)创立。两阶段随机规划和Benders分解（L-shaped方法）是经典求解方法。原书Ch 2.1.8将随机规划分类为CFA策略的一种，Ch 19.9深入讨论了两阶段和多重情景方法。

**算法定位**：随机优化/数学规划。与鲁棒优化（最坏情况）和机会约束规划（概率保证）并列。

**前置知识**：
- 线性规划（单纯形法、对偶理论）
- 概率论（期望、条件期望）
- 蒙特卡洛采样

## 2. 核心原理

**核心思想**：将随机参数$\omega$的分布纳入优化模型。关键在于决策的时序——哪些决策在观测随机性之前做出（here-and-now），哪些在观测之后做出（wait-and-see）。

**三种常见形式**：

1. **期望值模型**：$\min_x \mathbb{E}_\omega[f(x, \omega)]$
2. **两阶段模型**：第一阶段决策$x$（观测前），第二阶段决策$y(x,\omega)$（观测后）
3. **机会约束模型**：$\mathbb{P}[g(x,\omega) \leq 0] \geq 1-\alpha$

**两阶段模型的工作流程**：
1. 第一阶段（here-and-now）：做决策$x$，成本$c^Tx$
2. 观测随机参数$\omega$的实现
3. 第二阶段（wait-and-see）：做补偿决策$y(x,\omega)$
4. 目标：$\min_x \{c^Tx + \mathbb{E}_\omega[Q(x,\omega)]\}$

**关键概念**：

- **Here-and-now决策**：在不确定性观测前做出的决策
- **Wait-and-see决策**：在不确定性观测后做出的决策
- **补偿函数(recourse function)**：$Q(x,\omega) = \min_y\{q^Ty : Wy = h(\omega)-T(\omega)x, y\geq 0\}$
- **样本平均近似(SAA)**：用有限样本近似期望
- **非预期性约束(nonanticipativity)**：第一阶段决策不能依赖未观测的信息

**几何直观**：

```
时间轴：
  第一阶段决策x ──→ 观测ω ──→ 第二阶段决策y(x,ω)
  (here-and-now)    (随机性    (wait-and-see)
   成本c^Tx          实现)      成本q^Ty
  
  目标: min_x { c^Tx + E_ω[Q(x,ω)] }
                    ↑
              第二阶段最优成本（关于ω取期望）
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $x$ | 第一阶段决策变量 |
| $y$ | 第二阶段决策变量 |
| $\omega$ | 随机参数（场景） |
| $c, q$ | 第一/二阶段成本向量 |
| $A, T, W$ | 约束矩阵 |
| $b, h$ | 约束右端项 |
| $Q(x,\omega)$ | 第二阶段最优值函数 |

### 两阶段随机线性规划

$$\min_x \left\{c^Tx + \mathbb{E}_\omega[\min_y q(\omega)^Ty]\right\}$$
$$\text{s.t. } Ax = b, \quad T(\omega)x + W(\omega)y = h(\omega), \quad y \geq 0$$

### 补偿函数

$$Q(x,\omega) = \min_y\{q(\omega)^Ty : W(\omega)y = h(\omega) - T(\omega)x, y \geq 0\}$$

当第二阶段不可行时，$Q(x,\omega) = +\infty$（惩罚不可行的第一阶段决策）。

### 样本平均近似(SAA)

$$\min_x \frac{1}{N}\sum_{n=1}^N Q(x, \omega^n)$$

**SAA的统计性质**：
- 解的误差$O_p(1/\sqrt{N})$（CLT）
- SAA解是真实最优解的一致估计
- 置信区间可用batching方法构造

### 离散场景近似

假设$\omega$有$S$个离散场景，概率$p_s$：

$$\min_{x, y_1,...,y_S} c^Tx + \sum_{s=1}^S p_s q_s^Ty_s$$
$$\text{s.t. } Ax = b, \quad T_sx + W_sy_s = h_s, \quad y_s \geq 0, \quad s=1,...,S$$

### Benders分解（L-shaped方法）

将问题分解为主问题（第一阶段）和子问题（第二阶段）：

**主问题**：$\min_x \{c^Tx + \theta\}$，加最优性割平面

**子问题**（对每个场景$s$）：求解$Q(x, \omega^s)$，生成割平面

### 与报童问题的联系

报童问题是最简单的两阶段随机规划：
- 第一阶段：决定订货量$x$（here-and-now）
- 第二阶段：需求实现后，过剩（残值处理）或短缺（缺货惩罚）（wait-and-see）
- 最优解满足$F_W(x^*) = (p-c)/(p-c+v)$

## 4. 训练过程讲解

### 参数初始化
- 场景生成：从$\omega$的分布采样$N$个场景
- 概率分配：等概率$1/N$或按实际分布权重

### SAA求解过程
1. 生成$N$个场景$\omega^1, ..., \omega^N$
2. 构建确定性等价问题（大线性规划）
3. 用LP求解器求解
4. 评估SAA解的质量（多次采样取最好）

### Benders分解过程
1. 求解主问题（第一阶段），得到试探解$x^k$
2. 对每个场景求解子问题，得$Q(x^k, \omega^s)$和对偶乘子
3. 生成割平面并加入主问题
4. 重复直到收敛

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $N$ | SAA场景数 | [100, 10000] | 1000 |
| $S$ | 离散场景数 | [10, 500] | 50 |
| 收敛阈值 | Benders | [1e-4, 1e-6] | 1e-4 |
| max_iter | 最大迭代 | [50, 500] | 100 |

## 5. 应用场景

### 1. 供应链库存优化
为什么适合：需求不确定下的多阶段库存管理。第一阶段决定基础库存水平，第二阶段根据实际需求调整。

### 2. 能源系统规划
为什么适合：风电/光伏出力不确定。第一阶段决定容量投资，第二阶段根据实际出力调度。

### 3. 交通网络设计
为什么适合：出行需求不确定。第一阶段决定基础设施投资，第二阶段根据实际流量分配资源。

### 4. 金融风险管理
为什么适合：资产收益不确定。第一阶段决定资产配置，第二阶段根据市场实际表现调整。

### 不适用场景
- 不确定性集合比分布更容易获得（用鲁棒优化）
- 需要100%可行性保证（用鲁棒优化）
- 问题规模极大（需要分解或近似方法）

## 6. 优缺点分析

### 优点
1. **理论基础扎实**：SAA有收敛性保证（成立条件：场景数$N \to \infty$）
2. **灵活性强**：可处理多种不确定性结构
3. **决策时序清晰**：区分here-and-now和wait-and-see决策
4. **求解工具丰富**：CPLEX、Gurobi等商业求解器支持

### 缺点
1. **需要概率分布**：实际中分布往往难以精确估计
2. **维度灾难**：场景数随不确定性维度指数增长
3. **计算量大**：大规模问题的确定性等价模型非常庞大
4. **期望值优化忽略风险**：不关心结果的方差或最坏情况

### 算法对比

| 特性 | 随机规划 | 鲁棒优化 | 蒙特卡洛仿真 | 在线学习 |
|------|---------|---------|-------------|---------|
| 需要分布 | 是 | 否 | 是 | 否 |
| 优化类型 | 期望 | 最坏情况 | 统计估计 | 序贯 |
| 计算规模 | 大 | 中 | 小 | 小 |
| 实时性 | 离线 | 离线 | 中 | 在线 |

## 7. 调库实现

```python
"""
两阶段随机规划：报童问题的LP形式
使用scipy.optimize.linprog
"""
import numpy as np
from scipy.optimize import linprog

def two_stage_newsvendor(price, cost, salvage, demands):
    """两阶段随机规划求解报童问题"""
    n_scenarios = len(demands)
    prob = 1.0 / n_scenarios

    # 决策变量：[x, y_1,...,y_S, z_1,...,z_S]
    # x=订货量, y_s=销售量, z_s=剩余量
    n_var = 1 + 2 * n_scenarios
    c = np.zeros(n_var)
    c[0] = cost
    for s in range(n_scenarios):
        c[1 + s] = -price * prob
        c[1 + n_scenarios + s] = -salvage * prob

    A_eq, b_eq, A_ub, b_ub = [], [], [], []
    for s in range(n_scenarios):
        row = np.zeros(n_var)
        row[0] = -1; row[1+s] = 1; row[1+n_scenarios+s] = 1
        A_eq.append(row); b_eq.append(0)

        row2 = np.zeros(n_var)
        row2[1+s] = 1
        A_ub.append(row2); b_ub.append(demands[s])

    bounds = [(0, None)] * n_var
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, bounds=bounds)
    return result.x[0], -result.fun


def saa_newsvendor(price, cost, n_samples_list=[50, 200, 500, 1000]):
    """SAA方法：场景数对解的影响"""
    np.random.seed(42)
    true_demand_mean = 100
    true_demand_std = 20

    print("SAA方法：场景数对最优解的影响")
    print(f"{'场景数N':>8} {'最优订货量':>10} {'期望利润':>10}")
    print("-" * 32)

    for N in n_samples_list:
        demands = np.random.normal(true_demand_mean, true_demand_std, N)
        x_opt, profit = two_stage_newsvendor(price, cost, 2, demands)
        print(f"{N:>8} {x_opt:>10.1f} {profit:>10.1f}")

    # 理论值
    from scipy import stats
    cr = (price - cost) / price
    x_theory = stats.norm.ppf(cr, true_demand_mean, true_demand_std)
    print(f"{'理论值':>8} {x_theory:>10.1f}")


if __name__ == "__main__":
    saa_newsvendor(10, 6)
```

## 8. 手工代码实现

```python
"""
从零实现两阶段随机规划：Benders分解
纯NumPy，以报童问题为例
"""
import numpy as np

class TwoStageSP:
    """两阶段随机规划求解器（Benders分解）"""

    def __init__(self, n_scenarios, demand_mean=100, demand_std=20,
                 price=10, cost=6, salvage=2, penalty=5):
        self.S = n_scenarios
        self.price = price
        self.cost = cost
        self.salvage = salvage
        self.penalty = penalty
        np.random.seed(42)
        self.demands = np.random.normal(demand_mean, demand_std, n_scenarios)
        self.prob = np.ones(n_scenarios) / n_scenarios

    def second_stage(self, x, scenario_idx):
        """求解第二阶段子问题"""
        d = self.demands[scenario_idx]
        sold = min(x, d)
        leftover = max(0, x - d)
        shortage = max(0, d - x)
        q = (self.price * sold + self.salvage * leftover
             - self.penalty * shortage)
        # 对偶乘子（简化）
        dual = self.price if d > x else self.salvage
        return q, dual

    def solve_saa(self):
        """SAA方法：直接枚举最优订货量"""
        candidates = np.arange(50, 151, 1)
        best_x, best_profit = 0, -np.inf

        for x in candidates:
            total_profit = -self.cost * x
            for s in range(self.S):
                q, _ = self.second_stage(x, s)
                total_profit += self.prob[s] * q
            if total_profit > best_profit:
                best_profit = total_profit
                best_x = x
        return best_x, best_profit


# ========== 测试 ==========
if __name__ == "__main__":
    sp = TwoStageSP(n_scenarios=500, demand_mean=100, demand_std=20)
    x_opt, profit = sp.solve_saa()
    print(f"SAA最优订货量: {x_opt}")
    print(f"期望利润: {profit:.1f}")

    # 与理论值对比
    from scipy import stats
    cr = (sp.price - sp.cost) / sp.price
    x_theory = stats.norm.ppf(cr, 100, 20)
    print(f"理论最优订货量: {x_theory:.1f}")
```

## 11. 常见问题与易错点

### 数据层面

1. **场景数不足**
   - 现象：SAA解不稳定，每次运行结果不同
   - 原因：场景数$N$太小，采样噪声大
   - 解决方案：增加$N$或用多次SAA取最好解

2. **分布假设错误**
   - 现象：样本外表现差
   - 原因：训练分布与实际分布不一致
   - 解决方案：使用非参数场景生成或分布鲁棒方法

### 模型层面

3. **两阶段不够**
   - 现象：实际需要多阶段决策
   - 原因：标准两阶段只区分"之前"和"之后"
   - 解决方案：使用多阶段随机规划（但维度灾难加剧）

4. **忽略非预期性**
   - 现象：解使用了未来信息
   - 原因：模型没有正确区分here-and-now和wait-and-see决策
   - 解决方案：确保第一阶段决策不依赖场景信息

### 调参层面

5. **Benders分解收敛慢**
   - 现象：迭代次数过多
   - 原因：割平面不够紧
   - 解决方案：加入trust region或regularization

## 12. 学习总结

随机规划在数学规划框架中处理不确定性：$\min_x c^Tx + \mathbb{E}_\omega[Q(x,\omega)]$。核心是区分here-and-now和wait-and-see决策，SAA方法用蒙特卡洛近似期望。

**关键公式**：
1. 两阶段模型：$\min_x\{c^Tx + \mathbb{E}_\omega[\min_y q^Ty]\}$
2. SAA近似：$\min_x \frac{1}{N}\sum_{n=1}^N f(x, \omega^n)$
3. Benders割平面：$\theta \geq Q(x^k, \omega^s) + \nabla Q \cdot (x - x^k)$

原书将随机规划归为CFA策略的一种，Ch 19.9详细讨论了两阶段方法与DLA（直接前瞻近似）的关系。

## 13. 练习题与思考题

### 基础题

**题目1**：SAA方法中，样本数$N$如何影响解的质量？计算量如何随$N$变化？

**参考答案**：解的误差$O(1/\sqrt{N})$（由CLT保证）。计算量正比于$N$（每多一个场景多一组约束）。因此精度每提高一倍需要4倍计算量。实践中通常$N \in [100, 1000]$即可得到满意的解。

**题目2**：报童问题如何用两阶段随机规划建模？第一阶段和第二阶段的决策分别是什么？

**参考答案**：
- 第一阶段：决定订货量$x$（here-and-now）
- 第二阶段：需求实现后，决定过剩如何处理（残值）和短缺如何处理（缺货成本）
- 补偿函数：$Q(x,D) = p\min(x,D) + v\max(0,x-D) - b\max(0,D-x)$
- 两阶段模型退化为：$\max_x\{-cx + \mathbb{E}[Q(x,D)]\}$，即标准报童问题

### 进阶题

**题目3**：Benders分解（L-shaped方法）如何将两阶段随机规划分解？为什么这比直接求解确定性等价模型更高效？

**参考答案**：
- 分解：主问题只含第一阶段变量$x$+辅助变量$\theta$，子问题对每个场景独立求解
- 高效原因：(1)主问题规模小（只有第一阶段变量）；(2)子问题可并行求解；(3)割平面逐步收紧可行域
- 直接求解确定性等价模型的变量数为$|x| + S \times |y|$，当$S$很大时非常庞大
- Benders避免了显式构造大模型

### 开放思考题

**题目4**：原书(Ch 19.9)将两阶段随机规划归为DLA（直接前瞻近似）。但随机规划通常被视为"规划"方法。你如何理解这种归类？

**参考答案方向**：
- DLA的核心是"前瞻模拟未来场景+优化当前决策"，随机规划的两阶段模型正好符合
- 第一阶段是"当前决策"，第二阶段是"前瞻模拟"
- 归为DLA的原因：两阶段模型本质上是一种简化的前瞻——只看一步（而非多步）
- 多阶段随机规划才是完整的DLA：$\min_{x_1} c_1^Tx_1 + \mathbb{E}[\min_{x_2} c_2^Tx_2 + \mathbb{E}[\min_{x_3}...]]$

## 14. 学习路径建议
