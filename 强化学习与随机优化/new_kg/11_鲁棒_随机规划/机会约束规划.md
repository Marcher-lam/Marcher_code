# 机会约束规划(Chance-Constrained Programming) 学习文档

> 允许约束以一定概率被违反，在可行性和最优性之间取得平衡。

> 来源线索：本节内容根据原书中关于"Chance-Constrained Programming"的相关章节(Ch 2.1.12, Ch 4.2.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：机会约束规划将硬约束放松为$\mathbb{P}[g(x,\omega) \leq 0] \geq 1-\alpha$，允许约束以概率$\alpha$被违反。

**直觉类比**：设计水库容量。如果按历史最大洪水设计（硬约束），成本极高。机会约束允许"99%的年份不溢出"，在安全和经济间取平衡。

**历史背景**：Charnes & Cooper (1959)提出机会约束规划。在工程可靠性设计、金融风险管理中广泛使用。

**算法定位**：随机优化/约束方法。与鲁棒优化互补。

**前置知识**：概率分布、线性规划、分位数。

## 2-3. 核心原理与公式

### 机会约束

$$\min_x f(x) \quad \text{s.t.} \quad \mathbb{P}[g_i(x,\omega) \leq 0] \geq 1-\alpha_i$$

### 等价确定性约束（已知分布时）

若$g(x,\omega) = a(\omega)^Tx - b$，$a(\omega) \sim N(\bar{a}, \Sigma)$：

$$\bar{a}^Tx + \Phi^{-1}(1-\alpha)\sqrt{x^T\Sigma x} \leq b$$

### CVaR近似

机会约束可用CVaR松弛：

$$\mathbb{P}[g(x,\omega) \leq 0] \geq 1-\alpha \Leftarrow \text{CVaR}_\alpha[g(x,\omega)] \leq 0$$

CVaR可表示为线性规划，更容易求解。

## 4-8. 核心实现

```python
"""机会约束规划：水库设计示例"""
import numpy as np
from scipy.stats import norm

def chance_constraint_opt(mean_flow, std_flow, alpha=0.05):
    """水库容量机会约束优化"""
    # Φ^{-1}(1-α): 确保溢出概率 ≤ α
    z = norm.ppf(1 - alpha)
    # 等价约束: 容量 ≥ 均值 + z*标准差
    capacity = mean_flow + z * std_flow
    return capacity

if __name__ == "__main__":
    np.random.seed(42)
    flows = np.random.normal(100, 30, 1000)
    for alpha in [0.01, 0.05, 0.10, 0.20]:
        cap = chance_constraint_opt(100, 30, alpha)
        violation = np.mean(flows > cap)
        print(f"α={alpha:.2f}: 所需容量={cap:.1f}, 实际违反率={violation:.3f}")
```

### 12. 学习总结
机会约束：$\mathbb{P}[g(x,\omega) \leq 0] \geq 1-\alpha$。用CVaR近似可转为凸优化。在安全约束和经济效益间取平衡。

### 13. 练习题
**Q1**：$\alpha=0$的机会约束等价于什么？
**A1**：硬约束——要求100%满足，等价于鲁棒优化中的"最坏情况"约束。
