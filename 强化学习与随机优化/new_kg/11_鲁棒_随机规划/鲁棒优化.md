# 鲁棒优化(Robust Optimization) 学习文档

> 在最坏情况下优化，保证解对所有不确定性实现都可行。

> 来源线索：本节内容根据原书中关于"Robust Optimization"的相关章节(Ch 2.1.14, Ch 19.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：鲁棒优化在最坏不确定性情景下优化目标，而非在期望上优化，保证解对不确定性集合内的所有实现都可行。

**直觉类比**：你要在雨季规划通勤路线。随机规划选"平均最快"的路线，但偶尔会被淹。鲁棒优化选"即使最坏情况也不被淹"的路线——可能平时慢一点，但绝不迟到。

**历史背景**：鲁棒优化由Soyster (1973)提出线性规划中的鲁棒性概念。Ben-Tal & Nemirovski (1998, 1999)发展了椭球不确定性下的可解形式。Bertsimas & Sim (2004)提出了预算不确定性集，在保守性和可解性之间取得平衡。原书Ch 19.3将鲁棒优化归为CFA策略的一种实现。

**算法定位**：随机优化/最坏情况优化。与随机规划（期望优化）和机会约束规划（概率保证）并列，是处理不确定性的三大范式之一。

**前置知识**：
- 线性规划和凸优化基础
- 概率论和不确定性建模
- 对偶理论

## 2. 核心原理

**核心思想**：鲁棒优化不使用概率分布描述不确定性，而是用**不确定性集合**$\Omega$。解必须对$\Omega$内所有可能的参数值都可行，且在最坏情况下目标值最优。

**基本模型**：

$$\min_x \max_{\omega \in \Omega} f(x, \omega) \quad \text{s.t. } g(x, \omega) \leq 0, \forall \omega \in \Omega$$

**工作流程**：

1. 建立标称优化问题（忽略不确定性）
2. 识别不确定参数并定义不确定性集合$\Omega$
3. 用对偶或变形将鲁棒问题转化为可解的确定性优化
4. 求解并分析解的保守程度

**关键概念**：

- **不确定性集合**$\Omega$：不确定参数的取值范围，如箱集、椭球集
- **鲁棒可行解**：对$\Omega$内所有$\omega$都满足约束的解
- **保守性-性能权衡**：不确定性集合越大，解越保守但性能越差
- **预算不确定性**（Bertsimas-Sim）：限制同时取最坏值的参数个数

**三种处理不确定性的范式**：

```
处理不确定性的方法
├── 随机规划：优化E[f(x,ω)]，需要概率分布
├── 鲁棒优化：优化max_ω f(x,ω)，只需要不确定性集
└── 机会约束：P[g(x,ω)≤0]≥1-α，概率保证
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $x$ | 决策变量 |
| $\omega$ | 不确定参数 |
| $\Omega$ | 不确定性集合 |
| $\Gamma$ | 不确定性预算 |
| $\tilde{a}_{ij}$ | 名义系数$a_{ij}$的扰动 |

### 标称鲁棒线性规划

$$\min_x c^Tx \quad \text{s.t. } \tilde{A}x \leq b, \forall \tilde{A} \in \mathcal{U}$$

其中$\mathcal{U}$是矩阵$A$的不确定性集合。

### 箱不确定性

$\tilde{a}_{ij} \in [a_{ij} - \hat{a}_{ij}, a_{ij} + \hat{a}_{ij}]$

鲁棒约束等价于：$\sum_j a_{ij}x_j + \sum_j \hat{a}_{ij}|x_j| \leq b_i$

### Bertsimas-Sim预算不确定性

限制最多$\Gamma$个参数同时取最坏值：

鲁棒约束转化为：$\sum_j a_{ij}x_j + \max_{S \subseteq J, |S| \leq \Gamma}\sum_{j \in S}\hat{a}_{ij}|x_j| \leq b_i$

利用对偶，可转化为线性规划：

$$\sum_j a_{ij}x_j + \Gamma z_i + \sum_j p_{ij} \leq b_i$$
$$z_i + p_{ij} \geq \hat{a}_{ij}|x_j|, \quad z_i, p_{ij} \geq 0$$

### 椭球不确定性

$\omega^T\Sigma^{-1}\omega \leq \Gamma^2$时，鲁棒线性约束转化为二阶锥约束（SOCP）。

### 与最短路径的结合

原书用鲁棒优化改造最短路径：用$\theta$-百分位成本$\bar{c}_{ij}(\theta)$代替名义成本$c_{ij}$。

$$v_i = \min_{j}\left(\bar{c}_{ij}(\theta) + v_j\right)$$

$\theta=0$退化为确定性最短路径，$\theta=1$为最坏情况路径。

## 4. 训练过程讲解

### 参数初始化
- 名义参数：标称值$c, A, b$
- 不确定性范围：$\hat{a}_{ij}$、$\Gamma$
- 保守程度：$\theta$或$\Gamma$

### 求解过程
1. 建立标称优化模型
2. 定义不确定性集合$\Omega$
3. 用对偶转化将鲁棒问题化为确定性优化
4. 用LP/SOCP求解器求解

### 收敛/可行性条件
- 鲁棒可行集是标称可行集的子集
- 不确定性集合越大，可行域越小

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $\Gamma$ | 不确定性预算 | $[0, \|\mathcal{J}\|]$ | $\sqrt{\|\mathcal{J}\|}$ |
| $\hat{a}_{ij}$ | 扰动幅度 | 名义值的[5%, 30%] | 10% |
| $\theta$ | 百分位水平 | [0, 1] | 0.5 |

## 5. 应用场景

### 1. 供应链网络设计
为什么适合：需求和运输成本不确定。鲁棒优化设计在最坏需求下仍可行的网络拓扑。

### 2. 能源调度
为什么适合：风电/光伏出力不确定。鲁棒调度保证在出力波动下电网安全。

### 3. 投资组合优化
为什么适合：资产收益不确定。鲁棒投资组合在最坏市场情景下仍可接受。

### 4. 航空调度
为什么适合：飞行时间不确定（天气、流量控制）。鲁棒调度减少延误。

### 不适用场景
- 不确定性很小（确定性方法即可）
- 需要精确概率保证（用机会约束）
- 不确定性集合难以定义（用随机规划）

## 6. 优缺点分析

### 优点
1. **无需概率分布**：只需不确定性集合，不需要精确的分布信息（成立条件：不确定性有界且已知范围）
2. **确定性保证**：100%满足约束，不依赖概率假设
3. **可解性好**：很多情况下可转化为线性/锥规划
4. **理论优雅**：对偶理论保证转化的正确性

### 缺点
1. **过于保守**：最坏情况可能极端罕见，导致解性能差
2. **不确定性集选择主观**：$\Omega$的定义影响结果，缺乏数据驱动方法
3. **静态模型**：标准鲁棒优化不考虑观测后的自适应
4. **可解性限制**：一般非线性鲁棒优化仍难以求解

### 算法对比

| 特性 | 鲁棒优化 | 随机规划 | 机会约束 | 分布鲁棒 |
|------|---------|---------|---------|---------|
| 需要分布 | 否 | 是 | 是 | 模糊集 |
| 保证类型 | 最坏情况 | 期望 | 概率 | 最坏分布 |
| 保守程度 | 高 | 低 | 中 | 中-高 |
| 可解性 | 好(LP/SOCP) | 中(SAA) | 中 | 中 |

## 7. 调库实现

```python
"""
鲁棒优化：Bertsimas-Sim预算不确定性下的线性规划
使用scipy.optimize
"""
import numpy as np
from scipy.optimize import linprog

def robust_lp_bertsimas(c, A_nom, b, a_hat, Gamma):
    """Bertsimas-Sim鲁棒线性规划"""
    n_vars = len(c)
    n_constraints = len(b)

    # 扩展决策变量：[x, z_i, p_ij]
    n_z = n_constraints
    n_p = sum(min(Gamma, n_vars) for _ in range(n_constraints))

    # 简化实现：对每个约束加入鲁棒保护
    # 鲁棒约束: sum_j a_ij*x_j + Gamma*z_i + sum_j p_ij <= b_i
    #          z_i + p_ij >= hat_a_ij * |x_j|

    # 直接使用箱不确定性的对偶形式
    # 将绝对值线性化：x_j = x_j^+ - x_j^-
    n_ext = 3 * n_vars  # x, x+, x-
    c_ext = np.zeros(n_ext)
    c_ext[:n_vars] = c

    A_ub = []
    b_ub = []

    for i in range(n_constraints):
        # 名义约束 + Gamma*max_hat_a + ...
        row = np.zeros(n_ext)
        row[:n_vars] = A_nom[i]
        robust_b = b[i] - Gamma * np.max(a_hat[i])
        A_ub.append(row)
        b_ub.append(robust_b)

    bounds = [(None, None)] * n_vars + [(0, None)] * (2 * n_vars)
    result = linprog(c_ext[:n_vars], A_ub=A_ub[:n_constraints],
                     b_ub=b_ub[:n_constraints],
                     bounds=[(None, None)] * n_vars)
    return result


if __name__ == "__main__":
    np.random.seed(42)
    # 简单的鲁棒运输问题
    n = 5
    c = np.random.uniform(1, 10, n)
    A = np.eye(n)
    b = np.ones(n) * 5.0
    a_hat = np.random.uniform(0.5, 2.0, (n, n)) * 0.1

    for Gamma in [0, 1, 2, 3]:
        costs_robust = c + Gamma * np.max(a_hat, axis=1)
        print(f"Γ={Gamma}: 鲁棒总成本={costs_robust.sum():.1f}")
```

## 8. 手工代码实现

```python
"""
从零实现鲁棒最短路径
纯NumPy，基于百分位成本
"""
import numpy as np

class RobustShortestPath:
    """鲁棒最短路径求解器"""

    def __init__(self, n_nodes, edges, cost_std=None):
        self.n = n_nodes
        self.adj = {i: [] for i in range(n_nodes)}
        for i, j, c in edges:
            std = cost_std.get((i, j), 0.0) if cost_std else 0.0
            self.adj[i].append((j, c, std))

    def solve(self, target, theta=0.5, max_iter=500):
        """用θ-百分位成本求解鲁棒最短路径"""
        v = np.full(self.n, np.inf)
        v[target] = 0.0
        policy = np.full(self.n, -1, dtype=int)

        for _ in range(max_iter):
            v_new = v.copy()
            for i in range(self.n):
                if i == target or not self.adj[i]:
                    continue
                candidates = []
                for j, c, std in self.adj[i]:
                    # θ-百分位成本 = 名义成本 + θ * 不确定性
                    c_robust = c + theta * std
                    candidates.append((c_robust + v[j], j))
                if candidates:
                    best_val, best_j = min(candidates)
                    v_new[i] = best_val
                    policy[i] = best_j
            if np.allclose(v, v_new):
                break
            v = v_new
        return v, policy

    def get_path(self, source, policy):
        """回溯路径"""
        path = [source]
        current = source
        while policy[current] != -1:
            current = policy[current]
            path.append(current)
        return path

    def simulate(self, source, target, policy, n_trials=5000):
        """模拟鲁棒路径在随机成本下的表现"""
        costs = []
        for _ in range(n_trials):
            current = source
            total = 0
            while current != target and policy[current] != -1:
                next_node = policy[current]
                for j, c, std in self.adj[current]:
                    if j == next_node:
                        actual = max(0.1, c + std * np.random.randn())
                        total += actual
                        break
                current = next_node
            costs.append(total)
        return np.mean(costs), np.std(costs), np.max(costs)


# ========== 测试 ==========
if __name__ == "__main__":
    np.random.seed(42)
    edges = [
        (0, 1, 2), (0, 2, 5), (1, 3, 3), (2, 3, 1),
        (1, 4, 7), (3, 4, 2), (2, 4, 6), (4, 5, 3)
    ]
    cost_std = {(0,1): 1.0, (0,2): 0.5, (1,3): 2.0, (2,3): 0.3,
                (1,4): 3.0, (3,4): 0.5, (2,4): 4.0, (4,5): 1.0}

    rsp = RobustShortestPath(6, edges, cost_std)

    print("=== 不同保守程度下的鲁棒路径 ===")
    for theta in [0.0, 0.3, 0.5, 1.0]:
        v, policy = rsp.solve(target=5, theta=theta)
        path = rsp.get_path(0, policy)
        mean, std, worst = rsp.simulate(0, 5, policy)
        print(f"θ={theta:.1f}: 路径={'->'.join(map(str,path))}, "
              f"鲁棒成本={v[0]:.1f}, 模拟均值={mean:.1f}±{std:.1f}, 最坏={worst:.1f}")
```

## 9. 可视化与结果理解

```python
"""
鲁棒优化可视化：不同θ下的路径对比
"""
import matplotlib.pyplot as plt
import numpy as np

def visualize_robust_paths(results_dict):
    """对比不同保守程度的鲁棒路径"""
    fig, ax = plt.subplots(figsize=(10, 6))
    thetas = list(results_dict.keys())
    means = [results_dict[t]['mean'] for t in thetas]
    stds = [results_dict[t]['std'] for t in thetas]
    worsts = [results_dict[t]['worst'] for t in thetas]

    ax.errorbar(thetas, means, yerr=stds, label='平均成本', marker='o')
    ax.plot(thetas, worsts, 'r--', label='最坏成本', marker='s')
    ax.set_xlabel('保守程度 θ')
    ax.set_ylabel('路径成本')
    ax.set_title('鲁棒最短路径：保守程度 vs 成本')
    ax.legend()
    ax.grid(True, alpha=0.3)
    plt.savefig('robust_shortest_path.png', dpi=150, bbox_inches='tight')
    plt.show()
```

**结果解读**：
- θ=0退化为确定性最短路径（平均好但最坏差）
- θ增加使路径更保守（平均略差但最坏显著改善）
- 存在最优θ*使平均和最坏达到最佳平衡

## 10. 模型评估

```python
"""
鲁棒策略评估
"""
import numpy as np

def evaluate_robustness(policy_fn, env_fn, n_scenarios=5000, label="策略"):
    """评估策略在多种不确定性情景下的表现"""
    costs = []
    violations = 0
    for _ in range(n_scenarios):
        path = policy_fn()
        cost, feasible = env_fn(path)
        costs.append(cost)
        if not feasible:
            violations += 1
    print(f"{label}评估（{n_scenarios}情景）：")
    print(f"  平均成本: {np.mean(costs):.2f}")
    print(f"  最坏成本: {np.max(costs):.2f}")
    print(f"  违反约束比例: {violations/n_scenarios:.1%}")
    print(f"  CVaR(95%): {np.mean(sorted(costs)[int(0.95*len(costs)):]):.2f}")
```

**评估指标说明**：
- **平均成本**：日常性能
- **最坏成本**：鲁棒性的核心度量
- **约束违反率**：应为0%（鲁棒优化的核心保证）
- **CVaR**：尾部风险的度量

## 11. 常见问题与易错点

### 数据层面

1. **不确定性集过大**
   - 现象：解过于保守，性能远差于标称最优
   - 原因：$\Omega$包含了极端不太可能的情况
   - 解决方案：使用数据驱动方法校准$\Omega$，或使用预算不确定性

2. **忽略了不确定性的结构**
   - 现象：鲁棒解不实用
   - 原因：假设参数独立扰动，实际有相关性
   - 解决方案：使用椭球不确定性集或因子模型

### 模型层面

3. **可解性瓶颈**
   - 现象：鲁棒模型无法在合理时间内求解
   - 原因：不确定性集的复杂化导致问题规模爆炸
   - 解决方案：使用对偶转化或近似方法

4. **静态假设过强**
   - 现象：解假设所有决策在不确定性观测前做出
   - 原因：标准鲁棒优化不考虑自适应
   - 解决方案：使用自适应鲁棒优化（多阶段）

### 调参层面

5. **保守程度$\Gamma$选择困难**
   - 现象：$\Gamma$太小无鲁棒效果，太大过度保守
   - 解决方案：Bertsimas-Sim建议$\Gamma = \sqrt{n}$或通过交叉验证选择

## 12. 学习总结

鲁棒优化在最坏情况下优化：$\min_x \max_{\omega \in \Omega} f(x,\omega)$。核心是不用概率分布，只用不确定性集合$\Omega$。Bertsimas-Sim预算不确定性集在保守性和可解性之间取得平衡。

**关键公式**：
1. 鲁棒优化：$\min_x \max_{\omega \in \Omega} f(x,\omega)$
2. Bertsimas-Sim对偶转化：$\sum a_{ij}x_j + \Gamma z + \sum p_{ij} \leq b_i$
3. 百分位成本：$\bar{c}(\theta) = c + \theta \cdot \Delta c$

鲁棒优化是原书CFA策略的一种实现，与随机规划（期望优化）和机会约束（概率保证）并列。

## 13. 练习题与思考题

### 基础题

**题目1**：鲁棒优化和随机规划的核心区别是什么？各自的适用条件是什么？

**参考答案**：
- 鲁棒优化：优化最坏情况，不需要概率分布，只需要不确定性的范围。适用于"最坏情况不能太差"的安全关键场景。
- 随机规划：优化期望值，需要概率分布。适用于"平均表现要好"的常规场景。
- 选择依据：是否有分布信息 + 是否需要绝对安全保证。

### 进阶题

**题目2**：Bertsimas-Sim预算不确定性中，$\Gamma$的直觉含义是什么？$\Gamma=0$和$\Gamma=n$分别对应什么？

**参考答案**：
- $\Gamma$限制同时取最坏值的参数个数
- $\Gamma=0$：标称问题（无鲁棒性保护）
- $\Gamma=n$（所有参数）：等价于箱不确定性（完全保守）
- 中间值：在两者之间取得平衡。Bertsimas-Sim证明概率约束违反的上界随$\Gamma$指数递减。

### 开放思考题

**题目3**：原书(Ch 19.3)将鲁棒优化归为CFA策略。请思考：鲁棒优化作为策略函数和作为一次性优化求解有什么本质区别？

**参考答案方向**：
- 一次性优化：求解鲁棒问题得到一个固定解$x^*$，之后不再调整
- CFA策略：鲁棒优化参数化策略$X^\pi(S_t|\theta)$中的参数$\theta$，策略随状态$S_t$变化
- 本质区别：CFA版鲁棒优化是"用鲁棒方法训练参数化策略"，而非"直接求解鲁棒问题"
- CFA版可以在线适应：每次用当前状态的信息更新鲁棒模型并重新求解
