## 1-3. 核心认知与公式

**一句话定义**：用$k$个线性段$\{(\beta_j, c_j)\}$近似值函数，$j$是段编号，$\beta_j$是斜率，$c_j$是截距。

**近似函数**：

$$\bar{V}(R) \approx \max_j \{\beta_j R + c_j\}$$

取所有线性段的最大值保证凸性。

**或凹形式**（资源问题）：

$$\bar{V}(R) \approx \min_j \{\beta_j R + c_j\}$$

**更新**：采样到新的$(R, \hat{v})$对时，添加新的线性段或调整现有段。

## 4-8. 核心实现

```python
"""分段线性近似"""
import numpy as np

class PiecewiseLinearApprox:
    def __init__(self):
        self.slopes = [5.0, 3.0, 1.0, 0.1]  # 递减斜率（凹函数）
        self.intercepts = [0.0, 20.0, 60.0, 90.0]
        self.breakpoints = [0, 10, 20, 30, 50]

    def value(self, R):
        """计算分段线性值"""
        for i in range(len(self.breakpoints)-1):
            if R <= self.breakpoints[i+1]:
                return self.slopes[i] * (R - self.breakpoints[i]) + self._cumulative(i)
        return self._cumulative(len(self.slopes))

    def _cumulative(self, i):
        v = 0
        for j in range(min(i, len(self.slopes))):
            v += self.slopes[j] * (self.breakpoints[j+1] - self.breakpoints[j])
        return v

if __name__ == "__main__":
    pla = PiecewiseLinearApprox()
    for r in [0, 5, 10, 15, 20, 30, 40, 50]:
        print(f"V({r}) = {pla.value(r):.1f}")
```

## 9-14. 简要

### 12. 学习总结
分段线性：$\bar{V}(R) = \max_j\{\beta_j R + c_j\}$。保持凸/凹结构，优化问题仍为LP。

### 13. 练习题
**Q1**：为什么分段线性近似在优化中比神经网络方便？
**A1**：分段线性近似保持凸结构，优化仍是LP。神经网络的非凸结构使嵌入优化问题时需要启发式方法。
