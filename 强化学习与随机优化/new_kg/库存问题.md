# 库存问题(Inventory Problem) 学习文档

> 在需求不确定下管理库存的订货与销售，是动态规划最经典的连续决策应用。

> 来源线索：本节内容根据原书中关于"Inventory/Storage Problems"的相关章节(Ch 2.3.2, Ch 8.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：库存问题在随机需求下决定何时订多少货，在缺货成本和库存持有成本之间取得最优平衡。

**直觉类比**：管理一个仓库。每天有随机数量的顾客来买东西。你可以选择补货，但补货有成本；不补货可能缺货丢失利润；补多了库存积压也要花钱。目标是在整个运营周期内最大化总利润。

**历史背景**：库存问题是动态规划最早的应用之一（Arrow et al. 1958, Clark & Scarf 1960）。原书用库存问题贯穿全书，展示四种策略类（PFA/CFA/VFA/DLA）各自的适用场景。

**算法定位**：随机优化/多阶段决策。与报童问题（单阶段）对应，是动态规划的核心应用。

**前置知识**：报童问题、马尔可夫决策过程、Bellman方程。

## 2. 核心原理

**核心思想**：库存问题将报童问题扩展到多阶段。关键增加是**状态变量**：当前库存水平$R_t$，价格$p_t$，以及可能的需求信念$B_t$。

**状态转移**：

$$R_{t+1} = R_t + x_t - y_t$$

其中$x_t$是订货量，$y_t$是销售量（$y_t \leq \min(R_t + x_t, \hat{D}_t)$）。

**工作流程**：
1. 观察当前状态$S_t = (R_t, p_t, B_t)$
2. 根据策略$\pi$决定订货$x_t$和销售$y_t$
3. 观察需求$\hat{D}_{t+1}$，获得奖励$C_t = p_ty_t - c_tx_t$
4. 更新状态$S_{t+1}$

**关键概念**：
- **信念状态$B_t$**：对需求分布的当前认知（可能是一个概率分布）
- **延迟决策(lagged decisions)**：$x_{tt'}$表示$t$时刻订购、$t'$时刻到达的货物
- **预测信息**：状态中可包含需求预测$f_{tt'}^W$

## 3. 数学公式与推导

### 基本模型

单步利润：

$$C_t(x_t, y_t) = p_ty_t - c_tx_t$$

目标（累积奖励）：

$$\max_\pi \mathbb{E}\sum_{t=0}^{T}(p_tY^\pi(S_t) - c_tX^\pi(S_t))$$

### 状态变量演化

静态数据：$S_t = R_t$

动态价格：$S_t = (R_t, p_t)$

历史依赖：$p_{t+1} = \theta_0p_t + \theta_1p_{t-1} + \theta_2p_{t-2} + \varepsilon_{t+1}$，则$S_t = (R_t, p_t, p_{t-1}, p_{t-2})$

学习过程：$S_t = (R_t, p_t, B_t)$

### 与四种策略的对应

| 策略类 | 库存问题中的形式 |
|--------|-----------------|
| PFA | $(s, S)$策略：库存低于$s$时订到$S$ |
| CFA | 修正确定性规划的参数化模型 |
| VFA | 用值函数近似指导订货决策 |
| DLA | 前瞻模拟未来需求场景 |

## 4-6. 简要

### 应用
1. 零售库存管理（超市、电商）
2. 能源存储（电池充放电，原书Ch 11.9）
3. 血液库存管理
4. 备件库存（飞机、设备维护）

### 优缺点
**优点**：模型简洁但内涵丰富，可以展示所有策略类
**缺点**：高维状态（多产品+预测+信念）使精确DP不可行，需要近似

## 7-8. 核心实现

```python
"""库存问题：(s,S)策略与值迭代"""
import numpy as np

class InventoryProblem:
    """有限阶段库存问题"""
    def __init__(self, max_inv=50, T=20, p=10, c=6, h=1, b=5):
        self.max_inv = max_inv
        self.T = T
        self.p = p       # 售价
        self.c = c       # 成本
        self.h = h       # 库存持有成本
        self.b = b       # 缺货惩罚
        # 离散化需求
        self.demand_vals = np.arange(0, 20)
        self.demand_probs = np.array([0.05]*5 + [0.08]*5 + [0.06]*5 + [0.03]*5)
        self.demand_probs /= self.demand_probs.sum()

    def expected_reward(self, inv, order):
        """计算给定库存和订货量的期望利润"""
        total = inv + order
        cost = self.c * order
        expected_rev = 0
        expected_hold = 0
        expected_back = 0
        for d, prob in zip(self.demand_vals, self.demand_probs):
            sold = min(total, d)
            expected_rev += prob * self.p * sold
            leftover = max(0, total - d)
            expected_hold += prob * self.h * leftover
            shortage = max(0, d - total)
            expected_back += prob * self.b * shortage
        return expected_rev - cost - expected_hold - expected_back

    def solve_dp(self):
        """后向动态规划求解"""
        V = np.zeros((self.T + 1, self.max_inv + 1))
        policy = np.zeros((self.T, self.max_inv + 1), dtype=int)

        for t in range(self.T - 1, -1, -1):
            for inv in range(self.max_inv + 1):
                best_val = -np.inf
                best_order = 0
                for order in range(self.max_inv - inv + 1):
                    reward = self.expected_reward(inv, order)
                    # 期望未来价值
                    future = 0
                    for d, prob in zip(self.demand_vals, self.demand_probs):
                        next_inv = max(0, inv + order - d)
                        next_inv = min(next_inv, self.max_inv)
                        future += prob * V[t + 1, next_inv]
                    total_val = reward + future
                    if total_val > best_val:
                        best_val = total_val
                        best_order = order
                V[t, inv] = best_val
                policy[t, inv] = best_order
        return V, policy

    def simulate(self, policy, n_episodes=1000):
        """模拟策略执行"""
        total_rewards = []
        for _ in range(n_episodes):
            inv = 20  # 初始库存
            ep_reward = 0
            for t in range(self.T):
                order = min(policy[t, inv], self.max_inv - inv)
                demand = np.random.choice(self.demand_vals, p=self.demand_probs)
                sold = min(inv + order, demand)
                reward = self.p * sold - self.c * order
                reward -= self.h * max(0, inv + order - demand)
                reward -= self.b * max(0, demand - inv - order)
                inv = max(0, min(inv + order - demand, self.max_inv))
                ep_reward += reward
            total_rewards.append(ep_reward)
        return np.mean(total_rewards), np.std(total_rewards)

if __name__ == "__main__":
    np.random.seed(42)
    inv = InventoryProblem(max_inv=30, T=10)
    V, policy = inv.solve_dp()
    mean_r, std_r = inv.simulate(policy)
    print(f"最优策略下期望总利润: {V[0, 20]:.1f}")
    print(f"模拟平均利润: {mean_r:.1f} ± {std_r:.1f}")
    print(f"初始库存20时的最优订货量(前5期): {policy[:5, 20]}")
```

## 9-14. 简要

### 12. 学习总结
库存问题：$S_t = (R_t, p_t, B_t)$，目标$\max_\pi \mathbb{E}\sum_t(p_tY^\pi - c_tX^\pi)$。是报童问题的多阶段扩展，原书用来展示PFA/CFA/VFA/DLA四种策略。

### 13. 练习题
**Q1**：$(s,S)$策略属于四种策略类中的哪一种？
**A1**：PFA（策略函数近似）。$(s,S)$是参数化策略，参数$s$（再订货点）和$S$（订到水平）通过优化确定。
