## 1-3. 核心认知与公式

**一句话定义**：上下文赌博机在每步观测到上下文$x_t$后选择动作，奖励依赖于上下文和动作，是监督学习和RL之间的问题。

**与标准赌博机的区别**：
- 标准赌博机：每臂有固定（但未知）的均值
- 上下文赌博机：奖励$\mathbb{E}[r|x,a]$依赖上下文$x$和动作$a$

**问题形式化**：

$$\max_\pi \sum_{t=1}^T \mathbb{E}[r_t | x_t, a_t = \pi(x_t)]$$

**常用算法**：
- **LinUCB**：假设$r(x,a) = \theta_a^T x + \epsilon$，对每臂维护线性模型
- **Thompson采样 + 线性模型**：后验采样$\theta_a$，选$\arg\max_a \theta_a^T x$

**LinUCB置信上界**：

$$a^{LinUCB} = \arg\max_a \left[\theta_a^T x + \alpha\sqrt{x^T A_a^{-1} x}\right]$$

其中$A_a = X_a^TX_a + I$是正则化设计矩阵。

## 4-8. 核心实现

```python
"""上下文赌博机：LinUCB算法"""
import numpy as np

class LinUCB:
    def __init__(self, n_arms, dim, alpha=1.0):
        self.K = n_arms
        self.d = dim
        self.alpha = alpha
        self.A = [np.eye(dim) for _ in range(n_arms)]
        self.b = [np.zeros(dim) for _ in range(n_arms)]

    def select(self, x):
        p = np.zeros(self.K)
        for a in range(self.K):
            theta = np.linalg.solve(self.A[a], self.b[a])
            p[a] = theta @ x + self.alpha * np.sqrt(x @ np.linalg.solve(self.A[a], x))
        return np.argmax(p)

    def update(self, x, a, r):
        self.A[a] += np.outer(x, x)
        self.b[a] += r * x

if __name__ == "__main__":
    np.random.seed(42)
    K, d = 3, 5
    true_theta = np.random.randn(K, d)
    linucb = LinUCB(K, d, alpha=0.5)
    total_r = 0
    for t in range(1000):
        x = np.random.randn(d)
        true_rewards = true_theta @ x
        a = linucb.select(x)
        r = true_rewards[a] + 0.1*np.random.randn()
        linucb.update(x, a, r)
        total_r += true_rewards[a]
    print(f"LinUCB累积奖励: {total_r:.1f}")
    print(f"理论最优奖励: {sum(max(true_theta @ np.random.randn(d)) for _ in range(1000)):.1f}")
```

## 9-14. 简要

### 12. 学习总结
上下文赌博机：$\max_\pi \sum E[r|x,\pi(x)]$。LinUCB用线性模型+置信上界，是实际应用最广的上下文赌博机算法。

### 13. 练习题
**Q1**：上下文赌博机和完整RL的区别？
**A1**：上下文赌博机没有状态转移——当前动作不影响下一步的上下文分布。完整RL中动作改变状态，需要考虑长期回报。
