## 1. 算法基础认知

**一句话定义**：批量学习策略在每个决策点同时选择一组方案进行评估（而非逐个），在实验成本高或并行计算可用的场景中特别有效。

**直觉类比**：逐个学习像"一个人一次只能做一个实验"，批量学习像"一个团队同时做多个实验"。如果实验周期长（如药物试验需要3个月），并行做多个更高效。

**历史背景**：批量学习在仿真优化和实验设计中有广泛应用。OCBA（Optimal Computing Budget Allocation）是最优分配批次内预算的方法。

**算法定位**：无导数随机搜索的高级策略。与单步策略（如UCB、Thompson采样）互补。

**前置知识**：
- 多臂赌博机
- OCBA方法
- 实验设计

## 2. 核心原理

**核心思想**：在每个决策周期，选择一组 $B$ 个方案进行评估：
$$\{x^1, x^2, ..., x^B\} = \text{BatchPolicy}(S^n, B)$$

**批量策略的设计选择**：

1. **纯探索批次**：选择不确定性最大的 $B$ 个方案
2. **UCB批次**：按UCB指数排序选前 $B$ 个
3. **OCBA最优分配**：数学上最优的预算分配
4. **多样性批次**：确保批次内的方案有足够的多样性

**OCBA方法**：
给定总预算 $N$，分配给 $M$ 个方案的评估次数 $n_1, ..., n_M$，使得选择最优方案的概率最大：
$$\min_{n_1,...,n_M} P(\text{选择错误的方案})$$

OCBA的最优分配准则：
$$\frac{n_i}{n_j} = \left(\frac{\sigma_i / \delta_i}{\sigma_j / \delta_j}\right)^2$$

其中 $\delta_i = |\mu_i - \mu^*|$ 是与最优方案的均值差距。

**批量的优势**：
- 利用并行计算加速
- 更稳定的探索（不受序列偏差影响）
- 适合实验周期长的场景

## 3. Python 实现

```python
import numpy as np

def ocba_allocation(means, stds, total_budget):
    """OCBA最优预算分配"""
    M = len(means)
    best = np.argmax(means)
    deltas = np.abs(means - means[best])
    deltas[best] = 1.0  # 避免除零

    ratios = np.zeros(M)
    for i in range(M):
        if i != best:
            ratios[i] = (stds[i] / deltas[i]) ** 2

    # 最优方案的比率
    sum_ratio = np.sum(ratios)
    ratios[best] = np.sqrt(sum_ratio * stds[best]**2)

    # 归一化到总预算
    allocation = np.round(ratios / ratios.sum() * total_budget).astype(int)
    allocation = np.maximum(allocation, 1)  # 至少1次
    return allocation

# 示例
means = np.array([3.0, 4.2, 3.5, 4.0, 2.8])
stds = np.array([1.0, 0.8, 1.2, 0.5, 0.9])
budget = 100

alloc = ocba_allocation(means, stds, budget)
print("方案均值:", means)
print("方案标准差:", stds)
print("OCBA分配:", alloc)
print(f"最优方案(索引{np.argmax(means)})分配: {alloc[np.argmax(means)]}次")
```
