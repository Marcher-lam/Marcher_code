# 被动学习(Passive Learning) 学习文档

> 无法选择探索方向的纯观测学习——从被动学习到主动学习到Bandit问题的递进关系。

> 来源线索：本节内容根据原书中关于"From Passive Learning to Active Learning to Bandit Problems"的相关章节(Ch 7.1.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：被动学习中，决策者无法控制输入x^n，只能从被动接收的观测数据中学习函数f(x)。

**直觉类比**：被动学习像看电视——你无法选择播放什么节目，只能从看到的节目中了解世界。主动学习像点播——你可以选择看什么节目来更快了解世界。

**历史背景**：被动学习是经典的统计学习设定。从被动到主动再到Bandit的递进，体现了"能否选择数据"这一维度上的差异。

**算法定位**：学习范式的最基本形式，是理解主动学习和Bandit问题的起点。

**前置知识**：
- 统计学习基础
- 回归分析

## 2. 核心原理

**三种学习范式的递进**：

| 范式 | 能否选择输入 | 典型方法 |
|---|---|---|
| 被动学习 | 不能 | 回归、批量学习 |
| 主动学习 | 能选择x来查询 | 贝叶斯优化、KG |
| Bandit | 能选择x并获得奖励 | UCB、Thompson采样 |

**被动学习的设定**：
- 数据 $(x^n, y^n)$ 逐个到达，但 $x^n$ 不受控制
- 目标：从观测序列估计 $f(x) = E[Y|x]$
- 可以使用任何回归方法（线性、非线性、非参数）

**被动学习的局限**：
- 在感兴趣的区域可能没有足够数据
- 无法通过探索来减少不确定性
- 学习效率完全取决于数据分布

**何时使用被动学习**：
- 历史数据分析（事后建模）
- 无法控制实验的场景（如观测研究）
- 作为主动学习策略的对照基准

## 3. Python 实现

```python
import numpy as np

def passive_vs_active_demo():
    """对比被动学习和主动学习的效果"""
    np.random.seed(42)
    f = lambda x: np.sin(2 * x) + 0.5 * x  # 真实函数
    sigma = 0.3

    # 被动学习：x从均匀分布中随机抽取
    n = 50
    x_passive = np.random.uniform(-3, 3, n)
    y_passive = f(x_passive) + sigma * np.random.randn(n)

    # 简单线性回归
    from numpy.polynomial import polynomial as P
    coef_passive = np.polyfit(x_passive, y_passive, 3)

    x_test = np.linspace(-3, 3, 200)
    y_true = f(x_test)
    y_pred = np.polyval(coef_passive, x_test)
    mse = np.mean((y_pred - y_true)**2)
    print(f"被动学习 MSE: {mse:.4f}")
    print("被动学习无法控制采样位置，可能错过重要区域")

passive_vs_active_demo()
```

## 4. 与其他方法的关系

- **主动学习**：可以选择查询点的被动学习推广
- **Bandit问题**：主动学习+累积奖励优化
- **知识梯度**：从被动学习过渡到主动学习的桥梁
