# 区间估计法(Interval Estimation) 学习文档

> 为每臂构造置信区间，选择上界最大的臂——UCB的前身。

> 来源线索：本节内容根据原书中关于"Interval Estimation"的相关章节(Ch 7)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：区间估计法为每臂的均值构造$1-\alpha$置信区间，选择置信上界最大的臂。

**公式**：

$$k^{IE} = \arg\max_k \left[\bar{\mu}_k + z_{\alpha/2}\frac{\hat{\sigma}_k}{\sqrt{n_k}}\right]$$

- $z_{\alpha/2}$：标准正态的$1-\alpha/2$分位数
- $\hat{\sigma}_k/\sqrt{n_k}$：标准误差

**与UCB的区别**：UCB的探索项是$\sqrt{2\ln n/n_k}$（极值理论），区间估计是$z\cdot\hat{\sigma}/\sqrt{n_k}$（正态近似）。IE更保守，UCB理论上更优。

## 4-8. 核心实现

```python
"""区间估计法"""
import numpy as np
from scipy.stats import norm

class IntervalEstimation:
    def __init__(self, n_arms, alpha=0.05):
        self.K = n_arms
        self.z = norm.ppf(1 - alpha/2)
        self.counts = np.zeros(n_arms)
        self.means = np.zeros(n_arms)
        self.m2 = np.zeros(n_arms)  # Welford求和

    def select(self):
        if np.any(self.counts < 2):
            return np.argmin(self.counts)
        se = np.sqrt(self.m2 / (self.counts * (self.counts-1)) + 1e-10)
        upper = self.means + self.z * se
        return np.argmax(upper)

    def update(self, k, reward):
        self.counts[k] += 1
        old_mean = self.means[k]
        self.means[k] += (reward - self.means[k]) / self.counts[k]
        self.m2[k] += (reward - old_mean) * (reward - self.means[k])

if __name__ == "__main__":
    np.random.seed(42)
    true_means = [1.0, 0.8, 0.6, 0.4, 0.2]
    ie = IntervalEstimation(5, alpha=0.05)
    for t in range(1000):
        k = ie.select()
        r = true_means[k] + 0.5*np.random.randn()
        ie.update(k, r)
    print(f"区间估计: 估计均值={ie.means.round(2)}, 拉取={ie.counts.astype(int)}")
```

## 9-14. 简要

### 12. 学习总结
区间估计：选$\arg\max[\bar{\mu}_k + z_{\alpha/2}\hat{\sigma}_k/\sqrt{n_k}]$。UCB的前身，更保守但在小样本时更稳定。

### 13. 练习题
**Q1**：$\alpha$变小会怎样？
**A1**：$\alpha$小→$z_{\alpha/2}$大→探索更多（置信区间更宽）。$\alpha \to 0$退化为纯探索。
