# 知识梯度_最终奖励(Knowledge Gradient for Final Reward) 学习文档

> 面向离线学习的知识梯度——选择能最大化学到最优方案概率的实验。

> 来源线索：Ch 7.8.2 "The Knowledge Gradient for Maximizing Final Reward"

## 1. 算法基础认知

**一句话定义**：KG-FR衡量"做一次实验后，我们选择最优方案的期望改进"，适用于预算有限、最终只选一个方案的离线设定。

## 2. 核心原理

**设定**：N次实验预算，目标是在预算结束后选出最好的方案x*。

**知识梯度**：
$$\nu^{KG}(x) = \mathbb{E}[\max_{x'} \bar{\mu}_{x'}^{n+1} | x^n=x] - \max_{x'} \bar{\mu}_{x'}^n$$

即"做了实验x后，最优估计值的期望改进"。

**计算**（高斯信念下）：
$$\nu^{KG}(x) = \hat{\sigma}_x \cdot f\left(\frac{|\hat{\mu}_x - \max_{x' \neq x} \hat{\mu}_{x'}|}{\hat{\sigma}_x}\right)$$

其中 $\hat{\sigma}_x$ 是实验后的后验标准差，$f(\cdot)$ 是正态分布相关的函数。

## 3. Python 实现

```python
import numpy as np
from scipy.stats import norm

def kg_final_reward(means, sigmas, n_options):
    """计算每个选项的知识梯度(最终奖励版)"""
    kg_values = np.zeros(n_options)
    current_best = np.max(means)

    for x in range(n_options):
        # 实验后的后验方差
        if sigmas[x] < 1e-10:
            kg_values[x] = 0
            continue
        # 简化计算
        delta = means[x] - current_best
        z = delta / sigmas[x]
        kg_values[x] = sigmas[x] * (z * norm.cdf(z) + norm.pdf(z))
    return kg_values

np.random.seed(42)
n = 5
means = np.array([3.0, 4.2, 3.5, 4.0, 2.8])
sigmas = np.array([0.5, 0.3, 0.8, 0.2, 0.6])
kg = kg_final_reward(means, sigmas, n)
print("均值:", means)
print("KG值:", np.round(kg, 4))
print(f"KG推荐实验: 方案{np.argmax(kg)}")
```
