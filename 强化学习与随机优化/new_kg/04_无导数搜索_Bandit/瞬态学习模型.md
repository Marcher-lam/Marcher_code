# 瞬态学习模型(Transient Learning Model) 学习文档

> 当真值随时间漂移时的学习问题——知识梯度的推广需要在动态环境中适应变化。

> 来源线索：本节内容根据原书中关于"Learning in Nonstationary Settings"和"Transient Learning Model"的相关章节(Ch 7.12)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：瞬态学习模型处理参数具有系统性漂移的非平稳Bandit问题，需要在线遗忘旧信息并持续追踪变化。

**直觉类比**：假设你经营多个产品线，每个产品的利润率在缓慢变化（有的上升、有的下降）。你需要不断重新评估哪个产品最赚钱，但又不能被短期噪声误导——这就是瞬态学习。

**历史背景**：非平稳Bandit问题是近年来的研究热点。瞬态模型假设真值按 $\theta_{t+1} = M_t\theta_t + \varepsilon_t$ 演化，比鞅真值更具一般性。

**算法定位**：Bandit/无导数搜索在非平稳设定下的推广。

**前置知识**：
- 多臂赌博机
- 鞅真值模型
- 知识梯度

## 2. 核心原理

**核心思想**：在标准Bandit设定上增加参数漂移：
$$\theta_{t+1} = M_t \theta_t + \varepsilon_t$$

每步观测：
$$y_t = \theta_t + \eta_t$$

**关键挑战**：
- 旧数据可能已经过时
- 需要平衡"遗忘速度"和"估计精度"
- 静态的探索策略（如标准UCB）可能失效

**瞬态知识梯度**：
$$\nu^{KG,transient}(x) = E[\max_{x'} \bar{\mu}_{x'}^{n+1} | x^n=x] - \max_{x'} \bar{\mu}_{x'}^n$$

需要考虑：
- 当前信念的不确定性
- 未来参数漂移的影响
- 信息的"保质期"

**适应策略**：
- **滑动窗口**：只使用最近W个观测
- **指数衰减**：用衰减权重替代等权重
- **动态信念更新**：在Bayes框架中显式建模漂移

## 3. Python 实现

```python
import numpy as np

class TransientBandit:
    """瞬态Bandit问题的学习"""
    def __init__(self, n_arms, drift_rate=0.01, alpha=0.1):
        self.n_arms = n_arms
        self.drift_rate = drift_rate
        self.alpha = alpha  # 遗忘因子
        self.means = np.zeros(n_arms)
        self.counts = np.zeros(n_arms)

    def select(self):
        """带有衰减权重的UCB选择"""
        unexplored = np.where(self.counts == 0)[0]
        if len(unexplored) > 0:
            return unexplored[0]
        # 使用确定性退火UCB
        bonus = 1.0 / np.sqrt(self.counts + 1)
        indices = self.means + 2.0 * bonus
        return np.argmax(indices)

    def update(self, arm, reward):
        """带遗忘的更新"""
        self.counts[arm] += 1
        # 指数衰减更新（遗忘旧信息）
        self.means[arm] = (1 - self.alpha) * self.means[arm] + self.alpha * reward

    def decay_all(self):
        """所有未选臂的均值向先验收缩"""
        for i in range(self.n_arms):
            if self.counts[i] > 0:
                self.means[i] *= (1 - self.drift_rate)

# 演示
np.random.seed(42)
n_arms = 5
true_means = np.array([4.0, 3.0, 5.0, 2.0, 4.5])
agent = TransientBandit(n_arms, alpha=0.15)

for t in range(300):
    # 每100步，真值发生漂移
    if t > 0 and t % 100 == 0:
        true_means += np.random.randn(n_arms) * 0.5
        print(f"步骤{t}: 真值漂移为 {np.round(true_means, 2)}")

    arm = agent.select()
    reward = true_means[arm] + np.random.randn() * 0.5
    agent.update(arm, reward)

print(f"\n最终估计: {np.round(agent.means, 2)}")
print(f"真实均值: {np.round(true_means, 2)}")
```

## 4. 与其他方法的关系

| 方法 | 关系 |
|---|---|
| 鞅真值模型 | 无漂移的特例 |
| 知识梯度 | 可推广到瞬态设定 |

| ADWIN | 变化检测方法 |
