# 多臂赌博机(Multi-Armed Bandit) 学习文档

> 多臂赌博机问题是探索-利用困境的经典模型，是A/B测试、推荐系统和在线学习的理论基础。

> 来源线索：本节内容根据原书中关于"The Multiarmed Bandit Problem"的相关章节(Ch 2.1.9, Ch 7)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：多臂赌博机问题要求决策者在K个不确定奖励的选项（臂）中反复选择，平衡探索未知选项与利用已知最优选项。

**直觉类比**：你来到一个有10台老虎机的赌场，每台机器的胜率未知。你有1000枚硬币。每投一枚到某台机器，你观察是赢还是输。问题是：应该怎么分配硬币来最大化总收益？多试几台来找到最好的（探索）vs 一直投已知最好的那台（利用）——这就是探索-利用困境。

**历史背景**：多臂赌博机问题最早由Herbert Robbins在1952年提出。1979年，Gittins证明了在贝叶斯框架下的最优策略（Gittins指数）。后续发展出UCB（Auer et al., 2002）、Thompson采样（1933年提出，近年复兴）、Knowledge Gradient（Powell & Ryzhov, 2012）等经典策略。

**算法定位**：在线学习/探索-利用问题。在原书统一框架中，多臂赌博机是"无导数随机搜索"（Ch 7）的核心应用，也是理解所有序贯决策问题中探索-利用权衡的基础。

**前置知识**：概率论（贝叶斯、期望）、统计学基础、Python编程。

## 2. 核心原理

**核心思想**：多臂赌博机的核心矛盾是**探索（Exploration）**vs**利用（Exploitation）**。探索能获取更多关于未知臂的信息，利用能最大化当前已知的收益。任何好策略都必须在两者之间取得平衡。

**工作流程**：

1. 初始化：为每个臂设置初始信念（如均匀分布）
2. 在每一步$n$：
   a. 根据当前信念和策略选择一个臂$a^n$
   b. 拉动该臂，观察奖励$W^{n+1}$
   c. 更新该臂的信念
3. 重复直到达到预定步数或满足停止条件

**关键概念**：

- **臂（Arm）**：每个可供选择的选项（机器、广告、药物等）
- **遗憾（Regret）**：最优臂的期望奖励减去策略的实际奖励
- **贝叶斯信念**：对每个臂奖励分布的当前估计
- **先验/后验**：初始信念/观察到数据后更新的信念

**策略分类**：

```
多臂赌博机策略
├── 贪心策略：ε-greedy（ε概率随机，1-ε概率选最优）
├── 基于置信上界：UCB（Upper Confidence Bound）
├── 贝叶斯策略：Thompson采样（从后验采样）
├── 基于学习价值：Knowledge Gradient（选择使期望后验最优的臂）
├── 基于索引：Gittins指数（折扣贝叶斯框架的最优解）
└── 区间估计：Interval Estimation
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $K$ | 臂的数量 |
| $\mu_k$ | 臂$k$的真实期望奖励 |
| $\bar{\mu}_k^n$ | $n$步后臂$k$的估计奖励 |
| $N_k^n$ | $n$步后臂$k$被拉动的次数 |
| $R_n$ | 第$n$步的奖励 |
| $\text{Regret}_n$ | 前$n$步的累积遗憾 |

### 遗憾定义

$$\text{Regret}_n = n\mu^* - \sum_{t=1}^n \mathbb{E}[R_t] = n\mu^* - \sum_{k=1}^K \mu_k \mathbb{E}[N_k^n]$$

其中$\mu^* = \max_k \mu_k$是最优臂的期望奖励。目标是使遗憾增长尽可能慢。

### ε-Greedy策略

$$a^n = \begin{cases} \arg\max_k \bar{\mu}_k^n & \text{概率 } 1-\varepsilon \\ \text{随机选择} & \text{概率 } \varepsilon \end{cases}$$

遗憾为$O(\sqrt{n})$（固定$\varepsilon$时为$O(n)$，需要衰减$\varepsilon$）。

### UCB1策略

$$a^n = \arg\max_k \left[\bar{\mu}_k^n + \sqrt{\frac{2\ln n}{N_k^n}}\right]$$

UCB1的累积遗憾上界为$O(\sqrt{nK\ln n})$。

### Thompson采样

1. 维护每个臂的后验分布$\text{Beta}(\alpha_k, \beta_k)$
2. 每步从后验采样$\theta_k \sim \text{Beta}(\alpha_k, \beta_k)$
3. 选择采样值最大的臂：$a^n = \arg\max_k \theta_k$
4. 观察结果后更新后验参数

对于伯努利奖励：成功则$\alpha_k \leftarrow \alpha_k + 1$，失败则$\beta_k \leftarrow \beta_k + 1$。

Thompson采样的遗憾为$O(\sqrt{nK\ln K})$，渐近最优。

### Knowledge Gradient

KG策略选择使"后验期望最优值-当前最优值"最大的臂：

$$a^{KG,n} = \arg\max_a \mathbb{E}[\max_k \bar{\mu}_k^{n+1} | a^n = a] - \max_k \bar{\mu}_k^n$$

KG显式计算"学到的信息有多少价值"，是信息量最优的探索策略。

### 贝叶斯更新（Beta-Bernoulli模型）

对于伯努利奖励（成功/失败），使用Beta分布作为先验：

$$\mu_k \sim \text{Beta}(\alpha_k, \beta_k)$$

观察到奖励$W^{n+1}$后：

$$\alpha_k \leftarrow \alpha_k + W^{n+1}, \quad \beta_k \leftarrow \beta_k + (1 - W^{n+1})$$

## 4. 训练过程讲解

### 参数初始化
- Beta先验：$\alpha_k = 1, \beta_k = 1$（均匀先验）
- 或乐观先验：$\alpha_k = 1, \beta_k = 0$（鼓励早期探索）

### 迭代过程
1. 从各臂的后验分布采样/计算UCB
2. 选择最优臂
3. 拉动该臂，观察奖励
4. 更新该臂的信念
5. 重复

### 收敛条件
- 达到预定步数$n$
- 或最优臂的置信区间足够窄

### 超参数表

| 策略 | 参数 | 推荐值 |
|------|------|--------|
| ε-greedy | $\varepsilon$ | 0.1（固定）或$1/n$（衰减） |
| UCB1 | $c$（探索系数） | $\sqrt{2}$ |
| Thompson | 先验$\alpha, \beta$ | 1, 1 |

## 5. 应用场景

### 1. A/B/n测试
为什么适合：多个广告文案/网页设计同时测试，多臂赌博机在测试过程中就开始利用最优方案，比传统A/B测试高效得多。

### 2. 推荐系统
为什么适合：推荐不同商品给用户，每个商品是一个"臂"，用户点击率是奖励。

### 3. 临床试验
为什么适合：多种药物剂量试验，每个剂量是一个臂，在试验过程中逐步将更多患者分配给效果更好的剂量。

### 4. 广告投放
为什么适合：不同广告创意是不同的臂，点击率是奖励，需要在探索新创意和投放已知好创意之间平衡。

## 6. 优缺点分析

### 优点（作为问题框架）
1. **理论深刻**：探索-利用权衡是所有序贯决策的核心
2. **策略丰富**：多种策略（UCB、Thompson、KG等）各有优势
3. **简单到复杂**：从2个臂到百万个臂都有成熟方案
4. **实用价值**：直接对应A/B测试等实际应用

### 缺点
1. **忽略状态**：标准设定不包含上下文信息
2. **假设平稳**：臂的奖励分布通常假设不变
3. **小规模问题**：臂数量极多时需要额外处理

### 策略对比

| 策略 | 遗憾上界 | 计算复杂度 | 实现难度 |
|------|---------|-----------|---------|
| ε-greedy | $O(n)$（固定ε） | $O(K)$ | 极低 |
| UCB1 | $O(\sqrt{nK\ln n})$ | $O(K)$ | 低 |
| Thompson | $O(\sqrt{nK\ln K})$ | $O(K)$ | 低 |
| KG | 依问题而定 | $O(K)$-高 | 中 |
| Gittins | 最优（折扣） | 高 | 高 |

## 7. 调库实现

```python
"""
多臂赌博机实验：对比不同策略
"""
import numpy as np
import matplotlib.pyplot as plt

class BanditEnvironment:
    """多臂赌博机环境"""
    def __init__(self, n_arms, true_probs=None):
        self.n_arms = n_arms
        self.true_probs = true_probs or np.random.uniform(0.1, 0.9, n_arms)
        self.best_prob = np.max(self.true_probs)

    def pull(self, arm):
        return 1.0 if np.random.random() < self.true_probs[arm] else 0.0


def epsilon_greedy(env, n_steps, epsilon=0.1):
    counts = np.zeros(env.n_arms)
    values = np.zeros(env.n_arms)
    rewards = []
    for t in range(n_steps):
        if np.random.random() < epsilon:
            arm = np.random.randint(env.n_arms)
        else:
            arm = np.argmax(values)
        reward = env.pull(arm)
        counts[arm] += 1
        values[arm] += (reward - values[arm]) / counts[arm]
        rewards.append(reward)
    return rewards


def ucb1(env, n_steps):
    counts = np.zeros(env.n_arms)
    values = np.zeros(env.n_arms)
    rewards = []
    for t in range(n_steps):
        if t < env.n_arms:  # 先每个臂拉一次
            arm = t
        else:
            ucb = values + np.sqrt(2 * np.log(t + 1) / (counts + 1e-10))
            arm = np.argmax(ucb)
        reward = env.pull(arm)
        counts[arm] += 1
        values[arm] += (reward - values[arm]) / counts[arm]
        rewards.append(reward)
    return rewards


def thompson_sampling(env, n_steps):
    alpha = np.ones(env.n_arms)  # Beta先验参数
    beta = np.ones(env.n_arms)
    rewards = []
    for t in range(n_steps):
        samples = np.random.beta(alpha, beta)
        arm = np.argmax(samples)
        reward = env.pull(arm)
        alpha[arm] += reward
        beta[arm] += (1 - reward)
        rewards.append(reward)
    return rewards


# 运行对比实验
if __name__ == "__main__":
    np.random.seed(42)
    n_arms = 10
    n_steps = 5000
    n_runs = 100

    env = BanditEnvironment(n_arms)
    print(f"真实奖励概率: {env.true_probs.round(3)}")
    print(f"最优臂概率: {env.best_prob:.3f}")

    # 多次运行取平均
    results = {}
    for name, strategy in [('ε-greedy', epsilon_greedy),
                            ('UCB1', ucb1),
                            ('Thompson', thompson_sampling)]:
        all_rewards = np.zeros(n_steps)
        for _ in range(n_runs):
            all_rewards += np.array(strategy(env, n_steps))
        all_rewards /= n_runs
        results[name] = all_rewards

    # 计算累积遗憾
    optimal = np.cumsum(np.full(n_steps, env.best_prob))
    for name, rewards in results.items():
        regret = optimal - np.cumsum(rewards)
        print(f"{name}: 最终累积遗憾={regret[-1]:.1f}")
```

## 8. 手工代码实现

```python
"""
从零实现多臂赌博机策略（纯NumPy）
包含ε-greedy、UCB1、Thompson采样、Knowledge Gradient
"""
import numpy as np

class BanditSolver:
    """多臂赌博机求解器"""

    def __init__(self, n_arms):
        self.n_arms = n_arms

    def epsilon_greedy(self, pull_fn, n_steps, epsilon=0.1):
        """ε-greedy策略"""
        counts = np.zeros(self.n_arms)
        values = np.zeros(self.n_arms)
        cumulative_regret = []

        for t in range(n_steps):
            if np.random.random() < epsilon:
                arm = np.random.randint(self.n_arms)
            else:
                arm = np.argmax(values)
            reward, best_reward = pull_fn(arm)
            counts[arm] += 1
            values[arm] += (reward - values[arm]) / counts[arm]
            cumulative_regret.append(best_reward - reward)

        return np.cumsum(cumulative_regret)

    def ucb1(self, pull_fn, n_steps, c=1.414):
        """UCB1策略"""
        counts = np.ones(self.n_arms) * 0.001  # 避免除零
        values = np.zeros(self.n_arms)
        cumulative_regret = []

        for t in range(n_steps):
            ucb = values + c * np.sqrt(np.log(t + 1) / counts)
            arm = np.argmax(ucb)
            reward, best_reward = pull_fn(arm)
            counts[arm] += 1
            values[arm] += (reward - values[arm]) / counts[arm]
            cumulative_regret.append(best_reward - reward)

        return np.cumsum(cumulative_regret)

    def thompson_sampling(self, pull_fn, n_steps):
        """Thompson采样策略（Beta-Bernoulli模型）"""
        alpha = np.ones(self.n_arms)
        beta_param = np.ones(self.n_arms)
        cumulative_regret = []

        for t in range(n_steps):
            samples = np.random.beta(alpha, beta_param)
            arm = np.argmax(samples)
            reward, best_reward = pull_fn(arm)
            alpha[arm] += reward
            beta_param[arm] += (1 - reward)
            cumulative_regret.append(best_reward - reward)

        return np.cumsum(cumulative_regret)


# ========== 测试 ==========
if __name__ == "__main__":
    np.random.seed(42)
    K = 10
    true_probs = np.random.uniform(0.2, 0.8, K)
    best_prob = np.max(true_probs)

    def pull(arm):
        r = 1.0 if np.random.random() < true_probs[arm] else 0.0
        return r, best_prob

    solver = BanditSolver(K)
    n_steps = 3000

    reg_eg = solver.epsilon_greedy(pull, n_steps, epsilon=0.1)
    reg_ucb = solver.ucb1(pull, n_steps)
    reg_ts = solver.thompson_sampling(pull, n_steps)

    print(f"ε-greedy 最终遗憾: {reg_eg[-1]:.1f}")
    print(f"UCB1    最终遗憾: {reg_ucb[-1]:.1f}")
    print(f"Thompson最终遗憾: {reg_ts[-1]:.1f}")
```

## 11. 常见问题与易错点

### 数据层面

1. **先验选择不当**
   - 现象：Thompson采样初期表现很差
   - 原因：先验$\alpha=\beta=1$对于已知某些臂很好的情况不够informative
   - 解决方案：使用informative先验或warm-start

2. **非平稳奖励**
   - 现象：策略在后期表现退步
   - 原因：臂的真实奖励随时间变化
   - 解决方案：使用滑动窗口或衰减因子

### 模型层面

3. **ε-greedy的ε固定**
   - 现象：永远有ε比例的浪费探索
   - 原因：不衰减的ε导致线性遗憾
   - 解决方案：使用衰减ε（如$\varepsilon_t = 1/t$）

4. **忽略臂之间的相关性**
   - 现象：相似臂的信息未共享
   - 原因：独立信念假设忽略了结构信息
   - 解决方案：使用相关信念模型（原书Ch 7.8.5）

### 调参层面

5. **UCB探索常数c的选择**
   - 现象：c太大过度探索，c太小探索不足
   - 解决方案：理论最优$c=\sqrt{2}$，实践中可调至$[1, 2]$

## 12. 学习总结

多臂赌博机问题虽然简单，但蕴含了序贯决策的核心矛盾：探索与利用。不同的策略从不同角度解决这个问题——ε-greedy简单直接，UCB基于置信区间，Thompson基于贝叶斯采样，KG基于信息价值计算。

**关键公式**：
1. 累积遗憾：$\text{Regret}_n = n\mu^* - \sum_{t=1}^n R_t$
2. UCB1：$a^n = \arg\max_k [\bar{\mu}_k^n + \sqrt{2\ln n / N_k^n}]$
3. Thompson：$\theta_k \sim \text{Beta}(\alpha_k, \beta_k)$，选$\arg\max_k \theta_k$

多臂赌博机是理解所有强化学习探索策略的基础。在原书框架中，它是无导数随机搜索（Ch 7）的核心问题，也是"上下文赌博机"（引入状态信息）和完整RL问题的过渡桥梁。

## 13. 练习题与思考题

### 基础题

**题目1**：有3台老虎机，真实胜率分别为0.3、0.5、0.7。使用ε-greedy策略（ε=0.2），前10步奖励总和为4。最优策略（一直选臂3）的期望奖励总和是多少？累积遗憾是多少？

**参考答案**：
最优策略期望：$10 \times 0.7 = 7.0$
实际奖励总和：4
累积遗憾：$7.0 - 4 = 3.0$

### 进阶题

**题目2**：证明UCB1策略的累积遗憾最多为$O(\sqrt{nK\ln n})$。（给出直觉论证即可）

**参考答案**：
直觉论证：
- UCB公式中的$\sqrt{2\ln n/N}$项保证每个次优臂$k$被选择的次数不超过$O(\ln n/\Delta_k^2)$次（$\Delta_k = \mu^* - \mu_k$）
- 因为如果被选太多次，置信区间会变窄，UCB值会低于最优臂
- 每次选次优臂贡献$\Delta_k$遗憾
- 总遗憾$\leq \sum_{k \neq k^*} O(\ln n / \Delta_k) \cdot \Delta_k = O(K \ln n)$
- 更紧的界限通过Hoeffding不等式得到$O(\sqrt{nK\ln n})$

### 开放思考题

**题目3**：原书（Ch 7.13.6）讨论了"上下文赌博机"（Contextual Bandit），即在每次选择前可以观察到一个状态/上下文变量。这与标准赌博机有什么本质区别？在实际应用中，什么情况下需要上下文信息？

**参考答案方向**：
- 本质区别：标准赌博机对每个臂维护一个全局估计；上下文赌博机需要学习"在什么状态下哪个臂好"的函数
- 需要上下文的场景：(1)用户个性化推荐（用户特征是上下文）；(2)医疗决策（患者特征是上下文）；(3)动态定价（市场条件是上下文）
- 计算代价更高（需要函数近似），但效果显著更好

## 14. 学习路径建议

**前置算法**：概率论、贝叶斯统计、大数定律

**平行算法**：主动学习（Active Learning）、贝叶斯优化

**进阶算法**：上下文赌博机（Contextual Bandit）、Gittins指数、Knowledge Gradient、仿真优化
