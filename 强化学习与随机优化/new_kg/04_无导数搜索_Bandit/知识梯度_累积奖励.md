# 知识梯度_累积奖励(Knowledge Gradient for Cumulative Reward) 学习文档

> 面向在线学习的知识梯度——平衡"当前收益"和"未来信息价值"。

> 来源线索：Ch 7.8.3 "The Knowledge Gradient for Maximizing Cumulative Reward"

## 1. 算法基础认知

**一句话定义**：KG-CR在选择方案时同时考虑"当前的期望奖励"和"学到的信息在未来带来的价值"，适用于边学习边收获的在线设定。

## 2. 核心原理

**设定**：T次机会，每次选择一个方案并获得奖励，目标是最大化总奖励。

**KG-CR策略**：
$$x^{KG} = \arg\max_x \left(\bar{\mu}_x^n + (T-n) \cdot \nu^{KG}(x)\right)$$

- 第一项 $\bar{\mu}_x^n$：当前的期望收益（exploitation）
- 第二项 $(T-n) \cdot \nu^{KG}(x)$：未来利用信息的总价值（exploration）

**与最终奖励KG的区别**：
- KG-FR：只关心最终选对（离线设定）
- KG-CR：关心累积收益（在线设定），额外加了当期收益

**理论性质**：KG-CR的index结构与UCB、Gittins指数一致——都是"当期收益+探索bonus"。

## 3. Python 实现

```python
import numpy as np
from scipy.stats import norm

def kg_cumulative_reward(means, sigmas, n_options, T_remaining):
    """KG-CR策略"""
    current_best = np.max(means)
    kg_cr = np.zeros(n_options)

    for x in range(n_options):
        # 当期收益
        immediate = means[x]
        # KG值（未来信息价值）
        if sigmas[x] > 1e-10:
            delta = means[x] - current_best
            z = delta / sigmas[x]
            kg_val = sigmas[x] * (z * norm.cdf(z) + norm.pdf(z))
        else:
            kg_val = 0
        # 累积奖励 = 当期 + 未来
        kg_cr[x] = immediate + T_remaining * kg_val

    return kg_cr

np.random.seed(42)
means = np.array([3.0, 4.2, 3.5, 4.0, 2.8])
sigmas = np.array([0.5, 0.3, 0.8, 0.2, 0.6])
T = 100
kg_cr = kg_cumulative_reward(means, sigmas, 5, T)
print("KG-CR值:", np.round(kg_cr, 3))
print(f"推荐方案: {np.argmax(kg_cr)}")
print(f"(注意: 均值最高的是方案{np.argmax(means)}, KG-CR可能推荐探索其他方案)")
```
