# 知识梯度_瞬态问题(Knowledge Gradient for Transient Problems) 学习文档

> 当真值随时间漂移时，知识的"保质期"有限——KG需要考虑信息衰减。

> 来源线索：Ch 7.13 "The Knowledge Gradient for Transient Problems"

## 1. 算法基础认知

**一句话定义**：瞬态KG在标准KG基础上考虑参数漂移，信息的价值随时间衰减。

## 2. 核心原理

**核心问题**：标准KG假设真值不变，学到的东西永远有效。但在瞬态设定下，θ_t在漂移，所以信息会过时。

**修正**：
$$\nu^{KG,transient}(x) = \nu^{KG}(x) \cdot \gamma_{info}$$

其中 $\gamma_{info}$ 是信息的"折扣因子"，取决于漂移速度。

**特殊性质**：当漂移矩阵 $M_t = I$ 时（鞅真值），瞬态KG退化为标准KG。

## 3. Python 实现

```python
import numpy as np

def kg_transient(means, sigmas, drift_rate, T_remaining):
    """瞬态KG"""
    info_decay = 1.0 / (1.0 + drift_rate * T_remaining)
    kg = np.zeros(len(means))
    best = np.max(means)
    from scipy.stats import norm
    for x in range(len(means)):
        if sigmas[x] < 1e-10: continue
        z = (means[x] - best) / sigmas[x]
        kg[x] = sigmas[x] * (z * norm.cdf(z) + norm.pdf(z)) * info_decay
    return kg

means = np.array([3.0, 4.0, 3.5])
sigmas = np.array([0.5, 0.4, 0.8])
for drift in [0.0, 0.05, 0.2]:
    kg = kg_transient(means, sigmas, drift, T_remaining=50)
    print(f"漂移率={drift:.2f}: KG={np.round(kg,4)}, 推荐={np.argmax(kg)}")
```
