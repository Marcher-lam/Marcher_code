# 知识梯度_采样信念与相关信念(KG Extensions) 学习文档

> 知识梯度的两种扩展：采样信念模型处理非高斯分布，相关信念利用方案间相似性。

> 来源线索：Ch 7.8.4-7.8.5 "KG for Sampled Belief Model" 和 "KG for Correlated Beliefs"

## 1. 算法基础认知

**一句话定义**：KG的扩展版本，处理非高斯信念（用采样表示）和方案间存在相关性的情况。

## 2. 核心原理

### 采样信念模型(Sampled Belief)
当后验分布不是高斯时，用粒子/采样表示信念：
$$P(\theta|D) \approx \{theta^{(1)}, ..., theta^{(K)}\}$$

KG计算：
1. 对每个候选方案x，模拟实验结果
2. 对每种模拟结果更新采样信念
3. 计算期望改进

### 相关信念(Correlated Beliefs)
方案之间存在相关性（如地理位置相近的餐厅质量相关）：
$$Cov(\mu_x, \mu_{x'}) = \Sigma_{xx'} \neq 0$$

关键：观察方案x不仅减少x的不确定性，还减少相关方案x'的不确定性。

KG需要考虑"观察一个方案帮助了多少其他方案"。

## 3. Python 实现

```python
import numpy as np

def kg_correlated(means, cov_matrix, n_options):
    """相关信念下的知识梯度"""
    kg_values = np.zeros(n_options)
    current_best_idx = np.argmax(means)
    current_best_val = means[current_best_idx]

    for x in range(n_options):
        # 观察x后，所有方案的方差减少
        sigma_xx = cov_matrix[x, x]
        if sigma_xx < 1e-10:
            kg_values[x] = 0
            continue

        # 协方差向量
        cov_x = cov_matrix[:, x]
        # 更新后的均值方差
        post_var = cov_matrix - np.outer(cov_x, cov_x) / sigma_xx
        # 简化KG估计
        improvement = 0
        for s in range(100):
            noise = np.random.randn() * np.sqrt(sigma_xx)
            new_means = means + cov_x * noise / sigma_xx
            improvement += max(0, np.max(new_means) - current_best_val)
        kg_values[x] = improvement / 100

    return kg_values

np.random.seed(42)
n = 4
means = np.array([3.0, 4.0, 3.5, 3.8])
# 相关矩阵：相邻方案高相关
cov = np.array([[1.0, 0.5, 0.1, 0.0],
                [0.5, 1.0, 0.5, 0.1],
                [0.1, 0.5, 1.0, 0.5],
                [0.0, 0.1, 0.5, 1.0]])
kg = kg_correlated(means, cov, n)
print("KG(相关信念):", np.round(kg, 4))
print(f"推荐观察: 方案{np.argmax(kg)}")
```
