# 遗憾分析(Regret Analysis) 学习文档

> 评估序贯决策策略性能的核心理论工具：静态遗憾、动态遗憾和机会成本。

> 来源线索：本节内容根据原书中关于"Static Regret – Stochastic Setting"、"Dynamic Regret"、"Opportunity Cost"的相关章节(Ch 7, Derivative-free Stochastic Search章节)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：遗憾衡量策略累积回报与最优策略累积回报的差距，是评估Bandit和在线学习算法性能的核心度量。

**算法定位**：性能评估工具 / 理论分析框架。贯穿Bandit、在线学习和随机搜索。

**前置知识**：多臂赌博机、探索-利用困境、大数定律。

## 2. 核心原理

**核心思想**：与其问"算法找到了最优动作吗？"，不如问"算法因为不知道最优动作而损失了多少？"遗憾量化了这个差距。

**为什么需要遗憾而非精确度**：
- 精确度（是否找到最优）是二值的，不反映过程质量
- 遗憾是累积的，反映探索的代价
- 遗憾的渐近增长率（$O(\sqrt{T})$、$O(\log T)$等）是算法性能的理论保证

**三种遗憾度量**：
1. **静态遗憾(Static Regret)**：与固定的最优策略比较
2. **动态遗憾(Dynamic Regret)**：与时变的最优策略比较
3. **机会成本(Opportunity Cost)**：每次决策的即时损失

## 3. 数学公式

### 静态遗憾（随机设定）

$$R_T^{\text{static}} = \max_a \sum_{t=1}^T \mathbb{E}[r(a, W_t)] - \sum_{t=1}^T \mathbb{E}[r(a_t, W_t)]$$

其中$a$是固定的最优动作，$a_t$是算法在时刻$t$选择的动作，$W_t$是随机噪声。

### 静态遗憾（对抗设定）

$$R_T^{\text{adv}} = \max_{a \in \mathcal{A}} \sum_{t=1}^T r_t(a) - \sum_{t=1}^T r_t(a_t)$$

### 动态遗憾

$$R_T^{\text{dyn}} = \sum_{t=1}^T \max_a \mu_t(a) - \sum_{t=1}^T \mu_t(a_t)$$

其中$\mu_t(a)$在每步可能变化（非平稳环境）。动态遗憾的下界为$O(\sqrt{T V_T})$，$V_T$是环境变化量。

### 机会成本

$$\text{OC}(a_t) = \max_a r(a, W_t) - r(a_t, W_t)$$

每次决策的即时损失，是遗憾的"微观"版本：$R_T = \sum_{t=1}^T \mathbb{E}[\text{OC}(a_t)]$。

### 渐近收敛性

对于最终奖励(final reward)目标：

$$\mathbb{E}[R_T] = \mathbb{E}[\max_a \mu(a)] - \mathbb{E}[\mu(a_T)]$$

当$T \to \infty$时，好的策略应使$\mathbb{E}[R_T] \to 0$（选择收敛到最优）。

### 经典遗憾界

| 算法 | 遗憾界 | 设定 |
|------|--------|------|
| $\epsilon$-greedy | $O(T^{2/3})$ | 随机 |
| UCB | $O(\sqrt{T \log T})$ | 随机 |
| Thompson采样 | $O(\sqrt{T \log T})$ | 随机 |
| 知识梯度 | $O(\sqrt{T})$ | 随机 |
| EXP3 | $O(\sqrt{T \log K})$ | 对抗 |

## 4. 分析过程

1. **定义遗憾**：选择合适的遗憾度量（静态/动态/机会成本）
2. **推导上界**：分析算法的期望遗憾$\mathbb{E}[R_T]$
3. **推导下界**：证明任何算法至少有多少遗憾
4. **匹配上下界**：如果上界与下界同阶，算法是最优的
5. **经验验证**：在仿真中测量实际遗憾曲线

## 5. 应用场景

- **Bandit算法比较**：用遗憾曲线对比不同算法
- **在线广告投放**：遗憾 = 因非最优广告位损失的收入
- **临床试验**：遗憾 = 因非最优治疗方案损失的治愈率
- **推荐系统**：遗憾 = 因非最优推荐损失的用户满意度
- **算法调参**：遗憾 = 因非最优超参数损失的性能

## 6. 优缺点

**优点**：
- 提供理论性能保证
- 可比较不同算法（渐近增长率）
- 同时反映探索代价和利用效率

**缺点**：
- 期望遗憾可能掩盖高概率事件的风险
- 最坏情况遗憾可能过于保守
- 计算精确遗憾需要知道最优策略（实际不可得）

## 7. 库实现

遗憾分析通常是理论工具，但在实验中可直接计算。Python中可自定义遗憾计算函数。

## 8. 从零实现

```python
"""遗憾分析：对比Bandit算法的累积遗憾"""
import numpy as np

class RegretAnalyzer:
    def __init__(self, true_means):
        """
        true_means[a] = arm a的真实均值
        """
        self.means = true_means
        self.optimal_mean = np.max(true_means)
        self.cumulative_regret = []
        self.total_regret = 0

    def record(self, chosen_arm):
        """记录一次选择的即时遗憾"""
        instant_regret = self.optimal_mean - self.means[chosen_arm]
        self.total_regret += instant_regret
        self.cumulative_regret.append(self.total_regret)
        return instant_regret

class EpsilonGreedy:
    def __init__(self, n_arms, epsilon=0.1):
        self.n_arms = n_arms
        self.epsilon = epsilon
        self.counts = np.zeros(n_arms)
        self.values = np.zeros(n_arms)

    def select(self):
        if np.random.random() < self.epsilon:
            return np.random.randint(self.n_arms)
        return np.argmax(self.values)

    def update(self, arm, reward):
        self.counts[arm] += 1
        n = self.counts[arm]
        self.values[arm] += (reward - self.values[arm]) / n

class UCB:
    def __init__(self, n_arms, c=2.0):
        self.n_arms = n_arms
        self.c = c
        self.counts = np.zeros(n_arms)
        self.values = np.zeros(n_arms)
        self.t = 0

    def select(self):
        self.t += 1
        for a in range(self.n_arms):
            if self.counts[a] == 0:
                return a
        ucb = self.values + self.c * np.sqrt(np.log(self.t) / self.counts)
        return np.argmax(ucb)

    def update(self, arm, reward):
        self.counts[arm] += 1
        n = self.counts[arm]
        self.values[arm] += (reward - self.values[arm]) / n

def run_comparison(true_means, T=5000):
    K = len(true_means)
    results = {}

    for name, agent in [
        ("Epsilon-Greedy", EpsilonGreedy(K, epsilon=0.1)),
        ("UCB", UCB(K, c=2.0)),
    ]:
        analyzer = RegretAnalyzer(true_means)
        for t in range(T):
            arm = agent.select()
            reward = np.random.binomial(1, true_means[arm])
            agent.update(arm, reward)
            analyzer.record(arm)
        results[name] = analyzer.cumulative_regret
        print(f"{name:20s}: 最终遗憾={analyzer.total_regret:.1f}")

    return results

if __name__ == "__main__":
    np.random.seed(42)
    true_means = np.array([0.3, 0.5, 0.7, 0.4, 0.6])
    print(f"真实均值: {true_means}")
    print(f"最优arm: {np.argmax(true_means)}, 最优均值: {np.max(true_means):.1f}\n")

    results = run_comparison(true_means, T=5000)

    # 打印遗憾增长率分析
    T = len(results["UCB"])
    for name, regrets in results.items():
        # 检查遗憾是否为O(sqrt(T))
        ratio = regrets[-1] / np.sqrt(T)
        print(f"{name}: R_T/sqrt(T) = {ratio:.2f}")
```

## 10. 评估方法

- 累积遗憾曲线：直接绘制$R_t$随$t$的变化
- 遗憾增长率：$R_T / \sqrt{T}$（应收敛到常数）
- 高概率界：$\Pr(R_T > c\sqrt{T \log T})$的概率
- 与理论界的对比

## 11. 常见错误

- 混淆期望遗憾和高概率遗憾
- 在对抗设定中用随机遗憾界
- 忽略遗憾中的常数因子（理论界和实际性能可能差距大）
- 用瞬时遗憾而非累积遗憾评估算法

## 12. 学习总结

遗憾：$R_T = \sum_{t=1}^T (\mu^* - \mu_{a_t})$，衡量策略与最优的累积差距。静态遗憾对固定最优，动态遗憾对时变最优。UCB达$O(\sqrt{T\log T})$，是最优的（近似）。

## 13. 练习题

**Q1**：为什么UCB的遗憾是$O(\sqrt{T\log T})$而非$O(\sqrt{T})$？
**A1**：$O(\sqrt{T})$是下界，UCB多了一个$\sqrt{\log T}$因子来自置信区间。Thompson采样在某些条件下可以达到更紧的界$O(\sqrt{T})$，但UCB在实践中更稳健。

**Q2**：动态遗憾为什么总比静态遗憾大？
**A2**：动态遗憾与时变的最优策略比较，需要同时跟踪环境变化。下界为$O(\sqrt{T V_T})$，其中$V_T$衡量环境变化总量。当环境不变（$V_T=0$）时退化为静态遗憾。
