# 无差异区域算法(Indifference Zone Algorithm) 学习文档

> 在仿真优化中选择最优系统设计，保证选中的系统以高概率接近最优——OCBA之外的另一条统计路径。

> 来源线索：本节内容根据原书中关于"An Indifference Zone Algorithm"的相关章节(Ch 7.10)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：IZ算法通过两阶段序贯抽样，保证选出的系统以概率$\geq 1-\alpha$落入最优系统的$\delta$邻域内（indifference zone）。

**算法定位**：仿真优化 / 排序与选择(Ranking & Selection)。与OCBA并列的两大统计选择框架。

**前置知识**：多臂赌博机、假设检验、中心极限定理。

## 2. 核心原理

**核心思想**：用户指定两个参数——显著水平$\alpha$（选错的概率上限）和无差异区域$\delta$（"够好"的标准）。算法保证：如果真正最优与次优的差距$> \delta$，则以概率$\geq 1-\alpha$选中最优。

**与OCBA的关键区别**：
- OCBA：最小化总仿真次数（计算预算最优），但不给概率保证
- IZ：给定概率保证$1-\alpha$，自适应确定仿真次数（统计保证最优）

**两种范式**：
- **固定精度范式(IZ)**：给定$(\alpha, \delta)$，求最小样本量
- **固定预算范式(OCBA)**：给定总预算$N$，最大化正确选择概率

## 3. 数学公式

### 无差异区域条件

设$K$个系统的真实性能为$\mu_1 \geq \mu_2 \geq \cdots \geq \mu_K$。要求：

$$\Pr[\text{选择系统 } 1] \geq 1 - \alpha$$

只要$\mu_1 - \mu_2 \geq \delta$（无差异区域条件）。

### Rinott's Procedure（经典两阶段IZ）

**第一阶段**：每个系统仿真$n_0$次，估计样本方差：

$$S_i^2 = \frac{1}{n_0 - 1}\sum_{j=1}^{n_0}(X_{ij} - \bar{X}_i)^2$$

**计算附加样本量**：

$$N_i = \max\left(n_0, \left\lceil \frac{h^2 S_i^2}{\delta^2} \right\rceil \right)$$

其中$h = h(K, n_0, 1-\alpha)$是Rinott常数（查表或数值计算）。

**第二阶段**：每个系统追加$N_i - n_0$次仿真。

**选择**：选$\bar{X}_i$最大的系统。

### Rinott常数

$h$满足：

$$\Pr\left[\bigcap_{i=2}^{K}\left\{\bar{X}_1 - \bar{X}_i \geq 0\right\}\right] \geq 1 - \alpha$$

在$\mu_1 - \mu_i = \delta$（最不利配置）下计算。

### 序贯IZ（KN procedure）

Rinott是两阶段的，KN（Kim-Nelson）是全序贯的：

$$I = \{1, 2, \ldots, K\}$$
$$t = 0$$

每步$t$：
1. 对$i \in I$仿真一步
2. 更新$\bar{X}_i(t)$
3. 淘汰：若$\bar{X}_i(t) < \max_{j \in I} \bar{X}_j(t) - W(t)$，则$I \leftarrow I \setminus \{i\}$

其中$W(t)$是淘汰边界（随$t$递增的置信区间宽度）。

## 4. 迭代过程

**Rinott两阶段流程**：
1. 用户指定$(\alpha, \delta)$，选择初始样本量$n_0$
2. 第一阶段：每个系统仿真$n_0$次
3. 计算样本方差$S_i^2$
4. 查Rinott常数$h$
5. 计算总样本量$N_i = \lceil h^2 S_i^2 / \delta^2 \rceil$
6. 第二阶段：每个系统追加仿真到$N_i$次
7. 选择$\bar{X}_i$最大的系统

## 5. 应用场景

- 仿真优化：比较多个系统设计的性能
- 制造系统：选择最优生产参数
- 交通网络：选择最优信号配时方案
- 医疗试验：选择最优治疗方案（当需要统计保证时）
- 供应链：选择最优库存策略

## 6. 优缺点

**优点**：
- 给出明确的概率保证$\Pr[\text{正确选择}] \geq 1-\alpha$
- 方差越大的系统自动获得更多仿真次数
- 理论保证严格，不依赖渐近性

**缺点**：
- 保守：为保证概率，总仿真次数往往比OCBA多
- 需要预先指定$\delta$（不总是自然）
- 假设正态性（大样本下由CLT保证）
- 对方差估计敏感（$n_0$太小可能低估方差）

## 7. 库实现

Python中可用 `simpy` 做仿真，`scipy.stats` 计算Rinott常数。无主流库直接实现IZ，需自行编码。

## 8. 从零实现

```python
"""无差异区域算法：Rinott两阶段选择"""
import numpy as np
from scipy.stats import t as t_dist

def rinott_constant(K, n0, alpha):
    """近似计算Rinott常数h（基于t分布的多重比较）"""
    # 精确值需要数值积分，这里用Bonferroni近似
    # h ≈ t_{n0-1, 1-alpha/(K-1)} 的分位点
    t_quantile = t_dist.ppf(1 - alpha / (2 * (K - 1)), df=n0 - 1)
    return t_quantile * np.sqrt(2)  # 两样本比较的因子

def indifference_zone_select(systems, n0, alpha, delta):
    """
    IZ两阶段选择算法
    systems: list of callables, each returns a simulation sample
    n0: 第一阶段样本量
    alpha: 显著水平（选错概率上限）
    delta: 无差异区域半宽
    """
    K = len(systems)
    h = rinott_constant(K, n0, alpha)

    # 第一阶段：每个系统仿真n0次
    samples_stage1 = []
    means_stage1 = []
    variances = []
    for sys_fn in systems:
        obs = np.array([sys_fn() for _ in range(n0)])
        samples_stage1.append(obs)
        means_stage1.append(obs.mean())
        variances.append(obs.var(ddof=1))

    # 计算每个系统需要的总样本量
    N = []
    for i in range(K):
        Ni = max(n0, int(np.ceil(h**2 * variances[i] / delta**2)))
        N.append(Ni)

    # 第二阶段：追加仿真
    final_means = []
    for i in range(K):
        additional = N[i] - n0
        if additional > 0:
            obs2 = np.array([systems[i]() for _ in range(additional)])
            all_obs = np.concatenate([samples_stage1[i], obs2])
        else:
            all_obs = samples_stage1[i]
        final_means.append(all_obs.mean())

    best = np.argmax(final_means)
    return best, final_means, N

if __name__ == "__main__":
    np.random.seed(42)

    # 5个系统设计，真实性能不同
    true_means = [10.0, 9.5, 8.0, 9.8, 7.5]
    true_stds = [2.0, 1.5, 3.0, 1.0, 2.5]
    systems = [lambda mu=m, sig=s: np.random.normal(mu, sig)
               for m, s in zip(true_means, true_stds)]

    n0 = 10
    alpha = 0.05
    delta = 0.5

    best, means, N = indifference_zone_select(systems, n0, alpha, delta)

    print(f"无差异区域参数: alpha={alpha}, delta={delta}, n0={n0}")
    print(f"Rinott近似常数 h={rinott_constant(len(systems), n0, alpha):.3f}")
    print(f"\n选择结果:")
    for i in range(len(systems)):
        marker = " ← 最优" if i == best else ""
        print(f"  系统{i}: 真值={true_means[i]:.1f}, 估计={means[i]:.2f}, "
              f"样本量={N[i]}{marker}")
    print(f"\n选中的系统{best}，真实最优是系统{np.argmax(true_means)}")
    print(f"选择是否正确: {best == np.argmax(true_means)}")
```

## 10. 评估方法

- 正确选择概率（多次重复实验统计）
- 总仿真次数（与OCBA对比效率）
- 对$(\alpha, \delta)$参数的敏感性

## 11. 常见错误

- $n_0$太小导致方差估计不准，总样本量严重偏高
- $\delta$设得太大，把"够好但非最优"的系统也接受了
- 忘记Rinott常数依赖于$K$和$n_0$（不能复用）
- 假设正态性但不验证

## 12. 学习总结

IZ算法：两阶段抽样，第一阶段估方差，第二阶段按$h^2 S_i^2/\delta^2$确定样本量。保证$\Pr[\text{正确选择}] \geq 1-\alpha$。与OCBA互补：IZ给统计保证，OCBA给计算效率。

## 13. 练习题

**Q1**：IZ和OCBA各适合什么场景？
**A1**：IZ适合需要严格统计保证的场景（如安全关键系统、医疗决策），OCBA适合计算预算有限但需要高效分配的场景。IZ的保守性是统计保证的代价。

**Q2**：无差异区域$\delta$如何选择？
**A2**：$\delta$反映用户对"够好"的容忍度。$\delta$太大→接受次优解，$\delta$太小→需要大量仿真。实践中可设为最优值的一定百分比（如5%），或基于业务意义定义。
