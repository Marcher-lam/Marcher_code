# 区间估计策略(Interval Estimation Policy) 学习文档

> UCB策略的重要变体——用估计的标准差作为不确定性bonus，是平衡探索与利用的直觉方法。

> 来源线索：本节内容根据原书中关于"Interval estimation"的相关章节(Ch 7.5)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：区间估计策略选择使得"均值+不确定性bonus"最大的动作，bonus由估计的标准差决定，是一个直觉且可调的探索策略。

**直觉类比**：你有几个餐厅可选。你知道A餐厅平均4.5分（但只去过2次），B餐厅平均4.2分（去过20次）。区间估计策略不只看平均分，还考虑"不确定度"——因为A的不确定性大，策略可能选择A来获取更多信息。

**历史背景**：区间估计策略属于UCB策略族的一种变体，由Kaelbling (1993)在RL中推广。与经典UCB相比，它的bonus基于标准差而非计数。

**算法定位**：探索-利用策略。在Bandit问题和RL中广泛使用。

**前置知识**：
- 多臂赌博机问题
- UCB策略
- 标准差和置信区间

## 2. 核心原理

**核心思想**：对每个动作 $x$，维护均值估计 $\bar{\mu}_x^n$ 和标准差 $\bar{\sigma}_x^n$。

策略选择：
$$x^{IE} = \arg\max_x \left(\bar{\mu}_x^n + \theta^{IE} \cdot \bar{\sigma}_x^n\right)$$

其中 $\theta^{IE}$ 是可调参数，控制探索程度。

**参数 $\theta^{IE}$ 的作用**：
- $\theta^{IE} = 0$：纯利用（greedy），只选当前最优
- $\theta^{IE}$ 小（如1-2）：轻度探索
- $\theta^{IE}$ 大（如3-5）：激进探索
- 经验上 $\theta^{IE} \in [1, 3]$ 通常效果较好

**与UCB的对比**：
- UCB：bonus为 $\sqrt{\ln n / N_x}$（基于计数）
- IE：bonus为 $\theta^{IE} \cdot \bar{\sigma}_x^n$（基于估计方差）
- IE的参数范围更窄，调参相对容易

**更新规则**：
- 均值：$\bar{\mu}_x^{n+1} = \bar{\mu}_x^n + \frac{1}{N_x^n + 1}(y^{n+1} - \bar{\mu}_x^n)$
- 标准差：$\bar{\sigma}_x^{n+1}$ 可用Welford算法在线更新

## 3. Python 实现

```python
import numpy as np

class IntervalEstimation:
    """区间估计策略"""
    def __init__(self, n_arms, theta_ie=2.0):
        self.n_arms = n_arms
        self.theta_ie = theta_ie
        self.counts = np.zeros(n_arms)
        self.means = np.zeros(n_arms)
        self.M2 = np.zeros(n_arms)  # Welford's M2

    def select(self):
        """选择动作"""
        # 未探索过的动作优先
        unexplored = np.where(self.counts == 0)[0]
        if len(unexplored) > 0:
            return unexplored[0]

        # 计算IE index
        stds = np.sqrt(self.M2 / np.maximum(self.counts - 1, 1))
        indices = self.means + self.theta_ie * stds
        return np.argmax(indices)

    def update(self, arm, reward):
        """更新统计量（Welford算法）"""
        self.counts[arm] += 1
        n = self.counts[arm]
        delta = reward - self.means[arm]
        self.means[arm] += delta / n
        delta2 = reward - self.means[arm]
        self.M2[arm] += delta * delta2

# 演示
np.random.seed(42)
true_means = [3.0, 4.0, 2.5, 4.5, 3.5]
ie = IntervalEstimation(len(true_means), theta_ie=2.0)

for t in range(200):
    arm = ie.select()
    reward = true_means[arm] + np.random.randn() * 0.5
    ie.update(arm, reward)

print("真实均值:", true_means)
print("估计均值:", np.round(ie.means, 2))
print("选择次数:", ie.counts.astype(int))
```

## 4. 与其他方法的关系

| 方法 | 关系 |
|---|---|
| UCB | IE是UCB的一种变体 |
| Thompson采样 | 用概率分布而非点估计+bonus |
| epsilon-greedy | 更粗糙的探索策略 |
| 知识梯度 | 更理论化的探索策略 |
