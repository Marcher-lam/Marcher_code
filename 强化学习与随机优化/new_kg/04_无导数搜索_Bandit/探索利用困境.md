## 1-3. 核心认知与公式

**一句话定义**：探索-利用困境是序列决策中最根本的权衡——利用当前最佳选项，还是探索可能更好的未知选项。

**形式化**：$T$步内最大化累积奖励：

$$\max \sum_{t=1}^T r_t$$

- 利用（Exploitation）：选当前估计最优的动作，短期收益高
- 探索（Exploration）：试新动作，长期可能发现更好选项

**遗憾度量**：

$$\text{Regret} = T\mu^* - \sum_{t=1}^T \mu_{a_t}$$

目标是最小化累积遗憾。

**原书中的体现**：
- Ch 7赌博机：直接面对探索-利用
- Ch 12策略设计：ε-greedy、Boltzmann、Thompson采样
- Ch 15-17 ADP/RL：探索策略影响值函数学习质量

## 4-8. 核心实现

```python
"""探索-利用：不同策略对比"""
import numpy as np

def compare_strategies(true_means, T=2000, n_runs=50):
    K = len(true_means)
    results = {}

    for name in ['epsilon-greedy', 'ucb', 'thompson']:
        regrets = np.zeros(T)
        for run in range(n_runs):
            counts = np.zeros(K)
            rewards = np.zeros(K)
            for t in range(T):
                if name == 'epsilon-greedy':
                    eps = max(0.01, 0.5 - t*0.0005)
                    if np.random.random() < eps:
                        k = np.random.randint(K)
                    else:
                        k = np.argmax(rewards / (counts + 1e-10))
                elif name == 'ucb':
                    if np.any(counts == 0):
                        k = np.argmin(counts)
                    else:
                        ucb = rewards/(counts) + 2*np.sqrt(np.log(t+1)/counts)
                        k = np.argmax(ucb)
                elif name == 'thompson':
                    samples = np.random.beta(counts+1, counts-rewards/(rewards/(counts+1e-10)+1e-10)+1)
                    # 简化：用正态近似
                    means = rewards / (counts + 1e-10)
                    stds = 1.0 / (counts + 1)
                    k = np.argmax(means + stds * np.random.randn(K))

                r = float(np.random.random() < true_means[k])
                counts[k] += 1
                rewards[k] += r
                regrets[t] += max(true_means) - true_means[k]

        results[name] = regrets / n_runs
    return results

if __name__ == "__main__":
    np.random.seed(42)
    means = [0.9, 0.7, 0.5, 0.3, 0.1]
    results = compare_strategies(means, T=1000)
    for name, reg in results.items():
        print(f"{name:15s}: 累积遗憾={reg.sum():.1f}")
```

## 9-14. 简要

### 12. 学习总结
探索-利用：$\min \text{Regret} = T\mu^* - \sum\mu_{a_t}$。ε-greedy简单、UCB理论优、Thompson实际好。是所有RL问题的核心挑战。

### 13. 练习题
**Q1**：为什么纯利用（ε=0）在实践中表现差？
**A1**：纯利用可能一开始偶然选到差动作的奖励就锁定在那，永远不尝试可能更好的选项。偶尔的探索帮助发现更优选择。
