# 响应曲面法(Response Surface Methods) 学习文档

> 用低阶多项式拟合仿真响应面，在拟合曲面上找最优。

> 来源线索：本节内容根据原书中关于"Response Surface Methods"的相关章节(Ch 7)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：响应曲面法(RSM)在仿真输入的邻域内拟合一个多项式元模型，在元模型上用解析方法寻优。

**二次模型**：

$$y = \beta_0 + \sum_j \beta_j x_j + \sum_j \beta_{jj} x_j^2 + \sum_{j<k}\beta_{jk}x_jx_k + \epsilon$$

**算法**：
1. 在当前点附近做实验设计（中心复合设计CCD）
2. 仿真获取响应值
3. 拟合一阶模型
4. 沿最速上升方向移动
5. 接近最优点时切换到二阶模型
6. 在二阶曲面上解析求解驻点

## 4-8. 核心实现

```python
"""响应曲面法"""
import numpy as np

def rsm_optimize(f, x0, lr=0.5, delta=0.1, max_iter=50):
    """响应曲面优化"""
    x = np.array(x0, dtype=float)
    for it in range(max_iter):
        p = len(x)
        # 用中心差分估计梯度
        grad = np.zeros(p)
        for j in range(p):
            x_plus = x.copy(); x_plus[j] += delta
            x_minus = x.copy(); x_minus[j] -= delta
            grad[j] = (f(x_plus) - f(x_minus)) / (2*delta)
        x = x + lr * grad  # 最速上升
        if np.linalg.norm(grad) < 1e-4: break
    return x

if __name__ == "__main__":
    np.random.seed(42)
    f = lambda x: -(x[0]-3)**2 - (x[1]-2)**2 + 10
    x_opt = rsm_optimize(f, [0.0, 0.0])
    print(f"RSM最优: x={x_opt.round(2)}, f={f(x_opt):.2f}")
    print(f"真实最优: x=[3,2], f=10")
```

## 9-14. 简要

### 12. 学习总结
RSM：局部多项式拟合+最速上升+二次模型精确寻优。仿真优化的经典元模型方法。

### 13. 练习题
**Q1**：RSM和高斯过程贝叶斯优化的区别？
**A1**：RSM用低阶多项式（简单但表达能力有限），GP用核方法（灵活但计算$O(n^3)$）。RSM适合低维，GP适合高维和小样本。
