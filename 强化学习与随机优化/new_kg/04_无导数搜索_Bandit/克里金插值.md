## 1-3. 核心认知与公式

**一句话定义**：克里金插值是高斯过程回归在空间统计中的名称，提供点的预测值和预测不确定性。

**与高斯过程回归的关系**：克里金=GP回归。原书Ch 7.7中在仿真优化背景下讨论，Ch 3.4.3中在贝叶斯更新背景下讨论。

**预测公式**：

$$\hat{y}(x^*) = k(x^*)^T(K + \sigma^2I)^{-1}y$$

**预测方差**：

$$\sigma^2(x^*) = k(x^*,x^*) - k(x^*)^T(K+\sigma^2I)^{-1}k(x^*)$$

其中$K_{ij} = k(x_i, x_j)$是核矩阵。

**在仿真优化中的应用**：
- 用克里金拟合仿真响应面
- 选择不确定性最大或期望改进最大的点做下一次仿真
- 这是贝叶斯优化的核心思想

## 4-8. 核心实现

```python
"""克里金插值（简化版）"""
import numpy as np

class SimpleKriging:
    def __init__(self, sigma=1.0, length_scale=1.0, noise=0.01):
        self.sigma = sigma
        self.l = length_scale
        self.noise = noise
        self.X_train = None
        self.y_train = None

    def _kernel(self, X1, X2):
        dists = np.abs(X1.reshape(-1,1) - X2.reshape(1,-1))
        return self.sigma**2 * np.exp(-0.5 * (dists/self.l)**2)

    def fit(self, X, y):
        self.X_train = np.array(X)
        self.y_train = np.array(y)
        K = self._kernel(X, X) + self.noise * np.eye(len(X))
        self.K_inv = np.linalg.inv(K)

    def predict(self, X_new):
        k_star = self._kernel(X_new, self.X_train)
        y_pred = k_star @ self.K_inv @ self.y_train
        k_ss = self._kernel(X_new, X_new).diagonal()
        var = k_ss - (k_star @ self.K_inv @ k_star.T).diagonal()
        return y_pred, np.sqrt(np.maximum(var, 0))

if __name__ == "__main__":
    np.random.seed(42)
    X = np.linspace(0, 10, 10)
    y = np.sin(X) + 0.1*np.random.randn(10)
    kr = SimpleKriging(sigma=1.0, length_scale=1.5)
    kr.fit(X, y)
    X_test = np.linspace(0, 10, 50)
    y_pred, y_std = kr.predict(X_test)
    print(f"预测值范围: [{y_pred.min():.2f}, {y_pred.max():.2f}]")
    print(f"不确定性范围: [{y_std.min():.3f}, {y_std.max():.3f}]")
```

## 9-14. 简要

### 12. 学习总结
克里金=GP回归。预测$\hat{y}=k^TK^{-1}y$，方差$\sigma^2=k_{**}-k^TK^{-1}k$。仿真优化中的核心元模型。

### 13. 练习题
**Q1**：长度尺度$l$如何影响预测？
**A1**：$l$大→长程相关→预测平滑但可能欠拟合。$l$小→短程相关→拟合好但可能过拟合。通常用MLE优化$l$。
