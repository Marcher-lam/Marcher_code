# 主动学习(Active Learning) 学习文档

> 学习者主动选择最有信息量的样本标注，而非被动接受随机数据。

> 来源线索：本节内容根据原书中关于"Active Learning"的相关章节(Ch 2.1.11)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：主动学习让算法选择哪些数据需要标注，用最少的标注预算获得最大的学习效果。

**与被动学习的区别**：
- 被动：随机采样训练数据
- 主动：选择"最不确定"或"最有信息量"的样本

**采样策略**：
1. **不确定性采样**：选模型最不确定的样本
2. **期望模型变化**：选最能改变模型的样本
3. **期望误差减少**：选最能降低泛化误差的样本
4. **委员会查询(QBC)**：多个模型不一致时采样

**与赌博机的联系**：主动学习≈纯探索赌博机——目标不是最大化奖励，而是最小化模型不确定性。

## 4-8. 核心实现

```python
"""主动学习：不确定性采样"""
import numpy as np

class ActiveLearner:
    def __init__(self, n_classes=2):
        self.labeled_X = []
        self.labeled_y = []
        self.n_classes = n_classes

    def entropy(self, probs):
        """计算熵"""
        return -np.sum(probs * np.log(probs + 1e-10))

    def query(self, unlabeled_X, model_predict_fn, n_query=1):
        """选择最不确定的n_query个样本"""
        uncertainties = []
        for x in unlabeled_X:
            probs = model_predict_fn(x)
            uncertainties.append(self.entropy(probs))
        idx = np.argsort(uncertainties)[-n_query:]
        return idx

    def add_labeled(self, X, y):
        self.labeled_X.extend(X)
        self.labeled_y.extend(y)

if __name__ == "__main__":
    np.random.seed(42)
    predict_fn = lambda x: np.array([0.5, 0.5]) if abs(x[0]) < 0.3 else \
                            (np.array([0.9, 0.1]) if x[0] > 0 else np.array([0.1, 0.9]))
    learner = ActiveLearner()
    unlabeled = np.random.randn(100, 2)
    query_idx = learner.query(unlabeled, predict_fn, n_query=5)
    print(f"最不确定的5个样本索引: {query_idx}")
    print(f"对应x[0]值: {unlabeled[query_idx, 0].round(2)}")
```

## 9-14. 简要

### 12. 学习总结
主动学习：选择最不确定的样本标注。与赌博机的纯探索对应。减少标注成本，提高样本效率。

### 13. 练习题
**Q1**：主动学习和赌博机探索的核心区别？
**A1**：赌博机在探索和利用间权衡（需要累积奖励），主动学习是纯探索（只关心学习效率）。
