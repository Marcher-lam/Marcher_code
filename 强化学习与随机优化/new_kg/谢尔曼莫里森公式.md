# 谢尔曼-莫里森公式(Sherman-Morrison Formula) 学习文档

> 高效更新矩阵逆的一阶修正公式，是递归最小二乘的数学基础。

> 来源线索：本节内容根据原书中关于"Sherman-Morrison Formula"的相关章节(Ch 3.14.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：Sherman-Morrison公式给出$(A + uv^T)^{-1}$的显式表达式，避免对修改后的矩阵重新求逆。

**直觉类比**：你算好了一个1000×1000矩阵的逆。现在矩阵有一行发生变化。重新求逆要$O(n^3)$次运算。Sherman-Morrison告诉你只需$O(n^2)$——用旧逆和一个简单公式就能得到新逆。

**历史背景**：Sherman & Morrison (1949, 1950)提出。Woodbury公式是其矩阵推广。在递归最小二乘、Kalman滤波、在线学习中是核心数学工具。

**算法定位**：数学工具/矩阵恒等式。

**前置知识**：线性代数、矩阵求逆。

## 2. 核心原理

**Sherman-Morrison公式**：

$$(A + uv^T)^{-1} = A^{-1} - \frac{A^{-1}uv^TA^{-1}}{1 + v^TA^{-1}u}$$

**条件**：$A$可逆且$1 + v^TA^{-1}u \neq 0$。

**核心价值**：如果已知$A^{-1}$，只需$O(n^2)$计算$(A+uv^T)^{-1}$，而非$O(n^3)$重新求逆。

## 3. 数学公式与推导

### 推导

设$B = A + uv^T$，猜测$B^{-1} = A^{-1} + \beta A^{-1}uv^TA^{-1}$。

由$BB^{-1} = I$：

$$(A + uv^T)(A^{-1} + \beta A^{-1}uv^TA^{-1}) = I$$

展开：$I + \beta uv^TA^{-1} + uv^TA^{-1} + \beta uv^TA^{-1}uv^TA^{-1} = I$

化简：$uv^TA^{-1}(1 + \beta(1 + v^TA^{-1}u)) = 0$

令$1 + \beta(1 + v^TA^{-1}u) = 0$，解得$\beta = -\frac{1}{1 + v^TA^{-1}u}$。

### Woodbury推广

$$(A + UCV)^{-1} = A^{-1} - A^{-1}U(C^{-1} + VA^{-1}U)^{-1}VA^{-1}$$

### 在RLS中的应用

$(X^TX)^{-1}$的更新：$M^{n+1} = (M^{n,-1} + x^{n+1}(x^{n+1})^T)^{-1}$

直接应用SM公式：

$$M^{n+1} = M^n - \frac{M^n x^{n+1}(x^{n+1})^T M^n}{1 + (x^{n+1})^T M^n x^{n+1}}$$

## 4-8. 核心实现

```python
"""Sherman-Morrison公式验证与应用"""
import numpy as np

def sherman_morrison_update(A_inv, u, v):
    """Sherman-Morrison矩阵逆更新"""
    Au = A_inv @ u
    vA = v @ A_inv
    denom = 1.0 + v @ Au
    return A_inv - np.outer(Au, vA) / denom

if __name__ == "__main__":
    np.random.seed(42)
    n = 5
    A = np.random.randn(n, n)
    A = A.T @ A + np.eye(n)  # 确保正定
    A_inv = np.linalg.inv(A)
    u = np.random.randn(n)
    v = np.random.randn(n)

    # 直接求逆
    B = A + np.outer(u, v)
    B_inv_direct = np.linalg.inv(B)

    # SM公式
    B_inv_sm = sherman_morrison_update(A_inv, u, v)

    # 验证
    error = np.max(np.abs(B_inv_direct - B_inv_sm))
    print(f"直接求逆 vs SM公式 最大误差: {error:.2e}")

    # RLS应用：演示在线更新
    p = 3
    M = np.eye(p) * 100.0  # 初始精度矩阵
    for i in range(10):
        x = np.random.randn(p)
        M_new = sherman_morrison_update(M, x, x)
        M_direct = np.linalg.inv(np.linalg.inv(M) + np.outer(x, x))
        assert np.max(np.abs(M_new - M_direct)) < 1e-10
        M = M_new
    print(f"RLS更新10次后精度矩阵条件数: {np.linalg.cond(M):.2f}")
```

## 9-14. 简要

### 12. 学习总结
SM公式：$(A+uv^T)^{-1} = A^{-1} - \frac{A^{-1}uv^TA^{-1}}{1+v^TA^{-1}u}$。将$O(n^3)$求逆降为$O(n^2)$，是RLS和Kalman滤波的数学基石。

### 13. 练习题
**Q1**：如果$1+v^TA^{-1}u=0$会怎样？
**A1**：SM公式不适用（分母为0），意味着$A+uv^T$不可逆。此时$uv^T$的秩1修正恰好使矩阵奇异。
