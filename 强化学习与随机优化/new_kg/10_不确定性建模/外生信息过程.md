# 外生信息过程(Exogenous Information Process) 学习文档

> 不受决策影响的外部信息流——正确建模外生信息是随机优化的核心。

> 来源线索：本节内容根据原书中关于"The Exogenous Information Process"的相关章节(Ch 9.6)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：外生信息 $W_{t+1}$ 是在时刻t做决策后到达的不受决策影响的信息（如需求、价格、天气）。

## 2. 核心原理

**基本记号**：
$$W_{t+1} = \text{在时刻t+1观测到的外生信息}$$

**信息过程的类型**：

| 类型 | 描述 | 示例 |
|---|---|---|
| 状态无关 | $W_t$ 独立于 $(S_t, x_t)$ | 独立同分布需求 |
| 状态相关 | $W_t$ 依赖于 $S_t$ | 价格依赖库存 |
| 决策相关 | $W_t$ 依赖于 $x_t$ | 测量精度依赖实验选择 |
| 滞后过程 | $W_t$ 依赖于过去多个时期 | 时间序列（ARMA） |
| 监督过程 | 由更高层决策决定 | 政策变化、管理指令 |

**建模方法**：
- 独立同分布：最简单，$W_t \sim F(w)$
- 时间序列：$W_t = f(W_{t-1}, ..., W_{t-k}) + \epsilon$
- 体制转换：$W_t \sim F_k(w)$ 取决于当前体制 $k$
- 跳跃扩散：连续+跳跃（如价格突变）

## 3. Python 实现

```python
import numpy as np

class ExogenousInfoProcess:
    """外生信息过程示例"""
    def __init__(self, process_type='iid'):
        self.process_type = process_type
        self.history = []

    def generate(self, state=None):
        if self.process_type == 'iid':
            w = {'demand': max(0, np.random.normal(10, 3))}

        elif self.process_type == 'autoregressive':
            if len(self.history) < 1:
                price = 100
            else:
                price = 0.7 * self.history[-1]['price'] + 30 + np.random.randn() * 2
            w = {'price': max(0, price)}

        elif self.process_type == 'regime':
            regime = np.random.choice(['normal', 'high'], p=[0.8, 0.2])
            demand = np.random.normal(10 if regime == 'normal' else 20, 2)
            w = {'demand': max(0, demand), 'regime': regime}

        self.history.append(w)
        return w

# 演示
for ptype in ['iid', 'autoregressive', 'regime']:
    proc = ExogenousInfoProcess(ptype)
    samples = [proc.generate() for _ in range(5)]
    print(f"\n{ptype}: {samples}")
```

## 4. 与其他方法的关系

- **蒙特卡洛仿真**：从外生信息过程中采样
- **时间序列模型**：ARMA/ARIMA建模滞后过程
- **跳跃扩散模型**：金融中的复杂外生过程
