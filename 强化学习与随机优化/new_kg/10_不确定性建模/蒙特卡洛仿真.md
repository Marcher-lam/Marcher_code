# 蒙特卡洛仿真(Monte Carlo Simulation) 学习文档

> 通过随机采样估计复杂系统的统计性质，是处理高维积分和不确定性的万能计算工具。

> 来源线索：本节内容根据原书中关于"Monte Carlo Simulation"的相关章节(Ch 10.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：蒙特卡洛仿真通过大量随机采样来估计概率分布的期望值、分位数等统计量，是处理高维积分和复杂随机系统的通用方法。

**直觉类比**：估算圆周率π。在正方形内随机撒豆子，统计落在内切圆内的比例。撒的豆子越多，比例越接近π/4。这就是蒙特卡洛——用随机采样代替精确计算，样本越多结果越准。

**历史背景**：蒙特卡洛方法由冯·诺依曼和乌拉姆在1940年代Los Alamos实验室系统发展，名称来自摩纳哥的赌城。核物理中的中子扩散问题催生了这套方法。后续在金融工程、运筹学、机器学习中广泛使用。

**算法定位**：随机建模/计算方法。不是单一算法，而是一类基于随机采样的计算范式。

**前置知识**：概率统计、均匀分布、正态分布、Python基础。

## 2. 核心原理

**核心思想**：当解析计算期望 $E[f(X)] = \int f(x)p(x)dx$ 不可行时，通过从分布$p(x)$中采样$X^1, X^2, \ldots, X^N$，用样本均值近似：

$$E[f(X)] \approx \frac{1}{N}\sum_{n=1}^N f(X^n)$$

**工作流程**：
1. 确定目标量（期望、概率、分位数等）
2. 建立随机变量的概率模型
3. 从已知分布中生成随机样本
4. 对每个样本计算目标函数值
5. 汇总统计量（均值、方差、置信区间）

**关键概念**：
- **逆累积分布法（Inverse CDF）**：若$U \sim \text{Uniform}(0,1)$，则$X = F_X^{-1}(U)$服从分布$f_X(x)$
- **蒙特卡洛样本**：从分布中生成的一组独立随机变量序列$W^1, \ldots, W^N$
- **方差缩减**：通过重要性采样、对偶变量等技巧减少估计方差

## 3. 数学公式与推导

### 逆累积分布法

给定CDF $F_X(x)$和其逆$F_X^{-1}(u)$，令$U \sim \text{Uniform}(0,1)$：

$$X = F_X^{-1}(U) \sim f_X(x)$$

**证明**：$\mathbb{P}(X \leq x) = \mathbb{P}(F_X^{-1}(U) \leq x) = \mathbb{P}(U \leq F_X(x)) = F_X(x)$

### 指数分布采样

CDF: $F(x) = 1 - e^{-\lambda x}$，逆CDF: $F^{-1}(u) = -\frac{1}{\lambda}\ln(1-u)$

$$X = -\frac{1}{\lambda}\ln(U)$$

（因为$1-U$也是Uniform(0,1)，可直接用$U$）

### 相关正态向量生成

给定均值向量$\mu$和协方差矩阵$\Sigma$，通过Cholesky分解$\Sigma = CC^T$：

$$X = \mu + CZ$$

其中$Z$是独立标准正态向量。

### 蒙特卡洛估计误差

样本均值$\bar{X}_N = \frac{1}{N}\sum_{n=1}^N X^n$的标准误差：

$$SE = \frac{\sigma}{\sqrt{N}}$$

95%置信区间：$\bar{X}_N \pm 1.96 \cdot \frac{s}{\sqrt{N}}$

收敛速度为$O(1/\sqrt{N})$，与维度无关。

## 4. 训练过程讲解

蒙特卡洛仿真不是传统意义上的"训练"，但有其工作流程：

**数据准备**：
- 确定随机变量的分布类型和参数
- 选择随机数生成器种子（可重复性）

**采样过程**：
- 从Uniform(0,1)出发（线性同余生成器：$R^{n+1} = (a + bR^n) \bmod m$）
- 通过逆CDF或其他变换生成目标分布样本
- 每次迭代生成一个样本并计算函数值

**收敛判断**：
- 固定样本数N（如10000次）
- 或监控置信区间宽度：$\text{CI宽度} < \epsilon$时停止

**超参数表**：

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| N | 采样次数 | 1000-100000 |
| seed | 随机种子 | 固定值（可复现） |
| 置信水平 | 统计精度 | 95% |

## 5. 应用场景

1. **高维积分估计**：金融期权定价（Black-Scholes模型的高维扩展），解析解不存在时用MC
2. **随机规划**：原书Ch 19.9中，两阶段随机规划用MC生成情景树
3. **强化学习策略评估**：原书Ch 9.12和Ch 16.1中，用MC估计策略的价值函数
4. **系统仿真优化**：制造系统、物流网络、通信网络的性能评估
5. **参数估计**：贝叶斯后验分布的采样估计（MCMC的基础）

## 6. 优缺点分析

**优点**：
- 维度无关性：收敛速度$O(1/\sqrt{N})$不受问题维度影响
- 通用性强：只要能采样就能估计
- 实现简单：核心逻辑只需几行代码
- 可并行化：各样本独立，天然适合并行

**缺点**：
- 收敛慢：每增加一位精度需要100倍样本
- 方差大：需要方差缩减技术
- 只能给出近似解，不如解析解精确
- 依赖分布假设的准确性

**与其他方法对比**：

| 特性 | 蒙特卡洛 | 数值积分 | 确定性采样 |
|------|---------|---------|-----------|
| 维度扩展性 | 优 | 差 | 中 |
| 实现难度 | 低 | 中 | 高 |
| 收敛速度 | $O(1/\sqrt{N})$ | 指数级（低维） | $O(1/N)$ |
| 适用范围 | 广 | 窄 | 中 |

## 7-8. 核心实现

```python
"""蒙特卡洛仿真：从基础采样到积分估计"""
import numpy as np
from scipy import stats

class MonteCarloSimulator:
    """蒙特卡洛仿真器"""
    def __init__(self, seed=42):
        self.rng = np.random.RandomState(seed)

    def estimate_pi(self, n_samples=100000):
        """用蒙特卡洛估计π"""
        # 在[-1,1]×[-1,1]正方形内随机撒点
        x = self.rng.uniform(-1, 1, n_samples)
        y = self.rng.uniform(-1, 1, n_samples)
        # 落在单位圆内的比例 × 4 = π
        inside = x**2 + y**2 <= 1
        pi_estimate = 4 * np.mean(inside)
        pi_se = 4 * np.std(inside) / np.sqrt(n_samples)
        return pi_estimate, pi_se

    def estimate_expectation(self, func, sampler, n_samples=10000):
        """通用期望估计：E[f(X)]"""
        samples = np.array([sampler() for _ in range(n_samples)])
        values = np.array([func(x) for x in samples])
        mean = np.mean(values)
        se = np.std(values) / np.sqrt(n_samples)
        ci_low = mean - 1.96 * se
        ci_high = mean + 1.96 * se
        return mean, se, (ci_low, ci_high)

    def sample_exponential(self, lam, size=1):
        """逆CDF法采样指数分布"""
        u = self.rng.uniform(0, 1, size)
        return -np.log(u) / lam

    def sample_correlated_normal(self, mu, Sigma, size=1):
        """Cholesky分解采样相关正态向量"""
        C = np.linalg.cholesky(Sigma)
        z = self.rng.randn(len(mu), size)
        return mu.reshape(-1, 1) + C @ z

if __name__ == "__main__":
    mc = MonteCarloSimulator(seed=42)

    # 1. 估计π
    pi_est, pi_se = mc.estimate_pi(100000)
    print(f"π估计: {pi_est:.4f} ± {pi_se:.4f} (真实值: {np.pi:.4f})")

    # 2. 估计指数分布均值
    lam = 2.0
    mean, se, ci = mc.estimate_expectation(
        func=lambda x: x**2,
        sampler=lambda: mc.sample_exponential(lam)[0],
        n_samples=50000
    )
    true_val = 2 / lam**2  # E[X^2] for Exp(λ) = 2/λ^2
    print(f"E[X^2]估计: {mean:.4f} ± {se:.4f} (真实值: {true_val:.4f})")
    print(f"95%置信区间: [{ci[0]:.4f}, {ci[1]:.4f}]")

    # 3. 相关正态向量采样
    mu = np.array([10, 3, 7])
    Sigma = np.array([[9, 3.31, 0.1648],
                      [3.31, 9, 3.3109],
                      [0.1648, 3.3109, 9]])
    samples = mc.sample_correlated_normal(mu, Sigma, size=10000)
    print(f"\n相关正态采样统计:")
    print(f"样本均值: {samples.mean(axis=1).round(2)}")
    print(f"真实均值: {mu}")
```

## 10. 模型评估

蒙特卡洛估计的质量由以下指标衡量：

- **标准误差(SE)**：$SE = s/\sqrt{N}$，反映估计精度
- **置信区间(CI)**：95% CI为$\bar{X} \pm 1.96 \cdot SE$
- **相对误差**：$RE = SE / |\bar{X}|$，通常要求$RE < 0.01$

```python
def mc_quality_report(estimates, true_value=None):
    """蒙特卡洛估计质量报告"""
    mean = np.mean(estimates)
    se = np.std(estimates) / np.sqrt(len(estimates))
    ci = (mean - 1.96*se, mean + 1.96*se)
    re = se / abs(mean) if mean != 0 else float('inf')

    print(f"均值: {mean:.6f}")
    print(f"标准误差: {se:.6f}")
    print(f"95%置信区间: [{ci[0]:.6f}, {ci[1]:.6f}]")
    print(f"相对误差: {re:.4%}")
    if true_value is not None:
        print(f"偏差: {mean - true_value:.6f}")
        print(f"覆盖真值: {'是' if ci[0] <= true_value <= ci[1] else '否'}")
```

## 11. 常见问题与易错点

1. **随机种子未固定**：结果不可复现。设`np.random.seed()`确保可复现性。
2. **样本数不足**：高维问题需要更多样本。用置信区间宽度判断是否足够。
3. **忽略了分布假设**：MC结果依赖于正确的分布建模。分布选错会导致系统性偏差。
4. **混淆伪随机和真随机**：计算机生成的是伪随机数（线性同余），统计性质良好但不适合密码学。

## 12. 学习总结

蒙特卡洛仿真的核心：用$\frac{1}{N}\sum f(X^n)$近似$E[f(X)]$，收敛速度$O(1/\sqrt{N})$与维度无关。关键工具是逆CDF采样：$X = F^{-1}(U)$。在原书中是处理不确定性的基础工具，支撑后续的随机规划、ADP和RL策略评估。

## 13. 练习题

**Q1**：用蒙特卡洛估计$\int_0^1 e^x dx$，给出N=10000的结果和95%置信区间。
**A1**：$E[e^U] = \int_0^1 e^x dx = e - 1 \approx 1.7183$。采样$U_1, \ldots, U_N \sim \text{Uniform}(0,1)$，计算$\bar{Y} = \frac{1}{N}\sum e^{U_n}$。N=10000时SE约$\sigma/\sqrt{10000}$，$\sigma^2 = E[e^{2U}] - (E[e^U])^2 = (e^2-1)/2 - (e-1)^2 \approx 0.242$，SE$\approx 0.0049$。

**Q2**：为什么蒙特卡洛在高维问题中优于网格方法？
**A2**：网格方法在d维需要$N^d$个点，MC只需N个样本（与维度无关）。100维问题，网格法用每维10个点就需$10^{100}$个，而MC的$O(1/\sqrt{N})$收敛不受维度影响。
