# 转移函数(Transition Function) 学习文档

> 描述系统如何从一个状态转移到下一个状态——连接决策、信息和状态的桥梁。

> 来源线索：本节内容根据原书中关于"The Transition Function"的相关章节(Ch 9.5)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：转移函数 $S^M(S_t, x_t, W_{t+1})$ 描述系统在状态 $S_t$ 下执行决策 $x_t$ 并接收外生信息 $W_{t+1}$ 后如何转移到新状态 $S_{t+1}$。

## 2. 核心原理

**一般形式**：
$$S_{t+1} = S^M(S_t, x_t, W_{t+1})$$

转移函数在不同领域有不同名称：
- **RL/MDP**：状态转移概率 $P(s'|s,a)$
- **最优控制**：系统动态方程 $\dot{x} = f(x, u)$
- **仿真**：仿真模型/模拟器

**确定性转移**：$W_{t+1} = 0$（无随机性）
**随机转移**：$W_{t+1}$ 是随机变量

**转移函数的组成**：
1. 物理状态更新：$R_{t+1} = R^M(R_t, x_t, W_{t+1})$
2. 信息状态更新：$I_{t+1}$ 根据新到达的信息
3. 信念状态更新：$B_{t+1} = B^M(B_t, x_t, W_{t+1})$（Bayes更新）

## 3. Python 实现

```python
import numpy as np

class InventoryTransition:
    """库存系统的转移函数"""
    def transition(self, state, action, info):
        """S_{t+1} = S^M(S_t, x_t, W_{t+1})"""
        new_state = {}

        # 物理状态转移
        new_state['inventory'] = state['inventory'] + action['order'] - info['demand']
        new_state['inventory'] = max(0, new_state['inventory'])

        # 信息状态转移
        new_state['price'] = info.get('new_price', state['price'])
        new_state['time'] = state['time'] + 1

        # 信念状态转移（Bayes更新）
        old_mean = state['demand_mean']
        n = state['obs_count']
        new_state['demand_mean'] = (n * old_mean + info['demand']) / (n + 1)
        new_state['obs_count'] = n + 1

        return new_state

trans = InventoryTransition()
s0 = {'inventory': 50, 'price': 10, 'time': 0, 'demand_mean': 8.0, 'obs_count': 10}
action = {'order': 20}
info = {'demand': 12, 'new_price': 11}
s1 = trans.transition(s0, action, info)
print(f"转移后状态: {s1}")
```

## 4. 与其他方法的关系

- **MDP转移概率**：转移函数的离散化
- **系统动态方程**：连续版本的转移函数
- **Bayes更新**：信念状态的转移函数
