# 平坦与因式状态表示(Flat vs Factored State) 学习文档

> 展平为向量 vs 利用结构——因式表示在高维问题中不可或缺。

> 来源线索：本节内容根据原书中关于"Flat vs Factored State Representations"的相关章节(Ch 9.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：平坦表示将所有状态信息展平为一个向量；因式表示利用状态变量之间的结构（如图模型）降低维度。

## 2. 核心原理

**平坦表示**：
$$S_t = (s_1, s_2, ..., s_n) \in \mathbb{R}^n$$
- 简单直接
- 忽略变量间的关系
- 维度灾难：$n$ 个二值变量的状态数为 $2^n$

**因式表示**：
利用变量的条件独立性分解联合分布：
$$P(S) = \prod_i P(s_i | Pa(s_i))$$

其中 $Pa(s_i)$ 是 $s_i$ 的父变量（贝叶斯网络）。

**因式表示的优势**：
- 参数数量：从 $O(2^n)$ 降到 $O(n \cdot 2^k)$（$k$ 是最大父节点数）
- 可解释性：变量间的关系显式表达
- 泛化：相似状态可以共享信息

**在RL中的应用**：
- 因式MDP：转移函数利用因式结构
- 树结构/图模型：表示策略或值函数

## 3. Python 实现

```python
import numpy as np

def flat_vs_factored_demo():
    """平坦vs因式表示的参数量对比"""
    n_vars = 20  # 20个二值变量
    max_parents = 3

    # 平坦表示
    flat_params = 2 ** n_vars
    print(f"平坦表示参数量: {flat_params:,}")

    # 因式表示（每个变量最多3个父节点）
    factored_params = n_vars * (2 ** max_parents) * 2
    print(f"因式表示参数量: {factored_params:,}")
    print(f"压缩比: {flat_params / factored_params:.0f}x")

flat_vs_factored_demo()
```

## 4. 与其他方法的关系

- **贝叶斯网络**：因式表示的概率图模型基础
- **决策树**：因式策略的一种表示
- **层次聚合**：利用因式结构降低状态维度
