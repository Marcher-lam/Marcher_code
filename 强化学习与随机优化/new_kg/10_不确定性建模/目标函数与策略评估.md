# 目标函数与策略评估(Objective Function / Policy Evaluation) 学习文档

> 序贯决策的两个核心组件——如何定义目标和如何评估策略性能。

> 来源线索：Ch 9.7-9.8

## 1. 基础认知

**一句话定义**：目标函数定义什么是"最优"；策略评估衡量一个策略有多好。

## 2. 核心原理

**目标函数**：
- 累积奖励：$\max_\pi E[\sum_{t=0}^{T} \gamma^t C(S_t, X_t^\pi)]$
- 最终奖励：$\max_\pi E[C(S_T^\pi)]$
- 风险调整：$\max_\pi CVaR_\alpha[\sum_t C_t^\pi]$

**策略评估**：
- 直接模拟：运行策略多次取平均
- TD学习：在线估计值函数
- LSTD：用最小二乘法估计值函数参数

**关键权衡**：
- 在基模型中评估（精确但慢）vs 在前瞻模型中评估（近似但快）
- 在线评估 vs 离线评估

## 3. Python 实现

```python
import numpy as np

def policy_evaluation(policy, env_fn, n_episodes=500, gamma=0.9):
    """蒙特卡洛策略评估"""
    returns = []
    for _ in range(n_episodes):
        state = env_fn()
        G = 0; done = False; t = 0
        while not done and t < 50:
            action = policy(state)
            reward = -abs(action - 8) * 0.5
            G += gamma**t * reward
            state = state + action - np.random.poisson(3)
            state = max(0, state)
            t += 1
        returns.append(G)
    return np.mean(returns), np.std(returns)

np.random.seed(42)
policy = lambda s: max(0, 8 - s)
mean, std = policy_evaluation(policy, lambda: 20)
print(f"策略期望值: {mean:.2f} ± {std:.2f}")
```
