# 基模型与前瞻模型(Base vs Lookahead Models) 学习文档

> 真实世界(基模型) vs 简化近似(前瞻模型)——前瞻策略的核心权衡。

> 来源线索：本节内容根据原书中关于"Base Models and Lookahead Models"的相关章节(Ch 9.10)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：基模型是真实世界的完整表示；前瞻模型是为了在合理时间内做决策而简化的近似模型。

## 2. 核心原理

**基模型(Base Model)**：
- 完整描述真实系统的所有细节
- 可能非常复杂（高维、非线性、随机）
- 用于策略评估

**前瞻模型(Lookahead Model)**：
- 基模型的简化版本
- 用于前瞻策略的在线计算
- 必须在决策时限内求解

**近似策略**：

| 策略 | 近似方式 |
|---|---|
| 结果聚合/采样 | 减少场景数 |
| 阶段聚合 | 减少前瞻步数 |
| 策略近似 | 用简单策略替代部分决策 |
| 目标修正 | 修改目标函数补偿误差 |

## 3. Python 实现

```python
import numpy as np

class BaseModel:
    """完整基模型"""
    def simulate(self, policy, T=100):
        state = {'inv': 50, 'price': 10}
        total_reward = 0
        for t in range(T):
            action = policy(state)
            demand = max(0, np.random.normal(10, 3))
            state['inv'] = max(0, state['inv'] + action - demand)
            state['price'] = 0.8 * state['price'] + 2 + np.random.randn()
            total_reward += state['price'] * min(demand, state['inv'])
        return total_reward / T

class LookaheadModel:
    """简化前瞻模型"""
    def decide(self, state, H=3):
        best_action = 0
        best_value = -np.inf
        for action in range(0, 30):
            value = 0
            inv = state['inv'] + action
            for h in range(H):
                demand = 10  # 用期望值替代随机
                held = max(0, inv - demand)
                value += state['price'] * min(demand, inv) - held * 0.5
                inv = held
            if value > best_value:
                best_value = value
                best_action = action
        return best_action

# 对比
base = BaseModel()
lookahead = LookaheadModel()
policy = lambda s: lookahead.decide(s)
avg_reward = np.mean([base.simulate(policy) for _ in range(100)])
print(f"前瞻策略在基模型上的平均奖励: {avg_reward:.2f}")
```

## 4. 与其他方法的关系

- **模型预测控制**：滚动前瞻模型
- **SAA**：前瞻模型的采样近似
- **VFA**：替代前瞻的另一种近似
