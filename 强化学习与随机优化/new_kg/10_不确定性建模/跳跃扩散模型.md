# 跳跃扩散模型(Jump-Diffusion) 学习文档

> 在均值回归基础上加入随机跳跃项，捕捉价格的突变行为。

> 来源线索：本节内容根据原书中关于"Jump-Diffusion Models"的相关章节(Ch 10.5.2)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：跳跃扩散模型在均值回归噪声之外，以小概率$\rho^{jump}$添加大振幅跳跃，模拟电力价格等突发事件。

**模型**：

$$p_{t+1} = p_t + \kappa(\bar{\mu}_t - p_t) + \varepsilon_{t+1}^{base} + I_{t+1}^{jump}\varepsilon_{t+1}^{jump}$$

- $I^{jump} \sim \text{Bernoulli}(\rho^{jump})$：跳跃指示器
- $\varepsilon^{base} \sim N(0, \sigma_{base}^2)$：基础噪声
- $\varepsilon^{jump}$：跳跃噪声（大振幅）

**参数估计**：
1. 先拟合基础均值回归
2. 超过3σ残差的标记为跳跃
3. 用跳跃样本估计$\rho^{jump}$和$\varepsilon^{jump}$分布
4. 重新拟合基础模型（排除跳跃点）

## 4-8. 核心实现

```python
"""跳跃扩散模型"""
import numpy as np

class JumpDiffusion:
    def __init__(self, kappa=0.3, eta=0.05, sigma_base=1.0,
                 rho_jump=0.05, sigma_jump=10.0):
        self.kappa, self.eta = kappa, eta
        self.sigma_base = sigma_base
        self.rho_jump, self.sigma_jump = rho_jump, sigma_jump

    def simulate(self, p0, T):
        prices = [p0]
        mu = p0
        for t in range(T):
            mu = (1-self.eta)*mu + self.eta*prices[-1]
            base_noise = self.sigma_base * np.random.randn()
            jump = self.sigma_jump * np.random.randn() if np.random.random() < self.rho_jump else 0
            p = prices[-1] + self.kappa*(mu - prices[-1]) + base_noise + jump
            prices.append(p)
        return np.array(prices)

if __name__ == "__main__":
    np.random.seed(42)
    jd = JumpDiffusion(kappa=0.3, rho_jump=0.05, sigma_jump=15.0)
    prices = jd.simulate(50.0, 1000)
    jumps = np.abs(np.diff(prices)) > 3*jd.sigma_base
    print(f"模拟1000步: 均值={prices.mean():.1f}, 跳跃次数={jumps.sum()}")
    print(f"最大价格: {prices.max():.1f}, 最小价格: {prices.min():.1f}")
```

## 9-14. 简要

### 12. 学习总结
跳跃扩散：均值回归+基础噪声+概率跳跃。捕捉电力价格等重尾现象，Merton (1976)模型的基础。

### 13. 练习题
**Q1**：如何区分跳跃和大噪声？
**A1**：用3σ准则——基础噪声超过3σ的概率<0.3%，超出视为跳跃。实践中用迭代估计：先拟合基础→识别跳跃→重新拟合。
