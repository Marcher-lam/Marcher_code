# 相关性建模(Correlation Modeling) 学习文档

> 建模随机变量之间的相关性——忽略相关性可能导致次优决策。

> 来源线索：本节内容根据原书中关于"Modeling Correlations"的相关章节(Ch 10.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：相关性建模描述不同随机变量（如不同地点的需求、不同时期的价格）之间的统计依赖关系。

## 2. 核心原理

**相关性的类型**：
1. **空间相关**：不同地点的需求相关
2. **时间相关**：同一变量在不同时期相关（自相关）
3. **交叉相关**：不同变量之间的相关

**建模方法**：
- **协方差矩阵**：$\Sigma_{ij} = Cov(W_i, W_j)$
- **Copula方法**：分离边缘分布和相关性结构
- **因子模型**：$W = LF + \epsilon$（低维因子驱动）

**在决策中的影响**：
- 正相关→多样化效果减弱→需要更多缓冲
- 负相关→自然对冲→可以更激进
- 忽略相关性→低估或高估风险

## 3. Python 实现

```python
import numpy as np

def correlated_sampling(n_vars=3, n_samples=1000, corr_matrix=None):
    """生成相关随机变量"""
    if corr_matrix is None:
        corr_matrix = np.array([
            [1.0, 0.5, 0.3],
            [0.5, 1.0, 0.2],
            [0.3, 0.2, 1.0]
        ])

    # Cholesky分解
    L = np.linalg.cholesky(corr_matrix)
    Z = np.random.randn(n_samples, n_vars)
    W = Z @ L.T

    means = np.array([10, 15, 8])
    stds = np.array([2, 3, 1.5])
    W = W * stds + means

    # 验证相关性
    emp_corr = np.corrcoef(W.T)
    print("理论相关性:")
    print(corr_matrix)
    print("\n经验相关性:")
    print(np.round(emp_corr, 3))

    return W

np.random.seed(42)
W = correlated_sampling()
```

## 4. 与其他方法的关系

- **蒙特卡洛仿真**：需要正确建模相关性
- **Copula**：灵活的相关性建模工具
- **多变量时间序列**：VAR、VEC等模型
