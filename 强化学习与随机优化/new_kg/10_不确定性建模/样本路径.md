# 样本路径(Sample Paths) 学习文档

> 不确定性的一个具体实现——所有随机变量的一次完整"抽签"。

> 来源线索：本节内容根据原书中关于"Modeling Sample Paths"的相关章节(Ch 10.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：样本路径 $\omega$ 是随机过程从开始到结束的一次完整实现，是策略评估的基本单位。

## 2. 核心原理

**定义**：
$$\omega = (W_1, W_2, ..., W_T)$$
是一条完整的外生信息实现。

**在策略评估中的作用**：
$$F^\pi = E_\omega\left[\sum_{t=0}^{T} C(S_t^\pi, X_t^\pi(S_t))\right] \approx \frac{1}{L}\sum_{\ell=1}^{L} \sum_{t=0}^{T} C(S_t^{\pi,\ell}, X_t^\pi(S_t^{\pi,\ell}))$$

用 $L$ 条样本路径估计策略的期望性能。

**采样vs解析**：
- 采样：生成样本路径，模拟运行
- 解析：直接计算期望（通常不可行）

**样本路径的生成**：
1. 从分布 $F(W)$ 中抽取 $W_1$
2. 根据 $W_1$ 和状态转移抽取 $W_2$
3. 重复直到 $W_T$

## 3. Python 实现

```python
import numpy as np

def generate_sample_path(T, demand_dist):
    """生成一条样本路径"""
    return [np.random.choice(demand_dist) for _ in range(T)]

def evaluate_policy(policy, n_paths=1000, T=50, gamma=0.9):
    """用样本路径评估策略"""
    total_rewards = []

    for _ in range(n_paths):
        path = generate_sample_path(T, [3, 5, 7, 9, 11])
        state = {'inventory': 20}
        cumulative = 0

        for t in range(T):
            action = policy(state)
            state['inventory'] += action - path[t]
            state['inventory'] = max(0, state['inventory'])
            reward = -max(0, path[t] - state['inventory'] - action) * 5
            cumulative += gamma**t * reward

        total_rewards.append(cumulative)

    return np.mean(total_rewards), np.std(total_rewards)

# 固定策略
policy = lambda s: max(0, 8 - s['inventory'])
mean, std = evaluate_policy(policy)
print(f"策略期望值: {mean:.2f} ± {std:.2f}")
```

## 4. 与其他方法的关系

- **蒙特卡洛仿真**：基于样本路径的评估
- **SAA**：样本平均近似
- **策略评估**：用样本路径估计策略性能
