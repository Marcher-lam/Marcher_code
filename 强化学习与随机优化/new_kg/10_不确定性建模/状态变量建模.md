# 状态变量建模(State Variables) 学习文档

> 状态是决策的全部信息基础——正确建模状态变量是序贯决策问题的第一步。

> 来源线索：本节内容根据原书中关于"State Variables"的相关章节(Ch 9.2-9.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：状态变量 $S_t$ 包含时刻t做决策所需的所有信息，分为物理状态和信息状态（包括信念状态）。

## 2. 核心原理

**状态变量的三层结构**：
$$S_t = (R_t, I_t, B_t)$$

- **物理状态 $R_t$**：可直接观测的系统属性（库存量、位置、资金）
- **信息状态 $I_t$**：已知但不可控的外生信息（价格、天气预报、时间）
- **信念状态 $B_t$**：对未知参数的概率分布（需求分布、对手策略）

**后决策状态 vs 前决策状态**：
- **前决策状态** $S_t$：做决策前的状态（包含所有信息）
- **后决策状态** $S_t^a$：决策后、新信息到达前的状态

**设计原则**：
1. 完备性：状态必须包含做最优决策所需的全部信息
2. 最小性：不要包含冗余信息
3. 马尔可夫性：给定当前状态，未来与过去无关

**隐变量**：不可直接观测但影响系统行为的变量（如真实需求分布、对手意图）。

## 3. Python 实现

```python
import numpy as np

class StateVariable:
    """状态变量建模示例"""
    def __init__(self):
        self.physical = {'inventory': 50, 'cash': 1000}
        self.information = {'price': 10.0, 'day_of_week': 1}
        self.belief = {'demand_mean': 8.0, 'demand_std': 2.0, 'confidence': 10}

    def get_state(self):
        return {
            'physical': self.physical.copy(),
            'information': self.information.copy(),
            'belief': self.belief.copy()
        }

    def update(self, action, observation):
        """状态转移"""
        self.physical['inventory'] += action['order']
        self.physical['inventory'] -= observation['demand']
        self.physical['cash'] -= action['order'] * self.information['price']
        self.physical['cash'] += observation['demand'] * self.information['price'] * 1.2

        # 更新信念
        self.belief['confidence'] += 1
        n = self.belief['confidence']
        old_mean = self.belief['demand_mean']
        self.belief['demand_mean'] = old_mean + (observation['demand'] - old_mean) / n

state = StateVariable()
print("初始状态:", state.get_state())
state.update({'order': 20}, {'demand': 10})
print("更新后:", state.get_state())
```

## 4. 与其他方法的关系

- **MDP**：状态变量的离散化建模
- **POMDP**：状态不可直接观测的推广
- **后决策状态**：简化VFA计算的关键
