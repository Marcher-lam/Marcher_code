# 体制转换(Regime Shifting) 学习文档

> 价格在不同"体制"（高波动/低波动）间切换，用隐马尔可夫模型描述。

> 来源线索：本节内容根据原书中关于"Regime Shifting"的相关章节(Ch 10.5.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：体制转换模型假设系统在有限个离散状态（体制）间切换，每个体制有不同的参数，用隐马尔可夫模型(HMM)描述切换过程。

**直觉类比**：天气在"晴天"和"雨天"两种体制间切换。晴天时温度稳定（低波动），雨天时温度剧烈变化（高波动）。你不需要知道明天是晴还是雨，但知道两种体制的统计特性——晴天平均温度高、波动小，雨天平均温度低、波动大。

**历史背景**：体制转换模型由Hamilton (1989)引入经济学，用于描述经济扩张/衰退的切换。原书Ch 10.5.4将其用于电力价格建模——正常时段价格平稳，高峰时段价格暴涨。HMM框架（Baum-Welch算法估计参数）是标准的参数估计方法。

**算法定位**：不确定性建模/时间序列分析。体制转换是均值回归的扩展——不同体制有不同的回归速度和波动率。

**前置知识**：
- 均值回归模型
- 隐马尔可夫模型(HMM)
- 概率论（转移矩阵、条件概率）
- Python + NumPy

## 2. 核心原理

**核心思想**：单一参数的均值回归模型无法捕捉"持续性变化"——价格有时在低位平静波动，有时突然暴涨。体制转换模型引入隐状态$S_t$，不同状态下参数不同，状态之间通过转移矩阵切换。

**工作流程**：

1. 设定$K$个体制，每个有参数$(\mu_k, \sigma_k, \kappa_k)$
2. 设定转移矩阵$P_{ij} = \mathbb{P}(S_{t+1}=j|S_t=i)$
3. 在体制$S_t$下，价格按该体制的参数演化
4. 以概率$P_{S_t, j}$切换到体制$j$

**关键概念**：

- **体制(Regime)**：系统所处的隐状态，如"高波动"、"低波动"
- **转移矩阵**：体制间切换的概率矩阵，对角元素通常接近1（持续在同一体制）
- **隐状态**：体制不可直接观测，需要从观测数据推断
- **持续期(Duration)**：系统停留在某体制的平均时间，与$1/(1-P_{ii})$成正比

**与相关模型的关系**：

```
不确定性模型
├── 均值回归：单一体制，O-U过程
├── 体制转换：多体制，参数切换
├── 跳跃扩散：瞬时跳变（不持续）
└── GARCH：波动率时变（连续变化）
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $S_t$ | 时刻$t$的隐体制状态 |
| $K$ | 体制数量 |
| $\mu_k$ | 体制$k$的长期均值 |
| $\sigma_k$ | 体制$k$的波动率 |
| $\kappa_k$ | 体制$k$的回归速度 |
| $P_{ij}$ | 从体制$i$转移到$j$的概率 |

### 体制转换均值回归模型

$$p_{t+1} = p_t + \kappa(S_t)(\mu_{S_t} - p_t) + \sigma_{S_t}\varepsilon_{t+1}$$

其中$S_t \in \{1, ..., K\}$，$\varepsilon_{t+1} \sim N(0,1)$。

### 转移矩阵

$$P = \begin{pmatrix} P_{11} & P_{12} & \cdots \\ P_{21} & P_{22} & \cdots \\ \vdots & & \ddots \end{pmatrix}, \quad \sum_j P_{ij} = 1$$

典型两体制模型：

$$P = \begin{pmatrix} 0.95 & 0.05 \\ 0.10 & 0.90 \end{pmatrix}$$

体制1的平均持续期$= 1/(1-0.95) = 20$步，体制2的平均持续期$= 1/(1-0.90) = 10$步。

### 对数似然函数

给定观测$p_1, ..., p_T$，似然函数为：

$$\mathcal{L} = \sum_{t=1}^{T}\log\left(\sum_{k=1}^K \xi_t(k) \cdot f(p_t|S_t=k, p_{t-1})\right)$$

其中$\xi_t(k)$是时刻$t$处于体制$k$的滤波概率，$f$是高斯密度。

### Baum-Welch算法(EM)

**E步**：计算前向概率$\alpha_t(k)$和后向概率$\beta_t(k)$，得到体制的后验概率。

**M步**：更新参数：
- $\hat{\mu}_k = \frac{\sum_t \gamma_t(k) p_t}{\sum_t \gamma_t(k)}$
- $\hat{\sigma}_k^2 = \frac{\sum_t \gamma_t(k)(p_t - \hat{\mu}_k)^2}{\sum_t \gamma_t(k)}$
- $\hat{P}_{ij} = \frac{\sum_t \xi_t(i,j)}{\sum_t \gamma_t(i)}$

其中$\gamma_t(k)$是$t$时刻体制$k$的后验概率，$\xi_t(i,j)$是$t$到$t+1$从$i$到$j$的转移概率。

## 4. 训练过程讲解

### 参数初始化
- 体制数$K$：通常2-4个（过多会过拟合）
- 初始参数：用K-means聚类对数据分组，估计各组参数
- 转移矩阵：初始化为对角占优

### Baum-Welch迭代
1. E步：前向-后向算法计算后验概率
2. M步：更新均值、方差、转移矩阵
3. 检查似然函数收敛
4. 重复直到收敛

### 模型选择
- 用BIC/AIC选择最优体制数$K$
- 2体制通常足够（低波动/高波动）

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $K$ | 体制数 | [2, 4] | 2 |
| $\kappa_k$ | 回归速度 | [0.01, 0.5] | 0.1 |
| max_iter | EM最大迭代 | [50, 500] | 100 |
| tol | 收敛阈值 | [1e-4, 1e-6] | 1e-4 |

## 5. 应用场景

### 1. 电力价格建模
为什么适合：电价有明显的"正常"和"尖峰"两种体制。正常时段价格低且稳定，高峰时段价格暴涨。体制转换模型精确捕捉这种双模态行为。

### 2. 金融市场
为什么适合：股市有"牛市"和"熊市"两种体制——牛市波动低收益高，熊市波动高收益低。体制转换改进风险管理和期权定价。

### 3. 经济周期
为什么适合：宏观经济在扩张和衰退间切换，两种体制下GDP增长率、失业率等指标参数不同。

### 4. 网络流量
为什么适合：网络流量有"正常"和"突发"两种体制，用于异常检测和容量规划。

### 不适用场景
- 参数变化是连续渐变的（用GARCH）
- 只有一次瞬时跳变（用跳跃扩散）
- 体制数极多（HMM估计困难）

## 6. 优缺点分析

### 优点
1. **捕捉持续性变化**：比单一体制模型更灵活（成立条件：确实存在可区分的体制）
2. **可解释性强**：每个体制有明确的物理/经济含义
3. **HMM理论成熟**：参数估计（EM）和解码（Viterbi）有标准算法
4. **概率推断**：可以实时估计当前处于哪个体制

### 缺点
1. **体制数选择主观**：$K$需要人为设定或用信息准则
2. **参数估计不稳定**：EM算法可能收敛到局部最优
3. **假设有限体制**：实际可能是连续变化
4. **需要足够数据**：数据量不足时体制识别不准

### 算法对比

| 特性 | 体制转换 | 均值回归 | 跳跃扩散 | GARCH |
|------|---------|---------|---------|-------|
| 多体制 | 是 | 否 | 否 | 否 |
| 持续性变化 | 是 | 否 | 否 | 是 |
| 瞬时跳变 | 否 | 否 | 是 | 否 |
| 可解释性 | 高 | 高 | 中 | 低 |
| 参数估计 | EM | OLS | MCMC | MLE |

        returns = np.diff(prices).reshape(-1, 1)
        model = hmm.GaussianHMM(n_components=n_regimes, covariance_type='full',
                                n_iter=100, random_state=42)
        model.fit(returns)
        hidden_states = model.predict(returns)
        print(f"体制数: {n_regimes}")
        for k in range(n_regimes):
            mask = hidden_states == k
            print(f"  体制{k}: 均值={model.means_[k][0]:.3f}, "
                  f"标准差={np.sqrt(model.covars_[k][0][0]):.3f}, "
                  f"占比={mask.sum()/len(hidden_states):.1%}")
        print(f"转移矩阵:\n{model.transmat_.round(3)}")
        return model, hidden_states

## 8. 手工代码实现

```python
"""
从零实现体制转换模型（纯NumPy）
包含简化版EM算法
"""
import numpy as np

class RegimeSwitching:
    """体制转换模型"""

    def __init__(self, n_regimes=2):
        self.K = n_regimes
        self.params = [{'mu': 50, 'sigma': 2, 'kappa': 0.1}
                       for _ in range(n_regimes)]
        self.trans_mat = np.array([[0.95, 0.05], [0.1, 0.9]])

    def simulate(self, p0, T):
        """模拟体制转换过程"""
        prices = [p0]
        regimes = []
        s = 0
        for t in range(T):
            regimes.append(s)
            mu = self.params[s]['mu']
            sigma = self.params[s]['sigma']
            kappa = self.params[s]['kappa']
            noise = sigma * np.random.randn()
            p = prices[-1] + kappa*(mu - prices[-1]) + noise
            prices.append(p)
            s = np.random.choice(self.K, p=self.trans_mat[s])
        return np.array(prices), np.array(regimes)

    def forward_backward(self, prices):
        """简化的前向-后向算法"""
        T = len(prices) - 1
        changes = np.diff(prices)

        # 计算每个体制下的观测概率
        def obs_prob(x, k):
            mu = self.params[k]['kappa'] * (self.params[k]['mu'] - prices[:-1][np.arange(len(x))])
            sigma = self.params[k]['sigma']
            return np.exp(-0.5*((x - mu)/sigma)**2) / (sigma*np.sqrt(2*np.pi))

        # 简化：用滑动窗口检测体制
        window = 20
        volatilities = np.array([changes[max(0,i-window):i].std()
                                 for i in range(1, len(changes)+1)])
        threshold = np.median(volatilities)
        inferred = (volatilities > threshold).astype(int)
        return inferred

    def detect_regime(self, prices, window=20):
        """简单的体制检测（基于波动率）"""
        changes = np.diff(prices)
        vols = np.array([changes[max(0,i-window):i].std()
                        for i in range(window, len(changes)+1)])
        if len(vols) == 0:
            return np.zeros(len(changes), dtype=int)
        threshold = np.median(vols)
        regimes = (vols > threshold).astype(int)
        # 补齐长度
        if len(regimes) < len(changes):
            regimes = np.concatenate([np.zeros(len(changes)-len(regimes), dtype=int), regimes])
        return regimes[:len(changes)]


# ========== 测试 ==========
if __name__ == "__main__":
    np.random.seed(42)
    rs = RegimeSwitching()
    rs.params = [{'mu': 50, 'sigma': 1, 'kappa': 0.1},
                 {'mu': 50, 'sigma': 5, 'kappa': 0.1}]
    rs.trans_mat = np.array([[0.97, 0.03], [0.05, 0.95]])

    prices, true_regimes = rs.simulate(50.0, 500)
    print("体制转换模拟:")
    for k in range(rs.K):
        mask = true_regimes == k
        print(f"  体制{k}: {mask.sum()}步, σ≈{prices[1:][mask].std():.1f}")

    # 检测体制
    detected = rs.detect_regime(prices, window=20)
    accuracy = np.mean(detected[:len(true_regimes)] == true_regimes[:len(detected)])
    print(f"\n体制检测准确率: {accuracy:.1%}")
```

"""体制转换可视化"""
import matplotlib.pyplot as plt
import numpy as np

def visualize_regime_switching(prices, regimes, K=2):
    """可视化体制转换过程"""
    fig, axes = plt.subplots(2, 1, figsize=(14, 8), sharex=True)

    # 1. 价格序列 + 体制着色
    colors = ['blue', 'red', 'green', 'orange']
    for k in range(K):
        mask = regimes == k
        idx = np.where(mask)[0]
        if len(idx) > 0:
            axes[0].scatter(idx, prices[1:len(regimes)+1], c=colors[k],
                          alpha=0.3, s=2, label=f'体制{k}')
    axes[0].plot(prices, 'k-', alpha=0.2, linewidth=0.5)
    axes[0].set_ylabel('价格')
    axes[0].set_title('体制转换模型：价格与隐状态')
    axes[0].legend()
    axes[0].grid(True, alpha=0.3)

    # 2. 体制状态
    axes[1].plot(regimes, drawstyle='steps-post', linewidth=0.8)
    axes[1].set_ylabel('体制')
    axes[1].set_xlabel('时间步')
    axes[1].set_title('隐体制状态')

## 10. 模型评估

```python
"""体制转换模型评估"""
import numpy as np

def evaluate_regime_model(prices, true_regimes, detected_regimes, params):
    """评估体制转换模型"""
    # 检测准确率
    min_len = min(len(true_regimes), len(detected_regimes))
    accuracy = np.mean(true_regimes[:min_len] == detected_regimes[:min_len])

    # 预测误差
    changes = np.diff(prices)
    predicted = np.zeros(len(changes))
    for t in range(1, len(changes)):
        k = detected_regimes[t-1] if t-1 < len(detected_regimes) else 0
        predicted[t] = params[k]['kappa'] * (params[k]['mu'] - prices[t])
    mse = np.mean((changes - predicted)**2)

    print(f"体制转换模型评估：")
    print(f"  体制检测准确率: {accuracy:.1%}")
    print(f"  预测MSE: {mse:.4f}")
    print(f"  各体制参数:")
    for k, p in enumerate(params):
        print(f"    体制{k}: μ={p['mu']:.1f}, σ={p['sigma']:.1f}, κ={p['kappa']:.2f}")
```

## 11. 常见问题与易错点

### 数据层面

1. **体制数选择错误**
   - 现象：2体制太多或太少
   - 原因：数据可能只有1个体制，或有3+个体制
   - 解决方案：用BIC/AIC选择最优$K$，或用非参数方法验证

2. **数据量不足**
   - 现象：参数估计不稳定
   - 原因：EM算法需要足够数据来识别不同体制
   - 解决方案：至少需要几百个观测点

### 模型层面

3. **EM算法局部最优**
   - 现象：不同初始值给出不同结果
   - 原因：似然函数非凸
   - 解决方案：多次随机初始化，选似然最高的

4. **混淆跳跃和体制切换**
   - 现象：用体制转换拟合瞬时跳变
   - 原因：跳跃是瞬时事件，体制是持续状态
   - 解决方案：跳跃扩散捕捉瞬时跳变，体制转换捕捉持续性变化

### 调参层面

5. **转移矩阵对角元素过大**
   - 现象：体制几乎不切换
   - 原因：$P_{ii}$接近1导致体制"粘滞"
   - 解决方案：约束$P_{ii} \leq 0.99$或添加切换先验

## 12. 学习总结

体制转换用隐状态$S_t$切换参数$(\mu_k, \sigma_k, \kappa_k)$：$p_{t+1} = p_t + \kappa(S_t)(\mu_{S_t}-p_t) + \sigma_{S_t}\varepsilon$。HMM框架建模，EM算法估计参数。

**关键公式**：
1. 价格演化：$p_{t+1} = p_t + \kappa(S_t)(\mu_{S_t}-p_t) + \sigma_{S_t}\varepsilon$
2. 转移矩阵：$P_{ij} = \mathbb{P}(S_{t+1}=j|S_t=i)$
3. 持续期：$D_k = 1/(1-P_{kk})$

体制转换是均值回归的多体制扩展，原书用于电力价格和能源市场的不确定性建模。

## 13. 练习题与思考题

### 基础题

**题目1**：体制转换和跳跃扩散捕捉的不同现象是什么？

**参考答案**：
- 跳跃扩散：瞬时跳变后快速回归。跳是"事件"，持续时间极短（一步）
- 体制转换：持续性的参数变化。高波动期持续数十步，是一个"状态"而非"事件"
- 选择：如果异常持续很久用体制转换，如果只是短暂尖峰用跳跃扩散

### 进阶题

**题目2**：两体制模型中，转移矩阵$P = [[0.98, 0.02], [0.05, 0.95]]$。体制0和体制1的平均持续期分别是多少？稳态概率是多少？

**参考答案**：
- 体制0持续期：$1/(1-0.98) = 50$步
- 体制1持续期：$1/(1-0.95) = 20$步
- 稳态概率：$\pi_0 = P_{10}/(P_{10}+P_{01}) = 0.05/0.07 \approx 0.714$
- $\pi_1 = P_{01}/(P_{10}+P_{01}) = 0.02/0.07 \approx 0.286$

### 开放思考题

**题目3**：原书(Ch 10.5.4)将体制转换用于电力价格。在RL/随机优化的框架下，体制转换如何影响决策？

**参考答案方向**：
- 体制转换意味着环境参数随时间变化（非平稳），但变化方式有结构（体制切换）
- 对RL的影响：(1)策略必须适应不同体制；(2)值函数在不同体制下不同；(3)需要在线体制检测
- 实际方案：(1)将体制$S_t$纳入状态变量；(2)为每个体制训练不同的策略；(3)用贝叶斯滤波实时估计当前体制
- 这是"学习中的结构利用"的典型案例——利用体制切换的结构先验提高样本效率
