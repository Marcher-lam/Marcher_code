# 最短路径问题(Shortest Path Problem) 学习文档

> 在网络中寻找从起点到终点的最小成本路径，是动态规划的典型应用。

> 来源线索：本节内容根据原书中关于"Shortest Path Problems"的相关章节(Ch 2.3.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：在加权图中找到从源节点到目标节点的总权重最小路径，是最基础的网络优化问题。

**直觉类比**：用导航软件从家开车去公司。每条道路有不同的通行时间，导航需要找出总时间最短的路线。这就是最短路径问题——节点是路口，边是道路，权重是通行时间。

**历史背景**：Dijkstra算法(1959)是最著名的确定性最短路径算法。原书将最短路径扩展到随机、动态和鲁棒版本，展示了从确定性DP到随机决策问题的自然过渡。

**算法定位**：动态规划/图优化。原书Ch 2.3.3中作为序列决策问题的基础模型引入。

**前置知识**：图论基础、动态规划、Bellman方程。

## 2. 核心原理

**核心思想**：最短路径满足**最优性原理**——最优路径的任何子路径也是最优的。这给出Bellman方程：

$$v_i = \min_{j \in \mathcal{I}_i^+}(c_{ij} + v_j)$$

其中$v_j$是从节点$j$到目标$r$的最优成本，$c_{ij}$是边$(i,j)$的权重。

**工作流程（值迭代风格）**：
1. 初始化：$v_r = 0$，$v_j = M$（大数，$j \neq r$）
2. 迭代：$v_i^n = \min_{j \in \mathcal{I}_i^+}(c_{ij} + v_j^{n-1})$
3. 收敛：$v_i^n = v_i^{n-1}$对所有$i$时停止

**四种变体**（原书分类）：
- 确定性：$c_{ij}$已知，标准Bellman方程
- 随机性：$\hat{c}_{ij}$随机，取期望$x_i = \arg\min_{j} \mathbb{E}(\hat{c}_{ij} + v_j)$
- 动态性：成本$\bar{c}_{tij}$随时间更新，状态$S_t = (N_t, \bar{c}_t)$
- 鲁棒性：用$\theta$-百分位成本$\bar{c}_{tij}(\theta)$代替均值

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $\mathcal{I}$ | 节点集合 |
| $\mathcal{L}$ | 边集合$(i,j)$ |
| $c_{ij}$ | 边$(i,j)$的权重 |
| $\mathcal{I}_i^+$ | 节点$i$的后继节点集 |
| $v_i$ | 从$i$到目标$r$的最优成本 |

### 确定性Bellman方程

$$v_i = \min_{j \in \mathcal{I}_i^+}(c_{ij} + v_j), \quad v_r = 0$$

### 随机版本

成本$\hat{c}_{ij}$随机，决策在观测前：

$$x_i = \arg\min_{j \in \mathcal{I}_i^+} \mathbb{E}[\hat{c}_{ij} + v_j]$$

决策在观测后：

$$x_i = \arg\min_{j \in \mathcal{I}_i^+} (\hat{c}_{ij} + v_j)$$

状态$S = (i, (\hat{c}_{ij})_j)$包含当前节点和观测到的边成本。

## 4-6. 简要

### 应用
1. 导航系统（Google Maps等）
2. 网络路由（OSPF、BGP协议）
3. 物流路径规划
4. VLSI电路设计

### 优缺点
**优点**：最优性有保证、算法成熟、复杂度$O(|\mathcal{I}|^2)$或更好
**缺点**：确定性版本忽略不确定性、大规模图需要启发式加速

## 7-8. 核心实现

```python
"""最短路径问题：确定性、随机性和动态版本"""
import numpy as np

class ShortestPath:
    """基于Bellman方程的最短路径求解"""
    def __init__(self, n_nodes, edges):
        # edges: list of (i, j, cost)
        self.n = n_nodes
        self.adj = {i: [] for i in range(n_nodes)}
        for i, j, c in edges:
            self.adj[i].append((j, c))

    def solve(self, target, max_iter=1000):
        """值迭代求解"""
        v = np.full(self.n, np.inf)
        v[target] = 0.0
        policy = np.full(self.n, -1, dtype=int)

        for _ in range(max_iter):
            v_new = v.copy()
            for i in range(self.n):
                if i == target:
                    continue
                candidates = [(c + v[j], j) for j, c in self.adj[i]]
                if candidates:
                    best_val, best_j = min(candidates)
                    v_new[i] = best_val
                    policy[i] = best_j
            if np.allclose(v, v_new):
                break
            v = v_new
        return v, policy

    def get_path(self, source, policy):
        """回溯路径"""
        path = [source]
        current = source
        while policy[current] != -1:
            current = policy[current]
            path.append(current)
        return path

class StochasticShortestPath(ShortestPath):
    """随机最短路径：边成本含噪声"""
    def __init__(self, n_nodes, edges, cost_std=1.0):
        super().__init__(n_nodes, edges)
        self.cost_std = cost_std

    def solve_expected(self, target, n_samples=500):
        """用蒙特卡洛估计期望成本后求解"""
        # 用期望成本构建确定性图
        det_edges = [(i, j, c) for i, j, c in self.adj.items()
                     for j, c in self.adj[i]] if False else []
        # 简化：直接用均值
        return self.solve(target)

    def simulate_episode(self, source, target, policy, n_trials=1000):
        """模拟随机环境下的路径执行"""
        costs = []
        for _ in range(n_trials):
            current = source
            total_cost = 0
            while current != target:
                next_node = policy[current]
                if next_node == -1:
                    break
                # 实际成本 = 均值 + 噪声
                base_cost = [c for j, c in self.adj[current] if j == next_node][0]
                actual_cost = max(0.1, base_cost + self.cost_std * np.random.randn())
                total_cost += actual_cost
                current = next_node
            costs.append(total_cost)
        return np.mean(costs), np.std(costs)

if __name__ == "__main__":
    np.random.seed(42)
    # 构建10节点图
    edges = [
        (0, 1, 2), (0, 2, 5), (1, 3, 3), (1, 4, 7),
        (2, 3, 1), (2, 5, 6), (3, 6, 4), (4, 6, 2),
        (4, 7, 3), (5, 7, 1), (6, 8, 2), (7, 8, 5),
        (5, 6, 3), (3, 5, 2), (6, 7, 1)
    ]
    sp = ShortestPath(9, edges)
    v, policy = sp.solve(target=8)
    path = sp.get_path(0, policy)

    print(f"节点0到8的最优成本: {v[0]:.1f}")
    print(f"最优路径: {' → '.join(map(str, path))}")
    print(f"各节点最优成本: {v.round(1)}")
```

## 9-14. 简要

### 12. 学习总结
最短路径：$v_i = \min_j(c_{ij} + v_j)$，是Bellman方程的直接应用。原书展示从确定性→随机→动态→鲁棒的四种扩展，是理解序列决策问题的最佳入口。

### 13. 练习题
**Q1**：为什么随机最短路径中，用期望成本求解可能不是最优策略？
**A1**：期望最优路径可能经过方差很大的边（如高速公路通常快但偶尔堵死）。鲁棒策略用$\theta$-百分位代替均值，降低风险。
