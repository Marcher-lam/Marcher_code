# 平均奖励动态规划(Average Reward DP) 学习文档

> 与折扣DP并列的独立框架，用平均奖励(gain)和偏差(bias)替代折扣值函数。

> 来源线索：本节内容根据原书中关于"Average Reward Dynamic Programming"的相关章节(Ch 14, Exact DP章节)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：平均奖励DP优化长期平均回报$\rho = \lim_{T\to\infty}\frac{1}{T}\mathbb{E}[\sum_{t=0}^{T-1}r_t]$，通过gain+bias分解建立Bellman方程。

**算法定位**：精确动态规划。与折扣DP（discounted DP）并列为两大DP框架。

**前置知识**：MDP、Bellman方程、值迭代、策略迭代。

## 2. 核心原理

**核心思想**：折扣DP通过$\gamma < 1$保证值函数有界，但$\gamma$的选择往往缺乏物理意义。平均奖励准则直接优化长期平均回报，更自然地适用于连续运行系统（通信网络、生产调度等）。

**Gain和Bias分解**：对于策略$\pi$，值函数可分解为：

$$V^\pi(s) = \underbrace{\rho^\pi \cdot n}_{\text{gain项}} + \underbrace{h^\pi(s)}_{\text{bias项}} + o(1)$$

其中：
- $\rho^\pi$：平均奖励(gain)，与状态无关的常数
- $h^\pi(s)$：相对值(bias)，衡量从状态$s$出发比平均水平好多少

**与折扣DP的关系**：当$\gamma \to 1$时，折扣值函数近似为$V^\gamma(s) \approx \frac{\rho}{1-\gamma} + h(s)$。

## 3. 数学公式

### 平均奖励Bellman方程

$$\rho^* + h^*(s) = \max_a \left[ r(s,a) + \sum_{s'} P(s'|s,a) h^*(s') \right]$$

注意：与折扣Bellman方程的区别在于用$\rho^* + h^*(s)$替代$V(s)$。

### 相对值迭代(Relative VI for Average Reward)

选择一个参考状态$s^*$，每步减去$h(s^*)$：

$$h^{n+1}(s) = \max_a \left[ r(s,a) + \sum_{s'} P(s'|s,a) h^n(s') \right] - \max_a \left[ r(s^*,a) + \sum_{s'} P(s'|s^*,a) h^n(s') \right]$$

### 策略迭代(Policy Iteration for Average Reward)

1. **策略评估**：求解线性方程组

$$\rho + h(s) = r(s,\pi(s)) + \sum_{s'} P(s'|s,\pi(s)) h(s')$$

（$|S|$个方程，$|S|+1$个未知数，需固定$h(s_0)=0$）

2. **策略改进**：

$$\pi'(s) = \arg\max_a \left[ r(s,a) + \sum_{s'} P(s'|s,a) h(s') \right]$$

### 平均奖励的表达式

$$\rho^\pi = \sum_s \mu^\pi(s) \sum_{s'} P(s'|s,\pi(s)) r(s,\pi(s))$$

其中$\mu^\pi$是策略$\pi$下的平稳分布。

## 4. 训练/迭代过程

**相对值迭代流程**：
1. 初始化$h^0(s)$（如全零）
2. 对每个状态$s$，计算$q(s,a) = r(s,a) + \sum_{s'} P(s'|s,a) h^n(s')$
3. 更新：$h^{n+1}(s) = \max_a q(s,a) - \max_a q(s^*,a)$
4. 收敛判断：$\|h^{n+1} - h^n\| < \epsilon$
5. 提取最优策略：$\pi^*(s) = \arg\max_a q(s,a)$

## 5. 应用场景

- 通信网络路由优化（长期吞吐量最大化）
- 生产调度（稳态产出最大化）
- 库存控制（长期平均利润）
- 排队系统控制（长期平均等待时间最小化）
- 机器人路径规划（持续运行场景）

## 6. 优缺点

**优点**：
- 无需选择折扣因子$\gamma$
- 更适合持续运行的系统
- gain值$\rho^*$直接反映长期性能

**缺点**：
- 需要遍历性假设（所有状态在策略下可达）
- 策略评估需额外固定一个状态（$h(s_0)=0$）
- 数值稳定性不如折扣DP（bias值可能漂移）

## 7. 库实现

Python中可用 `mdp` 库或自定义实现。无主流RL库直接支持平均奖励准则（大多数用折扣奖励），但 `rlpyt` 等库有平均奖励选项。

## 8. 从零实现

```python
"""平均奖励动态规划：相对值迭代 + 策略迭代"""
import numpy as np

class AverageRewardDP:
    def __init__(self, n_states, n_actions, transitions, rewards):
        """
        transitions[s, a, s'] = P(s'|s,a)
        rewards[s, a] = r(s,a)
        """
        self.S = n_states
        self.A = n_actions
        self.P = transitions
        self.R = rewards

    def relative_value_iteration(self, max_iter=1000, tol=1e-6):
        """相对值迭代"""
        h = np.zeros(self.S)
        ref_state = 0  # 参考状态

        for it in range(max_iter):
            # 计算 Q(s,a) = R(s,a) + sum P(s'|s,a) h(s')
            Q = self.R + np.einsum('ijk,k->ij', self.P, h)
            # 更新 h
            h_new = np.max(Q, axis=1)
            # 减去参考状态值
            h_new -= h_new[ref_state]
            # 收敛检查
            if np.max(np.abs(h_new - h)) < tol:
                print(f"相对值迭代收敛于第{it}步")
                break
            h = h_new

        rho = np.max(Q[ref_state])  # 平均奖励
        policy = np.argmax(Q, axis=1)
        return rho, h, policy

    def policy_iteration(self, max_iter=100):
        """平均奖励策略迭代"""
        policy = np.zeros(self.S, dtype=int)

        for it in range(max_iter):
            # 策略评估：求解 rho + h(s) = R(s,pi(s)) + sum P h(s')
            # 固定 h[0] = 0，求解 |S|+1 未知数
            A = np.zeros((self.S, self.S + 1))
            b = np.zeros(self.S)
            for s in range(self.S):
                a = policy[s]
                A[s, 0] = -1  # -rho
                A[s, 1 + s] = 1  # h(s)
                for s2 in range(self.S):
                    A[s, 1 + s2] -= self.P[s, a, s2]  # -sum P h(s')
                b[s] = self.R[s, a]
            # 固定 h[0] = 0
            A_fixed = A[:, 1:]  # 去掉rho列
            A_fixed[0, :] = 0
            A_fixed[0, 0] = 1  # h[0] = 0
            b_fixed = b.copy()
            b_fixed[0] = 0

            sol = np.linalg.lstsq(A_fixed, b_fixed, rcond=None)[0]
            h = sol
            rho = np.mean(self.R[np.arange(self.S), policy] +
                         np.einsum('ijk,k->ij', self.P, h)[np.arange(self.S), policy])

            # 策略改进
            Q = self.R + np.einsum('ijk,k->ij', self.P, h)
            new_policy = np.argmax(Q, axis=1)

            if np.array_equal(new_policy, policy):
                print(f"策略迭代收敛于第{it}步")
                break
            policy = new_policy

        return rho, h, policy

if __name__ == "__main__":
    np.random.seed(42)
    S, A = 5, 2
    P = np.random.dirichlet(np.ones(S), size=(S, A))
    R = np.random.randn(S, A)

    dp = AverageRewardDP(S, A, P, R)

    rho_vi, h_vi, pi_vi = dp.relative_value_iteration()
    print(f"相对值迭代: 平均奖励={rho_vi:.4f}")
    print(f"  策略: {pi_vi}")
    print(f"  bias: {h_vi.round(4)}")

    rho_pi, h_pi, pi_pi = dp.policy_iteration()
    print(f"策略迭代: 平均奖励={rho_pi:.4f}")
    print(f"  策略: {pi_pi}")
```

## 10. 评估方法

- 平均奖励$\rho^*$的收敛速度
- 与折扣DP（$\gamma \to 1$）的结果对比验证
- 策略质量：在仿真中评估长期平均回报

## 11. 常见错误

- 忘记固定参考状态$h(s_0)=0$导致方程组奇异
- 系统不遍历导致gain不唯一
- 混淆bias与折扣值函数的物理含义

## 12. 学习总结

平均奖励DP：$\rho^* + h^*(s) = \max_a[r(s,a) + \sum P h^*(s')]$。gain $\rho^*$是长期平均回报，bias $h(s)$是相对优势。无需折扣因子，适合持续运行系统。

## 13. 练习题

**Q1**：平均奖励DP为什么需要遍历性假设？
**A1**：如果MDP有不连通的通信类，不同类可能有不同的平均奖励。遍历性保证所有状态在最优策略下形成一个单一通信类，gain $\rho^*$是唯一的。

**Q2**：如何从折扣DP过渡到平均奖励DP？
**A2**：令$\gamma \to 1$，此时$V^\gamma(s) \approx \frac{\rho}{1-\gamma} + h(s)$。用$\rho = (1-\gamma)V^\gamma(s_0)$估计gain，用$h(s) = V^\gamma(s) - V^\gamma(s_0)$估计bias。
