# 动态规划的线性规划方法(LP for DP) 学习文档

> 将Bellman方程转化为线性规划，是求解MDP的第三条路径。

> 来源线索：本节内容根据原书中关于"Linear Programming Method for Dynamic Programs"的相关章节(Ch 14.8)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：将MDP的最优性方程转化为对偶线性规划，用LP求解器高效求解大规模MDP。

**Primal LP（求最小上界）**：

$$\min_v \sum_s c_s v(s) \quad \text{s.t. } v(s) \geq r(s,a) + \gamma\sum_{s'}P(s'|s,a)v(s'), \forall s,a$$

**对偶LP**：

$$\max_x \sum_{s,a} r(s,a)x(s,a) \quad \text{s.t. } \sum_a x(s,a) = c_s + \gamma\sum_{s',a'}P(s|s',a')x(s',a')$$

对偶变量$x(s,a)$是状态-动作对的"访问频率"。

**优势**：LP可以利用商业求解器（如Gurobi）的高效实现，对大规模问题可能比VI/PI更快。

## 4-8. 核心实现

```python
"""DP的线性规划方法"""
import numpy as np
from scipy.optimize import linprog

def solve_mdp_lp(P, R, gamma=0.95):
    """用LP求解MDP"""
    nS, nA = R.shape
    # 变量: v(s_0), v(s_1), ..., v(s_{nS-1})
    # min c^T v s.t. v(s) >= r(s,a) + gamma*P(s,a)^T v for all s,a
    c = np.ones(nS)  # 目标系数

    A_ub, b_ub = [], []
    for s in range(nS):
        for a in range(nA):
            row = gamma * P[s, a]
            row[s] -= 1  # v(s)的系数为-1
            A_ub.append(row)
            b_ub.append(-R[s, a])

    result = linprog(c, A_ub=np.array(A_ub), b_ub=np.array(b_ub), method='highs')
    V = result.x
    policy = np.array([np.argmax([R[s,a] + gamma*P[s,a]@V for a in range(nA)])
                       for s in range(nS)])
    return V, policy

if __name__ == "__main__":
    np.random.seed(42)
    nS, nA = 8, 3
    P = np.random.dirichlet(np.ones(nS), (nS, nA))
    R = np.random.uniform(0, 2, (nS, nA))
    V, pi = solve_mdp_lp(P, R)
    print(f"LP方法值函数: {V.round(3)}")
    print(f"LP方法策略: {pi}")
```

## 9-14. 简要

### 12. 学习总结
LP for DP：$\min c^Tv$ s.t. $v(s) \geq r(s,a)+\gamma Pv$。Bellman方程的LP对偶，第三种MDP求解路径。

### 13. 练习题
**Q1**：LP方法相比VI/PI的核心优势？
**A1**：LP可以利用商业求解器的高效稀疏矩阵运算和并行化。对大规模但稀疏的MDP，LP通常比VI快。缺点是内存消耗$O(|S|^2)$。
