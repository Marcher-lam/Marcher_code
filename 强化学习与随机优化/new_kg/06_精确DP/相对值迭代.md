# 相对值迭代(Relative Value Iteration) 学习文档

> 用相对值消除无限horizon平均奖励问题的值函数漂移。

> 来源线索：本节内容根据原书中关于"Relative Value Iteration"的相关章节(Ch 14.6)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：相对值迭代在标准值迭代中减去一个参考状态的值，消除平均奖励设定下值函数的无界增长。

**问题背景**：无限horizon平均奖励准则$\lim_{T\to\infty}\frac{1}{T}\mathbb{E}\sum_t r_t$下，值函数可能无限增长（折扣$\gamma=1$）。

**公式**：

$$V^{n+1}(s) = \min_a \left[c(s,a) + \sum_{s'} P(s'|s,a) V^n(s')\right] - V^n(s_{ref})$$

其中$s_{ref}$是任意固定参考状态。减去$V^n(s_{ref})$保证值函数有界。

**最优平均奖励**：$g^* = \lim_{n\to\infty} V^n(s_{ref})$

**收敛条件**：MDP是通信的（任何状态可达任何其他状态）。

## 4-8. 核心实现

```python
"""相对值迭代"""
import numpy as np

def relative_vi(P, R, ref_state=0, max_iter=500, tol=1e-6):
    """平均奖励MDP的相对值迭代"""
    nS, nA = R.shape
    V = np.zeros(nS)
    g = 0  # 平均奖励估计

    for it in range(max_iter):
        V_new = np.zeros(nS)
        for s in range(nS):
            q_values = [R[s, a] + P[s, a] @ V for a in range(nA)]
            V_new[s] = max(q_values)  # 最大化奖励
        g = V_new[ref_state]
        V_new -= g  # 减去参考状态值
        if np.max(np.abs(V_new - V)) < tol:
            return V_new, g, it + 1
        V = V_new
    return V, g, max_iter

if __name__ == "__main__":
    np.random.seed(42)
    nS, nA = 10, 3
    P = np.random.dirichlet(np.ones(nS), (nS, nA))
    R = np.random.uniform(0, 2, (nS, nA))
    V, g, iters = relative_vi(P, R)
    print(f"相对值迭代在{iters}次迭代后收敛")
    print(f"最优平均奖励: {g:.4f}")
    print(f"相对值函数: {V.round(3)}")
```

## 9-14. 简要

### 12. 学习总结
相对VI：$V^{n+1}(s) = \max_a[r(s,a) + P V^n] - V^n(s_{ref})$。解决平均奖励MDP中值函数漂移问题。

### 13. 练习题
**Q1**：折扣VI和相对VI分别适用于什么场景？
**A1**：折扣VI适合有终止或远期不重要的问题（$\gamma<1$）。相对VI适合持续运行的系统（库存、队列控制），关注长期平均表现而非总折扣。
