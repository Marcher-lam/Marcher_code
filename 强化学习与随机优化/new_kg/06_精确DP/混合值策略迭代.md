# 混合值-策略迭代(Hybrid Value-Policy Iteration) 学习文档

> 结合值迭代和策略迭代的优点——先做几步值迭代改善值函数，再做策略改进，收敛更快。

> 来源线索：本节内容根据原书中关于"Hybrid Value-Policy Iteration"的相关章节(Ch 14.7)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：混合方法交替进行值迭代步和策略改进步，比纯值迭代收敛更快，比纯策略迭代每步计算量更小。

## 2. 核心原理

**纯值迭代**：每步对所有状态更新 $V(s) = \max_a Q(s,a)$
- 优点：每步简单
- 缺点：收敛慢（每步只做Bellman备份）

**纯策略迭代**：评估当前策略 → 改进策略
- 优点：策略层面的收敛快
- 缺点：策略评估步需要求解线性方程组（计算量大）

**混合方法**：
1. 从当前策略和值函数出发
2. 做 $k$ 步值迭代（而非完全评估）
3. 基于改善后的值函数做策略改进
4. 重复

$$\text{Repeat: } \begin{cases} \text{做 } k \text{ 步值迭代} \\ \pi(s) \leftarrow \arg\max_a Q(s,a) \end{cases}$$

$k$ 的选择是关键：$k$ 大则接近策略迭代，$k$ 小则接近值迭代。

## 3. Python 实现

```python
import numpy as np

def hybrid_value_policy_iteration(P, R, gamma=0.9, k=5, max_iter=100):
    """混合值-策略迭代"""
    n_states, n_actions = R.shape
    V = np.zeros(n_states)
    policy = np.zeros(n_states, dtype=int)

    for iteration in range(max_iter):
        # 1. 做k步值迭代
        for _ in range(k):
            V_new = np.zeros(n_states)
            for s in range(n_states):
                # 按当前策略计算
                a = policy[s]
                V_new[s] = R[s, a] + gamma * P[a][s] @ V
            V = V_new

        # 2. 策略改进
        policy_stable = True
        for s in range(n_states):
            Q = np.array([R[s, a] + gamma * P[a][s] @ V for a in range(n_actions)])
            best_a = np.argmax(Q)
            if best_a != policy[s]:
                policy_stable = True  # 标记有变化
                policy[s] = best_a

        if policy_stable:
            break

    return V, policy

# 示例：2状态2动作
P = [np.array([[0.7, 0.3], [0.4, 0.6]]),   # 动作0
     np.array([[0.5, 0.5], [0.3, 0.7]])]    # 动作1
R = np.array([[1.0, 2.0], [3.0, 0.5]])      # 奖励矩阵

V, policy = hybrid_value_policy_iteration(P, R, k=3)
print(f"值函数: {np.round(V, 3)}")
print(f"策略: {policy}")
```

## 4. 与其他方法的关系

- **值迭代**：$k=1$ 的特殊情况
- **策略迭代**：$k=\infty$（完全评估）的特殊情况
- **修改的策略迭代**：类似思想的不同表述
