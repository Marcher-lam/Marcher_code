# 策略梯度定理(Policy Gradient Theorem) 学习文档

> 策略梯度定理将策略优化转化为梯度上升问题，是REINFORCE、Actor-Critic、PPO等现代RL算法的理论基础。

> 来源线索：本节内容根据原书中关于"The Policy Gradient Theorem"的相关章节(Ch 12.8)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：策略梯度定理证明了目标函数对策略参数的梯度可以表示为期望形式，使得我们可以直接用采样数据通过梯度上升来优化策略。

**直觉类比**：想象你在练习投篮。每次投篮后，你记下当时的姿势（策略参数）和是否投中（奖励）。如果投中了，你就"稍微多做一点"那个姿势；如果没中，就"少做一点"。随着大量练习，你的姿势逐步趋近最优。策略梯度定理就是这种"好结果多做一些，坏结果少做一些"的数学表达。

**历史背景**：策略梯度定理由Sutton et al. (1999)和Silver et al.等独立发展。在此之前，RL主要依赖值函数方法（TD、Q-Learning）。策略梯度方法的优势在于可以自然处理连续动作空间和随机策略。Williams (1992)提出的REINFORCE是最早的策略梯度算法。

**算法定位**：策略优化/梯度方法。在原书四类策略中属于"策略函数近似（PFA）"的核心理论。

**前置知识**：MDP、梯度下降、概率论（期望、对数导数）、神经网络基础。

## 2. 核心原理

**核心思想**：与其间接地通过值函数推导策略（如Q-Learning），不如直接参数化策略$\pi_\theta(a|s)$并用梯度上升优化目标函数。策略梯度定理告诉我们，虽然目标函数$J(\theta) = \mathbb{E}[R|\pi_\theta]$看起来很难求梯度，但它可以表示为一个可以用采样估计的期望。

**工作流程**：

1. 收集一批轨迹（状态-动作-奖励序列）
2. 计算每个动作的对数概率$\log \pi_\theta(a|s)$
3. 用回报（或优势函数）加权对数概率
4. 求平均得到梯度估计
5. 沿梯度方向更新参数$\theta$
6. 重复

**关键概念**：

- **策略参数化**：$\pi_\theta(a|s)$用一个参数为$\theta$的函数表示策略
- **对数概率技巧**：$\nabla_\theta \log \pi_\theta(a|s)$是策略梯度的核心
- **REINFORCE**：用蒙特卡洛回报作为权重的策略梯度
- **基线（Baseline）**：减去一个基线值降低方差，不引入偏差

```
策略参数 θ → π_θ(a|s) → 采样轨迹 → 计算回报G
                                        ↓
                    θ ← θ + α · G · ∇log π_θ(a|s)
                         梯度上升更新参数
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $\pi_\theta(a\|s)$ | 参数化策略 |
| $J(\theta)$ | 目标函数（期望累积奖励） |
| $\tau$ | 一条轨迹$(s_0,a_0,r_1,...,s_T)$ |
| $G_t$ | 从时刻$t$的累积回报 |
| $A(s,a)$ | 优势函数 |

### 目标函数

策略梯度优化的目标函数（起始状态分布下的期望回报）：

$$J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}\left[\sum_{t=0}^{T-1} \gamma^t R_{t+1}\right]$$

### 策略梯度定理

**核心结果**：

$$\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\left[\sum_{t=0}^{T-1} \nabla_\theta \log \pi_\theta(A_t|S_t) \cdot G_t\right]$$

即：目标函数的梯度等于"对数策略概率的梯度"乘以"回报"的期望。

### 推导概要（对数导数技巧）

关键步骤：

$$\nabla_\theta J(\theta) = \nabla_\theta \mathbb{E}_{\pi_\theta}[R(\tau)] = \nabla_\theta \sum_\tau P(\tau|\theta) R(\tau)$$

$$= \sum_\tau \nabla_\theta P(\tau|\theta) R(\tau)$$

利用恒等式$\nabla_\theta P = P \cdot \nabla_\theta \log P$：

$$= \sum_\tau P(\tau|\theta) \nabla_\theta \log P(\tau|\theta) R(\tau) = \mathbb{E}_{\pi_\theta}[\nabla_\theta \log P(\tau|\theta) R(\tau)]$$

由于$\log P(\tau|\theta) = \sum_t \log \pi_\theta(A_t|S_t) + \text{const}$，最终得到策略梯度定理。

### REINFORCE算法

直接使用策略梯度定理的蒙特卡洛估计：

$$\theta \leftarrow \theta + \alpha \sum_{t} G_t \nabla_\theta \log \pi_\theta(A_t|S_t)$$

### 带基线的REINFORCE

引入基线$b(S_t)$降低方差：

$$\theta \leftarrow \theta + \alpha \sum_{t} (G_t - b(S_t)) \nabla_\theta \log \pi_\theta(A_t|S_t)$$

减去基线不改变梯度的期望（因为$\mathbb{E}[b(S_t)\nabla \log \pi] = 0$），但可以降低方差。通常选择$b(S_t) = V(S_t)$（值函数估计），此时$G_t - b(S_t)$就是优势函数的蒙特卡洛估计。

## 4. 训练过程讲解

### 参数初始化
- 策略网络：Xavier/He初始化
- 输出层：最后一层偏置初始化为0

### 迭代过程
1. 用当前策略$\pi_\theta$收集一批轨迹
2. 对每条轨迹计算每个时间步的回报$G_t$
3. 计算策略梯度估计
4. 用梯度上升更新$\theta$
5. 重复

### 收敛条件
- 累积奖励达到目标
- 策略在评估中表现稳定
- 或最大训练轮数

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $\alpha$ | 学习率 | [1e-4, 1e-2] | 1e-3 |
| $\gamma$ | 折扣因子 | [0.99, 0.999] | 0.99 |
| batch_size | 轨迹数/每更新 | [1, 50] | 10 |

## 5. 应用场景

### 1. 连续控制
为什么适合：策略直接输出连续动作值，不需要离散化。

### 2. 随机策略需求
为什么适合：某些问题需要内在随机性（如石头剪刀布），策略梯度可以学习最优随机策略。

### 3. 大动作空间
为什么适合：不需要遍历所有动作，直接参数化动作分布。

## 6. 优缺点分析

### 优点
1. **连续动作空间**：天然支持连续动作
2. **随机策略**：可以学习最优随机策略
3. **理论保证**：收敛到局部最优
4. **无需max操作**：不需要对动作空间做argmax

### 缺点
1. **高方差**：蒙特卡洛估计方差大
2. **样本效率低**：需要大量轨迹
3. **仅收敛到局部最优**：不保证全局最优
4. **在线学习**：通常需要当前策略收集数据

### 算法对比

| 特性 | 策略梯度 | Q-Learning | Actor-Critic |
|------|---------|------------|-------------|
| 动作空间 | 连续/离散 | 仅离散 | 连续/离散 |
| 策略类型 | 随机 | 确定性 | 随机 |
| 方差 | 高 | 低 | 中 |
| 样本效率 | 低 | 高 | 中 |

## 7. 调库实现

```python
"""
使用PyTorch实现REINFORCE策略梯度
场景：CartPole-v1
"""
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np
import gymnasium as gym

class PolicyNetwork(nn.Module):
    def __init__(self, n_obs, n_act, hidden=128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_obs, hidden), nn.ReLU(),
            nn.Linear(hidden, n_act), nn.Softmax(dim=-1)
        )
    def forward(self, x):
        return self.net(x)

def reinforce(env_name='CartPole-v1', n_episodes=2000, lr=1e-2, gamma=0.99):
    env = gym.make(env_name)
    n_obs = env.observation_space.shape[0]
    n_act = env.action_space.n
    policy = PolicyNetwork(n_obs, n_act)
    optimizer = optim.Adam(policy.parameters(), lr=lr)
    rewards_history = []

    for ep in range(n_episodes):
        state, _ = env.reset()
        log_probs, rewards = [], []

        while True:
            probs = policy(torch.FloatTensor(state))
            dist = torch.distributions.Categorical(probs)
            action = dist.sample()
            log_probs.append(dist.log_prob(action))
            state, reward, terminated, truncated, _ = env.step(action.item())
            rewards.append(reward)
            if terminated or truncated:
                break

        # 计算折扣回报
        G = 0
        returns = []
        for r in reversed(rewards):
            G = r + gamma * G
            returns.insert(0, G)
        returns = torch.FloatTensor(returns)

        # 策略梯度损失
        loss = -torch.stack([lp * G for lp, G in zip(log_probs, returns)]).sum()
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        ep_reward = sum(rewards)
        rewards_history.append(ep_reward)
        if (ep+1) % 200 == 0:
            print(f"Episode {ep+1}, 平均奖励: {np.mean(rewards_history[-100:]):.1f}")

    return rewards_history

# rewards = reinforce()
```

## 8. 手工代码实现

```python
"""
从零实现REINFORCE策略梯度算法
纯NumPy实现，自定义环境
"""
import numpy as np

class PolicyGradientAgent:
    """REINFORCE策略梯度智能体"""

    def __init__(self, n_states, n_actions, lr=0.01, gamma=0.99):
        self.n_states = n_states
        self.n_actions = n_actions
        self.lr = lr
        self.gamma = gamma
        # 线性策略参数
        self.theta = np.random.randn(n_states, n_actions) * 0.01

    def softmax(self, x):
        e = np.exp(x - np.max(x))
        return e / e.sum()

    def act(self, state):
        """根据策略选择动作"""
        logits = self.theta.T @ state
        probs = self.softmax(logits)
        action = np.random.choice(self.n_actions, p=probs)
        return action, probs

    def compute_returns(self, rewards):
        """计算折扣回报"""
        G = 0
        returns = []
        for r in reversed(rewards):
            G = r + self.gamma * G
            returns.insert(0, G)
        return np.array(returns)

    def update(self, states, actions, rewards):
        """REINFORCE策略梯度更新"""
        returns = self.compute_returns(rewards)
        # 标准化回报（降低方差）
        returns = (returns - returns.mean()) / (returns.std() + 1e-8)

        for t in range(len(states)):
            state = states[t]
            action = actions[t]
            G_t = returns[t]

            # 计算梯度: ∇log π(a|s) = (e_a - π) ⊗ s
            logits = self.theta.T @ state
            probs = self.softmax(logits)
            grad = np.outer(state, np.eye(self.n_actions)[action] - probs)

            # 策略梯度更新: θ ← θ + α · G · ∇log π
            self.theta += self.lr * G_t * grad


# ========== 测试 ==========
if __name__ == "__main__":
    np.random.seed(42)
    n_states, n_actions = 4, 2
    agent = PolicyGradientAgent(n_states, n_actions, lr=0.01, gamma=0.95)

    # 简单模拟训练
    for ep in range(500):
        states, actions, rewards = [], [], []
        state = np.random.randn(n_states)
        for step in range(20):
            action, probs = agent.act(state)
            reward = 1.0 if action == np.argmax(state) else -0.1
            states.append(state)
            actions.append(action)
            rewards.append(reward)
            state = np.random.randn(n_states)
        agent.update(states, actions, rewards)

    print("策略梯度训练完成")
    test_state = np.array([1.0, -1.0, 0.5, 0.0])
    logits = agent.theta.T @ test_state
    print(f"测试状态动作概率: {agent.softmax(logits).round(3)}")
```

"""策略评估"""
def evaluate_policy(policy, env, n_episodes=100):
    rewards = []
    for _ in range(n_episodes):
        state, _ = env.reset()
        done, ep_r = False, 0
        while not done:
            probs = policy(torch.FloatTensor(state))
            action = torch.argmax(probs).item()
            state, r, terminated, truncated, _ = env.step(action)
            done = terminated or truncated
            ep_r += r
        rewards.append(ep_r)
    return np.mean(rewards), np.std(rewards)

## 11. 常见问题与易错点

1. **高方差导致训练不稳定**
   - 现象：奖励曲线剧烈波动
   - 原因：蒙特卡洛回报方差高
   - 解决方案：引入基线（Critic），使用GAE（广义优势估计）

2. **学习率过大**
   - 现象：策略退化到确定性，失去探索能力
   - 原因：参数更新步长太大
   - 解决方案：降低学习率，或使用PPO的裁剪机制

3. **奖励尺度问题**
   - 现象：梯度太大或太小
   - 原因：回报绝对值影响梯度幅度
   - 解决方案：标准化回报，或使用优势函数

## 12. 学习总结

策略梯度定理的核心贡献是：**将策略优化问题转化为可以用采样数据估计的梯度上升问题**。公式$\nabla_\theta J = \mathbb{E}[G_t \nabla_\theta \log \pi_\theta(A_t|S_t)]$揭示了"好结果多做一些"的数学本质。

**关键公式**：
1. 策略梯度定理：$\nabla_\theta J(\theta) = \mathbb{E}[\sum_t G_t \nabla_\theta \log \pi_\theta(A_t|S_t)]$
2. REINFORCE更新：$\theta \leftarrow \theta + \alpha G_t \nabla_\theta \log \pi_\theta(A_t|S_t)$
3. 带基线：$\theta \leftarrow \theta + \alpha (G_t - b(S_t)) \nabla_\theta \log \pi_\theta(A_t|S_t)$

在原书框架中，策略梯度是"策略函数近似（PFA）"类方法的核心理论基础（Ch 12.8），直接启发了Actor-Critic（用Critic提供基线）、PPO（裁剪目标函数）等算法。

## 13. 练习题与思考题

### 基础题

**题目1**：对数导数技巧$\nabla_\theta \log P(x|\theta) = \frac{\nabla_\theta P(x|\theta)}{P(x|\theta)}$在策略梯度中的作用是什么？

**参考答案**：
作用是将"梯度"转化为"期望"形式。原问题$\nabla_\theta \sum_x P(x|\theta)R(x)$中梯度在求和外面，难以用采样估计。通过对数导数技巧，写成$\sum_x P(x|\theta)[\nabla_\theta \log P(x|\theta)]R(x) = \mathbb{E}[\nabla_\theta \log P(X|\theta) R(X)]$，可以用蒙特卡洛采样估计。

### 进阶题

**题目2**：为什么减去基线$b(S_t)$不改变策略梯度的期望？

**参考答案**：
需要证明$\mathbb{E}[b(S_t) \nabla_\theta \log \pi_\theta(A_t|S_t)] = 0$。

$$\mathbb{E}[b(S_t)\nabla \log \pi(a|S_t)] = \sum_s d(s) b(s) \sum_a \pi(a|s) \nabla \log \pi(a|s)$$

其中$\sum_a \pi(a|s) \nabla \log \pi(a|s) = \sum_a \pi(a|s) \frac{\nabla \pi(a|s)}{\pi(a|s)} = \sum_a \nabla \pi(a|s) = \nabla \sum_a \pi(a|s) = \nabla 1 = 0$

因此基线项期望为0，不影响梯度的无偏性。

### 开放思考题

**题目3**：策略梯度方法只能收敛到局部最优。在什么情况下这可能是一个严重问题？有什么方法可以缓解？

**参考答案方向**：
- 严重问题：(1)存在多个局部最优且差异大；(2)策略参数化不够灵活无法表示最优策略
- 缓解方法：(1)多次随机初始化取最好结果；(2)使用熵正则化鼓励探索；(3)策略参数化选择（如神经网络容量足够大）
