# 分段线性近似(Piecewise Linear Approximation) 学习文档

> 用有限个线性段近似非线性函数，在资源分配中保持优化结构。

> 来源线索：本节内容根据原书中关于"Piecewise Linear Approximation"的相关章节(Ch 18.5)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：用$k$个线性段近似非线性值函数，每段有独立的斜率和截距，保持凸/凹结构使嵌入优化问题时仍为线性规划。

**直觉类比**：你要画一条平滑曲线，但只被允许用直尺。于是你画很多短线段首尾相连，形成折线来逼近曲线。每个线段的斜率可以不同，但相邻段在断点处连续。这就是分段线性近似。

**历史背景**：分段线性近似在运筹学中有悠久历史。它在保持问题线性结构的同时提供非线性函数的近似能力，是混合整数规划和资源分配的核心工具。原书Ch 18.5将其作为CAVE算法的推广——CAVE是凹分段线性近似的特例。

**算法定位**：值函数近似/函数逼近。分段线性是介于查表法（精确但不可扩展）和参数化方法（灵活但不保证结构）之间的折中方案。

**前置知识**：
- 线性规划基础
- CAVE算法
- 凸/凹函数性质
- Python + NumPy

## 2. 核心原理

**核心思想**：将值函数$V(R)$用有限个线性段近似。每个线性段有斜率$\beta_j$和截距$c_j$。凸形式取所有线性段的最大值，凹形式取最小值。

**工作流程**：

1. 设定断点$R_0 < R_1 < ... < R_K$
2. 为每个区间$[R_j, R_{j+1})$分配斜率$\beta_j$
3. 评估：$V(R) = \sum_{j=0}^{k-1}\beta_j(R_{j+1}-R_j) + \beta_k(R - R_k)$（对于$R \in [R_k, R_{k+1})$）
4. 更新：通过采样调整斜率

**关键概念**：

- **断点(Breakpoints)**：线性段之间的连接点
- **凸形式**：$\bar{V}(R) = \max_j\{\beta_j R + c_j\}$，取所有线性段的最大值
- **凹形式**：$\bar{V}(R) = \min_j\{\beta_j R + c_j\}$，资源分配问题常用
- **与LP的结合**：分段线性目标可转化为LP，保持可解性

**几何直观**：

```
值函数 V(R)
    │    ╱── 斜率β₁
    │   ╱
    │  ╱ ── 斜率β₂（较小）
    │ ╱
    │╱  ── 斜率β₃（最小）
    └────────── R
    R₀  R₁  R₂  R₃
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $R$ | 连续变量（如资源水平） |
| $V(R)$ | 真实值函数 |
| $\bar{V}(R)$ | 分段线性近似 |
| $R_j$ | 第$j$个断点 |
| $\beta_j$ | 第$j$段的斜率（边际价值） |
| $c_j$ | 第$j$段的截距 |
| $K$ | 线性段数量 |

### 分段线性表示

对于$R \in [R_k, R_{k+1})$：

$$\bar{V}(R) = \bar{V}(R_k) + \beta_k(R - R_k)$$

其中$\bar{V}(R_k) = \sum_{j=0}^{k-1}\beta_j(R_{j+1} - R_j)$

### 凸形式（max-affine）

$$\bar{V}(R) = \max_{j=0,...,K-1}\{\beta_j R + c_j\}$$

凸性自动满足（凸函数的max仍是凸函数）。

### 凹形式（min-affine）

$$\bar{V}(R) = \min_{j=0,...,K-1}\{\beta_j R + c_j\}$$

适用于资源分配中边际价值递减的问题。

### 嵌入LP

将分段线性目标嵌入线性规划：

$$\max_{R, y} \sum_{j=0}^{K-1}\beta_j y_j \quad \text{s.t. } \sum_j y_j = R, \quad 0 \leq y_j \leq R_{j+1}-R_j$$

这保证了线性规划结构不被破坏。

### 误差分析

用$K$个等距线性段近似Lipschitz连续函数$f$（Lipschitz常数$L$）：

$$\max_R |f(R) - \bar{V}(R)| \leq \frac{L \cdot \Delta R}{2}$$

其中$\Delta R = (R_{max} - R_{min})/K$是段宽。误差以$O(1/K)$速度递减。

## 4. 训练过程讲解

### 参数初始化
- 断点：等距分布或按问题重要性分布
- 斜率：初始化为0或从少量采样估计

### 迭代更新
1. 在断点处采样值函数
2. 用相邻断点的差分估计斜率：$\beta_j \approx (\bar{V}(R_{j+1}) - \bar{V}(R_j))/(R_{j+1}-R_j)$
3. 可选：投影到凹函数空间（确保斜率递减）

### 收敛条件
- 斜率变化量小于阈值
- 或达到最大迭代次数

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $K$ | 线性段数 | [5, 50] | 10 |
| 断点分布 | 等距/自适应 | — | 等距 |
| 更新步长$\alpha$ | 斜率更新率 | [0.01, 0.2] | 0.1 |

## 5. 应用场景

### 1. 资源分配问题
为什么适合：值函数关于资源水平的边际价值递减。分段线性保持凹结构，嵌入LP后仍可高效求解。

### 2. 凸优化近似
为什么适合：将非线性目标近似为分段线性，问题仍为LP/SOCP，可用商业求解器高效求解。

### 3. 能源系统调度
为什么适合：储能价值函数非线性但可用分段线性近似，保持问题的可解性。

### 4. 网络流问题
为什么适合：分段线性成本函数在网络流优化中广泛应用。

### 不适用场景
- 需要高精度近似（段数过多时不如连续参数化）
- 值函数有剧烈振荡（段数不够）
- 高维输入（需要张量积，维度灾难）

## 6. 优缺点分析

### 优点
1. **保持LP结构**：嵌入优化问题后仍是线性规划（成立条件：目标或约束的分段线性化）
2. **可控精度**：增加段数可任意提高精度
3. **计算高效**：评估和更新都是$O(K)$
4. **可解释性强**：每段的斜率直接对应边际价值

### 缺点
1. **高维扩展困难**：多变量的分段线性需要张量积，维度灾难
2. **断点选择**：固定断点可能错过关键区域
3. **连续性限制**：标准形式只保证连续，不保证光滑
4. **精度有限**：比神经网络等高维函数近似器精度低

### 算法对比

| 特性 | 分段线性 | CAVE | 神经网络 | 核方法 |
|------|---------|------|---------|-------|
| LP兼容 | 是 | 是 | 否 | 否 |
| 凸/凹保证 | 可选 | 是 | 否 | 否 |
| 精度 | 中 | 中 | 高 | 高 |
| 高维扩展 | 差 | 差 | 好 | 中 |
| 可解释性 | 高 | 高 | 低 | 低 |

## 7. 调库实现

```python
"""
分段线性近似：使用scipy.interpolate
"""
import numpy as np
from scipy.interpolate import interp1d

def piecewise_linear_fit(x_data, y_data, n_segments=10):
    """用分段线性插值拟合数据"""
    # 选择断点
    x_sorted = np.sort(x_data)
    breakpoints = np.linspace(x_sorted[0], x_sorted[-1], n_segments + 1)
    # 在断点处取平均y值
    bp_y = []
    for i in range(n_segments):
        mask = (x_data >= breakpoints[i]) & (x_data < breakpoints[i+1])
        if mask.any():
            bp_y.append(np.mean(y_data[mask]))
        else:
            bp_y.append(0)
    bp_y.append(bp_y[-1])

    # 分段线性插值
    f = interp1d(breakpoints, bp_y, kind='linear')
    return f, breakpoints, bp_y


if __name__ == "__main__":
    np.random.seed(42)
    x = np.random.uniform(0, 50, 200)
    y = np.maximum(0, 5*x - 0.05*x**2) + np.random.randn(200)*5
    f, bp, bp_y = piecewise_linear_fit(x, y, n_segments=5)
    for r in [0, 10, 20, 30, 40, 50]:
        print(f"V({r}) = {f(r):.1f}")
```

## 8. 手工代码实现

```python
"""
从零实现分段线性近似（纯NumPy）
支持凸/凹约束
"""
import numpy as np

class PiecewiseLinear:
    """分段线性值函数近似"""

    def __init__(self, breakpoints, slopes=None):
        self.bp = np.sort(np.array(breakpoints, dtype=float))
        self.K = len(self.bp) - 1
        if slopes is None:
            self.slopes = np.ones(self.K) * 5.0
        else:
            self.slopes = np.array(slopes, dtype=float)
        # 预计算断点处的累积值
        self._update_cumulative()

    def _update_cumulative(self):
        """更新断点处的累积值函数"""
        self.cumulative = np.zeros(len(self.bp))
        for j in range(self.K):
            self.cumulative[j+1] = (self.cumulative[j] +
                self.slopes[j] * (self.bp[j+1] - self.bp[j]))

    def value(self, R):
        """评估分段线性值函数"""
        R = np.clip(R, self.bp[0], self.bp[-1])
        for j in range(self.K):
            if R <= self.bp[j+1]:
                return self.cumulative[j] + self.slopes[j] * (R - self.bp[j])
        return self.cumulative[-1]

    def marginal(self, R):
        """获取边际价值（斜率）"""
        for j in range(self.K):
            if R < self.bp[j+1]:
                return self.slopes[j]
        return self.slopes[-1]

    def update_slopes(self, samples, alpha=0.1):
        """从采样数据更新斜率"""
        for j in range(self.K):
            mask = (samples[:, 0] >= self.bp[j]) & (samples[:, 0] < self.bp[j+1])
            if mask.any():
                # 用线性回归拟合该段
                x_seg = samples[mask, 0] - self.bp[j]
                y_seg = samples[mask, 1]
                if len(x_seg) > 1:
                    new_slope = np.polyfit(x_seg, y_seg, 1)[0]
                    self.slopes[j] = (1-alpha)*self.slopes[j] + alpha*new_slope
        self._update_cumulative()

    def enforce_concavity(self):
        """投影到凹函数空间（斜率递减）"""
        changed = True
        while changed:
            changed = False
            for j in range(self.K - 1):
                if self.slopes[j] < self.slopes[j+1]:
                    avg = (self.slopes[j] + self.slopes[j+1]) / 2
                    self.slopes[j] = avg + 1e-8
                    self.slopes[j+1] = avg - 1e-8
                    changed = True
        self._update_cumulative()

    def to_lp_coefficients(self):
        """导出LP可用的系数"""
        return {
            'breakpoints': self.bp.copy(),
            'slopes': self.slopes.copy(),
            'cumulative': self.cumulative.copy()
        }


# ========== 测试 ==========
if __name__ == "__main__":
    np.random.seed(42)
    bp = [0, 10, 20, 30, 40, 50]
    true_slopes = [5.0, 3.5, 2.0, 1.0, 0.3]  # 递减（凹）

    pla = PiecewiseLinear(bp, slopes=true_slopes)
    print("分段线性近似:")
    for r in [0, 10, 20, 30, 40, 50]:
        print(f"  V({r}) = {pla.value(r):.1f}, 边际={pla.marginal(r):.1f}")

    # 测试凹性约束
    pla.slopes[2] = 6.0  # 人为破坏凹性
    print(f"\n破坏凹性后斜率: {pla.slopes}")
    pla.enforce_concavity()
    print(f"修复凹性后斜率: {pla.slopes.round(3)}")
```

"""分段线性可视化"""
import matplotlib.pyplot as plt
import numpy as np

def visualize_piecewise_linear(pla_obj, true_fn=None):
    """可视化分段线性近似"""
    fig, axes = plt.subplots(1, 2, figsize=(14, 5))
    r_range = np.linspace(pla_obj.bp[0], pla_obj.bp[-1], 200)
    values = [pla_obj.value(r) for r in r_range]

    # 1. 值函数
    axes[0].plot(r_range, values, 'b-', linewidth=2, label='分段线性近似')
    if true_fn:
        axes[0].plot(r_range, [true_fn(r) for r in r_range],
                    'r--', label='真实函数')

## 10. 模型评估

```python
"""分段线性近似评估"""
import numpy as np

def evaluate_pla(pla_obj, true_fn, n_test=100):
    """评估分段线性近似的精度"""
    test_points = np.linspace(pla_obj.bp[0], pla_obj.bp[-1], n_test)
    errors = [abs(pla_obj.value(r) - true_fn(r)) for r in test_points]
    max_err = np.max(errors)
    mae = np.mean(errors)
    print(f"分段线性近似评估（{n_test}测试点，{pla_obj.K}段）：")
    print(f"  MAE: {mae:.3f}")
    print(f"  最大误差: {max_err:.3f}")
    is_concave = all(pla_obj.slopes[j] >= pla_obj.slopes[j+1]
                     for j in range(pla_obj.K-1))
    print(f"  凹性: {'满足' if is_concave else '不满足'}")
    return mae
```

## 11. 常见问题与易错点

### 数据层面

1. **断点位置不当**
   - 现象：某些区域近似误差大
   - 原因：等距断点在函数变化快的区域覆盖不足
   - 解决方案：自适应断点选择（在误差大的区域加密）

2. **采样不均匀**
   - 现象：某些段的斜率估计不准
   - 原因：采样集中在部分区域
   - 解决方案：分层采样确保每段有足够样本

### 模型层面

3. **凸/凹方向混淆**
   - 现象：近似结果与预期相反
   - 原因：资源分配用凹形式（min-affine），错误使用了凸形式（max-affine）
   - 解决方案：明确问题性质——边际价值递减用凹，递增用凸

4. **与神经网络的选择困难**
   - 现象：不确定用分段线性还是神经网络
   - 原因：两者都能近似非线性函数
   - 解决方案：需要嵌入LP/整数规划时用分段线性；纯预测用神经网络

### 调参层面

5. **段数$K$选择**
   - 现象：$K$太小欠拟合，$K$太大过拟合
   - 解决方案：从$K=5$开始，逐步增加直到误差不再显著下降

## 12. 学习总结

分段线性近似用$K$个线性段拟合非线性函数：$\bar{V}(R) = \max_j\{\beta_j R + c_j\}$（凸）或$\min_j$（凹）。核心优势是保持LP结构——嵌入优化问题后仍是线性规划。

**关键公式**：
1. 值函数：$V(R) = V(R_k) + \beta_k(R - R_k)$，对于$R \in [R_k, R_{k+1})$
2. 凸形式：$\bar{V}(R) = \max_j\{\beta_j R + c_j\}$
3. 误差界：$O(L \cdot \Delta R)$，$L$是Lipschitz常数

分段线性是CAVE的推广形式，在资源分配和数学规划中广泛应用。

## 13. 练习题与思考题

### 基础题

**题目1**：为什么分段线性近似在优化中比神经网络方便？

**参考答案**：分段线性近似保持凸/凹结构，嵌入优化问题后仍为LP（线性规划），可被CPLEX/Gurobi等商业求解器高效求解。神经网络引入非凸结构，嵌入优化问题时需要启发式或分支定界法，计算量大且不保证最优。

### 进阶题

**题目2**：给定断点$(0, 10, 20, 30)$和斜率$(4, 2, 1)$，计算$V(5)$、$V(15)$、$V(25)$。验证凹性。

**参考答案**：
- $V(0) = 0$
- $V(10) = 0 + 4 \times 10 = 40$
- $V(20) = 40 + 2 \times 10 = 60$
- $V(30) = 60 + 1 \times 10 = 70$
- $V(5) = 0 + 4 \times 5 = 20$
- $V(15) = 40 + 2 \times 5 = 50$
- $V(25) = 60 + 1 \times 5 = 65$
- 凹性验证：斜率$4 \geq 2 \geq 1$，满足递减，凹性成立。

### 开放思考题

**题目3**：如何将分段线性从一维扩展到多维？遇到什么困难？

**参考答案方向**：
- 一维分段线性用$K$个断点和$K$个斜率
- 二维需要$K_1 \times K_2$个平面片段（张量积），参数量指数增长
- 高维时参数量不可控（维度灾难）
- 实际解决方案：(1)可分近似（各维度独立）；(2)低秩近似；(3)稀疏网格
- 这也是为什么高维问题更常用神经网络——参数量与维度线性相关而非指数
