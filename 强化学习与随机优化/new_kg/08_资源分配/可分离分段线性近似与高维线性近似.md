# 可分离分段线性近似与高维线性近似 学习文档

> 用分段线性近似值函数的两种方式——可分离（独立）和不可分离（Benders）。

> 来源线索：Ch 18.4-18.5 "Separable Piecewise Linear" 和 "Linear Approximations for High-Dimensional"

## 1. 基础认知

**一句话定义**：可分离近似假设值函数可分解为各资源独立贡献之和；高维线性近似用线性模型处理大量资源维度。

## 2. 核心原理

**可分离近似**：
$$\bar{V}(R) \approx \sum_r \bar{V}_r(R_r)$$

每个 $\bar{V}_r$ 是独立的分段线性凹函数。计算简单但忽略资源间交互。

**高维线性近似**：
$$\bar{V}(R|\theta) = \theta^T R$$

线性近似在高维时简单有效，可用递归最小二乘在线更新参数。

## 3. Python 实现

```python
import numpy as np

def separable_pwla(n_resources=3, n_levels=20):
    """可分离分段线性近似"""
    piecewise = [np.linspace(5, 0.5, n_levels) for _ in range(n_resources)]

    def value(R):
        total = 0
        for r in range(n_resources):
            level = min(int(R[r]), n_levels-1)
            if R[r] >= n_levels:
                total += sum(piecewise[r])
            else:
                frac = R[r] - level
                total += sum(piecewise[r][:level]) + frac * piecewise[r][level]
        return total

    R = np.array([5.3, 12.0, 3.7])
    print(f"资源量 {R} → 值函数 {value(R):.2f}")

separable_pwla()
```
