# 平整算法(Leveling Algorithm) 学习文档

> 将波动值函数"拉平"为单调递减的阶梯函数，是CAVE的简化版。

> 来源线索：本节内容根据原书中关于"Leveling Algorithm"的相关章节(Ch 18.3.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：平整算法将估计的值函数平滑为单调阶梯形，消除噪声导致的非单调波动，是CAVE算法的简化版本。

**直觉类比**：你画了一条应该从左到右递减的曲线，但手抖导致有些地方高有些地方低。平整算法就像用一把尺子，把违反递减规则的地方"压平"——如果相邻两点右边比左边高，就取平均，让它们一样高。

**历史背景**：平整算法是ADP中处理值函数估计噪声的基本后处理方法。原书Ch 18.3.1将其作为CAVE算法的前置步骤——先平整再拟合凹函数。

**算法定位**：值函数近似/后处理。平整是保证值函数结构性质（单调性）的简单而有效的方法。

**前置知识**：
- 值函数近似（VFA）
- CAVE算法
- 基础Python编程

## 2. 核心原理

**核心思想**：在资源分配问题中，值函数$V(R)$关于资源水平$R$通常满足单调性（边际价值递减）。但蒙特卡洛估计引入噪声，破坏单调性。平整算法扫描估计值，将违反单调性的相邻段平均化。

**工作流程**：

1. 输入：含噪声的值函数估计$\bar{v}(R_0), \bar{v}(R_1), ..., \bar{v}(R_K)$
2. 从左到右扫描
3. 若$\bar{v}(R_{i+1}) > \bar{v}(R_i)$（违反递减），找到连续违反的区间$[i, j]$
4. 将$[i, j]$内所有值替换为其平均值
5. 继续扫描直到末尾

**关键概念**：

- **单调递减**：值函数关于资源水平递减，即边际价值非负
- **局部平均**：只在违反单调性的区间内平均，保留整体趋势
- **后处理**：不改变采样/估计过程，只修正输出

**几何直观**：

```
值函数 V(R)
    │╲  ╱╲     含噪声的估计
    │  ╳   ╲
    │╱  ╲   ╲  平整后（单调递减）
    │     ╲  ╲
    └───────── R
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $\bar{v}(R_i)$ | 资源水平$R_i$处的值函数估计 |
| $K$ | 离散化点数 |
| $v^*(R_i)$ | 平整后的值函数 |

### 平整操作

输入序列$\bar{v} = (\bar{v}_0, \bar{v}_1, ..., \bar{v}_K)$，要求单调递减：

$$v_i^* \leq v_{i-1}^*, \quad i = 1, ..., K$$

**算法**：
1. $i = 0$
2. 若$i \geq K$，结束
3. 若$\bar{v}_{i+1} \leq v_i^*$，令$v_{i+1}^* = \bar{v}_{i+1}$，$i = i+1$，转2
4. 否则：找$j \geq i+1$使得$\bar{v}_{j+1} \leq \text{avg}(\bar{v}_i, ..., \bar{v}_j)$
5. 令$v_k^* = \text{avg}(\bar{v}_i, ..., \bar{v}_j)$对所有$k \in [i, j]$
6. $i = j+1$，转2

### 与Pool Adjacent Violators Algorithm (PAVA)的关系

平整算法等价于PAVA——经典的单调回归方法。PAVA保证在最小二乘意义下找到最接近原始数据的单调序列。

### 计算复杂度

$O(K)$——单次扫描即可完成。这是平整算法的最大优势之一。

## 4. 训练过程讲解

### 参数初始化
- 无需额外参数（纯后处理算法）
- 输入：离散化的值函数估计序列

### 迭代过程（单次扫描）
1. 从第一个点开始，向右扫描
2. 遇到违反单调性的点，扩展当前"平台"
3. 平台的平均值超过下一个点时，关闭当前平台
4. 继续直到所有点处理完毕

### 收敛条件
- 单次扫描即完成（算法本身不迭代）
- 多轮应用可进一步平滑（但通常不必要）

### 超参数表

| 参数 | 含义 | 说明 |
|------|------|------|
| 无 | — | 纯后处理，无需调参 |

## 5. 应用场景

### 1. 值函数后处理
为什么适合：ADP中蒙特卡洛估计的值函数通常含噪声。平整消除噪声同时保留单调结构。

### 2. CAVE算法前置
为什么适合：在CAVE拟合凹分段线性之前，先平整采样值保证输入单调。

### 3. 资源分配策略
为什么适合：保证资源分配策略关于资源水平单调递减，避免"多给资源反而更差"的非理性策略。

### 4. 经验分布估计
为什么适合：当估计的CDF不是单调递增时，用平整修正。

### 不适用场景
- 值函数本身不满足单调性
- 需要保留噪声信息（如不确定性量化）
- 非数值型的序列

## 6. 优缺点分析

### 优点
1. **极其简单**：核心代码不到20行
2. **无需参数**：纯后处理，不需要调参
3. **$O(K)$复杂度**：单次扫描，计算高效
4. **保证单调性**：数学上保证输出单调递减

### 缺点
1. **信息损失**：平均化会丢失局部细节
2. **仅处理单调性**：不保证凹性或其他高阶性质
3. **依赖离散化**：只能在离散点上操作
4. **过于简单**：对于复杂结构可能不够

### 算法对比

| 特性 | 平整算法 | CAVE | 移动平均 | 核平滑 |
|------|---------|------|---------|-------|
| 保证单调 | 是 | 是 | 否 | 否 |
| 保证凹性 | 否 | 是 | 否 | 否 |
| 复杂度 | $O(K)$ | $O(K)$ | $O(K)$ | $O(K^2)$ |
| 参数 | 无 | 断点,α | 窗口 | 带宽 |
| 表达力 | 低 | 中 | 中 | 高 |

## 7. 调库实现

"""
平整算法：使用scikit-learn的IsotonicRegression
"""
import numpy as np
from sklearn.isotonic import IsotonicRegression

def leveling_sklearn(values, increasing=False):
    """使用scikit-learn的等渗回归（PAVA）"""
    x = np.arange(len(values))
    ir = IsotonicRegression(increasing=increasing)
    return ir.fit_transform(x, values)

if __name__ == "__main__":
    np.random.seed(42)
    true_v = np.array([10, 8, 6, 5, 3, 2, 1.5, 1, 0.5, 0.2])
    noisy_v = true_v + np.random.randn(10) * 1.5
    leveled = leveling_sklearn(noisy_v, increasing=False)
    print(f"真实值:  {true_v.round(2)}")
    print(f"含噪声:  {noisy_v.round(2)}")
    print(f"平整后:  {leveled.round(2)}")

## 8. 手工代码实现

```python
"""
从零实现平整算法（纯NumPy）
Pool Adjacent Violators Algorithm (PAVA)
"""
import numpy as np

def leveling(values):
    """将值函数平整为单调递减"""
    v = values.copy().astype(float)
    n = len(v)
    i = 0
    while i < n - 1:
        if v[i+1] > v[i]:
            # 找到需要平整的范围
            j = i
            total = v[i]
            count = 1
            while j < n-1 and v[j+1] > v[j]:
                j += 1
                total += v[j]
                count += 1
            avg = total / count
            for k in range(i, j+1):
                v[k] = avg
            # 回溯检查：新平台是否与前一个平台违反单调性
            if i > 0 and v[i] > v[i-1]:
                # 重新处理
                i = max(0, i-1)
                continue
            i = j + 1
        else:
            i += 1
    return v


def leveling_recursive(values):
    """递归版平整算法（更清晰的PAVA实现）"""
    v = values.copy().astype(float)
    n = len(v)
    changed = True
    while changed:
        changed = False
        i = 0
        while i < n - 1:
            if v[i+1] > v[i]:
                avg = (v[i] + v[i+1]) / 2
                v[i] = avg
                v[i+1] = avg
                changed = True
            i += 1
    return v


# ========== 测试 ==========
if __name__ == "__main__":
    np.random.seed(42)
    n = 20
    true_v = np.array([10 - 0.5*i for i in range(n)])
    noisy_v = true_v + np.random.randn(n) * 2

    leveled = leveling(noisy_v)
    leveled_r = leveling_recursive(noisy_v)

    print("=== 平整算法测试 ===")
    print(f"{'索引':>4} {'真实':>6} {'含噪声':>6} {'平整':>6} {'递归版':>6}")
    for i in range(min(10, n)):
        print(f"{i:>4} {true_v[i]:>6.2f} {noisy_v[i]:>6.2f} {leveled[i]:>6.2f} {leveled_r[i]:>6.2f}")

    # 验证单调性
    assert all(leveled[i] >= leveled[i+1] for i in range(n-1)), "非单调！"
    print(f"\n单调性验证: 通过")
    print(f"MSE(含噪声): {np.mean((noisy_v-true_v)**2):.3f}")
    print(f"MSE(平整后): {np.mean((leveled-true_v)**2):.3f}")
```

## 11. 常见问题与易错点

### 数据层面

1. **噪声过大时过度平整**
   - 现象：平整后几乎所有值被压成同一水平
   - 原因：噪声太大导致几乎每个相邻点都违反单调性
   - 解决方案：增加采样量降低噪声，或使用CAVE等更精细的方法

2. **离散化粒度不当**
   - 现象：关键转折点被丢失
   - 原因：离散化太粗
   - 解决方案：在变化快的区域加密采样点

### 模型层面

3. **单调性方向搞反**
   - 现象：结果单调递增而非递减
   - 原因：PAVA参数设置错误
   - 解决方案：确保使用`increasing=False`

4. **仅处理单调性忽略凹性**
   - 现象：平整后的函数单调但非凹
   - 原因：平整只保证单调性，不保证二阶导数条件
   - 解决方案：在平整后再应用CAVE的凹投影

## 12. 学习总结

平整算法是保证值函数单调性的最简单方法：扫描序列，将违反单调性的相邻段平均。等价于经典的PAVA算法，$O(K)$复杂度，无需调参。

**关键操作**：若$v_{i+1} > v_i$，令$v_i = v_{i+1} = (v_i + v_{i+1})/2$

平整是CAVE算法的前置步骤，也是ADP中值函数后处理的基本工具。

## 13. 练习题与思考题

### 基础题

**题目1**：平整和直接取全局均值有什么区别？

**参考答案**：平整只在违反单调性时局部平均，保留整体递减趋势。全局均值将所有点压成同一值，丢失所有结构信息。平整后仍有阶梯形递减，而全局均值是一条水平线。

### 进阶题

**题目2**：给定序列$(5, 3, 4, 2, 1)$，写出平整算法的每一步过程。

**参考答案**：
初始：$(5, 3, 4, 2, 1)$
- $i=1$：$v_2=4 > v_1=3$，违反单调。$j=1$（因为$v_3=2 < \text{avg}(3,4)=3.5$）。平均$(3,4)$→$(3.5, 3.5)$
- 序列变为：$(5, 3.5, 3.5, 2, 1)$
- 检查$i=0$：$v_1=3.5 < v_0=5$，OK
- $i=2$：$v_3=2 < v_2=3.5$，OK
- $i=3$：$v_4=1 < v_3=2$，OK
- 结果：$(5, 3.5, 3.5, 2, 1)$

### 开放思考题

**题目3**：平整算法能否并行化？在大规模问题中如何加速？

**参考答案方向**：
- 标准PAVA是顺序扫描，难以直接并行
- 但可以分段并行：将序列分成$P$段，每段独立平整，然后在边界处合并处理
- 合并策略：比较相邻段边界的值，若违反单调性则合并后重新平整
- 也可以用GPU实现：将PAVA转化为矩阵运算（但通常不值得，因为$O(K)$已经够快）
