# 资源分配中的回归方法(Regression Methods for RA) 学习文档

> 用回归拟合值函数——线性回归、多项式回归在资源分配值函数近似中的应用。

> 来源线索：本节内容根据原书中关于"Regression Methods"的相关章节(Ch 18.4)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：在资源分配问题中，用回归方法从模拟数据拟合值函数 $V(R) \approx \hat{V}(R|\theta)$。

## 2. 核心原理

**方法**：
1. 收集数据：对各种资源水平 $R^n$，计算（或估计）值 $v^n$
2. 拟合模型：$\hat{V}(R|\theta) = \sum_k \theta_k \phi_k(R)$
3. 在ADP迭代中使用近似值函数

**特征选择**：
- 线性特征：$\phi_k(R) = R_k$
- 二次特征：$\phi_k(R) = R_k^2$ 或 $R_i R_j$
- 对数特征：$\phi_k(R) = \log(R_k + 1)$

**与分段线性的对比**：
- 回归：全局拟合，光滑但可能欠拟合
- 分段线性：局部精确，但可能过拟合

## 3. Python 实现

```python
import numpy as np
from sklearn.linear_model import Ridge

def regression_vfa(n_samples=200, n_resources=3):
    """用回归近似值函数"""
    # 生成数据
    R_data = np.random.randint(0, 50, (n_samples, n_resources))
    # 假设真实值函数
    V_true = np.sum(np.sqrt(R_data + 1), axis=1)

    # 特征：线性 + 二次
    features = np.column_stack([
        R_data,
        R_data**2,
        np.sqrt(R_data + 1),
        np.ones(n_samples)
    ])

    # Ridge回归
    model = Ridge(alpha=1.0)
    model.fit(features, V_true)

    # 评估
    V_pred = model.predict(features)
    mse = np.mean((V_pred - V_true)**2)
    print(f"回归MSE: {mse:.4f}")
    print(f"R²: {model.score(features, V_true):.4f}")

regression_vfa()
```

## 4. 与其他方法的关系

- **分段线性近似**：另一种值函数近似方法
- **CAVE算法**：基于边际值的近似
- **递归最小二乘**：在线版本的回归方法
