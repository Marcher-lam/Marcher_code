# 多期资源分配模型(Multiperiod Resource Allocation) 学习文档

> 将单期资源分配扩展到多期——需要考虑未来的资源需求和不确定性。

> 来源线索：本节内容根据原书中关于"A General Multiperiod Resource Allocation Model"的相关章节(Ch 18.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：多期资源分配在时间维度上优化资源的获取、分配和使用，每期决策影响未来的资源可用量。

## 2. 核心原理

**模型要素**：
- **状态** $R_t$：各类资源的当前持有量
- **决策** $x_t$：资源的分配方案
- **外生信息** $W_{t+1}$：随机需求/供应
- **转移函数**：$R_{t+1} = R_t - x_t + W_{t+1}$
- **目标**：最小化总成本或最大化总奖励

**求解方法**：
1. **分段线性近似(VFA)**：CAVE/平整算法
2. **Benders分解**：用切割平面近似值函数
3. **前瞻策略(DLA)**：两阶段/多阶段随机规划
4. **CFA**：参数化的分配规则+调优

**与报童问题的关系**：
- 报童问题是单期资源分配
- 多期扩展需要考虑库存动态
- 可用VFA近似未来价值

## 3. Python 实现

```python
import numpy as np

def multiperiod_allocation(T=10, capacity=100, n_resources=3):
    """多期资源分配模拟"""
    R = np.ones(n_resources) * capacity / n_resources
    total_reward = 0

    for t in range(T):
        # 随机需求
        demand = np.random.poisson(10, n_resources)
        # 简单策略：按需求比例分配
        total_demand = demand.sum()
        if total_demand > 0 and R.sum() > 0:
            allocation = np.minimum(R, R * demand / total_demand)
        else:
            allocation = np.zeros(n_resources)

        served = np.minimum(allocation, demand)
        reward = served.sum()
        R -= allocation

        # 补充
        R = np.minimum(R + np.random.poisson(8, n_resources), capacity/2)

        total_reward += reward

    print(f"总奖励: {total_reward}")
    print(f"最终库存: {np.round(R, 1)}")

np.random.seed(42)
multiperiod_allocation()
```

## 4. 与其他方法的关系

- **报童问题**：单期版本
- **CAVE算法**：多期问题的VFA方法
- **Benders分解**：大规模多期问题的分解方法
