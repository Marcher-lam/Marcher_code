# 边际值函数(Marginal Value Functions) 学习文档

> 增加一单位资源带来的额外价值——边际值递减是凸资源分配问题的核心性质。

> 来源线索：本节内容根据原书中关于"Values Versus Marginal Values"的相关章节(Ch 18.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：边际值函数 $v(r) = V(R+e_r) - V(R)$ 表示增加一单位类型r的资源带来的额外价值。

## 2. 核心原理

**定义**：
$$v_r(R) = V(R + e_r) - V(R)$$

其中 $e_r$ 是第r个单位向量。

**凸资源分配中的边际值**：
- 值函数 $V(R)$ 关于 $R$ 是凹的（边际值递减）
- 边际值 $v_r(R)$ 关于 $R$ 是单调递减的
- 最优分配：将资源分配到边际值最高的地方

**分段线性近似**：
利用边际值单调递减性质，可以用分段线性函数精确或近似值函数。

**应用**：
- CAVE算法：基于边际值更新的资源分配方法
- 平整算法：用分段线性近似值函数
- 多期资源分配中的值函数近似

## 3. Python 实现

```python
import numpy as np

def marginal_value_example():
    """边际值函数示例"""
    # 假设值函数为凹函数
    def V(R): return 10 * np.sqrt(R + 1) - 10

    # 计算边际值
    max_R = 20
    marginals = np.zeros(max_R)
    for R in range(max_R):
        marginals[R] = V(R + 1) - V(R)

    print("资源量 | 值函数 | 边际值")
    print("-" * 30)
    for R in range(10):
        print(f"  {R:2d}   | {V(R):6.2f} | {marginals[R]:6.3f}")
    print(f"\n边际值单调递减: {all(marginals[i] >= marginals[i+1] for i in range(len(marginals)-1))}")

marginal_value_example()
```

## 4. 与其他方法的关系

- **CAVE算法**：基于边际值的分段线性近似
- **Benders分解**：用切割平面近似值函数
- **微观经济学**：边际效用递减的数学对应
