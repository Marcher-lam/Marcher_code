# 神经网络(Neural Networks) 学习文档

> 通过多层非线性变换学习复杂函数映射，是深度学习和现代值函数近似的基础。

> 来源线索：本节内容根据原书中关于"Neural Networks"的相关章节(Ch 3.9.3)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：神经网络通过堆叠非线性变换层，从数据中学习输入到输出的复杂映射关系。

**直觉类比**：想象一个工厂流水线。原材料（输入）经过多个加工站（层），每个站点做一次简单变换（加权求和+非线性激活），最后产出成品（输出）。每个加工站的"加工方式"（权重）通过训练自动学习。

**历史背景**：神经网络的思想可追溯到McCulloch & Pitts (1943)和Rosenblatt (1958)的感知器。反向传播由Rumelhart, Hinton & Williams (1986)推广。原书Ch 3.9.3中作为值函数近似的参数化模型引入。

**算法定位**：监督学习/函数近似。在原书中是VFA的核心工具。

**前置知识**：线性回归、梯度下降、微积分链式法则。

## 2. 核心原理

**核心思想**：神经网络$f(x|\theta)$通过多层仿射变换和非线性激活函数组合实现通用近似：

$$h^{(l)} = \sigma(W^{(l)} h^{(l-1)} + b^{(l)})$$

单隐层网络可以近似任意连续函数（Universal Approximation Theorem）。

**工作流程**：
1. 前向传播：$x \to h^{(1)} \to \cdots \to h^{(L)} \to \hat{y}$
2. 计算损失：$L = \frac{1}{N}\sum(\hat{y}^n - y^n)^2$
3. 反向传播：用链式法则计算$\partial L / \partial \theta$
4. 参数更新：$\theta \leftarrow \theta - \alpha \nabla_\theta L$

## 3. 数学公式与推导

### 前向传播

第$l$层输出：

$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$$
$$a^{(l)} = \sigma(z^{(l)})$$

激活函数$\sigma$：ReLU($\max(0,z)$)、sigmoid($1/(1+e^{-z})$)、tanh。

### 反向传播

损失对第$l$层权重的梯度：

$$\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^T$$

其中$\delta^{(l)} = (W^{(l+1)})^T \delta^{(l+1)} \odot \sigma'(z^{(l)})$。

### 损失函数

回归：$L = \frac{1}{2N}\sum(\hat{y} - y)^2$（MSE）

分类：$L = -\sum[y\log\hat{y} + (1-y)\log(1-\hat{y})]$（交叉熵）

## 4-6. 简要

### 超参数

| 参数 | 含义 | 推荐范围 |
|------|------|---------|
| 隐层数 | 网络深度 | 1-3 |
| 隐层宽度 | 每层神经元 | 32-512 |
| 学习率α | 梯度步长 | 0.001-0.01 |
| 激活函数 | 非线性变换 | ReLU |

### 应用
1. 值函数近似（DQN、AlphaGo）
2. 策略网络（Actor-Critic）
3. 非线性回归/分类

### 优缺点
**优点**：强大的函数近似能力、自动特征提取
**缺点**：需要大量数据、训练不稳定、可解释性差

## 7-8. 核心实现

```python
"""神经网络：NumPy手工实现反向传播"""
import numpy as np

class NeuralNetwork:
    """三层神经网络（1隐层）"""
    def __init__(self, input_dim, hidden_dim, output_dim, lr=0.01):
        self.lr = lr
        # Xavier初始化
        self.W1 = np.random.randn(input_dim, hidden_dim) * np.sqrt(2.0/input_dim)
        self.b1 = np.zeros(hidden_dim)
        self.W2 = np.random.randn(hidden_dim, output_dim) * np.sqrt(2.0/hidden_dim)
        self.b2 = np.zeros(output_dim)

    @staticmethod
    def _relu(z):
        return np.maximum(0, z)

    @staticmethod
    def _relu_grad(z):
        return (z > 0).astype(float)

    def forward(self, X):
        self.z1 = X @ self.W1 + self.b1
        self.a1 = self._relu(self.z1)
        self.z2 = self.a1 @ self.W2 + self.b2
        return self.z2

    def backward(self, X, y):
        m = len(X)
        y_pred = self.forward(X)

        # 输出层梯度
        dz2 = (y_pred - y) / m
        dW2 = self.a1.T @ dz2
        db2 = dz2.sum(axis=0)

        # 隐层梯度（链式法则）
        da1 = dz2 @ self.W2.T
        dz1 = da1 * self._relu_grad(self.z1)
        dW1 = X.T @ dz1
        db1 = dz1.sum(axis=0)

        # 参数更新
        self.W2 -= self.lr * dW2
        self.b2 -= self.lr * db2
        self.W1 -= self.lr * dW1
        self.b1 -= self.lr * db1

        return np.mean((y_pred - y)**2)

    def predict(self, X):
        return self.forward(X)

if __name__ == "__main__":
    np.random.seed(42)
    n = 500
    X = np.random.randn(n, 2)
    y = (np.sin(X[:, 0]) + X[:, 1]**2).reshape(-1, 1)

    nn = NeuralNetwork(2, 32, 1, lr=0.01)
    for epoch in range(1000):
        loss = nn.backward(X, y)
        if (epoch+1) % 200 == 0:
            print(f"Epoch {epoch+1}: MSE = {loss:.4f}")

    y_pred = nn.predict(X)
    r2 = 1 - np.sum((y - y_pred)**2) / np.sum((y - y.mean())**2)
    print(f"R² = {r2:.4f}")
```

## 9-14. 简要

### 12. 学习总结
神经网络：$a^{(l)} = \sigma(W^{(l)}a^{(l-1)}+b^{(l)})$，反向传播用链式法则求梯度。通用近似器，是原书中VFA的核心工具。

### 13. 练习题
**Q1**：为什么需要非线性激活函数？
**A1**：没有非线性激活，多层线性变换等价于一层：$W_2(W_1x+b_1)+b_2 = (W_2W_1)x + (W_2b_1+b_2)$，网络退化为线性回归。
