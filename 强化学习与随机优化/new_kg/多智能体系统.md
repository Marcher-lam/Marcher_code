## 1-3. 核心认知与公式

**一句话定义**：多智能体系统中多个agent独立决策，每个agent的奖励依赖于其他所有agent的动作。

**模型**：$N$个agent，每个有状态$S_t^i$和动作$a_t^i$，联合动作$\mathbf{a}_t = (a_t^1, \ldots, a_t^N)$：

$$r_t^i = R^i(S_t, \mathbf{a}_t, W_{t+1})$$

**分类**：
- **合作型**：共享奖励，最大化团队收益
- **竞争型**：零和博弈，一方收益=他方损失
- **混合型**：部分合作部分竞争

**挑战**：
- 非平稳性：每个agent面对的环境因其他agent学习而变化
- 维度爆炸：联合状态-动作空间指数增长
- 信用分配：如何将团队奖励归因到个体

**方法**：
- 独立Q学习（简单但忽略交互）
- 中心化训练+去中心化执行（CTDE）
- 通信机制（共享信息）

## 4-8. 核心实现

```python
"""多智能体系统：独立Q学习"""
import numpy as np

class IndependentQLearner:
    def __init__(self, n_states, n_actions, lr=0.1, gamma=0.95, epsilon=0.1):
        self.Q = np.zeros((n_states, n_actions))
        self.lr, self.gamma, self.epsilon = lr, gamma, epsilon
        self.nA = n_actions

    def select(self, s):
        if np.random.random() < self.epsilon:
            return np.random.randint(self.nA)
        return np.argmax(self.Q[s])

    def update(self, s, a, r, s_next):
        td = r + self.gamma * self.Q[s_next].max() - self.Q[s, a]
        self.Q[s, a] += self.lr * td

if __name__ == "__main__":
    np.random.seed(42)
    N = 3  # 3个agent
    agents = [IndependentQLearner(10, 3) for _ in range(N)]
    for ep in range(500):
        states = [np.random.randint(10) for _ in range(N)]
        actions = [ag.select(s) for ag, s in zip(agents, states)]
        # 协作奖励：动作和接近目标值
        team_reward = -abs(sum(actions) - 4) + 2
        for i, ag in enumerate(agents):
            s_next = np.random.randint(10)
            ag.update(states[i], actions[i], team_reward, s_next)
    for i, ag in enumerate(agents):
        print(f"Agent {i} Q表均值: {ag.Q.mean():.3f}")
```

## 9-14. 简要

### 12. 学习总结
多智能体：$N$个agent联合决策，奖励$R^i(S,\mathbf{a})$。核心挑战是非平稳性和信用分配。

### 13. 练习题
**Q1**：为什么独立Q学习在多智能体中不稳定？
**A1**：每个agent面对的转移函数因其他agent策略变化而改变（非平稳环境），违反Q学习的马尔可夫假设。
