# 指数平滑(Exponential Smoothing) 学习文档

> 指数平滑是最简单实用的在线学习算法，用加权平均逐步更新估计值。

> 来源线索：本节内容根据原书中关于"Adaptive Learning Using Exponential Smoothing"的相关章节(Ch 3.2)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：指数平滑用固定比例$\alpha$将新观测与旧估计加权平均，是最基本的在线参数更新方法。

**直觉类比**：你预测明天的气温。不是记住所有历史数据再算平均，而是：新预测 = (1-α)×旧预测 + α×今天实际温度。如果$\alpha=0.3$，今天的实际温度占30%权重，之前的预测占70%。这种方式自动赋予近期数据更高权重。

**历史背景**：指数平滑由Robert Goodell Brown在1956年在库存管理中系统使用。它是SGD在目标函数为$\frac{1}{2}(x-\mu)^2$时的特例，也是TD(0)更新的基础形式。

**算法定位**：在线学习/自适应估计方法。在原书Ch 3.2中作为最基本的在线学习工具引入。

**前置知识**：概率论（均值、方差）、Python。

## 2. 核心原理

**更新公式**：

$$\bar{\mu}^{n+1} = (1-\alpha_n)\bar{\mu}^n + \alpha_n W^{n+1}$$

- $\bar{\mu}^n$：$n$步后的估计值
- $W^{n+1}$：第$n+1$个观测
- $\alpha_n$：步长/学习率/平滑因子

**关键性质**：
- $\alpha=1/n$时退化为简单算术平均
- $\alpha$固定时，远期观测的权重以$(1-\alpha)^k$指数衰减
- 等价于$\bar{\mu}^n = \sum_{k=1}^n w_k W^k$，权重$w_k = \alpha(1-\alpha)^{n-k}$

## 3. 数学公式与推导

### 展开

$$\bar{\mu}^n = \alpha\sum_{k=0}^{n-1}(1-\alpha)^k W^{n-k} + (1-\alpha)^n\bar{\mu}^0$$

当$n\to\infty$且$\alpha\in(0,1)$时，初始值$(1-\alpha)^n\bar{\mu}^0\to 0$。

### 等价SGD

指数平滑等价于SGD在$\min_\mu \frac{1}{2}\mathbb{E}[(W-\mu)^2]$上的更新：

$$\mu^{n+1} = \mu^n - \alpha_n(\mu^n - W^{n+1}) = (1-\alpha_n)\mu^n + \alpha_n W^{n+1}$$

### 偏差和方差

- 固定$\alpha$时：估计有偏差（跟不上真实值变化），但能跟踪非平稳过程
- $\alpha_n = 1/n$时：无偏但方差大，且无法跟踪变化

## 4-6. 简要

### 超参数

| $\alpha$ | 效果 |
|---------|------|
| 大(0.3-0.5) | 响应快，噪声多 |
| 小(0.05-0.1) | 平滑，滞后大 |
| $1/n$ | 算术平均，不跟踪 |

### 应用
1. 时间序列预测（需求预测、股价）
2. 在线参数估计（值函数、Q值更新）
3. 信号处理（滤波）

## 7-8. 实现

```python
"""指数平滑"""
import numpy as np

class ExponentialSmoothing:
    def __init__(self, alpha=0.3, initial=0.0):
        self.alpha = alpha
        self.estimate = initial

    def update(self, observation):
        self.estimate = (1 - self.alpha) * self.estimate + self.alpha * observation
        return self.estimate

    def predict(self):
        return self.estimate

# 测试
if __name__ == "__main__":
    np.random.seed(42)
    true_mean = 5.0
    data = np.random.normal(true_mean, 1.0, 100)

    es = ExponentialSmoothing(alpha=0.2)
    estimates = []
    for x in data:
        est = es.update(x)
        estimates.append(est)

    print(f"真实均值: {true_mean}")
    print(f"最终估计: {es.estimate:.3f}")
    print(f"算术平均: {np.mean(data):.3f}")
```

### 11. 常见问题
1. **初始值选择**：用第一个观测初始化，或用前几个值的平均
2. **α选择**：用交叉验证或最小化预测误差

### 12. 学习总结
指数平滑：$\bar{\mu}^{n+1} = (1-\alpha)\bar{\mu}^n + \alpha W^{n+1}$。是SGD、TD更新的基本形式，权重按$(1-\alpha)^k$指数衰减。

### 13. 练习题
**Q1**：证明$\alpha_n=1/n$时指数平滑退化为算术平均。
**A1**：归纳法。$\bar{\mu}^1 = W^1$。假设$\bar{\mu}^n = \frac{1}{n}\sum_{k=1}^n W^k$，则$\bar{\mu}^{n+1} = \frac{n}{n+1}\bar{\mu}^n + \frac{1}{n+1}W^{n+1} = \frac{1}{n+1}\sum_{k=1}^{n+1}W^k$。证毕。
