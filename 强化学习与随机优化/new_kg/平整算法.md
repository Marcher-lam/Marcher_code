# 平整算法(Leveling Algorithm) 学习文档

> 将波动值函数"拉平"为单调递减的阶梯函数，是CAVE的简化版。

> 来源线索：本节内容根据原书中关于"Leveling Algorithm"的相关章节(Ch 18.3.1)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：平整算法将估计的值函数平滑为单调阶梯形，消除噪声导致的非单调波动。

**核心操作**：给定估计$\bar{v}(R)$，从左到右扫描，若$\bar{v}(R_{i+1}) > \bar{v}(R_i)$（违反递减），将两者"拉平"到平均值。

## 4-8. 核心实现

```python
"""平整算法"""
import numpy as np

def leveling(values):
    """将值函数平整为单调递减"""
    v = values.copy()
    n = len(v)
    i = 0
    while i < n - 1:
        if v[i+1] > v[i]:
            # 找到需要平整的范围
            j = i
            total = v[i]
            while j < n-1 and v[j+1] > v[j]:
                j += 1
                total += v[j]
            avg = total / (j - i + 1)
            for k in range(i, j+1):
                v[k] = avg
            i = j + 1
        else:
            i += 1
    return v

if __name__ == "__main__":
    np.random.seed(42)
    true_v = np.array([10, 8, 6, 5, 3, 2, 1.5, 1, 0.5, 0.2])
    noisy_v = true_v + np.random.randn(10) * 1.5
    leveled = leveling(noisy_v)
    print(f"真实值:  {true_v.round(2)}")
    print(f"含噪声:  {noisy_v.round(2)}")
    print(f"平整后:  {leveled.round(2)}")
```

## 9-14. 简要

### 12. 学习总结
平整算法：扫描+平均违反单调性的相邻段。简单有效的后处理步骤，保证值函数结构。

### 13. 练习题
**Q1**：平整和直接取均值有什么区别？
**A1**：平整只在违反单调性时局部平均，保留整体趋势。全局均值会丢失所有结构信息。
