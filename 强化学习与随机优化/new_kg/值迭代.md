# 值迭代(Value Iteration) 学习文档

> 值迭代通过反复应用Bellman最优算子逐步逼近最优值函数，是动态规划最经典的求解算法。

> 来源线索：本节内容根据原书中关于"Value Iteration for Infinite Horizon Problems"的相关章节(Ch 14.6)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：值迭代是一种动态规划算法，通过反复应用Bellman最优性方程直到收敛来求解MDP的最优值函数和最优策略。

**直觉类比**：想象一张地图上每个城市都标注了"从这里到目的地的最短距离"。一开始你只知道目的地的距离是0，其他城市都是未知。每轮迭代，每个城市都问邻居："你的距离是多少？"然后更新自己的距离为"到邻居的距离+1步"中最小的。反复迭代后，所有城市的标注都收敛到真实最短距离。

**历史背景**：值迭代由Richard Bellman在1957年提出，是动态规划的核心算法之一。它直接求解Bellman最优性方程，是有限状态MDP的标准精确求解方法。

**算法定位**：动态规划/精确求解方法。值迭代是原书Ch 14（精确动态规划）的核心算法。

**前置知识**：MDP、Bellman方程、矩阵运算。

## 2. 核心原理

**核心思想**：Bellman最优算子$\mathcal{T}$是$\gamma$-压缩映射。反复应用$\mathcal{T}$（即值迭代），值函数序列$V^{(0)}, V^{(1)}, V^{(2)}, ...$必然收敛到唯一的不动点$V^*$（最优值函数）。

**工作流程**：

1. 初始化$V^{(0)}(s) = 0$（或任意值）
2. 对每个状态$s$，计算：$V^{(k+1)}(s) = \max_a (r(s,a) + \gamma \sum_{s'} P(s'|s,a) V^{(k)}(s'))$
3. 检查$\|V^{(k+1)} - V^{(k)}\|_\infty < \epsilon$
4. 若未收敛，回到步骤2
5. 从最终$V$提取最优策略：$\pi^*(s) = \arg\max_a (r(s,a) + \gamma \sum_{s'} P(s'|s,a) V(s'))$

**关键概念**：

- **Bellman算子**$\mathcal{T}$：一次完整的值函数更新
- **压缩映射**：$\|\mathcal{T}V - \mathcal{T}U\|_\infty \leq \gamma\|V-U\|_\infty$
- **收敛速率**：每次迭代误差至少以$\gamma$的比率衰减

```
V⁽⁰⁾ = [0, 0, 0, 0]    初始值（全零）
V⁽¹⁾ = TV⁽⁰⁾             第一轮Bellman更新
V⁽²⁾ = TV⁽¹⁾             第二轮...
...
V⁽ⁿ⁾ → V*               收敛到最优值函数
```

## 3. 数学公式与推导

### 值迭代更新公式

$$V^{(k+1)}(s) = \max_{a \in \mathcal{A}_s} \left[r(s,a) + \gamma \sum_{s' \in \mathcal{S}} P(s'|s,a) V^{(k)}(s')\right], \quad \forall s \in \mathcal{S}$$

### 向量形式

$$v^{(k+1)} = \max_\pi (r^\pi + \gamma P^\pi v^{(k)})$$

### Gauss-Seidel变体

标准值迭代使用上一轮的值$V^{(k)}$更新所有状态。Gauss-Seidel变体使用已更新的值：

$$V^{(k+1)}(s_i) = \max_a (r(s_i,a) + \gamma \sum_j P(s_j|s_i,a) V^{(new)}(s_j)_{j<i} + \gamma \sum_j P(s_j|s_i,a) V^{(old)}(s_j)_{j\geq i})$$

通常收敛更快，因为利用了最新信息。

### 相对值迭代

对平均奖励问题，减去一个参考值避免$V$无限增长：

$$V^{(k+1)}(s) = \max_a (r(s,a) + \gamma \sum_{s'} P(s'|s,a) V^{(k)}(s')) - V^{(k)}(s_{ref})$$

### 收敛速率

每轮迭代误差上界：

$$\|V^{(k)} - V^*\|_\infty \leq \frac{\gamma^k}{1-\gamma} \|V^{(1)} - V^{(0)}\|_\infty$$

策略提取的精度保证：若$\|V - V^*\|_\infty < \epsilon$，则提取的策略$\pi_V$满足$V^{\pi_V}(s) \geq V^*(s) - \frac{2\gamma\epsilon}{1-\gamma}$。

## 4. 训练过程讲解

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $\gamma$ | 折扣因子 | [0.9, 0.999] | 0.95 |
| $\epsilon$ | 收敛阈值 | [1e-6, 1e-10] | 1e-6 |
| max_iter | 最大迭代 | [100, 100000] | 10000 |

### 收敛判断
- $\|V^{(k+1)} - V^{(k)}\|_\infty < \epsilon$
- 理论上$\gamma$越接近1，收敛越慢

## 5. 应用场景

1. **最短路径**：确定性环境中的路径规划
2. **库存管理**：最优订购策略
3. **资源分配**：最优分配方案
4. **游戏AI**：小规模游戏的最优策略

## 6. 优缺点分析

### 优点
1. **理论最优**：收敛到精确最优解
2. **实现简单**：核心代码不到20行
3. **收敛保证**：$\gamma<1$时必收敛

### 缺点
1. **维度灾难**：$O(|\mathcal{S}|^2|\mathcal{A}|)$每轮
2. **需要完整模型**：必须知道$P$和$r$
3. **$\gamma$接近1时收敛慢**

### 算法对比

| 特性 | 值迭代 | 策略迭代 | Q-Learning |
|------|--------|---------|------------|
| 需要模型 | 是 | 是 | 否 |
| 每轮复杂度 | $O(S^2A)$ | $O(S^3)$ | $O(1)$ |
| 收敛速度 | 中 | 快 | 慢 |
| 内存 | $O(S)$ | $O(S^2)$ | $O(SA)$ |

## 7. 调库实现

```python
"""值迭代求解FrozenLake"""
import numpy as np

def value_iteration(P, R, gamma=0.95, epsilon=1e-6):
    n_states = P.shape[0]
    n_actions = P.shape[1]
    V = np.zeros(n_states)

    for i in range(10000):
        Q = R + gamma * np.einsum('ijk,k->ij', P, V)
        V_new = np.max(Q, axis=1)
        if np.max(np.abs(V_new - V)) < epsilon:
            print(f"值迭代在第{i+1}轮收敛")
            V = V_new
            break
        V = V_new

    policy = np.argmax(Q, axis=1)
    return V, policy

# 示例：4x4网格
n = 16; na = 4
P = np.zeros((n, na, n))
R = np.zeros((n, na)); R[15,:] = 1.0
for s in range(n):
    r, c = s//4, s%4
    for a in range(na):
        if a==0: nr,nc=max(r-1,0),c
        elif a==1: nr,nc=r,min(c+1,3)
        elif a==2: nr,nc=min(r+1,3),c
        else: nr,nc=r,max(c-1,0)
        P[s,a,nr*4+nc] = 1.0

V, pi = value_iteration(P, R, gamma=0.95)
print(f"最优值函数:\n{V.reshape(4,4).round(3)}")
print(f"最优策略:\n{pi.reshape(4,4)}")
```

## 8. 手工代码实现

```python
"""从零实现值迭代（含Gauss-Seidel变体）"""
import numpy as np

class ValueIteration:
    def __init__(self, P, R, gamma=0.95):
        self.P, self.R, self.gamma = P, R, gamma
        self.n_states = P.shape[0]
        self.n_actions = P.shape[1]

    def solve(self, epsilon=1e-6, max_iter=10000, gauss_seidel=False):
        V = np.zeros(self.n_states)
        for i in range(max_iter):
            delta = 0
            if gauss_seidel:
                for s in range(self.n_states):
                    v_old = V[s]
                    Q_s = self.R[s] + self.gamma * self.P[s] @ V
                    V[s] = np.max(Q_s)
                    delta = max(delta, abs(V[s] - v_old))
            else:
                Q = self.R + self.gamma * np.einsum('ijk,k->ij', self.P, V)
                V_new = np.max(Q, axis=1)
                delta = np.max(np.abs(V_new - V))
                V = V_new
            if delta < epsilon:
                print(f"收敛于第{i+1}轮")
                break
        Q = self.R + self.gamma * np.einsum('ijk,k->ij', self.P, V)
        return V, np.argmax(Q, axis=1)

if __name__ == "__main__":
    np.random.seed(42)
    # 构建5x5网格
    n = 25; na = 4
    P = np.zeros((n, na, n)); R = np.full((n, na), -0.1)
    R[24, :] = 10.0  # 目标
    for s in range(n):
        r, c = s//5, s%5
        for a in range(na):
            if a==0: nr,nc=max(r-1,0),c
            elif a==1: nr,nc=r,min(c+1,4)
            elif a==2: nr,nc=min(r+1,4),c
            else: nr,nc=r,max(c-1,0)
            P[s,a,nr*5+nc] = 1.0

    vi = ValueIteration(P, R, gamma=0.95)
    V, pi = vi.solve()
    print(f"值函数:\n{V.reshape(5,5).round(2)}")
```

## 10-14. 简要补充

### 10. 模型评估
通过仿真评估策略的累积奖励，与理论最优值$V(s_0)$比较。

### 11. 常见问题
1. **$\gamma=1$不收敛**：确保$\gamma<1$或使用平均奖励框架
2. **状态空间太大**：使用函数近似（ADP）
3. **收敛阈值过松**：用更小的$\epsilon$

### 12. 学习总结
值迭代通过反复应用Bellman算子$\mathcal{T}$利用其$\gamma$-压缩性质保证收敛。公式：$V^{(k+1)}(s) = \max_a(r(s,a) + \gamma\sum_{s'}P(s'|s,a)V^{(k)}(s'))$。它是策略迭代、Q-Learning等方法的简化版本。

### 13. 练习题
**Q1**：证明$\gamma=0.9$时，值迭代至多需要$\log(\epsilon(1-\gamma)/\|V^{(1)}-V^{(0)}\|)/\log(\gamma)$轮收敛。
**A1**：由压缩性质$\|V^{(k)}-V^*\| \leq \gamma^k/(1-\gamma)\|V^{(1)}-V^{(0)}\|$，令$\gamma^k/(1-\gamma)\|V^{(1)}-V^{(0)}\| < \epsilon$，解得$k > \log(\epsilon(1-\gamma)/\|V^{(1)}-V^{(0)}\|)/\log(\gamma)$。
