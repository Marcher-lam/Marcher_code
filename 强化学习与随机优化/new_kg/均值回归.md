# 均值回归(Mean Reversion) 学习文档

> 价格围绕均值波动的随机过程模型，是金融和能源价格建模的基础。

> 来源线索：本节内容根据原书中关于"Mean Reversion"的相关章节(Ch 10.5.1)整理、扩展与教学化改写。

## 1-3. 核心认知与公式

**一句话定义**：均值回归模型假设价格偏离均值后有回归趋势，用Ornstein-Uhlenbeck过程建模。

**模型**：

$$p_{t+1} = p_t + \kappa(\bar{\mu}_t - p_t) + \varepsilon_{t+1}$$

- $\bar{\mu}_t$：指数平滑均值 $(1-\eta)\bar{\mu}_{t-1} + \eta p_t$
- $\kappa$：回归速度（0到1之间）
- $\varepsilon_{t+1} \sim N(0, \sigma^2)$

**含义**：当$p_t > \bar{\mu}_t$（价格高于均值），下一期被拉低；反之亦然。

**参数估计**：$\kappa$和$\eta$通过最小化预测误差拟合。$\sigma^2$由残差估计。

## 4-8. 核心实现

```python
"""均值回归模型：Ornstein-Uhlenbeck过程"""
import numpy as np

class MeanReversion:
    def __init__(self, kappa=0.1, eta=0.05):
        self.kappa = kappa
        self.eta = eta

    def simulate(self, p0, sigma, T):
        prices = [p0]
        mu_bar = p0
        for t in range(T):
            mu_bar = (1-self.eta)*mu_bar + self.eta*prices[-1]
            p_next = prices[-1] + self.kappa*(mu_bar - prices[-1]) + sigma*np.random.randn()
            prices.append(p_next)
        return np.array(prices)

    def forecast(self, prices, steps=10):
        mu_bar = prices[-1]
        for p in prices[-20:]:
            mu_bar = (1-self.eta)*mu_bar + self.eta*p
        forecast = [prices[-1]]
        for _ in range(steps):
            f = forecast[-1] + self.kappa*(mu_bar - forecast[-1])
            forecast.append(f)
        return np.array(forecast[1:])

if __name__ == "__main__":
    np.random.seed(42)
    mr = MeanReversion(kappa=0.3, eta=0.05)
    prices = mr.simulate(50.0, 2.0, 500)
    print(f"模拟价格: 均值={prices.mean():.1f}, 标准差={prices.std():.1f}")
    fc = mr.forecast(prices, steps=5)
    print(f"5步预测: {fc.round(2)}")
```

## 9-14. 简要

### 12. 学习总结
均值回归：$p_{t+1} = p_t + \kappa(\bar{\mu}-p_t) + \varepsilon$。价格偏离后被拉回均值，用O-U过程建模。原书用于电力价格。

### 13. 练习题
**Q1**：$\kappa=0$时退化为什么？
**A1**：随机游走$p_{t+1} = p_t + \varepsilon$。无回归力，价格自由漂移。
