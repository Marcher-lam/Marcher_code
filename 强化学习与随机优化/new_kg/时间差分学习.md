# 时间差分学习(TD Learning) 学习文档

> TD学习结合了蒙特卡洛的采样思想和动态规划的自举机制，是强化学习中最核心的值函数估计方法。

> 来源线索：本节内容根据原书中关于"Temporal Difference Updates"的相关章节(Ch 16.1)整理、扩展与教学化改写。

## 1. 算法基础认知

**一句话定义**：时间差分（TD）学习是一种通过观察到的即时奖励和下一状态的估计值来更新当前状态值函数的在线学习方法。

**直觉类比**：假设你要预估从家到公司的时间。你不需要每天走完全程才能更新估计（那是蒙特卡洛方法）。当你从家走到第一个路口花了5分钟，你就可以立即更新"从家出发的总时间"估计：5分钟加上"从路口到公司"的已有估计。这就是TD学习的核心——"边走边更新"。

**历史背景**：TD学习由Richard Sutton在1988年的论文中系统提出。核心思想是将蒙特卡洛采样与动态规划的自举（bootstrapping）相结合。Sutton证明了TD(λ)在一定条件下比蒙特卡洛方法收敛更快。TD(0)是Q-Learning、SARSA等算法的基础。

**算法定位**：在线学习/值函数估计方法。TD学习既可以用于策略评估（预测问题），也可以与策略改进结合用于控制问题。

**前置知识**：马尔可夫决策过程、Bellman方程、概率论（期望、方差）。

## 2. 核心原理

**核心思想**：TD学习利用"自举"——用一个估计值来更新另一个估计值。具体来说，它用$r_{t+1} + \gamma V(S_{t+1})$（TD目标）来更新$V(S_t)$。这个目标结合了实际观察到的奖励$r_{t+1}$和对未来的估计$V(S_{t+1})$。

**工作流程**（TD(0)）：

1. 在状态$S_t$，选择动作$A_t$（根据当前策略）
2. 执行动作，获得奖励$R_{t+1}$，转移到状态$S_{t+1}$
3. 计算TD误差：$\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$
4. 更新值函数：$V(S_t) \leftarrow V(S_t) + \alpha \delta_t$
5. 重复

**TD(λ)的扩展**：
- TD(0)只用一步自举
- TD(λ)使用资格迹（eligibility traces），将多步信息融合
- λ=0等价于TD(0)，λ=1等价于蒙特卡洛

**关键概念**：

- **自举（Bootstrapping）**：用估计值更新估计值
- **TD误差**$\delta_t$：实际观察与当前估计之间的差距
- **TD目标**：$R_{t+1} + \gamma V(S_{t+1})$，对$V(S_t)$的改进估计
- **资格迹（Eligibility Trace）**：记录哪些状态"有资格"被更新
- **n步回报**：融合n步实际奖励和后续估计值

```
TD(0):     V(S_t) ← R_{t+1} + γV(S_{t+1})
2步TD:     V(S_t) ← R_{t+1} + γR_{t+2} + γ²V(S_{t+2})
...
蒙特卡洛:  V(S_t) ← R_{t+1} + γR_{t+2} + ... + γ^{T-t-1}R_T

TD(λ) = 所有n步回报的加权平均（权重 ∝ λ^{n-1}）
```

## 3. 数学公式与推导

### 符号约定

| 符号 | 含义 |
|------|------|
| $V(s)$ | 状态值函数估计 |
| $\delta_t$ | TD误差 |
| $\alpha$ | 学习率（步长） |
| $\gamma$ | 折扣因子 |
| $\lambda$ | 资格迹衰减参数 |
| $e_t(s)$ | 资格迹 |
| $G_t^{(n)}$ | n步回报 |

### TD(0)更新

最基本的TD更新：

$$V(S_t) \leftarrow V(S_t) + \alpha [R_{t+1} + \gamma V(S_{t+1}) - V(S_t)]$$

其中TD误差为：

$$\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$$

### n步TD

n步回报定义为：

$$G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n})$$

n步TD更新：

$$V(S_t) \leftarrow V(S_t) + \alpha [G_t^{(n)} - V(S_t)]$$

### TD(λ)前向视角

TD(λ)是所有n步回报的λ-加权平均：

$$G_t^\lambda = (1-\lambda)\sum_{n=1}^{\infty} \lambda^{n-1} G_t^{(n)}$$

### TD(λ)后向视角（资格迹）

资格迹更新：

$$e_t(s) = \begin{cases} \gamma\lambda e_{t-1}(s) + 1 & \text{if } s = S_t \\ \gamma\lambda e_{t-1}(s) & \text{otherwise} \end{cases}$$

值函数更新（所有状态）：

$$V(s) \leftarrow V(s) + \alpha \delta_t e_t(s), \quad \forall s$$

前向和后向视角在离线情况下等价。

### TD(0)与近似值迭代的关系

当使用TD(0)进行策略评估，同时逐步改进策略时，等价于随机近似值迭代：

$$\hat{V}_t(S_t) = R_{t+1} + \gamma V(S_{t+1})$$

这是对Bellman方程的一次采样近似。

## 4. 训练过程讲解

### 数据预处理
- 状态离散化（对于连续状态）
- 奖励归一化（可选，有助于稳定学习）

### 参数初始化
- 值函数：$V(s) = 0$
- 资格迹：$e_0(s) = 0$

### 迭代过程

**TD(0)策略评估**：
1. 在每个时间步，观察$(S_t, R_{t+1}, S_{t+1})$
2. 计算TD误差$\delta_t$
3. 更新$V(S_t)$

**TD(λ)控制**（如SARSA(λ)）：
1. 初始化$e(s,a) = 0$
2. 每步：计算TD误差，更新资格迹，用$\delta \times e$更新所有Q值

### 收敛条件
- TD(0)：步长满足Robbins-Monro条件时收敛到$V^\pi$
- TD(λ)：λ∈[0,1]时收敛

### 超参数表

| 参数 | 含义 | 推荐范围 | 默认值 |
|------|------|----------|--------|
| $\alpha$ | 学习率 | [0.01, 0.5] | 0.1 |
| $\gamma$ | 折扣因子 | [0.9, 0.99] | 0.95 |
| $\lambda$ | 资格迹参数 | [0.0, 1.0] | 0.5 |
| $\varepsilon$ | 探索率 | [0.01, 0.3] | 0.1 |

## 5. 应用场景

### 1. 策略评估
为什么适合：TD学习可以在线、增量式地评估某个策略的值函数，不需要等待整个回合结束。

### 2. 时序预测
为什么适合：TD学习最初就是为多步预测问题设计的（如天气预测、股票预测），能结合新观测和已有预测。

### 3. 游戏AI训练
为什么适合：游戏中的状态转移可以快速模拟，TD学习可以高效利用每次交互更新多个状态的估计。

### 4. 机器人控制
为什么适合：机器人需要在线学习，TD学习可以在与环境交互的同时更新值函数。

### 不适用场景
- 非马尔可夫环境（需要RNN等记忆方法）
- 需要精确策略评估（TD有偏差）
- 奖励极其稀疏（TD信号太弱）

## 6. 优缺点分析

### 优点
1. **在线学习**：不需要等待回合结束，每步即可更新
2. **低方差**：相比蒙特卡洛，TD目标的方差更低
3. **计算高效**：每次更新只涉及当前和下一个状态
4. **灵活性**：λ参数可以在偏差（TD(0)）和方差（MC）之间权衡

### 缺点
1. **有偏差**：自举引入偏差，初始值函数不准确时会传播错误
2. **需要调参**：$\alpha$和$\lambda$的选择影响性能
3. **收敛较慢**：对高维问题可能需要大量样本
4. **受函数近似影响大**：配合非线性函数近似时可能不收敛

### 算法对比

| 特性 | TD(0) | TD(λ) | 蒙特卡洛 | 动态规划 |
|------|-------|-------|---------|---------|
| 自举 | 是 | 是 | 否 | 是 |
| 采样 | 是 | 是 | 是 | 否 |
| 在线更新 | 是 | 是 | 否（回合结束） | — |
| 偏差 | 有 | 有（λ<1） | 无 | 无 |
| 方差 | 低 | 中 | 高 | 低 |
| 需要模型 | 否 | 否 | 否 | 是 |

## 7. 调库实现

```python
"""
TD学习示例：使用gymnasium的CliffWalking环境
对比TD(0)策略评估和蒙特卡洛策略评估
"""
import numpy as np
import gymnasium as gym

def td0_policy_evaluation(env, policy, gamma=0.99, alpha=0.1, n_episodes=5000):
    """TD(0)策略评估：估计给定策略的值函数"""
    n_states = env.observation_space.n
    V = np.zeros(n_states)

    for ep in range(n_episodes):
        state, _ = env.reset()
        done = False

        while not done:
            action = policy[state]
            next_state, reward, terminated, truncated, _ = env.step(action)
            done = terminated or truncated

            # TD(0)更新：V(S_t) <- V(S_t) + α[R + γV(S_{t+1}) - V(S_t)]
            td_target = reward + gamma * V[next_state] * (1 - terminated)
            td_error = td_target - V[state]
            V[state] += alpha * td_error

            state = next_state

    return V

# 创建环境和随机策略
env = gym.make('CliffWalking-v0')
n_states = env.observation_space.n
n_actions = env.action_space.n
random_policy = np.random.randint(n_actions, size=n_states)

# 运行TD(0)策略评估
V = td0_policy_evaluation(env, random_policy)
print(f"TD(0)策略评估完成，值函数范围: [{V.min():.2f}, {V.max():.2f}]")
env.close()
```

## 8. 手工代码实现

```python
"""
从零实现TD(0)和TD(λ)
使用NumPy，自定义网格世界环境
"""
import numpy as np

class SimpleGridWorld:
    """4x4网格世界环境"""
    def __init__(self, size=4):
        self.size = size
        self.n_states = size * size
        self.n_actions = 4
        self.goal = size * size - 1

    def reset(self):
        self.pos = 0
        return self.pos

    def step(self, action):
        row, col = self.pos // self.size, self.pos % self.size
        if action == 0: row = max(row-1, 0)
        elif action == 1: col = min(col+1, self.size-1)
        elif action == 2: row = min(row+1, self.size-1)
        elif action == 3: col = max(col-1, 0)
        self.pos = row * self.size + col
        done = (self.pos == self.goal)
        reward = 1.0 if done else -0.01
        return self.pos, reward, done


class TDLearning:
    """TD学习算法集合"""

    def __init__(self, n_states, n_actions, gamma=0.95):
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma

    def td0_evaluation(self, env, policy, alpha=0.1, n_episodes=3000):
        """TD(0)策略评估"""
        V = np.zeros(self.n_states)

        for _ in range(n_episodes):
            s = env.reset()
            done = False
            while not done:
                a = policy[s]
                s_next, r, done = env.step(a)
                # TD目标 = 即时奖励 + γ × 下一状态值
                td_target = r + self.gamma * V[s_next] * (1 - done)
                V[s] += alpha * (td_target - V[s])
                s = s_next
        return V

    def td_lambda_evaluation(self, env, policy, alpha=0.1, lam=0.5, n_episodes=3000):
        """TD(λ)策略评估（后向视角，资格迹）"""
        V = np.zeros(self.n_states)

        for _ in range(n_episodes):
            e = np.zeros(self.n_states)  # 资格迹初始化
            s = env.reset()
            done = False

            while not done:
                a = policy[s]
                s_next, r, done = env.step(a)

                # TD误差
                td_target = r + self.gamma * V[s_next] * (1 - done)
                delta = td_target - V[s]

                # 更新资格迹：访问的状态+1，其余衰减
                e[s] += 1.0

                # 用TD误差 × 资格迹更新所有状态
                V += alpha * delta * e

                # 资格迹衰减
                e *= self.gamma * lam

                s = s_next
        return V

    def sarsa_lambda(self, env, alpha=0.1, lam=0.5, epsilon=0.1, n_episodes=5000):
        """SARSA(λ)控制算法"""
        Q = np.zeros((self.n_states, self.n_actions))

        for ep in range(n_episodes):
            e = np.zeros((self.n_states, self.n_actions))
            s = env.reset()
            # ε-greedy选择动作
            a = np.argmax(Q[s]) if np.random.random() > epsilon else np.random.randint(self.n_actions)
            done = False

            while not done:
                s_next, r, done = env.step(a)
                a_next = np.argmax(Q[s_next]) if np.random.random() > epsilon else np.random.randint(self.n_actions)

                # TD误差（SARSA：使用实际选择的动作）
                td_target = r + self.gamma * Q[s_next, a_next] * (1 - done)
                delta = td_target - Q[s, a]

                # 更新资格迹
                e[s, a] += 1.0

                # 更新所有Q值
                Q += alpha * delta * e

                # 资格迹衰减
                e *= self.gamma * lam

                s, a = s_next, a_next

        return Q, np.argmax(Q, axis=1)


# ========== 测试 ==========
if __name__ == "__main__":
    np.random.seed(42)
    env = SimpleGridWorld(size=4)
    td = TDLearning(env.n_states, env.n_actions, gamma=0.95)

    # 固定策略：总是向右或向下（贪心趋向目标）
    policy = np.zeros(env.n_states, dtype=int)
    for s in range(env.n_states):
        row, col = s // 4, s % 4
        policy[s] = 2 if row < 3 else 1  # 优先向下，到底后向右

    # TD(0)策略评估
    V_td0 = td.td0_evaluation(env, policy, alpha=0.1)
    print("TD(0)值函数:")
    print(V_td0.reshape(4, 4).round(3))

    # TD(λ)策略评估
    V_tdl = td.td_lambda_evaluation(env, policy, alpha=0.1, lam=0.5)
    print("\nTD(λ=0.5)值函数:")
    print(V_tdl.reshape(4, 4).round(3))

    # SARSA(λ)控制
    Q, opt_policy = td.sarsa_lambda(env, alpha=0.1, lam=0.5, epsilon=0.1)
    print("\nSARSA(λ)学习到的策略:")
    arrows = ['↑', '→', '↓', '←']
    for s in range(env.n_states):
        print(arrows[opt_policy[s]], end=' ')
        if (s+1) % 4 == 0: print()
